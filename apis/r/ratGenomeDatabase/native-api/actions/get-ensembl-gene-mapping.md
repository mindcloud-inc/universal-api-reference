# Get Ensembl Gene Mapping with Rat Genome Database

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/id/map/EnsemblGene/:rgdId`
- **Base URL:** `https://rest.rgd.mcw.edu/rgdws`
- **Official documentation:** [Get Ensembl Gene Mapping](https://rest.rgd.mcw.edu/rgdws/rgd-api-docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `rgdId` | path | `string` | no |
