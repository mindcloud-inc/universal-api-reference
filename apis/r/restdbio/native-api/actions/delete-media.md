# Delete Media with Restdb.io

Deletes media content from Restdb.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/media/:mediaId`
- **Base URL:** `https://mindcloudstage0-7934.restdb.io`
- **Official documentation:** [Delete Media](https://restdb.io/media/restdb-cheat-sheet.pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `string` | yes | Restdb.io media archive ID or file name. |
