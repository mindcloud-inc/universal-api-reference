# Get Collection Metadata with Restdb.io

Retrieves collection metadata from Restdb.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/:collection/_meta`
- **Base URL:** `https://mindcloudstage0-7934.restdb.io`
- **Official documentation:** [Get Collection Metadata](https://restdb.io/media/restdb-cheat-sheet.pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection` | path | `string` | yes | Collection name in the target Restdb.io database. |
