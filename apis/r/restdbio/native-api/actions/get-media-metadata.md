# Get Media Metadata with Restdb.io

Retrieves media metadata from Restdb.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/media/:mediaId/meta`
- **Base URL:** `https://mindcloudstage0-7934.restdb.io`
- **Official documentation:** [Get Media Metadata](https://restdb.io/media/restdb-cheat-sheet.pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `string` | yes | Restdb.io media archive ID or file name. |
