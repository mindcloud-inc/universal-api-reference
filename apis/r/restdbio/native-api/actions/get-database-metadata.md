# Get Database Metadata with Restdb.io

Retrieves database metadata from Restdb.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/_meta`
- **Base URL:** `https://mindcloudstage0-7934.restdb.io`
- **Official documentation:** [Get Database Metadata](https://restdb.io/media/restdb-cheat-sheet.pdf)
