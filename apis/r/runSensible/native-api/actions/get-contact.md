# Get Contact with RunSensible

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Person/Get`
- **Base URL:** `https://app.runsensible.com`
- **Official documentation:** [Get Contact](https://help.runsensible.com/integration/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The RunSensible contact id to retrieve. |
