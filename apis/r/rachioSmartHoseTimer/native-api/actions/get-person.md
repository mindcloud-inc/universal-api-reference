# Get Person with Rachio Smart Hose Timer

Retrieves person details from your Rachio account.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/person/:id`
- **Base URL:** `https://api.rach.io/1`
- **Official documentation:** [Get Person](https://rachio.readme.io/reference/publicpersonid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
