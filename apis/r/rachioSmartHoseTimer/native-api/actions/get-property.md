# Get Property with Rachio Smart Hose Timer

Retrieves property details from your Rachio account.

## Endpoint

- **Method:** `GET`
- **Path:** `https://cloud-rest.rach.io/property/getProperty/:id`
- **Base URL:** `https://api.rach.io/1`
- **Official documentation:** [Get Property](https://rachio.readme.io/reference/propertyservice_getproperty)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Property UUID. |
