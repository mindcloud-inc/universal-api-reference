# List Webhook Event Types with Rachio Smart Hose Timer

Retrieves webhook event types from Rachio.

## Endpoint

- **Method:** `GET`
- **Path:** `https://cloud-rest.rach.io/webhook/listWebhookEventTypes`
- **Base URL:** `https://api.rach.io/1`
- **Official documentation:** [List Webhook Event Types](https://rachio.readme.io/reference/webhookservice_listwebhookeventtypes)
