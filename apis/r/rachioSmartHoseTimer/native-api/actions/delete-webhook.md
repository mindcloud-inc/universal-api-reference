# Delete Webhook with Rachio Smart Hose Timer

Deletes an existing webhook from Rachio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://cloud-rest.rach.io/webhook/deleteWebhook/:id`
- **Base URL:** `https://api.rach.io/1`
- **Official documentation:** [Delete Webhook](https://rachio.readme.io/reference/webhookservice_deletewebhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook id |
