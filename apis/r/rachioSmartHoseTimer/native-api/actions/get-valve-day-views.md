# Get Valve Day Views with Rachio Smart Hose Timer

Retrieves valve day views from Rachio.

## Endpoint

- **Method:** `POST`
- **Path:** `https://cloud-rest.rach.io/summary/getValveDayViews`
- **Base URL:** `https://api.rach.io/1`
- **Official documentation:** [Get Valve Day Views](https://rachio.readme.io/reference/summaryservice_getvalvedayviews)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `start` | body | `object` | no |
| `end` | body | `object` | no |
| `resourceId` | body | `object` | no |
