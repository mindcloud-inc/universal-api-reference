# List Notification Webhook Event Types with Rachio Smart Hose Timer

Retrieves notification webhook event types from Rachio.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/notification/webhook_event_type`
- **Base URL:** `https://api.rach.io/1`
- **Official documentation:** [List Notification Webhook Event Types](https://rachio.readme.io/reference/publicnotificationwebhook_event_type)
