# List Base Stations with Rachio Smart Hose Timer

Retrieves smart hose timer base stations from Rachio.

## Endpoint

- **Method:** `GET`
- **Path:** `https://cloud-rest.rach.io/valve/listBaseStations/:userId`
- **Base URL:** `https://api.rach.io/1`
- **Official documentation:** [List Base Stations](https://rachio.readme.io/reference/valveservice_listbasestations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | path | `string` | yes |
