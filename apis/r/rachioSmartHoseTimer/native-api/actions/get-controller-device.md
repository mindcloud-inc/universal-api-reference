# Get Controller Device with Rachio Smart Hose Timer

Retrieves controller device details from Rachio.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/device/:id`
- **Base URL:** `https://api.rach.io/1`
- **Official documentation:** [Get Controller Device](https://rachio.readme.io/reference/publicdeviceid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Controller device UUID. |
