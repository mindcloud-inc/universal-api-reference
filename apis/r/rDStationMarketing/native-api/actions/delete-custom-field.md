# Delete Custom Field with RD Station Marketing

## Endpoint

- **Method:** `DELETE`
- **Path:** `/platform/contacts/fields/:uuid`
- **Base URL:** `https://api.rd.services`
- **Official documentation:** [Delete Custom Field](https://developers.rdstation.com/reference/delete_platform-contacts-fields-uuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Contact field UUID in path. |
