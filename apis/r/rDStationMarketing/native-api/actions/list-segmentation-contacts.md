# List Segmentation Contacts with RD Station Marketing

## Endpoint

- **Method:** `GET`
- **Path:** `/platform/segmentations/:id/contacts`
- **Base URL:** `https://api.rd.services`
- **Official documentation:** [List Segmentation Contacts](https://developers.rdstation.com/reference/get_platform-segmentations-id-contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Segmentation ID in path. |
