# List Contact Events with RD Station Marketing

## Endpoint

- **Method:** `GET`
- **Path:** `/platform/contacts/:uuid/events`
- **Base URL:** `https://api.rd.services`
- **Official documentation:** [List Contact Events](https://developers.rdstation.com/reference/get_platform-contacts-uuid-events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Contact UUID in path. |
