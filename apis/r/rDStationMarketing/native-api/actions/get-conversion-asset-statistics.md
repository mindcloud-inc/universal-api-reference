# Get Conversion Asset Statistics with RD Station Marketing

## Endpoint

- **Method:** `GET`
- **Path:** `/platform/analytics/conversions`
- **Base URL:** `https://api.rd.services`
- **Official documentation:** [Get Conversion Asset Statistics](https://developers.rdstation.com/reference/get_platform-analytics-conversions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `end_date` | query | `string` | yes | End date for analytics range (YYYY-MM-DD). |
| `start_date` | query | `string` | yes | Start date for analytics range (YYYY-MM-DD). |
