# Get Email Marketing Statistics with RD Station Marketing

## Endpoint

- **Method:** `GET`
- **Path:** `/platform/analytics/emails`
- **Base URL:** `https://api.rd.services`
- **Official documentation:** [Get Email Marketing Statistics](https://developers.rdstation.com/reference/get_platform-analytics-emails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `end_date` | query | `string` | yes | End date for analytics range (YYYY-MM-DD). |
| `start_date` | query | `string` | yes | Start date for analytics range (YYYY-MM-DD). |
