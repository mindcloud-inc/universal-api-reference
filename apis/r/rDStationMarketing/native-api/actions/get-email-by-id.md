# Get Email by ID with RD Station Marketing

## Endpoint

- **Method:** `GET`
- **Path:** `/platform/emails/:id`
- **Base URL:** `https://api.rd.services`
- **Official documentation:** [Get Email by ID](https://developers.rdstation.com/reference/get_platform-emails-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Email ID in path. |
