# Get merchant by ID with Rakuten Advertising

Retrieves a merchant from Rakuten Advertising by advertiser ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/linklocator/1.0/getMerchByID/{advertiserId}`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Get merchant by ID](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/link_locator)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `advertiserId` | path | `string` | yes | Rakuten advertiser ID. |
