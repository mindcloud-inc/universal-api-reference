# Get merchants by category with Rakuten Advertising

Retrieves merchants from Rakuten Advertising by category.

## Endpoint

- **Method:** `GET`
- **Path:** `/linklocator/1.0/getMerchByCategory/{categoryId}`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Get merchants by category](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/link_locator)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `categoryId` | path | `string` | yes | Rakuten category ID. |
