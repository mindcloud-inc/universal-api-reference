# Get merchants by name with Rakuten Advertising

Finds merchants in Rakuten Advertising by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/linklocator/1.0/getMerchByName/{advertiserName}`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Get merchants by name](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/link_locator)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `advertiserName` | path | `string` | yes | Advertiser name to search for in Link Locator. |
