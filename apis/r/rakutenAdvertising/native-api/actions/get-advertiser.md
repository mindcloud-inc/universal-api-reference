# Get advertiser with Rakuten Advertising

Retrieves an advertiser from Rakuten Advertising.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/advertisers/{advertiserId}`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Get advertiser](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/advertisers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `advertiserId` | path | `string` | yes | Rakuten advertiser ID. |
