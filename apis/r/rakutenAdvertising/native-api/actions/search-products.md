# Search products with Rakuten Advertising

Finds products in Rakuten Advertising by search criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/productsearch/1.0`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Search products](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/product_search)
