# Delete postback with Rakuten Advertising

Deletes an existing postback from Rakuten Advertising.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/postback/{publisherId}`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Delete postback](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/postback)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `publisherId` | path | `string` | yes | Rakuten publisher SID. |
