# List commissioning lists with Rakuten Advertising

Retrieves commissioning lists from Rakuten Advertising.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/commissioninglists`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [List commissioning lists](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/commissioning_lists)
