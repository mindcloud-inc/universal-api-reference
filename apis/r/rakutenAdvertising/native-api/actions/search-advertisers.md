# Search advertisers with Rakuten Advertising

Finds advertisers in Rakuten Advertising by search criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/advertisersearch/1.0`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Search advertisers](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/advertiser_search)
