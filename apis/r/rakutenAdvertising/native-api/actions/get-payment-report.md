# Get payment report with Rakuten Advertising

Retrieves a payment report from Rakuten Advertising.

## Endpoint

- **Method:** `GET`
- **Path:** `/advancedreports/1.0`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Get payment report](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/advanced_reports)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payid` | query | `string` | yes | Rakuten payment ID. |
