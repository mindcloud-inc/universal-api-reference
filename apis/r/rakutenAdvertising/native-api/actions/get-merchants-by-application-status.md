# Get merchants by application status with Rakuten Advertising

Retrieves merchants from Rakuten Advertising by application status.

## Endpoint

- **Method:** `GET`
- **Path:** `/linklocator/1.0/getMerchByAppStatus/{applicationStatus}`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Get merchants by application status](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/link_locator)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `applicationStatus` | path | `string` | yes | Advertiser application status to filter merchants. |
