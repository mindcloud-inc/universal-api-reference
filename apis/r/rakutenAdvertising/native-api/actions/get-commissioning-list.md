# Get commissioning list with Rakuten Advertising

Retrieves a commissioning list from Rakuten Advertising.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/commissioninglists/{listId}`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Get commissioning list](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/commissioning_lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Rakuten commissioning list ID. |
