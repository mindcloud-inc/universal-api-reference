# List transactions with Rakuten Advertising

Retrieves transactions from Rakuten Advertising.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/1.0/transactions`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [List transactions](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/events)
