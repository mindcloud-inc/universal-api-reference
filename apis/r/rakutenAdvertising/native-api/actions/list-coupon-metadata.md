# List coupon metadata with Rakuten Advertising

Retrieves coupon metadata from Rakuten Advertising.

## Endpoint

- **Method:** `GET`
- **Path:** `/coupon/1.0`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [List coupon metadata](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/coupon/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `promocat` | query | `string` | yes | Set to 1 to retrieve coupon network, category, and promotion type metadata. |
