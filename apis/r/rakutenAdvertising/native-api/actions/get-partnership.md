# Get partnership with Rakuten Advertising

Retrieves a partnership from Rakuten Advertising.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/partnerships/{advertiserId}`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Get partnership](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/partnerships)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `advertiserId` | path | `string` | yes | Rakuten advertiser ID. |
