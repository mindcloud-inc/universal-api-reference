# List coupons with Rakuten Advertising

Retrieves coupons from Rakuten Advertising.

## Endpoint

- **Method:** `GET`
- **Path:** `/coupon/1.0`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [List coupons](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/coupon)
