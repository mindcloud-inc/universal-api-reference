# Get offer with Rakuten Advertising

Retrieves an offer from Rakuten Advertising.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/offers/{goid}`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Get offer](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/offers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `goid` | path | `string` | yes | Rakuten group offer ID from the offers API. |
