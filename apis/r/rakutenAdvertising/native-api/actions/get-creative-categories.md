# Get creative categories with Rakuten Advertising

Retrieves creative categories from Rakuten Advertising.

## Endpoint

- **Method:** `GET`
- **Path:** `/linklocator/1.0/getCreativeCategories/{advertiserId}`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Get creative categories](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/link_locator)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `advertiserId` | path | `string` | yes | Rakuten advertiser ID. |
