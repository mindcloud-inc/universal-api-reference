# Get invoice item report with Rakuten Advertising

Retrieves an invoice item report from Rakuten Advertising.

## Endpoint

- **Method:** `GET`
- **Path:** `/advancedreports/1.0`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [Get invoice item report](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/advanced_reports)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoiceid` | query | `string` | yes | Rakuten invoice ID. |
