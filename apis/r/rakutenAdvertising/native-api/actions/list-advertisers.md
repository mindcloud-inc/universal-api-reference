# List advertisers with Rakuten Advertising

Retrieves advertisers from Rakuten Advertising.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/advertisers`
- **Base URL:** `https://api.linksynergy.com`
- **Official documentation:** [List advertisers](https://developers.rakutenadvertising.com/documentation/en-US/affiliate_apis/advertisers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
