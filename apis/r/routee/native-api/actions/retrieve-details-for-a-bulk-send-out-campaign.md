# Retrieve details for a bulk send out - campaign with Routee

Retrieves details for a bulk send out - campaign from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:trackingId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve details for a bulk send out - campaign](https://docs.routee.net/reference/retrieve-details-for-a-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trackingId` | path | `string` | yes | The tracking id of the campaign |
