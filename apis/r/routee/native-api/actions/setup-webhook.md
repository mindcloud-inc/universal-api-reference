# Setup Webhook with Routee

Sets up a webhook in Routee.

## Endpoint

- **Method:** `POST`
- **Path:** `/webhook`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Setup Webhook](https://docs.routee.net/reference/setup-webhook)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `webhooks[]` | body | `array<object>` | yes |
