# Referrals statistics with Routee

Retrieves detailed referrals statistics from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:id/referrals`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Referrals statistics](https://docs.routee.net/reference/referrals-statistics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Campaign ID |
