# Retrieve a list of all of the senders with Routee

Retrieves a list of all of the senders from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/senders`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve a list of all of the senders](https://docs.routee.net/reference/retrieving-a-list-of-all-of-the-senders)
