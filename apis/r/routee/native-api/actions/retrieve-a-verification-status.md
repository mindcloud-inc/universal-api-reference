# Retrieve a verification status with Routee

Retrieves a verification status from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/2step/:trackingId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve a verification status](https://docs.routee.net/reference/retrieve-a-verification-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trackingId` | path | `string` | yes | the tracking id of the verification. |
