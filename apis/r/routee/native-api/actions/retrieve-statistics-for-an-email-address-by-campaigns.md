# Retrieve statistics for an email address by campaigns with Routee

Retrieves statistics for an email address by campaigns from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/emails/:email/campaigns`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve statistics for an email address by campaigns](https://docs.routee.net/reference/retrieving-statistics-for-an-email-address-by-campaigns)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | email address to retrieve statistics |
