# Track an Email Validator request with Routee

Tracks an email validator request in Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/emailvalidator/tracking/:trackingId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Track an Email Validator request](https://docs.routee.net/reference/track-an-email-validator-request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trackingId` | path | `string` | yes | The unique tracking id of the Email Validation request to track |
