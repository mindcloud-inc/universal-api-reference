# Delete a scheduled bulk send out - campaign with Routee

Deletes a scheduled bulk send out - campaign from Routee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sms/:trackingId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Delete a scheduled bulk send out - campaign](https://docs.routee.net/reference/delete-a-scheduled-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trackingId` | path | `string` | yes | the campaign’s tracking id. |
