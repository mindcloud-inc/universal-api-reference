# Retrieve Verification Statistics for any of your account applications with Routee

Retrieves verification statistics for any of your account applications from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/2step/reports/applications/:appId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve Verification Statistics for any of your account applications](https://docs.routee.net/reference/verification-reports-application)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Your application id |
