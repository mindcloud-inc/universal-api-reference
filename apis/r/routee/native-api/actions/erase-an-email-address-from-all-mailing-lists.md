# Erase an email address from all mailing lists with Routee

Deletes an email address from all mailing lists in Routee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/emails/:email`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Erase an email address from all mailing lists](https://docs.routee.net/reference/erasing-an-email-address-from-all-mailing-lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | email address to be erased |
