# Retrieve the list of unsubscribed with Routee

Retrieves the list of unsubscribed from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/smtp/unsubscribe`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve the list of unsubscribed](https://docs.routee.net/reference/retrieving-the-list-of-unsubscribed)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `day` | query | `string` | no | The day you want to get information about. Format: YYYY-MM-DD |
| `limit` | query | `string` | no | Number of entries |
| `offset` | query | `string` | no | Sample offset |
