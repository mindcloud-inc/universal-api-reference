# Retrieve information for a specific email with Routee

Retrieves information for a specific email from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/smtp/emails/:id`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve information for a specific email](https://docs.routee.net/reference/retrieving-information-for-a-specific-email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Email ID |
