# New domain verification with Routee

Creates a new domain verification in Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/smtp/domains/:email`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [New domain verification](https://docs.routee.net/reference/new-domain-verification)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | path | `string` | yes |
