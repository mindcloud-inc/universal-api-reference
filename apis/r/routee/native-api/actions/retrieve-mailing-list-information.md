# Retrieve mailing list information with Routee

Retrieves mailing list information from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/addressbooks/:id`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve mailing list information](https://docs.routee.net/reference/retrieving-mailing-list-information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | List ID |
