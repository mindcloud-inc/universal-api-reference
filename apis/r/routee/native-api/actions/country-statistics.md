# Country statistics with Routee

Retrieves detailed country statistics from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:id/countries`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Country statistics](https://docs.routee.net/reference/country-statistics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Campaign ID |
