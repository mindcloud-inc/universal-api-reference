# Delete a scheduled Viber campaign with Routee

Deletes a scheduled Viber campaign from Routee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/viber/campaign/:campaignTrackingId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Delete a scheduled Viber campaign](https://docs.routee.net/reference/delete-a-scheduled-viber-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignTrackingId` | path | `string` | yes | The viber campaign’s tracking id. |
