# View Time Summary Analytics for a range of Messages with Routee

Retrieves time summary analytics for a range of messages from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/my/breakdown`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [View Time Summary Analytics for a range of Messages](https://docs.routee.net/reference/view-time-summary-analytics-for-a-range-of-messages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `startDate` | query | `date` | yes | starting date to get reports |
| `endDate` | query | `date` | yes | ending date to get reports |
