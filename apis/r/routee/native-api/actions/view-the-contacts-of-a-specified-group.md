# View the Contacts of a specified group with Routee

Retrieves the contacts of a specified group from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/my/:name/contacts`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [View the Contacts of a specified group](https://docs.routee.net/reference/view-the-contacts-of-a-specified-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The name of the group. |
