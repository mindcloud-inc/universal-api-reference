# Calculate the cost of a campaign carried out by a mailing list with Routee

Calculates the cost of a campaign carried out by a mailing list in Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/addressbooks/:id/cost`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Calculate the cost of a campaign carried out by a mailing list](https://docs.routee.net/reference/calculating-the-cost-of-a-campaign-carried-out-by-a-mailing-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | List ID |
