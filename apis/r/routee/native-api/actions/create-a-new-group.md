# Create a new group with Routee

Creates a new group in Routee.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups/my`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Create a new group](https://docs.routee.net/reference/create-a-new-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | The name of the group to be created. Length must be between 2 and 30 characters. |
