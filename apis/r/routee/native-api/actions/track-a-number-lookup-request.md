# Track a Number Lookup request with Routee

Tracks a number lookup request in Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/:lookupId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Track a Number Lookup request](https://docs.routee.net/reference/track-a-single-hlr-lookup-record)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lookupId` | path | `string` | yes | The id of the single HLR lookup record |
