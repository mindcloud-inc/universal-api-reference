# Get whitelisted IP's for an application with Routee

Retrieves whitelisted IPs for an application from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/security/whitelist`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Get whitelisted IP's for an application](https://docs.routee.net/reference/get-whitelisted-ips-for-an-application)
