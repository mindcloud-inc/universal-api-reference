# Retrieve Failover trackings with Routee

Retrieves failover tracking records from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/failover/tracking/:trackingId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve Failover trackings](https://docs.routee.net/reference/retrieve-failover-trackings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trackingId` | path | `string` | yes | The tracking Id of a failover message |
