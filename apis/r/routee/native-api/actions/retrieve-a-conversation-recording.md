# Retrieve a Conversation Recording with Routee

Retrieves a conversation recording from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/recordings/my/downloads/:recordingTrackingId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve a Conversation Recording](https://docs.routee.net/reference/retrieve-conversation-recording)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recordingTrackingId` | path | `string` | yes | The tracking Id of the recorded file |
