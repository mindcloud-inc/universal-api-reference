# Create a mailing list with Routee

Creates a mailing list in Routee.

## Endpoint

- **Method:** `POST`
- **Path:** `/addressbooks`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Create a mailing list](https://docs.routee.net/reference/creating-a-mailing-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bookName` | body | `string` | yes | The mailing list you want to create |
