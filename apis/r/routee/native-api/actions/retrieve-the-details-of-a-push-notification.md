# Retrieve the details of a Push Notification with Routee

Retrieves the details of a push notification from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/push-notifications/messages/:trackingId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve the details of a Push Notification](https://docs.routee.net/reference/retrieve-the-details-of-a-push-notification)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `trackingId` | path | `string` | yes |
