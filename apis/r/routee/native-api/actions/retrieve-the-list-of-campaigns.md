# Retrieve the list of campaigns with Routee

Retrieves the list of campaigns from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve the list of campaigns](https://docs.routee.net/reference/retrieving-the-list-of-campaigns)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Number of entries (optional parameter) |
| `offset` | query | `string` | no | Offset issue (stating the record to display from) |
