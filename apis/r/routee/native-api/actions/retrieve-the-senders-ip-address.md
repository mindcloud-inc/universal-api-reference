# Retrieve the sender’s IP address with Routee

Retrieves the sender's IP address from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/smtp/ips`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve the sender’s IP address](https://docs.routee.net/reference/retrieving-the-senders-ip-address)
