# Retrieve a list of allowed domains with Routee

Retrieves a list of allowed domains from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/smtp/domains`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve a list of allowed domains](https://docs.routee.net/reference/retrieving-a-list-of-allowed-domains)
