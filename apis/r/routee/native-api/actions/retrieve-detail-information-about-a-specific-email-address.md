# Retrieve detail information about a specific email address with Routee

Retrieves detail information about a specific email address from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/emails/:email/details`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve detail information about a specific email address](https://docs.routee.net/reference/retrieve-detail-information-about-a-specific-email-address)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | The email to retrieve detail information |
