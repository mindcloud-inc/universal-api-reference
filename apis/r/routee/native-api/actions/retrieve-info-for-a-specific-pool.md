# Retrieve info for a specific Pool with Routee

Retrieves info for a specific pool from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/pools/my/:poolId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve info for a specific Pool](https://docs.routee.net/reference/retrieve-info-for-a-specific-pool)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `poolid` | path | `string` | yes | — |
| `poolid` | path | `string` | yes | The tracking id of the pool. |
