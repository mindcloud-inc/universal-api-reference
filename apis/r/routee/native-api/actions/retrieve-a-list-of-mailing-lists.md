# Retrieve a list of mailing lists with Routee

Retrieves a list of mailing lists from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/addressbooks`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve a list of mailing lists](https://docs.routee.net/reference/retrieving-a-list-of-mailing-lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | body | `number` | no | the number of records |
| `offset` | body | `string` | no | offset (first record to be displayed) |
