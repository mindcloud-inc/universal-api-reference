# Get a list of variables for a mailing list with Routee

Retrieves a list of variables for a mailing list from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/addressbooks/:id/variables`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Get a list of variables for a mailing list](https://docs.routee.net/reference/get-a-list-of-variables-for-a-mailing-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | mailing list identifier |
