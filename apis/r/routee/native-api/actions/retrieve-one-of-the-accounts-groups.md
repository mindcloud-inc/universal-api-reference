# Retrieve one of the account's groups with Routee

Retrieves one of the account's groups from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/my/:name`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve one of the account's groups](https://docs.routee.net/reference/retrieve-one-of-the-accounts-groups)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | path | `string` | yes |
