# Get shorten URL info for monitoring purposes with Routee

Retrieves shortened URL monitoring details from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/shorten/:trackingId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Get shorten URL info for monitoring purposes](https://docs.routee.net/reference/getting-shorten-url-info-for-monitoring-purposes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `{trackingId}` | path | `string` | yes | The unique traking id of a shorten URL |
| `tracking-id` | path | `string` | yes | — |
