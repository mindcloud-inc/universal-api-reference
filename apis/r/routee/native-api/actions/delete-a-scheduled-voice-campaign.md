# Delete a scheduled Voice campaign with Routee

Deletes a scheduled voice campaign from Routee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/voice/campaign/:trackingId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Delete a scheduled Voice campaign](https://docs.routee.net/reference/delete-a-voice-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trackingId` | path | `string` | yes | The campaign’s tracking id. |
