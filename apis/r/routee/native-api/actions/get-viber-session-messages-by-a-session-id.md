# Get Viber Session Messages by a Session Id with Routee

Retrieves Viber session messages by a session id from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/viber/session/:sessionId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Get Viber Session Messages by a Session Id](https://docs.routee.net/reference/get-viber-session-by-a-sessionid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sessionId` | path | `string` | yes | The session Id of the messages |
