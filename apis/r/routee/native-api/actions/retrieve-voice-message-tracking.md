# Retrieve Voice Message Tracking with Routee

Retrieves voice message tracking from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/voice/tracking/:messageTrackingId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve Voice Message Tracking](https://docs.routee.net/reference/voicemessagetracking)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `messageTrackingId` | path | `string` | yes |
