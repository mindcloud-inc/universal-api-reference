# Retrieve all the Pools of an account with Routee

Retrieves all the pools of an account from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/pools/my`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve all the Pools of an account](https://docs.routee.net/reference/retrieve-all-the-pools-of-an-account)
