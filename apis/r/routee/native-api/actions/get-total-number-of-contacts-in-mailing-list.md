# Get total number of contacts in mailing list with Routee

Retrieves total number of contacts in mailing list from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/addressbooks/:id/emails/total`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Get total number of contacts in mailing list](https://docs.routee.net/reference/get-total-number-of-contacts-in-mailing-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | the ID of the mailing list |
