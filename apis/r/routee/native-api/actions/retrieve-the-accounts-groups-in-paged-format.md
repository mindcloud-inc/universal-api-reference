# Retrieve the account's groups in paged format with Routee

Retrieves the account's groups in paged format from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/my/page`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve the account's groups in paged format](https://docs.routee.net/reference/retrieve-the-accounts-groups-in-paged-format)
