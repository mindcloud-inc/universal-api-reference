# Delete all IP whitelisting settings for API with Routee

Deletes all API IP whitelisting settings from Routee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/security/whitelist`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Delete all IP whitelisting settings for API](https://docs.routee.net/reference/delete-all-ip-whitelisting-settings-for-api)
