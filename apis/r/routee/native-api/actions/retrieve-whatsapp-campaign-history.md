# Retrieve Whatsapp Campaign history with Routee

Retrieves WhatsApp campaign history from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/tracking/campaign/:campaignTrackingId/history`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve Whatsapp Campaign history](https://docs.routee.net/reference/retrieve-whatsapp-campaign-history)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaignTrackingId` | path | `string` | yes |
