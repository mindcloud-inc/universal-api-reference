# Retrieve the account's contact labels with Routee

Retrieves the account's contact labels from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/labels/my`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve the account's contact labels](https://docs.routee.net/reference/retrieve-the-accounts-contact-labels)
