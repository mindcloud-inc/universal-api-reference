# Campaign information with Routee

Retrieves detailed campaign information from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:id`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Campaign information](https://docs.routee.net/reference/campaign-information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Campaign ID |
