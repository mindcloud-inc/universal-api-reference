# Retrieve a list of domains with Routee

Retrieves a list of domains from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/email-senders/domain`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve a list of domains](https://docs.routee.net/reference/email-api-v2-retrieving-a-list-of-domains)
