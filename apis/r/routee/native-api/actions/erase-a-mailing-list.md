# Erase a mailing list with Routee

Deletes a mailing list from Routee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/addressbooks/:id`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Erase a mailing list](https://docs.routee.net/reference/erasing-a-mailing-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | List ID |
