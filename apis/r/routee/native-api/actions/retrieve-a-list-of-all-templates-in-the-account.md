# Retrieve a list of all templates in the account with Routee

Retrieves a list of all templates in the account from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve a list of all templates in the account](https://docs.routee.net/reference/retrieving-a-list-of-all-templates-in-the-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `owner` | query | `string` | no | — |
| `lang` | path | `string` | yes | (Optional) language of template, two-character language code |
