# Delete a Pool with Routee

Deletes an existing pool from Routee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pools/my/:poolId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Delete a Pool](https://docs.routee.net/reference/delete-a-pool)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `poolId` | path | `string` | yes | The tracking id of the pool. |
