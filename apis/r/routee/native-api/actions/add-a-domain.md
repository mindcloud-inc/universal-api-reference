# Add a domain with Routee

Adds a new domain in Routee.

## Endpoint

- **Method:** `POST`
- **Path:** `/smtp/domains`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Add a domain](https://docs.routee.net/reference/adding-a-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | Sender’s email address |
