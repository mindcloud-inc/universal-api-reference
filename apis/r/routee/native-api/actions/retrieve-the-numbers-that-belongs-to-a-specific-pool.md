# Retrieve the Numbers that belongs to a specific Pool with Routee

Retrieves the numbers that belongs to a specific pool from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/pools/my/:poolId/numbers`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve the Numbers that belongs to a specific Pool](https://docs.routee.net/reference/retrieve-the-numbers-that-belongs-to-a-specific-pool)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `poolid` | path | `string` | yes | — |
| `poolid` | path | `string` | yes | The tracking id of the pool. |
