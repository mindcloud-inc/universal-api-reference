# Retrieve details about a contact with Routee

Retrieves details about a contact from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/my/:id`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve details about a contact](https://docs.routee.net/reference/retrieve-details-about-a-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the contact. |
