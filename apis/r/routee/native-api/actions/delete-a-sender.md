# Delete a sender with Routee

Deletes an existing sender from Routee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/senders`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Delete a sender](https://docs.routee.net/reference/deleting-a-sender)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Sender’s email address |
