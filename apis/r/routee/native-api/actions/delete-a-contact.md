# Delete a contact with Routee

Deletes an existing contact from Routee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/my/:id`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Delete a contact](https://docs.routee.net/reference/delete-a-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the contact to be deleted. |
