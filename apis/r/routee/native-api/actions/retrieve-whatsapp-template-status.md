# Retrieve Whatsapp template status with Routee

Retrieves WhatsApp template status from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/templates/:templateId`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Retrieve Whatsapp template status](https://docs.routee.net/reference/retrieve-whatsapp-template-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | Referenced template |
