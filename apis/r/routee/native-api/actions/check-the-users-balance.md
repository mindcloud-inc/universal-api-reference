# Check the user’s balance with Routee

Retrieves the current user balance from Routee.

## Endpoint

- **Method:** `GET`
- **Path:** `/balance`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Check the user’s balance](https://docs.routee.net/reference/checking-the-users-balance)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uSD` | path | `string` | yes | Optional parameter |
