# Cancel a campaign with Routee

Cancels an existing campaign in Routee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/campaigns/:id`
- **Base URL:** `https://connect.routee.net`
- **Official documentation:** [Cancel a campaign](https://docs.routee.net/reference/cancelling-a-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Campaign ID |
