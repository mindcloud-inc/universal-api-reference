# Get Customer Import with Reteach

## Endpoint

- **Method:** `GET`
- **Path:** `/customer-import/{customerImportId}`
- **Base URL:** `https://api.reteach.io`
- **Official documentation:** [Get Customer Import](https://api.reteach.io/docs/#/CustomerImport/CustomerImportController_findCustomerImportById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerImportId` | path | `string` | yes | The id of the customer import job. |
