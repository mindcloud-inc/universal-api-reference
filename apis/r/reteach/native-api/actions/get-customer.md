# Get Customer with Reteach

## Endpoint

- **Method:** `GET`
- **Path:** `/customer/{customerIdentifier}`
- **Base URL:** `https://api.reteach.io`
- **Official documentation:** [Get Customer](https://api.reteach.io/docs/#/Customer/CustomerController_findCustomerById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerIdentifier` | path | `string` | yes | The customer id, email, username, or externalId. |
