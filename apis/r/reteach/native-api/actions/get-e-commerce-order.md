# Get E-Commerce Order with Reteach

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/order/{orderId}`
- **Base URL:** `https://api.reteach.io`
- **Official documentation:** [Get E-Commerce Order](https://api.reteach.io/docs/#/Order/ProductVariantOrderController_findById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderId` | path | `string` | yes | The id of the e-commerce order. |
