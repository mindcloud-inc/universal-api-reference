# Get Course Invitation with Reteach

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/course-invitation/{courseInvitationId}`
- **Base URL:** `https://api.reteach.io`
- **Official documentation:** [Get Course Invitation](https://api.reteach.io/docs/#/CourseInvitation/CourseInvitationController_findById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `courseInvitationId` | path | `string` | yes | The id of the course invitation. |
