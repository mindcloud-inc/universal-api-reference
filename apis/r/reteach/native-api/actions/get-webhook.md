# Get Webhook with Reteach

## Endpoint

- **Method:** `GET`
- **Path:** `/subscription/{subscriptionId}`
- **Base URL:** `https://api.reteach.io`
- **Official documentation:** [Get Webhook](https://api.reteach.io/docs/#/Webhook/RestHookController_findSubscriptionById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscriptionId` | path | `string` | yes | The id of the webhook subscription. |
