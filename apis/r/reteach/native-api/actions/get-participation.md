# Get Participation with Reteach

## Endpoint

- **Method:** `GET`
- **Path:** `/participation/{participationId}`
- **Base URL:** `https://api.reteach.io`
- **Official documentation:** [Get Participation](https://api.reteach.io/docs/#/Participation/CustomerCourseParticipationController_findById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `participationId` | path | `string` | yes | The id of the participation. |
