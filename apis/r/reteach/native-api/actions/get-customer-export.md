# Get Customer Export with Reteach

## Endpoint

- **Method:** `GET`
- **Path:** `/customer-export/{customerExportId}`
- **Base URL:** `https://api.reteach.io`
- **Official documentation:** [Get Customer Export](https://api.reteach.io/docs/#/CustomerExport/CustomerExportController_findCustomerExportById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerExportId` | path | `string` | yes | The id of the customer export job. |
