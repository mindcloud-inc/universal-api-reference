# Get Course with Reteach

## Endpoint

- **Method:** `GET`
- **Path:** `/course/{courseId}`
- **Base URL:** `https://api.reteach.io`
- **Official documentation:** [Get Course](https://api.reteach.io/docs/#/Course/CourseController_findById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `courseId` | path | `string` | yes | The id of the course. |
