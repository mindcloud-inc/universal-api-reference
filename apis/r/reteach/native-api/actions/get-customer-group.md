# Get Customer Group with Reteach

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customer-group/{customerGroupId}`
- **Base URL:** `https://api.reteach.io`
- **Official documentation:** [Get Customer Group](https://api.reteach.io/docs/#/CustomerGroup/CustomerGroupController_findById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerGroupId` | path | `string` | yes | The id of the customer group. |
