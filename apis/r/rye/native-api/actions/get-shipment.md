# Get Shipment with Rye

Retrieves a shipment from Rye.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/shipments/{id}`
- **Base URL:** `https://staging.api.rye.com`
- **Official documentation:** [Get Shipment](https://rye.com/docs/api-v2/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The shipment id. |
