# List Transactions with Rye

Retrieves drawdown transactions from Rye.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/billing/transactions`
- **Base URL:** `https://staging.api.rye.com`
- **Official documentation:** [List Transactions](https://rye.com/docs/api-v2/introduction)

## Capabilities

This operation supports [pagination](../README.md#pagination).
