# Get Checkout Intent with Rye

Retrieves a checkout intent from Rye.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/checkout-intents/{id}`
- **Base URL:** `https://staging.api.rye.com`
- **Official documentation:** [Get Checkout Intent](https://rye.com/docs/api-v2/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The checkout intent id. |
