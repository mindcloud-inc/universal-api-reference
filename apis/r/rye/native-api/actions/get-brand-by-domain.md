# Get Brand By Domain with Rye

Finds a brand in Rye by domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/brands/domain/{domain}`
- **Base URL:** `https://staging.api.rye.com`
- **Official documentation:** [Get Brand By Domain](https://rye.com/docs/api-v2/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain name to look up. |
