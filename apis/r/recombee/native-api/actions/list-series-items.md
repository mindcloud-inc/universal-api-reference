# List Series Items with Recombee

Retrieves items from a Recombee series.

## Endpoint

- **Method:** `GET`
- **Path:** `/series/:seriesId/items/`
- **Base URL:** `https://rapi.recombee.com/{databaseId}`
- **Official documentation:** [List Series Items](https://docs.recombee.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `seriesId` | path | `string` | yes |
