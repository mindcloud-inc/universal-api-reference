# Get User Property Info with Recombee

Retrieves details for a user property in Recombee.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/properties/:propertyName`
- **Base URL:** `https://rapi.recombee.com/{databaseId}`
- **Official documentation:** [Get User Property Info](https://docs.recombee.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `propertyName` | path | `string` | yes |
