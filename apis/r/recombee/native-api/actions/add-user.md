# Add User with Recombee

Creates a new user in Recombee.

## Endpoint

- **Method:** `PUT`
- **Path:** `/users/:userId`
- **Base URL:** `https://rapi.recombee.com/{databaseId}`
- **Official documentation:** [Add User](https://docs.recombee.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | path | `string` | yes |
