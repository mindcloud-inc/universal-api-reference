# Add Detail View with Recombee

Creates a detail view event in Recombee.

## Endpoint

- **Method:** `POST`
- **Path:** `/detailviews/`
- **Base URL:** `https://rapi.recombee.com/{databaseId}`
- **Official documentation:** [Add Detail View](https://docs.recombee.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemId` | body | `string` | yes |
| `userId` | body | `string` | yes |
