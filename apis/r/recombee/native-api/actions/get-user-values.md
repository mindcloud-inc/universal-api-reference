# Get User Values with Recombee

Retrieves values for a user from Recombee.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://rapi.recombee.com/{databaseId}`
- **Official documentation:** [Get User Values](https://docs.recombee.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | path | `string` | yes |
