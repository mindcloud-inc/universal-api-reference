# List Items with Recombee

Retrieves items from your Recombee catalog.

## Endpoint

- **Method:** `GET`
- **Path:** `/items/list/`
- **Base URL:** `https://rapi.recombee.com/{databaseId}`
- **Official documentation:** [List Items](https://docs.recombee.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `count` | query | `string` | no |
| `filter` | query | `string` | no |
| `includedProperties` | query | `string` | no |
| `offset` | query | `string` | no |
| `returnProperties` | query | `string` | no |
