# List Users with Recombee

Retrieves users from your Recombee database.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/list/`
- **Base URL:** `https://rapi.recombee.com/{databaseId}`
- **Official documentation:** [List Users](https://docs.recombee.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `count` | query | `string` | no |
| `filter` | query | `string` | no |
| `includedProperties` | query | `string` | no |
| `offset` | query | `string` | no |
| `returnProperties` | query | `string` | no |
