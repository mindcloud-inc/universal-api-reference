# Get Item Property Info with Recombee

Retrieves details for an item property in Recombee.

## Endpoint

- **Method:** `GET`
- **Path:** `/items/properties/:propertyName`
- **Base URL:** `https://rapi.recombee.com/{databaseId}`
- **Official documentation:** [Get Item Property Info](https://docs.recombee.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `propertyName` | path | `string` | yes |
