# Add Item with Recombee

Creates a new item in Recombee.

## Endpoint

- **Method:** `PUT`
- **Path:** `/items/:itemId`
- **Base URL:** `https://rapi.recombee.com/{databaseId}`
- **Official documentation:** [Add Item](https://docs.recombee.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | yes | The unique item identifier in Recombee. |
