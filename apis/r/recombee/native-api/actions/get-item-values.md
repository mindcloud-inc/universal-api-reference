# Get Item Values with Recombee

Retrieves values for an item from Recombee.

## Endpoint

- **Method:** `GET`
- **Path:** `/items/:itemId`
- **Base URL:** `https://rapi.recombee.com/{databaseId}`
- **Official documentation:** [Get Item Values](https://docs.recombee.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemId` | path | `string` | yes |
