# Update More Items with Recombee

Updates multiple items in your Recombee catalog.

## Endpoint

- **Method:** `POST`
- **Path:** `/more-items/`
- **Base URL:** `https://rapi.recombee.com/{databaseId}`
- **Official documentation:** [Update More Items](https://docs.recombee.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `changes` | body | `object` | yes |
| `filter` | body | `string` | yes |
