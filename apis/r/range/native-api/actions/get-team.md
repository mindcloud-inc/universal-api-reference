# Get Team with Range

Retrieve a team by its Range team ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/teams/:teamId`
- **Base URL:** `https://api.range.co`
- **Official documentation:** [Get Team](https://www.range.co/docs/api#rpc-read-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `string` | no | The Range team ID. |
