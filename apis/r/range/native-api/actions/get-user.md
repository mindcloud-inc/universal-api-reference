# Get User with Range

Retrieve a user by its Range user ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users/:userId`
- **Base URL:** `https://api.range.co`
- **Official documentation:** [Get User](https://www.range.co/docs/api#rpc-read-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | no | The Range user ID. |
