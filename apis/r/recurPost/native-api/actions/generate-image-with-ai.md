# Generate Image with AI with RecurPost

Generates an image with AI in RecurPost.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/generate_image_with_ai`
- **Base URL:** `https://social.recurpost.com`
- **Official documentation:** [Generate Image with AI](https://developers.recurpost.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `prompt_text` | body | `string` | yes | Detailed description of the image to generate. |
