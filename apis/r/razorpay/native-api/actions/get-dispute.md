# Get Dispute with Razorpay

Retrieves a dispute from Razorpay by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/disputes/:id`
- **Base URL:** `https://api.razorpay.com`
- **Official documentation:** [Get Dispute](https://razorpay.com/docs/api/disputes/fetch/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the dispute. |
