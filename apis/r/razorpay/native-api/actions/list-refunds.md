# List Refunds with Razorpay

Retrieves all refund records from Razorpay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/refunds/`
- **Base URL:** `https://api.razorpay.com`
- **Official documentation:** [List Refunds](https://razorpay.com/docs/api/refunds/fetch-all/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
