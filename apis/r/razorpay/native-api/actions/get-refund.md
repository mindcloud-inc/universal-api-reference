# Get Refund with Razorpay

Retrieves a refund from Razorpay by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/refunds/:id`
- **Base URL:** `https://api.razorpay.com`
- **Official documentation:** [Get Refund](https://razorpay.com/docs/api/refunds/fetch-with-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the refund. |
