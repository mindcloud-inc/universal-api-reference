# List Payment Links with Razorpay

Retrieves payment link records from Razorpay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/payment_links/`
- **Base URL:** `https://api.razorpay.com`
- **Official documentation:** [List Payment Links](https://razorpay.com/docs/api/payments/payment-links/fetch-all-standard/)
