# List Customers with Razorpay

Retrieves all customer records from Razorpay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customers`
- **Base URL:** `https://api.razorpay.com`
- **Official documentation:** [List Customers](https://razorpay.com/docs/api/customers/fetch-all/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
