# List Settlements with Razorpay

Retrieves all settlement records from Razorpay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/settlements/`
- **Base URL:** `https://api.razorpay.com`
- **Official documentation:** [List Settlements](https://razorpay.com/docs/api/settlements/fetch-all/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
