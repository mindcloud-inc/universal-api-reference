# List Orders with Razorpay

Retrieves all order records from Razorpay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/orders`
- **Base URL:** `https://api.razorpay.com`
- **Official documentation:** [List Orders](https://razorpay.com/docs/api/orders/fetch-all/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
