# Get Order with Razorpay

Retrieves an order from Razorpay by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/orders/:id`
- **Base URL:** `https://api.razorpay.com`
- **Official documentation:** [Get Order](https://razorpay.com/docs/api/orders/fetch-with-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the order. |
