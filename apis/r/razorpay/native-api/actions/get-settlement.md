# Get Settlement with Razorpay

Retrieves a settlement from Razorpay by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/settlements/:id`
- **Base URL:** `https://api.razorpay.com`
- **Official documentation:** [Get Settlement](https://razorpay.com/docs/api/settlements/fetch-with-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the settlement. |
