# Get Episode with Rick and Morty

## Endpoint

- **Method:** `GET`
- **Path:** `/episode/:id`
- **Base URL:** `https://rickandmortyapi.com/api`
- **Official documentation:** [Get Episode](https://rickandmortyapi.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Episode identifier. |
