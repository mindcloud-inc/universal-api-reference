# Get Location with Rick and Morty

## Endpoint

- **Method:** `GET`
- **Path:** `/location/:id`
- **Base URL:** `https://rickandmortyapi.com/api`
- **Official documentation:** [Get Location](https://rickandmortyapi.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Location identifier. |
