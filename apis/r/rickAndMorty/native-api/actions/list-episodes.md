# List Episodes with Rick and Morty

## Endpoint

- **Method:** `GET`
- **Path:** `/episode`
- **Base URL:** `https://rickandmortyapi.com/api`
- **Official documentation:** [List Episodes](https://rickandmortyapi.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page of results. |
| `name` | query | `string` | no | Filter by name. |
| `episode` | query | `string` | no | Filter by episode code. |
