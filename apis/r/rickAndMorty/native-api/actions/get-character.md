# Get Character with Rick and Morty

## Endpoint

- **Method:** `GET`
- **Path:** `/character/:id`
- **Base URL:** `https://rickandmortyapi.com/api`
- **Official documentation:** [Get Character](https://rickandmortyapi.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Character identifier. |
