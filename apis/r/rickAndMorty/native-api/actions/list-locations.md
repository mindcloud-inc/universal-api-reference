# List Locations with Rick and Morty

## Endpoint

- **Method:** `GET`
- **Path:** `/location`
- **Base URL:** `https://rickandmortyapi.com/api`
- **Official documentation:** [List Locations](https://rickandmortyapi.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page of results. |
| `name` | query | `string` | no | Filter by name. |
| `type` | query | `string` | no | Filter by type. |
| `dimension` | query | `string` | no | Filter by dimension. |
