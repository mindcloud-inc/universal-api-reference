# List QR Codes with Recut URL Shortener

Retrieves QR codes from Recut URL Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/qr`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [List QR Codes](https://app.recut.in/developers#list-qr-codes)

## Capabilities

This operation supports [pagination](../README.md#pagination).
