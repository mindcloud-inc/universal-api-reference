# List Files with Recut URL Shortener

Retrieves files from Recut URL Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/files`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [List Files](https://app.recut.in/developers#list-files)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | Filter files by name |
