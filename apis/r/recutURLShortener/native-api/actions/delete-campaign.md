# Delete Campaign with Recut URL Shortener

Deletes an existing campaign from Recut URL Shortener.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/campaign/:id/delete`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [Delete Campaign](https://app.recut.in/developers#delete-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Campaign ID. |
