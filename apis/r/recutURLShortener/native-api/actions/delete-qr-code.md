# Delete QR Code with Recut URL Shortener

Deletes an existing QR code from Recut URL Shortener.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/qr/:id/delete`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [Delete QR Code](https://app.recut.in/developers#delete-a-qr-code)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | QR code ID |
