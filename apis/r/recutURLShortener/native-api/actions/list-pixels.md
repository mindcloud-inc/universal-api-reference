# List Pixels with Recut URL Shortener

Retrieves tracking pixels from Recut URL Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/pixels`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [List Pixels](https://app.recut.in/developers#list-pixels)

## Capabilities

This operation supports [pagination](../README.md#pagination).
