# Delete Channel with Recut URL Shortener

Deletes an existing channel from Recut URL Shortener.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/channel/:id/delete`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [Delete Channel](https://app.recut.in/developers#delete-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Channel ID. |
