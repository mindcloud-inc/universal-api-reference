# Delete Domain with Recut URL Shortener

Deletes an existing branded domain from Recut URL Shortener.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/domain/:id/delete`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [Delete Domain](https://app.recut.in/developers#delete-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Domain ID |
