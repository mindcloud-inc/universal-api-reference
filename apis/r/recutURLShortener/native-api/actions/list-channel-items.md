# List Channel Items with Recut URL Shortener

Retrieves items from a channel in Recut URL Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/channel/:id`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [List Channel Items](https://app.recut.in/developers#list-channel-items)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Channel ID. |
