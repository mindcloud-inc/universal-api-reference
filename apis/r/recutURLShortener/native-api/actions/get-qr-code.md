# Get QR Code with Recut URL Shortener

Retrieves QR code details from Recut URL Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/qr/:id`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [Get QR Code](https://app.recut.in/developers#get-a-single-qr-code)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | QR code ID |
