# List CTA Overlays with Recut URL Shortener

Retrieves CTA overlays from Recut URL Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/overlay`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [List CTA Overlays](https://app.recut.in/developers#list-cta-overlays)

## Capabilities

This operation supports [pagination](../README.md#pagination).
