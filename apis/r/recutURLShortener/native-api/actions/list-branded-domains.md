# List Branded Domains with Recut URL Shortener

Retrieves branded domains from Recut URL Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [List Branded Domains](https://app.recut.in/developers#list-branded-domains)

## Capabilities

This operation supports [pagination](../README.md#pagination).
