# Delete Link with Recut URL Shortener

Deletes an existing link from Recut URL Shortener.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/url/:id/delete`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [Delete Link](https://app.recut.in/developers#delete-a-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Link ID. |
