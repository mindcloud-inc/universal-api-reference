# List Channels with Recut URL Shortener

Retrieves channels from Recut URL Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [List Channels](https://app.recut.in/developers#list-channels)

## Capabilities

This operation supports [pagination](../README.md#pagination).
