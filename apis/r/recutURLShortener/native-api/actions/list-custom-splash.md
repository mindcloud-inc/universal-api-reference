# List Custom Splash with Recut URL Shortener

Retrieves custom splash pages from Recut URL Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/splash`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [List Custom Splash](https://app.recut.in/developers#list-custom-splash)

## Capabilities

This operation supports [pagination](../README.md#pagination).
