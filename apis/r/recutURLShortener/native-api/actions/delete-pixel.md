# Delete Pixel with Recut URL Shortener

Deletes an existing tracking pixel from Recut URL Shortener.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pixel/:id/delete`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [Delete Pixel](https://app.recut.in/developers#delete-pixel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pixel ID |
