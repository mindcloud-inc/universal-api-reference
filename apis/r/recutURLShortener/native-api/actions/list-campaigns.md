# List Campaigns with Recut URL Shortener

Retrieves campaigns from Recut URL Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [List Campaigns](https://app.recut.in/developers#list-campaigns)

## Capabilities

This operation supports [pagination](../README.md#pagination).
