# Get Link with Recut URL Shortener

Retrieves link details from Recut URL Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/url/:id`
- **Base URL:** `https://app.recut.in/api`
- **Official documentation:** [Get Link](https://app.recut.in/developers#get-a-single-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Link ID. |
