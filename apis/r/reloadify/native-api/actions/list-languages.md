# List Languages with Reloadify

Retrieves languages from Reloadify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/languages`
- **Base URL:** `https://api.reloadify.com/api`
- **Official documentation:** [List Languages](https://app.reloadify.com/api-docs/index.html#/languages/getV2Languages)

## Capabilities

This operation supports [pagination](../README.md#pagination).
