# List Custom Attributes with Reloadify

Retrieves custom attributes from Reloadify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/custom_attributes`
- **Base URL:** `https://api.reloadify.com/api`
- **Official documentation:** [List Custom Attributes](https://app.reloadify.com/api-docs/index.html#/custom_attributes/getV2CustomAttributes)

## Capabilities

This operation supports [pagination](../README.md#pagination).
