# Delete Timeline Event with Reportei

Deletes an existing timeline event from Reportei.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/timeline-events/:id`
- **Base URL:** `https://app.reportei.com/api/v2`
- **Official documentation:** [Delete Timeline Event](https://developers.reportei.com#timeline-endpoint-4)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID do evento. |
