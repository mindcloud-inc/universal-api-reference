# Get Webhook with Reportei

Retrieves a webhook from Reportei.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://app.reportei.com/api/v2`
- **Official documentation:** [Get Webhook](https://developers.reportei.com#webhooks-endpoint-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID do webhook. |
