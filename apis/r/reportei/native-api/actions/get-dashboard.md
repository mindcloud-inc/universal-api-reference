# Get Dashboard with Reportei

Retrieves a dashboard from Reportei.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboards/:id`
- **Base URL:** `https://app.reportei.com/api/v2`
- **Official documentation:** [Get Dashboard](https://developers.reportei.com#dashboards-endpoint-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID do dashboard. |
