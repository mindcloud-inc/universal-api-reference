# Get Project with Reportei

Retrieves a project from Reportei.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://app.reportei.com/api/v2`
- **Official documentation:** [Get Project](https://developers.reportei.com#projetos-endpoint-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID do projeto. |
