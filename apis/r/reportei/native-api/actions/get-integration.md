# Get Integration with Reportei

Retrieves an integration from Reportei.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations/:id`
- **Base URL:** `https://app.reportei.com/api/v2`
- **Official documentation:** [Get Integration](https://developers.reportei.com#integracoes-endpoint-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID da integração. |
