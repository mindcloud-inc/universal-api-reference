# Get Template with Reportei

Retrieves a template from Reportei.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:id`
- **Base URL:** `https://app.reportei.com/api/v2`
- **Official documentation:** [Get Template](https://developers.reportei.com#templates-endpoint-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID do template. |
