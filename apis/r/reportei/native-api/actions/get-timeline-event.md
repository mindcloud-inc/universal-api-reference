# Get Timeline Event with Reportei

Retrieves a timeline event from Reportei.

## Endpoint

- **Method:** `GET`
- **Path:** `/timeline-events/:id`
- **Base URL:** `https://app.reportei.com/api/v2`
- **Official documentation:** [Get Timeline Event](https://developers.reportei.com#timeline-endpoint-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID do evento. |
