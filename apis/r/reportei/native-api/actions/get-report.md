# Get Report with Reportei

Retrieves a report from Reportei.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/:id`
- **Base URL:** `https://app.reportei.com/api/v2`
- **Official documentation:** [Get Report](https://developers.reportei.com#relatorios-endpoint-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID do relatório. |
