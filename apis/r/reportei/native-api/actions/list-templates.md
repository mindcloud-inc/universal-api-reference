# List Templates with Reportei

Retrieves templates from Reportei.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://app.reportei.com/api/v2`
- **Official documentation:** [List Templates](https://developers.reportei.com#templates-endpoint-0)

## Capabilities

This operation supports [pagination](../README.md#pagination).
