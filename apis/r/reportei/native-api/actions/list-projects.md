# List Projects with Reportei

Retrieves projects from Reportei.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://app.reportei.com/api/v2`
- **Official documentation:** [List Projects](https://developers.reportei.com#projetos-endpoint-0)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search projects by name. |
