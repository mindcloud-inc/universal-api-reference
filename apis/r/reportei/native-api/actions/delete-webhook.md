# Delete Webhook with Reportei

Deletes an existing webhook from Reportei.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://app.reportei.com/api/v2`
- **Official documentation:** [Delete Webhook](https://developers.reportei.com#webhooks-endpoint-5)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID do webhook. |
