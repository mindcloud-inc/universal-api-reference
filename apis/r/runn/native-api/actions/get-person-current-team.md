# Get Person Current Team with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{personId}}/teams/current`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [Get Person Current Team](https://developer.runn.io/reference/get_people-personid-teams-current)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `number` | yes | Runn person ID. |
