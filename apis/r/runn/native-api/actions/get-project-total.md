# Get Project Total with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/totals/projects/{{projectId}}`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [Get Project Total](https://developer.runn.io/reference/get_reports-totals-projects-projectid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | Runn project ID. |
