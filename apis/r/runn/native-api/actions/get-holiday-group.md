# Get Holiday Group with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/holiday-groups/{{holidayGroupId}}`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [Get Holiday Group](https://developer.runn.io/reference/get_holiday-groups-holidaygroupid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `holidayGroupId` | path | `number` | yes | Runn holiday group ID. |
