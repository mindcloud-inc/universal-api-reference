# List Person Hour Report with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/hours/people/{{personId}}`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [List Person Hour Report](https://developer.runn.io/reference/get_reports-hours-people-personid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `number` | yes | Runn person ID. |
