# List Client Projects with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/{{clientId}}/projects/`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [List Client Projects](https://developer.runn.io/reference/get_clients-clientid-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | path | `number` | yes | Runn client ID. |
