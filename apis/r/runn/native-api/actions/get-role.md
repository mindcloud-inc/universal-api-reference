# Get Role with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/roles/{{roleId}}`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [Get Role](https://developer.runn.io/reference/get_roles-roleid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roleId` | path | `number` | yes | Runn role ID. |
