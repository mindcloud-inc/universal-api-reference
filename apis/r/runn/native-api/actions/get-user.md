# Get User with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{{userId}}`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [Get User](https://developer.runn.io/reference/get_users-userid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | Runn user ID. |
