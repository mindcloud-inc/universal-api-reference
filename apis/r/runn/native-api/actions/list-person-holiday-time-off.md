# List Person Holiday Time Off with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{personId}}/time-offs/holidays`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [List Person Holiday Time Off](https://developer.runn.io/reference/get_people-personid-time-offs-holidays)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `number` | yes | Runn person ID. |
