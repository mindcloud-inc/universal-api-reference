# Get Rate Card with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/rate-cards/{{rateCardId}}`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [Get Rate Card](https://developer.runn.io/reference/get_rate-cards-ratecardid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rateCardId` | path | `number` | yes | Runn rate card ID. |
