# List Team People with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/{{teamId}}/people/`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [List Team People](https://developer.runn.io/reference/get_teams-teamid-people)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `number` | yes | Runn team ID. |
