# List Project Hour Report with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/hours/projects/{{projectId}}`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [List Project Hour Report](https://developer.runn.io/reference/get_reports-hours-projects-projectid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | Runn project ID. |
