# List Project Assignments with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{{projectId}}/assignments/`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [List Project Assignments](https://developer.runn.io/reference/get_projects-projectid-assignments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | Runn project ID. |
