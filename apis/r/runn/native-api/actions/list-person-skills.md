# List Person Skills with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{personId}}/skills/`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [List Person Skills](https://developer.runn.io/reference/get_people-personid-skills)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `number` | yes | Runn person ID. |
