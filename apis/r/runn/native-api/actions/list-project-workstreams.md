# List Project Workstreams with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{{projectId}}/project-workstreams/`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [List Project Workstreams](https://developer.runn.io/reference/get_projects-projectid-project-workstreams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | Runn project ID. |
