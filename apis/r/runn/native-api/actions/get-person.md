# Get Person with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{personId}}`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [Get Person](https://developer.runn.io/reference/get_people-personid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `number` | yes | Runn person ID. |
