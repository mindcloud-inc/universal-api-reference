# List Person Projects with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{personId}}/projects/`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [List Person Projects](https://developer.runn.io/reference/get_people-personid-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `number` | yes | Runn person ID. |
