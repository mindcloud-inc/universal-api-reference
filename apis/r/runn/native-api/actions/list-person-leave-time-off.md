# List Person Leave Time Off with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{personId}}/time-offs/leave`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [List Person Leave Time Off](https://developer.runn.io/reference/get_people-personid-time-offs-leave)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `number` | yes | Runn person ID. |
