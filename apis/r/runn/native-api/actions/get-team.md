# Get Team with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/{{teamId}}/`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [Get Team](https://developer.runn.io/reference/get_teams-teamid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `number` | yes | Runn team ID. |
