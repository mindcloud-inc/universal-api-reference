# List Person Assignments with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{personId}}/assignments/`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [List Person Assignments](https://developer.runn.io/reference/get_people-personid-assignments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `number` | yes | Runn person ID. |
