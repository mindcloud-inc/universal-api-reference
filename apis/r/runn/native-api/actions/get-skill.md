# Get Skill with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/skills/{{skillId}}`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [Get Skill](https://developer.runn.io/reference/get_skills-skillid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `skillId` | path | `number` | yes | Runn skill ID. |
