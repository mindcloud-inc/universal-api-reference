# Get Client with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/{{clientId}}`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [Get Client](https://developer.runn.io/reference/get_clients-clientid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | path | `number` | yes | Runn client ID. |
