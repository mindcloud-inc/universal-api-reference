# Get Project with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{{projectId}}`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [Get Project](https://developer.runn.io/reference/get_projects-projectid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | Runn project ID. |
