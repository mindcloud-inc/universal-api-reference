# List Skill People with Runn

## Endpoint

- **Method:** `GET`
- **Path:** `/skills/{{skillId}}/people/`
- **Base URL:** `https://api.runn.io`
- **Official documentation:** [List Skill People](https://developer.runn.io/reference/get_skills-skillid-people)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `skillId` | path | `number` | yes | Runn skill ID. |
