# Delete Dynamic Value with Rulebricks

Deletes a dynamic value from Rulebricks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/values`
- **Base URL:** `https://rulebricks.com/api/v1`
- **Official documentation:** [Delete Dynamic Value](https://rulebricks.com/docs/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | ID of the dynamic value to delete |
