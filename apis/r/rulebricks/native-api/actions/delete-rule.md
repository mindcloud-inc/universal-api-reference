# Delete Rule with Rulebricks

Deletes a rule from Rulebricks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/admin/rules/delete`
- **Base URL:** `https://rulebricks.com/api/v1`
- **Official documentation:** [Delete Rule](https://rulebricks.com/docs/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | ID of the rule to delete |
