# List Rules with Rulebricks

Retrieves rules from Rulebricks.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/rules/list`
- **Base URL:** `https://rulebricks.com/api/v1`
- **Official documentation:** [List Rules](https://rulebricks.com/docs/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder` | query | `string` | no | Filter rules by folder name or folder ID |
