# Delete Folder with Rulebricks

Deletes a rule folder from Rulebricks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/admin/folders`
- **Base URL:** `https://rulebricks.com/api/v1`
- **Official documentation:** [Delete Folder](https://rulebricks.com/docs/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | ID of the folder to delete |
