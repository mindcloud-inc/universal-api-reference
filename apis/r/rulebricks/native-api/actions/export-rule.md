# Export Rule with Rulebricks

Exports a rule from Rulebricks.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/rules/export`
- **Base URL:** `https://rulebricks.com/api/v1`
- **Official documentation:** [Export Rule](https://rulebricks.com/docs/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | ID of the rule to export |
