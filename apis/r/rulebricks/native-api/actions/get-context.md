# Get Context with Rulebricks

Retrieves a context from Rulebricks.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/contexts/:id`
- **Base URL:** `https://rulebricks.com/api/v1`
- **Official documentation:** [Get Context](https://rulebricks.com/docs/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the context to retrieve |
