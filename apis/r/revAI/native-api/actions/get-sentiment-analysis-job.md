# Get Sentiment Analysis Job with Rev AI

Retrieves a sentiment analysis job from Rev AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/sentiment_analysis/v1/jobs/:id`
- **Base URL:** `https://api.rev.ai`
- **Official documentation:** [Get Sentiment Analysis Job](https://docs.rev.ai/api/sentiment-analysis/reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
