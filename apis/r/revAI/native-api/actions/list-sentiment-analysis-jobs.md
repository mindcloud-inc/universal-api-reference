# List Sentiment Analysis Jobs with Rev AI

Retrieves sentiment analysis jobs from Rev AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/sentiment_analysis/v1/jobs`
- **Base URL:** `https://api.rev.ai`
- **Official documentation:** [List Sentiment Analysis Jobs](https://docs.rev.ai/api/sentiment-analysis/reference)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | query | `number` | no |
| `starting_after` | query | `string` | no |
