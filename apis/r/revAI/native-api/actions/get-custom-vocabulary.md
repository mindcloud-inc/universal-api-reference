# Get Custom Vocabulary with Rev AI

Retrieves a custom vocabulary from Rev AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/speechtotext/v1/vocabularies/:id`
- **Base URL:** `https://api.rev.ai`
- **Official documentation:** [Get Custom Vocabulary](https://docs.rev.ai/api/custom-vocabulary/reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
