# Delete Sentiment Analysis Job with Rev AI

Deletes a sentiment analysis job from Rev AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sentiment_analysis/v1/jobs/:id`
- **Base URL:** `https://api.rev.ai`
- **Official documentation:** [Delete Sentiment Analysis Job](https://docs.rev.ai/api/sentiment-analysis/reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
