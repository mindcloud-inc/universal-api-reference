# Get Transcript Summary with Rev AI

Retrieves a transcript summary from Rev AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/speechtotext/v1/jobs/:id/transcript/summary`
- **Base URL:** `https://api.rev.ai`
- **Official documentation:** [Get Transcript Summary](https://docs.rev.ai/api/asynchronous/reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
