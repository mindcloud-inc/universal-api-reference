# Get Transcription Job with Rev AI

Retrieves a transcription job from Rev AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/speechtotext/v1/jobs/:id`
- **Base URL:** `https://api.rev.ai`
- **Official documentation:** [Get Transcription Job](https://docs.rev.ai/api/asynchronous/reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
