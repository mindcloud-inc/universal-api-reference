# Delete Topic Extraction Job with Rev AI

Deletes a topic extraction job from Rev AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/topic_extraction/v1/jobs/:id`
- **Base URL:** `https://api.rev.ai`
- **Official documentation:** [Delete Topic Extraction Job](https://docs.rev.ai/api/topic-extraction/reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
