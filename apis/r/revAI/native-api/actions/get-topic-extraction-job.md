# Get Topic Extraction Job with Rev AI

Retrieves a topic extraction job from Rev AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/topic_extraction/v1/jobs/:id`
- **Base URL:** `https://api.rev.ai`
- **Official documentation:** [Get Topic Extraction Job](https://docs.rev.ai/api/topic-extraction/reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
