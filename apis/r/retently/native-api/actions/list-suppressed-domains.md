# List Suppressed Domains with Retently

Retrieves a list of suppressed domains from Retently.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/suppressions/domains`
- **Base URL:** `https://app.retently.com`
- **Official documentation:** [List Suppressed Domains](https://www.retently.com/api/#api-get-suppressions-domains)
