# Remove Suppressed Email with Retently

Deletes a suppressed email entry from Retently.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/suppressions/emails/:id`
- **Base URL:** `https://app.retently.com`
- **Official documentation:** [Remove Suppressed Email](https://www.retently.com/api/#api-delete-suppressions-email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id |
