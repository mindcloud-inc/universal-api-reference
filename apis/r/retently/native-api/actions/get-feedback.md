# Get Feedback with Retently

Retrieves a feedback response from Retently by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/feedback/:feedbackId`
- **Base URL:** `https://app.retently.com`
- **Official documentation:** [Get Feedback](https://www.retently.com/api/#api-get-feedback-get-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `feedbackId` | path | `string` | yes | Feedback Id |
