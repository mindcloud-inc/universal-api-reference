# List Suppressed Emails with Retently

Retrieves a list of suppressed emails from Retently.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/suppressions/emails`
- **Base URL:** `https://app.retently.com`
- **Official documentation:** [List Suppressed Emails](https://www.retently.com/api/#api-get-suppressions-emails)
