# Remove Suppressed Domain with Retently

Deletes a suppressed domain entry from Retently.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/suppressions/domains/:id`
- **Base URL:** `https://app.retently.com`
- **Official documentation:** [Remove Suppressed Domain](https://www.retently.com/api/#api-delete-suppressions-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id |
