# Get Customer with Retently

Retrieves a customer from Retently by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/customers/:customerId`
- **Base URL:** `https://app.retently.com`
- **Official documentation:** [Get Customer](https://www.retently.com/api/#api-get-customer-get-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | Customer Id |
