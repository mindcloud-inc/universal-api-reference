# List Channels with respond.io

Retrieves channels from respond.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/space/channel`
- **Base URL:** `https://api.respond.io/v2`
- **Official documentation:** [List Channels](https://stoplight.io/api/v1/projects/respond/api/nodes/v2/space-api.yml/paths/~1space~1channel/get?fromExportButton=true&snapshotType=http_operation)

## Capabilities

This operation supports [pagination](../README.md#pagination).
