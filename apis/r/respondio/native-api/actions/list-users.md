# List Users with respond.io

Retrieves users from respond.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/space/user`
- **Base URL:** `https://api.respond.io/v2`
- **Official documentation:** [List Users](https://stoplight.io/api/v1/projects/respond/api/nodes/v2/space-api.yml/paths/~1space~1user/get?fromExportButton=true&snapshotType=http_operation)

## Capabilities

This operation supports [pagination](../README.md#pagination).
