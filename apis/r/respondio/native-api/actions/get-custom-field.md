# Get Custom Field with respond.io

Retrieves a custom field from respond.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/space/custom_field/:id`
- **Base URL:** `https://api.respond.io/v2`
- **Official documentation:** [Get Custom Field](https://stoplight.io/api/v1/projects/respond/api/nodes/v2/space-api.yml/paths/~1space~1custom_field~1%7Bid%7D/get?fromExportButton=true&snapshotType=http_operation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Custom field ID. |
