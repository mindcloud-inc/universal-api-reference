# List Closing Notes with respond.io

Retrieves closing notes from respond.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/space/closing_notes`
- **Base URL:** `https://api.respond.io/v2`
- **Official documentation:** [List Closing Notes](https://stoplight.io/api/v1/projects/respond/api/nodes/v2/space-api.yml/paths/~1space~1closing_notes/get?fromExportButton=true&snapshotType=http_operation)

## Capabilities

This operation supports [pagination](../README.md#pagination).
