# List Custom Fields with respond.io

Retrieves custom fields from respond.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/space/custom_field`
- **Base URL:** `https://api.respond.io/v2`
- **Official documentation:** [List Custom Fields](https://stoplight.io/api/v1/projects/respond/api/nodes/v2/space-api.yml/paths/~1space~1custom_field/get?fromExportButton=true&snapshotType=http_operation)

## Capabilities

This operation supports [pagination](../README.md#pagination).
