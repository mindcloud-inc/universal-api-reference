# Delete Space Tag with respond.io

Deletes a space tag from respond.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/space/tag`
- **Base URL:** `https://api.respond.io/v2`
- **Official documentation:** [Delete Space Tag](https://stoplight.io/api/v1/projects/respond/api/nodes/v2/space-api.yml/paths/~1space~1tag/delete?fromExportButton=true&snapshotType=http_operation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Space tag name to delete. |
