# Find Subscriber By Email with Realcrux

## Endpoint

- **Method:** `GET`
- **Path:** `subscribers/email/:email`
- **Base URL:** `https://sendcrux.com/api/v1`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Email address to search for in Sendcrux. |
