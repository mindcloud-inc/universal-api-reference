# Get Mail List with Realcrux

## Endpoint

- **Method:** `GET`
- **Path:** `lists/:uid`
- **Base URL:** `https://sendcrux.com/api/v1`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | UID of the Sendcrux mail list to inspect. |
