# Delete Subscriber with Realcrux

## Endpoint

- **Method:** `DELETE`
- **Path:** `subscribers/:uid`
- **Base URL:** `https://sendcrux.com/api/v1`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | UID of the subscriber record to delete. |
