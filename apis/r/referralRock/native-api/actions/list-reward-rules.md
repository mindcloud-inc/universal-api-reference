# List Reward Rules with Referral Rock

Retrieves member reward rules from Referral Rock.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/rewardrules`
- **Base URL:** `https://api.referralrock.com`
- **Official documentation:** [List Reward Rules](https://api.referralrock.com/Help/Api/GET-api-rewardrules_programId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `programId` | query | `string` | yes | ID of the program. |
