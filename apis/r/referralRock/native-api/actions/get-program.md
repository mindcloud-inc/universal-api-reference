# Get Program with Referral Rock

Retrieves a referral program from Referral Rock by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/program/getsingle`
- **Base URL:** `https://api.referralrock.com`
- **Official documentation:** [Get Program](https://api.referralrock.com/Help/Api/GET-api-program-getsingle_programName)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `programName` | query | `string` | yes | The name of the referral program to retrieve. |
