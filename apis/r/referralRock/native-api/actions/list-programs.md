# List Programs with Referral Rock

Retrieves referral programs from Referral Rock.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/programs`
- **Base URL:** `https://api.referralrock.com`
- **Official documentation:** [List Programs](https://api.referralrock.com/Help/Api/GET-api-programs_programId_offset_count)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `programId` | query | `string` | no | Id of the program of interest. |
| `programId` | query | `string` | no | ID of the program of interest. |
