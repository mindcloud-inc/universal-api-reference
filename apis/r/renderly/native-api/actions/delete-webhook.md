# Delete Webhook with Renderly

Deletes a webhook endpoint from Renderly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks`
- **Base URL:** `https://renderly.video/api/v1`
- **Official documentation:** [Delete Webhook](https://renderly.video/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The webhook ID to delete. |
