# Get Render Status with Renderly

Retrieves a render job's status from Renderly.

## Endpoint

- **Method:** `GET`
- **Path:** `/renders/:jobId`
- **Base URL:** `https://renderly.video/api/v1`
- **Official documentation:** [Get Render Status](https://renderly.video/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The ID of the render job. |
