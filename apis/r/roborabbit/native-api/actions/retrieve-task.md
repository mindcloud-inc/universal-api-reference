# Retrieve Task with Roborabbit

Retrieves a browser automation task from Roborabbit.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tasks/:uid`
- **Base URL:** `https://api.roborabbit.com`
- **Official documentation:** [Retrieve Task](https://developers.roborabbit.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The task UID from Roborabbit. |
