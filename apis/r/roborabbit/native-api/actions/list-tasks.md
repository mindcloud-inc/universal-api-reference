# List Tasks with Roborabbit

Retrieves browser automation tasks from Roborabbit.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tasks`
- **Base URL:** `https://api.roborabbit.com`
- **Official documentation:** [List Tasks](https://developers.roborabbit.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number for paginated task results. |
