# Get Workspace with Roger

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:id`
- **Base URL:** `https://api.rogerroger.io`
- **Official documentation:** [Get Workspace](https://developer.rogerroger.io/workspaces/workspaces)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Workspace identifier. |
