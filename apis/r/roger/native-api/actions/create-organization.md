# Create Organization with Roger

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations`
- **Base URL:** `https://api.rogerroger.io`
- **Official documentation:** [Create Organization](https://developer.rogerroger.io/organizations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Organization title. |
| `description` | body | `string` | no | Optional organization description. |
