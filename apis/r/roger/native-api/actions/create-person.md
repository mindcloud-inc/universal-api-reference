# Create Person with Roger

## Endpoint

- **Method:** `POST`
- **Path:** `/people`
- **Base URL:** `https://api.rogerroger.io`
- **Official documentation:** [Create Person](https://developer.rogerroger.io/crm/people)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `familyName` | body | `string` | yes | The contact's family name. |
| `givenName` | body | `string` | no | The contact's given name. |
