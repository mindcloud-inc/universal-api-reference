# Create Task with Roger

## Endpoint

- **Method:** `POST`
- **Path:** `/tasks`
- **Base URL:** `https://api.rogerroger.io`
- **Official documentation:** [Create Task](https://developer.rogerroger.io/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Task title. |
| `description` | body | `string` | no | Optional task description. |
