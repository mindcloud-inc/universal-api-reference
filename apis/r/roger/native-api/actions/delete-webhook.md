# Delete Webhook with Roger

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.rogerroger.io`
- **Official documentation:** [Delete Webhook](https://developer.rogerroger.io/webhooks/set-up-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook identifier. |
