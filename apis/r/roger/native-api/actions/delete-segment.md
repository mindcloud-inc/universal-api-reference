# Delete Segment with Roger

## Endpoint

- **Method:** `DELETE`
- **Path:** `/segments/:id`
- **Base URL:** `https://api.rogerroger.io`
- **Official documentation:** [Delete Segment](https://developer.rogerroger.io/lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Segment identifier. |
