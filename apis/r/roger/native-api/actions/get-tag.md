# Get Tag with Roger

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:id`
- **Base URL:** `https://api.rogerroger.io`
- **Official documentation:** [Get Tag](https://developer.rogerroger.io/global/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Tag identifier. |
