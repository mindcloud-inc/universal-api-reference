# Create Segment with Roger

## Endpoint

- **Method:** `POST`
- **Path:** `/segments`
- **Base URL:** `https://api.rogerroger.io`
- **Official documentation:** [Create Segment](https://developer.rogerroger.io/lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Segment title. |
| `icon` | body | `string` | yes | Segment icon identifier. |
