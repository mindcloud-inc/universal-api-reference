# Create Tag with Roger

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://api.rogerroger.io`
- **Official documentation:** [Create Tag](https://developer.rogerroger.io/global/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Tag title. |
| `backgroundColor` | body | `string` | no | Optional tag background color hex code. |
| `textColor` | body | `string` | no | Optional tag text color hex code. |
| `description` | body | `string` | no | Optional tag description. |
