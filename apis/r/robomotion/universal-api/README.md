# <img src="https://images.mindcloud.co/apps/icons/robomotion-icon_1776455688737.png" alt="Robomotion logo" width="28" height="28"> Robomotion: Universal API

Robomotion is an RPA platform for building, scheduling, and running robotic process automation workflows. This app connects to the Robomotion workspace API so you can manage flows, jobs, robots, schedules, users, queues, vaults, and related workspace resources.
