# List Remastering Presets with RemasterMedia

Retrieves remastering presets from RemasterMedia.

## Endpoint

- **Method:** `GET`
- **Path:** `/actions/remaster/presets`
- **Base URL:** `https://api-sandbox.remastermedia.com/v2`
- **Official documentation:** [List Remastering Presets](https://remastermedia-web-assets.s3-accelerate.amazonaws.com/api_reference-v2.html#action-details-list-remastering-presets-get)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
