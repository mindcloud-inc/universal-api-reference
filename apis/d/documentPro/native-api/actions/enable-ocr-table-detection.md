# Enable OCR Table Detection with DocumentPro

Enables OCR table detection for a DocumentPro workflow.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/templates/:template_id`
- **Base URL:** `https://api.documentpro.ai`
- **Official documentation:** [Enable OCR Table Detection](https://docs.documentpro.ai/docs/using-api/manage-workflows/update-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The workflow template_id. |
