# Delete Job with DocumentPro

Deletes an extract job from DocumentPro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files`
- **Base URL:** `https://api.documentpro.ai`
- **Official documentation:** [Delete Job](https://docs.documentpro.ai/docs/using-api/extract/delete-result)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `request_id` | query | `string` | yes | The request_id of the extract job to delete. |
