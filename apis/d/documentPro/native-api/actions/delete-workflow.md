# Delete Workflow with DocumentPro

Deletes an existing workflow from DocumentPro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/templates/:template_id`
- **Base URL:** `https://api.documentpro.ai`
- **Official documentation:** [Delete Workflow](https://docs.documentpro.ai/docs/using-api/manage-workflows/delete-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The workflow template_id. |
