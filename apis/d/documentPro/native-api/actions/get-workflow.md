# Get Workflow with DocumentPro

Retrieves a workflow from DocumentPro by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/templates/:template_id`
- **Base URL:** `https://api.documentpro.ai`
- **Official documentation:** [Get Workflow](https://docs.documentpro.ai/docs/using-api/manage-workflows/get-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The workflow template_id. |
