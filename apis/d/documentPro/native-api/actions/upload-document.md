# Upload Document with DocumentPro

Uploads a document to DocumentPro.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/documents`
- **Base URL:** `https://api.documentpro.ai`
- **Official documentation:** [Upload Document](https://docs.documentpro.ai/docs/using-api/extract/upload-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | body | `file` | yes | The document file to upload. |
