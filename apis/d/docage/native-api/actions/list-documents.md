# List Documents with Docage

Retrieves accessible documents from Docage.

## Endpoint

- **Method:** `GET`
- **Path:** `/Documents`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [List Documents](https://documentation.docage.com/obtenir-tous-les-documents-accessibles-par-lutilisateur-23707654e0)
