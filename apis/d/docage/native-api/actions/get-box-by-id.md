# Get Box By ID with Docage

Retrieves a box from Docage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/Boxes/ById/:id`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Get Box By ID](https://documentation.docage.com/obtenir-un-classeur-par-son-id-23707576e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docage box ID. |
