# Launch Transaction with Docage

Launches a transaction in Docage.

## Endpoint

- **Method:** `POST`
- **Path:** `/Transactions/LaunchTransaction/:id`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Launch Transaction](https://documentation.docage.com/lancer-une-transaction-23280555e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docage transaction ID. |
