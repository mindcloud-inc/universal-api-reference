# Get Transaction Status with Docage

Retrieves the status of a Docage transaction.

## Endpoint

- **Method:** `GET`
- **Path:** `/Transactions/Status/:id`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Get Transaction Status](https://documentation.docage.com/r%C3%A9cup%C3%A9rer-le-statut-dune-transaction-23280563e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docage transaction ID. |
