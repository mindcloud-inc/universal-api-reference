# Get Docage User By Email with Docage

Retrieves a user from Docage by email.

## Endpoint

- **Method:** `GET`
- **Path:** `/DocageUsers/byemail/:email`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Get Docage User By Email](https://documentation.docage.com/obtenir-un-utilisateur-par-son-email-23707629e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | The Docage user email address. |
