# List Boxes with Docage

Retrieves accessible boxes from Docage.

## Endpoint

- **Method:** `GET`
- **Path:** `/Boxes`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [List Boxes](https://documentation.docage.com/obtenir-tous-les-classeurs-accessibles-par-lutilisateur-23707569e0)
