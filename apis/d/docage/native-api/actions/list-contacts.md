# List Contacts with Docage

Retrieves accessible contacts from Docage.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contacts`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [List Contacts](https://documentation.docage.com/obtenir-tous-les-contacts-accessibles-par-lutilisateur-23280521e0)
