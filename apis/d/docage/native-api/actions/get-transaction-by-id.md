# Get Transaction By ID with Docage

Retrieves a transaction from Docage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/Transactions/ById/:id`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Get Transaction By ID](https://documentation.docage.com/obtenir-un-parcours-par-son-id-23707906e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docage transaction ID. |
