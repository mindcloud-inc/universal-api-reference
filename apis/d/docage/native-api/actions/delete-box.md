# Delete Box with Docage

Deletes an existing box from Docage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Boxes/:id`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Delete Box](https://documentation.docage.com/supprimer-un-classeur-23707564e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docage box ID. |
