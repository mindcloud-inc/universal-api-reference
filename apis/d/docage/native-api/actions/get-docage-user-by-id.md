# Get Docage User By ID with Docage

Retrieves a user from Docage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/DocageUsers/ById/:id`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Get Docage User By ID](https://documentation.docage.com/obtenir-un-utilisateur-par-son-id-23707639e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docage user ID. |
