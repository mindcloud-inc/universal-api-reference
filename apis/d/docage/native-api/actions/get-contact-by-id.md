# Get Contact By ID with Docage

Retrieves a contact from Docage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contacts/ById/:id`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Get Contact By ID](https://documentation.docage.com/obtenir-un-contact-par-son-id-23707622e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docage contact ID. |
