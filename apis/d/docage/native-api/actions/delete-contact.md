# Delete Contact with Docage

Deletes an existing contact from Docage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Contacts/:id`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Delete Contact](https://documentation.docage.com/supprimer-un-contact-23707611e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docage contact ID. |
