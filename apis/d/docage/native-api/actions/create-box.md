# Create Box with Docage

Creates a new box in Docage.

## Endpoint

- **Method:** `POST`
- **Path:** `/Boxes`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Create Box](https://documentation.docage.com/cr%C3%A9er-un-classeur-23280582e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Description` | body | `string` | no | An optional box description. |
| `Name` | body | `string` | yes | The box name. |
