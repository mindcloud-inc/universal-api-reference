# Delete Transaction with Docage

Deletes an existing transaction from Docage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Transactions/:id`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Delete Transaction](https://documentation.docage.com/supprimer-un-parcours-23707882e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docage transaction ID. |
