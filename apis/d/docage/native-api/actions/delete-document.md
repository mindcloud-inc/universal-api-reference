# Delete Document with Docage

Deletes an existing document from Docage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Documents/:id`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Delete Document](https://documentation.docage.com/suppression-dun-document-23707651e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docage document ID. |
