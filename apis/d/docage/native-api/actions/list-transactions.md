# List Transactions with Docage

Retrieves accessible transactions from Docage.

## Endpoint

- **Method:** `GET`
- **Path:** `/Transactions`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [List Transactions](https://documentation.docage.com/obtenir-tous-les-parcours-accessibles-par-lutilisateur-23280518e0)
