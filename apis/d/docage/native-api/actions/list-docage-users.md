# List Docage Users with Docage

Retrieves accessible users from Docage.

## Endpoint

- **Method:** `GET`
- **Path:** `/DocageUsers`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [List Docage Users](https://documentation.docage.com/obtenir-tous-les-utilisateurs-accessibles-par-lutilisateur-23707632e0)
