# List Transaction Members with Docage

Retrieves the members of a Docage transaction.

## Endpoint

- **Method:** `GET`
- **Path:** `/Transactions/GetTransactionMembers/:id`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [List Transaction Members](https://documentation.docage.com/obtenir-les-membres-dun-parcours-23707884e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docage transaction ID. |
