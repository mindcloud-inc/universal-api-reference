# Get Contact By Email with Docage

Retrieves a contact from Docage by email.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contacts/byemail/:email`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Get Contact By Email](https://documentation.docage.com/obtenir-un-contact-par-son-email-23707613e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | The Docage contact email address. |
