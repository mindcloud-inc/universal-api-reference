# Get Box By Name with Docage

Retrieves a box from Docage by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/Boxes/ByName/:name`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Get Box By Name](https://documentation.docage.com/obtenir-un-classeur-par-son-nom-23707566e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The Docage box name. |
