# List Organizations with Docage

Retrieves accessible organizations from Docage.

## Endpoint

- **Method:** `GET`
- **Path:** `/Organizations`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [List Organizations](https://documentation.docage.com/obtenir-toutes-les-organisations-accessibles-par-lutilisateur-23707774e0)
