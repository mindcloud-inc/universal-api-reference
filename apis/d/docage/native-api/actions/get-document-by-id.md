# Get Document By ID with Docage

Retrieves a document from Docage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/Documents/ById/:id`
- **Base URL:** `https://api.docage.com`
- **Official documentation:** [Get Document By ID](https://documentation.docage.com/obtenir-un-document-par-son-id-23707662e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docage document ID. |
