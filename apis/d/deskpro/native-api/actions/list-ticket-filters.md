# List Ticket Filters with Deskpro

Retrieves a list of ticket filters from Deskpro.

## Endpoint

- **Method:** `GET`
- **Path:** `/ticket_filters`
- **Base URL:** `{helpdeskUrl}/api/v2`
- **Official documentation:** [List Ticket Filters](https://www.deskpro.com/developers/api-docs/v2.html#get--api-v2-ticket_filters)

## Capabilities

This operation supports [pagination](../README.md#pagination).
