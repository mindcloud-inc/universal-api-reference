# List Online Agents with Deskpro

Retrieves a list of online agents from Deskpro.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/online`
- **Base URL:** `{helpdeskUrl}/api/v2`
- **Official documentation:** [List Online Agents](https://www.deskpro.com/developers/api-docs/v2.html#get--api-v2-agents-online)
