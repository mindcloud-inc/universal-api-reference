# List Ticket IDs with Deskpro

Retrieves a list of ticket IDs from Deskpro.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/ids`
- **Base URL:** `{helpdeskUrl}/api/v2`
- **Official documentation:** [List Ticket IDs](https://www.deskpro.com/developers/api-docs/v2.html#get--api-v2-tickets-ids)

## Capabilities

This operation supports [pagination](../README.md#pagination).
