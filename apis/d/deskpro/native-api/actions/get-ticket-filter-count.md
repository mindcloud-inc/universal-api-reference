# Get Ticket Filter Count with Deskpro

Retrieves the ticket count for a Deskpro filter.

## Endpoint

- **Method:** `GET`
- **Path:** `/ticket_filters/:ticketFilterId/count`
- **Base URL:** `{helpdeskUrl}/api/v2`
- **Official documentation:** [Get Ticket Filter Count](https://www.deskpro.com/developers/api-docs/v2.html#get--api-v2-ticket_filters-{id}-count)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ticketFilterId` | path | `number` | yes |
