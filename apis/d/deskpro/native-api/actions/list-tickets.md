# List Tickets with Deskpro

Retrieves a list of tickets from Deskpro.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets`
- **Base URL:** `{helpdeskUrl}/api/v2`
- **Official documentation:** [List Tickets](https://www.deskpro.com/developers/api-docs/v2.html#get--api-v2-tickets)

## Capabilities

This operation supports [pagination](../README.md#pagination).
