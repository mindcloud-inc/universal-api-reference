# List People with Deskpro

Retrieves a list of people from Deskpro.

## Endpoint

- **Method:** `GET`
- **Path:** `/people`
- **Base URL:** `{helpdeskUrl}/api/v2`
- **Official documentation:** [List People](https://www.deskpro.com/developers/api-docs/v2.html#get--api-v2-people)

## Capabilities

This operation supports [pagination](../README.md#pagination).
