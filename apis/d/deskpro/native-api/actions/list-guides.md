# List Guides with Deskpro

Retrieves a list of guides from Deskpro.

## Endpoint

- **Method:** `GET`
- **Path:** `/guides`
- **Base URL:** `{helpdeskUrl}/api/v2`
- **Official documentation:** [List Guides](https://www.deskpro.com/developers/api-docs/v2.html#get--api-v2-guides)

## Capabilities

This operation supports [pagination](../README.md#pagination).
