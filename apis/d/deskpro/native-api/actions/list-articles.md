# List Articles with Deskpro

Retrieves a list of articles from Deskpro.

## Endpoint

- **Method:** `GET`
- **Path:** `/articles`
- **Base URL:** `{helpdeskUrl}/api/v2`
- **Official documentation:** [List Articles](https://www.deskpro.com/developers/api-docs/v2.html#get--api-v2-articles)

## Capabilities

This operation supports [pagination](../README.md#pagination).
