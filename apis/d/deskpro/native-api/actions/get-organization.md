# Get Organization with Deskpro

Retrieves an organization record from Deskpro.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationId`
- **Base URL:** `{helpdeskUrl}/api/v2`
- **Official documentation:** [Get Organization](https://www.deskpro.com/developers/api-docs/v2.html#get--api-v2-organizations-{id})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `number` | yes |
