# Get Ticket Filter with Deskpro

Retrieves a ticket filter from Deskpro.

## Endpoint

- **Method:** `GET`
- **Path:** `/ticket_filters/:ticketFilterId`
- **Base URL:** `{helpdeskUrl}/api/v2`
- **Official documentation:** [Get Ticket Filter](https://www.deskpro.com/developers/api-docs/v2.html#get--api-v2-ticket_filters-{id})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ticketFilterId` | path | `number` | yes |
