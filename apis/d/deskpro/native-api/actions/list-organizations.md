# List Organizations with Deskpro

Retrieves a list of organizations from Deskpro.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations`
- **Base URL:** `{helpdeskUrl}/api/v2`
- **Official documentation:** [List Organizations](https://www.deskpro.com/developers/api-docs/v2.html#get--api-v2-organizations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
