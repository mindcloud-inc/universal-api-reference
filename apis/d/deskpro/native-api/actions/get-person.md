# Get Person with Deskpro

Retrieves a person record from Deskpro.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/:id`
- **Base URL:** `{helpdeskUrl}/api/v2`
- **Official documentation:** [Get Person](https://www.deskpro.com/developers/api-docs/v2.html#get--api-v2-people-{id})

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The id of the person resource to retrieve, for example 1. |
