# Delete Contact with DitLead

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contact/{contactId}`
- **Base URL:** `https://api.ditlead.com`
- **Official documentation:** [Delete Contact](https://ditlead.com/developer/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | Public ID of the contact. |
