# Create List with DitLead

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/list`
- **Base URL:** `https://api.ditlead.com`
- **Official documentation:** [Create List](https://ditlead.com/developer/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listName` | body | `string` | yes | Name for the new list. |
