# Set Mailbox Warming with DitLead

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/mailbox/warming`
- **Base URL:** `https://api.ditlead.com`
- **Official documentation:** [Set Mailbox Warming](https://ditlead.com/developer/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mailboxAddress` | body | `string` | no |
| `manualWarming` | body | `boolean` | no |
| `warming` | body | `boolean` | no |
