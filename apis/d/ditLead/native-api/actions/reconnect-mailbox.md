# Reconnect Mailbox with DitLead

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/mailbox/reconnect`
- **Base URL:** `https://api.ditlead.com`
- **Official documentation:** [Reconnect Mailbox](https://ditlead.com/developer/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mailboxAddress` | body | `string` | no |
| `mailboxId` | body | `string` | no |
