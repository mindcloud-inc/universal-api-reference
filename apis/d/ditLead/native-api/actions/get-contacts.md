# Get Contacts with DitLead

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contact`
- **Base URL:** `https://api.ditlead.com`
- **Official documentation:** [Get Contacts](https://ditlead.com/developer/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `listId` | query | `string` | no |
| `page` | query | `number` | no |
| `pageSize` | query | `number` | no |
| `search` | query | `string` | no |
