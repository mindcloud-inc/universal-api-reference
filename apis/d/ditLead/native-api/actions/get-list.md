# Get List with DitLead

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/list/{listId}`
- **Base URL:** `https://api.ditlead.com`
- **Official documentation:** [Get List](https://ditlead.com/developer/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Public ID of the list. |
