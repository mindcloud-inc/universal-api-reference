# Get Mailbox with DitLead

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/mailbox/{mailboxId}`
- **Base URL:** `https://api.ditlead.com`
- **Official documentation:** [Get Mailbox](https://ditlead.com/developer/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mailboxId` | path | `string` | yes |
