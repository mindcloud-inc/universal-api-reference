# Get Mailboxes with DitLead

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/mailbox`
- **Base URL:** `https://api.ditlead.com`
- **Official documentation:** [Get Mailboxes](https://ditlead.com/developer/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mailboxId` | path | `string` | yes | Public ID of the mailbox. |
