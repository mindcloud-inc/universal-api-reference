# Get Project with Dremio

Retrieves a project from Dremio by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://api.dremio.cloud/v0`
- **Official documentation:** [Get Project](https://docs.dremio.com/dremio-cloud/api/projects/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
