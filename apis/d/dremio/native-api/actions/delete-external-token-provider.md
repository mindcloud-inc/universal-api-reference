# Delete External Token Provider with Dremio

Deletes an external token provider from Dremio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/external-token-providers/:id`
- **Base URL:** `https://api.dremio.cloud/v0`
- **Official documentation:** [Delete External Token Provider](https://docs.dremio.com/dremio-cloud/api/external-token-providers/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
