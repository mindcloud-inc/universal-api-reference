# List Identity Providers with Dremio

Retrieves identity providers from Dremio.

## Endpoint

- **Method:** `GET`
- **Path:** `/identity-providers`
- **Base URL:** `https://api.dremio.cloud/v0`
- **Official documentation:** [List Identity Providers](https://docs.dremio.com/dremio-cloud/api/identity-providers/)
