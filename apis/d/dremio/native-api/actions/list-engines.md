# List Engines with Dremio

Retrieves engines from a Dremio project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/engines`
- **Base URL:** `https://api.dremio.cloud/v0`
- **Official documentation:** [List Engines](https://docs.dremio.com/dremio-cloud/api/engines/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
