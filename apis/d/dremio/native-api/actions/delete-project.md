# Delete Project with Dremio

Deletes an existing project from Dremio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:id`
- **Base URL:** `https://api.dremio.cloud/v0`
- **Official documentation:** [Delete Project](https://docs.dremio.com/dremio-cloud/api/projects/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
