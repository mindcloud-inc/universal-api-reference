# Get Identity Provider with Dremio

Retrieves an identity provider from Dremio by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/identity-providers/:id`
- **Base URL:** `https://api.dremio.cloud/v0`
- **Official documentation:** [Get Identity Provider](https://docs.dremio.com/dremio-cloud/api/identity-providers/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
