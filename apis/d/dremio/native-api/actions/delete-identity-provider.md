# Delete Identity Provider with Dremio

Deletes an identity provider from Dremio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/identity-providers/:id`
- **Base URL:** `https://api.dremio.cloud/v0`
- **Official documentation:** [Delete Identity Provider](https://docs.dremio.com/dremio-cloud/api/identity-providers/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
