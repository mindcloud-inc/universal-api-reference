# Get External Token Provider with Dremio

Retrieves an external token provider from Dremio by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/external-token-providers/:id`
- **Base URL:** `https://api.dremio.cloud/v0`
- **Official documentation:** [Get External Token Provider](https://docs.dremio.com/dremio-cloud/api/external-token-providers/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
