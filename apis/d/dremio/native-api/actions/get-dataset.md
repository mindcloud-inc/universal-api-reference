# Get Dataset with Dremio

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/catalog/:id`
- **Base URL:** `https://api.dremio.cloud/v0`
- **Official documentation:** [Get Dataset](https://docs.dremio.com/dremio-cloud/api/catalog/dataset/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `project_id` | path | `string` | yes |
