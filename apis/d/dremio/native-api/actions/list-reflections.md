# List Reflections with Dremio

Retrieves reflections from a Dremio project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/reflection`
- **Base URL:** `https://api.dremio.cloud/v0`
- **Official documentation:** [List Reflections](https://docs.dremio.com/dremio-cloud/api/reflection/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
