# Enable External Token Provider with Dremio

Enables an external token provider in Dremio.

## Endpoint

- **Method:** `PUT`
- **Path:** `/external-token-providers/:id/enable`
- **Base URL:** `https://api.dremio.cloud/v0`
- **Official documentation:** [Enable External Token Provider](https://docs.dremio.com/dremio-cloud/api/external-token-providers/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
