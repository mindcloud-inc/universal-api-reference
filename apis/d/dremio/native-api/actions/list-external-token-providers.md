# List External Token Providers with Dremio

Retrieves external token providers from Dremio.

## Endpoint

- **Method:** `GET`
- **Path:** `/external-token-providers`
- **Base URL:** `https://api.dremio.cloud/v0`
- **Official documentation:** [List External Token Providers](https://docs.dremio.com/dremio-cloud/api/external-token-providers/)
