# Delete Cache Entry with Dashcam

Deletes a cache entry from Dashcam.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/cache/entry`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Delete Cache Entry](https://docs.testdriver.ai)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cacheType` | query | `string` | no |
| `id` | query | `string` | no |
