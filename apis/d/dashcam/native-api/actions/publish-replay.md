# Publish Replay with Dashcam

Publishes a replay in Dashcam.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/replay/publish`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Publish Replay](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
