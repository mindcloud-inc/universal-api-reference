# Create Project with Dashcam

Creates a project in Dashcam.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/project`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Create Project](https://docs.testdriver.ai/v6/account/dashboard)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
| `team` | body | `string` | no |
