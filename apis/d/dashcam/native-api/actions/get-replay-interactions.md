# Get Replay Interactions with Dashcam

Retrieves replay interactions from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/testdriver/interactions`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Get Replay Interactions](https://docs.testdriver.ai/v6/getting-started/ci)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `replayId` | query | `string` | no |
| `shareKey` | query | `string` | no |
