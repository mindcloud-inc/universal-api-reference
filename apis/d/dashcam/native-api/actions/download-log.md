# Download Log with Dashcam

Downloads a log file from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/logs/:logId/download`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Download Log](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `logId` | path | `string` | no |
| `shareKey` | query | `string` | no |
