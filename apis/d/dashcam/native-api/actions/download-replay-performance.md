# Download Replay Performance with Dashcam

Downloads a replay performance report from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/replay/:replayId/performance`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Download Replay Performance](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `replayId` | path | `string` | no |
| `shareKey` | query | `string` | no |
