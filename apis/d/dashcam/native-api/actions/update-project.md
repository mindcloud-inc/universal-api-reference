# Update Project with Dashcam

Updates a project in Dashcam.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/projects/:id`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Update Project](https://docs.testdriver.ai/v6/account/dashboard)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
| `name` | body | `string` | no |
| `team` | body | `string` | no |
