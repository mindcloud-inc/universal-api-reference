# Get Replay Test Cases with Dashcam

Retrieves test cases for a replay from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v7.0.0/testdriver/test-cases-by-replay`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Get Replay Test Cases](https://docs.testdriver.ai/v6/getting-started/ci)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `replayId` | query | `string` | no |
| `shareKey` | query | `string` | no |
