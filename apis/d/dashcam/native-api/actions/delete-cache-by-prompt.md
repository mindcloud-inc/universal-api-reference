# Delete Cache By Prompt with Dashcam

Deletes cache entries by prompt in Dashcam.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/cache/by-prompt`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Delete Cache By Prompt](https://docs.testdriver.ai)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `prompt` | query | `string` | no |
