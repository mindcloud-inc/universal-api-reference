# Get Replay with Dashcam

Retrieves a replay from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/replay`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Get Replay](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `replayId` | query | `string` | no |
| `shareKey` | query | `string` | no |
