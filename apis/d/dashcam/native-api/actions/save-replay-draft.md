# Save Replay Draft with Dashcam

Saves a replay draft in Dashcam.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/replay/draft`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Save Replay Draft](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
