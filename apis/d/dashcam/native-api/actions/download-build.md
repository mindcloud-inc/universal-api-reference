# Download Build with Dashcam

Downloads a build from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/download`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Download Build](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `build` | query | `string` | no |
| `platform` | query | `string` | no |
| `version` | query | `string` | no |
