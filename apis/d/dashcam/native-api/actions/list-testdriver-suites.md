# List Testdriver Suites with Dashcam

Retrieves TestDriver suites from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/testdriver-suites`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [List Testdriver Suites](https://docs.testdriver.ai/v6/getting-started/ci)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `repo` | query | `string` | no |
