# List Usage Records with Dashcam

Retrieves usage records from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/billing/usage-records`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [List Usage Records](https://docs.testdriver.ai/v6/account/team)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `string` | no |
| `perPage` | query | `string` | no |
