# Get Coverage Report with Dashcam

Retrieves a coverage report from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/testdriver/coverage/report`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Get Coverage Report](https://docs.testdriver.ai/v6/getting-started/ci)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `includeTransitions` | query | `string` | no |
| `regenerate` | query | `string` | no |
| `renderHeatMaps` | query | `string` | no |
| `since` | query | `string` | no |
| `team` | query | `string` | no |
