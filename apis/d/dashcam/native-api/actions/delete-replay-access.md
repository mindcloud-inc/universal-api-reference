# Delete Replay Access with Dashcam

Deletes replay access from Dashcam.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/replay/:replayId/access-delete`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Delete Replay Access](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | query | `string` | no |
| `replayId` | path | `string` | no |
