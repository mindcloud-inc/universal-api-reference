# Delete Comment with Dashcam

Deletes a comment from Dashcam.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/comment`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Delete Comment](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | no |
