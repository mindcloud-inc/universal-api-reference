# List Replays with Dashcam

Retrieves replays from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/replays`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [List Replays](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `string` | no |
| `project` | query | `string` | no |
| `status` | query | `string` | no |
