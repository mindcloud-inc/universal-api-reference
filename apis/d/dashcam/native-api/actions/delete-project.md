# Delete Project with Dashcam

Deletes a project from Dashcam.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/projects/:id`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Delete Project](https://docs.testdriver.ai/v6/account/dashboard)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
