# Get Test Case Interactions with Dashcam

Retrieves interactions for a test case from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/testdriver/interactions/testcase/:testCaseId`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Get Test Case Interactions](https://docs.testdriver.ai/v6/getting-started/ci)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `testCaseId` | path | `string` | no |
