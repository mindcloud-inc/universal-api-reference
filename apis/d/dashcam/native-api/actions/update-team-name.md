# Update Team Name with Dashcam

Updates a team name in Dashcam.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/teams/edit-name`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Update Team Name](https://docs.testdriver.ai/v6/account/team)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
