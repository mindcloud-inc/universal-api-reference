# Clone Replay with Dashcam

Clones a replay in Dashcam.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/replay/:replayId/clone`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Clone Replay](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | body | `string` | no |
| `replayId` | path | `string` | no |
