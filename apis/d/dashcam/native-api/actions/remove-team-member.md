# Remove Team Member with Dashcam

Removes a team member from Dashcam.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/teams/member-delete`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Remove Team Member](https://docs.testdriver.ai/v6/account/team)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | query | `string` | no |
