# Create Comment with Dashcam

Creates a comment in Dashcam.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/comment`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Create Comment](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `description` | body | `string` | no |
| `replayId` | body | `string` | no |
| `timestamp` | body | `string` | no |
