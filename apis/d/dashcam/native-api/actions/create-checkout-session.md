# Create Checkout Session with Dashcam

Creates a checkout session in Dashcam.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/billing/checkout`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Create Checkout Session](https://docs.testdriver.ai/v6/account/team)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `planId` | body | `string` | no |
