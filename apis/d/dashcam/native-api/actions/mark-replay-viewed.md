# Mark Replay Viewed with Dashcam

Marks a replay as viewed in Dashcam.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/replay/view-notification`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Mark Replay Viewed](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `replayId` | body | `string` | no |
