# Update Replay Access with Dashcam

Updates replay access in Dashcam.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/teams/replay-access`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Update Replay Access](https://docs.testdriver.ai/v6/account/team)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `replayAccess` | body | `string` | no |
