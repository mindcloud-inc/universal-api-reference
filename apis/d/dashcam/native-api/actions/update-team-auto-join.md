# Update Team Auto Join with Dashcam

Updates team auto-join in Dashcam.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/teams/auto-join`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Update Team Auto Join](https://docs.testdriver.ai/v6/account/team)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `autoJoin` | body | `string` | no |
