# List Cache Entries with Dashcam

Retrieves cache entries from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/cache/entries`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [List Cache Entries](https://docs.testdriver.ai)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | query | `string` | no |
| `page` | query | `string` | no |
| `type` | query | `string` | no |
