# Delete Replay with Dashcam

Deletes a replay from Dashcam.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/replay/:replayId`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Delete Replay](https://docs.testdriver.ai/v7/api/dashcam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `replayId` | path | `string` | no |
