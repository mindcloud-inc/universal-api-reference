# Remove Pending Invite with Dashcam

Removes a pending invite from Dashcam.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/teams/pending-invite-delete`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Remove Pending Invite](https://docs.testdriver.ai/v6/account/team)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | query | `string` | no |
