# Get Cache Entry Interactions with Dashcam

Retrieves interactions for a cache entry from Dashcam.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/cache/entry/interactions`
- **Base URL:** `https://api.testdriver.ai`
- **Official documentation:** [Get Cache Entry Interactions](https://docs.testdriver.ai)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | query | `string` | no |
| `selectorId` | query | `string` | no |
