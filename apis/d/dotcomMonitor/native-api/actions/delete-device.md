# Delete Device with Dotcom Monitor

Deletes an existing device from Dotcom Monitor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/device/:deviceId`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [Delete Device](https://www.dotcom-monitor.com/wiki/knowledge-base/delete-device/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `device_id` | path | `string` | yes | The unique monitoring device ID. |
