# List Monitoring Platforms with Dotcom Monitor

Retrieves monitoring platforms from Dotcom Monitor.

## Endpoint

- **Method:** `GET`
- **Path:** `/platforms`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [List Monitoring Platforms](https://www.dotcom-monitor.com/wiki/knowledge-base/platforms/)
