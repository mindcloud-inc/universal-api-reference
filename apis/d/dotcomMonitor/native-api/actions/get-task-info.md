# Get Task Info with Dotcom Monitor

Retrieves task details from Dotcom Monitor.

## Endpoint

- **Method:** `GET`
- **Path:** `/task/:taskId`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [Get Task Info](https://www.dotcom-monitor.com/wiki/knowledge-base/get-task-info/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | The unique monitoring task ID. |
