# Delete Task with Dotcom Monitor

Deletes an existing task from Dotcom Monitor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/task/:taskId`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [Delete Task](https://www.dotcom-monitor.com/wiki/knowledge-base/delete-task/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | The unique monitoring task ID. |
