# Get Device Info with Dotcom Monitor

Retrieves device details from Dotcom Monitor.

## Endpoint

- **Method:** `GET`
- **Path:** `/device/:deviceId`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [Get Device Info](https://www.dotcom-monitor.com/wiki/knowledge-base/get-device-info/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `device_id` | path | `string` | yes | The unique monitoring device ID. |
