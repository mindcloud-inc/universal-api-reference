# List Schedulers with Dotcom Monitor

Retrieves configured schedulers from Dotcom Monitor.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedulers`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [List Schedulers](https://www.dotcom-monitor.com/wiki/knowledge-base/get-list-of-schedulers/)
