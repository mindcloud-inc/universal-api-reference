# List Notification Groups with Dotcom Monitor

Retrieves notification groups from Dotcom Monitor.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [List Notification Groups](https://www.dotcom-monitor.com/wiki/knowledge-base/get-list-of-notification-groups/)
