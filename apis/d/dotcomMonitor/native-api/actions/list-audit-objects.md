# List Audit Objects with Dotcom Monitor

Retrieves audit objects from Dotcom Monitor.

## Endpoint

- **Method:** `GET`
- **Path:** `/audit/list`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [List Audit Objects](https://www.dotcom-monitor.com/wiki/knowledge-base/get-list-of-audit-objects/)
