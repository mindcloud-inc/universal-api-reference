# List Alert Templates with Dotcom Monitor

Retrieves alert templates from Dotcom Monitor.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [List Alert Templates](https://www.dotcom-monitor.com/wiki/knowledge-base/get-list-of-notification-templates/)
