# Get Filter Info with Dotcom Monitor

Retrieves filter details from Dotcom Monitor.

## Endpoint

- **Method:** `GET`
- **Path:** `/filter/:filter_id`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [Get Filter Info](https://www.dotcom-monitor.com/wiki/knowledge-base/get-specific-filter-info/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filter_id` | path | `string` | yes | Unique filter id from Get Filter List. |
