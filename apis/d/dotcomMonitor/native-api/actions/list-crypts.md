# List Crypts with Dotcom Monitor

Retrieves secure vault crypts from Dotcom Monitor.

## Endpoint

- **Method:** `GET`
- **Path:** `/securevaults`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [List Crypts](https://www.dotcom-monitor.com/wiki/knowledge-base/api-get-list-of-crypts/)
