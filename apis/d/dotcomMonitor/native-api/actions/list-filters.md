# List Filters with Dotcom Monitor

Retrieves saved filters from Dotcom Monitor.

## Endpoint

- **Method:** `GET`
- **Path:** `/filters`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [List Filters](https://www.dotcom-monitor.com/wiki/knowledge-base/get-list-of-filters/)
