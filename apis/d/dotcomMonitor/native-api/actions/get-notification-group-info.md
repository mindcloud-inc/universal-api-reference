# Get Notification Group Info with Dotcom Monitor

Retrieves notification group details from Dotcom Monitor.

## Endpoint

- **Method:** `GET`
- **Path:** `/group/:group_id`
- **Base URL:** `https://api.dotcom-monitor.com/config_api_v1`
- **Official documentation:** [Get Notification Group Info](https://www.dotcom-monitor.com/wiki/knowledge-base/get-notification-group-info/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | yes | Unique notification group id from Get Notification Group List. |
