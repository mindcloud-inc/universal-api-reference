# Delete Transport Order with Dachser

Deletes an existing transport order from Dachser.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rest/v2/transportorders/{id}`
- **Base URL:** `https://api-gateway.dachser.com/`
- **Official documentation:** [Delete Transport Order](https://api-portal.dachser.com/bi.b2b.portal/api/library/transportorder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | DACHSER transport order ID. |
