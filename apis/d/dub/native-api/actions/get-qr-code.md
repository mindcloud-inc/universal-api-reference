# Get QR Code with Dub

Retrieves a QR code for a Dub link.

## Endpoint

- **Method:** `GET`
- **Path:** `/qr`
- **Base URL:** `https://api.dub.co`
- **Official documentation:** [Get QR Code](https://dub.co/docs/api-reference/endpoint/retrieve-a-qr-code)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The URL to generate a QR code for. |
