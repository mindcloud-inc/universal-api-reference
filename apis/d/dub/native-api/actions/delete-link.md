# Delete Link with Dub

Deletes a link from Dub.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/links/:linkId`
- **Base URL:** `https://api.dub.co`
- **Official documentation:** [Delete Link](https://dub.co/docs/api-reference/links/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkId` | path | `string` | yes | Dub link ID to delete. |
