# Retrieve Link with Dub

Retrieves a link from Dub.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/info`
- **Base URL:** `https://api.dub.co`
- **Official documentation:** [Retrieve Link](https://dub.co/docs/api-reference/links/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkId` | query | `string` | yes | Dub link ID to retrieve. |
