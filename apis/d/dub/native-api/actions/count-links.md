# Count Links with Dub

Retrieves the number of links in Dub.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/count`
- **Base URL:** `https://api.dub.co`
- **Official documentation:** [Count Links](https://dub.co/docs/api-reference/links/count)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | no | Count links for a specific domain. |
