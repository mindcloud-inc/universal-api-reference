# Delete Tag with Dub

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:id`
- **Base URL:** `https://api.dub.co`
- **Official documentation:** [Delete Tag](https://dub.co/docs/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Dub tag ID to delete. |
