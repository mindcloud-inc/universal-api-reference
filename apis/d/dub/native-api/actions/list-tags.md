# List Tags with Dub

Retrieves tags from Dub.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://api.dub.co`
- **Official documentation:** [List Tags](https://dub.co/docs/api-reference/tags/list)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search tags by text. |
