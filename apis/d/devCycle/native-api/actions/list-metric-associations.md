# List Metric Associations with DevCycle

Retrieves metric associations from DevCycle.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:project/metric-associations`
- **Base URL:** `https://api.devcycle.com`
- **Official documentation:** [List Metric Associations](https://docs.devcycle.com/management-api/#tag/Metric-Associations/operation/MetricAssociationsController_findAll)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | path | `string` | no | Project key. |
