# Get Project with DevCycle

Retrieves a project from DevCycle.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:key`
- **Base URL:** `https://api.devcycle.com`
- **Official documentation:** [Get Project](https://docs.devcycle.com/management-api/#tag/Projects/operation/ProjectsController_findOne)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | no | Project key. |
