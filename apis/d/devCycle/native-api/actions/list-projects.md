# List Projects with DevCycle

Retrieves projects from DevCycle.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects`
- **Base URL:** `https://api.devcycle.com`
- **Official documentation:** [List Projects](https://docs.devcycle.com/management-api/#tag/Projects/operation/ProjectsController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
