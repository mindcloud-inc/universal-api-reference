# Get Dynatrace Integration with DevCycle

Retrieves Dynatrace integrations from DevCycle.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/integrations/dynatrace`
- **Base URL:** `https://api.devcycle.com`
- **Official documentation:** [Get Dynatrace Integration](https://docs.devcycle.com/management-api/#tag/Integrations:-Dynatrace/operation/DynatraceIntegrationController_getIntegrations)
