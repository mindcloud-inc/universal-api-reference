# Get Job with Dribbble

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:id`
- **Base URL:** `https://api.dribbble.com/v2`
- **Official documentation:** [Get Job](https://developer.dribbble.com/v2/jobs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Dribbble job ID. |
