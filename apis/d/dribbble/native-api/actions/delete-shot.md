# Delete Shot with Dribbble

## Endpoint

- **Method:** `DELETE`
- **Path:** `/shots/:id`
- **Base URL:** `https://api.dribbble.com/v2`
- **Official documentation:** [Delete Shot](https://developer.dribbble.com/v2/shots/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Dribbble shot ID. |
