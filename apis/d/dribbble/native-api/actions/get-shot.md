# Get Shot with Dribbble

## Endpoint

- **Method:** `GET`
- **Path:** `/shots/:id`
- **Base URL:** `https://api.dribbble.com/v2`
- **Official documentation:** [Get Shot](https://developer.dribbble.com/v2/shots/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Dribbble shot ID. |
