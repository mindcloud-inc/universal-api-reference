# Create Project with Dribbble

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://api.dribbble.com/v2`
- **Official documentation:** [Create Project](https://developer.dribbble.com/v2/projects/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `description` | body | `string` | no |
