# Get Content Type Base Types with DotCMS

Retrieves base content type definitions from DotCMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contenttype/basetypes`
- **Base URL:** `https://demo.dotcms.com/`
- **Official documentation:** [Get Content Type Base Types](https://dev.dotcms.com/docs/api-playground)
