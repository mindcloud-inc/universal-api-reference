# List Relationship Cardinalities with DotCMS

Retrieves relationship cardinality options from DotCMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/relationships/cardinalities`
- **Base URL:** `https://demo.dotcms.com/`
- **Official documentation:** [List Relationship Cardinalities](https://dev.dotcms.com/docs/api-playground)
