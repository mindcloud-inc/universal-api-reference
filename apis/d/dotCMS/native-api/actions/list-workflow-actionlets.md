# List Workflow Actionlets with DotCMS

Retrieves available workflow actionlets from DotCMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/workflow/actionlets`
- **Base URL:** `https://demo.dotcms.com/`
- **Official documentation:** [List Workflow Actionlets](https://dev.dotcms.com/docs/api-playground)
