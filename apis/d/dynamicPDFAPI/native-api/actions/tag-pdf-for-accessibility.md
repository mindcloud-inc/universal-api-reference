# Tag PDF For Accessibility with DynamicPDF

Tags a PDF for accessibility in DynamicPDF API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1.0/pdf`
- **Base URL:** `https://api.dpdf.io`
- **Official documentation:** [Tag PDF For Accessibility](https://dpdf.io/docs/usersguide/cloud-api/schemas/cloud-api-schema-pdf)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `Instructions` | body | `object` | yes |
