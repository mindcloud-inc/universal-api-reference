# Retain Signature Fields During Processing with DynamicPDF

Retains signature fields while processing a PDF in DynamicPDF API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1.0/pdf`
- **Base URL:** `https://api.dpdf.io`
- **Official documentation:** [Retain Signature Fields During Processing](https://dpdf.io/docs/usersguide/cloud-api/schemas/cloud-api-schema-pdf)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `Instructions` | body | `object` | yes |
