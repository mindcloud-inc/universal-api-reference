# Split PDF Into Multiple PDFs with DynamicPDF

Splits a PDF into multiple PDFs in DynamicPDF API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1.0/pdf`
- **Base URL:** `https://api.dpdf.io`
- **Official documentation:** [Split PDF Into Multiple PDFs](https://dpdf.io/docs/split-pdf-into-multiple-files)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `Instructions` | body | `object` | yes |
