# Remove PDF Form Fields with DynamicPDF

Removes PDF form fields in DynamicPDF API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1.0/pdf`
- **Base URL:** `https://api.dpdf.io`
- **Official documentation:** [Remove PDF Form Fields](https://dpdf.io/docs/flatten-or-delete-pdf-form-fields)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `Instructions` | body | `object` | yes |
