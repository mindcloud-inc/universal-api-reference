# Delete Pages From PDF with DynamicPDF

Deletes pages from a PDF in DynamicPDF API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1.0/pdf`
- **Base URL:** `https://api.dpdf.io`
- **Official documentation:** [Delete Pages From PDF](https://dpdf.io/docs/delete-pages-from-pdf)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `Instructions` | body | `object` | yes |
