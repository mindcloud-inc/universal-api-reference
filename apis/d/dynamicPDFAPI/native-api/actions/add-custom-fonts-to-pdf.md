# Add Custom Fonts To PDF with DynamicPDF

Adds custom fonts to a PDF in DynamicPDF API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1.0/pdf`
- **Base URL:** `https://api.dpdf.io`
- **Official documentation:** [Add Custom Fonts To PDF](https://dpdf.io/docs/usersguide/cloud-api/cloud-api-pdf-instructions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Instructions` | body | `object` | yes | DynamicPDF instructions document sent as raw JSON. |
