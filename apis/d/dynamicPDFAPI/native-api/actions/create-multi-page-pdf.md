# Create Multi-Page PDF with DynamicPDF

Creates a multi-page PDF in DynamicPDF API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1.0/pdf`
- **Base URL:** `https://api.dpdf.io`
- **Official documentation:** [Create Multi-Page PDF](https://dpdf.io/docs/usersguide/cloud-api/cloud-api-pdf-instructions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Instructions` | body | `object` | yes | DynamicPDF pdf endpoint instructions JSON for a multi-page PDF. |
