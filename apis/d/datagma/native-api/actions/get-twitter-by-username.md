# Get Twitter By Username with Datagma

Retrieves Twitter profile data from Datagma by username.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/twitter/by_username`
- **Base URL:** `https://gateway.datagma.net/api/ingress`
- **Official documentation:** [Get Twitter By Username](https://datagmaapi.readme.io/reference/ingressservice_gettwitterbyusername)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | query | `string` | no | Twitter username used to look up a Twitter profile. |
