# Get Twitter By Email with Datagma

Retrieves Twitter profile data from Datagma by email.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/twitter/by_email`
- **Base URL:** `https://gateway.datagma.net/api/ingress`
- **Official documentation:** [Get Twitter By Email](https://datagmaapi.readme.io/reference/ingressservice_gettwitterbyemail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | Email address used to look up a Twitter profile. |
