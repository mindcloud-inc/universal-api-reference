# Get Cat Care Recommendations with Dappier

Retrieves cat care article recommendations from Dappier.

## Endpoint

- **Method:** `POST`
- **Path:** `/app/v2/search`
- **Base URL:** `https://api.dappier.com`
- **Official documentation:** [Get Cat Care Recommendations](https://docs.dappier.com/api-reference/endpoint/ai-recommendations)
