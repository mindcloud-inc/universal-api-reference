# Generate Initials Avatar with DiceBear

## Endpoint

- **Method:** `GET`
- **Path:** `/initials/svg`
- **Base URL:** `https://api.dicebear.com/10.x`
- **Official documentation:** [Generate Initials Avatar](https://www.dicebear.com/styles/initials/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `seed` | query | `string` | no | Seed used to generate a deterministic avatar. |
