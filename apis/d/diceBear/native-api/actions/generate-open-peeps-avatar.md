# Generate Open Peeps Avatar with DiceBear

## Endpoint

- **Method:** `GET`
- **Path:** `/open-peeps/svg`
- **Base URL:** `https://api.dicebear.com/10.x`
- **Official documentation:** [Generate Open Peeps Avatar](https://www.dicebear.com/styles/open-peeps/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `seed` | query | `string` | no | Seed value used to generate a deterministic avatar. |
