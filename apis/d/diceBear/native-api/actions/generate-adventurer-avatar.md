# Generate Adventurer Avatar with DiceBear

## Endpoint

- **Method:** `GET`
- **Path:** `/adventurer/svg`
- **Base URL:** `https://api.dicebear.com/10.x`
- **Official documentation:** [Generate Adventurer Avatar](https://www.dicebear.com/styles/adventurer/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `seed` | query | `string` | no | Seed value used to generate a deterministic avatar. |
