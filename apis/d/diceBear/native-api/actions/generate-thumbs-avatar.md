# Generate Thumbs Avatar with DiceBear

## Endpoint

- **Method:** `GET`
- **Path:** `/thumbs/svg`
- **Base URL:** `https://api.dicebear.com/10.x`
- **Official documentation:** [Generate Thumbs Avatar](https://www.dicebear.com/styles/thumbs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `seed` | query | `string` | no | Seed value used to generate a deterministic avatar. |
