# Generate Pixel Art Avatar with DiceBear

## Endpoint

- **Method:** `GET`
- **Path:** `/pixel-art/svg`
- **Base URL:** `https://api.dicebear.com/10.x`
- **Official documentation:** [Generate Pixel Art Avatar](https://www.dicebear.com/styles/pixel-art/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `seed` | query | `string` | no | Seed value used to generate a deterministic avatar. |
