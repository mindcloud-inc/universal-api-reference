# Get Model Family with Deep Infra

## Endpoint

- **Method:** `GET`
- **Path:** `/model-families/:family_name`
- **Base URL:** `https://api.deepinfra.com`
- **Official documentation:** [Get Model Family](https://docs.deepinfra.com/api-reference/models/model-family)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `family_name` | path | `string` | yes | Model family name from the model family URL path. |
