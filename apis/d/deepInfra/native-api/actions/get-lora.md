# Get LoRA with Deep Infra

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/lora/:lora_name`
- **Base URL:** `https://api.deepinfra.com`
- **Official documentation:** [Get LoRA](https://docs.deepinfra.com/api-reference/lora-adapters/get-lora)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lora_name` | path | `string` | yes | LoRA adapter name from the LoRA URL path. |
