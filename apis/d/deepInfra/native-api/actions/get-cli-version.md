# Get CLI Version with Deep Infra

## Endpoint

- **Method:** `GET`
- **Path:** `/cli/version`
- **Base URL:** `https://api.deepinfra.com`
- **Official documentation:** [Get CLI Version](https://docs.deepinfra.com/api-reference/utilities/cli-version)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `version` | query | `string` | yes | Installed DeepInfra CLI version to check against the latest available version. |
