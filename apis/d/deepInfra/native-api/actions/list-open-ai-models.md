# List OpenAI Models with Deep Infra

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/models`
- **Base URL:** `https://api.deepinfra.com`
- **Official documentation:** [List OpenAI Models](https://docs.deepinfra.com/api-reference/models/openai-models.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sort_by` | query | `string` | no | Optional model sorting key documented by DeepInfra. |
