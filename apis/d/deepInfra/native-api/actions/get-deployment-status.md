# Get Deployment Status with Deep Infra

## Endpoint

- **Method:** `GET`
- **Path:** `/deploy/:deploy_id`
- **Base URL:** `https://api.deepinfra.com`
- **Official documentation:** [Get Deployment Status](https://docs.deepinfra.com/api-reference/dedicated-models/deploy-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deploy_id` | path | `string` | yes | Dedicated deployment identifier from the deployment URL path. |
