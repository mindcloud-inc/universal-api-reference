# Get Model Versions with Deep Infra

## Endpoint

- **Method:** `GET`
- **Path:** `/models/:model_name/versions`
- **Base URL:** `https://api.deepinfra.com`
- **Official documentation:** [Get Model Versions](https://docs.deepinfra.com/api-reference/models/model-versions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_name` | path | `string` | yes | DeepInfra model identifier from the model URL path. |
