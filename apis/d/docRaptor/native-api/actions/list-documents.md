# List Documents with DocRaptor

Retrieves paginated document records from DocRaptor.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs.json`
- **Base URL:** `https://api.docraptor.com`
- **Official documentation:** [List Documents](https://docraptor.com/documentation/api/document_listing)

## Capabilities

This operation supports [pagination](../README.md#pagination).
