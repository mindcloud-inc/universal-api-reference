# List DocRaptor IP Addresses with DocRaptor

Retrieves the current DocRaptor IP addresses.

## Endpoint

- **Method:** `GET`
- **Path:** `https://docraptor.com/ips.json`
- **Base URL:** `https://api.docraptor.com`
- **Official documentation:** [List DocRaptor IP Addresses](https://docraptor.com/documentation/api/ip_listing)
