# List All Available Models with Deepgram

Retrieves available models from Deepgram.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/models`
- **Base URL:** `https://api.deepgram.com`
- **Official documentation:** [List All Available Models](https://developers.deepgram.com/reference/manage/models/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include_outdated` | query | `boolean` | no | Return non-latest versions of models. |
