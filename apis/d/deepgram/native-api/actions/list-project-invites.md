# List Project Invites with Deepgram

Retrieves project invites from Deepgram.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:project_id/invites`
- **Base URL:** `https://api.deepgram.com`
- **Official documentation:** [List Project Invites](https://developers.deepgram.com/reference/manage/invites/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The Deepgram project identifier to inspect. |
