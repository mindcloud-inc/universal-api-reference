# Get Available Model with Deepgram

Retrieves an available model from Deepgram.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/models/:model_id`
- **Base URL:** `https://api.deepgram.com`
- **Official documentation:** [Get Available Model](https://developers.deepgram.com/reference/manage/models/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | yes | The model UUID or identifier. |
