# List Project Members with Deepgram

Retrieves project members from Deepgram.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:project_id/members`
- **Base URL:** `https://api.deepgram.com`
- **Official documentation:** [List Project Members](https://developers.deepgram.com/reference/manage/members/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The Deepgram project identifier to inspect. |
