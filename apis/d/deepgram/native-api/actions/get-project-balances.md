# Get Project Balances with Deepgram

Retrieves project balances from Deepgram.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:project_id/balances`
- **Base URL:** `https://api.deepgram.com`
- **Official documentation:** [Get Project Balances](https://developers.deepgram.com/reference/manage/billing/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Deepgram project identifier. |
