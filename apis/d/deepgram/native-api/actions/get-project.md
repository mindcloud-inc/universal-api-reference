# Get Project with Deepgram

Retrieves a project from Deepgram.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:project_id`
- **Base URL:** `https://api.deepgram.com`
- **Official documentation:** [Get Project](https://developers.deepgram.com/reference/manage/projects/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The unique identifier of the project. |
