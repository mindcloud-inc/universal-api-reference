# Get Lead with DealMachine

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/leads/:lead_id`
- **Base URL:** `https://api.dealmachine.com`
- **Official documentation:** [Get Lead](https://docs.dealmachine.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lead_id` | path | `number` | yes | The DealMachine lead ID. |
