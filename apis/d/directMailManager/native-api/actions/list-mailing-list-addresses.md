# List Mailing List Addresses with Direct Mail Manager

## Endpoint

- **Method:** `GET`
- **Path:** `/mailing-lists/:mlg_lst_id/addresses`
- **Base URL:** `https://api.directmailmanager.com/api`
- **Official documentation:** [List Mailing List Addresses](https://apidocs.directmailmanager.com/#tag/Mailing-Lists/operation/list_mailing_list_addresses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mlg_lst_id` | path | `string` | yes | The unique ID of the mailing list. |
