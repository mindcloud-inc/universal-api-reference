# List Postcards with Direct Mail Manager

## Endpoint

- **Method:** `GET`
- **Path:** `/postcards`
- **Base URL:** `https://api.directmailmanager.com/api`
- **Official documentation:** [List Postcards](https://apidocs.directmailmanager.com/#tag/Postcards/operation/list_postcards)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
