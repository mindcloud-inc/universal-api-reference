# Attach Address To Mailing List with Direct Mail Manager

## Endpoint

- **Method:** `POST`
- **Path:** `/addresses/:adr_id/attach`
- **Base URL:** `https://api.directmailmanager.com/api`
- **Official documentation:** [Attach Address To Mailing List](https://apidocs.directmailmanager.com/#tag/Addresses/operation/attach-an-address)
