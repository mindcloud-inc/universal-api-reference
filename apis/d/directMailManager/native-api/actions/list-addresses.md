# List Addresses with Direct Mail Manager

## Endpoint

- **Method:** `GET`
- **Path:** `/addresses`
- **Base URL:** `https://api.directmailmanager.com/api`
- **Official documentation:** [List Addresses](https://apidocs.directmailmanager.com/#tag/Addresses/operation/list_addresses)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
