# List Custom Fields with Direct Mail Manager

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-fields`
- **Base URL:** `https://api.directmailmanager.com/api`
- **Official documentation:** [List Custom Fields](https://apidocs.directmailmanager.com/#tag/Custom-Fields/operation/list_custom_fields)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
