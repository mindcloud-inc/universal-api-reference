# List Segments with Direct Mail Manager

## Endpoint

- **Method:** `GET`
- **Path:** `/segments`
- **Base URL:** `https://api.directmailmanager.com/api`
- **Official documentation:** [List Segments](https://apidocs.directmailmanager.com/#tag/Segments/operation/list_segments)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
