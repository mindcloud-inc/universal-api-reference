# Detach Address From Mailing List with Direct Mail Manager

## Endpoint

- **Method:** `POST`
- **Path:** `/addresses/:adr_id/detach`
- **Base URL:** `https://api.directmailmanager.com/api`
- **Official documentation:** [Detach Address From Mailing List](https://apidocs.directmailmanager.com/#tag/Addresses/operation/detach-an-address)
