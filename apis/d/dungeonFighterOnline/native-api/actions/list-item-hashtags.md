# List Item Hashtags with Dungeon Fighter Online

Retrieves item hashtags from Dungeon Fighter Online.

## Endpoint

- **Method:** `GET`
- **Path:** `/df/item-hashtag`
- **Base URL:** `https://api.neople.co.kr`
- **Official documentation:** [List Item Hashtags](https://developers.neople.co.kr/contents/apiDocs/df)
