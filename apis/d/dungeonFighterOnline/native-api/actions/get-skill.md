# Get Skill with Dungeon Fighter Online

Retrieves skill details from Dungeon Fighter Online.

## Endpoint

- **Method:** `GET`
- **Path:** `/df/skills/:jobId/:skillId`
- **Base URL:** `https://api.neople.co.kr`
- **Official documentation:** [Get Skill](https://developers.neople.co.kr/contents/apiDocs/df)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | Dungeon Fighter job ID. |
| `skillId` | path | `string` | yes | Dungeon Fighter skill ID. |
