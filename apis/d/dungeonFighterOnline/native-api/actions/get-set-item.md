# Get Set Item with Dungeon Fighter Online

Retrieves set item details from Dungeon Fighter Online.

## Endpoint

- **Method:** `GET`
- **Path:** `/df/setitems/:setItemId`
- **Base URL:** `https://api.neople.co.kr`
- **Official documentation:** [Get Set Item](https://developers.neople.co.kr/contents/apiDocs/df)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `setItemId` | path | `string` | yes | Dungeon Fighter set item ID. |
