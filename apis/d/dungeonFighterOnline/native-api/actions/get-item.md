# Get Item with Dungeon Fighter Online

Retrieves item details from Dungeon Fighter Online.

## Endpoint

- **Method:** `GET`
- **Path:** `/df/items/:itemId`
- **Base URL:** `https://api.neople.co.kr`
- **Official documentation:** [Get Item](https://developers.neople.co.kr/contents/apiDocs/df)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | yes | Dungeon Fighter item ID. |
