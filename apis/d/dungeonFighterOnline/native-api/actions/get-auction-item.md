# Get Auction Item with Dungeon Fighter Online

Retrieves an auction listing from Dungeon Fighter Online.

## Endpoint

- **Method:** `GET`
- **Path:** `/df/auction/:auctionNo`
- **Base URL:** `https://api.neople.co.kr`
- **Official documentation:** [Get Auction Item](https://developers.neople.co.kr/contents/apiDocs/df)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `auctionNo` | path | `number` | yes | Auction listing number. |
