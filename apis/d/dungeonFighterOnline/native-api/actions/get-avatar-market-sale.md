# Get Avatar Market Sale with Dungeon Fighter Online

Retrieves an avatar market listing from Dungeon Fighter Online.

## Endpoint

- **Method:** `GET`
- **Path:** `/df/avatar-market/sale/:goodsNo`
- **Base URL:** `https://api.neople.co.kr`
- **Official documentation:** [Get Avatar Market Sale](https://developers.neople.co.kr/contents/apiDocs/df)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `goodsNo` | path | `number` | yes | Avatar market goods number. |
