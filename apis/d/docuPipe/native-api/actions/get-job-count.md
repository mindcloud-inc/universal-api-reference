# Get Job Count with DocuPipe

Retrieves the job count from DocuPipe.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/summary`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Get Job Count](https://docs.docupipe.ai/reference/get_job_summary)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `include_daily_usage` | query | `boolean` | no |
