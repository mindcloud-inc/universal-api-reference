# Get Webhook Portal URL with DocuPipe

Retrieves the webhook portal URL from DocuPipe.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook/get-portal-link`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Get Webhook Portal URL](https://docs.docupipe.ai/reference/get_portal_link)
