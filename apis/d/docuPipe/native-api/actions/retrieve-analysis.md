# Retrieve Analysis with DocuPipe

Retrieves an analysis from DocuPipe.

## Endpoint

- **Method:** `GET`
- **Path:** `/analysis/:analysisId`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve Analysis](https://docs.docupipe.ai/reference/get_analysis)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `analysis_id` | path | `string` | yes |
