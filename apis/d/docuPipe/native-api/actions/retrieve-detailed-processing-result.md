# Retrieve Detailed Processing Result with DocuPipe

Retrieves detailed processing results from DocuPipe.

## Endpoint

- **Method:** `GET`
- **Path:** `/document/:documentId/detailed`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve Detailed Processing Result](https://docs.docupipe.ai/reference/get_document_detailed)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
