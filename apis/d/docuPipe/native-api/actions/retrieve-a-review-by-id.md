# Retrieve a Review by ID with DocuPipe

Retrieves a review from DocuPipe by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/review/:reviewId`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve a Review by ID](https://docs.docupipe.ai/reference/get_review_by_id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `review_id` | path | `string` | yes |
