# Retrieve a Standardization JSON with DocuPipe

Retrieves standardization JSON from DocuPipe.

## Endpoint

- **Method:** `GET`
- **Path:** `/standardization/:standardizationId`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve a Standardization JSON](https://docs.docupipe.ai/reference/get_standardization)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `standardization_id` | path | `string` | yes |
