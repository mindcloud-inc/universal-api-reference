# Retrieve a Standardization XML with DocuPipe

Retrieves standardization XML from DocuPipe.

## Endpoint

- **Method:** `GET`
- **Path:** `/standardization/:standardizationId/xml`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve a Standardization XML](https://docs.docupipe.ai/reference/get_standardization_xml)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `standardization_id` | path | `string` | yes |
