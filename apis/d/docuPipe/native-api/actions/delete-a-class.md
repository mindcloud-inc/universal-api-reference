# Delete a Class with DocuPipe

Deletes a class from DocuPipe.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/class/:classId`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Delete a Class](https://docs.docupipe.ai/reference/delete_class)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `class_id` | path | `string` | yes |
