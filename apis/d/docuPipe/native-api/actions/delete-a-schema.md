# Delete a Schema with DocuPipe

Deletes a schema from DocuPipe.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/schema/:schemaId`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Delete a Schema](https://docs.docupipe.ai/reference/delete_schema)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `schema_id` | path | `string` | yes |
