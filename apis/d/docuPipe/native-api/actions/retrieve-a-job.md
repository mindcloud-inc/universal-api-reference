# Retrieve a Job with DocuPipe

Retrieves a job from DocuPipe.

## Endpoint

- **Method:** `GET`
- **Path:** `/job/:jobId`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve a Job](https://docs.docupipe.ai/reference/get_job)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `job_id` | path | `string` | yes |
