# Get Schema Proposals with DocuPipe

Retrieves schema proposals for a DocuPipe document.

## Endpoint

- **Method:** `GET`
- **Path:** `/document/:documentId/proposed-schemas`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Get Schema Proposals](https://docs.docupipe.ai/reference/get_proposed_schemas)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
