# List Classes with DocuPipe

Retrieves classes from DocuPipe.

## Endpoint

- **Method:** `GET`
- **Path:** `/classes`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [List Classes](https://docs.docupipe.ai/reference/list_classes)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `include_unknown` | query | `boolean` | no |
