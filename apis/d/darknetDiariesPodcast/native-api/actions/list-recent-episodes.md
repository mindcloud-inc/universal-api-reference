# List Recent Episodes with Darknet Diaries Podcast

Retrieves recent podcast episodes from Darknet Diaries Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://podcast.darknetdiaries.com`
- **Official documentation:** [List Recent Episodes](https://podcast.darknetdiaries.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of recent episodes to return. |
