# Search Episodes By Title with Darknet Diaries Podcast

Finds podcast episodes in Darknet Diaries Podcast by title.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://podcast.darknetdiaries.com`
- **Official documentation:** [Search Episodes By Title](https://podcast.darknetdiaries.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Title search term. |
