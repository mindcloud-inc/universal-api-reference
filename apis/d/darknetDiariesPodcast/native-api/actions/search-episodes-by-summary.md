# Search Episodes By Summary with Darknet Diaries Podcast

Finds podcast episodes in Darknet Diaries Podcast by summary text.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://podcast.darknetdiaries.com`
- **Official documentation:** [Search Episodes By Summary](https://podcast.darknetdiaries.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Summary search term. |
