# Get Episode By Number with Darknet Diaries Podcast

Retrieves a podcast episode by episode number from Darknet Diaries Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://podcast.darknetdiaries.com`
- **Official documentation:** [Get Episode By Number](https://podcast.darknetdiaries.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `episodeNumber` | query | `number` | yes | Episode number from the podcast feed. |
