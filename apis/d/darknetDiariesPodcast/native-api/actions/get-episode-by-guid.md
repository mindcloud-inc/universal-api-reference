# Get Episode By GUID with Darknet Diaries Podcast

Retrieves a podcast episode by GUID from Darknet Diaries Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://podcast.darknetdiaries.com`
- **Official documentation:** [Get Episode By GUID](https://podcast.darknetdiaries.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | query | `string` | yes | Episode GUID from the podcast feed. |
