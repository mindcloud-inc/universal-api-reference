# Get Space Usage with Dropbox

Retrieves account space usage from Dropbox.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/get_space_usage`
- **Base URL:** `https://api.dropboxapi.com/2`
- **Official documentation:** [Get Space Usage](https://www.dropbox.com/developers/documentation/http/documentation#users-get_space_usage)
