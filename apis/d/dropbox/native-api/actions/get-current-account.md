# Get Current Account with Dropbox

Retrieves the current account details from Dropbox.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/get_current_account`
- **Base URL:** `https://api.dropboxapi.com/2`
- **Official documentation:** [Get Current Account](https://www.dropbox.com/developers/documentation/http/documentation#users-get_current_account)
