# Send WhatsApp Generic Attachment Message with D7 Messaging

Sends a WhatsApp attachment message through D7 Messaging.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp/v2/send`
- **Base URL:** `https://api.d7networks.com`
- **Official documentation:** [Send WhatsApp Generic Attachment Message](https://d7networks.com/docs/whatsapp/send-message/media-message/)
