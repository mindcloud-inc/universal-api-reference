# Send WhatsApp Location Message with D7 Messaging

Sends a WhatsApp location message through D7 Messaging.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp/v2/send`
- **Base URL:** `https://api.d7networks.com`
- **Official documentation:** [Send WhatsApp Location Message](https://d7networks.com/docs/whatsapp/send-message/location-message/)
