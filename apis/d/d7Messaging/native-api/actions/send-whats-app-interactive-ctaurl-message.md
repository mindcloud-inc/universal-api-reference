# Send WhatsApp Interactive CTA URL Message with D7 Messaging

Sends a WhatsApp interactive CTA URL message through D7 Messaging.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp/v2/send`
- **Base URL:** `https://api.d7networks.com`
- **Official documentation:** [Send WhatsApp Interactive CTA URL Message](https://d7networks.com/docs/whatsapp/send-message/interactive-message/)
