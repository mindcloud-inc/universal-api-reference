# Download WhatsApp Media with D7 Messaging

Downloads WhatsApp media from D7 Messaging.

## Endpoint

- **Method:** `GET`
- **Path:** `/whatsapp/v2/download/:media_id`
- **Base URL:** `https://api.d7networks.com`
- **Official documentation:** [Download WhatsApp Media](https://d7networks.com/docs/whatsapp/download-media/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `media_id` | path | `string` | yes | Media ID returned by a WhatsApp media message. |
