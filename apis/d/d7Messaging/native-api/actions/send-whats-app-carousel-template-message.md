# Send WhatsApp Carousel Template Message with D7 Messaging

Sends a WhatsApp carousel template message through D7 Messaging.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp/v2/send`
- **Base URL:** `https://api.d7networks.com`
- **Official documentation:** [Send WhatsApp Carousel Template Message](https://d7networks.com/docs/whatsapp/send-templated-message/carousel-template-message/)
