# Send WhatsApp Flows Template Message with D7 Messaging

Sends a WhatsApp flows template message through D7 Messaging.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp/v2/send`
- **Base URL:** `https://api.d7networks.com`
- **Official documentation:** [Send WhatsApp Flows Template Message](https://d7networks.com/docs/whatsapp/send-templated-message/flows-template-message/)
