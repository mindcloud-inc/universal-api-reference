# List Webhook Events with DataForB2B

Retrieves webhook events from DataForB2B.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/events`
- **Base URL:** `https://api.dataforb2b.ai`
- **Official documentation:** [List Webhook Events](https://docs.dataforb2b.ai/api-reference/webhooks-events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of events to return. |
| `offset` | query | `number` | no | Result offset for pagination. |
