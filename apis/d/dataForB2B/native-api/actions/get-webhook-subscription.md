# Get Webhook Subscription with DataForB2B

Retrieves a webhook subscription from DataForB2B.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.dataforb2b.ai`
- **Official documentation:** [Get Webhook Subscription](https://docs.dataforb2b.ai/api-reference/webhooks-get)
