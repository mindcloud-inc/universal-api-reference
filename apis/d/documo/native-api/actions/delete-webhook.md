# Delete Webhook with Documo

Deletes an existing webhook from Documo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://api.documo.com`
- **Official documentation:** [Delete Webhook](https://docs.documo.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Webhook UUID. |
