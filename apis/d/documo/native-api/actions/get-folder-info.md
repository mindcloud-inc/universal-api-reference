# Get Folder Info with Documo

Retrieves folder details and counts from Documo.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders/:folderId/info`
- **Base URL:** `https://api.documo.com`
- **Official documentation:** [Get Folder Info](https://docs.documo.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `string` | yes | String \| Required \| Folder UUID |
