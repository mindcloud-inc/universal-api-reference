# Delete Custom Field with Documo

Deletes an existing custom field from Documo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/custom-fields/:customFieldId`
- **Base URL:** `https://api.documo.com`
- **Official documentation:** [Delete Custom Field](https://docs.documo.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customFieldId` | path | `string` | yes | String \| Required \| Custom Field UUID |
