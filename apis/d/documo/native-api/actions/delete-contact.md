# Delete Contact with Documo

Deletes an existing contact from Documo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contacts/:contactId`
- **Base URL:** `https://api.documo.com`
- **Official documentation:** [Delete Contact](https://docs.documo.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | String \| Required \| Contact UUID |
