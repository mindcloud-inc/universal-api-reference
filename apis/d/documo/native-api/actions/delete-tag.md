# Delete Tag with Documo

Deletes an existing tag from Documo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/tag/:tagId`
- **Base URL:** `https://api.documo.com`
- **Official documentation:** [Delete Tag](https://docs.documo.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `string` | yes | Tag UUID. |
