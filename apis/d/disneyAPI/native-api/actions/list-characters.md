# List Characters with Disney API

## Endpoint

- **Method:** `GET`
- **Path:** `/character`
- **Base URL:** `https://api.disneyapi.dev`
- **Official documentation:** [List Characters](https://disneyapi.dev/docs/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | Character name filter documented by Disney API. |
