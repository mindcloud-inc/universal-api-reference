# Get Character with Disney API

## Endpoint

- **Method:** `GET`
- **Path:** `/character/:id`
- **Base URL:** `https://api.disneyapi.dev`
- **Official documentation:** [Get Character](https://disneyapi.dev/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Disney character ID. |
