# Get Job Result File Details with DocMaker

Retrieves result file details from a DocMaker job.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:jobId`
- **Base URL:** `https://api.v2.docmaker.co`
- **Official documentation:** [Get Job Result File Details](https://docmaker.co/docMaker-swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The unique identifier of the DocMaker job. |
