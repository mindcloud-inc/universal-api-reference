# Get Job Status with DocMaker

Retrieves job status from DocMaker.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:jobId`
- **Base URL:** `https://api.v2.docmaker.co`
- **Official documentation:** [Get Job Status](https://docmaker.co/docMaker-swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The unique identifier of the DocMaker job. |
