# List Schedulers (Session Required) with Dubsado

## Endpoint

- **Method:** `GET`
- **Path:** `/scheduler`
- **Base URL:** `https://app.dubsado.com/api`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | query | `string` | no | Optional project ID filter observed in the Dubsado app bundle for /scheduler reads. |
