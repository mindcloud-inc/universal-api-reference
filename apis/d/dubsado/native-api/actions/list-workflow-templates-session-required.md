# List Workflow Templates (Session Required) with Dubsado

## Endpoint

- **Method:** `GET`
- **Path:** `/workflow/template`
- **Base URL:** `https://app.dubsado.com/api`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sortBy` | query | `string` | no | Optional sort key observed in the Dubsado app bundle for /workflow/template reads. |
| `limit` | query | `number` | no | Optional result limit observed in the Dubsado app bundle for /workflow/template reads. |
