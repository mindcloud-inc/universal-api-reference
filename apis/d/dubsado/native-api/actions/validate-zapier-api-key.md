# Validate Zapier API Key with Dubsado

Validates a Zapier API key in Dubsado.

## Endpoint

- **Method:** `GET`
- **Path:** `/zapier/key`
- **Base URL:** `https://app.dubsado.com/api`
- **Official documentation:** [Validate Zapier API Key](https://help.dubsado.com/en/articles/909872-connecting-with-zapier)
