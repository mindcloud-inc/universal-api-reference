# Retrieve URL Mappings with Dynamic Content Snippet

Retrieves URL mappings from Dynamic Content Snippet.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/mappings`
- **Base URL:** `https://app.contentsnip.com`
- **Official documentation:** [Retrieve URL Mappings](https://contentsnip.com/documentation.htm)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | no | Optional URL filter. ContentSnip docs say it cannot be empty when provided. |
