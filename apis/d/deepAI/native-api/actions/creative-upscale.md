# Creative Upscale with DeepAI

Creates a creatively upscaled image in DeepAI.

## Endpoint

- **Method:** `POST`
- **Path:** `/creative-upscale`
- **Base URL:** `https://api.deepai.org/api`
- **Official documentation:** [Creative Upscale](https://api.deepai.org/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image` | body | `string` | yes | The image URL or uploaded file to upscale creatively. |
