# Colorize Image with DeepAI

Creates a colorized image in DeepAI.

## Endpoint

- **Method:** `POST`
- **Path:** `/colorizer`
- **Base URL:** `https://api.deepai.org/api`
- **Official documentation:** [Colorize Image](https://api.deepai.org/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image` | body | `string` | yes | The image URL or uploaded file to colorize. |
