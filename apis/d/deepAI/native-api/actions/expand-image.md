# Expand Image with DeepAI

## Endpoint

- **Method:** `POST`
- **Path:** `/zoom-out`
- **Base URL:** `https://api.deepai.org/api`
- **Official documentation:** [Expand Image](https://api.deepai.org/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image` | body | `string` | yes | The image URL or uploaded file to expand. |
