# Create New Deck with Deck of Cards

Creates a new deck in Deck of Cards.

## Endpoint

- **Method:** `GET`
- **Path:** `deck/new/`
- **Base URL:** `https://www.deckofcardsapi.com/api/`
- **Official documentation:** [Create New Deck](https://www.deckofcardsapi.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jokers_enabled` | query | `boolean` | no | Include two jokers in the new deck when true. |
