# List Accounts with DotSimple

Retrieves connected social accounts from DotSimple.

## Endpoint

- **Method:** `GET`
- **Path:** `/:workspaceUuid/accounts`
- **Base URL:** `https://app.dotsimple.io/app/api`
- **Official documentation:** [List Accounts](https://help.dotsimple.io/en/articles/65-accounts)
