# Delete Comparison with Draftable

Deletes a document comparison from Draftable.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/comparisons/{{identifier}}`
- **Base URL:** `https://api.draftable.com/v1`
- **Official documentation:** [Delete Comparison](https://api.draftable.com/reference/comparison-lifecycle)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The comparison identifier. |
