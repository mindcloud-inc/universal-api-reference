# List Comparisons with Draftable

Retrieves your document comparisons from Draftable.

## Endpoint

- **Method:** `GET`
- **Path:** `/comparisons`
- **Base URL:** `https://api.draftable.com/v1`
- **Official documentation:** [List Comparisons](https://api.draftable.com/reference/comparison-lifecycle)

## Capabilities

This operation supports [pagination](../README.md#pagination).
