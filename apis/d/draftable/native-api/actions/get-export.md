# Get Export with Draftable

Retrieves a comparison export job from Draftable.

## Endpoint

- **Method:** `GET`
- **Path:** `/exports/{{identifier}}`
- **Base URL:** `https://api.draftable.com/v1`
- **Official documentation:** [Get Export](https://api.draftable.com/reference/exporting-comparisons)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The export identifier. |
