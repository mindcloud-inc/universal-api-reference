# Delete Doc with Dovetail

Deletes an existing doc from Dovetail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/docs/:docId`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Delete Doc](https://developers.dovetail.com/reference/delete_v1-docs-doc_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `docId` | path | `string` | yes | Doc ID to delete. |
