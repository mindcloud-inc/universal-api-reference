# Delete Folder with Dovetail

Deletes an existing folder from Dovetail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/folders/:folderId`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Delete Folder](https://developers.dovetail.com/reference/delete_v1-folders-folderid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
