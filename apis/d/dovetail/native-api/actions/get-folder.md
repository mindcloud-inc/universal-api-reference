# Get Folder with Dovetail

Retrieves a folder from Dovetail by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/folders/:folderId`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Get Folder](https://developers.dovetail.com/reference/get_v1-folders-folderid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
