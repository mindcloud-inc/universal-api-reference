# List Data with Dovetail

Retrieves data entries from your Dovetail workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/data`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [List Data](https://developers.dovetail.com/reference/get_v1-data)

## Capabilities

This operation supports [pagination](../README.md#pagination).
