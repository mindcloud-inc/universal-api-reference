# Get Contact with Dovetail

Retrieves a contact from Dovetail by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/:contactId`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Get Contact](https://developers.dovetail.com/reference/get_v1-contacts-contactid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
