# List Folders with Dovetail

Retrieves folders from your Dovetail workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/folders`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [List Folders](https://developers.dovetail.com/reference/get_v1-folders)

## Capabilities

This operation supports [pagination](../README.md#pagination).
