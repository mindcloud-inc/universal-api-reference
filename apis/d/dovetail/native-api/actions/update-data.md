# Update Data with Dovetail

Updates an existing data entry in Dovetail.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/data/:dataId`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Update Data](https://developers.dovetail.com/reference/patch_v1-data-data_id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dataId` | path | `string` | yes |
