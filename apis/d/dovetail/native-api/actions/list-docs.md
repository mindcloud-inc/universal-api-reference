# List Docs with Dovetail

Retrieves docs from your Dovetail workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/docs`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [List Docs](https://developers.dovetail.com/reference/get_v1-docs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
