# Create Project with Dovetail

Creates a new project in your Dovetail workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/projects`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Create Project](https://developers.dovetail.com/reference/post_v1-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | no | Project title. |
