# Get Doc with Dovetail

Retrieves a doc from Dovetail by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/docs/:docId`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Get Doc](https://developers.dovetail.com/reference/get_v1-docs-docid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `docId` | path | `string` | yes |
