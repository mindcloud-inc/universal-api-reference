# Delete Data with Dovetail

Deletes an existing data entry from Dovetail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/data/:dataId`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Delete Data](https://developers.dovetail.com/reference/delete_v1-data-data_id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dataId` | path | `string` | yes |
