# Delete Contact with Dovetail

Deletes an existing contact from Dovetail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contacts/:contactId`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Delete Contact](https://developers.dovetail.com/reference/delete_v1-contacts-contactid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
