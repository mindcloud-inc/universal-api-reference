# List Contacts with Dovetail

Retrieves contacts from your Dovetail workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [List Contacts](https://developers.dovetail.com/reference/get_v1-contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
