# Delete Project with Dovetail

Deletes an existing project from Dovetail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/projects/:projectId`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Delete Project](https://developers.dovetail.com/reference/delete_v1-projects-projectid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
