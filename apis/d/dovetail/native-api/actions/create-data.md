# Create Data with Dovetail

Creates a new data entry in Dovetail.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/data`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Create Data](https://developers.dovetail.com/reference/post_v1-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | body | `string` | yes | Project ID that owns the data record. |
