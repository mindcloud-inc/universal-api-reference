# List Projects with Dovetail

Retrieves projects from your Dovetail workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [List Projects](https://developers.dovetail.com/reference/get_v1-projects)

## Capabilities

This operation supports [pagination](../README.md#pagination).
