# Get Data with Dovetail

Retrieves a data entry from Dovetail by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/data/:dataId`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Get Data](https://developers.dovetail.com/reference/get_v1-data-data_id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dataId` | path | `string` | yes |
