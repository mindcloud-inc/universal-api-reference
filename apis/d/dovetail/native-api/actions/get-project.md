# Get Project with Dovetail

Retrieves a project from Dovetail by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:projectId`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Get Project](https://developers.dovetail.com/reference/get_v1-projects-projectid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
