# Create Folder with Dovetail

Creates a new folder in your Dovetail workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/folders`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Create Folder](https://developers.dovetail.com/reference/post_v1-folders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Folder title. |
