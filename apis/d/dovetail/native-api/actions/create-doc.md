# Create Doc with Dovetail

Creates a new doc in your Dovetail workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/docs`
- **Base URL:** `https://dovetail.com/api`
- **Official documentation:** [Create Doc](https://developers.dovetail.com/reference/post_v1-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | no | Doc title. |
