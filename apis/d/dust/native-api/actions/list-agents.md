# List Agents with Dust

Retrieves agent configurations from the Dust workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/w/:workspaceId/assistant/agent_configurations`
- **Base URL:** `https://dust.tt`
- **Official documentation:** [List Agents](https://docs.dust.tt/reference/get_api-v1-w-wid-assistant-agent-configurations)
