# Get Data Sources with Dust

Retrieves data sources from a Dust space.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/w/:workspaceId/spaces/:spaceId/data_sources`
- **Base URL:** `https://dust.tt`
- **Official documentation:** [Get Data Sources](https://docs.dust.tt/reference/get_api-v1-w-wid-spaces-spaceid-data-sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Dust space sId. |
