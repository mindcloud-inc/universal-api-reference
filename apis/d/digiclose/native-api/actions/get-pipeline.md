# Get Pipeline with Digiclose

## Endpoint

- **Method:** `GET`
- **Path:** `/pipelines/:pipeline_id`
- **Base URL:** `https://app.digiclose.ai/api/v1`
- **Official documentation:** [Get Pipeline](https://app.digiclose.ai/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pipeline_id` | path | `number` | yes | Unique identifier for the pipeline. |
