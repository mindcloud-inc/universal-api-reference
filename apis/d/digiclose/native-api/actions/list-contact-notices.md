# List Contact Notices with Digiclose

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contact_id/notices`
- **Base URL:** `https://app.digiclose.ai/api/v1`
- **Official documentation:** [List Contact Notices](https://app.digiclose.ai/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `number` | yes | Unique identifier for the contact. |
