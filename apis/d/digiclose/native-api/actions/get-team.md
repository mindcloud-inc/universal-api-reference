# Get Team with Digiclose

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:team_id`
- **Base URL:** `https://app.digiclose.ai/api/v1`
- **Official documentation:** [Get Team](https://app.digiclose.ai/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `number` | yes | Unique identifier for the team. |
