# Create Contact with Digiclose

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts`
- **Base URL:** `https://app.digiclose.ai/api/v1`
- **Official documentation:** [Create Contact](https://app.digiclose.ai/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | body | `object` | yes | Contact field values using Digiclose internal field names. |
