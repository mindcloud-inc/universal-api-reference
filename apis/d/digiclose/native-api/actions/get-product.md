# Get Product with Digiclose

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:product_id`
- **Base URL:** `https://app.digiclose.ai/api/v1`
- **Official documentation:** [Get Product](https://app.digiclose.ai/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `number` | yes | Unique identifier for the product. |
