# List Contacts with Digiclose

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://app.digiclose.ai/api/v1`
- **Official documentation:** [List Contacts](https://app.digiclose.ai/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `exact` | query | `string` | no | Set to 1 for exact matches instead of partial matches. |
| `search` | query | `string` | no | Search contacts by name, email, phone, or company. |
