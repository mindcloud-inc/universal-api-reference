# Create Product with Digiclose

## Endpoint

- **Method:** `POST`
- **Path:** `/products`
- **Base URL:** `https://app.digiclose.ai/api/v1`
- **Official documentation:** [Create Product](https://app.digiclose.ai/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `description` | body | `string` | yes |
| `name` | body | `string` | yes |
| `price` | body | `number` | yes |
| `short_description` | body | `string` | yes |
| `vat` | body | `number` | yes |
