# Get Contact Search Status with DataMerge

Retrieves a DataMerge contact search job status.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contact/search/:job_id/status`
- **Base URL:** `https://api.datamerge.ai`
- **Official documentation:** [Get Contact Search Status](https://api.datamerge.ai/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `job_id` | path | `string` | yes |
