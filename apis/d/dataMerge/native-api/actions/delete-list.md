# Delete List with DataMerge

Deletes an existing list from DataMerge.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/lists/:object_type/:list`
- **Base URL:** `https://api.datamerge.ai`
- **Official documentation:** [Delete List](https://api.datamerge.ai/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `object_type` | path | `string` | yes |
| `list` | path | `string` | yes |
