# Get Contact Enrichment Status with DataMerge

Retrieves a DataMerge contact enrichment job status.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contact/enrich/:job_id/status`
- **Base URL:** `https://api.datamerge.ai`
- **Official documentation:** [Get Contact Enrichment Status](https://api.datamerge.ai/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `job_id` | path | `string` | yes |
