# Search Lookalike Companies with DataMerge

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/company/lookalike`
- **Base URL:** `https://api.datamerge.ai`
- **Official documentation:** [Search Lookalike Companies](https://api.datamerge.ai/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companiesFilters` | body | `object` | no |
| `size` | body | `number` | no |
| `list` | body | `string` | no |
| `exclude_all` | body | `boolean` | no |
| `refresh` | body | `boolean` | no |
| `searchAfter` | body | `string` | no |
| `webhook` | body | `string` | no |
