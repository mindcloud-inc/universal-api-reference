# Get Lists with DataMerge

Retrieves company or contact lists from DataMerge.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/lists`
- **Base URL:** `https://api.datamerge.ai`
- **Official documentation:** [Get Lists](https://api.datamerge.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `object_type` | query | `string` | no | Optional object type filter. |
