# Get Contact with DataMerge

Retrieves a contact from DataMerge by record ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contact/get`
- **Base URL:** `https://api.datamerge.ai`
- **Official documentation:** [Get Contact](https://api.datamerge.ai/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `record_id` | query | `string` | yes |
