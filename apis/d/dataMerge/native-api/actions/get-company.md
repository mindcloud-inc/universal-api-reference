# Get Company with DataMerge

Retrieves a company from DataMerge by DataMerge ID or record ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/company/get`
- **Base URL:** `https://api.datamerge.ai`
- **Official documentation:** [Get Company](https://api.datamerge.ai/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `record_id` | query | `string` | no |
| `datamerge_id` | query | `string` | no |
| `add_to_list` | query | `string` | no |
