# Remove Item From List with DataMerge

Removes an item from a DataMerge list.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/lists/:object_type/:list/:item_id`
- **Base URL:** `https://api.datamerge.ai`
- **Official documentation:** [Remove Item From List](https://api.datamerge.ai/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `object_type` | path | `string` | yes |
| `list` | path | `string` | yes |
| `item_id` | path | `string` | yes |
