# Delete Template with Documint

Permanently deletes an existing template from Documint.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/templates/:id`
- **Base URL:** `https://api.documint.me/1`
- **Official documentation:** [Delete Template](https://documenter.getpostman.com/view/11741160/TVK5cLxQ)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Documint template ID to delete. |
