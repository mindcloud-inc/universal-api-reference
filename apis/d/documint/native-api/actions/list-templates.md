# List Templates with Documint

Retrieves a list of templates from Documint.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://api.documint.me/1`
- **Official documentation:** [List Templates](https://documenter.getpostman.com/view/11741160/TVK5cLxQ)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `select` | query | `string` | no | Comma-separated list of fields to include in each template record. |
