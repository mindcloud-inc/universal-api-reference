# Get Template with Digit.ink

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:templateUuid`
- **Base URL:** `https://app.digit.ink/api/v1`
- **Official documentation:** [Get Template](https://app.digit.ink/api/v1/classic-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateUuid` | path | `string` | yes | Template UUID path parameter. |
