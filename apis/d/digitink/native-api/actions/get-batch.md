# Get Batch with Digit.ink

## Endpoint

- **Method:** `GET`
- **Path:** `/batches/:batchUuid`
- **Base URL:** `https://app.digit.ink/api/v1`
- **Official documentation:** [Get Batch](https://app.digit.ink/api/v1/classic-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batchUuid` | path | `string` | yes | Batch UUID path parameter. |
