# Create Stack with Digit.ink

## Endpoint

- **Method:** `POST`
- **Path:** `/stacks`
- **Base URL:** `https://app.digit.ink/api/v1`
- **Official documentation:** [Create Stack](https://app.digit.ink/api/v1/classic-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stackName` | body | `string` | yes | Name for the new stack. |
