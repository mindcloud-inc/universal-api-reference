# Get Credential Stack with Digit.ink

## Endpoint

- **Method:** `GET`
- **Path:** `/credentials/:credentialUuid/stack`
- **Base URL:** `https://app.digit.ink/api/v1`
- **Official documentation:** [Get Credential Stack](https://app.digit.ink/api/v1/classic-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `credentialUuid` | path | `string` | yes | Credential UUID path parameter. |
| `password` | query | `string` | no | Optional credential password query parameter. |
