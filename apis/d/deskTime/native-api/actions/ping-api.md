# Ping API with DeskTime

Checks whether the DeskTime API is responding.

## Endpoint

- **Method:** `GET`
- **Path:** `/ping`
- **Base URL:** `https://desktime.com/api/v2/json`
- **Official documentation:** [Ping API](https://help.desktime.com/hc/en-us/articles/25494685459357-How-to-use-ping-request)
