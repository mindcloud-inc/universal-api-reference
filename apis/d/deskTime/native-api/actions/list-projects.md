# List Projects with DeskTime

Retrieves active projects from DeskTime with their tasks.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://desktime.com/api/v2/json`
- **Official documentation:** [List Projects](https://help.desktime.com/hc/en-us/articles/25495195415453-How-to-get-projects-with-API)
