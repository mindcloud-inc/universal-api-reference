# Get User Details with DigiCert

Retrieves details for a user in DigiCert.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:user_id`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [Get User Details](https://dev.digicert.com/certcentral-apis/services-api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The DigiCert user identifier. |
