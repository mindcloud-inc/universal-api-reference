# List Organization Approvers with DigiCert

Retrieves potential organization approvers from DigiCert.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/potential-approvers`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [List Organization Approvers](https://dev.digicert.com/certcentral-apis/services-api.html)
