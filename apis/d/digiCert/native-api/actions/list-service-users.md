# List Service Users with DigiCert

Retrieves service users from your DigiCert account.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/api-only`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [List Service Users](https://dev.digicert.com/certcentral-apis/services-api.html)
