# List Permissions with DigiCert

Retrieves permissions for the authenticated DigiCert user.

## Endpoint

- **Method:** `GET`
- **Path:** `/authorization`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [List Permissions](https://dev.digicert.com/certcentral-apis/services-api.html)
