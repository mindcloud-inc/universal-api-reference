# Get Account Details with DigiCert

Retrieves your CertCentral account details from DigiCert.

## Endpoint

- **Method:** `GET`
- **Path:** `/account`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [Get Account Details](https://dev.digicert.com/services-api/account/account-details)
