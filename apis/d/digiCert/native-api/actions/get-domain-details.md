# Get Domain Details with DigiCert

Retrieves details for a domain in DigiCert.

## Endpoint

- **Method:** `GET`
- **Path:** `/domain/:domain_id`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [Get Domain Details](https://dev.digicert.com/certcentral-apis/services-api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | path | `string` | yes | The DigiCert domain identifier. |
