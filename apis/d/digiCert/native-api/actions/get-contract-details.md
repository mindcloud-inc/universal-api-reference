# Get Contract Details with DigiCert

Retrieves active contract details from your DigiCert account.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/contract`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [Get Contract Details](https://dev.digicert.com/certcentral-apis/services-api.html)
