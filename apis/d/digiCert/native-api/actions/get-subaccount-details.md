# Get Subaccount Details with DigiCert

Retrieves details for a DigiCert subaccount.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/subaccount/:subaccount_id`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [Get Subaccount Details](https://dev.digicert.com/certcentral-apis/services-api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subaccount_id` | path | `string` | yes | The DigiCert subaccount identifier. |
