# List Subaccounts with DigiCert

Retrieves subaccounts from your DigiCert account.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/subaccount`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [List Subaccounts](https://dev.digicert.com/services-api/subaccount/list-subaccounts/)
