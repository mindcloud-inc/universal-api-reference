# Get API Key Details with DigiCert

Retrieves details for an API key in DigiCert.

## Endpoint

- **Method:** `GET`
- **Path:** `/key/:api_key_id`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [Get API Key Details](https://dev.digicert.com/certcentral-apis/services-api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `api_key_id` | path | `string` | yes | The DigiCert API key identifier. |
