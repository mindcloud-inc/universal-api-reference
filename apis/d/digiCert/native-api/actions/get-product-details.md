# Get Product Details with DigiCert

Retrieves details for a DigiCert product.

## Endpoint

- **Method:** `GET`
- **Path:** `/product/:product_id`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [Get Product Details](https://dev.digicert.com/certcentral-apis/services-api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `string` | yes | The DigiCert product identifier. |
