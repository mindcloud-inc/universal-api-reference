# List Auth Keys with DigiCert

Retrieves active AuthKeys linked to your DigiCert account.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/auth-keys`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [List Auth Keys](https://dev.digicert.com/certcentral-apis/services-api.html)
