# Get Container Details with DigiCert

Retrieves details for a container in DigiCert.

## Endpoint

- **Method:** `GET`
- **Path:** `/container/:container_id`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [Get Container Details](https://dev.digicert.com/certcentral-apis/services-api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `container_id` | path | `string` | yes | The DigiCert container identifier. |
