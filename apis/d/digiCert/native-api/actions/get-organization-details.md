# Get Organization Details with DigiCert

Retrieves details for an organization in DigiCert.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/:organization_id`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [Get Organization Details](https://dev.digicert.com/certcentral-apis/services-api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `string` | yes | The DigiCert organization identifier. |
