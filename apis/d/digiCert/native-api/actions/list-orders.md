# List Orders with DigiCert

Retrieves certificate orders from your DigiCert account.

## Endpoint

- **Method:** `GET`
- **Path:** `/order/certificate`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [List Orders](https://dev.digicert.com/certcentral-apis/services-api.html)
