# Get Domain Validation Types with DigiCert

Retrieves available domain validation types from DigiCert.

## Endpoint

- **Method:** `GET`
- **Path:** `/domain/validation/type`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [Get Domain Validation Types](https://dev.digicert.com/certcentral-apis/services-api.html)
