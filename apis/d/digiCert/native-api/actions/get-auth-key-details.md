# Get Auth Key Details with DigiCert

Retrieves details for an AuthKey in DigiCert.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/auth-key/:auth_key_id`
- **Base URL:** `https://www.digicert.com/services/v2`
- **Official documentation:** [Get Auth Key Details](https://dev.digicert.com/certcentral-apis/services-api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `auth_key_id` | path | `string` | yes | The DigiCert AuthKey identifier. |
