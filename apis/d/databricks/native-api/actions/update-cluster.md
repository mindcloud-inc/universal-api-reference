# Update Cluster with Databricks

Updates an existing cluster in the Databricks workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `{host}/api/2.1/clusters/update`
- **Base URL:** `https://accounts.cloud.databricks.com`
- **Official documentation:** [Update Cluster](https://docs.databricks.com/api/workspace/clusters/update)

## Parameters

| `autotermination_minutes` | body | `number` | no | Automatically terminates the cluster after it is inactive for this time in minutes. If not set, this cluster will not be automatically terminated. Most programming languages, cluster features and data governance features are available in this mode. * `USER_ISOLATION`: A secure cluster that can be shared by multiple users. Cluster users are fully isolated so that they cannot see each other's data and credentials. Most data governance features are supported in this mode. But programming languages and cluster features might be limited.
