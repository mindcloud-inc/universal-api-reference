# List Workspaces with Databricks

Retrieves workspaces from the Databricks account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/accounts/{accountId}/workspaces`
- **Base URL:** `https://accounts.cloud.databricks.com`
- **Official documentation:** [List Workspaces](https://docs.databricks.com/api/account/workspaces/list)
