# Read Current User with Deepset

Retrieves the current user from Deepset.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/me`
- **Base URL:** `https://api.cloud.deepset.ai`
- **Official documentation:** [Read Current User](https://docs.cloud.deepset.ai/docs/api/main/read-users-me-api-v-1-me-get)
