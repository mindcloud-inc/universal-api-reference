# Get Organization with Deepset

Retrieves your current Deepset organization details.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/organization`
- **Base URL:** `https://api.cloud.deepset.ai`
- **Official documentation:** [Get Organization](https://docs.cloud.deepset.ai/docs/api/main/get-organization-api-v-1-organization-get)
