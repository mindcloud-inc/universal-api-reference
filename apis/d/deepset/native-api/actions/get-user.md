# Get User with Deepset

Retrieves a Deepset user by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/users/:user_id`
- **Base URL:** `https://api.cloud.deepset.ai`
- **Official documentation:** [Get User](https://docs.cloud.deepset.ai/docs/api/main/get-user-api-v-1-users-user-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | deepset user ID. |
