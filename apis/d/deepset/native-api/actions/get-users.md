# Get Users with Deepset

Retrieves users from your Deepset organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/users`
- **Base URL:** `https://api.cloud.deepset.ai`
- **Official documentation:** [Get Users](https://docs.cloud.deepset.ai/docs/api/main/get-users-api-v-1-users-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
