# Get Workspace By Name with Deepset

Retrieves a Deepset workspace by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/workspaces/:workspace_name`
- **Base URL:** `https://api.cloud.deepset.ai`
- **Official documentation:** [Get Workspace By Name](https://docs.cloud.deepset.ai/docs/api/main/get-workspace-by-name-api-v-1-workspaces-workspace-name-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspace_name` | path | `string` | yes | deepset workspace name. |
