# Get Shared Jobs with Deepset

Retrieves shared jobs from a Deepset workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/workspaces/:workspace_id/shared_jobs`
- **Base URL:** `https://api.cloud.deepset.ai`
- **Official documentation:** [Get Shared Jobs](https://docs.cloud.deepset.ai/docs/api/jobs/get-shared-jobs-api-v-2-workspaces-workspace-id-shared-jobs-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspace_id` | path | `string` | yes | deepset workspace ID. |
