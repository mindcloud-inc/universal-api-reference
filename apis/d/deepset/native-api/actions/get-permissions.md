# Get Permissions with Deepset

Retrieves permissions for your Deepset organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/organization/permissions`
- **Base URL:** `https://api.cloud.deepset.ai`
- **Official documentation:** [Get Permissions](https://docs.cloud.deepset.ai/docs/api/main/get-permissions-api-v-1-organization-permissions-get)
