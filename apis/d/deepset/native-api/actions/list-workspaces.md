# List Workspaces with Deepset

Retrieves workspaces from your Deepset organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/workspaces`
- **Base URL:** `https://api.cloud.deepset.ai`
- **Official documentation:** [List Workspaces](https://docs.cloud.deepset.ai/docs/api/main/list-workspaces-api-v-1-workspaces-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
