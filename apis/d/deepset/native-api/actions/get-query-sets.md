# Get Query Sets with Deepset

Retrieves query sets from a Deepset workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/workspaces/:workspace_id/query_sets`
- **Base URL:** `https://api.cloud.deepset.ai`
- **Official documentation:** [Get Query Sets](https://docs.cloud.deepset.ai/docs/api/jobs/get-query-sets-api-v-2-workspaces-workspace-id-query-sets-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspace_id` | path | `string` | yes | deepset workspace ID. |
