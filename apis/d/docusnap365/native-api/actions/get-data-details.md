# Get Data Details with Docusnap365

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/segment/data/:id/detailed`
- **Base URL:** `https://api.docusnap365.com`
- **Official documentation:** [Get Data Details](https://api-doc.docusnap.com/reference/datadetailsexample)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docusnap365 data ID to fetch in detailed form. |
