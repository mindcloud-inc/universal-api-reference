# Get Service Details with Docusnap365

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/segment/services/:id/detailed`
- **Base URL:** `https://api.docusnap365.com`
- **Official documentation:** [Get Service Details](https://api-doc.docusnap.com/reference/servicedetailsexample)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docusnap365 service ID to fetch in detailed form. |
