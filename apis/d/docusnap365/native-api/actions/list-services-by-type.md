# List Services By Type with Docusnap365

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/segment/services/type/:typeId`
- **Base URL:** `https://api.docusnap365.com`
- **Official documentation:** [List Services By Type](https://api-doc.docusnap.com/reference/getservicebytype)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `typeId` | path | `string` | yes | The Docusnap365 service type ID to filter by. |
