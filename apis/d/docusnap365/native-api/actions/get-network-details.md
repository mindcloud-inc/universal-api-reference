# Get Network Details with Docusnap365

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/segment/networks/:id/detailed`
- **Base URL:** `https://api.docusnap365.com`
- **Official documentation:** [Get Network Details](https://api-doc.docusnap.com/reference/networkdetailsexample)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docusnap365 network ID to fetch in detailed form. |
