# List Systems By Type with Docusnap365

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/segment/systems/type/:typeId`
- **Base URL:** `https://api.docusnap365.com`
- **Official documentation:** [List Systems By Type](https://api-doc.docusnap.com/reference/getsystemsbytype)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `typeId` | path | `string` | yes | The Docusnap365 system type ID to filter by. |
