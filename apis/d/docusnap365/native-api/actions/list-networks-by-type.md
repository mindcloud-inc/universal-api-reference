# List Networks By Type with Docusnap365

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/segment/networks/type/:typeId`
- **Base URL:** `https://api.docusnap365.com`
- **Official documentation:** [List Networks By Type](https://api-doc.docusnap.com/reference/getnetworksbytype)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `typeId` | path | `string` | yes | The Docusnap365 network type ID to filter by. |
