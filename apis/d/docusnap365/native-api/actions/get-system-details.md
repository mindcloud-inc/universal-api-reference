# Get System Details with Docusnap365

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/segment/systems/:id/detailed`
- **Base URL:** `https://api.docusnap365.com`
- **Official documentation:** [Get System Details](https://api-doc.docusnap.com/reference/systemdetailsexample)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Docusnap365 system ID to fetch in detailed form. |
