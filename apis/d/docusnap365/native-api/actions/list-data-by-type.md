# List Data By Type with Docusnap365

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/segment/data/type/:typeId`
- **Base URL:** `https://api.docusnap365.com`
- **Official documentation:** [List Data By Type](https://api-doc.docusnap.com/reference/getdatabytype)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `typeId` | path | `string` | yes | The Docusnap365 data type ID to filter by. |
