# List Webhook Subscriptions with Dwolla

Retrieves a list of webhook subscriptions from Dwolla.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook-subscriptions`
- **Base URL:** `https://api-sandbox.dwolla.com`
- **Official documentation:** [List Webhook Subscriptions](https://developers.dwolla.com/docs/api-reference/webhook-subscriptions/list-webhook-subscriptions)
