# Get Transfer with Dwolla

Retrieves details for a transfer from Dwolla.

## Endpoint

- **Method:** `GET`
- **Path:** `/transfers/[:id]`
- **Base URL:** `https://api-sandbox.dwolla.com`
- **Official documentation:** [Get Transfer](https://developers.dwolla.com/docs/api-reference/transfers/retrieve-a-transfer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Dwolla transfer ID. |
