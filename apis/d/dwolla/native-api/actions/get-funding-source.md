# Get Funding Source with Dwolla

Retrieves details for a funding source from Dwolla.

## Endpoint

- **Method:** `GET`
- **Path:** `/funding-sources/[:id]`
- **Base URL:** `https://api-sandbox.dwolla.com`
- **Official documentation:** [Get Funding Source](https://developers.dwolla.com/docs/api-reference/funding-sources/retrieve-a-funding-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Dwolla funding source ID. |
