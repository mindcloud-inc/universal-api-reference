# Get Webhook Subscription with Dwolla

Retrieves a webhook subscription from Dwolla.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook-subscriptions/[:id]`
- **Base URL:** `https://api-sandbox.dwolla.com`
- **Official documentation:** [Get Webhook Subscription](https://developers.dwolla.com/docs/api-reference/webhook-subscriptions/retrieve-a-webhook-subscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Dwolla webhook subscription ID. |
