# Get Account with Dwolla

Retrieves details for a Dwolla account.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/[:id]`
- **Base URL:** `https://api-sandbox.dwolla.com`
- **Official documentation:** [Get Account](https://developers.dwolla.com/docs/api-reference/accounts/retrieve-account-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Dwolla account ID. |
