# Get Customer with Dwolla

Retrieves details for a customer from Dwolla.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/[:id]`
- **Base URL:** `https://api-sandbox.dwolla.com`
- **Official documentation:** [Get Customer](https://developers.dwolla.com/docs/api-reference/customers/retrieve-a-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Dwolla customer ID. |
