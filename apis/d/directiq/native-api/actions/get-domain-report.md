# Get domain report with DirectIQ

Retrieves campaign domain details from DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/core/reports/domains`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Get domain report](https://directiq.readme.io/reference/get_reports-domains)

## Capabilities

This operation supports [pagination](../README.md#pagination).
