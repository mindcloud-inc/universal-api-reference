# Set Contacts Disabled in Bulk with DirectIQ

Sets multiple contacts to manually disabled in DirectIQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/contact/disablebulk`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Set Contacts Disabled in Bulk](https://directiq.readme.io/reference/post_contact-disablebulk)
