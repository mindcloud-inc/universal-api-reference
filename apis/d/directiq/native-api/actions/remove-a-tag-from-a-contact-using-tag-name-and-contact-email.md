# Remove a tag from a contact using tag name and contact email with DirectIQ

Removes a tag from a DirectIQ contact by tag name and email.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts/tag/removecontact`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Remove a tag from a contact using tag name and contact email](https://directiq.readme.io/reference/put_tag-removecontact)
