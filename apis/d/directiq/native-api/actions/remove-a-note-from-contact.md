# Remove a note from contact with DirectIQ

Deletes a note from a contact in DirectIQ.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/contactnotes/deletenote/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Remove a note from contact](https://directiq.readme.io/reference/delete_contactnotes-deletenote-id)
