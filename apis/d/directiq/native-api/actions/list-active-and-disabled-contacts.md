# List Active and Disabled Contacts with DirectIQ

Retrieves active and disabled contact counts from DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/contact/getstatuscount`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [List Active and Disabled Contacts](https://directiq.readme.io/reference/get_contact-getstatuscount)
