# Delete contacts from a list with DirectIQ

Deletes contacts from a specific list in DirectIQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/lists/deletecontacts/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Delete contacts from a list](https://directiq.readme.io/reference/post_lists-deletecontacts-id)
