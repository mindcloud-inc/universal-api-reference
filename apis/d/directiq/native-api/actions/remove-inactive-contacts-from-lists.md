# Remove Inactive Contacts from Lists with DirectIQ

Removes inactive contacts from specified DirectIQ lists.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/lists/sanitizelists`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Remove Inactive Contacts from Lists](https://directiq.readme.io/reference/post_lists-sanitizelists)
