# Add or Create Tag for Contact with DirectIQ

Adds a tag to a contact or creates one in DirectIQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/tag/createorassign`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Add or Create Tag for Contact](https://directiq.readme.io/reference/post_tag-createorassign)
