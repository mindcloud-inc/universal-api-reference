# List Date Keys with DirectIQ

Retrieves date-type contact keys from DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/extradata/listdatekeys`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [List Date Keys](https://directiq.readme.io/reference/get_extradata-listdatekeys)
