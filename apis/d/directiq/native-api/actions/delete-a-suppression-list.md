# Delete a suppression list with DirectIQ

Deletes a suppression list from DirectIQ.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/suppressionlist/delete/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Delete a suppression list](https://directiq.readme.io/reference/delete_suppressionlist-delete-id)
