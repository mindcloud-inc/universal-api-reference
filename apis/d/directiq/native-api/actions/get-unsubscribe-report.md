# Get unsubscribe report with DirectIQ

Retrieves campaign unsubscribe records from DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/core/reports/unsubscribes`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Get unsubscribe report](https://directiq.readme.io/reference/get_reports-unsubscribes)

## Capabilities

This operation supports [pagination](../README.md#pagination).
