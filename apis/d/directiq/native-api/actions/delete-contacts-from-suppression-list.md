# Delete contacts from suppression list with DirectIQ

Deletes contacts from a suppression list in DirectIQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/suppressionlist/deletecontacts`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Delete contacts from suppression list](https://directiq.readme.io/reference/post_suppressionlist-deletecontacts)
