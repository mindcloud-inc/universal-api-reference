# Update contact key visibility with DirectIQ

Updates contact key visibility in DirectIQ.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts/extradata/updatekeyvisibility/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Update contact key visibility](https://directiq.readme.io/reference/put_extradata-updatekeyvisibility-id)
