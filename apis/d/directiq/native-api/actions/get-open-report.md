# Get open report with DirectIQ

Retrieves campaign open records from DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/core/reports/opens`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Get open report](https://directiq.readme.io/reference/get_reports-opens)

## Capabilities

This operation supports [pagination](../README.md#pagination).
