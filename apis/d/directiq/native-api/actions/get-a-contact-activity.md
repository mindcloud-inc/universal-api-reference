# Get a contact activity with DirectIQ

Retrieves a contact activity from DirectIQ by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/contactactivity/get/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Get a contact activity](https://directiq.readme.io/reference/get_contactactivity-get-id)
