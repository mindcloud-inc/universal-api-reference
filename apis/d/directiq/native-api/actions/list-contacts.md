# List Contacts with DirectIQ

Retrieves a paginated list of contacts from DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/contact/list`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [List Contacts](https://directiq.readme.io/reference/get_contact-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
