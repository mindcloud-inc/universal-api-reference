# Remove a contact from a list with DirectIQ

Removes a contact from a list in DirectIQ.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts/lists/removecontact/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Remove a contact from a list](https://directiq.readme.io/reference/put_lists-removecontact-id)
