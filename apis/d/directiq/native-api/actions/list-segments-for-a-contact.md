# List Segments for a Contact with DirectIQ

Retrieves segments for a contact in DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/segment/listcontactsegments`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [List Segments for a Contact](https://directiq.readme.io/reference/get_segment-listcontactsegments)
