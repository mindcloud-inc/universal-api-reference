# Add a note to contact with DirectIQ

Adds a note to a contact in DirectIQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/contactnotes/addnote/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Add a note to contact](https://directiq.readme.io/reference/post_contactnotes-addnote-id)
