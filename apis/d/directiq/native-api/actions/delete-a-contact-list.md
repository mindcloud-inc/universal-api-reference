# Delete a contact list with DirectIQ

Deletes a contact list from DirectIQ and contacts only on it.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/lists/delete/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Delete a contact list](https://directiq.readme.io/reference/delete_lists-delete-id)
