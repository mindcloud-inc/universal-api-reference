# Add a tag to contacts with DirectIQ

Adds a tag to multiple contacts in DirectIQ.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts/tag/addcontacts/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Add a tag to contacts](https://directiq.readme.io/reference/put_tag-addcontacts-id)
