# Get a suppression list with DirectIQ

Retrieves a suppression list from DirectIQ by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/suppressionlist/get/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Get a suppression list](https://directiq.readme.io/reference/get_suppressionlist-get-id)
