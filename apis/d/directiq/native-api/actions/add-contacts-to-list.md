# Add Contacts to List with DirectIQ

Adds multiple contacts to a list in DirectIQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/lists/importcontacts/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Add Contacts to List](https://directiq.readme.io/reference/post_lists-importcontacts-id)
