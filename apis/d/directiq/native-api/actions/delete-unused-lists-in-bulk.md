# Delete Unused Lists in Bulk with DirectIQ

Deletes unused contact lists from DirectIQ.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/lists/deleteunusedbulk`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Delete Unused Lists in Bulk](https://directiq.readme.io/reference/delete_lists-deleteunusedbulk)
