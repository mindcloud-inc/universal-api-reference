# Get recipient report with DirectIQ

Retrieves campaign recipient records from DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/core/reports/recipients`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Get recipient report](https://directiq.readme.io/reference/get_reports-recipients)

## Capabilities

This operation supports [pagination](../README.md#pagination).
