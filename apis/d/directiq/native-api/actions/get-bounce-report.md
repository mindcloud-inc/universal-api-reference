# Get bounce report with DirectIQ

Retrieves campaign bounce records from DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/core/reports/bounces`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Get bounce report](https://directiq.readme.io/reference/get_reports-bounces)

## Capabilities

This operation supports [pagination](../README.md#pagination).
