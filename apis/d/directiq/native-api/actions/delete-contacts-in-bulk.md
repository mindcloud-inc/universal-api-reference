# Delete Contacts in Bulk with DirectIQ

Deletes multiple existing contacts from DirectIQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/contact/deletebulk`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Delete Contacts in Bulk](https://directiq.readme.io/reference/post_contact-deletebulk)
