# Rename a suppression list with DirectIQ

Renames a suppression list in DirectIQ.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts/suppressionlist/rename/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Rename a suppression list](https://directiq.readme.io/reference/put_suppressionlist-rename-id)
