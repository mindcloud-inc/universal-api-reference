# Update a contact note with DirectIQ

Updates a note on a contact in DirectIQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/contactnotes/editnote/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Update a contact note](https://directiq.readme.io/reference/post_contactnotes-editnote-id)
