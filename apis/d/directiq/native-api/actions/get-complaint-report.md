# Get complaint report with DirectIQ

Retrieves campaign complaint records from DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/core/reports/complaints`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Get complaint report](https://directiq.readme.io/reference/get_reports-complaints)

## Capabilities

This operation supports [pagination](../README.md#pagination).
