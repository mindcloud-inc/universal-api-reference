# Set Contacts Active in Bulk with DirectIQ

Sets multiple contacts to active in DirectIQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/contact/activatebulk`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Set Contacts Active in Bulk](https://directiq.readme.io/reference/post_contact-activatebulk)
