# Get click report with DirectIQ

Retrieves campaign click records from DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/core/reports/clicks`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Get click report](https://directiq.readme.io/reference/get_reports-clicks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
