# Get email client report with DirectIQ

Retrieves campaign email client details from DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/core/reports/emailclients`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Get email client report](https://directiq.readme.io/reference/get_reports-emailclients)

## Capabilities

This operation supports [pagination](../README.md#pagination).
