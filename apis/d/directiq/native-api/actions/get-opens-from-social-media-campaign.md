# Get opens from social media campaign with DirectIQ

Retrieves social media campaign opens from DirectIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/core/reports/socialmedia`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Get opens from social media campaign](https://directiq.readme.io/reference/get_reports-socialmedia)

## Capabilities

This operation supports [pagination](../README.md#pagination).
