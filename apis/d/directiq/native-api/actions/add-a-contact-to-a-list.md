# Add a contact to a list with DirectIQ

Adds a contact to a list in DirectIQ.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts/lists/addcontact/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Add a contact to a list](https://directiq.readme.io/reference/put_lists-addcontact-id)
