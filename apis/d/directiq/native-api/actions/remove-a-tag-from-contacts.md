# Remove a tag from contacts with DirectIQ

Removes a tag from multiple contacts in DirectIQ.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts/tag/removecontacts/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Remove a tag from contacts](https://directiq.readme.io/reference/put_tag-removecontacts-id)
