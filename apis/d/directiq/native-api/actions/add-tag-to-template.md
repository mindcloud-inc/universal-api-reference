# Add Tag to Template with DirectIQ

Adds a tag to a template in DirectIQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/core/template/assigntag/{id}`
- **Base URL:** `https://rest.directiq.com`
- **Official documentation:** [Add Tag to Template](https://directiq.readme.io/reference/post_template-assigntag-id)
