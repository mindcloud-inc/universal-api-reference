# Get Private Lists with Dotdigital

Retrieves all private lists from Dotdigital.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/address-books/private`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Private Lists](https://developer.dotdigital.com/reference/get-private-address-books)

## Capabilities

This operation supports [pagination](../README.md#pagination).
