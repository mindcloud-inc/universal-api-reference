# Get Campaign Summary with Dotdigital

Retrieves campaign reporting summary information from Dotdigital.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/campaigns/:id/summary`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Campaign Summary](https://developer.dotdigital.com/reference/get-campaign-summary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the campaign. |
