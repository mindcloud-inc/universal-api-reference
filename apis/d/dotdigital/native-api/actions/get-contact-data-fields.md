# Get Contact Data Fields with Dotdigital

Retrieves contact data fields from Dotdigital.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/data-fields`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Contact Data Fields](https://developer.dotdigital.com/reference/get-contact-data-fields)
