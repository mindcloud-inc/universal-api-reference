# Get Public Lists with Dotdigital

Retrieves all public lists from Dotdigital.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/address-books/public`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Public Lists](https://developer.dotdigital.com/reference/get-public-address-books)

## Capabilities

This operation supports [pagination](../README.md#pagination).
