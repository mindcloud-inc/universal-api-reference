# Get Templates with Dotdigital

Retrieves email campaign templates from Dotdigital.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/templates`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Templates](https://developer.dotdigital.com/reference/get-templates)

## Capabilities

This operation supports [pagination](../README.md#pagination).
