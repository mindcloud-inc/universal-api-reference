# Get Program by ID with Dotdigital

Retrieves a program from Dotdigital by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/programs/:id`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Program by ID](https://developer.dotdigital.com/reference/get-program-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric identifier of the program. |
