# Get Template by ID with Dotdigital

Retrieves an email campaign template from Dotdigital by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/templates/:id`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Template by ID](https://developer.dotdigital.com/reference/get-template-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the email campaign template. |
