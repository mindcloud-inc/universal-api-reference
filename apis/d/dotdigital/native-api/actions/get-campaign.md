# Get Campaign with Dotdigital

Retrieves a campaign from Dotdigital by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/campaigns/:id`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Campaign](https://developer.dotdigital.com/reference/get-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the campaign. |
