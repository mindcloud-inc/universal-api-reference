# Get Campaign With Details with Dotdigital

Retrieves a campaign and its details from Dotdigital.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/campaigns/:id/with-details`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Campaign With Details](https://developer.dotdigital.com/reference/get-campaign-with-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the campaign. |
