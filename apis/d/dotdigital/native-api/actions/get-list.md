# Get List with Dotdigital

Retrieves a list from Dotdigital by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/address-books/:id`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get List](https://developer.dotdigital.com/reference/get-address-book)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the list or address book. |
