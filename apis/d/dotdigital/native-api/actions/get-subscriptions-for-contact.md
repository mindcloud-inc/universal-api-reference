# Get Subscriptions for Contact with Dotdigital

Retrieves subscriptions for a contact from Dotdigital.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/contacts/:email/subscriptions`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Subscriptions for Contact](https://developer.dotdigital.com/reference/get-subscriptions-for-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | path | `string` | yes |
