# Get Form by ID with Dotdigital

Retrieves a form from Dotdigital by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/surveys/:id`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Form by ID](https://developer.dotdigital.com/reference/get-form-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the form. |
