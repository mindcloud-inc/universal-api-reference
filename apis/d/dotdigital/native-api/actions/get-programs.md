# Get Programs with Dotdigital

Retrieves all account programs from Dotdigital.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/programs`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Programs](https://developer.dotdigital.com/reference/get-programs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
