# Get All Custom Identifiers with Dotdigital

Retrieves custom identifiers defined in Dotdigital.

## Endpoint

- **Method:** `GET`
- **Path:** `/configuration/v3/customIdentifiers`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get All Custom Identifiers](https://developer.dotdigital.com/reference/getcustomidentifiers)
