# Get Lists with Dotdigital

Retrieves all available lists from Dotdigital.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/address-books`
- **Base URL:** `https://r2-api.dotmailer.com`
- **Official documentation:** [Get Lists](https://developer.dotdigital.com/reference/get-address-books)

## Capabilities

This operation supports [pagination](../README.md#pagination).
