# Retrieve Classification Job with DocuPanda - Document Understanding

Retrieves a classification job from DocuPanda.

## Endpoint

- **Method:** `GET`
- **Path:** `/classify/:job_id`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve Classification Job](https://docs.docupipe.ai/openapi/docupanda.json)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `job_id` | path | `string` | yes |
