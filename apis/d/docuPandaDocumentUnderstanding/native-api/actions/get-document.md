# Retrieve a Processed Document with DocuPanda - Document Understanding

Retrieves a processed document from DocuPanda.

## Endpoint

- **Method:** `GET`
- **Path:** `/document/:document_id`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve a Processed Document](https://docs.docupipe.ai/reference/get_document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
