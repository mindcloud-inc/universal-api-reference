# Retrieve a Schema with DocuPanda - Document Understanding

Retrieves a schema from DocuPanda.

## Endpoint

- **Method:** `GET`
- **Path:** `/schema/:schema_id`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve a Schema](https://docs.docupipe.ai/reference/get_schema)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `schema_id` | path | `string` | yes |
