# Download Public URL with DocuPanda - Document Understanding

Retrieves a public document URL from DocuPanda.

## Endpoint

- **Method:** `GET`
- **Path:** `/document/:document_id/download/public-url`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Download Public URL](https://docs.docupipe.ai/reference/download_public_url)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
