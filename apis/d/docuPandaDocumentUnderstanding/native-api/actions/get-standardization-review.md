# Retrieve review by standardization ID with DocuPanda - Document Understanding

Retrieves a review by standardization ID from DocuPanda.

## Endpoint

- **Method:** `GET`
- **Path:** `/review`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve review by standardization ID](https://docs.docupipe.ai/reference/get_standardization_review)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `review_id` | query | `string` | no |
| `standardization_id` | query | `string` | no |
