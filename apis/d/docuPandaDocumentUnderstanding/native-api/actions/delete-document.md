# Delete a Document with DocuPanda - Document Understanding

Deletes an existing document from DocuPanda.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/document/:document_id`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Delete a Document](https://docs.docupipe.ai/reference/delete_document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
