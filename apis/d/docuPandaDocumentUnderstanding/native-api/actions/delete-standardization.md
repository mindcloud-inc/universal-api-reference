# Delete a Standardization with DocuPanda - Document Understanding

Deletes an existing standardization from DocuPanda.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/standardization/:standardization_id`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Delete a Standardization](https://docs.docupipe.ai/reference/delete_standardization)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `standardization_id` | path | `string` | yes |
