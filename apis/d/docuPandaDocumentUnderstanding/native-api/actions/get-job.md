# Retrieve a Job with DocuPanda - Document Understanding

Retrieves a job from DocuPanda.

## Endpoint

- **Method:** `GET`
- **Path:** `/job/:job_id`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve a Job](https://docs.docupipe.ai/reference/get_job)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `job_id` | path | `string` | yes |
