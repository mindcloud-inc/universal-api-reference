# Retrieve AutoGenerate Schema Job with DocuPanda - Document Understanding

Retrieves a schema generation job from DocuPanda.

## Endpoint

- **Method:** `GET`
- **Path:** `/schema/autogenerate/:job_id`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve AutoGenerate Schema Job](https://docs.docupipe.ai/openapi/docupanda.json)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `job_id` | path | `string` | yes |
