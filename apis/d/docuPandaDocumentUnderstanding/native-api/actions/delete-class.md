# Delete a Class with DocuPanda - Document Understanding

Deletes an existing class from DocuPanda.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/class/:class_id`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Delete a Class](https://docs.docupipe.ai/reference/delete_class)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `class_id` | path | `string` | yes |
