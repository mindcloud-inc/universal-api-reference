# Delete a Workflow with DocuPanda - Document Understanding

Deletes an existing workflow from DocuPanda.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workflow/:workflow_id`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Delete a Workflow](https://docs.docupipe.ai/reference/delete_workflow)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workflow_id` | path | `string` | yes |
