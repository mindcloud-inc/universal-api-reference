# Retrieve a Standardization JSON with DocuPanda - Document Understanding

Retrieves a standardization JSON result from DocuPanda.

## Endpoint

- **Method:** `GET`
- **Path:** `/standardization/:standardization_id`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve a Standardization JSON](https://docs.docupipe.ai/reference/get_standardization)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `standardization_id` | path | `string` | yes |
