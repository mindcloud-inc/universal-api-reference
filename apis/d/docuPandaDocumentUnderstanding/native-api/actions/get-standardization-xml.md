# Retrieve a Standardization XML with DocuPanda - Document Understanding

Retrieves a standardization XML result from DocuPanda.

## Endpoint

- **Method:** `GET`
- **Path:** `/standardization/:standardization_id/xml`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve a Standardization XML](https://docs.docupipe.ai/reference/get_standardization_xml)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `standardization_id` | path | `string` | yes |
