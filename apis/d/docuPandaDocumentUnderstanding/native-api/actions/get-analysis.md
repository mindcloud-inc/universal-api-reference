# Retrieve Analysis with DocuPanda - Document Understanding

Retrieves an analysis from DocuPanda.

## Endpoint

- **Method:** `GET`
- **Path:** `/analysis/:analysis_id`
- **Base URL:** `https://app.docupipe.ai`
- **Official documentation:** [Retrieve Analysis](https://docs.docupipe.ai/reference/get_analysis)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `analysis_id` | path | `string` | yes |
