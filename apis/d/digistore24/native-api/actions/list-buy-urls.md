# List Buy URLs with Digistore24

Retrieves a list of buy URLs from Digistore24.

## Endpoint

- **Method:** `GET`
- **Path:** `/listBuyUrls`
- **Base URL:** `https://www.digistore24.com/api/call`
- **Official documentation:** [List Buy URLs](https://digistore24.com/api/docs/paths/listBuyUrls.yaml)
