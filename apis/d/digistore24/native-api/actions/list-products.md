# List Products with Digistore24

Retrieves a list of products from Digistore24.

## Endpoint

- **Method:** `GET`
- **Path:** `/listProducts`
- **Base URL:** `https://www.digistore24.com/api/call`
- **Official documentation:** [List Products](https://digistore24.com/api/docs/paths/listProducts.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sort_by` | query | `string` | no | Sort products by name or product group |
