# List Invoices with Digistore24

Retrieves invoices for a Digistore24 purchase.

## Endpoint

- **Method:** `GET`
- **Path:** `/listInvoices`
- **Base URL:** `https://www.digistore24.com/api/call`
- **Official documentation:** [List Invoices](https://digistore24.com/api/docs/paths/listInvoices.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `purchase_id` | query | `string` | yes | Purchase ID |
