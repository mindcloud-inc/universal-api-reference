# Get Purchase with Digistore24

Retrieves detailed purchase data from Digistore24.

## Endpoint

- **Method:** `GET`
- **Path:** `/getPurchase`
- **Base URL:** `https://www.digistore24.com/api/call`
- **Official documentation:** [Get Purchase](https://digistore24.com/api/docs/paths/getPurchase.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `purchase_id` | query | `string` | yes | Purchase ID |
