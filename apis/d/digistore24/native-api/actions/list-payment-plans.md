# List Payment Plans with Digistore24

Retrieves payment plans for a Digistore24 product.

## Endpoint

- **Method:** `GET`
- **Path:** `/listPaymentPlans`
- **Base URL:** `https://www.digistore24.com/api/call`
- **Official documentation:** [List Payment Plans](https://digistore24.com/api/docs/paths/listPaymentPlans.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | query | `number` | yes | Product ID |
