# List Product Groups with Digistore24

Retrieves a list of product groups from Digistore24.

## Endpoint

- **Method:** `GET`
- **Path:** `/listProductGroups`
- **Base URL:** `https://www.digistore24.com/api/call`
- **Official documentation:** [List Product Groups](https://digistore24.com/api/docs/paths/listProductGroups.yaml)
