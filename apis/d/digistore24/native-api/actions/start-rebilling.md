# Start Rebilling with Digistore24

Resumes rebilling for a Digistore24 purchase.

## Endpoint

- **Method:** `POST`
- **Path:** `/startRebilling`
- **Base URL:** `https://www.digistore24.com/api/call`
- **Official documentation:** [Start Rebilling](https://digistore24.com/api/docs/paths/startRebilling.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `purchase_id` | query | `string` | yes | Purchase ID |
