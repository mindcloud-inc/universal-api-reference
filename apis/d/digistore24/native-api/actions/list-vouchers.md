# List Vouchers with Digistore24

Retrieves a list of voucher codes from Digistore24.

## Endpoint

- **Method:** `POST`
- **Path:** `/listVouchers`
- **Base URL:** `https://www.digistore24.com/api/call`
- **Official documentation:** [List Vouchers](https://digistore24.com/api/docs/paths/listVouchers.yaml)
