# List Lists with Doppler Marketing Automation

Retrieves lists from Doppler Marketing Automation.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountName/lists`
- **Base URL:** `https://restapi.fromdoppler.com`
- **Official documentation:** [List Lists](https://restapi.fromdoppler.com/docs/rels/get-list-collection)
