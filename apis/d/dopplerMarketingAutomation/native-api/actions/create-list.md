# Create List with Doppler Marketing Automation

Creates a new list in Doppler Marketing Automation.

## Endpoint

- **Method:** `POST`
- **Path:** `/accounts/:accountName/lists`
- **Base URL:** `https://restapi.fromdoppler.com`
- **Official documentation:** [Create List](https://restapi.fromdoppler.com/docs/rels/create-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name for the Doppler list. |
