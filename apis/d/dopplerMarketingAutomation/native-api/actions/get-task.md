# Get Task with Doppler Marketing Automation

Retrieves a task from Doppler Marketing Automation.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountName/tasks/:taskId`
- **Base URL:** `https://restapi.fromdoppler.com`
- **Official documentation:** [Get Task](https://restapi.fromdoppler.com/docs/rels/get-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | Doppler task identifier. |
