# Get Subscriber with Doppler Marketing Automation

Retrieves a subscriber from Doppler Marketing Automation.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountName/subscribers/:email`
- **Base URL:** `https://restapi.fromdoppler.com`
- **Official documentation:** [Get Subscriber](https://restapi.fromdoppler.com/docs/rels/get-subscriber)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Subscriber email address. |
