# Get List with Doppler Marketing Automation

Retrieves a list from Doppler Marketing Automation.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountName/lists/:listId`
- **Base URL:** `https://restapi.fromdoppler.com`
- **Official documentation:** [Get List](https://restapi.fromdoppler.com/docs/rels/get-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Doppler list identifier. |
