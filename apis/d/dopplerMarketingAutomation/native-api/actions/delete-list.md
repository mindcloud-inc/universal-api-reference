# Delete List with Doppler Marketing Automation

Deletes an existing list from Doppler Marketing Automation.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/accounts/:accountName/lists/:listId`
- **Base URL:** `https://restapi.fromdoppler.com`
- **Official documentation:** [Delete List](https://restapi.fromdoppler.com/docs/rels/delete-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Doppler list identifier. |
