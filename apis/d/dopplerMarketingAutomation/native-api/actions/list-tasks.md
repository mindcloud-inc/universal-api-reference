# List Tasks with Doppler Marketing Automation

Retrieves tasks from Doppler Marketing Automation.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountName/tasks`
- **Base URL:** `https://restapi.fromdoppler.com`
- **Official documentation:** [List Tasks](https://restapi.fromdoppler.com/docs/rels/get-task-collection)
