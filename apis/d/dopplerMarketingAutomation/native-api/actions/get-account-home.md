# Get Account Home with Doppler Marketing Automation

Retrieves account details from Doppler Marketing Automation.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountName`
- **Base URL:** `https://restapi.fromdoppler.com`
- **Official documentation:** [Get Account Home](https://restapi.fromdoppler.com/docs/rels/get-account-home)
