# List Fields with Doppler Marketing Automation

Retrieves fields from Doppler Marketing Automation.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountName/fields`
- **Base URL:** `https://restapi.fromdoppler.com`
- **Official documentation:** [List Fields](https://restapi.fromdoppler.com/docs/rels/get-field-collection)
