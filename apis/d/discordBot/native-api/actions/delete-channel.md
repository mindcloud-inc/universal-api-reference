# Delete Channel with Discord-Bot

Deletes or closes a Discord channel.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/channels/:channelId`
- **Base URL:** `https://discord.com/api/v10`
- **Official documentation:** [Delete Channel](https://docs.discord.com/developers/resources/channel#deleteclose-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | Discord channel ID. |
