# Get Guild with Discord-Bot

Retrieves a Discord guild by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/guilds/:guildId`
- **Base URL:** `https://discord.com/api/v10`
- **Official documentation:** [Get Guild](https://docs.discord.com/developers/resources/guild#get-guild)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guildId` | path | `string` | yes | Discord guild (server) ID. |
