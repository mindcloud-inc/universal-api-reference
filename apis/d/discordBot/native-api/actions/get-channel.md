# Get Channel with Discord-Bot

Retrieves a Discord channel by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels/:channelId`
- **Base URL:** `https://discord.com/api/v10`
- **Official documentation:** [Get Channel](https://docs.discord.com/developers/resources/channel#get-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | Discord channel ID. |
