# Get Balance with Dataway

Retrieves the current vendor balance from Dataway.

## Endpoint

- **Method:** `POST`
- **Path:** `/balance`
- **Base URL:** `https://datawayapp.com/vendor`
- **Official documentation:** [Get Balance](https://documenter.getpostman.com/view/421216/UV5Ukz4U)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `multipart/form-data` |
