# List Service Variations with Dataway

Retrieves service variations from Dataway for a selected service.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-service-variations`
- **Base URL:** `https://datawayapp.com/vendor`
- **Official documentation:** [List Service Variations](https://documenter.getpostman.com/view/421216/UV5Ukz4U)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `service_slug` | query | `string` | yes | Service slug, for example mtn-data. |
