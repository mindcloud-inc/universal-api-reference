# List Connected Postmaster Accounts with DMARC Report

Retrieves connected postmaster accounts from DMARC Report.

## Endpoint

- **Method:** `GET`
- **Path:** `/postmaster_account_records/connected.json`
- **Base URL:** `https://api.dmarcreport.com/v2`
- **Official documentation:** [List Connected Postmaster Accounts](https://docs.dmarcreport.com/api/2.0.html)
