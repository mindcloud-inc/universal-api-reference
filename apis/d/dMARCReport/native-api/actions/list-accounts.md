# List Accounts with DMARC Report

Retrieves accessible accounts from DMARC Report.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://api.dmarcreport.com/v2`
- **Official documentation:** [List Accounts](https://docs.dmarcreport.com/api/2.0.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
