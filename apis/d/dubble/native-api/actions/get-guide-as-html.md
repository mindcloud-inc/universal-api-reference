# Get Guide as HTML with Dubble

Retrieves a guide as HTML from Dubble.

## Endpoint

- **Method:** `GET`
- **Path:** `/guides/:guideId/html`
- **Base URL:** `https://api.dubble.so/v1`
- **Official documentation:** [Get Guide as HTML](https://dubble.readme.io/reference/getguidehtml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guideId` | path | `string` | yes | The ID of the guide |
