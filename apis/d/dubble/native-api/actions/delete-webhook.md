# Delete Webhook with Dubble

Deletes an existing webhook from Dubble.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://api.dubble.so/v1`
- **Official documentation:** [Delete Webhook](https://dubble.readme.io/reference/deletewebhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | no | The ID of the webhook |
