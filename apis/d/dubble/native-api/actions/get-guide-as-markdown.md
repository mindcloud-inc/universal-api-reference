# Get Guide as Markdown with Dubble

Retrieves a guide as Markdown from Dubble.

## Endpoint

- **Method:** `GET`
- **Path:** `/guides/:guideId/markdown`
- **Base URL:** `https://api.dubble.so/v1`
- **Official documentation:** [Get Guide as Markdown](https://dubble.readme.io/reference/getguidemarkdown)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guideId` | path | `string` | yes | The ID of the guide |
