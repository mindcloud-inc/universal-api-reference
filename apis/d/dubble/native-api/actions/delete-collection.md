# Delete Collection with Dubble

Deletes an existing collection from Dubble.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/collections/:collectionId`
- **Base URL:** `https://api.dubble.so/v1`
- **Official documentation:** [Delete Collection](https://dubble.readme.io/reference/deletecollection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | The ID of the collection |
