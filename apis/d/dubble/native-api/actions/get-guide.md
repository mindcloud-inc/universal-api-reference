# Get Guide with Dubble

Retrieves details for a guide from Dubble.

## Endpoint

- **Method:** `GET`
- **Path:** `/guides/:guideId`
- **Base URL:** `https://api.dubble.so/v1`
- **Official documentation:** [Get Guide](https://dubble.readme.io/reference/getguide)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guideId` | path | `string` | yes | The ID of the guide |
