# Get Webhook with DocDroid

Retrieves a webhook from DocDroid by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook/:id`
- **Base URL:** `https://www.docdroid.com/api`
- **Official documentation:** [Get Webhook](https://www.docdroid.com/apidocs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the webhook. |
