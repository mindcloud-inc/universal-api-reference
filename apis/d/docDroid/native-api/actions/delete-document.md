# Delete Document with DocDroid

Deletes an existing document from DocDroid.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/document/:id`
- **Base URL:** `https://www.docdroid.com/api`
- **Official documentation:** [Delete Document](https://www.docdroid.com/apidocs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the document. |
