# List My Documents with DocDroid

Retrieves your uploaded documents from DocDroid.

## Endpoint

- **Method:** `GET`
- **Path:** `/document`
- **Base URL:** `https://www.docdroid.com/api`
- **Official documentation:** [List My Documents](https://www.docdroid.com/apidocs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
