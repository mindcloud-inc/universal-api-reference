# Delete Webhook with DocDroid

Deletes an existing webhook from DocDroid.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhook/:id`
- **Base URL:** `https://www.docdroid.com/api`
- **Official documentation:** [Delete Webhook](https://www.docdroid.com/apidocs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the webhook. |
