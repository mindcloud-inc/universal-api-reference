# Get Document with DocDroid

Retrieves a document from DocDroid by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/document/:id`
- **Base URL:** `https://www.docdroid.com/api`
- **Official documentation:** [Get Document](https://www.docdroid.com/apidocs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the document. |
