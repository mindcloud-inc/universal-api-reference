# List NDCs with DailyMed

Retrieves NDCs from DailyMed.

## Endpoint

- **Method:** `GET`
- **Path:** `/ndcs.json`
- **Base URL:** `https://dailymed.nlm.nih.gov/dailymed/services/v2`
- **Official documentation:** [List NDCs](https://dailymed.nlm.nih.gov/dailymed/webservices-help/v2/ndcs_api.cfm)

## Capabilities

This operation supports [pagination](../README.md#pagination).
