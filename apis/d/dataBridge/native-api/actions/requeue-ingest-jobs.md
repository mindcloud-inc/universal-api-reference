# Requeue Ingest Jobs with DataBridge

Requeues document ingest jobs in DataBridge.

## Endpoint

- **Method:** `POST`
- **Path:** `/ingest/requeue`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Requeue Ingest Jobs](https://www.morphik.ai/docs/api-reference/getting-started)
