# Get Auth Status For Connector with DataBridge

Retrieves connector auth status from DataBridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/ee/connectors/:connector_type/auth_status`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Get Auth Status For Connector](https://www.morphik.ai/docs/api-reference/getting-started)
