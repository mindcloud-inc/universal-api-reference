# Ingest Repository with DataBridge

Ingests an entire GitHub repository into DataBridge.

## Endpoint

- **Method:** `POST`
- **Path:** `/ee/connectors/:connector_type/ingest-repository`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Ingest Repository](https://www.morphik.ai/docs/api-reference/getting-started)
