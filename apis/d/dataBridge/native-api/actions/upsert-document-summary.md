# Upsert Document Summary with DataBridge

Creates or updates a document summary in DataBridge.

## Endpoint

- **Method:** `PUT`
- **Path:** `/documents/:document_id/summary`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Upsert Document Summary](https://www.morphik.ai/docs/api-reference/getting-started)
