# Connector Oauth Callback with DataBridge

Handles a connector OAuth callback in DataBridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/ee/connectors/:connector_type/oauth2callback`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Connector Oauth Callback](https://www.morphik.ai/docs/api-reference/getting-started)
