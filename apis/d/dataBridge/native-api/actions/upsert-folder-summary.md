# Upsert Folder Summary with DataBridge

Creates or updates a folder summary in DataBridge.

## Endpoint

- **Method:** `PUT`
- **Path:** `/folders/:folder_id_or_name/summary`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Upsert Folder Summary](https://www.morphik.ai/docs/api-reference/getting-started)
