# List Docs (Legacy Route) with DataBridge

Retrieves documents from DataBridge using the legacy route.

## Endpoint

- **Method:** `POST`
- **Path:** `/documents/list_docs`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [List Docs (Legacy Route)](https://www.morphik.ai/docs/api-reference/getting-started)
