# Add Document To Folder with DataBridge

Adds a document to a folder in DataBridge.

## Endpoint

- **Method:** `POST`
- **Path:** `/folders/:folder_id_or_name/documents/:document_id`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Add Document To Folder](https://www.morphik.ai/docs/api-reference/getting-started)
