# Ingest Connector File with DataBridge

Ingests a single file from a connector in DataBridge.

## Endpoint

- **Method:** `POST`
- **Path:** `/ee/connectors/:connector_type/ingest`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Ingest Connector File](https://www.morphik.ai/docs/api-reference/getting-started)
