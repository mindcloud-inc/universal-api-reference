# Remove Document From Folder with DataBridge

Removes a document from a folder in DataBridge.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/folders/:folder_id_or_name/documents/:document_id`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Remove Document From Folder](https://www.morphik.ai/docs/api-reference/getting-started)
