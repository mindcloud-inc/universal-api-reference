# Initiate Auth with DataBridge

Initiates the OAuth flow for a connector in DataBridge.

## Endpoint

- **Method:** `POST`
- **Path:** `/ee/connectors/initiate-auth`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Initiate Auth](https://www.morphik.ai/docs/api-reference/getting-started)
