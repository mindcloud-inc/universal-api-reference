# Get Folder Summary with DataBridge

Retrieves a folder summary from DataBridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders/:folder_id_or_name/summary`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Get Folder Summary](https://www.morphik.ai/docs/api-reference/getting-started)
