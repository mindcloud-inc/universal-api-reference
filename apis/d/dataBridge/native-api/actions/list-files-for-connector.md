# List Files For Connector with DataBridge

Retrieves files and folders for a connector in DataBridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/ee/connectors/:connector_type/files`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [List Files For Connector](https://www.morphik.ai/docs/api-reference/getting-started)
