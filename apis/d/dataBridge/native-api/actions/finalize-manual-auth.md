# Finalize Manual Auth with DataBridge

Finalizes connector authentication manually in DataBridge.

## Endpoint

- **Method:** `POST`
- **Path:** `/ee/connectors/:connector_type/auth/finalize`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Finalize Manual Auth](https://www.morphik.ai/docs/api-reference/getting-started)
