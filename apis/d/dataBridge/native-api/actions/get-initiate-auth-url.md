# Get Initiate Auth Url with DataBridge

Retrieves a connector auth URL from DataBridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/ee/connectors/:connector_type/auth/initiate_url`
- **Base URL:** `https://api.morphik.ai`
- **Official documentation:** [Get Initiate Auth Url](https://www.morphik.ai/docs/api-reference/getting-started)
