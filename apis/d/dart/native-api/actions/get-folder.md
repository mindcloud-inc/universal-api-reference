# Get Folder with Dart

Retrieves a folder record from Dart.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders/:id`
- **Base URL:** `https://app.dartai.com/api/v0/public`
- **Official documentation:** [Get Folder](https://app.dartai.com/api/v0/public/docs/#/Folder/getFolder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
