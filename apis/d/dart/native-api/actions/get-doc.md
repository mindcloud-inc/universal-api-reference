# Get Doc with Dart

Retrieves a doc record from Dart.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/:id`
- **Base URL:** `https://app.dartai.com/api/v0/public`
- **Official documentation:** [Get Doc](https://app.dartai.com/api/v0/public/docs/#/Doc/getDoc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
