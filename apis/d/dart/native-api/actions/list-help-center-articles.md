# List Help Center Articles with Dart

Retrieves help center articles from Dart.

## Endpoint

- **Method:** `GET`
- **Path:** `/help-center-articles/list`
- **Base URL:** `https://app.dartai.com/api/v0/public`
- **Official documentation:** [List Help Center Articles](https://app.dartai.com/api/v0/public/docs/#/Help%20center%20article/listHelpCenterArticles)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | query | `string` | no |
