# Create Doc with Dart

Creates a new doc in Dart.

## Endpoint

- **Method:** `POST`
- **Path:** `/docs`
- **Base URL:** `https://app.dartai.com/api/v0/public`
- **Official documentation:** [Create Doc](https://app.dartai.com/api/v0/public/docs/#/Doc/createDoc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `item.folder` | body | `string` | no |
| `item.text` | body | `string` | no |
| `item.title` | body | `string` | no |
