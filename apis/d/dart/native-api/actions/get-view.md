# Get View with Dart

Retrieves a view record from Dart.

## Endpoint

- **Method:** `GET`
- **Path:** `/views/:id`
- **Base URL:** `https://app.dartai.com/api/v0/public`
- **Official documentation:** [Get View](https://app.dartai.com/api/v0/public/docs/#/View/getView)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
