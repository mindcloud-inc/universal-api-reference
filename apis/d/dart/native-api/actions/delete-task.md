# Delete Task with Dart

Deletes an existing task from Dart.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/:id`
- **Base URL:** `https://app.dartai.com/api/v0/public`
- **Official documentation:** [Delete Task](https://app.dartai.com/api/v0/public/docs/#/Task/deleteTask)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
