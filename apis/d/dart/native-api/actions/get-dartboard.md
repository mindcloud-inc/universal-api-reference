# Get Dartboard with Dart

Retrieves a dartboard record from Dart.

## Endpoint

- **Method:** `GET`
- **Path:** `/dartboards/:id`
- **Base URL:** `https://app.dartai.com/api/v0/public`
- **Official documentation:** [Get Dartboard](https://app.dartai.com/api/v0/public/docs/#/Dartboard/getDartboard)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
