# Delete Doc with Dart

Deletes an existing doc from Dart.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/docs/:id`
- **Base URL:** `https://app.dartai.com/api/v0/public`
- **Official documentation:** [Delete Doc](https://app.dartai.com/api/v0/public/docs/#/Doc/deleteDoc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
