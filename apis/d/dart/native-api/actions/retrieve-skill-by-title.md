# Retrieve Skill by Title with Dart

Retrieves a skill from Dart by title.

## Endpoint

- **Method:** `GET`
- **Path:** `/skills/by-title`
- **Base URL:** `https://app.dartai.com/api/v0/public`
- **Official documentation:** [Retrieve Skill by Title](https://app.dartai.com/api/v0/public/docs/#/Skill/retrieveSkillByTitle)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `title` | query | `string` | no |
