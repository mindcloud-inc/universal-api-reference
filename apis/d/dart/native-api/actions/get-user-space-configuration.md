# Get User Space Configuration with Dart

Retrieves user space configuration details from Dart.

## Endpoint

- **Method:** `GET`
- **Path:** `/config`
- **Base URL:** `https://app.dartai.com/api/v0/public`
- **Official documentation:** [Get User Space Configuration](https://app.dartai.com/api/v0/public/docs/#/Config/getConfig)
