# Get Task with Dart

Retrieves a task record from Dart.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://app.dartai.com/api/v0/public`
- **Official documentation:** [Get Task](https://app.dartai.com/api/v0/public/docs/#/Task/getTask)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
