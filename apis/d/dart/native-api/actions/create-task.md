# Create Task with Dart

Creates a new task in Dart.

## Endpoint

- **Method:** `POST`
- **Path:** `/tasks`
- **Base URL:** `https://app.dartai.com/api/v0/public`
- **Official documentation:** [Create Task](https://app.dartai.com/api/v0/public/docs/#/Task/createTask)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `item.assignee` | body | `string` | no |
| `item.dartboard` | body | `string` | no |
| `item.description` | body | `string` | no |
| `item.dueAt` | body | `string` | no |
| `item.priority` | body | `string` | no |
| `item.startAt` | body | `string` | no |
| `item.status` | body | `string` | no |
| `item.tags` | body | `string` | no |
| `item.title` | body | `string` | no |
| `item.type` | body | `string` | no |
