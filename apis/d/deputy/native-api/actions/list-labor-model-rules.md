# List Labor Model Rules with Deputy

Retrieves labor model rules from Deputy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/labor-model/location/:locationId/rules`
- **Base URL:** `https://{endpoint}.deputy.com`
- **Official documentation:** [List Labor Model Rules](https://developer.deputy.com/docs/retrieving-the-list-of-existing-labor-model-rules)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locationId` | path | `number` | yes | Deputy location ID. |
