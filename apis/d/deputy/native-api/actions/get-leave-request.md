# Get Leave Request with Deputy

Retrieves a single leave request from Deputy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/resource/Leave/:id`
- **Base URL:** `https://{endpoint}.deputy.com`
- **Official documentation:** [Get Leave Request](https://developer.deputy.com/docs/leave)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Leave request ID from Deputy. |
