# List Employee Pay Conditions with Deputy

Retrieves employee pay conditions from Deputy.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/resource/EmployeeAgreement/QUERY`
- **Base URL:** `https://{endpoint}.deputy.com`
- **Official documentation:** [List Employee Pay Conditions](https://developer.deputy.com/docs/retrieving-an-employees-pay-conditions)
