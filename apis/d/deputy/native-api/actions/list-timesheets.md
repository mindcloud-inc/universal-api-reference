# List Timesheets with Deputy

Retrieves the timesheet list from Deputy.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/resource/Timesheet/QUERY`
- **Base URL:** `https://{endpoint}.deputy.com`
- **Official documentation:** [List Timesheets](https://developer.deputy.com/docs/retrieving-timesheets-from-deputy)
