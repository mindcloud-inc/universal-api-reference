# Get Contact with Deputy

Retrieves a single contact from Deputy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/resource/Contact/:id`
- **Base URL:** `https://{endpoint}.deputy.com`
- **Official documentation:** [Get Contact](https://developer.deputy.com/docs/contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Contact ID from Deputy. |
