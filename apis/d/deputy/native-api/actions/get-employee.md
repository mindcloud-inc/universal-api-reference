# Get Employee with Deputy

Retrieves a single employee from Deputy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/resource/Employee/:id`
- **Base URL:** `https://{endpoint}.deputy.com`
- **Official documentation:** [Get Employee](https://developer.deputy.com/docs/employee)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Employee ID from Deputy. |
