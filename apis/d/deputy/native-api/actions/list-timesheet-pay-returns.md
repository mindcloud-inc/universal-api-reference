# List Timesheet Pay Returns with Deputy

Retrieves timesheet pay returns from Deputy.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/resource/TimesheetPayReturn/QUERY`
- **Base URL:** `https://{endpoint}.deputy.com`
- **Official documentation:** [List Timesheet Pay Returns](https://developer.deputy.com/docs/retrieving-timesheets-from-deputy)
