# List Countries with Deputy

Retrieves the country list from Deputy.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/resource/Country/QUERY`
- **Base URL:** `https://{endpoint}.deputy.com`
- **Official documentation:** [List Countries](https://developer.deputy.com/docs/retrieving-state-and-country-ids-for-use-with-the-deputy-api)
