# List States with Deputy

Retrieves the state list from Deputy.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/resource/State/QUERY`
- **Base URL:** `https://{endpoint}.deputy.com`
- **Official documentation:** [List States](https://developer.deputy.com/docs/retrieving-state-and-country-ids-for-use-with-the-deputy-api)
