# Get Custom Field with Deputy

Retrieves a single custom field from Deputy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/resource/CustomField/:id`
- **Base URL:** `https://{endpoint}.deputy.com`
- **Official documentation:** [Get Custom Field](https://developer.deputy.com/docs/customfield)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Custom field ID from Deputy. |
