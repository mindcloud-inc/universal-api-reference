# Get Timesheet Details with Deputy

Retrieves detailed timesheet data from Deputy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/supervise/timesheet/:id/details`
- **Base URL:** `https://{endpoint}.deputy.com`
- **Official documentation:** [Get Timesheet Details](https://developer.deputy.com/docs/timesheet-management-calls)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Timesheet ID from Deputy. |
