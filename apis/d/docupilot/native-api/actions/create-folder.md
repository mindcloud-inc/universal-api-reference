# Create Folder with Docupilot

Creates a folder in Docupilot.

## Endpoint

- **Method:** `POST`
- **Path:** `/dashboard/api/v2/folders/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [Create Folder](https://help.docupilot.app/developers/folders-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
