# List Template Merge Links with Docupilot

Retrieves template merge links from Docupilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboard/api/v2/templates/{template_id}/merge_links/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [List Template Merge Links](https://help.docupilot.app/developers/templates-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `number` | yes |
