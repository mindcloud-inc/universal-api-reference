# Get Current Workspace with Docupilot

Retrieves current workspace details from Docupilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboard/accounts/v2/workspaces/current/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [Get Current Workspace](https://help.docupilot.app/developers/api-overview)
