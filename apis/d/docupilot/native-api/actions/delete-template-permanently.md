# Delete Template Permanently with Docupilot

Permanently deletes a trashed template from Docupilot.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/dashboard/api/v2/templates/{id}/permanent_delete/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [Delete Template Permanently](https://help.docupilot.app/developers/templates-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
