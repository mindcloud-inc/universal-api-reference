# Restore Template From Trash with Docupilot

Restores a template from trash in Docupilot.

## Endpoint

- **Method:** `PUT`
- **Path:** `/dashboard/api/v2/templates/{id}/restore/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [Restore Template From Trash](https://help.docupilot.app/developers/templates-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
