# Get Content Block with Docupilot

Retrieves a content block from Docupilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboard/api/v2/content_blocks/{id}/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [Get Content Block](https://help.docupilot.app/developers/templates-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
