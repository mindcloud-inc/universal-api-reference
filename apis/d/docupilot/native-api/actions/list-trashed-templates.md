# List Trashed Templates with Docupilot

Retrieves trashed templates from Docupilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboard/api/v2/templates/trash/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [List Trashed Templates](https://help.docupilot.app/developers/templates-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | A page number within the paginated result set. |
