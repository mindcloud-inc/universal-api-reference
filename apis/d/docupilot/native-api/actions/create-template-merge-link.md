# Create Template Merge Link with Docupilot

Creates a template merge link in Docupilot.

## Endpoint

- **Method:** `POST`
- **Path:** `/dashboard/api/v2/templates/{template_id}/merge_links/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [Create Template Merge Link](https://help.docupilot.app/developers/templates-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `string` | yes |
