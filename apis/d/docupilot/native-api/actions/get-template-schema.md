# Get Template Schema with Docupilot

Retrieves a template schema from Docupilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboard/api/v2/templates/{id}/schema/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [Get Template Schema](https://help.docupilot.app/developers/templates-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
