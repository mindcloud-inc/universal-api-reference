# Get Template Test Data with Docupilot

Retrieves template test data from Docupilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboard/api/v2/templates/{id}/test_data/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [Get Template Test Data](https://help.docupilot.app/developers/templates-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
