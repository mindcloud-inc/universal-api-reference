# Get Template with Docupilot

Retrieves a template from Docupilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboard/api/v2/templates/{id}/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [Get Template](https://help.docupilot.app/developers/templates-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
