# Delete Template Merge Link with Docupilot

Deletes a template merge link from Docupilot.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/dashboard/api/v2/templates/{template_id}/merge_links/{id}/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [Delete Template Merge Link](https://help.docupilot.app/developers/templates-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `template_id` | path | `string` | yes |
