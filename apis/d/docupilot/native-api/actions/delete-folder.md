# Delete Folder with Docupilot

Deletes an existing folder from Docupilot.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/dashboard/api/v2/folders/{id}/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [Delete Folder](https://help.docupilot.app/developers/folders-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
