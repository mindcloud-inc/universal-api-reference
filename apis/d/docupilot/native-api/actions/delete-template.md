# Delete Template with Docupilot

Moves a template to trash in Docupilot.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/dashboard/api/v2/templates/{id}/`
- **Base URL:** `https://api.docupilot.app`
- **Official documentation:** [Delete Template](https://help.docupilot.app/developers/templates-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
