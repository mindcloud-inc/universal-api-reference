# Get Screenshot with Diffy

Retrieves a single screenshot from Diffy.

## Endpoint

- **Method:** `GET`
- **Path:** `/snapshots/:id`
- **Base URL:** `https://app.diffy.website/api`
- **Official documentation:** [Get Screenshot](https://app.diffy.website/rest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Screenshot ID. |
