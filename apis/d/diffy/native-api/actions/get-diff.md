# Get Diff with Diffy

Retrieves a single diff from Diffy.

## Endpoint

- **Method:** `GET`
- **Path:** `/diffs/:id`
- **Base URL:** `https://app.diffy.website/api`
- **Official documentation:** [Get Diff](https://app.diffy.website/rest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Diff ID. |
