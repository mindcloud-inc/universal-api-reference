# Delete Screenshot with Diffy

Deletes an existing screenshot from Diffy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/snapshots/:id`
- **Base URL:** `https://app.diffy.website/api`
- **Official documentation:** [Delete Screenshot](https://app.diffy.website/rest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Screenshot ID. |
