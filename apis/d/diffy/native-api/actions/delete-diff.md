# Delete Diff with Diffy

Deletes an existing diff from Diffy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/diffs/:id`
- **Base URL:** `https://app.diffy.website/api`
- **Official documentation:** [Delete Diff](https://app.diffy.website/rest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Diff ID. |
