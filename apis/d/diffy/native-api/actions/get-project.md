# Get Project with Diffy

Retrieves a single project from Diffy.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://app.diffy.website/api`
- **Official documentation:** [Get Project](https://app.diffy.website/rest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Project ID. |
