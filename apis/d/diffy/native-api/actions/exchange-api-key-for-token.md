# Exchange API Key for Token with Diffy

Creates an access token in Diffy.

## Endpoint

- **Method:** `POST`
- **Path:** `/auth/key`
- **Base URL:** `https://app.diffy.website/api`
- **Official documentation:** [Exchange API Key for Token](https://app.diffy.website/rest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | body | `string` | yes | Diffy API key used for the /auth/key login exchange. |
