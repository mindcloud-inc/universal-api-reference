# Search Work Items with Datastreamer

## Endpoint

- **Method:** `POST`
- **Path:** `/api/pipelines/work-items/search`
- **Base URL:** `https://api.platform.datastreamer.io`
- **Official documentation:** [Search Work Items](https://docs.datastreamer.io/docs/searching-work-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `object` | yes | Search request payload for work items. |
