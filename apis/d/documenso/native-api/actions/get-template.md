# Get Template with Documenso

Retrieves a template from Documenso.

## Endpoint

- **Method:** `GET`
- **Path:** `/template/:templateId`
- **Base URL:** `https://app.documenso.com/api/v2`
- **Official documentation:** [Get Template](https://docs.documenso.com/docs/developers/api/templates)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `templateId` | path | `number` | yes |
