# Get Document with Documenso

Retrieves a document from Documenso.

## Endpoint

- **Method:** `GET`
- **Path:** `/envelope/:envelopeId`
- **Base URL:** `https://app.documenso.com/api/v2`
- **Official documentation:** [Get Document](https://docs.documenso.com/docs/developers/api/documents)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `envelopeId` | path | `string` | yes |
