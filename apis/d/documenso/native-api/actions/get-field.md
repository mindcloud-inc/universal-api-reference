# Get Field with Documenso

Retrieves a field from Documenso.

## Endpoint

- **Method:** `GET`
- **Path:** `/envelope/field/:fieldId`
- **Base URL:** `https://app.documenso.com/api/v2`
- **Official documentation:** [Get Field](https://docs.documenso.com/docs/developers/api/fields)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fieldId` | path | `number` | yes |
