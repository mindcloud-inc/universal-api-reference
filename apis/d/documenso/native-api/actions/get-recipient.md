# Get Recipient with Documenso

Retrieves a recipient from Documenso.

## Endpoint

- **Method:** `GET`
- **Path:** `/envelope/recipient/:recipientId`
- **Base URL:** `https://app.documenso.com/api/v2`
- **Official documentation:** [Get Recipient](https://docs.documenso.com/docs/developers/api/recipients)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `recipientId` | path | `number` | yes |
