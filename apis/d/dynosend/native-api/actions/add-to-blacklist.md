# Add to Blacklist with Dynosend

Adds a contact to the Dynosend blacklist.

## Endpoint

- **Method:** `POST`
- **Path:** `/blacklist/add`
- **Base URL:** `https://api.dynosend.com/api/v2`
- **Official documentation:** [Add to Blacklist](https://developers.dynosend.com/#addtoblacklist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | The email address to add to the blacklist. |
