# Resume Campaign with Dynosend

Resumes a campaign in Dynosend.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/resume`
- **Base URL:** `https://api.dynosend.com/api/v2`
- **Official documentation:** [Resume Campaign](https://developers.dynosend.com/#resumeacampaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_uid` | body | `string` | yes | The UID of the campaign to resume. |
