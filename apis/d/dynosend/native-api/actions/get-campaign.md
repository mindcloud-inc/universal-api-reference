# Get Campaign with Dynosend

Retrieves a campaign from Dynosend.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://api.dynosend.com/api/v2`
- **Official documentation:** [Get Campaign](https://developers.dynosend.com/#getacampaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_uid` | query | `string` | yes | The UID of the campaign to fetch. |
