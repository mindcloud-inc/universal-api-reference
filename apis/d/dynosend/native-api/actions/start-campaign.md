# Start Campaign with Dynosend

Starts a campaign in Dynosend.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/start`
- **Base URL:** `https://api.dynosend.com/api/v2`
- **Official documentation:** [Start Campaign](https://developers.dynosend.com/#startacampaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_uid` | body | `string` | yes | The UID of the campaign to start. |
