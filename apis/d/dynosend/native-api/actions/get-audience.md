# Get Audience with Dynosend

Retrieves an audience from Dynosend.

## Endpoint

- **Method:** `GET`
- **Path:** `/audiences`
- **Base URL:** `https://api.dynosend.com/api/v2`
- **Official documentation:** [Get Audience](https://developers.dynosend.com/#getanaudience)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audience_uid` | query | `string` | yes | The UID of the audience to fetch. |
