# List Use Cases with Datarobot

Retrieves a list of use cases from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/useCases/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [List Use Cases](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
