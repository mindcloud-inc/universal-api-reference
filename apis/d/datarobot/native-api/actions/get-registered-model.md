# Get Registered Model with Datarobot

Retrieves details for a registered model from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/registeredModels/:registeredModelId/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [Get Registered Model](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `registeredModelId` | path | `string` | yes | The ID of the registered model. |
