# Get Deployment with Datarobot

Retrieves details for a deployment from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/deployments/:deploymentId/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [Get Deployment](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deploymentId` | path | `string` | yes | The unique identifier of the deployment. |
