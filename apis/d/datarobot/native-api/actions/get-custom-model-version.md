# Get Custom Model Version with Datarobot

Retrieves details for a custom model version from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/customModels/:customModelId/versions/:customModelVersionId/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [Get Custom Model Version](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customModelId` | path | `string` | yes |
| `customModelVersionId` | path | `string` | yes |
