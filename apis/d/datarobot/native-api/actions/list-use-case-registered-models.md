# List Use Case Registered Models with Datarobot

Retrieves registered models for a use case from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/useCases/:useCaseId/registeredModels/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [List Use Case Registered Models](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `useCaseId` | path | `string` | yes |
