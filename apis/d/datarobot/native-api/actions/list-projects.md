# List Projects with Datarobot

Retrieves a list of projects from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [List Projects](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
