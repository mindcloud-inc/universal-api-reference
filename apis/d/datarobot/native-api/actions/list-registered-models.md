# List Registered Models with Datarobot

Retrieves a list of registered models from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/registeredModels/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [List Registered Models](https://docs.datarobot.com/en/docs/api/reference/index.html)
