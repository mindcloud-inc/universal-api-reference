# List Dataset Projects with Datarobot

Retrieves projects for a dataset from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasets/:datasetId/projects/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [List Dataset Projects](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | The ID of the dataset. |
