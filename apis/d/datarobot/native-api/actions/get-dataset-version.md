# Get Dataset Version with Datarobot

Retrieves details for a dataset version from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasets/:datasetId/versions/:datasetVersionId/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [Get Dataset Version](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `datasetId` | path | `string` | yes |
| `datasetVersionId` | path | `string` | yes |
