# List Use Case Datasets with Datarobot

Retrieves datasets for a use case from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/useCases/:useCaseId/datasets/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [List Use Case Datasets](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `useCaseId` | path | `string` | yes |
