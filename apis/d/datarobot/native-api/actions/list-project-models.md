# List Project Models with Datarobot

Retrieves models for a project from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/models/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [List Project Models](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The project ID. |
