# Get Registered Model Version with Datarobot

Retrieves details for a registered model version from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/registeredModels/:registeredModelId/versions/:versionId/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [Get Registered Model Version](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `registeredModelId` | path | `string` | yes |
| `versionId` | path | `string` | yes |
