# Get Custom Model with Datarobot

Retrieves details for a custom model from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/customModels/:customModelId/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [Get Custom Model](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customModelId` | path | `string` | yes | The ID of the custom model. |
