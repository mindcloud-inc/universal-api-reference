# List Custom Model Versions with Datarobot

Retrieves versions for a custom model from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/customModels/:customModelId/versions/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [List Custom Model Versions](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customModelId` | path | `string` | yes |
