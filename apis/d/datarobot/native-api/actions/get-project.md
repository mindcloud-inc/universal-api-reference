# Get Project with Datarobot

Retrieves details for a project from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [Get Project](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The project ID. |
