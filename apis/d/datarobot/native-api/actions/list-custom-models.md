# List Custom Models with Datarobot

Retrieves a list of custom models from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/customModels/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [List Custom Models](https://docs.datarobot.com/en/docs/api/reference/index.html)
