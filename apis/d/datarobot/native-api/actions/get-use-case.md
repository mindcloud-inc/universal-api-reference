# Get Use Case with Datarobot

Retrieves details for a use case from Datarobot.

## Endpoint

- **Method:** `GET`
- **Path:** `/useCases/:useCaseId/`
- **Base URL:** `https://app.datarobot.com/api/v2`
- **Official documentation:** [Get Use Case](https://docs.datarobot.com/en/docs/api/reference/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `useCaseId` | path | `string` | yes | The ID of the use case. |
