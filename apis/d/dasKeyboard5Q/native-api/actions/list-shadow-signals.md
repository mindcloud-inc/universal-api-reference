# List Shadow Signals with Das Keyboard 5Q

Retrieves shadow signals from Das Keyboard 5Q.

## Endpoint

- **Method:** `GET`
- **Path:** `/signals/shadows`
- **Base URL:** `https://q2.daskeyboard.com/api/1.0`
- **Official documentation:** [List Shadow Signals](https://www.daskeyboard.io/api-ressources/signal/get-all-shadow-signals/)
