# Delete Signal with Das Keyboard 5Q

Deletes a signal from Das Keyboard 5Q.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/signals/:id`
- **Base URL:** `https://q2.daskeyboard.com/api/1.0`
- **Official documentation:** [Delete Signal](https://www.daskeyboard.io/api-ressources/signal/delete-signal/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the signal to delete. |
