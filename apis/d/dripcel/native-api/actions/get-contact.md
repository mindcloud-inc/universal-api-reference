# Get Contact with Dripcel

Retrieves a contact from Dripcel by cell number.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:cell`
- **Base URL:** `https://api.dripcel.com`
- **Official documentation:** [Get Contact](https://docs.dripcel.com/API/contacts#get-a-single-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cell` | path | `string` | yes |
