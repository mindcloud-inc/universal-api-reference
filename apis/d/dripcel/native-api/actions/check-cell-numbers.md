# Check Cell Numbers with Dripcel

Checks whether cell numbers can receive a Dripcel campaign.

## Endpoint

- **Method:** `POST`
- **Path:** `/compliance/send`
- **Base URL:** `https://api.dripcel.com`
- **Official documentation:** [Check Cell Numbers](https://docs.dripcel.com/API/compliance#check-a-list-of-cell-numbers)
