# Get Campaign with Dripcel

Retrieves a campaign from Dripcel by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaign_id`
- **Base URL:** `https://api.dripcel.com`
- **Official documentation:** [Get Campaign](https://docs.dripcel.com/API/campaigns#view-a-single-campaign)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes |
