# Get Send Log with Dripcel

Retrieves a send log from Dripcel by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/send-logs/:send_id`
- **Base URL:** `https://api.dripcel.com`
- **Official documentation:** [Get Send Log](https://docs.dripcel.com/API/send-logs#view-a-single-send-log)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `send_id` | path | `string` | yes |
