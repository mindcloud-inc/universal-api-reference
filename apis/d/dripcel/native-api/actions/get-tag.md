# Get Tag with Dripcel

Retrieves a tag from Dripcel by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:tag_id`
- **Base URL:** `https://api.dripcel.com`
- **Official documentation:** [Get Tag](https://docs.dripcel.com/API/tags#view-a-single-tag)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tag_id` | path | `string` | yes |
