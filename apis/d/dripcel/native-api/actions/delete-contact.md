# Delete Contact with Dripcel

Deletes a contact from Dripcel by cell number.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:cell`
- **Base URL:** `https://api.dripcel.com`
- **Official documentation:** [Delete Contact](https://docs.dripcel.com/API/contacts#delete-a-single-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cell` | path | `string` | yes |
