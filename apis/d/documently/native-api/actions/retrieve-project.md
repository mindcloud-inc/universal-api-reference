# Retrieve Project with Documently

Retrieves a project from Documently.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [Retrieve Project](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | no | The project id. |
