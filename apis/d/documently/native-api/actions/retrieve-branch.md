# Retrieve Branch with Documently

Retrieves a branch from Documently.

## Endpoint

- **Method:** `GET`
- **Path:** `/branches/:branchId`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [Retrieve Branch](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `branchId` | path | `string` | yes |
