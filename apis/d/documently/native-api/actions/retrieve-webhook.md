# Retrieve Webhook with Documently

Retrieves a webhook from Documently.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [Retrieve Webhook](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | no | The webhook id. |
