# List Storage Files with Documently

Retrieves storage files from Documently.

## Endpoint

- **Method:** `GET`
- **Path:** `/storage`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [List Storage Files](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | query | `string` | no | Project ID filter for storage listing. |
