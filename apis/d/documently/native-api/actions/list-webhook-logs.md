# List Webhook Logs with Documently

Retrieves webhook logs from Documently.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook-logs`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [List Webhook Logs](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | query | `string` | no | Project ID filter required by Documently. |
