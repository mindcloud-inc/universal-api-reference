# Delete Branch with Documently

Deletes an existing branch from Documently.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/branches/:branchId`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [Delete Branch](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `branchId` | path | `string` | yes |
