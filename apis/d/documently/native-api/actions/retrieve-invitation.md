# Retrieve Invitation with Documently

Retrieves an invitation from Documently.

## Endpoint

- **Method:** `GET`
- **Path:** `/invitations/:invitationId`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [Retrieve Invitation](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invitationId` | path | `string` | no | The invitation id. |
