# Retrieve Storage Directory with Documently

Retrieves a storage directory from Documently.

## Endpoint

- **Method:** `GET`
- **Path:** `/storage-directories/:directoryId`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [Retrieve Storage Directory](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `directoryId` | path | `string` | no | The storage directory id. |
