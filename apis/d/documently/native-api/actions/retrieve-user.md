# Retrieve User with Documently

Retrieves a user from Documently.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [Retrieve User](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | Documently user ID. |
