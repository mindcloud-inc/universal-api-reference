# Retrieve Organization with Documently

Retrieves an organization from Documently.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationId`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [Retrieve Organization](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | no | Documently organization ID. |
