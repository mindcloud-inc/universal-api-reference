# List Permissions with Documently

Retrieves permissions from Documently.

## Endpoint

- **Method:** `GET`
- **Path:** `/permissions`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [List Permissions](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization` | query | `string` | no | Organization ID filter. |
| `project` | query | `string` | no | Project ID filter. |
