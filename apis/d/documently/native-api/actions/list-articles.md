# List Articles with Documently

Retrieves articles from Documently.

## Endpoint

- **Method:** `GET`
- **Path:** `/articles`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [List Articles](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | query | `string` | no | Filter articles by project id. |
