# Retrieve Permission with Documently

Retrieves a permission from Documently.

## Endpoint

- **Method:** `GET`
- **Path:** `/permissions/:permissionId`
- **Base URL:** `https://app.documently.io/api`
- **Official documentation:** [Retrieve Permission](https://app.documently.io/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `permissionId` | path | `string` | no | Permission ID. |
