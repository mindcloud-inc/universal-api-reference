# Get Table Row with Data Blaze

Retrieves a table row from Data Blaze.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/database/rows/table/6S69TxVQg3kaNMphZCdHyV/{rowId}/`
- **Base URL:** `https://data-api.blaze.today`
- **Official documentation:** [Get Table Row](https://blaze.today/datablaze/docs/apis/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rowId` | path | `string` | yes | Mindcloud row ID. |
