# Delete Table Row with Data Blaze

Deletes an existing table row from Data Blaze.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/database/rows/table/6S69TxVQg3kaNMphZCdHyV/{rowId}/`
- **Base URL:** `https://data-api.blaze.today`
- **Official documentation:** [Delete Table Row](https://blaze.today/datablaze/docs/apis/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rowId` | path | `string` | yes | Mindcloud row ID to delete. |
