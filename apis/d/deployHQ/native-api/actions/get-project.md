# Get Project with DeployHQ

Retrieves a project from DeployHQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://{account}.deployhq.com`
- **Official documentation:** [Get Project](https://api.deployhq.com/docs#tag/Projects/operation/getProject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The identifier or permalink of the project. |
