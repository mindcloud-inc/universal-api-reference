# Fetch a Chatbot with DONNAJAMES Easy

Retrieves a chatbot from DONNAJAMES Easy.

## Endpoint

- **Method:** `GET`
- **Path:** `chatbot/:uuid`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Fetch a Chatbot](https://guide.gpt-trainer.com/api-reference/chatbots/fetch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Chatbot uuid |
