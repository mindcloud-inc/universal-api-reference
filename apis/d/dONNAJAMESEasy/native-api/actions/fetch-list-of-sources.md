# Fetch List of Sources with DONNAJAMES Easy

Retrieves all sources for a chatbot from DONNAJAMES Easy.

## Endpoint

- **Method:** `GET`
- **Path:** `chatbot/:uuid/data-sources`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Fetch List of Sources](https://guide.gpt-trainer.com/api-reference/data-sources/fetch_multi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Chatbot uuid |
