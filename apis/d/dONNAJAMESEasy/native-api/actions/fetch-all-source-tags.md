# Fetch All Source Tags with DONNAJAMES Easy

Retrieves all source tags from DONNAJAMES Easy.

## Endpoint

- **Method:** `GET`
- **Path:** `chatbot/:uuid/source-tags`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Fetch All Source Tags](https://guide.gpt-trainer.com/api-reference/source-tags/fetch-multi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Chatbot uuid |
