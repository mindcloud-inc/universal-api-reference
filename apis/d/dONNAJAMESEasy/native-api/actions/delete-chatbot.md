# Delete Chatbot with DONNAJAMES Easy

Deletes an existing chatbot from DONNAJAMES Easy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `chatbot/:uuid/delete`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Delete Chatbot](https://guide.gpt-trainer.com/api-reference/chatbots/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Chatbot uuid |
