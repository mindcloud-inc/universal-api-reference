# Fetch All Messages with DONNAJAMES Easy

Retrieves all messages for a session from DONNAJAMES Easy.

## Endpoint

- **Method:** `GET`
- **Path:** `session/:uuid/messages`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Fetch All Messages](https://guide.gpt-trainer.com/api-reference/messages/fetch_multi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Session uuid |
