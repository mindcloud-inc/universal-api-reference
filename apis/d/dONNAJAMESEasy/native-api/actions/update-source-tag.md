# Update Source Tag with DONNAJAMES Easy

Updates an existing source tag in DONNAJAMES Easy.

## Endpoint

- **Method:** `POST`
- **Path:** `source-tag/:uuid/update`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Update Source Tag](https://guide.gpt-trainer.com/api-reference/source-tags/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `color` | body | `string` | no | — |
| `name` | body | `string` | no | — |
| `uuid` | path | `string` | yes | Source tag uuid |
