# Delete Source with DONNAJAMES Easy

Deletes an existing source from DONNAJAMES Easy.

## Endpoint

- **Method:** `POST`
- **Path:** `data-source/:uuid/delete`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Delete Source](https://guide.gpt-trainer.com/api-reference/data-sources/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Data source uuid |
