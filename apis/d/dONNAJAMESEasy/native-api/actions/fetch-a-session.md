# Fetch a Session with DONNAJAMES Easy

Retrieves a chatbot session from DONNAJAMES Easy.

## Endpoint

- **Method:** `GET`
- **Path:** `session/:uuid`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Fetch a Session](https://guide.gpt-trainer.com/api-reference/sessions/fetch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Session uuid |
