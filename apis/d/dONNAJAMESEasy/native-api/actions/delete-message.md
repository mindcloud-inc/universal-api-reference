# Delete Message with DONNAJAMES Easy

Deletes an existing message from DONNAJAMES Easy.

## Endpoint

- **Method:** `POST`
- **Path:** `message/:uuid/delete`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Delete Message](https://guide.gpt-trainer.com/api-reference/messages/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Message uuid |
