# Delete Session with DONNAJAMES Easy

Deletes an existing session from DONNAJAMES Easy.

## Endpoint

- **Method:** `POST`
- **Path:** `session/:uuid/delete`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Delete Session](https://guide.gpt-trainer.com/api-reference/sessions/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Session uuid |
