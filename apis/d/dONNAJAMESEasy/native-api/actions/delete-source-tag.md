# Delete Source Tag with DONNAJAMES Easy

Deletes an existing source tag from DONNAJAMES Easy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `source-tag/:uuid/delete`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Delete Source Tag](https://guide.gpt-trainer.com/api-reference/source-tags/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Source tag uuid |
