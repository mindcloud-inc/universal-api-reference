# Delete Agent with DONNAJAMES Easy

Deletes an existing agent from DONNAJAMES Easy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `agent/:uuid/delete`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Delete Agent](https://guide.gpt-trainer.com/api-reference/agents/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Agent uuid |
