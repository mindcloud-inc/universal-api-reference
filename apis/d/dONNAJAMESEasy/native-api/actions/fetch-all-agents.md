# Fetch All Agents with DONNAJAMES Easy

Retrieves all agents for a chatbot from DONNAJAMES Easy.

## Endpoint

- **Method:** `GET`
- **Path:** `chatbot/:uuid/agents`
- **Base URL:** `https://app.gpt-trainer.com/api/v1`
- **Official documentation:** [Fetch All Agents](https://guide.gpt-trainer.com/api-reference/agents/fetch_multi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Chatbot uuid |
