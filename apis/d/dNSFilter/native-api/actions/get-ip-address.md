# Get IP Address with DNSFilter

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/ip_addresses/:id`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [Get IP Address](https://api.dnsfilter.com/docs#/paths/~1v1~1ip_addresses~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | IP address ID |
