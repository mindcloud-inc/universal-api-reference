# Get Policy with DNSFilter

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/policies/:id`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [Get Policy](https://api.dnsfilter.com/docs#/paths/~1v1~1policies~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Policy ID |
