# Get Block Page with DNSFilter

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/block_pages/:id`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [Get Block Page](https://api.dnsfilter.com/docs#/paths/~1v1~1block_pages~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Block page ID |
