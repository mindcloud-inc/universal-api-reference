# Lookup Domain with DNSFilter

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/domains/user_lookup`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [Lookup Domain](https://api.dnsfilter.com/docs#/paths/~1v1~1domains~1user_lookup/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fqdn` | query | `string` | no | FQDN to lookup |
