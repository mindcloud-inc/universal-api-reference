# Get Policy Application with DNSFilter

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/policies/application`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [Get Policy Application](https://api.dnsfilter.com/docs#/paths/~1v1~1policies~1application/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `application_id` | query | `number` | yes | Application ID |
| `organization_id` | query | `number` | yes | Organization ID |
