# List IP Addresses with DNSFilter

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/ip_addresses`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [List IP Addresses](https://api.dnsfilter.com/docs#/paths/~1v1~1ip_addresses/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search IP addresses |
