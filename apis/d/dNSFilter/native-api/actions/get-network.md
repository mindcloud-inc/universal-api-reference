- **Method:** `GET`
- **Path:** `/v1/networks/:id`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [Get Network](https://api.dnsfilter.com/docs#/paths/~1v1~1networks~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Network ID |
