# List Network Subnets with DNSFilter

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/networks/:id/subnets`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [List Network Subnets](https://api.dnsfilter.com/docs#/paths/~1v1~1networks~1{id}~1subnets/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Network ID |
