# Get Organization User with DNSFilter

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/organizations/:organization_id/users/:id`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [Get Organization User](https://api.dnsfilter.com/docs#/paths/~1v1~1organizations~1{organization_id}~1users~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `number` | yes | Organization ID |
| `id` | path | `number` | yes | User ID |
