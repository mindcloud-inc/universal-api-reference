# Get Application Category with DNSFilter

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/application_categories/:id`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [Get Application Category](https://api.dnsfilter.com/docs#/paths/~1v1~1application_categories~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Application category ID |
