# Get Application with DNSFilter

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/applications/:id`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [Get Application](https://api.dnsfilter.com/docs#/paths/~1v1~1applications~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Application ID |
