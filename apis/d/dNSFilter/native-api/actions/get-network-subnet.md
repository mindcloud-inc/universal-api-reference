# Get Network Subnet with DNSFilter

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/networks/:id/subnets/:subnet_id`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [Get Network Subnet](https://api.dnsfilter.com/docs#/paths/~1v1~1networks~1{id}~1subnets~1{subnet_id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Network ID |
| `subnet_id` | path | `number` | yes | Subnet ID |
