# List Organization Users with DNSFilter

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/organizations/:organization_id/users`
- **Base URL:** `https://api.dnsfilter.com`
- **Official documentation:** [List Organization Users](https://api.dnsfilter.com/docs#/paths/~1v1~1organizations~1{organization_id}~1users/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `number` | yes | Organization ID |
