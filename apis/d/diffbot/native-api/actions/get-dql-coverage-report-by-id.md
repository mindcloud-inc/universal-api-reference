# Get DQL Coverage Report By ID with Diffbot

Retrieves a DQL coverage report from Diffbot by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `https://kg.diffbot.com/kg/v3/dql/report/{id}`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Get DQL Coverage Report By ID](https://docs.diffbot.com/reference/reportget)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Coverage report identifier. |
