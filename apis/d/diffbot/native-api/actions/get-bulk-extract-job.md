# Get Bulk Extract Job with Diffbot

Retrieves details for a Diffbot bulk extract job.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/bulk/`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Get Bulk Extract Job](https://docs.diffbot.com/reference/manage-a-bulk-extract-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Bulk extract job name. |
