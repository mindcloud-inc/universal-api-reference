# Extract Video with Diffbot

Extracts video details from a page with Diffbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/video`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Extract Video](https://docs.diffbot.com/reference/video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Video page URL to extract. |
