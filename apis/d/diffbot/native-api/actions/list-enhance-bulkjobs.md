# List Enhance Bulkjobs with Diffbot

Lists Enhance bulk jobs for the current Diffbot token.

## Endpoint

- **Method:** `GET`
- **Path:** `https://kg.diffbot.com/kg/v3/enhance/bulk/status`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [List Enhance Bulkjobs](https://docs.diffbot.com/reference/list-bulkjobs-for-token)
