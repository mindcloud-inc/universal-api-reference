# Get Crawl Job with Diffbot

Retrieves details for a Diffbot crawl job.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/crawl`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Get Crawl Job](https://docs.diffbot.com/reference/manage-a-crawl-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Crawl job name. |
