# Extract List with Diffbot

Extracts a structured item list from a page with Diffbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/list`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Extract List](https://docs.diffbot.com/reference/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | List page URL to extract. |
