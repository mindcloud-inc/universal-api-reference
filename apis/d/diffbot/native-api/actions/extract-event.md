# Extract Event with Diffbot

Extracts event details from a page with Diffbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/event`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Extract Event](https://docs.diffbot.com/reference/event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Event page URL to extract. |
