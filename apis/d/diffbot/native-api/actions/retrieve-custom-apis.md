# Retrieve Custom APIs with Diffbot

Retrieves Custom APIs defined on the current Diffbot token.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/custom`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Retrieve Custom APIs](https://docs.diffbot.com/reference/retrieve-custom-apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | Optional custom API name filter. |
