# Extract Job with Diffbot

Extracts job posting details from a page with Diffbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/job`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Extract Job](https://docs.diffbot.com/reference/job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Job posting page URL to extract. |
