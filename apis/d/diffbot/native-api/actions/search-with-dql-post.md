# Search With DQL (POST) with Diffbot

Searches the Diffbot Knowledge Graph with DQL using POST.

## Endpoint

- **Method:** `POST`
- **Path:** `https://kg.diffbot.com/kg/v3/dql`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Search With DQL (POST)](https://docs.diffbot.com/reference/search-with-dql)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | DQL query string. |
