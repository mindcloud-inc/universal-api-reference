# Download Enhance Bulkjob Coverage Report with Diffbot

Downloads the coverage report for a Diffbot Enhance bulk job.

## Endpoint

- **Method:** `GET`
- **Path:** `https://kg.diffbot.com/kg/v3/enhance/bulk/report/{bulkjobId}/{reportId}`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Download Enhance Bulkjob Coverage Report](https://docs.diffbot.com/reference/download-bulkjob-coverage-report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bulkjobId` | path | `string` | yes | Enhance bulkjob identifier. |
| `reportId` | path | `string` | yes | Coverage report identifier. |
