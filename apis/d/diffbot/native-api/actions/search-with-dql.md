# Search With DQL with Diffbot

Searches the Diffbot Knowledge Graph with a DQL query.

## Endpoint

- **Method:** `GET`
- **Path:** `https://kg.diffbot.com/kg/v3/dql`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Search With DQL](https://docs.diffbot.com/reference/search-with-dql)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | DQL query string. |
