# Retrieve Crawl Job Data with Diffbot

Downloads extracted data for a Diffbot crawl job.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/crawl/data`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Retrieve Crawl Job Data](https://docs.diffbot.com/reference/retrieve-crawl-job-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Crawl job name. |
