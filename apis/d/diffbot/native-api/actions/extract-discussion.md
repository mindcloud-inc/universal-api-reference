# Extract Discussion with Diffbot

Extracts discussion threads from a page with Diffbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/discussion`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Extract Discussion](https://docs.diffbot.com/reference/discussion)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Discussion page URL to extract. |
