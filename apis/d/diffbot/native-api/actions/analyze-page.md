# Analyze Page with Diffbot

Analyzes a page and classifies its content with Diffbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/analyze`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Analyze Page](https://docs.diffbot.com/reference/analyze)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL to analyze with Diffbot Analyze API. |
