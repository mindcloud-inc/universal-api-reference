# Download Enhance Bulkjob Results (POST) with Diffbot

Downloads results for a completed Diffbot Enhance bulk job using POST.

## Endpoint

- **Method:** `POST`
- **Path:** `https://kg.diffbot.com/kg/v3/enhance/bulk/{bulkjobId}`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Download Enhance Bulkjob Results (POST)](https://docs.diffbot.com/reference/download-results-of-bulkjob)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bulkjobId` | path | `string` | yes | Enhance bulkjob identifier. |
