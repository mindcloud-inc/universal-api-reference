# Extract Product with Diffbot

Extracts product details from a page with Diffbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/product`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Extract Product](https://docs.diffbot.com/reference/product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Product page URL to extract. |
