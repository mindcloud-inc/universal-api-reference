# Extract Article with Diffbot

Extracts article content from a page with Diffbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/article`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Extract Article](https://docs.diffbot.com/reference/article)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Article page URL to extract. |
