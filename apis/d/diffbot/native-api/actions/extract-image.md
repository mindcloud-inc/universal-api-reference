# Extract Image with Diffbot

Extracts primary image details from a page with Diffbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/image`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Extract Image](https://docs.diffbot.com/reference/image)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Image page URL to extract. |
