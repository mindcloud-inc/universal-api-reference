# Download Enhance Bulkjob Results with Diffbot

Downloads results for a completed Diffbot Enhance bulk job.

## Endpoint

- **Method:** `GET`
- **Path:** `https://kg.diffbot.com/kg/v3/enhance/bulk/{bulkjobId}`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Download Enhance Bulkjob Results](https://docs.diffbot.com/reference/download-results-of-bulkjob)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bulkjobId` | path | `string` | yes | Enhance bulkjob identifier. |
