# Retrieve Bulk Extract Job Data with Diffbot

Downloads extracted data for a Diffbot bulk extract job.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/bulk/data`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Retrieve Bulk Extract Job Data](https://docs.diffbot.com/reference/retrieve-bulk-extract-job-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Bulk extract job name. |
