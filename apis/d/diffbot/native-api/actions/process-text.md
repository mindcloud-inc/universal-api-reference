# Process Text with Diffbot

Processes raw text with Diffbot Natural Language API.

## Endpoint

- **Method:** `POST`
- **Path:** `https://nl.diffbot.com/v1/`
- **Base URL:** `https://api.diffbot.com`
- **Official documentation:** [Process Text](https://docs.diffbot.com/reference/process-text)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `content` | body | `string` | yes | Text content to process with Diffbot NLP. |
