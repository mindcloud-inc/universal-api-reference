# List Entries with DataForms.io

Retrieves entries from DataForms.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/entries`
- **Base URL:** `https://api.dataforms.io`
- **Official documentation:** [List Entries](https://dataforms.readme.io/reference/index-entries)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Limit the number of entries returned. Maximum 50. |
