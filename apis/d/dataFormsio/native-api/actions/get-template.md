# Get Template with DataForms.io

Retrieves a template from DataForms.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/{template_id}`
- **Base URL:** `https://api.dataforms.io`
- **Official documentation:** [Get Template](https://dataforms.readme.io/reference/index-templates-copy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The DataForms.io template identifier. |
