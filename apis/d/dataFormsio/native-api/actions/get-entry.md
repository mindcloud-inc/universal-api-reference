# Get Entry with DataForms.io

Retrieves an entry from DataForms.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/entries/{entry_id}`
- **Base URL:** `https://api.dataforms.io`
- **Official documentation:** [Get Entry](https://dataforms.readme.io/reference/index-entries-copy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entry_id` | path | `string` | yes | The DataForms.io entry identifier. |
