# Get Data Form with DataForms.io

Retrieves a data form from DataForms.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/dataforms/{form_id}`
- **Base URL:** `https://api.dataforms.io`
- **Official documentation:** [Get Data Form](https://dataforms.readme.io/reference/index-data-forms-copy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `form_id` | path | `string` | yes | The DataForms.io form identifier. |
