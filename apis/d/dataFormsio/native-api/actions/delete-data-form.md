# Delete Data Form with DataForms.io

Deletes an existing data form from DataForms.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/dataforms/{form_id}`
- **Base URL:** `https://api.dataforms.io`
- **Official documentation:** [Delete Data Form](https://dataforms.readme.io/reference/store-data-form-copy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `form_id` | path | `string` | yes | The DataForms.io form identifier. |
