# Delete Upload Permanently with Dromo

Deletes an upload permanently from Dromo.

## Endpoint

- **Method:** `POST`
- **Path:** `/upload/:id/delete/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [Delete Upload Permanently](https://developer.dromo.io/api-reference/uploads/delete-an-upload-permanently)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Path parameter id. |
