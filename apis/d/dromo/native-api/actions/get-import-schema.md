# Get Import Schema with Dromo

Retrieves an import schema from Dromo.

## Endpoint

- **Method:** `GET`
- **Path:** `/schemas/:id/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [Get Import Schema](https://developer.dromo.io/api-reference/import-schemas/get-an-import-schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Path parameter id. |
