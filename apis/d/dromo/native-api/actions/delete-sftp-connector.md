# Delete SFTP Connector with Dromo

Deletes an existing SFTP connector from Dromo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/headless/sftp/connectors/:id/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [Delete SFTP Connector](https://developer.dromo.io/api-reference/sftp-connectors/delete-sftp-connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Path parameter id. |
