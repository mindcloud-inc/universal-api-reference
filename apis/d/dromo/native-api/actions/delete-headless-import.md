# Delete Headless Import with Dromo

Deletes a headless import from Dromo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/headless/imports/:id/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [Delete Headless Import](https://developer.dromo.io/api-reference/headless/delete-headless-import)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Path parameter id. |
