# List Headless Imports with Dromo

Retrieves all headless imports from Dromo.

## Endpoint

- **Method:** `GET`
- **Path:** `/headless/imports/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [List Headless Imports](https://developer.dromo.io/api-reference/headless/list-headless-imports)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `offset` | query | `number` | no | Query parameter offset. |
| `limit` | query | `number` | no | Query parameter limit. |
