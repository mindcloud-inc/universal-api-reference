# Delete SFTP Credentials with Dromo

Deletes existing SFTP credentials from Dromo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/headless/sftp/credentials/:id/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [Delete SFTP Credentials](https://developer.dromo.io/api-reference/sftp-credentials/delete-sftp-credentials)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Path parameter id. |
