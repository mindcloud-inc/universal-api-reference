# Retrieve SFTP Connector with Dromo

Retrieves an SFTP connector from Dromo.

## Endpoint

- **Method:** `GET`
- **Path:** `/headless/sftp/connectors/:id/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [Retrieve SFTP Connector](https://developer.dromo.io/api-reference/sftp-connectors/retrieve-sftp-connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Path parameter id. |
