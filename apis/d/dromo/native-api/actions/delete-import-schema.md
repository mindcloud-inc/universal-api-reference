# Delete Import Schema with Dromo

Deletes an existing import schema from Dromo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/schemas/:id/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [Delete Import Schema](https://developer.dromo.io/api-reference/import-schemas/delete-an-import-schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Path parameter id. |
