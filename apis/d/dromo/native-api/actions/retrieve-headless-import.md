# Retrieve Headless Import with Dromo

Retrieves a headless import from Dromo.

## Endpoint

- **Method:** `GET`
- **Path:** `/headless/imports/:id/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [Retrieve Headless Import](https://developer.dromo.io/api-reference/headless/retrieve-headless-import)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Path parameter id. |
