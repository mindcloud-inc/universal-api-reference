# Get Upload Metadata with Dromo

Retrieves metadata for an upload from Dromo.

## Endpoint

- **Method:** `GET`
- **Path:** `/upload/:id/metadata/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [Get Upload Metadata](https://developer.dromo.io/api-reference/uploads/get-upload-metadata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Path parameter id. |
