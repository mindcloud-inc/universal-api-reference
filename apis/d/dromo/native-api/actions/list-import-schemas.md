# List Import Schemas with Dromo

Retrieves all import schemas from Dromo.

## Endpoint

- **Method:** `GET`
- **Path:** `/schemas/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [List Import Schemas](https://developer.dromo.io/api-reference/import-schemas/get-all-import-schemas)
