# List SFTP Credentials with Dromo

Retrieves all SFTP credentials from Dromo.

## Endpoint

- **Method:** `GET`
- **Path:** `/headless/sftp/credentials/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [List SFTP Credentials](https://developer.dromo.io/api-reference/sftp-credentials/list-sftp-credentials)
