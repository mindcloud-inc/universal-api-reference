# List SFTP Connectors with Dromo

Retrieves all SFTP connectors from Dromo.

## Endpoint

- **Method:** `GET`
- **Path:** `/headless/sftp/connectors/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [List SFTP Connectors](https://developer.dromo.io/api-reference/sftp-connectors/list-sftp-connectors)
