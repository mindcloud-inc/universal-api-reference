# List Uploads with Dromo

Retrieves all upload records from Dromo.

## Endpoint

- **Method:** `GET`
- **Path:** `/uploads/`
- **Base URL:** `https://app.dromo.io/api/v1`
- **Official documentation:** [List Uploads](https://developer.dromo.io/api-reference/uploads/get-all-uploads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `start` | query | `number` | no | Query parameter start. |
| `end` | query | `number` | no | Query parameter end. |
