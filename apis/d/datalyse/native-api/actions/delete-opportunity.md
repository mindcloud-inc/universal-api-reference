# Delete Opportunity with Datalyse

Deletes an existing opportunity from Datalyse.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/1.0/opportunities/delete.json`
- **Base URL:** `https://api.datalyse.io`
- **Official documentation:** [Delete Opportunity](https://developers.datalyse.io/devs/content_api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `opportunity_id` | body | `string` | yes | ID of the opportunity to delete |
