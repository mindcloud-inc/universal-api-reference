# Get Agent Types with Datalyse

Retrieves company agent types from Datalyse.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/1.0/companyuserdata/agentstypes.json`
- **Base URL:** `https://api.datalyse.io`
- **Official documentation:** [Get Agent Types](https://developers.datalyse.io/devs/content_api.html)
