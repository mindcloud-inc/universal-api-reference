# Get All Agents with Datalyse

Retrieves all company agents from Datalyse.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/1.0/companyuserdata/getallagents.json`
- **Base URL:** `https://api.datalyse.io`
- **Official documentation:** [Get All Agents](https://developers.datalyse.io/devs/content_api.html)
