# Get Email with Datalyse

Retrieves a single email from Datalyse.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/1.0/emails/getone.json`
- **Base URL:** `https://api.datalyse.io`
- **Official documentation:** [Get Email](https://developers.datalyse.io/devs/content_api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email_id` | body | `string` | yes | ID of the email |
