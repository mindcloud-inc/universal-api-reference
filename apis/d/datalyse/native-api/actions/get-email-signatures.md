# Get Email Signatures with Datalyse

Retrieves all email signatures from Datalyse.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/1.0/emails/signatures/get.json`
- **Base URL:** `https://api.datalyse.io`
- **Official documentation:** [Get Email Signatures](https://developers.datalyse.io/devs/content_api.html)
