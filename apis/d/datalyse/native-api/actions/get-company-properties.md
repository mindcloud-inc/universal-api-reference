# Get Company Properties with Datalyse

Retrieves company properties and statuses from Datalyse.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/1.0/companyuserdata/companyproperties.json`
- **Base URL:** `https://api.datalyse.io`
- **Official documentation:** [Get Company Properties](https://developers.datalyse.io/devs/content_api.html)
