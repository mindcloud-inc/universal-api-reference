# Get Signature Process Status with Docubee

Retrieves the status of a Docubee signature process.

## Endpoint

- **Method:** `GET`
- **Path:** `/signatures/:processId/status`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [Get Signature Process Status](https://docs.docubee.app/#get-signature-process-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processId` | path | `string` | no | The signature process ID. |
