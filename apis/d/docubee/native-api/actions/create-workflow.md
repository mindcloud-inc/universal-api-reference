# Create Workflow with Docubee

Creates a new workflow in Docubee.

## Endpoint

- **Method:** `POST`
- **Path:** `/workflowTemplates`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [Create Workflow](https://docs.docubee.app/#create-new)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `string` | no | The workflow template payload. |
