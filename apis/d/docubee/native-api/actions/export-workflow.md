# Export Workflow with Docubee

Exports a workflow from Docubee.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflowTemplates/:templateId`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [Export Workflow](https://docs.docubee.app/#export)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | no | The workflow template ID. |
