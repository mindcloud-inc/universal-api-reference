# List Instance Properties with Docubee

Retrieves properties for a Docubee workflow instance.

## Endpoint

- **Method:** `GET`
- **Path:** `/instances/:instanceId/properties`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [List Instance Properties](https://docs.docubee.app/#list-instance-properties)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `instanceId` | path | `string` | no | The workflow instance ID. |
