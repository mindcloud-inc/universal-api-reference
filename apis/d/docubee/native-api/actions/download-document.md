# Download Document with Docubee

Downloads a document from Docubee.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentId`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [Download Document](https://docs.docubee.app/#download)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | no | The Docubee document ID. |
