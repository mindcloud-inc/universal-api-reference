# Replace Document Content with Docubee

Replaces templated content in a Docubee document.

## Endpoint

- **Method:** `POST`
- **Path:** `/contentReplacers`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [Replace Document Content](https://docs.docubee.app/#inline-replace-existing-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `string` | no | The inline replacement payload. |
