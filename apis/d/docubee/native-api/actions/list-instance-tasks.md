# List Instance Tasks with Docubee

Retrieves tasks for a Docubee workflow instance.

## Endpoint

- **Method:** `GET`
- **Path:** `/instances/:instanceId/tasks`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [List Instance Tasks](https://docs.docubee.app/#list-instance-tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `instanceId` | path | `string` | no | The workflow instance ID. |
