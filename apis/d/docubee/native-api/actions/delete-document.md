# Delete Document with Docubee

Deletes an existing document from Docubee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/documents/:documentId`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [Delete Document](https://docs.docubee.app/#delete-existing-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | no | The Docubee document ID. |
