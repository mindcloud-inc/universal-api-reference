# Get Workflow Start Form Data with Docubee

Retrieves start form fields for a Docubee workflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflowTemplates/:templateId/startForm`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [Get Workflow Start Form Data](https://docs.docubee.app/#get-start-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | no | The workflow template ID. |
