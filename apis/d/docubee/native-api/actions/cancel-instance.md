# Cancel Instance with Docubee

Cancels or removes a Docubee workflow instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/instances/:instanceId`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [Cancel Instance](https://docs.docubee.app/#cancel-instance)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `instanceId` | path | `string` | no | The workflow instance ID. |
