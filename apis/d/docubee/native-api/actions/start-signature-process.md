# Start Signature Process with Docubee

Starts a signature process in Docubee.

## Endpoint

- **Method:** `POST`
- **Path:** `/signatures`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [Start Signature Process](https://docs.docubee.app/#start-signature-process)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `string` | no | The signature process payload. |
