# List Workflow Instances with Docubee

Retrieves instances for a Docubee workflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflowTemplates/:templateId/instances`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [List Workflow Instances](https://docs.docubee.app/#list-instances)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | no | The workflow template ID. |
