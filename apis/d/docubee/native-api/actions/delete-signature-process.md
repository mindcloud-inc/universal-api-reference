# Delete Signature Process with Docubee

Deletes a signature process from Docubee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/signatures/:processId`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [Delete Signature Process](https://docs.docubee.app/#delete-signature-process)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processId` | path | `string` | no | The signature process ID. |
