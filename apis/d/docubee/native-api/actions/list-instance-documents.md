# List Instance Documents with Docubee

Retrieves documents for a Docubee workflow instance.

## Endpoint

- **Method:** `GET`
- **Path:** `/instances/:instanceId/documents`
- **Base URL:** `https://docubee.app/api/v2`
- **Official documentation:** [List Instance Documents](https://docs.docubee.app/#list-instance-documents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `instanceId` | path | `string` | no | The workflow instance ID. |
