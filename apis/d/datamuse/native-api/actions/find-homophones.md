# Find Homophones with Datamuse

Finds homophones in Datamuse for a given word.

## Endpoint

- **Method:** `GET`
- **Path:** `/words`
- **Base URL:** `https://api.datamuse.com`
- **Official documentation:** [Find Homophones](https://www.datamuse.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rel_hom` | query | `string` | yes | Word to find homophones for. |
