# Find Consonant Matches with Datamuse

Finds consonant matches in Datamuse for a given word.

## Endpoint

- **Method:** `GET`
- **Path:** `/words`
- **Base URL:** `https://api.datamuse.com`
- **Official documentation:** [Find Consonant Matches](https://www.datamuse.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rel_cns` | query | `string` | yes | Word to find consonant matches for. |
