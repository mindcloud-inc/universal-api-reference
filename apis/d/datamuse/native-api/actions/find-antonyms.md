# Find Antonyms with Datamuse

Finds antonyms in Datamuse for a given word.

## Endpoint

- **Method:** `GET`
- **Path:** `/words`
- **Base URL:** `https://api.datamuse.com`
- **Official documentation:** [Find Antonyms](https://www.datamuse.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rel_ant` | query | `string` | yes | Word to find antonyms for. |
