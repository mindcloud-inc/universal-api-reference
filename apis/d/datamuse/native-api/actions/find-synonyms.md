# Find Synonyms with Datamuse

Finds synonyms in Datamuse for a given word.

## Endpoint

- **Method:** `GET`
- **Path:** `/words`
- **Base URL:** `https://api.datamuse.com`
- **Official documentation:** [Find Synonyms](https://www.datamuse.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rel_syn` | query | `string` | yes | Word to find synonyms for. |
