# Find Words That Sound Like with Datamuse

Finds words in Datamuse by pronunciation similarity.

## Endpoint

- **Method:** `GET`
- **Path:** `/words`
- **Base URL:** `https://api.datamuse.com`
- **Official documentation:** [Find Words That Sound Like](https://www.datamuse.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sl` | query | `string` | yes | Text that the results should be pronounced similarly to. |
