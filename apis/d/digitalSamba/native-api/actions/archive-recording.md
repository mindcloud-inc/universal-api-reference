# Archive recording with Digital Samba

Updates a recording to archived in Digital Samba.

## Endpoint

- **Method:** `POST`
- **Path:** `/recordings/:recording/archive`
- **Base URL:** `https://api.digitalsamba.com/api/v1`
- **Official documentation:** [Archive recording](https://developer.digitalsamba.com/rest-api/#recordings-POSTapi-v1-recordings--recording--archive)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recording` | path | `string` | yes | Recording path parameter. |
