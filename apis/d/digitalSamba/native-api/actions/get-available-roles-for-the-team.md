# Get available roles for the team with Digital Samba

Retrieves team roles from Digital Samba.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles`
- **Base URL:** `https://api.digitalsamba.com/api/v1`
- **Official documentation:** [Get available roles for the team](https://developer.digitalsamba.com/rest-api/#roles-GETapi-v1-roles)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
