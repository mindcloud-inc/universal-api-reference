# Get participant statistics with Digital Samba

Retrieves participant statistics from Digital Samba.

## Endpoint

- **Method:** `GET`
- **Path:** `/participants/:participant`
- **Base URL:** `https://api.digitalsamba.com/api/v1`
- **Official documentation:** [Get participant statistics](https://developer.digitalsamba.com/rest-api/#statistics-GETapi-v1-participants--participant--statistics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `participant` | path | `string` | yes | Participant path parameter. |
