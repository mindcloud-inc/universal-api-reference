# Get the specified library hierarchy with Digital Samba

Retrieves a library hierarchy from Digital Samba.

## Endpoint

- **Method:** `GET`
- **Path:** `/libraries/:library/hierarchy`
- **Base URL:** `https://api.digitalsamba.com/api/v1`
- **Official documentation:** [Get the specified library hierarchy](https://developer.digitalsamba.com/rest-api/#libraries-GETapi-v1-libraries--library--hierarchy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `library` | path | `string` | yes | Library path parameter. |
