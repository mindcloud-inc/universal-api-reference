# Get the specified room with Digital Samba

Retrieves a room from Digital Samba.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:room`
- **Base URL:** `https://api.digitalsamba.com/api/v1`
- **Official documentation:** [Get the specified room](https://developer.digitalsamba.com/rest-api/#rooms-GETapi-v1-rooms--room-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `room` | path | `string` | yes | Room path parameter. |
