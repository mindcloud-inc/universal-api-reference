# Get available permissions for roles with Digital Samba

Retrieves role permissions from Digital Samba.

## Endpoint

- **Method:** `GET`
- **Path:** `/permissions`
- **Base URL:** `https://api.digitalsamba.com/api/v1`
- **Official documentation:** [Get available permissions for roles](https://developer.digitalsamba.com/rest-api/#permissions-GETapi-v1-permissions)
