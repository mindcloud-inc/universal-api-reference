# Get session summary with Digital Samba

Retrieves a session summary from Digital Samba.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/:session/summary`
- **Base URL:** `https://api.digitalsamba.com/api/v1`
- **Official documentation:** [Get session summary](https://developer.digitalsamba.com/rest-api/#sessions-GETapi-v1-sessions--session--summary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session` | path | `string` | yes | Session path parameter. |
