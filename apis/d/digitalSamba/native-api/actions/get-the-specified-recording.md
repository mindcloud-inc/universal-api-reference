# Get the specified recording with Digital Samba

Retrieves a recording from Digital Samba.

## Endpoint

- **Method:** `GET`
- **Path:** `/recordings/:recording`
- **Base URL:** `https://api.digitalsamba.com/api/v1`
- **Official documentation:** [Get the specified recording](https://developer.digitalsamba.com/rest-api/#recordings-GETapi-v1-recordings--recording-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recording` | path | `string` | yes | Recording path parameter. |
