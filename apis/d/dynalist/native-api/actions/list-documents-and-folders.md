# List Documents And Folders with Dynalist

Retrieves documents and folders from Dynalist.

## Endpoint

- **Method:** `POST`
- **Path:** `/file/list`
- **Base URL:** `https://dynalist.io/api/v1/`
- **Official documentation:** [List Documents And Folders](https://apidocs.dynalist.io/#get-all-documents-and-folders)
