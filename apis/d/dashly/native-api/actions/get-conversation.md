# Get Conversation with Dashly

Retrieves a Dashly conversation by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `conversations/:id`
- **Base URL:** `https://api.dashly.app`
- **Official documentation:** [Get Conversation](https://developers.dashly.io/webapi/endpoints/conversations/conversation/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `id_as_string` | query | `boolean` | no |
