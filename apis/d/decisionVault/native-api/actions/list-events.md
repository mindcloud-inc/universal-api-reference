# List Events with DecisionVault

Retrieves events from your firm in DecisionVault.

## Endpoint

- **Method:** `GET`
- **Path:** `/events`
- **Base URL:** `https://api.decisionvault.com/v1`
- **Official documentation:** [List Events](https://docs.decisionvault.com/get-events-21684967e0.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
