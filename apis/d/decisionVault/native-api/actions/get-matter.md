# Get Matter with DecisionVault

Retrieves a matter from DecisionVault by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/matters/:matter_id`
- **Base URL:** `https://api.decisionvault.com/v1`
- **Official documentation:** [Get Matter](https://docs.decisionvault.com/get-single-matter-21684962e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `matter_id` | path | `string` | yes | The matter ID. |
