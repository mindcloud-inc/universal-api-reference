# List Assets for Matter with DecisionVault

Retrieves assets for a matter in DecisionVault.

## Endpoint

- **Method:** `GET`
- **Path:** `/matters/:matter_id/assets`
- **Base URL:** `https://api.decisionvault.com/v1`
- **Official documentation:** [List Assets for Matter](https://docs.decisionvault.com/get-assets-for-a-matter-21684963e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `matter_id` | path | `string` | yes | The matter ID. |
