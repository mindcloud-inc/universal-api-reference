# List Clients for Matter with DecisionVault

Retrieves clients for a matter in DecisionVault.

## Endpoint

- **Method:** `GET`
- **Path:** `/matters/:matter_id/clients`
- **Base URL:** `https://api.decisionvault.com/v1`
- **Official documentation:** [List Clients for Matter](https://docs.decisionvault.com/get-clients-for-a-matter-21684965e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `matter_id` | path | `string` | yes | The matter ID. |
