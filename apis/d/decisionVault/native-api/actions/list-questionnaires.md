# List Questionnaires with DecisionVault

Retrieves questionnaires from your firm in DecisionVault.

## Endpoint

- **Method:** `GET`
- **Path:** `/questionnaires`
- **Base URL:** `https://api.decisionvault.com/v1`
- **Official documentation:** [List Questionnaires](https://docs.decisionvault.com/get-questionnaires-21684958e0.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
