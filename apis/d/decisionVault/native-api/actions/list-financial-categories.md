# List Financial Categories with DecisionVault

Retrieves financial categories available in DecisionVault.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-categories`
- **Base URL:** `https://api.decisionvault.com/v1`
- **Official documentation:** [List Financial Categories](https://docs.decisionvault.com/get-financial-categories-21684960e0.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
