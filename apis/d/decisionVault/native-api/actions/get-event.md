# Get Event with DecisionVault

Retrieves an event from DecisionVault by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:event_id`
- **Base URL:** `https://api.decisionvault.com/v1`
- **Official documentation:** [Get Event](https://docs.decisionvault.com/get-single-event-21684968e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | The event ID. |
