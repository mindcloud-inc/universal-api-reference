# Get User with DecisionVault

Retrieves a user from DecisionVault by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user_id`
- **Base URL:** `https://api.decisionvault.com/v1`
- **Official documentation:** [Get User](https://docs.decisionvault.com/get-single-user-21684969e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The user ID. |
