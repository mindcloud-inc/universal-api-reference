# Get Questionnaire with DecisionVault

Retrieves a questionnaire from DecisionVault by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/questionnaires/:questionnaire_id`
- **Base URL:** `https://api.decisionvault.com/v1`
- **Official documentation:** [Get Questionnaire](https://docs.decisionvault.com/get-single-questionnaire-21684959e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `questionnaire_id` | path | `string` | yes | The questionnaire ID. |
