# Delete Webhook Subscription with DecisionVault

Deletes a webhook subscription from DecisionVault.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscriptions/:subscription_id`
- **Base URL:** `https://api.decisionvault.com/v1`
- **Official documentation:** [Delete Webhook Subscription](https://docs.decisionvault.com/delete-webhook-subscription-21684971e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscription_id` | path | `string` | yes | The webhook subscription ID to remove. |
