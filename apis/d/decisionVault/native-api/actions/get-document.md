# Get Document with DecisionVault

Retrieves a document from DecisionVault by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document_id`
- **Base URL:** `https://api.decisionvault.com/v1`
- **Official documentation:** [Get Document](https://docs.decisionvault.com/get-single-document-21747687e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The document ID. |
