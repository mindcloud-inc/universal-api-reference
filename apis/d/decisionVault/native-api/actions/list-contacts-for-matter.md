# List Contacts for Matter with DecisionVault

Retrieves contacts for a matter in DecisionVault.

## Endpoint

- **Method:** `GET`
- **Path:** `/matters/:matter_id/contacts`
- **Base URL:** `https://api.decisionvault.com/v1`
- **Official documentation:** [List Contacts for Matter](https://docs.decisionvault.com/get-contacts-for-a-matter-21684964e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `matter_id` | path | `string` | yes | The matter ID. |
