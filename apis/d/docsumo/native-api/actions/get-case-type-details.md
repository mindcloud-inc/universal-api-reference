# Get Case Type Details with Docsumo

Retrieves configuration details for a Docsumo case type.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/external/agents/:casetype_id`
- **Base URL:** `https://app.docsumo.com`
- **Official documentation:** [Get Case Type Details](https://support.docsumo.com/reference/get-casetype-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `casetype_id` | path | `string` | yes | Docsumo case type ID. |
