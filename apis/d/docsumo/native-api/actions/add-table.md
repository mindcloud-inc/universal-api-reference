# Add Table with Docsumo

Creates a database table in Docsumo.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/raichu/drop_down/db/add/`
- **Base URL:** `https://app.docsumo.com`
- **Official documentation:** [Add Table](https://support.docsumo.com/reference/post_api-v1-raichu-drop-down-db-add)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | body | `string` | no | CSV file to upload for the new table. |
