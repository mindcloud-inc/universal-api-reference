# Get User And Document Types with Docsumo

Retrieves your Docsumo user details and active document types.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/eevee/apikey/limit/`
- **Base URL:** `https://app.docsumo.com`
- **Official documentation:** [Get User And Document Types](https://support.docsumo.com/reference/api-v1-user-document-type-list)
