# Get Bank Statement Analytics with Docsumo

Retrieves bank statement analytics for a Docsumo document.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/mew/usbs-analytics/:doc_id/`
- **Base URL:** `https://app.docsumo.com`
- **Official documentation:** [Get Bank Statement Analytics](https://support.docsumo.com/reference/api-v1-bank-statement-analytics-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `doc_id` | path | `string` | yes | Docsumo bank statement document ID. |
