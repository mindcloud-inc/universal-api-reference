# Get Documents Summary with Docsumo

Retrieves document counts by type and status in Docsumo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/mew/apikey/documents/summary/`
- **Base URL:** `https://app.docsumo.com`
- **Official documentation:** [Get Documents Summary](https://support.docsumo.com/reference/api-v1-user-documents-summary)
