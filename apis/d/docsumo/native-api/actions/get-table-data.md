# Get Table Data with Docsumo

Retrieves all rows from a Docsumo database table.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/raichu/drop_down/db/get/:ddid/`
- **Base URL:** `https://app.docsumo.com`
- **Official documentation:** [Get Table Data](https://support.docsumo.com/reference/get-table-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ddid` | path | `string` | yes | Docsumo dropdown database identifier. |
