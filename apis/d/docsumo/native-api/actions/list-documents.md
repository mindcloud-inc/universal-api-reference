# List Documents with Docsumo

Retrieves documents from Docsumo with filtering and sorting.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/eevee/apikey/documents/all/`
- **Base URL:** `https://app.docsumo.com`
- **Official documentation:** [List Documents](https://support.docsumo.com/reference/api-v1-user-documents-list)
