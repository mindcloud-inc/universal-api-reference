# Get Folder Review URL with Docsumo

Retrieves a secure folder review URL from Docsumo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/eevee/apikey/review-url-folder/:folder_id/`
- **Base URL:** `https://app.docsumo.com`
- **Official documentation:** [Get Folder Review URL](https://support.docsumo.com/reference/get_api-v1-eevee-apikey-review-url-folder-folder-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder_id` | path | `string` | yes | Docsumo folder ID. |
