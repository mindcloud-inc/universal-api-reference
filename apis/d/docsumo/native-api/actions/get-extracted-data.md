# Get Extracted Data with Docsumo

Retrieves simplified extracted data for a Docsumo document.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/eevee/apikey/data/simplified/:doc_id/`
- **Base URL:** `https://app.docsumo.com`
- **Official documentation:** [Get Extracted Data](https://support.docsumo.com/reference/api-v1-extracted-data-simplified)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `doc_id` | path | `string` | yes | Docsumo document ID. |
