# Delete Document with Docsumo

Deletes an existing document from Docsumo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/eevee/apikey/delete/:doc_id/`
- **Base URL:** `https://app.docsumo.com`
- **Official documentation:** [Delete Document](https://support.docsumo.com/reference/api-v1-user-document-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `doc_id` | path | `string` | yes | Docsumo document ID. |
