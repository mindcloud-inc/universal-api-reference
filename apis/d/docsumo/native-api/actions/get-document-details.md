# Get Document Details with Docsumo

Retrieves detailed metadata for a document in Docsumo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/eevee/apikey/documents/detail/:doc_id/`
- **Base URL:** `https://app.docsumo.com`
- **Official documentation:** [Get Document Details](https://support.docsumo.com/reference/api-v1-user-documents-detail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `doc_id` | path | `string` | yes | Docsumo document ID. |
