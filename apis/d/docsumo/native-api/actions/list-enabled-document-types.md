# List Enabled Document Types with Docsumo

Retrieves enabled document types from Docsumo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/mew/documents/types/`
- **Base URL:** `https://app.docsumo.com`
- **Official documentation:** [List Enabled Document Types](https://support.docsumo.com/reference/user-enabled-doc_types)
