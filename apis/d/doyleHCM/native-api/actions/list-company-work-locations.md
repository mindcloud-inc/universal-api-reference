# List company work locations with Doyle HCM

Retrieves company work locations from Doyle HCM.

## Endpoint

- **Method:** `GET`
- **Path:** `/wep/companies/:companyId/worklocations`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [List company work locations](https://apidocs.worklio.com/docs/work-with-work-locations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
