# Get dashboard with Doyle HCM

Retrieves the current admin dashboard definition from Doyle HCM.

## Endpoint

- **Method:** `GET`
- **Path:** `/wep/dashboard`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [Get dashboard](https://apidocs.worklio.com/reference/get_wep-dashboard-1)
