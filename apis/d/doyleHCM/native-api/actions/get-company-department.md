# Get company department with Doyle HCM

Retrieves a company department from Doyle HCM.

## Endpoint

- **Method:** `GET`
- **Path:** `/wep/companies/:companyId/departments/:departmentId`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [Get company department](https://apidocs.worklio.com/reference/get_wep-companies-companyid-departments-departmentid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
| `departmentId` | path | `number` | yes |
