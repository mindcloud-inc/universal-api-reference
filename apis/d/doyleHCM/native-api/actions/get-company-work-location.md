# Get company work location with Doyle HCM

Retrieves a company work location from Doyle HCM.

## Endpoint

- **Method:** `GET`
- **Path:** `/wep/companies/:companyId/worklocations/:wlocationId`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [Get company work location](https://apidocs.worklio.com/reference/get_wep-companies-companyid-worklocations-wlocationid-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
| `wlocationId` | path | `number` | yes |
