# Get company KYC document type with Doyle HCM

Retrieves a company KYC document type from Doyle HCM.

## Endpoint

- **Method:** `GET`
- **Path:** `/wep/companies/:companyId/kyc/documenttypes/:key`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [Get company KYC document type](https://apidocs.worklio.com/reference/get_wep-companies-companyid-kyc-documenttypes-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
| `key` | path | `string` | yes |
