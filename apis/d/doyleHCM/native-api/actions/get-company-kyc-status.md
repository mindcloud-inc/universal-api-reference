# Get company KYC status with Doyle HCM

- **Method:** `GET`
- **Path:** `/wep/companies/:companyId/kyc`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [Get company KYC status](https://apidocs.worklio.com/reference/get_wep-companies-companyid-kyc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
