# Get company with Doyle HCM

Retrieves a company from Doyle HCM by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/wep/companies/:companyId`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [Get company](https://apidocs.worklio.com/reference/get_wep-companies-companyid.md)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
