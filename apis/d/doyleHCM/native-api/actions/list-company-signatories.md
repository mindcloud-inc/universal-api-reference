# List company signatories with Doyle HCM

Retrieves company signatories from Doyle HCM.

## Endpoint

- **Method:** `GET`
- **Path:** `/wep/companies/:companyId/signatories`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [List company signatories](https://apidocs.worklio.com/reference/get_wep-companies-companyid-signatories)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
