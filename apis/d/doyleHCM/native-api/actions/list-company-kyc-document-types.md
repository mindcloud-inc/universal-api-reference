# List company KYC document types with Doyle HCM

Retrieves company KYC document types from Doyle HCM.

## Endpoint

- **Method:** `GET`
- **Path:** `/wep/companies/:companyId/kyc/documenttypes`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [List company KYC document types](https://apidocs.worklio.com/reference/get_wep-companies-companyid-kyc-documenttypes)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
