# Get company access policy with Doyle HCM

Retrieves the company access policy from Doyle HCM.

## Endpoint

- **Method:** `GET`
- **Path:** `/wep/companies/:companyId/access-policy`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [Get company access policy](https://apidocs.worklio.com/reference/get_wep-companies-companyid-access-policy)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
