# Get company dashboard with Doyle HCM

Retrieves a company dashboard definition from Doyle HCM.

## Endpoint

- **Method:** `GET`
- **Path:** `/wep/companies/:companyId/dashboard`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [Get company dashboard](https://apidocs.worklio.com/reference/get_wep-companies-companyid-dashboard-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
