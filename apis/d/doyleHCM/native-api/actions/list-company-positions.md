# List company positions with Doyle HCM

Retrieves company positions from Doyle HCM.

## Endpoint

- **Method:** `GET`
- **Path:** `/wep/companies/:companyId/positions`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [List company positions](https://apidocs.worklio.com/reference/get_wep-companies-companyid-positions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
