# List company departments with Doyle HCM

Retrieves company departments from Doyle HCM.

## Endpoint

- **Method:** `GET`
- **Path:** `/wep/companies/:companyId/departments`
- **Base URL:** `https://api.worklio.com`
- **Official documentation:** [List company departments](https://apidocs.worklio.com/reference/get_wep-companies-companyid-departments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
