# List Timesheets with Deel

Retrieves a paginated list of timesheets from Deel.

## Endpoint

- **Method:** `GET`
- **Path:** `/timesheets`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [List Timesheets](https://developer.deel.com/api/endpoints/timesheets/get-timesheets)
