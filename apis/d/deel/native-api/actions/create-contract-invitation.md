# Create Contract Invitation with Deel

Sends a contract invitation to a worker in Deel.

## Endpoint

- **Method:** `POST`
- **Path:** `/contracts/:contract_id/invitations`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [Create Contract Invitation](https://developer.deel.com/api/endpoints/contractor-hiring/create-contract-invitation)
