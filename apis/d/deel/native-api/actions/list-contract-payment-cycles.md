# List Contract Payment Cycles with Deel

Retrieves contract payment cycles from Deel.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts/:contract_id/payment_cycles`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [List Contract Payment Cycles](https://developer.deel.com/api/endpoints/contractor-hiring/get-contract-payment-cycles)
