# List Contract Amendments with Deel

Retrieves the amendments for a contract from Deel.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts/:contract_id/amendments`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [List Contract Amendments](https://developer.deel.com/api/endpoints/contractor-amendments/get-contract-amendments)
