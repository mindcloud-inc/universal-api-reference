# Delete Contract Adjustment with Deel

Deletes an existing contract adjustment from Deel.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/adjustments/:id`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [Delete Contract Adjustment](https://developer.deel.com/api/endpoints/adjustments/delete-contract-adjustment)
