# Get Contract Invite with Deel

Retrieves the contract invite link from Deel.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts/:contract_id/invite`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [Get Contract Invite](https://developer.deel.com/api/endpoints/contractor-hiring/get-contract-invite)
