# List Contract Milestones with Deel

Retrieves milestones for a contract from Deel.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts/:contract_id/milestones`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [List Contract Milestones](https://developer.deel.com/api/endpoints/milestones/get-contract-milestones)
