# Create Contract Document with Deel

Attaches a document to a contract in Deel.

## Endpoint

- **Method:** `POST`
- **Path:** `/contracts/:contract_id/documents`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [Create Contract Document](https://developer.deel.com/api/endpoints/contractor-hiring/create-contract-document)
