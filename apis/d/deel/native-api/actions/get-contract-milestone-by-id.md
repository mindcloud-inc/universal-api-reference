# Get Contract Milestone by ID with Deel

Retrieves a contract milestone from Deel by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts/:contract_id/milestones/:milestone_id`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [Get Contract Milestone by ID](https://developer.deel.com/api/endpoints/milestones/get-contract-milestone-by-id)
