# Delete Contract Task with Deel

Deletes an existing contract task from Deel.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contracts/:contract_id/tasks/:task_id`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [Delete Contract Task](https://developer.deel.com/api/endpoints/tasks/delete-contract-task)
