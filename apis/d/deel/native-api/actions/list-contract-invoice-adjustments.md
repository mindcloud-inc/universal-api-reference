# List Contract Invoice Adjustments with Deel

Retrieves invoice adjustments for a contract from Deel.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts/:contract_id/invoice-adjustments`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [List Contract Invoice Adjustments](https://developer.deel.com/api/endpoints/invoice-adjustments/get-contract-invoice-adjustments)
