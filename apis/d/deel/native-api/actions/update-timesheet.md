# Update Timesheet with Deel

Updates an existing timesheet in Deel.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/timesheets/:id`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [Update Timesheet](https://developer.deel.com/api/endpoints/timesheets/update-timesheet)
