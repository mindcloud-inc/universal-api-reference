# Create Contract Milestone with Deel

Creates a contract milestone in Deel.

## Endpoint

- **Method:** `POST`
- **Path:** `/contracts/:contract_id/milestones`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [Create Contract Milestone](https://developer.deel.com/api/endpoints/milestones/create-contract-milestone)
