# Delete Contract Milestone with Deel

Deletes an existing contract milestone from Deel.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contracts/:contract_id/milestones/:milestone_id`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [Delete Contract Milestone](https://developer.deel.com/api/endpoints/milestones/delete-contract-milestone)
