# Delete Invoice Adjustment with Deel

Deletes an existing invoice adjustment from Deel.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/invoice-adjustments/:id`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [Delete Invoice Adjustment](https://developer.deel.com/api/endpoints/invoice-adjustments/delete-invoice-adjustment)
