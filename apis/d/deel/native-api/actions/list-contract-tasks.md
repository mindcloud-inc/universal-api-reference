# List Contract Tasks with Deel

Retrieves tasks for a contract from Deel.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts/:contract_id/tasks`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [List Contract Tasks](https://developer.deel.com/api/endpoints/tasks/get-contract-tasks)
