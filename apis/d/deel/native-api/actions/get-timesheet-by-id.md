# Get Timesheet by ID with Deel

Retrieves a timesheet from Deel by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/timesheets/:id`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [Get Timesheet by ID](https://developer.deel.com/api/endpoints/timesheets/get-timesheet-by-id)
