# List Contract Adjustments with Deel

Retrieves adjustments for a contract from Deel.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts/:contract_id/adjustments`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [List Contract Adjustments](https://developer.deel.com/api/endpoints/adjustments/get-contract-adjustments)
