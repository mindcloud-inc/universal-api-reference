# List Invoice Adjustments with Deel

Retrieves the invoice adjustments from Deel.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoice-adjustments`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [List Invoice Adjustments](https://developer.deel.com/api/endpoints/invoice-adjustments/get-invoice-adjustments)
