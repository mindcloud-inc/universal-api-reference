# Get Invoice Adjustment by ID with Deel

Retrieves an invoice adjustment from Deel by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoice-adjustments/:id`
- **Base URL:** `https://api.letsdeel.com/rest/v2`
- **Official documentation:** [Get Invoice Adjustment by ID](https://developer.deel.com/api/endpoints/invoice-adjustments/get-invoice-adjustment-by-id)
