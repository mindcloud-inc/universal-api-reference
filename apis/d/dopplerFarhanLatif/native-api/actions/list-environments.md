# List Environments with Doppler Farhan Latif

Retrieves environments from a Doppler project.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/environments`
- **Base URL:** `https://api.doppler.com`
- **Official documentation:** [List Environments](https://docs.doppler.com/reference/environments-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | query | `string` | yes | The project's name. |
