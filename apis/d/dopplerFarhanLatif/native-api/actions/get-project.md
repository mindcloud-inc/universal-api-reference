# Get Project with Doppler Farhan Latif

Retrieves project details from Doppler.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/projects/project`
- **Base URL:** `https://api.doppler.com`
- **Official documentation:** [Get Project](https://docs.doppler.com/reference/projects-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | query | `string` | yes | Unique identifier for the project object. |
