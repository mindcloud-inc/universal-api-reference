# Product Photo Unification with DeepImage

Creates a unified product photo in DeepImage.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest_api/process_result`
- **Base URL:** `https://deep-image.ai`
- **Official documentation:** [Product Photo Unification](https://documentation.deep-image.ai/common-usecases/product-photo-unification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Public URL of the product image to normalize. |
