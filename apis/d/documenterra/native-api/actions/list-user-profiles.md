# List User Profiles with Documenterra

Retrieves user profiles from Documenterra.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://mindclouddocumenterra.try.documenterra.net/api/v1`
- **Official documentation:** [List User Profiles](https://docs.documenterra.ru/articles/rukovodstvo-polzovatelya-dokumenterry/api-poluchenie-profiley-polzovateley)
