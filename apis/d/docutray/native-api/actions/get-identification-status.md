# Get Identification Status with Docutray

## Endpoint

- **Method:** `GET`
- **Path:** `api/identify-async/status/:id`
- **Base URL:** `https://app.docutray.com`
- **Official documentation:** [Get Identification Status](https://docs.docutray.com/docs/operations/identify)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identification ID to check |
