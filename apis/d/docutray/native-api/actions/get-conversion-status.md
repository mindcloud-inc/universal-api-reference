# Get Conversion Status with Docutray

## Endpoint

- **Method:** `GET`
- **Path:** `api/convert-async/status/:id`
- **Base URL:** `https://app.docutray.com`
- **Official documentation:** [Get Conversion Status](https://docs.docutray.com/docs/operations/convert)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique conversion ID to check |
