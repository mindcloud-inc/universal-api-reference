# Get Document Type with Docutray

## Endpoint

- **Method:** `GET`
- **Path:** `api/document-types/:id`
- **Base URL:** `https://app.docutray.com`
- **Official documentation:** [Get Document Type](https://docs.docutray.com/docs/operations/document-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Document type ID |
