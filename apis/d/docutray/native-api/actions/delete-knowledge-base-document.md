# Delete Knowledge Base Document with Docutray

## Endpoint

- **Method:** `DELETE`
- **Path:** `api/knowledge-bases/:id/documents/:documentId`
- **Base URL:** `https://app.docutray.com`
- **Official documentation:** [Delete Knowledge Base Document](https://docs.docutray.com/docs/operations/knowledge-bases)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | Unique ID of the document |
| `id` | path | `string` | yes | Unique ID of the Knowledge Base |
