# List Document Types with Docutray

## Endpoint

- **Method:** `GET`
- **Path:** `api/document-types`
- **Base URL:** `https://app.docutray.com`
- **Official documentation:** [List Document Types](https://docs.docutray.com/docs/api/document-types/listDocumentTypes)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search by name, code, or description of the document type |
