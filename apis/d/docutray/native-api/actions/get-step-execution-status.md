# Get Step Execution Status with Docutray

## Endpoint

- **Method:** `GET`
- **Path:** `api/steps-async/status/:executionId`
- **Base URL:** `https://app.docutray.com`
- **Official documentation:** [Get Step Execution Status](https://docs.docutray.com/docs/operations/steps)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `executionId` | path | `string` | yes | Step execution ID returned from the execute step endpoint |
