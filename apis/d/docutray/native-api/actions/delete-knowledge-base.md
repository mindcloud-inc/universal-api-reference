# Delete Knowledge Base with Docutray

## Endpoint

- **Method:** `DELETE`
- **Path:** `api/knowledge-bases/:id`
- **Base URL:** `https://app.docutray.com`
- **Official documentation:** [Delete Knowledge Base](https://docs.docutray.com/docs/operations/knowledge-bases)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of the Knowledge Base |
