# List Texts with DialMyCalls

Retrieves a list of texts from DialMyCalls.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/texts`
- **Base URL:** `https://{apiKey}@api.dialmycalls.com/2.0`
- **Official documentation:** [List Texts](https://www.dialmycalls.com/api-documentation#texts-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
