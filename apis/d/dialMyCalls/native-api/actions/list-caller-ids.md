# List Caller IDs with DialMyCalls

Retrieves a list of caller IDs from DialMyCalls.

## Endpoint

- **Method:** `GET`
- **Path:** `/callerids`
- **Base URL:** `https://{apiKey}@api.dialmycalls.com/2.0`
- **Official documentation:** [List Caller IDs](https://www.dialmycalls.com/api-documentation#callerids-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
