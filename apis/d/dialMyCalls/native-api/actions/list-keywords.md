# List Keywords with DialMyCalls

Retrieves a list of keywords from DialMyCalls.

## Endpoint

- **Method:** `GET`
- **Path:** `/keywords`
- **Base URL:** `https://{apiKey}@api.dialmycalls.com/2.0`
- **Official documentation:** [List Keywords](https://www.dialmycalls.com/api-documentation#keywords-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
