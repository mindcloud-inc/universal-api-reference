# Get Group with DialMyCalls

Retrieves a group from DialMyCalls.

## Endpoint

- **Method:** `GET`
- **Path:** `/group/:GroupId`
- **Base URL:** `https://{apiKey}@api.dialmycalls.com/2.0`
- **Official documentation:** [Get Group](https://www.dialmycalls.com/api-documentation#group-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `GroupId` | path | `string` | yes | The DialMyCalls group ID to retrieve. |
