# List Recordings with DialMyCalls

Retrieves a list of recordings from DialMyCalls.

## Endpoint

- **Method:** `GET`
- **Path:** `/recordings`
- **Base URL:** `https://{apiKey}@api.dialmycalls.com/2.0`
- **Official documentation:** [List Recordings](https://www.dialmycalls.com/api-documentation#recordings-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
