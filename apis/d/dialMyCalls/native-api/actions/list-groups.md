# List Groups with DialMyCalls

Retrieves a list of groups from DialMyCalls.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://{apiKey}@api.dialmycalls.com/2.0`
- **Official documentation:** [List Groups](https://www.dialmycalls.com/api-documentation#groups-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
