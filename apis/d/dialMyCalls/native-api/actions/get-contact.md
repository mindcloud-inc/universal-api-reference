# Get Contact with DialMyCalls

Retrieves a contact record from DialMyCalls.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/:ContactId`
- **Base URL:** `https://{apiKey}@api.dialmycalls.com/2.0`
- **Official documentation:** [Get Contact](https://www.dialmycalls.com/api-documentation#contact-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ContactId` | path | `string` | yes | The DialMyCalls contact ID to retrieve. |
