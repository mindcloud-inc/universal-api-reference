# Add Group with DialMyCalls

Creates a new group in DialMyCalls.

## Endpoint

- **Method:** `POST`
- **Path:** `/group`
- **Base URL:** `https://{apiKey}@api.dialmycalls.com/2.0`
- **Official documentation:** [Add Group](https://www.dialmycalls.com/api-documentation#group-add)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The contact group's name. |
