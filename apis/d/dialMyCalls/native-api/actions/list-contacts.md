# List Contacts with DialMyCalls

Retrieves a list of contacts from DialMyCalls.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://{apiKey}@api.dialmycalls.com/2.0`
- **Official documentation:** [List Contacts](https://www.dialmycalls.com/api-documentation#contacts-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
