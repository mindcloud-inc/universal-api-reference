# Get Account with DialMyCalls

Retrieves your account details from DialMyCalls.

## Endpoint

- **Method:** `GET`
- **Path:** `/account`
- **Base URL:** `https://{apiKey}@api.dialmycalls.com/2.0`
- **Official documentation:** [Get Account](https://www.dialmycalls.com/api-documentation#account-get)
