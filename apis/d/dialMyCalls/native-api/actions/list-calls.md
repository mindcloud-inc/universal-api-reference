# List Calls with DialMyCalls

Retrieves a list of calls from DialMyCalls.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/calls`
- **Base URL:** `https://{apiKey}@api.dialmycalls.com/2.0`
- **Official documentation:** [List Calls](https://www.dialmycalls.com/api-documentation#calls-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
