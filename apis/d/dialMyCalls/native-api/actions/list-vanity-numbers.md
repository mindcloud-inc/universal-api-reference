# List Vanity Numbers with DialMyCalls

Retrieves available vanity numbers from DialMyCalls.

## Endpoint

- **Method:** `GET`
- **Path:** `/vanitynumbers`
- **Base URL:** `https://{apiKey}@api.dialmycalls.com/2.0`
- **Official documentation:** [List Vanity Numbers](https://www.dialmycalls.com/api-documentation#vanitynumbers-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
