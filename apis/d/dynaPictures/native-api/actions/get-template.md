# Get Template with DynaPictures

Retrieves a template from DynaPictures by UID.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:uid`
- **Base URL:** `https://api.dynapictures.com`
- **Official documentation:** [Get Template](https://dynapictures.com/docs/#get-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `UID` | path | `string` | yes | UID of the template to load. |
