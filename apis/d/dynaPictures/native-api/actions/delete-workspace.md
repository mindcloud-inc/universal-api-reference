# Delete Workspace with DynaPictures

Deletes an existing workspace from DynaPictures.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workspaces/:id`
- **Base URL:** `https://api.dynapictures.com`
- **Official documentation:** [Delete Workspace](https://dynapictures.com/docs/#delete-workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ID` | path | `string` | yes | ID of the workspace to delete. |
