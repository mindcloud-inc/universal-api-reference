# Create Workspace with DynaPictures

Creates a workspace in DynaPictures.

## Endpoint

- **Method:** `POST`
- **Path:** `/workspaces`
- **Base URL:** `https://api.dynapictures.com`
- **Official documentation:** [Create Workspace](https://dynapictures.com/docs/#create-workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the new workspace. |
