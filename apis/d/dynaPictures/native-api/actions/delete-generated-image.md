# Delete Generated Image with DynaPictures

Deletes a generated image from DynaPictures.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/images/:imagePath`
- **Base URL:** `https://api.dynapictures.com`
- **Official documentation:** [Delete Generated Image](https://dynapictures.com/docs/#delete-generated-image)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `IMAGE_PATH` | path | `string` | yes | Subpath of the generated image returned by DynaPictures. |
