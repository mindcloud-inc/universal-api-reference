# Get Profile with DoneDone

Retrieves your DoneDone profile.

## Endpoint

- **Method:** `GET`
- **Path:** `/:account_id/profile`
- **Base URL:** `https://2.donedone.com/public-api`
- **Official documentation:** [Get Profile](https://donedone.com/help-docs/public-api-webhooks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `number` | yes | DoneDone account ID. |
