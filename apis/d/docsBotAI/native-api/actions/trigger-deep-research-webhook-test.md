# Trigger Deep Research Webhook Test with DocsBot AI

Triggers a deep research webhook delivery test in DocsBot AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/teams/:teamId/bots/:botId/webhooks/deliver-research`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Trigger Deep Research Webhook Test](https://docsbot.ai/documentation/developer/webhooks-api)
