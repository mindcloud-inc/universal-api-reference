# Delete Webhook with DocsBot AI

Deletes an existing webhook from DocsBot AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/teams/:teamId/bots/:botId/webhooks/:webhookId`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Delete Webhook](https://docsbot.ai/documentation/developer/webhooks-api)
