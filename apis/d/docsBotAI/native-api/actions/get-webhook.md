# Get Webhook with DocsBot AI

Retrieves a webhook from DocsBot AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/bots/:botId/webhooks/:webhookId`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Get Webhook](https://docsbot.ai/documentation/developer/webhooks-api)
