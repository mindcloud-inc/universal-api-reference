# Get Team with DocsBot AI

Retrieves a team from DocsBot AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Get Team](https://docsbot.ai/documentation/developer/team-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | The DocsBot team ID. |
