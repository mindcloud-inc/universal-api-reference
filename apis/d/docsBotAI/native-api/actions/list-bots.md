# List Bots with DocsBot AI

Retrieves bots from DocsBot AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/bots`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [List Bots](https://docsbot.ai/documentation/developer/bot-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | The DocsBot team ID. |
