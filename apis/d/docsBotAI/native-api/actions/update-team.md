# Update Team with DocsBot AI

Updates an existing team in DocsBot AI.

## Endpoint

- **Method:** `PUT`
- **Path:** `/teams/:teamId`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Update Team](https://docsbot.ai/documentation/developer/team-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | The DocsBot team ID. |
