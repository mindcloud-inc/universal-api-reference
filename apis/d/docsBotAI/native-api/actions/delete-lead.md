# Delete Lead with DocsBot AI

Deletes an existing lead from DocsBot AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/teams/:teamId/bots/:botId/leads/:leadId`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Delete Lead](https://docsbot.ai/documentation/developer/leads-api)
