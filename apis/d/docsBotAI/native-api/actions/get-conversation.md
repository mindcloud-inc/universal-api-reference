# Get Conversation with DocsBot AI

Retrieves a conversation from DocsBot AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/bots/:botId/conversations/:conversationId`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Get Conversation](https://docsbot.ai/documentation/developer/conversations-api)
