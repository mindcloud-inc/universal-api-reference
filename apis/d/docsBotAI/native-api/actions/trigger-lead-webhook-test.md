# Trigger Lead Webhook Test with DocsBot AI

Triggers a lead webhook delivery test in DocsBot AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/teams/:teamId/bots/:botId/webhooks/deliver-lead`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Trigger Lead Webhook Test](https://docsbot.ai/documentation/developer/webhooks-api)
