# Create Bot with DocsBot AI

Creates a new bot in DocsBot AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/teams/:teamId/bots`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Create Bot](https://docsbot.ai/documentation/developer/bot-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | The DocsBot team ID. |
