# Respond to Team Invite with DocsBot AI

Updates a team invite response in DocsBot AI.

## Endpoint

- **Method:** `PUT`
- **Path:** `/teams/:teamId/invite`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Respond to Team Invite](https://docsbot.ai/documentation/developer/team-members-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | The DocsBot team ID. |
