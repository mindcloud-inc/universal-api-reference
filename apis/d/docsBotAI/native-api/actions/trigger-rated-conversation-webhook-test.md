# Trigger Rated Conversation Webhook Test with DocsBot AI

Triggers a rated conversation webhook test in DocsBot AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/teams/:teamId/bots/:botId/webhooks/deliver-rated`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Trigger Rated Conversation Webhook Test](https://docsbot.ai/documentation/developer/webhooks-api)
