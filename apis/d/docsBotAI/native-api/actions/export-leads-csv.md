# Export Leads CSV with DocsBot AI

Retrieves a leads CSV export from DocsBot AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/bots/:botId/leads/export`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Export Leads CSV](https://docsbot.ai/documentation/developer/leads-api)
