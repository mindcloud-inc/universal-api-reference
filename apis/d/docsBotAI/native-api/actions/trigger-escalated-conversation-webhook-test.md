# Trigger Escalated Conversation Webhook Test with DocsBot AI

Triggers an escalated conversation webhook test in DocsBot AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/teams/:teamId/bots/:botId/webhooks/deliver-escalated`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Trigger Escalated Conversation Webhook Test](https://docsbot.ai/documentation/developer/webhooks-api)
