# Update Webhook with DocsBot AI

Updates an existing webhook in DocsBot AI.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/teams/:teamId/bots/:botId/webhooks/:webhookId`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Update Webhook](https://docsbot.ai/documentation/developer/webhooks-api)
