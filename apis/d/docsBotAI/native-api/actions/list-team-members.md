# List Team Members with DocsBot AI

Retrieves team members from DocsBot AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/members`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [List Team Members](https://docsbot.ai/documentation/developer/team-members-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | The DocsBot team ID. |
