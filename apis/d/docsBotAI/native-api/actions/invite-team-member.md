# Invite Team Member with DocsBot AI

Creates a team invite in DocsBot AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/teams/:teamId/invite`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Invite Team Member](https://docsbot.ai/documentation/developer/team-members-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | The DocsBot team ID. |
