# Delete Conversation with DocsBot AI

Deletes an existing conversation from DocsBot AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/teams/:teamId/bots/:botId/conversations/:conversationId`
- **Base URL:** `https://docsbot.ai/api`
- **Official documentation:** [Delete Conversation](https://docsbot.ai/documentation/developer/conversations-api)
