# Restore Record Version with DatoCMS

## Endpoint

- **Method:** `POST`
- **Path:** `/versions/:versionId/restore`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Restore Record Version](https://www.datocms.com/docs/content-management-api/resources/item-version/restore)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `versionId` | path | `string` | yes | Record version ID. |
