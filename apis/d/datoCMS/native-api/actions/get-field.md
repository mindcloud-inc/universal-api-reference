# Get Field with DatoCMS

## Endpoint

- **Method:** `GET`
- **Path:** `/fields/:fieldId`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Get Field](https://www.datocms.com/docs/content-management-api/resources/field/self)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fieldId` | path | `string` | yes | Field ID. |
