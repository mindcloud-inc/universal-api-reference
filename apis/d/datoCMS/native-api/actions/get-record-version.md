# Get Record Version with DatoCMS

## Endpoint

- **Method:** `GET`
- **Path:** `/versions/:versionId`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Get Record Version](https://www.datocms.com/docs/content-management-api/resources/item-version/self)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `versionId` | path | `string` | yes | Record version ID. |
