# List Referenced Records for Record with DatoCMS

## Endpoint

- **Method:** `GET`
- **Path:** `/items/:itemId/references`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [List Referenced Records for Record](https://www.datocms.com/docs/content-management-api/resources/item/references)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | yes | Record ID. |
