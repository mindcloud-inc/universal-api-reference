# List Referenced Records for Upload with DatoCMS

## Endpoint

- **Method:** `GET`
- **Path:** `/uploads/:uploadId/references`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [List Referenced Records for Upload](https://www.datocms.com/docs/content-management-api/resources/upload/references)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uploadId` | path | `string` | yes | Upload ID. |
