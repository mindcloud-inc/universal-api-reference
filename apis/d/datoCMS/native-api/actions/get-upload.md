# Get Upload with DatoCMS

## Endpoint

- **Method:** `GET`
- **Path:** `/uploads/:uploadId`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Get Upload](https://www.datocms.com/docs/content-management-api/resources/upload/self)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uploadId` | path | `string` | yes | Upload ID. |
