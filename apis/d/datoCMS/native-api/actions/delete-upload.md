# Delete Upload with DatoCMS

## Endpoint

- **Method:** `DELETE`
- **Path:** `/uploads/:uploadId`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Delete Upload](https://www.datocms.com/docs/content-management-api/resources/upload/destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uploadId` | path | `string` | yes | Upload ID. |
