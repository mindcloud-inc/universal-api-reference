# Delete Field with DatoCMS

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fields/:fieldId`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Delete Field](https://www.datocms.com/docs/content-management-api/resources/field/destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fieldId` | path | `string` | yes | Field ID. |
