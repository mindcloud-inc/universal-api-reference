# Duplicate Record with DatoCMS

## Endpoint

- **Method:** `POST`
- **Path:** `/items/:itemId/duplicate`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Duplicate Record](https://www.datocms.com/docs/content-management-api/resources/item/duplicate)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemId` | path | `string` | yes |
