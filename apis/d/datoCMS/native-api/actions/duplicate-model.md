# Duplicate Model with DatoCMS

## Endpoint

- **Method:** `POST`
- **Path:** `/item-types/:itemTypeId/duplicate`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Duplicate Model](https://www.datocms.com/docs/content-management-api/resources/item-type/duplicate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemTypeId` | path | `string` | yes | Model ID or API key. |
