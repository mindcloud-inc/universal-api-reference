# Get Model with DatoCMS

## Endpoint

- **Method:** `GET`
- **Path:** `/item-types/:itemTypeId`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Get Model](https://www.datocms.com/docs/content-management-api/resources/item-type/self)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemTypeId` | path | `string` | yes | Model ID or API key. |
