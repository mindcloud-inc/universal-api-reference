# List Model Fields with DatoCMS

## Endpoint

- **Method:** `GET`
- **Path:** `/item-types/:model_id_or_api_key/fields`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [List Model Fields](https://www.datocms.com/docs/content-management-api/resources/field/instances)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `model_id_or_api_key` | path | `string` | yes |
