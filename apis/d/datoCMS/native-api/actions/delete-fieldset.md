# Delete Fieldset with DatoCMS

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fieldsets/:fieldsetId`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Delete Fieldset](https://www.datocms.com/docs/content-management-api/resources/fieldset/destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fieldsetId` | path | `string` | yes | Fieldset ID. |
