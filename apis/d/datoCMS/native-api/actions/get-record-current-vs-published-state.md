# Get Record Current vs Published State with DatoCMS

## Endpoint

- **Method:** `GET`
- **Path:** `/items/:itemId/current-vs-published-state`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Get Record Current vs Published State](https://www.datocms.com/docs/content-management-api/resources/item/current_vs_published_state)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemId` | path | `string` | yes |
