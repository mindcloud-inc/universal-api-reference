# Duplicate Field with DatoCMS

## Endpoint

- **Method:** `POST`
- **Path:** `/fields/:fieldId/duplicate`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Duplicate Field](https://www.datocms.com/docs/content-management-api/resources/field/duplicate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fieldId` | path | `string` | yes | Field ID. |
