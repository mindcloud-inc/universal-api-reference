# Delete Record with DatoCMS

## Endpoint

- **Method:** `DELETE`
- **Path:** `/items/:itemId`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [Delete Record](https://www.datocms.com/docs/content-management-api/resources/item/destroy)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemId` | path | `string` | yes |
