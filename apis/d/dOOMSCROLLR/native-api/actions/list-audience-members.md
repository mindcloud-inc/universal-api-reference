# List Audience Members with DOOMSCROLLR

## Endpoint

- **Method:** `GET`
- **Path:** `/api/audience/list`
- **Base URL:** `https://mindcloudapps0402.doomscrollr.com`
- **Official documentation:** [List Audience Members](https://doomscrollr.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `per_page` | query | `number` | no | Maximum number of audience members to return. The docs example uses 100. |
