# List Content Posts with DOOMSCROLLR

## Endpoint

- **Method:** `GET`
- **Path:** `/api/content/posts`
- **Base URL:** `https://mindcloudapps0402.doomscrollr.com`
- **Official documentation:** [List Content Posts](https://doomscrollr.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `per_page` | query | `number` | no | Maximum number of posts to return. The docs example uses 100. |
