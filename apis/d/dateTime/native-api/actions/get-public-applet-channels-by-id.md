# Get Public Applet Channels By ID with Date & Time

## Endpoint

- **Method:** `POST`
- **Path:** `api/v3/graph`
- **Base URL:** `https://ifttt.com/`
- **Official documentation:** [Get Public Applet Channels By ID](https://ifttt.com/date_and_time)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.id` | body | `string` | no | IFTTT public applet ID. |
