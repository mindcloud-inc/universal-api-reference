# Get Trigger Ingredients By Module Name with Date & Time

## Endpoint

- **Method:** `POST`
- **Path:** `api/v3/graph`
- **Base URL:** `https://ifttt.com/`
- **Official documentation:** [Get Trigger Ingredients By Module Name](https://ifttt.com/date_and_time/triggers/every_day_at)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.module` | body | `string` | no | Full IFTTT trigger module name such as date_and_time.every_day_at. |
