# List Date & Time + Email Digest Applets with Date & Time

## Endpoint

- **Method:** `POST`
- **Path:** `api/v3/graph`
- **Base URL:** `https://ifttt.com/`
- **Official documentation:** [List Date & Time + Email Digest Applets](https://ifttt.com/date_and_time)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.limit` | body | `number` | no | Maximum number of applets to return. |
| `variables.offset` | body | `number` | no | Number of applets to skip before returning results. |
