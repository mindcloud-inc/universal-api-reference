# Get Trigger Fields By ID with Date & Time

## Endpoint

- **Method:** `POST`
- **Path:** `api/v3/graph`
- **Base URL:** `https://ifttt.com/`
- **Official documentation:** [Get Trigger Fields By ID](https://ifttt.com/date_and_time/triggers/every_day_at)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.id` | body | `number` | no | IFTTT trigger numeric ID. |
