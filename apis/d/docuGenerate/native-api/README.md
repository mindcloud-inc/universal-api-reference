# DocuGenerate: Native API Reference

A consolidated summary of DocuGenerate's API configuration, with links to official documentation.

- **Official docs:** https://api.docugenerate.com
- **OpenAPI specification:** https://www.docugenerate.com/assets/articles/developers/reference/002-openapi-specification/docugenerate-api-1.8.4.json
- **API base URL:** `https://api.docugenerate.com`

## Authentication

### API Key

Connect with your DocuGenerate API key.

### Credentials

- **API Key:** `apiKey` · required

Send these headers with each API request:

```http
Authorization: <apiKey>
```

[Official authentication documentation](https://www.docugenerate.com/developers/quickstart/)

## API conventions

Responses from this API use JSON.
