# Deactivate Template with Disparo PRO

Updates a template to inactive in Disparo PRO.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/template/deactivate/:id`
- **Base URL:** `https://gateway.disparopro.com.br/rcs`
- **Official documentation:** [Deactivate Template](https://painel.disparopro.com.br/docs/rcs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Template ID to deactivate. |
