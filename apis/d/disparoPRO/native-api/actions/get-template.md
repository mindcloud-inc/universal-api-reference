# Get Template with Disparo PRO

Retrieves a template from Disparo PRO.

## Endpoint

- **Method:** `GET`
- **Path:** `/template/:id`
- **Base URL:** `https://gateway.disparopro.com.br/rcs`
- **Official documentation:** [Get Template](https://painel.disparopro.com.br/docs/rcs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Template ID to find. |
