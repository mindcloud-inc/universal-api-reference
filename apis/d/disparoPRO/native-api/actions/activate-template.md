# Activate Template with Disparo PRO

Updates a template to active in Disparo PRO.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/template/activate/:id`
- **Base URL:** `https://gateway.disparopro.com.br/rcs`
- **Official documentation:** [Activate Template](https://painel.disparopro.com.br/docs/rcs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Template ID to activate. |
