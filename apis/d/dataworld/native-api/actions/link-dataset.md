# Link Dataset with data.world

Links a dataset to a project in data.world.

## Endpoint

- **Method:** `PUT`
- **Path:** `/projects/{owner}/{id}/linkedDatasets/{linkedDatasetOwner}/{linkedDatasetId}`
- **Base URL:** `https://api.data.world/v0`
- **Official documentation:** [Link Dataset](https://developer.data.world/reference/addlinkeddataset-1)
