# Retrieve a Dataset Version with data.world

Retrieves a dataset version from data.world.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasets/{owner}/{id}/v/{versionId}`
- **Base URL:** `https://api.data.world/v0`
- **Official documentation:** [Retrieve a Dataset Version](https://developer.data.world/reference/getdatasetbyversion-1)
