# Unlink Dataset with data.world

Unlinks a dataset from a project in data.world.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/{owner}/{id}/linkedDatasets/{linkedDatasetOwner}/{linkedDatasetId}`
- **Base URL:** `https://api.data.world/v0`
- **Official documentation:** [Unlink Dataset](https://developer.data.world/reference/removelinkeddataset-1)
