# Retrieve a Data Project Version with data.world

Retrieves a data project version from data.world.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{owner}/{id}/v/{versionId}`
- **Base URL:** `https://api.data.world/v0`
- **Official documentation:** [Retrieve a Data Project Version](https://developer.data.world/reference/getprojectbyversion-1)
