# List User Saved Queries with data.world

Retrieves user saved queries from data.world.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasets/{owner}/{id}/userQueries`
- **Base URL:** `https://api.data.world/v0`
- **Official documentation:** [List User Saved Queries](https://developer.data.world/reference/getusersaveddatasetqueries)
