# Execute a Saved Query (with Parameters) with data.world

Executes a saved query with parameters in data.world.

## Endpoint

- **Method:** `POST`
- **Path:** `/queries/{id}/results`
- **Base URL:** `https://api.data.world/v0`
- **Official documentation:** [Execute a Saved Query (with Parameters)](https://developer.data.world/reference/executequerywithpost-1)
