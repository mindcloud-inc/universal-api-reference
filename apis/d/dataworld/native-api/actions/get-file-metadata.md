# Get File Description and Labels with data.world

Retrieves file descriptions and labels from data.world.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasets/{owner}/{id}/files/{file}/metadata`
- **Base URL:** `https://api.data.world/v0`
- **Official documentation:** [Get File Description and Labels](https://developer.data.world/reference/getfilemetadata-1)
