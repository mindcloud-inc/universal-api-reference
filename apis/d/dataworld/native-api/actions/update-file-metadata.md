# Update File Description and Labels with data.world

Updates file descriptions and labels in data.world.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/datasets/{owner}/{id}/files/{file}/metadata`
- **Base URL:** `https://api.data.world/v0`
- **Official documentation:** [Update File Description and Labels](https://developer.data.world/reference/patchfilemetadata-1)
