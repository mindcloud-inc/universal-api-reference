# Sync Files (via GET) with data.world

Synchronizes dataset files in data.world using GET.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasets/{owner}/{id}/sync`
- **Base URL:** `https://api.data.world/v0`
- **Official documentation:** [Sync Files (via GET)](https://developer.data.world/reference/syncviaget-1)
