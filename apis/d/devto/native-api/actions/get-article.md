# Get Article with Dev.to

Retrieves a published Dev.to article by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/articles/:id`
- **Base URL:** `https://dev.to/api`
- **Official documentation:** [Get Article](https://developers.forem.com/api/v1#tag/articles/operation/getArticleById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric article ID. |
