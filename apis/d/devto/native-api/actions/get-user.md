# Get User with Dev.to

Retrieves a Dev.to user by ID or username.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://dev.to/api`
- **Official documentation:** [Get User](https://developers.forem.com/api/v1#tag/users/operation/getUser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | User ID or username. |
