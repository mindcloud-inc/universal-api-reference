# Get Comment with Dev.to

Retrieves a Dev.to comment and its descendant comments by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/comments/:id`
- **Base URL:** `https://dev.to/api`
- **Official documentation:** [Get Comment](https://developers.forem.com/api/v1#tag/comments/operation/getCommentById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Comment ID code. |
