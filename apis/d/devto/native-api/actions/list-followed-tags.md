# List Followed Tags with Dev.to

Lists the tags followed by the authenticated Dev.to user.

## Endpoint

- **Method:** `GET`
- **Path:** `/follows/tags`
- **Base URL:** `https://dev.to/api`
- **Official documentation:** [List Followed Tags](https://developers.forem.com/api/v1#tag/followed_tags/operation/getFollowedTags)
