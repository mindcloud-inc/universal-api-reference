# List Followers with Dev.to

Lists the followers of the authenticated Dev.to user.

## Endpoint

- **Method:** `GET`
- **Path:** `/followers/users`
- **Base URL:** `https://dev.to/api`
- **Official documentation:** [List Followers](https://developers.forem.com/api/v1#tag/followers/operation/getFollowers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
