# List Tags with Dev.to

Lists tags that can be used on Dev.to articles.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://dev.to/api`
- **Official documentation:** [List Tags](https://developers.forem.com/api/v1#tag/tags/operation/getTags)

## Capabilities

This operation supports [pagination](../README.md#pagination).
