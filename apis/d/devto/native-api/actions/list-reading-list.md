# List Reading List with Dev.to

Lists articles saved to the authenticated user's Dev.to reading list.

## Endpoint

- **Method:** `GET`
- **Path:** `/readinglist`
- **Base URL:** `https://dev.to/api`
- **Official documentation:** [List Reading List](https://developers.forem.com/api/v1#tag/readinglist/operation/getReadinglist)

## Capabilities

This operation supports [pagination](../README.md#pagination).
