# Get Organization with Dev.to

Retrieves a Dev.to organization by username.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:username`
- **Base URL:** `https://dev.to/api`
- **Official documentation:** [Get Organization](https://developers.forem.com/api/v1#tag/organizations/operation/getOrganization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Organization username. |
