# List Latest Articles with Dev.to

Lists published Dev.to articles sorted by newest publish date.

## Endpoint

- **Method:** `GET`
- **Path:** `/articles/latest`
- **Base URL:** `https://dev.to/api`
- **Official documentation:** [List Latest Articles](https://developers.forem.com/api/v1#tag/articles/operation/getLatestArticles)

## Capabilities

This operation supports [pagination](../README.md#pagination).
