# Get Generated Image Detail with Duply

Retrieves details for a generated image from Duply.

## Endpoint

- **Method:** `GET`
- **Path:** `/generate/:generateId`
- **Base URL:** `https://gen.duply.co/v1`
- **Official documentation:** [Get Generated Image Detail](https://app.duply.co/docs#get-generate-api-detail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `generateId` | path | `string` | yes | The generated image ID to fetch. |
