# Get Generated Video Detail with Duply

Retrieves details for a generated video from Duply.

## Endpoint

- **Method:** `GET`
- **Path:** `/generate-video/:generateId`
- **Base URL:** `https://gen.duply.co/v1`
- **Official documentation:** [Get Generated Video Detail](https://app.duply.co/docs#get-generate-api-video-detail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `generateId` | path | `string` | yes | The generated video ID to fetch. |
