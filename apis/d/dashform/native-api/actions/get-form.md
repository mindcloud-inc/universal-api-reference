# Get Form with Dashform

Retrieves a form from Dashform.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/forms/:id`
- **Base URL:** `https://getaiform.com`
- **Official documentation:** [Get Form](https://github.com/makloai/dashform-cli-docs#forms-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Dashform form ID or public ID from the list action. |
