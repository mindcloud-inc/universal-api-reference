# Delete Form with Dashform

Deletes a form from Dashform.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/forms/:id`
- **Base URL:** `https://getaiform.com`
- **Official documentation:** [Delete Form](https://github.com/makloai/dashform-cli-docs#forms-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Dashform form ID or public ID. |
