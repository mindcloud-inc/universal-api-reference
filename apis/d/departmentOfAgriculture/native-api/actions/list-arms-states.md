# List ARMS States with Department of Agriculture

Retrieves ARMS states from Department of Agriculture.

## Endpoint

- **Method:** `GET`
- **Path:** `/arms/state`
- **Base URL:** `https://api.ers.usda.gov/data`
- **Official documentation:** [List ARMS States](https://www.ers.usda.gov/developer/data-apis/arms-data-api)
