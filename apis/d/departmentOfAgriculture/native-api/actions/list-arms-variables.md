# List ARMS Variables with Department of Agriculture

Retrieves ARMS variables from Department of Agriculture.

## Endpoint

- **Method:** `GET`
- **Path:** `/arms/variable`
- **Base URL:** `https://api.ers.usda.gov/data`
- **Official documentation:** [List ARMS Variables](https://www.ers.usda.gov/developer/data-apis/arms-data-api)
