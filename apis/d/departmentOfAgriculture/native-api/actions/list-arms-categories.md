# List ARMS Categories with Department of Agriculture

Retrieves ARMS categories from Department of Agriculture.

## Endpoint

- **Method:** `GET`
- **Path:** `/arms/category`
- **Base URL:** `https://api.ers.usda.gov/data`
- **Official documentation:** [List ARMS Categories](https://www.ers.usda.gov/developer/data-apis/arms-data-api)
