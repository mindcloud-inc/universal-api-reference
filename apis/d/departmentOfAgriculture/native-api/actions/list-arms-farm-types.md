# List ARMS Farm Types with Department of Agriculture

Retrieves ARMS farm types from Department of Agriculture.

## Endpoint

- **Method:** `GET`
- **Path:** `/arms/farmtype`
- **Base URL:** `https://api.ers.usda.gov/data`
- **Official documentation:** [List ARMS Farm Types](https://www.ers.usda.gov/developer/data-apis/arms-data-api)
