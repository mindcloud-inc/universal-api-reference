# Retrieve Session with Didit

Retrieves a session decision from Didit.

## Endpoint

- **Method:** `GET`
- **Path:** `https://verification.didit.me/v3/session/{sessionId}/decision/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Retrieve Session](https://docs.didit.me/sessions-api/retrieve-session)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sessionId` | path | `string` | yes | Didit session identifier. |
