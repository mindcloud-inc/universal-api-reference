# Update Workflow with Didit

Updates an existing workflow in Didit.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/workflows/{workflowId}/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Update Workflow](https://docs.didit.me/management-api/workflows/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Didit workflow identifier. |
