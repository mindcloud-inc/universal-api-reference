# Face Search with Didit

Creates a face search report in Didit.

## Endpoint

- **Method:** `POST`
- **Path:** `https://verification.didit.me/v3/face-search/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Face Search](https://docs.didit.me/standalone-apis/face-search)
