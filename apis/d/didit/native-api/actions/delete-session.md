# Delete Session with Didit

Deletes a session from Didit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://verification.didit.me/v3/session/{sessionId}/delete/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Delete Session](https://docs.didit.me/sessions-api/delete-session)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sessionId` | path | `string` | yes | Didit session identifier. |
