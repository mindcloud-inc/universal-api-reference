# Get Questionnaire with Didit

Retrieves a questionnaire from Didit.

## Endpoint

- **Method:** `GET`
- **Path:** `/questionnaires/{questionnaireId}/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Get Questionnaire](https://docs.didit.me/management-api/questionnaires/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `questionnaireId` | path | `string` | yes | Didit questionnaire identifier. |
