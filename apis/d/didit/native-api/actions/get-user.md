# Get User with Didit

Retrieves a user from Didit.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{vendorData}/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Get User](https://docs.didit.me/management-api/users/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vendorData` | path | `string` | yes | Didit user vendor_data identifier. |
