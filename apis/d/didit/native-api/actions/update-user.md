# Update User with Didit

Updates an existing user in Didit.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/users/{vendorData}/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Update User](https://docs.didit.me/management-api/users/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vendorData` | path | `string` | yes | Didit user vendor_data identifier. |
