# Proof of Address with Didit

Creates a proof of address report in Didit.

## Endpoint

- **Method:** `POST`
- **Path:** `https://verification.didit.me/v3/poa/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Proof of Address](https://docs.didit.me/standalone-apis/proof-of-address)
