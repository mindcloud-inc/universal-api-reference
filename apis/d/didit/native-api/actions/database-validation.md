# Database Validation with Didit

Creates a database validation report in Didit.

## Endpoint

- **Method:** `POST`
- **Path:** `https://verification.didit.me/v3/database-validation/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Database Validation](https://docs.didit.me/standalone-apis/database-validation)
