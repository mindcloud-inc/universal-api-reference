# Face Match with Didit

Creates a face match report in Didit.

## Endpoint

- **Method:** `POST`
- **Path:** `https://verification.didit.me/v3/face-match/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Face Match](https://docs.didit.me/standalone-apis/face-match)
