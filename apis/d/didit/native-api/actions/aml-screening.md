# AML Screening with Didit

Creates an AML screening report in Didit.

## Endpoint

- **Method:** `POST`
- **Path:** `https://verification.didit.me/v3/aml/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [AML Screening](https://docs.didit.me/standalone-apis/aml-screening)
