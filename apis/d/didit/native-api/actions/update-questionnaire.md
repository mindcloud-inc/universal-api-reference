# Update Questionnaire with Didit

Updates an existing questionnaire in Didit.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/questionnaires/{questionnaireId}/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Update Questionnaire](https://docs.didit.me/management-api/questionnaires/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `questionnaireId` | path | `string` | yes | Didit questionnaire identifier. |
