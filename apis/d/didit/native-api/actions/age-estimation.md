# Age Estimation with Didit

Creates an age estimation report in Didit.

## Endpoint

- **Method:** `POST`
- **Path:** `https://verification.didit.me/v3/age-estimation/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Age Estimation](https://docs.didit.me/standalone-apis/age-estimation)
