# List Sessions with Didit

Retrieves sessions from Didit.

## Endpoint

- **Method:** `GET`
- **Path:** `https://verification.didit.me/v3/sessions`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [List Sessions](https://docs.didit.me/sessions-api/list-sessions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
