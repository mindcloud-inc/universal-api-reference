# ID Verification with Didit

Creates an ID verification report in Didit.

## Endpoint

- **Method:** `POST`
- **Path:** `https://verification.didit.me/v3/id-verification/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [ID Verification](https://docs.didit.me/standalone-apis/id-verification)
