# Delete Questionnaire with Didit

Deletes a questionnaire from Didit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/questionnaires/{questionnaireId}/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Delete Questionnaire](https://docs.didit.me/management-api/questionnaires/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `questionnaireId` | path | `string` | yes | Didit questionnaire identifier. |
