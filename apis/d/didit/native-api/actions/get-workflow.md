# Get Workflow with Didit

Retrieves a workflow from Didit.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/{workflowId}/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Get Workflow](https://docs.didit.me/management-api/workflows/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Didit workflow identifier. |
