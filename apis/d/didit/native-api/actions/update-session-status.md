# Update Session Status with Didit

Updates a session status in Didit.

## Endpoint

- **Method:** `PATCH`
- **Path:** `https://verification.didit.me/v3/session/{sessionId}/update-status/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Update Session Status](https://docs.didit.me/sessions-api/update-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sessionId` | path | `string` | yes | Didit session identifier. |
