# Delete Workflow with Didit

Deletes a workflow from Didit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workflows/{workflowId}/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Delete Workflow](https://docs.didit.me/management-api/workflows/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Didit workflow identifier. |
