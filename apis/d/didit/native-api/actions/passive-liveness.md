# Passive Liveness with Didit

Creates a passive liveness report in Didit.

## Endpoint

- **Method:** `POST`
- **Path:** `https://verification.didit.me/v3/passive-liveness/`
- **Base URL:** `https://verification.didit.me/v3`
- **Official documentation:** [Passive Liveness](https://docs.didit.me/standalone-apis/passive-liveness)
