# Get Feed Export Status with Dealfront

Retrieves feed export status from Dealfront.

## Endpoint

- **Method:** `GET`
- **Path:** `/export-requests/:id`
- **Base URL:** `https://api.leadfeeder.com`
- **Official documentation:** [Get Feed Export Status](https://docs.leadfeeder.com/api/#feed-export-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the export request to inspect. |
