# Get Article with Document360

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/Articles/:articleId/:langCode`
- **Base URL:** `https://apihub.document360.io`
- **Official documentation:** [Get Article](https://apidocs.document360.com/apidocs/get-article)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `articleId` | path | `string` | yes |
| `langCode` | path | `string` | yes |
