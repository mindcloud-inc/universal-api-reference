# Get Category with Document360

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/Categories/:categoryId`
- **Base URL:** `https://apihub.document360.io`
- **Official documentation:** [Get Category](https://apidocs.document360.com/apidocs/get-category)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `categoryId` | path | `string` | yes |
| `langCode` | query | `string` | no |
