# List Version Languages with Document360

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/Language/:projectVersionId`
- **Base URL:** `https://apihub.document360.io`
- **Official documentation:** [List Version Languages](https://apidocs.document360.com/apidocs/gets-all-version-languages-in-the-project)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectVersionId` | path | `string` | yes |
