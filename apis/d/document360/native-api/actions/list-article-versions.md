# List Article Versions with Document360

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/Articles/:articleId/:langCode/versions`
- **Base URL:** `https://apihub.document360.io`
- **Official documentation:** [List Article Versions](https://apidocs.document360.com/apidocs/get-article-versions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `articleId` | path | `string` | yes | The ID of the article |
| `langCode` | path | `string` | yes | The language code of the article |
