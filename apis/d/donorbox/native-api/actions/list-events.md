# List Events with Donorbox

Retrieves events from Donorbox.

## Endpoint

- **Method:** `GET`
- **Path:** `/events`
- **Base URL:** `https://donorbox.org/api/v1`
- **Official documentation:** [List Events](https://github.com/donorbox/donorbox-api#events)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
