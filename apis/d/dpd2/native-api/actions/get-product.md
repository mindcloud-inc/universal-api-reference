# Get Product with Dpd2

Retrieves a product from DPD by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:id`
- **Base URL:** `https://api.getdpd.com/v2`
- **Official documentation:** [Get Product](https://getdpd.com/docs/api/products.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique product ID. |
