# Get Storefront with Dpd2

Retrieves a storefront from DPD by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/storefronts/:id`
- **Base URL:** `https://api.getdpd.com/v2`
- **Official documentation:** [Get Storefront](https://getdpd.com/docs/api/storefronts.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique storefront ID. |
