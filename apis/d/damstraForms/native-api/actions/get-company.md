# Get Company with Damstra Forms

Retrieves a company from Damstra Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Company](https://sammapi.docs.apiary.io/#reference/companies/company-instance/retrieve-a-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the company. |
