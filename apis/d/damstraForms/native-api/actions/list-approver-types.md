# List Approver Types with Damstra Forms

Retrieves approver types from Damstra Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/approver_types`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Approver Types](https://sammapi.docs.apiary.io/#reference/approver-types/approver-type-collection/get-a-list-of-approver-types)

## Capabilities

This operation supports [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `show_managed` | query | `boolean` | no | Show/hide the managed attribute. |
