# Get Form with Damstra Forms

Retrieves a form from Damstra Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Form](https://sammapi.docs.apiary.io/#reference/forms/form-instance/retrieve-a-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the form. |
