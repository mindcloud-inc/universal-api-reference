# List Project List Types with Damstra Forms

Retrieves project list types from Damstra Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/project_list_types`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Project List Types](https://sammapi.docs.apiary.io/#reference/project-list-types/project-list-type-collection/get-a-list-of-project-list-types)

## Capabilities

This operation supports [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `show_managed` | query | `boolean` | no | Show/hide the managed attribute. |
