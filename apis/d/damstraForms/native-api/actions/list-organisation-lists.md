# List Organisation Lists with Damstra Forms

Retrieves organisation lists from Damstra Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/organisation_lists`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Organisation Lists](https://sammapi.docs.apiary.io/#reference/organisation-lists/organisation-list-collection/get-a-list-of-organisation-lists)

## Capabilities

This operation supports [sorting](../README.md#sorting).
