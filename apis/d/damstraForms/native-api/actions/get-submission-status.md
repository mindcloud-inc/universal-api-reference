# Get Submission Status with Damstra Forms

Retrieves the status of a submitted request from Damstra Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/submissions/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Submission Status](https://sammapi.docs.apiary.io/#reference/submissions/submission-instance/check-the-status-of-a-submitted-request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the submission. |
