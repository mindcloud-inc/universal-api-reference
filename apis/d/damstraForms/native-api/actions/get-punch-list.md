# Get Punch List with Damstra Forms

Retrieves a punch list from Damstra Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/punch_lists/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Punch List](https://sammapi.docs.apiary.io/#reference/punch-lists/punch-list-instance/get-a-punch-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the punch list. |
