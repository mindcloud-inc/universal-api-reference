# Get Action with Damstra Forms

Retrieves an action from Damstra Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/actions/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Action](https://sammapi.docs.apiary.io/#reference/actions/action-instance/retrieve-an-action)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the action. |
