# Get Memo with Damstra Forms

Retrieves a memo from Damstra Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/memos/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Memo](https://sammapi.docs.apiary.io/#reference/memos/memo-instance/retrieve-a-memo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the memo. |
