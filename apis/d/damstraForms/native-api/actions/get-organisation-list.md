# Get Organisation List with Damstra Forms

Retrieves an organisation list from Damstra Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/organisation_lists/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Organisation List](https://sammapi.docs.apiary.io/#reference/organisation-lists/organisation-list-instance/get-an-organisation-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique id (numeric) or uuid (string) of the organisation list. |
