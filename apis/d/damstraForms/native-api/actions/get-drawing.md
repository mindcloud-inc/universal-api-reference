# Get Drawing with Damstra Forms

Retrieves a drawing from Damstra Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/drawings/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Drawing](https://sammapi.docs.apiary.io/#reference/drawings/drawing-instance/get-a-drawing)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the drawing. |
