# List Contact Statuses with DMSales

Retrieves contact statuses from DMSales.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/contact-card/available-contact-statuses`
- **Base URL:** `https://app.dmsales.com`
- **Official documentation:** [List Contact Statuses](https://app.dmsales.com/api-doc/default)
