# Get Contact with DMSales

Retrieves contact details from DMSales.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/contact-card/`
- **Base URL:** `https://app.dmsales.com`
- **Official documentation:** [Get Contact](https://app.dmsales.com/api-doc/default)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `base_key` | query | `string` | yes | Contact base key returned by list contacts. |
