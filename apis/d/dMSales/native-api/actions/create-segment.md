# Create Segment with DMSales

Creates a new segment in DMSales.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/segment/create`
- **Base URL:** `https://app.dmsales.com`
- **Official documentation:** [Create Segment](https://app.dmsales.com/api-doc/default)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Segment name. |
