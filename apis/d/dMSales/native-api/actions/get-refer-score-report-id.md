# Get Refer Score Report ID with DMSales

Retrieves a Refer Score report ID from DMSales.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/person/get-refer-score-report-id`
- **Base URL:** `https://app.dmsales.com`
- **Official documentation:** [Get Refer Score Report ID](https://app.dmsales.com/api-doc/default)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `nip` | query | `string` | yes | Polish tax identification number for report lookup. |
