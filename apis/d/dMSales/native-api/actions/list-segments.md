# List Segments with DMSales

Retrieves segments from DMSales.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/segment/list`
- **Base URL:** `https://app.dmsales.com`
- **Official documentation:** [List Segments](https://app.dmsales.com/api-doc/default)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `with_filters` | query | `boolean` | no | Whether to include segment filters. |
