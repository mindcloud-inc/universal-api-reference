# Create Project with DMSales

Creates a new project in DMSales.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/project/create`
- **Base URL:** `https://app.dmsales.com`
- **Official documentation:** [Create Project](https://app.dmsales.com/api-doc/default)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name for the new DMSales project. |
