# Fetch Async Result with Dreamstudio

Retrieves an async generation result from Dreamstudio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2beta/results/:id`
- **Base URL:** `https://api.stability.ai`
- **Official documentation:** [Fetch Async Result](https://platform.stability.ai/docs/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Async generation job identifier. |
