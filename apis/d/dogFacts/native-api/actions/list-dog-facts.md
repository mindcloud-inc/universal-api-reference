# List Dog Facts with Dog Facts

## Endpoint

- **Method:** `GET`
- **Path:** `/facts`
- **Base URL:** `https://dogapi.dog/api/v2`
- **Official documentation:** [List Dog Facts](https://dogapi.dog/docs/api-v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of random dog facts to return. |
