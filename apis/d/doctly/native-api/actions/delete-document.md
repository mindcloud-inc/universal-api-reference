# Delete Document with Doctly

## Endpoint

- **Method:** `DELETE`
- **Path:** `/documents/:id`
- **Base URL:** `https://api.doctly.ai/api/v1`
- **Official documentation:** [Delete Document](https://docs.doctly.ai/api-reference/documents/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique document UUID to delete. |
