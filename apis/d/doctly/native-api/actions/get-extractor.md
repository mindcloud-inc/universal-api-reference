# Get Extractor with Doctly

## Endpoint

- **Method:** `GET`
- **Path:** `/e/:extractorId`
- **Base URL:** `https://api.doctly.ai/api/v1`
- **Official documentation:** [Get Extractor](https://docs.doctly.ai/api-reference/extractors/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `extractorId` | path | `string` | yes | Unique extractor UUID to retrieve. |
