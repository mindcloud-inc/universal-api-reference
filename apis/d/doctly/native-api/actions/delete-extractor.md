# Delete Extractor with Doctly

## Endpoint

- **Method:** `DELETE`
- **Path:** `/e/:extractorId`
- **Base URL:** `https://api.doctly.ai/api/v1`
- **Official documentation:** [Delete Extractor](https://docs.doctly.ai/api-reference/extractors/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `extractorId` | path | `string` | yes | Unique extractor UUID to delete. |
