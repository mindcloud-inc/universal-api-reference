# Get Document with Doctly

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id`
- **Base URL:** `https://api.doctly.ai/api/v1`
- **Official documentation:** [Get Document](https://docs.doctly.ai/api-reference/documents/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique document UUID to retrieve. |
