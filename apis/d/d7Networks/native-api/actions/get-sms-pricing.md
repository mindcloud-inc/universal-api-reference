# Get SMS Pricing with D7 Networks

Retrieves SMS pricing details from D7 Networks.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/v1/sms/pricing`
- **Base URL:** `https://api.d7networks.com`
- **Official documentation:** [Get SMS Pricing](https://d7networks.com/docs/sms/pricing/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `country_iso` | query | `string` | no | Optional ISO Alpha-2 country code, such as US or AE. |
