# Get Client with Dext

Retrieves detailed client information from Dext.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:client_id`
- **Base URL:** `https://api.precision.dext.com`
- **Official documentation:** [Get Client](https://help.dext.com/en/articles/272702-data-health-insights-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `string` | yes | The Dext client identifier. |
