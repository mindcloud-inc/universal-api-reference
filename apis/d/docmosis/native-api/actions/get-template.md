# Get Template with Docmosis

## Endpoint

- **Method:** `POST`
- **Path:** `/getTemplate`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Template](https://resources.docmosis.com/Documentation/Cloud/DWS4/Cloud-Web-Services-Guide-DWS4.pdf#page=32)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateName[]` | body | `array<string>` | yes | One or more template names to download. |
