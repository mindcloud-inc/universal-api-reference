# Get Template with Dropbox Sign

Retrieves a template from Dropbox Sign by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/template/:template_id`
- **Base URL:** `https://api.hellosign.com/v3`
- **Official documentation:** [Get Template](https://developers.hellosign.com/api/reference/operation/templateGet/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The id of the Template to retrieve. |
