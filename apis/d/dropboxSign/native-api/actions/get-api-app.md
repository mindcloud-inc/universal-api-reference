# Get API App with Dropbox Sign

Retrieves an API app from Dropbox Sign by client ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api_app/:client_id`
- **Base URL:** `https://api.hellosign.com/v3`
- **Official documentation:** [Get API App](https://developers.hellosign.com/api/reference/operation/apiAppGet/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `string` | yes | The client ID of the API App to retrieve. |
