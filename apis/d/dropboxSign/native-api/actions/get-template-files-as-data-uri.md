# Get Template Files as Data URI with Dropbox Sign

Retrieves template files as data URIs from Dropbox Sign.

## Endpoint

- **Method:** `GET`
- **Path:** `/template/files_as_data_uri/:template_id`
- **Base URL:** `https://api.hellosign.com/v3`
- **Official documentation:** [Get Template Files as Data URI](https://developers.hellosign.com/api/reference/operation/templateFilesAsDataUri/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The ID of the template to retrieve files for. |
