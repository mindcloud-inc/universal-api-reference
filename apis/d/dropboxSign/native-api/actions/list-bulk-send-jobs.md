# List Bulk Send Jobs with Dropbox Sign

Retrieves bulk send jobs from Dropbox Sign.

## Endpoint

- **Method:** `GET`
- **Path:** `/bulk_send_job/list`
- **Base URL:** `https://api.hellosign.com/v3`
- **Official documentation:** [List Bulk Send Jobs](https://developers.hellosign.com/api/reference/operation/bulkSendJobList/)
