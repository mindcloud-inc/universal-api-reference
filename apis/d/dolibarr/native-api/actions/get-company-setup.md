# Get Company Setup with Dolibarr

Retrieves company properties from Dolibarr.

## Endpoint

- **Method:** `GET`
- **Path:** `/setup/company`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [Get Company Setup](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))
