# Get Current User Info with Dolibarr

Retrieves the current user's details from Dolibarr.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/info`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [Get Current User Info](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))
