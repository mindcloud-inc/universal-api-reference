# Get User Group with Dolibarr

Retrieves a user group from Dolibarr.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/groups/{group}`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [Get User Group](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group` | path | `string` | yes | Dolibarr user group identifier. |
