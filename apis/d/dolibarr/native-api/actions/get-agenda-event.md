# Get Agenda Event with Dolibarr

Retrieves an agenda event from Dolibarr.

## Endpoint

- **Method:** `GET`
- **Path:** `/agendaevents/{id}`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [Get Agenda Event](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Dolibarr agenda event ID. |
