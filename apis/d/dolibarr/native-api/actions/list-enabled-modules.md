# List Enabled Modules with Dolibarr

Retrieves a list of enabled modules from Dolibarr.

## Endpoint

- **Method:** `GET`
- **Path:** `/setup/modules`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [List Enabled Modules](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))
