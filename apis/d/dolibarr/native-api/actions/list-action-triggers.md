# List Action Triggers with Dolibarr

Retrieves a list of action triggers from Dolibarr.

## Endpoint

- **Method:** `GET`
- **Path:** `/setup/actiontriggers`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [List Action Triggers](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))
