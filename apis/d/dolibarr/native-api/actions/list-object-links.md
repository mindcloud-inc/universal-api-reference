# List Object Links with Dolibarr

Retrieves object links from Dolibarr by linked object values.

## Endpoint

- **Method:** `GET`
- **Path:** `/objectlinks`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [List Object Links](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))
