# List Current User Groups with Dolibarr

Retrieves the current user's groups from Dolibarr.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/groups`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [List Current User Groups](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))
