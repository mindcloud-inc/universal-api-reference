# List Categories with Dolibarr

Retrieves a list of categories from Dolibarr.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [List Categories](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
