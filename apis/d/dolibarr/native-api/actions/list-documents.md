# List Documents with Dolibarr

Retrieves documents for a specific Dolibarr record.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [List Documents](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
