# Get Object Link with Dolibarr

Retrieves an object link from Dolibarr.

## Endpoint

- **Method:** `GET`
- **Path:** `/objectlinks/{id}`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [Get Object Link](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Dolibarr object link ID. |
