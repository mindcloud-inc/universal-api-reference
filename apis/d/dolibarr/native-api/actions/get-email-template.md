# Get Email Template with Dolibarr

Retrieves an email template from Dolibarr.

## Endpoint

- **Method:** `GET`
- **Path:** `/emailtemplates/{id}`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [Get Email Template](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Dolibarr email template ID. |
