# Get Status with Dolibarr

Retrieves status information for the Dolibarr instance.

## Endpoint

- **Method:** `GET`
- **Path:** `/status`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [Get Status](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))
