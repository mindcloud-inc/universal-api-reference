# Get User with Dolibarr

Retrieves a user record from Dolibarr.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{id}`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [Get User](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Dolibarr user ID. |
