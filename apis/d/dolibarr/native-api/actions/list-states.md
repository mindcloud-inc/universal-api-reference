# List States with Dolibarr

Retrieves a list of states from Dolibarr.

## Endpoint

- **Method:** `GET`
- **Path:** `/setup/dictionary/states`
- **Base URL:** `https://mindcloud-dolibarr-0421.with7.dolicloud.com/api/index.php`
- **Official documentation:** [List States](https://wiki.dolibarr.org/index.php/Module_Web_Services_API_REST_(developer))
