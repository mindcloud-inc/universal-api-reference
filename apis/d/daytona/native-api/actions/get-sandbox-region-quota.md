# Get Sandbox Region Quota with Daytona

Retrieves the sandbox region quota from Daytona.

## Endpoint

- **Method:** `GET`
- **Path:** `/sandbox/[:sandboxId]/region-quota`
- **Base URL:** `https://app.daytona.io/api`
- **Official documentation:** [Get Sandbox Region Quota](https://www.daytona.io/docs/tools/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sandboxId` | path | `string` | yes | ID of the sandbox. |
