# Create Sandbox Snapshot with Daytona

Creates a snapshot from a sandbox in Daytona.

## Endpoint

- **Method:** `POST`
- **Path:** `/sandbox/[:sandboxIdOrName]/snapshot`
- **Base URL:** `https://app.daytona.io/api`
- **Official documentation:** [Create Sandbox Snapshot](https://www.daytona.io/docs/tools/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sandboxIdOrName` | path | `string` | yes | Sandbox ID or name. |
