# Get Sandbox Toolbox Proxy URL with Daytona

Retrieves the sandbox toolbox proxy URL from Daytona.

## Endpoint

- **Method:** `GET`
- **Path:** `/sandbox/[:sandboxId]/toolbox-proxy-url`
- **Base URL:** `https://app.daytona.io/api`
- **Official documentation:** [Get Sandbox Toolbox Proxy URL](https://www.daytona.io/docs/tools/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sandboxId` | path | `string` | yes | ID of the sandbox. |
