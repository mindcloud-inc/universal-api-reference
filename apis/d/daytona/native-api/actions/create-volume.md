# Create Volume with Daytona

Creates a new volume in Daytona.

## Endpoint

- **Method:** `POST`
- **Path:** `/volumes`
- **Base URL:** `https://app.daytona.io/api`
- **Official documentation:** [Create Volume](https://www.daytona.io/docs/tools/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The volume name. |
