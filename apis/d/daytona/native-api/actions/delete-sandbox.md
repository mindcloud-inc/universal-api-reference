# Delete Sandbox with Daytona

Deletes an existing sandbox from Daytona.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sandbox/[:sandboxIdOrName]`
- **Base URL:** `https://app.daytona.io/api`
- **Official documentation:** [Delete Sandbox](https://www.daytona.io/docs/tools/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sandboxIdOrName` | path | `string` | yes | Sandbox ID or name. |
