# Archive Sandbox with Daytona

Archives a sandbox in Daytona.

## Endpoint

- **Method:** `POST`
- **Path:** `/sandbox/[:sandboxIdOrName]/archive`
- **Base URL:** `https://app.daytona.io/api`
- **Official documentation:** [Archive Sandbox](https://www.daytona.io/docs/tools/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sandboxIdOrName` | path | `string` | yes | Sandbox ID or name. |
