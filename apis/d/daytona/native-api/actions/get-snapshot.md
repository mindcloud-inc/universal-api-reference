# Get Snapshot with Daytona

Retrieves snapshot details from Daytona.

## Endpoint

- **Method:** `GET`
- **Path:** `/snapshots/[:id]`
- **Base URL:** `https://app.daytona.io/api`
- **Official documentation:** [Get Snapshot](https://www.daytona.io/docs/tools/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Snapshot ID or name. |
