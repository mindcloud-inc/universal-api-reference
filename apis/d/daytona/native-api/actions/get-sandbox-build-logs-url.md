# Get Sandbox Build Logs URL with Daytona

Retrieves the sandbox build logs URL from Daytona.

## Endpoint

- **Method:** `GET`
- **Path:** `/sandbox/[:sandboxIdOrName]/build-logs-url`
- **Base URL:** `https://app.daytona.io/api`
- **Official documentation:** [Get Sandbox Build Logs URL](https://www.daytona.io/docs/tools/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sandboxIdOrName` | path | `string` | yes | Sandbox ID or name. |
