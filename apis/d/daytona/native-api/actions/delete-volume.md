# Delete Volume with Daytona

Deletes an existing volume from Daytona.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/volumes/[:volumeId]`
- **Base URL:** `https://app.daytona.io/api`
- **Official documentation:** [Delete Volume](https://www.daytona.io/docs/tools/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `volumeId` | path | `string` | yes | Volume ID. |
