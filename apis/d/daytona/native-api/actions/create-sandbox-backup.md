# Create Sandbox Backup with Daytona

Creates a sandbox backup in Daytona.

## Endpoint

- **Method:** `POST`
- **Path:** `/sandbox/[:sandboxIdOrName]/backup`
- **Base URL:** `https://app.daytona.io/api`
- **Official documentation:** [Create Sandbox Backup](https://www.daytona.io/docs/tools/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sandboxIdOrName` | path | `string` | yes | Sandbox ID or name. |
