# Get Base Calendar with DivvyHQ

## Endpoint

- **Method:** `GET`
- **Path:** `/basecalendars/:id/`
- **Base URL:** `https://app.divvyhq.com/api/2.0`
- **Official documentation:** [Get Base Calendar](https://developer.divvyhq.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Base calendar ID. |
