# List Content Items with DivvyHQ

## Endpoint

- **Method:** `GET`
- **Path:** `/contentitems/`
- **Base URL:** `https://app.divvyhq.com/api/2.0`
- **Official documentation:** [List Content Items](https://developer.divvyhq.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
