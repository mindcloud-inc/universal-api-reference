# Get Simple Calendar with DivvyHQ

## Endpoint

- **Method:** `GET`
- **Path:** `/simplecalendars/:id/`
- **Base URL:** `https://app.divvyhq.com/api/2.0`
- **Official documentation:** [Get Simple Calendar](https://developer.divvyhq.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Simple calendar ID. |
