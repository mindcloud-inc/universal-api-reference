# Get Campaign with DivvyHQ

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:id/`
- **Base URL:** `https://app.divvyhq.com/api/2.0`
- **Official documentation:** [Get Campaign](https://developer.divvyhq.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Campaign ID. |
