# Get Content Item with DivvyHQ

## Endpoint

- **Method:** `GET`
- **Path:** `/contentitems/:id/`
- **Base URL:** `https://app.divvyhq.com/api/2.0`
- **Official documentation:** [Get Content Item](https://developer.divvyhq.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Content item ID. |
