# List Space Documents with DocuWriter.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/api/spaces/{{space_id}}/documents`
- **Base URL:** `https://app.docuwriter.ai`
- **Official documentation:** [List Space Documents](https://docs.docuwriter.ai/docuwriterai-api-docs/118761)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `space_id` | path | `number` | yes | The ID of the Space. |
