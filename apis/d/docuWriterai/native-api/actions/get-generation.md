# Get Generation with DocuWriter.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/api/generations/{{id}}`
- **Base URL:** `https://app.docuwriter.ai`
- **Official documentation:** [Get Generation](https://docs.docuwriter.ai/docuwriterai-api-docs/92066)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the generation to retrieve. |
