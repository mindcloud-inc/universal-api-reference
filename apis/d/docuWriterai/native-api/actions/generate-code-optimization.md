# Generate Code Optimization with DocuWriter.ai

## Endpoint

- **Method:** `POST`
- **Path:** `/api/generate-code-optimization`
- **Base URL:** `https://app.docuwriter.ai`
- **Official documentation:** [Generate Code Optimization](https://docs.docuwriter.ai/docuwriterai-api-docs/92062)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `source_code` | body | `string` | yes | Raw source code to optimize. |
| `filename` | body | `string` | yes | Original file name. |
