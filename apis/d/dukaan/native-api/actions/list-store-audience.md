# List Store Audience with Dukaan

Retrieves store audience records from Dukaan.

## Endpoint

- **Method:** `GET`
- **Path:** `api/store/seller/store-buyer/`
- **Base URL:** `https://api.mydukaan.io`
- **Official documentation:** [List Store Audience](https://documenter.getpostman.com/view/25389466/2s9Yynk3f7)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
