# Search Product Categories with Dukaan

Finds product categories in Dukaan by search query.

## Endpoint

- **Method:** `GET`
- **Path:** `api/product/seller/product-category/`
- **Base URL:** `https://api.mydukaan.io`
- **Official documentation:** [Search Product Categories](https://documenter.getpostman.com/view/25389466/2s9Yynk3f7)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | yes | Category search text. |
