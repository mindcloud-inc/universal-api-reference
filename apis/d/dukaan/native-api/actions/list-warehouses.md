# List Warehouses with Dukaan

Retrieves warehouses from Dukaan.

## Endpoint

- **Method:** `GET`
- **Path:** `api/store/seller/store-warehouse/v2/`
- **Base URL:** `https://api.mydukaan.io`
- **Official documentation:** [List Warehouses](https://documenter.getpostman.com/view/25389466/2s9Yynk3f7)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
