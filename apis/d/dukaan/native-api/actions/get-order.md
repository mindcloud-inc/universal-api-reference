# Get Order with Dukaan

Retrieves an order from Dukaan.

## Endpoint

- **Method:** `GET`
- **Path:** `api/order/seller/:orderUuid/order/`
- **Base URL:** `https://api.mydukaan.io`
- **Official documentation:** [Get Order](https://documenter.getpostman.com/view/25389466/2s9Yynk3f7)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderUuid` | path | `string` | yes | Dukaan order UUID. |
