# List Discounts with Dukaan

Retrieves discounts from Dukaan.

## Endpoint

- **Method:** `GET`
- **Path:** `api/coupon/seller/coupon/v2/`
- **Base URL:** `https://api.mydukaan.io`
- **Official documentation:** [List Discounts](https://documenter.getpostman.com/view/25389466/2s9Yynk3f7)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Discount/coupon search text. |
