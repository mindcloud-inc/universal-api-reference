# List Product Categories with Dukaan

Retrieves product categories from Dukaan.

## Endpoint

- **Method:** `GET`
- **Path:** `api/product/seller/product-category/`
- **Base URL:** `https://api.mydukaan.io`
- **Official documentation:** [List Product Categories](https://documenter.getpostman.com/view/25389466/2s9Yynk3f7)

## Capabilities

This operation supports [pagination](../README.md#pagination).
