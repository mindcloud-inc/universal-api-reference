# Get Customer Details with Dukaan

Retrieves customer details from Dukaan.

## Endpoint

- **Method:** `GET`
- **Path:** `api/campaign/seller/store-lead/v2/store-lead-data/:storeLeadId/`
- **Base URL:** `https://api.mydukaan.io`
- **Official documentation:** [Get Customer Details](https://documenter.getpostman.com/view/25389466/2s9Yynk3f7)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `storeLeadId` | path | `number` | yes | Dukaan store lead/customer ID. |
