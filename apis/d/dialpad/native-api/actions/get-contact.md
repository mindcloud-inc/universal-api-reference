# Get Contact with Dialpad

Retrieves detailed contact information from Dialpad.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://dialpad.com/api/v2`
- **Official documentation:** [Get Contact](https://developers.dialpad.com/reference/contactsget)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The contact's id. |
