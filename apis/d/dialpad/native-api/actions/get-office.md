# Get Office with Dialpad

Retrieves detailed office information from Dialpad.

## Endpoint

- **Method:** `GET`
- **Path:** `/offices/:id`
- **Base URL:** `https://dialpad.com/api/v2`
- **Official documentation:** [Get Office](https://developers.dialpad.com/reference/officesget)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Dialpad office ID to retrieve. |
