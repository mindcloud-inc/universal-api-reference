# Get Channel with Dialpad

Retrieves detailed channel information from Dialpad.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels/:id`
- **Base URL:** `https://dialpad.com/api/v2`
- **Official documentation:** [Get Channel](https://developers.dialpad.com/reference/channelsget)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The channel id. |
