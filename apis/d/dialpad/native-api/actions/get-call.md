# Get Call with Dialpad

Retrieves detailed information for a concluded call in Dialpad.

## Endpoint

- **Method:** `GET`
- **Path:** `/call/:id`
- **Base URL:** `https://dialpad.com/api/v2`
- **Official documentation:** [Get Call](https://developers.dialpad.com/reference/callget_call_info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The call's id. |
