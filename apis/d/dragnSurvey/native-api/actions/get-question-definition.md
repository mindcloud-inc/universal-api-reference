# Get Question Definition with Drag'n Survey

Retrieves a question definition from Drag'n Survey.

## Endpoint

- **Method:** `GET`
- **Path:** `components/:componentId`
- **Base URL:** `https://developer.dragnsurvey.com/api/v2.0.0`
- **Official documentation:** [Get Question Definition](https://developer.dragnsurvey.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `componentId` | path | `string` | no | The Drag'n Survey component ID. |
