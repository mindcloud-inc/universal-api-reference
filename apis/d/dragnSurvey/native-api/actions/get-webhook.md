# Get Webhook with Drag'n Survey

Retrieves a webhook from Drag'n Survey by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `webhooks/:webhookId`
- **Base URL:** `https://developer.dragnsurvey.com/api/v2.0.0`
- **Official documentation:** [Get Webhook](https://developer.dragnsurvey.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | no | The Drag'n Survey webhook ID. |
