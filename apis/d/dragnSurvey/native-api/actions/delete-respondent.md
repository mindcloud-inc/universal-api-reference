# Delete Respondent with Drag'n Survey

Deletes a respondent from Drag'n Survey.

## Endpoint

- **Method:** `DELETE`
- **Path:** `respondents/:respondentId`
- **Base URL:** `https://developer.dragnsurvey.com/api/v2.0.0`
- **Official documentation:** [Delete Respondent](https://developer.dragnsurvey.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `respondentId` | path | `string` | no | The Drag'n Survey respondent ID. |
