# Get Report with Drag'n Survey

Retrieves a report from Drag'n Survey by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `reports/:reportId`
- **Base URL:** `https://developer.dragnsurvey.com/api/v2.0.0`
- **Official documentation:** [Get Report](https://developer.dragnsurvey.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `string` | no | The Drag'n Survey report ID. |
