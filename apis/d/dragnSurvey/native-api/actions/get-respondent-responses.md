# Get Respondent Responses with Drag'n Survey

Retrieves responses for a Drag'n Survey respondent.

## Endpoint

- **Method:** `GET`
- **Path:** `respondents/:respondentId`
- **Base URL:** `https://developer.dragnsurvey.com/api/v2.0.0`
- **Official documentation:** [Get Respondent Responses](https://developer.dragnsurvey.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `respondentId` | path | `string` | no | The Drag'n Survey respondent ID. |
