# Delete Collector with Drag'n Survey

Deletes a collector from Drag'n Survey.

## Endpoint

- **Method:** `DELETE`
- **Path:** `collectors/:collectorId`
- **Base URL:** `https://developer.dragnsurvey.com/api/v2.0.0`
- **Official documentation:** [Delete Collector](https://developer.dragnsurvey.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectorId` | path | `string` | no | The Drag'n Survey collector ID. |
