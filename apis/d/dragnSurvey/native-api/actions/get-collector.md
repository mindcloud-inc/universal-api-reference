# Get Collector with Drag'n Survey

Retrieves a collector from Drag'n Survey by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `collectors/:collectorId`
- **Base URL:** `https://developer.dragnsurvey.com/api/v2.0.0`
- **Official documentation:** [Get Collector](https://developer.dragnsurvey.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectorId` | path | `string` | no | The Drag'n Survey collector ID. |
