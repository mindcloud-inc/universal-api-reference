# Unsubscribe from Webhook with Drag'n Survey

Deletes a webhook from Drag'n Survey.

## Endpoint

- **Method:** `DELETE`
- **Path:** `webhooks/:webhookId`
- **Base URL:** `https://developer.dragnsurvey.com/api/v2.0.0`
- **Official documentation:** [Unsubscribe from Webhook](https://developer.dragnsurvey.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | no | The Drag'n Survey webhook ID. |
