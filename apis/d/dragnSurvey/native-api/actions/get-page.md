# Get Page with Drag'n Survey

Retrieves a page from Drag'n Survey by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `pages/:pageId`
- **Base URL:** `https://developer.dragnsurvey.com/api/v2.0.0`
- **Official documentation:** [Get Page](https://developer.dragnsurvey.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageId` | path | `string` | no | The Drag'n Survey page ID. |
