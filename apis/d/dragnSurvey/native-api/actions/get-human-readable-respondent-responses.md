# Get Human Readable Respondent Responses with Drag'n Survey

Retrieves human-readable responses for a Drag'n Survey respondent.

## Endpoint

- **Method:** `GET`
- **Path:** `respondents/:respondentId/responses`
- **Base URL:** `https://developer.dragnsurvey.com/api/v2.0.0`
- **Official documentation:** [Get Human Readable Respondent Responses](https://developer.dragnsurvey.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `respondentId` | path | `string` | no | The Drag'n Survey respondent ID. |
