# Get Enterprise Total Tree Count with Digital Humani

Retrieves an enterprise's total tree count from Digital Humani.

## Endpoint

- **Method:** `GET`
- **Path:** `/enterprise/:id/treeCount/total`
- **Base URL:** `https://api.digitalhumani.com`
- **Official documentation:** [Get Enterprise Total Tree Count](https://docs.digitalhumani.com/#apitree_get_enterprise_total_count)
