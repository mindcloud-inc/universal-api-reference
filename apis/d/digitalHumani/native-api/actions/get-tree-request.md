# Get Tree Request with Digital Humani

Retrieves a tree-planting request from Digital Humani by UUID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tree/:uuid`
- **Base URL:** `https://api.digitalhumani.com`
- **Official documentation:** [Get Tree Request](https://docs.digitalhumani.com/#apitree_get_request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The UUID of the tree-planting request to retrieve. |
