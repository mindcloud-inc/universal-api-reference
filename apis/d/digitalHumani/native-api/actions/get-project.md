# Get Project with Digital Humani

Retrieves a reforestation project from Digital Humani by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id`
- **Base URL:** `https://api.digitalhumani.com`
- **Official documentation:** [Get Project](https://docs.digitalhumani.com/#apiproject_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Digital Humani project ID to retrieve. |
