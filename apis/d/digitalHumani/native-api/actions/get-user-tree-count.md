# Get User Tree Count with Digital Humani

Retrieves a user's tree count from Digital Humani.

## Endpoint

- **Method:** `GET`
- **Path:** `/tree`
- **Base URL:** `https://api.digitalhumani.com`
- **Official documentation:** [Get User Tree Count](https://docs.digitalhumani.com/#apitree_get_user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user` | query | `string` | yes | The user whose tree count you want to retrieve. |
