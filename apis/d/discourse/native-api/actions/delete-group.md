# Delete Group with Discourse

Deletes an existing group from Discourse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/admin/groups/:id.json`
- **Base URL:** `https://mindcloud.discourse.group`
- **Official documentation:** [Delete Group](https://docs.discourse.org/#tag/Groups/operation/deleteGroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Group id. |
