# Delete Topic with Discourse

Deletes an existing topic from Discourse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/t/:id.json`
- **Base URL:** `https://mindcloud.discourse.group`
- **Official documentation:** [Delete Topic](https://docs.discourse.org/#tag/Topics/operation/removeTopic)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Topic id. |
