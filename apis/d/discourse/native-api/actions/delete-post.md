# Delete Post with Discourse

Deletes an existing post from Discourse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/posts/:id.json`
- **Base URL:** `https://mindcloud.discourse.group`
- **Official documentation:** [Delete Post](https://docs.discourse.org/#tag/Posts/operation/deletePost)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Post id. |
