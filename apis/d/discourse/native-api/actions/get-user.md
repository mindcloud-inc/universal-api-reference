# Get User with Discourse

Retrieves a Discourse user by username.

## Endpoint

- **Method:** `GET`
- **Path:** `/u/:username.json`
- **Base URL:** `https://mindcloud.discourse.group`
- **Official documentation:** [Get User](https://docs.discourse.org/#tag/Users/operation/getUser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Discourse username. |
