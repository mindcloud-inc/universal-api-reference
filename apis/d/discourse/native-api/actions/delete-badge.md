# Delete Badge with Discourse

Deletes an existing badge from Discourse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/admin/badges/:id.json`
- **Base URL:** `https://mindcloud.discourse.group`
- **Official documentation:** [Delete Badge](https://docs.discourse.org/#tag/Badges/operation/deleteBadge)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Badge id. |
