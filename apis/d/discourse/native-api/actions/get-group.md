# Get Group with Discourse

Retrieves a specific group from Discourse.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:name.json`
- **Base URL:** `https://mindcloud.discourse.group`
- **Official documentation:** [Get Group](https://docs.discourse.org/#tag/Groups/operation/getGroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Discourse group name. |
