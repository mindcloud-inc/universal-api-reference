# Delete User with Discourse

Deletes an existing user from Discourse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/admin/users/:id.json`
- **Base URL:** `https://mindcloud.discourse.group`
- **Official documentation:** [Delete User](https://docs.discourse.org/#tag/Users/operation/deleteUser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | User id. |
