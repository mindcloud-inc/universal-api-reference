# List App Feedbacks with Dify

Retrieves app feedback entries from Dify.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/feedbacks`
- **Base URL:** `https://api.dify.ai/v1`
- **Official documentation:** [List App Feedbacks](https://docs.dify.ai/api-reference/feedback/list-app-feedbacks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to return. |
