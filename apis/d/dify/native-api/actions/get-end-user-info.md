# Get End User Info with Dify

Retrieves end-user details from Dify.

## Endpoint

- **Method:** `GET`
- **Path:** `/end-users/:end_user_id`
- **Base URL:** `https://api.dify.ai/v1`
- **Official documentation:** [Get End User Info](https://docs.dify.ai/api-reference/end-users/get-end-user-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `end_user_id` | path | `string` | yes | End-user ID to inspect. |
