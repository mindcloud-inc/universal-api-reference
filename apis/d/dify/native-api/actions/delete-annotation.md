# Delete Annotation with Dify

Deletes an existing annotation from Dify.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/apps/annotations/:annotation_id`
- **Base URL:** `https://api.dify.ai/v1`
- **Official documentation:** [Delete Annotation](https://docs.dify.ai/api-reference/annotations/delete-annotation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `annotation_id` | path | `string` | yes | Annotation ID to delete. |
