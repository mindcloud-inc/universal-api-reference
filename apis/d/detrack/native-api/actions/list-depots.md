# List Depots with Detrack

Retrieves a list of depots from Detrack.

## Endpoint

- **Method:** `GET`
- **Path:** `/dn/depots`
- **Base URL:** `https://app.detrack.com/api/v2`
- **Official documentation:** [List Depots](https://detrackapiv2.docs.apiary.io/#reference/depots/list-depots/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
