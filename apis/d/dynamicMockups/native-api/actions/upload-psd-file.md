# Upload PSD File with Dynamic Mockups

Uploads a PSD file to Dynamic Mockups.

## Endpoint

- **Method:** `POST`
- **Path:** `api/v1/psd/upload`
- **Base URL:** `https://app.dynamicmockups.com`
- **Official documentation:** [Upload PSD File](https://docs.dynamicmockups.com/api-reference/psd-upload-api)
