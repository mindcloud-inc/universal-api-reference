# List Catalogs with Dynamic Mockups

Retrieves your catalogs from Dynamic Mockups.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/catalogs`
- **Base URL:** `https://app.dynamicmockups.com`
- **Official documentation:** [List Catalogs](https://docs.dynamicmockups.com/api-reference/catalogs-api)
