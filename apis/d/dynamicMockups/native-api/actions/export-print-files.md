# Export Print Files with Dynamic Mockups

Exports print files from a Dynamic Mockups mockup.

## Endpoint

- **Method:** `POST`
- **Path:** `api/v1/renders/print-files`
- **Base URL:** `https://app.dynamicmockups.com`
- **Official documentation:** [Export Print Files](https://docs.dynamicmockups.com/api-reference/render-print-files-api)
