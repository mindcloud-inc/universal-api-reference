# Delete PSD File with Dynamic Mockups

Deletes a PSD file from Dynamic Mockups.

## Endpoint

- **Method:** `POST`
- **Path:** `api/v1/psd/delete`
- **Base URL:** `https://app.dynamicmockups.com`
- **Official documentation:** [Delete PSD File](https://docs.dynamicmockups.com/api-reference/psd-upload-api)
