# Get Mockup with Dynamic Mockups

Retrieves a mockup from Dynamic Mockups by UUID.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/mockup/:uuid`
- **Base URL:** `https://app.dynamicmockups.com`
- **Official documentation:** [Get Mockup](https://docs.dynamicmockups.com/api-reference/get-mockups-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID of the mockup to retrieve. |
