# Get Asset Share with Dash.app

Retrieves an asset share from Dash.app by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/asset-shares/:id`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Asset Share](https://api-docs.dash.app/dash/openapi/asset-shares/getassetshare)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
