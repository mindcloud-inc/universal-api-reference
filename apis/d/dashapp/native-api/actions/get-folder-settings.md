# Get Folder Settings with Dash.app

Retrieves folder settings from your Dash.app account.

## Endpoint

- **Method:** `GET`
- **Path:** `/folder-settings`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Folder Settings](https://api-docs.dash.app/dash/openapi/folder-settings/getfoldersettings)
