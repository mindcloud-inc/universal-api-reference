# Get Asset Files with Dash.app

Retrieves files for an asset from Dash.app.

## Endpoint

- **Method:** `GET`
- **Path:** `/assets/:id/files`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Asset Files](https://api-docs.dash.app/dash/openapi/assets/getassetfiles)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
