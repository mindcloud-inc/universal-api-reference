# Get Field Option with Dash.app

Retrieves a field option from Dash.app by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/field-options/:id`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Field Option](https://api-docs.dash.app/dash/openapi/field-options/getfieldoption)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
