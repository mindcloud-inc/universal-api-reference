# Get Field Views with Dash.app

Retrieves field views from your Dash.app account.

## Endpoint

- **Method:** `GET`
- **Path:** `/field-views`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Field Views](https://api-docs.dash.app/dash/openapi/field-views/getfieldviews)
