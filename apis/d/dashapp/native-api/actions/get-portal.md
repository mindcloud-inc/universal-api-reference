# Get Portal with Dash.app

Retrieves a portal from Dash.app by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/portals/:id`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Portal](https://api-docs.dash.app/dash/openapi/portals/getportal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Dash portal identifier. |
