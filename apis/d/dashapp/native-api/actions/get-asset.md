# Get Asset with Dash.app

Retrieves an asset from Dash.app by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/assets/:id`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Asset](https://api-docs.dash.app/dash/openapi/assets/getasset)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
