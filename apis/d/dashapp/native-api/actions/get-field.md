# Get Field with Dash.app

Retrieves a metadata field from Dash.app by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/fields/:id`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Field](https://api-docs.dash.app/dash/openapi/fields/getfield)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Dash field ID. |
