# Get User with Dash.app

Retrieves a user from Dash.app by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get User](https://api-docs.dash.app/dash/openapi/users/getuser.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the user or the user's email. |
