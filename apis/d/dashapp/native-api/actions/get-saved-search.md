# Get Saved Search with Dash.app

Retrieves a saved search from Dash.app by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/saved-searches/:id`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Saved Search](https://api-docs.dash.app/dash/openapi/saved-searches/getsavedsearch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Dash saved search identifier. |
