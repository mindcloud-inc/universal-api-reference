# Get Search Filter View with Dash.app

Retrieves the search filter view from Dash.app.

## Endpoint

- **Method:** `GET`
- **Path:** `/search-filter-view`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Search Filter View](https://api-docs.dash.app/dash/openapi/search-filters/getsearchfilterview)
