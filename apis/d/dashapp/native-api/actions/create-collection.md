# Create Collection with Dash.app

Creates a new collection in Dash.app.

## Endpoint

- **Method:** `POST`
- **Path:** `/collections`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Create Collection](https://api-docs.dash.app/dash/openapi/collections/postcollection.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the collection to create. |
