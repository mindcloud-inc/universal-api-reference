# Get Group with Dash.app

Retrieves a group from Dash.app by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Group](https://api-docs.dash.app/dash/openapi/users/getgroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Dash group ID. |
