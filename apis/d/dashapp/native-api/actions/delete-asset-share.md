# Delete Asset Share with Dash.app

Deletes an existing asset share from Dash.app.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/asset-shares/:id`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Delete Asset Share](https://api-docs.dash.app/dash/openapi/asset-shares/deleteassetshare)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
