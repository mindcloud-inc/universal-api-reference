# Get Corebook Settings with Dash.app

Retrieves Corebook settings from your Dash.app account.

## Endpoint

- **Method:** `GET`
- **Path:** `/corebook-settings`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Corebook Settings](https://api-docs.dash.app/dash/openapi/corebook/getcorebooksettings)
