# Get Grouped Preset Transformations with Dash.app

Retrieves grouped preset transformations from Dash.app.

## Endpoint

- **Method:** `GET`
- **Path:** `/grouped-preset-transformations`
- **Base URL:** `https://api-v2.dash.app`
- **Official documentation:** [Get Grouped Preset Transformations](https://api-docs.dash.app/dash/openapi/preset-transformations/getgroupedpresettransformations)
