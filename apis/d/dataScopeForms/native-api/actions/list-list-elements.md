# List List Elements with DataScope Forms

Retrieves list elements from DataScope Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/external/metadata_objects`
- **Base URL:** `https://www.mydatascope.com/api`
- **Official documentation:** [List List Elements](https://dscope.github.io/docs/#get-all-list-elements)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `metadata_type` | query | `string` | no | Internal code that identifies the target list. |
