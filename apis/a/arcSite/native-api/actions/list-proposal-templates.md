# List Proposal Templates with ArcSite

Retrieves proposal templates from your ArcSite organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/proposal_templates`
- **Base URL:** `https://api.arcsite.com/v1`
- **Official documentation:** [List Proposal Templates](https://dev.arcsite.com/#query-proposal-templates)

## Capabilities

This operation supports [pagination](../README.md#pagination).
