# Unarchive Project with ArcSite

Unarchives an existing project in ArcSite.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:projectId/unarchive`
- **Base URL:** `https://api.arcsite.com/v1`
- **Official documentation:** [Unarchive Project](https://dev.arcsite.com/#unarchive-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The ID of the project. |
