# Archive Project with ArcSite

Archives an existing project in ArcSite.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:projectId/archive`
- **Base URL:** `https://api.arcsite.com/v1`
- **Official documentation:** [Archive Project](https://dev.arcsite.com/#archive-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The ID of the project. |
