# Get Project with ArcSite

Retrieves one project by ID from ArcSite.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://api.arcsite.com/v1`
- **Official documentation:** [Get Project](https://dev.arcsite.com/#get-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The ID of the project. |
