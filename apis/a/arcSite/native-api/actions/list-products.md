# List Products with ArcSite

Retrieves product records from your ArcSite organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://api.arcsite.com/v1`
- **Official documentation:** [List Products](https://dev.arcsite.com/#query-products)

## Capabilities

This operation supports [pagination](../README.md#pagination).
