# List Finished Tasks with Abbyy

Retrieves finished OCR tasks from ABBYY Cloud OCR SDK.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/listFinishedTasks`
- **Base URL:** `https://cloud-westus.ocrsdk.com`
- **Official documentation:** [List Finished Tasks](https://support.abbyy.com/hc/en-us/articles/360017269600-listFinishedTasks-Method)
