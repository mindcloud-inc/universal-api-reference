# Add Model To Team with Airiam AI

Adds a model to the team in Airiam AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/models/add-to-team`
- **Base URL:** `https://platform.sectorflow.ai`
- **Official documentation:** [Add Model To Team](https://docs.ai.airiam.com/reference/models)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Model ID to add to the team. |
