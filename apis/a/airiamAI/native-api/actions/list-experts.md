# List Experts with Airiam AI

Retrieves a list of experts from Airiam AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/plus`
- **Base URL:** `https://platform.sectorflow.ai`
- **Official documentation:** [List Experts](https://docs.ai.airiam.com/reference/airiam-ai-experts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `showPublic` | query | `boolean` | no | Whether to include public experts. |
