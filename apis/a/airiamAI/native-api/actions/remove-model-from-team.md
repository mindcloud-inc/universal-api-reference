# Remove Model From Team with Airiam AI

Removes a model from the team in Airiam AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/models/remove-from-team`
- **Base URL:** `https://platform.sectorflow.ai`
- **Official documentation:** [Remove Model From Team](https://docs.ai.airiam.com/reference/models)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Model ID to remove from the team. |
