# Delete Expert File with Airiam AI

Deletes an existing expert file from Airiam AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/plus/file/:fileId`
- **Base URL:** `https://platform.sectorflow.ai`
- **Official documentation:** [Delete Expert File](https://docs.ai.airiam.com/reference/airiam-ai-experts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | Expert file identifier. |
