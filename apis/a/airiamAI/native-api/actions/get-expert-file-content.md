# Get Expert File Content with Airiam AI

Retrieves expert file content from Airiam AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/plus/file/:fileId/content`
- **Base URL:** `https://platform.sectorflow.ai`
- **Official documentation:** [Get Expert File Content](https://docs.ai.airiam.com/reference/airiam-ai-experts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | Expert file identifier. |
