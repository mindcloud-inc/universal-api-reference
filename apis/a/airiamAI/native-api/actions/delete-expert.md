# Delete Expert with Airiam AI

Deletes an existing expert from Airiam AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/plus/:plusId`
- **Base URL:** `https://platform.sectorflow.ai`
- **Official documentation:** [Delete Expert](https://docs.ai.airiam.com/reference/airiam-ai-experts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `plusId` | path | `string` | yes | Expert identifier from the Airiam plus endpoint. |
