# Update Product with Agiliron

Updates an existing product in Agiliron.

## Endpoint

- **Method:** `POST`
- **Path:** `Products`
- **Base URL:** `https://{yourCompany}.agiliron.net/agiliron/api-40.php/`
- **Official documentation:** [Update Product](https://api.agiliron.com/docs/update-product-2)
