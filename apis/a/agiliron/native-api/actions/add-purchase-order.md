# Add PurchaseOrder with Agiliron

Creates a new purchase order in Agiliron.

## Endpoint

- **Method:** `POST`
- **Path:** `PurchaseOrder`
- **Base URL:** `https://{yourCompany}.agiliron.net/agiliron/api-40.php/`
- **Official documentation:** [Add PurchaseOrder](https://api.agiliron.com/docs/add-purchaseorder-1)
