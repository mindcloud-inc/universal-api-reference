# Read Product Inventory with Agiliron

Retrieves product inventory records from Agiliron.

## Endpoint

- **Method:** `GET`
- **Path:** `ProductsInventory`
- **Base URL:** `https://{yourCompany}.agiliron.net/agiliron/api-40.php/`
- **Official documentation:** [Read Product Inventory](https://api.agiliron.com/docs/read-product-inventory)
