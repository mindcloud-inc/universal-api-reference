# Update SalesOrder with Agiliron

Updates an existing sales order in Agiliron.

## Endpoint

- **Method:** `PUT`
- **Path:** `SalesOrder`
- **Base URL:** `https://{yourCompany}.agiliron.net/agiliron/api-40.php/`
- **Official documentation:** [Update SalesOrder](https://api.agiliron.com/docs/update-salesorder-1)
