# Read SalesOrder with Agiliron

Retrieves sales order records from Agiliron.

## Endpoint

- **Method:** `GET`
- **Path:** `SalesOrder`
- **Base URL:** `https://{yourCompany}.agiliron.net/agiliron/api-40.php/`
- **Official documentation:** [Read SalesOrder](https://api.agiliron.com/docs/read-salesorder-1)
