# Update PurchaseOrder with Agiliron

Updates an existing purchase order in Agiliron.

## Endpoint

- **Method:** `PUT`
- **Path:** `PurchaseOrder`
- **Base URL:** `https://{yourCompany}.agiliron.net/agiliron/api-40.php/`
- **Official documentation:** [Update PurchaseOrder](https://api.agiliron.com/docs/update-purchaseorder-1)
