# Read PurchaseOrder with Agiliron

Retrieves purchase order records from Agiliron.

## Endpoint

- **Method:** `GET`
- **Path:** `PurchaseOrder`
- **Base URL:** `https://{yourCompany}.agiliron.net/agiliron/api-40.php/`
- **Official documentation:** [Read PurchaseOrder](https://api.agiliron.com/docs/read-purchaseorder-1)
