# Add Product Inventory with Agiliron

Adds inventory to an existing product in Agiliron.

## Endpoint

- **Method:** `POST`
- **Path:** `ProductsInventory`
- **Base URL:** `https://{yourCompany}.agiliron.net/agiliron/api-40.php/`
- **Official documentation:** [Add Product Inventory](https://api.agiliron.com/docs/add-product-inventory-1)
