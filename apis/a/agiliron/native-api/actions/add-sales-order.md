# Add SalesOrder with Agiliron

Creates a new sales order in Agiliron.

## Endpoint

- **Method:** `POST`
- **Path:** `SalesOrder`
- **Base URL:** `https://{yourCompany}.agiliron.net/agiliron/api-40.php/`
- **Official documentation:** [Add SalesOrder](https://api.agiliron.com/docs/add-salesorder-1)
