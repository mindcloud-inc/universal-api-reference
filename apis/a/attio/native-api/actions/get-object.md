# Get Object with Attio

Retrieves an object from Attio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/objects/:object`
- **Base URL:** `https://api.attio.com`
- **Official documentation:** [Get Object](https://docs.attio.com/rest-api/endpoint-reference/objects/get-an-object)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `object` | path | `string` | yes | The Attio object slug or UUID to retrieve. |
