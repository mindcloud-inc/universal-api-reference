# List Notes with Attio

Retrieves notes from Attio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/notes`
- **Base URL:** `https://api.attio.com`
- **Official documentation:** [List Notes](https://docs.attio.com/rest-api/endpoint-reference/notes/list-notes)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `parent_object` | query | `string` | no |
| `parent_record_id` | query | `string` | no |
