# Get Task with Attio

Retrieves a task from Attio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/tasks/:task_id`
- **Base URL:** `https://api.attio.com`
- **Official documentation:** [Get Task](https://docs.attio.com/rest-api/endpoint-reference/tasks/get-a-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | The ID of the task to retrieve. |
