# List Webhooks with Attio

Retrieves webhooks from Attio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/webhooks`
- **Base URL:** `https://api.attio.com`
- **Official documentation:** [List Webhooks](https://docs.attio.com/rest-api/endpoint-reference/webhooks/list-webhooks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
