# Get List with Attio

Retrieves a list from Attio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/lists/:list`
- **Base URL:** `https://api.attio.com`
- **Official documentation:** [Get List](https://docs.attio.com/rest-api/endpoint-reference/lists/get-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list` | path | `string` | yes | The UUID or slug identifying the list. |
