# Delete Image with AltTextify

Deletes an image from AltTextify by asset ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/image/:asset_id`
- **Base URL:** `https://api.alttextify.net/api/v1`
- **Official documentation:** [Delete Image](https://apidoc.alttextify.net/#api-Image-DeleteImage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `asset_id` | path | `string` | yes | The AltTextify asset ID of the image to delete. |
