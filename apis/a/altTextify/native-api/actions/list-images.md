# List Images with AltTextify

Retrieves all account images from AltTextify.

## Endpoint

- **Method:** `GET`
- **Path:** `/image`
- **Base URL:** `https://api.alttextify.net/api/v1`
- **Official documentation:** [List Images](https://apidoc.alttextify.net/#api-Image-GetImages)

## Capabilities

This operation supports [pagination](../README.md#pagination).
