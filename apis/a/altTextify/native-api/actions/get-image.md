# Get Image with AltTextify

Retrieves an image from AltTextify by asset ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/image/:asset_id`
- **Base URL:** `https://api.alttextify.net/api/v1`
- **Official documentation:** [Get Image](https://apidoc.alttextify.net/#api-Image-GetImageByAssetID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `asset_id` | path | `string` | yes | The AltTextify asset ID of the image to retrieve. |
