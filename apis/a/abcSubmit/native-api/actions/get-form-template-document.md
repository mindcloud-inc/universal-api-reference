# Get Form Template Document with AbcSubmit

Retrieves a form template document from AbcSubmit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/templates/:form_id`
- **Base URL:** `https://www.abcsubmit.com`
- **Official documentation:** [Get Form Template Document](https://www.abcsubmit.com/site/api-documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `form_id` | path | `string` | yes | The ID of the form template document to retrieve. |
