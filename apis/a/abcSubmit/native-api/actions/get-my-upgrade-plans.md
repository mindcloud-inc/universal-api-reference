# Get My Upgrade Plans with AbcSubmit

Retrieves your personalized upgrade plans from AbcSubmit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/users/my-upgrade-plans`
- **Base URL:** `https://www.abcsubmit.com`
- **Official documentation:** [Get My Upgrade Plans](https://www.abcsubmit.com/site/api-documentation/)
