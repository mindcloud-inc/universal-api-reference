# Count Contacts with Autotask

## Endpoint

- **Method:** `GET`
- **Path:** `/Contacts/query/count`
- **Base URL:** `https://webservices14.autotask.net/ATServicesRest/v1.0`
- **Official documentation:** [Count Contacts](https://www.autotask.net/help/developerhelp/Content/APIs/REST/Entities/ContactsEntity.htm)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Optional Autotask search JSON used to count matching contacts. |
