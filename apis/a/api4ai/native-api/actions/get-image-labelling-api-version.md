# Get Image Labelling API Version with api4ai

Retrieves the image labelling API version from api4ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/general-cls/v1/version`
- **Base URL:** `https://api4ai.cloud`
- **Official documentation:** [Get Image Labelling API Version](https://api4.ai/docs/image-labelling)
