# Get Image Upscale API Version with api4ai

Retrieves the image upscale API version from api4ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/image-upscale/v1/version`
- **Base URL:** `https://api4ai.cloud`
- **Official documentation:** [Get Image Upscale API Version](https://api4.ai/docs/image-upscale)
