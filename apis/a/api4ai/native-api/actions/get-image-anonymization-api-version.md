# Get Image Anonymization API Version with api4ai

Retrieves the image anonymization API version from api4ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/img-anonymization/v1/version`
- **Base URL:** `https://api4ai.cloud`
- **Official documentation:** [Get Image Anonymization API Version](https://api4.ai/docs/image-anonymization)
