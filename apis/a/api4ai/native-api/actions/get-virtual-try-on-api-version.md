# Get Virtual Try-On API Version with api4ai

Retrieves the virtual try-on API version from api4ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/virtual-try-on/v1/version`
- **Base URL:** `https://api4ai.cloud`
- **Official documentation:** [Get Virtual Try-On API Version](https://api4.ai/docs/virtual-try-on)
