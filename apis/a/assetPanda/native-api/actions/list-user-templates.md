# List User Templates with Asset Panda

Retrieves user templates from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/users/templates`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [List User Templates](https://team-asset-panda.readme.io/reference/get_v3-users-templates)
