# Search Objects with Asset Panda

Finds objects in Asset Panda.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/groups/:groupId/search/objects`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Search Objects](https://team-asset-panda.readme.io/reference/post_v3-groups-group-id-search-objects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
