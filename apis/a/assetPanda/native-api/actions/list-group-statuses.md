# List Group Statuses with Asset Panda

Retrieves group statuses from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/groups/:groupId/statuses`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [List Group Statuses](https://team-asset-panda.readme.io/reference/get_v3-groups-group-id-statuses)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
