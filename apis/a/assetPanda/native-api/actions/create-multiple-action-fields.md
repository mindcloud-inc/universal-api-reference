# Create Multiple Action Fields with Asset Panda

Creates multiple action fields in Asset Panda.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/actions/:actionId/fields`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Create Multiple Action Fields](https://team-asset-panda.readme.io/reference/post_v3-actions-action-id-fields)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `action_id` | path | `string` | no |
