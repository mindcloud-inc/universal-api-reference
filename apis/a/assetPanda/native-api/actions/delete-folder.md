# Delete Folder with Asset Panda

Deletes an attachment folder from Asset Panda.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/attachment/folders/:folderId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Delete Folder](https://team-asset-panda.readme.io/reference/delete_v3-attachment-folders-folder-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folder_id` | path | `string` | no |
