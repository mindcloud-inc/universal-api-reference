# List Action Fields with Asset Panda

Retrieves action fields from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/actions/:actionId/fields`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [List Action Fields](https://team-asset-panda.readme.io/reference/get_v3-actions-action-id-fields)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `action_id` | path | `string` | no |
