# Link Attachment to Object with Asset Panda

Links an attachment to an object in Asset Panda.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/group/objects/:groupObjectId/attachments`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Link Attachment to Object](https://team-asset-panda.readme.io/reference/post_v3-group-objects-group-object-id-attachments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_object_id` | path | `string` | no |
