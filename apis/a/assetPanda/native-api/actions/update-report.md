# Update Report with Asset Panda

Updates a report in Asset Panda.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v3/reports/:reportId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Update Report](https://team-asset-panda.readme.io/reference/put_v3-reports-report-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `report_id` | path | `string` | no |
