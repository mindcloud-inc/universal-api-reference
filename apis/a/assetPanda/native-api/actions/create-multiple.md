# Create Multiple with Asset Panda

Creates multiple action objects in Asset Panda.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/entity_objects/action_objects/:id/create_multiple`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Create Multiple](https://team-asset-panda.readme.io/reference/post_v3-entity-objects-action-objects-id-create-multiple)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
