# Update Multiple Objects with Asset Panda

Updates multiple objects in Asset Panda.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v3/groups/:groupId/objects`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Update Multiple Objects](https://team-asset-panda.readme.io/reference/put_v3-groups-group-id-objects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
