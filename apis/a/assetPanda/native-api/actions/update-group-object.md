# Update Group Object with Asset Panda

Updates a group object in Asset Panda.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v3/groups/:groupId/objects/:objectId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Update Group Object](https://team-asset-panda.readme.io/reference/patch_v3-groups-group-id-objects-object-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
| `object_id` | path | `string` | no |
