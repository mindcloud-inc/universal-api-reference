# List Linked Fields with Asset Panda

Retrieves linked fields from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/entity_objects/:id/linked_fields`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [List Linked Fields](https://team-asset-panda.readme.io/reference/get_v3-entity-objects-id-linked-fields)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
