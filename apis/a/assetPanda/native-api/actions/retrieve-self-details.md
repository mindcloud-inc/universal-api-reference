# Retrieve Self Details with Asset Panda

Retrieves your user details from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/users/me`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Retrieve Self Details](https://team-asset-panda.readme.io/reference/get_v3-users-me)
