# List Linked Objects with Asset Panda

Retrieves linked objects from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/entity_objects/:id/linked_objects/:fieldId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [List Linked Objects](https://team-asset-panda.readme.io/reference/get_v3-entity-objects-id-linked-objects-field-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `field_id` | path | `string` | no |
| `id` | path | `string` | no |
