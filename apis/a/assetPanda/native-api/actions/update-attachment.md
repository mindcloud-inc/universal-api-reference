# Update Attachment with Asset Panda

Updates an attachment in Asset Panda.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v3/attachments/:attachmentId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Update Attachment](https://team-asset-panda.readme.io/reference/put_v3-attachments-attachment-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `attachment_id` | path | `string` | no |
