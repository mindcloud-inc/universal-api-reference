# Delete Action Field with Asset Panda

Deletes an action field from Asset Panda.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/actions/:actionId/fields/:fieldId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Delete Action Field](https://team-asset-panda.readme.io/reference/delete_v3-actions-action-id-fields-field-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `action_id` | path | `string` | no |
| `field_id` | path | `string` | no |
