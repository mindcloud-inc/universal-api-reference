# Create Object with Asset Panda

Creates one or more objects in Asset Panda.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/groups/:groupId/objects`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Create Object](https://team-asset-panda.readme.io/reference/post_v3-groups-group-id-objects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
