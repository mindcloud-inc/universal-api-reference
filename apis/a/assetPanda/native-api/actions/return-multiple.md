# Return Multiple with Asset Panda

Returns multiple objects in Asset Panda.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/entity_objects/action_objects/:id/return_multiple`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Return Multiple](https://team-asset-panda.readme.io/reference/post_v3-entity-objects-action-objects-id-return-multiple)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
