# List Action Objects with Asset Panda

Retrieves action objects from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/entity_objects/:objectId/action_objects`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [List Action Objects](https://team-asset-panda.readme.io/reference/get_v3-entity-objects-object-id-action-objects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `object_id` | path | `string` | no |
