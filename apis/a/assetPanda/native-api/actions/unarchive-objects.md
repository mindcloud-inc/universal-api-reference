# Unarchive Objects with Asset Panda

Unarchives objects in Asset Panda.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/groups/:groupId/objects/unarchive`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Unarchive Objects](https://team-asset-panda.readme.io/reference/post_v3-groups-group-id-objects-unarchive)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
