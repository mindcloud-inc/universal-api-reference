# Create Folder with Asset Panda

Creates a new attachment folder in Asset Panda.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/attachment/folders/:folderId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Create Folder](https://team-asset-panda.readme.io/reference/post_v3-attachment-folders-folder-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folder_id` | path | `string` | no |
