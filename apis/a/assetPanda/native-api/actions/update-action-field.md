# Update Action Field with Asset Panda

Updates an action field in Asset Panda.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v3/actions/:actionId/fields/:fieldId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Update Action Field](https://team-asset-panda.readme.io/reference/put_v3-actions-action-id-fields-field-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `action_id` | path | `string` | no |
| `field_id` | path | `string` | no |
