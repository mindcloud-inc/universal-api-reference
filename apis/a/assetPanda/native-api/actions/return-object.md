# Return Object with Asset Panda

Returns an object in Asset Panda.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/entity_objects/action_objects/:actionId/return_object`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Return Object](https://team-asset-panda.readme.io/reference/post_v3-entity-objects-action-objects-action-id-return-object)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `action_id` | path | `string` | no |
