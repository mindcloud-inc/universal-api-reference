# List Attachments with Asset Panda

Retrieves attachments from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/attachments`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [List Attachments](https://team-asset-panda.readme.io/reference/get_v3-attachments)
