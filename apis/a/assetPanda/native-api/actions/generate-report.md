# Generate Report with Asset Panda

Generates a report in Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/reports/:reportId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Generate Report](https://team-asset-panda.readme.io/reference/get_v3-reports-report-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `report_id` | path | `string` | no |
