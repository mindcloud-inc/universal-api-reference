# Attach Attachment to Object with Asset Panda

Attaches an attachment to an object in Asset Panda.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v3/groups/:groupId/objects/:groupObjectId/attachment/:attachmentId/attach`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Attach Attachment to Object](https://team-asset-panda.readme.io/reference/put_v3-groups-group-id-objects-group-object-id-attachment-attachment-id-attach)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `attachment_id` | path | `string` | no |
| `group_id` | path | `string` | no |
| `group_object_id` | path | `string` | no |
