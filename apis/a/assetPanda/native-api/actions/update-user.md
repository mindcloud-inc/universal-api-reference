# Update User with Asset Panda

Updates a user in Asset Panda.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v3/users/:userId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Update User](https://team-asset-panda.readme.io/reference/put_v3-users-user-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | path | `string` | no |
