# Get Group with Asset Panda

Retrieves a group from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/groups/:groupId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Get Group](https://team-asset-panda.readme.io/reference/get_v3-groups-group-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
