# List Change Logs with Asset Panda

Retrieves change logs from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/entity_objects/:objectId/change_logs`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [List Change Logs](https://team-asset-panda.readme.io/reference/get_v3-entity-objects-object-id-change-logs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `object_id` | path | `string` | no |
