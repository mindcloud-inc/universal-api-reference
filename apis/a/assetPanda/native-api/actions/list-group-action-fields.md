# List Group Action Fields with Asset Panda

Retrieves group action fields from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/groups/:groupId/actions/:actionId/fields`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [List Group Action Fields](https://team-asset-panda.readme.io/reference/get_v3-groups-group-id-actions-action-id-fields)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `action_id` | path | `string` | no |
| `group_id` | path | `string` | no |
