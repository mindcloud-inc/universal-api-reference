# Get Account Details with Asset Panda

Retrieves account details from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/accounts/:accountId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Get Account Details](https://team-asset-panda.readme.io/reference/get_v3-accounts-account-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `account_id` | path | `string` | no |
