# Delete Account with Asset Panda

Deletes an account from Asset Panda.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/accounts/:accountId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Delete Account](https://team-asset-panda.readme.io/reference/delete_v3-accounts-account-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `account_id` | path | `string` | no |
