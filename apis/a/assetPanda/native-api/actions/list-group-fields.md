# List Group Fields with Asset Panda

Retrieves group fields from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/groups/:groupId/fields`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [List Group Fields](https://team-asset-panda.readme.io/reference/get_v3-groups-group-id-fields)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
