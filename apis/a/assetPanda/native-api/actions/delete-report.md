# Delete Report with Asset Panda

Deletes a report from Asset Panda.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/reports/:reportId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Delete Report](https://team-asset-panda.readme.io/reference/delete_v3-reports-report-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `report_id` | path | `string` | no |
