# Archive Objects with Asset Panda

Archives objects in Asset Panda.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/groups/:groupId/objects/archive`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Archive Objects](https://team-asset-panda.readme.io/reference/post_v3-groups-group-id-objects-archive)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
