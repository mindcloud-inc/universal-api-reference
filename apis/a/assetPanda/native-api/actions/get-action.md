# Get Action with Asset Panda

Retrieves an action from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/actions/:actionId`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Get Action](https://team-asset-panda.readme.io/reference/get_v3-actions-action-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `action_id` | path | `string` | no |
