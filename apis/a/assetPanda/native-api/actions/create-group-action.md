# Create Group Action with Asset Panda

Creates a new group action in Asset Panda.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/groups/:groupId/actions`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Create Group Action](https://team-asset-panda.readme.io/reference/post_v3-groups-group-id-actions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
