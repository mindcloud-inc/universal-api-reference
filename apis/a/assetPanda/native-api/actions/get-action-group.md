# Get Action Group with Asset Panda

Retrieves an action group from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/actions/:actionId/group`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [Get Action Group](https://team-asset-panda.readme.io/reference/get_v3-actions-action-id-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `action_id` | path | `string` | no |
