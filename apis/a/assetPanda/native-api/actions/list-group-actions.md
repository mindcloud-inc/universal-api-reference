# List Group Actions with Asset Panda

Retrieves group actions from Asset Panda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/groups/:groupId/actions`
- **Base URL:** `https://api.assetpanda.com`
- **Official documentation:** [List Group Actions](https://team-asset-panda.readme.io/reference/get_v3-groups-group-id-actions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
