# Get Adjusted Monthly Time Series with Alpha Vantage

Retrieves adjusted monthly time series data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Adjusted Monthly Time Series](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Query parameter $key for TIME_SERIES_MONTHLY_ADJUSTED. |
