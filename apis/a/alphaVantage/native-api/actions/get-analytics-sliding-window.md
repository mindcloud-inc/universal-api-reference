# Get Analytics Sliding Window with Alpha Vantage

Retrieves analytics sliding window data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Analytics Sliding Window](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CALCULATIONS` | query | `string` | yes | Query parameter $key for ANALYTICS_SLIDING_WINDOW. |
| `INTERVAL` | query | `string` | yes | Query parameter $key for ANALYTICS_SLIDING_WINDOW. |
| `OHLC` | query | `string` | yes | Query parameter $key for ANALYTICS_SLIDING_WINDOW. |
| `RANGE` | query | `string` | yes | Query parameter $key for ANALYTICS_SLIDING_WINDOW. |
| `SYMBOLS` | query | `string` | yes | Query parameter $key for ANALYTICS_SLIDING_WINDOW. |
| `WINDOW_SIZE` | query | `string` | yes | Query parameter $key for ANALYTICS_SLIDING_WINDOW. |
