# Get CMO Indicator with Alpha Vantage

Retrieves CMO indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get CMO Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `interval` | query | `string` | yes | Query parameter $key for CMO. |
| `series_type` | query | `string` | yes | Query parameter $key for CMO. |
| `symbol` | query | `string` | yes | Query parameter $key for CMO. |
| `time_period` | query | `string` | yes | Query parameter $key for CMO. |
