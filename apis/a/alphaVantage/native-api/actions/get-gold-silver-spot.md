# Get Gold Silver Spot with Alpha Vantage

Retrieves gold and silver spot prices from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Gold Silver Spot](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Query parameter $key for GOLD_SILVER_SPOT. |
