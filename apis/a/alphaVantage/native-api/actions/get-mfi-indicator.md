# Get MFI Indicator with Alpha Vantage

Retrieves MFI indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get MFI Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `interval` | query | `string` | yes | Query parameter $key for MFI. |
| `symbol` | query | `string` | yes | Query parameter $key for MFI. |
| `time_period` | query | `string` | no | Number of periods to evaluate. |
| `time_period` | query | `string` | yes | Query parameter $key for MFI. |
