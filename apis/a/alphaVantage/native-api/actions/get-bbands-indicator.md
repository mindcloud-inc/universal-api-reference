# Get BBANDS Indicator with Alpha Vantage

Retrieves BBANDS indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get BBANDS Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `interval` | query | `string` | yes | Query parameter $key for BBANDS. |
| `nbdevdn` | query | `string` | yes | Query parameter $key for BBANDS. |
| `nbdevup` | query | `string` | yes | Query parameter $key for BBANDS. |
| `series_type` | query | `string` | yes | Query parameter $key for BBANDS. |
| `symbol` | query | `string` | yes | Query parameter $key for BBANDS. |
| `time_period` | query | `string` | yes | Query parameter $key for BBANDS. |
