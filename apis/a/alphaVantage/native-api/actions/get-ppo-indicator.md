# Get PPO Indicator with Alpha Vantage

Retrieves PPO indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get PPO Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fastperiod` | query | `string` | yes | Query parameter $key for PPO. |
| `interval` | query | `string` | yes | Query parameter $key for PPO. |
| `matype` | query | `string` | yes | Query parameter $key for PPO. |
| `series_type` | query | `string` | yes | Query parameter $key for PPO. |
| `symbol` | query | `string` | yes | Query parameter $key for PPO. |
