# Get Earnings Call Transcript with Alpha Vantage

Retrieves an earnings call transcript from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Earnings Call Transcript](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `quarter` | query | `string` | yes | Query parameter $key for EARNINGS_CALL_TRANSCRIPT. |
| `symbol` | query | `string` | yes | Query parameter $key for EARNINGS_CALL_TRANSCRIPT. |
