# Get Gold Silver History with Alpha Vantage

Retrieves gold and silver price history from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Gold Silver History](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `interval` | query | `string` | yes | Query parameter $key for GOLD_SILVER_HISTORY. |
| `symbol` | query | `string` | yes | Query parameter $key for GOLD_SILVER_HISTORY. |
