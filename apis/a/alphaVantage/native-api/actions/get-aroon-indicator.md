# Get AROON Indicator with Alpha Vantage

Retrieves AROON indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get AROON Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `interval` | query | `string` | yes | Query parameter $key for AROON. |
| `symbol` | query | `string` | yes | Query parameter $key for AROON. |
| `time_period` | query | `string` | yes | Query parameter $key for AROON. |
