# Get Crypto Monthly with Alpha Vantage

Retrieves crypto monthly data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Crypto Monthly](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `market` | query | `string` | yes | Query parameter $key for DIGITAL_CURRENCY_MONTHLY. |
| `symbol` | query | `string` | yes | Query parameter $key for DIGITAL_CURRENCY_MONTHLY. |
