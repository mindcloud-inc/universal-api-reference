# Get Institutional Holdings with Alpha Vantage

Retrieves institutional holdings data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Institutional Holdings](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Query parameter $key for INSTITUTIONAL_HOLDINGS. |
