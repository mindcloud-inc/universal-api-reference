# Get IPO Calendar with Alpha Vantage

Retrieves IPO calendar data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get IPO Calendar](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `function` | query | `string` | no | Fixed Alpha Vantage function name for IPO calendar. |
