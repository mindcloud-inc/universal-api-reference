# Get STOCH Indicator with Alpha Vantage

Retrieves STOCH indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get STOCH Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `interval` | query | `string` | yes | Query parameter $key for STOCH. |
| `symbol` | query | `string` | yes | Query parameter $key for STOCH. |
