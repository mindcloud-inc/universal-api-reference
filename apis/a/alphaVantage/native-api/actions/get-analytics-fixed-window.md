# Get Analytics Fixed Window with Alpha Vantage

Retrieves analytics fixed window data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Analytics Fixed Window](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CALCULATIONS` | query | `string` | yes | Query parameter $key for ANALYTICS_FIXED_WINDOW. |
| `INTERVAL` | query | `string` | yes | Query parameter $key for ANALYTICS_FIXED_WINDOW. |
| `OHLC` | query | `string` | yes | Query parameter $key for ANALYTICS_FIXED_WINDOW. |
| `RANGE` | query | `string` | yes | Query parameter $key for ANALYTICS_FIXED_WINDOW. |
| `SYMBOLS` | query | `string` | yes | Query parameter $key for ANALYTICS_FIXED_WINDOW. |
