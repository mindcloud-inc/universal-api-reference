# Get Realtime Put Call Ratio with Alpha Vantage

Retrieves realtime put-call ratio data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Realtime Put Call Ratio](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Query parameter $key for REALTIME_PUT_CALL_RATIO. |
