# Get APO Indicator with Alpha Vantage

Retrieves APO indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get APO Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fastperiod` | query | `string` | yes | Query parameter $key for APO. |
| `interval` | query | `string` | yes | Query parameter $key for APO. |
| `matype` | query | `string` | yes | Query parameter $key for APO. |
| `series_type` | query | `string` | yes | Query parameter $key for APO. |
| `symbol` | query | `string` | yes | Query parameter $key for APO. |
