# Get Historical Volume Open Interest Ratio with Alpha Vantage

Retrieves historical volume open interest ratio data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Historical Volume Open Interest Ratio](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `date` | query | `string` | yes | Query parameter $key for HISTORICAL_VOLUME_OPEN_INTEREST_RATIO. |
| `symbol` | query | `string` | yes | Query parameter $key for HISTORICAL_VOLUME_OPEN_INTEREST_RATIO. |
