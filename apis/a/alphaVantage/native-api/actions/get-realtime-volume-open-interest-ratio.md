# Get Realtime Volume Open Interest Ratio with Alpha Vantage

Retrieves realtime volume open interest ratio data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Realtime Volume Open Interest Ratio](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Query parameter $key for REALTIME_VOLUME_OPEN_INTEREST_RATIO. |
