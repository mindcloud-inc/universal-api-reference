# Get TRIX Indicator with Alpha Vantage

Retrieves TRIX indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get TRIX Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `interval` | query | `string` | yes | Query parameter $key for TRIX. |
| `series_type` | query | `string` | yes | Query parameter $key for TRIX. |
| `symbol` | query | `string` | yes | Query parameter $key for TRIX. |
| `time_period` | query | `string` | yes | Query parameter $key for TRIX. |
