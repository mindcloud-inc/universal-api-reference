# Get HT_DCPHASE Indicator with Alpha Vantage

Retrieves HT_DCPHASE indicator data from Alpha Vantage.

- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get HT_DCPHASE Indicator](https://www.alphavantage.co/documentation/)
