# Get ULTOSC Indicator with Alpha Vantage

Retrieves ULTOSC indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get ULTOSC Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `interval` | query | `string` | yes | Query parameter $key for ULTOSC. |
| `symbol` | query | `string` | yes | Query parameter $key for ULTOSC. |
| `timeperiod1` | query | `string` | no | Query parameter $key for ULTOSC. |
