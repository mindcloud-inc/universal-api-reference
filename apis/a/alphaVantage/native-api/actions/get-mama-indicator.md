# Get MAMA Indicator with Alpha Vantage

Retrieves MAMA indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get MAMA Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fastlimit` | query | `string` | yes | Query parameter $key for MAMA. |
| `interval` | query | `string` | yes | Query parameter $key for MAMA. |
| `series_type` | query | `string` | yes | Query parameter $key for MAMA. |
| `symbol` | query | `string` | yes | Query parameter $key for MAMA. |
