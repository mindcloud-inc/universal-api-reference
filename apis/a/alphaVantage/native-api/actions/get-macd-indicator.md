# Get MACD Indicator with Alpha Vantage

Retrieves MACD indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get MACD Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `interval` | query | `string` | yes | Query parameter $key for MACD. |
| `series_type` | query | `string` | yes | Query parameter $key for MACD. |
| `symbol` | query | `string` | yes | Query parameter $key for MACD. |
