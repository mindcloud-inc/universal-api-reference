# Get Historical Put Call Ratio with Alpha Vantage

Retrieves historical put call ratio data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Historical Put Call Ratio](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `date` | query | `string` | yes | Query parameter $key for HISTORICAL_PUT_CALL_RATIO. |
| `symbol` | query | `string` | yes | Query parameter $key for HISTORICAL_PUT_CALL_RATIO. |
