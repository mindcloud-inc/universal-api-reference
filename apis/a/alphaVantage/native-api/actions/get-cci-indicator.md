# Get CCI Indicator with Alpha Vantage

Retrieves CCI indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get CCI Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `interval` | query | `string` | yes | Query parameter $key for CCI. |
| `symbol` | query | `string` | yes | Query parameter $key for CCI. |
| `time_period` | query | `string` | no | Number of periods to evaluate. |
| `time_period` | query | `string` | yes | Query parameter $key for CCI. |
