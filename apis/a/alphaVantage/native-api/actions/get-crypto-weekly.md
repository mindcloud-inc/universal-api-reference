# Get Crypto Weekly with Alpha Vantage

Retrieves crypto weekly data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Crypto Weekly](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `market` | query | `string` | yes | Query parameter $key for DIGITAL_CURRENCY_WEEKLY. |
| `symbol` | query | `string` | yes | Query parameter $key for DIGITAL_CURRENCY_WEEKLY. |
