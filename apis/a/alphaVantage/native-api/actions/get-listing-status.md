# Get Listing Status with Alpha Vantage

Retrieves listing status data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Listing Status](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `date` | query | `string` | no | Query parameter $key for LISTING_STATUS. |
| `state` | query | `string` | no | Query parameter $key for LISTING_STATUS. |
