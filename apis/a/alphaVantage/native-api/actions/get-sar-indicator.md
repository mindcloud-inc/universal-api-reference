# Get SAR Indicator with Alpha Vantage

Retrieves SAR indicator data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get SAR Indicator](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `acceleration` | query | `string` | yes | Query parameter $key for SAR. |
| `interval` | query | `string` | yes | Query parameter $key for SAR. |
| `maximum` | query | `string` | yes | Query parameter $key for SAR. |
| `symbol` | query | `string` | yes | Query parameter $key for SAR. |
