# Get Crypto Daily with Alpha Vantage

Retrieves crypto daily data from Alpha Vantage.

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://www.alphavantage.co`
- **Official documentation:** [Get Crypto Daily](https://www.alphavantage.co/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `market` | query | `string` | yes | Query parameter $key for DIGITAL_CURRENCY_DAILY. |
| `symbol` | query | `string` | yes | Query parameter $key for DIGITAL_CURRENCY_DAILY. |
