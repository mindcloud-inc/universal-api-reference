# List Schedules with Allscreenshots

Retrieves recurring screenshot schedules from Allscreenshots.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/schedules`
- **Base URL:** `https://api.allscreenshots.com`
- **Official documentation:** [List Schedules](https://docs.allscreenshots.com/api-reference/schedules)
