# Get Talent Documents with Avionte

## Endpoint

- **Method:** `GET`
- **Path:** `/front-office/v1/talent/:talentId/document`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get Talent Documents](https://developer.avionte.com/reference/gettalentdocuments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `talentId` | path | `string` | no |
