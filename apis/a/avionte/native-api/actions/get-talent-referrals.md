# Get Talent Referrals with Avionte

Retrieves talent referrals from Avionte.

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/talent/:talentId/talent-referrals`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get Talent Referrals](https://developer.avionte.com/reference/gettalentreferrals)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `talentId` | path | `number` | yes | The Avionte talent identifier. |
