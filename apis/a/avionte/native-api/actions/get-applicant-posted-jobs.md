# Get Applicant Posted Jobs with Avionte

Retrieves posted jobs for a talent from Avionte.

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/webapplicants/talent/:talentId/posted-jobs`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get Applicant Posted Jobs](https://developer.avionte.com/reference/getapplicantpostedjobs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `talentId` | path | `number` | yes | The Avionte talent identifier. |
