# Get Talent Skills with Avionte

Retrieves talent skills from Avionte.

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/talent/:talentId/skills`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get Talent Skills](https://developer.avionte.com/reference/gettalentskills)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `talentId` | path | `number` | yes | The Avionte talent identifier. |
