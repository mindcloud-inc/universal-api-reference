# Get Talent Document Types with Avionte

Retrieves talent document types from Avionte.

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/talent-document-types`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get Talent Document Types](https://developer.avionte.com/reference/gettalentdocumenttypes)
