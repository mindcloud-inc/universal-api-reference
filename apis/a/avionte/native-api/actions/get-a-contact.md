# Get a Contact with Avionte

Retrieves a contact from Avionte.

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/contact/:contactId`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get a Contact](https://developer.avionte.com/reference/getcontact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | yes | The Avionte contact identifier. |
