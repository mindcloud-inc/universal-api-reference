# Get a Talent Nomination Stage with Avionte

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/talent/stage/:nominationId`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get a Talent Nomination Stage](https://developer.avionte.com/reference/gettalentstage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `nominationId` | path | `number` | yes | The Avionte nomination stage identifier. |
