# Get Web Applicants for a Job with Avionte

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/webapplicants/job/:jobId`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get Web Applicants for a Job](https://developer.avionte.com/reference/get-web-applicants-for-job)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json; charset=utf-8` |

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `jobId` | path | `number` | no |
