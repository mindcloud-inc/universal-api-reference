# Get a Job with Avionte

Retrieves a job from Avionte.

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/job/:jobId`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get a Job](https://developer.avionte.com/reference/getjob)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `number` | yes | The Avionte job identifier. |
