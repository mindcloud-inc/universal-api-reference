# Get Talent Tags with Avionte

## Endpoint

- **Method:** `GET`
- **Path:** `/front-office/v1/talent/:talentId/all-tags`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get Talent Tags](https://developer.avionte.com/reference/get-all-talent-tags)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `talentId` | path | `string` | yes |
