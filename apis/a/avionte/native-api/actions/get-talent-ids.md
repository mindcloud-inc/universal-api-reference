# Get Talent IDs with Avionte

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/talents/ids/:page/:pageSize`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get Talent IDs](https://developer.avionte.com/reference/talentids)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json; charset=utf-8` |
