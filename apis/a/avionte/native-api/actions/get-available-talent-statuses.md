# Get Available Talent Statuses with Avionte

Retrieves talent statuses from Avionte.

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/talent-statuses`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get Available Talent Statuses](https://developer.avionte.com/reference/getavailabletalentstatuses)
