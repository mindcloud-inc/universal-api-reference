# Get a List of Talent Assessments with Avionte

Retrieves talent assessments from Avionte.

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/talent/:talentId/assessments`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get a List of Talent Assessments](https://developer.avionte.com/reference/gettalentassessment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `talentId` | path | `number` | yes | The Avionte talent identifier. |
