# Get a Placement with Avionte

Retrieves a placement from Avionte.

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/placement/:placementId`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get a Placement](https://developer.avionte.com/reference/gethire)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `placementId` | path | `number` | yes | The Avionte placement identifier. |
