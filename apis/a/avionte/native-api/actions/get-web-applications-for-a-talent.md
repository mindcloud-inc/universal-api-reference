# Get Web Applications for a Talent with Avionte

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/webapplicants/talent/:talentId`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get Web Applications for a Talent](https://developer.avionte.com/reference/get-web-applications-for-talent)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `talentId` | path | `string` | yes |
