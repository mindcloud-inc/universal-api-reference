# Get Talent Onboarding Tasks with Avionte

Retrieves talent onboarding tasks from Avionte.

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/talent/:talentId/talent-onboarding-tasks`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get Talent Onboarding Tasks](https://developer.avionte.com/reference/gettalentonbordingtasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `talentId` | path | `number` | yes | The Avionte talent identifier. |
