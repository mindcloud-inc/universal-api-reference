# Get a Department with Avionte

Retrieves a department from Avionte.

## Endpoint

- **Method:** `GET`
- **Path:** `front-office/v1/department/:departmentId`
- **Base URL:** `https://api.avionte.com/`
- **Official documentation:** [Get a Department](https://developer.avionte.com/reference/getdepartment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `departmentId` | path | `number` | yes | The Avionte department identifier. |
