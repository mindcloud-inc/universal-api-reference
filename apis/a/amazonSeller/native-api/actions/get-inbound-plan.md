# Get Inbound Plan with Amazon Seller

Retrieves an inbound plan from Amazon Seller.

## Endpoint

- **Method:** `GET`
- **Path:** `inbound/fba/2024-03-20/inboundPlans/:inboundPlanId`
- **Base URL:** `https://{environment}-{region}.amazon.com`
- **API:** REST
- **Official documentation:** [Get Inbound Plan](https://developer-docs.amazon.com/sp-api/reference/getinboundplan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inboundPlanId` | path | `string` | yes | Identifier for an inbound plan. |
