# Get FBM Report Status with Amazon Seller

Retrieves FBM report details from Amazon Seller.

## Endpoint

- **Method:** `GET`
- **Path:** `reports/2021-06-30/reports/:reportId`
- **Base URL:** `https://{environment}-{region}.amazon.com`
- **API:** REST
- **Official documentation:** [Get FBM Report Status](https://developer-docs.amazon.com/sp-api/docs/reports-api-v2021-06-30-reference#getreport)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `reportId` | path | `string` | yes |
