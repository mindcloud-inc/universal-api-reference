# Get FBM Report Document with Amazon Seller

Retrieves FBM report document details from Amazon Seller.

## Endpoint

- **Method:** `GET`
- **Path:** `reports/2021-06-30/documents/:reportDocumentId`
- **Base URL:** `https://{environment}-{region}.amazon.com`
- **API:** REST
- **Official documentation:** [Get FBM Report Document](https://developer-docs.amazon.com/sp-api/docs/reports-api-v2021-06-30-reference#getreportdocument)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `reportDocumentId` | path | `string` | yes |
