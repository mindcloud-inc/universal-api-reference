# Get Marketplace Participations with Amazon Seller

Retrieves marketplace participations from Amazon Seller.

## Endpoint

- **Method:** `GET`
- **Path:** `sellers/v1/marketplaceParticipations`
- **Base URL:** `https://{environment}-{region}.amazon.com`
- **API:** REST
- **Official documentation:** [Get Marketplace Participations](https://developer-docs.amazon.com/sp-api/reference/getmarketplaceparticipations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
