# Get Account with Amazon Seller

Retrieves seller account and marketplace details from Amazon Seller.

## Endpoint

- **Method:** `GET`
- **Path:** `sellers/v1/account`
- **Base URL:** `https://{environment}-{region}.amazon.com`
- **API:** REST
- **Official documentation:** [Get Account](https://developer-docs.amazon.com/sp-api/reference/getaccount)
