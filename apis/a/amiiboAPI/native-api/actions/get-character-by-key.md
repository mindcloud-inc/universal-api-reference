# Get Character by Key with Amiibo API

## Endpoint

- **Method:** `GET`
- **Path:** `/api/character/`
- **Base URL:** `https://amiiboapi.com`
- **Official documentation:** [Get Character by Key](https://github.com/N3evin/AmiiboAPI)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | query | `string` | yes | Required 4-digit hexadecimal character key. |
