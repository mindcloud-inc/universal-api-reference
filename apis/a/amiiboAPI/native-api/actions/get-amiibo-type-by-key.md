# Get Amiibo Type by Key with Amiibo API

## Endpoint

- **Method:** `GET`
- **Path:** `/api/type/`
- **Base URL:** `https://amiiboapi.com`
- **Official documentation:** [Get Amiibo Type by Key](https://github.com/N3evin/AmiiboAPI)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | query | `string` | yes | Required 2-digit hexadecimal Amiibo type key. |
