# Get contact with Atera

Retrieves a contact from Atera by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/contacts/:contactId`
- **Base URL:** `https://app.atera.com`
- **Official documentation:** [Get contact](https://app.atera.com/apidocs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | yes | System contact ID. |
