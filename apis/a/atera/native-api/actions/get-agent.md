# Get agent with Atera

Retrieves an agent from Atera by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/agents/:agentId`
- **Base URL:** `https://app.atera.com`
- **Official documentation:** [Get agent](https://app.atera.com/apidocs#!/Agent/Agent_AgentQueryDTO)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `number` | yes | System agent ID. |
