# Get alert with Atera

Retrieves an alert from Atera by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/alerts/:alertId`
- **Base URL:** `https://app.atera.com`
- **Official documentation:** [Get alert](https://app.atera.com/apidocs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alertId` | path | `number` | yes | System alert ID. |
