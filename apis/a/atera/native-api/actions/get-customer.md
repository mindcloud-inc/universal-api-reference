# Get customer with Atera

Retrieves a customer from Atera by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/customers/:customerId`
- **Base URL:** `https://app.atera.com`
- **Official documentation:** [Get customer](https://app.atera.com/apidocs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `number` | yes | System customer ID. |
