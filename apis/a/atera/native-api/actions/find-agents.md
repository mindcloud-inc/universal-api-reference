# Find agents with Atera

Finds agents in Atera.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/agents`
- **Base URL:** `https://app.atera.com`
- **Official documentation:** [Find agents](https://app.atera.com/apidocs#!/Agent/Agent_Get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
