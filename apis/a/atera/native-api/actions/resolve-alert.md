# Resolve alert with Atera

Updates an existing alert in Atera as resolved.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v3/alerts/:alertId`
- **Base URL:** `https://app.atera.com`
- **Official documentation:** [Resolve alert](https://app.atera.com/apidocs#!/Alert/Alert_ResolveAlert)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alertId` | path | `number` | yes | System alert ID. |
