# Find alerts with Atera

Finds alerts in Atera.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/alerts`
- **Base URL:** `https://app.atera.com`
- **Official documentation:** [Find alerts](https://app.atera.com/apidocs)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alertStatus` | query | `string` | no | Filter alerts by status. |
