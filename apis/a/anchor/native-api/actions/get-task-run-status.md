# Get Task Run Status with Anchor

Retrieves task run status from Anchor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/tasks/runs/:runId/status`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Get Task Run Status](https://docs.anchorbrowser.io/api-reference/tasks/get-task-run-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `runId` | path | `string` | yes |
