# Create Profile with Anchor

Creates a profile in Anchor.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/profiles`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Create Profile](https://docs.anchorbrowser.io/api-reference/profiles/create-profile)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
