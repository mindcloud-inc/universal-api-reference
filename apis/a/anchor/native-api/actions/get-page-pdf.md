# Get Page PDF with Anchor

Retrieves a webpage PDF from Anchor.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/tools/page-pdf`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Get Page PDF](https://docs.anchorbrowser.io/api-reference/tools/get-page-pdf)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | body | `string` | yes |
