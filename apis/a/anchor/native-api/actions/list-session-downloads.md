# List Session Downloads with Anchor

Retrieves session downloads from Anchor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sessions/:sessionId/downloads`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [List Session Downloads](https://docs.anchorbrowser.io/api-reference/browser-sessions/list-session-downloads)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `session_id` | path | `string` | yes |
