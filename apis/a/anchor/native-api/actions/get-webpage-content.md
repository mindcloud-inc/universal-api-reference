# Get Webpage Content with Anchor

Retrieves rendered webpage or PDF content from Anchor.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/tools/fetch-webpage`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Get Webpage Content](https://docs.anchorbrowser.io/api-reference/tools/get-webpage-content)
