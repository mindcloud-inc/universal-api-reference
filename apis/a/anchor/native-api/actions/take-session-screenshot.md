# Take Session Screenshot with Anchor

Retrieves a browser session screenshot from Anchor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sessions/:sessionId/screenshot`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Take Session Screenshot](https://docs.anchorbrowser.io/api-reference/os-level-control/take-screenshot)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sessionId` | path | `string` | yes |
