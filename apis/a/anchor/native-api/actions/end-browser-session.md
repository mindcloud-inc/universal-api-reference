# End Browser Session with Anchor

Deletes a browser session from Anchor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/sessions/:sessionId`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [End Browser Session](https://docs.anchorbrowser.io/api-reference/browser-sessions/end-browser-session)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `session_id` | path | `string` | yes |
