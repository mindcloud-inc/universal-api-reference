# Get Browser Session Pages with Anchor

Retrieves browser session pages from Anchor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sessions/:sessionId/pages`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Get Browser Session Pages](https://docs.anchorbrowser.io/api-reference/browser-sessions/get-browser-session-pages)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `session_id` | path | `string` | yes |
