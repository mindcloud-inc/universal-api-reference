# Get Profile with Anchor

Retrieves a profile from Anchor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/profiles/:name`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Get Profile](https://docs.anchorbrowser.io/api-reference/profiles/get-profile)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | path | `string` | yes |
