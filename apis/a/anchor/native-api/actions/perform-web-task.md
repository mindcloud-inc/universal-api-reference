# Perform Web Task with Anchor

Performs a web task in Anchor.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/tools/perform-web-task`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Perform Web Task](https://docs.anchorbrowser.io/api-reference/ai-tools/perform-web-task)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `prompt` | body | `string` | yes |
