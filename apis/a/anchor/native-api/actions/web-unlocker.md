# Web Unlocker with Anchor

Retrieves webpage content from bot-protected sites with Anchor Web Unlocker.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/tools/fetch/webpage`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Web Unlocker](https://docs.anchorbrowser.io/api-reference/tools/web-unlocker)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | body | `string` | yes |
