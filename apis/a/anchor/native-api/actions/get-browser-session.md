# Get Browser Session with Anchor

Retrieves a browser session from Anchor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sessions/:sessionId`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Get Browser Session](https://docs.anchorbrowser.io/api-reference/browser-sessions/get-browser-session)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `session_id` | path | `string` | yes |
