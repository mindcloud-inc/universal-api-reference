# Delete Profile with Anchor

Deletes a profile from Anchor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/profiles/:name`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Delete Profile](https://docs.anchorbrowser.io/api-reference/profiles/delete-profile)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | path | `string` | yes |
