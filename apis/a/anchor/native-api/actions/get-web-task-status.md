# Get Web Task Status with Anchor

Retrieves web task status from Anchor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tools/perform-web-task/:workflowId/status`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Get Web Task Status](https://docs.anchorbrowser.io/api-reference/ai-tools/get-perform-web-task-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workflowId` | path | `string` | yes |
