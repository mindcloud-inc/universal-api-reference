# Mouse Click with Anchor

Clicks the mouse in an Anchor session.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/sessions/:sessionId/mouse/click`
- **Base URL:** `https://api.anchorbrowser.io`
- **Official documentation:** [Mouse Click](https://docs.anchorbrowser.io/api-reference/os-level-control/mouse-click)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sessionId` | path | `string` | yes |
