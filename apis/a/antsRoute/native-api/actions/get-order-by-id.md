# Get Order by ID with AntsRoute

Retrieves an order from AntsRoute by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/capi/order/id/:id`
- **Base URL:** `https://app.antsroute.com`
- **Official documentation:** [Get Order by ID](https://app.antsroute.com/doc-api/index.html#/Service%2FDelivery%2FCollect/getOrderById)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
