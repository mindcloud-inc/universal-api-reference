# Get Order by External ID with AntsRoute

Retrieves an order from AntsRoute by external ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/capi/order/external-id/:externalId`
- **Base URL:** `https://app.antsroute.com`
- **Official documentation:** [Get Order by External ID](https://app.antsroute.com/doc-api/index.html#/Service%2FDelivery%2FCollect/getOrderByExternalId)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `externalId` | path | `string` | yes |
