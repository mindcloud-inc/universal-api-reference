# Search Order Availabilities with AntsRoute

Finds order availabilities in AntsRoute planning.

## Endpoint

- **Method:** `POST`
- **Path:** `/capi/order/search-availabilities`
- **Base URL:** `https://app.antsroute.com`
- **Official documentation:** [Search Order Availabilities](https://app.antsroute.com/doc-api/index.html#/Search%20availabilities%20and%20validate%20one%20in%20your%20planning/checkOrderAvailabilities)
