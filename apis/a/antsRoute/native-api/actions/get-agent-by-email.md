# Get Agent by Email with AntsRoute

Retrieves an agent from AntsRoute by email.

## Endpoint

- **Method:** `GET`
- **Path:** `/capi/agent/:agentEmail`
- **Base URL:** `https://app.antsroute.com`
- **Official documentation:** [Get Agent by Email](https://app.antsroute.com/doc-api/index.html#/Agent/getAgent)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agentEmail` | path | `string` | yes |
