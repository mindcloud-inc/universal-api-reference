# Get Company Email with AeroLeads

## Endpoint

- **Method:** `GET`
- **Path:** `/api/get_email_details`
- **Base URL:** `https://aeroleads.com`
- **Official documentation:** [Get Company Email](https://aeroleads.com/api#email_api_get_started)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `first_name` | query | `string` | yes | Prospect first name. |
| `last_name` | query | `string` | yes | Prospect last name. |
| `company` | query | `string` | yes | Prospect company name. |
