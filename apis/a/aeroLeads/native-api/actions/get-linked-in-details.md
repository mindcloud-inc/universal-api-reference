# Get LinkedIn Details with AeroLeads

## Endpoint

- **Method:** `GET`
- **Path:** `/api/get_linkedin_details`
- **Base URL:** `https://aeroleads.com`
- **Official documentation:** [Get LinkedIn Details](https://aeroleads.com/api#linkedin_api_get_started)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkedin_url` | query | `string` | yes | LinkedIn profile URL of the prospect. |
