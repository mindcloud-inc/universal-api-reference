# Get Account Information with Amazing Marvin

Retrieves account information from Amazing Marvin.

## Endpoint

- **Method:** `GET`
- **Path:** `/me`
- **Base URL:** `https://serv.amazingmarvin.com/api`
- **Official documentation:** [Get Account Information](https://github.com/amazingmarvin/MarvinAPI/wiki/Marvin-API#me)
