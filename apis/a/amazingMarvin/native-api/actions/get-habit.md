# Get Habit with Amazing Marvin

Retrieves a habit and its history from Amazing Marvin.

## Endpoint

- **Method:** `GET`
- **Path:** `/habit`
- **Base URL:** `https://serv.amazingmarvin.com/api`
- **Official documentation:** [Get Habit](https://github.com/amazingmarvin/MarvinAPI/wiki/Marvin-API#get-a-habit)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Habit ID to retrieve. |
