# List Habits with Amazing Marvin

Retrieves habits and their history from Amazing Marvin.

## Endpoint

- **Method:** `GET`
- **Path:** `/habits`
- **Base URL:** `https://serv.amazingmarvin.com/api`
- **Official documentation:** [List Habits](https://github.com/amazingmarvin/MarvinAPI/wiki/Marvin-API#list-habits)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `raw` | query | `number` | no | Set to 1 to return full habit objects. |
