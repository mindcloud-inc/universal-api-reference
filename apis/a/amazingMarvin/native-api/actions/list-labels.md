# List Labels with Amazing Marvin

Retrieves all labels from Amazing Marvin.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels`
- **Base URL:** `https://serv.amazingmarvin.com/api`
- **Official documentation:** [List Labels](https://github.com/amazingmarvin/MarvinAPI/wiki/Marvin-API#get-a-list-of-all-labels)
