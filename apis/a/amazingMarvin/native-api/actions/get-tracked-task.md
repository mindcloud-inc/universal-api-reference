# Get Tracked Task with Amazing Marvin

Retrieves the tracked task from Amazing Marvin.

## Endpoint

- **Method:** `GET`
- **Path:** `/trackedItem`
- **Base URL:** `https://serv.amazingmarvin.com/api`
- **Official documentation:** [Get Tracked Task](https://github.com/amazingmarvin/MarvinAPI/wiki/Marvin-API#get-the-currently-tracked-task)
