# List Categories with Amazing Marvin

Retrieves all categories from Amazing Marvin.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories`
- **Base URL:** `https://serv.amazingmarvin.com/api`
- **Official documentation:** [List Categories](https://github.com/amazingmarvin/MarvinAPI/wiki/Marvin-API#get-a-list-of-all-categories)
