# Get Kudos with Amazing Marvin

Retrieves kudos information from Amazing Marvin.

## Endpoint

- **Method:** `GET`
- **Path:** `/kudos`
- **Base URL:** `https://serv.amazingmarvin.com/api`
- **Official documentation:** [Get Kudos](https://github.com/amazingmarvin/MarvinAPI/wiki/Marvin-API#get-marvin-kudos-info)
