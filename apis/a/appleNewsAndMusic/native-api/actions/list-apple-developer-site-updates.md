# List Apple Developer Site Updates with Apple News and Music

Retrieves Apple Developer site updates from the official RSS feed.

## Endpoint

- **Method:** `GET`
- **Path:** `https://developer.apple.com/news/site-updates/rss/site-updates.rss`
- **Base URL:** `https://itunes.apple.com`
- **Official documentation:** [List Apple Developer Site Updates](https://developer.apple.com/news/site-updates/rss/site-updates.rss)
