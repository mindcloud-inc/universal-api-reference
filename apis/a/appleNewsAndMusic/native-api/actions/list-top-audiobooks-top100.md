# List Top Audiobooks (Top 100) with Apple News and Music

Retrieves the top 100 audiobooks from Apple Books charts.

## Endpoint

- **Method:** `GET`
- **Path:** `https://rss.marketingtools.apple.com/api/v2/us/audio-books/top/100/audio-books.json`
- **Base URL:** `https://itunes.apple.com`
- **Official documentation:** [List Top Audiobooks (Top 100)](https://rss.marketingtools.apple.com/)
