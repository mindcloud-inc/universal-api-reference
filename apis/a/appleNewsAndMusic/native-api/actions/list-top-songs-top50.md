# List Top Songs (Top 50) with Apple News and Music

Retrieves the top 50 songs from Apple Music charts.

## Endpoint

- **Method:** `GET`
- **Path:** `https://rss.marketingtools.apple.com/api/v2/us/music/most-played/50/songs.json`
- **Base URL:** `https://itunes.apple.com`
- **Official documentation:** [List Top Songs (Top 50)](https://rss.marketingtools.apple.com/)
