# List Top Podcasts (Top 100) with Apple News and Music

Retrieves the top 100 podcasts from Apple Podcasts charts.

## Endpoint

- **Method:** `GET`
- **Path:** `https://rss.marketingtools.apple.com/api/v2/us/podcasts/top/100/podcasts.json`
- **Base URL:** `https://itunes.apple.com`
- **Official documentation:** [List Top Podcasts (Top 100)](https://rss.marketingtools.apple.com/)
