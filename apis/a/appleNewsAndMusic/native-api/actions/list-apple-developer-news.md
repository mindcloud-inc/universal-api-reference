# List Apple Developer News with Apple News and Music

Retrieves Apple Developer news from the official RSS feed.

## Endpoint

- **Method:** `GET`
- **Path:** `https://developer.apple.com/news/rss/news.rss`
- **Base URL:** `https://itunes.apple.com`
- **Official documentation:** [List Apple Developer News](https://developer.apple.com/news/rss/news.rss)
