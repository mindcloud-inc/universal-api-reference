# Get Type of Work with actiTIME

Retrieves a type of work from actiTIME.

## Endpoint

- **Method:** `GET`
- **Path:** `/typesOfWork/:id`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Get Type of Work](https://www.actitime.com/api-documentation/types-of-work-resource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Type of work identifier. |
