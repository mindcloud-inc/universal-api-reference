# Get Project with actiTIME

Retrieves a specific project from actiTIME.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Get Project](https://www.actitime.com/api-documentation/projects-resource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Project identifier. |
