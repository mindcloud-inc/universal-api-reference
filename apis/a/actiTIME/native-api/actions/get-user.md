# Get User with actiTIME

Retrieves a specific user from actiTIME.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:uid`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Get User](https://www.actitime.com/api-documentation/users-resource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | User ID or username. |
