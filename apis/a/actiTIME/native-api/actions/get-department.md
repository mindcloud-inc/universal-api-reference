# Get Department with actiTIME

Retrieves a specific department from actiTIME.

## Endpoint

- **Method:** `GET`
- **Path:** `/departments/:id`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Get Department](https://www.actitime.com/api-documentation/departments-resource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Department identifier. |
