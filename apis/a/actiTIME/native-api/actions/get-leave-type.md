# Get Leave Type with actiTIME

Retrieves a leave type from actiTIME.

## Endpoint

- **Method:** `GET`
- **Path:** `/leaveTypes/:id`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Get Leave Type](https://www.actitime.com/api-documentation/leave-types-resource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Leave type identifier. |
