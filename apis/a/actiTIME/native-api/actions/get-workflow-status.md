# Get Workflow Status with actiTIME

Retrieves a workflow status from actiTIME.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflowStatuses/:id`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Get Workflow Status](https://www.actitime.com/api-documentation/workflow-statuses-resource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Workflow status identifier. |
