# Get Default Type of Work with actiTIME

Retrieves the default type of work from actiTIME.

## Endpoint

- **Method:** `GET`
- **Path:** `/typesOfWork/default`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Get Default Type of Work](https://www.actitime.com/api-documentation/types-of-work-resource)
