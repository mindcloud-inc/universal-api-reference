# Get Customer with actiTIME

Retrieves a specific customer from actiTIME.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:id`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Get Customer](https://www.actitime.com/api-documentation/customers-resource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Customer identifier. |
