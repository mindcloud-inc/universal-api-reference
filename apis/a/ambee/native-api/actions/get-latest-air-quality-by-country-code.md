# Get Latest Air Quality By Country Code with Ambee

Retrieves latest air quality data in Ambee by country code.

## Endpoint

- **Method:** `GET`
- **Path:** `/latest/by-country-code`
- **Base URL:** `https://api.ambeedata.com`
- **Official documentation:** [Get Latest Air Quality By Country Code](https://docs.ambeedata.com/apis/air-quality#latest-countrywise)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `countryCode` | query | `string` | yes |
