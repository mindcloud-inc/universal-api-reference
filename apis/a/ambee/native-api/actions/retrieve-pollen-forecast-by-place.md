# Retrieve Pollen Forecast By Place with Ambee

Retrieves pollen forecasts in Ambee by place name.

## Endpoint

- **Method:** `GET`
- **Path:** `/forecast/pollen/by-place`
- **Base URL:** `https://api.ambeedata.com`
- **Official documentation:** [Retrieve Pollen Forecast By Place](https://docs.ambeedata.com/apis/pollen#forecast-placewise)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `place` | query | `string` | yes |
