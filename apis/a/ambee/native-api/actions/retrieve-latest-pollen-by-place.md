# Retrieve Latest Pollen By Place with Ambee

Retrieves latest pollen data in Ambee by place name.

## Endpoint

- **Method:** `GET`
- **Path:** `/latest/pollen/by-place`
- **Base URL:** `https://api.ambeedata.com`
- **Official documentation:** [Retrieve Latest Pollen By Place](https://docs.ambeedata.com/apis/pollen#latest-placewise)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `place` | query | `string` | yes |
