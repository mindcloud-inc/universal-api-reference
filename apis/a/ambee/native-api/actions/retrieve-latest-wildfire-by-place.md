# Retrieve Latest Wildfire By Place with Ambee

Retrieves latest wildfire data in Ambee by place name.

## Endpoint

- **Method:** `GET`
- **Path:** `/fire/latest/by-place`
- **Base URL:** `https://api.ambeedata.com`
- **Official documentation:** [Retrieve Latest Wildfire By Place](https://docs.ambeedata.com/apis/fire#latest-placewise)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `place` | query | `string` | yes |
