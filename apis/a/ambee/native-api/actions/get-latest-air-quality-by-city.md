# Get Latest Air Quality By City with Ambee

Retrieves latest air quality data in Ambee by city.

## Endpoint

- **Method:** `GET`
- **Path:** `/latest/by-city`
- **Base URL:** `https://api.ambeedata.com`
- **Official documentation:** [Get Latest Air Quality By City](https://docs.ambeedata.com/apis/air-quality#latest-citywise)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `city` | query | `string` | yes |
