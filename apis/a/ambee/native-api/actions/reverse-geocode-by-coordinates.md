# Reverse Geocode By Coordinates with Ambee

Retrieves nearby location details in Ambee by coordinates.

## Endpoint

- **Method:** `GET`
- **Path:** `/geocode/reverse/by-lat-lng`
- **Base URL:** `https://api.ambeedata.com`
- **Official documentation:** [Reverse Geocode By Coordinates](https://docs.ambeedata.com/apis/location#reverse-geocoding-geospatial)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `lat` | query | `number` | yes |
| `lng` | query | `number` | yes |
