# Retrieve Wildfire Forecast By Place with Ambee

Retrieves wildfire risk forecasts in Ambee by place name.

## Endpoint

- **Method:** `GET`
- **Path:** `/fire/risk/by-place`
- **Base URL:** `https://api.ambeedata.com`
- **Official documentation:** [Retrieve Wildfire Forecast By Place](https://docs.ambeedata.com/apis/fire#forecast-placewise)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `place` | query | `string` | yes |
