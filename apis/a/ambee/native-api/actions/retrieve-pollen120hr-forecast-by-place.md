# Retrieve Pollen 120hr Forecast By Place with Ambee

Retrieves 120-hour pollen forecasts in Ambee by place name.

## Endpoint

- **Method:** `GET`
- **Path:** `/forecast/v2/pollen/120hr/by-place`
- **Base URL:** `https://api.ambeedata.com`
- **Official documentation:** [Retrieve Pollen 120hr Forecast By Place](https://docs.ambeedata.com/apis/pollen#forecast-placewise-120hr)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `place` | query | `string` | yes |
