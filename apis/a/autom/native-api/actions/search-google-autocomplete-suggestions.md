# Search Google Autocomplete Suggestions with Autom

Finds Google autocomplete suggestions in Autom.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/google/search/autocomplete`
- **Base URL:** `https://api.autom.dev`
- **Official documentation:** [Search Google Autocomplete Suggestions](https://docs.autom.dev/google-search-autocomplete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | The query to get autocomplete suggestions for. |
