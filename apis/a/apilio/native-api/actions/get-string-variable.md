# Get String Variable with Apilio

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/string_variables/{{uuid}}`
- **Base URL:** `https://api.apilio.com`
- **Official documentation:** [Get String Variable](https://documenter.getpostman.com/view/13480928/TzCHAVD2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The UUID of the string variable to retrieve. |
