# Evaluate Logicblock with Apilio

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/logicblocks/{{uuid}}/evaluate`
- **Base URL:** `https://api.apilio.com`
- **Official documentation:** [Evaluate Logicblock](https://documenter.getpostman.com/view/13480928/TzCHAVD2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The UUID of the logicblock to evaluate. |
