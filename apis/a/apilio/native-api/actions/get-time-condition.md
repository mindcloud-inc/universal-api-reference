# Get Time Condition with Apilio

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/timeconditions/{{uuid}}`
- **Base URL:** `https://api.apilio.com`
- **Official documentation:** [Get Time Condition](https://documenter.getpostman.com/view/13480928/TzCHAVD2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The UUID of the time condition to retrieve. |
