# Get Current User with ApptiveGrid

Retrieves the current user from ApptiveGrid.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/users/me`
- **Base URL:** `https://app.apptivegrid.de`
- **Official documentation:** [Get Current User](https://pub.dev/documentation/apptive_grid_core/latest/apptive_grid_core/ApptiveGridClient/getMe.html)
