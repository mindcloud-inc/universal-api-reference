# List Flows with ApptiveGrid

Retrieves flows from ApptiveGrid.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/users/:user_id/flows`
- **Base URL:** `https://app.apptivegrid.de`
- **Official documentation:** [List Flows](https://pub.dev/documentation/apptive_grid_core/latest/apptive_grid_core/ApptiveLinkType.html#flows)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The ApptiveGrid user id. |
