# Get Installation with Airzone Cloud

Retrieves a user's installation relation from Airzone Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/installations/{installationId}`
- **Base URL:** `https://m.airzonecloud.com/api/v1`
- **Official documentation:** [Get Installation](https://developers.airzonecloud.com/docs/web-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `installationId` | path | `string` | yes | The Airzone installation identifier. |
