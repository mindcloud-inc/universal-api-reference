# Get Installation Location with Airzone Cloud

Retrieves an installation location from Airzone Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/installations/location/{locationId}`
- **Base URL:** `https://m.airzonecloud.com/api/v1`
- **Official documentation:** [Get Installation Location](https://developers.airzonecloud.com/docs/web-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locationId` | path | `string` | yes | The Airzone location identifier. |
