# List Vendors and Customers with Asset Infinity

Retrieves vendors and customers from Asset Infinity.

## Endpoint

- **Method:** `POST`
- **Path:** `VendorCustomerList`
- **Base URL:** `https://api.assetinfinity.io/api/`
- **Official documentation:** [List Vendors and Customers](https://api.assetinfinity.io/index.html)
