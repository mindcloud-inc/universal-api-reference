# List Movement Type Statuses with Asset Infinity

Retrieves movement type statuses from Asset Infinity.

## Endpoint

- **Method:** `GET`
- **Path:** `MovementTypeStatusList`
- **Base URL:** `https://api.assetinfinity.io/api/`
- **Official documentation:** [List Movement Type Statuses](https://api.assetinfinity.io/index.html)
