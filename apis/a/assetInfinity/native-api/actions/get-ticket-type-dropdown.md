# Get Ticket Type Dropdown with Asset Infinity

Retrieves ticket type dropdown options from Asset Infinity.

## Endpoint

- **Method:** `POST`
- **Path:** `GetTicketTypeDropDown`
- **Base URL:** `https://api.assetinfinity.io/api/`
- **Official documentation:** [Get Ticket Type Dropdown](https://api.assetinfinity.io/index.html)
