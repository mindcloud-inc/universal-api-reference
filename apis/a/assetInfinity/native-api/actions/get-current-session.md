# Get Current Session with Asset Infinity

Retrieves current session details from Asset Infinity.

## Endpoint

- **Method:** `GET`
- **Path:** `auth`
- **Base URL:** `https://api.assetinfinity.io/api/`
- **Official documentation:** [Get Current Session](https://support.assetinfinity.com/portal/en/kb/articles/jwt-token-for-authorization-to-asset-infinity)
