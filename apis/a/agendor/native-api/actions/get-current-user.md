# Get Current User with Agendor

Retrieves the authenticated user from Agendor.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/me`
- **Base URL:** `https://api.agendor.com.br/v3`
- **Official documentation:** [Get Current User](https://api.agendor.com.br/docs/#operation/Get%20current%20user)
