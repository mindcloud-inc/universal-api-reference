# Create Person with Agendor

Creates a new person in Agendor.

## Endpoint

- **Method:** `POST`
- **Path:** `/people`
- **Base URL:** `https://api.agendor.com.br/v3`
- **Official documentation:** [Create Person](https://api.agendor.com.br/docs/#operation/Create%20person)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `person` | body | `object` | yes | Person payload matching Agendor's create person body. |
