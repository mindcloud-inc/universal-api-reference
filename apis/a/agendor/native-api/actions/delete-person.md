# Delete Person with Agendor

Deletes an existing person from Agendor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/people/:id`
- **Base URL:** `https://api.agendor.com.br/v3`
- **Official documentation:** [Delete Person](https://api.agendor.com.br/docs/#operation/Delete%20person)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the person to delete. |
