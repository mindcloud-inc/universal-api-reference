# Delete Organization with Agendor

Deletes an existing organization from Agendor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/:id`
- **Base URL:** `https://api.agendor.com.br/v3`
- **Official documentation:** [Delete Organization](https://api.agendor.com.br/docs/#operation/Delete%20organization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the organization to delete. |
