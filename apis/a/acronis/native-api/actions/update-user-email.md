# Update User Email with Acronis

Updates a user's email address in Acronis.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/2/users/{user_id}`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [Update User Email](https://developer.acronis.com/doc/outbound/apis/api-library/account/users/changing-email.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | User Id path parameter. |
