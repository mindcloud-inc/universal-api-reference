# List Resources with Acronis

Retrieves a list of resources from Acronis.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/resource_management/v4/resources`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [List Resources](https://developer.acronis.com/doc/outbound/apis/api-library/resource-policy/resources/fetching-resources.html)
