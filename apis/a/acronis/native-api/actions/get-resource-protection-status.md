# Get Resource Protection Status with Acronis

Retrieves protection statuses for resources from Acronis.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/resource_management/v4/resource_statuses`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [Get Resource Protection Status](https://developer.acronis.com/doc/outbound/apis/api-library/resource-policy/resources/fetching-protection-status-of-resources.html)
