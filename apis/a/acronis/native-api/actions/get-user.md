# Get User with Acronis

Retrieves a user account from Acronis.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2/users/{user_id}`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [Get User](https://developer.acronis.com/doc/outbound/apis/api-library/account/users/fetching-user-info.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | User Id path parameter. |
