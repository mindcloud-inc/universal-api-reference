# Apply Protection Plan To Resources with Acronis

Applies a protection plan to resources in Acronis.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/policy_management/v4/applications`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [Apply Protection Plan To Resources](https://developer.acronis.com/doc/outbound/apis/api-library/resource-policy/policies/applying-plan-to-resources.html)
