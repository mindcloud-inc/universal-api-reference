# Start Policy Execution with Acronis

Starts execution of a protection policy in Acronis.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/policy_management/v4/applications/run`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [Start Policy Execution](https://developer.acronis.com/doc/outbound/apis/api-library/resource-policy/policies/starting-policy.html)
