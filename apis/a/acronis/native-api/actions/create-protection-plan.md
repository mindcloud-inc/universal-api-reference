# Create Protection Plan with Acronis

Creates a new protection plan in Acronis.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/policy_management/v4/policies`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [Create Protection Plan](https://developer.acronis.com/doc/outbound/apis/api-library/resource-policy/policies/creating-protection-plan.html)
