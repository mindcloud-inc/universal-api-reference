# List Tasks with Acronis

Retrieves a list of tasks from Acronis.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/task_manager/v2/tasks`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [List Tasks](https://developer.acronis.com/doc/outbound/apis/api-library/tasks/tasks/fetching-tasks.html)
