# List Tenants with Acronis

Retrieves a list of tenants from Acronis.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2/tenants`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [List Tenants](https://developer.acronis.com/doc/outbound/apis/api-library/account/tenants/fetching-tenants.html)
