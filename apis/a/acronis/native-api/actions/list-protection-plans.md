# List Protection Plans with Acronis

Retrieves protection plans and policies from Acronis.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/policy_management/v4/policies`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [List Protection Plans](https://developer.acronis.com/doc/outbound/apis/api-library/resource-policy/policies/fetching-plans-policies.html)
