# List Platform Services with Acronis

Retrieves all platform services from Acronis.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2/applications`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [List Platform Services](https://developer.acronis.com/doc/outbound/apis/api-library/account/services/fetching-all-services.html)
