# Revoke Protection Plans From Resources with Acronis

Revokes protection plans from resources in Acronis.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/policy_management/v4/applications`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [Revoke Protection Plans From Resources](https://developer.acronis.com/doc/outbound/apis/api-library/resource-policy/policies/revoking-plan-from-resources.html)
