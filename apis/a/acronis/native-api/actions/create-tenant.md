# Create Tenant with Acronis

Creates a new tenant in Acronis.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/2/tenants`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [Create Tenant](https://developer.acronis.com/doc/outbound/apis/api-library/account/tenants/creating-tenant.html)
