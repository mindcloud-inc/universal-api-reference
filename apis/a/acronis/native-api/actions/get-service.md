# Get Service with Acronis

Retrieves a service from Acronis.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2/applications/{application_id}`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [Get Service](https://developer.acronis.com/doc/outbound/apis/api-library/account/services/fetching-service.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `application_id` | path | `string` | yes | Application Id path parameter. |
