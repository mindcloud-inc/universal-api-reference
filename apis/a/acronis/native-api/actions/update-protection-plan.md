# Update Protection Plan with Acronis

Updates an existing protection plan in Acronis.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/policy_management/v4/policies/{policy_id}`
- **Base URL:** `{dataCenterUrl}`
- **Official documentation:** [Update Protection Plan](https://developer.acronis.com/doc/outbound/apis/api-library/resource-policy/policies/updating-policy-or-plan.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `policy_id` | path | `string` | yes | Policy Id path parameter. |
