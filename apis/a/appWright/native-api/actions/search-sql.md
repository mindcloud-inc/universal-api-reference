# Search SQL with AppWright

Retrieves AppWright data with a SQL select query.

## Endpoint

- **Method:** `POST`
- **Path:** `awAPI/awAPI.asp`
- **Base URL:** `https://{clientId}.AppWright.com`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `SQL` | query | `string` | yes |
