# Get Transcript with AssemblyAI

Retrieves one transcript from your AssemblyAI account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/transcript/:transcript_id`
- **Base URL:** `https://api.assemblyai.com`
- **Official documentation:** [Get Transcript](https://www.assemblyai.com/docs/api-reference/transcripts/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transcript_id` | path | `string` | yes | The transcript ID to retrieve. |
