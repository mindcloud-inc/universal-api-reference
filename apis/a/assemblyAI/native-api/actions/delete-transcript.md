# Delete Transcript with AssemblyAI

Deletes one transcript from your AssemblyAI account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/transcript/:transcript_id`
- **Base URL:** `https://api.assemblyai.com`
- **Official documentation:** [Delete Transcript](https://www.assemblyai.com/docs/api-reference/transcripts/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transcript_id` | path | `string` | yes | The transcript ID to delete. |
