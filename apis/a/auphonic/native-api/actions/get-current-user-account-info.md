# Get Current User Account Info with Auphonic

Retrieves current user account info from Auphonic.

## Endpoint

- **Method:** `GET`
- **Path:** `/user.json`
- **Base URL:** `https://auphonic.com/api`
- **Official documentation:** [Get Current User Account Info](https://auphonic.com/help/api/query.html#information-about-a-user-account)
