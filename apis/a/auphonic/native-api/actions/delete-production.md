# Delete Production with Auphonic

Deletes an existing production from Auphonic.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/production/:uuid.json`
- **Base URL:** `https://auphonic.com/api`
- **Official documentation:** [Delete Production](https://auphonic.com/help/api/update.html#further-examples)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID of the production. |
