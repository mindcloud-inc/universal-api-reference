# Delete Preset with Auphonic

Deletes an existing preset from Auphonic.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/preset/:uuid.json`
- **Base URL:** `https://auphonic.com/api`
- **Official documentation:** [Delete Preset](https://auphonic.com/help/api/update.html#further-examples)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID of the preset. |
