# Get Production Status Codes with Auphonic

Retrieves production status codes from Auphonic.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/production_status.json`
- **Base URL:** `https://auphonic.com/api`
- **Official documentation:** [Get Production Status Codes](https://auphonic.com/help/api/query.html#query-production-status)
