# Get Production Status with Auphonic

Retrieves production status from Auphonic.

## Endpoint

- **Method:** `GET`
- **Path:** `/production/:uuid/status.json`
- **Base URL:** `https://auphonic.com/api`
- **Official documentation:** [Get Production Status](https://auphonic.com/help/api/query.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID of the production. |
