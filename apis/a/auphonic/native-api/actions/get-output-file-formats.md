# Get Output File Formats with Auphonic

Retrieves output file formats from Auphonic.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/output_files.json`
- **Base URL:** `https://auphonic.com/api`
- **Official documentation:** [Get Output File Formats](https://auphonic.com/help/api/details.html#query-output-formats)
