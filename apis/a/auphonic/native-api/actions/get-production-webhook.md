# Get Production Webhook with Auphonic

Retrieves a production webhook from Auphonic.

## Endpoint

- **Method:** `GET`
- **Path:** `/production/:uuid/webhook.json`
- **Base URL:** `https://auphonic.com/api`
- **Official documentation:** [Get Production Webhook](https://auphonic.com/help/api/webhook.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID of the production. |
