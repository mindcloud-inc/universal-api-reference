# Get Production with Auphonic

Retrieves a production from Auphonic.

## Endpoint

- **Method:** `GET`
- **Path:** `/production/:uuid.json`
- **Base URL:** `https://auphonic.com/api`
- **Official documentation:** [Get Production](https://auphonic.com/help/api/query.html#details-about-a-production)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID of the production. |
