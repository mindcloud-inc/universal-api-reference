# Get Preset with Auphonic

Retrieves a preset from Auphonic.

## Endpoint

- **Method:** `GET`
- **Path:** `/preset/:uuid.json`
- **Base URL:** `https://auphonic.com/api`
- **Official documentation:** [Get Preset](https://auphonic.com/help/api/query.html#details-about-a-preset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID of the preset. |
