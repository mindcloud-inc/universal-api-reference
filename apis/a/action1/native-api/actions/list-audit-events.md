# List Audit Events with Action1

Retrieves audit trail events from Action1.

## Endpoint

- **Method:** `GET`
- **Path:** `/audit/events`
- **Base URL:** `https://app.action1.com/api/3.0`
- **Official documentation:** [List Audit Events](https://app.action1.com/apidocs/#/Audit%20Trail/audit_events_get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
