# Check Endpoint Status with Action1

Retrieves endpoint addition status from Action1 for an organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/endpoints/status/:orgId`
- **Base URL:** `https://app.action1.com/api/3.0`
- **Official documentation:** [Check Endpoint Status](https://app.action1.com/apidocs/#/Endpoints/endpoints_status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgId` | path | `string` | yes | Provide an organization ID. |
