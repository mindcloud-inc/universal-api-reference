# Complete a live stream with api.video

Requests completion of a live stream in api.video.

## Endpoint

- **Method:** `PUT`
- **Path:** `/live-streams/:liveStreamId/complete`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Complete a live stream](https://docs.api.video/reference/api/Live-Streams#complete-a-live-stream)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `liveStreamId` | path | `string` | yes | The unique identifier for the live stream. |
