# Retrieve upload token with api.video

Retrieves an upload token from api.video.

## Endpoint

- **Method:** `GET`
- **Path:** `/upload-tokens/:uploadToken`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Retrieve upload token](https://docs.api.video/reference/api/Upload-Tokens#retrieve-upload-token)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uploadToken` | path | `string` | yes | The upload token identifier. |
