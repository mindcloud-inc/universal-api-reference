# Retrieve live stream with api.video

Retrieves a live stream from api.video.

## Endpoint

- **Method:** `GET`
- **Path:** `/live-streams/:liveStreamId`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Retrieve live stream](https://docs.api.video/reference/api/Live-Streams#retrieve-live-stream)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `liveStreamId` | path | `string` | yes | The unique identifier for the live stream. |
