# Create a video object with api.video

Creates a new video object in api.video.

## Endpoint

- **Method:** `POST`
- **Path:** `/videos`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Create a video object](https://docs.api.video/reference/api/Videos#create-a-video-object)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `description` | body | `string` | no | Optional description for the video object. |
| `tags` | body | `string` | no | Comma-separated video tags. |
| `title` | body | `string` | no | Optional title for the video object. |
