# Retrieve a video object with api.video

Retrieves a video object from api.video.

## Endpoint

- **Method:** `GET`
- **Path:** `/videos/:videoId`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Retrieve a video object](https://docs.api.video/reference/api/Videos#retrieve-a-video-object)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videoId` | path | `string` | yes | The unique identifier for the video. |
