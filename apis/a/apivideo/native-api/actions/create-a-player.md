# Create a player with api.video

Creates a new player theme in api.video.

## Endpoint

- **Method:** `POST`
- **Path:** `/players`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Create a player](https://docs.api.video/reference/api/Player-Themes#create-a-player)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Optional display name for the player theme. |
