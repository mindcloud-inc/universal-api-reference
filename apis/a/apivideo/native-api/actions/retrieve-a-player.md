# Retrieve a player with api.video

Retrieves a player theme from api.video.

## Endpoint

- **Method:** `GET`
- **Path:** `/players/:playerId`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Retrieve a player](https://docs.api.video/reference/api/Player-Themes#retrieve-a-player)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `playerId` | path | `string` | yes | The unique identifier for the player theme. |
