# Delete video summary with api.video

Deletes a video summary from api.video.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/summaries/:summaryId`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Delete video summary](https://docs.api.video/reference/api/Summaries#delete-video-summary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `summaryId` | path | `string` | yes | The unique identifier for the summary. |
