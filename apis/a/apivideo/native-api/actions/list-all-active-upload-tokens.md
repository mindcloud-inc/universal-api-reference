# List all active upload tokens with api.video

Retrieves active delegated upload tokens from api.video.

## Endpoint

- **Method:** `GET`
- **Path:** `/upload-tokens`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [List all active upload tokens](https://docs.api.video/reference/api/Upload-Tokens#list-all-active-upload-tokens)
