# Create live stream with api.video

Creates a new live stream in api.video.

## Endpoint

- **Method:** `POST`
- **Path:** `/live-streams`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Create live stream](https://docs.api.video/reference/api/Live-Streams#create-live-stream)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Optional display name for the live stream. |
