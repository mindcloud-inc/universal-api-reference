# Get summary details with api.video

Retrieves summary source details from api.video.

## Endpoint

- **Method:** `GET`
- **Path:** `/summaries/:summaryId/source`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Get summary details](https://docs.api.video/reference/api/Summaries#get-summary-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `summaryId` | path | `string` | yes | The unique identifier for the summary. |
