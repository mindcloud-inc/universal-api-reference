# Delete an upload token with api.video

Deletes an upload token from api.video.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/upload-tokens/:uploadToken`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Delete an upload token](https://docs.api.video/reference/api/Upload-Tokens#delete-an-upload-token)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uploadToken` | path | `string` | yes | The upload token identifier. |
