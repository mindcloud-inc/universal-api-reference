# Delete a player with api.video

Deletes a player theme from api.video.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/players/:playerId`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Delete a player](https://docs.api.video/reference/api/Player-Themes#delete-a-player)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `playerId` | path | `string` | yes | The unique identifier for the player theme. |
