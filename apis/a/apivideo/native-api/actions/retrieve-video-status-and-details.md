# Retrieve video status and details with api.video

Retrieves video status and details from api.video.

## Endpoint

- **Method:** `GET`
- **Path:** `/videos/:videoId/status`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Retrieve video status and details](https://docs.api.video/reference/api/Videos#retrieve-video-status-and-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videoId` | path | `string` | yes | The unique identifier for the video. |
