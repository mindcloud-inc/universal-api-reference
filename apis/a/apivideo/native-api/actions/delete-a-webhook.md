# Delete a Webhook with api.video

Deletes an existing webhook from api.video.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Delete a Webhook](https://docs.api.video/reference/api/Webhooks#delete-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The unique identifier for the webhook. |
