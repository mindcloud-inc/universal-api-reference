# Delete a live stream with api.video

Deletes a live stream from api.video.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/live-streams/:liveStreamId`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Delete a live stream](https://docs.api.video/reference/api/Live-Streams#delete-a-live-stream)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `liveStreamId` | path | `string` | yes | The unique identifier for the live stream. |
