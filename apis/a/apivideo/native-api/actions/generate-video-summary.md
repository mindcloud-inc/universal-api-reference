# Generate video summary with api.video

Creates a new video summary in api.video.

## Endpoint

- **Method:** `POST`
- **Path:** `/summaries`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Generate video summary](https://docs.api.video/reference/api/Summaries#generate-video-summary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videoId` | body | `string` | yes | The unique identifier for the video to summarize. |
