# Retrieve metrics over time with api.video

Retrieves analytics metrics over time from api.video.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/timeseries/:metric`
- **Base URL:** `https://ws.api.video`
- **Official documentation:** [Retrieve metrics over time](https://docs.api.video/reference/api/Analytics#retrieve-metrics-over-time)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `metric` | path | `string` | yes | The metric to retrieve over time. |
