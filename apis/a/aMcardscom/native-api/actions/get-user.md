# Get User with AMcards.com

Retrieves a specific user from AMcards.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:userId/`
- **Base URL:** `https://amcards.com/.api/v1`
- **Official documentation:** [Get User](https://staging.amcards.com/docs/developers-only/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | no | AMcards user identifier from the `/user/` resource URI. |
