# Search Contacts with AMcards.com

Finds contacts in AMcards.com by search query.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/search/`
- **Base URL:** `https://amcards.com/.api/v1`
- **Official documentation:** [Search Contacts](https://staging.amcards.com/docs/developers-only/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Text to search across contacts. |
