# Get Campaign with AMcards.com

Retrieves a specific campaign from AMcards.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/:campaignId/`
- **Base URL:** `https://amcards.com/.api/v1`
- **Official documentation:** [Get Campaign](https://staging.amcards.com/docs/developers-only/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | no | AMcards campaign identifier from the `/campaign/` resource URI. |
