# List Mailings with AMcards.com

Retrieves mailings from your AMcards.com account.

## Endpoint

- **Method:** `GET`
- **Path:** `/mailing/`
- **Base URL:** `https://amcards.com/.api/v1`
- **Official documentation:** [List Mailings](https://staging.amcards.com/docs/developers-only/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
