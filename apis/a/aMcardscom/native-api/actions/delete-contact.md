# Delete Contact with AMcards.com

Deletes an existing contact from AMcards.com.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contact/:contactId/`
- **Base URL:** `https://amcards.com/.api/v1`
- **Official documentation:** [Delete Contact](https://staging.amcards.com/docs/developers-only/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | no | AMcards contact identifier from the `/contact/` resource URI. |
