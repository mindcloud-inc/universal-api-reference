# Get Card Template Category with AMcards.com

Retrieves a specific card template category from AMcards.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/category/:categoryId/`
- **Base URL:** `https://amcards.com/.api/v1`
- **Official documentation:** [Get Card Template Category](https://staging.amcards.com/docs/developers-only/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `categoryId` | path | `number` | no | AMcards category identifier from the `/category/` resource URI. |
