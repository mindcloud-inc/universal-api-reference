# Delete Group with AMcards.com

Deletes an existing contact group from AMcards.com.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/group/:groupId/`
- **Base URL:** `https://amcards.com/.api/v1`
- **Official documentation:** [Delete Group](https://staging.amcards.com/docs/developers-only/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `number` | no | AMcards group identifier from the `/group/` resource URI. |
