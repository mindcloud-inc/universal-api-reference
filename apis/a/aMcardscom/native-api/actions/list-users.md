# List Users with AMcards.com

Retrieves authorized user records from AMcards.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/`
- **Base URL:** `https://amcards.com/.api/v1`
- **Official documentation:** [List Users](https://staging.amcards.com/docs/developers-only/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
