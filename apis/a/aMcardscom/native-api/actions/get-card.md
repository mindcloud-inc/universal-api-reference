# Get Card with AMcards.com

Retrieves a specific card from AMcards.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/card/:cardId/`
- **Base URL:** `https://amcards.com/.api/v1`
- **Official documentation:** [Get Card](https://staging.amcards.com/docs/developers-only/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `number` | no | AMcards card identifier from the `/card/` resource URI. |
