# Get Mailing with AMcards.com

Retrieves a specific mailing from AMcards.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/mailing/:mailingId/`
- **Base URL:** `https://amcards.com/.api/v1`
- **Official documentation:** [Get Mailing](https://staging.amcards.com/docs/developers-only/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mailingId` | path | `number` | no | AMcards mailing identifier from the `/mailing/` resource URI. |
