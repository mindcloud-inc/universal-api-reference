# List Campaigns with AMcards.com

Retrieves campaign records from your AMcards.com account.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/`
- **Base URL:** `https://amcards.com/.api/v1`
- **Official documentation:** [List Campaigns](https://staging.amcards.com/docs/developers-only/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
