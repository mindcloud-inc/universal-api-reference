# List Expense Payment Methods Lookup with Avaza

Retrieves expense payment methods lookup entries from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/ExpensePaymentMethod/Lookup`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [List Expense Payment Methods Lookup](https://api.avaza.com/#!/ExpensePaymentMethod/ExpensePaymentMethodLookup)
