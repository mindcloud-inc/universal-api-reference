# List Bill Payments with Avaza

Retrieves bill payments from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/BillPayment`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [List Bill Payments](https://api.avaza.com/#!/BillPayment/BillPayment_Get)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `UpdatedAfter` | query | `date` | no |
