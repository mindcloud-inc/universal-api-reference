# Get Timesheet with Avaza

Retrieves timesheet from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Timesheet/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Timesheet](https://api.avaza.com/#!/Timesheet/Timesheet_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Timesheet ID number |
