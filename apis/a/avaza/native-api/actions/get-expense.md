# Get Expense with Avaza

Retrieves expense from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Expense/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Expense](https://api.avaza.com/#!/Expense/Expense_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Expense ID number |
