# Get Project with Avaza

Retrieves project from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Project/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Project](https://api.avaza.com/#!/Project/Project_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Project ID number |
