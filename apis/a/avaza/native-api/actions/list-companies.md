# List Companies with Avaza

Retrieves companies from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Company`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [List Companies](https://api.avaza.com/#!/Company/Company_Get)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `UpdatedAfter` | query | `date` | no |
