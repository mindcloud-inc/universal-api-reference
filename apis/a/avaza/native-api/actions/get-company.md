# Get Company with Avaza

Retrieves company from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Company/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Company](https://api.avaza.com/#!/Company/Company_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Company ID Number |
