# Get Bill Payment with Avaza

Retrieves bill payment from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/BillPayment/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Bill Payment](https://api.avaza.com/#!/BillPayment/BillPayment_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Invoice Transaction ID Number |
