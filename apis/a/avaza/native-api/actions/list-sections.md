# List Sections with Avaza

Retrieves sections from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Section`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [List Sections](https://api.avaza.com/#!/Section/Section_Get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectID` | query | `number` | yes | Get sections for Project with ProjectID |
