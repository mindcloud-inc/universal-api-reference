# List Companies Lookup with Avaza

Retrieves companies lookup entries from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Company/Lookup`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [List Companies Lookup](https://api.avaza.com/#!/Company/CompanyLookup)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search string to match against Company title |
