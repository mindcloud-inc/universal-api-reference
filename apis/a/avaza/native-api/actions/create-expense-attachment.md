# Create Expense Attachment with Avaza

Uploads an expense attachment to Avaza.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/Expense/Attachment`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Create Expense Attachment](https://api.avaza.com/#!/Expense/ExpenseAttachment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `File` | body | `file` | yes | Upload software package |
