# Get Task with Avaza

Retrieves task from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Task/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Task](https://api.avaza.com/#!/Task/Task_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Task ID number |
