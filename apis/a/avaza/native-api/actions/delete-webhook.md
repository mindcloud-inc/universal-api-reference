# Delete Webhook with Avaza

Deletes an existing webhook from Avaza.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/Webhook/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Delete Webhook](https://api.avaza.com/#!/Webhook/Webhook_Delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Subscription id to be deleted |
