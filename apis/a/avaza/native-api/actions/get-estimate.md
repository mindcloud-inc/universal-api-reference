# Get Estimate with Avaza

Retrieves estimate from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Estimate/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Estimate](https://api.avaza.com/#!/Estimate/Estimate_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Estimate Estimate ID number |
