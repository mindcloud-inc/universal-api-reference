# Get Inventory with Avaza

Retrieves inventory from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Inventory/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Inventory](https://api.avaza.com/#!/Inventory/Inventory_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | InventoryItem ID number |
