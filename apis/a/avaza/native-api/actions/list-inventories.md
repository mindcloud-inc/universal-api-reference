# List Inventories with Avaza

Retrieves inventory items from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Inventory`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [List Inventories](https://api.avaza.com/#!/Inventory/Inventory_Get)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `UpdatedAfter` | query | `date` | no |
