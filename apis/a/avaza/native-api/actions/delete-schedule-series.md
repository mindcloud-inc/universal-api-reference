# Delete Schedule Series with Avaza

Deletes an existing schedule series from Avaza.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/ScheduleSeries/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Delete Schedule Series](https://api.avaza.com/#!/ScheduleSeries/ScheduleSeries_Delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the Schedule Series to delete |
