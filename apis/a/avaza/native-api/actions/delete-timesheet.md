# Delete Timesheet with Avaza

Deletes an existing timesheet from Avaza.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/Timesheet/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Delete Timesheet](https://api.avaza.com/#!/Timesheet/Timesheet_Delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The id of the timesheet entry to be deleted |
