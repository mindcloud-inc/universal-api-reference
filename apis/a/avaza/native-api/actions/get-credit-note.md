# Get Credit Note with Avaza

Retrieves credit note from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/CreditNote/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Credit Note](https://api.avaza.com/#!/CreditNote/CreditNote_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Credit Note ID Number |
