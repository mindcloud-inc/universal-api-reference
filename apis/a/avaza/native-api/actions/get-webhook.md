# Get Webhook with Avaza

Retrieves webhook from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Webhook/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Webhook](https://api.avaza.com/#!/Webhook/Webhook_GetByID)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
