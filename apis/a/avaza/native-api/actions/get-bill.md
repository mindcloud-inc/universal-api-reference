# Get Bill with Avaza

Retrieves bill from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Bill/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Bill](https://api.avaza.com/#!/Bill/Bill_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Bill Transaction ID number |
