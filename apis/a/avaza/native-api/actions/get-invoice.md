# Get Invoice with Avaza

Retrieves invoice from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Invoice/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Invoice](https://api.avaza.com/#!/Invoice/Invoice_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Invoice Transaction ID number |
