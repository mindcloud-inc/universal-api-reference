# Get Payment with Avaza

Retrieves payment from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Payment/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Payment](https://api.avaza.com/#!/Payment/Payment_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Invoice Transaction ID Number |
