# Get Contact with Avaza

Retrieves contact from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Contact/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Contact](https://api.avaza.com/#!/Contact/Contact_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Contact ID number |
