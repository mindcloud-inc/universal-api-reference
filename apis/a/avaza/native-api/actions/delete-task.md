# Delete Task with Avaza

Deletes an existing task from Avaza.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/Task`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Delete Task](https://api.avaza.com/#!/Task/Task_Delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `TaskID` | query | `number` | yes |
