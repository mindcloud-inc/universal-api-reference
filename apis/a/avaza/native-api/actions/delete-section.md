# Delete Section with Avaza

Deletes an existing section from Avaza.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/Section`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Delete Section](https://api.avaza.com/#!/Section/Section_Delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `SectionID` | query | `number` | yes |
