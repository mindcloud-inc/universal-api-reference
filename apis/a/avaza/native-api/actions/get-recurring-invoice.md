# Get Recurring Invoice with Avaza

Retrieves recurring invoice from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/RecurringInvoice/:id`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [Get Recurring Invoice](https://api.avaza.com/#!/RecurringInvoice/RecurringInvoice_GetByID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Recurring Invoice Profile ID number |
