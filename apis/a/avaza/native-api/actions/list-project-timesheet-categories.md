# List Project Timesheet Categories with Avaza

Retrieves project timesheet categories from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/ProjectTimesheetCategory`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [List Project Timesheet Categories](https://api.avaza.com/#!/ProjectTimesheetCategory/ProjectTimesheetCategory_Get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectID` | query | `number` | no | Get categories filtered by ProjectID |
