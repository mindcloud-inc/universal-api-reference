# List Credit Notes with Avaza

Retrieves credit notes from Avaza.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/CreditNote`
- **Base URL:** `https://api.avaza.com`
- **Official documentation:** [List Credit Notes](https://api.avaza.com/#!/CreditNote/CreditNote_Get)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `UpdatedAfter` | query | `date` | no |
