# List Databases For Team with AnyDB

Retrieves databases for a team in AnyDB.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/integrations/ext/listdbsforteam`
- **Base URL:** `https://app.anydb.com`
- **Official documentation:** [List Databases For Team](https://www.anydb.com/openapi/spec.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamid` | query | `string` | yes | The AnyDB team ID. |
