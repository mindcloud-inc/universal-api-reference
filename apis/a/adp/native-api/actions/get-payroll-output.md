# Get Payroll Output with ADP

## Endpoint

- **Method:** `GET`
- **Path:** `payroll/v2/payroll-output/:outputId`
- **Base URL:** `https://api.adp.com/`
- **Official documentation:** [Get Payroll Output](https://marketplace-cdn.adp.com/dev-portal/pdf/protected/Payroll_Output_API_Guide_for_RUN_Powered_by_ADP)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `outputId` | path | `string` | yes |
