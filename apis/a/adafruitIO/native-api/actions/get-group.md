# Get Group with Adafruit IO

Retrieves a group from Adafruit IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/{username}/groups/:group_key`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Get Group](https://io.adafruit.com/api/docs/#get-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_key` | path | `string` | yes |
