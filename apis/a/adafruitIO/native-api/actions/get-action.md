# Get Action with Adafruit IO

Retrieves an action from Adafruit IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/{username}/actions/:id`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Get Action](https://io.adafruit.com/api/docs/#return-action)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
