# Get Token with Adafruit IO

Retrieves an access token from Adafruit IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/{username}/tokens/:id`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Get Token](https://io.adafruit.com/api/docs/#returns-token)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
