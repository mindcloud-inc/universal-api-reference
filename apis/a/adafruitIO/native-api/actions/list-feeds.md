# List Feeds with Adafruit IO

Retrieves feeds from Adafruit IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/{username}/feeds`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [List Feeds](https://io.adafruit.com/api/docs/#all-feeds)

## Capabilities

This operation supports [pagination](../README.md#pagination).
