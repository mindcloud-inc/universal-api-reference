# Create Token with Adafruit IO

Creates an access token in Adafruit IO.

## Endpoint

- **Method:** `POST`
- **Path:** `/{username}/tokens`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Create Token](https://io.adafruit.com/api/docs/#create-token)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `token` | body | `string` | yes |
