# Delete Token with Adafruit IO

Deletes an access token from Adafruit IO.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/{username}/tokens/:id`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Delete Token](https://io.adafruit.com/api/docs/#delete-token)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
