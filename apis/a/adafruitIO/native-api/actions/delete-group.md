# Delete Group with Adafruit IO

Deletes a group from Adafruit IO.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/{username}/groups/:group_key`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Delete Group](https://io.adafruit.com/api/docs/#delete-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_key` | path | `string` | yes |
