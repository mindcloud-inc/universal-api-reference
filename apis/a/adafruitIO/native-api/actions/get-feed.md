# Get Feed with Adafruit IO

Retrieves a feed from Adafruit IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/{username}/feeds/:feed_key`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Get Feed](https://io.adafruit.com/api/docs/#get-feed)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `feed_key` | path | `string` | yes |
