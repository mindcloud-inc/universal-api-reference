# Delete Action with Adafruit IO

Deletes an action from Adafruit IO.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/{username}/actions/:id`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Delete Action](https://io.adafruit.com/api/docs/#delete-action)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
