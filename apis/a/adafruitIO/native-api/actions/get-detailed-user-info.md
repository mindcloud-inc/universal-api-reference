# Get Detailed User Info with Adafruit IO

Retrieves detailed user throttle info from Adafruit IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/{username}/throttle`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Get Detailed User Info](https://io.adafruit.com/api/docs/#get-detailed-user-info)
