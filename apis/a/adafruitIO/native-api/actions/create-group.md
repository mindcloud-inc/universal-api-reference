# Create Group with Adafruit IO

Creates a new group in Adafruit IO.

## Endpoint

- **Method:** `POST`
- **Path:** `/{username}/groups`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Create Group](https://io.adafruit.com/api/docs/#create-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group` | body | `object` | yes |
