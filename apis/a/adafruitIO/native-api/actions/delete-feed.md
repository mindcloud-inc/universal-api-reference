# Delete Feed with Adafruit IO

Deletes a feed from Adafruit IO.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/{username}/feeds/:feed_key`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Delete Feed](https://io.adafruit.com/api/docs/#delete-feed)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `feed_key` | path | `string` | yes |
