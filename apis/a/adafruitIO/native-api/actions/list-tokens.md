# List Tokens with Adafruit IO

Retrieves access tokens from Adafruit IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/{username}/tokens`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [List Tokens](https://io.adafruit.com/api/docs/#get-all-tokens)

## Capabilities

This operation supports [pagination](../README.md#pagination).
