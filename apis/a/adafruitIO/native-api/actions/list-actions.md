# List Actions with Adafruit IO

Retrieves actions from Adafruit IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/{username}/actions`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [List Actions](https://io.adafruit.com/api/docs/#get-all-actions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
