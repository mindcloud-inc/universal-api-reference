# Create Action with Adafruit IO

Creates a new action in Adafruit IO.

## Endpoint

- **Method:** `POST`
- **Path:** `/{username}/actions`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Create Action](https://io.adafruit.com/api/docs/#create-action)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `trigger` | body | `object` | yes |
