# Create Feed with Adafruit IO

Creates a new feed in Adafruit IO.

## Endpoint

- **Method:** `POST`
- **Path:** `/{username}/feeds`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [Create Feed](https://io.adafruit.com/api/docs/#create-feed)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `feed` | body | `object` | yes |
