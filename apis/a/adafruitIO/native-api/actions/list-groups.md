# List Groups with Adafruit IO

Retrieves groups from Adafruit IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/{username}/groups`
- **Base URL:** `https://io.adafruit.com/api/v2`
- **Official documentation:** [List Groups](https://io.adafruit.com/api/docs/#get-all-groups)

## Capabilities

This operation supports [pagination](../README.md#pagination).
