# List webhook logs with AiWifi

Retrieves webhook delivery logs from AiWifi.

## Endpoint

- **Method:** `GET`
- **Path:** `/brands/{{brandId}}/webhook-logs`
- **Base URL:** `https://api.aiwifi.io/api/v1`
- **Official documentation:** [List webhook logs](https://help.aiwifi.io/en/category/webhook/article/logs-validation-and-testing-of-webhooks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
