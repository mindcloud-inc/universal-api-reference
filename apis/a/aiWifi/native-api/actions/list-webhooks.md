# List webhooks with AiWifi

Retrieves webhook configurations from AiWifi.

## Endpoint

- **Method:** `GET`
- **Path:** `/brands/{{brandId}}/webhook-configs`
- **Base URL:** `https://api.aiwifi.io/api/v1`
- **Official documentation:** [List webhooks](https://help.aiwifi.io/en/category/webhook/article/webhook-setup-and-configuration)
