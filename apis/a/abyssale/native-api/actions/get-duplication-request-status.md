# Get Duplication Request Status with Abyssale

Retrieves a template duplication request status from Abyssale.

## Endpoint

- **Method:** `GET`
- **Path:** `/design-duplication-requests/:duplicateRequestId`
- **Base URL:** `https://api.abyssale.com`
- **Official documentation:** [Get Duplication Request Status](https://developers.abyssale.com/rest-api/workspace-templates)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `duplicateRequestId` | path | `string` | yes |
