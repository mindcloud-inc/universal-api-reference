# Get Design Details with Abyssale

Retrieves design details from Abyssale.

## Endpoint

- **Method:** `GET`
- **Path:** `/designs/:designId`
- **Base URL:** `https://api.abyssale.com`
- **Official documentation:** [Get Design Details](https://developers.abyssale.com/rest-api/designs/design-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `designId` | path | `string` | yes | Unique identifier (UUID) of the design |
