# Create Dynamic Image URL with Abyssale

Creates a dynamic image URL in Abyssale.

## Endpoint

- **Method:** `POST`
- **Path:** `/designs/:designId/dynamic-image-url`
- **Base URL:** `https://api.abyssale.com`
- **Official documentation:** [Create Dynamic Image URL](https://developers.abyssale.com/dynamic-images/create-a-dynamic-image-by-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `designId` | path | `string` | yes | Design ID associated with this dynamic image |
