# Create Project with Abyssale

Creates a new project in Abyssale.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://api.abyssale.com`
- **Official documentation:** [Create Project](https://developers.abyssale.com/rest-api/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the project |
