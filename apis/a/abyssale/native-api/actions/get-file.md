# Get File with Abyssale

Retrieves a generated file from Abyssale.

## Endpoint

- **Method:** `GET`
- **Path:** `/banners/:bannerId`
- **Base URL:** `https://api.abyssale.com`
- **Official documentation:** [Get File](https://api-reference.abyssale.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `bannerId` | path | `string` | yes |
