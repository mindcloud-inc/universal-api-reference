# List Designs By Type with Abyssale

Retrieves designs from Abyssale by type.

## Endpoint

- **Method:** `GET`
- **Path:** `/designs`
- **Base URL:** `https://api.abyssale.com`
- **Official documentation:** [List Designs By Type](https://developers.abyssale.com/rest-api/designs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | query | `string` | yes | Filter designs by type |
