# Update Workspace with Aspera on Cloud

Updates a workspace in Aspera on Cloud.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/workspaces/{id}`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [Update Workspace](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#update_workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the workspace. |
