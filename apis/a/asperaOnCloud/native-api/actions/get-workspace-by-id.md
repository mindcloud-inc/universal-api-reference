# Get Workspace with Aspera on Cloud

Retrieves a workspace from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/workspaces/{id}`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [Get Workspace](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_workspace_by_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the workspace. |
