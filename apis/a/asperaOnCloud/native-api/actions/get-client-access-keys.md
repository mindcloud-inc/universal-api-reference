# List Client Access Keys with Aspera on Cloud

Retrieves client access keys from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/client_access_keys`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [List Client Access Keys](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_client_access_keys)
