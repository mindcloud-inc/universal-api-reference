# Create User with Aspera on Cloud

Creates a new user in Aspera on Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/users`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [Create User](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#add_user)
