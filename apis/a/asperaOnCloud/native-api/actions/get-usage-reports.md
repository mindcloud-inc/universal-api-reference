# List Usage Reports with Aspera on Cloud

Retrieves usage reports from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/usage_reports`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [List Usage Reports](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_usage_reports)
