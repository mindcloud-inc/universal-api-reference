# List Nodes with Aspera on Cloud

Retrieves nodes from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/nodes`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [List Nodes](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_nodes)
