# Create Workspace with Aspera on Cloud

Creates a new workspace in Aspera on Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/workspaces`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [Create Workspace](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#add_workspace)
