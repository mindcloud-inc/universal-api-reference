# Create Shared Inbox with Aspera on Cloud

Creates a new shared inbox in Aspera on Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/dropboxes`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [Create Shared Inbox](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#add_dropbox)
