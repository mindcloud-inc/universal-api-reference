# Get Shared Inbox with Aspera on Cloud

Retrieves a shared inbox from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/dropboxes/{id}`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [Get Shared Inbox](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_dropbox_by_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the shared inbox. |
