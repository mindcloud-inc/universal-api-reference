# Update Package with Aspera on Cloud

Updates a package in Aspera on Cloud.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/packages/{id}`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [Update Package](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#update_package)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the package. |
