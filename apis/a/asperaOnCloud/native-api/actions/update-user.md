# Update User with Aspera on Cloud

Updates a user in Aspera on Cloud.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/users/{id}`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [Update User](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#update_user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the user. |
