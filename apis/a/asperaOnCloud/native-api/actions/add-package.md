# Create Package with Aspera on Cloud

Creates a new package in Aspera on Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/packages`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [Create Package](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#add_package)
