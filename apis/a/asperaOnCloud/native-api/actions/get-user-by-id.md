# Get User with Aspera on Cloud

Retrieves a user from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users/{id}`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [Get User](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_user_by_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the user. |
