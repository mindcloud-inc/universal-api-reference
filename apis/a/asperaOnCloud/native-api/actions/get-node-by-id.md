# Get Node with Aspera on Cloud

Retrieves a node from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/nodes/{id}`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [Get Node](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_node_by_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the node. |
