# List Shared Inboxes with Aspera on Cloud

Retrieves shared inboxes from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/dropboxes`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [List Shared Inboxes](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_dropboxes)
