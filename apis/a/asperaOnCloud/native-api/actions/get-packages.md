# List Packages with Aspera on Cloud

Retrieves packages from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/packages`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [List Packages](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_packages)
