# List Users with Aspera on Cloud

Retrieves users from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [List Users](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_users)
