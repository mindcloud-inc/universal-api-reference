# Get Package with Aspera on Cloud

Retrieves a package from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/packages/{id}`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [Get Package](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_package_by_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the package. |
