# List Workspaces with Aspera on Cloud

Retrieves workspaces from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/workspaces`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [List Workspaces](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_workspaces)
