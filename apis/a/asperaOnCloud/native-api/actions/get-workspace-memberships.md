# List Workspace Members with Aspera on Cloud

Retrieves workspace members from Aspera on Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/workspace_memberships`
- **Base URL:** `https://api.ibmaspera.com/api`
- **Official documentation:** [List Workspace Members](https://developer.ibm.com/apis/catalog/aspera--aspera-on-cloud-api/api/API--aspera--files-api#get_workspace_memberships)
