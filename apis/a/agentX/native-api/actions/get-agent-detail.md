# Get Agent Detail with AgentX

Retrieves an agent's details from AgentX.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:id`
- **Base URL:** `https://api.agentx.so/api/v1/access`
- **Official documentation:** [Get Agent Detail](https://docs.agentx.so/reference/get_api-v1-access-agents-id-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Agent Id |
