# Reset Conversation Context with AgentX

Resets conversation context in AgentX.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/conversations/:id`
- **Base URL:** `https://api.agentx.so/api/v1/access`
- **Official documentation:** [Reset Conversation Context](https://docs.agentx.so/reference/delete_api-v1-access-conversations-id-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Conversation Id |
