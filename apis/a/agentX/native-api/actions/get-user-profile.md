# Get User Profile with AgentX

Retrieves the current user profile from AgentX.

## Endpoint

- **Method:** `GET`
- **Path:** `/getProfile`
- **Base URL:** `https://api.agentx.so/api/v1/access`
- **Official documentation:** [Get User Profile](https://docs.agentx.so/reference/get_api-v1-access-getprofile-1)
