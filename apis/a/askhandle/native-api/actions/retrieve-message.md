# Retrieve Message with AskHandle

Retrieves one AskHandle message by UUID.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/:uuid/`
- **Base URL:** `https://dashboard.askhandle.com/api/v1`
- **Official documentation:** [Retrieve Message](https://dashboard.askhandle.com/api/v1/docs/api_reference.html#message)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The message UUID. |
