# List Rooms with AskHandle

Retrieves room records from your AskHandle account.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/`
- **Base URL:** `https://dashboard.askhandle.com/api/v1`
- **Official documentation:** [List Rooms](https://dashboard.askhandle.com/api/v1/docs/api_reference.html#room)

## Capabilities

This operation supports [pagination](../README.md#pagination).
