# List Messages with AskHandle

Retrieves message records from your AskHandle account.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/`
- **Base URL:** `https://dashboard.askhandle.com/api/v1`
- **Official documentation:** [List Messages](https://dashboard.askhandle.com/api/v1/docs/api_reference.html#message)

## Capabilities

This operation supports [pagination](../README.md#pagination).
