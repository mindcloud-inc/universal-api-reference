# List Keyword Notifications with AskHandle

Retrieves keyword notifications from your AskHandle account.

## Endpoint

- **Method:** `GET`
- **Path:** `/keyword_notifications/`
- **Base URL:** `https://dashboard.askhandle.com/api/v1`
- **Official documentation:** [List Keyword Notifications](https://dashboard.askhandle.com/api/v1/docs/api_reference.html#keyword-notification)

## Capabilities

This operation supports [pagination](../README.md#pagination).
