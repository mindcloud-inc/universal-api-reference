# Retrieve Room with AskHandle

Retrieves one AskHandle room by label.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:label/`
- **Base URL:** `https://dashboard.askhandle.com/api/v1`
- **Official documentation:** [Retrieve Room](https://dashboard.askhandle.com/api/v1/docs/api_reference.html#room)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `label` | path | `string` | no | The room label. |
