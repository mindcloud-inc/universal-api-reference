# List Webhooks with AskHandle

Retrieves webhook records from your AskHandle account.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/`
- **Base URL:** `https://dashboard.askhandle.com/api/v1`
- **Official documentation:** [List Webhooks](https://dashboard.askhandle.com/api/v1/docs/api_reference.html#webhook)

## Capabilities

This operation supports [pagination](../README.md#pagination).
