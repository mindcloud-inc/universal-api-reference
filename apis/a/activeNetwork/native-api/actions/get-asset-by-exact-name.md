# Get Asset By Exact Name with Active Network

Retrieves an asset by exact name in Active Network.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/search`
- **Base URL:** `http://api.amp.active.com`
- **Official documentation:** [Get Asset By Exact Name](https://developer.active.com/docs/read/v2_Activity_API_Search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `asset.assetName` | query | `string` | yes | Exact ACTIVE asset name to retrieve. |
