# Get Window Info with Airtop

Retrieves browser window details from Airtop.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/:sessionId/windows/:windowId`
- **Base URL:** `https://api.airtop.ai/api/v1`
- **Official documentation:** [Get Window Info](https://docs.airtop.ai/api-reference/airtop-api/windows/get-window-info)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sessionId` | path | `string` | yes |
| `windowId` | path | `string` | yes |
