# Terminate Session with Airtop

Terminates an existing session in Airtop.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sessions/:sessionId`
- **Base URL:** `https://api.airtop.ai/api/v1`
- **Official documentation:** [Terminate Session](https://docs.airtop.ai/api-reference/airtop-api/sessions/terminate)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sessionId` | path | `string` | yes |
