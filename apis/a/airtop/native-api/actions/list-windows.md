# List Windows with Airtop

Retrieves browser windows from an Airtop session.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/:sessionId/windows`
- **Base URL:** `https://api.airtop.ai/api/v1`
- **Official documentation:** [List Windows](https://docs.airtop.ai/api-reference/airtop-api/windows/list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sessionId` | path | `string` | yes |
