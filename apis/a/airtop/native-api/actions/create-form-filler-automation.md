# Create Form Filler Automation with Airtop

Creates a form-filler automation synchronously in Airtop.

## Endpoint

- **Method:** `POST`
- **Path:** `/sessions/:sessionId/windows/:windowId/create-form-filler`
- **Base URL:** `https://api.airtop.ai/api/v1`
- **Official documentation:** [Create Form Filler Automation](https://docs.airtop.ai/api-reference/airtop-api/windows/create-form-filler)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sessionId` | path | `string` | yes |
| `windowId` | path | `string` | yes |
