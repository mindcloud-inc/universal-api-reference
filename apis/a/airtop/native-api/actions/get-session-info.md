# Get Session Info with Airtop

Retrieves session details from Airtop by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/:sessionId`
- **Base URL:** `https://api.airtop.ai/api/v1`
- **Official documentation:** [Get Session Info](https://docs.airtop.ai/api-reference/airtop-api/sessions/get-info)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sessionId` | path | `string` | yes |
