# List Labels with ActiveCollab

Retrieves predefined labels from your ActiveCollab workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels`
- **Base URL:** `https://app.activecollab.com/:instanceId/api/v1`
- **Official documentation:** [List Labels](https://developers.activecollab.com/api-documentation/v1/utilities/labels.html)
