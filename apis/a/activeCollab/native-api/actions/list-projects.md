# List Projects with ActiveCollab

Retrieves all projects from your ActiveCollab workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://app.activecollab.com/:instanceId/api/v1`
- **Official documentation:** [List Projects](https://developers.activecollab.com/api-documentation/v1/projects/projects.html)
