# Create Project with ActiveCollab

Creates a new project in ActiveCollab.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://app.activecollab.com/:instanceId/api/v1`
- **Official documentation:** [Create Project](https://developers.activecollab.com/api-documentation/v1/projects/projects.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The project name. |
