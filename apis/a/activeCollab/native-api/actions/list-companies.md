# List Companies with ActiveCollab

Retrieves all companies from your ActiveCollab workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies`
- **Base URL:** `https://app.activecollab.com/:instanceId/api/v1`
- **Official documentation:** [List Companies](https://developers.activecollab.com/api-documentation/v1/people/companies/all.html)
