# Delete Project with ActiveCollab

Deletes an existing project from ActiveCollab.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://app.activecollab.com/:instanceId/api/v1`
- **Official documentation:** [Delete Project](https://developers.activecollab.com/api-documentation/v1/projects/projects.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The project ID. |
