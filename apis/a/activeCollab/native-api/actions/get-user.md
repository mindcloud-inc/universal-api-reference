# Get User with ActiveCollab

Retrieves a user from your ActiveCollab workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://app.activecollab.com/:instanceId/api/v1`
- **Official documentation:** [Get User](https://developers.activecollab.com/api-documentation/v1/people/users/users.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The user ID. |
