# List Project Labels with ActiveCollab

Retrieves project labels from your ActiveCollab workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels/project-labels`
- **Base URL:** `https://app.activecollab.com/:instanceId/api/v1`
- **Official documentation:** [List Project Labels](https://developers.activecollab.com/api-documentation/v1/projects/labels.html)
