# Get Workspace Info with ActiveCollab

Retrieves application details from your ActiveCollab workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/info`
- **Base URL:** `https://app.activecollab.com/:instanceId/api/v1`
- **Official documentation:** [Get Workspace Info](https://developers.activecollab.com/api-documentation/v1/info.html)
