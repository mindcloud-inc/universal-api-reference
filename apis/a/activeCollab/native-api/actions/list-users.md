# List Users with ActiveCollab

Retrieves all users from your ActiveCollab workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://app.activecollab.com/:instanceId/api/v1`
- **Official documentation:** [List Users](https://developers.activecollab.com/api-documentation/v1/people/users/users.html)
