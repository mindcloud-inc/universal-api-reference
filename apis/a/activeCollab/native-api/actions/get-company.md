# Get Company with ActiveCollab

Retrieves a company from your ActiveCollab workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:companyId`
- **Base URL:** `https://app.activecollab.com/:instanceId/api/v1`
- **Official documentation:** [Get Company](https://developers.activecollab.com/api-documentation/v1/people/companies/all.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | The company ID. |
