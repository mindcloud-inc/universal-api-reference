# Create Tag List with Audome

Creates a new tag list in Audome.

## Endpoint

- **Method:** `POST`
- **Path:** `/tag-lists`
- **Base URL:** `https://app.audome.com/api/v1`
- **Official documentation:** [Create Tag List](https://app.audome.com/api-documentation#endpoints-POSTapi-v1-tag-lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name for the tag list. |
