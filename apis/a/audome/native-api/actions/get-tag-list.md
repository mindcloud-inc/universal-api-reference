# Get Tag List with Audome

Retrieves one tag list from Audome.

## Endpoint

- **Method:** `GET`
- **Path:** `/tag-lists/:taglistUuid`
- **Base URL:** `https://app.audome.com/api/v1`
- **Official documentation:** [Get Tag List](https://app.audome.com/api-documentation#endpoints-GETapi-v1-tag-lists--taglistUuid-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taglistUuid` | path | `string` | yes | Numeric tag-list identifier. |
