# Delete Tag List with Audome

Deletes an existing tag list from Audome.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tag-lists/:taglistUuid`
- **Base URL:** `https://app.audome.com/api/v1`
- **Official documentation:** [Delete Tag List](https://app.audome.com/api-documentation#endpoints-DELETEapi-v1-tag-lists--taglistUuid-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taglistUuid` | path | `string` | yes | Numeric tag-list identifier. |
