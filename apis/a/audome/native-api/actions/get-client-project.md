# Get Client Project with Audome

## Endpoint

- **Method:** `GET`
- **Path:** `/client-projects/:uuid`
- **Base URL:** `https://app.audome.com/api/v1`
- **Official documentation:** [Get Client Project](https://app.audome.com/api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID of the client project to fetch. |
