# Create GPT-5.2 Chat Completion with AI/ML API

Creates a GPT-5.2 chat completion in AI/ML API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/chat/completions`
- **Base URL:** `https://api.aimlapi.com`
- **Official documentation:** [Create GPT-5.2 Chat Completion](https://docs.aimlapi.com/api-references/text-models-llm/openai/gpt-5.2)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `messages[]` | body | `array<object>` | yes |
