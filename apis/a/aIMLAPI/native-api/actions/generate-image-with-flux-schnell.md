# Generate Image With Flux Schnell with AI/ML API

Generates an image with Flux Schnell in AI/ML API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/images/generations`
- **Base URL:** `https://api.aimlapi.com`
- **Official documentation:** [Generate Image With Flux Schnell](https://docs.aimlapi.com/api-references/image-models/flux/flux-schnell)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `prompt` | body | `string` | yes |
