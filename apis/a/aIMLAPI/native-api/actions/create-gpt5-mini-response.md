# Create GPT-5 Mini Response with AI/ML API

Creates a GPT-5 Mini response in AI/ML API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/responses`
- **Base URL:** `https://api.aimlapi.com`
- **Official documentation:** [Create GPT-5 Mini Response](https://docs.aimlapi.com/api-references/text-models-llm/openai/gpt-5-mini)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `input` | body | `string` | yes |
