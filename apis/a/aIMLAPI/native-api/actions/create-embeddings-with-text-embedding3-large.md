# Create Embeddings With Text-Embedding-3-Large with AI/ML API

Creates text-embedding-3-large embeddings in AI/ML API.

- **Path:** `/v1/embeddings`
- **Base URL:** `https://api.aimlapi.com`
- **Official documentation:** [Create Embeddings With Text-Embedding-3-Large](https://docs.aimlapi.com/api-references/embedding-models/openai/text-embedding-3-large)
