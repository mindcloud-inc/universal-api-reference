# Create Gemini 2.5 Flash Chat Completion with AI/ML API

Creates a Gemini 2.5 Flash chat completion in AI/ML API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/chat/completions`
- **Base URL:** `https://api.aimlapi.com`
- **Official documentation:** [Create Gemini 2.5 Flash Chat Completion](https://docs.aimlapi.com/api-references/text-models-llm/google/gemini-2.5-flash)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `messages[]` | body | `array<object>` | yes |
