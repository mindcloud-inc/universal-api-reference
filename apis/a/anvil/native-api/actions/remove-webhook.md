# Remove Webhook with Anvil

Deletes an existing webhook from Anvil.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://graphql.useanvil.com`
- **Official documentation:** [Remove Webhook](https://www.useanvil.com/docs/api/graphql/reference/#mutation-removeWebhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.eid` | body | `string` | yes | Provide EID for Remove Webhook. |
