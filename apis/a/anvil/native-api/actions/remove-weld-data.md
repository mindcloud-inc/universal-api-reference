# Remove Weld Data with Anvil

Deletes existing weld data from Anvil.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://graphql.useanvil.com`
- **Official documentation:** [Remove Weld Data](https://www.useanvil.com/docs/api/graphql/reference/#mutation-removeWeldData)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.eid` | body | `string` | yes | Provide EID for Remove Weld Data. |
