# Remove Etch Packet with Anvil

Deletes an existing Etch packet from Anvil.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://graphql.useanvil.com`
- **Official documentation:** [Remove Etch Packet](https://www.useanvil.com/docs/api/graphql/reference/#mutation-removeEtchPacket)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.eid` | body | `string` | yes | Provide EID for Remove Etch Packet. |
