# Get Webhook Log with Anvil

Retrieves a webhook log from Anvil.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://graphql.useanvil.com`
- **Official documentation:** [Get Webhook Log](https://www.useanvil.com/docs/api/graphql/reference/#query-webhookLog)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.eid` | body | `string` | yes | Provide EID for Get Webhook Log. |
