# Remove Webhook Action with Anvil

Deletes an existing webhook action from Anvil.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://graphql.useanvil.com`
- **Official documentation:** [Remove Webhook Action](https://www.useanvil.com/docs/api/graphql/reference/#mutation-removeWebhookAction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.eid` | body | `string` | yes | Provide EID for Remove Webhook Action. |
