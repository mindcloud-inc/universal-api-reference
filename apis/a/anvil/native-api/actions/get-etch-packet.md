# Get Etch Packet with Anvil

Retrieves an Etch packet from Anvil.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://graphql.useanvil.com`
- **Official documentation:** [Get Etch Packet](https://www.useanvil.com/docs/api/graphql/reference/#query-etchPacket)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.eid` | body | `string` | yes | Provide EID for Get Etch Packet. |
