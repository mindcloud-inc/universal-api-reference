# Delete Slides with Aspose

Deletes existing slides from a presentation in Aspose.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/slides/:name/slides`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [Delete Slides](https://docs.aspose.cloud/slides/delete-slides/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
| `slides` | query | `string` | no | Comma-separated 1-based slide indices to delete. |
