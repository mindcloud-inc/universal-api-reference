# Create Slide with Aspose

Creates a new slide in a presentation in Aspose.

## Endpoint

- **Method:** `POST`
- **Path:** `/slides/:name/slides`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [Create Slide](https://docs.aspose.cloud/slides/add-a-new-slide/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
