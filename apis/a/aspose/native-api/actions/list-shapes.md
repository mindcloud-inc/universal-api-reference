# List Shapes with Aspose

Retrieves shapes from a slide in Aspose.

## Endpoint

- **Method:** `GET`
- **Path:** `/slides/:name/slides/:slideIndex/shapes`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [List Shapes](https://docs.aspose.cloud/slides/get-shapes-from-a-slide/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
| `slideIndex` | path | `number` | yes | The 1-based slide index. |
