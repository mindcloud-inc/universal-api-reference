# Copy Slide with Aspose

Copies slides within a presentation in Aspose.

## Endpoint

- **Method:** `POST`
- **Path:** `/slides/:name/slides/copy`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [Copy Slide](https://docs.aspose.cloud/slides/copy-slides/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
| `slideToCopy` | query | `number` | yes | The 1-based slide index to copy. |
