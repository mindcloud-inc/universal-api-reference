# Delete Slide with Aspose

Deletes a slide from a presentation in Aspose.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/slides/:name/slides/:slideIndex`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [Delete Slide](https://docs.aspose.cloud/slides/delete-slides/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
| `slideIndex` | path | `number` | yes | The 1-based slide index to delete. |
