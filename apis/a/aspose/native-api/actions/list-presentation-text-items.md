# List Presentation Text Items with Aspose

Retrieves text items from a presentation in Aspose.

## Endpoint

- **Method:** `GET`
- **Path:** `/slides/:name/textItems`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [List Presentation Text Items](https://docs.aspose.cloud/slides/read-text-items/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
