# Get Slide with Aspose

Retrieves a slide from a presentation in Aspose.

## Endpoint

- **Method:** `GET`
- **Path:** `/slides/:name/slides/:slideIndex`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [Get Slide](https://docs.aspose.cloud/slides/get-information-about-slides/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
| `slideIndex` | path | `number` | yes | The 1-based slide index. |
