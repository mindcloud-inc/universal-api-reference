# List Document Properties with Aspose

Retrieves document properties from a presentation in Aspose.

## Endpoint

- **Method:** `GET`
- **Path:** `/slides/:name/documentproperties`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [List Document Properties](https://docs.aspose.cloud/slides/read-document-properties/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
