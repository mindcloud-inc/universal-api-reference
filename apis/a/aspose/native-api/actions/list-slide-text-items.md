# List Slide Text Items with Aspose

Retrieves text items from a slide in Aspose.

## Endpoint

- **Method:** `GET`
- **Path:** `/slides/:name/slides/:slideIndex/textItems`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [List Slide Text Items](https://docs.aspose.cloud/slides/read-text-items/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
| `slideIndex` | path | `number` | yes | The 1-based slide index. |
