# List Slides with Aspose

Retrieves slides from a presentation in Aspose.

## Endpoint

- **Method:** `GET`
- **Path:** `/slides/:name/slides`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [List Slides](https://docs.aspose.cloud/slides/get-information-about-slides/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
