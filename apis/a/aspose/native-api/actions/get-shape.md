# Get Shape with Aspose

Retrieves a shape from a slide in Aspose.

## Endpoint

- **Method:** `GET`
- **Path:** `/slides/:name/slides/:slideIndex/shapes/:shapeIndex`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [Get Shape](https://docs.aspose.cloud/slides/get-a-shape-from-a-slide/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
| `slideIndex` | path | `number` | yes | The 1-based slide index. |
| `shapeIndex` | path | `number` | yes | The 1-based shape index. |
