# Create Presentation with Aspose

Creates a new presentation in Aspose.

## Endpoint

- **Method:** `POST`
- **Path:** `/slides/:name`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [Create Presentation](https://docs.aspose.cloud/slides/create-a-new-presentation/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `multipart/form-data` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
