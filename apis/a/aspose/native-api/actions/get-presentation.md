# Get Presentation with Aspose

Retrieves details for a presentation in Aspose.

## Endpoint

- **Method:** `GET`
- **Path:** `/slides/:name`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [Get Presentation](https://docs.aspose.cloud/slides/read-information-about-a-presentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
