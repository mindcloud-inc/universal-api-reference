# Get Document Property with Aspose

Retrieves a document property from a presentation in Aspose.

## Endpoint

- **Method:** `GET`
- **Path:** `/slides/:name/documentproperties/:propertyName`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [Get Document Property](https://docs.aspose.cloud/slides/read-document-properties/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
| `propertyName` | path | `string` | yes | The document property name. |
