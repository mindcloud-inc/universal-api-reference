# List Slide Placeholders with Aspose

Retrieves placeholders from a slide in Aspose.

## Endpoint

- **Method:** `GET`
- **Path:** `/slides/:name/slides/:slideIndex/placeholders`
- **Base URL:** `https://api.aspose.cloud/v3.0`
- **Official documentation:** [List Slide Placeholders](https://docs.aspose.cloud/slides/get-placeholders-from-a-slide/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The presentation file name. |
| `slideIndex` | path | `number` | yes | The 1-based slide index. |
