# Get Daily Index Metadata with AccuWeather

Retrieves daily index metadata from AccuWeather.

## Endpoint

- **Method:** `GET`
- **Path:** `/indices/v1/daily/:ID`
- **Base URL:** `https://dataservice.accuweather.com`
- **Official documentation:** [Get Daily Index Metadata](https://developer.accuweather.com/accuweather-indices-api/apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ID` | path | `string` | no | Required index ID. |
