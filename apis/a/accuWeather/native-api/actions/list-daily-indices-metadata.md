# List Daily Indices Metadata with AccuWeather

Lists daily indices metadata in AccuWeather.

## Endpoint

- **Method:** `GET`
- **Path:** `/indices/v1/daily`
- **Base URL:** `https://dataservice.accuweather.com`
- **Official documentation:** [List Daily Indices Metadata](https://developer.accuweather.com/accuweather-indices-api/apis)
