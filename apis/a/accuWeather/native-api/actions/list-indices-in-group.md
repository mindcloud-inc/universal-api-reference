# List Indices In Group with AccuWeather

Lists daily indices in an AccuWeather group.

## Endpoint

- **Method:** `GET`
- **Path:** `/indices/v1/daily/groups/:ID`
- **Base URL:** `https://dataservice.accuweather.com`
- **Official documentation:** [List Indices In Group](https://developer.accuweather.com/accuweather-indices-api/apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ID` | path | `string` | no | Required index group ID. |
