# List Index Groups with AccuWeather

Lists daily index groups in AccuWeather.

## Endpoint

- **Method:** `GET`
- **Path:** `/indices/v1/daily/groups`
- **Base URL:** `https://dataservice.accuweather.com`
- **Official documentation:** [List Index Groups](https://developer.accuweather.com/accuweather-indices-api/apis)
