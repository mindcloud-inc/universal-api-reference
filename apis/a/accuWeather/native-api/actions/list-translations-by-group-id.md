# List Translations By Group Id with AccuWeather

Lists translations in AccuWeather for a group.

## Endpoint

- **Method:** `GET`
- **Path:** `/translations/v1/groups/:groupID`
- **Base URL:** `https://dataservice.accuweather.com`
- **Official documentation:** [List Translations By Group Id](https://developer.accuweather.com/core-weather/languages-translations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupID` | path | `string` | yes | Required translation group ID. |
