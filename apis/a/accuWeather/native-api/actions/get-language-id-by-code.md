# Get Language Id By Code with AccuWeather

Retrieves a language ID from AccuWeather by code.

## Endpoint

- **Method:** `GET`
- **Path:** `/translations/v1/languages/code/:languageCode`
- **Base URL:** `https://dataservice.accuweather.com`
- **Official documentation:** [Get Language Id By Code](https://developer.accuweather.com/core-weather/languages-translations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `languageCode` | path | `string` | yes | Required AccuWeather language code. |
