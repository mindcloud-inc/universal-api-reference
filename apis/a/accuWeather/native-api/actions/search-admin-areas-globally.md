# Search Admin Areas Globally with AccuWeather

Finds admin areas in AccuWeather by global search.

## Endpoint

- **Method:** `GET`
- **Path:** `/locations/v1/adminareas/search`
- **Base URL:** `https://dataservice.accuweather.com`
- **Official documentation:** [Search Admin Areas Globally](https://developer.accuweather.com/core-weather/text-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Required search query text. |
