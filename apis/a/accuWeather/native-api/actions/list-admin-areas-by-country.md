# List Admin Areas By Country with AccuWeather

Lists the admin areas in AccuWeather for a country.

## Endpoint

- **Method:** `GET`
- **Path:** `/locations/v1/adminareas/:countryCode`
- **Base URL:** `https://dataservice.accuweather.com`
- **Official documentation:** [List Admin Areas By Country](https://developer.accuweather.com/accuweather-locations-api/apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `countryCode` | path | `string` | yes | Required AccuWeather country code. |
