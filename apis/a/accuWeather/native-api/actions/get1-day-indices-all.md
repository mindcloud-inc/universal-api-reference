# Get 1 Day Indices All with AccuWeather

Retrieves all 1-day indices from AccuWeather.

## Endpoint

- **Method:** `GET`
- **Path:** `/indices/v1/daily/1day/:locationKey`
- **Base URL:** `https://dataservice.accuweather.com`
- **Official documentation:** [Get 1 Day Indices All](https://developer.accuweather.com/accuweather-indices-api/apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locationKey` | path | `string` | no | Required AccuWeather location key. |
