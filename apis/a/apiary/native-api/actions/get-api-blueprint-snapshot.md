# Get API Blueprint Snapshot with Apiary

## Endpoint

- **Method:** `GET`
- **Path:** `https://jsapi.apiary.io/apis/{{apiName}}/blueprint`
- **Base URL:** `https://api.apiary.io`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `apiName` | path | `string` | yes | Select the Apiary API subdomain to fetch the blueprint snapshot for. |
