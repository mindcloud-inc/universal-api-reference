# Get API Documentation Snapshot with Apiary

## Endpoint

- **Method:** `GET`
- **Path:** `https://jsapi.apiary.io/apis/{{apiName}}/documentation`
- **Base URL:** `https://api.apiary.io`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `apiName` | path | `string` | yes | Select the Apiary API subdomain to fetch the documentation snapshot for. |
