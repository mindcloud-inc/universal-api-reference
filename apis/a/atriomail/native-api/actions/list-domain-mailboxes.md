# List Domain Mailboxes with Atriomail

## Endpoint

- **Method:** `GET`
- **Path:** `/mailboxes`
- **Base URL:** `https://system.atriomail.com/api/v1`

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain_id` | query | `number` | yes |
