# Get Domain with Atriomail

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domainId`
- **Base URL:** `https://system.atriomail.com/api/v1`
- **Official documentation:** [Get Domain](https://system.atriomail.com/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domainId` | path | `number` | yes | The AtrioMail domain ID. |
