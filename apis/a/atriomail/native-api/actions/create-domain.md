# Create Domain with Atriomail

## Endpoint

- **Method:** `POST`
- **Path:** `/domains`
- **Base URL:** `https://system.atriomail.com/api/v1`
- **Official documentation:** [Create Domain](https://system.atriomail.com/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_name` | body | `string` | yes | The domain name to create. |
