# Delete Mailbox with Atriomail

## Endpoint

- **Method:** `DELETE`
- **Path:** `/mailboxes/:mailboxId`
- **Base URL:** `https://system.atriomail.com/api/v1`
- **Official documentation:** [Delete Mailbox](https://system.atriomail.com/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mailboxId` | path | `number` | yes | The AtrioMail mailbox ID. |
