# Get Story Transcript with All Things Considered Podcast

Retrieves a story transcript from All Things Considered Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/transcripts/:storyId`
- **Base URL:** `https://www.npr.org`
- **API:** rest
- **Official documentation:** [Get Story Transcript](https://www.npr.org/transcripts/nx-s1-5803566)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `storyId` | path | `string` | yes |
