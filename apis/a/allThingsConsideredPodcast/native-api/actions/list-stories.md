# List Stories with All Things Considered Podcast

Retrieves recent stories from All Things Considered Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `https://feeds.npr.org/2/rss.xml`
- **Base URL:** `https://www.npr.org`
- **API:** rest
- **Official documentation:** [List Stories](https://feeds.npr.org/2/rss.xml)
