# List Archive Shows with All Things Considered Podcast

Retrieves archived shows from All Things Considered Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/programs/all-things-considered/archive`
- **Base URL:** `https://www.npr.org`
- **API:** rest
- **Official documentation:** [List Archive Shows](https://www.npr.org/programs/all-things-considered/archive)
