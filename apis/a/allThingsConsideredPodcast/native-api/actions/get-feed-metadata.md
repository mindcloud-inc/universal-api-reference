# Get Feed Metadata with All Things Considered Podcast

Retrieves feed metadata from All Things Considered Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `https://feeds.npr.org/2/rss.xml`
- **Base URL:** `https://www.npr.org`
- **API:** rest
- **Official documentation:** [Get Feed Metadata](https://feeds.npr.org/2/rss.xml)
