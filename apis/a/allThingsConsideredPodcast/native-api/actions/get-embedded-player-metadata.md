# Get Embedded Player Metadata with All Things Considered Podcast

Retrieves embedded player metadata from All Things Considered Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/player/embed/:storyId/:mediaId`
- **Base URL:** `https://www.npr.org`
- **API:** rest
- **Official documentation:** [Get Embedded Player Metadata](https://www.npr.org/player/embed/nx-s1-5803566/nx-s1-9750301)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `storyId` | path | `string` | yes |
| `mediaId` | path | `string` | yes |
