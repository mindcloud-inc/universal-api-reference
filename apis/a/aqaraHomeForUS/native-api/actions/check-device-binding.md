# Check Device Binding with Aqara Home for US

Retrieves Aqara hub binding status from a bind key.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Check Device Binding](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/addDeviceinterface.html)
