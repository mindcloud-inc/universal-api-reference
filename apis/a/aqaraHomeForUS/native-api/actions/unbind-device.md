# Unbind Device with Aqara Home for US

Deletes an Aqara device binding from its gateway.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Unbind Device](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/DeviceManagement.html)
