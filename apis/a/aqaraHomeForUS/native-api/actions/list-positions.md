# List Positions with Aqara Home for US

Retrieves subordinate positions from Aqara Home for US.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [List Positions](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/PositionManagement.html)
