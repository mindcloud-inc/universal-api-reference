# Get Device Info with Aqara Home for US

Retrieves device details from Aqara Home for US.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Get Device Info](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/DeviceManagement.html)
