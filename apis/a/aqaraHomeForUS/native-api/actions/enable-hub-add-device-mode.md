# Enable Hub Add-Device Mode with Aqara Home for US

Enables hub add-device mode in Aqara Home for US.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Enable Hub Add-Device Mode](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/addDeviceinterface.html)
