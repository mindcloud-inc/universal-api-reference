# Get Resource Names with Aqara Home for US

Retrieves default resource names for an Aqara device.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Get Resource Names](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/ResourceManagement.html)
