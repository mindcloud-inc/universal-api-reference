# Set Device Name with Aqara Home for US

Updates a device name in Aqara Home for US.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Set Device Name](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/DeviceManagement.html)
