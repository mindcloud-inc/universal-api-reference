# Create Linkage with Aqara Home for US

Creates a new linkage in Aqara Home for US.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Create Linkage](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/LinkageManagement.html)
