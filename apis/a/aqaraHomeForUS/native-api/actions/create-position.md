# Create Position with Aqara Home for US

Creates a new position in Aqara Home for US.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Create Position](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/PositionManagement.html)
