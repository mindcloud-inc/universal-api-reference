# Get Resource Statistics with Aqara Home for US

Retrieves resource statistics from an Aqara device.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Get Resource Statistics](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/ResourceManagement.html)
