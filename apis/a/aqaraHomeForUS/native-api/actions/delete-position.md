# Delete Position with Aqara Home for US

Deletes an existing position from Aqara Home for US.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Delete Position](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/PositionManagement.html)
