# Set Device Position with Aqara Home for US

Updates a device position in Aqara Home for US.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Set Device Position](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/DeviceManagement.html)
