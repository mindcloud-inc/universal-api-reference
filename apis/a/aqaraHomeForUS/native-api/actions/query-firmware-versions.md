# Query Firmware Versions with Aqara Home for US

Retrieves firmware versions for an Aqara device model.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Query Firmware Versions](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/FirmwareManagement.html)
