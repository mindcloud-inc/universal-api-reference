# Get Position Details with Aqara Home for US

Retrieves Aqara Home for US position details by ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Get Position Details](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/PositionManagement.html)
