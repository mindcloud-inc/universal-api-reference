# List Scenes by Position with Aqara Home for US

Retrieves scenes from Aqara Home for US by position.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [List Scenes by Position](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/SceneManagement.html)
