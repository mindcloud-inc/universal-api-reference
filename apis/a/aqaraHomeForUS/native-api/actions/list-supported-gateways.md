# List Supported Gateways with Aqara Home for US

Retrieves gateways that support an Aqara sub-device.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [List Supported Gateways](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/addDeviceinterface.html)
