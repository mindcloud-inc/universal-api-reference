# List IFTTT Triggers with Aqara Home for US

Retrieves IFTTT triggers for an Aqara object model.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [List IFTTT Triggers](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/Linkageconfiguration.html)
