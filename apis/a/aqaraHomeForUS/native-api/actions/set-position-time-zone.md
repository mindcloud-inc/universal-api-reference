# Set Position Time Zone with Aqara Home for US

Updates a top-level position time zone in Aqara Home for US.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Set Position Time Zone](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/PositionManagement.html)
