# Get Device Bind Key with Aqara Home for US

Retrieves a bind key for adding an Aqara hub.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Get Device Bind Key](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/addDeviceinterface.html)
