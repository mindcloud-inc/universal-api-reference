# Get Device Sub-Info with Aqara Home for US

Retrieves Aqara sub-device details for a gateway.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Get Device Sub-Info](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/DeviceManagement.html)
