# Control Resource Device with Aqara Home for US

Updates an Aqara device through resource controls.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open-usa.aqara.com/v3.0/open/api`
- **Official documentation:** [Control Resource Device](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/ResourceManagement.html)
