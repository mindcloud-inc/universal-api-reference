# Delete Contact List with AvoSMS

Deletes an existing contact list from AvoSMS.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contact/list/delete`
- **Base URL:** `https://api.avosms.com`
- **Official documentation:** [Delete Contact List](https://www.avosms.com/en/api/documentation/contact/list/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listContactId` | body | `string` | yes | Contact list ID |
