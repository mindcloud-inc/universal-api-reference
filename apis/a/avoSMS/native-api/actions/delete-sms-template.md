# Delete SMS Template with AvoSMS

Deletes an existing SMS template from AvoSMS.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/model/sms/delete`
- **Base URL:** `https://api.avosms.com`
- **Official documentation:** [Delete SMS Template](https://www.avosms.com/en/api/documentation/model/sms/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `modelId` | body | `string` | yes | SMS template ID |
