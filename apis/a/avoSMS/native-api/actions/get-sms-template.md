# Get SMS Template with AvoSMS

Retrieves an SMS template from AvoSMS.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/model/sms/information`
- **Base URL:** `https://api.avosms.com`
- **Official documentation:** [Get SMS Template](https://www.avosms.com/en/api/documentation/model/sms/information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `modelId` | body | `string` | yes | SMS template ID |
