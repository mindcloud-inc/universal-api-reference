# Get Contact List with AvoSMS

Retrieves a contact list and its contacts from AvoSMS.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contact/list/information`
- **Base URL:** `https://api.avosms.com`
- **Official documentation:** [Get Contact List](https://www.avosms.com/en/api/documentation/contact/list/information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listContactId` | body | `string` | yes | Contact list ID |
