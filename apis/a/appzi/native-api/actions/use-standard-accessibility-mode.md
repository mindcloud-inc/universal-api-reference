# Use Standard Accessibility Mode with Appzi

Retrieves Appzi standard accessibility mode guidance.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/probe/:portalToken`
- **Base URL:** `https://api.appzi.io`
- **Official documentation:** [Use Standard Accessibility Mode](https://docs.appzi.io/configuration/accessibility/#standard-mode)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `portalToken` | path | `string` | yes | Portal token path segment used only to validate runtime against the existing Appzi probe surface. |
