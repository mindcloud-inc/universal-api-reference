# List Portal Survey Configurations with Appzi

Retrieves portal survey configurations from Appzi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/probe/:portalToken`
- **Base URL:** `https://api.appzi.io`
- **Official documentation:** [List Portal Survey Configurations](https://docs.appzi.io/installation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `portalToken` | path | `string` | yes | Appzi portal token from Portal Settings > Installation Code. |
