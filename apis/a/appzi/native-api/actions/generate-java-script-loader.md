# Generate JavaScript Loader with Appzi

Generates an Appzi JavaScript loader snippet.

## Endpoint

- **Method:** `GET`
- **Path:** `https://docs.appzi.io/installation/`
- **Base URL:** `https://api.appzi.io`
- **Official documentation:** [Generate JavaScript Loader](https://docs.appzi.io/installation/#javascript-function)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `portalToken` | query | `string` | yes | Portal token inserted into the generated Appzi loader snippet. |
