# Open Survey Inline with Appzi

Generates an inline Appzi survey trigger snippet.

## Endpoint

- **Method:** `GET`
- **Path:** `https://docs.appzi.io/integration/triggering-surveys/`
- **Base URL:** `https://api.appzi.io`
- **Official documentation:** [Open Survey Inline](https://docs.appzi.io/integration/triggering-surveys/#inline-trigger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `configId` | query | `string` | yes | Survey configuration ID inserted into the generated trigger snippet. |
