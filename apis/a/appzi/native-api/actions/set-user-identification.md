# Set User Identification with Appzi

Generates an Appzi user identification settings snippet.

## Endpoint

- **Method:** `GET`
- **Path:** `https://docs.appzi.io/integration/add-data/`
- **Base URL:** `https://api.appzi.io`
- **Official documentation:** [Set User Identification](https://docs.appzi.io/integration/add-data/#user-identification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | query | `string` | yes | Stable user identifier inserted into the generated Appzi tracking snippet. |
