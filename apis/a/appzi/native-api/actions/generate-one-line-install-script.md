# Generate One-Line Install Script with Appzi

Generates a one-line Appzi install script.

## Endpoint

- **Method:** `GET`
- **Path:** `https://docs.appzi.io/installation/`
- **Base URL:** `https://api.appzi.io`
- **Official documentation:** [Generate One-Line Install Script](https://docs.appzi.io/installation/#one-line-script-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `portalToken` | query | `string` | yes | Portal token inserted into the generated Appzi install snippet. |
