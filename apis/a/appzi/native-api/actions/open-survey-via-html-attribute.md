# Open Survey Via HTML Attribute with Appzi

Generates an Appzi HTML-attribute survey trigger snippet.

## Endpoint

- **Method:** `GET`
- **Path:** `https://docs.appzi.io/integration/triggering-surveys/`
- **Base URL:** `https://api.appzi.io`
- **Official documentation:** [Open Survey Via HTML Attribute](https://docs.appzi.io/integration/triggering-surveys/#html-attribute)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `configId` | query | `string` | yes | Survey configuration ID inserted into the generated HTML-attribute trigger snippet. |
