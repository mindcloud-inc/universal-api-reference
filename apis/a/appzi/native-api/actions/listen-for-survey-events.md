# Listen For Survey Events with Appzi

Retrieves a survey event listener snippet from Appzi.

## Endpoint

- **Method:** `GET`
- **Path:** `https://docs.appzi.io/integration/events/`
- **Base URL:** `https://api.appzi.io`
- **Official documentation:** [Listen For Survey Events](https://docs.appzi.io/integration/events/#basic-event-handling)
