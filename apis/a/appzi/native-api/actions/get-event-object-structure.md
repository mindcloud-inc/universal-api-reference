# Get Event Object Structure with Appzi

Retrieves the Appzi survey event object structure.

## Endpoint

- **Method:** `GET`
- **Path:** `https://docs.appzi.io/integration/events/`
- **Base URL:** `https://api.appzi.io`
- **Official documentation:** [Get Event Object Structure](https://docs.appzi.io/integration/events/#event-object-structure)
