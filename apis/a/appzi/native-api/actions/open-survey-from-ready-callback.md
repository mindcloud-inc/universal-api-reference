# Open Survey From Ready Callback with Appzi

Generates an Appzi ready-callback survey trigger snippet.

## Endpoint

- **Method:** `GET`
- **Path:** `https://docs.appzi.io/integration/triggering-surveys/`
- **Base URL:** `https://api.appzi.io`
- **Official documentation:** [Open Survey From Ready Callback](https://docs.appzi.io/integration/triggering-surveys/#ready-callback)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `configId` | query | `string` | yes | Survey configuration ID inserted into the generated ready-callback trigger snippet. |
