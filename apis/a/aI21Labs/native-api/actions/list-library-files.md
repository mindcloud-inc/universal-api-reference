# List Library Files with AI21 Labs

Retrieves documents from your AI21 Labs library.

## Endpoint

- **Method:** `GET`
- **Path:** `/library/files`
- **Base URL:** `https://api.ai21.com/studio/v1`
- **Official documentation:** [List Library Files](https://docs.ai21.com/reference/manage-library-ref/list-library-files)
