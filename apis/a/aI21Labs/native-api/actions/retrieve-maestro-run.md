# Retrieve Maestro Run with AI21 Labs

Retrieves a Maestro run by ID from AI21 Labs.

## Endpoint

- **Method:** `GET`
- **Path:** `/maestro/runs/:run_id`
- **Base URL:** `https://api.ai21.com/studio/v1`
- **Official documentation:** [Retrieve Maestro Run](https://docs.ai21.com/reference/retrieve-run)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_id` | path | `string` | yes | The AI21 Maestro run id to retrieve. |
