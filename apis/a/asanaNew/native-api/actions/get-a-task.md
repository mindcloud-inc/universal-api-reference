# Get a task with Asana

Retrieves a task from Asana.

## Endpoint

- **Method:** `GET`
- **Path:** `tasks/:task_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Get a task](https://developers.asana.com/reference/gettask)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_gid` | path | `string` | yes |
