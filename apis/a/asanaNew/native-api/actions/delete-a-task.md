# Delete a task with Asana

Deletes a task from Asana.

## Endpoint

- **Method:** `DELETE`
- **Path:** `tasks/:task_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Delete a task](https://developers.asana.com/reference/deletetask)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_gid` | path | `string` | yes |
