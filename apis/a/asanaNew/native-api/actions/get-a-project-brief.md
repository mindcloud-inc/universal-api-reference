# Get a project brief with Asana

Retrieves a project brief from Asana.

## Endpoint

- **Method:** `GET`
- **Path:** `project_briefs/:project_brief_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Get a project brief](https://developers.asana.com/reference/getprojectbrief)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_brief_gid` | path | `string` | yes |
