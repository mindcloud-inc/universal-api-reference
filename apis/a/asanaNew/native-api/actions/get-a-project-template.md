# Get a project template with Asana

Retrieves a project template from Asana.

## Endpoint

- **Method:** `GET`
- **Path:** `project_templates/:project_template_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Get a project template](https://developers.asana.com/reference/getprojecttemplate)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_template_gid` | path | `string` | yes |
