# Get a status update with Asana

Retrieves a status update from Asana.

## Endpoint

- **Method:** `GET`
- **Path:** `status_updates/:status_update_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Get a status update](https://developers.asana.com/reference/getstatus)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `status_update_gid` | path | `string` | yes |
