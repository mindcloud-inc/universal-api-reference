# Get multiple portfolio memberships with Asana

Retrieves portfolio memberships from Asana.

## Endpoint

- **Method:** `GET`
- **Path:** `portfolio_memberships`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Get multiple portfolio memberships](https://developers.asana.com/reference/getportfoliomemberships)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `opt_fields[]` | query | `array<string>` | no |
