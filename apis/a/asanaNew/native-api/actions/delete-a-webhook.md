# Delete a webhook with Asana

Deletes a webhook from Asana.

## Endpoint

- **Method:** `DELETE`
- **Path:** `webhooks/:webhook_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Delete a webhook](https://developers.asana.com/reference/deletewebhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_gid` | path | `string` | yes | Path parameter: webhook_gid |
