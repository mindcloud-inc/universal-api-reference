# Get a webhook with Asana

Retrieves a webhook from Asana.

## Endpoint

- **Method:** `GET`
- **Path:** `webhooks/:webhook_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Get a webhook](https://developers.asana.com/reference/getwebhook)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `webhook_gid` | path | `string` | yes |
