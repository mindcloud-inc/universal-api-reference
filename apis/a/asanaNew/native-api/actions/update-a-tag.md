# Update a tag with Asana

Updates a tag in Asana.

## Endpoint

- **Method:** `PUT`
- **Path:** `tags/:tag_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Update a tag](https://developers.asana.com/reference/updatetag)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tag_gid` | path | `string` | yes |
