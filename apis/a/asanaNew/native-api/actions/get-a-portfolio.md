# Get a portfolio with Asana

Retrieves a portfolio from Asana.

## Endpoint

- **Method:** `GET`
- **Path:** `portfolios/:portfolio_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Get a portfolio](https://developers.asana.com/reference/getportfolio)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `portfolio_gid` | path | `string` | yes |
