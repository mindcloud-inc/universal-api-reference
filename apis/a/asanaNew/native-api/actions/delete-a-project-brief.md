# Delete a project brief with Asana

Deletes a project brief from Asana.

## Endpoint

- **Method:** `DELETE`
- **Path:** `project_briefs/:project_brief_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Delete a project brief](https://developers.asana.com/reference/deleteprojectbrief)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_brief_gid` | path | `string` | yes | Path parameter: project_brief_gid |
