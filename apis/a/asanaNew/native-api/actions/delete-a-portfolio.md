# Delete a portfolio with Asana

Deletes a portfolio from Asana.

## Endpoint

- **Method:** `DELETE`
- **Path:** `portfolios/:portfolio_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Delete a portfolio](https://developers.asana.com/reference/deleteportfolio)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `portfolio_gid` | path | `string` | yes |
