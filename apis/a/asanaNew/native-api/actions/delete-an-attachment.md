# Delete an attachment with Asana

Deletes an attachment from Asana.

## Endpoint

- **Method:** `DELETE`
- **Path:** `attachments/:attachment_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Delete an attachment](https://developers.asana.com/reference/deleteattachment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `attachment_gid` | path | `string` | yes | Path parameter: attachment_gid |
