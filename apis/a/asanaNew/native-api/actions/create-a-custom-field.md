# Create a custom field with Asana

Creates a custom field in Asana.

## Endpoint

- **Method:** `POST`
- **Path:** `custom_fields`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Create a custom field](https://developers.asana.com/reference/createcustomfield)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `data` | body | `string` | no |
