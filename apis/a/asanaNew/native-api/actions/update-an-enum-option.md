# Update an enum option with Asana

Updates an enum option in Asana.

## Endpoint

- **Method:** `PUT`
- **Path:** `enum_options/:enum_option_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Update an enum option](https://developers.asana.com/reference/updateenumoption)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `data` | body | `string` | no |
| `enum_option_gid` | path | `string` | yes |
