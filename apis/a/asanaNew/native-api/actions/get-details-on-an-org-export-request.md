# Get details on an org export request with Asana

Retrieves an organization export request from Asana.

## Endpoint

- **Method:** `GET`
- **Path:** `organization_exports/:organization_export_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Get details on an org export request](https://developers.asana.com/reference/getorganizationexport)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization_export_gid` | path | `string` | yes |
