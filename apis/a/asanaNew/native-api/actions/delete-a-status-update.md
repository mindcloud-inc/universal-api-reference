# Delete a status update with Asana

Deletes a status update from Asana.

## Endpoint

- **Method:** `DELETE`
- **Path:** `status_updates/:status_update_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Delete a status update](https://developers.asana.com/reference/deletestatus)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status_update_gid` | path | `string` | yes | Path parameter: status_update_gid |
