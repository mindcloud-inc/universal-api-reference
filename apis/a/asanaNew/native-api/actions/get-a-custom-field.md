# Get a custom field with Asana

Retrieves a custom field from Asana.

## Endpoint

- **Method:** `GET`
- **Path:** `custom_fields/:custom_field_gid`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Get a custom field](https://developers.asana.com/reference/getcustomfield)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `custom_field_gid` | path | `string` | yes |
