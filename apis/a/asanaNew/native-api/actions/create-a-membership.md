# Create a membership with Asana

Creates a membership for an object in Asana.

## Endpoint

- **Method:** `POST`
- **Path:** `memberships`
- **Base URL:** `https://app.asana.com/api/1.0`
- **Official documentation:** [Create a membership](https://developers.asana.com/reference/createprojectforteam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `data` | body | `object` | yes |
