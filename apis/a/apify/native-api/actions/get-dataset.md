# Get Dataset with Apify

Retrieves a dataset from Apify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/datasets/:datasetId`
- **Base URL:** `https://api.apify.com`
- **Official documentation:** [Get Dataset](https://docs.apify.com/api/v2/dataset-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | The ID of the dataset to retrieve. |
