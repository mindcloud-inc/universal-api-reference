# Get Actor Task with Apify

Retrieves an actor task from Apify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/actor-tasks/:actorTaskId`
- **Base URL:** `https://api.apify.com`
- **Official documentation:** [Get Actor Task](https://docs.apify.com/api/v2/actor-task-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `actorTaskId` | path | `string` | yes | The ID of the actor task to retrieve. |
