# Get Request Queue with Apify

Retrieves a request queue from Apify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/request-queues/:queueId`
- **Base URL:** `https://api.apify.com`
- **Official documentation:** [Get Request Queue](https://docs.apify.com/api/v2/request-queue-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `queueId` | path | `string` | yes | The ID of the request queue to retrieve. |
