# Get Dataset Statistics with Apify

Retrieves statistics for an Apify dataset.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/datasets/:datasetId/statistics`
- **Base URL:** `https://api.apify.com`
- **Official documentation:** [Get Dataset Statistics](https://docs.apify.com/api/v2/dataset-statistics-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | The ID of the dataset whose statistics to retrieve. |
