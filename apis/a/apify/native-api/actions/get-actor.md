# Get Actor with Apify

Retrieves an actor from Apify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/acts/:actorId`
- **Base URL:** `https://api.apify.com`
- **Official documentation:** [Get Actor](https://docs.apify.com/api/v2/act-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `actorId` | path | `string` | yes | The ID or username of the actor to retrieve. |
