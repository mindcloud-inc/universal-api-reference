# List Actor Tasks with Apify

Retrieves actor tasks from Apify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/actor-tasks`
- **Base URL:** `https://api.apify.com`
- **Official documentation:** [List Actor Tasks](https://docs.apify.com/api/v2/actor-tasks-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
