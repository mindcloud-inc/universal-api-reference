# Get Key-Value Store with Apify

Retrieves a key-value store from Apify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/key-value-stores/:storeId`
- **Base URL:** `https://api.apify.com`
- **Official documentation:** [Get Key-Value Store](https://docs.apify.com/api/v2/key-value-store-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `storeId` | path | `string` | yes | The ID of the key-value store to retrieve. |
