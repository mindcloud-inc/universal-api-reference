# Delete Position with Aqara Home for CH

Deletes an existing position from Aqara Home for CH.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-cn.aqara.com`
- **Official documentation:** [Delete Position](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/PositionManagement.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data` | body | `object` | yes | Aqara request data object for the selected intent. |
