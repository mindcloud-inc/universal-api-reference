# Get Position Details with Aqara Home for CH

Retrieves Aqara Home for CH position details by ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-cn.aqara.com`
- **Official documentation:** [Get Position Details](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/PositionManagement.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data` | body | `object` | yes | Aqara request data object for the selected intent. |
