# Search Agencies with AdPage

Finds agencies in AdPage by name.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/agency/search`
- **Base URL:** `https://whitelabel.adpage.io`
- **Official documentation:** [Search Agencies](https://whitelabel.adpage.io/api/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Agency name to search for. |
