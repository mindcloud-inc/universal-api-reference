# Phone Number Validation with AddressZen

Retrieves phone number validation details from AddressZen.

## Endpoint

- **Method:** `GET`
- **Path:** `/phone_numbers`
- **Base URL:** `https://api.addresszen.com/v1`
- **Official documentation:** [Phone Number Validation](https://docs.addresszen.com/docs/api/api-reference.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Phone number to validate |
