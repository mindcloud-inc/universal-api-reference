# Create Webhook with Airslate

Creates a new webhook in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/webhooks`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Webhook](https://docs.airslate.io/docs/airslate-api/webhooks-api)
