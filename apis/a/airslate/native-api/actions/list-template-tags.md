# List Template Tags with Airslate

Retrieves template tag records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/tags`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Template Tags](https://docs.airslate.io/docs/airslate-api/templates-api)
