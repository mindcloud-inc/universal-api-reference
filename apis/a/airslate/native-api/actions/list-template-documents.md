# List Template Documents with Airslate

Retrieves template document records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/documents`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Template Documents](https://docs.airslate.io/docs/airslate-api/templates-api/operations/list-organization-template-documents)
