# Create Template Copy with Airslate

Creates a copy of a template in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/copy`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Template Copy](https://docs.airslate.io/docs/airslate-api/templates-api/operations/create-a-organization-template-copy)
