# Update Template Step Jump with Airslate

Updates a template step jump in airSlate.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/step-jumps/{jump_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Update Template Step Jump](https://docs.airslate.io/docs/airslate-api/templates-api)
