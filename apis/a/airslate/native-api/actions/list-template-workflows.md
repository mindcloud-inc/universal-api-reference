# List Template Workflows with Airslate

Retrieves workflows for a template in airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/flows`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Template Workflows](https://docs.airslate.io/docs/airslate-api/flows-api)
