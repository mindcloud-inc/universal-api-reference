# Invite Workflow Recipients with Airslate

Invites recipients to a workflow in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/flows/{flow_id}/invite`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Invite Workflow Recipients](https://docs.airslate.io/docs/airslate-api/flows-api)
