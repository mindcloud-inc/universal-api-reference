# Create Organization Group with Airslate

Creates a new organization group in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/groups`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Organization Group](https://docs.airslate.io/docs/airslate-api/team-management-api)
