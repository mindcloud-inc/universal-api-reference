# Generate Template DOCX Document with Airslate

Creates a DOCX template document in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/documents`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Generate Template DOCX Document](https://docs.airslate.io/docs/airslate-api/docgen-api/operations/create-a-organization-template-document)
