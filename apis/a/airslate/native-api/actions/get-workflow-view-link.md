# Get Workflow View Link with Airslate

Retrieves a workflow view link from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/flows/{flow_id}/view`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Get Workflow View Link](https://docs.airslate.io/docs/airslate-api/flows-api)
