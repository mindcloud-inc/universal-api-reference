# Add Group Members with Airslate

Adds members to a group in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/groups/{group_id}/members`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Add Group Members](https://docs.airslate.io/docs/airslate-api/team-management-api)
