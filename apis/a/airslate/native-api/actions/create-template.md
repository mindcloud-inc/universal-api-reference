# Create Template with Airslate

Creates a new template in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Template](https://docs.airslate.io/docs/airslate-api/templates-api/operations/create-a-organization-template)
