# Upload Template Document with Airslate

Uploads a template document to airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/documents`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Upload Template Document](https://docs.airslate.io/docs/airslate-api/templates-api/operations/create-a-organization-template-document)
