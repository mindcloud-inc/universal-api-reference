# Get User Info with Airslate

Retrieves user profile details from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `https://oauth.airslate.com/public/userinfo`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Get User Info](https://docs.airslate.io/docs/airslate-api/authentication)
