# List Workflow Bot Logs with Airslate

Retrieves workflow bot logs from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/flows/{flow_id}/bot-logs`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Workflow Bot Logs](https://docs.airslate.io/docs/airslate-api/flows-api)
