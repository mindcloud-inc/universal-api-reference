# Create Workflow Batch with Airslate

Creates a workflow batch in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/flows/batch`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Workflow Batch](https://docs.airslate.io/docs/airslate-api/flows-api)
