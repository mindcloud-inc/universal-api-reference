# Update Organization Settings with Airslate

Updates existing organization settings in airSlate.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/organizations/{organization_id}/settings`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Update Organization Settings](https://docs.airslate.io/docs/airslate-api/organizations-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `string` | no | ID of the organization. |
