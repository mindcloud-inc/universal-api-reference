# Delete Template with Airslate

Deletes an existing template from airSlate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{organization_id}/templates/{template_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Delete Template](https://docs.airslate.io/docs/airslate-api/templates-api/operations/delete-a-organization-template)
