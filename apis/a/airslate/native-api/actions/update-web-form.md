# Update Web Form with Airslate

Updates a web form in airSlate.

## Endpoint

- **Method:** `PUT`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/forms/{form_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Update Web Form](https://docs.airslate.io/docs/airslate-api/forms-api)
