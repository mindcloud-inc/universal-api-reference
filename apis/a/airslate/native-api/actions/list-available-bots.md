# List Available Bots with Airslate

Retrieves available bot records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/bots`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Available Bots](https://docs.airslate.io/docs/airslate-api/bots-api)
