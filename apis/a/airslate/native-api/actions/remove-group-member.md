# Remove Group Member with Airslate

Removes a group member from airSlate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{organization_id}/groups/{group_id}/members/{user_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Remove Group Member](https://docs.airslate.io/docs/airslate-api/team-management-api)
