# Get Organization User by ID with Airslate

Retrieves an organization user by ID from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/users/{user_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Get Organization User by ID](https://docs.airslate.io/docs/airslate-api/team-management-api)
