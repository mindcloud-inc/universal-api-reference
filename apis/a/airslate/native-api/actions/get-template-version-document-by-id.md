# Get Template Version Document by ID with Airslate

Retrieves a template version document by ID from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/versions/{version_id}/documents/{document_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Get Template Version Document by ID](https://docs.airslate.io/docs/airslate-api/templates-api)
