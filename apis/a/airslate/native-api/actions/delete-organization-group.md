# Delete Organization Group with Airslate

Deletes an organization group from airSlate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{organization_id}/groups/{group_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Delete Organization Group](https://docs.airslate.io/docs/airslate-api/team-management-api)
