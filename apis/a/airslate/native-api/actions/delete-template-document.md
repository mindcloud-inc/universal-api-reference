# Delete Template Document with Airslate

Deletes a template document from airSlate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/documents/{document_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Delete Template Document](https://docs.airslate.io/docs/airslate-api/templates-api/operations/delete-a-organization-template-document)
