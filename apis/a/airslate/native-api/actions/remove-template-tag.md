# Remove Template Tag with Airslate

Removes a tag from a template in airSlate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/tags/{tag_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Remove Template Tag](https://docs.airslate.io/docs/airslate-api/templates-api)
