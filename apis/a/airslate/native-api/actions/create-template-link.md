# Create Template Link with Airslate

Creates a template link in airSlate.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/distribute`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Template Link](https://docs.airslate.io/docs/airslate-api/templates-api)
