# Create Template Version with Airslate

Creates a new template version in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/versions`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Template Version](https://docs.airslate.io/docs/airslate-api/templates-api)
