# Update Template Bot with Airslate

Updates a template bot in airSlate.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/bots/{template_bot_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Update Template Bot](https://docs.airslate.io/docs/airslate-api/bots-api)
