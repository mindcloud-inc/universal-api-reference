# List Template Bots with Airslate

Retrieves template bot records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/bots`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Template Bots](https://docs.airslate.io/docs/airslate-api/bots-api)
