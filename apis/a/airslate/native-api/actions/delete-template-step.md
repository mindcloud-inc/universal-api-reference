# Delete Template Step with Airslate

Deletes a template step from airSlate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/steps/{step_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Delete Template Step](https://docs.airslate.io/docs/airslate-api/templates-api)
