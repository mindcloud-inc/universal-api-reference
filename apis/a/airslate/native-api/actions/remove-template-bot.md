# Remove Template Bot with Airslate

Removes a template bot from airSlate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/bots/{template_bot_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Remove Template Bot](https://docs.airslate.io/docs/airslate-api/bots-api)
