# Delete Template Step Jump with Airslate

Deletes a template step jump from airSlate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/step-jumps/{jump_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Delete Template Step Jump](https://docs.airslate.io/docs/airslate-api/templates-api)
