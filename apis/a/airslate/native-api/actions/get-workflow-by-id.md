# Get Workflow by ID with Airslate

Retrieves a workflow by ID from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/flows/{flow_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Get Workflow by ID](https://docs.airslate.io/docs/airslate-api/flows-api)
