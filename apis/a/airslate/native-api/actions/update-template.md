# Update Template with Airslate

Updates an existing template in airSlate.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/organizations/{organization_id}/templates/{template_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Update Template](https://docs.airslate.io/docs/airslate-api/templates-api/operations/modify-a-organization-template)
