# Get Template by ID with Airslate

Retrieves a template by ID from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Get Template by ID](https://docs.airslate.io/docs/airslate-api/templates-api/operations/get-a-organization-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `string` | no | ID of the organization. |
| `template_id` | path | `string` | no | ID of the template. |
