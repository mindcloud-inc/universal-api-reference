# Get Organization Settings with Airslate

Retrieves organization settings details from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/settings`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Get Organization Settings](https://docs.airslate.io/docs/airslate-api/organizations-api)
