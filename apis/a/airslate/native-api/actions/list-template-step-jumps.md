# List Template Step Jumps with Airslate

Retrieves template step jumps from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/step-jumps`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Template Step Jumps](https://docs.airslate.io/docs/airslate-api/templates-api)
