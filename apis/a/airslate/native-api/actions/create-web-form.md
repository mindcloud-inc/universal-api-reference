# Create Web Form with Airslate

Creates a web form in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/forms`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Web Form](https://docs.airslate.io/docs/airslate-api/forms-api)
