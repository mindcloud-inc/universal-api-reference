# Add Web Form Field with Airslate

Adds a field to a web form in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/forms/{form_id}/fields`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Add Web Form Field](https://docs.airslate.io/docs/airslate-api/forms-api)
