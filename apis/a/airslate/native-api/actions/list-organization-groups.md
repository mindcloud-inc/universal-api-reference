# List Organization Groups with Airslate

Retrieves organization group records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/groups`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Organization Groups](https://docs.airslate.io/docs/airslate-api/team-management-api)
