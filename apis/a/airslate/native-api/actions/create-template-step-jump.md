# Create Template Step Jump with Airslate

Creates a template step jump in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/step-jumps`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Template Step Jump](https://docs.airslate.io/docs/airslate-api/templates-api)
