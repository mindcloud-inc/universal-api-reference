# Update Document Placeholder Form with Airslate

Updates a document placeholder form in airSlate.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/document-placeholders/{form_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Update Document Placeholder Form](https://docs.airslate.io/docs/airslate-api/document-placeholder-api)
