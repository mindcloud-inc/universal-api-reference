# Update Template Step with Airslate

Updates a template step in airSlate.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/steps/{step_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Update Template Step](https://docs.airslate.io/docs/airslate-api/templates-api)
