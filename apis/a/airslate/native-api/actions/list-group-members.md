# List Group Members with Airslate

Retrieves group member records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/groups/{group_id}/members`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Group Members](https://docs.airslate.io/docs/airslate-api/team-management-api)
