# Delete Webhook with Airslate

Deletes an existing webhook from airSlate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{organization_id}/webhooks/{webhook_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Delete Webhook](https://docs.airslate.io/docs/airslate-api/webhooks-api)
