# List Template Steps with Airslate

Retrieves template step records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/steps`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Template Steps](https://docs.airslate.io/docs/airslate-api/templates-api)
