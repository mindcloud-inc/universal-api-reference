# Rename Organization Group with Airslate

Renames an organization group in airSlate.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/organizations/{organization_id}/groups/{group_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Rename Organization Group](https://docs.airslate.io/docs/airslate-api/team-management-api)
