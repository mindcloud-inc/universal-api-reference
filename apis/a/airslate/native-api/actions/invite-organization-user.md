# Invite Organization User with Airslate

Invites a user to an organization in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/users/invite`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Invite Organization User](https://docs.airslate.io/docs/airslate-api/team-management-api)
