# Attach Template Bot with Airslate

Attaches a bot to a template in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/bots`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Attach Template Bot](https://docs.airslate.io/docs/airslate-api/bots-api)
