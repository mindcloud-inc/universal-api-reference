# Publish Template Version with Airslate

Publishes a template version in airSlate.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/versions/{version_id}/publish`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Publish Template Version](https://docs.airslate.io/docs/airslate-api/templates-api)
