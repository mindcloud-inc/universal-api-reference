# Get Template Document Assignments with Airslate

Retrieves template document assignments from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/documents/{document_id}/assignments`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Get Template Document Assignments](https://docs.airslate.io/docs/airslate-api/templates-api)
