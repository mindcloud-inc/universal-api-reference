# Add Template Tag with Airslate

Adds a tag to a template in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/tags`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Add Template Tag](https://docs.airslate.io/docs/airslate-api/templates-api)
