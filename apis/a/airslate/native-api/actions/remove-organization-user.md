# Remove Organization User with Airslate

Removes an organization user from airSlate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{organization_id}/users/{user_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Remove Organization User](https://docs.airslate.io/docs/airslate-api/team-management-api)
