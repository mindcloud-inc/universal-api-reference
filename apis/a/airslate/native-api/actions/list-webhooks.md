# List Webhooks with Airslate

Retrieves all webhook records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/webhooks`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Webhooks](https://docs.airslate.io/docs/airslate-api/webhooks-api)
