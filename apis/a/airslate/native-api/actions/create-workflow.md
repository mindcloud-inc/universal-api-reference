# Create Workflow with Airslate

Creates a new workflow in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/flows`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Workflow](https://docs.airslate.io/docs/airslate-api/flows-api)
