# Create Template Step with Airslate

Creates a new template step in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/steps`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Template Step](https://docs.airslate.io/docs/airslate-api/templates-api)
