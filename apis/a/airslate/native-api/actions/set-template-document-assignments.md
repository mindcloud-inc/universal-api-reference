# Set Template Document Assignments with Airslate

Sets template document assignments in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/documents/{document_id}/assignments`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Set Template Document Assignments](https://docs.airslate.io/docs/airslate-api/templates-api)
