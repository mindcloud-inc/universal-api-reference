# List Template Version Documents with Airslate

Retrieves template version documents from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/versions/{version_id}/documents`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Template Version Documents](https://docs.airslate.io/docs/airslate-api/templates-api/operations/list-organization-template-version-documents)
