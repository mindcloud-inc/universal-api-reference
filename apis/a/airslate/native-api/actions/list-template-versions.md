# List Template Versions with Airslate

Retrieves template version records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/versions`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Template Versions](https://docs.airslate.io/docs/airslate-api/templates-api)
