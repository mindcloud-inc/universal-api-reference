# Update Organization User with Airslate

Updates an organization user in airSlate.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/organizations/{organization_id}/users/{user_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Update Organization User](https://docs.airslate.io/docs/airslate-api/team-management-api)
