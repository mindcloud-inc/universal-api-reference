# List Organizations with Airslate

Retrieves all organization records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Organizations](https://docs.airslate.io/docs/airslate-api/organizations-api/operations/list-organizations)
