# List Templates with Airslate

Retrieves templates from an airSlate organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Templates](https://docs.airslate.io/docs/airslate-api/templates-api/operations/list-organization-templates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `string` | no | ID of the organization. |
