# Prefill Template Document with Airslate

Prefills a template document in airSlate.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/documents/{document_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Prefill Template Document](https://docs.airslate.io/docs/airslate-api/templates-api/operations/modify-a-organization-template-document)
