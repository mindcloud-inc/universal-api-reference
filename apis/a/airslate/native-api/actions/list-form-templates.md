# List Form Templates with Airslate

Retrieves form template records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/forms/templates`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Form Templates](https://docs.airslate.io/docs/airslate-api/forms-api)
