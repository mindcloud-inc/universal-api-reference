# Get Web Form Field by ID with Airslate

Retrieves a web form field by ID from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/forms/{form_id}/fields/{field_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Get Web Form Field by ID](https://docs.airslate.io/docs/airslate-api/forms-api)
