# Get Webhook by ID with Airslate

Retrieves a webhook by ID from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/webhooks/{webhook_id}`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Get Webhook by ID](https://docs.airslate.io/docs/airslate-api/webhooks-api)
