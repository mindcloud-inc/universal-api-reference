# List Organization Users with Airslate

Retrieves organization user records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/users`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Organization Users](https://docs.airslate.io/docs/airslate-api/team-management-api)
