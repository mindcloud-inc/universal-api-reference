# Create Workflow Link with Airslate

Creates a workflow link in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/flows/{flow_id}/share`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Workflow Link](https://docs.airslate.io/docs/airslate-api/flows-api)
