# List Template Version Steps with Airslate

Retrieves template version steps from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/versions/{version_id}/steps`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Template Version Steps](https://docs.airslate.io/docs/airslate-api/templates-api)
