# List Workflow Anonymous Links with Airslate

Retrieves anonymous workflow links from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/flows/{flow_id}/links`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Workflow Anonymous Links](https://docs.airslate.io/docs/airslate-api/flows-api)
