# List Workflow Documents with Airslate

Retrieves workflow document records from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/flows/{flow_id}/documents`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [List Workflow Documents](https://docs.airslate.io/docs/airslate-api/flows-api)
