# Download Workflow Documents with Airslate

Downloads workflow document files from airSlate.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/flows/{flow_id}/download`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Download Workflow Documents](https://docs.airslate.io/docs/airslate-api/flows-api)
