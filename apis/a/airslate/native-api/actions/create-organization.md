# Create Organization with Airslate

Creates a new organization in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Organization](https://docs.airslate.io/docs/airslate-api/organizations-api/operations/create-a-organization)
