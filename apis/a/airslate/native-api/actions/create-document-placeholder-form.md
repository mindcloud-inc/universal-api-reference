# Create Document Placeholder Form with Airslate

Creates a document placeholder form in airSlate.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{organization_id}/templates/{template_id}/document-placeholders`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Create Document Placeholder Form](https://docs.airslate.io/docs/airslate-api/document-placeholder-api)
