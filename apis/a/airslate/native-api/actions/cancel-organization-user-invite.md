# Cancel Organization User Invite with Airslate

Cancels an organization user invite in airSlate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{organization_id}/users/{user_id}/reject-invite`
- **Base URL:** `https://api.airslate.io/v1`
- **Official documentation:** [Cancel Organization User Invite](https://docs.airslate.io/docs/airslate-api/team-management-api)
