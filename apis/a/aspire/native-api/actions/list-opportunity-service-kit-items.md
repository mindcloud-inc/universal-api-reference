# List Opportunity Service Kit Items with Aspire

Retrieves opportunity service kit items from your Aspire account.

## Endpoint

- **Method:** `GET`
- **Path:** `OpportunityServiceKitItems`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [List Opportunity Service Kit Items](https://cloud-api.youraspire.com/swagger/index.html#/OpportunityServiceKitItems/OpportunityServiceKitItems_Get)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `$filter` | query | `string` | no |
