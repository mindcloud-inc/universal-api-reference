# List Opportunity Tags Assignments with Aspire

Retrieves opportunity tags from your Aspire account.

## Endpoint

- **Method:** `GET`
- **Path:** `OpportunityTags`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [List Opportunity Tags Assignments](https://cloud-api.youraspire.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `$filter` | query | `string` | no |
