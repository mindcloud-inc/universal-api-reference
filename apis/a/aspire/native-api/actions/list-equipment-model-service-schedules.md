# List Equipment Model Service Schedules with Aspire

Retrieves equipment model service schedules from your Aspire account.

## Endpoint

- **Method:** `GET`
- **Path:** `EquipmentModelServiceSchedules`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [List Equipment Model Service Schedules](https://cloud-api.youraspire.com/swagger/index.html#/EquipmentModelServiceSchedules/EquipmentModelServiceSchedules_Get)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
