# List Work Ticket Times with Aspire

Start and end time for a crew member during a visit for a work ticket.

## Endpoint

- **Method:** `GET`
- **Path:** `WorkTicketTimes`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [List Work Ticket Times](https://guide.youraspire.com/apidocs/worktickettimes-4)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).

| `$filter` | query | `string` | no |
| `$orderby` | query | `string` | no |
