# List Division Integration Codes with Aspire

Retrieves division integration codes from your Aspire account.

## Endpoint

- **Method:** `GET`
- **Path:** `DivisionIntegrationCodes`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [List Division Integration Codes](https://cloud-api.youraspire.com/swagger/index.html#/DivisionIntegrationCodes/DivisionIntegrationCodes_Get)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `$expand` | query | `string` | no |
| `$filter` | query | `string` | no |
| `$orderby` | query | `string` | no |
| `$select` | query | `string` | no |
