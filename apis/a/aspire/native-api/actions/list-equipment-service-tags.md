# List Equipment Service Tags with Aspire

Retrieves equipment service tags from your Aspire account.

## Endpoint

- **Method:** `GET`
- **Path:** `EquipmentServiceTags`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [List Equipment Service Tags](https://cloud-api.youraspire.com/swagger/index.html#/EquipmentServiceTags/EquipmentServiceTags_Get)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).

| Parameter | Location | Type | Required |

| `$filter` | query | `string` | no |
| `$orderby` | query | `string` | no |
