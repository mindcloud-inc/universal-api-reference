# Delete Opportunity Tag with Aspire

Deletes an existing opportunity tag from your Aspire account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `OpportunityTags/:id`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [Delete Opportunity Tag](https://cloud-api.youraspire.com/swagger/index.html#/OpportunityTags/OpportunityTags_Delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
