# List Work Ticket Revenues with Aspire

Total income generated within a work ticket.

## Endpoint

- **Method:** `GET`
- **Path:** `WorkTicketRevenues`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [List Work Ticket Revenues](https://guide.youraspire.com/apidocs/workticketrevenues-3)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
