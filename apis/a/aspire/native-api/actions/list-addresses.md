# List Addresses with Aspire

## Endpoint

- **Method:** `GET`
- **Path:** `Addresses`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [List Addresses](https://cloud-api.youraspire.com/swagger/v1/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
