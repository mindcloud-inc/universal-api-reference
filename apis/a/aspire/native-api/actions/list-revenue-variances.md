# List Revenue Variances with Aspire

Retrieves revenue variances from your Aspire account.

## Endpoint

- **Method:** `GET`
- **Path:** `RevenueVariances`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [List Revenue Variances](https://cloud-api.youraspire.com/swagger/index.html#/RevenueVariances/RevenueVariances_Get)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).

| Parameter | Location | Type | Required |

| `$filter` | query | `string` | no |
| `$orderby` | query | `string` | no |
