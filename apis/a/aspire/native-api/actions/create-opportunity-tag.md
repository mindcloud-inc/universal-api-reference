# Create Opportunity Tag with Aspire

Creates a new opportunity tag in your Aspire account.

## Endpoint

- **Method:** `POST`
- **Path:** `OpportunityTags`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [Create Opportunity Tag](https://cloud-api.youraspire.com/swagger/index.html#/OpportunityTags/OpportunityTags_Create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `OpportunityID` | body | `number` | yes |
| `TagID` | body | `number` | yes |
