# Get API Version with Aspire

Retrieves the current API version from Aspire.

## Endpoint

- **Method:** `GET`
- **Path:** `Version/GetApiVersion`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [Get API Version](https://cloud-api.youraspire.com/swagger/index.html#/Version/Version_GetApiVersion)
