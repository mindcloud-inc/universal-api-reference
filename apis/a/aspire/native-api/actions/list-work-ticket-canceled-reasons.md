# List Work Ticket Canceled Reasons with Aspire

Retrieves work ticket canceled reasons from your Aspire account.

- **Path:** `WorkTicketCanceledReasons`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [List Work Ticket Canceled Reasons](https://cloud-api.youraspire.com/swagger/index.html#/WorkTicketCanceledReasons/WorkTicketCanceledReasons_Get)
