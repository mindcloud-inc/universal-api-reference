# List Employee Incident Types with Aspire

Retrieves employee incident types from your Aspire account.

## Endpoint

- **Method:** `GET`
- **Path:** `EmployeeIncidentTypes`
- **Base URL:** `https://{environment}.youraspire.com/`
- **Official documentation:** [List Employee Incident Types](https://cloud-api.youraspire.com/swagger/index.html#/EmployeeIncidentTypes/EmployeeIncidentTypes_Get)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
