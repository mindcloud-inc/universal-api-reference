# Delete Presentation with Alai

Permanently deletes a presentation from Alai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/presentations/:presentation_id`
- **Base URL:** `https://slides-api.getalai.com/api/v1`
- **Official documentation:** [Delete Presentation](https://docs.getalai.com/api/delete-presentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `presentation_id` | path | `string` | yes | Presentation identifier to delete. |
