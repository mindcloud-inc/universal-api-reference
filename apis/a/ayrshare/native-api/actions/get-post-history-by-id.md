# Get Post History By ID with Ayrshare

Retrieves post history by ID from Ayrshare.

## Endpoint

- **Method:** `GET`
- **Path:** `/history/:id`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Get Post History By ID](https://www.ayrshare.com/docs/apis/history/get-history-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Ayrshare Post ID to retrieve from post history. |
