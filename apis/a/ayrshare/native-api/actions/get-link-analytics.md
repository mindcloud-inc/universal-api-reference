# Get Link Analytics with Ayrshare

Retrieves short link analytics from Ayrshare.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/:id`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Get Link Analytics](https://www.ayrshare.com/docs/apis/links/link-analytics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Ayrshare short link ID to retrieve analytics for. |
