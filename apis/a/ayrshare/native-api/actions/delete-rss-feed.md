# Delete RSS Feed with Ayrshare

Deletes an RSS feed from Ayrshare.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/feed`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Delete RSS Feed](https://www.ayrshare.com/docs/apis/feeds/delete-feed)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Ayrshare RSS feed ID to delete. |
