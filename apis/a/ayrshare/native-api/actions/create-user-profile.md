# Create User Profile with Ayrshare

Creates a new user profile in Ayrshare.

## Endpoint

- **Method:** `POST`
- **Path:** `/profiles`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Create User Profile](https://www.ayrshare.com/docs/apis/profiles/create-profile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Title for the Ayrshare user profile. |
