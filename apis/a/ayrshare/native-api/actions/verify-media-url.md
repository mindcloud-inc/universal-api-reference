# Verify Media URL with Ayrshare

Verifies a media URL in Ayrshare.

## Endpoint

- **Method:** `POST`
- **Path:** `/media/urlExists`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Verify Media URL](https://www.ayrshare.com/docs/apis/media/verify-media-url)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | HTTPS media URL to verify. |
