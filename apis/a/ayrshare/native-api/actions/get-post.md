# Get Post with Ayrshare

Retrieves a post by Ayrshare post ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/post/:id`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Get Post](https://www.ayrshare.com/docs/apis/post/get-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Ayrshare Post ID returned by the publish post endpoint. |
