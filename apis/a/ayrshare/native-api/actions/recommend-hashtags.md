# Recommend Hashtags with Ayrshare

Finds hashtag suggestions by keyword in Ayrshare.

## Endpoint

- **Method:** `GET`
- **Path:** `/hashtags/recommend`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Recommend Hashtags](https://www.ayrshare.com/docs/apis/hashtags/recommend-hashtags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyword` | query | `string` | yes | Single keyword to get recommended hashtags from TikTok. |
