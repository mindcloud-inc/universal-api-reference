# Rewrite Post with Ayrshare

Generates post rewrites with AI in Ayrshare.

## Endpoint

- **Method:** `POST`
- **Path:** `/generate/rewrite`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Rewrite Post](https://www.ayrshare.com/docs/apis/generate/rewrite-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `post` | body | `string` | yes | Post text to rewrite into variations. |
