# Generate Post Text with Ayrshare

Generates a social post with AI in Ayrshare.

## Endpoint

- **Method:** `POST`
- **Path:** `/generate/post`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Generate Post Text](https://www.ayrshare.com/docs/apis/generate/post-text)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | body | `string` | yes | Description of what the generated social post should be about. |
