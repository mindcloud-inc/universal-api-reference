# Create Short Link with Ayrshare

Creates a short link in Ayrshare.

## Endpoint

- **Method:** `POST`
- **Path:** `/links`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Create Short Link](https://www.ayrshare.com/docs/apis/links/create-short-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Destination URL to shorten. |
