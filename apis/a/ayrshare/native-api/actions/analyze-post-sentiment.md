# Analyze Post Sentiment with Ayrshare

Analyzes sentiment for a post or comment in Ayrshare.

## Endpoint

- **Method:** `POST`
- **Path:** `/generate/sentiment`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Analyze Post Sentiment](https://www.ayrshare.com/docs/apis/generate/sentiment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | body | `string` | yes | Text to analyze for sentiment. |
