# Delete Post with Ayrshare

Deletes a post from Ayrshare.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/post`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Delete Post](https://www.ayrshare.com/docs/apis/post/delete-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Ayrshare post ID to delete. |
