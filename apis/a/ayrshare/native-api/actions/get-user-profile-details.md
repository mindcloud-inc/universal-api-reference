# Get User Profile Details with Ayrshare

Retrieves user profile details from Ayrshare.

## Endpoint

- **Method:** `GET`
- **Path:** `/user`
- **Base URL:** `https://api.ayrshare.com/api`
- **Official documentation:** [Get User Profile Details](https://www.ayrshare.com/docs/apis/user/profile-details)
