# List Supported Countries with Address Auto-Complete by Fetchify

Retrieves supported address countries from Fetchify.

## Endpoint

- **Method:** `GET`
- **Path:** `/countries`
- **Base URL:** `https://api.craftyclicks.co.uk/address/1.1`
- **Official documentation:** [List Supported Countries](https://docs.fetchify.com/json-api/address-auto-complete.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `language` | query | `string` | no | Optional response language for country names. |
