# Update Whitelabel with Adrapid

Updates existing whitelabel settings in Adrapid.

## Endpoint

- **Method:** `PUT`
- **Path:** `/whitelabel/:id`
- **Base URL:** `https://api.adrapid.com/v1/api`
- **Official documentation:** [Update Whitelabel](https://docs.adrapid.com/enterprise/administrative-api)
