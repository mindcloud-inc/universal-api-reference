# Generate User SSO Token with Adrapid

Generates an SSO login token for a user in Adrapid.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/sso`
- **Base URL:** `https://api.adrapid.com/v1/api`
- **Official documentation:** [Generate User SSO Token](https://docs.adrapid.com/enterprise/administrative-api)
