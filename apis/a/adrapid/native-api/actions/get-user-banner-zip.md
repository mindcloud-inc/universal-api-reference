# Get User Banner Zip with Adrapid

Retrieves a ZIP download URL for a user banner in Adrapid.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/banners/:id/zip`
- **Base URL:** `https://api.adrapid.com/v1/api`
- **Official documentation:** [Get User Banner Zip](https://docs.adrapid.com/api/overview)
