# Import User Template with Adrapid

Imports a template for a user in Adrapid.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/:userId/templates/import`
- **Base URL:** `https://api.adrapid.com/v1/api`
- **Official documentation:** [Import User Template](https://docs.adrapid.com/enterprise/administrative-api)
