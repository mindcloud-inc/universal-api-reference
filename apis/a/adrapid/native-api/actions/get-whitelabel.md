# Get Whitelabel with Adrapid

Retrieves current whitelabel settings from Adrapid.

## Endpoint

- **Method:** `GET`
- **Path:** `/whitelabel`
- **Base URL:** `https://api.adrapid.com/v1/api`
- **Official documentation:** [Get Whitelabel](https://docs.adrapid.com/enterprise/whitelabel/administration-panel)
