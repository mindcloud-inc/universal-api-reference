# Delete User Template with Adrapid

Deletes an existing user template from Adrapid.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:userId/templates/:id`
- **Base URL:** `https://api.adrapid.com/v1/api`
- **Official documentation:** [Delete User Template](https://docs.adrapid.com/enterprise/administrative-api)
