# Refresh User Access Token with Adrapid

Refreshes a user's access token in Adrapid.

## Endpoint

- **Method:** `PUT`
- **Path:** `/users/:userId/token`
- **Base URL:** `https://api.adrapid.com/v1/api`
- **Official documentation:** [Refresh User Access Token](https://docs.adrapid.com/enterprise/administrative-api)
