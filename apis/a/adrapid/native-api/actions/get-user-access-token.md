# Get User Access Token with Adrapid

Retrieves a user access token from Adrapid.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/token`
- **Base URL:** `https://api.adrapid.com/v1/api`
- **Official documentation:** [Get User Access Token](https://docs.adrapid.com/enterprise/administrative-api)
