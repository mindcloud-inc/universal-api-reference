# Delete User Image with Adrapid

Deletes an existing user image from Adrapid.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:userId/images/:id`
- **Base URL:** `https://api.adrapid.com/v1/api`
- **Official documentation:** [Delete User Image](https://docs.adrapid.com/enterprise/administrative-api)
