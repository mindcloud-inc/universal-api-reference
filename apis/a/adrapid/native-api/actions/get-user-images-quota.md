# Get User Images Quota with Adrapid

Retrieves image quota for a user in Adrapid.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/images/quota`
- **Base URL:** `https://api.adrapid.com/v1/api`
- **Official documentation:** [Get User Images Quota](https://docs.adrapid.com/enterprise/administrative-api)
