# Get User Access URL with Adrapid

Retrieves editor access URLs for a user in Adrapid.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/access`
- **Base URL:** `https://api.adrapid.com/v1/api`
- **Official documentation:** [Get User Access URL](https://docs.adrapid.com/enterprise/whitelabel/widget)
