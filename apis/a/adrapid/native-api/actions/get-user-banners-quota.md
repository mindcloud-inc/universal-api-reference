# Get User Banners Quota with Adrapid

Retrieves banner quota for a user in Adrapid.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/banners/quota`
- **Base URL:** `https://api.adrapid.com/v1/api`
- **Official documentation:** [Get User Banners Quota](https://docs.adrapid.com/api/overview)
