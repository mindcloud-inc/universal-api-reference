# Get Organization User with Astra

Retrieves one organization user from Astra.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/organizations/users/:userId`
- **Base URL:** `https://api.astra.datastax.com`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The Astra organization user ID. |
