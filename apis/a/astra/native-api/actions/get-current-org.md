# Get Current Org with Astra

Retrieves the current organization from Astra.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/currentOrg`
- **Base URL:** `https://api.astra.datastax.com`
- **Official documentation:** [Get Current Org](https://docs.datastax.com/en/astra-api-docs/_attachments/devops-api/index.html#tag/Organization-Operations/operation/getCurrentOrg)
