# Delete Glossary with Amberscript

Deletes an existing glossary from Amberscript.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/glossary/:glossaryId`
- **Base URL:** `https://api.amberscript.com/api`
- **Official documentation:** [Delete Glossary](https://amberscript.github.io/api-docs/#delete-a-glossary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `glossaryId` | path | `string` | yes | Glossary to delete. |
