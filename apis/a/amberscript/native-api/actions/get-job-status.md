# Get Job Status with Amberscript

Retrieves the status of an Amberscript job.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/status`
- **Base URL:** `https://api.amberscript.com/api`
- **Official documentation:** [Get Job Status](https://amberscript.github.io/api-docs/#getting-the-status-of-a-transcription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | query | `string` | yes | The job to inspect. |
