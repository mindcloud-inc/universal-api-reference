# Delete Job with Amberscript

Deletes an existing job from Amberscript.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/jobs`
- **Base URL:** `https://api.amberscript.com/api`
- **Official documentation:** [Delete Job](https://amberscript.github.io/api-docs/#delete-a-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | query | `string` | yes | The job to delete. |
