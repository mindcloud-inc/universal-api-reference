# List Glossaries with Amberscript

Retrieves glossaries from your Amberscript account.

## Endpoint

- **Method:** `GET`
- **Path:** `/glossary`
- **Base URL:** `https://api.amberscript.com/api`
- **Official documentation:** [List Glossaries](https://amberscript.github.io/api-docs/#get-a-list-of-glossaries)

## Capabilities

This operation supports [sorting](../README.md#sorting).
