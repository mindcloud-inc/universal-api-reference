# Enrich Company with Anyleads

Retrieves enriched company data from Anyleads.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-product/incoming-webhook/enrich-company`
- **Base URL:** `https://myapiconnect.com`
- **Official documentation:** [Enrich Company](https://docs.anyleads.com/product/en/enrichment-data-software-to-find-emails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | yes | Domain to enrich. |
