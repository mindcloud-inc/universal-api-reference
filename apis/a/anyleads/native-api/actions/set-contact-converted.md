# Set Contact Converted with Anyleads

Updates a contact as converted in Anyleads.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-product/incoming-webhook/set-contact-converted`
- **Base URL:** `https://myapiconnect.com`
- **Official documentation:** [Set Contact Converted](https://docs.anyleads.com/product/en/sequence-cadence-newsletter-campaigns-tool)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Contact email used to mark the contact as converted. |
