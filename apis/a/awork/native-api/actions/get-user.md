# Get User with Awork

Retrieves a user from Awork.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://api.awork.com/api/v1`
- **Official documentation:** [Get User](https://developers.awork.com/apiv1/users/get-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The id of the user. |
