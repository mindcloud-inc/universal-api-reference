# Get Task with Awork

Retrieves a task from Awork.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:taskId`
- **Base URL:** `https://api.awork.com/api/v1`
- **Official documentation:** [Get Task](https://developers.awork.com/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | The id of the task. |
