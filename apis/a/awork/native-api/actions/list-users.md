# List Users with Awork

Retrieves users from Awork.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.awork.com/api/v1`
- **Official documentation:** [List Users](https://developers.awork.com/apiv1/users/get-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `showArchived` | query | `boolean` | no | Whether to include archived users. |
