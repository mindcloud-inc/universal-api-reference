# List Time Entries with Awork

Retrieves time entries from Awork.

## Endpoint

- **Method:** `GET`
- **Path:** `/timeentries`
- **Base URL:** `https://api.awork.com/api/v1`
- **Official documentation:** [List Time Entries](https://developers.awork.com/apiv1/time-entries/get-time-entries)

## Capabilities

This operation supports [pagination](../README.md#pagination).
