# Get Document with Awork

Retrieves a document from Awork.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentId`
- **Base URL:** `https://api.awork.com/api/v1`
- **Official documentation:** [Get Document](https://developers.awork.com/apiv1/documents/get-document-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The id of the document. |
