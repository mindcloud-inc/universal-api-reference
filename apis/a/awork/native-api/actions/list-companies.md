# List Companies with Awork

Retrieves companies from Awork.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies`
- **Base URL:** `https://api.awork.com/api/v1`
- **Official documentation:** [List Companies](https://developers.awork.com/apiv1/companies/get-companies)

## Capabilities

This operation supports [pagination](../README.md#pagination).
