# Get Company with Awork

Retrieves a company from Awork.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:companyId`
- **Base URL:** `https://api.awork.com/api/v1`
- **Official documentation:** [Get Company](https://developers.awork.com/companies)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | The id of the company. |
