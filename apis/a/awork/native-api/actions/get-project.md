# Get Project with Awork

Retrieves a project from Awork.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://api.awork.com/api/v1`
- **Official documentation:** [Get Project](https://developers.awork.com/apiv1/projects/returns-the-project-with-the-specified-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The id of the project. |
