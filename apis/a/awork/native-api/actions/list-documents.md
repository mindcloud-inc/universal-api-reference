# List Documents with Awork

Retrieves documents from Awork.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents`
- **Base URL:** `https://api.awork.com/api/v1`
- **Official documentation:** [List Documents](https://developers.awork.com/apiv1/documents/returns-all-documents)

## Capabilities

This operation supports [pagination](../README.md#pagination).
