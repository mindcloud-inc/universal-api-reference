# List Projects with Awork

Retrieves projects from Awork.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.awork.com/api/v1`
- **Official documentation:** [List Projects](https://developers.awork.com/apiv1/projects/returns-all-projects)

## Capabilities

This operation supports [pagination](../README.md#pagination).
