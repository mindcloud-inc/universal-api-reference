# List Deal Stages with ActiveCampaign

Retrieves deal stages from ActiveCampaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/dealStages`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [List Deal Stages](https://developers.activecampaign.com/reference/list-all-deal-stages)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
