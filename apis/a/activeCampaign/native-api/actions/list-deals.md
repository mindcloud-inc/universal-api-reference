# List Deals with ActiveCampaign

Retrieves deals from ActiveCampaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/deals`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [List Deals](https://developers.activecampaign.com/reference/list-all-deals)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
