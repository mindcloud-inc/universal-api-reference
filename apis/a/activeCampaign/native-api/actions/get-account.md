# Get Account with ActiveCampaign

Retrieves an account from ActiveCampaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:id`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [Get Account](https://developers.activecampaign.com/reference/retrieve-an-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The account ID. |
