# Delete List with ActiveCampaign

Deletes an existing list from ActiveCampaign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/:id`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [Delete List](https://developers.activecampaign.com/reference/delete-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The list ID. |
