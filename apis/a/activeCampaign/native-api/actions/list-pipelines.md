# List Pipelines with ActiveCampaign

Retrieves pipelines from ActiveCampaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/dealGroups`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [List Pipelines](https://developers.activecampaign.com/reference/list-all-pipelines)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
