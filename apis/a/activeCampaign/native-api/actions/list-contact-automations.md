# List Contact Automations with ActiveCampaign

Retrieves contact automations from ActiveCampaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/contactAutomations`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [List Contact Automations](https://developers.activecampaign.com/reference/list-all-contact-automations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
