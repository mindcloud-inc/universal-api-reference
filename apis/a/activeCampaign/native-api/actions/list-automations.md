# List Automations with ActiveCampaign

Retrieves automations from ActiveCampaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/automations`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [List Automations](https://developers.activecampaign.com/reference/list-all-automations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
