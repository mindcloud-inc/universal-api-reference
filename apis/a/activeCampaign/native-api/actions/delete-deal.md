# Delete Deal with ActiveCampaign

Deletes an existing deal from ActiveCampaign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deals/:id`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [Delete Deal](https://developers.activecampaign.com/reference/delete-a-deal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The deal ID. |
