# Remove Tag From Contact with ActiveCampaign

Removes a tag from a contact in ActiveCampaign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contactTags/:id`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [Remove Tag From Contact](https://developers.activecampaign.com/reference/remove-a-contacts-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The contact tag ID. |
