# Get List with ActiveCampaign

Retrieves a list from ActiveCampaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:id`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [Get List](https://developers.activecampaign.com/reference/retrieve-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The list ID. |
