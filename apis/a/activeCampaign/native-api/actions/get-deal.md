# Get Deal with ActiveCampaign

Retrieves a deal from ActiveCampaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/deals/:id`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [Get Deal](https://developers.activecampaign.com/reference/retrieve-a-deal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The deal ID. |
