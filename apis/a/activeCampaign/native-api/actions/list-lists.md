# List Lists with ActiveCampaign

Retrieves lists from ActiveCampaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [List Lists](https://developers.activecampaign.com/reference/retrieve-all-lists)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
