# Delete Contact with ActiveCampaign

Deletes an existing contact from ActiveCampaign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [Delete Contact](https://developers.activecampaign.com/reference/delete-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The contact ID. |
