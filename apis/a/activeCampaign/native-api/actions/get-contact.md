# Get Contact with ActiveCampaign

Retrieves a contact from ActiveCampaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [Get Contact](https://developers.activecampaign.com/reference/get-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The contact ID. |
