# List Custom Field Values with ActiveCampaign

Retrieves custom field values from ActiveCampaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/fieldValues`
- **Base URL:** `{apiUrl}/api/3`
- **Official documentation:** [List Custom Field Values](https://developers.activecampaign.com/reference/list-all-custom-field-values)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
