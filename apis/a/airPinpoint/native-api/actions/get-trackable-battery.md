# Get Trackable Battery with AirPinpoint

Retrieves battery status for a trackable in AirPinpoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/trackables/{trackableId}/battery`
- **Base URL:** `https://api.airpinpoint.com/v1`
- **Official documentation:** [Get Trackable Battery](https://airpinpoint.com/docs/trackables)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `trackableId` | path | `string` | yes |
