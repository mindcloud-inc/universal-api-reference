# Get Trackable with AirPinpoint

Retrieves details for a trackable in AirPinpoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/trackables/{trackableId}`
- **Base URL:** `https://api.airpinpoint.com/v1`
- **Official documentation:** [Get Trackable](https://airpinpoint.com/docs/trackables)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `trackableId` | path | `string` | yes |
