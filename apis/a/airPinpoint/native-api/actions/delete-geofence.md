# Delete Geofence with AirPinpoint

Deletes an existing geofence from AirPinpoint.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/geofences/{geofence_id}`
- **Base URL:** `https://api.airpinpoint.com/v1`
- **Official documentation:** [Delete Geofence](https://airpinpoint.com/docs/geofences)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `geofence_id` | path | `string` | yes |
