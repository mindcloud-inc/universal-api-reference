# Delete Claim Status Inquiry with Availity

Deletes a claim status inquiry from Availity.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/availity/v1/claim-statuses/{id}`
- **Base URL:** `https://api.availity.com`
- **Official documentation:** [Delete Claim Status Inquiry](https://developer.availity.com/blog/2025/3/25/hipaa-transactions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique response ID for the claim status inquiry to delete. |
