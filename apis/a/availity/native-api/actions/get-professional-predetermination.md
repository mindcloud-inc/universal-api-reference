# Get Professional Predetermination with Availity

Retrieves a professional predetermination from Availity.

## Endpoint

- **Method:** `GET`
- **Path:** `/availity/v1/professional-claims/{id}`
- **Base URL:** `https://api.availity.com`
- **Official documentation:** [Get Professional Predetermination](https://developer.availity.com/blog/2025/3/25/hipaa-transactions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique response ID from the initial professional predetermination request. |
