# Get Professional Cost Estimate with Availity

Retrieves a professional cost estimate from Availity.

## Endpoint

- **Method:** `GET`
- **Path:** `/availity/v2/patient-cost-estimates/prof/{id}`
- **Base URL:** `https://api.availity.com`
- **Official documentation:** [Get Professional Cost Estimate](https://developer.availity.com/blog/2025/3/25/hipaa-transactions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique response ID from the initial PCE 2.0 professional cost estimate request. |
