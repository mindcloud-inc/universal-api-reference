# Delete Coverage Inquiry with Availity

Deletes a coverage inquiry from Availity.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/coverages/{id}`
- **Base URL:** `https://api.availity.com`
- **Official documentation:** [Delete Coverage Inquiry](https://developer.availity.com/blog/2025/3/25/hipaa-transactions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique response ID for the coverage inquiry to delete. |
