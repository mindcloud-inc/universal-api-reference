# Get Coverage Inquiry with Availity

Retrieves a coverage inquiry from Availity.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/coverages/{id}`
- **Base URL:** `https://api.availity.com`
- **Official documentation:** [Get Coverage Inquiry](https://developer.availity.com/blog/2025/3/25/hipaa-transactions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique response ID from the initial coverage inquiry request. |
