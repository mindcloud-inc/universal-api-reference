# Get Institutional Predetermination with Availity

Retrieves an institutional predetermination from Availity.

## Endpoint

- **Method:** `GET`
- **Path:** `/availity/v1/institutional-claims/{id}`
- **Base URL:** `https://api.availity.com`
- **Official documentation:** [Get Institutional Predetermination](https://developer.availity.com/blog/2025/3/25/hipaa-transactions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique response ID from the initial institutional predetermination request. |
