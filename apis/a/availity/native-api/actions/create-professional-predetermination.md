# Create Professional Predetermination with Availity

Creates a professional predetermination in Availity.

## Endpoint

- **Method:** `POST`
- **Path:** `/availity/v1/professional-claims`
- **Base URL:** `https://api.availity.com`
- **Official documentation:** [Create Professional Predetermination](https://developer.availity.com/blog/2025/3/25/hipaa-transactions)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `professionalClaim` | body | `object` | no | PCE 1.0 professional claim predetermination request body. |
