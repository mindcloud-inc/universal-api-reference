# Get Top Users with Audius

Retrieves top users from Audius.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/top`
- **Base URL:** `https://api.audius.co/v1`
- **Official documentation:** [Get Top Users](https://api.audius.co/v1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | query | `number` | no |
| `offset` | query | `number` | no |
