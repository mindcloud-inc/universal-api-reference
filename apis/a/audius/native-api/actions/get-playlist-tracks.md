# Get Playlist Tracks with Audius

Retrieves tracks in an Audius playlist.

## Endpoint

- **Method:** `GET`
- **Path:** `/playlists/:playlist_id/tracks`
- **Base URL:** `https://api.audius.co/v1`
- **Official documentation:** [Get Playlist Tracks](https://api.audius.co/v1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `playlist_id` | path | `string` | yes |
