# Get Trending Tracks with Audius

Retrieves trending tracks from Audius.

## Endpoint

- **Method:** `GET`
- **Path:** `/tracks/trending`
- **Base URL:** `https://api.audius.co/v1`
- **Official documentation:** [Get Trending Tracks](https://api.audius.co/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | The number of items to fetch. |
