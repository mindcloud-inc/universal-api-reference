# Get Track with Audius

Retrieves a track from Audius by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tracks/:track_id`
- **Base URL:** `https://api.audius.co/v1`
- **Official documentation:** [Get Track](https://api.audius.co/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `track_id` | path | `string` | yes | A Track ID. |
