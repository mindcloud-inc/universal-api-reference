# Get User by Handle with Audius

Retrieves a user from Audius by handle.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/handle/:handle`
- **Base URL:** `https://api.audius.co/v1`
- **Official documentation:** [Get User by Handle](https://api.audius.co/v1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `handle` | path | `string` | yes |
