# Get Playlist with Audius

Retrieves a playlist from Audius by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/playlists/:playlist_id`
- **Base URL:** `https://api.audius.co/v1`
- **Official documentation:** [Get Playlist](https://api.audius.co/v1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `playlist_id` | path | `string` | yes |
