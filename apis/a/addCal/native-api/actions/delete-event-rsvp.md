# Delete Event RSVP with AddCal

Deletes an RSVP from a specific AddCal event.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/calendars/:calendar_public_id/events/:event_public_id/rsvps/:public_id`
- **Base URL:** `https://addcal.co/api`
- **Official documentation:** [Delete Event RSVP](https://addcal.co/api-docs)
