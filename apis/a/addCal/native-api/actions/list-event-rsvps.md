# List Event RSVPs with AddCal

Retrieves RSVPs for a specific AddCal event.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendars/:calendar_public_id/events/:event_public_id/rsvps`
- **Base URL:** `https://addcal.co/api`
- **Official documentation:** [List Event RSVPs](https://addcal.co/api-docs)
