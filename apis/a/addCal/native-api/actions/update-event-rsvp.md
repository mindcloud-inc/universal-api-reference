# Update Event RSVP with AddCal

Updates an RSVP for a specific AddCal event.

## Endpoint

- **Method:** `PUT`
- **Path:** `/calendars/:calendar_public_id/events/:event_public_id/rsvps/:public_id`
- **Base URL:** `https://addcal.co/api`
- **Official documentation:** [Update Event RSVP](https://addcal.co/api-docs)
