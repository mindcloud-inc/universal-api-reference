# Create Event RSVP with AddCal

Creates an RSVP for a specific AddCal event.

## Endpoint

- **Method:** `POST`
- **Path:** `/calendars/:calendar_public_id/events/:event_public_id/rsvps`
- **Base URL:** `https://addcal.co/api`
- **Official documentation:** [Create Event RSVP](https://addcal.co/api-docs)
