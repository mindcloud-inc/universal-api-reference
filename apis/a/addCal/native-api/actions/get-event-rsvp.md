# Get Event RSVP with AddCal

Retrieves an RSVP from a specific AddCal event.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendars/:calendar_public_id/events/:event_public_id/rsvps/:public_id`
- **Base URL:** `https://addcal.co/api`
- **Official documentation:** [Get Event RSVP](https://addcal.co/api-docs)
