# Get Recording By UUID with Avoma

Retrieves a recording by UUID from Avoma.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/recordings/:uuid/`
- **Base URL:** `https://api.avoma.com`
- **Official documentation:** [Get Recording By UUID](https://dev.avoma.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Unique ID of the recording. |
