# Delete Meeting Type with Avoma

Deletes an existing meeting type from Avoma.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/meeting_type/:uuid/`
- **Base URL:** `https://api.avoma.com`
- **Official documentation:** [Delete Meeting Type](https://dev.avoma.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Unique ID of the meeting type. |
