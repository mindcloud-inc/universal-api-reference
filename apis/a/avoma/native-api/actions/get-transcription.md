# Get Transcription with Avoma

Retrieves a transcription from Avoma.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/transcriptions/:uuid/`
- **Base URL:** `https://api.avoma.com`
- **Official documentation:** [Get Transcription](https://dev.avoma.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Unique ID of the transcription. |
