# Get Call with Avoma

Retrieves a call by external ID from Avoma.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/calls/:external_id/`
- **Base URL:** `https://api.avoma.com`
- **Official documentation:** [Get Call](https://dev.avoma.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `external_id` | path | `string` | yes | External ID of the call. |
