# Delete Meeting Outcome with Avoma

Deletes an existing meeting outcome from Avoma.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/meeting_outcome/:uuid/`
- **Base URL:** `https://api.avoma.com`
- **Official documentation:** [Delete Meeting Outcome](https://dev.avoma.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Unique ID of the meeting outcome. |
