# Get Meeting Segments with Avoma

Retrieves segments for a meeting from Avoma.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/meeting_segments/`
- **Base URL:** `https://api.avoma.com`
- **Official documentation:** [Get Meeting Segments](https://dev.avoma.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | query | `string` | yes | Unique ID of the meeting. |
