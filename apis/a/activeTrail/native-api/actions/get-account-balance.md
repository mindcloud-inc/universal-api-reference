# Get Account Balance with ActiveTrail

Retrieves account email and SMS balances from ActiveTrail.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/balance`
- **Base URL:** `https://webapi.mymarketing.co.il/api`
- **Official documentation:** [Get Account Balance](https://webapi.mymarketing.co.il/api/docs/and/Api/GET-api-account-balance)
