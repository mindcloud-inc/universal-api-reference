# Get Campaign with ActiveTrail

Retrieves a campaign from ActiveTrail.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:id`
- **Base URL:** `https://webapi.mymarketing.co.il/api`
- **Official documentation:** [Get Campaign](https://webapi.mymarketing.co.il/api/docs/and/Api/GET-api-campaigns-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Campaign id. |
