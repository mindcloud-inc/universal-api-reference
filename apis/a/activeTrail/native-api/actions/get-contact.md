# Get Contact with ActiveTrail

Retrieves a contact from ActiveTrail.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://webapi.mymarketing.co.il/api`
- **Official documentation:** [Get Contact](https://webapi.mymarketing.co.il/api/docs/and/Api/GET-api-contacts-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Contact id. Can be found using the contacts list endpoint. |
