# Get Group with ActiveTrail

Retrieves a group from ActiveTrail.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id`
- **Base URL:** `https://webapi.mymarketing.co.il/api`
- **Official documentation:** [Get Group](https://webapi.mymarketing.co.il/api/docs/and/Api/GET-api-groups-Id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Group id. Can be found using the account groups endpoint or in the UI. |
