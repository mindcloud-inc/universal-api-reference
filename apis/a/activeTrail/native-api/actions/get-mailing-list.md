# Get Mailing List with ActiveTrail

Retrieves a mailing list from ActiveTrail.

## Endpoint

- **Method:** `GET`
- **Path:** `/mailinglist/:id`
- **Base URL:** `https://webapi.mymarketing.co.il/api`
- **Official documentation:** [Get Mailing List](https://webapi.mymarketing.co.il/api/docs/and/Api/GET-api-mailinglist-Id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Mailing list id. Can be found using the mailing lists endpoint or in the UI. |
