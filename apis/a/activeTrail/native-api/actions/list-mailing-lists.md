# List Mailing Lists with ActiveTrail

Retrieves mailing lists from ActiveTrail.

## Endpoint

- **Method:** `GET`
- **Path:** `/mailinglist`
- **Base URL:** `https://webapi.mymarketing.co.il/api`
- **Official documentation:** [List Mailing Lists](https://webapi.mymarketing.co.il/api/docs/and/Api/GET-api-mailinglist)
