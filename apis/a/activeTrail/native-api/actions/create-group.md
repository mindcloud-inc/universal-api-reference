# Create Group with ActiveTrail

Creates a new group in ActiveTrail.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://webapi.mymarketing.co.il/api`
- **Official documentation:** [Create Group](https://webapi.mymarketing.co.il/api/docs/and/Api/POST-api-groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the group. |
