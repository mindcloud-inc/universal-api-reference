# List Groups with ActiveTrail

Retrieves a list of groups from ActiveTrail.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://webapi.mymarketing.co.il/api`
- **Official documentation:** [List Groups](https://webapi.mymarketing.co.il/api/docs/and/Api/GET-api-groups_SearchTerm_Page_Limit)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `SearchTerm` | query | `string` | no | Search groups by name. |
