# Delete Group with ActiveTrail

Deletes an existing group from ActiveTrail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/:id`
- **Base URL:** `https://webapi.mymarketing.co.il/api`
- **Official documentation:** [Delete Group](https://webapi.mymarketing.co.il/api/docs/and/Api/DELETE-api-groups-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Group id. Can be found using the account groups endpoint or in the UI. |
