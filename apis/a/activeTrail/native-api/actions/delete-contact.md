# Delete Contact with ActiveTrail

Deletes an existing contact from ActiveTrail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `https://webapi.mymarketing.co.il/api`
- **Official documentation:** [Delete Contact](https://webapi.mymarketing.co.il/api/docs/and/Api/DELETE-api-contacts-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Contact id. Can be found using the contacts list endpoint. |
