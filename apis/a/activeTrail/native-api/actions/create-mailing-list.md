# Create Mailing List with ActiveTrail

Creates a new mailing list in ActiveTrail.

## Endpoint

- **Method:** `POST`
- **Path:** `/mailinglist`
- **Base URL:** `https://webapi.mymarketing.co.il/api`
- **Official documentation:** [Create Mailing List](https://webapi.mymarketing.co.il/api/docs/and/Api/POST-api-mailinglist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Name` | body | `string` | yes | Name of the mailing list. |
