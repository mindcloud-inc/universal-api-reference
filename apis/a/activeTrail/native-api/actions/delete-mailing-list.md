# Delete Mailing List with ActiveTrail

Deletes an existing mailing list from ActiveTrail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/mailinglist/:id`
- **Base URL:** `https://webapi.mymarketing.co.il/api`
- **Official documentation:** [Delete Mailing List](https://webapi.mymarketing.co.il/api/docs/and/Api/DELETE-api-mailinglist-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Mailing list id. Can be found using the mailing lists endpoint or in the UI. |
