# Get Products with AXL

## Endpoint

- **Method:** `GET`
- **Path:** `/product`
- **Base URL:** `https://app.axl.tech/api/v1`
- **Official documentation:** [Get Products](https://app.axl.tech/api/public)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Fields to return using AXL field-selection syntax, for example {id,name} |
