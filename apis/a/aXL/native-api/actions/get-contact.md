# Get Contact with AXL

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/lead/:id`
- **Base URL:** `https://app.axl.tech/api/v1`
- **Official documentation:** [Get Contact](https://app.axl.tech/api/public)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `fields` | query | `string` | no |
