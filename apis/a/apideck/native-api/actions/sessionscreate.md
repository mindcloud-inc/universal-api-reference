# Create session with Apideck

Creates a Hosted Vault session in Apideck.

## Endpoint

- **Method:** `POST`
- **Path:** `/vault/sessions`
- **Base URL:** `https://unify.apideck.com`
- **Official documentation:** [Create session](https://developers.apideck.com/apis/vault/reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `consumer_metadata` | body | `object` | no |
| `redirect_uri` | body | `string` | no |
| `settings` | body | `object` | no |
| `theme` | body | `object` | no |
| `custom_consumer_settings` | body | `object` | no |
