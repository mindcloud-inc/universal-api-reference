# Delete consumer with Apideck

Deletes a consumer and all their connections from Apideck Vault.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/vault/consumers/:consumer_id`
- **Base URL:** `https://unify.apideck.com`
- **Official documentation:** [Delete consumer](https://developers.apideck.com/apis/vault/reference/consumers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `consumer_id` | path | `string` | yes |
