# Get consumer with Apideck

Retrieves a consumer from Apideck Vault.

## Endpoint

- **Method:** `GET`
- **Path:** `/vault/consumers/:consumer_id`
- **Base URL:** `https://unify.apideck.com`
- **Official documentation:** [Get consumer](https://developers.apideck.com/apis/vault/reference/consumers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `consumer_id` | path | `string` | yes |
