# Create consumer with Apideck

Creates a new consumer in Apideck Vault.

## Endpoint

- **Method:** `POST`
- **Path:** `/vault/consumers`
- **Base URL:** `https://unify.apideck.com`
- **Official documentation:** [Create consumer](https://developers.apideck.com/apis/vault/reference/consumers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `consumer_id` | body | `string` | yes |
| `metadata` | body | `object` | no |
