# List custom mappings with Apideck

Retrieves custom mappings from Apideck Vault.

## Endpoint

- **Method:** `GET`
- **Path:** `/vault/custom-mappings/:unified_api/:service_id`
- **Base URL:** `https://unify.apideck.com`
- **Official documentation:** [List custom mappings](https://developers.apideck.com/apis/vault/reference/custom-mappings)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `unified_api` | path | `string` | yes |
| `service_id` | path | `string` | yes |
