# Get all connections with Apideck

Retrieves all connections from Apideck Vault.

## Endpoint

- **Method:** `GET`
- **Path:** `/vault/connections`
- **Base URL:** `https://unify.apideck.com`
- **Official documentation:** [Get all connections](https://developers.apideck.com/apis/vault/reference/connections)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `api` | query | `string` | no |
| `configured` | query | `boolean` | no |
