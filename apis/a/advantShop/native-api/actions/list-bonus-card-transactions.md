# List Bonus Card Transactions with AdvantShop

Retrieves bonus card transactions from AdvantShop.

## Endpoint

- **Method:** `GET`
- **Path:** `/bonus-cards/{id}/transactions`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Bonus Card Transactions](https://www.advantshop.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Bonus card number from AdvantShop. |
