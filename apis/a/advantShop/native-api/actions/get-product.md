# Get Product with AdvantShop

Retrieves a product from AdvantShop.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Product](https://www.advantshop.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Product identifier from AdvantShop. |
