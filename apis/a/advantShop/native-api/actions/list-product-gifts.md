# List Product Gifts with AdvantShop

Retrieves product gifts from AdvantShop.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{id}/gifts`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Product Gifts](https://www.advantshop.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Product identifier from AdvantShop. |
