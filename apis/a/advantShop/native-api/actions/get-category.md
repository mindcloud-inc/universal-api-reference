# Get Category with AdvantShop

Retrieves a category from AdvantShop.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Category](https://www.advantshop.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Category identifier from AdvantShop. |
