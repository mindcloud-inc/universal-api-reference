# Get Customer with AdvantShop

Retrieves a customer from AdvantShop.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Customer](https://www.advantshop.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Customer identifier from AdvantShop. |
