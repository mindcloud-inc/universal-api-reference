# Get Bonus Card with AdvantShop

Retrieves a bonus card from AdvantShop.

## Endpoint

- **Method:** `GET`
- **Path:** `/bonus-cards/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Bonus Card](https://www.advantshop.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Bonus card number from AdvantShop. |
