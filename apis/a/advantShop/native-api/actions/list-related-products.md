# List Related Products with AdvantShop

Retrieves related products from AdvantShop.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{id}/related-products`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Related Products](https://www.advantshop.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Product identifier from AdvantShop. |
