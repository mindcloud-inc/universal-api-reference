# List Product Reviews with AdvantShop

Retrieves product reviews from AdvantShop.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{id}/reviews`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Product Reviews](https://www.advantshop.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Product identifier from AdvantShop. |
