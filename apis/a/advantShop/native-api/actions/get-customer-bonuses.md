# Get Customer Bonuses with AdvantShop

Retrieves a customer's bonus card from AdvantShop.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/{id}/bonuses`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Customer Bonuses](https://www.advantshop.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Customer identifier from AdvantShop. |
