# Get Order with AdvantShop

Retrieves an order from AdvantShop.

## Endpoint

- **Method:** `GET`
- **Path:** `/order/get/{id}`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Order](https://www.advantshop.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Order identifier from AdvantShop. |
