# List Dataset Examples with Arize AX

Retrieves examples for a dataset in Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/datasets/:datasetId/examples`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [List Dataset Examples](https://arize.com/docs/api-reference/datasets/list-dataset-examples)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dataset_id` | path | `string` | yes |
