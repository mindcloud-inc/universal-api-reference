# Get a Space with Arize AX

Retrieves a space from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/spaces/:spaceId`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [Get a Space](https://arize.com/docs/api-reference/spaces/get-a-space)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `space_id` | path | `string` | yes |
