# List Spans with Arize AX

Retrieves spans from Arize AX.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/spans`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [List Spans](https://arize.com/docs/api-reference/spans/list-spans)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | body | `string` | yes |
