# Create a Project with Arize AX

Creates a new project in Arize AX.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/projects`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [Create a Project](https://arize.com/docs/api-reference/projects/create-a-project)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
