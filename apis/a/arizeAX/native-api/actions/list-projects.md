# List Projects with Arize AX

Retrieves projects from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [List Projects](https://arize.com/docs/api-reference/projects/list-projects)

## Capabilities

This operation supports [pagination](../README.md#pagination).
