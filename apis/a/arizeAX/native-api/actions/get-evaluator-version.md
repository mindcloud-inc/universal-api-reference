# Get Evaluator Version with Arize AX

Retrieves an evaluator version from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/evaluator-versions/:versionId`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [Get Evaluator Version](https://arize.com/docs/api-reference/evaluators/get-evaluator-version)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `version_id` | path | `string` | yes |
