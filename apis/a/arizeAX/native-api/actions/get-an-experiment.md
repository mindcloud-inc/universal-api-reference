# Get an Experiment with Arize AX

Retrieves an experiment from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/experiments/:experimentId`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [Get an Experiment](https://arize.com/docs/api-reference/experiments/get-an-experiment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `experiment_id` | path | `string` | yes |
