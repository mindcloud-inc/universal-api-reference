# List Experiment Runs with Arize AX

Retrieves runs for an experiment in Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/experiments/:experimentId/runs`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [List Experiment Runs](https://arize.com/docs/api-reference/experiments/list-experiment-runs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `experiment_id` | path | `string` | yes |
