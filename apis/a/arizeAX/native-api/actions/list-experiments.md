# List Experiments with Arize AX

Retrieves experiments from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/experiments`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [List Experiments](https://arize.com/docs/api-reference/experiments/list-experiments)

## Capabilities

This operation supports [pagination](../README.md#pagination).
