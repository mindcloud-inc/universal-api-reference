# Create a Prompt with Arize AX

Creates a new prompt in Arize AX.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/prompts`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [Create a Prompt](https://arize.com/docs/api-reference/prompts/create-a-prompt)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `version` | body | `object` | yes |
