# Get a Project with Arize AX

Retrieves a project from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [Get a Project](https://arize.com/docs/api-reference/projects/get-a-project)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
