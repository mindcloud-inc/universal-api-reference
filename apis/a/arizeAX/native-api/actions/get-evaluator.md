# Get Evaluator with Arize AX

Retrieves an evaluator from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/evaluators/:evaluatorId`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [Get Evaluator](https://arize.com/docs/api-reference/evaluators/get-evaluator)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `evaluator_id` | path | `string` | yes |
