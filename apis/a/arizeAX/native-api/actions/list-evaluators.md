# List Evaluators with Arize AX

Retrieves evaluators from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/evaluators`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [List Evaluators](https://arize.com/docs/api-reference/evaluators/list-evaluators)

## Capabilities

This operation supports [pagination](../README.md#pagination).
