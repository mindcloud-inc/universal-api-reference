# Update Evaluator with Arize AX

Updates an evaluator in Arize AX.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v2/evaluators/{evaluator_id}`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [Update Evaluator](https://arize.com/docs/api-reference/evaluators/update-evaluator)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `evaluator_id` | path | `string` | yes |
