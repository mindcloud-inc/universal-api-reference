# List Prompts with Arize AX

Retrieves prompts from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/prompts`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [List Prompts](https://arize.com/docs/api-reference/prompts/list-prompts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
