# List Datasets with Arize AX

Retrieves datasets from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/datasets`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [List Datasets](https://arize.com/docs/api-reference/datasets/list-datasets)

## Capabilities

This operation supports [pagination](../README.md#pagination).
