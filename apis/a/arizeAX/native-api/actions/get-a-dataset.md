# Get a Dataset with Arize AX

Retrieves a dataset from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/datasets/:datasetId`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [Get a Dataset](https://arize.com/docs/api-reference/datasets/get-a-dataset)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dataset_id` | path | `string` | yes |
