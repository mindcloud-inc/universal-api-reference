# List Spaces with Arize AX

Retrieves spaces from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/spaces`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [List Spaces](https://arize.com/docs/api-reference/spaces/list-spaces)

## Capabilities

This operation supports [pagination](../README.md#pagination).
