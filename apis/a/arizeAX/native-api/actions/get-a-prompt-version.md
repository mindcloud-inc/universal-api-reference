# Get a Prompt Version with Arize AX

Retrieves a prompt version from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/prompt-versions/:version_id`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [Get a Prompt Version](https://arize.com/docs/api-reference/prompts/get-a-prompt-version)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `version_id` | path | `string` | yes |
