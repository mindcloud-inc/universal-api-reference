# Get a Prompt with Arize AX

Retrieves a prompt from Arize AX.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/prompts/:promptId`
- **Base URL:** `https://api.arize.com`
- **Official documentation:** [Get a Prompt](https://arize.com/docs/api-reference/prompts/get-a-prompt)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `prompt_id` | path | `string` | yes |
