# Update Position Time Zone with Aqara Home for RU

Updates a position time zone in Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Update Position Time Zone](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
