# Query Resource Value with Aqara Home for RU

Retrieves resource values from Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Query Resource Value](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
