# List Linkages by Subject with Aqara Home for RU

Retrieves linkages by subject from Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [List Linkages by Subject](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
