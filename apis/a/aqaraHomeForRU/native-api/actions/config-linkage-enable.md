# Enable Linkage with Aqara Home for RU

Enables or disables a linkage in Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Enable Linkage](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
