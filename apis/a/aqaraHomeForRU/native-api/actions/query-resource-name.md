# Query Resource Name with Aqara Home for RU

Retrieves resource names from Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Query Resource Name](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
