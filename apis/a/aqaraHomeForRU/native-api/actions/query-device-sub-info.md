# Query Sub-Device Info with Aqara Home for RU

Retrieves sub-device details from Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Query Sub-Device Info](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
