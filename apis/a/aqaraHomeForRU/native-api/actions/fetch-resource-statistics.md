# Fetch Resource Statistics with Aqara Home for RU

Retrieves resource statistics from Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Fetch Resource Statistics](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
