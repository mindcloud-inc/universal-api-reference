# Subscribe Resource with Aqara Home for RU

Subscribes to resource updates in Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Subscribe Resource](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
