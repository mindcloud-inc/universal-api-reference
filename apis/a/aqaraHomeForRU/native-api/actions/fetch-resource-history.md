# Fetch Resource History with Aqara Home for RU

Retrieves resource history from Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Fetch Resource History](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
