# Update Device Name with Aqara Home for RU

Updates a device name in Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Update Device Name](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
