# Create Scene with Aqara Home for RU

Creates a scene in Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Create Scene](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
