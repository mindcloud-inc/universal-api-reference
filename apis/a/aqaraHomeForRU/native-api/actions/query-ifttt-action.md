# Query IFTTT Actions with Aqara Home for RU

Retrieves supported IFTTT actions from Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Query IFTTT Actions](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
