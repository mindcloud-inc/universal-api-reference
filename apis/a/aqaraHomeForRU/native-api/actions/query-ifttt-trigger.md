# Query IFTTT Triggers with Aqara Home for RU

Retrieves supported IFTTT triggers from Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Query IFTTT Triggers](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
