# Query Position Detail with Aqara Home for RU

Retrieves position details from Aqara Home for RU.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3.0/open/api`
- **Base URL:** `https://open-ru.aqara.com`
- **Official documentation:** [Query Position Detail](https://opendoc.aqara.com/en/docs/developmanual/apiIntroduction/requestIntent.html)
