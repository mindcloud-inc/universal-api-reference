# Batch Add Subscribers with Acumbamail

Creates subscribers in an Acumbamail list in bulk.

## Endpoint

- **Method:** `POST`
- **Path:** `/batchAddSubscribers/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [Batch Add Subscribers](https://acumbamail.com/apidoc/function/batchAddSubscribers/)
