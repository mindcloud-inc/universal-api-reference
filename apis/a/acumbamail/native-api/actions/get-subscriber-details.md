# Get Subscriber Details with Acumbamail

Retrieves detailed subscriber information from Acumbamail.

## Endpoint

- **Method:** `POST`
- **Path:** `/getSubscriberDetails/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [Get Subscriber Details](https://acumbamail.com/apidoc/function/getSubscriberDetails/)
