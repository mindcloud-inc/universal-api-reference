# List Campaign Links with Acumbamail

Retrieves campaign links and clicks from Acumbamail.

## Endpoint

- **Method:** `POST`
- **Path:** `/getCampaignLinks/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [List Campaign Links](https://acumbamail.com/apidoc/function/getCampaignLinks/)
