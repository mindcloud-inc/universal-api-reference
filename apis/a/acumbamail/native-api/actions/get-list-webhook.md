# Get List Webhook with Acumbamail

Retrieves list webhook settings from Acumbamail.

## Endpoint

- **Method:** `POST`
- **Path:** `/getListWebhook/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [Get List Webhook](https://acumbamail.com/apidoc/function/getListWebhook/)
