# List Campaigns with Acumbamail

Retrieves created campaign names and IDs from Acumbamail.

## Endpoint

- **Method:** `POST`
- **Path:** `/getCampaigns/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [List Campaigns](https://acumbamail.com/apidoc/function/getCampaigns/)
