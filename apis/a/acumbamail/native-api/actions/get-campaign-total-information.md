# Get Campaign Total Information with Acumbamail

Retrieves complete campaign information from Acumbamail.

## Endpoint

- **Method:** `POST`
- **Path:** `/getCampaignTotalInformation/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [Get Campaign Total Information](https://acumbamail.com/apidoc/function/getCampaignTotalInformation/)
