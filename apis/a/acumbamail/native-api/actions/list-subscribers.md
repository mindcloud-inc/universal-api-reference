# List Subscribers with Acumbamail

Retrieves subscribers from an Acumbamail list.

## Endpoint

- **Method:** `POST`
- **Path:** `/getSubscribers/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [List Subscribers](https://acumbamail.com/apidoc/function/getSubscribers/)
