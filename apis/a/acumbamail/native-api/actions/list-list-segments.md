# List List Segments with Acumbamail

Retrieves subscriber list segments from Acumbamail.

## Endpoint

- **Method:** `POST`
- **Path:** `/getListSegments/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [List List Segments](https://acumbamail.com/apidoc/function/getListSegments/)
