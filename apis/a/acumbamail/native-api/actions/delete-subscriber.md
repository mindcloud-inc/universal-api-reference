# Delete Subscriber with Acumbamail

Deletes a subscriber from an Acumbamail list.

## Endpoint

- **Method:** `POST`
- **Path:** `/deleteSubscriber/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [Delete Subscriber](https://acumbamail.com/apidoc/function/deleteSubscriber/)
