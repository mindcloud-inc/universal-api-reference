# Send Template Campaign with Acumbamail

Creates and sends a template campaign in Acumbamail.

## Endpoint

- **Method:** `POST`
- **Path:** `/sendTemplateCampaign/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [Send Template Campaign](https://acumbamail.com/apidoc/function/sendTemplateCampaign/)
