# Search Subscriber with Acumbamail

Finds a subscriber across Acumbamail lists by email.

## Endpoint

- **Method:** `POST`
- **Path:** `/searchSubscriber/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [Search Subscriber](https://acumbamail.com/apidoc/function/searchSubscriber/)
