# List Campaign Clicks with Acumbamail

Retrieves campaign click activity from Acumbamail.

## Endpoint

- **Method:** `POST`
- **Path:** `/getCampaignClicks/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [List Campaign Clicks](https://acumbamail.com/apidoc/function/getCampaignClicks/)
