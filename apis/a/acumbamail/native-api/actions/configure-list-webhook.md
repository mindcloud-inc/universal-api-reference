# Configure List Webhook with Acumbamail

Updates list webhook settings in Acumbamail.

## Endpoint

- **Method:** `POST`
- **Path:** `/configListWebhook/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [Configure List Webhook](https://acumbamail.com/apidoc/function/configListWebhook/)
