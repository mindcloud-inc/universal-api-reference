# Unsubscribe Subscriber with Acumbamail

Updates a subscriber to unsubscribe from an Acumbamail list.

## Endpoint

- **Method:** `POST`
- **Path:** `/unsubscribeSubscriber/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [Unsubscribe Subscriber](https://acumbamail.com/apidoc/function/unsubscribeSubscriber/)
