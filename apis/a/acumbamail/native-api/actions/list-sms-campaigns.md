# List SMS Campaigns with Acumbamail

Retrieves SMS campaign summaries from Acumbamail.

## Endpoint

- **Method:** `POST`
- **Path:** `/getSMSCampaigns/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [List SMS Campaigns](https://acumbamail.com/apidoc/function/getSMSCampaigns/)
