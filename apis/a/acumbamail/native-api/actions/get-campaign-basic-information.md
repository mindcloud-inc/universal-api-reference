# Get Campaign Basic Information with Acumbamail

Retrieves basic campaign information from Acumbamail.

## Endpoint

- **Method:** `POST`
- **Path:** `/getCampaignBasicInformation/`
- **Base URL:** `https://acumbamail.com/api/1`
- **Official documentation:** [Get Campaign Basic Information](https://acumbamail.com/apidoc/function/getCampaignBasicInformation/)
