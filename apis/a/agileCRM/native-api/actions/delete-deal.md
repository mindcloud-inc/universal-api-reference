# Delete Deal with Agile CRM

Deletes an existing deal from Agile CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/opportunity/:dealId`
- **Base URL:** `https://mindcloud.agilecrm.com/dev/api`
- **Official documentation:** [Delete Deal](https://github.com/agilecrm/rest-api#36-delete-deal)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dealId` | path | `list<string>` | yes |
