# Delete Contact with Agile CRM

Deletes an existing contact from Agile CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{{contactId}}`
- **Base URL:** `https://mindcloud.agilecrm.com/dev/api`
- **Official documentation:** [Delete Contact](https://github.com/agilecrm/rest-api#110-delete-single-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `list<number>` | yes |
