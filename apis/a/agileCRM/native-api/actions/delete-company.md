# Delete Company with Agile CRM

Deletes an existing company from Agile CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{{companyId}}`
- **Base URL:** `https://mindcloud.agilecrm.com/dev/api`
- **Official documentation:** [Delete Company](https://github.com/agilecrm/rest-api#25-delete-single-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `list` | yes | Company record to delete. |
