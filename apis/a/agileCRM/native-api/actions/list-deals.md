# List Deals with Agile CRM

Finds deals in Agile CRM by filters.

## Endpoint

- **Method:** `GET`
- **Path:** `/opportunity`
- **Base URL:** `https://mindcloud.agilecrm.com/dev/api`
- **Official documentation:** [List Deals](https://github.com/agilecrm/rest-api#31-listing-deals)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
