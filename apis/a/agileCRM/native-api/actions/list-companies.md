# List Companies with Agile CRM

Finds companies in Agile CRM by filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/companies/list`
- **Base URL:** `https://mindcloud.agilecrm.com/dev/api`
- **Official documentation:** [List Companies](https://github.com/agilecrm/rest-api#23-get-list-of-companies)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
