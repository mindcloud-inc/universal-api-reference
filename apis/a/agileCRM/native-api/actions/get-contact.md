# Get Contact with Agile CRM

Retrieves a contact from Agile CRM by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId`
- **Base URL:** `https://mindcloud.agilecrm.com/dev/api`
- **Official documentation:** [Get Contact](https://github.com/agilecrm/rest-api#12-get-contact-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `list<string>` | yes |
