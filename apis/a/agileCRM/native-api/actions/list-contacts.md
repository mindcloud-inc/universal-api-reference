# List Contacts with Agile CRM

Finds contacts in Agile CRM by filters.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://mindcloud.agilecrm.com/dev/api`
- **Official documentation:** [List Contacts](https://github.com/agilecrm/rest-api#11-listing-contacts-)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
