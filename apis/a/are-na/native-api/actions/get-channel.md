# Get Channel with Are.na

Retrieves a channel from Are.na.

## Endpoint

- **Method:** `GET`
- **Path:** `channels/:id`
- **Base URL:** `https://api.are.na/v3`
- **Official documentation:** [Get Channel](https://www.are.na/developers/explore/channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Are.na channel ID or slug. |
