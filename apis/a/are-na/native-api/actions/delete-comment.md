# Delete Comment with Are.na

Deletes an existing comment from Are.na.

## Endpoint

- **Method:** `DELETE`
- **Path:** `comments/:id`
- **Base URL:** `https://api.are.na/v3`
- **Official documentation:** [Delete Comment](https://www.are.na/developers/explore/comment/delete-comment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Are.na comment ID. |
