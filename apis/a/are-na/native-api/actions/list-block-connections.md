# List Block Connections with Are.na

Retrieves connections for a block in Are.na.

## Endpoint

- **Method:** `GET`
- **Path:** `blocks/:id/connections`
- **Base URL:** `https://api.are.na/v3`
- **Official documentation:** [List Block Connections](https://www.are.na/developers/explore/block/connections)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Are.na block ID. |
