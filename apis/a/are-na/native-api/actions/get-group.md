# Get Group with Are.na

Retrieves a group profile from Are.na.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/:id`
- **Base URL:** `https://api.are.na/v3`
- **Official documentation:** [Get Group](https://www.are.na/developers/explore/group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Are.na group ID. |
