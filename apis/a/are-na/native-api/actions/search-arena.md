# Search Are.na with Are.na

Finds blocks, channels, users, and groups in Are.na.

## Endpoint

- **Method:** `GET`
- **Path:** `search`
- **Base URL:** `https://api.are.na/v3`
- **Official documentation:** [Search Are.na](https://www.are.na/developers/explore/search)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Search term. |
| `type` | query | `string` | no | Optional result type filter. |
