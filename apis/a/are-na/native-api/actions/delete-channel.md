# Delete Channel with Are.na

Deletes an existing channel from Are.na.

## Endpoint

- **Method:** `DELETE`
- **Path:** `channels/:id`
- **Base URL:** `https://api.are.na/v3`
- **Official documentation:** [Delete Channel](https://www.are.na/developers/explore/channel/delete-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Are.na channel ID or slug. |
