# Get Connection with Are.na

Retrieves a connection by ID from Are.na.

## Endpoint

- **Method:** `GET`
- **Path:** `connections/:id`
- **Base URL:** `https://api.are.na/v3`
- **Official documentation:** [Get Connection](https://www.are.na/developers/explore/connection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Are.na connection ID. |
