# Get User with Are.na

Retrieves a user profile from Are.na.

## Endpoint

- **Method:** `GET`
- **Path:** `users/:id`
- **Base URL:** `https://api.are.na/v3`
- **Official documentation:** [Get User](https://www.are.na/developers/explore/user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Are.na user ID or slug. |
