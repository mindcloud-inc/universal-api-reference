# Delete Connection with Are.na

Deletes an existing connection from Are.na.

## Endpoint

- **Method:** `DELETE`
- **Path:** `connections/:id`
- **Base URL:** `https://api.are.na/v3`
- **Official documentation:** [Delete Connection](https://www.are.na/developers/explore/connection/delete-connection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Are.na connection ID. |
