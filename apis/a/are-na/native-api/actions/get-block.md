# Get Block with Are.na

Retrieves a block by ID from Are.na.

## Endpoint

- **Method:** `GET`
- **Path:** `blocks/:id`
- **Base URL:** `https://api.are.na/v3`
- **Official documentation:** [Get Block](https://www.are.na/developers/explore/block)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Are.na block ID. |
