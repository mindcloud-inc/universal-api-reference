# Get Agent by ID with Agent700

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agent_id`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [Get Agent by ID](https://agent700.readme.io/reference/get_api-agents-agent-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | The Agent700 agent identifier. |
