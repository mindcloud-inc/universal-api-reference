# Read MCP Resource for Agent with Agent700

## Endpoint

- **Method:** `POST`
- **Path:** `/agents/:agent_id/mcp/resources/read`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [Read MCP Resource for Agent](https://agent700.readme.io/reference/post_api-mcp-resources-read)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agent_id` | path | `string` | yes |
