# Get Agent Sharing Info with Agent700

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agent_id/sharing`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [Get Agent Sharing Info](https://agent700.readme.io/reference/getagentsharinginfo-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | The Agent700 agent identifier. |
