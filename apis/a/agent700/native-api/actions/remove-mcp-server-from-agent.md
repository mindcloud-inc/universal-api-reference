# Remove MCP Server from Agent with Agent700

## Endpoint

- **Method:** `DELETE`
- **Path:** `/agents/:agent_id/mcp/servers/:server_id`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [Remove MCP Server from Agent](https://agent700.readme.io/reference/deleteagentmcpserverbyid-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agent_id` | path | `string` | yes |
| `server_id` | path | `string` | yes |
