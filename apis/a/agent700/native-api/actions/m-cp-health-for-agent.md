# MCP Health for Agent with Agent700

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agent_id/mcp/health`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [MCP Health for Agent](https://agent700.readme.io/reference/getagentmcphealth-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agent_id` | path | `string` | yes |
