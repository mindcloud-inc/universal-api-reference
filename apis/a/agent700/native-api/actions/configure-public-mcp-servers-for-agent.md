# Configure Public MCP Servers for Agent with Agent700

## Endpoint

- **Method:** `POST`
- **Path:** `/agents/:agent_id/mcp/public-servers`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [Configure Public MCP Servers for Agent](https://agent700.readme.io/reference/postagentmcppublicservers-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agent_id` | path | `string` | yes |
