# Update Agent Sharing with Agent700

## Endpoint

- **Method:** `POST`
- **Path:** `/agents/:agent_id/share`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [Update Agent Sharing](https://agent700.readme.io/reference/getagents-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agent_id` | path | `string` | yes |
