# Toggle MCP Server Enabled State with Agent700

## Endpoint

- **Method:** `POST`
- **Path:** `/mcp/servers/:server_name/toggle`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [Toggle MCP Server Enabled State](https://agent700.readme.io/reference/getmcpservers-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `server_name` | path | `string` | yes |
