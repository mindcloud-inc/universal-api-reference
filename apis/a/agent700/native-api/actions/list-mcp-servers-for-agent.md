# List MCP Servers for Agent with Agent700

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agent_id/mcp/servers`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [List MCP Servers for Agent](https://agent700.readme.io/reference/getagentmcpservers-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agent_id` | path | `string` | yes |
