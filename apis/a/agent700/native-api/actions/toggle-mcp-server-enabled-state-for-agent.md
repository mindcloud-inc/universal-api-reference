# Toggle MCP Server Enabled State for Agent with Agent700

## Endpoint

- **Method:** `POST`
- **Path:** `/agents/:agent_id/mcp/servers/:server_name/toggle`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [Toggle MCP Server Enabled State for Agent](https://agent700.readme.io/reference/postagentmcpservertoggle-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agent_id` | path | `string` | yes |
| `server_name` | path | `string` | yes |
