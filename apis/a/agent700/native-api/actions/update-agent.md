# Duplicate Agent with Agent700

## Endpoint

- **Method:** `PUT`
- **Path:** `/agents/:agent_id`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [Duplicate Agent](https://agent700.readme.io/reference/putagentbyid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | The Agent700 agent identifier. |
