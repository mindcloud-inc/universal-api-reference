# Get QA Sheet with Agent700

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agent_id/qa-sheets/:qa_sheet_id`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [Get QA Sheet](https://agent700.readme.io/reference/postagentqasheets-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agent_id` | path | `string` | yes |
| `qa_sheet_id` | path | `string` | yes |
