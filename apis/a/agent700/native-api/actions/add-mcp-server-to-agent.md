# Add MCP Server to Agent with Agent700

## Endpoint

- **Method:** `POST`
- **Path:** `/agents/:agent_id/mcp/servers`
- **Base URL:** `https://api.agent700.ai/api`
- **Official documentation:** [Add MCP Server to Agent](https://agent700.readme.io/reference/postagentmcpservers-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agent_id` | path | `string` | yes |
