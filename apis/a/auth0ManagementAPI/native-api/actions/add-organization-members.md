# Add Organization Members with Auth0 Management

Adds members to an organization in Auth0 Management API.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{id}/members`
- **Base URL:** `https://{tenantDomain}/api/v2`
- **Official documentation:** [Add Organization Members](https://dev.auth0.com/docs/api/management/v2#!/Organizations)
