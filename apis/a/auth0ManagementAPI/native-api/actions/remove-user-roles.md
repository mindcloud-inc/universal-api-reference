# Remove User Roles with Auth0 Management

Removes roles from a user in Auth0 Management API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/{id}/roles`
- **Base URL:** `https://{tenantDomain}/api/v2`
- **Official documentation:** [Remove User Roles](https://dev.auth0.com/docs/api/management/v2#!/Users)
