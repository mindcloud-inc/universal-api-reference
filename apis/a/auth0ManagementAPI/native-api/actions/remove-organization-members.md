# Remove Organization Members with Auth0 Management

Removes members from an organization in Auth0 Management API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{id}/members`
- **Base URL:** `https://{tenantDomain}/api/v2`
- **Official documentation:** [Remove Organization Members](https://dev.auth0.com/docs/api/management/v2#!/Organizations)
