# Delete Organization Connection with Auth0 Management

Deletes a connection from an organization in Auth0 Management API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/{id}/enabled_connections/{connection_id}`
- **Base URL:** `https://{tenantDomain}/api/v2`
- **Official documentation:** [Delete Organization Connection](https://dev.auth0.com/docs/api/management/v2#!/Organizations)
