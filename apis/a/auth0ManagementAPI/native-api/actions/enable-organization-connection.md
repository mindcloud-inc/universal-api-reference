# Enable Organization Connection with Auth0 Management

Enables a connection for an organization in Auth0 Management API.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/{id}/enabled_connections`
- **Base URL:** `https://{tenantDomain}/api/v2`
- **Official documentation:** [Enable Organization Connection](https://dev.auth0.com/docs/api/management/v2#!/Organizations)
