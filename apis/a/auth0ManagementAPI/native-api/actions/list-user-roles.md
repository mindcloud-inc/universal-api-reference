# List User Roles with Auth0 Management

Retrieves roles assigned to a user in Auth0 Management API.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{id}/roles`
- **Base URL:** `https://{tenantDomain}/api/v2`
- **Official documentation:** [List User Roles](https://dev.auth0.com/docs/api/management/v2#!/Users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
