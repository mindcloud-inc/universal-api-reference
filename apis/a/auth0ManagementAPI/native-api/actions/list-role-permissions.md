# List Role Permissions with Auth0 Management

Retrieves permissions assigned to a role in Auth0 Management API.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles/{id}/permissions`
- **Base URL:** `https://{tenantDomain}/api/v2`
- **Official documentation:** [List Role Permissions](https://dev.auth0.com/docs/api/management/v2#!/Roles)

## Capabilities

This operation supports [pagination](../README.md#pagination).
