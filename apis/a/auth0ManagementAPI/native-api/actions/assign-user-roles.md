# Assign User Roles with Auth0 Management

Assigns roles to a user in Auth0 Management API.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/{id}/roles`
- **Base URL:** `https://{tenantDomain}/api/v2`
- **Official documentation:** [Assign User Roles](https://dev.auth0.com/docs/api/management/v2#!/Users)
