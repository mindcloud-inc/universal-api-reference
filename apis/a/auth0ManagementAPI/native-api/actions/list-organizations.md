# List Organizations with Auth0 Management

Retrieves organizations from Auth0 Management API.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations`
- **Base URL:** `https://{tenantDomain}/api/v2`
- **Official documentation:** [List Organizations](https://dev.auth0.com/docs/api/management/v2#!/Organizations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
