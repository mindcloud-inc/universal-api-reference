# List Users with Auth0 Management

Retrieves users from Auth0 Management API.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://{tenantDomain}/api/v2`
- **Official documentation:** [List Users](https://dev.auth0.com/docs/api/management/v2#!/Users/get_users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
