# List Roles with Auth0 Management

Retrieves roles from Auth0 Management API.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles`
- **Base URL:** `https://{tenantDomain}/api/v2`
- **Official documentation:** [List Roles](https://dev.auth0.com/docs/api/management/v2#!/Roles)

## Capabilities

This operation supports [pagination](../README.md#pagination).
