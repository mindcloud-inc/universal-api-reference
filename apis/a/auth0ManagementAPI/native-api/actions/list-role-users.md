# List Role Users with Auth0 Management

Retrieves users assigned to a role in Auth0 Management API.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles/{id}/users`
- **Base URL:** `https://{tenantDomain}/api/v2`
- **Official documentation:** [List Role Users](https://dev.auth0.com/docs/api/management/v2#!/Roles)

## Capabilities

This operation supports [pagination](../README.md#pagination).
