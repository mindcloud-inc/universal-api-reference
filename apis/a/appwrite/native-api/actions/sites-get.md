# Get site with Appwrite

Retrieves site details from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/{siteId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Get site](https://appwrite.io/docs/references/cloud/server-rest/sites)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | Site ID. |
