# Get favicon with Appwrite

Retrieves a favicon image from Appwrite.

## Endpoint

- **Method:** `GET`
- **Path:** `/avatars/favicon`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Get favicon](https://appwrite.io/docs/references/cloud/server-rest/avatars)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Website URL which you want to fetch the favicon from. |
