# Update MFA recovery codes (regenerate) with Appwrite

Regenerates MFA recovery codes in Appwrite.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/account/mfa/recovery-codes`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Update MFA recovery codes (regenerate)](https://appwrite.io/docs/references/cloud/server-rest/account)
