# Delete log with Appwrite

Deletes the log from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sites/{siteId}/logs/{logId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete log](https://appwrite.io/docs/references/cloud/server-rest/sites)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | Site ID. |
| `logId` | path | `string` | yes | Log ID. |
