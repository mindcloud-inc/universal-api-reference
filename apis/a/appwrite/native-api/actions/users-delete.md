# Delete user with Appwrite

Deletes the user from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/{userId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete user](https://appwrite.io/docs/references/cloud/server-rest/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | User ID. |
