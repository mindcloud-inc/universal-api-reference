# Get deployment with Appwrite

Retrieves the deployment from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/functions/{functionId}/deployments/{deploymentId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Get deployment](https://appwrite.io/docs/references/cloud/server-rest/functions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `functionId` | path | `string` | yes | Function ID. |
| `deploymentId` | path | `string` | yes | Deployment ID. |
