# Get function with Appwrite

Retrieves function details from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/functions/{functionId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Get function](https://appwrite.io/docs/references/cloud/server-rest/functions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `functionId` | path | `string` | yes | Function ID. |
