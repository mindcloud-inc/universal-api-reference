# Delete user target with Appwrite

Deletes the user target from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/{userId}/targets/{targetId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete user target](https://appwrite.io/docs/references/cloud/server-rest/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | User ID. |
| `targetId` | path | `string` | yes | Target ID. |
