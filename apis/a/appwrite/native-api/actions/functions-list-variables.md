# List variables with Appwrite

Retrieves a list of variables from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/functions/{functionId}/variables`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [List variables](https://appwrite.io/docs/references/cloud/server-rest/functions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `functionId` | path | `string` | yes | Function unique ID. |
