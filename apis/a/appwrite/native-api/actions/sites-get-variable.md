# Get variable with Appwrite

Retrieves the variable from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/{siteId}/variables/{variableId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Get variable](https://appwrite.io/docs/references/cloud/server-rest/sites)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | Site unique ID. |
| `variableId` | path | `string` | yes | Variable unique ID. |
