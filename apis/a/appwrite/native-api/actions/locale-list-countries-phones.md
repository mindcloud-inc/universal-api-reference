# List countries phone codes with Appwrite

Retrieves a list of countries phone codes from Appwrite.

## Endpoint

- **Method:** `GET`
- **Path:** `/locale/countries/phones`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [List countries phone codes](https://appwrite.io/docs/references/cloud/server-rest/locale)
