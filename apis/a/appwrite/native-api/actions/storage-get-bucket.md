# Get bucket with Appwrite

Retrieves bucket details from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/storage/buckets/{bucketId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Get bucket](https://appwrite.io/docs/references/cloud/server-rest/storage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bucketId` | path | `string` | yes | Bucket unique ID. |
