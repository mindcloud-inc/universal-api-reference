# Get the SSL certificate for a domain with Appwrite

Retrieves Appwrite SSL certificate details for a domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/health/certificate`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Get the SSL certificate for a domain](https://appwrite.io/docs/references/cloud/server-rest/health)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | no | string |
