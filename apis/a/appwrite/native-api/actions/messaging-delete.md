# Delete message with Appwrite

Deletes the message from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/messaging/messages/{messageId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete message](https://appwrite.io/docs/references/cloud/server-rest/messaging)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `messageId` | path | `string` | yes | Message ID. |
