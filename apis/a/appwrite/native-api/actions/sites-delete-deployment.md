# Delete deployment with Appwrite

Deletes the deployment from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sites/{siteId}/deployments/{deploymentId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete deployment](https://appwrite.io/docs/references/cloud/server-rest/sites)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | Site ID. |
| `deploymentId` | path | `string` | yes | Deployment ID. |
