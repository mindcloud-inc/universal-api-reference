# Delete site with Appwrite

Deletes the site from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sites/{siteId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete site](https://appwrite.io/docs/references/cloud/server-rest/sites)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | Site ID. |
