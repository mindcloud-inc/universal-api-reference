# Get team membership with Appwrite

Retrieves the team membership from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/{teamId}/memberships/{membershipId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Get team membership](https://appwrite.io/docs/references/cloud/server-rest/teams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | Team ID. |
| `membershipId` | path | `string` | yes | Membership ID. |
