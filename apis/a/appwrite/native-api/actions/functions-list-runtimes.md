# List runtimes with Appwrite

Retrieves a list of runtimes from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/functions/runtimes`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [List runtimes](https://appwrite.io/docs/references/cloud/server-rest/functions)
