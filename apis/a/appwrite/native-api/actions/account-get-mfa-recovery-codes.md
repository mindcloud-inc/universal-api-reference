# List MFA recovery codes with Appwrite

Retrieves a list of MFA recovery codes from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/mfa/recovery-codes`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [List MFA recovery codes](https://appwrite.io/docs/references/cloud/server-rest/account)
