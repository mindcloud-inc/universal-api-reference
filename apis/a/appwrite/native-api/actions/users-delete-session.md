# Delete user session with Appwrite

Deletes the user session from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/{userId}/sessions/{sessionId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete user session](https://appwrite.io/docs/references/cloud/server-rest/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | User ID. |
| `sessionId` | path | `string` | yes | Session ID. |
