# Update preferences with Appwrite

Updates the preferences in your Appwrite project.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/account/prefs`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Update preferences](https://appwrite.io/docs/references/cloud/server-rest/account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `prefs` | body | `object` | yes | Prefs key-value JSON object. |
