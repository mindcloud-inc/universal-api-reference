# Update MFA recovery codes (regenerate) with Appwrite

Regenerates MFA recovery codes in Appwrite.

## Endpoint

- **Method:** `PUT`
- **Path:** `/users/{userId}/mfa/recovery-codes`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Update MFA recovery codes (regenerate)](https://appwrite.io/docs/references/cloud/server-rest/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | User ID. |
