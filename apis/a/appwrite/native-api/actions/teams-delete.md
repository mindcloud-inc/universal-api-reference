# Delete team with Appwrite

Deletes the team from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/teams/{teamId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete team](https://appwrite.io/docs/references/cloud/server-rest/teams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | Team ID. |
