# Create transaction with Appwrite

Creates a new transaction in your Appwrite project.

## Endpoint

- **Method:** `POST`
- **Path:** `/tablesdb/transactions`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Create transaction](https://appwrite.io/docs/references/cloud/server-rest/tablesdb)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ttl` | body | `number` | no | Seconds before the transaction expires. |
