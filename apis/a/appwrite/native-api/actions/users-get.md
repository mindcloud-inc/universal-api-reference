# Get user with Appwrite

Retrieves user details from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{userId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Get user](https://appwrite.io/docs/references/cloud/server-rest/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | User ID. |
