# Delete topic with Appwrite

Deletes the topic from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/messaging/topics/{topicId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete topic](https://appwrite.io/docs/references/cloud/server-rest/messaging)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `topicId` | path | `string` | yes | Topic ID. |
