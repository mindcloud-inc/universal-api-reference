# Delete identity with Appwrite

Deletes the identity from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/account/identities/{identityId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete identity](https://appwrite.io/docs/references/cloud/server-rest/account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identityId` | path | `string` | yes | Identity ID. |
