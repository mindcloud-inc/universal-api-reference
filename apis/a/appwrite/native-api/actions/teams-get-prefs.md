# Get team preferences with Appwrite

Retrieves the team preferences from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/{teamId}/prefs`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Get team preferences](https://appwrite.io/docs/references/cloud/server-rest/teams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | Team ID. |
