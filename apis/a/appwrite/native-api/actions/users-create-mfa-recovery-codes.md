# Create MFA recovery codes with Appwrite

Creates MFA recovery codes in your Appwrite project.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/users/{userId}/mfa/recovery-codes`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Create MFA recovery codes](https://appwrite.io/docs/references/cloud/server-rest/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | User ID. |
