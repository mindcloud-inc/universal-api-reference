# Delete provider with Appwrite

Deletes the provider from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/messaging/providers/{providerId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete provider](https://appwrite.io/docs/references/cloud/server-rest/messaging)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `providerId` | path | `string` | yes | Provider ID. |
