# List factors with Appwrite

Retrieves a list of factors from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{userId}/mfa/factors`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [List factors](https://appwrite.io/docs/references/cloud/server-rest/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | User ID. |
