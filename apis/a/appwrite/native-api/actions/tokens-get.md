# Get token with Appwrite

Retrieves token details from your Appwrite project.

## Endpoint

- **Method:** `GET`
- **Path:** `/tokens/{tokenId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Get token](https://appwrite.io/docs/references/cloud/server-rest/tokens)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tokenId` | path | `string` | yes | Token ID. |
