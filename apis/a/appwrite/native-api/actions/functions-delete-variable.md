# Delete variable with Appwrite

Deletes the variable from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/functions/{functionId}/variables/{variableId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete variable](https://appwrite.io/docs/references/cloud/server-rest/functions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `functionId` | path | `string` | yes | Function unique ID. |
| `variableId` | path | `string` | yes | Variable unique ID. |
