# Delete execution with Appwrite

Deletes the execution from your Appwrite project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/functions/{functionId}/executions/{executionId}`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Delete execution](https://appwrite.io/docs/references/cloud/server-rest/functions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `functionId` | path | `string` | yes | Function ID. |
| `executionId` | path | `string` | yes | Execution ID. |
