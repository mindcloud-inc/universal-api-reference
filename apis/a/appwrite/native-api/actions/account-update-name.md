# Update name with Appwrite

Updates the name in your Appwrite project.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/account/name`
- **Base URL:** `https://cloud.appwrite.io/v1`
- **Official documentation:** [Update name](https://appwrite.io/docs/references/cloud/server-rest/account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | User name. Max length: 128 chars. |
