# Update Hosting Configuration with Agentset

Updates hosting configuration in Agentset.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/namespace/:namespaceId/hosting`
- **Base URL:** `https://api.agentset.ai`
- **Official documentation:** [Update Hosting Configuration](https://docs.agentset.ai/api-reference/endpoint/hosting/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `namespaceId` | path | `string` | yes | The Agentset namespace ID, prefixed with ns_. |
