# Delete Namespace with Agentset

Deletes a namespace from Agentset.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/namespace/:namespaceId`
- **Base URL:** `https://api.agentset.ai`
- **Official documentation:** [Delete Namespace](https://docs.agentset.ai/api-reference/endpoint/namespaces/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `namespaceId` | path | `string` | yes | The Agentset namespace ID, prefixed with ns_. |
