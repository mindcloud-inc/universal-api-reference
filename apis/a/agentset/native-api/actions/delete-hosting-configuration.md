# Delete Hosting Configuration with Agentset

Deletes hosting configuration from Agentset.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/namespace/:namespaceId/hosting`
- **Base URL:** `https://api.agentset.ai`
- **Official documentation:** [Delete Hosting Configuration](https://docs.agentset.ai/api-reference/endpoint/hosting/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `namespaceId` | path | `string` | yes | The Agentset namespace ID, prefixed with ns_. |
