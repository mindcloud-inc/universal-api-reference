# List Integrations with AWeber

Retrieves integrations from AWeber.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/integrations`
- **Base URL:** `https://api.aweber.com/1.0`
- **Official documentation:** [List Integrations](https://api.aweber.com/#tag/Integrations/paths/~1accounts~1{accountId}~1integrations/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `string` | yes |
