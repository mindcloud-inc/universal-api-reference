# Get Tags For List with AWeber

Retrieves tags for a list from AWeber.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/lists/:listId/tags`
- **Base URL:** `https://api.aweber.com/1.0`
- **Official documentation:** [Get Tags For List](https://api.aweber.com/#tag/Lists/paths/~1accounts~1{accountId}~1lists~1{listId}~1tags/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `string` | yes |
| `listId` | path | `string` | yes |
