# List Custom Fields with AWeber

Retrieves custom fields from AWeber.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/lists/:listId/custom_fields`
- **Base URL:** `https://api.aweber.com/1.0`
- **Official documentation:** [List Custom Fields](https://api.aweber.com/#tag/Custom-Fields/paths/~1accounts~1{accountId}~1lists~1{listId}~1custom_fields/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `string` | yes |
| `listId` | path | `string` | yes |
