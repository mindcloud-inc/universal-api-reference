# Get Integration with AWeber

Retrieves an integration from AWeber.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/integrations/:integrationId`
- **Base URL:** `https://api.aweber.com/1.0`
- **Official documentation:** [Get Integration](https://api.aweber.com/#tag/Integrations/paths/~1accounts~1{accountId}~1integrations~1{integrationId}/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `string` | yes |
| `integrationId` | path | `string` | no |
