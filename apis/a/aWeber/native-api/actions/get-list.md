# Get List with AWeber

Retrieves a list from AWeber.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/lists/:listId`
- **Base URL:** `https://api.aweber.com/1.0`
- **Official documentation:** [Get List](https://api.aweber.com/#tag/Lists/paths/~1accounts~1{accountId}~1lists~1{listId}/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `string` | yes |
| `listId` | path | `string` | yes |
