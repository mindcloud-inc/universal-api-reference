# List Accounts with AWeber

Retrieves accounts from AWeber.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://api.aweber.com/1.0`
- **Official documentation:** [List Accounts](https://api.aweber.com/#tag/Accounts/paths/~1accounts/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
