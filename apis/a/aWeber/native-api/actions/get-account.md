# Get Account with AWeber

Retrieves an account from AWeber.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId`
- **Base URL:** `https://api.aweber.com/1.0`
- **Official documentation:** [Get Account](https://api.aweber.com/#tag/Accounts/paths/~1accounts~1{accountId}/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `string` | yes |
