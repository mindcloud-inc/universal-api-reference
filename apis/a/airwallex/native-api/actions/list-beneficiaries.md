# List Beneficiaries with Airwallex

Retrieves saved payout beneficiaries from Airwallex.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/beneficiaries`
- **Base URL:** `https://api-demo.airwallex.com`
- **Official documentation:** [List Beneficiaries](https://www.airwallex.com/docs/payouts/beneficiaries/retrieve-beneficiaries)
