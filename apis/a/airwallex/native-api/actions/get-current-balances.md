# Get Current Balances with Airwallex

Retrieves current balances for a connected Airwallex account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/balances/current`
- **Base URL:** `https://api-demo.airwallex.com`
- **Official documentation:** [Get Current Balances](https://www.airwallex.com/docs/payments-for-platforms/compliance-support/strong-customer-authentication-(sca)/sca-for-transaction-data-retrieval)
