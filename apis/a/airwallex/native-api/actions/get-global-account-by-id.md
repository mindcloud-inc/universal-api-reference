# Get Global Account by ID with Airwallex

Retrieves a global account by ID from Airwallex.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/global_accounts/{{globalAccountId}}`
- **Base URL:** `https://api-demo.airwallex.com`
- **Official documentation:** [Get Global Account by ID](https://www.airwallex.com/docs/accounts/get-started/global-accounts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `globalAccountId` | path | `string` | no | The Airwallex global account ID to retrieve. |
