# Obtain Access Token with Airwallex

Creates an API access token in Airwallex.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/authentication/login`
- **Base URL:** `https://api-demo.airwallex.com`
- **Official documentation:** [Obtain Access Token](https://www.airwallex.com/docs/developer-tools/api/manage-api-keys)
