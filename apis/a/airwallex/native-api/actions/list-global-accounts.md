# List Global Accounts with Airwallex

Retrieves global account records from Airwallex.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/global_accounts`
- **Base URL:** `https://api-demo.airwallex.com`
- **Official documentation:** [List Global Accounts](https://www.airwallex.com/docs/accounts/get-started/global-accounts)
