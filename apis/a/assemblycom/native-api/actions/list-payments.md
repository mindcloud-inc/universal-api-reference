# List Payments with Assembly.com

Retrieves payments from Assembly.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments`
- **Base URL:** `https://api.assembly.com/v1`
- **Official documentation:** [List Payments](https://docs.assembly.com/reference/list-payments)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoiceId` | query | `string` | no | Unique ID of invoice. |
