# Retrieve Company with Assembly.com

Retrieves a company from Assembly.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:id`
- **Base URL:** `https://api.assembly.com/v1`
- **Official documentation:** [Retrieve Company](https://docs.assembly.com/reference/retrieve-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the company to retrieve |
