# Cancel Subscription with Assembly.com

Cancels an existing subscription in Assembly.com.

## Endpoint

- **Method:** `POST`
- **Path:** `/subscriptions/:id/cancel`
- **Base URL:** `https://api.assembly.com/v1`
- **Official documentation:** [Cancel Subscription](https://docs.assembly.com/reference/cancel-subscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the subscription to cancel. |
