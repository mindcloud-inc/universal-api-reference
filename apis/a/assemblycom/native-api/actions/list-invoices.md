# List Invoices with Assembly.com

Retrieves invoices from Assembly.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices`
- **Base URL:** `https://api.assembly.com/v1`
- **Official documentation:** [List Invoices](https://docs.assembly.com/reference/list-invoices)

## Capabilities

This operation supports [pagination](../README.md#pagination).
