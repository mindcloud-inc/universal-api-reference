# Retrieve Invoice with Assembly.com

Retrieves an invoice from Assembly.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:id`
- **Base URL:** `https://api.assembly.com/v1`
- **Official documentation:** [Retrieve Invoice](https://docs.assembly.com/reference/retrieve-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the invoice to retrieve. |
