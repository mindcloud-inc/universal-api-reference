# Retrieve Task with Assembly.com

Retrieves a task from Assembly.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://api.assembly.com/v1`
- **Official documentation:** [Retrieve Task](https://docs.assembly.com/reference/retrieve-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the task to retrieve. |
