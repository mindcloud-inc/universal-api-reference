# Retrieve Client with Assembly.com

Retrieves a client from Assembly.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:id`
- **Base URL:** `https://api.assembly.com/v1`
- **Official documentation:** [Retrieve Client](https://docs.assembly.com/reference/retrieve-client)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the client to retrieve |
