# Retrieve Contract with Assembly.com

Retrieves a contract from Assembly.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts/:id`
- **Base URL:** `https://api.assembly.com/v1`
- **Official documentation:** [Retrieve Contract](https://docs.assembly.com/reference/retrieve-contract)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the contract to retrieve. |
