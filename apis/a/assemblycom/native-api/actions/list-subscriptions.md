# List Subscriptions with Assembly.com

Retrieves subscriptions from Assembly.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions`
- **Base URL:** `https://api.assembly.com/v1`
- **Official documentation:** [List Subscriptions](https://docs.assembly.com/reference/list-subscriptions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
