# List Facebook and Instagram Ads with Adyntel

Retrieves Facebook and Instagram ads from Adyntel by company or page.

## Endpoint

- **Method:** `POST`
- **Path:** `/facebook`
- **Base URL:** `https://api.adyntel.com`
- **Official documentation:** [List Facebook and Instagram Ads](https://docs.adyntel.com/ad-libraries/meta)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `facebook_url` | body | `string` | no | Facebook page URL starting with https://. |
| `company_domain` | body | `string` | no | Company website. |
