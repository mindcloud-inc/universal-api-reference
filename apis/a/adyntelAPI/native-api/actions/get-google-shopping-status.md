# Get Google Shopping Status with Adyntel

Retrieves Google Shopping search results from Adyntel by search ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/google_shopping_status`
- **Base URL:** `https://api.adyntel.com`
- **Official documentation:** [Get Google Shopping Status](https://docs.adyntel.com/ad-libraries/google-shopping-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Request ID returned by the initial Google Shopping action. |
