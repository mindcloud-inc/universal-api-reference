# Search TikTok Ads with Adyntel

Finds TikTok ads in Adyntel by keyword.

## Endpoint

- **Method:** `POST`
- **Path:** `/tiktok_search`
- **Base URL:** `https://api.adyntel.com`
- **Official documentation:** [Search TikTok Ads](https://docs.adyntel.com/ad-libraries/tiktok-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyword` | body | `string` | yes | Search query for the TikTok ad library. |
