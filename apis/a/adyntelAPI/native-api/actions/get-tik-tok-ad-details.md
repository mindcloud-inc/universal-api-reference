# Get TikTok Ad Details with Adyntel

Retrieves TikTok ad details from Adyntel by ad ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/tiktok_ad_details`
- **Base URL:** `https://api.adyntel.com`
- **Official documentation:** [Get TikTok Ad Details](https://docs.adyntel.com/ad-libraries/tiktok-ad-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | TikTok ad ID. |
