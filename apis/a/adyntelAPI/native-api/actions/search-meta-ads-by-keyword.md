# Search Meta Ads by Keyword with Adyntel

Finds Meta ads in Adyntel by keyword.

## Endpoint

- **Method:** `POST`
- **Path:** `/facebook_ad_search`
- **Base URL:** `https://api.adyntel.com`
- **Official documentation:** [Search Meta Ads by Keyword](https://docs.adyntel.com/ad-libraries/meta-ad-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyword` | body | `string` | yes | Keyword to search in the Meta Ad Library. |
