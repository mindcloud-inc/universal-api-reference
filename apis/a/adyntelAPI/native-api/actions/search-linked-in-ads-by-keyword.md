# Search LinkedIn Ads by Keyword with Adyntel

Finds LinkedIn ads in Adyntel by keyword.

## Endpoint

- **Method:** `POST`
- **Path:** `/linkedin-keyword-search`
- **Base URL:** `https://api.adyntel.com`
- **Official documentation:** [Search LinkedIn Ads by Keyword](https://docs.adyntel.com/ad-libraries/linkedin-keyword-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyword` | body | `string` | yes | Keyword to search in the LinkedIn Ad Library. |
