# List Google Ads with Adyntel

Retrieves Google ads from Adyntel by company domain.

## Endpoint

- **Method:** `POST`
- **Path:** `/google`
- **Base URL:** `https://api.adyntel.com`
- **Official documentation:** [List Google Ads](https://docs.adyntel.com/ad-libraries/google)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_domain` | body | `string` | yes | Company website. |
