# List LinkedIn Ads with Adyntel

Retrieves LinkedIn ads from Adyntel by company domain.

## Endpoint

- **Method:** `POST`
- **Path:** `/linkedin`
- **Base URL:** `https://api.adyntel.com`
- **Official documentation:** [List LinkedIn Ads](https://docs.adyntel.com/ad-libraries/linkedin)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkedin_page_id` | body | `string` | no | LinkedIn page ID. |
| `company_domain` | body | `string` | no | Company website. |
