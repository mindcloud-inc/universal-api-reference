# List pending transaction events with Atlar

Retrieves pending transaction events from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2/pending-transactions/{id}/events`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List pending transaction events](https://docs.atlar.com/reference/get-financial-data-v2-pending-transactions-id-events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
