# V1 Approve Credit Transfer with Atlar

Approves a credit transfer in Atlar v1.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/credit-transfers/{id}/approvals/{approvalStepId}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Approve Credit Transfer](https://docs.atlar.com/v1/reference/put_v1-credit-transfers-id-approvals-approvalstepid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `approvalStepId` | path | `string` | yes |
