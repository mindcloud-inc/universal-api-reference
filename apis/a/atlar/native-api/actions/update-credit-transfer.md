# Update credit transfer with Atlar

Updates an existing credit transfer in Atlar.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/payments/v2/credit-transfers/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Update credit transfer](https://docs.atlar.com/reference/patch-payments-v2-credit-transfers-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
| `If-Match` | query | `string<string>` | no |
