# V1 Read account with Atlar

Retrieves an account from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Read account](https://docs.atlar.com/v1/reference/get_v1-accounts-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
