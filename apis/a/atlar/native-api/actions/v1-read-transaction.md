# V1 Read transaction with Atlar

Retrieves a transaction from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/transactions/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Read transaction](https://docs.atlar.com/v1/reference/get_v1-transactions-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
