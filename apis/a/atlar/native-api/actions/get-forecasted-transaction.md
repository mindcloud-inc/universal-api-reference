# Get forecasted transaction with Atlar

Retrieves a forecasted transaction from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics/v2beta/forecasted-transactions/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get forecasted transaction](https://docs.atlar.com/reference/get-analytics-v2beta-forecasted-transactions-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
