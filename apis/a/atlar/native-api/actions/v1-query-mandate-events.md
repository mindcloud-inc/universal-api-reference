# V1 Query Mandate events with Atlar

Retrieves mandate events from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/mandates/{id}/events`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Query Mandate events](https://docs.atlar.com/v1/reference/get_v1-mandates-id-events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
