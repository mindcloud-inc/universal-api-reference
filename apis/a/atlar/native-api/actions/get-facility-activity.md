# Get facility activity with Atlar

Retrieves a facility activity from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2beta/facilities/{id}/activities/{activityId}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get facility activity](https://docs.atlar.com/reference/get-financial-data-v2beta-facilities-id-activities-activityid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
| `activityId` | path | `string<string>` | yes |
