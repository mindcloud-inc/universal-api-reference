# Get credit transfer batch with Atlar

Retrieves a credit transfer batch from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2beta/credit-transfer-batches/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get credit transfer batch](https://docs.atlar.com/reference/get-payments-v2beta-credit-transfer-batches-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
