# V1 Update counterparty with Atlar

Updates an existing counterparty in Atlar v1.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/counterparties/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Update counterparty](https://docs.atlar.com/v1/reference/put_v1-counterparties-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
