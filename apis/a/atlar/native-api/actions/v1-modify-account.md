# V1 Modify account with Atlar

Updates an existing account in Atlar v1.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/accounts/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Modify account](https://docs.atlar.com/v1/reference/put_v1-accounts-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
