# Get entity with Atlar

Retrieves an entity from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2/entities/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get entity](https://docs.atlar.com/reference/get-financial-data-v2-entities-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
