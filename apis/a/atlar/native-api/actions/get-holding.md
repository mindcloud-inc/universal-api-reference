# Get holding with Atlar

Retrieves a holding from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2beta/portfolios/{pid}/holdings/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get holding](https://docs.atlar.com/reference/get-financial-data-v2beta-portfolios-pid-holdings-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pid` | path | `string<string>` | yes |
| `id` | path | `string<string>` | yes |
