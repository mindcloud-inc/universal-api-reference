# List counterparties with Atlar

Retrieves counterparties from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/counterparties`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List counterparties](https://docs.atlar.com/reference/get-payments-v2-counterparties)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | query | `string<string>` | no |
| `entityIdsIn[]` | query | `array<string>` | no |
