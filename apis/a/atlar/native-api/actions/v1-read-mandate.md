# V1 Read Mandate with Atlar

Retrieves a mandate from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/mandates/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Read Mandate](https://docs.atlar.com/v1/reference/get_v1-mandates-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
