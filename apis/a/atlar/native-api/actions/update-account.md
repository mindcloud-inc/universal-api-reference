# Update account with Atlar

Updates an existing account in Atlar.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/financial-data/v2/accounts/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Update account](https://docs.atlar.com/reference/patch-financial-data-v2-accounts-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
| `If-Match` | query | `string<string>` | no |
