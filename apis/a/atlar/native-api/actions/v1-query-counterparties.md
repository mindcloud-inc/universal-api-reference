# V1 Query counterparties with Atlar

Retrieves counterparties from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/counterparties`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Query counterparties](https://docs.atlar.com/v1/reference/get_v1-counterparties)
