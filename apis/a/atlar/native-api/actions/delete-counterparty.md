# Delete counterparty with Atlar

Deletes an existing counterparty from Atlar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/payments/v2/counterparties/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Delete counterparty](https://docs.atlar.com/reference/delete-payments-v2-counterparties-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
