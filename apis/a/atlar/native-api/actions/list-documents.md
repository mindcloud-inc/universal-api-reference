# List documents with Atlar

Retrieves documents from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounting/v2beta/documents`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List documents](https://docs.atlar.com/reference/get-accounting-v2beta-documents)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `glEntityId` | query | `string<string>` | no |
