# List accounts with Atlar

Retrieves accounts from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2/accounts`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List accounts](https://docs.atlar.com/reference/get-financial-data-v2-accounts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `status[]` | query | `array<string>` | no |
