# V1 Delete counterparty with Atlar

Deletes an existing counterparty from Atlar v1.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/counterparties/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Delete counterparty](https://docs.atlar.com/v1/reference/delete_v1-counterparties-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
