# Get portfolio with Atlar

Retrieves a portfolio from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2beta/portfolios/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get portfolio](https://docs.atlar.com/reference/get-financial-data-v2beta-portfolios-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
