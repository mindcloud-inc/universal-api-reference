# Delete entity with Atlar

Deletes an existing entity from Atlar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/financial-data/v2/entities/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Delete entity](https://docs.atlar.com/reference/delete-financial-data-v2-entities-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
