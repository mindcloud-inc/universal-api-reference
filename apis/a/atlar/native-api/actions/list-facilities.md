# List facilities with Atlar

Retrieves facilities from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2beta/facilities`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List facilities](https://docs.atlar.com/reference/get-financial-data-v2beta-facilities)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `closed` | query | `boolean<string>` | no |
| `expiryDate` | query | `string<string>` | no |
