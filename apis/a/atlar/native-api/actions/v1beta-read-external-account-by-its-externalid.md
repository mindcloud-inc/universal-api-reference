# V1BETA Read external account by its externalId with Atlar

Retrieves an external account by its external ID from Atlar v1beta.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta/external-accounts:getByExternalId/{externalId}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1BETA Read external account by its externalId](https://docs.atlar.com/v1/reference/get_v1beta-external-accounts-getbyexternalid-externalid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `externalId` | path | `string` | yes |
