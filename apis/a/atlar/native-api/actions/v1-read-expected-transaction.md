# V1 Read Expected Transaction with Atlar

Retrieves an expected transaction from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/expected-transactions/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Read Expected Transaction](https://docs.atlar.com/v1/reference/get_v1-expected-transactions-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
