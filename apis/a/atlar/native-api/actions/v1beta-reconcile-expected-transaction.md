# V1BETA Reconcile Expected Transaction with Atlar

Reconciles an expected transaction in Atlar v1beta.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1beta/expected-transactions/{id}:reconcile`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1BETA Reconcile Expected Transaction](https://docs.atlar.com/v1/reference/post_v1beta-expected-transactions-id-reconcile)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
