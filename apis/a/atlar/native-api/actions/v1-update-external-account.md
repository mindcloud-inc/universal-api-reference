# V1 Update external account with Atlar

Updates an existing external account in Atlar v1.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/external-accounts/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Update external account](https://docs.atlar.com/v1/reference/put_v1-external-accounts-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
