# Get account with Atlar

Retrieves an account from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2/accounts/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get account](https://docs.atlar.com/reference/get-financial-data-v2-accounts-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
