# V1 Read external account by its externalId with Atlar

Retrieves an external account by its external ID from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/external-accounts:getByExternalId/{externalId}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Read external account by its externalId](https://docs.atlar.com/v1/reference/get_v1-external-accounts-getbyexternalid-externalid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `externalId` | path | `string` | yes |
