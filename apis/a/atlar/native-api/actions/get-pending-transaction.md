# Get pending transaction with Atlar

Retrieves a pending transaction from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2/pending-transactions/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get pending transaction](https://docs.atlar.com/reference/get-financial-data-v2-pending-transactions-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
