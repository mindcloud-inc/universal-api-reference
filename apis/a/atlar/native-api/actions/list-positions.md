# List positions with Atlar

Retrieves positions from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2beta/portfolios/{pid}/holdings/{id}/positions`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List positions](https://docs.atlar.com/reference/get-financial-data-v2beta-portfolios-pid-holdings-id-positions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pid` | path | `string<string>` | yes |
| `id` | path | `string<string>` | yes |
