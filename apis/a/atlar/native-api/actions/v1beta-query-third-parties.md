# V1BETA Query Third Parties with Atlar

Retrieves third parties from Atlar v1beta.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta/third-parties`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1BETA Query Third Parties](https://docs.atlar.com/v1/reference/get_v1beta-third-parties)
