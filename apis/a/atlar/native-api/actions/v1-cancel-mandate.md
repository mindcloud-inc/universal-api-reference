# V1 Cancel Mandate with Atlar

Cancels a mandate in Atlar v1.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/mandates/{id}:cancel`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Cancel Mandate](https://docs.atlar.com/v1/reference/post_v1-mandates-id-cancel)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
