# List credit transfer batches with Atlar

Retrieves credit transfer batches from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2beta/credit-transfer-batches`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List credit transfer batches](https://docs.atlar.com/reference/get-payments-v2beta-credit-transfer-batches)
