# Get direct debit batch with Atlar

Retrieves a direct debit batch from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2beta/direct-debit-batches/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get direct debit batch](https://docs.atlar.com/reference/get-payments-v2beta-direct-debit-batches-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
