# V1BETA Read third party with Atlar

Retrieves a third party from Atlar v1beta.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta/third-parties/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1BETA Read third party](https://docs.atlar.com/v1/reference/get_v1beta-third-parties-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
