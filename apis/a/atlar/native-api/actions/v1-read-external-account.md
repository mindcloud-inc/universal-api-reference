# V1 Read external account with Atlar

Retrieves an external account from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/external-accounts/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Read external account](https://docs.atlar.com/v1/reference/get_v1-external-accounts-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
