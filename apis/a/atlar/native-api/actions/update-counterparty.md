# Update counterparty with Atlar

Updates an existing counterparty in Atlar.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/payments/v2/counterparties/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Update counterparty](https://docs.atlar.com/reference/patch-payments-v2-counterparties-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
| `If-Match` | query | `string<string>` | no |
