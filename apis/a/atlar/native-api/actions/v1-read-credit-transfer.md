# V1 Read Credit Transfer with Atlar

Retrieves a credit transfer from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/credit-transfers/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Read Credit Transfer](https://docs.atlar.com/v1/reference/get_v1-credit-transfers-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
