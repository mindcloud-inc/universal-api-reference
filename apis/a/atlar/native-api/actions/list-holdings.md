# List holdings with Atlar

Retrieves holdings from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2beta/portfolios/{id}/holdings`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List holdings](https://docs.atlar.com/reference/get-financial-data-v2beta-portfolios-id-holdings)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
