# V1 Create external account with Atlar

Creates an external account in Atlar v1.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/external-accounts`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Create external account](https://docs.atlar.com/v1/reference/post_v1-external-accounts)
