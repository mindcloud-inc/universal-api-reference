# Create counterparty with Atlar

Creates a counterparty in Atlar.

## Endpoint

- **Method:** `POST`
- **Path:** `/payments/v2/counterparties`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Create counterparty](https://docs.atlar.com/reference/post-payments-v2-counterparties)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `legalName` | body | `string<string>` | yes |
