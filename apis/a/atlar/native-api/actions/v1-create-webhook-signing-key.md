# V1 Create webhook signing key with Atlar

Creates a webhook signing key in Atlar v1.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/webhooks/{id}/keys`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Create webhook signing key](https://docs.atlar.com/v1/reference/post_v1-webhooks-id-keys)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
