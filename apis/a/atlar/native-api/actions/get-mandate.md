# Get mandate with Atlar

Retrieves a mandate from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/mandates/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get mandate](https://docs.atlar.com/reference/get-payments-v2-mandates-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
