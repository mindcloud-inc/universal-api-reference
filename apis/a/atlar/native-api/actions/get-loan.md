# Get loan with Atlar

Retrieves a loan from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2beta/loans/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get loan](https://docs.atlar.com/reference/get-financial-data-v2beta-loans-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
