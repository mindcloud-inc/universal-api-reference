# Create entity with Atlar

Creates an entity in Atlar.

## Endpoint

- **Method:** `POST`
- **Path:** `/financial-data/v2/entities`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Create entity](https://docs.atlar.com/reference/post-financial-data-v2-entities)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `legalName` | body | `string<string>` | yes |
