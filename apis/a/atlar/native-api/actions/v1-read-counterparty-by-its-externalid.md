# V1 Read counterparty by its externalId with Atlar

Retrieves a counterparty by its external ID from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/counterparties:getByExternalId/{externalId}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Read counterparty by its externalId](https://docs.atlar.com/v1/reference/get_v1-counterparties-getbyexternalid-externalid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `externalId` | path | `string` | yes |
