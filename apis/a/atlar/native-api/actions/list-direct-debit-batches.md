# List direct debit batches with Atlar

Retrieves direct debit batches from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2beta/direct-debit-batches`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List direct debit batches](https://docs.atlar.com/reference/get-payments-v2beta-direct-debit-batches)
