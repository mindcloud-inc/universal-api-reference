# V1 Query external accounts with Atlar

Retrieves external accounts from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/external-accounts`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Query external accounts](https://docs.atlar.com/v1/reference/get_v1-external-accounts)
