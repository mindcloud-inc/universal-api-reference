# V1 Reject Credit Transfer with Atlar

Rejects a credit transfer in Atlar v1.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/credit-transfers/{id}/approvals`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Reject Credit Transfer](https://docs.atlar.com/v1/reference/delete_v1-credit-transfers-id-approvals)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
