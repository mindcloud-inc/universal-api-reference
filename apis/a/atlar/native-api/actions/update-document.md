# Update document with Atlar

Updates an existing document in Atlar.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/accounting/v2beta/documents/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Update document](https://docs.atlar.com/reference/patch-accounting-v2beta-documents-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
| `If-Match` | query | `string<string>` | no |
