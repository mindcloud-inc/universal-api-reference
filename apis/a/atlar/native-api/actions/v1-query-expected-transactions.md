# V1 Query Expected Transactions with Atlar

Retrieves expected transactions from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/expected-transactions`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Query Expected Transactions](https://docs.atlar.com/v1/reference/get_v1-expected-transactions)
