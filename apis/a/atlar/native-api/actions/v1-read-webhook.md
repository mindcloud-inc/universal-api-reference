# V1 Read webhook with Atlar

Retrieves a webhook from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Read webhook](https://docs.atlar.com/v1/reference/get_v1-webhooks-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
