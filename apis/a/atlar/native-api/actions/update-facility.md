# Update facility with Atlar

Updates an existing facility in Atlar.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/financial-data/v2beta/facilities/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Update facility](https://docs.atlar.com/reference/patch-financial-data-v2beta-facilities-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
| `If-Match` | query | `string<string>` | no |
