# Update external account with Atlar

Updates an existing external account in Atlar.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/payments/v2/external-accounts/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Update external account](https://docs.atlar.com/reference/patch-payments-v2-external-accounts-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
| `If-Match` | query | `string<string>` | no |
