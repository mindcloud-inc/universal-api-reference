# Update loan with Atlar

Updates an existing loan in Atlar.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/financial-data/v2beta/loans/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Update loan](https://docs.atlar.com/reference/patch-financial-data-v2beta-loans-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
| `If-Match` | query | `string<string>` | no |
