# V1BETA Unreconcile Expected Transaction with Atlar

Unreconciles an expected transaction in Atlar v1beta.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1beta/expected-transactions/{id}:unreconcile`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1BETA Unreconcile Expected Transaction](https://docs.atlar.com/v1/reference/post_v1beta-expected-transactions-id-unreconcile)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
