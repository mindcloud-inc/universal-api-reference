# V1BETA Read Direct Debit by its externalId with Atlar

Retrieves a direct debit by its external ID from Atlar v1beta.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta/direct-debits:getByExternalId/{externalId}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1BETA Read Direct Debit by its externalId](https://docs.atlar.com/v1/reference/get_v1beta-direct-debits-getbyexternalid-externalid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `externalId` | path | `string` | yes |
