# Get credit transfer with Atlar

Retrieves a credit transfer from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/credit-transfers/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get credit transfer](https://docs.atlar.com/reference/get-payments-v2-credit-transfers-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
