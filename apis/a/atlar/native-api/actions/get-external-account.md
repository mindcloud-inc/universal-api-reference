# Get external account with Atlar

Retrieves an external account from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/external-accounts/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get external account](https://docs.atlar.com/reference/get-payments-v2-external-accounts-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
