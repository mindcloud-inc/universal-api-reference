# V1 Query Credit Transfer events with Atlar

Retrieves credit transfer events from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/credit-transfers/{id}/events`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Query Credit Transfer events](https://docs.atlar.com/v1/reference/get_v1-credit-transfers-id-events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
