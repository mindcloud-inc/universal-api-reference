# Get direct debit with Atlar

Retrieves a direct debit from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/direct-debits/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get direct debit](https://docs.atlar.com/reference/get-payments-v2-direct-debits-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
