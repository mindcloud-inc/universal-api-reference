# V1 Query Direct Debit events with Atlar

Retrieves direct debit events from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/direct-debits/{id}/events`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Query Direct Debit events](https://docs.atlar.com/v1/reference/get_v1-direct-debits-id-events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
