# List pending transactions with Atlar

Retrieves pending transactions from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2/pending-transactions`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List pending transactions](https://docs.atlar.com/reference/get-financial-data-v2-pending-transactions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | query | `string<string>` | no |
| `date` | query | `string<string>` | no |
