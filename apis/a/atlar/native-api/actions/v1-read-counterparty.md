# V1 Read counterparty with Atlar

Retrieves a counterparty from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/counterparties/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Read counterparty](https://docs.atlar.com/v1/reference/get_v1-counterparties-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
