# V1 Update webhook with Atlar

Updates an existing webhook in Atlar v1.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/webhooks/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Update webhook](https://docs.atlar.com/v1/reference/put_v1-webhooks-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
