# List counterparty events with Atlar

Retrieves counterparty events from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/counterparties/{id}/events`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List counterparty events](https://docs.atlar.com/reference/get-payments-v2-counterparties-id-events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
