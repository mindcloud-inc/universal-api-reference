# List regulatory reporting codes with Atlar

Retrieves regulatory reporting codes from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/regulatory-reporting-codes`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List regulatory reporting codes](https://docs.atlar.com/reference/get-payments-v2-regulatory-reporting-codes)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `market` | query | `string<string>` | yes |
