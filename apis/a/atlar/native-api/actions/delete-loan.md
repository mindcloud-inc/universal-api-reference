# Delete loan with Atlar

Deletes an existing loan from Atlar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/financial-data/v2beta/loans/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Delete loan](https://docs.atlar.com/reference/delete-financial-data-v2beta-loans-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
| `If-Match` | query | `string<string>` | no |
