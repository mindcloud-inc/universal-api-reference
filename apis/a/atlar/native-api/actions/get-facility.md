# Get facility with Atlar

Retrieves a facility from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2beta/facilities/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get facility](https://docs.atlar.com/reference/get-financial-data-v2beta-facilities-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
