# V1 Read Direct Debit with Atlar

Retrieves a direct debit from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/direct-debits/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Read Direct Debit](https://docs.atlar.com/v1/reference/get_v1-direct-debits-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
