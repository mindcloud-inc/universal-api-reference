# Delete external account with Atlar

Deletes an existing external account from Atlar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/payments/v2/external-accounts/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Delete external account](https://docs.atlar.com/reference/delete-payments-v2-external-accounts-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
