# Delete facility with Atlar

Deletes an existing facility from Atlar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/financial-data/v2beta/facilities/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Delete facility](https://docs.atlar.com/reference/delete-financial-data-v2beta-facilities-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
| `If-Match` | query | `string<string>` | no |
