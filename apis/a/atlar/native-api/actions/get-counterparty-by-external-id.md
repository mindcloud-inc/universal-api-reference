# Get counterparty by external ID with Atlar

Retrieves a counterparty from Atlar by external ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/counterparties/external:{externalId}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get counterparty by external ID](https://docs.atlar.com/docs/migrate-from-v1-to-v2)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `externalId` | path | `string` | yes |
