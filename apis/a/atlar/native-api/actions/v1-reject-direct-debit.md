# V1 Reject Direct Debit with Atlar

Rejects a direct debit in Atlar v1.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/direct-debits/{id}/approvals`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Reject Direct Debit](https://docs.atlar.com/v1/reference/delete_v1-direct-debits-id-approvals)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
