# Get document with Atlar

Retrieves a document from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounting/v2beta/documents/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get document](https://docs.atlar.com/reference/get-accounting-v2beta-documents-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
