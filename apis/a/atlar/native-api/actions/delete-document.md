# Delete document with Atlar

Deletes an existing document from Atlar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/accounting/v2beta/documents/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Delete document](https://docs.atlar.com/reference/delete-accounting-v2beta-documents-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
