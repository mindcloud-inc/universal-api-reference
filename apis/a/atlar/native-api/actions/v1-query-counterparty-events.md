# V1 Query Counterparty events with Atlar

Retrieves counterparty events from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/counterparties/{id}/events`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Query Counterparty events](https://docs.atlar.com/v1/reference/get_v1-counterparties-id-events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
