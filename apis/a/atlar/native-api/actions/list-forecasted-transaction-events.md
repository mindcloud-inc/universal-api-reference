# List forecasted transaction events with Atlar

Retrieves forecasted transaction events from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics/v2beta/forecasted-transactions/{id}/events`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List forecasted transaction events](https://docs.atlar.com/reference/get-analytics-v2beta-forecasted-transactions-id-events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
