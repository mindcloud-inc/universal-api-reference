# V1 Query Transaction events with Atlar

Retrieves transaction events from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/transactions/{id}/events`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Query Transaction events](https://docs.atlar.com/v1/reference/get_v1-transactions-id-events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
