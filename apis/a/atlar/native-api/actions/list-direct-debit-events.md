# List direct debit events with Atlar

Retrieves direct debit events from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/direct-debits/{id}/events`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List direct debit events](https://docs.atlar.com/reference/get-payments-v2-direct-debits-id-events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
