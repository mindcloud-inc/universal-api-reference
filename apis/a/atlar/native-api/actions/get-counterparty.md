# Get counterparty with Atlar

Retrieves a counterparty from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/counterparties/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get counterparty](https://docs.atlar.com/reference/get-payments-v2-counterparties-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
