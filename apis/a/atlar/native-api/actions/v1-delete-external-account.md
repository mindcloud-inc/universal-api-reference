# V1 Delete external account with Atlar

Deletes an existing external account from Atlar v1.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/external-accounts/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Delete external account](https://docs.atlar.com/v1/reference/delete_v1-external-accounts-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
