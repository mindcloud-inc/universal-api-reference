# Update entity with Atlar

Updates an existing entity in Atlar.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/financial-data/v2/entities/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Update entity](https://docs.atlar.com/reference/patch-financial-data-v2-entities-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
| `If-Match` | query | `string<string>` | no |
