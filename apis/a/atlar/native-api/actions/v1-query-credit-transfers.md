# V1 Query Credit Transfers with Atlar

Retrieves credit transfers from Atlar v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/credit-transfers`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Query Credit Transfers](https://docs.atlar.com/v1/reference/get_v1-credit-transfers)
