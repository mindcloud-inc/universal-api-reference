# List credit transfer events with Atlar

Retrieves credit transfer events from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/credit-transfers/{id}/events`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List credit transfer events](https://docs.atlar.com/reference/get-payments-v2-credit-transfers-id-events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
