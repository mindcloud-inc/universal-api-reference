# List audit log entries with Atlar

Retrieves audit log entries from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/iam/v2beta/audit-log-entries`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List audit log entries](https://docs.atlar.com/reference/get-iam-v2beta-audit-log-entries)
