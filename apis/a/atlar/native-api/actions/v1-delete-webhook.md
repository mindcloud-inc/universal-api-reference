# V1 Delete webhook with Atlar

Deletes an existing webhook from Atlar v1.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/webhooks/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [V1 Delete webhook](https://docs.atlar.com/v1/reference/delete_v1-webhooks-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
