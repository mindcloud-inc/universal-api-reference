# List mandate events with Atlar

Retrieves mandate events from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/mandates/{id}/events`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List mandate events](https://docs.atlar.com/reference/get-payments-v2-mandates-id-events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
