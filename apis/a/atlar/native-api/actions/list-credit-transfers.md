# List credit transfers with Atlar

Retrieves credit transfers from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/v2/credit-transfers`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List credit transfers](https://docs.atlar.com/reference/get-payments-v2-credit-transfers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | query | `string<string>` | no |
| `status` | query | `string<string>` | no |
| `date` | query | `string<string>` | no |
| `batchId` | query | `string<string>` | no |
