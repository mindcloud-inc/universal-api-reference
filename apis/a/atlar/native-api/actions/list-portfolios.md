# List portfolios with Atlar

Retrieves portfolios from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2beta/portfolios`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [List portfolios](https://docs.atlar.com/reference/get-financial-data-v2beta-portfolios)
