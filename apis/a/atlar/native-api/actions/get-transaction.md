# Get transaction with Atlar

Retrieves a transaction from Atlar.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-data/v2/transactions/{id}`
- **Base URL:** `https://api.atlar.com`
- **Official documentation:** [Get transaction](https://docs.atlar.com/reference/get-financial-data-v2-transactions-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string<string>` | yes |
