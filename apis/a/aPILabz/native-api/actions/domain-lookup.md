# Domain Lookup with API Labz

Retrieves domain information from API Labz.

## Endpoint

- **Method:** `POST`
- **Path:** `/module/131`
- **Base URL:** `https://hub.apilabz.com`
- **Official documentation:** [Domain Lookup](https://apilabz.apidog.io/domain-lookup-15128896e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | yes | Domain name to lookup |
