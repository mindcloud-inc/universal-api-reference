# VAT Validator with API Labz

Validates a VAT number with API Labz.

## Endpoint

- **Method:** `POST`
- **Path:** `/module/114`
- **Base URL:** `https://hub.apilabz.com`
- **Official documentation:** [VAT Validator](https://apilabz.apidog.io/vat-validator-15128890e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vatNumber` | body | `string` | yes | VAT number to validate |
