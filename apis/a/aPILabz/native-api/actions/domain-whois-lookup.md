# Domain WHOIS Lookup with API Labz

Retrieves WHOIS details for a domain in API Labz.

## Endpoint

- **Method:** `POST`
- **Path:** `/module/614`
- **Base URL:** `https://hub.apilabz.com`
- **Official documentation:** [Domain WHOIS Lookup](https://apilabz.apidog.io/domain-whois-lookup-15128905e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | yes | Domain name to lookup |
