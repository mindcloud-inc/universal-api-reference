# Get Database Tree with ActivityInfo

Retrieves a database tree from ActivityInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/databases/:databaseId`
- **Base URL:** `https://www.activityinfo.org`
- **Official documentation:** [Get Database Tree](https://www.activityinfo.org/support/docs/api/reference/getDatabaseTree.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `databaseId` | path | `string` | yes | ActivityInfo database ID. |
