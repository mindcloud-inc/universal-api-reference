# Get Database Billing Account with ActivityInfo

Retrieves a database's billing account from ActivityInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/databases/:databaseId/billingAccount`
- **Base URL:** `https://www.activityinfo.org`
- **Official documentation:** [Get Database Billing Account](https://www.activityinfo.org/support/docs/api/reference/getDatabaseBillingAccount.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `databaseId` | path | `string` | yes | ActivityInfo database ID. |
