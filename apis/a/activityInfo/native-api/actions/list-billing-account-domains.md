# List Billing Account Domains with ActivityInfo

Retrieves domains for an ActivityInfo billing account.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/billingAccounts/:accountId/domains`
- **Base URL:** `https://www.activityinfo.org`
- **Official documentation:** [List Billing Account Domains](https://www.activityinfo.org/support/docs/api/reference/getBillingAccountDomains.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | ActivityInfo billing account ID. |
