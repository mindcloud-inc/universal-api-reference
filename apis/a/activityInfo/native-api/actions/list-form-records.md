# List Form Records with ActivityInfo

Retrieves records from a specific ActivityInfo form.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/form/:formId/query`
- **Base URL:** `https://www.activityinfo.org`
- **Official documentation:** [List Form Records](https://www.activityinfo.org/support/docs/api/reference/getFormRecords.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | ActivityInfo form ID. |
