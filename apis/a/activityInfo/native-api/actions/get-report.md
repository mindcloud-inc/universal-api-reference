# Get Report with ActivityInfo

Retrieves a specific report from ActivityInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/reports/:reportId`
- **Base URL:** `https://www.activityinfo.org`
- **Official documentation:** [Get Report](https://www.activityinfo.org/support/docs/api/reference/getReport.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `string` | yes | ActivityInfo report ID. |
