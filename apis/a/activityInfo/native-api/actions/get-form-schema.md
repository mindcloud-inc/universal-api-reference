# Get Form Schema with ActivityInfo

Retrieves a form schema from ActivityInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/form/:formId/schema`
- **Base URL:** `https://www.activityinfo.org`
- **Official documentation:** [Get Form Schema](https://www.activityinfo.org/support/docs/api/reference/getFormSchema.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | ActivityInfo form ID. |
