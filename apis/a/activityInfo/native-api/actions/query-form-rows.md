# Query Form Rows with ActivityInfo

Queries rows for a specific ActivityInfo form.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/query/v43/form/:formId`
- **Base URL:** `https://www.activityinfo.org`
- **Official documentation:** [Query Form Rows](https://www.activityinfo.org/support/docs/api/reference/queryFormRows.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | ActivityInfo form ID. |
