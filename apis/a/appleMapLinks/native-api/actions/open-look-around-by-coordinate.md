# Open Look Around By Coordinate with Apple Map Links

Opens Apple Maps Look Around by coordinate.

## Endpoint

- **Method:** `GET`
- **Path:** `/look-around`
- **Base URL:** `https://maps.apple.com`
- **Official documentation:** [Open Look Around By Coordinate](https://developer.apple.com/documentation/mapkit/unified-map-urls)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `coordinate` | query | `string` | yes | Look Around start location as latitude,longitude. |
