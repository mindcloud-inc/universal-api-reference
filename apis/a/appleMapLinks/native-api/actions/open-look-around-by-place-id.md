# Open Look Around By Place ID with Apple Map Links

Opens Apple Maps Look Around by Place ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/look-around`
- **Base URL:** `https://maps.apple.com`
- **Official documentation:** [Open Look Around By Place ID](https://developer.apple.com/documentation/mapkit/unified-map-urls)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `place-id` | query | `string` | yes | Apple Maps Place ID for the Look Around start location. |
