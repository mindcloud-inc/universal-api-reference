# Open Look Around By Address with Apple Map Links

Opens Apple Maps Look Around by address.

## Endpoint

- **Method:** `GET`
- **Path:** `/look-around`
- **Base URL:** `https://maps.apple.com`
- **Official documentation:** [Open Look Around By Address](https://developer.apple.com/documentation/mapkit/unified-map-urls)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | query | `string` | yes | Look Around start location as an address string. |
