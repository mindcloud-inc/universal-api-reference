# Apple Map Links: Native API Reference

A consolidated summary of Apple Map Links's API configuration and 17 documented operations, with links to official documentation.

- **Official docs:** https://developer.apple.com/documentation/mapkit/unified-map-urls
- **API base URL:** `https://maps.apple.com`

## Authentication

### No Auth

No credentials required. Apple Maps links are public URL constructions.

This API does not require request authentication.

[Official authentication documentation](https://developer.apple.com/documentation/mapkit/unified-map-urls)
