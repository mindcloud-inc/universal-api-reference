# Get File Details with Autype

Retrieves tool file details from Autype.

## Endpoint

- **Method:** `GET`
- **Path:** `/tools/files/{fileId}`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Get File Details](https://docs.autype.com/api-reference/developer-api/get-file-details)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
