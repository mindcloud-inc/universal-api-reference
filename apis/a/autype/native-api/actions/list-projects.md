# List Projects with Autype

Retrieves projects from Autype.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [List Projects](https://docs.autype.com/api-reference/developer-api/list-projects)

## Capabilities

This operation supports [pagination](../README.md#pagination).
