# Download Bulk Render Output ZIP with Autype

Downloads a bulk render output ZIP from Autype.

## Endpoint

- **Method:** `GET`
- **Path:** `/bulk-render/{bulkJobId}/download`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Download Bulk Render Output ZIP](https://docs.autype.com/api-reference/developer-api/download-bulk-render-output-zip)
