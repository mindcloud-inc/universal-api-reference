# Get Render Job Status with Autype

Retrieves render job status from Autype.

## Endpoint

- **Method:** `GET`
- **Path:** `/render/{jobId}`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Get Render Job Status](https://docs.autype.com/api-reference/developer-api/get-render-job-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `jobId` | path | `string` | yes |
