# List Temporary Images with Autype

Retrieves temporary images from Autype.

## Endpoint

- **Method:** `GET`
- **Path:** `/images`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [List Temporary Images](https://docs.autype.com/api-reference/developer-api/list-temporary-images)
