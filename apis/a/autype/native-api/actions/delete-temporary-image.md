# Delete Temporary Image with Autype

Deletes a temporary image from Autype.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/images/{imageId}`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Delete Temporary Image](https://docs.autype.com/api-reference/developer-api/delete-temporary-image)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `imageId` | path | `string` | yes |
