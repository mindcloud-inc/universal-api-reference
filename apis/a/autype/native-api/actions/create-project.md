# Create Project with Autype

Creates a new project in Autype.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Create Project](https://docs.autype.com/api-reference/developer-api/create-project)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `description` | body | `string` | no |
| `name` | body | `string` | yes |
