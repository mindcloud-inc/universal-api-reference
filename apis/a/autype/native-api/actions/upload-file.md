# Upload File with Autype

Uploads a tool file to Autype.

## Endpoint

- **Method:** `POST`
- **Path:** `/tools/files/upload`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Upload File](https://docs.autype.com/api-reference/developer-api/upload-a-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file` | body | `file` | yes |
