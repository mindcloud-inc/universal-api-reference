# List Documents with Autype

Retrieves documents from Autype.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [List Documents](https://docs.autype.com/api-reference/developer-api/list-documents.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | query | `string` | no |
