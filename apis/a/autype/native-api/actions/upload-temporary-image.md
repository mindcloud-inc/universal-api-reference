# Upload Temporary Image with Autype

Uploads a temporary image to Autype.

## Endpoint

- **Method:** `POST`
- **Path:** `/images/upload`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Upload Temporary Image](https://docs.autype.com/api-reference/developer-api/upload-temporary-image)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file` | body | `file` | yes |
