# Validate Document JSON with Autype

Validates document JSON content in Autype.

## Endpoint

- **Method:** `POST`
- **Path:** `/render/validate`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Validate Document JSON](https://docs.autype.com/api-reference/developer-api/validate-document-json)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `config` | body | `object` | yes |
| `strict` | query | `boolean` | no |
