# Get Document with Autype

Retrieves a document from Autype.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/{documentId}`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Get Document](https://docs.autype.com/api-reference/developer-api/get-document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `documentId` | path | `string` | yes |
