# Get Bulk Render Job Status with Autype

Retrieves bulk render job status from Autype.

## Endpoint

- **Method:** `GET`
- **Path:** `/bulk-render/{bulkJobId}`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Get Bulk Render Job Status](https://docs.autype.com/api-reference/developer-api/get-bulk-render-job-status)
