# Delete File with Autype

Deletes an existing tool file from Autype.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tools/files/{fileId}`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Delete File](https://docs.autype.com/api-reference/developer-api/delete-a-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
