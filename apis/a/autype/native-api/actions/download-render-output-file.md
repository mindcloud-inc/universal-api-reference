# Download Render Output File with Autype

Downloads a render output file from Autype.

## Endpoint

- **Method:** `GET`
- **Path:** `/render/{jobId}/download`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Download Render Output File](https://docs.autype.com/api-reference/developer-api/download-render-output-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `jobId` | path | `string` | yes |
