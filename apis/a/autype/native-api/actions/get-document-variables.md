# Get Document Variables with Autype

Retrieves document variables from Autype.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/{documentId}/variables`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Get Document Variables](https://docs.autype.com/api-reference/developer-api/get-document-variables)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `documentId` | path | `string` | yes |
