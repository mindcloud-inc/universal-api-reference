# Download File with Autype

Downloads a tool file from Autype.

## Endpoint

- **Method:** `GET`
- **Path:** `/tools/files/{fileId}/download`
- **Base URL:** `https://api.autype.com/api/v1/dev`
- **Official documentation:** [Download File](https://docs.autype.com/api-reference/developer-api/download-a-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
