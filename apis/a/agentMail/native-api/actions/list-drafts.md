# List Drafts with Agent Mail

Retrieves drafts from AgentMail for the authenticated account.

## Endpoint

- **Method:** `GET`
- **Path:** `/drafts`
- **Base URL:** `https://api.agentmail.to/v0`
- **Official documentation:** [List Drafts](https://docs.agentmail.to/api-reference/drafts/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
