# List Threads with Agent Mail

Retrieves threads from AgentMail for the authenticated account.

## Endpoint

- **Method:** `GET`
- **Path:** `/threads`
- **Base URL:** `https://api.agentmail.to/v0`
- **Official documentation:** [List Threads](https://docs.agentmail.to/api-reference/threads/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
