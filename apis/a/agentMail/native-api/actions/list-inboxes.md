# List Inboxes with Agent Mail

Retrieves inboxes from AgentMail for the authenticated account.

## Endpoint

- **Method:** `GET`
- **Path:** `/inboxes`
- **Base URL:** `https://api.agentmail.to/v0`
- **Official documentation:** [List Inboxes](https://docs.agentmail.to/api-reference/inboxes/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
