# Delete Webhook with Agent Mail

Deletes an existing webhook from AgentMail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/{webhook_id}`
- **Base URL:** `https://api.agentmail.to/v0`
- **Official documentation:** [Delete Webhook](https://docs.agentmail.to/api-reference/webhooks/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes | The AgentMail webhook ID. |
