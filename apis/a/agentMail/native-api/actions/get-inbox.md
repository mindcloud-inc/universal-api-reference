# Get Inbox with Agent Mail

Retrieves a specific inbox from AgentMail.

## Endpoint

- **Method:** `GET`
- **Path:** `/inboxes/{inbox_id}`
- **Base URL:** `https://api.agentmail.to/v0`
- **Official documentation:** [Get Inbox](https://docs.agentmail.to/api-reference/inboxes/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inbox_id` | path | `string` | yes | The AgentMail inbox ID. |
