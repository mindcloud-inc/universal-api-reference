# Get Thread with Agent Mail

Retrieves a specific thread from AgentMail.

## Endpoint

- **Method:** `GET`
- **Path:** `/threads/{thread_id}`
- **Base URL:** `https://api.agentmail.to/v0`
- **Official documentation:** [Get Thread](https://docs.agentmail.to/api-reference/threads/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `thread_id` | path | `string` | yes | The AgentMail thread ID. |
