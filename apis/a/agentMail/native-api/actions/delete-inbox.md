# Delete Inbox with Agent Mail

Deletes an existing inbox from AgentMail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inboxes/{inbox_id}`
- **Base URL:** `https://api.agentmail.to/v0`
- **Official documentation:** [Delete Inbox](https://docs.agentmail.to/api-reference/inboxes/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inbox_id` | path | `string` | yes | The AgentMail inbox ID. |
