# Get Webhook with Agent Mail

Retrieves a specific webhook from AgentMail.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/{webhook_id}`
- **Base URL:** `https://api.agentmail.to/v0`
- **Official documentation:** [Get Webhook](https://docs.agentmail.to/api-reference/webhooks/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes | The AgentMail webhook ID. |
