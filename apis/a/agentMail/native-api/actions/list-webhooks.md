# List Webhooks with Agent Mail

Retrieves webhooks from AgentMail for the authenticated account.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.agentmail.to/v0`
- **Official documentation:** [List Webhooks](https://docs.agentmail.to/api-reference/webhooks/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
