# List Send Reports with Audienceful

Retrieves a list of send reports from Audienceful.

## Endpoint

- **Method:** `GET`
- **Path:** `/emails/reports`
- **Base URL:** `https://app.audienceful.com/api`
- **Official documentation:** [List Send Reports](https://developer.audienceful.com/api-reference/sendReports/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search send reports that match the provided string. |
