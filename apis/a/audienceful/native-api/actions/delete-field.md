# Delete Field with Audienceful

Deletes an existing custom field from Audienceful.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/people/fields/{{id}}/`
- **Base URL:** `https://app.audienceful.com/api`
- **Official documentation:** [Delete Field](https://developer.audienceful.com/api-reference/fields/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Audienceful field id. |
