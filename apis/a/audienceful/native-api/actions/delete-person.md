# Delete Person with Audienceful

Deletes an existing person from Audienceful.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/people/`
- **Base URL:** `https://app.audienceful.com/api`
- **Official documentation:** [Delete Person](https://developer.audienceful.com/api-reference/people/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | The email of the person you wish to delete. |
