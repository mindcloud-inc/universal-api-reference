# Generate Luma Video with Apiframe

Creates a Luma video generation task in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/luma-imagine`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Generate Luma Video](https://docs.apiframe.ai/luma-ai-api/imagine)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `prompt` | body | `string` | yes |
