# Extend Suno Song with Apiframe

Creates a Suno song extension task in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/suno-extend`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Extend Suno Song](https://docs.apiframe.ai/suno-ai-api/extend)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `parent_task_id` | body | `string` | yes |
