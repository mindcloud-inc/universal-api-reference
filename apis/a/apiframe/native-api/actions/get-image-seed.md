# Get Image Seed with Apiframe

Retrieves an Apiframe image seed by task ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/seed`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Get Image Seed](https://docs.apiframe.ai/api-endpoints/seed)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | body | `string` | yes |
