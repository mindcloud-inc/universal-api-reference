# Generate Udio Song with Apiframe

Creates a Udio song generation task in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/udio-generate`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Generate Udio Song](https://docs.apiframe.ai/udio-ai-api/generate-a-song)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `lyrics` | body | `string` | no |
