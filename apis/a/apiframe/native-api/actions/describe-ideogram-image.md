# Describe Ideogram Image with Apiframe

Creates an Ideogram image description task in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/ideogram-describe`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Describe Ideogram Image](https://docs.apiframe.ai/ideogram/describe)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `image_url` | body | `string` | yes |
