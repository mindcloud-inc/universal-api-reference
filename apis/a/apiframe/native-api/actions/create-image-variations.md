# Create Image Variations with Apiframe

Creates image variations from a previous Apiframe task.

## Endpoint

- **Method:** `POST`
- **Path:** `/variations`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Create Image Variations](https://docs.apiframe.ai/api-endpoints/variations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `parent_task_id` | body | `string` | yes |
| `index` | body | `string` | yes |
