# Pan Image with Apiframe

Creates an image panning task in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/pan`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Pan Image](https://docs.apiframe.ai/api-endpoints/pan)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `parent_task_id` | body | `string` | yes |
| `direction` | body | `string` | yes |
