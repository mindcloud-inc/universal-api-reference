# Upload Image with Apiframe

Uploads an image to Apiframe and returns its URL.

## Endpoint

- **Method:** `POST`
- **Path:** `/upload`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Upload Image](https://docs.apiframe.ai/media-upload-apis/upload-image)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `image` | body | `file` | yes |
