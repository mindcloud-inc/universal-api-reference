# Extend Luma Video with Apiframe

Creates a Luma video extension task in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/luma-extend`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Extend Luma Video](https://docs.apiframe.ai/luma-ai-api/extend)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `parent_task_id` | body | `string` | yes |
| `prompt` | body | `string` | yes |
