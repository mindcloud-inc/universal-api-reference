# Swap Face with Apiframe

Creates a face swap task in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/faceswap`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Swap Face](https://docs.apiframe.ai/api-endpoints/faceswap)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `target_image_url` | body | `string` | yes |
| `swap_image_url` | body | `string` | yes |
