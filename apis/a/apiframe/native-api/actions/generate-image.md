# Generate Image with Apiframe

Creates an image generation task in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/imagine`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Generate Image](https://docs.apiframe.ai/api-endpoints/imagine)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `prompt` | body | `string` | yes |
