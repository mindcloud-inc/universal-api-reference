# Get Task Result with Apiframe

Retrieves an Apiframe task result by task ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/fetch`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Get Task Result](https://docs.apiframe.ai/api-endpoints/fetch)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | body | `string` | yes |
