# Reroll Images with Apiframe

Creates rerolled images from a previous Apiframe task.

## Endpoint

- **Method:** `POST`
- **Path:** `/reroll`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Reroll Images](https://docs.apiframe.ai/api-endpoints/reroll)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `parent_task_id` | body | `string` | yes |
