# Blend Images with Apiframe

Creates an image blending task in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/blend`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Blend Images](https://docs.apiframe.ai/api-endpoints/blend)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `image_urls[]` | body | `array<string>` | yes |
