# Generate Suno Song with Apiframe

Creates a Suno song generation task in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/suno-imagine`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Generate Suno Song](https://docs.apiframe.ai/suno-ai-api/imagine)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `prompt` | body | `string` | no |
