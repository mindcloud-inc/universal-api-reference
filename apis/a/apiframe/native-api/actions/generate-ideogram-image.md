# Generate Ideogram Image with Apiframe

Creates an Ideogram image generation task in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/ideogram-imagine`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Generate Ideogram Image](https://docs.apiframe.ai/ideogram/imagine)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `prompt` | body | `string` | yes |
