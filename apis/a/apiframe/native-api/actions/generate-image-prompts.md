# Generate Image Prompts with Apiframe

Creates four image prompts from an image in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/describe`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Generate Image Prompts](https://docs.apiframe.ai/api-endpoints/describe)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `image_url` | body | `string` | yes |
