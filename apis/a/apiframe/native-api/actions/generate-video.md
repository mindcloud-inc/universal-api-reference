# Generate Video with Apiframe

Creates a video generation task in Apiframe.

## Endpoint

- **Method:** `POST`
- **Path:** `/imagine-video`
- **Base URL:** `https://api.apiframe.pro`
- **Official documentation:** [Generate Video](https://docs.apiframe.ai/api-endpoints/imagine-video)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `prompt` | body | `string` | yes |
| `image_url` | body | `string` | yes |
