# List App Collections with AppFollow

Retrieves app collections from AppFollow.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/account/apps`
- **Base URL:** `https://api.appfollow.io`
- **Official documentation:** [List App Collections](https://docs.api.appfollow.io/reference/app_collections_list_api_v2_account_apps_get-1)
