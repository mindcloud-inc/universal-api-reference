# List Collection Apps with AppFollow

Retrieves apps from an AppFollow collection.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/account/apps/app`
- **Base URL:** `https://api.appfollow.io`
- **Official documentation:** [List Collection Apps](https://docs.api.appfollow.io/reference/list_of_apps_from_the_collection_api_v2_account_apps_app_get-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `apps_id` | query | `number` | yes | Collection ID. |
