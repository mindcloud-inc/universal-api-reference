# ARForms: Native API Reference

A consolidated summary of ARForms's API configuration, with links to official documentation.

- **Official docs:** https://www.arformsplugin.com/documentation/

## Authentication

### No authentication

ARForms sends form submissions to a MindCloud-generated webhook URL without provider credentials.

This API does not require request authentication.

[Official authentication documentation](https://www.arformsplugin.com/documentation/custom-webhook-url/)
