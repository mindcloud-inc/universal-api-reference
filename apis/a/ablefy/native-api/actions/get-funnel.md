# Get Funnel with Ablefy

Retrieves a funnel from Ablefy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/funnels/:id`
- **Base URL:** `https://api.myablefy.com`
- **Official documentation:** [Get Funnel](https://api.myablefy.com/api/swagger_doc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Funnel ID. |
