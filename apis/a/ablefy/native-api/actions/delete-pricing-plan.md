# Delete Pricing Plan with Ablefy

Deletes an existing pricing plan from Ablefy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/pricing_plans/:id`
- **Base URL:** `https://api.myablefy.com`
- **Official documentation:** [Delete Pricing Plan](https://api.myablefy.com/api/swagger_doc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pricing plan ID. |
