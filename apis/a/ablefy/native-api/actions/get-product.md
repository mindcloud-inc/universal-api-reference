# Get Product with Ablefy

Retrieves a product from Ablefy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/products/:id`
- **Base URL:** `https://api.myablefy.com`
- **Official documentation:** [Get Product](https://api.myablefy.com/api/swagger_doc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Product ID. |
