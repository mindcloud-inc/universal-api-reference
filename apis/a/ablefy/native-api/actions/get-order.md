# Get Order with Ablefy

Retrieves an order from Ablefy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/orders/:id`
- **Base URL:** `https://api.myablefy.com`
- **Official documentation:** [Get Order](https://api.myablefy.com/api/swagger_doc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Order ID. |
