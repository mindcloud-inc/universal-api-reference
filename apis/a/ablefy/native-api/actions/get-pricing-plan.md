# Get Pricing Plan with Ablefy

Retrieves a pricing plan from Ablefy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/pricing_plans/:id`
- **Base URL:** `https://api.myablefy.com`
- **Official documentation:** [Get Pricing Plan](https://api.myablefy.com/api/swagger_doc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pricing plan ID. |
