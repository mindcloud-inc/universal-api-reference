# Delete Funnel with Ablefy

Deletes an existing funnel from Ablefy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/funnels/:id`
- **Base URL:** `https://api.myablefy.com`
- **Official documentation:** [Delete Funnel](https://api.myablefy.com/api/swagger_doc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Funnel ID. |
