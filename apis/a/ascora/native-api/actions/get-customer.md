# Get Customer with Ascora

Retrieves a customer from Ascora.

## Endpoint

- **Method:** `GET`
- **Path:** `/Customers/Customer/{{id}}`
- **Base URL:** `https://api.ascora.com.au`
- **Official documentation:** [Get Customer](https://www.dropbox.com/scl/fi/75586ygs35arfb7d3cvxi/API-Endpoints-1.2.pdf?rlkey=ztci7pf4nuasegnybjreqsqe2&dl=0#page=9)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Ascora customer ID. |
