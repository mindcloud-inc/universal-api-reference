# List Contacts For Customer with Ascora

Retrieves contacts for a customer from Ascora.

## Endpoint

- **Method:** `GET`
- **Path:** `/Customers/GetContactsForCustomer/{{customerId}}`
- **Base URL:** `https://api.ascora.com.au`
- **Official documentation:** [List Contacts For Customer](https://www.dropbox.com/scl/fi/75586ygs35arfb7d3cvxi/API-Endpoints-1.2.pdf?rlkey=ztci7pf4nuasegnybjreqsqe2&dl=0#page=11)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | no | Ascora customer ID. |
