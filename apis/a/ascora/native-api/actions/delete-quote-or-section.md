# Delete Quote Or Section with Ascora

Deletes a quote or quote section from Ascora.

## Endpoint

- **Method:** `POST`
- **Path:** `/Quotes/DeleteQuote`
- **Base URL:** `https://api.ascora.com.au`
- **Official documentation:** [Delete Quote Or Section](https://www.dropbox.com/scl/fi/75586ygs35arfb7d3cvxi/API-Endpoints-1.2.pdf?rlkey=ztci7pf4nuasegnybjreqsqe2&dl=0#page=45)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `quoteNumber` | body | `string` | no | Quotation or quotation section number to delete. |
