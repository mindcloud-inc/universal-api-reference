# Get Supplier Invoice with Ascora

Retrieves a supplier invoice from Ascora.

## Endpoint

- **Method:** `GET`
- **Path:** `/SupplierInvoices/SupplierInvoice/{{id}}`
- **Base URL:** `https://api.ascora.com.au`
- **Official documentation:** [Get Supplier Invoice](https://www.dropbox.com/scl/fi/75586ygs35arfb7d3cvxi/API-Endpoints-1.2.pdf?rlkey=ztci7pf4nuasegnybjreqsqe2&dl=0#page=62)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Supplier Invoice ID. |
