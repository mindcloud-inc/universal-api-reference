# Get Public Domain Rating with Ahrefs

## Endpoint

- **Method:** `GET`
- **Path:** `/public/domain-rating-free`
- **Base URL:** `https://api.ahrefs.com/v3`
- **Official documentation:** [Get Public Domain Rating](https://docs.ahrefs.com/en/api/reference/public/get-domain-rating-free)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Domain or URL to analyze with the free public endpoint. |
