# Get Domain Rating with Ahrefs

## Endpoint

- **Method:** `GET`
- **Path:** `/site-explorer/domain-rating`
- **Base URL:** `https://api.ahrefs.com/v3`
- **Official documentation:** [Get Domain Rating](https://docs.ahrefs.com/en/api/reference/site-explorer/get-domain-rating)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Domain or URL to analyze. |
| `date` | query | `date` | yes | Report date in YYYY-MM-DD format. |
