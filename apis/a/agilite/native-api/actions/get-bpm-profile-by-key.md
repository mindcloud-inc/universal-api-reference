# Get BPM Profile By Key with Agilite

Retrieves BPM profiles from Agilite by profile key.

## Endpoint

- **Method:** `GET`
- **Path:** `/bpm/getByProfileKey`
- **Base URL:** `https://api.agilite.io`
- **Official documentation:** [Get BPM Profile By Key](https://docs.agilite.io/reference/getbyprofilekey-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profile-key` | query | `string` | yes | BPM profile key. |
