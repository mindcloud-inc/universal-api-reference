# Generate Number with Agilite

Generates a unique number in Agilite by profile key.

## Endpoint

- **Method:** `POST`
- **Path:** `/numbering/generate`
- **Base URL:** `https://api.agilite.io`
- **Official documentation:** [Generate Number](https://docs.agilite.io/reference/generate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profile-key` | query | `string` | yes | Numbering profile key to generate from. |
