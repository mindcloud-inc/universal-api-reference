# Delete Payment with Alegra

Deletes an existing payment from Alegra.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/payments/:id`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [Delete Payment](https://developer.alegra.com/reference/delete_payments-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
