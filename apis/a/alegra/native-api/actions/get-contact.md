# Get Contact with Alegra

Retrieves a contact from your Alegra account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [Get Contact](https://developer.alegra.com/reference/contactsdetails-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `fields` | query | `string` | no |
