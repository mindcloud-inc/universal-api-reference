# Restore Contact with Alegra

Restores a deleted contact in Alegra.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts/restore/:id`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [Restore Contact](https://developer.alegra.com/reference/restorecontact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
