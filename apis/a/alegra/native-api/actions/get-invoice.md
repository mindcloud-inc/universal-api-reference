# Get Invoice with Alegra

Retrieves a sales invoice from Alegra.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:id`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [Get Invoice](https://developer.alegra.com/reference/get_invoices-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `fields` | query | `string` | no |
