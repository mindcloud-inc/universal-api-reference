# List Items with Alegra

Retrieves items from your Alegra account.

## Endpoint

- **Method:** `GET`
- **Path:** `/items`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [List Items](https://developer.alegra.com/reference/get_items)
