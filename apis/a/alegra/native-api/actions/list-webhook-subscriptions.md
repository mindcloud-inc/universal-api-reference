# List Webhook Subscriptions with Alegra

Retrieves webhook subscriptions from your Alegra account.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/subscriptions`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [List Webhook Subscriptions](https://developer.alegra.com/reference/get_webhooks-subscriptions)
