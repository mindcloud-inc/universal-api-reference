# List Contacts with Alegra

Retrieves contacts from your Alegra account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [List Contacts](https://developer.alegra.com/reference/listcontacts-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `metadata` | query | `boolean` | no |
| `start` | query | `number` | no |
| `limit` | query | `number` | no |
| `order_direction` | query | `string` | no |
| `order_field` | query | `string` | no |
| `query` | query | `string` | no |
| `identification` | query | `string` | no |
| `name` | query | `string` | no |
| `type` | query | `string` | no |
| `mode` | query | `string` | no |
