# Delete Invoice with Alegra

Deletes an existing sales invoice from Alegra.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/invoices/:id`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [Delete Invoice](https://developer.alegra.com/reference/delete_invoices-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
