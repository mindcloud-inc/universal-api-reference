# Get Item with Alegra

Retrieves an item from your Alegra account.

## Endpoint

- **Method:** `GET`
- **Path:** `/items/:id`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [Get Item](https://developer.alegra.com/reference/get_items-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `fields` | query | `string` | no |
