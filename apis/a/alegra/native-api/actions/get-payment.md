# Get Payment with Alegra

Retrieves a payment from your Alegra account.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/:id`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [Get Payment](https://developer.alegra.com/reference/get_payments-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
| `fields` | query | `string` | no |
