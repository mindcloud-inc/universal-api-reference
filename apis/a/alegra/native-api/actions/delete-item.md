# Delete Item with Alegra

Deletes an existing item from Alegra.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/items/:id`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [Delete Item](https://developer.alegra.com/reference/delete_items-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
