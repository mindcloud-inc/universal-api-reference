# Delete Webhook Subscription with Alegra

Deletes a webhook subscription from Alegra.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/subscriptions/:id`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [Delete Webhook Subscription](https://developer.alegra.com/reference/delete_webhooks-subscriptions-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
