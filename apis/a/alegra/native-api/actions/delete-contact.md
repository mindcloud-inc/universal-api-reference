# Delete Contact with Alegra

Deletes an existing contact from Alegra.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.alegra.com/api/v1`
- **Official documentation:** [Delete Contact](https://developer.alegra.com/reference/deletecontact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
