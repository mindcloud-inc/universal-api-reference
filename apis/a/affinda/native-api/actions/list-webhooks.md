# Get list of all resthook subscriptions with Affinda

Retrieves all resthook subscriptions from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/resthook_subscriptions`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get list of all resthook subscriptions](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | The numbers of results to return. |
| `offset` | query | `string` | no | The number of documents to skip before starting to collect the result set. |
