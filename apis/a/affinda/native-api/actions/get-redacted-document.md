# Get redacted document with Affinda

Retrieves a redacted document from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/documents/:identifier/redacted`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get redacted document](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Document identifier |
