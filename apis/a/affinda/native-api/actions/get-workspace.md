# Get specific workspace with Affinda

Retrieves a specific workspace from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/workspaces/:identifier`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get specific workspace](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Workspace's identifier |
