# Get specific tag with Affinda

Retrieves a specific tag from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/tags/:id`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get specific tag](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Tag's ID |
