# Get specific resthook subscription with Affinda

Retrieves a specific resthook subscription from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/resthook_subscriptions/:id`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get specific resthook subscription](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resthook subscription's ID |
