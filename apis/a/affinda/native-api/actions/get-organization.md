# Get detail of an organization with Affinda

Retrieves a specific organization from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/organizations/:identifier`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get detail of an organization](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Organization identifier. |
