# Get specific extractor with Affinda

Retrieves a specific extractor from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/extractors/:identifier`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get specific extractor](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Extractor's identifier |
