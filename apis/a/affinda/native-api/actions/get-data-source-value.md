# Get specific data source value with Affinda

Retrieves a specific Affinda mapping data source value.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/mapping_data_sources/:identifier/values/:value`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get specific data source value](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Data source's identifier |
| `value` | path | `string` | yes | — |
