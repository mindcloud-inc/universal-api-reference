# Get specific data source with Affinda

Retrieves a specific mapping data source from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/mapping_data_sources/:identifier`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get specific data source](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Data source's identifier |
