# Get list of all annotations with Affinda

Retrieves annotations for an Affinda document.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/annotations`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get list of all annotations](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | query | `string` | yes | Filter by document. |
