# Get specific workspace membership with Affinda

Retrieves a specific workspace membership from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/workspace_memberships/:identifier`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get specific workspace membership](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Workspace membership's identifier. |
