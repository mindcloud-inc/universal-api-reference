# Get specific annotation with Affinda

Retrieves a specific annotation from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/annotations/:id`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get specific annotation](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Annotation's ID |
