# Get a document type with Affinda

Retrieves a specific document type from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/document_types/:identifier`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get a document type](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Document type identifier |
