# Get specific validation result with Affinda

Retrieves a specific validation result from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/validation_results/:id`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [Get specific validation result](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Validation result's ID. |
