# List document types with Affinda

Retrieves accessible document types from Affinda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/document_types`
- **Base URL:** `https://api.us1.affinda.com`
- **Official documentation:** [List document types](https://docs.affinda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization` | query | `string` | no | Filter by organization identifier |
| `workspace` | query | `string` | no | Filter by workspace identifier |
