# Retrieve calendar subscriber with AddEvent

## Endpoint

- **Method:** `GET`
- **Path:** `/subscribers/:subscriber_id`
- **Base URL:** `https://api.addevent.com/calevent/v2`
- **Official documentation:** [Retrieve calendar subscriber](https://docs.addevent.com/reference/retrieve-calendar-subscriber)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscriber_id` | path | `string` | yes | Unique identifier for the calendar subscriber. |
