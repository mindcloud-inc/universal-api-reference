# Delete RSVP attendee with AddEvent

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rsvps/:attendee_id`
- **Base URL:** `https://api.addevent.com/calevent/v2`
- **Official documentation:** [Delete RSVP attendee](https://docs.addevent.com/reference/delete-rsvp-attendee)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `attendee_id` | path | `string` | yes | Unique identifier for the RSVP attendee. |
