# Delete calendar with AddEvent

## Endpoint

- **Method:** `DELETE`
- **Path:** `/calendars/:calendar_id`
- **Base URL:** `https://api.addevent.com/calevent/v2`
- **Official documentation:** [Delete calendar](https://docs.addevent.com/reference/delete-calendar)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `calendar_id` | path | `string` | yes | Unique identifier for the calendar. |
