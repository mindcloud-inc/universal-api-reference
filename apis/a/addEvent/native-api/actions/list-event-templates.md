# List event templates with AddEvent

## Endpoint

- **Method:** `GET`
- **Path:** `/events/templates`
- **Base URL:** `https://api.addevent.com/calevent/v2`
- **Official documentation:** [List event templates](https://docs.addevent.com/reference/list-event-templates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | query | `string` | no | Template type to return. |
