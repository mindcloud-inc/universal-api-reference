# Delete event with AddEvent

## Endpoint

- **Method:** `DELETE`
- **Path:** `/events/:event_id`
- **Base URL:** `https://api.addevent.com/calevent/v2`
- **Official documentation:** [Delete event](https://docs.addevent.com/reference/delete-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | Unique identifier for the event. |
