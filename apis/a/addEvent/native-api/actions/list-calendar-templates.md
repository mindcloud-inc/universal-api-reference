# List calendar templates with AddEvent

## Endpoint

- **Method:** `GET`
- **Path:** `/calendars/templates`
- **Base URL:** `https://api.addevent.com/calevent/v2`
- **Official documentation:** [List calendar templates](https://docs.addevent.com/reference/list-calendar-templates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | query | `string` | no | Calendar template type to return. |
