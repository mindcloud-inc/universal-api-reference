# Get Contact with Anabix CRM

Retrieves a contact from Anabix CRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api`
- **Base URL:** `https://app.anabix.cz`
- **Official documentation:** [Get Contact](https://www.anabix.cz/wp-content/uploads/2025/02/anabix_api_manual-2025.pdf)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `idContact` | body | `number` | yes |
