# List Event Series with Airmeet

Finds event series in an Airmeet community.

## Endpoint

- **Method:** `GET`
- **Path:** `/event-series`
- **Base URL:** `https://api-gateway-prod.us.airmeet.com/prod`
- **Official documentation:** [List Event Series](https://help.airmeet.com/support/solutions/articles/82000912150-4-manage-event-series-airmeet-public-api)
