# Obtain Access Token with Airmeet

Creates a new access token in Airmeet.

## Endpoint

- **Method:** `POST`
- **Path:** `/auth`
- **Base URL:** `https://api-gateway-prod.us.airmeet.com/prod`
- **Official documentation:** [Obtain Access Token](https://help.airmeet.com/support/solutions/articles/82000909768-1-event-details-airmeet-public-api)
