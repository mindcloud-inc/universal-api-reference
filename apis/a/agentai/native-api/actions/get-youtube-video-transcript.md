# Get YouTube Video Transcript with Agent.ai

Retrieves a YouTube transcript from Agent.ai by video URL.

## Endpoint

- **Method:** `POST`
- **Path:** `/action/get_youtube_transcript`
- **Base URL:** `https://api-lr.agent.ai/v1`
- **Official documentation:** [Get YouTube Video Transcript](https://docs.agent.ai/api-reference/get-data/youtube-video-transcript)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | URL of the YouTube video. |
