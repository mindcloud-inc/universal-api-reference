# Get LinkedIn Profile with Agent.ai

Retrieves a LinkedIn profile from Agent.ai by handle.

## Endpoint

- **Method:** `POST`
- **Path:** `/action/get_linkedin_profile`
- **Base URL:** `https://api-lr.agent.ai/v1`
- **Official documentation:** [Get LinkedIn Profile](https://docs.agent.ai/api-reference/get-data/get-linkedin-profile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profile_handle` | body | `string` | yes | LinkedIn profile handle to retrieve details. |
