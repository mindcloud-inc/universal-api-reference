# Get YouTube Channel Data with Agent.ai

Retrieves YouTube channel data from Agent.ai by channel or video URL.

## Endpoint

- **Method:** `POST`
- **Path:** `/action/get_youtube_channel`
- **Base URL:** `https://api-lr.agent.ai/v1`
- **Official documentation:** [Get YouTube Channel Data](https://docs.agent.ai/api-reference/get-data/youtube-channel-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | URL of the YouTube channel or video to inspect. |
