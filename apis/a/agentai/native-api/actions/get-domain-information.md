# Get Domain Information with Agent.ai

Retrieves domain registration data from Agent.ai by domain.

## Endpoint

- **Method:** `POST`
- **Path:** `/action/domain_info`
- **Base URL:** `https://api-lr.agent.ai/v1`
- **Official documentation:** [Get Domain Information](https://docs.agent.ai/api-reference/get-data/get-domain-information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | yes | Domain name to retrieve information for. |
