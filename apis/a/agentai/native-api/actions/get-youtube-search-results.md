# Get YouTube Search Results with Agent.ai

Finds YouTube search results in Agent.ai by query.

## Endpoint

- **Method:** `POST`
- **Path:** `/action/run_youtube_search`
- **Base URL:** `https://api-lr.agent.ai/v1`
- **Official documentation:** [Get YouTube Search Results](https://docs.agent.ai/api-reference/get-data/youtube-search-results)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search terms for YouTube. |
