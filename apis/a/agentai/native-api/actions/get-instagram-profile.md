# Get Instagram Profile with Agent.ai

Retrieves an Instagram profile from Agent.ai by username.

## Endpoint

- **Method:** `POST`
- **Path:** `/action/get_instagram_profile`
- **Base URL:** `https://api-lr.agent.ai/v1`
- **Official documentation:** [Get Instagram Profile](https://docs.agent.ai/api-reference/get-data/get-instagram-profile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | body | `string` | yes | Instagram username without @. |
