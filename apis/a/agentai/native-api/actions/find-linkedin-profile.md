# Find LinkedIn Profile with Agent.ai

Finds a LinkedIn profile slug in Agent.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/action/find_linkedin_profile`
- **Base URL:** `https://api-lr.agent.ai/v1`
- **Official documentation:** [Find LinkedIn Profile](https://docs.agent.ai/api-reference/get-data/find-linkedin-profile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Text query to find the LinkedIn profile slug. |
