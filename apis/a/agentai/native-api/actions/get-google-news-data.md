# Get Google News Data with Agent.ai

Finds Google News articles in Agent.ai by query.

## Endpoint

- **Method:** `POST`
- **Path:** `/action/get_google_news`
- **Base URL:** `https://api-lr.agent.ai/v1`
- **Official documentation:** [Get Google News Data](https://docs.agent.ai/api-reference/get-data/google-news-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search query for Google News results. |
