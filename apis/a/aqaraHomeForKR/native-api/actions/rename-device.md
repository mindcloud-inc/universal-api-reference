# Rename Device with Aqara Home for KR

Updates a device name in Aqara Home for KR.

## Endpoint

- **Method:** `POST`
- **Path:** `v3.0/open/api`
- **Base URL:** `https://open-kr.aqara.com`
- **Official documentation:** [Rename Device](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/DeviceManagement.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `intent` | body | `string` | no |
