# List Gateway Subdevices with Aqara Home for KR

Retrieves subdevices for a gateway in Aqara Home for KR.

## Endpoint

- **Method:** `POST`
- **Path:** `v3.0/open/api`
- **Base URL:** `https://open-kr.aqara.com`
- **Official documentation:** [List Gateway Subdevices](https://opendoc.aqara.com/en/docs/developmanual/apiDocument/DeviceManagement.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `did` | body | `string` | yes | Gateway ID. |
