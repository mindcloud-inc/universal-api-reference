# List Reporting Unit Types with AIHW MyHospitals

Retrieves reporting unit types from AIHW MyHospitals.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/reporting-unit-types`
- **Base URL:** `https://myhospitalsapi.aihw.gov.au`
- **Official documentation:** [List Reporting Unit Types](https://myhospitalsapi.aihw.gov.au/swagger/v1/swagger.json)
