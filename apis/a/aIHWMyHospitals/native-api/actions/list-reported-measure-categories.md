# List Reported Measure Categories with AIHW MyHospitals

Retrieves reported measure categories from AIHW MyHospitals.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/reported-measure-categories`
- **Base URL:** `https://myhospitalsapi.aihw.gov.au`
- **Official documentation:** [List Reported Measure Categories](https://myhospitalsapi.aihw.gov.au/swagger/v1/swagger.json)
