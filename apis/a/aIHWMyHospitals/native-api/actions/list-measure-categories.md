# List Measure Categories with AIHW MyHospitals

Retrieves measure categories from AIHW MyHospitals.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/measure-categories`
- **Base URL:** `https://myhospitalsapi.aihw.gov.au`
- **Official documentation:** [List Measure Categories](https://myhospitalsapi.aihw.gov.au/swagger/v1/swagger.json)
