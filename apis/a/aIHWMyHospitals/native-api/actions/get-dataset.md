# Get Dataset with AIHW MyHospitals

Retrieves a dataset from AIHW MyHospitals.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/datasets/{dataset-id}`
- **Base URL:** `https://myhospitalsapi.aihw.gov.au`
- **Official documentation:** [Get Dataset](https://myhospitalsapi.aihw.gov.au/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataset-id` | path | `number` | yes | The dataset id. |
