# Send Notification To User with Alpha TransForm

Sends an email or SMS notification to a user in Alpha TransForm.

## Endpoint

- **Method:** `POST`
- **Path:** `/SendNotificationToUser`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [Send Notification To User](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/SendNotificationToUser.xml)
