# Get API Keys with Alpha TransForm

Retrieves API keys from Alpha TransForm.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetAPIKeys`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [Get API Keys](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/GetAPIKeys.xml)
