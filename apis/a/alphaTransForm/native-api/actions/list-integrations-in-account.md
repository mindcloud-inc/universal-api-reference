# List Integrations In Account with Alpha TransForm

Retrieves connected applications from Alpha TransForm.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetListOfIntegrationsForAccount`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [List Integrations In Account](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/GetListOfIntegrationsForAccount.xml)
