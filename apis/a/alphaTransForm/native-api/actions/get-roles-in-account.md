# Get Roles In Account with Alpha TransForm

Retrieves account roles from Alpha TransForm.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetRolesInAccount`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [Get Roles In Account](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/GetRolesInAccount.xml)
