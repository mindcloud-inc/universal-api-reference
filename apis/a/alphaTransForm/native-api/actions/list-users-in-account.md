# List Users In Account with Alpha TransForm

Retrieves account users from Alpha TransForm.

## Endpoint

- **Method:** `GET`
- **Path:** `/getUsersInTransformAccount`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [List Users In Account](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/GetUsersInTransformAccount.xml)
