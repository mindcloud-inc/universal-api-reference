# Get API Scope Codes with Alpha TransForm

Retrieves API scope codes from Alpha TransForm.

## Endpoint

- **Method:** `GET`
- **Path:** `/getAPIScopeCodes`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [Get API Scope Codes](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/GetAPIScopeCodes.xml)
