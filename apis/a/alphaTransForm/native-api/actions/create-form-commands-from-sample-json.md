# Create Form Commands From Sample JSON with Alpha TransForm

Retrieves generated form commands from sample JSON in Alpha TransForm.

## Endpoint

- **Method:** `POST`
- **Path:** `/CreateFormCommandsFromSampleJSON`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [Create Form Commands From Sample JSON](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/CreateFormCommandsFromSampleJSON.xml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `json` | body | `string` | no | sample json data from which the form definition commands should be created |
