# Change Form Instance Status with Alpha TransForm

Updates a form instance status in Alpha TransForm.

## Endpoint

- **Method:** `GET`
- **Path:** `/ChangeFormInstanceStatus`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [Change Form Instance Status](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/ChangeFormInstanceStatus.xml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formInstanceId` | query | `string` | no | statusCharacter The new status for the form |
