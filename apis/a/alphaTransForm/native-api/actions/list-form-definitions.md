# List Form Definitions with Alpha TransForm

Retrieves form definitions from Alpha TransForm.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetListOfFormDefinitionsForAccount`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [List Form Definitions](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/GetListOfFormDefinitionsForAccount.xml)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `includeFormDefinitions` | query | `boolean` | no |
