# Get Form Definition with Alpha TransForm

Retrieves a form definition from Alpha TransForm.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetFormDefinitionForFormId/:formId`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [Get Form Definition](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/GetFormDefinitionForFormId.xml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | FormId of the form definition |
