# Get Form Media Field Names with Alpha TransForm

Retrieves form media field names from Alpha TransForm.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetFormMediaFieldNamesForFormId/:formId`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [Get Form Media Field Names](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/GetFormMediaFieldNamesForFormId.xml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | Form Id of the form definition |
