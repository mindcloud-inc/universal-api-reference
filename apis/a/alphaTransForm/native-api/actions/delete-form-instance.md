# Delete Form Instance with Alpha TransForm

Deletes an existing form instance from Alpha TransForm.

## Endpoint

- **Method:** `GET`
- **Path:** `/DeleteFormInstance/:formInstanceId`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [Delete Form Instance](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/DeleteFormInstance.xml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formInstanceId` | path | `string` | yes | id for form instance |
