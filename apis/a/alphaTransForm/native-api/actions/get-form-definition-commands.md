# Get Form Definition Commands with Alpha TransForm

Retrieves form definition commands from Alpha TransForm.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetFormDefinitionCommandsForFormId/:formId`
- **Base URL:** `https://transform.alphasoftware.com/transformAPIVersion1.a5svc`
- **Official documentation:** [Get Form Definition Commands](https://documentation.alphasoftware.com/TransFormDocumentation/pages/Ref/API/GetFormDefinitionCommandsForFormId.xml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | Form definition id. |
