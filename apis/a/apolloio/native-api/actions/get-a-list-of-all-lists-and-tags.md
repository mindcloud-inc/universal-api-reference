# Get Lists and Tags with Apollo

Retrieves information about all lists and tags in your Apollo account. This action can be used to check available lists before using the Create a Contact action.

## Endpoint

- **Method:** `GET`
- **Path:** `v1/labels`
- **Base URL:** `https://app.apollo.io/api`
- **Official documentation:** [Get Lists and Tags](https://docs.apollo.io/reference/get-a-list-of-all-lists)
