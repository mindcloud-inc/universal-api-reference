# Get User Profile Info with Apollo

Retrieves the authorized user profile from Apollo.

## Endpoint

- **Method:** `GET`
- **Path:** `v1/users/api_profile`
- **Base URL:** `https://app.apollo.io/api`
- **Official documentation:** [Get User Profile Info](https://docs.apollo.io/docs/use-oauth-20-authorization-flow-to-access-apollo-user-information-partners#get-user-profile-info)
