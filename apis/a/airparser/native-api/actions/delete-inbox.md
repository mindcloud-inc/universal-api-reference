# Delete Inbox with Airparser

Deletes an existing inbox from Airparser.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inboxes/:inbox_id`
- **Base URL:** `https://api.airparser.com`
- **Official documentation:** [Delete Inbox](https://help.airparser.com/public-api/public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inbox_id` | path | `string` | yes | The Airparser inbox ID to delete. |
