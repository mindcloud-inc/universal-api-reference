# Get Extended Document Details with Airparser

Retrieves extended document details from Airparser.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/:document_id/extended`
- **Base URL:** `https://api.airparser.com`
- **Official documentation:** [Get Extended Document Details](https://help.airparser.com/public-api/public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Airparser document ID. |
