# Get Campaign Statistics with Atlas AI Revenue Engine

## Endpoint

- **Method:** `GET`
- **Path:** `/call/stats/:id`
- **Base URL:** `https://api.youratlas.com/v1/api`
- **Official documentation:** [Get Campaign Statistics](https://apidocs.youratlas.com/get-campaign-statistics-26105303e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The campaign ID. |
