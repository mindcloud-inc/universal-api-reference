# List Campaign Bookings with Atlas AI Revenue Engine

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/:campaignId/bookings`
- **Base URL:** `https://api.youratlas.com/v1/api`
- **Official documentation:** [List Campaign Bookings](https://apidocs.youratlas.com/get-bookings-for-campaign-26754251e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The campaign ID. |
