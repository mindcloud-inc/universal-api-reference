# List Call Bookings with Atlas AI Revenue Engine

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/:campaignId/bookings/callId/:callId`
- **Base URL:** `https://api.youratlas.com/v1/api`
- **Official documentation:** [List Call Bookings](https://apidocs.youratlas.com/get-bookings-for-call-26754252e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `callId` | path | `string` | yes | The call ID. |
| `campaignId` | path | `string` | yes | The campaign ID. |
