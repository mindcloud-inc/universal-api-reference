# Attach Knowledge Base File to Campaign with Atlas AI Revenue Engine

## Endpoint

- **Method:** `POST`
- **Path:** `/knowledgebase/:campaignId/:rowKey`
- **Base URL:** `https://api.youratlas.com/v1/api`
- **Official documentation:** [Attach Knowledge Base File to Campaign](https://apidocs.youratlas.com/attach-file-to-campaign-26917876e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The campaign ID. |
| `rowKey` | path | `string` | yes | The file row key. |
