# Create Scheduled Call with Atlas AI Revenue Engine

## Endpoint

- **Method:** `POST`
- **Path:** `/campaign/createschedule`
- **Base URL:** `https://api.youratlas.com/v1/api`
- **Official documentation:** [Create Scheduled Call](https://apidocs.youratlas.com/create-scheduled-call-26754250e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | body | `string` | yes | The campaign ID. |
| `customerName` | body | `string` | yes | Customer name. |
| `customerPhoneNumber` | body | `string` | yes | Customer phone number. |
