# List Call Records with Atlas AI Revenue Engine

## Endpoint

- **Method:** `GET`
- **Path:** `/call`
- **Base URL:** `https://api.youratlas.com/v1/api`
- **Official documentation:** [List Call Records](https://apidocs.youratlas.com/get-call-records-26753535e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assistantId` | query | `string` | no | Filter by assistant ID. |
| `callType` | query | `string` | no | Filter by call type. |
| `campaignId` | query | `string` | no | Filter by campaign ID. |
| `campaignType` | query | `string` | no | Filter by campaign type. |
| `customerPhoneNumber` | query | `string` | no | Filter by customer phone number. |
| `endDate` | query | `string` | no | Filter by end date (date-time). |
| `startDate` | query | `string` | no | Filter by start date (date-time). |
| `successResult` | query | `string` | no | Filter by success result. |
