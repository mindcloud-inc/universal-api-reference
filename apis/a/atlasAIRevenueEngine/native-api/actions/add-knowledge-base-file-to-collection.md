# Add Knowledge Base File to Collection with Atlas AI Revenue Engine

## Endpoint

- **Method:** `POST`
- **Path:** `/knowledgebase/:id/tag`
- **Base URL:** `https://api.youratlas.com/v1/api`
- **Official documentation:** [Add Knowledge Base File to Collection](https://apidocs.youratlas.com/add-file-to-collection-26917878e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The file ID. |
| `tagName` | body | `string` | yes | The collection or tag name. |
