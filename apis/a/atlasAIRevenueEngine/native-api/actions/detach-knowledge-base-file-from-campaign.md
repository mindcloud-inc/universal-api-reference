# Detach Knowledge Base File from Campaign with Atlas AI Revenue Engine

## Endpoint

- **Method:** `DELETE`
- **Path:** `/knowledgebase/:campaignId/:rowKey`
- **Base URL:** `https://api.youratlas.com/v1/api`
- **Official documentation:** [Detach Knowledge Base File from Campaign](https://apidocs.youratlas.com/detach-file-from-campaign-26917877e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The campaign ID. |
| `rowKey` | path | `string` | yes | The file row key. |
