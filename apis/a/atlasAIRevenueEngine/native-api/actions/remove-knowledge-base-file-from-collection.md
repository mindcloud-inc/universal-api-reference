# Remove Knowledge Base File from Collection with Atlas AI Revenue Engine

## Endpoint

- **Method:** `DELETE`
- **Path:** `/knowledgebase/:rowKey/tag/:collectionName`
- **Base URL:** `https://api.youratlas.com/v1/api`
- **Official documentation:** [Remove Knowledge Base File from Collection](https://apidocs.youratlas.com/remove-file-from-collection-26917879e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionName` | path | `string` | yes | The collection name. |
| `rowKey` | path | `string` | yes | The file row key. |
