# Extract Browser HTML With Session Context with Automatic Data Extraction

Extracts browser HTML with session context in Automatic Data Extraction.

## Endpoint

- **Method:** `POST`
- **Path:** `/extract`
- **Base URL:** `https://api.zyte.com/v1`
- **Official documentation:** [Extract Browser HTML With Session Context](https://docs.zyte.com/zyte-api/usage/features.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Absolute URL to extract data from. |
