# Extract Product With Custom Attributes From Browser HTML Only with Automatic Data Extraction

Extracts product custom attributes from browser HTML only in Automatic Data Extraction.

## Endpoint

- **Method:** `POST`
- **Path:** `/extract`
- **Base URL:** `https://api.zyte.com/v1`
- **Official documentation:** [Extract Product With Custom Attributes From Browser HTML Only](https://docs.zyte.com/zyte-api/usage/extract/custom-attributes.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customAttributes` | body | `object` | yes | — |
| `url` | body | `string` | yes | Absolute URL to extract data from. |
