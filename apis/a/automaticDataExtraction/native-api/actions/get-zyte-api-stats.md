# Get Zyte API Stats with Automatic Data Extraction

Retrieves Zyte API usage stats from Automatic Data Extraction.

## Endpoint

- **Method:** `GET`
- **Path:** `https://zyte-api-stats.zyte.com/api/stats`
- **Base URL:** `https://api.zyte.com/v1`
- **Official documentation:** [Get Zyte API Stats](https://docs.zyte.com/zyte-api/usage/stats.html)
