# Extract HTTP Body With Server Session Setup with Automatic Data Extraction

Extracts HTTP response body with server session setup in Automatic Data Extraction.

## Endpoint

- **Method:** `POST`
- **Path:** `/extract`
- **Base URL:** `https://api.zyte.com/v1`
- **Official documentation:** [Extract HTTP Body With Server Session Setup](https://docs.zyte.com/zyte-api/usage/features.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Absolute URL to extract data from. |
