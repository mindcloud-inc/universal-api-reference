# Get Template with API Template

Retrieves a PDF template from API Template.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/get-template`
- **Base URL:** `https://rest.apitemplate.io`
- **Official documentation:** [Get Template](https://apitemplate.io/apiv2/#tag/Template-Management/operation/get-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | query | `string` | no | Template ID to fetch. |
