# Get Image with AltText.Ai

Retrieves an image from your AltText.Ai library.

## Endpoint

- **Method:** `GET`
- **Path:** `/images/:asset_id`
- **Base URL:** `https://alttext.ai/api/v1`
- **Official documentation:** [Get Image](https://alttext.ai/apidocs#tag/Images/operation/get-image-by-asset-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `asset_id` | path | `string` | yes | The asset ID of the image to retrieve. |
