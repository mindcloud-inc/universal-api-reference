# Delete Image with AltText.Ai

Deletes an image from your AltText.Ai library.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/images/:asset_id`
- **Base URL:** `https://alttext.ai/api/v1`
- **Official documentation:** [Delete Image](https://alttext.ai/apidocs#tag/Images/operation/delete-image-by-asset-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `asset_id` | path | `string` | yes | The asset ID of the image to delete. |
