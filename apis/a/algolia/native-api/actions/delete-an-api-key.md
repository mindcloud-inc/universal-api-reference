# Delete an API Key with Algolia

Deletes an API key from Algolia.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/1/keys/:key`
- **Base URL:** `https://{applicationId}.algolia.net`
- **Official documentation:** [Delete an API Key](https://www.algolia.com/doc/rest-api/search/delete-api-key)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | API key to delete. |
