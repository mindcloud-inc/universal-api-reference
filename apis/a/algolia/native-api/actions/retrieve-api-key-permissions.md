# Retrieve API Key Permissions with Algolia

Retrieves API key permissions and restrictions from Algolia.

## Endpoint

- **Method:** `GET`
- **Path:** `/1/keys/:key`
- **Base URL:** `https://{applicationId}.algolia.net`
- **Official documentation:** [Retrieve API Key Permissions](https://www.algolia.com/doc/rest-api/search/get-api-key)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | API key to retrieve. |
