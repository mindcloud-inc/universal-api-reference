# Get Badge Status with Absinthe

Retrieves badge eligibility and claim status from Absinthe.

## Endpoint

- **Method:** `GET`
- **Path:** `/badges/{badge_id}/status`
- **Base URL:** `https://api.absinthe.network`
- **Official documentation:** [Get Badge Status](https://api.absinthe.network/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `badge_id` | path | `string` | no | UUID of the badge. |
