# Update Inventory Item with Absinthe

Updates a reward item in an Absinthe campaign.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/inventory/{inventory_id}`
- **Base URL:** `https://api.absinthe.network`
- **Official documentation:** [Update Inventory Item](https://api.absinthe.network/doc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `inventory_id` | path | `string` | no |
