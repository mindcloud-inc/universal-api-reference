# Get User XP Balance with Absinthe

Retrieves a user's XP balance from Absinthe.

## Endpoint

- **Method:** `GET`
- **Path:** `/redemptions/users/{user_id}/balance`
- **Base URL:** `https://api.absinthe.network`
- **Official documentation:** [Get User XP Balance](https://api.absinthe.network/doc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | path | `string` | yes |
| `user_id` | path | `string` | no |
