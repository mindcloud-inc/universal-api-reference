# Get Badge with Absinthe

Retrieves details for a badge from Absinthe.

## Endpoint

- **Method:** `GET`
- **Path:** `/badges/{badge_id}`
- **Base URL:** `https://api.absinthe.network`
- **Official documentation:** [Get Badge](https://api.absinthe.network/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `badge_id` | path | `string` | no | UUID of the badge. |
