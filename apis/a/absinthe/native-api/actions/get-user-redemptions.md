# Get User Redemptions with Absinthe

Retrieves a user's redemption history from Absinthe.

## Endpoint

- **Method:** `GET`
- **Path:** `/redemptions/users/{user_id}/redemptions`
- **Base URL:** `https://api.absinthe.network`
- **Official documentation:** [Get User Redemptions](https://api.absinthe.network/doc)
