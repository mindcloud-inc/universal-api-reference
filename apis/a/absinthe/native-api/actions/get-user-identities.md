# Get User Identities with Absinthe

Retrieves a user's identities from Absinthe.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{user_id}`
- **Base URL:** `https://api.absinthe.network`
- **Official documentation:** [Get User Identities](https://api.absinthe.network/doc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | path | `string` | yes |
| `user_id` | path | `string` | no |
