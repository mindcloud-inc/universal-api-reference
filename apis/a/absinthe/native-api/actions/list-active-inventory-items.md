# List Active Inventory Items with Absinthe

Retrieves active reward items from an Absinthe campaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/inventory/public`
- **Base URL:** `https://api.absinthe.network`
- **Official documentation:** [List Active Inventory Items](https://api.absinthe.network/doc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | query | `string` | yes |
