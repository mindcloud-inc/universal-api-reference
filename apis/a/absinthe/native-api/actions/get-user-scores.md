# Get User Scores with Absinthe

Retrieves a user's scores and rank from Absinthe.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{user_id}/scores`
- **Base URL:** `https://api.absinthe.network`
- **Official documentation:** [Get User Scores](https://api.absinthe.network/doc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | path | `string` | yes |
| `user_id` | path | `string` | no |
