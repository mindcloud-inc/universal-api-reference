# Get User Point Sources with Absinthe

Retrieves a user's earned points by source in Absinthe.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{user_id}/point-sources`
- **Base URL:** `https://api.absinthe.network`
- **Official documentation:** [Get User Point Sources](https://api.absinthe.network/doc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | path | `string` | yes |
| `user_id` | path | `string` | no |
