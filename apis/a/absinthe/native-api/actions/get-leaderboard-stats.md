# Get Leaderboard Stats with Absinthe

Retrieves leaderboard metrics for a campaign in Absinthe.

## Endpoint

- **Method:** `GET`
- **Path:** `/leaderboard/stats`
- **Base URL:** `https://api.absinthe.network`
- **Official documentation:** [Get Leaderboard Stats](https://api.absinthe.network/doc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaign_id` | query | `string` | yes |
