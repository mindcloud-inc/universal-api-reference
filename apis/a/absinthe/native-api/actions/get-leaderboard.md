# Get Leaderboard with Absinthe

Retrieves a campaign leaderboard from Absinthe.

## Endpoint

- **Method:** `GET`
- **Path:** `/leaderboard`
- **Base URL:** `https://api.absinthe.network`
- **Official documentation:** [Get Leaderboard](https://api.absinthe.network/doc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaign_id` | query | `string` | yes |
