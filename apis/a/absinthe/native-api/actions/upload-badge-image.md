# Upload Badge Image with Absinthe

Uploads a badge image to Absinthe.

## Endpoint

- **Method:** `POST`
- **Path:** `/badges/upload-image`
- **Base URL:** `https://api.absinthe.network`
- **Official documentation:** [Upload Badge Image](https://api.absinthe.network/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image` | body | `string` | no | Badge image file to upload. |
