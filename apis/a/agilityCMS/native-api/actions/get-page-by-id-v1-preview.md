# Get Page By ID V1 (Preview) with Agility CMS

Retrieves a preview page by ID from Agility CMS v1.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/:guid/preview/:locale/page/:id`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Get Page By ID V1 (Preview)](https://api.aglty.io/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The pageID of the page to retrieve. |
