# List Posts (Preview) with Agility CMS

Retrieves preview posts from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/preview/:locale/list/posts`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [List Posts (Preview)](https://api.aglty.io/swagger/v2/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
