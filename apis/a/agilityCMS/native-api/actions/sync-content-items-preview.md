# Sync Content Items (Preview) with Agility CMS

Retrieves preview content item sync data from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/preview/:locale/sync/items`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Sync Content Items (Preview)](https://api.aglty.io/swagger/v2/swagger.json)
