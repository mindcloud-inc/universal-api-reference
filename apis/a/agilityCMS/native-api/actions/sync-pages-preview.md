# Sync Pages (Preview) with Agility CMS

Retrieves preview page sync data from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/preview/:locale/sync/pages`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Sync Pages (Preview)](https://api.aglty.io/swagger/v2/swagger.json)
