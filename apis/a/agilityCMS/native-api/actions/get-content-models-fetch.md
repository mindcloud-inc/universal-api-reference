# Get Content Models (Fetch) with Agility CMS

Retrieves published content models from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/fetch/contentmodels`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Get Content Models (Fetch)](https://api.aglty.io/swagger/v2/swagger.json)
