# Get URL Redirections (Preview) with Agility CMS

Retrieves preview URL redirections from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/preview/urlredirection`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Get URL Redirections (Preview)](https://api.aglty.io/swagger/v2/swagger.json)
