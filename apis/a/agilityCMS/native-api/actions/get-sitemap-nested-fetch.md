# Get Sitemap Nested (Fetch) with Agility CMS

Retrieves the published sitemap in nested format from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/fetch/:locale/sitemap/nested/:channelName`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Get Sitemap Nested (Fetch)](https://api.aglty.io/swagger/v2/swagger.json)
