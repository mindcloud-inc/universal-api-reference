# Get URL Redirections (Fetch) with Agility CMS

Retrieves published URL redirections from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/fetch/urlredirection`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Get URL Redirections (Fetch)](https://api.aglty.io/swagger/v2/swagger.json)
