# Get Page By ID (Preview) with Agility CMS

Retrieves a preview page by ID from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/preview/:locale/page/:id`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Get Page By ID (Preview)](https://api.aglty.io/swagger/v2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The pageID of the page to retrieve. |
