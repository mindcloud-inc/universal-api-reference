# Get Sitemap Flat (Fetch) with Agility CMS

Retrieves the published sitemap as a flat list from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/fetch/:locale/sitemap/flat/:channelName`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Get Sitemap Flat (Fetch)](https://api.aglty.io/swagger/v2/swagger.json)
