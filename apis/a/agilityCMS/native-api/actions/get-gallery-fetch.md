# Get Gallery (Fetch) with Agility CMS

Retrieves a published gallery from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/:guid/fetch/gallery/:id`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Get Gallery (Fetch)](https://api.aglty.io/swagger/v2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Agility CMS gallery ID to retrieve. |
