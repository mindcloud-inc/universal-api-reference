# Get Content Item (Preview) with Agility CMS

Retrieves a preview content item from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/preview/:locale/item/:id`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Get Content Item (Preview)](https://api.aglty.io/swagger/v2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The contentID of the item to retrieve. |
