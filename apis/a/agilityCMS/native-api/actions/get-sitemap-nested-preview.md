# Get Sitemap Nested (Preview) with Agility CMS

Retrieves the preview sitemap in nested format from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/preview/:locale/sitemap/nested/:channelName`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Get Sitemap Nested (Preview)](https://api.aglty.io/swagger/v2/swagger.json)
