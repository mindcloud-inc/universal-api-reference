# Sync Pages (Fetch) with Agility CMS

Retrieves published page sync data from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/fetch/:locale/sync/pages`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Sync Pages (Fetch)](https://api.aglty.io/swagger/v2/swagger.json)
