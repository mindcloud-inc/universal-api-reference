# Get Content Models (Preview) with Agility CMS

Retrieves preview content models from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/preview/contentmodels`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Get Content Models (Preview)](https://api.aglty.io/swagger/v2/swagger.json)
