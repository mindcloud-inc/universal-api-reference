# Get Sitemap Flat (Preview) with Agility CMS

Retrieves the preview sitemap as a flat list from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/preview/:locale/sitemap/flat/:channelName`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Get Sitemap Flat (Preview)](https://api.aglty.io/swagger/v2/swagger.json)
