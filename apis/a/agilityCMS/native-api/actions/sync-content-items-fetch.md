# Sync Content Items (Fetch) with Agility CMS

Retrieves published content item sync data from Agility CMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/:guid/fetch/:locale/sync/items`
- **Base URL:** `https://api.aglty.io`
- **Official documentation:** [Sync Content Items (Fetch)](https://api.aglty.io/swagger/v2/swagger.json)
