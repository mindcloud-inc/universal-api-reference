# Get Workflow with ApproveThis

Retrieves a workflow from ApproveThis by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/:workflow`
- **Base URL:** `https://app.approvethis.com/api/v1`
- **Official documentation:** [Get Workflow](https://app.approvethis.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflow` | path | `string` | yes | The workflow ID. |
