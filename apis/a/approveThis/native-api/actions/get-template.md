# Get Template with ApproveThis

Retrieves an approval template from ApproveThis by slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:template`
- **Base URL:** `https://app.approvethis.com/api/v1`
- **Official documentation:** [Get Template](https://app.approvethis.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template` | path | `string` | yes | The template slug. |
