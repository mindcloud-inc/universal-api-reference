# Get Prompt Trace Detail with AssignX

Retrieves prompt trace details from AssignX.

## Endpoint

- **Method:** `GET`
- **Path:** `traces/:id`
- **Base URL:** `https://api.agentx.so/api/v1/access/`
- **Official documentation:** [Get Prompt Trace Detail](https://docs.agentx.so/reference/get_api-v1-access-traces-id-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Trace identifier from prompt trace output. |
