# List Conversations with AssignX

Retrieves conversations for an AssignX agent.

## Endpoint

- **Method:** `GET`
- **Path:** `agents/:id/conversations`
- **Base URL:** `https://api.agentx.so/api/v1/access/`
- **Official documentation:** [List Conversations](https://docs.agentx.so/reference/get_api-v1-access-agents-id-conversations-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The AssignX agent identifier. |
