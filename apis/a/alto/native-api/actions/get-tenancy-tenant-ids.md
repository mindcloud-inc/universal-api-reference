# Get Tenancy Tenant IDs with Alto

Retrieves tenant IDs for a tenancy in Alto.

## Endpoint

- **Method:** `GET`
- **Path:** `/tenancies/:tenancyId/tenantIds`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Tenancy Tenant IDs](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tenancyId` | path | `string` | yes | Unique Alto tenancy identifier. |
