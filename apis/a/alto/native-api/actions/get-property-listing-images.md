# Get Property Listing Images with Alto

Retrieves property image metadata from Alto.

## Endpoint

- **Method:** `GET`
- **Path:** `/listing/property/:propertyId/images`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Property Listing Images](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | path | `string` | yes | Unique Alto property identifier. |
