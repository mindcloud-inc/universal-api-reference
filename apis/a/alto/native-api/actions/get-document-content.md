# Get Document Content with Alto

Retrieves document content from Alto by document ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentId/content`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Document Content](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | Unique Alto document identifier. |
