# Get Work Order with Alto

Retrieves a work order from Alto by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/work-orders/:id`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Work Order](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique Alto work order identifier. |
