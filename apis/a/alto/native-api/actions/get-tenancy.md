# Get Tenancy with Alto

Retrieves a tenancy from Alto by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tenancies/:tenancyId`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Tenancy](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tenancyId` | path | `string` | yes | Unique Alto tenancy identifier. |
