# Get Contact with Alto

Retrieves a contact from Alto by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Contact](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | Unique Alto contact identifier. |
