# Get Negotiator with Alto

Retrieves a negotiator from Alto by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/negotiators/:negotiatorId`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Negotiator](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `negotiatorId` | path | `string` | yes | Unique Alto negotiator identifier. |
