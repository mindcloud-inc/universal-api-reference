# Get Inventory Landlords with Alto

Retrieves landlords for an inventory item in Alto.

## Endpoint

- **Method:** `GET`
- **Path:** `/inventory/:inventoryId/landlords`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Inventory Landlords](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inventoryId` | path | `string` | yes | Unique Alto inventory item identifier. |
