# Get Branch with Alto

Retrieves a branch from Alto by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/branches/:branchId`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Branch](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `branchId` | path | `string` | yes | Unique Alto branch identifier. |
