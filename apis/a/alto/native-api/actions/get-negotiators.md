# Get Negotiators with Alto

Retrieves negotiator records from your Alto account.

## Endpoint

- **Method:** `GET`
- **Path:** `/negotiators`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Negotiators](https://developers.vebraalto.com/api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
