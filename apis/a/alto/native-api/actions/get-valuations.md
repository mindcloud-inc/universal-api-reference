# Get Valuations with Alto

Retrieves valuations from Alto by created date range.

## Endpoint

- **Method:** `GET`
- **Path:** `/appointments/valuations`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Valuations](https://developers.vebraalto.com/api)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
