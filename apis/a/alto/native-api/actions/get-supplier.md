# Get Supplier with Alto

Retrieves a supplier from Alto by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/suppliers/:supplierId`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Supplier](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `supplierId` | path | `string` | yes | Unique Alto supplier identifier. |
