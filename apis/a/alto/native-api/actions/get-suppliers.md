# Get Suppliers with Alto

Retrieves supplier records from your Alto account.

## Endpoint

- **Method:** `GET`
- **Path:** `/suppliers`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Suppliers](https://developers.vebraalto.com/api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
