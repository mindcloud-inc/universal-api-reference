# Get Inventory Item with Alto

Retrieves an inventory item from Alto by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/inventory/:inventoryId`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Inventory Item](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inventoryId` | path | `string` | yes | Unique Alto inventory item identifier. |
