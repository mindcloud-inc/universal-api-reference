# Get Landlords with Alto

Retrieves landlord records from your Alto account.

## Endpoint

- **Method:** `GET`
- **Path:** `/landlords`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Landlords](https://developers.vebraalto.com/api)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `active-status` | query | `string` | no | Landlord active-status filter. |
