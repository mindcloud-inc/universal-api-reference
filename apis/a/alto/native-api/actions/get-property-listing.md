# Get Property Listing with Alto

Retrieves a property listing from Alto by property ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/listing/property/:propertyId`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Property Listing](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | path | `string` | yes | Unique Alto property identifier. |
