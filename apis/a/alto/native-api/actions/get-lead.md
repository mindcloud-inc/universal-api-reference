# Get Lead with Alto

Retrieves a lead from Alto by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:leadId`
- **Base URL:** `https://api.alto.zoopladev.co.uk`
- **Official documentation:** [Get Lead](https://developers.vebraalto.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | yes | Unique Alto lead identifier. |
