# Get Skill with Anthropic

Retrieves a specific skill from Anthropic.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/skills/:skill_id`
- **Base URL:** `https://api.anthropic.com`
- **Official documentation:** [Get Skill](https://platform.claude.com/docs/en/api/beta/skills/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `skill_id` | path | `string` | yes | Identifier of the skill to retrieve. |
