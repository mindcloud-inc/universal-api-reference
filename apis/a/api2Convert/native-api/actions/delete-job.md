# Delete Job with Api2Convert

Cancels an existing job in Api2Convert.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/jobs/:job_id`
- **Base URL:** `https://api.api2convert.com/v2`
- **Official documentation:** [Delete Job](https://api.api2convert.com/v2/schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | Unique identifier of the job to delete. |
