# Get Job History with Api2Convert

Retrieves change history for a job from Api2Convert.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id/history`
- **Base URL:** `https://api.api2convert.com/v2`
- **Official documentation:** [Get Job History](https://api.api2convert.com/v2/schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | ID of the job. |
