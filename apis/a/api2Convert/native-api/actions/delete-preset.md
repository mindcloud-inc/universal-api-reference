# Delete Preset with Api2Convert

Deletes an existing preset from Api2Convert.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/presets/:preset_id`
- **Base URL:** `https://api.api2convert.com/v2`
- **Official documentation:** [Delete Preset](https://api.api2convert.com/v2/schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `preset_id` | path | `string` | yes | Unique identifier of the preset to delete. |
