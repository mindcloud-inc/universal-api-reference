# Get Job with Api2Convert

Retrieves details for a job from Api2Convert.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id`
- **Base URL:** `https://api.api2convert.com/v2`
- **Official documentation:** [Get Job](https://api.api2convert.com/v2/schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | ID of the job. |
