# Get Preset with Api2Convert

Retrieves a specific preset from Api2Convert.

## Endpoint

- **Method:** `GET`
- **Path:** `/presets/:preset_id`
- **Base URL:** `https://api.api2convert.com/v2`
- **Official documentation:** [Get Preset](https://api.api2convert.com/v2/schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `preset_id` | path | `string` | yes | Unique identifier of the preset to retrieve. |
