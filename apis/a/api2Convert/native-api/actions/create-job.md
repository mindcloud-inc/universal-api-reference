# Create Job with Api2Convert

Creates a new job in Api2Convert.

## Endpoint

- **Method:** `POST`
- **Path:** `/jobs`
- **Base URL:** `https://api.api2convert.com/v2`
- **Official documentation:** [Create Job](https://api.api2convert.com/v2/schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Job payload with type, process flags, notification settings, conversions, and inputs. |
