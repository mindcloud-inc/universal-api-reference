# List Job Inputs with Api2Convert

Retrieves input files for a job from Api2Convert.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id/input`
- **Base URL:** `https://api.api2convert.com/v2`
- **Official documentation:** [List Job Inputs](https://api.api2convert.com/v2/schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | ID of the job. |
