# Get Company with Avalara AvaTax

## Endpoint

- **Method:** `GET`
- **Path:** `companies/:id`
- **Base URL:** `{environment}`
- **Official documentation:** [Get Company](https://developer.avalara.com/api-reference/avatax/rest/v2/methods/Companies/GetCompany/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Avalara company ID. |
