# Get Item with Avalara AvaTax

## Endpoint

- **Method:** `GET`
- **Path:** `companies/:companyId/items/:id`
- **Base URL:** `{environment}`
- **Official documentation:** [Get Item](https://developer.avalara.com/api-reference/avatax/rest/v2/methods/Items/GetItem/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `number` | yes | Avalara company ID. |
| `id` | path | `number` | yes | Avalara item ID. |
