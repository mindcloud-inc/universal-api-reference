# Get Nexus with Avalara AvaTax

## Endpoint

- **Method:** `GET`
- **Path:** `companies/:companyId/nexus/:id`
- **Base URL:** `{environment}`
- **Official documentation:** [Get Nexus](https://developer.avalara.com/api-reference/avatax/rest/v2/methods/Nexus/GetNexus/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `number` | yes | Avalara company ID. |
| `id` | path | `number` | yes | Avalara nexus ID. |
