# Query Companies with Avalara AvaTax

## Endpoint

- **Method:** `GET`
- **Path:** `companies`
- **Base URL:** `{environment}`
- **Official documentation:** [Query Companies](https://developer.avalara.com/api-reference/avatax/rest/v2/methods/Companies/QueryCompanies/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
