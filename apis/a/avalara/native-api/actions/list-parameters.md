# List Parameters with Avalara AvaTax

## Endpoint

- **Method:** `GET`
- **Path:** `definitions/parameters`
- **Base URL:** `{environment}`
- **Official documentation:** [List Parameters](https://developer.avalara.com/api-reference/avatax/rest/v2/methods/Definitions/ListParameters/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
