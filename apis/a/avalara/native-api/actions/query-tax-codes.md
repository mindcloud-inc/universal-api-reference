# Query Tax Codes with Avalara AvaTax

## Endpoint

- **Method:** `GET`
- **Path:** `taxcodes`
- **Base URL:** `{environment}`
- **Official documentation:** [Query Tax Codes](https://developer.avalara.com/api-reference/avatax/rest/v2/methods/TaxCodes/QueryTaxCodes/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
