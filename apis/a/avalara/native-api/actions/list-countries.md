# List Countries with Avalara AvaTax

## Endpoint

- **Method:** `GET`
- **Path:** `definitions/countries`
- **Base URL:** `{environment}`
- **Official documentation:** [List Countries](https://developer.avalara.com/api-reference/avatax/rest/v2/methods/Definitions/ListCountries/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
