# List Tax Codes By Company with Avalara AvaTax

## Endpoint

- **Method:** `GET`
- **Path:** `companies/:companyId/taxcodes`
- **Base URL:** `{environment}`
- **Official documentation:** [List Tax Codes By Company](https://developer.avalara.com/api-reference/avatax/rest/v2/methods/TaxCodes/ListTaxCodesByCompany/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `number` | yes | Avalara company ID. |
