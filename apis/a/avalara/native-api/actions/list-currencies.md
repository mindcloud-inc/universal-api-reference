# List Currencies with Avalara AvaTax

## Endpoint

- **Method:** `GET`
- **Path:** `definitions/currencies`
- **Base URL:** `{environment}`
- **Official documentation:** [List Currencies](https://developer.avalara.com/api-reference/avatax/rest/v2/methods/Definitions/ListCurrencies/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
