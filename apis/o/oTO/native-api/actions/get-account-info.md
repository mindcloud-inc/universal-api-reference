# Get Account Info with OTO

Retrieves account information from the OTO API.

## Endpoint

- **Method:** `GET`
- **Path:** `/accountInfo`
- **Base URL:** `https://api.tryoto.com/rest/v2`
- **Official documentation:** [Get Account Info](https://help.tryoto.com/en/support/solutions/articles/150000213806-account-apis)
