# List Delivery Companies with OTO

Retrieves delivery companies from the OTO API.

## Endpoint

- **Method:** `POST`
- **Path:** `/dcList`
- **Base URL:** `https://api.tryoto.com/rest/v2`
- **Official documentation:** [List Delivery Companies](https://help.tryoto.com/en/support/solutions/articles/150000213813-carrier-integrations-apis)
