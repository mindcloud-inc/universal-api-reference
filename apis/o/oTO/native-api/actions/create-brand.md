# Create Brand with OTO

Creates a new brand in OTO.

## Endpoint

- **Method:** `POST`
- **Path:** `/createBrand`
- **Base URL:** `https://api.tryoto.com/rest/v2`
- **Official documentation:** [Create Brand](https://help.tryoto.com/en/support/solutions/articles/150000213815-brands-apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `storeName` | body | `string` | yes | Brand or storefront name to create. |
