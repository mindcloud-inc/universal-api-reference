# Get Client Info with OTO

Retrieves client information from the OTO API.

## Endpoint

- **Method:** `GET`
- **Path:** `/clientInfo`
- **Base URL:** `https://api.tryoto.com/rest/v2`
- **Official documentation:** [Get Client Info](https://help.tryoto.com/en/support/solutions/articles/150000213806-account-apis)
