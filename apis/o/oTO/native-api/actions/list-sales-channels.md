# List Sales Channels with OTO

Retrieves sales channels from the OTO API.

## Endpoint

- **Method:** `GET`
- **Path:** `/salesChannel/getSalesChannelsList`
- **Base URL:** `https://api.tryoto.com/rest/v2`
- **Official documentation:** [List Sales Channels](https://help.tryoto.com/en/support/solutions/articles/150000213816-sales-channels-apis)
