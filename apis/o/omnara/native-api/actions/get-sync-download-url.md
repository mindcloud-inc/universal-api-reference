# Get Sync Download Url with Omnara

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/workspaces/{workspaceId}/sync/download-url`
- **Base URL:** `https://api.omnara.com`
- **Official documentation:** [Get Sync Download Url](https://docs.omnara.com/api-reference/workspaces/get-sync-download-url)
