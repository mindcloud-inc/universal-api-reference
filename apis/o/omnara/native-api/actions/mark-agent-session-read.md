# Mark Agent Session Read with Omnara

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/user-sessions/{userSessionId}/agent-sessions/{agentSessionId}/mark-read`
- **Base URL:** `https://api.omnara.com`
- **Official documentation:** [Mark Agent Session Read](https://docs.omnara.com/api-reference/user_sessions/mark-agent-session-read)
