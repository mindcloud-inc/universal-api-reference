# Get Agent Session Messages with Omnara

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/user-sessions/{userSessionId}/agent-sessions/{agentSessionId}/messages`
- **Base URL:** `https://api.omnara.com`
- **Official documentation:** [Get Agent Session Messages](https://docs.omnara.com/api-reference/user_sessions/get-agent-session-messages)
