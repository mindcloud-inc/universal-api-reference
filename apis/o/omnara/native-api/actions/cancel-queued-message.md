# Cancel Queued Message with Omnara

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/user-sessions/{userSessionId}/agent-sessions/{agentSessionId}/messages/{messageId}`
- **Base URL:** `https://api.omnara.com`
- **Official documentation:** [Cancel Queued Message](https://docs.omnara.com/api-reference/user_sessions/cancel-queued-message)
