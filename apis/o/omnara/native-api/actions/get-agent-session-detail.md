# Get Agent Session Detail with Omnara

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/user-sessions/{userSessionId}/agent-sessions/{agentSessionId}`
- **Base URL:** `https://api.omnara.com`
- **Official documentation:** [Get Agent Session Detail](https://docs.omnara.com/api-reference/user_sessions/get-agent-session-detail)
