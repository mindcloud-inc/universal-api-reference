# Get Customer Organization By External ID with OneDesk

Retrieves a customer organization by external ID from OneDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/public/customer-organizations/externalId/:externalId`
- **Base URL:** `https://app.onedesk.com`
- **Official documentation:** [Get Customer Organization By External ID](https://onedesk.com/public-api/swagger.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `externalId` | path | `string` | yes | External ID of the customer organization. |
