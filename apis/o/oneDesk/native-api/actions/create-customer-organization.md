# Create Customer Organization with OneDesk

Creates a customer organization in OneDesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/public/customer-organizations/`
- **Base URL:** `https://app.onedesk.com`
- **Official documentation:** [Create Customer Organization](https://onedesk.com/public-api/swagger.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the customer organization to create. |
