# Create Project with OneDesk

Creates a project in OneDesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/public/projects/`
- **Base URL:** `https://app.onedesk.com`
- **Official documentation:** [Create Project](https://onedesk.com/public-api/swagger.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the project to create. |
