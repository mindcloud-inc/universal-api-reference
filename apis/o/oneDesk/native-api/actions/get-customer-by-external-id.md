# Get Customer By External ID with OneDesk

Retrieves a customer by external ID from OneDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/public/customers/externalId/:externalId`
- **Base URL:** `https://app.onedesk.com`
- **Official documentation:** [Get Customer By External ID](https://onedesk.com/public-api/swagger.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `externalId` | path | `string` | yes | External ID of the customer. |
