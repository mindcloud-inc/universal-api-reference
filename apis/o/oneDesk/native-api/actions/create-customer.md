# Create Customer with OneDesk

Creates a customer in OneDesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/public/customers/`
- **Base URL:** `https://app.onedesk.com`
- **Official documentation:** [Create Customer](https://onedesk.com/public-api/swagger.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Email of the customer to create. |
