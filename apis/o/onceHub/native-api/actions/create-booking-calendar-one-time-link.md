# Create Booking Calendar One-Time Link with OnceHub

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/booking-calendars/:id/one-time-links`
- **Base URL:** `https://api.oncehub.com`
- **Official documentation:** [Create Booking Calendar One-Time Link](https://developers.oncehub.com/reference/booking-calendars/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The OnceHub booking calendar identifier. |
