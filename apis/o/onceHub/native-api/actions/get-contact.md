# Get Contact with OnceHub

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/contacts/:id`
- **Base URL:** `https://api.oncehub.com`
- **Official documentation:** [Get Contact](https://developers.oncehub.com/reference/booking-calendars/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The OnceHub contact identifier. |
