# Get Team with OnceHub

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/teams/:id`
- **Base URL:** `https://api.oncehub.com`
- **Official documentation:** [Get Team](https://developers.oncehub.com/reference/booking-calendars/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The OnceHub team identifier. |
