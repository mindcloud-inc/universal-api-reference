# Get Booking Calendar with OnceHub

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/booking-calendars/:id`
- **Base URL:** `https://api.oncehub.com`
- **Official documentation:** [Get Booking Calendar](https://developers.oncehub.com/reference/booking-calendars/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The OnceHub booking calendar identifier. |
