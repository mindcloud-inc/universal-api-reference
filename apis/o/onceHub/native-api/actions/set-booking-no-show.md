# Set Booking No-Show with OnceHub

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/bookings/:id/no-show`
- **Base URL:** `https://api.oncehub.com`
- **Official documentation:** [Set Booking No-Show](https://developers.oncehub.com/reference/booking-calendars/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The OnceHub booking identifier. |
