# Get Category with Olvy

Retrieves category details from Olvy.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://app.olvy.co/api/v2/graphql`
- **Official documentation:** [Get Category](https://app.olvy.co/settings/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.id` | body | `string` | yes | Category id to retrieve. |
