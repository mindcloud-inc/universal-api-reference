# Get Project with Olvy

Retrieves project details from Olvy.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://app.olvy.co/api/v2/graphql`
- **Official documentation:** [Get Project](https://app.olvy.co/settings/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.id` | body | `string` | yes | Project id to retrieve. |
