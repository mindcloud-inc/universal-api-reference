# Get Remaining Quotes with Oanda

Retrieves remaining quote usage from Oanda.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/remaining_quotes.:ext`
- **Base URL:** `https://exchange-rates-api.oanda.com`
- **Official documentation:** [Get Remaining Quotes](https://exchange-rates-api.oanda.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ext` | path | `string` | yes | Response format. |
