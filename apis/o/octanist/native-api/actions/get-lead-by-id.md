# Get Lead by ID with Octanist

Retrieves a lead by ID from Octanist.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/{id}`
- **Base URL:** `https://octanist.com/api`
- **Official documentation:** [Get Lead by ID](https://octanist.com/docs/api-reference/endpoint/get-lead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Octanist lead ID to fetch. |
