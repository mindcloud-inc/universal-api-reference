# Get Template with OneSignal

Retrieves template details from OneSignal.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:template_id`
- **Base URL:** `https://api.onesignal.com`
- **Official documentation:** [Get Template](https://documentation.onesignal.com/reference/view-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The OneSignal template ID to fetch. |
