# Get Segment with OneSignal

Retrieves segment details from OneSignal.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:app_id/segments/:segment_id`
- **Base URL:** `https://api.onesignal.com`
- **Official documentation:** [Get Segment](https://documentation.onesignal.com/reference/view-segment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segment_id` | path | `string` | yes | The OneSignal segment ID to fetch. |
