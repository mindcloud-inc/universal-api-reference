# List Messages with OneSignal

Retrieves messages from OneSignal.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications`
- **Base URL:** `https://api.onesignal.com`
- **Official documentation:** [List Messages](https://documentation.onesignal.com/reference/view-messages)

## Capabilities

This operation supports [pagination](../README.md#pagination).
