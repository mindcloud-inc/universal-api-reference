# Get Message with OneSignal

Retrieves message details from OneSignal.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications/:notification_id`
- **Base URL:** `https://api.onesignal.com`
- **Official documentation:** [Get Message](https://documentation.onesignal.com/reference/view-message)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `notification_id` | path | `string` | yes | The OneSignal notification ID to fetch. |
