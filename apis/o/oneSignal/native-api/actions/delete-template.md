# Delete Template with OneSignal

Deletes a template from OneSignal.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/templates/:template_id`
- **Base URL:** `https://api.onesignal.com`
- **Official documentation:** [Delete Template](https://documentation.onesignal.com/reference/delete-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The identifier of the template in UUID v4 format. |
