# Get Department Details with OfficeMaps

Retrieves department details from OfficeMaps.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/department/:departmentId`
- **Base URL:** `https://api.officemaps.io`
- **Official documentation:** [Get Department Details](https://api.officemaps.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `departmentId` | path | `string` | yes | The OfficeMaps department UUID. |
