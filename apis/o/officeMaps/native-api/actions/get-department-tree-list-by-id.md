# Get Department Tree List By Id with OfficeMaps

Retrieves a department tree from OfficeMaps by department ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/department/treelist/:id`
- **Base URL:** `https://api.officemaps.io`
- **Official documentation:** [Get Department Tree List By Id](https://api.officemaps.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Department UUID. |
