# Get Person with OfficeMaps

Retrieves a person from OfficeMaps by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/person/:personId`
- **Base URL:** `https://api.officemaps.io`
- **Official documentation:** [Get Person](https://api.officemaps.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `string` | yes | The OfficeMaps person UUID. |
