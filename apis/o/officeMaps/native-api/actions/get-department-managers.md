# Get Department Managers with OfficeMaps

Retrieves managers in an OfficeMaps department.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/department/:departmentId/managers`
- **Base URL:** `https://api.officemaps.io`
- **Official documentation:** [Get Department Managers](https://api.officemaps.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `departmentId` | path | `string` | yes | Department UUID. |
