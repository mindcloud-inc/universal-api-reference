# Delete Person with OfficeMaps

Deletes an existing person from OfficeMaps.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/person/:id`
- **Base URL:** `https://api.officemaps.io`
- **Official documentation:** [Delete Person](https://api.officemaps.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Person UUID. |
