# Get Joke by ID with Official Joke API

## Endpoint

- **Method:** `GET`
- **Path:** `/jokes/:id`
- **Base URL:** `https://official-joke-api.appspot.com`
- **Official documentation:** [Get Joke by ID](https://github.com/15Dkatz/official_joke_api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Identifier of the joke to retrieve. |
