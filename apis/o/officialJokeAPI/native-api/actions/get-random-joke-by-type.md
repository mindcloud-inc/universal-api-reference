# Get Random Joke by Type with Official Joke API

## Endpoint

- **Method:** `GET`
- **Path:** `/jokes/:type/random`
- **Base URL:** `https://official-joke-api.appspot.com`
- **Official documentation:** [Get Random Joke by Type](https://github.com/15Dkatz/official_joke_api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | path | `string` | yes | Joke type returned by List Joke Types. |
