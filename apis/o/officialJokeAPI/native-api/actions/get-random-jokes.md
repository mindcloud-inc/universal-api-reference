# Get Random Jokes with Official Joke API

## Endpoint

- **Method:** `GET`
- **Path:** `/jokes/random/:count`
- **Base URL:** `https://official-joke-api.appspot.com`
- **Official documentation:** [Get Random Jokes](https://github.com/15Dkatz/official_joke_api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `count` | path | `number` | yes | Number of random jokes to return. |
