# Full Text Search Switzerland with OpenPLZ

## Endpoint

- **Method:** `GET`
- **Path:** `/ch/FullTextSearch`
- **Base URL:** `https://openplzapi.org`
- **Official documentation:** [Full Text Search Switzerland](https://www.openplzapi.org/en/switzerland/#requesting-streets)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchTerm` | query | `string` | yes | Street name, postal code, or locality text to search for in Switzerland. |
