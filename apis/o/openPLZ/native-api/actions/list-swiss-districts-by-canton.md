# List Swiss Districts by Canton with OpenPLZ

## Endpoint

- **Method:** `GET`
- **Path:** `/ch/Cantons/{key}/Districts`
- **Base URL:** `https://openplzapi.org`
- **Official documentation:** [List Swiss Districts by Canton](https://www.openplzapi.org/en/switzerland/#requesting-districts)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | Swiss canton key. |
