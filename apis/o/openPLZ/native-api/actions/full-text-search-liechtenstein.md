# Full Text Search Liechtenstein with OpenPLZ

## Endpoint

- **Method:** `GET`
- **Path:** `/li/FullTextSearch`
- **Base URL:** `https://openplzapi.org`
- **Official documentation:** [Full Text Search Liechtenstein](https://www.openplzapi.org/en/liechtenstein/#requesting-streets)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchTerm` | query | `string` | yes | Street name, postal code, or locality text to search for in Liechtenstein. |
