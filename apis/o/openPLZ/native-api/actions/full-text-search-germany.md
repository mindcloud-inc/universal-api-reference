# Full Text Search Germany with OpenPLZ

## Endpoint

- **Method:** `GET`
- **Path:** `/de/FullTextSearch`
- **Base URL:** `https://openplzapi.org`
- **Official documentation:** [Full Text Search Germany](https://www.openplzapi.org/en/germany/#requesting-streets)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchTerm` | query | `string` | yes | Street name, postal code, or locality text to search for in Germany. |
