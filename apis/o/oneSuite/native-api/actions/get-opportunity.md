# Get Opportunity with OneSuite

Retrieves an opportunity from OneSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/opportunities/:opportunity_id`
- **Base URL:** `https://api.onesuite.io`
- **Official documentation:** [Get Opportunity](https://rest-api.onesuite.io/#get-single-opportunity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `opportunity_id` | path | `string` | yes | Opportunity ID from the OneSuite single-opportunity docs. |
