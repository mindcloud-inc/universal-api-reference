# List Project Sections with OneSuite

Retrieves sections for a project in OneSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:project_id/sections`
- **Base URL:** `https://api.onesuite.io`
- **Official documentation:** [List Project Sections](https://rest-api.onesuite.io/#get-all-sections)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The ID of the project |
