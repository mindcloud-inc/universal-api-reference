# Get Invoice with OneSuite

Retrieves an invoice from OneSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/invoices/:invoice_id`
- **Base URL:** `https://api.onesuite.io`
- **Official documentation:** [Get Invoice](https://rest-api.onesuite.io/#get-specific-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_id` | path | `string` | yes | Invoice ID |
