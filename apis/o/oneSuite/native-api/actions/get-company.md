# Get Company with OneSuite

Retrieves a company from OneSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/companies/:company_id`
- **Base URL:** `https://api.onesuite.io`
- **Official documentation:** [Get Company](https://rest-api.onesuite.io/#get-single-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | path | `string` | yes | Company ID from the OneSuite single-company docs. |
