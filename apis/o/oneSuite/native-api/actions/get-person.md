# Get Person with OneSuite

Retrieves a person from OneSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/people/:people_id`
- **Base URL:** `https://api.onesuite.io`
- **Official documentation:** [Get Person](https://rest-api.onesuite.io/#get-single-people)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `people_id` | path | `string` | yes | People ID from the OneSuite single-people docs. |
