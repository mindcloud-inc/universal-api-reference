# Get Project with OneSuite

Retrieves a project from OneSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:project_id`
- **Base URL:** `https://api.onesuite.io`
- **Official documentation:** [Get Project](https://rest-api.onesuite.io/#get-specific-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The ID of the project |
