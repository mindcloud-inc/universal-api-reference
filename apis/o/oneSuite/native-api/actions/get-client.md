# Get Client with OneSuite

Retrieves a client from OneSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/clients/:client_id`
- **Base URL:** `https://api.onesuite.io`
- **Official documentation:** [Get Client](https://rest-api.onesuite.io/#get-specific-client)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `string` | yes | The ID of the client to retrieve |
