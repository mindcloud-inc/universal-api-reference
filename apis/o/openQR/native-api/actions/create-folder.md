# Create Folder with OpenQR

Creates a new folder in OpenQR.

## Endpoint

- **Method:** `POST`
- **Path:** `/folders`
- **Base URL:** `https://api.openqr.io/api/v1`
- **Official documentation:** [Create Folder](https://docs.openqr.io/#tag/Folders/operation/CreateFolder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Folder name. |
