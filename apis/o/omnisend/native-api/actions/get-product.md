# Get Product with Omnisend

Retrieves a product from Omnisend.

## Endpoint

- **Method:** `GET`
- **Path:** `/v5/products/:productID`
- **Base URL:** `https://api.omnisend.com`
- **Official documentation:** [Get Product](https://api-docs.omnisend.com/reference/get_products-productid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productID` | path | `string` | yes | Unique Omnisend product identifier. |
