# Delete Product with Omnisend

Deletes an existing product from Omnisend.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v5/products/:productID`
- **Base URL:** `https://api.omnisend.com`
- **Official documentation:** [Delete Product](https://api-docs.omnisend.com/reference/delete_products-productid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productID` | path | `string` | yes | Unique Omnisend product identifier. |
