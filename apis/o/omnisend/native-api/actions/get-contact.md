# Get Contact with Omnisend

Retrieves a contact from Omnisend.

## Endpoint

- **Method:** `GET`
- **Path:** `/v5/contacts/:contactID`
- **Base URL:** `https://api.omnisend.com`
- **Official documentation:** [Get Contact](https://api-docs.omnisend.com/reference/get_contacts-contactid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactID` | path | `string` | yes | Omnisend contact ID. |
