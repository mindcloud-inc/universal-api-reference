# List Products with Omnisend

Retrieves products from Omnisend.

## Endpoint

- **Method:** `GET`
- **Path:** `/v5/products`
- **Base URL:** `https://api.omnisend.com`
- **Official documentation:** [List Products](https://api-docs.omnisend.com/reference/get_products)

## Capabilities

This operation supports [pagination](../README.md#pagination).
