# List Orders with Omnisend

Retrieves orders from Omnisend.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/orders`
- **Base URL:** `https://api.omnisend.com`
- **Official documentation:** [List Orders](https://api-docs.omnisend.com/v3/reference/get_orders)

## Capabilities

This operation supports [pagination](../README.md#pagination).
