# List Carts with Omnisend

Retrieves carts from Omnisend.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/carts`
- **Base URL:** `https://api.omnisend.com`
- **Official documentation:** [List Carts](https://api-docs.omnisend.com/v3/reference/get_carts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
