# Get Cart with Omnisend

Retrieves a cart from Omnisend.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/carts/:cartID`
- **Base URL:** `https://api.omnisend.com`
- **Official documentation:** [Get Cart](https://api-docs.omnisend.com/v3/reference/get_carts-cartid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cartID` | path | `string` | yes | Omnisend cart ID. |
