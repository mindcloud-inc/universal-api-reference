# Create Category with Omnisend

Creates a new product category in Omnisend.

## Endpoint

- **Method:** `POST`
- **Path:** `/v5/product-categories`
- **Base URL:** `https://api.omnisend.com`
- **Official documentation:** [Create Category](https://api-docs.omnisend.com/reference/post_product-categories)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `categoryID` | body | `string` | no |
| `title` | body | `string` | no |
