# Get Order with Omnisend

Retrieves an order from Omnisend.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/orders/:orderID`
- **Base URL:** `https://api.omnisend.com`
- **Official documentation:** [Get Order](https://api-docs.omnisend.com/v3/reference/get_orders-orderid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderID` | path | `string` | yes | Omnisend order ID. |
