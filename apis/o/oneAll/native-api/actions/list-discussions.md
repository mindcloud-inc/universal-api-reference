# List Discussions with OneAll

Retrieves all LoudVoice discussions from OneAll.

## Endpoint

- **Method:** `GET`
- **Path:** `/loudvoice/discussions.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [List Discussions](https://docs.oneall.com/api/resources/loudvoice/discussions/list/)
