# List Authors with OneAll

Retrieves all LoudVoice authors from OneAll.

## Endpoint

- **Method:** `GET`
- **Path:** `/loudvoice/authors.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [List Authors](https://docs.oneall.com/api/resources/loudvoice/authors/list/)
