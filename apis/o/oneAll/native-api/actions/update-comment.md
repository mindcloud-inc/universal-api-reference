# Update Comment with OneAll

Updates a LoudVoice comment in OneAll.

## Endpoint

- **Method:** `PUT`
- **Path:** `/loudvoice/comments/<comment_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Update Comment](https://docs.oneall.com/api/resources/loudvoice/comment/update/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `comment_token` | path | `string` | yes | The OneAll comment token. |
