# Update Discussion with OneAll

Updates a LoudVoice discussion in OneAll.

## Endpoint

- **Method:** `PUT`
- **Path:** `/loudvoice/discussions/<discussion_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Update Discussion](https://docs.oneall.com/api/resources/loudvoice/discussions/update/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `discussion_token` | path | `string` | yes | The OneAll discussion token. |
