# List Identities with OneAll

Retrieves all social identities from OneAll.

## Endpoint

- **Method:** `GET`
- **Path:** `/identities.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [List Identities](https://docs.oneall.com/api/resources/identities/list-all-identities/)
