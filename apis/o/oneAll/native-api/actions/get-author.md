# Get Author with OneAll

Retrieves LoudVoice author details from OneAll.

## Endpoint

- **Method:** `GET`
- **Path:** `/loudvoice/authors/<author_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Get Author](https://docs.oneall.com/api/resources/loudvoice/authors/read/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `author_token` | path | `string` | yes | The OneAll author token. |
