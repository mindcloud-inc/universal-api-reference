# Get Connection with OneAll

Retrieves social connection details from OneAll.

## Endpoint

- **Method:** `GET`
- **Path:** `/connections/<connection_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Get Connection](https://docs.oneall.com/api/resources/connections/read-connection-details/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `connection_token` | path | `string` | yes | The OneAll connection token. |
