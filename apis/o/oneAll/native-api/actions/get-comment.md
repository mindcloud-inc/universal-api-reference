# Get Comment with OneAll

Retrieves LoudVoice comment details from OneAll.

## Endpoint

- **Method:** `GET`
- **Path:** `/loudvoice/comments/<comment_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Get Comment](https://docs.oneall.com/api/resources/loudvoice/comment/read/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `comment_token` | path | `string` | yes | The OneAll comment token. |
