# List SSO Sessions with OneAll

Retrieves all SSO sessions from OneAll.

## Endpoint

- **Method:** `GET`
- **Path:** `/sso/sessions.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [List SSO Sessions](https://docs.oneall.com/api/resources/sso/list-all-sessions/)
