# Delete Author with OneAll

Deletes a LoudVoice author from OneAll.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/loudvoice/authors/<author_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Delete Author](https://docs.oneall.com/api/resources/loudvoice/authors/delete/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `author_token` | path | `string` | yes | The OneAll author token. |
