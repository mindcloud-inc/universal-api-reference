# List Comments with OneAll

Retrieves all LoudVoice comments from OneAll.

## Endpoint

- **Method:** `GET`
- **Path:** `/loudvoice/comments.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [List Comments](https://docs.oneall.com/api/resources/loudvoice/comment/list/)
