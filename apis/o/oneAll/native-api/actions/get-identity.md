# Get Identity with OneAll

Retrieves social identity details from OneAll.

## Endpoint

- **Method:** `GET`
- **Path:** `/identities/<identity_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Get Identity](https://docs.oneall.com/api/resources/identities/read-identity-details/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identity_token` | path | `string` | yes | The OneAll identity token. |
