# Delete Discussion with OneAll

Deletes a LoudVoice discussion from OneAll.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/loudvoice/discussions/<discussion_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Delete Discussion](https://docs.oneall.com/api/resources/loudvoice/discussions/delete/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `discussion_token` | path | `string` | yes | The OneAll discussion token. |
