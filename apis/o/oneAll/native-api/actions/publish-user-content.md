# Publish User Content with OneAll

Publishes content to a user's social networks in OneAll.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/<user_token>/publish.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Publish User Content](https://docs.oneall.com/api/resources/users/write-to-users-wall/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_token` | path | `string` | yes | The OneAll user token. |
