# Update Author with OneAll

Updates a LoudVoice author in OneAll.

## Endpoint

- **Method:** `PUT`
- **Path:** `/loudvoice/authors/<author_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Update Author](https://docs.oneall.com/api/resources/loudvoice/authors/update/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `author_token` | path | `string` | yes | The OneAll author token. |
