# Get Discussion with OneAll

Retrieves LoudVoice discussion details from OneAll.

## Endpoint

- **Method:** `GET`
- **Path:** `/loudvoice/discussions/<discussion_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Get Discussion](https://docs.oneall.com/api/resources/loudvoice/discussions/read/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `discussion_token` | path | `string` | yes | The OneAll discussion token. |
