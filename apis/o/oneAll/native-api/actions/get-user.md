# Get User with OneAll

Retrieves a user's details from OneAll.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/<user_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Get User](https://docs.oneall.com/api/resources/users/read-user-details/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_token` | path | `string` | yes | The OneAll user token. |
