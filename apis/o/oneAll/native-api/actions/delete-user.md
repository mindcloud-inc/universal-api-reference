# Delete User with OneAll

Deletes an existing user from OneAll.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/<user_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Delete User](https://docs.oneall.com/api/resources/users/delete-user/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_token` | path | `string` | yes | The OneAll user token. |
