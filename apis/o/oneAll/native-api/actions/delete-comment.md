# Delete Comment with OneAll

Deletes a LoudVoice comment from OneAll.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/loudvoice/comments/<comment_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Delete Comment](https://docs.oneall.com/api/resources/loudvoice/comment/delete/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `comment_token` | path | `string` | yes | The OneAll comment token. |
