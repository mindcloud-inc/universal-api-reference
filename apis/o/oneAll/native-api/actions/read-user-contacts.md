# Read User Contacts with OneAll

Retrieves a user's social contacts from OneAll.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/<user_token>/contacts.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Read User Contacts](https://docs.oneall.com/api/resources/users/read-contacts/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_token` | path | `string` | yes | The OneAll user token. |
