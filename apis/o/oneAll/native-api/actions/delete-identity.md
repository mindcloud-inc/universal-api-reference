# Delete Identity with OneAll

Deletes a social identity from OneAll.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/identities/<identity_token>.json`
- **Base URL:** `https://mindcloudco.api.oneall.com`
- **Official documentation:** [Delete Identity](https://docs.oneall.com/api/resources/identities/delete-identity/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identity_token` | path | `string` | yes | The OneAll identity token. |
