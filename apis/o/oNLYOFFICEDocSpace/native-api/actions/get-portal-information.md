# Get Portal Information with ONLYOFFICE DocSpace

Retrieves portal information from ONLYOFFICE DocSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/portal`
- **Base URL:** `https://docspace-t0dtrp.onlyoffice.com`
- **Official documentation:** [Get Portal Information](https://api.onlyoffice.com/docspace/api-backend/usage-api/get-portal-information/)
