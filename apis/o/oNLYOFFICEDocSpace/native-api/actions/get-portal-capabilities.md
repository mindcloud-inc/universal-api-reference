# Get Portal Capabilities with ONLYOFFICE DocSpace

Retrieves portal capabilities from ONLYOFFICE DocSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/capabilities`
- **Base URL:** `https://docspace-t0dtrp.onlyoffice.com`
- **Official documentation:** [Get Portal Capabilities](https://api.onlyoffice.com/docspace/api-backend/usage-api/get-portal-capabilities/)
