# Get Portal Settings with ONLYOFFICE DocSpace

Retrieves portal settings from ONLYOFFICE DocSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/settings`
- **Base URL:** `https://docspace-t0dtrp.onlyoffice.com`
- **Official documentation:** [Get Portal Settings](https://api.onlyoffice.com/docspace/api-backend/usage-api/get-settings/)
