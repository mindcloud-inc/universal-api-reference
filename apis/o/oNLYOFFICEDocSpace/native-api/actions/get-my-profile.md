# Get My Profile with ONLYOFFICE DocSpace

Retrieves your profile from ONLYOFFICE DocSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/people/@self`
- **Base URL:** `https://docspace-t0dtrp.onlyoffice.com`
- **Official documentation:** [Get My Profile](https://api.onlyoffice.com/docspace/api-backend/usage-api/get-self-profile/)
