# Get File Settings with ONLYOFFICE DocSpace

Retrieves file settings from ONLYOFFICE DocSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/files/settings`
- **Base URL:** `https://docspace-t0dtrp.onlyoffice.com`
- **Official documentation:** [Get File Settings](https://api.onlyoffice.com/docspace/api-backend/usage-api/get-files-settings/)
