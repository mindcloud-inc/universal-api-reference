# Delete Customer with OPN

Deletes an existing customer from OPN.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customers/:id`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [Delete Customer](https://docs.omise.co/customer-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The customer ID to delete. |
