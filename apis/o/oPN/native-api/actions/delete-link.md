# Delete Link with OPN

Deletes an existing link from OPN.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/links/:id`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [Delete Link](https://docs.omise.co/links-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The link ID to delete. |
