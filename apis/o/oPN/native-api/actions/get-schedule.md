# Get Schedule with OPN

Retrieves details for a schedule from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedules/:id`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [Get Schedule](https://docs.omise.co/schedules-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The schedule ID to retrieve. |
