# Get Event with OPN

Retrieves details for an event from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:id`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [Get Event](https://docs.omise.co/events-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The event ID to retrieve. |
