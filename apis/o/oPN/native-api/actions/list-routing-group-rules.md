# List Routing Group Rules with OPN

Retrieves a list of routing Group Rules from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/routing_group_rules`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Routing Group Rules](https://docs.omise.co)

## Capabilities

This operation supports [pagination](../README.md#pagination).
