# List Customer Schedules with OPN

Retrieves a list of schedules for a customer from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:id/schedules`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Customer Schedules](https://docs.omise.co/schedules-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
