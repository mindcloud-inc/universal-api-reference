# List Schedules with OPN

Retrieves a list of schedules from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedules`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Schedules](https://docs.omise.co/schedules-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
