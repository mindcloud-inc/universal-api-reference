# Delete Schedule with OPN

Deletes an existing schedule from OPN.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/schedules/:id`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [Delete Schedule](https://docs.omise.co/schedules-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The schedule ID to delete. |
