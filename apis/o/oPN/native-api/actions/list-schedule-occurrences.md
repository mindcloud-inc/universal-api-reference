# List Schedule Occurrences with OPN

Retrieves a list of occurrences for a schedule from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedules/:id/occurrences`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Schedule Occurrences](https://docs.omise.co/schedules-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
