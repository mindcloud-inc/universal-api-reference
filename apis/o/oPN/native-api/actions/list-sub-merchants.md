# List Sub Merchants with OPN

Retrieves a list of sub Merchants from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/sub_merchants`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Sub Merchants](https://docs.omise.co)

## Capabilities

This operation supports [pagination](../README.md#pagination).
