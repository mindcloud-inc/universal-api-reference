# List Linked Accounts with OPN

Retrieves a list of linked Accounts from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/linked_accounts`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Linked Accounts](https://docs.omise.co)

## Capabilities

This operation supports [pagination](../README.md#pagination).
