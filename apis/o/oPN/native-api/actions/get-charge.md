# Get Charge with OPN

Retrieves details for a charge from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/charges/:id`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [Get Charge](https://docs.omise.co/charge-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The charge ID to retrieve. |
