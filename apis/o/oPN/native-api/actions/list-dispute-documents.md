# List Dispute Documents with OPN

Retrieves a list of documents for a dispute from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/disputes/:id/documents`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Dispute Documents](https://docs.omise.co/disputes-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
