# List Chain Keys with OPN

Retrieves a list of keys for a chain from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/chains/:id/keys`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Chain Keys](https://docs.omise.co)

## Capabilities

This operation supports [pagination](../README.md#pagination).
