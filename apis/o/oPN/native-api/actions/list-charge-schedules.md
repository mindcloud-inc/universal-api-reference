# List Charge Schedules with OPN

Retrieves a list of charge Schedules from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/charges/schedules`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Charge Schedules](https://docs.omise.co/schedules-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
