# Get Link with OPN

Retrieves details for a link from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/:id`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [Get Link](https://docs.omise.co/links-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The link ID to retrieve. |
