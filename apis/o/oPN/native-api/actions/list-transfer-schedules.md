# List Transfer Schedules with OPN

Retrieves a list of transfer Schedules from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/transfers/schedules`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Transfer Schedules](https://docs.omise.co/schedules-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
