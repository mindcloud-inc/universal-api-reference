# List Webhook Secrets with OPN

Retrieves a list of webhook Secrets from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/secrets`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Webhook Secrets](https://docs.omise.co)

## Capabilities

This operation supports [pagination](../README.md#pagination).
