# List Open Disputes with OPN

Retrieves a list of open Disputes from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/disputes/open`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Open Disputes](https://docs.omise.co/disputes-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
