# Search Charges with OPN

Finds charges in OPN by search criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/charges/search`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [Search Charges](https://docs.omise.co/search-query-and-filters)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Free-text search query. |
