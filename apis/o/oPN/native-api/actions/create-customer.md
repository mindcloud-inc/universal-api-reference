# Create Customer with OPN

Creates a new customer in OPN.

## Endpoint

- **Method:** `POST`
- **Path:** `/customers`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [Create Customer](https://docs.omise.co/customer-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `description` | body | `string` | no | The customer description. |
| `email` | body | `string` | no | The customer email address. |
