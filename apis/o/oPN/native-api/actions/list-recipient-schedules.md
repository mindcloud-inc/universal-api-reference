# List Recipient Schedules with OPN

Retrieves a list of schedules for a recipient from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipients/:id/schedules`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Recipient Schedules](https://docs.omise.co/schedules-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
