# List Closed Disputes with OPN

Retrieves a list of closed Disputes from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/disputes/closed`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Closed Disputes](https://docs.omise.co/disputes-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
