# List Pending Disputes with OPN

Retrieves a list of pending Disputes from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/disputes/pending`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Pending Disputes](https://docs.omise.co/disputes-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
