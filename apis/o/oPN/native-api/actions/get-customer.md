# Get Customer with OPN

Retrieves details for a customer from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:id`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [Get Customer](https://docs.omise.co/customer-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The customer ID to retrieve. |
