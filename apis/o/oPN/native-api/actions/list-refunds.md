# List Refunds with OPN

Retrieves a list of refunds from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/refunds`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [List Refunds](https://docs.omise.co/refunds-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
