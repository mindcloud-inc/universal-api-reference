# Get Dispute with OPN

Retrieves details for a dispute from OPN.

## Endpoint

- **Method:** `GET`
- **Path:** `/disputes/:id`
- **Base URL:** `https://api.omise.co`
- **Official documentation:** [Get Dispute](https://docs.omise.co/disputes-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The dispute ID to retrieve. |
