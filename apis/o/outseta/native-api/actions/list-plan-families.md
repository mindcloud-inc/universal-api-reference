# List Plan Families with Outseta

Retrieves a list of plan families from Outseta.

## Endpoint

- **Method:** `GET`
- **Path:** `/billing/planfamilies`
- **Base URL:** `https://{subdomain}.outseta.com/api/v1`
- **Official documentation:** [List Plan Families](https://documenter.getpostman.com/view/3613332/outseta-rest-api-v1/7TNfr6k)
