# Get Deal with Outseta

Retrieves a deal from Outseta.

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/deals/:dealUid`
- **Base URL:** `https://{subdomain}.outseta.com/api/v1`
- **Official documentation:** [Get Deal](https://documenter.getpostman.com/view/3613332/outseta-rest-api-v1/7TNfr6k)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dealUid` | path | `string` | yes |
