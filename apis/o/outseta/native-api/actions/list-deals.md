# List Deals with Outseta

Retrieves a list of deals from Outseta.

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/deals`
- **Base URL:** `https://{subdomain}.outseta.com/api/v1`
- **Official documentation:** [List Deals](https://documenter.getpostman.com/view/3613332/outseta-rest-api-v1/7TNfr6k)
