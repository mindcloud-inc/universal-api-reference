# List Activities with Outseta

Retrieves a list of activities from Outseta.

## Endpoint

- **Method:** `GET`
- **Path:** `/activities`
- **Base URL:** `https://{subdomain}.outseta.com/api/v1`
- **Official documentation:** [List Activities](https://documenter.getpostman.com/view/3613332/outseta-rest-api-v1/7TNfr6k)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ActivityType` | query | `number` | no |
| `EntityType` | query | `number` | no |
