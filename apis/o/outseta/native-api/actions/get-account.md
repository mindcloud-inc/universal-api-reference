# Get Account with Outseta

Retrieves an account from Outseta.

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/accounts/:accountUid`
- **Base URL:** `https://{subdomain}.outseta.com/api/v1`
- **Official documentation:** [Get Account](https://documenter.getpostman.com/view/3613332/outseta-rest-api-v1/7TNfr6k)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountUid` | path | `string` | yes |
