# List Plans with Outseta

Retrieves a list of plans from Outseta.

## Endpoint

- **Method:** `GET`
- **Path:** `/billing/plans`
- **Base URL:** `https://{subdomain}.outseta.com/api/v1`
- **Official documentation:** [List Plans](https://documenter.getpostman.com/view/3613332/outseta-rest-api-v1/7TNfr6k)
