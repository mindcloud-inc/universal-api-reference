# Add Custom Activity with Outseta

Creates a custom activity in Outseta.

## Endpoint

- **Method:** `POST`
- **Path:** `/activities/customactivity`
- **Base URL:** `https://{subdomain}.outseta.com/api/v1`
- **Official documentation:** [Add Custom Activity](https://documenter.getpostman.com/view/3613332/outseta-rest-api-v1/7TNfr6k)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `Title` | body | `string` | no |
| `Description` | body | `string` | no |
| `ActivityData` | body | `string` | no |
| `EntityType` | body | `number` | no |
| `EntityUid` | body | `string` | no |
