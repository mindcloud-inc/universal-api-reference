# Extend Trial Subscription with Outseta

Extends a trial subscription in Outseta.

## Endpoint

- **Method:** `PUT`
- **Path:** `/crm/accounts/extendtrial/:accountUid/:date`
- **Base URL:** `https://{subdomain}.outseta.com/api/v1`
- **Official documentation:** [Extend Trial Subscription](https://documenter.getpostman.com/view/3613332/outseta-rest-api-v1/7TNfr6k)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountUid` | path | `string` | yes |
| `date` | path | `string` | yes |
