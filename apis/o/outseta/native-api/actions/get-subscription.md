# Get Subscription with Outseta

Retrieves a subscription from Outseta.

## Endpoint

- **Method:** `GET`
- **Path:** `/billing/subscriptions/:subscriptionUid`
- **Base URL:** `https://{subdomain}.outseta.com/api/v1`
- **Official documentation:** [Get Subscription](https://documenter.getpostman.com/view/3613332/outseta-rest-api-v1/7TNfr6k)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriptionUid` | path | `string` | yes |
