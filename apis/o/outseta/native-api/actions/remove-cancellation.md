# Remove Cancellation with Outseta

Removes an account cancellation in Outseta.

## Endpoint

- **Method:** `PUT`
- **Path:** `/crm/accounts/removecancellation/:accountUid`
- **Base URL:** `https://{subdomain}.outseta.com/api/v1`
- **Official documentation:** [Remove Cancellation](https://documenter.getpostman.com/view/3613332/outseta-rest-api-v1/7TNfr6k)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountUid` | path | `string` | yes |
