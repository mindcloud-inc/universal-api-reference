# Get Person with Outseta

Retrieves a person from Outseta.

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/people/:personUid`
- **Base URL:** `https://{subdomain}.outseta.com/api/v1`
- **Official documentation:** [Get Person](https://documenter.getpostman.com/view/3613332/outseta-rest-api-v1/7TNfr6k)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `personUid` | path | `string` | yes |
