# List Accounts with Outseta

Retrieves a list of accounts from Outseta.

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/accounts`
- **Base URL:** `https://{subdomain}.outseta.com/api/v1`
- **Official documentation:** [List Accounts](https://documenter.getpostman.com/view/3613332/outseta-rest-api-v1/7TNfr6k)

## Capabilities

This operation supports [pagination](../README.md#pagination).
