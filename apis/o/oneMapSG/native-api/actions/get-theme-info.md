# Get Theme Info with OneMap SG

Retrieves information about a OneMap SG theme.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/themesvc/getThemeInfo`
- **Base URL:** `https://www.onemap.gov.sg`
- **Official documentation:** [Get Theme Info](https://www.onemap.gov.sg/apidocs/themes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `queryName` | query | `string` | yes | The theme query name. |
