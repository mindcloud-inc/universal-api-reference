# Get Auth Token with OneMap SG

Creates an authentication token in OneMap SG.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/auth/post/getToken`
- **Base URL:** `https://www.onemap.gov.sg`
- **Official documentation:** [Get Auth Token](https://www.onemap.gov.sg/apidocs/authentication)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | no | The email address for your OneMap account. |
