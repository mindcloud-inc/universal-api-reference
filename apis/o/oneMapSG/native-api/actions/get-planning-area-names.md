# Get Planning Area Names with OneMap SG

Retrieves planning area names from OneMap SG.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/popapi/getPlanningareaNames`
- **Base URL:** `https://www.onemap.gov.sg`
- **Official documentation:** [Get Planning Area Names](https://www.onemap.gov.sg/apidocs/planningarea)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `year` | query | `number` | yes | The year to retrieve planning area names for. |
