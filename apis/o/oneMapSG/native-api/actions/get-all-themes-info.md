# Get All Themes Info with OneMap SG

Retrieves information about all OneMap SG themes.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/themesvc/getAllThemesInfo`
- **Base URL:** `https://www.onemap.gov.sg`
- **Official documentation:** [Get All Themes Info](https://www.onemap.gov.sg/apidocs/themes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `moreInfo` | query | `string` | no | Whether to include more theme information. |
