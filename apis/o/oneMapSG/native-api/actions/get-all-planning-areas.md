# Get All Planning Areas with OneMap SG

Retrieves all planning areas from OneMap SG.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/popapi/getAllPlanningarea`
- **Base URL:** `https://www.onemap.gov.sg`
- **Official documentation:** [Get All Planning Areas](https://www.onemap.gov.sg/apidocs/planningarea)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `year` | query | `number` | yes | The year to retrieve planning area polygons for. |
