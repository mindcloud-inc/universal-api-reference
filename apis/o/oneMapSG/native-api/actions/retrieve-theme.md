# Retrieve Theme with OneMap SG

Retrieves theme data from OneMap SG.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/themesvc/retrieveTheme`
- **Base URL:** `https://www.onemap.gov.sg`
- **Official documentation:** [Retrieve Theme](https://www.onemap.gov.sg/apidocs/themes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `queryName` | query | `string` | yes | The theme query name. |
