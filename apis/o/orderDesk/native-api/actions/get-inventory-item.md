# Get Inventory Item with Order Desk

Retrieves an inventory item from Order Desk.

## Endpoint

- **Method:** `GET`
- **Path:** `/inventory-items/:inventoryItemId`
- **Base URL:** `https://app.orderdesk.me/api/v2`
- **Official documentation:** [Get Inventory Item](https://apidocs.orderdesk.com/?shell=#get-a-single-inventory-item)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inventoryItemId` | path | `string` | yes | Order Desk internal inventory item ID. |
