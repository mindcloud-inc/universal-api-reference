# Get Order with Order Desk

Retrieves an order from Order Desk.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:orderId`
- **Base URL:** `https://app.orderdesk.me/api/v2`
- **Official documentation:** [Get Order](https://apidocs.orderdesk.com/?shell=#get-a-single-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderId` | path | `string` | yes | Order Desk internal order ID. |
