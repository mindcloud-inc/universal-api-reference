# List Inventory Items with Order Desk

Retrieves inventory items from Order Desk.

## Endpoint

- **Method:** `GET`
- **Path:** `/inventory-items`
- **Base URL:** `https://app.orderdesk.me/api/v2`
- **Official documentation:** [List Inventory Items](https://apidocs.orderdesk.com/?shell=#get-all-inventory-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | query | `string` | no | Filter inventory items by SKU code. |
