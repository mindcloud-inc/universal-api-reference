# Delete Custom Field with Ortto

## Endpoint

- **Method:** `DELETE`
- **Path:** `/instances/custom-field/delete`
- **Base URL:** `{apiBaseUrl}/v1`
- **Official documentation:** [Delete Custom Field](https://help.ortto.com/a-908-delete-custom-field)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `field_id` | body | `string` | yes | Ortto custom field identifier to delete. |
