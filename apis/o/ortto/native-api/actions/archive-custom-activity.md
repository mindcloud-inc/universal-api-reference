# Archive Custom Activity with Ortto

## Endpoint

- **Method:** `DELETE`
- **Path:** `/definitions/activity/delete`
- **Base URL:** `{apiBaseUrl}/v1`
- **Official documentation:** [Archive Custom Activity](https://help.ortto.com/a-275-delete-a-custom-activity-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activity_field_id` | body | `string` | yes | Custom activity field ID to archive. |
