# Get Result with OnceOnly

Retrieves an AI task result from OnceOnly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/ai/result`
- **Base URL:** `https://api.onceonly.tech`
- **Official documentation:** [Get Result](https://docs.onceonly.tech/reference/ai/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | query | `string` | yes | Lease key to retrieve final result for. |
