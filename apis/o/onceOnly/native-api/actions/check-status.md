# Check Status with OnceOnly

Retrieves AI lease status from OnceOnly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/ai/status`
- **Base URL:** `https://api.onceonly.tech`
- **Official documentation:** [Check Status](https://docs.onceonly.tech/reference/ai/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | query | `string` | yes | Lease key to look up. |
