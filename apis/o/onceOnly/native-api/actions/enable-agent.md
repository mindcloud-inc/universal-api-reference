# Enable Agent with OnceOnly

Enables an agent in OnceOnly.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/agents/:agent_id/enable`
- **Base URL:** `https://api.onceonly.tech`
- **Official documentation:** [Enable Agent](https://docs.onceonly.tech/reference/agents/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | Agent id to enable. |
