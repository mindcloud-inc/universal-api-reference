# List Tools with OnceOnly

Retrieves tools from OnceOnly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tools`
- **Base URL:** `https://api.onceonly.tech`
- **Official documentation:** [List Tools](https://docs.onceonly.tech/reference/tools/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scope_id` | query | `string` | no | Tool scope to list. |
