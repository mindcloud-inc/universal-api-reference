# Get Policy with OnceOnly

Retrieves a policy from OnceOnly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/policies/:agent_id`
- **Base URL:** `https://api.onceonly.tech`
- **Official documentation:** [Get Policy](https://docs.onceonly.tech/reference/policies/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | Agent id to fetch policy for. |
