# Get Usage with OnceOnly

Retrieves usage details from OnceOnly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/usage`
- **Base URL:** `https://api.onceonly.tech`
- **Official documentation:** [Get Usage](https://docs.onceonly.tech/reference/usage/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `kind` | query | `string` | no | Usage counter kind: make or ai. |
