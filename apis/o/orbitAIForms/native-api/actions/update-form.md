# Update Form with Orbit AI (Forms)

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/forms/:id`
- **Base URL:** `https://orbitforms.ai`
- **Official documentation:** [Update Form](https://docs.orbitforms.ai/developers/api/forms#endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The Orbit form UUID. |
