# List Forms with Orbit AI (Forms)

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/forms`
- **Base URL:** `https://orbitforms.ai`
- **Official documentation:** [List Forms](https://docs.orbitforms.ai/developers/api/forms#list-forms)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Filter forms by status. |
