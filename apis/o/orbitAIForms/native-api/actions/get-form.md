# Get Form with Orbit AI (Forms)

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/forms/:id`
- **Base URL:** `https://orbitforms.ai`
- **Official documentation:** [Get Form](https://docs.orbitforms.ai/developers/api/forms#get-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The Orbit form UUID. |
