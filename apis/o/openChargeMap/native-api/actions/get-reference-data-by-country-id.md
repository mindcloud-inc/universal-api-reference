# Get Reference Data By Country ID with Open Charge Map

## Endpoint

- **Method:** `GET`
- **Path:** `/referencedata`
- **Base URL:** `https://api.openchargemap.io/v3`
- **Official documentation:** [Get Reference Data By Country ID](https://www.openchargemap.org/develop/api#/operations/get-referencedata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `countryid` | query | `string` | yes | Optional numeric country ID filter for Open Charge Map reference data. |
