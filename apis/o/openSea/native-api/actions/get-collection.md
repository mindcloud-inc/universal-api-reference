# Get Single Collection with OpenSea

Retrieves a collection from OpenSea.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/collections/{slug}`
- **Base URL:** `https://api.opensea.io`
- **Official documentation:** [Get Single Collection](https://docs.opensea.io/reference/get_collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Unique identifier for the specific collection |
