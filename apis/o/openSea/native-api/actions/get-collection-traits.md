# Get Collection Traits with OpenSea

Retrieves collection traits from OpenSea.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/traits/{slug}`
- **Base URL:** `https://api.opensea.io`
- **Official documentation:** [Get Collection Traits](https://docs.opensea.io/reference/get_collection_traits)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Unique identifier for the specific collection |
