# Get Collection Stats with OpenSea

Retrieves collection stats from OpenSea.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/collections/{slug}/stats`
- **Base URL:** `https://api.opensea.io`
- **Official documentation:** [Get Collection Stats](https://docs.opensea.io/reference/get_collection_stats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Unique identifier for the specific collection |
