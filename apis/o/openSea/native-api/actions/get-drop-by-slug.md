# Get Drop By Collection Slug with OpenSea

Retrieves a drop from OpenSea.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/drops/{slug}`
- **Base URL:** `https://api.opensea.io`
- **Official documentation:** [Get Drop By Collection Slug](https://docs.opensea.io/reference/get_drop_by_slug)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Collection slug |
