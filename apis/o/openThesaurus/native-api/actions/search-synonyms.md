# Search Synonyms with OpenThesaurus

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://www.openthesaurus.de/synonyme/search`
- **Official documentation:** [Search Synonyms](https://www.openthesaurus.de/about/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `q` | query | `string` | yes |
| `similar` | query | `boolean` | no |
| `substring` | query | `boolean` | no |
| `startswith` | query | `boolean` | no |
| `supersynsets` | query | `boolean` | no |
| `subsynsets` | query | `boolean` | no |
| `baseform` | query | `boolean` | no |
