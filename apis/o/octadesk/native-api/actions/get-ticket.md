# Get Ticket with Octadesk

Retrieves a ticket from Octadesk by number.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/:number`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Ticket](https://developers.octadesk.com/reference/getbynumber)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `number` | path | `string` | yes | Ticket number |
