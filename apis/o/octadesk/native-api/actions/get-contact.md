# Get Contact with Octadesk

Retrieves a contact from Octadesk by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Contact](https://developers.octadesk.com/reference/getcontactbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact ID from Octadesk. |
