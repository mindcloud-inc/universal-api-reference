# List Chat Events with Octadesk

Retrieves events from an Octadesk chat.

## Endpoint

- **Method:** `GET`
- **Path:** `/chat/:id/events`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Chat Events](https://developers.octadesk.com/reference/geteventsbychatid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Chat ID from Octadesk. |
