# List Survey Submissions with Octadesk

Retrieves survey submissions from Octadesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/survey/submissions`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Survey Submissions](https://developers.octadesk.com/reference/getsubmissions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `string` | no | Number of the page viewed. |
| `size` | query | `string` | no | Number of items retrieved per page. |
