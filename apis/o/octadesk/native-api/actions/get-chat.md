# Get Chat with Octadesk

Retrieves a chat from Octadesk by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/chat/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Chat](https://developers.octadesk.com/reference/getchatbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Chat ID from Octadesk. |
