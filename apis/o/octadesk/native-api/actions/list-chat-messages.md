# List Chat Messages with Octadesk

Retrieves messages from an Octadesk chat.

## Endpoint

- **Method:** `GET`
- **Path:** `/chat/:id/messages`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Chat Messages](https://developers.octadesk.com/reference/getmessagesbychatid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Chat ID from Octadesk. |
