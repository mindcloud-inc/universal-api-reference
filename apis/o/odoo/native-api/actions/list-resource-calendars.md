# List Resource Calendars with Odoo

Retrieves resource calendars from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/resource.calendar/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Resource Calendars](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
