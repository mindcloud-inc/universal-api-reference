# List Blacklisted Phone Numbers with Odoo

Retrieves blacklisted phone numbers from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/phone.blacklist/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Blacklisted Phone Numbers](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
