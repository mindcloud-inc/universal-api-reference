# List Planning Roles with Odoo

Retrieves planning roles from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/planning.role/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Planning Roles](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
