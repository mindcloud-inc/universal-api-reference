# List Resume Lines with Odoo

Retrieves resume lines from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/hr.resume.line/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Resume Lines](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
