# List Work Locations with Odoo

Retrieves work locations from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/hr.work.location/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Work Locations](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
