# List Country States with Odoo

Retrieves country states from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/res.country.state/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Country States](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
