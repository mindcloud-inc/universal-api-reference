# List Skill Types with Odoo

Retrieves skill types from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/hr.skill.type/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Skill Types](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
