# List Planning Shifts with Odoo

Retrieves planning shifts from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/planning.slot/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Planning Shifts](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
