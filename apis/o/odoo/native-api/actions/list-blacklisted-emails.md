# List Blacklisted Emails with Odoo

Retrieves blacklisted emails from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/mail.blacklist/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Blacklisted Emails](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
