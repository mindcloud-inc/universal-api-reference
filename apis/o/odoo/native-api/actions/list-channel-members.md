# List Channel Members with Odoo

Retrieves channel members from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/discuss.channel.member/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Channel Members](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
