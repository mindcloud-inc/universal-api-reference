# List Model Data with Odoo

Retrieves model data from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/ir.model.data/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Model Data](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
