# List Currencies with Odoo

Retrieves currencies from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/res.currency/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Currencies](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
