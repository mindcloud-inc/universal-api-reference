# List Mail Servers with Odoo

Retrieves mail servers from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/ir.mail_server/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Mail Servers](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
