# List Employee Skills with Odoo

Retrieves employee skills from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/hr.employee.skill/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Employee Skills](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
