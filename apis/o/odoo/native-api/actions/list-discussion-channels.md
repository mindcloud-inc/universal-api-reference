# List Discussion Channels with Odoo

Retrieves discussion channels from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/discuss.channel/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Discussion Channels](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
