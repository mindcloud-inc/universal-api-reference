# List Action Windows with Odoo

Retrieves action windows from Odoo.

## Endpoint

- **Method:** `POST`
- **Path:** `/ir.actions.act_window/search_read`
- **Base URL:** `https://{domain}/json/2`
- **Official documentation:** [List Action Windows](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
