# Get Subject Access Request with Optimizely

Retrieves a subject access request from Optimizely.

## Endpoint

- **Method:** `GET`
- **Path:** `/subject-access-requests/{requestId}`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Subject Access Request](https://docs.developers.optimizely.com/web-experimentation/reference/get_sar_request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `request_id` | path | `string` | yes | The subject access request id. |
