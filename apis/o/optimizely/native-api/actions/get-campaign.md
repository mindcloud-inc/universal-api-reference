# Get Campaign with Optimizely

Retrieves campaign details from the Optimizely API.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/{campaignId}`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Campaign](https://docs.developers.optimizely.com/web-experimentation/reference/get_campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | The campaign id. |
