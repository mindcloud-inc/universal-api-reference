# Get Audience with Optimizely

Retrieves audience details from the Optimizely API.

## Endpoint

- **Method:** `GET`
- **Path:** `/audiences/{audienceId}`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Audience](https://docs.developers.optimizely.com/web-experimentation/reference/get_audience)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audience_id` | path | `string` | yes | The audience id. |
