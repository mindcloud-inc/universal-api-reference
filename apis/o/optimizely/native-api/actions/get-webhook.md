# Get Webhook with Optimizely

Retrieves webhook details from the Optimizely API.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/{webhookId}`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Webhook](https://docs.developers.optimizely.com/web-experimentation/reference/get_webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes | The webhook id. |
