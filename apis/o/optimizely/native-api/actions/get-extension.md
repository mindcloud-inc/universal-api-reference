# Get Extension with Optimizely

Retrieves extension details from the Optimizely API.

## Endpoint

- **Method:** `GET`
- **Path:** `/extensions/{extensionId}`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Extension](https://docs.developers.optimizely.com/web-experimentation/reference/get_extension)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `extension_id` | path | `string` | yes | The extension id. |
