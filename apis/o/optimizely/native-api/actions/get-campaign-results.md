# Get Campaign Results with Optimizely

Retrieves results for a campaign in Optimizely.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/{campaignId}/results`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Campaign Results](https://docs.developers.optimizely.com/web-experimentation/reference/get_campaign_results)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | The campaign id to fetch results for. |
