# Get Group with Optimizely

Retrieves an exclusion group from Optimizely.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/{groupId}`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Group](https://docs.developers.optimizely.com/web-experimentation/reference/get_group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | yes | The group id. |
