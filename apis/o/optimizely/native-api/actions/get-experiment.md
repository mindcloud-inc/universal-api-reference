# Get Experiment with Optimizely

Retrieves experiment details from the Optimizely API.

## Endpoint

- **Method:** `GET`
- **Path:** `/experiments/{experimentId}`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Experiment](https://docs.developers.optimizely.com/web-experimentation/reference/get_experiment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `experiment_id` | path | `string` | yes | The experiment id. |
