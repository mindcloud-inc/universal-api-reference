# Get Attribute with Optimizely

Retrieves attribute details from the Optimizely API.

## Endpoint

- **Method:** `GET`
- **Path:** `/attributes/{attributeId}`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Attribute](https://docs.developers.optimizely.com/web-experimentation/reference/get_attribute)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `attribute_id` | path | `string` | yes | The attribute id. |
