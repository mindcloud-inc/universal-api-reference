# List Subject Access Requests with Optimizely

Retrieves subject access requests from Optimizely.

## Endpoint

- **Method:** `GET`
- **Path:** `/subject-access-requests`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [List Subject Access Requests](https://docs.developers.optimizely.com/web-experimentation/reference/list_sar_requests_by_account)

## Capabilities

This operation supports [pagination](../README.md#pagination).
