# Get Page with Optimizely

Retrieves page details from the Optimizely API.

## Endpoint

- **Method:** `GET`
- **Path:** `/pages/{pageId}`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Page](https://docs.developers.optimizely.com/web-experimentation/reference/get_page)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | path | `string` | yes | The page id. |
