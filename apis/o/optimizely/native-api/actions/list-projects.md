# List Projects with Optimizely

Retrieves a list of projects from Optimizely.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [List Projects](https://docs.developers.optimizely.com/web-experimentation/reference/list_projects)

## Capabilities

This operation supports [pagination](../README.md#pagination).
