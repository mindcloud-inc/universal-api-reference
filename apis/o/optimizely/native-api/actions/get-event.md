# Get Event with Optimizely

Retrieves event details from the Optimizely API.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/{eventId}`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Event](https://docs.developers.optimizely.com/web-experimentation/reference/get_event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | The event id. |
