# Get Project with Optimizely

Retrieves project details from the Optimizely API.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{projectId}`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Project](https://docs.developers.optimizely.com/web-experimentation/reference/get_project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The Optimizely project id. |
