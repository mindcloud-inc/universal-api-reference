# Get Environment with Optimizely

Retrieves environment details from the Optimizely API.

## Endpoint

- **Method:** `GET`
- **Path:** `/environments/{environmentId}`
- **Base URL:** `https://api.optimizely.com/v2`
- **Official documentation:** [Get Environment](https://docs.developers.optimizely.com/web-experimentation/reference/get_environment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `environment_id` | path | `string` | yes | The environment id. |
