# Get Enterprise Team with OnePlan

Retrieves an enterprise team from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/enterpriseteams/{id}`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Enterprise Team](https://my.oneplan.ai/ApiHelp/Api/GET-api-enterpriseteams-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Enterprise team identifier from the path. |
