# Get My Work Update with OnePlan

Retrieves a My Work update from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/mywork/getupdate/{id}`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get My Work Update](https://my.oneplan.ai/ApiHelp/Api/GET-api-mywork-getupdate-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Task identifier from the path. |
