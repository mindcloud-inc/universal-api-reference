# List Workplan Fragments with OnePlan

Retrieves workplan fragments from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/workplan/fragments`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [List Workplan Fragments](https://my.oneplan.ai/ApiHelp/Api/GET-api-workplan-fragments_FragmentCategory)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `FragmentCategory` | query | `string` | no | Optional fragment category query parameter from the docs. |
