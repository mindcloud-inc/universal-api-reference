# Get Team List For Plan with OnePlan

Retrieves shared teams for a plan from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/workplan/{PlanId}/sharedwithteam`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Team List For Plan](https://my.oneplan.ai/ApiHelp/Api/GET-api-workplan-PlanId-sharedwithteam)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PlanId` | path | `string` | yes | Plan identifier from the path. |
