# Get Enterprise Team Members with OnePlan

Retrieves enterprise team members from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/enterpriseteams/{id}/members`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Enterprise Team Members](https://my.oneplan.ai/ApiHelp/Api/GET-api-enterpriseteams-id-members)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Enterprise team identifier from the path. |
