# Get Child Plans with OnePlan

Retrieves child plans from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/workplan/{PlanId}/subplans`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Child Plans](https://my.oneplan.ai/ApiHelp/Api/GET-api-workplan-PlanId-subplans)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PlanId` | path | `string` | yes | Plan identifier from the path. |
