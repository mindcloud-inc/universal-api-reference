# Get Plan Level Fields with OnePlan

Retrieves plan-level fields from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/workplan/fields`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Plan Level Fields](https://my.oneplan.ai/ApiHelp/Api/GET-api-workplan-fields_HideSystem)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `HideSystem` | query | `string` | no | Optional flag to hide system fields. |
