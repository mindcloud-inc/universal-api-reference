# Get Event Logs with OnePlan

Retrieves event logs from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/{Id}/log`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Event Logs](https://my.oneplan.ai/ApiHelp/Api/GET-api-events-Id-log)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | path | `string` | yes | Event identifier from the path. |
