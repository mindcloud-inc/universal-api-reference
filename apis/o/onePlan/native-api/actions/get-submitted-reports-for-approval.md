# Get Submitted Reports For Approval with OnePlan

Retrieves submitted reports for approval from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/statusreports/mysubmit`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Submitted Reports For Approval](https://my.oneplan.ai/ApiHelp/Api/GET-api-statusreports-mysubmit)
