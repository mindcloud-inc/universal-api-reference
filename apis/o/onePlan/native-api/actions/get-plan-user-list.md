# Get Plan User List with OnePlan

Retrieves plan users from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/workplan/{PlanId}/user`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Plan User List](https://my.oneplan.ai/ApiHelp/Api/GET-api-workplan-PlanId-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PlanId` | path | `string` | yes | Plan identifier from the path. |
