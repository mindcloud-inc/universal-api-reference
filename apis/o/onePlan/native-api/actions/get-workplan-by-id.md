# Get Workplan By ID with OnePlan

Retrieves a workplan from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/workplan/{PlanId}`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Workplan By ID](https://my.oneplan.ai/ApiHelp/Api/GET-api-workplan-PlanId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PlanId` | path | `string` | yes | Plan identifier from the path. |
