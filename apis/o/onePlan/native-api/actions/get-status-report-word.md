# Get Status Report Word with OnePlan

Retrieves a status report Word document from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/statusreports/{id}/doc`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Status Report Word](https://my.oneplan.ai/ApiHelp/Api/GET-api-statusreports-id-doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Status report identifier from the path. |
