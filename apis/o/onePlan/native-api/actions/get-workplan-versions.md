# Get Workplan Versions with OnePlan

Retrieves workplan versions from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/workplan/{id}/versions`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Workplan Versions](https://my.oneplan.ai/ApiHelp/Api/GET-api-workplan-id-versions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Workplan identifier from the path. |
