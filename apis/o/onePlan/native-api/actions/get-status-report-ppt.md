# Get Status Report PPT with OnePlan

Retrieves a status report PowerPoint from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/statusreports/{id}/ppt`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Status Report PPT](https://my.oneplan.ai/ApiHelp/Api/GET-api-statusreports-id-ppt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Status report identifier from the path. |
