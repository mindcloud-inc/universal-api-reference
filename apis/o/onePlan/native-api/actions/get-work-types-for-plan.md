# Get Work Types For Plan with OnePlan

Retrieves work types for a plan from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/workplan/{PlanId}/worktypes`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Work Types For Plan](https://my.oneplan.ai/ApiHelp/Api/GET-api-workplan-PlanId-worktypes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PlanId` | path | `string` | yes | Plan identifier from the path. |
