# Get Process History with OnePlan

Retrieves process history from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/workplan/{PlanId}/processhistory`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Process History](https://my.oneplan.ai/ApiHelp/Api/GET-api-workplan-PlanId-processhistory)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PlanId` | path | `string` | yes | Plan identifier from the path. |
