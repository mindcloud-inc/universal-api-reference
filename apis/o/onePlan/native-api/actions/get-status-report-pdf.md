# Get Status Report PDF with OnePlan

Retrieves a status report PDF from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/statusreports/{id}/pdf`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Status Report PDF](https://my.oneplan.ai/ApiHelp/Api/GET-api-statusreports-id-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Status report identifier from the path. |
