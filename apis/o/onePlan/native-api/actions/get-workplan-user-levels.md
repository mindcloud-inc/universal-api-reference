# Get Workplan User Levels with OnePlan

Retrieves workplan user levels from OnePlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/workplan/user/levels`
- **Base URL:** `https://my.oneplan.ai/api`
- **Official documentation:** [Get Workplan User Levels](https://my.oneplan.ai/ApiHelp/Api/GET-api-workplan-user-levels)
