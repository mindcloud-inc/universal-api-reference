# Get User by ID with Ordoro

Retrieves a user from Ordoro by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/{user_id}/`
- **Base URL:** `https://api.ordoro.com`
- **Official documentation:** [Get User by ID](https://docs.ordoro.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The Ordoro user ID. |
