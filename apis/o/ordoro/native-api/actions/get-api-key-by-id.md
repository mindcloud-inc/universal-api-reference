# Get API Key by ID with Ordoro

Retrieves an API key from Ordoro by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api_key/{api_key_id}/`
- **Base URL:** `https://api.ordoro.com`
- **Official documentation:** [Get API Key by ID](https://docs.ordoro.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `api_key_id` | path | `string` | yes | The Ordoro API key ID. |
