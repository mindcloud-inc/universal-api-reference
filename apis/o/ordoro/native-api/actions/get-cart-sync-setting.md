# Get Cart Sync Setting with Ordoro

Retrieves cart sync settings from Ordoro.

## Endpoint

- **Method:** `GET`
- **Path:** `/cart/{cart_id}/autosync/`
- **Base URL:** `https://api.ordoro.com`
- **Official documentation:** [Get Cart Sync Setting](https://docs.ordoro.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cart_id` | path | `string` | yes | The Ordoro cart ID. |
