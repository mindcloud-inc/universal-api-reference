# Get Cart Warehouses with Ordoro

Retrieves warehouses for an Ordoro cart.

## Endpoint

- **Method:** `GET`
- **Path:** `/cart/{cart_id}/warehouse/`
- **Base URL:** `https://api.ordoro.com`
- **Official documentation:** [Get Cart Warehouses](https://docs.ordoro.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cart_id` | path | `string` | yes | The Ordoro cart ID. |
