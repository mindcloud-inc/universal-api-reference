# Get Cart with Ordoro

Retrieves a cart from Ordoro.

## Endpoint

- **Method:** `GET`
- **Path:** `/cart/{cart_id}/`
- **Base URL:** `https://api.ordoro.com`
- **Official documentation:** [Get Cart](https://docs.ordoro.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cart_id` | path | `string` | yes | The Ordoro cart ID. |
