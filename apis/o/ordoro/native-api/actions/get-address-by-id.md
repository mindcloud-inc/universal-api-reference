# Get Address by ID with Ordoro

Retrieves an address from Ordoro by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/address/{address_id}/`
- **Base URL:** `https://api.ordoro.com`
- **Official documentation:** [Get Address by ID](https://docs.ordoro.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address_id` | path | `string` | yes | The Ordoro address ID. |
