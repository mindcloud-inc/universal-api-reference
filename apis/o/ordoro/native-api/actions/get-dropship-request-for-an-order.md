# Get Dropship Request for an Order with Ordoro

Retrieves a dropship request for an Ordoro order.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/order/{order_number}/dropship`
- **Base URL:** `https://api.ordoro.com`
- **Official documentation:** [Get Dropship Request for an Order](https://docs.ordoro.com)
