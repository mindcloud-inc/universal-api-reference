# Retrieve Specific Tag with Ontraport

Retrieves a specific tag from Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Tag`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Specific Tag](https://api.ontraport.com/doc/#retrieve-a-specific-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The tag ID. |
