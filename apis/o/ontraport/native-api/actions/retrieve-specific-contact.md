# Retrieve Specific Contact with Ontraport

Retrieves a specific contact from Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contact`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Specific Contact](https://api.ontraport.com/doc/#retrieve-a-specific-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The contact ID. |
