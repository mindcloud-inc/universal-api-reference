# Retrieve Product Collection Info with Ontraport

Retrieves collection info for products in Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Products/getInfo`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Product Collection Info](https://api.ontraport.com/doc/#retrieve-product-collection-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search the collection info response. |
