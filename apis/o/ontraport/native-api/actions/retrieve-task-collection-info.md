# Retrieve Task Collection Info with Ontraport

Retrieves collection info for tasks in Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Tasks/getInfo`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Task Collection Info](https://api.ontraport.com/doc/#retrieve-task-collection-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search the collection info response. |
