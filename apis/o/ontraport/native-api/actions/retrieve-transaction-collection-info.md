# Retrieve Transaction Collection Info with Ontraport

Retrieves collection info for transactions in Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Invoices/getInfo`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Transaction Collection Info](https://api.ontraport.com/doc/#retrieve-transaction-collection-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search the collection info response. |
