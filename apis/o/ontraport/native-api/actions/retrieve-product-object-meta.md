# Retrieve Product Object Meta with Ontraport

Retrieves metadata for product objects in Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Products/meta`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Product Object Meta](https://api.ontraport.com/doc/#retrieve-product-object-meta)
