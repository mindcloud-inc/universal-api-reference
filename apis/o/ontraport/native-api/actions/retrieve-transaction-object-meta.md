# Retrieve Transaction Object Meta with Ontraport

Retrieves metadata for transaction objects in Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Transactions/meta`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Transaction Object Meta](https://api.ontraport.com/doc/#retrieve-transaction-object-meta)
