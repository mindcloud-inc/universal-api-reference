# List Tasks with Ontraport

Retrieves a list of tasks from Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Tasks`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [List Tasks](https://api.ontraport.com/doc/#retrieve-multiple-tasks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
