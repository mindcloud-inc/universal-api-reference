# Retrieve Contact Object Meta with Ontraport

Retrieves metadata for contact objects in Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contacts/meta`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Contact Object Meta](https://api.ontraport.com/doc/#retrieve-contact-object-meta)
