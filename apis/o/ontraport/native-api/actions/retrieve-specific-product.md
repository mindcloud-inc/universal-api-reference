# Retrieve Specific Product with Ontraport

Retrieves a specific product from Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Product`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Specific Product](https://api.ontraport.com/doc/#retrieve-a-specific-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The product ID. |
