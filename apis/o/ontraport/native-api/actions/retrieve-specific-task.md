# Retrieve Specific Task with Ontraport

Retrieves a specific task from Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Task`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Specific Task](https://api.ontraport.com/doc/#retrieve-a-specific-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The task ID. |
