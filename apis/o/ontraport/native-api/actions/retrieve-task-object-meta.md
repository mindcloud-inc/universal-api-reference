# Retrieve Task Object Meta with Ontraport

Retrieves metadata for task objects in Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Tasks/meta`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Task Object Meta](https://api.ontraport.com/doc/#retrieve-task-object-meta)
