# List Products with Ontraport

Retrieves a list of products from Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Products`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [List Products](https://api.ontraport.com/doc/#retrieve-multiple-products)

## Capabilities

This operation supports [pagination](../README.md#pagination).
