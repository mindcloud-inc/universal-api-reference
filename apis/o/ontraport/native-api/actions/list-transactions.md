# List Transactions with Ontraport

Retrieves a list of transactions from Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Transactions`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [List Transactions](https://api.ontraport.com/doc/#retrieve-multiple-transactions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
