# Retrieve Tag Object Meta with Ontraport

Retrieves metadata for tag objects in Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Tags/meta`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Tag Object Meta](https://api.ontraport.com/doc/#retrieve-tag-object-meta)
