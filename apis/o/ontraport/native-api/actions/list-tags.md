# List Tags with Ontraport

Retrieves a list of tags from Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Tags`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [List Tags](https://api.ontraport.com/doc/#retrieve-multiple-tags)

## Capabilities

This operation supports [pagination](../README.md#pagination).
