# List Messages with Ontraport

Retrieves a list of messages from Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Messages`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [List Messages](https://api.ontraport.com/doc/#retrieve-multiple-messages)

## Capabilities

This operation supports [pagination](../README.md#pagination).
