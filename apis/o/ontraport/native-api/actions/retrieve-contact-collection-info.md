# Retrieve Contact Collection Info with Ontraport

Retrieves collection info for contacts in Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contacts/getInfo`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Contact Collection Info](https://api.ontraport.com/doc/#retrieve-contact-collection-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search the collection info response. |
