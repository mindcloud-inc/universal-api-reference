# Retrieve Tag Collection Info with Ontraport

Retrieves collection info for tags in Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Tags/getInfo`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Tag Collection Info](https://api.ontraport.com/doc/#retrieve-tag-collection-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search the collection info response. |
