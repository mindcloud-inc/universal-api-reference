# Retrieve Specific Message with Ontraport

Retrieves a specific message from Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Message`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Specific Message](https://api.ontraport.com/doc/#retrieve-a-specific-message)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The message ID. |
