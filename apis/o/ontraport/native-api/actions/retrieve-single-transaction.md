# Retrieve Single Transaction with Ontraport

Retrieves a single transaction from Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Transaction`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Single Transaction](https://api.ontraport.com/doc/#retrieve-a-single-transaction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The transaction ID. |
