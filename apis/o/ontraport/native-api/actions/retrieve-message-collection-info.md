# Retrieve Message Collection Info with Ontraport

Retrieves collection info for messages in Ontraport.

## Endpoint

- **Method:** `GET`
- **Path:** `/Messages/getInfo`
- **Base URL:** `https://api.ontraport.com/1`
- **Official documentation:** [Retrieve Message Collection Info](https://api.ontraport.com/doc/#retrieve-message-collection-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search the collection info response. |
