# Get Inference Pipeline with Openlayer

Retrieves an inference pipeline from Openlayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/inference-pipelines/:inferencePipelineId`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [Get Inference Pipeline](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inferencePipelineId` | path | `string` | yes | Openlayer inference pipeline ID. |
