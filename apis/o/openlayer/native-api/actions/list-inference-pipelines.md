# List Inference Pipelines with Openlayer

Retrieves inference pipelines for a project in Openlayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/inference-pipelines`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [List Inference Pipelines](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Openlayer project ID. |
