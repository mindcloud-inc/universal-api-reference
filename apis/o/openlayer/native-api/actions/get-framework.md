# Get Framework with Openlayer

Retrieves framework details from the Openlayer API.

## Endpoint

- **Method:** `GET`
- **Path:** `/frameworks/:frameworkId`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [Get Framework](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `frameworkId` | path | `string` | yes | Openlayer framework ID. |
