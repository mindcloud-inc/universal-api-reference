# List Project User Tags with Openlayer

Retrieves user tags for a project in Openlayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/user-tags`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [List Project User Tags](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Openlayer project ID. |
