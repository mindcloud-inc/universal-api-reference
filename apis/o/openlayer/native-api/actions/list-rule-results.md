# List Rule Results with Openlayer

Retrieves results for a rule in Openlayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/rules/:ruleId/results`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [List Rule Results](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ruleId` | path | `string` | yes | Openlayer rule ID. |
