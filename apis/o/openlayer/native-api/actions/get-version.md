# Get Version with Openlayer

Retrieves version details from the Openlayer API.

## Endpoint

- **Method:** `GET`
- **Path:** `/versions/:versionId`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [Get Version](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `versionId` | path | `string` | yes | The project version ID. |
