# List Rule Result Goals with Openlayer

Retrieves goals for a rule result in Openlayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/rule-results/:ruleResultId/goals`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [List Rule Result Goals](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ruleResultId` | path | `string` | yes | Openlayer rule result ID. |
