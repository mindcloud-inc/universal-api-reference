# Get Rule Result with Openlayer

Retrieves a rule result from Openlayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/rule-results/:ruleResultId`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [Get Rule Result](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ruleResultId` | path | `string` | yes | Openlayer rule result ID. |
