# List Inference Pipeline Goals with Openlayer

Retrieves goals for an inference pipeline in Openlayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/inference-pipelines/:inferencePipelineId/goals`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [List Inference Pipeline Goals](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inferencePipelineId` | path | `string` | yes | Openlayer inference pipeline ID. |
