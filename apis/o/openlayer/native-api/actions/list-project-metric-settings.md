# List Project Metric Settings with Openlayer

Retrieves metric settings for a project in Openlayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/metric-settings`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [List Project Metric Settings](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Openlayer project ID. |
