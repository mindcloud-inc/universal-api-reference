# List Version Results with Openlayer

Retrieves results for a version in Openlayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/versions/:versionId/results`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [List Version Results](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `versionId` | path | `string` | yes | The project version ID. |
