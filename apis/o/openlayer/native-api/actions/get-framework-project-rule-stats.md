# Get Framework Project Rule Stats with Openlayer

Retrieves framework project rule statistics from Openlayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/frameworks/:frameworkId/project-rule-stats`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [Get Framework Project Rule Stats](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `frameworkId` | path | `string` | yes | Openlayer framework ID. |
