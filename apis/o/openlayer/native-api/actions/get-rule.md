# Get Rule with Openlayer

Retrieves rule details from the Openlayer API.

## Endpoint

- **Method:** `GET`
- **Path:** `/rules/:ruleId`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [Get Rule](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ruleId` | path | `string` | yes | Openlayer rule ID. |
