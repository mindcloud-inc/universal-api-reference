# List Rule Result Evidence with Openlayer

Retrieves evidence for a rule result in Openlayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/rule-results/:ruleResultId/evidence`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [List Rule Result Evidence](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ruleResultId` | path | `string` | yes | Openlayer rule result ID. |
