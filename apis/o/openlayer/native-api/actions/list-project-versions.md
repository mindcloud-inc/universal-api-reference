# List Project Versions with Openlayer

Retrieves versions for a project in Openlayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/versions`
- **Base URL:** `https://api.openlayer.com/v1`
- **Official documentation:** [List Project Versions](https://api.openlayer.com/v1/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Openlayer project ID. |
