# List Campaigns with OptiMonk

Retrieves a list of campaigns from OptiMonk.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/`
- **Base URL:** `https://api.optimonk.com/v1`
- **Official documentation:** [List Campaigns](https://api.optimonk.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Pagination index. Starts at 1. |
