# Get Campaign with OptiMonk

Retrieves a campaign from OptiMonk.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/{id}`
- **Base URL:** `https://api.optimonk.com/v1`
- **Official documentation:** [Get Campaign](https://api.optimonk.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The OptiMonk campaign ID. |
