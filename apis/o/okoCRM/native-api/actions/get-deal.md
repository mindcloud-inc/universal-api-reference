# Get deal with OkoCRM

Retrieves deal details from OkoCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/[:lead_id]/`
- **Base URL:** `https://api.okocrm.com/v2`
- **Official documentation:** [Get deal](https://okocrm.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lead_id` | path | `number` | yes | The OkoCRM deal ID. |
