# Delete contact with OkoCRM

Deletes an existing contact from OkoCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/[:contact_id]/`
- **Base URL:** `https://api.okocrm.com/v2`
- **Official documentation:** [Delete contact](https://okocrm.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `number` | yes | The OkoCRM contact ID. |
