# Delete deal with OkoCRM

Deletes an existing deal from OkoCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/leads/[:lead_id]/`
- **Base URL:** `https://api.okocrm.com/v2`
- **Official documentation:** [Delete deal](https://okocrm.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lead_id` | path | `number` | yes | The OkoCRM deal ID. |
