# List notes with OkoCRM

Retrieves notes from OkoCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/notes/`
- **Base URL:** `https://api.okocrm.com/v2`
- **Official documentation:** [List notes](https://okocrm.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | query | `number` | yes | List notes for a contact. |
