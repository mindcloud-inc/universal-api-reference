# Delete company with OkoCRM

Deletes an existing company from OkoCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/companies/[:company_id]/`
- **Base URL:** `https://api.okocrm.com/v2`
- **Official documentation:** [Delete company](https://okocrm.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | path | `number` | yes | The OkoCRM company ID. |
