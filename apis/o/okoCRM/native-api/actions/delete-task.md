# Delete task with OkoCRM

Deletes an existing task from OkoCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/[:task_id]/`
- **Base URL:** `https://api.okocrm.com/v2`
- **Official documentation:** [Delete task](https://okocrm.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `number` | yes | The OkoCRM task ID. |
