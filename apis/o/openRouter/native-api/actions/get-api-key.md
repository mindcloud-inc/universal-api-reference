# Get API Key with OpenRouter

Retrieves a specific API key from OpenRouter.

## Endpoint

- **Method:** `GET`
- **Path:** `/keys/:hash`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [Get API Key](https://openrouter.ai/docs/api/api-reference/api-keys/get-key)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hash` | path | `string` | yes | API key hash identifier. |
