# Update Guardrail with OpenRouter

Updates an existing guardrail in OpenRouter.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/guardrails/:id`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [Update Guardrail](https://openrouter.ai/docs/api/api-reference/guardrails/update-guardrail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Guardrail identifier. |
