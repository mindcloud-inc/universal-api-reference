# Create Guardrail with OpenRouter

Creates a new guardrail in OpenRouter.

## Endpoint

- **Method:** `POST`
- **Path:** `/guardrails`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [Create Guardrail](https://openrouter.ai/docs/api/api-reference/guardrails/create-guardrail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name for the new guardrail. |
