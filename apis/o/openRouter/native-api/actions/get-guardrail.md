# Get Guardrail with OpenRouter

Retrieves a specific guardrail from OpenRouter.

## Endpoint

- **Method:** `GET`
- **Path:** `/guardrails/:id`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [Get Guardrail](https://openrouter.ai/docs/api/api-reference/guardrails/get-guardrail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Guardrail identifier. |
