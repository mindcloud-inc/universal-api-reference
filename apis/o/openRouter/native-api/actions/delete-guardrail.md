# Delete Guardrail with OpenRouter

Deletes an existing guardrail from OpenRouter.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/guardrails/:id`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [Delete Guardrail](https://openrouter.ai/docs/api/api-reference/guardrails/delete-guardrail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Guardrail identifier. |
