# Update API Key with OpenRouter

Updates an existing API key in OpenRouter.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/keys/:hash`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [Update API Key](https://openrouter.ai/docs/api/api-reference/api-keys/update-keys)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hash` | path | `string` | yes | API key hash identifier. |
