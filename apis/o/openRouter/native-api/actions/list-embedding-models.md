# List Embedding Models with OpenRouter

Retrieves available embedding models from OpenRouter.

## Endpoint

- **Method:** `GET`
- **Path:** `/embeddings/models`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [List Embedding Models](https://openrouter.ai/docs/api/api-reference/embeddings/list-embeddings-models)
