# List User Models with OpenRouter

Retrieves models filtered by user settings from OpenRouter.

## Endpoint

- **Method:** `GET`
- **Path:** `/models/user`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [List User Models](https://openrouter.ai/docs/api/api-reference/models/list-models-user)
