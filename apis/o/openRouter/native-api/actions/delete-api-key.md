# Delete API Key with OpenRouter

Deletes an existing API key from OpenRouter.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/keys/:hash`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [Delete API Key](https://openrouter.ai/docs/api/api-reference/api-keys/delete-keys)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hash` | path | `string` | yes | API key hash identifier. |
