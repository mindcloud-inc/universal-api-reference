# Get Current API Key with OpenRouter

Retrieves the current API key from OpenRouter.

## Endpoint

- **Method:** `GET`
- **Path:** `/key`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [Get Current API Key](https://openrouter.ai/docs/api/api-reference/api-keys/get-current-key)
