# Create API Key with OpenRouter

Creates a new API key in OpenRouter.

## Endpoint

- **Method:** `POST`
- **Path:** `/keys`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [Create API Key](https://openrouter.ai/docs/api/api-reference/api-keys/create-keys)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name for the new API key. |
