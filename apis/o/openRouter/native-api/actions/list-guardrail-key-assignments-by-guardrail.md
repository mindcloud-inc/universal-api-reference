# List Guardrail Key Assignments By Guardrail with OpenRouter

Retrieves key assignments for a specific guardrail in OpenRouter.

## Endpoint

- **Method:** `GET`
- **Path:** `/guardrails/:id/assignments/keys`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [List Guardrail Key Assignments By Guardrail](https://openrouter.ai/docs/api/api-reference/guardrails/list-guardrail-key-assignments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Guardrail identifier. |
