# Get Generation with OpenRouter

Retrieves request and usage metadata for an OpenRouter generation.

## Endpoint

- **Method:** `GET`
- **Path:** `/generation`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [Get Generation](https://openrouter.ai/docs/api/api-reference/generations/get-generation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Identifier of the generation to retrieve. |
