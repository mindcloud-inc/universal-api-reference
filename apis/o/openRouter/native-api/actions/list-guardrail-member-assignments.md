# List Guardrail Member Assignments with OpenRouter

Retrieves all guardrail-to-member assignments from OpenRouter.

## Endpoint

- **Method:** `GET`
- **Path:** `/guardrails/assignments/members`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [List Guardrail Member Assignments](https://openrouter.ai/docs/api/api-reference/guardrails/list-member-assignments)
