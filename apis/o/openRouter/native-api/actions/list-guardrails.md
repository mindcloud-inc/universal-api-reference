# List Guardrails with OpenRouter

Retrieves all configured guardrails from OpenRouter.

## Endpoint

- **Method:** `GET`
- **Path:** `/guardrails`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [List Guardrails](https://openrouter.ai/docs/api/api-reference/guardrails/list-guardrails)
