# List Guardrail Key Assignments with OpenRouter

Retrieves all guardrail-to-key assignments from OpenRouter.

## Endpoint

- **Method:** `GET`
- **Path:** `/guardrails/assignments/keys`
- **Base URL:** `https://openrouter.ai/api/v1/`
- **Official documentation:** [List Guardrail Key Assignments](https://openrouter.ai/docs/api/api-reference/guardrails/list-key-assignments)
