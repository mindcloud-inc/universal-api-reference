# Count Tobacco Problem Records with OpenFDA

Counts tobacco problem records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/tobacco/problem.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Count Tobacco Problem Records](https://open.fda.gov/apis/tobacco/problem/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering).
