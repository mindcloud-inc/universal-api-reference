# Search UNII Records with OpenFDA

Finds UNII records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/other/unii.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search UNII Records](https://open.fda.gov/apis/other/unii/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
