# Search Device Classification Records with OpenFDA

Finds device classification records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/device/classification.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search Device Classification Records](https://open.fda.gov/apis/device/classification/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
