# Count Device Event Records with OpenFDA

Counts device event records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/device/event.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Count Device Event Records](https://open.fda.gov/apis/device/event/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering).
