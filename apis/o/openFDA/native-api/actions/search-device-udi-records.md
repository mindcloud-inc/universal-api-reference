# Search Device UDI Records with OpenFDA

Finds device UDI records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/device/udi.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search Device UDI Records](https://open.fda.gov/apis/device/udi/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
