# Search Historical Document Records with OpenFDA

Finds historical document records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/other/historicaldocument.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search Historical Document Records](https://open.fda.gov/apis/other/historicaldocument/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
