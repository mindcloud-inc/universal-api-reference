# Search Food Enforcement Records with OpenFDA

Finds food enforcement records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/enforcement.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search Food Enforcement Records](https://open.fda.gov/apis/food/enforcement/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
