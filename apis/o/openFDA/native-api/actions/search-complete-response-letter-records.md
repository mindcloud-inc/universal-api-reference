# Search Complete Response Letter Records with OpenFDA

Finds complete response letter records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/transparency/crl.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search Complete Response Letter Records](https://open.fda.gov/apis/transparency/completeresponseletters/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
