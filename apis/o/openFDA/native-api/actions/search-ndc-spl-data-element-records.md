# Search NDC SPL Data Element Records with OpenFDA

Finds NDC SPL data element records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/other/nsde.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search NDC SPL Data Element Records](https://open.fda.gov/apis/other/nsde/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
