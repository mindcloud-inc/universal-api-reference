# Count Device 510(k) Records with OpenFDA

Counts device 510(k) records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/device/510k.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Count Device 510(k) Records](https://open.fda.gov/apis/device/510k/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering).
