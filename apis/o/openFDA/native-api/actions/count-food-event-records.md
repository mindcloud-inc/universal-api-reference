# Count Food Event Records with OpenFDA

Counts food event records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/event.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Count Food Event Records](https://open.fda.gov/apis/food/event/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering).
