# Search Device PMA Records with OpenFDA

Finds device PMA records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/device/pma.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search Device PMA Records](https://open.fda.gov/apis/device/pma/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
