# Search Animal Veterinary Event Records with OpenFDA

Finds animal veterinary event records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/animalandveterinary/event.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search Animal Veterinary Event Records](https://open.fda.gov/apis/animalandveterinary/event/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
