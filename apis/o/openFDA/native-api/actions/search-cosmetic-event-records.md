# Search Cosmetic Event Records with OpenFDA

Finds cosmetic event records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/cosmetic/event.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search Cosmetic Event Records](https://open.fda.gov/apis/cosmetic/event/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
