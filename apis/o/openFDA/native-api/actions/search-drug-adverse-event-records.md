# Search Drug Adverse Event Records with OpenFDA

Finds drug adverse event records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/drug/event.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search Drug Adverse Event Records](https://open.fda.gov/apis/drug/event/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
