# Count Device COVID-19 Serology Records with OpenFDA

Counts device COVID-19 serology records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/device/covid19serology.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Count Device COVID-19 Serology Records](https://open.fda.gov/apis/device/covid19serology/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering).
