# Search Device Recall Records with OpenFDA

Finds device recall records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/device/recall.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search Device Recall Records](https://open.fda.gov/apis/device/recall/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
