# Count Device Registration Listing Records with OpenFDA

Counts device registration listing records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/device/registrationlisting.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Count Device Registration Listing Records](https://open.fda.gov/apis/device/registrationlisting/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering).
