# Search Tobacco Smokefree Research Records with OpenFDA

Finds tobacco smokefree research records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/tobacco/researchsmokefree.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Search Tobacco Smokefree Research Records](https://open.fda.gov/apis/tobacco/researchsmokefree/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
