# Count Tobacco Prevention Ads Research Records with OpenFDA

Counts tobacco prevention ads research records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/tobacco/researchpreventionads.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Count Tobacco Prevention Ads Research Records](https://open.fda.gov/apis/tobacco/researchpreventionads/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering).
