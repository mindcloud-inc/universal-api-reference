# Count Device Enforcement Records with OpenFDA

Counts device enforcement records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/device/enforcement.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Count Device Enforcement Records](https://open.fda.gov/apis/device/enforcement/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering).
