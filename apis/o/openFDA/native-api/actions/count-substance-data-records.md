# Count Substance Data Records with OpenFDA

Counts substance data records in OpenFDA.

## Endpoint

- **Method:** `GET`
- **Path:** `/other/substance.json`
- **Base URL:** `https://api.fda.gov`
- **Official documentation:** [Count Substance Data Records](https://open.fda.gov/apis/other/substance/how-to-use-the-endpoint/)

## Capabilities

This operation supports [filtering](../README.md#filtering).
