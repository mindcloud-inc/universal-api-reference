# Get Supported Locales with One-Time Secret

Retrieves supported locales from One-Time Secret.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/supported-locales`
- **Base URL:** `https://us.onetimesecret.com`
- **Official documentation:** [Get Supported Locales](https://api.onetimesecret.com/doc/api-v2/operation/operation-v2_getsupportedlocales)
