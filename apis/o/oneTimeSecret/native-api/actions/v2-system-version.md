# System Version with One-Time Secret

Retrieves current system version from One-Time Secret.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/version`
- **Base URL:** `https://us.onetimesecret.com`
- **Official documentation:** [System Version](https://api.onetimesecret.com/doc/api-v2/operation/operation-v2_systemversion)
