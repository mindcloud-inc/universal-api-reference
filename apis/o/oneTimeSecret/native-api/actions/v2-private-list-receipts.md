# Private List Receipts with One-Time Secret

Retrieves recent private secret receipts from One-Time Secret.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/private/recent`
- **Base URL:** `https://us.onetimesecret.com`
- **Official documentation:** [Private List Receipts](https://api.onetimesecret.com/doc/api-v2/operation/operation-v2_private_listreceipts)
