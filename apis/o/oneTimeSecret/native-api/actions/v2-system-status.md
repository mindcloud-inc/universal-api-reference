# System Status with One-Time Secret

Retrieves current system status from One-Time Secret.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/status`
- **Base URL:** `https://us.onetimesecret.com`
- **Official documentation:** [System Status](https://api.onetimesecret.com/doc/api-v2/operation/operation-v2_systemstatus)
