# List Receipts with One-Time Secret

Retrieves recent secret receipts from One-Time Secret.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/receipt/recent`
- **Base URL:** `https://us.onetimesecret.com`
- **Official documentation:** [List Receipts](https://api.onetimesecret.com/doc/api-v2/operation/operation-v2_listreceipts)
