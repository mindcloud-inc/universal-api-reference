# Get Team with Onfleet

Retrieves a team from Onfleet.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId`
- **Base URL:** `https://onfleet.com/api/v2`
- **Official documentation:** [Get Team](https://docs.onfleet.com/reference/get-single-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | The Onfleet team ID. |
