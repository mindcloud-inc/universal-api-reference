# Get Recipient with Onfleet

Retrieves a recipient from Onfleet.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipients/:recipientId`
- **Base URL:** `https://onfleet.com/api/v2`
- **Official documentation:** [Get Recipient](https://docs.onfleet.com/reference/get-single-recipient)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recipientId` | path | `string` | yes | The Onfleet recipient ID. |
