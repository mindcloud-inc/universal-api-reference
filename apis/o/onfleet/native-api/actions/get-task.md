# Get Task with Onfleet

Retrieves a task from Onfleet.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:taskId`
- **Base URL:** `https://onfleet.com/api/v2`
- **Official documentation:** [Get Task](https://docs.onfleet.com/reference/get-single-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | The Onfleet task ID. |
