# Get Destination with Onfleet

Retrieves a destination from Onfleet.

## Endpoint

- **Method:** `GET`
- **Path:** `/destinations/:destinationId`
- **Base URL:** `https://onfleet.com/api/v2`
- **Official documentation:** [Get Destination](https://docs.onfleet.com/reference/get-single-destination)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `destinationId` | path | `string` | yes | The Onfleet destination ID. |
