# Delete Workspace with OpnForm

Deletes an existing workspace from OpnForm.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/open/workspaces/:workspaceId`
- **Base URL:** `https://api.opnform.com`
- **Official documentation:** [Delete Workspace](https://docs.opnform.com/api-reference/workspaces/delete-workspace)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceId` | path | `number` | yes |
