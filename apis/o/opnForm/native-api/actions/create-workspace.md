# Create Workspace with OpnForm

Creates a new workspace in OpnForm.

## Endpoint

- **Method:** `POST`
- **Path:** `/open/workspaces/create`
- **Base URL:** `https://api.opnform.com`
- **Official documentation:** [Create Workspace](https://docs.opnform.com/api-reference/workspaces/create-workspace)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `emoji` | body | `string` | no |
