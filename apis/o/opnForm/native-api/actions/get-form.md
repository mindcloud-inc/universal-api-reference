# Get Form with OpnForm

Retrieves a form from OpnForm by slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/open/forms/:slug`
- **Base URL:** `https://api.opnform.com`
- **Official documentation:** [Get Form](https://docs.opnform.com/api-reference/forms/get-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Form slug or UUID. |
