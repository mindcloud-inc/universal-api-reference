# List Form Integrations with OpnForm

Lists integrations for an OpnForm form.

## Endpoint

- **Method:** `GET`
- **Path:** `/open/forms/:formId/integrations`
- **Base URL:** `https://api.opnform.com`
- **Official documentation:** [List Form Integrations](https://docs.opnform.com/api-reference/integrations/list-form-integrations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `number` | yes |
