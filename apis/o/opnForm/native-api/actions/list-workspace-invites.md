# List Workspace Invites with OpnForm

Lists invites in an OpnForm workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/open/workspaces/:workspaceId/invites`
- **Base URL:** `https://api.opnform.com`
- **Official documentation:** [List Workspace Invites](https://docs.opnform.com/api-reference/workspace-users/list-workspace-invites)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceId` | path | `number` | yes |
