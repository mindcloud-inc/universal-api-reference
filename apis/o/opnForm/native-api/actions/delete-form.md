# Delete Form with OpnForm

Deletes an existing form from OpnForm.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/open/forms/:id`
- **Base URL:** `https://api.opnform.com`
- **Official documentation:** [Delete Form](https://docs.opnform.com/api-reference/forms/delete-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric ID of the form to delete. |
