# List Workspace Forms with OpnForm

Lists forms in an OpnForm workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/open/workspaces/:workspaceId/forms`
- **Base URL:** `https://api.opnform.com`
- **Official documentation:** [List Workspace Forms](https://docs.opnform.com/api-reference/forms/list-workspace-forms)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | path | `number` | yes | Workspace ID to list forms from. |
