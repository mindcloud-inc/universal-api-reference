# List Workspace Users with OpnForm

Lists users in an OpnForm workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/open/workspaces/:workspaceId/users`
- **Base URL:** `https://api.opnform.com`
- **Official documentation:** [List Workspace Users](https://docs.opnform.com/api-reference/workspace-users/list-workspace-users)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceId` | path | `number` | yes |
