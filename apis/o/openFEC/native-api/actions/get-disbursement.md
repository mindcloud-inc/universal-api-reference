# Get Disbursement with OpenFEC

Retrieves a disbursement from OpenFEC.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedules/schedule_b/:sub_id/`
- **Base URL:** `https://api.open.fec.gov/v1`
- **Official documentation:** [Get Disbursement](https://api.open.fec.gov/developers/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sub_id` | path | `string` | yes | Schedule B transaction sub ID. |
