# List Disbursements By Recipient with OpenFEC

Retrieves disbursement totals in OpenFEC by recipient.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedules/schedule_b/by_recipient/`
- **Base URL:** `https://api.open.fec.gov/v1`
- **Official documentation:** [List Disbursements By Recipient](https://api.open.fec.gov/developers/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
