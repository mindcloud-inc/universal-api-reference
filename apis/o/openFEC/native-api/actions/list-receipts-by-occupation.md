# List Receipts By Occupation with OpenFEC

Retrieves receipt totals in OpenFEC by occupation.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedules/schedule_a/by_occupation/`
- **Base URL:** `https://api.open.fec.gov/v1`
- **Official documentation:** [List Receipts By Occupation](https://api.open.fec.gov/developers/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
