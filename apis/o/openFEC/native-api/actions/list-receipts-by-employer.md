# List Receipts By Employer with OpenFEC

Retrieves receipt totals in OpenFEC by employer.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedules/schedule_a/by_employer/`
- **Base URL:** `https://api.open.fec.gov/v1`
- **Official documentation:** [List Receipts By Employer](https://api.open.fec.gov/developers/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
