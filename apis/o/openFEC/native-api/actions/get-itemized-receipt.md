# Get Itemized Receipt with OpenFEC

Retrieves an itemized receipt from OpenFEC.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedules/schedule_a/:sub_id/`
- **Base URL:** `https://api.open.fec.gov/v1`
- **Official documentation:** [Get Itemized Receipt](https://api.open.fec.gov/developers/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sub_id` | path | `string` | yes | Schedule A transaction sub ID. |
