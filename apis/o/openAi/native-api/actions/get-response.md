# Get Response with Open AI

Retrieves a model response from Open AI.

## Endpoint

- **Method:** `GET`
- **Path:** `v1/responses/:response_id`
- **Base URL:** `https://api.openai.com`
- **Official documentation:** [Get Response](https://developers.openai.com/api/reference/resources/responses/methods/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `response_id` | path | `string` | yes | The ID of the response to retrieve. |
