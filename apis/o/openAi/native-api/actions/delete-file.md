# Delete File with Open AI

Deletes a file from Open AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `v1/files/:file_id`
- **Base URL:** `https://api.openai.com`
- **Official documentation:** [Delete File](https://developers.openai.com/api/reference/files/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | OpenAI file ID to delete. |
