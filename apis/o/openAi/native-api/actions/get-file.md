# Get File with Open AI

Retrieves a file from Open AI.

## Endpoint

- **Method:** `GET`
- **Path:** `v1/files/:file_id`
- **Base URL:** `https://api.openai.com`
- **Official documentation:** [Get File](https://developers.openai.com/api/reference/files/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | OpenAI file ID to retrieve. |
