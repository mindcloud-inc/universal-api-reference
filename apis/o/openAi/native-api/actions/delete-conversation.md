# Delete Conversation with Open AI

Deletes a conversation from Open AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `v1/conversations/:conversation_id`
- **Base URL:** `https://api.openai.com`
- **Official documentation:** [Delete Conversation](https://developers.openai.com/api/reference/overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversation_id` | path | `string` | yes | Conversation ID to delete. |
