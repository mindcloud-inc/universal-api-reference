# Retrieve Model with Open AI

Retrieves a model from Open AI.

## Endpoint

- **Method:** `GET`
- **Path:** `v1/models/:model`
- **Base URL:** `https://api.openai.com`
- **Official documentation:** [Retrieve Model](https://developers.openai.com/api/reference/resources/models/methods/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model` | path | `string` | yes | The model ID to retrieve. |
