# Get Conversation with Open AI

Retrieves a conversation from Open AI.

## Endpoint

- **Method:** `GET`
- **Path:** `v1/conversations/:conversation_id`
- **Base URL:** `https://api.openai.com`
- **Official documentation:** [Get Conversation](https://developers.openai.com/api/reference/overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversation_id` | path | `string` | yes | Conversation ID to retrieve. |
