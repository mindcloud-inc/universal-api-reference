# Get Order with Open Letter Connect

Retrieves an order from Open Letter Connect.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:id`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [Get Order](https://api-docs.openletterconnect.com/orders/get-one-order/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric order ID from Open Letter Connect. |
