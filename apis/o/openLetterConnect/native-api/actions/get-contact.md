# Get Contact with Open Letter Connect

Retrieves a contact from Open Letter Connect.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [Get Contact](https://api-docs.openletterconnect.com/contacts/get-one-contact/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric contact ID from Open Letter Connect. |
