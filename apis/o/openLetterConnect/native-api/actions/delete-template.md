# Delete Template with Open Letter Connect

Deletes a template from Open Letter Connect.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/templates/:id`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [Delete Template](https://api-docs.openletterconnect.com/_templates/delete-template/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric template ID from Open Letter Connect. |
