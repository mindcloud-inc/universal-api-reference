# Create Custom Field with Open Letter Connect

Creates a custom field in Open Letter Connect.

## Endpoint

- **Method:** `POST`
- **Path:** `/custom-fields`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [Create Custom Field](https://api-docs.openletterconnect.com/custom-fields/create-custom-field/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customFieldName` | body | `string` | yes | The custom field label to create. |
