# Get Custom Field with Open Letter Connect

Retrieves a custom field from Open Letter Connect.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-fields/:id`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [Get Custom Field](https://api-docs.openletterconnect.com/custom-fields/get-one-custom-field/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric custom field ID from Open Letter Connect. |
