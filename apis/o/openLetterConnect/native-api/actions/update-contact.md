# Update Contact with Open Letter Connect

Updates a contact in Open Letter Connect.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [Update Contact](https://api-docs.openletterconnect.com/contacts/update-contact/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric contact ID from Open Letter Connect. |
