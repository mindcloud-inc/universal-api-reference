# Get Order Details with Open Letter Connect

Retrieves order details from Open Letter Connect.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/detail/:id`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [Get Order Details](https://api-docs.openletterconnect.com/orders/items/order-details/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric order ID from Open Letter Connect. |
