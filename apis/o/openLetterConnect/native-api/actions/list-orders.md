# List Orders with Open Letter Connect

Retrieves orders from Open Letter Connect.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [List Orders](https://api-docs.openletterconnect.com/orders/get-order-history/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
