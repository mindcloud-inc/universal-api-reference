# Delete Custom Field with Open Letter Connect

Deletes a custom field from Open Letter Connect.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/custom-fields/:id`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [Delete Custom Field](https://api-docs.openletterconnect.com/custom-fields/delete-custom-field/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric custom field ID from Open Letter Connect. |
