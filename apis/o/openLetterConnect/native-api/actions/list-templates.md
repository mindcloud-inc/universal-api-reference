# List Templates with Open Letter Connect

Retrieves templates from Open Letter Connect.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [List Templates](https://api-docs.openletterconnect.com/_templates/get-all-templates/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
