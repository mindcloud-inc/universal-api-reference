# Get Product Types with Open Letter Connect

Retrieves product types from Open Letter Connect.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/types`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [Get Product Types](https://api-docs.openletterconnect.com/products/get-product-types/)
