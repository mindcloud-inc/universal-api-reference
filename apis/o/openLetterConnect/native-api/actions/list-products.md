# List Products with Open Letter Connect

Retrieves products from Open Letter Connect.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [List Products](https://api-docs.openletterconnect.com/products/get-all-products/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
