# List Custom Fields with Open Letter Connect

Retrieves custom fields from Open Letter Connect.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-fields`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [List Custom Fields](https://api-docs.openletterconnect.com/custom-fields/get-all-custom-fields/)
