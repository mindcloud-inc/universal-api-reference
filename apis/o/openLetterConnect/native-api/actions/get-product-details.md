# Get Product Details with Open Letter Connect

Retrieves product details from Open Letter Connect.

## Endpoint

- **Method:** `POST`
- **Path:** `/products/details`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [Get Product Details](https://api-docs.openletterconnect.com/products/product-details/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productType` | body | `string` | yes | The product type to inspect, for example Personal Letters. |
