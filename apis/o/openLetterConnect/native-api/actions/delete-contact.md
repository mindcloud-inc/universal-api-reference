# Delete Contact with Open Letter Connect

Deletes a contact from Open Letter Connect.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [Delete Contact](https://api-docs.openletterconnect.com/contacts/delete-contact/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric contact ID from Open Letter Connect. |
