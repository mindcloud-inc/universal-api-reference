# Get Template with Open Letter Connect

Retrieves a template from Open Letter Connect.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:id`
- **Base URL:** `https://api.openletterconnect.com/api/v1`
- **Official documentation:** [Get Template](https://api-docs.openletterconnect.com/_templates/get-one-template/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric template ID from Open Letter Connect. |
