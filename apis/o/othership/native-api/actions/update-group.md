# Update Group with Othership

Updates an existing group in Othership.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/Groups/:id`
- **Base URL:** `https://hwms-api.othership.com/api/v1/azure/scim`
- **Official documentation:** [Update Group](https://www.ietf.org/rfc/rfc7644)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The SCIM group identifier. |
