# Get Ordered Wow with Owen Wilson Wow API

## Endpoint

- **Method:** `GET`
- **Path:** `/wows/ordered/:index`
- **Base URL:** `https://owen-wilson-wow-api.onrender.com`
- **Official documentation:** [Get Ordered Wow](https://github.com/amamenko/owen-wilson-wow-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `index` | path | `number` | yes | Chronological wow index. |
