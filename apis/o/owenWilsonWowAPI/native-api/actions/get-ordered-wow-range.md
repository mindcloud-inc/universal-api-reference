# Get Ordered Wow Range with Owen Wilson Wow API

## Endpoint

- **Method:** `GET`
- **Path:** `/wows/ordered/:range`
- **Base URL:** `https://owen-wilson-wow-api.onrender.com`
- **Official documentation:** [Get Ordered Wow Range](https://github.com/amamenko/owen-wilson-wow-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `range` | path | `string` | yes | Inclusive chronological wow index range, for example 3-7. |
