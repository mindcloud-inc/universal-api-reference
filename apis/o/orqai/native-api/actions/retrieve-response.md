# Retrieve Response with Orq.ai

Retrieves a response from Orq.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/router/responses/[:response_id]`
- **Base URL:** `https://api.orq.ai`
- **Official documentation:** [Retrieve Response](https://docs.orq.ai/reference/responses/v3-retrieve-response)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `response_id` | path | `string` | yes | Response ID from the Orq.ai path parameter. |
