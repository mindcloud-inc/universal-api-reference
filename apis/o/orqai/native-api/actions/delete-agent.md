# Delete Agent with Orq.ai

Deletes an existing agent from Orq.ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/agents/[:agent_key]`
- **Base URL:** `https://api.orq.ai`
- **Official documentation:** [Delete Agent](https://docs.orq.ai/reference/agents/delete-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_key` | path | `string` | yes | Agent Key from the Orq.ai path parameter. |
