# Update Agent with Orq.ai

Updates an existing agent in Orq.ai.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v2/agents/[:agent_key]`
- **Base URL:** `https://api.orq.ai`
- **Official documentation:** [Update Agent](https://docs.orq.ai/reference/agents/update-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_key` | path | `string` | yes | Agent Key from the Orq.ai path parameter. |
