# Delete File with Orq.ai

Deletes an existing file from Orq.ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/files/[:file_id]`
- **Base URL:** `https://api.orq.ai`
- **Official documentation:** [Delete File](https://docs.orq.ai/reference/files/delete-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | File ID from the Orq.ai path parameter. |
