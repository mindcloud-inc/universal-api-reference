# Create Chat Completion with Orq.ai

Creates a chat completion in Orq.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/router/chat/completions`
- **Base URL:** `https://api.orq.ai`
- **Official documentation:** [Create Chat Completion](https://docs.orq.ai/reference/chat/create-chat-completion)
