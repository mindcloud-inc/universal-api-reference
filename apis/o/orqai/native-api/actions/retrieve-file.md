# Retrieve File with Orq.ai

Retrieves a file from Orq.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/files/[:file_id]`
- **Base URL:** `https://api.orq.ai`
- **Official documentation:** [Retrieve File](https://docs.orq.ai/reference/files/retrieve-a-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | File ID from the Orq.ai path parameter. |
