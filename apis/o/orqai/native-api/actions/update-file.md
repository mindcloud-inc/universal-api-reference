# Update File with Orq.ai

Updates an existing file in Orq.ai.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v2/files/[:file_id]`
- **Base URL:** `https://api.orq.ai`
- **Official documentation:** [Update File](https://docs.orq.ai/reference/files/update-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | File ID from the Orq.ai path parameter. |
