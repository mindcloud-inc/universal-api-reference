# Create Agent Response with Orq.ai

Creates an agent response in Orq.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/agents/[:agent_key]/responses`
- **Base URL:** `https://api.orq.ai`
- **Official documentation:** [Create Agent Response](https://docs.orq.ai/reference/agents/create-response)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_key` | path | `string` | yes | Agent Key from the Orq.ai path parameter. |
