# Retrieve Agent with Orq.ai

Retrieves an agent from Orq.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/agents/[:agent_key]`
- **Base URL:** `https://api.orq.ai`
- **Official documentation:** [Retrieve Agent](https://docs.orq.ai/reference/agents/retrieve-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_key` | path | `string` | yes | Agent Key from the Orq.ai path parameter. |
