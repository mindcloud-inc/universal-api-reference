# Get Transaction with 1Shot

Retrieves transaction details from 1Shot API.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions/:transactionId`
- **Base URL:** `https://api.1shotapi.com/v0`
- **Official documentation:** [Get Transaction](https://docs.1shotapi.com/api/openapi.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transactionId` | path | `string` | yes | The internal UUID of the transaction. |
