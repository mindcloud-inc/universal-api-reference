# List Webhook Triggers with 1Shot

Retrieves webhook trigger types from 1Shot API.

## Endpoint

- **Method:** `GET`
- **Path:** `/business/:businessId/webhooks/triggers`
- **Base URL:** `https://api.1shotapi.com/v0`
- **Official documentation:** [List Webhook Triggers](https://docs.1shotapi.com/api/openapi.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `businessId` | path | `string` | yes |
