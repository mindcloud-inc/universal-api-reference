# List Delegations with 1Shot

Retrieves delegations for a wallet in 1Shot API.

## Endpoint

- **Method:** `GET`
- **Path:** `/wallets/:walletId/delegations`
- **Base URL:** `https://api.1shotapi.com/v0`
- **Official documentation:** [List Delegations](https://docs.1shotapi.com/api/openapi.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `walletId` | path | `string` | yes |
