# Estimate Contract Method with 1Shot

Estimates a contract method transaction in 1Shot API.

## Endpoint

- **Method:** `POST`
- **Path:** `/methods/:contractMethodId/estimate`
- **Base URL:** `https://api.1shotapi.com/v0`
- **Official documentation:** [Estimate Contract Method](https://docs.1shotapi.com/api/openapi.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contractMethodId` | path | `string` | yes |
| `params` | body | `object` | no |
