# Get Chain Fees with 1Shot

Retrieves chain fee details from 1Shot API.

## Endpoint

- **Method:** `GET`
- **Path:** `/chains/:chainId/fees`
- **Base URL:** `https://api.1shotapi.com/v0`
- **Official documentation:** [Get Chain Fees](https://docs.1shotapi.com/api/openapi.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chainId` | path | `string` | yes | The chain identifier. |
