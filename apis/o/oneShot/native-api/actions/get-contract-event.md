# Get Contract Event with 1Shot

Retrieves contract event details from 1Shot API.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:contractEventId`
- **Base URL:** `https://api.1shotapi.com/v0`
- **Official documentation:** [Get Contract Event](https://docs.1shotapi.com/api/openapi.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contractEventId` | path | `string` | yes | The internal UUID of the contract event. |
