# Get Contract Method with 1Shot

Retrieves contract method endpoint details from 1Shot API.

## Endpoint

- **Method:** `GET`
- **Path:** `/methods/:contractMethodId`
- **Base URL:** `https://api.1shotapi.com/v0`
- **Official documentation:** [Get Contract Method](https://docs.1shotapi.com/api/openapi.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contractMethodId` | path | `string` | yes | The internal UUID of the contract method. |
