# List Webhook Endpoints with 1Shot

Retrieves webhook endpoint configurations from 1Shot API.

## Endpoint

- **Method:** `GET`
- **Path:** `/business/:businessId/webhooks/endpoints`
- **Base URL:** `https://api.1shotapi.com/v0`
- **Official documentation:** [List Webhook Endpoints](https://docs.1shotapi.com/api/openapi.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `businessId` | path | `string` | yes |
