# List Supported Networks with OxaPay Crypto Payment Gateway

Retrieves supported networks from OxaPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/common/networks`
- **Base URL:** `https://api.oxapay.com/v1`
- **Official documentation:** [List Supported Networks](https://docs.oxapay.com/api-reference/common/supported-networks)
