# List Supported Fiat Currencies with OxaPay Crypto Payment Gateway

Retrieves supported fiat currencies from OxaPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/common/fiats`
- **Base URL:** `https://api.oxapay.com/v1`
- **Official documentation:** [List Supported Fiat Currencies](https://docs.oxapay.com/api-reference/common/supported-fiat-currencies2)
