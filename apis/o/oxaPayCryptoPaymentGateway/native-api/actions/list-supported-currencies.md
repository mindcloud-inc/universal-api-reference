# List Supported Currencies with OxaPay Crypto Payment Gateway

Retrieves supported currencies from OxaPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/common/currencies`
- **Base URL:** `https://api.oxapay.com/v1`
- **Official documentation:** [List Supported Currencies](https://docs.oxapay.com/api-reference/common/supported-currencies2)
