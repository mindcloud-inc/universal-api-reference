# Get System Status with OxaPay Crypto Payment Gateway

Retrieves system status from OxaPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/common/monitor`
- **Base URL:** `https://api.oxapay.com/v1`
- **Official documentation:** [Get System Status](https://docs.oxapay.com/api-reference/common/system-status)
