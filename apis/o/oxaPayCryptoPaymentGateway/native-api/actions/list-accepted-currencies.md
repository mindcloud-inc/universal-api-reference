# List Accepted Currencies with OxaPay Crypto Payment Gateway

Retrieves accepted currencies from OxaPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment/accepted-currencies`
- **Base URL:** `https://api.oxapay.com/v1`
- **Official documentation:** [List Accepted Currencies](https://docs.oxapay.com/api-reference/payment/accepted-currencies)
