# Retrieve Form Descriptor with OKSign

Retrieves a form descriptor from OKSign.

## Endpoint

- **Method:** `GET`
- **Path:** `/formdesc/retrieve`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Retrieve Form Descriptor](https://www.oksign.be/public/api/#formdesc_retrieve)
