# Create Sign Express with OKSign

Creates a new Sign Express request in OKSign.

## Endpoint

- **Method:** `POST`
- **Path:** `/signexpress/create`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Create Sign Express](https://www.oksign.be/public/api/#signexpress_create)
