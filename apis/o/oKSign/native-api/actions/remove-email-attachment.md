# Remove Email Attachment with OKSign

Deletes an email attachment from OKSign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/emailattachment/remove`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Remove Email Attachment](https://www.oksign.be/public/api/#emailattachment_remove)
