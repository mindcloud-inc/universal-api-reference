# Retrieve Linked List with OKSign

Retrieves linked document identifiers from OKSign.

## Endpoint

- **Method:** `GET`
- **Path:** `/linkedlist/retrieve`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Retrieve Linked List](https://www.oksign.be/public/api/#linkedlist_retrieve)
