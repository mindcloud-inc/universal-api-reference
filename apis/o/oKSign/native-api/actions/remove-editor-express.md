# Remove Editor Express with OKSign

Deletes an Editor Express session from OKSign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/editorexpress/remove`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Remove Editor Express](https://www.oksign.be/public/api/#editorexpress_remove)
