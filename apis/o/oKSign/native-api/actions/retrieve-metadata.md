# Retrieve Metadata with OKSign

Retrieves document metadata from OKSign.

## Endpoint

- **Method:** `GET`
- **Path:** `/metadata/retrieve/v2`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Retrieve Metadata](https://www.oksign.be/public/api/#metadata_retrieve_v2)
