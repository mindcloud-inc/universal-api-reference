# Retrieve Sign Express with OKSign

Retrieves a Sign Express request from OKSign.

## Endpoint

- **Method:** `GET`
- **Path:** `/signexpress/retrieve`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Retrieve Sign Express](https://www.oksign.be/public/api/#signexpress_retrieve)
