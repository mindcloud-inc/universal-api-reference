# Create Editor Express with OKSign

Creates a new Editor Express session in OKSign.

## Endpoint

- **Method:** `POST`
- **Path:** `/editorexpress/create`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Create Editor Express](https://www.oksign.be/public/api/#editorexpress_create)
