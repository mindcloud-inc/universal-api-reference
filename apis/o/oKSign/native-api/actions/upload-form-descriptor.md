# Upload Form Descriptor with OKSign

Creates a new form descriptor in OKSign.

## Endpoint

- **Method:** `POST`
- **Path:** `/formdesc/upload`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Upload Form Descriptor](https://www.oksign.be/public/api/#formdesc_upload)
