# Remove Sign Express with OKSign

Deletes a Sign Express request from OKSign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/signexpress/remove`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Remove Sign Express](https://www.oksign.be/public/api/#signexpress_remove)
