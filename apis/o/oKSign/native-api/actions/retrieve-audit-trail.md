# Retrieve Audit Trail with OKSign

Retrieves an audit trail report from OKSign.

## Endpoint

- **Method:** `GET`
- **Path:** `/audittrail/retrieve`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Retrieve Audit Trail](https://www.oksign.be/public/api/#audittrail_retrieve)
