# Update Organization Token Info with OKSign

Updates organization token info in OKSign.

## Endpoint

- **Method:** `POST`
- **Path:** `/orgtokeninfo/update`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Update Organization Token Info](https://www.oksign.be/public/api/#orgtokeninfo_update)
