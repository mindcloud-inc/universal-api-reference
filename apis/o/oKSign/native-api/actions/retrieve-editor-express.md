# Retrieve Editor Express with OKSign

Retrieves an Editor Express session from OKSign.

## Endpoint

- **Method:** `GET`
- **Path:** `/editorexpress/retrieve`
- **Base URL:** `https://www.oksign.be/services/rest/v1`
- **Official documentation:** [Retrieve Editor Express](https://www.oksign.be/public/api/#editorexpress_retrieve)
