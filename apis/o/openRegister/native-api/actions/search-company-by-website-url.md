# Search Company By Website URL with OpenRegister

Finds a company in OpenRegister by website URL.

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/search/lookup`
- **Base URL:** `https://api.openregister.de`
- **Official documentation:** [Search Company By Website URL](https://docs.openregister.de/endpoint/search-lookup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Website URL to search for. |
