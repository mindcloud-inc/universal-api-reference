# Get Stored Document with OpenRegister

Retrieves a stored document from OpenRegister by document ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/document/:document_id`
- **Base URL:** `https://api.openregister.de`
- **Official documentation:** [Get Stored Document](https://docs.openregister.de/endpoint/document-stored)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | Stored document ID to retrieve. |
