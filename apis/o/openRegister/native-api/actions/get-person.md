# Get Person with OpenRegister

Retrieves person information from OpenRegister by person ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/person/:person_id`
- **Base URL:** `https://api.openregister.de`
- **Official documentation:** [Get Person](https://docs.openregister.de/endpoint/person)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `person_id` | path | `string` | yes | Unique person identifier. |
