# List Customers with OneHash ERP

Retrieves a list of customers from OneHash ERP.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/resource/Customer`
- **Base URL:** `https://{siteName}.onehash.ai`
- **Official documentation:** [List Customers](https://docs.frappe.io/framework/user/en/api/rest)

## Capabilities

This operation supports [pagination](../README.md#pagination).
