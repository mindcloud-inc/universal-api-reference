# Get Patient with Otiom

Retrieves a patient from Otiom.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/patients/:id/`
- **Base URL:** `https://api.otiom.com`
- **Official documentation:** [Get Patient](https://api.otiom.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | A unique integer value identifying this patient. |
