# Get Geofence with Otiom

Retrieves a geofence from Otiom.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/geofences/:id/`
- **Base URL:** `https://api.otiom.com`
- **Official documentation:** [Get Geofence](https://api.otiom.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | A unique integer value identifying this geo fence. |
