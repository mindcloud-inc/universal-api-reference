# List Items with Opinion Stage

Retrieves a list of items from Opinion Stage.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/items`
- **Base URL:** `https://api.opinionstage.com`
- **Official documentation:** [List Items](https://api.opinionstage.com/api-docs/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
