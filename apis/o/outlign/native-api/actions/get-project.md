# Get Project with Outlign

Retrieves a specific project from Outlign.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://go.outlign.co/api/v1`
- **Official documentation:** [Get Project](https://go.outlign.co/api/docs/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the project to retrieve |
