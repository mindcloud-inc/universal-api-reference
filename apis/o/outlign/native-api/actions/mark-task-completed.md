# Mark Task Completed with Outlign

Updates an existing task to completed in Outlign.

## Endpoint

- **Method:** `PUT`
- **Path:** `/steps/:id`
- **Base URL:** `https://go.outlign.co/api/v1`
- **Official documentation:** [Mark Task Completed](https://go.outlign.co/api/docs/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Task ID |
