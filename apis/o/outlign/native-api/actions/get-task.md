# Get Task with Outlign

Retrieves a specific task from Outlign.

## Endpoint

- **Method:** `GET`
- **Path:** `/steps/:id`
- **Base URL:** `https://go.outlign.co/api/v1`
- **Official documentation:** [Get Task](https://go.outlign.co/api/docs/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Task ID |
