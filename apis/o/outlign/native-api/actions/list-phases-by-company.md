# List Phases By Company with Outlign

Retrieves project phase records from Outlign by company.

## Endpoint

- **Method:** `GET`
- **Path:** `/phases`
- **Base URL:** `https://go.outlign.co/api/v1`
- **Official documentation:** [List Phases By Company](https://go.outlign.co/api/docs/phases)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | query | `number` | yes | Filter phases by company ID. |
