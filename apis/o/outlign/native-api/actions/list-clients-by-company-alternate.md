# List Clients by Company (Alternate) with Outlign

Retrieves accessible client records from Outlign.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients`
- **Base URL:** `https://go.outlign.co/api/v1`
- **Official documentation:** [List Clients by Company (Alternate)](https://go.outlign.co/api/docs/clients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | query | `number` | no | Filter clients by company ID. |
