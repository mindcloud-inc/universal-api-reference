# List Completed Tasks with Outlign

Retrieves completed task records from Outlign.

## Endpoint

- **Method:** `GET`
- **Path:** `/steps`
- **Base URL:** `https://go.outlign.co/api/v1`
- **Official documentation:** [List Completed Tasks](https://go.outlign.co/api/docs/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | query | `number` | no | Company to filter tasks by |
