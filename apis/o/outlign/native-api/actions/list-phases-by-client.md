# List Phases By Client with Outlign

Retrieves project phase records from Outlign by client.

## Endpoint

- **Method:** `GET`
- **Path:** `/phases`
- **Base URL:** `https://go.outlign.co/api/v1`
- **Official documentation:** [List Phases By Client](https://go.outlign.co/api/docs/phases)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | query | `number` | yes | Filter phases by client ID. |
