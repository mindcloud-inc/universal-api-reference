# Get Phase with Outlign

Retrieves a specific phase from Outlign.

## Endpoint

- **Method:** `GET`
- **Path:** `/phases/:id`
- **Base URL:** `https://go.outlign.co/api/v1`
- **Official documentation:** [Get Phase](https://go.outlign.co/api/docs/phases)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The phase ID. |
