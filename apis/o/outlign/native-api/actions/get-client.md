# Get Client with Outlign

Retrieves a specific client from Outlign.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:id`
- **Base URL:** `https://go.outlign.co/api/v1`
- **Official documentation:** [Get Client](https://go.outlign.co/api/docs/clients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the client to retrieve |
