# Get Website Growth with Omniconvert Explore

Retrieves website growth metrics from Omniconvert Explore.

## Endpoint

- **Method:** `GET`
- **Path:** `/websites/:id/growth`
- **Base URL:** `https://api.omniconvert.com/v1`
- **Official documentation:** [Get Website Growth](https://api.omniconvert.com/docs#get--v1-websites-{id}-growth)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Website identifier used in the endpoint path. |
