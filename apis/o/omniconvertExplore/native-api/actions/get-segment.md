# Get Segment with Omniconvert Explore

Retrieves a segment from Omniconvert Explore.

## Endpoint

- **Method:** `GET`
- **Path:** `/segments/:id`
- **Base URL:** `https://api.omniconvert.com/v1`
- **Official documentation:** [Get Segment](https://api.omniconvert.com/docs#get--v1-segments-{id})

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Segment identifier. |
