# Validate Account with Omniconvert Explore

Retrieves account validation details from Omniconvert Explore.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.omniconvert.com/zapier/validate-account`
- **Base URL:** `https://api.omniconvert.com/v1`
- **Official documentation:** [Validate Account](https://api.omniconvert.com/docs#get--zapier-validate-account)
