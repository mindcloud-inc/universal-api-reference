# Delete Segment with Omniconvert Explore

Deletes an existing segment from Omniconvert Explore.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/segments/:id`
- **Base URL:** `https://api.omniconvert.com/v1`
- **Official documentation:** [Delete Segment](https://api.omniconvert.com/docs#delete--v1-segments-{id})

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Segment identifier. |
