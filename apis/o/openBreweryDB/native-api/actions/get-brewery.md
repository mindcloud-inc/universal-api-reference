# Get Brewery with Open Brewery DB

Retrieves a brewery from Open Brewery DB.

## Endpoint

- **Method:** `GET`
- **Path:** `/breweries/:id`
- **Base URL:** `https://api.openbrewerydb.org/v1`
- **Official documentation:** [Get Brewery](https://www.openbrewerydb.org/documentation#single-brewery)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique Open Brewery DB brewery identifier. |
