# List Estimates with Orderry

Retrieves a list of estimates from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `estimates`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Estimates](https://orderry.readme.io/reference/get-estimates)

## Capabilities

This operation supports [pagination](../README.md#pagination).
