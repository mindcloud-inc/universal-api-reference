# List Locations with Orderry

Retrieves a list of company locations from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `branches/`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Locations](https://orderry.readme.io/reference/get-locations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
