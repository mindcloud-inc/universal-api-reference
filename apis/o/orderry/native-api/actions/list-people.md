# List People with Orderry

Retrieves a list of people from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `contacts/people`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List People](https://orderry.readme.io/reference/get-people)

## Capabilities

This operation supports [pagination](../README.md#pagination).
