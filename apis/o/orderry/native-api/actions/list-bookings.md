# List Bookings with Orderry

Retrieves a list of bookings from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `bookings`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Bookings](https://orderry.readme.io/reference/get-bookings)

## Capabilities

This operation supports [pagination](../README.md#pagination).
