# List Invoices with Orderry

Retrieves a list of invoices from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `invoice/`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Invoices](https://orderry.readme.io/reference/get-invoices)

## Capabilities

This operation supports [pagination](../README.md#pagination).
