# List Cashbox Transactions with Orderry

## Endpoint

- **Method:** `GET`
- **Path:** `cashbox/report/:cashboxId`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Cashbox Transactions](https://orderry.readme.io/reference/get-cashbox-transactions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cashboxId` | path | `string` | no | The cashbox ID to list transactions for. |
