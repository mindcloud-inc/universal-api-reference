# Get Organization by ID with Orderry

Retrieves an organization by ID from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `contacts/organizations/:organizationId`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [Get Organization by ID](https://orderry.readme.io/reference/get-organization-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | no | The organization ID to fetch. |
