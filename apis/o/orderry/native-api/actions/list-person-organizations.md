# List Person Organizations with Orderry

Retrieves a person's organization from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `contacts/people/:personId/organizations`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Person Organizations](https://orderry.readme.io/reference/get-person-organization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `string` | no | The person ID to list organizations for. |
