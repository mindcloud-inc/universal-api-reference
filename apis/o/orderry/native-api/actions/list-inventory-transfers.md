# List Inventory Transfers with Orderry

## Endpoint

- **Method:** `GET`
- **Path:** `warehouse/moves/`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Inventory Transfers](https://orderry.readme.io/reference/get-inventory-transfers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `branch_id` | query | `string` | no | The branch ID to filter inventory transfers for. |
