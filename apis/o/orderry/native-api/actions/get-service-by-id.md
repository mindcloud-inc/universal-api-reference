# Get Service by ID with Orderry

Retrieves a service by ID from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `services/:serviceId`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [Get Service by ID](https://orderry.readme.io/reference/get-service-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serviceId` | path | `string` | no | The service ID to fetch. |
