# List Stock with Orderry

## Endpoint

- **Method:** `GET`
- **Path:** `warehouse/goods/:warehouseId`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Stock](https://orderry.readme.io/reference/get-stock)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `warehouseId` | path | `string` | no | The warehouse ID to list stock for. |
