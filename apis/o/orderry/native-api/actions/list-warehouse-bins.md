# List Warehouse Bins with Orderry

## Endpoint

- **Method:** `GET`
- **Path:** `warehouse/:warehouseId/cells`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Warehouse Bins](https://orderry.readme.io/reference/get-warehouse-bins)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `warehouseId` | path | `string` | no | The warehouse ID to list bins for. |
