# List Inventory Write-Offs with Orderry

## Endpoint

- **Method:** `GET`
- **Path:** `warehouse/outcome-transactions/`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Inventory Write-Offs](https://orderry.readme.io/reference/get-inventory-writeoffs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `branch_id` | query | `string` | no | The branch ID to filter write-offs for. |
