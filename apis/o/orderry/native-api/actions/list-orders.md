# List Orders with Orderry

Retrieves a list of orders from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `orders`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Orders](https://orderry.readme.io/reference/get-orders)

## Capabilities

This operation supports [pagination](../README.md#pagination).
