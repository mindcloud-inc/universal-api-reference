# Get Product by ID with Orderry

Retrieves a product by ID from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `products/:productId`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [Get Product by ID](https://orderry.readme.io/reference/get-product-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | no | The product ID to fetch. |
