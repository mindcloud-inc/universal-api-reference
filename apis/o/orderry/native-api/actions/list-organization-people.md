# List Organization People with Orderry

Retrieves people for an organization from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `contacts/organizations/:organizationId/people`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Organization People](https://orderry.readme.io/reference/get-organization-people)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | no | The organization ID to list people for. |
