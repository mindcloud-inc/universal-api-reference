# List Location Resources with Orderry

Retrieves a list of location resources from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `branches/resources/`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Location Resources](https://orderry.readme.io/reference/get-location-resources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `branch_id` | query | `string` | no | The Orderry branch ID to list resources for. |
