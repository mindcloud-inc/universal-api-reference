# Get Person by ID with Orderry

Retrieves a person by ID from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `contacts/people/:personId`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [Get Person by ID](https://orderry.readme.io/reference/get-person-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `string` | no | The person ID to fetch. |
