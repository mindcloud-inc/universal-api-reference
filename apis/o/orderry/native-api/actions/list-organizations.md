# List Organizations with Orderry

Retrieves a list of organizations from Orderry.

## Endpoint

- **Method:** `GET`
- **Path:** `contacts/organizations`
- **Base URL:** `https://api.orderry.com`
- **Official documentation:** [List Organizations](https://orderry.readme.io/reference/get-organizations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
