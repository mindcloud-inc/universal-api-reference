# Get Reconciliation Manifest with OpenSanctions

## Endpoint

- **Method:** `GET`
- **Path:** `/reconcile/:dataset`
- **Base URL:** `https://api.opensanctions.org`
- **Official documentation:** [Get Reconciliation Manifest](https://api.opensanctions.org/docs#/Reconciliation/reconcile_reconcile__dataset__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataset` | path | `string` | yes | Data source or collection name to scope the reconciliation manifest to. |
