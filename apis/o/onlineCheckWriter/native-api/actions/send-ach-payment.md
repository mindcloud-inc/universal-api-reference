# Send ACH Payment with OnlineCheckWriter

Initiates an ACH payment from a wallet or bank account.

## Endpoint

- **Method:** `POST`
- **Path:** `/send-payment/ach`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Send ACH Payment](https://apiv3.onlinecheckwriter.com)
