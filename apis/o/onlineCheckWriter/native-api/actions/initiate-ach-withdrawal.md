# Initiate ACH Withdrawal with OnlineCheckWriter

Initiates an ACH withdrawal from a wallet.

## Endpoint

- **Method:** `POST`
- **Path:** `/wallet/withdraw/ach/initiate`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Initiate ACH Withdrawal](https://apiv3.onlinecheckwriter.com)
