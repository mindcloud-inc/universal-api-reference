# List Mail Check Mailing Options with OnlineCheckWriter

Lists available mailing, paper, and insert options for mail checks.

## Endpoint

- **Method:** `GET`
- **Path:** `/mailchecks/mailingOptions`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [List Mail Check Mailing Options](https://apiv3.onlinecheckwriter.com)
