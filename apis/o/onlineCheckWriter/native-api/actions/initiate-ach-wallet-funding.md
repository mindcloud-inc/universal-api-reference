# Initiate ACH Wallet Funding with OnlineCheckWriter

Initiates ACH funding for a wallet.

## Endpoint

- **Method:** `POST`
- **Path:** `/wallet/fund/ach/initiate`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Initiate ACH Wallet Funding](https://apiv3.onlinecheckwriter.com)
