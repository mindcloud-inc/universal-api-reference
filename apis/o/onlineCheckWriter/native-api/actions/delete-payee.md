# Delete Payee with OnlineCheckWriter

Deletes an existing payee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/payees/:payeeId`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Delete Payee](https://apiv3.onlinecheckwriter.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payeeId` | path | `string` | yes | The payee identifier. |
