# Get Bank Account with OnlineCheckWriter

Retrieves details for a specific bank account.

## Endpoint

- **Method:** `GET`
- **Path:** `/bankAccounts/:bankAccountId`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Get Bank Account](https://apiv3.onlinecheckwriter.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bankAccountId` | path | `string` | yes | The bank account identifier. |
