# Send Check Mail Payment with OnlineCheckWriter

Initiates a check mail payment from a wallet.

## Endpoint

- **Method:** `POST`
- **Path:** `/send-payment/checkMail`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Send Check Mail Payment](https://apiv3.onlinecheckwriter.com)
