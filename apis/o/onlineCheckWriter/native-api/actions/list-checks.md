# List Checks with OnlineCheckWriter

Lists checks in the connected OnlineCheckWriter account.

## Endpoint

- **Method:** `GET`
- **Path:** `/checks`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [List Checks](https://apiv3.onlinecheckwriter.com)

## Capabilities

This operation supports [pagination](../README.md#pagination).
