# Get Payee with OnlineCheckWriter

Retrieves details for a specific payee.

## Endpoint

- **Method:** `GET`
- **Path:** `/payees/:payeeId`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Get Payee](https://apiv3.onlinecheckwriter.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payeeId` | path | `string` | yes | The payee identifier. |
