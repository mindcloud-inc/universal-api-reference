# Calculate Mail Check Fee with OnlineCheckWriter

Calculates fees for a mail check request.

## Endpoint

- **Method:** `POST`
- **Path:** `/mailchecks/calculateFee`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Calculate Mail Check Fee](https://apiv3.onlinecheckwriter.com)
