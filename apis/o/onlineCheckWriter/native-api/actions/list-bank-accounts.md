# List Bank Accounts with OnlineCheckWriter

Lists bank accounts in the connected OnlineCheckWriter account.

## Endpoint

- **Method:** `GET`
- **Path:** `/bankAccounts`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [List Bank Accounts](https://apiv3.onlinecheckwriter.com)

## Capabilities

This operation supports [pagination](../README.md#pagination).
