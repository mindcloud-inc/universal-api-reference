# Void Check with OnlineCheckWriter

Voids a specific check.

## Endpoint

- **Method:** `POST`
- **Path:** `/checks/:checkId/void`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Void Check](https://apiv3.onlinecheckwriter.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `checkId` | path | `string` | yes | The check identifier. |
