# Update Payee with OnlineCheckWriter

Updates an existing payee.

## Endpoint

- **Method:** `PUT`
- **Path:** `/payees/:payeeId`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Update Payee](https://apiv3.onlinecheckwriter.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payeeId` | path | `string` | yes | The payee identifier. |
