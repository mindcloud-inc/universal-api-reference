# Get Check with OnlineCheckWriter

Retrieves details for a specific check.

## Endpoint

- **Method:** `GET`
- **Path:** `/checks/:checkId`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Get Check](https://apiv3.onlinecheckwriter.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `checkId` | path | `string` | yes | The check identifier. |
