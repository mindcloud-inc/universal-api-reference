# Delete Check with OnlineCheckWriter

Deletes an existing check.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/checks/:checkId`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Delete Check](https://apiv3.onlinecheckwriter.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `checkId` | path | `string` | yes | The check identifier. |
