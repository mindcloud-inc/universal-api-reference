# Get Wallet with OnlineCheckWriter

Retrieves details for a specific wallet.

## Endpoint

- **Method:** `GET`
- **Path:** `/wallet/:walletId`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [Get Wallet](https://apiv3.onlinecheckwriter.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `walletId` | path | `string` | yes | The wallet identifier. |
