# List Payees with OnlineCheckWriter

Lists payees in the connected OnlineCheckWriter account.

## Endpoint

- **Method:** `GET`
- **Path:** `/payees`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [List Payees](https://apiv3.onlinecheckwriter.com)

## Capabilities

This operation supports [pagination](../README.md#pagination).
