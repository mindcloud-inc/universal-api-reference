# List Wallet Transactions with OnlineCheckWriter

Lists transactions for a specific wallet.

## Endpoint

- **Method:** `GET`
- **Path:** `/wallet/:walletId/transactions`
- **Base URL:** `https://test.onlinecheckwriter.com/api/v3`
- **Official documentation:** [List Wallet Transactions](https://apiv3.onlinecheckwriter.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `walletId` | path | `string` | yes | The wallet identifier. |
