# Get Link with Once.to

Retrieves a short link from Once.to.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/:id`
- **Base URL:** `https://once.to/api/public/v1`
- **Official documentation:** [Get Link](https://docs.once.to/en/api/v1/endpoints/links-get-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the short link to fetch. |
