# Get Domain with Once.to

Retrieves a domain from Once.to.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:id`
- **Base URL:** `https://once.to/api/public/v1`
- **Official documentation:** [Get Domain](https://docs.once.to/en/api/v1/endpoints/domains-get-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the domain to fetch. |
