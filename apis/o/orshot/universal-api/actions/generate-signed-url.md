# Orshot: Generate Signed URL



```
POST https://connect.mindcloud.co/v1/universal/orshot/latest/actions/generate-signed-url
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Orshot `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X POST "https://connect.mindcloud.co/v1/universal/orshot/latest/actions/generate-signed-url" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "connectionId": "$CONNECTION_ID",
  "templateId": "string",
  "renderType": "string"
}'
```

```js
const response = await fetch('https://connect.mindcloud.co/v1/universal/orshot/latest/actions/generate-signed-url', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    connectionId,
    "templateId": "string",
    "renderType": "string"
  })
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as JSON body fields ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `modifications.delay` | number | no | Delay in milliseconds before capture. |
| `modifications.fullCapture` | boolean | no | Whether to capture the full page when using website screenshot utilities. |
| `modifications.height` | number | no | Output height for the signed-url render. |
| `modifications.websiteUrl` | string | no | Public website URL used by utility templates like website-screenshot. |
| `modifications.width` | number | no | Output width for the signed-url render. |
| `responseFormat` | string | no | Format for the signed URL render output. |
| `templateId` | string | yes | Template identifier for generating the signed URL. |
| `renderType` | string | yes | Render type supported by the template when generating the signed URL. |
| `expiresAt` | number | no | Optional UNIX timestamp in milliseconds for signed URL expiration. |

## Response

```json
{
  "success": true,
  "data": [
    {
      "data": {
        "url": "https://example.com"
      }
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `data.url` | string | Signed render URL generated by Orshot. |

## Native endpoint

Through the native Orshot API, this operation is `POST /signed-url/create` (base URL `https://api.orshot.com/v1`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/generate-signed-url.md) for the provider-specific parameters and requirements.
