# Delete Brand Asset Image with Orshot

## Endpoint

- **Method:** `DELETE`
- **Path:** `/brand-assets/images/delete/:id`
- **Base URL:** `https://api.orshot.com/v1`
- **Official documentation:** [Delete Brand Asset Image](https://orshot.com/docs/api-reference/brand-assets-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The brand asset image ID. |
