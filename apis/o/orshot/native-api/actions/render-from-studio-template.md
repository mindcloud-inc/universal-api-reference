# Render from Studio Template with Orshot

## Endpoint

- **Method:** `POST`
- **Path:** `/studio/render`
- **Base URL:** `https://api.orshot.com/v1`
- **Official documentation:** [Render from Studio Template](https://orshot.com/docs/api-reference/render-from-studio-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | body | `number` | yes | Studio template identifier to render. |
