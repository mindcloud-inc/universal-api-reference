# Delete Brand Color with Orshot

## Endpoint

- **Method:** `DELETE`
- **Path:** `/brand-assets/colors/delete/:id`
- **Base URL:** `https://api.orshot.com/v1`
- **Official documentation:** [Delete Brand Color](https://orshot.com/docs/api-reference/brand-colors-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The saved brand color ID. |
