# Get Brand Videos with Orshot

## Endpoint

- **Method:** `GET`
- **Path:** `/brand-assets/videos/get`
- **Base URL:** `https://api.orshot.com/v1`
- **Official documentation:** [Get Brand Videos](https://orshot.com/docs/api-reference/brand-videos-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | query | `string` | no | Filter videos by tag. |
