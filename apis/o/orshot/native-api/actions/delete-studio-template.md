# Delete Studio Template with Orshot

## Endpoint

- **Method:** `DELETE`
- **Path:** `/studio/templates/:templateId/delete`
- **Base URL:** `https://api.orshot.com/v1`
- **Official documentation:** [Delete Studio Template](https://orshot.com/docs/api-reference/studio-template-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `number` | yes | The unique identifier of the studio template to delete. |
