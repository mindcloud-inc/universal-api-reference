# Get Brand Colors with Orshot

## Endpoint

- **Method:** `GET`
- **Path:** `/brand-assets/colors/get`
- **Base URL:** `https://api.orshot.com/v1`
- **Official documentation:** [Get Brand Colors](https://orshot.com/docs/api-reference/brand-colors-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | query | `string` | no | Filter colors by tag. |
