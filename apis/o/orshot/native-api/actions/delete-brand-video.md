# Delete Brand Video with Orshot

## Endpoint

- **Method:** `DELETE`
- **Path:** `/brand-assets/videos/delete/:id`
- **Base URL:** `https://api.orshot.com/v1`
- **Official documentation:** [Delete Brand Video](https://orshot.com/docs/api-reference/brand-videos-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The brand video ID. |
