# Get Brand Fonts with Orshot

## Endpoint

- **Method:** `GET`
- **Path:** `/brand-assets/fonts/get`
- **Base URL:** `https://api.orshot.com/v1`
- **Official documentation:** [Get Brand Fonts](https://orshot.com/docs/api-reference/custom-fonts-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | query | `string` | no | Filter fonts by tag. |
