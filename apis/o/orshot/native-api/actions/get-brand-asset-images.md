# Get Brand Asset Images with Orshot

## Endpoint

- **Method:** `GET`
- **Path:** `/brand-assets/images/get`
- **Base URL:** `https://api.orshot.com/v1`
- **Official documentation:** [Get Brand Asset Images](https://orshot.com/docs/api-reference/brand-assets-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | query | `string` | no | Filter assets by tag. |
