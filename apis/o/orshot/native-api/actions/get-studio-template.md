# Get Studio Template with Orshot

## Endpoint

- **Method:** `GET`
- **Path:** `/studio/templates/:templateId`
- **Base URL:** `https://api.orshot.com/v1`
- **Official documentation:** [Get Studio Template](https://orshot.com/docs/api-reference/studio-template-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `number` | yes | The unique ID of the template to fetch. |
