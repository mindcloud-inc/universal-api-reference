# Get Model (OpenAI Compatible) with Ollama

Retrieves an OpenAI-compatible model from Ollama.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/models/:model`
- **Base URL:** `https://ollama.com`
- **Official documentation:** [Get Model (OpenAI Compatible)](https://docs.ollama.com/api/openai-compatibility)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `model` | path | `string` | yes |
