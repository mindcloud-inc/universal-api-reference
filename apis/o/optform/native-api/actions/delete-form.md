# Delete Form with Optform

Deletes an existing form from Optform.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/Form/:id`
- **Base URL:** `https://optform.azure-api.net`
- **Official documentation:** [Delete Form](https://optform.com/help/api/api)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
