# Delete Push Menu Webhook with OrderOut

Deletes a push menu webhook from OrderOut.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/webhooks/push_menu/:delivery_service_type`
- **Base URL:** `https://api.orderout.co`
- **Official documentation:** [Delete Push Menu Webhook](https://developers.orderout.co/reference/delete-push_menu-webhook-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `delivery_service_type` | path | `string` | yes | Delivery service type |
