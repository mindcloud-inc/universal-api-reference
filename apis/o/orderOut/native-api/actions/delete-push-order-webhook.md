# Delete Push Order Webhook with OrderOut

Deletes a push order webhook from OrderOut.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/webhooks/push_order/:push_order_webhook_id`
- **Base URL:** `https://api.orderout.co`
- **Official documentation:** [Delete Push Order Webhook](https://developers.orderout.co/reference/delete-push_order-webhook-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `push_order_webhook_id` | path | `string` | yes | Push order webhook identifier |
