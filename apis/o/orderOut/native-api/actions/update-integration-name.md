# Update Integration Name with OrderOut

Updates the integration name in OrderOut.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/integrator/update_name`
- **Base URL:** `https://api.orderout.co`
- **Official documentation:** [Update Integration Name](https://developers.orderout.co/reference/update-integration-name)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Integration name |
