# Get Event with Orufy Bookings

## Endpoint

- **Method:** `GET`
- **Path:** `/api/event/:eventId`
- **Base URL:** `https://bookings.orufy.com/api/v1/bookings`
- **Official documentation:** [Get Event](https://orufy.com/bookings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | The Orufy event ID. |
