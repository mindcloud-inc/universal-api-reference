# List Public Events with Orufy Bookings

## Endpoint

- **Method:** `GET`
- **Path:** `/website/events/:accessLink`
- **Base URL:** `https://bookings.orufy.com/api/v1/bookings`
- **Official documentation:** [List Public Events](https://orufy.com/support/bookings/firstsetup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accessLink` | path | `string` | yes | The Orufy access link, for example `mindcloud`. |
