# Add Contact Labels with OneHash

Updates a contact's labels in OneHash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/accounts/:accountId/contacts/:id/labels`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Add Contact Labels](https://developers.chatwoot.com/api-reference/contact-labels/add-labels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
