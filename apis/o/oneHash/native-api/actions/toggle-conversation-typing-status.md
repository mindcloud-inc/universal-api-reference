# Toggle Conversation Typing Status with OneHash

Updates conversation typing status in OneHash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/accounts/:accountId/conversations/:conversationId/toggle_typing_status`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Toggle Conversation Typing Status](https://developers.chatwoot.com/api-reference/conversations/toggle-typing-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
