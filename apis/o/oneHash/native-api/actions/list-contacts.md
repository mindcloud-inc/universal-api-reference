# List Contacts with OneHash

Retrieves contacts from OneHash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId/contacts`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [List Contacts](https://developers.chatwoot.com/api-reference/contacts/list-contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
