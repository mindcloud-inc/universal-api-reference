# Create Conversation with OneHash

Creates a new conversation in OneHash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/accounts/:accountId/conversations`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Create Conversation](https://developers.chatwoot.com/api-reference/conversations/create-new-conversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
