# Get Conversation Counts with OneHash

Retrieves conversation counts from OneHash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId/conversations/meta`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Get Conversation Counts](https://developers.chatwoot.com/api-reference/conversations/get-conversation-counts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
