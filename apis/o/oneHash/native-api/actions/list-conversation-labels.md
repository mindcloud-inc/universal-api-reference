# List Conversation Labels with OneHash

Retrieves a conversation's labels from OneHash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId/conversations/:conversationId/labels`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [List Conversation Labels](https://developers.chatwoot.com/api-reference/conversations/list-labels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
