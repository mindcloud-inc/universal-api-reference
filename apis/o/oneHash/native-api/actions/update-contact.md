# Update Contact with OneHash

Updates an existing contact in OneHash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/accounts/:accountId/contacts/:id`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Update Contact](https://developers.chatwoot.com/api-reference/contacts/update-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
