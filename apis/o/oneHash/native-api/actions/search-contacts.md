# Search Contacts with OneHash

Finds contacts in OneHash by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId/contacts/search`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Search Contacts](https://developers.chatwoot.com/api-reference/contacts/search-contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
