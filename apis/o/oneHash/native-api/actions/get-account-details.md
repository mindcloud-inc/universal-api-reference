# Get Account Details with OneHash

Retrieves account details from OneHash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Get Account Details](https://developers.chatwoot.com/api-reference/account/get-account-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
