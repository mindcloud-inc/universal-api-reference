# List Labels with OneHash

Retrieves account labels from OneHash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId/labels`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [List Labels](https://developers.chatwoot.com/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
