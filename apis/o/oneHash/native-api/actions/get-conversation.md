# Get Conversation with OneHash

Retrieves a conversation from OneHash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId/conversations/:conversationId`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Get Conversation](https://developers.chatwoot.com/api-reference/conversations/conversation-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
