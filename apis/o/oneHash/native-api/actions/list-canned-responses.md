# List Canned Responses with OneHash

Retrieves canned responses from OneHash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId/canned_responses`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [List Canned Responses](https://developers.chatwoot.com/api-reference/canned-responses/list-all-canned-responses-in-an-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
