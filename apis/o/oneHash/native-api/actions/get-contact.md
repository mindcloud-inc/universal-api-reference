# Get Contact with OneHash

Retrieves a contact from OneHash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId/contacts/:id`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Get Contact](https://developers.chatwoot.com/api-reference/contacts/show-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
