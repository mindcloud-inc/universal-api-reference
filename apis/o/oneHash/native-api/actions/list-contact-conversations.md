# List Contact Conversations with OneHash

Retrieves a contact's conversations from OneHash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId/contacts/:id/conversations`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [List Contact Conversations](https://developers.chatwoot.com/api-reference/contacts/contact-conversations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
