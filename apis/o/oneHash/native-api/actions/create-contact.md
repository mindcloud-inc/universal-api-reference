# Create Contact with OneHash

Creates a new contact in OneHash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/accounts/:accountId/contacts`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Create Contact](https://developers.chatwoot.com/api-reference/contacts/create-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
