# List Contact Labels with OneHash

Retrieves a contact's labels from OneHash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId/contacts/:id/labels`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [List Contact Labels](https://developers.chatwoot.com/api-reference/contact-labels/list-labels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
