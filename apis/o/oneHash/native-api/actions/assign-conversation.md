# Assign Conversation with OneHash

Updates a conversation assignment in OneHash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/accounts/:accountId/conversations/:conversationId/assignments`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Assign Conversation](https://developers.chatwoot.com/api-reference/conversation-assignments/assign-conversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
