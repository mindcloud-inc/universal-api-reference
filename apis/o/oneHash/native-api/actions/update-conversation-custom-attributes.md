# Update Conversation Custom Attributes with OneHash

Updates conversation custom attributes in OneHash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/accounts/:accountId/conversations/:conversationId/custom_attributes`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Update Conversation Custom Attributes](https://developers.chatwoot.com/api-reference/conversations/update-custom-attributes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
