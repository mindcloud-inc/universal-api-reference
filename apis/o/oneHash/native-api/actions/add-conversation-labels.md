# Add Conversation Labels with OneHash

Updates a conversation's labels in OneHash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/accounts/:accountId/conversations/:conversationId/labels`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Add Conversation Labels](https://developers.chatwoot.com/api-reference/conversations/add-labels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
