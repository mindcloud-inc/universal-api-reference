# Delete Canned Response with OneHash

Deletes an existing canned response from OneHash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/accounts/:accountId/canned_responses/:id`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Delete Canned Response](https://developers.chatwoot.com/api-reference/canned-responses/remove-a-canned-response-from-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
