# Create Canned Response with OneHash

Creates a new canned response in OneHash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/accounts/:accountId/canned_responses`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Create Canned Response](https://developers.chatwoot.com/api-reference/canned-responses/add-a-new-canned-response)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
