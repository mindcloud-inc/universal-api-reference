# Create Conversation Message with OneHash

Creates a new conversation message in OneHash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/accounts/:accountId/conversations/:conversationId/messages`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Create Conversation Message](https://developers.chatwoot.com/api-reference/messages/create-new-message)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
