# List Conversation Messages with OneHash

Retrieves conversation messages from OneHash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId/conversations/:conversationId/messages`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [List Conversation Messages](https://developers.chatwoot.com/api-reference/messages/get-messages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
