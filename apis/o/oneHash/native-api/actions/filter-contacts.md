# Filter Contacts with OneHash

Finds contacts in OneHash using filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/accounts/:accountId/contacts/filter`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Filter Contacts](https://developers.chatwoot.com/api-reference/contacts/contact-filter)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
