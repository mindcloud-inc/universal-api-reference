# Create Contact Inbox with OneHash

Creates a contact inbox in OneHash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/accounts/:accountId/contacts/:id/contact_inboxes`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Create Contact Inbox](https://developers.chatwoot.com/api-reference/contacts/create-contact-inbox)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
