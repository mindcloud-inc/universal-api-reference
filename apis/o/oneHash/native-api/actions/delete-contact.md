# Delete Contact with OneHash

Deletes an existing contact from OneHash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/accounts/:accountId/contacts/:id`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Delete Contact](https://developers.chatwoot.com/api-reference/contacts/delete-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
