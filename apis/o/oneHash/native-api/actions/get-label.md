# Get Label with OneHash

Retrieves a label from OneHash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/accounts/:accountId/labels/:id`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Get Label](https://developers.chatwoot.com/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
| `id` | path | `string` | no | Label id. |
