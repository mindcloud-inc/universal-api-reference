# Toggle Conversation Priority with OneHash

Updates conversation priority in OneHash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/accounts/:accountId/conversations/:conversationId/toggle_priority`
- **Base URL:** `https://chat.onehash.ai`
- **Official documentation:** [Toggle Conversation Priority](https://developers.chatwoot.com/api-reference/conversations/toggle-priority)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | no | OneHash Chat account id. |
