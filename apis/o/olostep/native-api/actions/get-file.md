# Get File with Olostep

Retrieves details for a file in Olostep.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/files/[:file_id]`
- **Base URL:** `https://api.olostep.com`
- **Official documentation:** [Get File](https://docs.olostep.com/api-reference/files/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | The ID of the file to retrieve. |
