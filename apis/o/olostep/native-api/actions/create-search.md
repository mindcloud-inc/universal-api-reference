# Create Search with Olostep

Creates a new search in Olostep.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/searches`
- **Base URL:** `https://api.olostep.com`
- **Official documentation:** [Create Search](https://docs.olostep.com/api-reference/searches/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | The search query to run. |
