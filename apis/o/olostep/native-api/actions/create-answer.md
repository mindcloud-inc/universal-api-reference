# Create Answer with Olostep

Creates a new answer in Olostep.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/answers`
- **Base URL:** `https://api.olostep.com`
- **Official documentation:** [Create Answer](https://docs.olostep.com/api-reference/answers/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task` | body | `string` | yes | The question or task Olostep should answer. |
