# Delete File with Olostep

Deletes an existing file from Olostep.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/files/[:file_id]`
- **Base URL:** `https://api.olostep.com`
- **Official documentation:** [Delete File](https://docs.olostep.com/api-reference/files/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | The ID of the file to delete. |
