# Get Answer with Olostep

Retrieves details for an answer in Olostep.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/answers/[:answer_id]`
- **Base URL:** `https://api.olostep.com`
- **Official documentation:** [Get Answer](https://docs.olostep.com/api-reference/answers/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `answer_id` | path | `string` | yes | The ID of the answer to retrieve. |
