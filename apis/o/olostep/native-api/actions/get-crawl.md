# Get Crawl with Olostep

Retrieves details for a crawl in Olostep.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/crawls/[:crawl_id]`
- **Base URL:** `https://api.olostep.com`
- **Official documentation:** [Get Crawl](https://docs.olostep.com/api-reference/crawls/info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `crawl_id` | path | `string` | yes | The ID of the crawl to retrieve. |
