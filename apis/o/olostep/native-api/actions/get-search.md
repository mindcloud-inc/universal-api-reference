# Get Search with Olostep

Retrieves details for a search in Olostep.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/searches/[:search_id]`
- **Base URL:** `https://api.olostep.com`
- **Official documentation:** [Get Search](https://docs.olostep.com/api-reference/searches/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search_id` | path | `string` | yes | The ID of the search to retrieve. |
