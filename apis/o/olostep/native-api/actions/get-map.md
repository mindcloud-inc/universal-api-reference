# Get Map with Olostep

Retrieves details for a map in Olostep.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/maps/[:map_id]`
- **Base URL:** `https://api.olostep.com`
- **Official documentation:** [Get Map](https://docs.olostep.com/api-reference/maps/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `map_id` | path | `string` | yes | The ID of the map to retrieve. |
