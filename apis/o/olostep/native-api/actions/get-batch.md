# Get Batch with Olostep

Retrieves details for a batch in Olostep.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/batches/[:batch_id]`
- **Base URL:** `https://api.olostep.com`
- **Official documentation:** [Get Batch](https://docs.olostep.com/api-reference/batches/info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batch_id` | path | `string` | yes | The ID of the batch to retrieve. |
