# Get Scrape with Olostep

Retrieves details for a scrape in Olostep.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/scrapes/[:scrape_id]`
- **Base URL:** `https://api.olostep.com`
- **Official documentation:** [Get Scrape](https://docs.olostep.com/api-reference/scrapes/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scrape_id` | path | `string` | yes | The ID of the scrape to retrieve. |
