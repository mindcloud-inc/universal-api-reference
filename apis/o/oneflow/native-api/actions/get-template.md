# Get Template with Oneflow

Retrieves template details from Oneflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:id`
- **Base URL:** `https://api.oneflow.com/v1`
- **Official documentation:** [Get Template](https://developer.oneflow.com/reference/get-a-template-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Oneflow template ID. |
