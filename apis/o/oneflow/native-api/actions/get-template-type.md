# Get Template Type with Oneflow

Retrieves template type details from Oneflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/template_types/:id`
- **Base URL:** `https://api.oneflow.com/v1`
- **Official documentation:** [Get Template Type](https://developer.oneflow.com/reference/get-template-type-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Oneflow template type ID. |
