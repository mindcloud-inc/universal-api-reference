# List Templates with Oneflow

Retrieves templates from Oneflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://api.oneflow.com/v1`
- **Official documentation:** [List Templates](https://developer.oneflow.com/reference/get-templates)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
