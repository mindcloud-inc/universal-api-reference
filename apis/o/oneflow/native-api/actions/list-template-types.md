# List Template Types with Oneflow

Retrieves template types from Oneflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/template_types`
- **Base URL:** `https://api.oneflow.com/v1`
- **Official documentation:** [List Template Types](https://developer.oneflow.com/reference/get-template-types)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
