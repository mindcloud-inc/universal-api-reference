# List Workspaces with Oneflow

Retrieves workspaces from Oneflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces`
- **Base URL:** `https://api.oneflow.com/v1`
- **Official documentation:** [List Workspaces](https://developer.oneflow.com/reference/get-workspaces)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
