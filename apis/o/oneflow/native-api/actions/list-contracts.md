# List Contracts with Oneflow

Retrieves contracts from Oneflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts`
- **Base URL:** `https://api.oneflow.com/v1`
- **Official documentation:** [List Contracts](https://developer.oneflow.com/reference/get-contracts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
