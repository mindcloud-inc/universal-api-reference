# Get Contract with Oneflow

Retrieves contract details from Oneflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts/:id`
- **Base URL:** `https://api.oneflow.com/v1`
- **Official documentation:** [Get Contract](https://developer.oneflow.com/reference/get-a-contract-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Oneflow contract ID. |
