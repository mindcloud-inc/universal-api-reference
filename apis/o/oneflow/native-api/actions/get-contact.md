# Get Contact with Oneflow

Retrieves contact details from Oneflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.oneflow.com/v1`
- **Official documentation:** [Get Contact](https://developer.oneflow.com/reference/get-a-contact-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Oneflow contact ID. |
