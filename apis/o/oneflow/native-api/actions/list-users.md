# List Users with Oneflow

Retrieves users from Oneflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.oneflow.com/v1`
- **Official documentation:** [List Users](https://developer.oneflow.com/reference/get-users-in-an-account)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
