# List Expense Group Profiles with OfficeClip

Retrieves expense group profiles from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/expense-group-profile`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Expense Group Profiles](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
