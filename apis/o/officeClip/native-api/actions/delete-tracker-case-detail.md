# Delete Tracker Case Detail with OfficeClip

Deletes a tracker case detail from OfficeClip.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/tracker-case-detail/{id}`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [Delete Tracker Case Detail](https://app.officeclip.com/swagger/ui/index)
