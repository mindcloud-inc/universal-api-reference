# Get Tracker Case Detail with OfficeClip

Retrieves a tracker case detail from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/tracker-case-detail/{id}`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [Get Tracker Case Detail](https://app.officeclip.com/swagger/ui/index)
