# List Time Off Group Profiles with OfficeClip

Retrieves time off group profiles from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/timeoff-group-profile`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Time Off Group Profiles](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
