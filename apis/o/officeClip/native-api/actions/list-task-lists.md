# List Task Lists with OfficeClip

Retrieves task lists from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/task-lists`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Task Lists](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
