# List Timesheet Details with OfficeClip

Retrieves timesheet details from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/timesheet-detail`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Timesheet Details](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
