# Update Timesheet Detail with OfficeClip

Updates a timesheet detail in OfficeClip.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/timesheet-detail/{id}`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [Update Timesheet Detail](https://app.officeclip.com/swagger/ui/index)
