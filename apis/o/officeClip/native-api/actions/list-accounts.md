# List Accounts with OfficeClip

Retrieves accounts from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/account-summary`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Accounts](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
