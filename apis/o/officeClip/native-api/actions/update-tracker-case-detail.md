# Update Tracker Case Detail with OfficeClip

Updates a tracker case detail in OfficeClip.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/tracker-case-detail/{id}`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [Update Tracker Case Detail](https://app.officeclip.com/swagger/ui/index)
