# List Regarding with OfficeClip

Retrieves regarding lists from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/regarding`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Regarding](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
