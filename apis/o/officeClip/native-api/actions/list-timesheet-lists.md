# List Timesheet Lists with OfficeClip

Retrieves timesheet lists from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/timesheet-lists`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Timesheet Lists](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
