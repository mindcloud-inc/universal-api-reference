# List Time Off Lists with OfficeClip

Retrieves time off lists from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/timeoff-lists`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Time Off Lists](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
