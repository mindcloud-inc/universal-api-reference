# Get Timesheet Detail with OfficeClip

Retrieves a timesheet detail from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/timesheet-detail/{id}`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [Get Timesheet Detail](https://app.officeclip.com/swagger/ui/index)
