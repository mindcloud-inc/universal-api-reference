# List Expense Details with OfficeClip

Retrieves expense details from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/expense-detail`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Expense Details](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
