# List Account Children with OfficeClip

Retrieves account child lists from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/account-children`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Account Children](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
