# Get Task Detail by Query ID with OfficeClip

Retrieves task details by query ID from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/task-detail`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [Get Task Detail by Query ID](https://app.officeclip.com/swagger/ui/index)
