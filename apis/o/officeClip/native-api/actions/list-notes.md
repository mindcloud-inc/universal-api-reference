# List Notes with OfficeClip

Retrieves notes from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/note`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Notes](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
