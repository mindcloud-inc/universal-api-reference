# List Notebooks with OfficeClip

Retrieves notebooks from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/notebook`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Notebooks](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
