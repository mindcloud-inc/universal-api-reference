# List Note Details with OfficeClip

Retrieves note details from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/note-detail`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Note Details](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
