# List Tasks with OfficeClip

Retrieves tasks from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/task-summary`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Tasks](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
