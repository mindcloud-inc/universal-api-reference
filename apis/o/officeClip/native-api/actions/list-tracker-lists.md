# List Tracker Lists with OfficeClip

Retrieves tracker lists from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/tracker-lists`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Tracker Lists](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
