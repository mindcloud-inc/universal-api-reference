# List TE Comments with OfficeClip

Retrieves timesheet and expense comments from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/te-comments`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List TE Comments](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
