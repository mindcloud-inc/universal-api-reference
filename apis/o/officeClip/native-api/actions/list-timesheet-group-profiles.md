# List Timesheet Group Profiles with OfficeClip

Retrieves timesheet group profiles from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/timesheet-group-profile`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Timesheet Group Profiles](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
