# List Contact Lists with OfficeClip

Retrieves contact lists from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/contact-lists`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Contact Lists](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
