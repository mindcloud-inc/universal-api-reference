# List Tracker Binders with OfficeClip

Retrieves tracker binders from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/tracker-binder-summary`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Tracker Binders](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
