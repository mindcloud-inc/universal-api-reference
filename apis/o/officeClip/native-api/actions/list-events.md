# List Events with OfficeClip

Retrieves events from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/event-summary`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Events](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
