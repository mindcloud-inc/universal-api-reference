# List Users with OfficeClip

Retrieves users from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/user-summary`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Users](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
