# Delete Timesheet Detail with OfficeClip

Deletes a timesheet detail from OfficeClip.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/timesheet-detail/{id}`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [Delete Timesheet Detail](https://app.officeclip.com/swagger/ui/index)
