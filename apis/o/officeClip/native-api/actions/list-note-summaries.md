# List Note Summaries with OfficeClip

Retrieves note summaries from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/note-summary`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Note Summaries](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
