# List Contacts with OfficeClip

Retrieves contacts from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/contact-summary`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Contacts](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
