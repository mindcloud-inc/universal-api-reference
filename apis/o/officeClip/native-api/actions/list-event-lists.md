# List Event Lists with OfficeClip

Retrieves event lists from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/event-lists`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Event Lists](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
