# List Contact Children with OfficeClip

Retrieves contact child lists from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/contact-children`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Contact Children](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
