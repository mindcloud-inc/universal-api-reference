# Delete Time Off Detail with OfficeClip

Deletes a time off entry from OfficeClip.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/timeoff-detail/{id}`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [Delete Time Off Detail](https://app.officeclip.com/swagger/ui/index)
