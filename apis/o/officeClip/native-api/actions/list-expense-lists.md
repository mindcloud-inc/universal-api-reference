# List Expense Lists with OfficeClip

Retrieves expense lists from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/expense-lists`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Expense Lists](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
