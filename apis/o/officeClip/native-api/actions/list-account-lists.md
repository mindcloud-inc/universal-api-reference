# List Account Lists with OfficeClip

Retrieves account lists from OfficeClip.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/account-lists`
- **Base URL:** `https://app.officeclip.com`
- **Official documentation:** [List Account Lists](https://app.officeclip.com/swagger/ui/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
