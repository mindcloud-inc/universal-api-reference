# List Supported Fungible Tokens with Overledger

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/tokens/fungible`
- **Base URL:** `https://api.overledger.dev`
- **Official documentation:** [List Supported Fungible Tokens](https://docs.overledger.dev/docs/supported-tokens-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `location` | query | `string` | no | Optional Overledger location filter, when supported by the endpoint. |
