# Lookup Packages with openpm

## Endpoint

- **Method:** `GET`
- **Path:** `/packages/lookup`
- **Base URL:** `https://openpm.ai/api`
- **Official documentation:** [Lookup Packages](https://openpm.ai/apis/openpm)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ids` | query | `string` | yes | CSV list of package IDs. |
