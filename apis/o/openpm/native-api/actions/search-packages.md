# Search Packages with openpm

## Endpoint

- **Method:** `GET`
- **Path:** `/packages/search`
- **Base URL:** `https://openpm.ai/api`
- **Official documentation:** [Search Packages](https://openpm.ai/apis/openpm)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query. |
