# List Mail Folders with Outlook

Retrieves mail folders from an Outlook mailbox.

## Endpoint

- **Method:** `GET`
- **Path:** `/me/mailFolders`
- **Base URL:** `https://graph.microsoft.com/v1.0`
- **Official documentation:** [List Mail Folders](https://learn.microsoft.com/en-us/graph/api/user-list-mailfolders)
