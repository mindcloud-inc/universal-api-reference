# Search Google Travel Hotels with Oxylabs

Searches Google Travel hotel listings with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Search Google Travel Hotels](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/google/travel-hotels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Destination or hotel search query for Google Travel Hotels. |
