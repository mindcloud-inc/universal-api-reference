# Search Amazon with Oxylabs

Searches Amazon product results with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Search Amazon](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/amazon/search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search term to submit to Amazon Search. |
