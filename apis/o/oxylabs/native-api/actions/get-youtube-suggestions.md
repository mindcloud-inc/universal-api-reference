# Get YouTube Suggestions with Oxylabs

Retrieves YouTube search suggestions with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get YouTube Suggestions](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/youtube/autocomplete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Partial search term to get YouTube suggestions for. |
