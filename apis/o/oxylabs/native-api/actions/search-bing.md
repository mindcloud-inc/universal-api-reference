# Search Bing with Oxylabs

Searches Bing web results with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Search Bing](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/bing/search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search term to submit to Bing Search. |
