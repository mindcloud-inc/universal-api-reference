# Check YouTube Trainability with Oxylabs

Checks YouTube AI training permission status with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Check YouTube Trainability](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/youtube/youtube-video-trainability)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | body | `string` | yes | YouTube video ID to check for trainability. |
