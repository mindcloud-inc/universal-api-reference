# Get eBay Product with Oxylabs

Retrieves eBay product details with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get eBay Product](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/ebay/product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | body | `string` | yes | eBay product ID to retrieve. |
