# Search Walmart with Oxylabs

Searches Walmart product results with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Search Walmart](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/walmart/search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search term to submit to Walmart Search. |
