# Explore Google Trends with Oxylabs

Retrieves Google Trends data with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Explore Google Trends](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/google/trends-explore)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Topic or keyword to explore in Google Trends. |
