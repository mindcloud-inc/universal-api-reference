# Browse Target Category with Oxylabs

Retrieves Target category listings with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Browse Target Category](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/north-american-e-commerce/target/category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category_id` | body | `string` | yes | Target category ID to retrieve. |
