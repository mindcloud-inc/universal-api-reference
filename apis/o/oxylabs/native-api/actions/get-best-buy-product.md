# Get Best Buy Product with Oxylabs

Retrieves Best Buy product details with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get Best Buy Product](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/north-american-e-commerce/bestbuy/product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | body | `string` | yes | Best Buy product ID to retrieve. |
