# Search Google Ads with Oxylabs

Searches Google ad results with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Search Google Ads](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/google/ads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search term to submit to Google Ads. |
