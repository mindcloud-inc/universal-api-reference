# Get YouTube Channel with Oxylabs

Retrieves YouTube channel data with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get YouTube Channel](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/youtube/youtube-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_handle` | body | `string` | yes | YouTube channel handle to retrieve. |
