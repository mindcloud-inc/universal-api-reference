# Search YouTube with Oxylabs

Searches YouTube search results with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Search YouTube](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/youtube/youtube-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search term to submit to YouTube Search. |
