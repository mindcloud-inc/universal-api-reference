# Ask Google AI Mode with Oxylabs

Retrieves Google AI Mode responses with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Ask Google AI Mode](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/google/ai-mode)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Prompt to submit to Google AI Mode. |
