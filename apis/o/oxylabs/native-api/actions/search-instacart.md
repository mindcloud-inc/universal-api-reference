# Search Instacart with Oxylabs

Searches Instacart product results with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Search Instacart](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/north-american-e-commerce/instacart/search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search term to submit to Instacart Search. |
