# Search Google Shopping with Oxylabs

Searches Google Shopping results with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Search Google Shopping](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/google/shopping/shopping-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search term to submit to Google Shopping. |
