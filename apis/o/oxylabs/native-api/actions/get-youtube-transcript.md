# Get YouTube Transcript with Oxylabs

Retrieves YouTube transcript data with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get YouTube Transcript](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/youtube/youtube-transcript)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | YouTube video ID to retrieve transcript for. |
