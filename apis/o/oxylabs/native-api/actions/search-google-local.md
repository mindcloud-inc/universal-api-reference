# Search Google Local with Oxylabs

Searches Google local results with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Search Google Local](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/google/search/local-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search term to submit to Google Local Search. |
