# Search Google Images with Oxylabs

Searches Google image results with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Search Google Images](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/google/search/image-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search term to submit to Google Image Search. |
