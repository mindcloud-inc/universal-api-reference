# Get Etsy Product with Oxylabs

Retrieves Etsy product details with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get Etsy Product](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/etsy/product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | body | `string` | yes | Etsy product ID to retrieve. |
