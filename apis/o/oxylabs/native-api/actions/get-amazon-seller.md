# Get Amazon Seller with Oxylabs

Retrieves Amazon seller details with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get Amazon Seller](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/amazon/sellers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Amazon seller identifier to retrieve. |
