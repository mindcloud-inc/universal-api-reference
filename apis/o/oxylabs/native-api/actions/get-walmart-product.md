# Get Walmart Product with Oxylabs

Retrieves Walmart product details with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get Walmart Product](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/walmart/product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | body | `string` | yes | Walmart product ID to retrieve. |
