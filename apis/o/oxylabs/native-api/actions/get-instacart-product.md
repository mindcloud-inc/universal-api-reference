# Get Instacart Product with Oxylabs

Retrieves Instacart product details with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get Instacart Product](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/north-american-e-commerce/instacart/product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | body | `string` | yes | Instacart product ID to retrieve. |
