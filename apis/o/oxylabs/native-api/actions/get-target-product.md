# Get Target Product with Oxylabs

Retrieves Target product details with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get Target Product](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/north-american-e-commerce/target/product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | body | `string` | yes | Target product ID to retrieve. |
