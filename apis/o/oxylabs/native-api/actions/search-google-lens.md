# Search Google Lens with Oxylabs

Searches Google Lens results with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Search Google Lens](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/google/lens)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Public image URL to inspect with Google Lens. |
