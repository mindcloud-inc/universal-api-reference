# Get YouTube Metadata with Oxylabs

Retrieves YouTube video metadata with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get YouTube Metadata](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/youtube/youtube-metadata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | YouTube video ID to retrieve metadata for. |
