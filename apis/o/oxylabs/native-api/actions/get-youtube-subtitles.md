# Get YouTube Subtitles with Oxylabs

Retrieves YouTube subtitles data with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get YouTube Subtitles](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/youtube/youtube-subtitles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | YouTube video ID to retrieve subtitles for. |
