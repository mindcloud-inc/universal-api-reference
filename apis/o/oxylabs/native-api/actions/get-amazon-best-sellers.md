# Get Amazon Best Sellers with Oxylabs

Retrieves Amazon Best Sellers data with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get Amazon Best Sellers](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/amazon/best-sellers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Amazon Best Sellers category ID to retrieve. |
