# Get Amazon Product with Oxylabs

Retrieves Amazon product details with Oxylabs.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/queries`
- **Base URL:** `https://realtime.oxylabs.io`
- **Official documentation:** [Get Amazon Product](https://developers.oxylabs.io/scraping-solutions/web-scraper-api/targets/amazon/product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Amazon ASIN to retrieve. |
