# Get Location Batch With Query Options with Open Data DC

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.2/locationbatch/:address_base64`
- **Base URL:** `https://datagate.dc.gov/mar/open`
- **Official documentation:** [Get Location Batch With Query Options](https://datagate.dc.gov/mar/open/swagger/v2.2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address_base64` | path | `string` | yes | Base64 encoded address string. |
