# Autocomplete Address From Body with Open Data DC

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2.2/autocomplete`
- **Base URL:** `https://datagate.dc.gov/mar/open`
- **Official documentation:** [Autocomplete Address From Body](https://datagate.dc.gov/mar/open/swagger/v2.2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | body | `string` | yes | Address in JSON object. |
