# Create SSL Lookup By Identifier with Open Data DC

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2.2/ssls/:ssl`
- **Base URL:** `https://datagate.dc.gov/mar/open`
- **Official documentation:** [Create SSL Lookup By Identifier](https://datagate.dc.gov/mar/open/swagger/v2.2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ssl` | path | `string` | yes | Square, suffix, lot identifier. |
