# Create Unit Lookup with Open Data DC

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2.2/units`
- **Base URL:** `https://datagate.dc.gov/mar/open`
- **Official documentation:** [Create Unit Lookup](https://datagate.dc.gov/mar/open/swagger/v2.2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `marid` | body | `string` | yes | MAR identifier. |
