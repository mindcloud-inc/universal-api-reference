# Get Units By MAR ID with Open Data DC

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.2/units/:marid`
- **Base URL:** `https://datagate.dc.gov/mar/open`
- **Official documentation:** [Get Units By MAR ID](https://datagate.dc.gov/mar/open/swagger/v2.2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `marid` | path | `string` | yes | MAR identifier. |
