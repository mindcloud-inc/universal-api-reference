# Create Zone Lookup with Open Data DC

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2.2/zone/:zone`
- **Base URL:** `https://datagate.dc.gov/mar/open`
- **Official documentation:** [Create Zone Lookup](https://datagate.dc.gov/mar/open/swagger/v2.2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `zone` | path | `string` | yes | Zone identifier to retrieve. |
