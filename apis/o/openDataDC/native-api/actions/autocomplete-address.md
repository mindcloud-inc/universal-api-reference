# Autocomplete Address with Open Data DC

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.2/autocomplete/:address`
- **Base URL:** `https://datagate.dc.gov/mar/open`
- **Official documentation:** [Autocomplete Address](https://datagate.dc.gov/mar/open/swagger/v2.2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | path | `string` | yes | Address string value. |
