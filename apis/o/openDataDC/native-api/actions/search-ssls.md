# Search SSLs with Open Data DC

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.2/ssls`
- **Base URL:** `https://datagate.dc.gov/mar/open`
- **Official documentation:** [Search SSLs](https://datagate.dc.gov/mar/open/swagger/v2.2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `marid` | query | `string` | no | MAR identifier. |
| `square` | query | `string` | no | Square value. |
| `suffix` | query | `string` | no | Suffix value. |
| `lot` | query | `string` | no | Lot value. |
