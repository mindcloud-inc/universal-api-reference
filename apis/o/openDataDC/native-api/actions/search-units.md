# Search Units with Open Data DC

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.2/units`
- **Base URL:** `https://datagate.dc.gov/mar/open`
- **Official documentation:** [Search Units](https://datagate.dc.gov/mar/open/swagger/v2.2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `marid` | query | `string` | no | MAR identifier. |
| `type` | query | `string` | no | Unit type. |
