# Get Document with OneDeck

Retrieves a document from OneDeck.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentId`
- **Base URL:** `https://{accountName}.onedeck.com/api/v1`
- **Official documentation:** [Get Document](https://www.onedeck.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | Document identifier to retrieve. |
