# Get Action with OnePageCRM

Retrieves an action from OnePageCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/actions/:action_id`
- **Base URL:** `https://app.onepagecrm.com/api/v3`
- **Official documentation:** [Get Action](https://developer.onepagecrm.com/api/#/Actions/get_actions__action_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `action_id` | path | `string` | yes | Action ID. |
