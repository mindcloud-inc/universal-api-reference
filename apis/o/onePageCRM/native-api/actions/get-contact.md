# Get Contact with OnePageCRM

Retrieves a contact from OnePageCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://app.onepagecrm.com/api/v3`
- **Official documentation:** [Get Contact](https://developer.onepagecrm.com/api/#/Contacts/get_contacts_contact_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `list<string>` | yes | Contact ID. |
