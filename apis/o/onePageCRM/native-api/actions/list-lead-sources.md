# List Lead Sources with OnePageCRM

Retrieves lead sources from OnePageCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/lead_sources`
- **Base URL:** `https://app.onepagecrm.com/api/v3`
- **Official documentation:** [List Lead Sources](https://developer.onepagecrm.com/api/#/Lead%20Sources/get_lead_sources)
