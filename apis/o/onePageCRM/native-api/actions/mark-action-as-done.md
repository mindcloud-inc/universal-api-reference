# Mark Action as Done with OnePageCRM

Marks an action as done in OnePageCRM.

## Endpoint

- **Method:** `PUT`
- **Path:** `/actions/:action_id/mark_as_done`
- **Base URL:** `https://app.onepagecrm.com/api/v3`
- **Official documentation:** [Mark Action as Done](https://developer.onepagecrm.com/api/#/Actions/put_actions__action_id__mark_as_done)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `action_id` | path | `string` | yes | Action ID. |
