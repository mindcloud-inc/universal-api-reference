# Get Company with OnePageCRM

Retrieves a company from OnePageCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:company_id`
- **Base URL:** `https://app.onepagecrm.com/api/v3`
- **Official documentation:** [Get Company](https://developer.onepagecrm.com/api/#/Companies/get_companies__company_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | path | `list<string>` | yes | ID of the company to retrieve |
