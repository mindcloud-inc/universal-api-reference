# List Solar Locations with OpenWeather

Lists solar locations in OpenWeather.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.openweathermap.org/energy/2.0/locations`
- **Base URL:** `https://api.openweathermap.org`
- **Official documentation:** [List Solar Locations](https://openweathermap.org/api/solar-panels-and-energy-prediction-2)
