# List Supplier Document Types with Oboloo

Retrieves supplier document types from Oboloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/configuration/get-suppliers-document-Types`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [List Supplier Document Types](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter supplier document types by name. |
