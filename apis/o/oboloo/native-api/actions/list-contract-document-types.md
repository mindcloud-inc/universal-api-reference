# List Contract Document Types with Oboloo

Retrieves contract document types from Oboloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/configuration/get-contract-document-Types`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [List Contract Document Types](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter contract document types by name. |
