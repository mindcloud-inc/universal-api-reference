# Create Payment Term with Oboloo

Creates a new payment term in Oboloo.

## Endpoint

- **Method:** `POST`
- **Path:** `/configuration/addpaymentTerms`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [Create Payment Term](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payment_term_name` | body | `string` | yes | Name of the payment term to create. |
