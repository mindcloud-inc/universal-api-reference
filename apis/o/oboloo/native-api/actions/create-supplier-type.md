# Create Supplier Type with Oboloo

Creates a new supplier type in Oboloo.

## Endpoint

- **Method:** `POST`
- **Path:** `/configuration/add-supplier-Types`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [Create Supplier Type](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `supplier_type` | body | `string` | yes | Supplier type name to create. |
