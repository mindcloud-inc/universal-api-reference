# Create Contract Type with Oboloo

Creates a new contract type in Oboloo.

## Endpoint

- **Method:** `POST`
- **Path:** `/configuration/add-contract-type`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [Create Contract Type](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Contract type name to create. |
