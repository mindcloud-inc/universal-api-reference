# List Industries with Oboloo

Retrieves industries from Oboloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/configuration/getIndustries`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [List Industries](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter industries by name. |
