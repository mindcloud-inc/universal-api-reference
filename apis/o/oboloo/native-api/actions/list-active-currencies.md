# List Active Currencies with Oboloo

Retrieves active currencies from Oboloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/currency-rates/get-all-active-currency`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [List Active Currencies](https://oboloo.app/api/documentation)
