# List Subcategories with Oboloo

Retrieves subcategories from Oboloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/configuration/getAllSubCategories`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [List Subcategories](https://oboloo.app/api/documentation)
