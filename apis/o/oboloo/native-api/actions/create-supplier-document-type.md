# Create Supplier Document Type with Oboloo

Creates a new supplier document type in Oboloo.

## Endpoint

- **Method:** `POST`
- **Path:** `/configuration/add-suppliers-document-Types`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [Create Supplier Document Type](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `supplier_document_type` | body | `string` | yes | Title of the supplier document type to create. |
