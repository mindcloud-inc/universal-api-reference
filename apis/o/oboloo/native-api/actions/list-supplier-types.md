# List Supplier Types with Oboloo

Retrieves supplier types from Oboloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/configuration/get-supplier-Types`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [List Supplier Types](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter supplier types by name. |
