# Create Industry with Oboloo

Creates a new industry in Oboloo.

## Endpoint

- **Method:** `POST`
- **Path:** `/configuration/addIndustry`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [Create Industry](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `industry_name` | body | `string` | yes | Name of the industry to create. |
