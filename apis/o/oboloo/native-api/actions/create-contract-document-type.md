# Create Contract Document Type with Oboloo

Creates a new contract document type in Oboloo.

## Endpoint

- **Method:** `POST`
- **Path:** `/configuration/add-contract-document-Types`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [Create Contract Document Type](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contract_document_type` | body | `string` | yes | Title of the contract document type to create. |
