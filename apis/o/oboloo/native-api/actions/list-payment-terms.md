# List Payment Terms with Oboloo

Retrieves payment terms from Oboloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/configuration/getpaymentTerms`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [List Payment Terms](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter payment terms by name. |
