# List Contract Types with Oboloo

Retrieves contract types from Oboloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/configuration/contract-type-list`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [List Contract Types](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter contract types by name. |
