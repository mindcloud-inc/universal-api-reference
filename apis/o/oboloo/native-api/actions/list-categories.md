# List Categories with Oboloo

Retrieves categories from Oboloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/configuration/getCategories`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [List Categories](https://oboloo.app/api/documentation)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter categories by name. |
