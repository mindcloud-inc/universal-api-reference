# Create Saving Type with Oboloo

Creates a new saving type in Oboloo.

## Endpoint

- **Method:** `POST`
- **Path:** `/configuration/add-saving-type`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [Create Saving Type](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Saving type name to create. |
