# List Subindustries with Oboloo

Retrieves subindustries from Oboloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/configuration/getSubIndustries`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [List Subindustries](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `industry` | query | `string` | yes | Industry identifier used to fetch subindustries. |
