# List Saving Types with Oboloo

Retrieves saving types from Oboloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/configuration/saving-type-list`
- **Base URL:** `https://mindcloudwizard20260330.oboloo.app/api`
- **Official documentation:** [List Saving Types](https://oboloo.app/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter saving types by name. |
