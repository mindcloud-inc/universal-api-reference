# List Projects with BlazeMeter

Retrieves projects from BlazeMeter.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [List Projects](https://help.blazemeter.com/apidocs/#tag/projects/operation/projectsRetrieveListOfProjects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | query | `number` | no |
| `skip` | query | `number` | no |
