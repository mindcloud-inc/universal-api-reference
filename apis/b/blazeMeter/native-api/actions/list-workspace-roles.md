# List Workspace Roles with BlazeMeter

Retrieves available workspace roles from BlazeMeter.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:entityId/roles`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [List Workspace Roles](https://help.blazemeter.com/apidocs/#tag/workspaces/operation/workspacesRetrieveAvailableRoles)
