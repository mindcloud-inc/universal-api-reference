# List Workspace Tags with BlazeMeter

Retrieves workspace tags from BlazeMeter.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId/tags`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [List Workspace Tags](https://help.blazemeter.com/apidocs/#tag/workspaces/operation/tagsRetrieveAllTags)
