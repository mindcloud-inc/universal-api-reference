# List Account Roles with BlazeMeter

Retrieves available account roles from BlazeMeter.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:entityId/roles`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [List Account Roles](https://help.blazemeter.com/apidocs/#tag/accounts/operation/accountsRetrieveAvailableRoles)
