# Get Project with BlazeMeter

Retrieves a project from BlazeMeter.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [Get Project](https://help.blazemeter.com/apidocs/#tag/projects/operation/projectsRetrieveProject)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
