# List Tests with BlazeMeter

Retrieves tests from BlazeMeter.

## Endpoint

- **Method:** `GET`
- **Path:** `/tests`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [List Tests](https://help.blazemeter.com/apidocs/#tag/tests/operation/listTests)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | query | `number` | no |
