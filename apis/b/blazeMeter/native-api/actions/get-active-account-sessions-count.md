# Get Active Account Sessions Count with BlazeMeter

Retrieves the active session count for a BlazeMeter account.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/sessions/active/count`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [Get Active Account Sessions Count](https://help.blazemeter.com/apidocs/#tag/accounts/operation/accountsRetrieveActiveSessionsCount)
