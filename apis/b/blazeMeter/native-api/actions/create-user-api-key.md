# Create User API Key with BlazeMeter

Creates a user API key in BlazeMeter.

## Endpoint

- **Method:** `POST`
- **Path:** `/user/api-keys`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [Create User API Key](https://help.blazemeter.com/apidocs/#tag/user/operation/apiKeysCreateApiKey)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
