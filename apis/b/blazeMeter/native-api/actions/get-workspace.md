# Get Workspace with BlazeMeter

Retrieves a workspace from BlazeMeter.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [Get Workspace](https://help.blazemeter.com/apidocs/#tag/workspaces/operation/workspacesRetrieveWorkspace)
