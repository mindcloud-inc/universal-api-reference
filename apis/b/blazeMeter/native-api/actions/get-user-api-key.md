# Get User API Key with BlazeMeter

## Endpoint

- **Method:** `GET`
- **Path:** `/user/api-keys/:apiKeyId`
- **Base URL:** `https:///a.blazemeter.com/api/v4`
- **Official documentation:** [Get User API Key](https://help.blazemeter.com/apidocs/#tag/user/operation/apiKeysRetrieveApiKey)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `apiKeyId` | path | `string` | yes |
