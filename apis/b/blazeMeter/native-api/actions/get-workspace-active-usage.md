# Get Workspace Active Usage with BlazeMeter

Retrieves active test usage for a BlazeMeter workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId/active`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [Get Workspace Active Usage](https://help.blazemeter.com/apidocs/#tag/workspaces/operation/workspacesRetrieveActiveTestsInfo)
