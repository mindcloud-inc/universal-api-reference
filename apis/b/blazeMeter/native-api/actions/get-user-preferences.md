# Get User Preferences with BlazeMeter

Retrieves user preferences from BlazeMeter.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/preferences`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [Get User Preferences](https://help.blazemeter.com/apidocs/#tag/user/operation/userPreferencesRetrieveUserPreferences)
