# Delete Workspace Tag with BlazeMeter

Deletes a workspace tag from BlazeMeter.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workspaces/:workspaceId/tags/:tagId`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [Delete Workspace Tag](https://help.blazemeter.com/apidocs/#tag/workspaces/operation/tagsRemoveTag)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tagId` | path | `string` | yes |
