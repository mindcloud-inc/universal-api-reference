# Get Account with BlazeMeter

Retrieves an account from BlazeMeter.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [Get Account](https://help.blazemeter.com/apidocs/#tag/accounts/operation/accountsRetrieveAccount)
