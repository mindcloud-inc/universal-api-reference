# List User Projects with BlazeMeter

Retrieves the current user's projects from BlazeMeter.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/projects`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [List User Projects](https://help.blazemeter.com/apidocs/#tag/user/operation/userRetrieveProjects)
