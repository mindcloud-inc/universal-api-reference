# Get Workspace Active Masters Count with BlazeMeter

Retrieves the active master count for a BlazeMeter workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId/masters/active/count`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [Get Workspace Active Masters Count](https://help.blazemeter.com/apidocs/#tag/workspaces/operation/workspacesRetrieveActiveMastersCount)
