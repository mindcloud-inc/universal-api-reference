# Delete User API Key with BlazeMeter

Deletes a user API key from BlazeMeter.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/user/api-keys/:apiKeyId`
- **Base URL:** `https://a.blazemeter.com/api/v4`
- **Official documentation:** [Delete User API Key](https://help.blazemeter.com/apidocs/#tag/User-API-Keys)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `apiKeyId` | path | `string` | yes |
