# Reactivate Invoice with Billwerkplus

Reactivates an invoice in Billwerkplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/invoice/:id/reactivate`
- **Base URL:** `https://api.frisbii.com/v1`
- **Official documentation:** [Reactivate Invoice](https://docs.frisbii.com/reference/reactivateinvoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Invoice id or handle. |
