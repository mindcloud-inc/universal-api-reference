# Get Subscription with Billwerkplus

Retrieves a subscription from Billwerkplus.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscription/:handle`
- **Base URL:** `https://api.frisbii.com/v1`
- **Official documentation:** [Get Subscription](https://docs.frisbii.com/reference/getsubscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Subscription handle. |
