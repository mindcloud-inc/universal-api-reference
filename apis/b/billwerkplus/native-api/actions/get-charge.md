# Get Charge with Billwerkplus

Retrieves a charge from Billwerkplus.

## Endpoint

- **Method:** `GET`
- **Path:** `/charge/:handle`
- **Base URL:** `https://api.frisbii.com/v1`
- **Official documentation:** [Get Charge](https://docs.frisbii.com/reference/getcharge)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Charge handle. |
