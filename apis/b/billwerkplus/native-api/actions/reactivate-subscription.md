# Reactivate Subscription with Billwerkplus

Reactivates a subscription on hold in Billwerkplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/subscription/:handle/reactivate`
- **Base URL:** `https://api.frisbii.com/v1`
- **Official documentation:** [Reactivate Subscription](https://docs.frisbii.com/reference/reactivatesubscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Subscription handle. |
