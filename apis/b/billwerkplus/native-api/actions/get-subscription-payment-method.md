# Get Subscription Payment Method with Billwerkplus

Retrieves the payment method for a Billwerkplus subscription.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscription/:handle/pm`
- **Base URL:** `https://api.frisbii.com/v1`
- **Official documentation:** [Get Subscription Payment Method](https://docs.frisbii.com/reference/getsubscriptionpaymentmethod)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Subscription handle. |
