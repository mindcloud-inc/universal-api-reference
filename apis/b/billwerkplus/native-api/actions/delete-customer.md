# Delete Customer with Billwerkplus

Soft-deletes a customer from Billwerkplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customer/:handle`
- **Base URL:** `https://api.frisbii.com/v1`
- **Official documentation:** [Delete Customer](https://docs.frisbii.com/reference/deletecustomer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Customer handle. |
