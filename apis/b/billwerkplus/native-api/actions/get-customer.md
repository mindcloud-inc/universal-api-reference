# Get Customer with Billwerkplus

Retrieves a customer from Billwerkplus.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer/:handle`
- **Base URL:** `https://api.frisbii.com/v1`
- **Official documentation:** [Get Customer](https://docs.frisbii.com/reference/getcustomer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Customer handle. |
