# Get Plan with Billwerkplus

Retrieves a plan from Billwerkplus.

## Endpoint

- **Method:** `GET`
- **Path:** `/plan/:handle/current`
- **Base URL:** `https://api.frisbii.com/v1`
- **Official documentation:** [Get Plan](https://docs.frisbii.com/reference/getcurrentplan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Plan handle. |
