# Get Invoice with Billwerkplus

Retrieves an invoice from Billwerkplus.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoice/:id`
- **Base URL:** `https://api.frisbii.com/v1`
- **Official documentation:** [Get Invoice](https://docs.frisbii.com/reference/getinvoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Invoice id or handle. |
