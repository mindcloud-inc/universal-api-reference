# Preview Next Subscription Invoice with Billwerkplus

Retrieves the next invoice preview for a Billwerkplus subscription.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscription/:handle/next_invoice_preview`
- **Base URL:** `https://api.frisbii.com/v1`
- **Official documentation:** [Preview Next Subscription Invoice](https://docs.frisbii.com/reference/previewnextsubscriptioninvoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Subscription handle. |
