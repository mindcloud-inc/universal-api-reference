# Delete Knowledgebase with Bolna

Deletes an existing knowledgebase from your Bolna account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/knowledgebase/:ragId`
- **Base URL:** `https://api.bolna.ai`
- **Official documentation:** [Delete Knowledgebase](https://www.bolna.ai/docs/api-reference/knowledgebase/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rag_id` | path | `string` | yes | The ID of the knowledgebase. |
