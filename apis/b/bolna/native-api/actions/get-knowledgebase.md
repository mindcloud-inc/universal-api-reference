# Get Knowledgebase with Bolna

Retrieves a specific knowledgebase from your Bolna account.

## Endpoint

- **Method:** `GET`
- **Path:** `/knowledgebase/:ragId`
- **Base URL:** `https://api.bolna.ai`
- **Official documentation:** [Get Knowledgebase](https://www.bolna.ai/docs/api-reference/knowledgebase/get_knowledgebase)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rag_id` | path | `string` | yes | The unique knowledgebase ID from Bolna. |
