# List All Knowledgebases with Bolna

Retrieves all knowledgebases in your Bolna account.

## Endpoint

- **Method:** `GET`
- **Path:** `/knowledgebase/all`
- **Base URL:** `https://api.bolna.ai`
- **Official documentation:** [List All Knowledgebases](https://www.bolna.ai/docs/api-reference/knowledgebase/get_knowledgebases)
