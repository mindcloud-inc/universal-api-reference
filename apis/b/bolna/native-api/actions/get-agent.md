# Get Agent with Bolna

Retrieves a specific Bolna voice AI agent.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/agent/:agentId`
- **Base URL:** `https://api.bolna.ai`
- **Official documentation:** [Get Agent](https://www.bolna.ai/docs/api-reference/agent/v2/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | The unique agent ID from Bolna. |
