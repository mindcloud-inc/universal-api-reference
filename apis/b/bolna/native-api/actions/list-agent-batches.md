# List Agent Batches with Bolna

Retrieves all batches for a specific Bolna agent.

## Endpoint

- **Method:** `GET`
- **Path:** `/batches/:agentId/all`
- **Base URL:** `https://api.bolna.ai`
- **Official documentation:** [List Agent Batches](https://www.bolna.ai/docs/api-reference/batches/get_batches)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | The ID of the agent. |
