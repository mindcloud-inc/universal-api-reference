# Delete Agent with Bolna

Deletes an existing voice AI agent from Bolna.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/agent/:agentId`
- **Base URL:** `https://api.bolna.ai`
- **Official documentation:** [Delete Agent](https://www.bolna.ai/docs/api-reference/agent/v2/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | The ID of the agent. |
