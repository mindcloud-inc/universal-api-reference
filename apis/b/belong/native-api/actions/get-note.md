# Get Note with Belong

Retrieves a note from Belong by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/notes/:id`
- **Base URL:** `https://api.belong.net/api/v3`
- **Official documentation:** [Get Note](https://api.belong.net/api/v3/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
