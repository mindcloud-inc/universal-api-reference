# Search Address Suggestions with Belong

Finds address suggestions in Belong by search text.

## Endpoint

- **Method:** `GET`
- **Path:** `/addresses/autocomplete`
- **Base URL:** `https://api.belong.net/api/v3`
- **Official documentation:** [Search Address Suggestions](https://api.belong.net/api/v3/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `q` | query | `string` | yes |
