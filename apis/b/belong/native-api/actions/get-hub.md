# Get Hub with Belong

Retrieves a hub from Belong by ID or slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/hubs/:id`
- **Base URL:** `https://api.belong.net/api/v3`
- **Official documentation:** [Get Hub](https://api.belong.net/api/v3/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
