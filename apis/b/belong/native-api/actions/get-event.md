# Get Event with Belong

Retrieves an event from Belong by ID or slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:id`
- **Base URL:** `https://api.belong.net/api/v3`
- **Official documentation:** [Get Event](https://api.belong.net/api/v3/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
