# List Project Fields with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/accounts/:id/project-fields`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [List Project Fields](https://developers.gobridgit.com/reference/projectfields_query)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Account ID |
