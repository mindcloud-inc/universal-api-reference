# List Account Phases with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/accounts/:accountId/Phases`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [List Account Phases](https://developers.gobridgit.com/reference/phases_query)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | The Account ID |
