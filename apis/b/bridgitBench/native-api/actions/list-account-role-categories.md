# List Account Role Categories with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/Accounts/:id/role-categories`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [List Account Role Categories](https://developers.gobridgit.com/reference/accounts_queryrolecategories)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Account ID |
