# List Experience Field Candidates with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/accounts/:accountId/experience-fields/candidates`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [List Experience Field Candidates](https://developers.gobridgit.com/reference/experiencefields_querycandidates)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `number` | yes |
