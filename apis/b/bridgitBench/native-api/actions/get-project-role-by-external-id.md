# Get Project Role by External ID with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/accounts/:accountId/external/roles/:externalId`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [Get Project Role by External ID](https://developers.gobridgit.com/reference/external_getprojectrole)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `number` | yes |
| `externalId` | path | `string` | yes |
