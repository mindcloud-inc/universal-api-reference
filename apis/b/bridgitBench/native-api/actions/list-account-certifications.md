# List Account Certifications with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/accounts/:accountId/certifications`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [List Account Certifications](https://developers.gobridgit.com/reference/accountcertifications_query)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | The Account ID |
