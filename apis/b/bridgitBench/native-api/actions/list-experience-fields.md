# List Experience Fields with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/accounts/:accountId/experience-fields`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [List Experience Fields](https://developers.gobridgit.com/reference/experiencefields_query)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `number` | yes |
