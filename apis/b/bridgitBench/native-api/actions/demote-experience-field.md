# Demote Experience Field with Bridgit Bench

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rp/api/v1/accounts/:accountId/experience-fields/:experienceFieldId`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [Demote Experience Field](https://developers.gobridgit.com/reference/experiencefields_demoteexperiencefield)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `number` | yes |
| `experienceFieldId` | path | `string` | yes |
