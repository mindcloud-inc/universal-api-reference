# List Project Phases with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/accounts/:accountId/projects/:projectId/phases`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [List Project Phases](https://developers.gobridgit.com/reference/projectsphases_query)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | The Account ID |
| `projectId` | path | `number` | yes | The Project ID |
