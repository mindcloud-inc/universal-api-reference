# Get Saved Filter with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/accounts/:accountId/my-filters/:id`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [Get Saved Filter](https://developers.gobridgit.com/reference/userfilters_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | The Account ID |
| `id` | path | `number` | yes | The filter's ID |
