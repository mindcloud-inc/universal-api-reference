# Get Account Certification with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/accounts/:accountId/certifications/:id`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [Get Account Certification](https://developers.gobridgit.com/reference/accountcertifications_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | The Account ID |
| `id` | path | `number` | yes | The Certification's ID |
