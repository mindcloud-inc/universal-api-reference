# Get Account Grouping with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/accounts/:accountId/groupings/:id`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [Get Account Grouping](https://developers.gobridgit.com/reference/accountgroupings_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | The Account ID |
| `id` | path | `number` | yes | The grouping's ID |
