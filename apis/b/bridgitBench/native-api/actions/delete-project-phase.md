# Delete Project Phase with Bridgit Bench

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rp/api/v1/accounts/:accountId/projects/:projectId/phases/:phaseId`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [Delete Project Phase](https://developers.gobridgit.com/reference/projectsphases_delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | The Account ID |
| `projectId` | path | `number` | yes | The Project ID |
| `phaseId` | path | `number` | yes | The Phase ID |
