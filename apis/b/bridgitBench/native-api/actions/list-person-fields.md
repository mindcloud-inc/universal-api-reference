# List Person Fields with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/accounts/:id/person-fields`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [List Person Fields](https://developers.gobridgit.com/reference/personfields_query)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The account ID |
