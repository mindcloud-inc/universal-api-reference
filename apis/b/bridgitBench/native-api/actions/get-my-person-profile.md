# Get My Person Profile with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/accounts/:accountId/persons/me`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [Get My Person Profile](https://developers.gobridgit.com/reference/personprofile_getmine)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | The Account ID |
