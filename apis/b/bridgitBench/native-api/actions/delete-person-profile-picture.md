# Delete Person Profile Picture with Bridgit Bench

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rp/api/v1/accounts/:accountId/persons/:personId/profile-picture`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [Delete Person Profile Picture](https://developers.gobridgit.com/reference/personprofile_delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | The Account ID |
| `personId` | path | `number` | yes | The Person ID |
