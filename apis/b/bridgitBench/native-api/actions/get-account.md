# Get Account with Bridgit Bench

## Endpoint

- **Method:** `GET`
- **Path:** `/rp/api/v1/Accounts/:id`
- **Base URL:** `https://bench.gobridgit.com`
- **Official documentation:** [Get Account](https://developers.gobridgit.com/reference/accounts_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Account ID |
