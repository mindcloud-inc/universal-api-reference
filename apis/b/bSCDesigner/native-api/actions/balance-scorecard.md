# Balance Scorecard with BSC Designer

## Endpoint

- **Method:** `PUT`
- **Path:** `/rest/api/document/:docId/kpi/weight-balance`
- **Base URL:** `https://www.webbsc.com`
- **Official documentation:** [Balance Scorecard](https://www.webbsc.com/swagger-ui.html#/rest-document-controller/runStrategyMapWizardUsingPUT)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `docId` | path | `string` | yes | Document id or alias to balance. |
