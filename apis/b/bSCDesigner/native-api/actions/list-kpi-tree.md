# List KPI Tree with BSC Designer

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/api/document/:docId/kpi/tree`
- **Base URL:** `https://www.webbsc.com`
- **Official documentation:** [List KPI Tree](https://www.webbsc.com/swagger-ui.html#/rest-document-controller/getKpiTreeUsingGET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `docId` | path | `string` | yes | Document ID or alias. |
