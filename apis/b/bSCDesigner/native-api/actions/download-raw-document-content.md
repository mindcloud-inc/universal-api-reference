# Download Raw Document Content with BSC Designer

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/api/document/:docId/download`
- **Base URL:** `https://www.webbsc.com`
- **Official documentation:** [Download Raw Document Content](https://www.webbsc.com/swagger-ui.html#/rest-document-controller/downloadDocumentUsingGET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `docId` | path | `string` | yes | Document ID or alias. |
