# List Document Maps with BSC Designer

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/api/document/:docId/maps`
- **Base URL:** `https://www.webbsc.com`
- **Official documentation:** [List Document Maps](https://www.webbsc.com/swagger-ui.html#/rest-document-map-controller/getMapsUsingGET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `docId` | path | `string` | yes | Document ID or alias. |
