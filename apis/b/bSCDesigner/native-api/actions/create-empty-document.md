# Create Empty Document with BSC Designer

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/api/documents`
- **Base URL:** `https://www.webbsc.com`
- **Official documentation:** [Create Empty Document](https://www.webbsc.com/swagger-ui.html#/rest-document-list-controller/createDocumentUsingPOST)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `parentGroupId` | body | `number` | no | Optional parent document group ID for the new empty document. |
