# Get Document Info with BSC Designer

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/api/documents/list/:idOrAlias`
- **Base URL:** `https://www.webbsc.com`
- **Official documentation:** [Get Document Info](https://www.webbsc.com/swagger-ui.html#/rest-document-list-controller/getDocumentInfoUsingGET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `idOrAlias` | path | `string` | yes | Document ID or alias. |
