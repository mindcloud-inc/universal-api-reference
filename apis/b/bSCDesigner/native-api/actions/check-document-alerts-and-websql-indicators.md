# Check Document Alerts And WEB SQL Indicators with BSC Designer

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/api/document/:docId/document-check-requests`
- **Base URL:** `https://www.webbsc.com`
- **Official documentation:** [Check Document Alerts And WEB SQL Indicators](https://www.webbsc.com/swagger-ui.html#/rest-document-controller/checkDocumentUsingPOST)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `docId` | path | `string` | yes | Document ID. |
