# List Services with Details with Bookafy

Retrieves services with details from Bookafy.

## Endpoint

- **Method:** `GET`
- **Path:** `/services`
- **Base URL:** `https://app.bookafy.com/api/v2`
- **Official documentation:** [List Services with Details](https://app.bookafy.com/api-docs/v3/appointment_types_services.yaml)
