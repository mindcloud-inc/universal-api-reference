# List Appointment Types with Booking Links with Bookafy

Retrieves appointment types and booking links from Bookafy.

## Endpoint

- **Method:** `GET`
- **Path:** `/appointment_types`
- **Base URL:** `https://app.bookafy.com/api/v2`
- **Official documentation:** [List Appointment Types with Booking Links](https://app.bookafy.com/api-docs/v3/appointment_types.yaml)
