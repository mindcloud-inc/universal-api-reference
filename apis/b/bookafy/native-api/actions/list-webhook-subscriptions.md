# List Webhook Subscriptions with Bookafy

Retrieves webhook subscriptions from Bookafy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api_subscriptions`
- **Base URL:** `https://app.bookafy.com/api/v2`
- **Official documentation:** [List Webhook Subscriptions](https://app.bookafy.com/api-docs/v3/webhook_part1.yaml)
