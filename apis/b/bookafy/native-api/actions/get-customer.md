# Get Customer with Bookafy

Retrieves a customer from Bookafy.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:id`
- **Base URL:** `https://app.bookafy.com/api/v2`
- **Official documentation:** [Get Customer](https://app.bookafy.com/api-docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Customer ID from Bookafy. |
