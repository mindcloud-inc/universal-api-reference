# Delete Customer with Bookafy

Deletes a customer from Bookafy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customers/:id`
- **Base URL:** `https://app.bookafy.com/api/v2`
- **Official documentation:** [Delete Customer](https://app.bookafy.com/api-docs/v3/customers_part3.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Customer ID from Bookafy. |
