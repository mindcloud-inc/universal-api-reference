# List Columns with BugHerd

Retrieves columns from a BugHerd project.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:project_id/columns.json`
- **Base URL:** `https://www.bugherd.com/api_v2`
- **Official documentation:** [List Columns](https://docs.bugherd.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | The BugHerd project ID. |
