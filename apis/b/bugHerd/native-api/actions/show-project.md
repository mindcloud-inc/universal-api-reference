# Show Project with BugHerd

Retrieves a project from BugHerd.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:project_id.json`
- **Base URL:** `https://www.bugherd.com/api_v2`
- **Official documentation:** [Show Project](https://docs.bugherd.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `number` | yes |
