# Delete Project with BugHerd

Deletes a project from BugHerd.

## Endpoint

- **Method:** `DELETE`
- **Path:** `projects/:project_id.json`
- **Base URL:** `https://www.bugherd.com/api_v2`
- **Official documentation:** [Delete Project](https://docs.bugherd.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | The BugHerd project ID. |
