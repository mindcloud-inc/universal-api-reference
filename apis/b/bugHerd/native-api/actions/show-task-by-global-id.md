# Show Task By Global ID with BugHerd

Retrieves a BugHerd task by global ID.

## Endpoint

- **Method:** `GET`
- **Path:** `tasks/:task_id.json`
- **Base URL:** `https://www.bugherd.com/api_v2`
- **Official documentation:** [Show Task By Global ID](https://docs.bugherd.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | path | `number` | yes |
