# List Tasks with BugHerd

Retrieves tasks from a BugHerd project.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:project_id/tasks.json`
- **Base URL:** `https://www.bugherd.com/api_v2`
- **Official documentation:** [List Tasks](https://docs.bugherd.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `number` | yes |
