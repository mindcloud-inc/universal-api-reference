# Delete Webhook with BugHerd

Deletes a webhook from BugHerd.

## Endpoint

- **Method:** `DELETE`
- **Path:** `webhooks/:id.json`
- **Base URL:** `https://www.bugherd.com/api_v2`
- **Official documentation:** [Delete Webhook](https://docs.bugherd.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The BugHerd webhook ID. |
