# Search Locations with BodyGraph

Finds locations in BodyGraph by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/v210502/locations`
- **Base URL:** `https://api.bodygraphchart.com`
- **Official documentation:** [Search Locations](https://bodygraph.com/docs/#find-timezone)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | A search word to find locations. |
