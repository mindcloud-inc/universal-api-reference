# Get Space with Bika.ai

Retrieves a space from Bika.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId`
- **Base URL:** `https://bika.ai/api/openapi/bika/v1`
- **Official documentation:** [Get Space](https://bika.ai/help/openapi/bika)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Bika.ai space ID. |
