# List Embed Links with Bika.ai

Retrieves embed links from a Bika.ai space.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/embed-links`
- **Base URL:** `https://bika.ai/api/openapi/bika/v1`
- **Official documentation:** [List Embed Links](https://bika.ai/help/openapi/bika)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Bika.ai space ID. |
