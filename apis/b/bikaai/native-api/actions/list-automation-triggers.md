# List Automation Triggers with Bika.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/automations/:nodeId/triggers`
- **Base URL:** `https://bika.ai/api/openapi/bika/v1`
- **Official documentation:** [List Automation Triggers](https://bika.ai/help/openapi/bika)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `nodeId` | path | `string` | yes | Automation node ID. |
