# List Outbound Webhooks with Bika.ai

Retrieves outbound webhooks from a Bika.ai space.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/outgoing-webhooks`
- **Base URL:** `https://bika.ai/api/openapi/bika/v1`
- **Official documentation:** [List Outbound Webhooks](https://bika.ai/help/openapi/bika)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Bika.ai space ID. |
