# Retrieve Bundle Data with Blueink

Retrieves field data for a Blueink bundle.

## Endpoint

- **Method:** `GET`
- **Path:** `/bundles/:bundleSlug/data/`
- **Base URL:** `https://api.blueink.com/api/v2`
- **Official documentation:** [Retrieve Bundle Data](https://developer.blueink.com/api/#tag/Bundles/operation/getBundleData)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bundleSlug` | path | `string` | yes | Bundle slug to retrieve field data for. |
