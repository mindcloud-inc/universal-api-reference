# List Envelope Templates with Blueink

Retrieves available envelope templates from Blueink.

## Endpoint

- **Method:** `GET`
- **Path:** `/envelope-templates/`
- **Base URL:** `https://api.blueink.com/api/v2`
- **Official documentation:** [List Envelope Templates](https://developer.blueink.com/api/#tag/Envelope-Templates/operation/listEnvelopeTemplates)

## Capabilities

This operation supports [pagination](../README.md#pagination).
