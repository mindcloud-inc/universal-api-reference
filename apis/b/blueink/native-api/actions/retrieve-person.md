# Retrieve Person with Blueink

Retrieves an existing person from Blueink.

## Endpoint

- **Method:** `GET`
- **Path:** `/persons/:personId/`
- **Base URL:** `https://api.blueink.com/api/v2`
- **Official documentation:** [Retrieve Person](https://developer.blueink.com/api/#tag/Person/operation/getPerson)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `string` | yes | Person ID to retrieve. |
