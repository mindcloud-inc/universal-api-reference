# Delete Person with Blueink

Deletes an existing person from Blueink.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/persons/:personId/`
- **Base URL:** `https://api.blueink.com/api/v2`
- **Official documentation:** [Delete Person](https://developer.blueink.com/api/#tag/Person/operation/deletePerson)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `string` | yes | Person ID to delete. |
