# Retrieve Bundle with Blueink

Retrieves an existing bundle from Blueink.

## Endpoint

- **Method:** `GET`
- **Path:** `/bundles/:bundleSlug/`
- **Base URL:** `https://api.blueink.com/api/v2`
- **Official documentation:** [Retrieve Bundle](https://developer.blueink.com/api/#tag/Bundles/operation/retrieveBundle)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bundleSlug` | path | `string` | yes | Bundle slug to retrieve. |
