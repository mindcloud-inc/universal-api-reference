# List Document Templates with Blueink

Retrieves available document templates from Blueink.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/`
- **Base URL:** `https://api.blueink.com/api/v2`
- **Official documentation:** [List Document Templates](https://developer.blueink.com/api/#tag/Templates/operation/listTemplates)

## Capabilities

This operation supports [pagination](../README.md#pagination).
