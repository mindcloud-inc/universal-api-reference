# Retrieve Document Template with Blueink

Retrieves a document template from Blueink.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:templateId/`
- **Base URL:** `https://api.blueink.com/api/v2`
- **Official documentation:** [Retrieve Document Template](https://developer.blueink.com/api/#tag/Templates/operation/retrieveTemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | Template ID to retrieve. |
