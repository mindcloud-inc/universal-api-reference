# Retrieve Packet with Blueink

Retrieves an existing packet from Blueink.

## Endpoint

- **Method:** `GET`
- **Path:** `/packets/:packetId/`
- **Base URL:** `https://api.blueink.com/api/v2`
- **Official documentation:** [Retrieve Packet](https://developer.blueink.com/api/#tag/Packet/operation/retrievePacket)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `packetId` | path | `string` | yes | Packet ID to retrieve. |
