# List Publications with Beehiiv

Retrieves publications from Beehiiv.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/publications`
- **Base URL:** `https://api.beehiiv.com`
- **Official documentation:** [List Publications](https://developers.beehiiv.com/api-reference/publications/index)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `expand` | query | `string` | no | Optional expansions for publication stats and related data. |
