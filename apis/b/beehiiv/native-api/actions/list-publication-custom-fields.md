# List Publication Custom Fields with Beehiiv

Retrieves publication custom fields from Beehiiv.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/publications/:publicationId/custom_fields`
- **Base URL:** `https://api.beehiiv.com`
- **Official documentation:** [List Publication Custom Fields](https://developers.beehiiv.com/api-reference/custom-fields/index)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `publicationId` | path | `string` | yes | The prefixed ID of the publication object. |
