# Identify Workspace with Beehiiv

Retrieves the current workspace from Beehiiv.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/workspaces/identify`
- **Base URL:** `https://api.beehiiv.com`
- **Official documentation:** [Identify Workspace](https://developers.beehiiv.com/api-reference/workspaces/identify)
