# Get Robot with Browse AI

Retrieves a robot from Browse AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/robots/:robotId`
- **Base URL:** `https://api.browse.ai/v2`
- **Official documentation:** [Get Robot](https://developers.browse.ai/v2#tag/robots/GET/robots/{robotId})

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `robotId` | path | `string` | yes | Unique robot ID You can find a robot's ID by opening it on the dashboard and copying its ID in the browser address bar. |
