# Get All Discounts with Big Cartel

Retrieves discounts from Big Cartel.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/[:account-id]/discounts`
- **Base URL:** `https://api.bigcartel.com`
- **Official documentation:** [Get All Discounts](https://developers.bigcartel.com/api/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account-id` | path | `number` | yes | The Big Cartel account ID. |
