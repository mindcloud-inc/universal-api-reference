# Get All Products with Big Cartel

Retrieves products from Big Cartel.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/[:account-id]/products`
- **Base URL:** `https://api.bigcartel.com`
- **Official documentation:** [Get All Products](https://developers.bigcartel.com/api/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account-id` | path | `number` | yes | The Big Cartel account ID. |
