# Get Regional Data with Bureau of Economic Analysis

Retrieves regional data from the Bureau of Economic Analysis.

## Endpoint

- **Method:** `GET`
- **Path:** `/data`
- **Base URL:** `https://apps.bea.gov/api`
- **Official documentation:** [Get Regional Data](https://apps.bea.gov/api/_pdf/bea_web_service_api_user_guide.pdf)
