# Get API Dataset Metadata with Bureau of Economic Analysis

Retrieves API dataset metadata from the Bureau of Economic Analysis.

## Endpoint

- **Method:** `GET`
- **Path:** `/data`
- **Base URL:** `https://apps.bea.gov/api`
- **Official documentation:** [Get API Dataset Metadata](https://apps.bea.gov/api/_pdf/bea_web_service_api_user_guide.pdf)
