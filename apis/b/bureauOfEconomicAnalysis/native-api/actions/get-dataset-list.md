# Get Dataset List with Bureau of Economic Analysis

Retrieves available datasets from the Bureau of Economic Analysis.

## Endpoint

- **Method:** `GET`
- **Path:** `/data`
- **Base URL:** `https://apps.bea.gov/api`
- **Official documentation:** [Get Dataset List](https://apps.bea.gov/api/_pdf/bea_web_service_api_user_guide.pdf)
