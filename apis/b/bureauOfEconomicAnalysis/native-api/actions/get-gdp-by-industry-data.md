# Get GDP by Industry Data with Bureau of Economic Analysis

Retrieves GDP by industry data from the Bureau of Economic Analysis.

## Endpoint

- **Method:** `GET`
- **Path:** `/data`
- **Base URL:** `https://apps.bea.gov/api`
- **Official documentation:** [Get GDP by Industry Data](https://apps.bea.gov/api/_pdf/bea_web_service_api_user_guide.pdf)
