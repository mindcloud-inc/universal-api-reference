# Get Browser List with BrowserStack

Retrieves available browsers and devices from BrowserStack Automate.

## Endpoint

- **Method:** `GET`
- **Path:** `/automate/browsers.json`
- **Base URL:** `https://api.browserstack.com`
- **Official documentation:** [Get Browser List](https://www.browserstack.com/docs/automate/api-reference/selenium/browser#get-browser-list)
