# Get Project Details with BrowserStack

Retrieves project details from BrowserStack Automate.

## Endpoint

- **Method:** `GET`
- **Path:** `/automate/projects/:project_id.json`
- **Base URL:** `https://api.browserstack.com`
- **Official documentation:** [Get Project Details](https://www.browserstack.com/docs/automate/api-reference/selenium/project#get-project-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | BrowserStack project ID from List Projects. |
