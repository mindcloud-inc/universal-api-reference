# Get Automate Plan Details with BrowserStack

Retrieves Automate plan details from BrowserStack.

## Endpoint

- **Method:** `GET`
- **Path:** `/automate/plan.json`
- **Base URL:** `https://api.browserstack.com`
- **Official documentation:** [Get Automate Plan Details](https://www.browserstack.com/docs/automate/api-reference/selenium/plan#get-plan-details)
