# List Uploaded Media Files with BrowserStack

Retrieves uploaded media files from BrowserStack Automate.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api-cloud.browserstack.com/automate/recent_media_files`
- **Base URL:** `https://api.browserstack.com`
- **Official documentation:** [List Uploaded Media Files](https://www.browserstack.com/docs/automate/api-reference/selenium/media#list-uploaded-media-files)
