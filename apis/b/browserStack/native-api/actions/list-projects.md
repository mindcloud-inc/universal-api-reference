# List Projects with BrowserStack

Retrieves project records from BrowserStack Automate.

## Endpoint

- **Method:** `GET`
- **Path:** `/automate/projects.json`
- **Base URL:** `https://api.browserstack.com`
- **Official documentation:** [List Projects](https://www.browserstack.com/docs/automate/api-reference/selenium/project#get-project-list)
