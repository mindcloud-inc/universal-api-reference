# Get Project Status Badge Key with BrowserStack

Retrieves a project status badge key from BrowserStack.

## Endpoint

- **Method:** `GET`
- **Path:** `/automate/projects/:project_id/badge_key`
- **Base URL:** `https://api.browserstack.com`
- **Official documentation:** [Get Project Status Badge Key](https://www.browserstack.com/docs/automate/api-reference/selenium/project#get-status-badge)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | BrowserStack project ID from List Projects. |
