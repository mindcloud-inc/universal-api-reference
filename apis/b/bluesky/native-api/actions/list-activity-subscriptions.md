# List Activity Subscriptions with Bluesky

Retrieves accounts the current Bluesky account subscribes to for notifications.

## Endpoint

- **Method:** `GET`
- **Path:** `/xrpc/app.bsky.notification.listActivitySubscriptions`
- **Base URL:** `{pdsUrl}`
- **Official documentation:** [List Activity Subscriptions](https://docs.bsky.app/docs/api/app-bsky-notification-list-activity-subscriptions)
