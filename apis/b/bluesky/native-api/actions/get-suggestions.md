# Get Suggestions with Bluesky

Retrieves suggested Bluesky accounts to follow.

## Endpoint

- **Method:** `GET`
- **Path:** `/xrpc/app.bsky.actor.getSuggestions`
- **Base URL:** `{pdsUrl}`
- **Official documentation:** [Get Suggestions](https://docs.bsky.app/docs/api/app-bsky-actor-get-suggestions)
