# Get Preferences with Bluesky

Retrieves the current account's private Bluesky preferences.

## Endpoint

- **Method:** `GET`
- **Path:** `/xrpc/app.bsky.actor.getPreferences`
- **Base URL:** `{pdsUrl}`
- **Official documentation:** [Get Preferences](https://docs.bsky.app/docs/api/app-bsky-actor-get-preferences)
