# Describe Server with Bluesky

Retrieves Bluesky server capabilities and account creation requirements.

## Endpoint

- **Method:** `GET`
- **Path:** `/xrpc/com.atproto.server.describeServer`
- **Base URL:** `{pdsUrl}`
- **Official documentation:** [Describe Server](https://docs.bsky.app/docs/api/com-atproto-server-describe-server)
