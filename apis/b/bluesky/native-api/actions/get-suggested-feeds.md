# Get Suggested Feeds with Bluesky

Retrieves suggested Bluesky feeds for the current account.

## Endpoint

- **Method:** `GET`
- **Path:** `/xrpc/app.bsky.feed.getSuggestedFeeds`
- **Base URL:** `{pdsUrl}`
- **Official documentation:** [Get Suggested Feeds](https://docs.bsky.app/docs/api/app-bsky-feed-get-suggested-feeds)
