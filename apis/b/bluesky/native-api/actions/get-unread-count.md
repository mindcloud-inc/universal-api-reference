# Get Unread Count with Bluesky

Retrieves the current Bluesky unread notification count.

## Endpoint

- **Method:** `GET`
- **Path:** `/xrpc/app.bsky.notification.getUnreadCount`
- **Base URL:** `{pdsUrl}`
- **Official documentation:** [Get Unread Count](https://docs.bsky.app/docs/api/app-bsky-notification-get-unread-count)
