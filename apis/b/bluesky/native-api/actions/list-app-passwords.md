# List App Passwords with Bluesky

Retrieves app passwords for the current Bluesky account.

## Endpoint

- **Method:** `GET`
- **Path:** `/xrpc/com.atproto.server.listAppPasswords`
- **Base URL:** `{pdsUrl}`
- **Official documentation:** [List App Passwords](https://docs.bsky.app/docs/api/com-atproto-server-list-app-passwords)
