# Create Subscriber with Bento Now

Creates a new subscriber in Bento Now.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/fetch/subscribers`
- **Base URL:** `https://app.bentonow.com/api`
- **Official documentation:** [Create Subscriber](https://bentonow.com/docs/subscribers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriber.email` | body | `string` | yes |
