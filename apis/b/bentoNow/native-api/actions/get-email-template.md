# Get Email Template with Bento Now

Retrieves an email template with stats from Bento Now.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/fetch/emails/templates/:id`
- **Base URL:** `https://app.bentonow.com/api`
- **Official documentation:** [Get Email Template](https://bentonow.com/docs/email_templates_api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
