# Create Field with Bento Now

Creates a custom profile field in Bento Now.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/fetch/fields`
- **Base URL:** `https://app.bentonow.com/api`
- **Official documentation:** [Create Field](https://bentonow.com/docs/fields)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | body | `string` | yes |
