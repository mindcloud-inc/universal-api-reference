# Get Workflows with Bento Now

Retrieves workflows and email templates from Bento Now.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/fetch/workflows`
- **Base URL:** `https://app.bentonow.com/api`
- **Official documentation:** [Get Workflows](https://bentonow.com/docs/workflows_api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
