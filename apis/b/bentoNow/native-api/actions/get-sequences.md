# Get Sequences with Bento Now

Retrieves sequences and email templates from Bento Now.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/fetch/sequences`
- **Base URL:** `https://app.bentonow.com/api`
- **Official documentation:** [Get Sequences](https://bentonow.com/docs/sequences_api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
