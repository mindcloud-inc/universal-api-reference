# Get Broadcasts with Bento Now

Retrieves broadcast history and metadata from Bento Now.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/fetch/broadcasts`
- **Base URL:** `https://app.bentonow.com/api`
- **Official documentation:** [Get Broadcasts](https://bentonow.com/docs/broadcasts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
