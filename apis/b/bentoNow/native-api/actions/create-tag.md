# Create Tag with Bento Now

Creates a custom tag in Bento Now.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/fetch/tags`
- **Base URL:** `https://app.bentonow.com/api`
- **Official documentation:** [Create Tag](https://bentonow.com/docs/tags_api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
