# Get Segment Stats with Bento Now

Retrieves subscriber statistics for a Bento Now segment.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/stats/segment`
- **Base URL:** `https://app.bentonow.com/api`
- **Official documentation:** [Get Segment Stats](https://bentonow.com/docs/stats)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `segment_id` | query | `string` | yes |
