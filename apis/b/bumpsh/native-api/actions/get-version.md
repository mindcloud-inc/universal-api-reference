# Get Version with Bump.sh

Retrieves a documentation version from Bump.sh.

## Endpoint

- **Method:** `GET`
- **Path:** `versions/:version_id`
- **Base URL:** `https://bump.sh/api/v1`
- **Official documentation:** [Get Version](https://developers.bump.sh/source.json#/paths/~1versions~1{version_id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `version_id` | path | `string` | yes | Version ID. |
