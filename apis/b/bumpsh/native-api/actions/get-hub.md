# Get Hub with Bump.sh

Retrieves a hub from Bump.sh.

## Endpoint

- **Method:** `GET`
- **Path:** `hubs/:hub_id_or_slug`
- **Base URL:** `https://bump.sh/api/v1`
- **Official documentation:** [Get Hub](https://developers.bump.sh/source.json#/paths/~1hubs~1{hub_id_or_slug}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hub_id_or_slug` | path | `string` | yes | Hub ID or slug. |
