# List Hubs with Bump.sh

Retrieves hubs from Bump.sh.

## Endpoint

- **Method:** `GET`
- **Path:** `hubs`
- **Base URL:** `https://bump.sh/api/v1`
- **Official documentation:** [List Hubs](https://developers.bump.sh/operation/operation-listhubs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formats` | query | `string` | no | Optional response format selector from the official docs. |
