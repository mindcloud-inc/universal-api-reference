# Get Order with BigCommerce (B2B)

## Endpoint

- **Method:** `GET`
- **Path:** `https://api-b2b.bigcommerce.com/api/v3/io/orders/:orderId`
- **Base URL:** `https://api-b2b.bigcommerce.com/api/v3/io/`
- **Official documentation:** [Get Order](https://developer.bigcommerce.com/b2b-edition/apis/rest-management/invoice-management/invoice#get-invoice-detail)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orderId` | path | `string` | yes |
