# Get Company Payment Terms with BigCommerce (B2B)

## Endpoint

- **Method:** `GET`
- **Path:** `companies/:companyId/payment-terms`
- **Base URL:** `https://api-b2b.bigcommerce.com/api/v3/io/`
- **Official documentation:** [Get Company Payment Terms](https://developer.bigcommerce.com/b2b-edition/apis/rest-management/payment#update-company-credit)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `string` | yes |
