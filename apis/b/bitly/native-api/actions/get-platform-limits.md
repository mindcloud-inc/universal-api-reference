# Get Platform Limits with Bitly

Retrieves platform limits from your Bitly account.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/platform_limits`
- **Base URL:** `https://api-ssl.bitly.com/v4`
- **Official documentation:** [Get Platform Limits](https://dev.bitly.com/api-reference#getPlatformLimits)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `path` | query | `string` | no | Filter platform limits to one API path. |
