# Get Bitlink with Bitly

Retrieves a bitlink from your Bitly account.

## Endpoint

- **Method:** `GET`
- **Path:** `/bitlinks/:bitlink`
- **Base URL:** `https://api-ssl.bitly.com/v4`
- **Official documentation:** [Get Bitlink](https://dev.bitly.com/api-reference#getBitlink)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bitlink` | path | `string` | yes | The Bitly bitlink to retrieve. |
