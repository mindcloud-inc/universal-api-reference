# Get QR Code with Bitly

Retrieves a QR code from Bitly.

## Endpoint

- **Method:** `GET`
- **Path:** `/qr-codes/:qrcode_id`
- **Base URL:** `https://api-ssl.bitly.com/v4`
- **Official documentation:** [Get QR Code](https://dev.bitly.com/api-reference#getQRCodeByIdPublic)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `qrcode_id` | path | `string` | yes |
