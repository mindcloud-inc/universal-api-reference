# Get Group with Bitly

Retrieves a group from your Bitly account.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:group_guid`
- **Base URL:** `https://api-ssl.bitly.com/v4`
- **Official documentation:** [Get Group](https://dev.bitly.com/api-reference#getGroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_guid` | path | `string` | yes | The Bitly group GUID. |
