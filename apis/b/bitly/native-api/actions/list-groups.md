# List Groups with Bitly

Retrieves groups from your Bitly account.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://api-ssl.bitly.com/v4`
- **Official documentation:** [List Groups](https://dev.bitly.com/api-reference#getGroups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_guid` | query | `string` | no | Filter results to one Bitly organization GUID. |
