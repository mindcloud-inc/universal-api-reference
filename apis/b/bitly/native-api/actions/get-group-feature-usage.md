# Get Group Feature Usage with Bitly

Retrieves feature usage for a Bitly group.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:group_guid/feature_usage`
- **Base URL:** `https://api-ssl.bitly.com/v4`
- **Official documentation:** [Get Group Feature Usage](https://dev.bitly.com/api-reference#getGroupFeatureUsage)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_guid` | path | `string` | yes |
