# Delete Bitlink with Bitly

Deletes an unedited hash bitlink from Bitly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bitlinks/:bitlink`
- **Base URL:** `https://api-ssl.bitly.com/v4`
- **Official documentation:** [Delete Bitlink](https://dev.bitly.com/api-reference#deleteBitlink)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bitlink` | path | `string` | yes | The Bitly bitlink to delete. |
