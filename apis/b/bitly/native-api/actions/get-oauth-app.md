# Get OAuth App with Bitly

Retrieves an OAuth app from Bitly.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:client_id`
- **Base URL:** `https://api-ssl.bitly.com/v4`
- **Official documentation:** [Get OAuth App](https://dev.bitly.com/api-reference#getOAuthApp)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `client_id` | path | `string` | yes |
