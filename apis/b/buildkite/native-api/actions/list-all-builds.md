# List All Builds with Buildkite

Retrieves all builds from Buildkite.

## Endpoint

- **Method:** `GET`
- **Path:** `/builds`
- **Base URL:** `https://api.buildkite.com/v2`
- **Official documentation:** [List All Builds](https://buildkite.com/docs/apis/rest-api/builds)

## Capabilities

This operation supports [pagination](../README.md#pagination).
