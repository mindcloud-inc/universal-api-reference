# List Organizations with Buildkite

Retrieves organizations from Buildkite.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations`
- **Base URL:** `https://api.buildkite.com/v2`
- **Official documentation:** [List Organizations](https://buildkite.com/docs/apis/rest-api/organizations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
