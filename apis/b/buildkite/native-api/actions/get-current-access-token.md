# Get Current Access Token with Buildkite

Retrieves the current access token from Buildkite.

## Endpoint

- **Method:** `GET`
- **Path:** `/access-token`
- **Base URL:** `https://api.buildkite.com/v2`
- **Official documentation:** [Get Current Access Token](https://buildkite.com/docs/apis/rest-api/access-token)
