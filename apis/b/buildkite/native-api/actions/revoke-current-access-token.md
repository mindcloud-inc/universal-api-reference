# Revoke Current Access Token with Buildkite

Revokes the current access token in Buildkite.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/access-token`
- **Base URL:** `https://api.buildkite.com/v2`
- **Official documentation:** [Revoke Current Access Token](https://buildkite.com/docs/apis/rest-api/access-token)
