# Get Download Artifact Link with Bitbucket

Retrieves a download artifact link from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/downloads/:filename`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Download Artifact Link](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-downloads/)
