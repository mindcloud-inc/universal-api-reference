# Get Snippet Comment with Bitbucket

Retrieves a snippet comment from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/snippets/:workspace/:encoded_id/comments/:comment_id`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Snippet Comment](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-snippets/)
