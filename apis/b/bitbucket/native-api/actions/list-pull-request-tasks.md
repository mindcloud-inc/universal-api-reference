# List Pull Request Tasks with Bitbucket

Retrieves pull request tasks from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/pullrequests/:pull_request_id/tasks`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [List Pull Request Tasks](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-pullrequests/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
