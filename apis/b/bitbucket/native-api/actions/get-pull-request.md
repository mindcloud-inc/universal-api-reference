# Get Pull Request with Bitbucket

Retrieves a pull request from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/pullrequests/:pull_request_id`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Pull Request](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-pullrequests/)
