# List Repository Deploy Keys with Bitbucket

Retrieves repository deploy keys from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/deploy-keys`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [List Repository Deploy Keys](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-ssh/)
