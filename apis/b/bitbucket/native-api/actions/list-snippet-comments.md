# List Snippet Comments with Bitbucket

Retrieves snippet comments from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/snippets/:workspace/:encoded_id/comments`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [List Snippet Comments](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-snippets/)
