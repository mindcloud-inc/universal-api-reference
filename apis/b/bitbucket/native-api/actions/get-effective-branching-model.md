# Get Effective Branching Model with Bitbucket

Retrieves the effective branching model from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/effective-branching-model`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Effective Branching Model](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-branching-model/)
