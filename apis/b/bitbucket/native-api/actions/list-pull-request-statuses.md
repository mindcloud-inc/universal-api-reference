# List Pull Request Statuses with Bitbucket

Retrieves pull request commit statuses from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/pullrequests/:pull_request_id/statuses`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [List Pull Request Statuses](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-pullrequests/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
