# Get Snippet with Bitbucket

Retrieves a snippet from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/snippets/:workspace/:encoded_id`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Snippet](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-snippets/)
