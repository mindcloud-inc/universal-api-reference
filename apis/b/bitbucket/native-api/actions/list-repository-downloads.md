# List Repository Downloads with Bitbucket

Retrieves repository download artifacts from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/downloads`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [List Repository Downloads](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-downloads/)
