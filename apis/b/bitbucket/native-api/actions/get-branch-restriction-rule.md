# Get Branch Restriction Rule with Bitbucket

Retrieves a branch restriction rule from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/branch-restrictions/:id`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Branch Restriction Rule](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-branch-restrictions/)
