# Get Repository Branching Model with Bitbucket

Retrieves a repository branching model from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/branching-model`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Repository Branching Model](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-branching-model/)
