# List Branches with Bitbucket

Retrieves open branches from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/refs/branches`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [List Branches](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-refs/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
