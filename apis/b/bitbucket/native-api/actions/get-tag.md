# Get Tag with Bitbucket

Retrieves a tag from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/refs/tags/:name`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Tag](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-refs/)
