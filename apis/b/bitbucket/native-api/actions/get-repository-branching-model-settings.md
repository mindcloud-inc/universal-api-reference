# Get Repository Branching Model Settings with Bitbucket

Retrieves repository branching model settings from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/branching-model/settings`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Repository Branching Model Settings](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-branching-model/)
