# Get Branch with Bitbucket

Retrieves a branch from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/refs/branches/:name`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Branch](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-refs/)
