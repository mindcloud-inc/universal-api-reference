# Get Commit Comment with Bitbucket

Retrieves a commit comment from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/commit/:commit/comments/:comment_id`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Commit Comment](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-commits/)
