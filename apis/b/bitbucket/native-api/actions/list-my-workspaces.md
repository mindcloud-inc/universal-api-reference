# List My Workspaces with Bitbucket

Retrieves your Bitbucket workspaces.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/workspaces`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [List My Workspaces](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-workspaces/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
