# List Snippet Watchers with Bitbucket

Retrieves snippet watchers from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/snippets/:workspace/:encoded_id/watchers`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [List Snippet Watchers](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-snippets/)
