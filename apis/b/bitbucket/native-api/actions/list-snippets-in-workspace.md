# List Snippets in Workspace with Bitbucket

Retrieves snippets from a Bitbucket workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/snippets/:workspace`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [List Snippets in Workspace](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-snippets/)
