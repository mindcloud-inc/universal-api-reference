# List Branch Restrictions with Bitbucket

Retrieves branch restrictions from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/branch-restrictions`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [List Branch Restrictions](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-branch-restrictions/)
