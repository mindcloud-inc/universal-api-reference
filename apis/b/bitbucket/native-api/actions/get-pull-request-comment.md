# Get Pull Request Comment with Bitbucket

Retrieves a pull request comment from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/pullrequests/:pull_request_id/comments/:comment_id`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Pull Request Comment](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-pullrequests/)
