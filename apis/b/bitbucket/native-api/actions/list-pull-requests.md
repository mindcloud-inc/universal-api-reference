# List Pull Requests with Bitbucket

Retrieves pull requests from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/pullrequests`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [List Pull Requests](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-pullrequests/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
