# Get Pull Request Task with Bitbucket

Retrieves a pull request task from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/pullrequests/:pull_request_id/tasks/:task_id`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Pull Request Task](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-pullrequests/)
