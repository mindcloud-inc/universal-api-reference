# Check Snippet Watching with Bitbucket

Retrieves current snippet watch status from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/snippets/:workspace/:encoded_id/watch`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Check Snippet Watching](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-snippets/)
