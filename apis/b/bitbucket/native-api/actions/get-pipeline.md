# Get Pipeline with Bitbucket

Retrieves a pipeline from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/pipelines/:pipeline_uuid`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Pipeline](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-pipelines/)
