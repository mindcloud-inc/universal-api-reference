# Get Repository Deploy Key with Bitbucket

Retrieves a repository deploy key from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/deploy-keys/:key_id`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [Get Repository Deploy Key](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-ssh/)
