# List Pipelines with Bitbucket

Retrieves pipelines from Bitbucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/repositories/:workspace/:repo_slug/pipelines`
- **Base URL:** `https://api.bitbucket.org/2.0`
- **Official documentation:** [List Pipelines](https://developer.atlassian.com/cloud/bitbucket/rest/api-group-pipelines/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
