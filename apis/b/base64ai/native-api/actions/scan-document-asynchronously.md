# Scan Document Asynchronously with Base64.ai

Starts an asynchronous document scan in Base64.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/scan/async`
- **Base URL:** `https://base64.ai`
- **Official documentation:** [Scan Document Asynchronously](https://apidoc.base64.ai/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Public URL of the document to scan asynchronously. |
