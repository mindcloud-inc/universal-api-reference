# Delete Flow with Base64.ai

Deletes an existing flow from Base64.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/flow/:flowId`
- **Base URL:** `https://base64.ai`
- **Official documentation:** [Delete Flow](https://apidoc.base64.ai/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `flowId` | path | `string` | yes | Flow identifier to delete. |
