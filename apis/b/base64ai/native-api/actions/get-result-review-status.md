# Get Result Review Status with Base64.ai

Retrieves a result and review status from Base64.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/result/:resultUuid`
- **Base URL:** `https://base64.ai`
- **Official documentation:** [Get Result Review Status](https://apidoc.base64.ai/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resultUuid` | path | `string` | yes | Base64.ai result UUID. |
