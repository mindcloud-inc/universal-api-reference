# List Product Customer Prices with B2B Wave

Retrieves customer-specific product prices from B2B Wave.

## Endpoint

- **Method:** `GET`
- **Path:** `/product_customer_prices`
- **Base URL:** `{storeUrl}/api`
- **Official documentation:** [List Product Customer Prices](https://docs.b2bwave.com/article/107-product-customer-prices)
