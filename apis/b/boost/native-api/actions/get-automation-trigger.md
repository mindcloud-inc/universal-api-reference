# Get Automation Trigger with Boost

Retrieves an automation trigger from Boost by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/automatization/trigger/{triggerId}`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [Get Automation Trigger](https://apidoc.boost.space/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `triggerId` | path | `number` | yes | Boost.space automation trigger ID. |
