# List Dashboards with Boost

Retrieves dashboard records available in Boost.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboard`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [List Dashboards](https://apidoc.boost.space/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
