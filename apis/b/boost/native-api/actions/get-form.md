# Get Form with Boost

Retrieves a form from Boost by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/form/{formId}`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [Get Form](https://apidoc.boost.space/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `number` | yes | Boost.space form ID. |
