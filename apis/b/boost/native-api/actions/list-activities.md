# List Activities with Boost

Retrieves activity types available in Boost.

## Endpoint

- **Method:** `GET`
- **Path:** `/activities`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [List Activities](https://apidoc.boost.space/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
