# Get User with Boost

Retrieves a user from Boost by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/{userId}`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [Get User](https://apidoc.boost.space/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | Boost.space user ID. |
