# Get File with Boost

Retrieves a file record from Boost by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/file/{fileId}`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [Get File](https://apidoc.boost.space/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `number` | yes | Boost.space file ID. |
