# Get Space with Boost

Retrieves a space from Boost by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/space/{spaceId}`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [Get Space](https://apidoc.boost.space/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `number` | yes | Boost.space space ID. |
