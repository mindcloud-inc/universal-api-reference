# Get Automation Action with Boost

Retrieves an automation action from Boost by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/automatization/action/{actionId}`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [Get Automation Action](https://apidoc.boost.space/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `actionId` | path | `number` | yes | Boost.space automation action ID. |
