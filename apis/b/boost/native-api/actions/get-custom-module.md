# Get Custom Module with Boost

Retrieves a custom module from Boost by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-module/{customModuleId}`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [Get Custom Module](https://apidoc.boost.space/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customModuleId` | path | `number` | yes | Boost.space custom module ID. |
