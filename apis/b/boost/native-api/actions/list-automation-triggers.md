# List Automation Triggers with Boost

Retrieves automation trigger records from Boost.

## Endpoint

- **Method:** `GET`
- **Path:** `/automatization/trigger`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [List Automation Triggers](https://apidoc.boost.space/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
