# List Forms with Boost

Retrieves form records available in Boost.

## Endpoint

- **Method:** `GET`
- **Path:** `/form`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [List Forms](https://apidoc.boost.space/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
