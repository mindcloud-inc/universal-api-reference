# Get AppFlow with Boost

Retrieves an appflow from Boost by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/appflow/{appflowId}`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [Get AppFlow](https://apidoc.boost.space/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appflowId` | path | `number` | yes | Boost.space AppFlow ID. |
