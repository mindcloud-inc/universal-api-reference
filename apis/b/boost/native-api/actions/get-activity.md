# Get Activity with Boost

Retrieves an activity type from Boost by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/activities/{activityId}`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [Get Activity](https://apidoc.boost.space/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activityId` | path | `number` | yes | Boost.space activity ID. |
