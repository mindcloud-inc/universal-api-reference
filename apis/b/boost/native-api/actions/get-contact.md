# Get Contact with Boost

Retrieves a contact from Boost by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/{contactId}`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [Get Contact](https://apidoc.boost.space/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | yes | Boost.space contact ID. |
