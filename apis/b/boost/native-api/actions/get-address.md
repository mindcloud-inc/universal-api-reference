# Get Address with Boost

Retrieves an address from Boost by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/address/{addressId}`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [Get Address](https://apidoc.boost.space/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `addressId` | path | `number` | yes | Boost.space address ID. |
