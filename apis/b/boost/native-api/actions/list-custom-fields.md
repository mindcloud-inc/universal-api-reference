# List Custom Fields with Boost

Retrieves custom field records from Boost.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-field`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [List Custom Fields](https://apidoc.boost.space/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
