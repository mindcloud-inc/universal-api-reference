# List Automation Actions with Boost

Retrieves automation action records from Boost.

## Endpoint

- **Method:** `GET`
- **Path:** `/automatization/action`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [List Automation Actions](https://apidoc.boost.space/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
