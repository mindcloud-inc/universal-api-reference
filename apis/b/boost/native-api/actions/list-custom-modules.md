# List Custom Modules with Boost

Retrieves custom module records from Boost.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-module`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [List Custom Modules](https://apidoc.boost.space/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
