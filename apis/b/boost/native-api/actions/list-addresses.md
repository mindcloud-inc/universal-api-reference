# List Addresses with Boost

Retrieves address records available in Boost.

## Endpoint

- **Method:** `GET`
- **Path:** `/address`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [List Addresses](https://apidoc.boost.space/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
