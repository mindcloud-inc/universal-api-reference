# List AppFlows with Boost

Retrieves appflow records available in Boost.

## Endpoint

- **Method:** `GET`
- **Path:** `/appflow`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [List AppFlows](https://apidoc.boost.space/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
