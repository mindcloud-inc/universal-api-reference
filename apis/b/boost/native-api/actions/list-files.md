# List Files with Boost

Retrieves file records available in Boost.

## Endpoint

- **Method:** `GET`
- **Path:** `/file/`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [List Files](https://apidoc.boost.space/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
