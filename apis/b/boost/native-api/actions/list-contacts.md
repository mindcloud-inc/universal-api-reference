# List Contacts with Boost

Retrieves contact records available in Boost.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [List Contacts](https://apidoc.boost.space/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
