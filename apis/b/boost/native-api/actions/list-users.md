# List Users with Boost

Finds users in Boost by search criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/user`
- **Base URL:** `https://{systemKey}.boost.space/api`
- **Official documentation:** [List Users](https://apidoc.boost.space/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
