# Request Magic Link From And To Email with BuildChatbot

Requests a magic link between email addresses in BuildChatbot.

## Endpoint

- **Method:** `POST`
- **Path:** `/login_with_magic_link_from_and_to_email`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Request Magic Link From And To Email](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#2781b6a8-c8d0-47fa-9b2f-bbc6dcbd3ff0)
