# Get Coupon Discount Percent with BuildChatbot

Retrieves a coupon discount percent from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/checkout/get/coupon/discount_percent/`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Get Coupon Discount Percent](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#27081964-7db7-421f-89b2-ada9a38d50ea)
