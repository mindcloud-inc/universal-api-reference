# Request Magic Link Login with BuildChatbot

Requests a magic link login from BuildChatbot.

## Endpoint

- **Method:** `POST`
- **Path:** `/login_with_magic_link`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Request Magic Link Login](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#cbe7bef2-58c8-4e61-beec-4cbfb2d30bc0)
