# List Recent Chat History with BuildChatbot

Retrieves recent chat history from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/bot/chat-history/recent/`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [List Recent Chat History](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#77ffafb3-2474-4a73-9592-28320bce20f5)
