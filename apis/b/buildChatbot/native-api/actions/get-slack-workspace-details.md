# Get Slack Workspace Details with BuildChatbot

Retrieves Slack workspace details from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/slack/workspace_details/`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Get Slack Workspace Details](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#3e30595f-a6fc-4771-bfd4-234506af006f)
