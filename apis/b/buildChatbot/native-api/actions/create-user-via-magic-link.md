# Create User Via Magic Link with BuildChatbot

Creates a user in BuildChatbot via magic link.

## Endpoint

- **Method:** `POST`
- **Path:** `/user/create/magic_link`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Create User Via Magic Link](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#8691df55-0a0b-43b9-8318-aa453006ec5e)
