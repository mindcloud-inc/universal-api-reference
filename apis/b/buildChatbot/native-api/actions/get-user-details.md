# Get User Details with BuildChatbot

Retrieves user account details from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Get User Details](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#507e5bce-d38c-4745-a315-a17c6bcb7982)
