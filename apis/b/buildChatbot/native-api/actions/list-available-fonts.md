# List Available Fonts with BuildChatbot

Retrieves available font options from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/bot/fonts`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [List Available Fonts](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#a71ac1cf-135e-4961-a313-d6c597983f84)
