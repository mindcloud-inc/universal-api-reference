# List Subscription Plans with BuildChatbot

Retrieves subscription plan options from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/subcriptionplans/monthly/rupee/`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [List Subscription Plans](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#b5a68f08-118b-406f-94e3-221a4e248f5b)
