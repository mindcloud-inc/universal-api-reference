# Validate Selected Subscription Plan with BuildChatbot

Validates a selected subscription plan in BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/checkout/warning_for_sbscription_plan_upgrade/`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
