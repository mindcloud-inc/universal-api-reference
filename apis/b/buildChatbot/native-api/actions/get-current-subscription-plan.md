# Get Current Subscription Plan with BuildChatbot

Retrieves the current subscription plan from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/current_subscription_plan`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Get Current Subscription Plan](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#a6e3c554-4ad5-459e-baa0-264efc7d983a)
