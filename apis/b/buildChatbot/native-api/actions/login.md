# Login with BuildChatbot

Creates a login session in BuildChatbot.

## Endpoint

- **Method:** `POST`
- **Path:** `/login`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Login](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#45b1b734-a65b-4975-ba30-9ce5646c8893)
