# Get Subscription Plan Details with BuildChatbot

Retrieves subscription plan details from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/checkout/subscription_plan_details/`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Get Subscription Plan Details](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#a2e80a10-465f-488e-844e-d772a9f31f2d)
