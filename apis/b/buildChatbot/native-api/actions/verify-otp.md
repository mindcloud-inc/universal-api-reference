# Verify OTP with BuildChatbot

Verifies a one-time password in BuildChatbot.

## Endpoint

- **Method:** `POST`
- **Path:** `/user/verify_otp`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Verify OTP](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#febd1d1b-8152-4db9-8111-c742271298a6)
