# Logout with BuildChatbot

Deletes the current session from BuildChatbot.

## Endpoint

- **Method:** `POST`
- **Path:** `/logout`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Logout](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#569c56b2-2ce6-4503-8424-9264ff3c57e7)
