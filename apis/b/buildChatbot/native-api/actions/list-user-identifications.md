# List User Identifications with BuildChatbot

Retrieves user identification records from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/zapier/useridentification/list`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [List User Identifications](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#71f8b43a-964c-4fa0-9a87-74632a16b446)
