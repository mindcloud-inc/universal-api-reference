# Forgot Password with BuildChatbot

Requests a password reset from BuildChatbot.

## Endpoint

- **Method:** `POST`
- **Path:** `/forgot_password/`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Forgot Password](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#3a8a2ca3-d5e4-4d25-8a63-d2b2def4860e)
