# Get Tenant Subscription Details with BuildChatbot

Retrieves tenant subscription details from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/tenant/{{tenantId}}/subscription_details`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Get Tenant Subscription Details](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#14af84c7-5388-4eb8-ab54-936093e9f8e1)
