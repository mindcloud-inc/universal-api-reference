# Get Integrations Enable Detail with BuildChatbot

Retrieves integrations enable details from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations/enable_details`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Get Integrations Enable Detail](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#180f9ce2-17b7-4f6c-9ad2-df29f0a4b94f)
