# List Tenant Bots with BuildChatbot

Retrieves tenant bot records from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/bots`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [List Tenant Bots](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#cba9b7f0-980b-4daf-8d17-f07ca0997a49)
