# List User Bots with BuildChatbot

Retrieves user bot records from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/get_all_user_bots/`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [List User Bots](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#f4e7a568-2c20-480f-b306-caa7333be04f)
