# Get User Profile Details with BuildChatbot

Retrieves user profile details from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/profile_details/`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Get User Profile Details](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#e48aead1-ce9d-4fb5-8554-a557d3db9d8e)
