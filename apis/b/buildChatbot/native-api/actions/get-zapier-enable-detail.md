# Get Zapier Enable Detail with BuildChatbot

Retrieves Zapier enable details from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/zapier/enable_details`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Get Zapier Enable Detail](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#df3ffd2f-3ee7-4ddb-903b-fd8c99aae891)
