# Get Tenant Metrics with BuildChatbot

Retrieves tenant usage metrics from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/get_all_tenant_metrics`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Get Tenant Metrics](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#b8919ba4-8fc3-47c9-a106-f77bd7f4758a)
