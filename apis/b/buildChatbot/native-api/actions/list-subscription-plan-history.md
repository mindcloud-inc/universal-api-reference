# List Subscription Plan History with BuildChatbot

Retrieves subscription plan history from BuildChatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/subscription_plan_history`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [List Subscription Plan History](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#814dd9ed-cb44-410a-a167-dbab7fb33f57)
