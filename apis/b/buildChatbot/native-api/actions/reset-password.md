# Reset Password with BuildChatbot

Updates a user password in BuildChatbot.

## Endpoint

- **Method:** `POST`
- **Path:** `/password/reset//`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Reset Password](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#b77c417f-873a-4285-bebb-6da9f314c658)
