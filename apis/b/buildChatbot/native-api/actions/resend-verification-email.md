# Resend Verification Email with BuildChatbot

Resends a verification email from BuildChatbot.

## Endpoint

- **Method:** `POST`
- **Path:** `/user/resend_verification_link/`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Resend Verification Email](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#a55531a5-e5ff-41c5-9f37-67b502f4e6ab)
