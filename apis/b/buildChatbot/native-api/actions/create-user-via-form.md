# Create User Via Form with BuildChatbot

Creates a user in BuildChatbot via form signup.

## Endpoint

- **Method:** `POST`
- **Path:** `/user/create/form`
- **Base URL:** `https://api.buildchatbot.ai/api/v1`
- **Official documentation:** [Create User Via Form](https://documenter.getpostman.com/view/27680478/2s9YR6baAb#3758bf4a-67e9-412e-a2e8-63f57d152f33)
