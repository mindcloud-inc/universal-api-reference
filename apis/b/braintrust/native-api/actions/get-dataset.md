# Get Dataset with Braintrust

Retrieves a dataset from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/dataset/:dataset_id`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [Get Dataset](https://braintrust.dev/docs/api-reference/datasets/get-dataset.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataset_id` | path | `string` | yes | Dataset id. |
