# List Functions with Braintrust

Retrieves functions from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/function`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [List Functions](https://braintrust.dev/docs/api-reference/functions/list-functions.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
