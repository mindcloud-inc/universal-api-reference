# List Datasets with Braintrust

Retrieves datasets from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/dataset`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [List Datasets](https://braintrust.dev/docs/api-reference/datasets/list-datasets.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
