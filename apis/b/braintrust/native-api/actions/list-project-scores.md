# List Project Scores with Braintrust

Retrieves project scores from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/project_score`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [List Project Scores](https://braintrust.dev/docs/api-reference/projectscores/list-project_scores.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
