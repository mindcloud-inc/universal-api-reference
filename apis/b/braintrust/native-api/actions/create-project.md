# Create Project with Braintrust

Creates a new project in Braintrust.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/project`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [Create Project](https://www.braintrust.dev/docs/api-reference/projects/create-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Project name. |
