# Get Prompt with Braintrust

Retrieves a prompt from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/prompt/:prompt_id`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [Get Prompt](https://braintrust.dev/docs/api-reference/prompts/get-prompt.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `prompt_id` | path | `string` | yes | Prompt id. |
