# Fetch Experiment with Braintrust

Retrieves events from an experiment in Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/experiment/:experiment_id/fetch`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [Fetch Experiment](https://braintrust.dev/docs/api-reference/experiments/fetch-experiment-get-form.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `experiment_id` | path | `string` | yes | Experiment id. |
