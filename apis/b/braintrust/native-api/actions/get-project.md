# Get Project with Braintrust

Retrieves a project from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/project/:project_id`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [Get Project](https://braintrust.dev/docs/api-reference/projects/get-project.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id. |
