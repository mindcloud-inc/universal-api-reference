# List Projects with Braintrust

Retrieves projects from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/project`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [List Projects](https://braintrust.dev/docs/api-reference/projects/list-projects.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
