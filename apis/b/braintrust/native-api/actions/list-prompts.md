# List Prompts with Braintrust

Retrieves prompts from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/prompt`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [List Prompts](https://braintrust.dev/docs/api-reference/prompts/list-prompts.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
