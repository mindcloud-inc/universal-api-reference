# Get Function with Braintrust

Retrieves a function from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/function/:function_id`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [Get Function](https://braintrust.dev/docs/api-reference/functions/get-function.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `function_id` | path | `string` | yes | Function id. |
