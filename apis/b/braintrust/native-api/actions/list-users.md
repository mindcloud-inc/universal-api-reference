# List Users with Braintrust

Retrieves users from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/user`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [List Users](https://braintrust.dev/docs/api-reference/users/list-users.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
