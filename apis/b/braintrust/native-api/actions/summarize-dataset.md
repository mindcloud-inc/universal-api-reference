# Summarize Dataset with Braintrust

Retrieves a summary of a dataset in Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/dataset/:dataset_id/summarize`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [Summarize Dataset](https://braintrust.dev/docs/api-reference/datasets/summarize-dataset.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataset_id` | path | `string` | yes | Dataset id. |
