# Get Experiment with Braintrust

Retrieves an experiment from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/experiment/:experiment_id`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [Get Experiment](https://braintrust.dev/docs/api-reference/experiments/get-experiment.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `experiment_id` | path | `string` | yes | Experiment id. |
