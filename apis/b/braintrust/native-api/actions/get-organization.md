# Get Organization with Braintrust

Retrieves an organization from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/organization/:organization_id`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [Get Organization](https://braintrust.dev/docs/api-reference/organizations/get-organization.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `string` | yes | Organization id. |
