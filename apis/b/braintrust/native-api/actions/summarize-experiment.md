# Summarize Experiment with Braintrust

Retrieves a summary of an experiment in Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/experiment/:experiment_id/summarize`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [Summarize Experiment](https://braintrust.dev/docs/api-reference/experiments/summarize-experiment.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `experiment_id` | path | `string` | yes | Experiment id. |
