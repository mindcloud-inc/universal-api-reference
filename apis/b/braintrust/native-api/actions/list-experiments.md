# List Experiments with Braintrust

Retrieves experiments from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/experiment`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [List Experiments](https://braintrust.dev/docs/api-reference/experiments/list-experiments.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
