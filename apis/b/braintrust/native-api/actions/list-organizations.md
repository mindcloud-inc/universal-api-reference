# List Organizations with Braintrust

Retrieves organizations from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/organization`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [List Organizations](https://www.braintrust.dev/docs/api-reference/organizations/list-organizations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
