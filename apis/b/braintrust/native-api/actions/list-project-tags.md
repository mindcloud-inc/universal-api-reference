# List Project Tags with Braintrust

Retrieves project tags from Braintrust.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/project_tag`
- **Base URL:** `https://api.braintrust.dev`
- **Official documentation:** [List Project Tags](https://braintrust.dev/docs/api-reference/projecttags/list-project_tags.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
