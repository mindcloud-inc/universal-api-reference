# List All Tables with Baserow

Retrieves all accessible tables from Baserow.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/database/tables/all-tables/`
- **Base URL:** `https://api.baserow.io`
- **Official documentation:** [List All Tables](https://api.baserow.io/api/redoc/#operation/list_all_token_tables)
