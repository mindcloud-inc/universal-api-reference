# Connect Airbnb Listing to Existing Room with Beds24

Connects an Airbnb listing to an existing Beds24 room.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/airbnb`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Connect Airbnb Listing to Existing Room](https://wiki.beds24.com/index.php/API_V2.0)
