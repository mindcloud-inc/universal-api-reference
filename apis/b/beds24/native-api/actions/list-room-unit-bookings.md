# List Room Unit Bookings with Beds24

Retrieves unit booking dates from Beds24.

## Endpoint

- **Method:** `GET`
- **Path:** `/inventory/rooms/unitBookings`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [List Room Unit Bookings](https://wiki.beds24.com/index.php/API_V2.0)
