# Get Access Token from Invite Code with Beds24

Retrieves access and refresh tokens from a Beds24 invite code.

## Endpoint

- **Method:** `GET`
- **Path:** `/authentication/setup`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Get Access Token from Invite Code](https://wiki.beds24.com/index.php/API_V2.0)
