# Create Stripe Checkout Session with Beds24

Creates a Stripe Checkout session in Beds24.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/stripe`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Create Stripe Checkout Session](https://wiki.beds24.com/index.php/API_V2.0)
