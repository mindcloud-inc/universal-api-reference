# List Channel Settings with Beds24

Retrieves channel settings from Beds24.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels/settings`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [List Channel Settings](https://wiki.beds24.com/index.php/API_V2.0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | query | `number` | yes | Beds24 property ID whose channel settings should be returned. |
