# Charge Stripe Payment Method with Beds24

Creates a Stripe charge from a payment method in Beds24.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/stripe`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Charge Stripe Payment Method](https://wiki.beds24.com/index.php/API_V2.0)
