# Create or Update Fixed Prices with Beds24

Creates or updates fixed prices in Beds24.

## Endpoint

- **Method:** `POST`
- **Path:** `/inventory/fixedPrices`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Create or Update Fixed Prices](https://wiki.beds24.com/index.php/API_V2.0)
