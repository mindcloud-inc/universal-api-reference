# Import Airbnb Listing as New Property with Beds24

Imports an Airbnb listing as a new property in Beds24.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/airbnb`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Import Airbnb Listing as New Property](https://wiki.beds24.com/index.php/API_V2.0)
