# Import Airbnb Listing to Existing Property with Beds24

Imports an Airbnb listing to an existing Beds24 property.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/airbnb`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Import Airbnb Listing to Existing Property](https://wiki.beds24.com/index.php/API_V2.0)
