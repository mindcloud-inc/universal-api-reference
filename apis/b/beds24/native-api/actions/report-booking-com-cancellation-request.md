# Report Booking.com Cancellation Request with Beds24

Reports a cancellation request to Booking.com from Beds24.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/booking`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Report Booking.com Cancellation Request](https://wiki.beds24.com/index.php/API_V2.0)
