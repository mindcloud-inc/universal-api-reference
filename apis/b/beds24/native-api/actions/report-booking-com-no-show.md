# Report Booking.com No Show with Beds24

Reports a no-show to Booking.com from Beds24.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/booking`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Report Booking.com No Show](https://wiki.beds24.com/index.php/API_V2.0)
