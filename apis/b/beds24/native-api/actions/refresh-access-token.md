# Refresh Access Token with Beds24

Retrieves an access token from a Beds24 refresh token.

## Endpoint

- **Method:** `GET`
- **Path:** `/authentication/token`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Refresh Access Token](https://wiki.beds24.com/index.php/API_V2.0)
