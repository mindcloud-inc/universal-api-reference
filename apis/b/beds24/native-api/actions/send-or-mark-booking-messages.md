# Send or Mark Booking Messages with Beds24

Sends booking messages or marks them as read in Beds24.

## Endpoint

- **Method:** `POST`
- **Path:** `/bookings/messages`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Send or Mark Booking Messages](https://wiki.beds24.com/index.php/API_V2.0)
