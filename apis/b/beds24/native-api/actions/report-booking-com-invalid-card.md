# Report Booking.com Invalid Card with Beds24

Reports an invalid card to Booking.com from Beds24.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/booking`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Report Booking.com Invalid Card](https://wiki.beds24.com/index.php/API_V2.0)
