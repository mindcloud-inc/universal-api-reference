# Detach Stripe Payment Method with Beds24

Detaches a Stripe payment method from Beds24.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/stripe`
- **Base URL:** `https://beds24.com/api/v2`
- **Official documentation:** [Detach Stripe Payment Method](https://wiki.beds24.com/index.php/API_V2.0)
