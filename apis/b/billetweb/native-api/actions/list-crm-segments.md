# List CRM Segments with Billetweb

Retrieves CRM segments from your Billetweb account.

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/segments`
- **Base URL:** `https://www.billetweb.fr/api`
- **Official documentation:** [List CRM Segments](https://www.billetweb.fr/bo/api.php#/api/crm/segments)
