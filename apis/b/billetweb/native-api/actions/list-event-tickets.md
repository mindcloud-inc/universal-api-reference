# List Event Tickets with Billetweb

Retrieves tickets for a Billetweb event.

## Endpoint

- **Method:** `GET`
- **Path:** `/event/:id/tickets`
- **Base URL:** `https://www.billetweb.fr/api`
- **Official documentation:** [List Event Tickets](https://www.billetweb.fr/bo/api.php#/api/event/:id/tickets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Event identifier. |
