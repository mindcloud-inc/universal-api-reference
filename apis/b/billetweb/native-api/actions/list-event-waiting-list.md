# List Event Waiting List with Billetweb

Retrieves the waiting list for a Billetweb event.

## Endpoint

- **Method:** `GET`
- **Path:** `/event/:id/waiting`
- **Base URL:** `https://www.billetweb.fr/api`
- **Official documentation:** [List Event Waiting List](https://www.billetweb.fr/bo/api.php#/api/event/:id/waiting)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Event identifier. |
