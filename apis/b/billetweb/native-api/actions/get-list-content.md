# Get List Content with Billetweb

Retrieves the contents of a Billetweb list.

## Endpoint

- **Method:** `GET`
- **Path:** `/list/:id/data`
- **Base URL:** `https://www.billetweb.fr/api`
- **Official documentation:** [Get List Content](https://www.billetweb.fr/bo/api.php#/api/lists/:id/data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Target list identifier. |
