# Get Form with ByteForms

Retrieves a form from ByteForms by form ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/form/:formId`
- **Base URL:** `https://api.forms.bytesuite.io/`
- **Official documentation:** [Get Form](https://forms.bytesuite.io/docs/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `number` | yes |
