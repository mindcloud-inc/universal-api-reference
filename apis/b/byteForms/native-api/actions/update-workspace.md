# Update Workspace with ByteForms

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/workspace/:workspaceId`
- **Base URL:** `https://api.forms.bytesuite.io/`
- **Official documentation:** [Update Workspace](https://forms.bytesuite.io/docs/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `description` | body | `string` | no |
| `name` | body | `string` | no |
| `workspaceId` | path | `string` | no |
