# Get Form Analytics with ByteForms

## Endpoint

- **Method:** `GET`
- **Path:** `/api/form/analytics/:formId`
- **Base URL:** `https://api.forms.bytesuite.io/`
- **Official documentation:** [Get Form Analytics](https://forms.bytesuite.io/docs/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | no |
