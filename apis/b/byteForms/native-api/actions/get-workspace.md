# Get Workspace with ByteForms

## Endpoint

- **Method:** `GET`
- **Path:** `/api/workspace/:workspaceId`
- **Base URL:** `https://api.forms.bytesuite.io/`
- **Official documentation:** [Get Workspace](https://forms.bytesuite.io/docs/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceId` | path | `string` | no |
