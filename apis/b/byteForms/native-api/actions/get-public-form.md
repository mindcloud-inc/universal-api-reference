# Get Public Form with ByteForms

## Endpoint

- **Method:** `GET`
- **Path:** `/f/:publicId`
- **Base URL:** `https://api.forms.bytesuite.io/`
- **Official documentation:** [Get Public Form](https://forms.bytesuite.io/docs/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `publicId` | path | `string` | no |
