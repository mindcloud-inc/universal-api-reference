# Export Responses CSV with ByteForms

## Endpoint

- **Method:** `GET`
- **Path:** `/api/form/export/csv/:formId`
- **Base URL:** `https://api.forms.bytesuite.io/`
- **Official documentation:** [Export Responses CSV](https://forms.bytesuite.io/docs/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | no |
