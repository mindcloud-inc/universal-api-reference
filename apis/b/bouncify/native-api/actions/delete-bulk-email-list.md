# Delete Bulk Email List with Bouncify

Deletes a bulk email list from Bouncify.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bulk/:job_id`
- **Base URL:** `https://api.bouncify.io/v1`
- **Official documentation:** [Delete Bulk Email List](https://bouncify.io/docs/api-docs/bulk-validation/delete-list/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | Bulk verification job id to delete. |
