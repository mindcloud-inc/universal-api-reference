# Validate Email with Bouncify

Validates an email address with Bouncify.

## Endpoint

- **Method:** `GET`
- **Path:** `/verify`
- **Base URL:** `https://api.bouncify.io/v1`
- **Official documentation:** [Validate Email](https://bouncify.io/docs/api-docs/single-validation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to validate with Bouncify. |
