# List Speakers V1 with Botnoi Voice

Retrieves speakers from Botnoi Voice V1.

## Endpoint

- **Method:** `GET`
- **Path:** `/openapi/v1/get_speaker_data`
- **Base URL:** `https://api-voice.botnoi.ai`
- **Official documentation:** [List Speakers V1](https://api-voice.botnoi.ai/openapi/v1/openapi.json)
