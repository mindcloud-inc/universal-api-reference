# Update Contact with Billage

Updates an existing contact in Billage.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/contacts`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Update Contact](https://app.getbillage.com/api/documentation.html#/Contacts/contactUpdate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact` | body | `object` | yes | Contact payload |
