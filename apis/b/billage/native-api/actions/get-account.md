# Get Account with Billage

Retrieves an account record from Billage.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/accounts/:accountId`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Get Account](https://app.getbillage.com/api/documentation.html#/Accounts/accountById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | Billage account ID |
