# Update Spending with Billage

Updates an existing spending in Billage.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/spendings`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Update Spending](https://app.getbillage.com/api/documentation.html#/Spendings/spendingUpdate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spending` | body | `object` | yes | Spending payload |
