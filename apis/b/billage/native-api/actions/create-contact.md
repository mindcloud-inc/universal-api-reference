# Create Contact with Billage

Creates a new contact in Billage.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/contacts`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Create Contact](https://app.getbillage.com/api/documentation.html#/Contacts/contactCreate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact` | body | `object` | yes | Contact payload |
