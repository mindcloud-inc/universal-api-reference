# Create Budget with Billage

Creates a new budget in Billage.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/budgets`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Create Budget](https://app.getbillage.com/api/documentation.html#/Budgets/budgetCreate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `budget` | body | `object` | yes | Budget payload |
