# Update Product with Billage

Updates an existing product in Billage.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/products`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Update Product](https://app.getbillage.com/api/documentation.html#/Products/productUpdate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product` | body | `object` | yes | Product payload |
