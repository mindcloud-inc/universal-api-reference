# Get Contact with Billage

Retrieves a contact record from Billage.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/contacts/:id`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Get Contact](https://app.getbillage.com/api/documentation.html#/Contacts/contactById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Billage contact ID |
