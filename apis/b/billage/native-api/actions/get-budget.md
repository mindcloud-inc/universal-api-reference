# Get Budget with Billage

Retrieves a budget record from Billage.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/budgets/:id`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Get Budget](https://app.getbillage.com/api/documentation.html#/Budgets/budgetFindById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Billage budget ID |
