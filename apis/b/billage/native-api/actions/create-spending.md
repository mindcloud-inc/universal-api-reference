# Create Spending with Billage

Creates a new spending in Billage.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/spendings`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Create Spending](https://app.getbillage.com/api/documentation.html#/Spendings/spendingCreate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spending` | body | `object` | yes | Spending payload |
