# Create Account with Billage

Creates a new account in Billage.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/accounts`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Create Account](https://app.getbillage.com/api/documentation.html#/Accounts/accountCreate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account` | body | `object` | yes | Account payload |
