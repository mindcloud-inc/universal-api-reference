# Get Company Info with Billage

Retrieves company profile information from Billage.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/companies/info`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Get Company Info](https://app.getbillage.com/api/documentation.html#/Companies/companyInformation)
