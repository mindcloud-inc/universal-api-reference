# Create Invoice with Billage

Creates a new invoice in Billage.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/invoices`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Create Invoice](https://app.getbillage.com/api/documentation.html#/Invoices/invoiceCreate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice` | body | `object` | yes | Invoice payload |
