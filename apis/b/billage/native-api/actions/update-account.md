# Update Account with Billage

Updates an existing account in Billage.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/accounts`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Update Account](https://app.getbillage.com/api/documentation.html#/Accounts/accountUpdate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account` | body | `object` | yes | Account payload |
