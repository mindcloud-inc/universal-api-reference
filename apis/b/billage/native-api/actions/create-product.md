# Create Product with Billage

Creates a new product in Billage.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/products`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Create Product](https://app.getbillage.com/api/documentation.html#/Products/productCreate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product` | body | `object` | yes | Product payload |
