# Update Budget with Billage

Updates an existing budget in Billage.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/budgets`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Update Budget](https://app.getbillage.com/api/documentation.html#/Budgets/budgetUpdate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `budget` | body | `object` | yes | Budget payload |
