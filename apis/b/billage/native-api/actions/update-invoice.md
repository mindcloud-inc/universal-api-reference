# Update Invoice with Billage

Updates an existing invoice in Billage.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/invoices`
- **Base URL:** `https://app.getbillage.com/api`
- **Official documentation:** [Update Invoice](https://app.getbillage.com/api/documentation.html#/Invoices/invoiceUpdate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice` | body | `object` | yes | Invoice payload |
