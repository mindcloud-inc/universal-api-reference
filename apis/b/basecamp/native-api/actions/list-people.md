# List People with Basecamp

Retrieves all people from Basecamp.

## Endpoint

- **Method:** `GET`
- **Path:** `/:accountId/people.json`
- **Base URL:** `https://3.basecampapi.com`
- **Official documentation:** [List People](https://github.com/basecamp/bc3-api/blob/master/sections/people.md#get-all-people)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Basecamp account ID. |
