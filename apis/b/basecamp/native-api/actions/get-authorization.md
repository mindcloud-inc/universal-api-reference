# Get Authorization with Basecamp

Retrieves authorization details and accessible accounts from Basecamp.

## Endpoint

- **Method:** `GET`
- **Path:** `https://launchpad.37signals.com/authorization.json`
- **Base URL:** `https://3.basecampapi.com`
- **Official documentation:** [Get Authorization](https://github.com/basecamp/api/blob/master/sections/authentication.md)
