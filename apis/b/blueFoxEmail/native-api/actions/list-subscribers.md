# List Subscribers with BlueFox Email

Retrieves subscribers from a BlueFox Email list.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/subscriber-lists/:subscriberListId`
- **Base URL:** `https://api.bluefox.email`
- **Official documentation:** [List Subscribers](https://bluefox.email/docs/api/subscriber-list-management#list-subscribers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscriberListId` | path | `string` | yes | BlueFox subscriber list ID. |
