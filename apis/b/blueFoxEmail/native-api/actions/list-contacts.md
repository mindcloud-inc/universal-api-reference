# List Contacts with BlueFox Email

Retrieves contacts from BlueFox Email.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/:projectId`
- **Base URL:** `https://api.bluefox.email`
- **Official documentation:** [List Contacts](https://bluefox.email/docs/api/contacts-management#list-contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | BlueFox project ID from the target project settings. |
