# Get Bicycle Rental Stations with BKK Futar

Retrieves bicycle rental stations from BKK Futar.

## Endpoint

- **Method:** `GET`
- **Path:** `/bicycle-rental.json`
- **Base URL:** `https://futar.bkk.hu/api/query/v1/ws/otp/api/where`
- **Official documentation:** [Get Bicycle Rental Stations](https://learn.microsoft.com/en-us/connectors/bkkfutarip/#get-bicycle-rental-stations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `includeReferences` | query | `string` | no | Reference data to include in the response. |
