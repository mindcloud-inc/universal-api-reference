# List Dashboard Emails with Boomlify

Retrieves dashboard-created and API emails from Boomlify.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/emails`
- **Base URL:** `https://v1.boomlify.com`
- **Official documentation:** [List Dashboard Emails](https://boomlify.com/en/temp-mail-api-docs?endpoint=list-dashboard-emails&tab=docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include_expired` | query | `boolean` | no | Whether expired dashboard emails should be included. |
