# Get Dashboard Telegram Forwarding with Boomlify

Retrieves Telegram forwarding status for an owned mailbox in Boomlify.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/emails/{id}/telegram-forwarding`
- **Base URL:** `https://v1.boomlify.com`
- **Official documentation:** [Get Dashboard Telegram Forwarding](https://boomlify.com/en/temp-mail-api-docs?endpoint=get-dashboard-telegram-forwarding&tab=docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Boomlify dashboard email UUID. |
