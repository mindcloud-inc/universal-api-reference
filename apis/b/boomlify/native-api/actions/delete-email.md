# Delete Email with Boomlify

Deletes an existing email from Boomlify.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/emails/{id}`
- **Base URL:** `https://v1.boomlify.com`
- **Official documentation:** [Delete Email](https://boomlify.com/en/temp-mail-api-docs?endpoint=delete-email&tab=docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the temporary email inbox to delete. |
