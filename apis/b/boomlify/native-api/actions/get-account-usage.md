# Get Account Usage with Boomlify

Retrieves API usage statistics from Boomlify.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/account/usage`
- **Base URL:** `https://v1.boomlify.com`
- **Official documentation:** [Get Account Usage](https://boomlify.com/en/temp-mail-api-docs?endpoint=get-usage&tab=docs)
