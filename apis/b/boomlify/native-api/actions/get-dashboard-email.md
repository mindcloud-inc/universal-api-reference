# Get Dashboard Email with Boomlify

Retrieves details for a dashboard email from Boomlify.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/emails/{id}`
- **Base URL:** `https://v1.boomlify.com`
- **Official documentation:** [Get Dashboard Email](https://boomlify.com/en/temp-mail-api-docs?endpoint=get-dashboard-email&tab=docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Boomlify dashboard email UUID. |
