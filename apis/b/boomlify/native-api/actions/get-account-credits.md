# Get Account Credits with Boomlify

Retrieves credit balance and usage information from Boomlify.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/account/credits`
- **Base URL:** `https://v1.boomlify.com`
- **Official documentation:** [Get Account Credits](https://boomlify.com/en/temp-mail-api-docs?endpoint=get-account-credits&tab=docs)
