# Get Account Info with Boomlify

Retrieves account information from Boomlify.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/account/info`
- **Base URL:** `https://v1.boomlify.com`
- **Official documentation:** [Get Account Info](https://boomlify.com/en/temp-mail-api-docs?endpoint=get-account-info&tab=docs)
