# Get All Product Variants with BigCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/catalog/products/:productId/variants`
- **Base URL:** `https://api.bigcommerce.com/stores/{storeHash}`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `productId` | path | `string` | no |
