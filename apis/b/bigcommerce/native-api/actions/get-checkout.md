# Get Checkout with BigCommerce

## Endpoint

- **Method:** `GET`
- **URL:** `https://api.bigcommerce.com/stores/:storeHash/v3/checkouts/:checkoutId?include=:include`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `checkoutId` | path | `string` | yes |
| `storeHash` | path | `string` | no |
| `include` | path | `string` | no |
