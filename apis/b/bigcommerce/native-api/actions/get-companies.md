# Get Companies with BigCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `https://api-b2b.bigcommerce.com/api/v3/io/companies`
- **Base URL:** `https://api.bigcommerce.com/stores/{storeHash}`
- **Official documentation:** [Get Companies](https://developer.bigcommerce.com/docs/rest-management/customers#get-all-customers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
