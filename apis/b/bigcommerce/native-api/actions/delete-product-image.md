# Delete Product Image with BigCommerce

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/catalog/products/:product_id/images/:image_id`
- **Base URL:** `https://api.bigcommerce.com/stores/{storeHash}`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `string` | yes |
| `image_id` | path | `string` | yes |
