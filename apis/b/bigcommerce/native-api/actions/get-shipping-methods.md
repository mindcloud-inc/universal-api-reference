# Get Shipping Method with BigCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/shipping/zones/:zoneID/methods/:methodID`
- **Base URL:** `https://api.bigcommerce.com/stores/{storeHash}`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `zoneID` | path | `string` | yes |
| `methodID` | path | `string` | yes |
