# Get Shipment from Order with BigCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/orders/:orderId/shipments`
- **Base URL:** `https://api.bigcommerce.com/stores/{storeHash}`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orderId` | path | `string` | yes |
