# Get Channel Currency with BigCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/channels/:channelId/currency-assignments`
- **Base URL:** `https://api.bigcommerce.com/stores/{storeHash}`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `channelId` | path | `string` | no |
