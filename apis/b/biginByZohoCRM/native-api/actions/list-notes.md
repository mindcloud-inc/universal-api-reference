# List Notes with Bigin by Zoho CRM

Retrieves notes from Bigin by Zoho CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/Notes`
- **Base URL:** `{api_domain}/bigin/v2`
- **Official documentation:** [List Notes](https://www.bigin.com/developer/docs/apis/v2/get-notes.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated note fields to return. |
