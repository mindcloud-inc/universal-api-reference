# List Modules with Bigin by Zoho CRM

Retrieves module details from Bigin by Zoho CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/modules`
- **Base URL:** `{api_domain}/bigin/v2`
- **Official documentation:** [List Modules](https://www.bigin.com/developer/docs/apis/v2/modules-api.html)
