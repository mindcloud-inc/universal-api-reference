# List Orders with Brightpearl

## Endpoint

- **Method:** `GET`
- **Path:** `/order-service/order-search`
- **Base URL:** `https://{apiDomain}/public-api/{account}`
- **Official documentation:** [List Orders](https://api-docs.brightpearl.com/order/order/search.html)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
