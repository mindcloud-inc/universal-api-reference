# Get Next Invoice Sequence with Billit

Retrieves the next Billit invoice sequence preview.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/account/sequences`
- **Base URL:** `https://api.sandbox.billit.be`
- **Official documentation:** [Get Next Invoice Sequence](https://docs.billit.be/reference/account_postsequences-1)
