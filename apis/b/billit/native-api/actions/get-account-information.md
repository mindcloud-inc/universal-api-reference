# Get Account Information with Billit

Retrieves account information for the authenticated Billit user.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/account/accountInformation`
- **Base URL:** `https://api.sandbox.billit.be`
- **Official documentation:** [Get Account Information](https://docs.billit.be/reference/account_getaccountinformation-1)
