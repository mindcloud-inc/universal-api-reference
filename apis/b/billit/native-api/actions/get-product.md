# Get Product with Billit

Retrieves a Billit product by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/products/:productID`
- **Base URL:** `https://api.sandbox.billit.be`
- **Official documentation:** [Get Product](https://docs.billit.be/reference/product_getproduct-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productID` | path | `number` | yes | Billit ProductID. |
