# Get Party with Billit

Retrieves a Billit party by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/parties/:partyID`
- **Base URL:** `https://api.sandbox.billit.be`
- **Official documentation:** [Get Party](https://docs.billit.be/reference/party_getparty-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `partyID` | path | `number` | yes | Billit PartyID. |
