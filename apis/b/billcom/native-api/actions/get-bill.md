# Get Bill with BILL Payables & Receivables

Retrieves a bill from Bill.com.

## Endpoint

- **Method:** `POST`
- **Path:** `Crud/Read/Bill.json`
- **Base URL:** `https://api.bill.com/api/v2`
- **Official documentation:** [Get Bill](https://developer.bill.com/v2/reference/ap-vendortransactions-readbill)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | yes |
