# Update Vendor with BILL Payables & Receivables

Updates a vendor in Bill.com.

## Endpoint

- **Method:** `POST`
- **Path:** `Crud/Update/Vendor.json`
- **Base URL:** `https://api.bill.com/api/v2`
- **Official documentation:** [Update Vendor](https://developer.bill.com/v2/reference/ap-vendormgmt-updatevendor)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `data` | body | `string` | no |
