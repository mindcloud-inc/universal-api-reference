# Approve Bill with BILL Payables & Receivables

Approves a bill in Bill.com.

## Endpoint

- **Method:** `POST`
- **Path:** `Approve.json`
- **Base URL:** `https://api.bill.com/api/v2`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `objectId` | body | `string` | yes |
