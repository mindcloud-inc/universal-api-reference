# Create Vendor with BILL Payables & Receivables

Creates a vendor in Bill.com.

## Endpoint

- **Method:** `POST`
- **Path:** `Crud/Create/Vendor.json`
- **Base URL:** `https://api.bill.com/api/v2`
- **Official documentation:** [Create Vendor](https://developer.bill.com/v2/reference/ap-vendormgmt-createvendor)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `data` | body | `string` | no |
