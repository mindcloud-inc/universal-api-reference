# Delete Target Group with Billetto

Deletes a target group from Billetto.

## Endpoint

- **Method:** `DELETE`
- **Path:** `organiser/target_groups/{id}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Delete Target Group](https://api.billetto.com/reference/delete-a-target-group-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto target group ID. |
