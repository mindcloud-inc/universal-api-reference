# Retrieve Webhook with Billetto

Retrieves a webhook from Billetto.

## Endpoint

- **Method:** `GET`
- **Path:** `organiser/webhooks/{id}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Retrieve Webhook](https://api.billetto.com/reference/retrieve-a-webhook-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto webhook ID. |
