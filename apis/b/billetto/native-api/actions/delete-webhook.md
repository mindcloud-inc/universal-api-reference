# Delete Webhook with Billetto

Deletes a webhook from Billetto.

## Endpoint

- **Method:** `DELETE`
- **Path:** `organiser/webhooks/{id}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Delete Webhook](https://api.billetto.com/reference/delete-a-webhook-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto webhook ID. |
