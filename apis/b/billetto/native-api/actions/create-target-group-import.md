# Create Target Group Import with Billetto

Creates a target group import in Billetto.

## Endpoint

- **Method:** `POST`
- **Path:** `organiser/target_group_imports`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Create Target Group Import](https://api.billetto.com/reference/post-a-target-group-1)
