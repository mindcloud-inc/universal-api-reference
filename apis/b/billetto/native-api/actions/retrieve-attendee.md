# Retrieve Attendee with Billetto

Retrieves an attendee from Billetto.

## Endpoint

- **Method:** `GET`
- **Path:** `organiser/attendees/{id}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Retrieve Attendee](https://api.billetto.com/reference/retrieve-an-attendee-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto attendee ID. |
