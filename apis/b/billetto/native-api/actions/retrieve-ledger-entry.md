# Retrieve Ledger Entry with Billetto

Retrieves a ledger entry from Billetto.

## Endpoint

- **Method:** `GET`
- **Path:** `organiser/ledger_entries/{id}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Retrieve Ledger Entry](https://api.billetto.com/reference/retrieve-a-ledger-entry-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto ledger entry ID. |
