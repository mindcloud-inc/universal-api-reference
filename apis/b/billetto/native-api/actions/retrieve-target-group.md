# Retrieve Target Group with Billetto

Retrieves a target group from Billetto.

## Endpoint

- **Method:** `GET`
- **Path:** `organiser/target_groups/{id}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Retrieve Target Group](https://api.billetto.com/reference/retrieve-a-target-group-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto target group ID. |
