# Retrieve BI Report with Billetto

Retrieves a business intelligence report from Billetto in JSON.

## Endpoint

- **Method:** `GET`
- **Path:** `organiser/events/{eventid}/bi_report/`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Retrieve BI Report](https://api.billetto.com/reference/retrieve-business-intelligence-report-in-json-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventid` | path | `string` | yes | Billetto event ID. |
