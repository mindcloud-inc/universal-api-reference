# Delete Target Group Member with Billetto

Deletes a target group member from Billetto.

## Endpoint

- **Method:** `DELETE`
- **Path:** `organiser/target_group_members/{id}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Delete Target Group Member](https://api.billetto.com/reference/delete-a-target-group-member-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto target group member ID. |
