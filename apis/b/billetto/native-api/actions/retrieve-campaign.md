# Retrieve Campaign with Billetto

Retrieves a campaign from Billetto.

## Endpoint

- **Method:** `GET`
- **Path:** `organiser/campaigns/{id}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Retrieve Campaign](https://api.billetto.com/reference/retrieve-a-global-campaign-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto campaign ID. |
