# List Target Group Imports By Target Group with Billetto

Retrieves target group imports from Billetto by target group.

## Endpoint

- **Method:** `GET`
- **Path:** `organiser/target_group_imports`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [List Target Group Imports By Target Group](https://api.billetto.com/reference/list-target-group-import)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target_group` | query | `string` | yes | Required target group ID to list imports for. |
