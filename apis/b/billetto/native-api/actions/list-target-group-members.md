# List Target Group Members with Billetto

Retrieves target group members from Billetto.

## Endpoint

- **Method:** `GET`
- **Path:** `organiser/target_group_members`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [List Target Group Members](https://api.billetto.com/reference/list-target-group-members-1)
