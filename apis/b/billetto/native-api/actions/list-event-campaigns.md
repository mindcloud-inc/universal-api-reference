# List Event Campaigns with Billetto

Retrieves campaigns for an event from Billetto.

## Endpoint

- **Method:** `GET`
- **Path:** `organiser/events/{id}/campaigns`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [List Event Campaigns](https://api.billetto.com/reference/list-event-campaigns-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto event ID. |
