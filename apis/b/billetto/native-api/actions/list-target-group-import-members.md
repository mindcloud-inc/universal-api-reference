# List Import Members with Billetto

Retrieves target group import members from Billetto.

## Endpoint

- **Method:** `GET`
- **Path:** `organiser/target_group_import_members`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [List Import Members](https://api.billetto.com/reference/list-target-group-members-imports-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `import` | query | `string` | yes | Billetto target group import ID. |
