# Retrieve Order with Billetto

Retrieves an order from Billetto.

## Endpoint

- **Method:** `GET`
- **Path:** `organiser/orders/{id}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Retrieve Order](https://api.billetto.com/reference/retrieve-an-order-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto order ID. |
