# Retrieve Public Event with Billetto

Retrieves a public event from Billetto.

## Endpoint

- **Method:** `GET`
- **Path:** `public/events/{id}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Retrieve Public Event](https://api.billetto.com/reference/retrieve-a-public-events-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto public event ID. |
