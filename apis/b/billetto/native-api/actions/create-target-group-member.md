# Create Target Group Member with Billetto

Creates a target group member in Billetto.

## Endpoint

- **Method:** `POST`
- **Path:** `organiser/target_group_members`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Create Target Group Member](https://api.billetto.com/reference/create-a-target-group-member-1)
