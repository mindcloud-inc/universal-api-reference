# List Target Group Imports with Billetto

Retrieves imports for a target group from Billetto.

## Endpoint

- **Method:** `GET`
- **Path:** `organiser/target_group_imports/{target_group}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [List Target Group Imports](https://api.billetto.com/reference/list-target-group-import-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target_group` | path | `string` | yes | Billetto target group ID. |
