# Update Webhook with Billetto

Updates a webhook in Billetto.

## Endpoint

- **Method:** `PATCH`
- **Path:** `organiser/webhooks/{id}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Update Webhook](https://api.billetto.com/reference/update-a-webhook-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto webhook ID. |
