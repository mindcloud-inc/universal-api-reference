# Update Target Group Member with Billetto

Updates a target group member in Billetto.

## Endpoint

- **Method:** `PATCH`
- **Path:** `organiser/target_group_members/{id}`
- **Base URL:** `https://billetto.dk/api/v3`
- **Official documentation:** [Update Target Group Member](https://api.billetto.com/reference/update-a-target-group-member-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billetto target group member ID. |
