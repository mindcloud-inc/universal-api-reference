# List Clusters with BigML

Retrieves clusters from BigML.

## Endpoint

- **Method:** `GET`
- **Path:** `/cluster`
- **Base URL:** `https://bigml.io`
- **Official documentation:** [List Clusters](https://bigml.com/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of records to return. |
| `offset` | query | `number` | no | Pagination offset. |
