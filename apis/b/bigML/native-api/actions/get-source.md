# Get Source with BigML

Retrieves a source from BigML.

## Endpoint

- **Method:** `GET`
- **Path:** `/source/:sourceId`
- **Base URL:** `https://bigml.io`
- **Official documentation:** [Get Source](https://bigml.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sourceId` | path | `string` | yes | BigML source identifier suffix only (for example, 69cd1234abcd1234abcd1234). Do not include source/. |
