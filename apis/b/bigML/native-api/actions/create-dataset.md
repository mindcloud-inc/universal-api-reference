# Create Dataset with BigML

Creates a dataset in BigML.

## Endpoint

- **Method:** `POST`
- **Path:** `/dataset`
- **Base URL:** `https://bigml.io`
- **Official documentation:** [Create Dataset](https://bigml.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `source` | body | `string` | yes | BigML source resource ID in full resource format (for example, source/69cd1234abcd1234abcd1234). |
