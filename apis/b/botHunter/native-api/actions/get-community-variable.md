# Get Community Variable with BotHunter

Retrieves a BotHunter community variable value.

## Endpoint

- **Method:** `GET`
- **Path:** `/globalvars/get`
- **Base URL:** `https://smm.targethunter.ru/api`
- **Official documentation:** [Get Community Variable](https://smm.targethunter.help/dev/api/methods/globalvars/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `var_id` | query | `string` | yes | ID of the BotHunter community variable to read. |
