# Get Webhook with Blooio Messaging

Retrieves a webhook from Blooio Messaging.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/{webhookId}`
- **Base URL:** `https://backend.blooio.com/v2/api`
- **Official documentation:** [Get Webhook](https://docs.blooio.com/webhooks/getWebhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Webhook identifier. |
