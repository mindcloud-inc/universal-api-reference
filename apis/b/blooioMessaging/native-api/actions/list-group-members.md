# List Group Members with Blooio Messaging

Retrieves group members from Blooio Messaging.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/{groupId}/members`
- **Base URL:** `https://backend.blooio.com/v2/api`
- **Official documentation:** [List Group Members](https://docs.blooio.com/group-members/listGroupMembers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | Group identifier. |
