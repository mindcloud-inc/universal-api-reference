# Create Group with Blooio Messaging

Creates a new group in Blooio Messaging.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://backend.blooio.com/v2/api`
- **Official documentation:** [Create Group](https://docs.blooio.com/groups/createGroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Group name. |
