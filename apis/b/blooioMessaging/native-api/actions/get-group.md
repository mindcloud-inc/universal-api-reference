# Get Group with Blooio Messaging

Retrieves a group from Blooio Messaging.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/{groupId}`
- **Base URL:** `https://backend.blooio.com/v2/api`
- **Official documentation:** [Get Group](https://docs.blooio.com/groups/getGroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | Group identifier. |
