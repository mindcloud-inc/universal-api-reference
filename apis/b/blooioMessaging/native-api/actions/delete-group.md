# Delete Group with Blooio Messaging

Deletes a group from Blooio Messaging.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/{groupId}`
- **Base URL:** `https://backend.blooio.com/v2/api`
- **Official documentation:** [Delete Group](https://docs.blooio.com/groups/deleteGroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | Group identifier. |
