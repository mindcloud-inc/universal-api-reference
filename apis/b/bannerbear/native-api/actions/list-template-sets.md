# List Template Sets with Bannerbear

Retrieves template sets from Bannerbear.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/template_sets`
- **Base URL:** `https://api.bannerbear.com`
- **Official documentation:** [List Template Sets](https://developers.bannerbear.com/v2/#list-all-template-sets)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `extended` | query | `boolean` | no | Return the extended response including current layer defaults. |
