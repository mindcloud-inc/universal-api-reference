# Duplicate Template with Bannerbear

Duplicates a template in Bannerbear.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/templates`
- **Base URL:** `https://api.bannerbear.com`
- **Official documentation:** [Duplicate Template](https://developers.bannerbear.com/v2/#duplicate-a-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `source` | query | `string` | yes | The template UID to duplicate from the same project. |
