# List Videos with Bannerbear

Retrieves videos from Bannerbear.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/videos`
- **Base URL:** `https://api.bannerbear.com`
- **Official documentation:** [List Videos](https://developers.bannerbear.com/v2/#list-all-videos)

## Capabilities

This operation supports [pagination](../README.md#pagination).
