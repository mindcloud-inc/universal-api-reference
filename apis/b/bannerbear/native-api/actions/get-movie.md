# Get Movie with Bannerbear

Retrieves movie from Bannerbear.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/movies/:uid`
- **Base URL:** `https://api.bannerbear.com`
- **Official documentation:** [Get Movie](https://developers.bannerbear.com/v2/#retrieve-a-movie)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The movie uid that you want to retrieve. |
