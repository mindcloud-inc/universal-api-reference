# List Movies with Bannerbear

Retrieves movies from Bannerbear.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/movies`
- **Base URL:** `https://api.bannerbear.com`
- **Official documentation:** [List Movies](https://developers.bannerbear.com/v2/#list-all-movies)

## Capabilities

This operation supports [pagination](../README.md#pagination).
