# List Collections with Bannerbear

Retrieves collections from Bannerbear.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/collections`
- **Base URL:** `https://api.bannerbear.com`
- **Official documentation:** [List Collections](https://developers.bannerbear.com/v2/#collections)

## Capabilities

This operation supports [pagination](../README.md#pagination).
