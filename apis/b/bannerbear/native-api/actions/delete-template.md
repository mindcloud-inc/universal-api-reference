# Delete Template with Bannerbear

Deletes an existing template from Bannerbear.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/templates/:uid`
- **Base URL:** `https://api.bannerbear.com`
- **Official documentation:** [Delete Template](https://developers.bannerbear.com/v2/#delete-a-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The unique ID of the template to delete. |
