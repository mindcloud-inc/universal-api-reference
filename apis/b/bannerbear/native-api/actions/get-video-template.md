# Get Video Template with Bannerbear

Retrieves video template from Bannerbear.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/video_templates/:uid`
- **Base URL:** `https://api.bannerbear.com`
- **Official documentation:** [Get Video Template](https://developers.bannerbear.com/v2/#retrieve-a-video-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The unique ID of the video template to retrieve. |
