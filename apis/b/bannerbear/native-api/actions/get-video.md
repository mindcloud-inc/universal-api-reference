# Get Video with Bannerbear

Retrieves video from Bannerbear.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/videos/:uid`
- **Base URL:** `https://api.bannerbear.com`
- **Official documentation:** [Get Video](https://developers.bannerbear.com/v2/#retrieve-a-video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The unique ID of the video to retrieve. |
