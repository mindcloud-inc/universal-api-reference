# Get Image with Bannerbear

Retrieves image from Bannerbear.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/images/:uid`
- **Base URL:** `https://api.bannerbear.com`
- **Official documentation:** [Get Image](https://developers.bannerbear.com/v2/#retrieve-an-image)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The unique ID of the image to retrieve. |
