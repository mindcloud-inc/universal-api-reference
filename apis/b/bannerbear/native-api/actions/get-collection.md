# Get Collection with Bannerbear

Retrieves collection from Bannerbear.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/collections/:uid`
- **Base URL:** `https://api.bannerbear.com`
- **Official documentation:** [Get Collection](https://developers.bannerbear.com/v2/#collections)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The collection uid that you want to retrieve. |
