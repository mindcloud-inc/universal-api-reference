# Get IPv4 Address Space Monitoring with BigDataCloud

Retrieves IPv4 address space monitoring data from BigDataCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/address-space-stats-ipv4`
- **Base URL:** `https://api-bdc.net`
- **Official documentation:** [Get IPv4 Address Space Monitoring](https://www.bigdatacloud.com/network-engineering/ipv4-address-space-monitoring-api)
