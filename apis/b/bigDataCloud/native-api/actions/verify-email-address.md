# Verify Email Address with BigDataCloud

Verifies an email address in BigDataCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/email-verify`
- **Base URL:** `https://api-bdc.net`
- **Official documentation:** [Verify Email Address](https://www.bigdatacloud.com/phone-email-verification/email-verify-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `emailAddress` | query | `string` | no | Email address to verify. |
