# Parse User Agent with BigDataCloud

Parses a user agent in BigDataCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/user-agent-info`
- **Base URL:** `https://api-bdc.net`
- **Official documentation:** [Parse User Agent](https://www.bigdatacloud.com/ip-geolocation/user-agent-parser-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userAgentRaw` | query | `string` | no | User agent string input. |
