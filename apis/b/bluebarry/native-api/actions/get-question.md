# Get Question with Bluebarry

Retrieves a single question from Bluebarry.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/Questions({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Get Question](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
