# Update Live Product Feed with Bluebarry

Updates an existing live product feed in Bluebarry.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/data/LiveProductFeeds({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Update Live Product Feed](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
