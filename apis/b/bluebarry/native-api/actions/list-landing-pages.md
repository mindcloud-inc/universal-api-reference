# List Landing Pages with Bluebarry

Retrieves landing page records from Bluebarry.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/LandingPages`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [List Landing Pages](https://data.bluebarry.ai/data/$metadata)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
