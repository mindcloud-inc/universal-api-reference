# Update Answer with Bluebarry

Updates an existing answer in Bluebarry.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/data/Answers({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Update Answer](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
