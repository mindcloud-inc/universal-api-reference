# Update Landing Page with Bluebarry

Updates an existing landing page in Bluebarry.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/data/LandingPages({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Update Landing Page](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
