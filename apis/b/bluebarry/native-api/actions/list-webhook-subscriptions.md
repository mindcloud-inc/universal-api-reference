# List Webhook Subscriptions with Bluebarry

Retrieves webhook subscription records from Bluebarry.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/WebhookSubscriptions`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [List Webhook Subscriptions](https://data.bluebarry.ai/data/$metadata)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
