# Delete Product with Bluebarry

Deletes an existing product from Bluebarry.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/data/Products({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Delete Product](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
