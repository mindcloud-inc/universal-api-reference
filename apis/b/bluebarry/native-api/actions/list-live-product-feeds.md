# List Live Product Feeds with Bluebarry

Retrieves live product feeds from Bluebarry.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/LiveProductFeeds`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [List Live Product Feeds](https://data.bluebarry.ai/data/$metadata)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
