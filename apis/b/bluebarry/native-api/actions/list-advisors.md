# List Advisors with Bluebarry

Retrieves advisor entity records from Bluebarry.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/Advisors`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [List Advisors](https://data.bluebarry.ai/data/$metadata)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
