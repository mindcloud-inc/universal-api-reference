# Delete Answer with Bluebarry

Deletes an existing answer from Bluebarry.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/data/Answers({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Delete Answer](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
