# List Products with Bluebarry

Retrieves product entity records from Bluebarry.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/Products`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [List Products](https://data.bluebarry.ai/data/$metadata)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
