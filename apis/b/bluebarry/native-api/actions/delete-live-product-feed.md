# Delete Live Product Feed with Bluebarry

Deletes a live product feed from Bluebarry.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/data/LiveProductFeeds({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Delete Live Product Feed](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
