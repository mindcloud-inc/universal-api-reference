# Get Landing Page with Bluebarry

Retrieves a landing page from Bluebarry.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/LandingPages({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Get Landing Page](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
