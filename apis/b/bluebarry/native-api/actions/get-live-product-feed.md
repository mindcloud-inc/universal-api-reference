# Get Live Product Feed with Bluebarry

Retrieves a live product feed from Bluebarry.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/LiveProductFeeds({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Get Live Product Feed](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
