# List Questions with Bluebarry

Retrieves question entity records from Bluebarry.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/Questions`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [List Questions](https://data.bluebarry.ai/data/$metadata)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
