# Delete Landing Page with Bluebarry

Deletes a landing page from Bluebarry.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/data/LandingPages({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Delete Landing Page](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
