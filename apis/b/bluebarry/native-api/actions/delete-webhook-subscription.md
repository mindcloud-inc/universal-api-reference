# Delete Webhook Subscription with Bluebarry

Deletes a webhook subscription from Bluebarry.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/data/WebhookSubscriptions({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Delete Webhook Subscription](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
