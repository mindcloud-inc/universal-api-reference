# List Answers with Bluebarry

Retrieves answer entity records from Bluebarry.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/Answers`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [List Answers](https://data.bluebarry.ai/data/$metadata)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
