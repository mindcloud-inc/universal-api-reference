# List Settings with Bluebarry

Retrieves settings entity records from Bluebarry.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/Settings`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [List Settings](https://data.bluebarry.ai/data/$metadata)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
