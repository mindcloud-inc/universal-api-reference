# Update Product with Bluebarry

Updates an existing product in Bluebarry.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/data/Products({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Update Product](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
