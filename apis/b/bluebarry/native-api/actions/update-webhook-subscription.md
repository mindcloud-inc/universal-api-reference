# Update Webhook Subscription with Bluebarry

Updates an existing webhook subscription in Bluebarry.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/data/WebhookSubscriptions({id})`
- **Base URL:** `https://data.bluebarry.ai/`
- **Official documentation:** [Update Webhook Subscription](https://data.bluebarry.ai/data/$metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
