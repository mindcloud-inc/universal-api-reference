# Delete Post with Beamer

Deletes an existing post from Beamer.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v0/posts/:postId`
- **Base URL:** `https://api.getbeamer.com`
- **Official documentation:** [Delete Post](https://help.userflow.com/beamer/docs/beamer-api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `postId` | path | `number` | yes | ID of the post to delete. |
