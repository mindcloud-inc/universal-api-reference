# Delete Bot Data with Botsonic

Deletes existing bot data from Botsonic.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/business/bot-data/:dataId`
- **Base URL:** `https://api.botsonic.ai`
- **Official documentation:** [Delete Bot Data](https://docs.botsonic.com/reference/delete_bot_data_v1_business_bot_data__data_id__delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data_id` | path | `string` | yes | data_id of the bot data item. |
