# List Starter Presets with Botsonic

Retrieves all starter presets from Botsonic.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/business/bot-starter-presets/all`
- **Base URL:** `https://api.botsonic.ai`
- **Official documentation:** [List Starter Presets](https://docs.botsonic.com/reference/get_all_starter_presets_by_bot_id_v1_business_bot_starter_presets_all_get-1)
