# Delete FAQ with Botsonic

Deletes an existing FAQ from Botsonic.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/business/bot-faq/:faqId`
- **Base URL:** `https://api.botsonic.ai`
- **Official documentation:** [Delete FAQ](https://docs.botsonic.com/reference/delete_bot_faq_v1_business_bot_faq__faq_id__delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `faq_id` | path | `string` | yes | FAQ identifier to delete. |
