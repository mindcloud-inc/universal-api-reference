# Get Conversation with Botsonic

Retrieves a specific conversation from Botsonic.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/business/bot-data/conversations/:chatId`
- **Base URL:** `https://api.botsonic.ai`
- **Official documentation:** [Get Conversation](https://docs.botsonic.com/reference/get_specific_conversation_v1_business_bot_data_conversations__chat_id__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chat_id` | path | `string` | yes | chat_id of the conversation. |
