# List Environment and Parks News with BC Gov News

Retrieves Environment and Parks announcements from BC Gov News.

## Endpoint

- **Method:** `GET`
- **Path:** `/ministries/environment-and-parks/feed`
- **Base URL:** `https://news.gov.bc.ca`
- **Official documentation:** [List Environment and Parks News](https://news.gov.bc.ca/ministries/environment-and-parks/feed)
