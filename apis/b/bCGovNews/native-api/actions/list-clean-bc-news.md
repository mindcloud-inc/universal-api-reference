# List CleanBC News with BC Gov News

Retrieves CleanBC announcements from BC Gov News.

## Endpoint

- **Method:** `GET`
- **Path:** `/news-subscribe/cleanbc/feed`
- **Base URL:** `https://news.gov.bc.ca`
- **Official documentation:** [List CleanBC News](https://news.gov.bc.ca/news-subscribe/cleanbc/feed)
