# List BC Coroners Service News with BC Gov News

Retrieves BC Coroners Service announcements from BC Gov News.

## Endpoint

- **Method:** `GET`
- **Path:** `/news-subscribe/bc-coroners-service/feed`
- **Base URL:** `https://news.gov.bc.ca`
- **Official documentation:** [List BC Coroners Service News](https://news.gov.bc.ca/news-subscribe/bc-coroners-service/feed)
