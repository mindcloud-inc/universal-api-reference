# List Intergovernmental Relations Secretariat News with BC Gov News

Retrieves Intergovernmental Relations Secretariat announcements from BC Gov News.

## Endpoint

- **Method:** `GET`
- **Path:** `/ministries/intergovernmental-relations-secretariat/feed`
- **Base URL:** `https://news.gov.bc.ca`
- **Official documentation:** [List Intergovernmental Relations Secretariat News](https://news.gov.bc.ca/ministries/intergovernmental-relations-secretariat/feed)
