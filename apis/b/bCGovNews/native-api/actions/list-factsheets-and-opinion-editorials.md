# List Factsheets and Opinion Editorials with BC Gov News

Retrieves factsheets and opinion editorials from BC Gov News.

## Endpoint

- **Method:** `GET`
- **Path:** `/factsheets/feed`
- **Base URL:** `https://news.gov.bc.ca`
- **Official documentation:** [List Factsheets and Opinion Editorials](https://news.gov.bc.ca/factsheets/feed)
