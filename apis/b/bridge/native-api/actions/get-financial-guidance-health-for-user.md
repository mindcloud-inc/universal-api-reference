# Get Financial Guidance Health for User with Bridge

Retrieves financial guidance for a user in Bridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/guidance/health/:user_uuid`
- **Base URL:** `https://api.bridgeapi.io/v3`
- **Official documentation:** [Get Financial Guidance Health for User](https://docs.bridgeapi.io/reference/getguidancehealth)
