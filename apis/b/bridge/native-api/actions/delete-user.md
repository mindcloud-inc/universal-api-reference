# Delete User with Bridge

Deletes a user from Bridge.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/aggregation/users/:uuid`
- **Base URL:** `https://api.bridgeapi.io/v3`
- **Official documentation:** [Delete User](https://docs.bridgeapi.io/reference/deleteuser)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
