# Get Payment Link with Bridge

Retrieves a payment link from Bridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment/payment-links/:id`
- **Base URL:** `https://api.bridgeapi.io/v3`
- **Official documentation:** [Get Payment Link](https://docs.bridgeapi.io/reference/getpaymentlink)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
