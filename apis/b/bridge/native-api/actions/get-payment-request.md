# Get Payment Request with Bridge

Retrieves a payment request from Bridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment/payment-requests/:id`
- **Base URL:** `https://api.bridgeapi.io/v3`
- **Official documentation:** [Get Payment Request](https://docs.bridgeapi.io/reference/getpaymentrequest)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
