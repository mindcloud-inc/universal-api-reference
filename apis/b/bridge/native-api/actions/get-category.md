# Get Category with Bridge

Retrieves a category from Bridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/aggregation/categories/:id`
- **Base URL:** `https://api.bridgeapi.io/v3`
- **Official documentation:** [Get Category](https://docs.bridgeapi.io/reference/getcategory)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
