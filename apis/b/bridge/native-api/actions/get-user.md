# Get User with Bridge

Retrieves a user from Bridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/aggregation/users/:uuid`
- **Base URL:** `https://api.bridgeapi.io/v3`
- **Official documentation:** [Get User](https://docs.bridgeapi.io/reference/getuser)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
