# List Items with Bridge

Retrieves items from Bridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/aggregation/items`
- **Base URL:** `https://api.bridgeapi.io/v3`
- **Official documentation:** [List Items](https://docs.bridgeapi.io/reference/getitems)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userAccessToken` | body | `string` | yes | Bridge user access token returned by the Authorization token action. |
