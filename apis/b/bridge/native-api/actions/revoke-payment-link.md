# Revoke payment link with Bridge

Revokes a payment link in Bridge.

## Endpoint

- **Method:** `POST`
- **Path:** `/payment/payment-links/:id/revoke`
- **Base URL:** `https://api.bridgeapi.io/v3`
- **Official documentation:** [Revoke payment link](https://docs.bridgeapi.io/reference/revokepaymentlink)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
