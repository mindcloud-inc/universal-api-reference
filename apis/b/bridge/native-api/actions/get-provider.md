# Get Provider with Bridge

Retrieves a provider from Bridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/providers/:id`
- **Base URL:** `https://api.bridgeapi.io/v3`
- **Official documentation:** [Get Provider](https://docs.bridgeapi.io/reference/getprovider)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
