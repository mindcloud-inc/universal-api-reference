# Get Payout with Bridge

Retrieves a payout from Bridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment/payment-account/payouts/:id`
- **Base URL:** `https://api.bridgeapi.io/v3`
- **Official documentation:** [Get Payout](https://docs.bridgeapi.io/reference/getpayout)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
