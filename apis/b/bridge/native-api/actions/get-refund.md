# Get Refund with Bridge

Retrieves a refund from Bridge.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment/payment-account/refunds/:id`
- **Base URL:** `https://api.bridgeapi.io/v3`
- **Official documentation:** [Get Refund](https://docs.bridgeapi.io/reference/getrefund)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
