# Get Scheduled Email with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/smtp/emailStatus/:identifier`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Scheduled Email](https://developers.brevo.com/reference/getscheduledemailbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The scheduled email identifier. |
