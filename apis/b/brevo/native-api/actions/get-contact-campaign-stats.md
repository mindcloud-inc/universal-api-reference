# Get Contact Campaign Stats with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/contacts/:identifier/campaignStats`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Contact Campaign Stats](https://developers.brevo.com/reference/get-contact-stats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The email address or contact id. |
