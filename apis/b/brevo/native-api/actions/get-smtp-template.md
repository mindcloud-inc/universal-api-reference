# Get SMTP Template with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/smtp/templates/:templateId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get SMTP Template](https://developers.brevo.com/reference/get-smtp-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | SMTP template ID. |
