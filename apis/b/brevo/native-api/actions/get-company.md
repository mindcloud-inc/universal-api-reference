# Get Company with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/companies/:id`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Company](https://developers.brevo.com/reference/getacompany)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The company identifier. |
