# Send Email Campaign Report with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/emailCampaigns/:campaignId/sendReport`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Send Email Campaign Report](https://developers.brevo.com/reference/sendreport)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The email campaign identifier. |
