# Send SMS Campaign Test with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/smsCampaigns/:campaignId/sendTest`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Send SMS Campaign Test](https://developers.brevo.com/reference/sendtestsms)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The SMS campaign identifier. |
