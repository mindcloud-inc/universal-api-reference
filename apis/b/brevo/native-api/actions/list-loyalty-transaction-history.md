# List Loyalty Transaction History with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/loyalty/balance/programs/:pid/transaction-history`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [List Loyalty Transaction History](https://developers.brevo.com/reference/gettransactionhistory)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pid` | path | `string` | yes |
