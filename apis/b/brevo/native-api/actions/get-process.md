# Get Process with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/processes/:processId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Process](https://developers.brevo.com/reference/getprocess)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processId` | path | `number` | yes | The process identifier returned by Brevo. |
