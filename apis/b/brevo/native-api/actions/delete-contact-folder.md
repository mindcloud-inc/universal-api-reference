# Delete Contact Folder with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/contacts/folders/:folderId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete Contact Folder](https://developers.brevo.com/reference/deletefolder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `number` | yes | The contact folder identifier. |
