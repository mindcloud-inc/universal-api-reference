# Create Loyalty Subscription Balances with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/loyalty/balance/programs/:pid/subscriptions/:cid/balances`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Create Loyalty Subscription Balances](https://developers.brevo.com/reference/createbalanceforcontact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cid` | path | `string` | yes |
| `pid` | path | `string` | yes |
