# List Sender IPs by Sender with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/senders/:senderId/ips`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [List Sender IPs by Sender](https://developers.brevo.com/reference/getipsfromsender)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `senderId` | path | `number` | yes | The sender identifier. |
