# Delete SMTP Log with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/smtp/log/:identifier`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete SMTP Log](https://developers.brevo.com/reference/delete-an-smtp-transactional-log)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The SMTP log identifier. |
