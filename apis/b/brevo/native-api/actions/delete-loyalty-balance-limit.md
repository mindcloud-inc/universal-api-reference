# Delete Loyalty Balance Limit with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/loyalty/balance/programs/:pid/balance-definitions/:bdid/limits/:blid`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete Loyalty Balance Limit](https://developers.brevo.com/reference/deletebalancelimit)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `bdid` | path | `string` | yes |
| `blid` | path | `string` | yes |
| `pid` | path | `string` | yes |
