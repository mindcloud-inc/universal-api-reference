# Delete Scheduled Email with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/smtp/email/:identifier`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete Scheduled Email](https://developers.brevo.com/reference/deletescheduledemailbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The scheduled email identifier. |
