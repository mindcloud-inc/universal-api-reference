# Send SMS Campaign Now with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/smsCampaigns/:campaignId/sendNow`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Send SMS Campaign Now](https://developers.brevo.com/reference/sendsmscampaignnow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The SMS campaign identifier. |
