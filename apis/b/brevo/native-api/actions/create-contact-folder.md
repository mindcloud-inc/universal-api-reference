# Create Contact Folder with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/contacts/folders`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Create Contact Folder](https://developers.brevo.com/reference/createfolder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The contact folder name. |
