# Get WhatsApp Campaign with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/whatsappCampaigns/:campaignId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get WhatsApp Campaign](https://developers.brevo.com/reference/getwhatsappcampaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The WhatsApp campaign identifier. |
