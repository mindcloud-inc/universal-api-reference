# Delete Blocked Domain with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/smtp/blockedDomains/:domain`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete Blocked Domain](https://developers.brevo.com/reference/deleteblockeddomain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | The blocked domain. |
