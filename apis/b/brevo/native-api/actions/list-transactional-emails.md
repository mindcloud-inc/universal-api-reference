# List Transactional Emails with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/smtp/emails`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [List Transactional Emails](https://developers.brevo.com/reference/get-transac-emails-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Filter logs by recipient email. |
