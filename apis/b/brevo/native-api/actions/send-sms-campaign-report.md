# Send SMS Campaign Report with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/smsCampaigns/:campaignId/sendReport`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Send SMS Campaign Report](https://developers.brevo.com/reference/sendsmsreport)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The SMS campaign identifier. |
