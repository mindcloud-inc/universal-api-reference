# List Contacts with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/contacts`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [List Contacts](https://developers.brevo.com/reference/get-contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum records to return. |
| `offset` | query | `number` | no | Number of records to skip. |
| `sort` | query | `string` | no | Sort direction (asc or desc). |
