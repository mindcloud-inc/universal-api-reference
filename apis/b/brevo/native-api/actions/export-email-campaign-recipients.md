# Export Email Campaign Recipients with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/emailCampaigns/:campaignId/exportRecipients`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Export Email Campaign Recipients](https://developers.brevo.com/reference/emailexportrecipients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The email campaign identifier. |
