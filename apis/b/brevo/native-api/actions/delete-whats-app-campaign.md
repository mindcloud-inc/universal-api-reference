# Delete WhatsApp Campaign with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/whatsappCampaigns/:campaignId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete WhatsApp Campaign](https://developers.brevo.com/reference/deletewhatsappcampaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The WhatsApp campaign identifier. |
