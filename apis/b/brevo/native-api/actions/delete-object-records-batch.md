# Delete Object Records Batch with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/objects/:object_type/batch/delete`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete Object Records Batch](https://developers.brevo.com/reference/deletebatchrecords)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `object_type` | path | `string` | yes |
