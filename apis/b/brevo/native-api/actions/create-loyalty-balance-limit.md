# Create Loyalty Balance Limit with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/loyalty/balance/programs/:pid/balance-definitions/:bdid/limits`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Create Loyalty Balance Limit](https://developers.brevo.com/reference/createbalancelimit)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `bdid` | path | `string` | yes |
| `pid` | path | `string` | yes |
