# List Contacts in List with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/contacts/lists/:listId/contacts`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [List Contacts in List](https://developers.brevo.com/reference/get-contacts-from-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Brevo list ID. |
