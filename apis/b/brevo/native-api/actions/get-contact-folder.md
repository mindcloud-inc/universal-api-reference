# Get Contact Folder with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/contacts/folders/:folderId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Contact Folder](https://developers.brevo.com/reference/get-folder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `number` | yes | The contact folder identifier. |
