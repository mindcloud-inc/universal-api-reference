# Upsert Object Records Batch with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/objects/:object_type/batch/upsert`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Upsert Object Records Batch](https://developers.brevo.com/reference/upsertbatchrecords)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `object_type` | path | `string` | yes |
