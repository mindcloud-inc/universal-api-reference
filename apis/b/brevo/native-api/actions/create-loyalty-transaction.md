# Create Loyalty Transaction with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/loyalty/balance/programs/:pid/transactions`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Create Loyalty Transaction](https://developers.brevo.com/reference/createtransaction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pid` | path | `string` | yes |
