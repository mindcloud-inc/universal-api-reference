# Export SMS Campaign Recipients with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/smsCampaigns/:campaignId/exportRecipients`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Export SMS Campaign Recipients](https://developers.brevo.com/reference/requestsmsrecipientexport)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The SMS campaign identifier. |
