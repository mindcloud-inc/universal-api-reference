# Delete Sender Domain with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/senders/domains/:domainName`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete Sender Domain](https://developers.brevo.com/reference/deletedomain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domainName` | path | `string` | yes | The sender domain name. |
