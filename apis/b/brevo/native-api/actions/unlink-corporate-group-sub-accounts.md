# Unlink Corporate Group Sub Accounts with Brevo

## Endpoint

- **Method:** `PUT`
- **Path:** `/v3/corporate/group/unlink/:groupId/subAccounts`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Unlink Corporate Group Sub Accounts](https://developers.brevo.com/reference/delete-sub-account-from-group)
