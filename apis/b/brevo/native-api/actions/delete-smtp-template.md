# Delete SMTP Template with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/smtp/templates/:templateId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete SMTP Template](https://developers.brevo.com/reference/delete-smtp-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | SMTP template ID. |
