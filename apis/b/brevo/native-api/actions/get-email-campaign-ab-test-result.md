# Get Email Campaign AB Test Result with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/emailCampaigns/:campaignId/abTestCampaignResult`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Email Campaign AB Test Result](https://developers.brevo.com/reference/get-ab-test-campaign-result)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The email campaign identifier. |
