# List Ecommerce Attributed Products with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/ecommerce/attribution/products/:conversionSource/:conversionSourceId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [List Ecommerce Attributed Products](https://developers.brevo.com/reference/get-attributed-product-sales-for-a-single-brevo-campaign-or-workflow)
