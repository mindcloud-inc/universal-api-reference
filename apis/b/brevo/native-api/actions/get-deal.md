# Get Deal with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/crm/deals/:id`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Deal](https://developers.brevo.com/reference/getadeal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The deal identifier. |
