# List Loyalty Contact Balances with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/loyalty/balance/programs/:pid/contact-balances`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [List Loyalty Contact Balances](https://developers.brevo.com/reference/getcontactbalances)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pid` | path | `string` | yes |
