# Complete Loyalty Transaction with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/loyalty/balance/programs/:pid/transactions/:tid/complete`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Complete Loyalty Transaction](https://developers.brevo.com/reference/completetransaction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pid` | path | `string` | yes |
| `tid` | path | `string` | yes |
