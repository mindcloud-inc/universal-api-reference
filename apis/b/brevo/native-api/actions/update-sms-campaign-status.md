# Update SMS Campaign Status with Brevo

## Endpoint

- **Method:** `PUT`
- **Path:** `/v3/smsCampaigns/:campaignId/status`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Update SMS Campaign Status](https://developers.brevo.com/reference/updatesmscampaignstatus)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The SMS campaign identifier. |
