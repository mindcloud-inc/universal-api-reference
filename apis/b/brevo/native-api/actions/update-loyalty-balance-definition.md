# Update Loyalty Balance Definition with Brevo

## Endpoint

- **Method:** `PUT`
- **Path:** `/v3/loyalty/balance/programs/:pid/balance-definitions/:bdid`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Update Loyalty Balance Definition](https://developers.brevo.com/reference/updatebalancedefinition)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `bdid` | path | `string` | yes |
| `pid` | path | `string` | yes |
