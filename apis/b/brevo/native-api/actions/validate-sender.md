# Validate Sender with Brevo

- **Method:** `PUT`
- **Path:** `/v3/senders/:senderId/validate`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Validate Sender](https://developers.brevo.com/reference/validatesender)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `senderId` | path | `string` | yes |
