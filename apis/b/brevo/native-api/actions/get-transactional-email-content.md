# Get Transactional Email Content with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/smtp/emails/:uuid`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Transactional Email Content](https://developers.brevo.com/reference/gettransacemailcontent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The transactional email UUID. |
