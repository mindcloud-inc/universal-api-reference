# Get Category with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/categories/:id`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Category](https://developers.brevo.com/reference/getcategoryinfo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The category identifier. |
