# Update Sender with Brevo

## Endpoint

- **Method:** `PUT`
- **Path:** `/v3/senders/:senderId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Update Sender](https://developers.brevo.com/reference/updatesender)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `senderId` | path | `string` | yes |
