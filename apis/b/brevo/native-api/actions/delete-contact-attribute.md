# Delete Contact Attribute with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/contacts/attributes/:attributeCategory/:attributeName`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete Contact Attribute](https://developers.brevo.com/reference/delete-attribute)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `attributeCategory` | path | `string` | yes | The attribute category. |
| `attributeName` | path | `string` | yes | The attribute name. |
