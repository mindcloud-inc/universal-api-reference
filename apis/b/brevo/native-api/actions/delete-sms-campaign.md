# Delete SMS Campaign with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/smsCampaigns/:campaignId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete SMS Campaign](https://developers.brevo.com/reference/deletesmscampaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The SMS campaign identifier. |
