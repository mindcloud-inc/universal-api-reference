# Get Email Campaign Shared URL with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/emailCampaigns/:campaignId/sharedUrl`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Email Campaign Shared URL](https://developers.brevo.com/reference/get-shared-template-url)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The email campaign identifier. |
