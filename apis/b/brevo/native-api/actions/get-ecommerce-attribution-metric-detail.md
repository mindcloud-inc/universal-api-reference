# Get Ecommerce Attribution Metric Detail with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/ecommerce/attribution/metrics/:conversionSource/:conversionSourceId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Ecommerce Attribution Metric Detail](https://developers.brevo.com/reference/get-detailed-attribution-metrics-for-a-single-brevo-campaign-or-workflow)
