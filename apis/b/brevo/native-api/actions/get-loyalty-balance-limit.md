# Get Loyalty Balance Limit with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/loyalty/balance/programs/:pid/balance-definitions/:bdid/limits/:blid`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Loyalty Balance Limit](https://developers.brevo.com/reference/getbalancelimit)
