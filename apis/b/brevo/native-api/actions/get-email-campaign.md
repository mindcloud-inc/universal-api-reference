# Get Email Campaign with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/emailCampaigns/:campaignId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Email Campaign](https://developers.brevo.com/reference/get-email-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | Email campaign ID. |
