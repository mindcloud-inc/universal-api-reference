# Delete Email Campaign with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/emailCampaigns/:campaignId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete Email Campaign](https://developers.brevo.com/reference/delete-email-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The email campaign identifier. |
