# List Lists in Folder with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/contacts/folders/:folderId/lists`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [List Lists in Folder](https://developers.brevo.com/reference/get-folder-lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `number` | yes | The contact folder identifier. |
