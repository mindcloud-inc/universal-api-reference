# Delete Sender with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/senders/:senderId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete Sender](https://developers.brevo.com/reference/deletesender)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `senderId` | path | `number` | yes | The sender identifier. |
