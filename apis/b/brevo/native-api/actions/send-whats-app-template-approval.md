# Send WhatsApp Template Approval with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/whatsappCampaigns/template/approval/:templateId`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Send WhatsApp Template Approval](https://developers.brevo.com/reference/send-your-whatsapp-template-for-approval)
