# Send Email Campaign Now with Brevo

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/emailCampaigns/:campaignId/sendNow`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Send Email Campaign Now](https://developers.brevo.com/reference/sendcampaignnow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The email campaign identifier. |
