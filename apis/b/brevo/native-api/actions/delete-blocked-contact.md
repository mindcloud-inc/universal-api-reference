# Delete Blocked Contact with Brevo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/smtp/blockedContacts/:email`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Delete Blocked Contact](https://developers.brevo.com/reference/unblock-or-resubscribe-a-transactional-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | The blocked contact email. |
