# Authenticate Sender Domain with Brevo

## Endpoint

- **Method:** `PUT`
- **Path:** `/v3/senders/domains/:domainName/authenticate`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Authenticate Sender Domain](https://developers.brevo.com/reference/authenticatedomain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domainName` | path | `string` | yes | The sender domain name. |
