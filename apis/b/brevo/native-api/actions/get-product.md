# Get Product with Brevo

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/products/:id`
- **Base URL:** `https://api.brevo.com`
- **Official documentation:** [Get Product](https://developers.brevo.com/reference/getproductinfo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The product identifier. |
