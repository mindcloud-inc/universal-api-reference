# Create Deal Field with BoardCRM

Creates a new deal field in BoardCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/field/create`
- **Base URL:** `https://api.boardcrm.io/api`
- **Official documentation:** [Create Deal Field](https://dev.boardcrm.io/public/0.1/methods/field#create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Field title. |
