# Delete Deal with BoardCRM

Deletes an existing deal from BoardCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/offer/delete`
- **Base URL:** `https://api.boardcrm.io/api`
- **Official documentation:** [Delete Deal](https://dev.boardcrm.io/public/0.1/methods/offer#delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Deal ID to delete. |
