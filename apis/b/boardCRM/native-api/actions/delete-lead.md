# Delete Lead with BoardCRM

Deletes an existing lead from BoardCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/lead/delete`
- **Base URL:** `https://api.boardcrm.io/api`
- **Official documentation:** [Delete Lead](https://dev.boardcrm.io/public/0.1/methods/lead#delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Lead ID to delete. |
