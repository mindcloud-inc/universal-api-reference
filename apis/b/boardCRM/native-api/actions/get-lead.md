# Get Lead with BoardCRM

Retrieves a single lead from BoardCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/lead/get`
- **Base URL:** `https://api.boardcrm.io/api`
- **Official documentation:** [Get Lead](https://dev.boardcrm.io/public/0.1/methods/lead#get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Lead ID. |
