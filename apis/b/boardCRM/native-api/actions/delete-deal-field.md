# Delete Deal Field with BoardCRM

Deletes an existing deal field from BoardCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/field/delete`
- **Base URL:** `https://api.boardcrm.io/api`
- **Official documentation:** [Delete Deal Field](https://dev.boardcrm.io/public/0.1/methods/field#delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Field ID to delete. |
