# List Leads with BoardCRM

Retrieves lead records from the BoardCRM workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/lead/list`
- **Base URL:** `https://api.boardcrm.io/api`
- **Official documentation:** [List Leads](https://dev.boardcrm.io/public/0.1/methods/lead#list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
