# Get Deal with BoardCRM

Retrieves a single deal from BoardCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/offer/get`
- **Base URL:** `https://api.boardcrm.io/api`
- **Official documentation:** [Get Deal](https://dev.boardcrm.io/public/0.1/methods/offer#get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Deal ID. |
