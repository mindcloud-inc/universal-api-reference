# List Calls with Beyond Presence

Retrieves agent-managed calls from Beyond Presence.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/calls`
- **Base URL:** `https://api.bey.dev`
- **Official documentation:** [List Calls](https://docs.bey.dev/api-reference/calls/list-calls)

## Capabilities

This operation supports [pagination](../README.md#pagination).
