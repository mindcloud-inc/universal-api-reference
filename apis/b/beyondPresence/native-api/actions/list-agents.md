# List Agents with Beyond Presence

Retrieves available agents from Beyond Presence.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents`
- **Base URL:** `https://api.bey.dev`
- **Official documentation:** [List Agents](https://docs.bey.dev/api-reference/agents/list-agents)

## Capabilities

This operation supports [pagination](../README.md#pagination).
