# Get Agent with Beyond Presence

Retrieves an agent from Beyond Presence.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents/:id`
- **Base URL:** `https://api.bey.dev`
- **Official documentation:** [Get Agent](https://docs.bey.dev/api-reference/agents/retrieve-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Agent ID. |
