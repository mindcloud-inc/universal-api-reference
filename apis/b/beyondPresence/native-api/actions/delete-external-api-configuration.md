# Delete External API Configuration with Beyond Presence

Deletes an external API configuration from Beyond Presence.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/external-apis/:id`
- **Base URL:** `https://api.bey.dev`
- **Official documentation:** [Delete External API Configuration](https://docs.bey.dev/api-reference/external-apis/delete-external-api-configuration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | External API configuration ID. |
