# Get Call with Beyond Presence

Retrieves a call from Beyond Presence.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/calls/:id`
- **Base URL:** `https://api.bey.dev`
- **Official documentation:** [Get Call](https://docs.bey.dev/api-reference/calls/retrieve-call)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Call ID. |
