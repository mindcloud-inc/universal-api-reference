# Get Avatar with Beyond Presence

Retrieves an avatar from Beyond Presence.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/avatars/:id`
- **Base URL:** `https://api.bey.dev`
- **Official documentation:** [Get Avatar](https://docs.bey.dev/api-reference/avatars/retrieve-avatar)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Avatar ID. |
