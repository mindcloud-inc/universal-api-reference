# Delete Agent with Beyond Presence

Deletes an existing agent from Beyond Presence.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/agents/:id`
- **Base URL:** `https://api.bey.dev`
- **Official documentation:** [Delete Agent](https://docs.bey.dev/api-reference/agents/delete-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Agent ID. |
