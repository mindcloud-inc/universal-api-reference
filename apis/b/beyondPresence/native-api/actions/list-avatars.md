# List Avatars with Beyond Presence

Retrieves available avatars from Beyond Presence.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/avatars`
- **Base URL:** `https://api.bey.dev`
- **Official documentation:** [List Avatars](https://docs.bey.dev/api-reference/avatars/list-avatars)

## Capabilities

This operation supports [pagination](../README.md#pagination).
