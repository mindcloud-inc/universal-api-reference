# List External API Configurations with Beyond Presence

Retrieves external API configurations from Beyond Presence.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/external-apis`
- **Base URL:** `https://api.bey.dev`
- **Official documentation:** [List External API Configurations](https://docs.bey.dev/api-reference/external-apis/list-external-api-configurations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
