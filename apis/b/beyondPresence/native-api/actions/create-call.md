# Create Call with Beyond Presence

Creates a new call in Beyond Presence.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/calls`
- **Base URL:** `https://api.bey.dev`
- **Official documentation:** [Create Call](https://docs.bey.dev/api-reference/calls/create-call)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | body | `string` | yes | ID of agent managing the call. |
