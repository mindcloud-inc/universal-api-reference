# List Status Pages with Better Stack Uptime

Retrieves status pages from Better Stack Uptime.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/status-pages`
- **Base URL:** `https://uptime.betterstack.com/api`
- **Official documentation:** [List Status Pages](https://betterstack.com/docs/uptime/api/list-all-existing-status-pages/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
