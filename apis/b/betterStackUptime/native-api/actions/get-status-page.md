# Get Status Page with Better Stack Uptime

Retrieves a status page from Better Stack Uptime.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/status-pages/:statusPageId`
- **Base URL:** `https://uptime.betterstack.com/api`
- **Official documentation:** [Get Status Page](https://betterstack.com/docs/uptime/api/get-a-single-status-page/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `statusPageId` | path | `string` | yes | Status page ID. |
