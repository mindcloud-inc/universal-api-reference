# Get Monitor with Better Stack Uptime

Retrieves a monitor from Better Stack Uptime.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/monitors/:monitor_id`
- **Base URL:** `https://uptime.betterstack.com/api`
- **Official documentation:** [Get Monitor](https://betterstack.com/docs/uptime/api/get-a-single-monitor/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `monitor_id` | path | `string` | yes | The ID of the monitor you want to get |
