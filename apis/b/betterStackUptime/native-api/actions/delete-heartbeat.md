# Delete Heartbeat with Better Stack Uptime

Deletes an existing heartbeat from Better Stack Uptime.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/heartbeats/:heartbeat_id`
- **Base URL:** `https://uptime.betterstack.com/api`
- **Official documentation:** [Delete Heartbeat](https://betterstack.com/docs/uptime/api/delete-existing-heartbeat/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `heartbeat_id` | path | `string` | yes | The heartbeat ID. |
