# Delete Monitor with Better Stack Uptime

Deletes an existing monitor from Better Stack Uptime.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/monitors/:monitor_id`
- **Base URL:** `https://uptime.betterstack.com/api`
- **Official documentation:** [Delete Monitor](https://betterstack.com/docs/uptime/api/delete-an-existing-monitor/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `monitor_id` | path | `string` | yes | The monitor ID. |
