# List Heartbeats with Better Stack Uptime

Retrieves heartbeats from Better Stack Uptime.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/heartbeats`
- **Base URL:** `https://uptime.betterstack.com/api`
- **Official documentation:** [List Heartbeats](https://betterstack.com/docs/uptime/api/list-all-existing-hearbeats/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
