# Get Heartbeat with Better Stack Uptime

Retrieves a heartbeat from Better Stack Uptime.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/heartbeats/:heartbeat_id`
- **Base URL:** `https://uptime.betterstack.com/api`
- **Official documentation:** [Get Heartbeat](https://betterstack.com/docs/uptime/api/get-a-single-hearbeat/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `heartbeat_id` | path | `string` | yes | The heartbeat ID. |
