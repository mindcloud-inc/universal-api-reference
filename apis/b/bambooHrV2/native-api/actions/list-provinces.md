# List Provinces with BambooHR

Lists provinces from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/meta/provinces`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Provinces](https://documentation.bamboohr.com/reference/get-all-provinces)

## Requirements

- **OAuth scopes:** `meta`
- **scope:** `meta` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
