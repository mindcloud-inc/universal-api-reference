# Get Job Titles and Level Assignments with BambooHR

Retrieves job titles and level assignments from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/pay-grades-and-bands/job-titles`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [Get Job Titles and Level Assignments](https://documentation.bamboohr.com/reference/get-job-title-level-assignments)

## Requirements

- **OAuth scopes:** `pay_grades_and_bands`
- **scope:** `pay_grades_and_bands` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
