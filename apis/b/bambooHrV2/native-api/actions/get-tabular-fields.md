# Get Tabular Fields with BambooHR

Retrieves available tabular field metadata from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/meta/tables`
- **Base URL:** `https://mindcloud.bamboohr.com/api`
- **Official documentation:** [Get Tabular Fields](https://documentation.bamboohr.com/reference/metadata-get-a-list-of-tabular-fields)
