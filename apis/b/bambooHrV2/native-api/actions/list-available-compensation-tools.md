# List Available Compensation Tools with BambooHR

Lists available compensation tools from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/compensation/tools`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Available Compensation Tools](https://documentation.bamboohr.com/reference/e7d3012f6a8f037cb74486bcf3a77bde)

## Requirements

- **OAuth scopes:** `compensation_tools`
- **scope:** `compensation_tools` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
