# List Webhooks with BambooHR

Lists webhooks from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Webhooks](https://documentation.bamboohr.com/reference/list-webhooks)

## Requirements

- **OAuth scopes:** `webhooks`
- **scope:** `webhooks` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
