# List Alert Templates with BambooHR

Lists alert templates from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/alerts`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Alert Templates](https://documentation.bamboohr.com/reference/list-alert-templates)

## Requirements

- **OAuth scopes:** `alerts`
- **scope:** `alerts` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
