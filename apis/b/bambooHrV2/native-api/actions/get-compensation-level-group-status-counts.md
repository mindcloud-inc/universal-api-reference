# Get Compensation Level Group Status Counts with BambooHR

Retrieves compensation level group status counts from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/pay-grades-and-bands/status-counts`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [Get Compensation Level Group Status Counts](https://documentation.bamboohr.com/reference/get-compensation-level-group-status-counts)

## Requirements

- **OAuth scopes:** `pay_grades_and_bands`
- **scope:** `pay_grades_and_bands` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
