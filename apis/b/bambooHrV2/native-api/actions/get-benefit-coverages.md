# Get Benefit Coverages with BambooHR

Retrieves benefit coverage options from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/benefitcoverages`
- **Base URL:** `https://mindcloud.bamboohr.com/api`
- **Official documentation:** [Get Benefit Coverages](https://documentation.bamboohr.com/reference/get-benefit-coverages-2)
