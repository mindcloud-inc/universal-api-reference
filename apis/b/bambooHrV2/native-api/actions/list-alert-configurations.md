# List Alert Configurations with BambooHR

Lists alert configurations from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/alert-configurations`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Alert Configurations](https://documentation.bamboohr.com/reference/list-alert-configurations)

## Requirements

- **OAuth scopes:** `alerts`
- **scope:** `alerts` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
