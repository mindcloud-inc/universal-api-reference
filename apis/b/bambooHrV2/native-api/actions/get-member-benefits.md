# Get Member Benefits with BambooHR

Retrieves member benefit enrollments from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/benefits/member-benefits`
- **Base URL:** `https://mindcloud.bamboohr.com/api`
- **Official documentation:** [Get Member Benefits](https://documentation.bamboohr.com/reference/get-member-benefits)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `calendarYear` | query | `string` | yes | Calendar year to return benefit membership for. |
