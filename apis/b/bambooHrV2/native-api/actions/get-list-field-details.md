# Get List Field Details with BambooHR

Retrieves list field details from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/meta/lists`
- **Base URL:** `https://mindcloud.bamboohr.com/api`
- **Official documentation:** [Get List Field Details](https://documentation.bamboohr.com/reference/metadata-get-details-for-list-fields)
