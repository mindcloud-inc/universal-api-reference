# List Compensation Planning Cycles with BambooHR

Lists compensation planning cycles from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/compensation/planning_cycles`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Compensation Planning Cycles](https://documentation.bamboohr.com/reference/186eb76d2c656f8309cae9dff6ed8a69)

## Requirements

- **OAuth scopes:** `planning_cycles`
- **scope:** `planning_cycles` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
