# Get Levels and Bands Status with BambooHR

Retrieves levels and bands status from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/pay-grades-and-bands/status`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [Get Levels and Bands Status](https://documentation.bamboohr.com/reference/get-levels-and-bands-status)

## Requirements

- **OAuth scopes:** `pay_grades_and_bands`
- **scope:** `pay_grades_and_bands` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
