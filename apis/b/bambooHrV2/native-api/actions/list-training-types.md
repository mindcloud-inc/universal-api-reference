# List Training Types with BambooHR

Lists training types from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/training/type`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Training Types](https://documentation.bamboohr.com/reference/list-training-types)

## Requirements

- **OAuth scopes:** `training`
- **scope:** `training` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
