# List Webhook Post Fields with BambooHR

Lists webhook post fields from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks/post-fields`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Webhook Post Fields](https://documentation.bamboohr.com/reference/get-post-fields)

## Requirements

- **OAuth scopes:** `webhooks`
- **scope:** `webhooks` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
