# List Industries with BambooHR

Lists industries from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/meta/industries`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Industries](https://documentation.bamboohr.com/reference/list-industries)

## Requirements

- **OAuth scopes:** `meta`
- **scope:** `meta` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
