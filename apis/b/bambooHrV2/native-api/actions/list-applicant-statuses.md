# List Applicant Statuses with BambooHR

Lists applicant statuses from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/applicant_tracking/statuses`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Applicant Statuses](https://documentation.bamboohr.com/reference/get-statuses)

## Requirements

- **OAuth scopes:** `hiring:applications`
- **scope:** `hiring:applications` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
