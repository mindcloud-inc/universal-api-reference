# List New Hire Packets with BambooHR

Lists new hire packets from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/new-hire-packets`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List New Hire Packets](https://documentation.bamboohr.com/reference/6d181e2defa79e054c4415c11dc42dab)

## Requirements

- **OAuth scopes:** `onboarding`
- **scope:** `onboarding` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.

## Capabilities

This operation supports [pagination](../README.md#pagination).
