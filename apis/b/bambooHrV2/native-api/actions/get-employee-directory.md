# Get Employee Directory with BambooHR

Retrieves the published employee directory from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/employees/directory`
- **Base URL:** `https://mindcloud.bamboohr.com/api`
- **Official documentation:** [Get Employee Directory](https://documentation.bamboohr.com/reference/get-employees-directory)
