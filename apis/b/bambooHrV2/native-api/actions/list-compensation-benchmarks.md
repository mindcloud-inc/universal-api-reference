# List Compensation Benchmarks with BambooHR

Lists compensation benchmarks from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/compensation/benchmarks`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Compensation Benchmarks](https://documentation.bamboohr.com/reference/list-compensation-benchmarks)

## Requirements

- **OAuth scopes:** `compensation_benchmarks`
- **scope:** `compensation_benchmarks` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
