# Get Company Information with BambooHR

Retrieves company profile information from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/company_information`
- **Base URL:** `https://mindcloud.bamboohr.com/api`
- **Official documentation:** [Get Company Information](https://documentation.bamboohr.com/reference/get-company-information-1)
