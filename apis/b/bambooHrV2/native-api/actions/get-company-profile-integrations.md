# Get Company Profile Integrations with BambooHR

Retrieves company profile integrations from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/company-profile-integrations`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [Get Company Profile Integrations](https://documentation.bamboohr.com/reference/get-company-profile-integrations)

## Requirements

- **OAuth scopes:** `company:details`
- **scope:** `company:details` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
