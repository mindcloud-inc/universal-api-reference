# Get Company Equity Settings with BambooHR

Retrieves company equity settings from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/compensation/equity/settings`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [Get Company Equity Settings](https://documentation.bamboohr.com/reference/d90d59c4f1201ea05c23a1313c071db4)

## Requirements

- **OAuth scopes:** `equity`
- **scope:** `equity` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
