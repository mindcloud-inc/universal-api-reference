# List Hiring Leads with BambooHR

Lists hiring leads from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/applicant_tracking/hiring_leads`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Hiring Leads](https://documentation.bamboohr.com/reference/get-hiring-leads)
