# List Custom Field Types with BambooHR

Lists custom field types from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/hris/custom-fields/types`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Custom Field Types](https://documentation.bamboohr.com/reference/list-custom-field-types)

## Requirements

- **OAuth scopes:** `employee:custom_fields`
- **scope:** `employee:custom_fields` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
