# Get Welcome New Hires Widget with BambooHR

Retrieves welcome new hires widget from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/onboarding/new-hire-widget`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [Get Welcome New Hires Widget](https://documentation.bamboohr.com/reference/b5c0155d30e7dc52aabacf0a2db87e48)

## Requirements

- **OAuth scopes:** `onboarding`
- **scope:** `onboarding` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
