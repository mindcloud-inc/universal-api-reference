# Get Legacy Report Field Map with BambooHR

Retrieves legacy report field map from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/custom-reports/legacy-field-map`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [Get Legacy Report Field Map](https://documentation.bamboohr.com/reference/get-legacy-report-field-map)

## Requirements

- **OAuth scopes:** `report`
- **scope:** `report` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
