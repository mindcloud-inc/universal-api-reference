# List Company Files and Categories with BambooHR

Lists company files and categories from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/files/view`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Company Files and Categories](https://documentation.bamboohr.com/reference/list-company-files)

## Requirements

- **OAuth scopes:** `company_file`
- **scope:** `company_file` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
