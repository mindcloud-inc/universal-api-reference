# Get Time Off Policies with BambooHR

Retrieves time off policies from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/meta/time_off/policies`
- **Base URL:** `https://mindcloud.bamboohr.com/api`
- **Official documentation:** [Get Time Off Policies](https://documentation.bamboohr.com/reference/get-time-off-policies-1)
