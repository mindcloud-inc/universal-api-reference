# List Currency Types with BambooHR

Lists currency types from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/meta/currency/types`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Currency Types](https://documentation.bamboohr.com/reference/get-all-currency-types)
