# Get Fields with BambooHR

Retrieves available field metadata from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/meta/fields`
- **Base URL:** `https://mindcloud.bamboohr.com/api`
- **Official documentation:** [Get Fields](https://documentation.bamboohr.com/reference/metadata-get-a-list-of-fields-1)
