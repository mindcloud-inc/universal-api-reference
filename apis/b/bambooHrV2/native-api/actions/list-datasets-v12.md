# List Datasets V1 2 with BambooHR

Lists datasets v1 2 from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1_2/datasets`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Datasets V1 2](https://documentation.bamboohr.com/reference/list-datasets-v1_2)

## Requirements

- **OAuth scopes:** `report`
- **scope:** `report` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
