# List Compensation Benchmark Sources with BambooHR

Lists compensation benchmark sources from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/compensation/benchmarks/sources`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Compensation Benchmark Sources](https://documentation.bamboohr.com/reference/list-compensation-benchmark-sources)

## Requirements

- **OAuth scopes:** `compensation_benchmarks`
- **scope:** `compensation_benchmarks` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
