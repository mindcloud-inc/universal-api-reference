# List Monitor Fields with BambooHR

Lists monitor fields from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks/monitor_fields`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Monitor Fields](https://documentation.bamboohr.com/reference/list-monitor-fields)

## Requirements

- **OAuth scopes:** `webhooks`
- **scope:** `webhooks` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
