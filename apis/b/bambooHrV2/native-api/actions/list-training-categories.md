# List Training Categories with BambooHR

Lists training categories from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/training/category`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Training Categories](https://documentation.bamboohr.com/reference/list-training-categories)

## Requirements

- **OAuth scopes:** `training`
- **scope:** `training` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
