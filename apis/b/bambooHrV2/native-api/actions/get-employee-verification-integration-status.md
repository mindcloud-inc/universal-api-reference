# Get Employee Verification Integration Status with BambooHR

Retrieves employee verification integration status from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/employee-verifications/integration`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [Get Employee Verification Integration Status](https://documentation.bamboohr.com/reference/get-employee-verification-integration)

## Requirements

- **OAuth scopes:** `employee_verifications`
- **scope:** `employee_verifications` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
