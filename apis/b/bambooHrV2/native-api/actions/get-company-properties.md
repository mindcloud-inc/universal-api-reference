# Get Company Properties with BambooHR

Retrieves company properties from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/meta/company`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [Get Company Properties](https://documentation.bamboohr.com/reference/get-meta-company)

## Requirements

- **OAuth scopes:** `company:info`
- **scope:** `company:info` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
