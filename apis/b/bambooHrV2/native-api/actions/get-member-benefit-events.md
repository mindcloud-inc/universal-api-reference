# Get Member Benefit Events with BambooHR

Retrieves member benefit events from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/benefit/member_benefit`
- **Base URL:** `https://mindcloud.bamboohr.com/api`
- **Official documentation:** [Get Member Benefit Events](https://documentation.bamboohr.com/reference/get-member-benefit-2)
