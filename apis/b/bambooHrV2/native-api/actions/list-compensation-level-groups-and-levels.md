# List Compensation Level Groups and Levels with BambooHR

Lists compensation level groups and levels from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/pay-grades-and-bands/levels`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Compensation Level Groups and Levels](https://documentation.bamboohr.com/reference/list-compensation-level-groups-and-levels)

## Requirements

- **OAuth scopes:** `pay_grades_and_bands`
- **scope:** `pay_grades_and_bands` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
