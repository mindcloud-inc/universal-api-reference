# List Job Titles with Employees with BambooHR

Lists job titles with employees from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/pay-grades-and-bands/job-titles-with-employees`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Job Titles with Employees](https://documentation.bamboohr.com/reference/list-job-titles-with-employees)

## Requirements

- **OAuth scopes:** `pay_grades_and_bands`
- **scope:** `pay_grades_and_bands` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
