# List Custom Tables with BambooHR

Lists custom tables from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/hris/custom-tables`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Custom Tables](https://documentation.bamboohr.com/reference/list-custom-tables)

## Requirements

- **OAuth scopes:** `employee:custom_fields`
- **scope:** `employee:custom_fields` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.

## Capabilities

This operation supports [pagination](../README.md#pagination).
