# Get Benefit Deduction Types with BambooHR

Retrieves benefit deduction types from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/benefits/settings/deduction_types/all`
- **Base URL:** `https://mindcloud.bamboohr.com/api`
- **Official documentation:** [Get Benefit Deduction Types](https://documentation.bamboohr.com/reference/get-benefit-deduction-types-2)
