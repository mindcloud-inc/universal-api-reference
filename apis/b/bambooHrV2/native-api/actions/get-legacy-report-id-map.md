# Get Legacy Report ID Map with BambooHR

Retrieves legacy report id map from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/custom-reports/legacy-id-map`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [Get Legacy Report ID Map](https://documentation.bamboohr.com/reference/get-legacy-report-id-map)

## Requirements

- **OAuth scopes:** `report`
- **scope:** `report` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
