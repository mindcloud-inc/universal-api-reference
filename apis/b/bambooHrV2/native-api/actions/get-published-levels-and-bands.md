# Get Published Levels and Bands with BambooHR

Retrieves published levels and bands from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/pay-grades-and-bands`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [Get Published Levels and Bands](https://documentation.bamboohr.com/reference/get-published-levels-and-bands)

## Requirements

- **OAuth scopes:** `pay_grades_and_bands`
- **scope:** `pay_grades_and_bands` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
