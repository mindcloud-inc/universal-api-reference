# List Hiring Locations with BambooHR

Lists hiring locations from BambooHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/applicant_tracking/locations`
- **Base URL:** `https://{companyDomain}.bamboohr.com/api`
- **Official documentation:** [List Hiring Locations](https://documentation.bamboohr.com/reference/get-company-locations)

## Requirements

- **OAuth scopes:** `hiring:applications`
- **scope:** `hiring:applications` — BambooHR documents these OAuth scopes for this endpoint; access also follows the connected user permissions.
