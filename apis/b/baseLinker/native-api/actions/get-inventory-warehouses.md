# Get Inventory Warehouses with BaseLinker

Retrieves inventory warehouses from BaseLinker.

## Endpoint

- **Method:** `POST`
- **Path:** `/connector.php`
- **Base URL:** `https://api.baselinker.com`
- **Official documentation:** [Get Inventory Warehouses](https://api.baselinker.com/index.php?method=getInventoryWarehouses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inventory_id` | body | `number` | yes | Inventory identifier. |
