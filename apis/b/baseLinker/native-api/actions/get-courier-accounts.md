# Get Courier Accounts with BaseLinker

Retrieves courier accounts from BaseLinker.

## Endpoint

- **Method:** `POST`
- **Path:** `/connector.php`
- **Base URL:** `https://api.baselinker.com`
- **Official documentation:** [Get Courier Accounts](https://api.baselinker.com/index.php?method=getCourierAccounts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `courier_code` | body | `string` | yes |
