# Scrape Raw HTML from a URL with Brand.dev

Retrieves raw HTML from a URL using Brand.dev.

## Endpoint

- **Method:** `GET`
- **Path:** `/web/scrape/html`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Scrape Raw HTML from a URL](https://docs.context.dev/api-reference/web-scraping/scrape-raw-html-from-a-url)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Full URL to scrape raw HTML from. |
