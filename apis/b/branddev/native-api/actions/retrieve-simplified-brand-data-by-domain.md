# Retrieve Simplified Brand Data by Domain with Brand.dev

Retrieves simplified brand data from Brand.dev by domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/brand/retrieve-simplified`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Retrieve Simplified Brand Data by Domain](https://docs.context.dev/api-reference/retrieve-brand/retrieve-simplified-brand-data-by-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Domain name to retrieve simplified brand data for. |
