# Retrieve NAICS Code for Any Brand with Brand.dev

Retrieves a NAICS code for a brand in Brand.dev.

## Endpoint

- **Method:** `GET`
- **Path:** `/brand/naics`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Retrieve NAICS Code for Any Brand](https://docs.context.dev/api-reference/industry-classification/retrieve-naics-code-for-any-brand)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | query | `string` | yes | Brand name or domain to classify. |
