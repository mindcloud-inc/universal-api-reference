# Crawl Website Sitemap with Brand.dev

Retrieves sitemap data from a website using Brand.dev.

## Endpoint

- **Method:** `GET`
- **Path:** `/web/scrape/sitemap`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Crawl Website Sitemap](https://docs.context.dev/api-reference/web-scraping/crawl-website-sitemap)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Domain name to crawl the sitemap for. |
