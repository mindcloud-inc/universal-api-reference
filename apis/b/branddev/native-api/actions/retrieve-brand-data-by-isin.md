# Retrieve Brand Data by ISIN with Brand.dev

Retrieves brand data from Brand.dev by ISIN.

## Endpoint

- **Method:** `GET`
- **Path:** `/brand/retrieve-by-isin`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Retrieve Brand Data by ISIN](https://docs.context.dev/api-reference/retrieve-brand/retrieve-brand-data-by-isin)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `isin` | query | `string` | yes | ISIN to retrieve brand data for. |
