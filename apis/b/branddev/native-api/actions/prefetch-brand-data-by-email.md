# Prefetch Brand Data by Email with Brand.dev

Prefetches brand data in Brand.dev by email.

## Endpoint

- **Method:** `POST`
- **Path:** `/brand/prefetch-by-email`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Prefetch Brand Data by Email](https://docs.context.dev/api-reference/utility/prefetch-brand-data-by-email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Email address to prefetch brand data for. |
