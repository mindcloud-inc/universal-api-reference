# Extract Products from a Brand's Website with Brand.dev

Extracts product data from a brand website using Brand.dev.

## Endpoint

- **Method:** `POST`
- **Path:** `/brand/ai/products`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Extract Products from a Brand's Website](https://docs.context.dev/api-reference/ai-data-extraction/extract-products-from-a-brands-website)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | yes | Domain name to extract products from. |
