# Extract a Single Product from a URL with Brand.dev

Extracts product data from a URL using Brand.dev.

## Endpoint

- **Method:** `POST`
- **Path:** `/brand/ai/product`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Extract a Single Product from a URL](https://docs.context.dev/api-reference/ai-data-extraction/extract-a-single-product-from-a-url)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Product page URL to extract product data from. |
