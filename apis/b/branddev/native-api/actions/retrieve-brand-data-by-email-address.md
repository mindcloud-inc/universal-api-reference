# Retrieve Brand Data by Email Address with Brand.dev

Retrieves brand data from Brand.dev by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/brand/retrieve-by-email`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Retrieve Brand Data by Email Address](https://docs.context.dev/api-reference/retrieve-brand/retrieve-brand-data-by-email-address)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to retrieve brand data for. |
