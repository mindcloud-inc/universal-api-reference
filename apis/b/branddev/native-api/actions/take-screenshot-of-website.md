# Take Screenshot of Website with Brand.dev

Retrieves a website screenshot from Brand.dev.

## Endpoint

- **Method:** `GET`
- **Path:** `/brand/screenshot`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Take Screenshot of Website](https://docs.context.dev/api-reference/screenshot-styleguide/take-screenshot-of-website)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Domain name to take a screenshot of. |
