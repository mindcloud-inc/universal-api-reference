# Scrape URL and Convert to Markdown with Brand.dev

Retrieves markdown from a URL using Brand.dev.

## Endpoint

- **Method:** `GET`
- **Path:** `/web/scrape/markdown`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Scrape URL and Convert to Markdown](https://docs.context.dev/api-reference/web-scraping/scrape-url-and-convert-to-markdown)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Full URL to scrape and convert to Markdown. |
