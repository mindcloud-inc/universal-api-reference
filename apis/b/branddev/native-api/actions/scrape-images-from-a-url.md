# Scrape Images from a URL with Brand.dev

Retrieves images from a URL using Brand.dev.

## Endpoint

- **Method:** `GET`
- **Path:** `/web/scrape/images`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Scrape Images from a URL](https://docs.context.dev/api-reference/web-scraping/scrape-images-from-a-url)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Full URL to scrape images from. |
