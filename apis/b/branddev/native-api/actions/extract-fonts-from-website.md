# Extract Fonts from Website with Brand.dev

Retrieves website font data from Brand.dev.

## Endpoint

- **Method:** `GET`
- **Path:** `/brand/fonts`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Extract Fonts from Website](https://docs.context.dev/api-reference/screenshot-styleguide/extract-fonts-from-website)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Domain name to extract fonts from. |
