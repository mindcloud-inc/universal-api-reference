# Prefetch Brand Data for a Domain with Brand.dev

Prefetches brand data in Brand.dev for a domain.

## Endpoint

- **Method:** `POST`
- **Path:** `/brand/prefetch`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Prefetch Brand Data for a Domain](https://docs.context.dev/api-reference/utility/prefetch-brand-data-for-a-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | yes | Domain name to prefetch brand data for. |
