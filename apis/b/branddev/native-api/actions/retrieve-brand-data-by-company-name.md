# Retrieve Brand Data by Company Name with Brand.dev

Retrieves brand data from Brand.dev by company name.

## Endpoint

- **Method:** `GET`
- **Path:** `/brand/retrieve-by-name`
- **Base URL:** `https://api.brand.dev/v1`
- **Official documentation:** [Retrieve Brand Data by Company Name](https://docs.context.dev/api-reference/retrieve-brand/retrieve-brand-data-by-company-name)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Company name to retrieve brand data for. |
