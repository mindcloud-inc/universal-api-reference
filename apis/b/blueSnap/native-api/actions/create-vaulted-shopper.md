# Create Vaulted Shopper with BlueSnap

Creates a vaulted shopper in BlueSnap.

## Endpoint

- **Method:** `POST`
- **Path:** `/vaulted-shoppers`
- **Base URL:** `https://sandbox.bluesnap.com/services/2`
- **Official documentation:** [Create Vaulted Shopper](https://developers.bluesnap.com/v8976-JSON/reference/create-vaulted-shopper)
