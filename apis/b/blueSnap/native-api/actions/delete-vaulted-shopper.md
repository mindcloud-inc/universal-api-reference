# Delete Vaulted Shopper with BlueSnap

Deletes a vaulted shopper from BlueSnap.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/vaulted-shoppers/:vaultedShopperId`
- **Base URL:** `https://sandbox.bluesnap.com/services/2`
- **Official documentation:** [Delete Vaulted Shopper](https://developers.bluesnap.com/v8976-JSON/reference/delete-vaulted-shopper)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vaultedShopperId` | path | `string` | yes | ID of the vaulted shopper to delete. |
