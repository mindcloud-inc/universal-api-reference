# List Vaulted Shoppers with BlueSnap

Retrieves vaulted shoppers from BlueSnap.

## Endpoint

- **Method:** `GET`
- **Path:** `/vaulted-shoppers`
- **Base URL:** `https://sandbox.bluesnap.com/services/2`
- **Official documentation:** [List Vaulted Shoppers](https://developers.bluesnap.com/v8976-JSON/reference/retrieve-vaulted-shopper)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
