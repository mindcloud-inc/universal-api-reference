# List Store Products with BHuman

Retrieves available store products from BHuman.

## Endpoint

- **Method:** `GET`
- **Path:** `https://store.bhuman.ai/api/store/product`
- **Base URL:** `https://studio.bhuman.ai/api`
- **Official documentation:** [List Store Products](https://github.com/bhuman-ai/public_api#api-endpoints)
