# List Workspaces with BHuman

Retrieves available account workspaces from BHuman.

## Endpoint

- **Method:** `GET`
- **Path:** `https://user.bhuman.ai/api/workspace`
- **Base URL:** `https://studio.bhuman.ai/api`
- **Official documentation:** [List Workspaces](https://github.com/bhuman-ai/public_api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | Optional workspace ID filter. |
