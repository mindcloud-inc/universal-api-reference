# Get Video Instance with BHuman

Retrieves an AI Studio video instance from BHuman.

## Endpoint

- **Method:** `GET`
- **Path:** `/ai_studio/video_instance`
- **Base URL:** `https://studio.bhuman.ai/api`
- **Official documentation:** [Get Video Instance](https://github.com/bhuman-ai/public_api#api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The BHuman video instance ID. |
