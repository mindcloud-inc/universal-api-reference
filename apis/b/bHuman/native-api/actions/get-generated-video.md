# Get Generated Video with BHuman

Retrieves a generated video from BHuman.

## Endpoint

- **Method:** `GET`
- **Path:** `/ai_studio/generated_video_by_id`
- **Base URL:** `https://studio.bhuman.ai/api`
- **Official documentation:** [Get Generated Video](https://github.com/bhuman-ai/public_api#api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The generated video ID returned by a generate action. |
