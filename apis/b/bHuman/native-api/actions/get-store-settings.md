# Get Store Settings with BHuman

Retrieves store categories and tags from BHuman.

## Endpoint

- **Method:** `GET`
- **Path:** `https://store.bhuman.ai/api/store/settings`
- **Base URL:** `https://studio.bhuman.ai/api`
- **Official documentation:** [Get Store Settings](https://github.com/bhuman-ai/public_api#api-endpoints)
