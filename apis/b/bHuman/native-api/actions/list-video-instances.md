# List Video Instances with BHuman

Retrieves AI Studio video instances from BHuman.

## Endpoint

- **Method:** `GET`
- **Path:** `/ai_studio/video_instances`
- **Base URL:** `https://studio.bhuman.ai/api`
- **Official documentation:** [List Video Instances](https://github.com/bhuman-ai/public_api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
