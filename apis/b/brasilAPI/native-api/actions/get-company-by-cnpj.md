# Get Company by CNPJ with Brasil API

Retrieves company details from Brasil API by CNPJ.

## Endpoint

- **Method:** `GET`
- **Path:** `/cnpj/v1/{cnpj}`
- **Base URL:** `https://brasilapi.com.br/api`
- **Official documentation:** [Get Company by CNPJ](https://brasilapi.com.br/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cnpj` | path | `string` | yes | The 14-digit CNPJ identifier. |
