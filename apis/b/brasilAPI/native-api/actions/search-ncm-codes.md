# Search NCM Codes with Brasil API

Finds NCM codes in Brasil API by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/ncm/v1`
- **Base URL:** `https://brasilapi.com.br/api`
- **Official documentation:** [Search NCM Codes](https://brasilapi.com.br/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | yes | The NCM code or description search term. |
