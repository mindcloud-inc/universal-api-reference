# Search CPTEC Cities with Brasil API

Finds CPTEC cities in Brasil API by city name.

## Endpoint

- **Method:** `GET`
- **Path:** `/cptec/v1/cidade/{cityName}`
- **Base URL:** `https://brasilapi.com.br/api`
- **Official documentation:** [Search CPTEC Cities](https://brasilapi.com.br/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cityName` | path | `string` | yes | The full or partial city name to search. |
