# Get Domain Status with Brasil API

Retrieves a .br domain status from Brasil API.

## Endpoint

- **Method:** `GET`
- **Path:** `/registrobr/v1/{domain}`
- **Base URL:** `https://brasilapi.com.br/api`
- **Official documentation:** [Get Domain Status](https://brasilapi.com.br/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | The .br domain to evaluate. |
