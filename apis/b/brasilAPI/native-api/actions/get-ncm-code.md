# Get NCM Code with Brasil API

Retrieves an NCM code from Brasil API by code.

## Endpoint

- **Method:** `GET`
- **Path:** `/ncm/v1/{code}`
- **Base URL:** `https://brasilapi.com.br/api`
- **Official documentation:** [Get NCM Code](https://brasilapi.com.br/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | The NCM code to look up. |
