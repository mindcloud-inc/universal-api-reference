# Get City Weather Forecast with Brasil API

Retrieves a one-day city weather forecast from Brasil API.

## Endpoint

- **Method:** `GET`
- **Path:** `/cptec/v1/clima/previsao/{cityCode}`
- **Base URL:** `https://brasilapi.com.br/api`
- **Official documentation:** [Get City Weather Forecast](https://brasilapi.com.br/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cityCode` | path | `string` | yes | The CPTEC city code. |
