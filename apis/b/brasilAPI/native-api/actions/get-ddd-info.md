# Get DDD Info with Brasil API

Retrieves DDD cities and state information from Brasil API.

## Endpoint

- **Method:** `GET`
- **Path:** `/ddd/v1/{ddd}`
- **Base URL:** `https://brasilapi.com.br/api`
- **Official documentation:** [Get DDD Info](https://brasilapi.com.br/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ddd` | path | `string` | yes | The Brazilian telephone area code. |
