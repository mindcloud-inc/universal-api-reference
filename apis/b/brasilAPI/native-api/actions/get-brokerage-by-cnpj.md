# Get Brokerage by CNPJ with Brasil API

Retrieves a brokerage from Brasil API by CNPJ.

## Endpoint

- **Method:** `GET`
- **Path:** `/cvm/corretoras/v1/{cnpj}`
- **Base URL:** `https://brasilapi.com.br/api`
- **Official documentation:** [Get Brokerage by CNPJ](https://brasilapi.com.br/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cnpj` | path | `string` | yes | The brokerage CNPJ identifier. |
