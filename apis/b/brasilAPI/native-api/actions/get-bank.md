# Get Bank with Brasil API

Retrieves a bank from Brasil API by code.

## Endpoint

- **Method:** `GET`
- **Path:** `/banks/v1/{code}`
- **Base URL:** `https://brasilapi.com.br/api`
- **Official documentation:** [Get Bank](https://brasilapi.com.br/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | The bank code to look up. |
