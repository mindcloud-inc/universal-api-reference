# List National Holidays with Brasil API

Retrieves Brazilian national holidays from Brasil API by year.

## Endpoint

- **Method:** `GET`
- **Path:** `/feriados/v1/{ano}`
- **Base URL:** `https://brasilapi.com.br/api`
- **Official documentation:** [List National Holidays](https://brasilapi.com.br/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ano` | path | `string` | yes | The year to list national holidays for. |
