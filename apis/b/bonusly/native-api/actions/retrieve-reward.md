# Retrieve Reward with Bonusly

Retrieves a reward from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/rewards/:id`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Retrieve Reward](https://docs.bonus.ly/reference/retrieve-a-reward)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The reward ID. |
