# Get Points Received with Bonusly

Retrieves received points analytics from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/data_layer/recognition/points_received`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Get Points Received](https://docs.bonus.ly/reference/get_v1-data-layer-recognition-points-received)
