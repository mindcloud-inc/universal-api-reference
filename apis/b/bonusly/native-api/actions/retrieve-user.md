# Retrieve User with Bonusly

Retrieves a user from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Retrieve User](https://docs.bonus.ly/reference/retrieve-a-user-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Bonusly user ID to retrieve. |
