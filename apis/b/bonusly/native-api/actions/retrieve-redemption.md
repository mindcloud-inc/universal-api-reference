# Retrieve Redemption with Bonusly

Retrieves a redemption from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/redemptions/:id`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Retrieve Redemption](https://docs.bonus.ly/reference/retrieve-a-redemption)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The redemption ID. |
