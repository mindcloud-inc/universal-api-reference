# List Bonuses with Bonusly

Retrieves bonuses from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/bonuses`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [List Bonuses](https://docs.bonus.ly/reference/list-bonuses)

## Capabilities

This operation supports [pagination](../README.md#pagination).
