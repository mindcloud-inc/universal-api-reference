# Get Recognition Add-ons with Bonusly

Retrieves recognition add-on analytics from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/data_layer/recognition/addons`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Get Recognition Add-ons](https://docs.bonus.ly/reference/get_v1-data-layer-recognition-addons)
