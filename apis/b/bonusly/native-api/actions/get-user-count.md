# Get User Count with Bonusly

Retrieves recognition user counts from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/data_layer/recognition/user_count`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Get User Count](https://docs.bonus.ly/reference/get_v1-data-layer-recognition-user-count)
