# Get Company Value Hashtags Received with Bonusly

Retrieves company value hashtag analytics from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/data_layer/recognition/hashtags_core_value`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Get Company Value Hashtags Received](https://docs.bonus.ly/reference/get_v1-data-layer-recognition-hashtags-core-value)
