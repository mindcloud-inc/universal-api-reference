# Retrieve Bonus with Bonusly

Retrieves a bonus from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/bonuses/:id`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Retrieve Bonus](https://docs.bonus.ly/reference/retrieve-a-bonus)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Bonusly bonus ID to retrieve. |
