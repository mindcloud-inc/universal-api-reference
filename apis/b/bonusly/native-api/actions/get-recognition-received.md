# Get Recognition Received with Bonusly

Retrieves received recognition analytics from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/data_layer/recognition/bonuses_received`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Get Recognition Received](https://docs.bonus.ly/reference/get_v1-data-layer-recognition-bonuses-received)
