# Get SCIM Metadata with Bonusly

Retrieves SCIM service provider metadata from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bonus.ly/api/scim11/ServiceProviderConfigs`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Get SCIM Metadata](https://docs.bonus.ly/reference/get-metadata-about-the-bonusly-scim-api)
