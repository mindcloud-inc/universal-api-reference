# Get Participation Rates with Bonusly

Retrieves participation rates from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/data_layer/participation`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Get Participation Rates](https://docs.bonus.ly/reference/get_v1-data-layer-participation)
