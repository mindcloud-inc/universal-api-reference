# Remove Webhook with Bonusly

Deletes an existing webhook from Bonusly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Remove Webhook](https://docs.bonus.ly/reference/remove-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The webhook ID. |
