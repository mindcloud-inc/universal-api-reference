# Get Recognition Rates with Bonusly

Retrieves recognition rates from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/data_layer/recognition/rates`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Get Recognition Rates](https://docs.bonus.ly/reference/get_v1-data-layer-recognition-rates)
