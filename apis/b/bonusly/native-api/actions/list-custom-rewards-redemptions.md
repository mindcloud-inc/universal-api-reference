# List Custom Rewards Redemptions with Bonusly

Retrieves custom reward redemptions from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom_rewards_redemptions`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [List Custom Rewards Redemptions](https://docs.bonus.ly/reference/list-custom-rewards-redemptions)
