# Search Users with Bonusly

Finds users in Bonusly by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/autocomplete`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Search Users](https://docs.bonus.ly/reference/autocomplete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search text for user autocomplete. |
