# Admin Deactivate User with Bonusly

Deactivates an existing user in Bonusly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:id`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Admin Deactivate User](https://docs.bonus.ly/reference/admin-deactivate-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Bonusly user ID. |
