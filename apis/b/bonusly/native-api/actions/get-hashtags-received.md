# Get Hashtags Received with Bonusly

Retrieves received hashtag analytics from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/data_layer/recognition/hashtags_all`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [Get Hashtags Received](https://docs.bonus.ly/reference/get_v1-data-layer-recognition-hashtags-all)
