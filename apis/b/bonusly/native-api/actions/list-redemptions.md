# List Redemptions with Bonusly

Retrieves redemptions from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/redemptions`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [List Redemptions](https://docs.bonus.ly/reference/list-redemptions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
