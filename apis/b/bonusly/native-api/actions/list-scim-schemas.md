# List SCIM Schemas with Bonusly

Retrieves SCIM schemas from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bonus.ly/api/scim11/Schemas`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [List SCIM Schemas](https://docs.bonus.ly/reference/list-the-scim-schemas-supported-by-bonusly)
