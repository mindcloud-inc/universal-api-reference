# List Users with Bonusly

Retrieves users from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [List Users](https://docs.bonus.ly/reference/list-users-1)

## Capabilities

This operation supports [pagination](../README.md#pagination).
