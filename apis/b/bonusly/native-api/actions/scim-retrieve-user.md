# SCIM Retrieve User with Bonusly

Retrieves a SCIM user from Bonusly.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bonus.ly/api/scim11/Users/:id`
- **Base URL:** `https://bonus.ly/api/v1`
- **Official documentation:** [SCIM Retrieve User](https://docs.bonus.ly/reference/list-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The SCIM user ID. |
