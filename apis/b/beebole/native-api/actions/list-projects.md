# List Projects with Beebole

Retrieves projects from your Beebole account.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://beebole-apps.com/api/v2`
- **Official documentation:** [List Projects](https://beebole.com/help/api#list-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company.id` | body | `number` | yes | The Beebole company ID whose projects should be listed. |
