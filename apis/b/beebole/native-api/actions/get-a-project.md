# Get a Project with Beebole

Retrieves a project from your Beebole account.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://beebole-apps.com/api/v2`
- **Official documentation:** [Get a Project](https://beebole.com/help/api#get-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | The Beebole project ID to retrieve. |
