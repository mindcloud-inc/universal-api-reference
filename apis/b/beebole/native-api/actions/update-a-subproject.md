# Update a Subproject with Beebole

Updates an existing subproject in Beebole.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://beebole-apps.com/api/v2`
- **Official documentation:** [Update a Subproject](https://beebole.com/help/api#update-a-subproject)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subproject.id` | body | `number` | yes |
| `subproject.name` | body | `string` | no |
