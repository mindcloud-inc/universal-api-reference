# Activate a Subproject with Beebole

Activates a subproject in Beebole.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://beebole-apps.com/api/v2`
- **Official documentation:** [Activate a Subproject](https://beebole.com/help/api#activate-a-subproject)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `number` | yes |
