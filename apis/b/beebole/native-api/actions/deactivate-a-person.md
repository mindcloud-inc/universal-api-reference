# Deactivate a Person with Beebole

Deactivates a person in Beebole.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://beebole-apps.com/api/v2`
- **Official documentation:** [Deactivate a Person](https://beebole.com/help/api#deactivate-a-person)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `number` | yes |
