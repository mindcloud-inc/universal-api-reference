# Deactivate a Company with Beebole

Deactivates a company in Beebole.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://beebole-apps.com/api/v2`
- **Official documentation:** [Deactivate a Company](https://beebole.com/help/api#deactivate-a-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | The Beebole company ID to deactivate. |
