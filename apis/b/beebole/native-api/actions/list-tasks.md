# List Tasks with Beebole

Retrieves tasks from your Beebole account.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://beebole-apps.com/api/v2`
- **Official documentation:** [List Tasks](https://beebole.com/help/api#list-tasks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company.id` | body | `number` | yes |
