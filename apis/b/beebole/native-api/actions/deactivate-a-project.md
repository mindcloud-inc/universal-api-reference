# Deactivate a Project with Beebole

Deactivates a project in Beebole.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://beebole-apps.com/api/v2`
- **Official documentation:** [Deactivate a Project](https://beebole.com/help/api#deactivate-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | The Beebole project ID to deactivate. |
