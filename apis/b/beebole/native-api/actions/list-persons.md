# List Persons with Beebole

Retrieves people from your Beebole account.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://beebole-apps.com/api/v2`
- **Official documentation:** [List Persons](https://beebole.com/help/api#list-persons)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company.id` | body | `number` | yes | The Beebole company identifier whose people should be listed. |
