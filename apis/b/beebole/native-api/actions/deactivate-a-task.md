# Deactivate a Task with Beebole

Deactivates a task in Beebole.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://beebole-apps.com/api/v2`
- **Official documentation:** [Deactivate a Task](https://beebole.com/help/api#deactivate-a-task)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `number` | yes |
