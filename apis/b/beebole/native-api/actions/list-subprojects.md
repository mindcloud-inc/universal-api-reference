# List Subprojects with Beebole

Retrieves subprojects from your Beebole account.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://beebole-apps.com/api/v2`
- **Official documentation:** [List Subprojects](https://beebole.com/help/api#list-subprojects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project.id` | body | `number` | yes |
