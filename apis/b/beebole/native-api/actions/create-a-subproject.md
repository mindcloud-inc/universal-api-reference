# Create a Subproject with Beebole

Creates a new subproject in Beebole.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://beebole-apps.com/api/v2`
- **Official documentation:** [Create a Subproject](https://beebole.com/help/api#create-a-subproject)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subproject.name` | body | `string` | yes |
| `subproject.project.id` | body | `number` | yes |
