# Get Exploration with Better Stack Telemetry

Retrieves an exploration from Better Stack Telemetry.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/explorations/:id`
- **Base URL:** `https://telemetry.betterstack.com`
- **Official documentation:** [Get Exploration](https://betterstack.com/docs/logs/api/explorations/get/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the exploration to retrieve. |
