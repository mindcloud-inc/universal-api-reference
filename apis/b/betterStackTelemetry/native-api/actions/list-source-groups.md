# List Source Groups with Better Stack Telemetry

Retrieves source groups from Better Stack Telemetry.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/source-groups`
- **Base URL:** `https://telemetry.betterstack.com`
- **Official documentation:** [List Source Groups](https://betterstack.com/docs/logs/api/list-all-existing-source-groups/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
