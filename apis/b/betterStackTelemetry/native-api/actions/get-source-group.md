# Get Source Group with Better Stack Telemetry

Retrieves a source group from Better Stack Telemetry.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/source-groups/:source_group_id`
- **Base URL:** `https://telemetry.betterstack.com`
- **Official documentation:** [Get Source Group](https://betterstack.com/docs/logs/api/getting-a-single-source-group/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `source_group_id` | path | `string` | yes | ID of the source group to retrieve |
