# Get Source with Better Stack Telemetry

Retrieves a telemetry source from Better Stack Telemetry.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/sources/:source_id`
- **Base URL:** `https://telemetry.betterstack.com`
- **Official documentation:** [Get Source](https://betterstack.com/docs/logs/api/get-a-single-source/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `source_id` | path | `string` | yes | ID of the source to retrieve |
