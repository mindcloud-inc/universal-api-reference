# List Sources with Better Stack Telemetry

Retrieves telemetry sources from Better Stack Telemetry.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/sources`
- **Base URL:** `https://telemetry.betterstack.com`
- **Official documentation:** [List Sources](https://betterstack.com/docs/logs/api/list-all-existing-sources/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
