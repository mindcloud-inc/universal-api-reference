# Get Dashboard with Better Stack Telemetry

Retrieves a dashboard from Better Stack Telemetry.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/dashboards/:id`
- **Base URL:** `https://telemetry.betterstack.com`
- **Official documentation:** [Get Dashboard](https://betterstack.com/docs/logs/api/dashboards/get/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the dashboard. |
