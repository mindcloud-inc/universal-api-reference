# List Dashboard Templates with Better Stack Telemetry

Retrieves dashboard templates from Better Stack Telemetry.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/dashboards/templates`
- **Base URL:** `https://telemetry.betterstack.com`
- **Official documentation:** [List Dashboard Templates](https://betterstack.com/docs/logs/api/dashboards/templates/)
