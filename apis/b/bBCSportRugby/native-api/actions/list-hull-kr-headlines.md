# List Hull KR Headlines with BBC Sport - Rugby

Retrieves Hull KR headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-league/teams/hull-kr/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Hull KR Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
