# List Ireland Rugby Team Headlines with BBC Sport - Rugby

Retrieves Ireland rugby team headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/teams/ireland/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Ireland Rugby Team Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
