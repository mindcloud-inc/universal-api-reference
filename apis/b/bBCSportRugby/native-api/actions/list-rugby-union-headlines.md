# List Rugby Union Headlines with BBC Sport - Rugby

Retrieves rugby union headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Rugby Union Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
