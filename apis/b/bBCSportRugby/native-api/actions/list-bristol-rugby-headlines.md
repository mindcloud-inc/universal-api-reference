# List Bristol Rugby Headlines with BBC Sport - Rugby

Retrieves Bristol rugby headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/teams/bristol/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Bristol Rugby Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
