# List Harlequins Rugby Headlines with BBC Sport - Rugby

Retrieves Harlequins rugby headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/teams/harlequins/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Harlequins Rugby Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
