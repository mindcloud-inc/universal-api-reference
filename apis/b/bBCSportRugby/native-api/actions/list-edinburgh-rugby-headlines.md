# List Edinburgh Rugby Headlines with BBC Sport - Rugby

Retrieves Edinburgh rugby headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/teams/edinburgh/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Edinburgh Rugby Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
