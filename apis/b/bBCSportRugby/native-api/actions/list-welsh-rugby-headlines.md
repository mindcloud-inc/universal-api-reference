# List Welsh Rugby Headlines with BBC Sport - Rugby

Retrieves Welsh rugby headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/welsh/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Welsh Rugby Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
