# List Leicester Rugby Headlines with BBC Sport - Rugby

Retrieves Leicester rugby headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/teams/leicester/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Leicester Rugby Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
