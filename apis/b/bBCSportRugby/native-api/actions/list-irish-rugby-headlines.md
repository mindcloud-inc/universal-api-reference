# List Irish Rugby Headlines with BBC Sport - Rugby

Retrieves Irish rugby headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/irish/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Irish Rugby Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
