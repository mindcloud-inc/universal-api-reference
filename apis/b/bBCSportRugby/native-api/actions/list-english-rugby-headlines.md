# List English Rugby Headlines with BBC Sport - Rugby

Retrieves English rugby headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/english/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List English Rugby Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
