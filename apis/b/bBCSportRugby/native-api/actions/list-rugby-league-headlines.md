# List Rugby League Headlines with BBC Sport - Rugby

Retrieves rugby league headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-league/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Rugby League Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
