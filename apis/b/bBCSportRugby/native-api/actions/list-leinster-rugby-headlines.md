# List Leinster Rugby Headlines with BBC Sport - Rugby

Retrieves Leinster rugby headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/teams/leinster/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Leinster Rugby Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
