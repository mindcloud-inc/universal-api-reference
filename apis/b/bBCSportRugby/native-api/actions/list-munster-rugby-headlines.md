# List Munster Rugby Headlines with BBC Sport - Rugby

Retrieves Munster rugby headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/teams/munster/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Munster Rugby Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
