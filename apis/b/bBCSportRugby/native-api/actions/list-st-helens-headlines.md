# List St Helens Headlines with BBC Sport - Rugby

Retrieves St Helens headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-league/teams/st-helens/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List St Helens Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
