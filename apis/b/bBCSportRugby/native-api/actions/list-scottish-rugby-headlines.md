# List Scottish Rugby Headlines with BBC Sport - Rugby

Retrieves Scottish rugby headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/scottish/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Scottish Rugby Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
