# List Bath Rugby Headlines with BBC Sport - Rugby

Retrieves Bath rugby headlines from BBC Sport - Rugby.

## Endpoint

- **Method:** `GET`
- **Path:** `/rugby-union/teams/bath/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk/sport`
- **Official documentation:** [List Bath Rugby Headlines](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)
