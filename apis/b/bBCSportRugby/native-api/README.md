# BBC Sport - Rugby: Native API Reference

A consolidated summary of BBC Sport - Rugby's API configuration and 20 documented operations, with links to official documentation.

- **Official docs:** https://support.bbc.co.uk/platform/feeds/SportFeeds.htm
- **API base URL:** `https://feeds.bbci.co.uk/sport`

## Authentication

### No Auth

Public BBC Sport RSS feeds are accessible without credentials.

This API does not require request authentication.

[Official authentication documentation](https://support.bbc.co.uk/platform/feeds/SportFeeds.htm)

## API conventions

Responses from this API use XML.
