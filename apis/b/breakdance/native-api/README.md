# Breakdance: Native API Reference

A consolidated summary of Breakdance's API configuration, with links to official documentation.

- **Official docs:** https://breakdance.com/documentation/forms/actions-and-integrations/

## Authentication

### No Authentication

Breakdance sends form submissions to MindCloud through its built-in Webhook action.

This API does not require request authentication.

[Official authentication documentation](https://breakdance.com/documentation/forms/actions-and-integrations/webhooks-and-api-integrations/)
