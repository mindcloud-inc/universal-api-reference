# List Post Comments with BlogIn

Retrieves comments for a BlogIn post.

## Endpoint

- **Method:** `GET`
- **Path:** `/posts/:id/comments`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [List Post Comments](https://blogin.co/api/rest/docs/#get-all-post-comments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the post whose comments to list. |
