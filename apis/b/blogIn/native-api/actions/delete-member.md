# Delete Member with BlogIn

Deletes an existing member from BlogIn.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/members/:id`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [Delete Member](https://blogin.co/api/rest/docs/#delete-a-specific-member)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the member to delete. |
