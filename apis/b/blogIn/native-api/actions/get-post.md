# Get Post with BlogIn

Retrieves a specific post from BlogIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/posts/:id`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [Get Post](https://blogin.co/api/rest/docs/#get-a-specific-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the post to retrieve. |
