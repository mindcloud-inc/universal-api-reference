# Get Category with BlogIn

Retrieves a specific category from BlogIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories/:id`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [Get Category](https://blogin.co/api/rest/docs/#get-a-specific-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the category to retrieve. |
