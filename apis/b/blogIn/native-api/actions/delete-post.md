# Delete Post with BlogIn

Deletes an existing post from BlogIn.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/posts/:id`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [Delete Post](https://blogin.co/api/rest/docs/#delete-a-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the post to delete. |
