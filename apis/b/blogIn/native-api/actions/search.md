# Search with BlogIn

Finds matching content in BlogIn by search terms.

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [Search](https://blogin.co/api/rest/docs/#search-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `terms` | query | `string` | yes | The search terms to look up. |
