# Delete Category with BlogIn

Deletes an existing category from BlogIn.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/categories/:id`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [Delete Category](https://blogin.co/api/rest/docs/#delete-a-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the category to delete. |
