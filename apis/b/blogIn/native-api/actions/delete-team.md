# Delete Team with BlogIn

Deletes an existing team from BlogIn.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/teams/:id`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [Delete Team](https://blogin.co/api/rest/docs/#delete-a-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the team to delete. |
