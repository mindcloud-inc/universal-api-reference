# List Pages with BlogIn

Retrieves all pages from BlogIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/pages`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [List Pages](https://blogin.co/api/rest/docs/#get-all-pages)

## Capabilities

This operation supports [sorting](../README.md#sorting).
