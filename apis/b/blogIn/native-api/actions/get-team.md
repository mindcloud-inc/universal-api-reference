# Get Team with BlogIn

Retrieves a specific team from BlogIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:id`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [Get Team](https://blogin.co/api/rest/docs/#get-a-specific-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the team to retrieve. |
