# List Posts with BlogIn

Retrieves all posts from BlogIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/posts`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [List Posts](https://blogin.co/api/rest/docs/#get-all-posts)

## Capabilities

This operation supports [sorting](../README.md#sorting).
