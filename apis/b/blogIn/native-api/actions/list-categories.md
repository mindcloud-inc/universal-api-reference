# List Categories with BlogIn

Retrieves all categories from BlogIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [List Categories](https://blogin.co/api/rest/docs/#get-all-categories)

## Capabilities

This operation supports [sorting](../README.md#sorting).
