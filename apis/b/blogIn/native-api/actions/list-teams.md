# List Teams with BlogIn

Retrieves all teams from BlogIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [List Teams](https://blogin.co/api/rest/docs/#get-all-teams)

## Capabilities

This operation supports [sorting](../README.md#sorting).
