# Delete Page with BlogIn

Deletes an existing page from BlogIn.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pages/:id`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [Delete Page](https://blogin.co/api/rest/docs/#delete-a-page)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the page to delete. |
