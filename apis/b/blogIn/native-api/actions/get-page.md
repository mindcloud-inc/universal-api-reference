# Get Page with BlogIn

Retrieves a specific page from BlogIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/pages/:id`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [Get Page](https://blogin.co/api/rest/docs/#get-a-specific-page)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the page to retrieve. |
