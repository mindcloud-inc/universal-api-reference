# Get Member with BlogIn

Retrieves a specific member from BlogIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/members/:id`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [Get Member](https://blogin.co/api/rest/docs/#get-a-specific-member)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the member to retrieve. |
