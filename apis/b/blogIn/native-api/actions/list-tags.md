# List Tags with BlogIn

Retrieves all tags from BlogIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://blogin.co/api/rest`
- **Official documentation:** [List Tags](https://blogin.co/api/rest/docs/#get-all-tags)

## Capabilities

This operation supports [sorting](../README.md#sorting).
