# Get Token Transfers with Blockscout

Retrieves blockchain token transfers from Blockscout.

## Endpoint

- **Method:** `GET`
- **Path:** `/:chain_id/api/v2/token-transfers`
- **Base URL:** `https://api.blockscout.com`
- **Official documentation:** [Get Token Transfers](https://docs.blockscout.com/api-reference/get-token-transfers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chain_id` | path | `string` | no |
