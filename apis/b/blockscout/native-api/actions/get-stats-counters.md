# Get Stats Counters with Blockscout

Retrieves current stats counters from Blockscout.

## Endpoint

- **Method:** `GET`
- **Path:** `/:chain_id/api/v2/stats`
- **Base URL:** `https://api.blockscout.com`
- **Official documentation:** [Get Stats Counters](https://docs.blockscout.com/api-reference/get-stats-counters)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chain_id` | path | `string` | no |
