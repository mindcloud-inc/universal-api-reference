# Get Transactions Chart with Blockscout

Retrieves transaction chart data from Blockscout.

## Endpoint

- **Method:** `GET`
- **Path:** `/:chain_id/api/v2/stats/charts/transactions`
- **Base URL:** `https://api.blockscout.com`
- **Official documentation:** [Get Transactions Chart](https://docs.blockscout.com/api-reference/get-transactions-chart)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chain_id` | path | `string` | no |
