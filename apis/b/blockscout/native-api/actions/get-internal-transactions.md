# Get Internal Transactions with Blockscout

Retrieves blockchain internal transactions from Blockscout.

## Endpoint

- **Method:** `GET`
- **Path:** `/:chain_id/api/v2/internal-transactions`
- **Base URL:** `https://api.blockscout.com`
- **Official documentation:** [Get Internal Transactions](https://docs.blockscout.com/api-reference/get-internal-transactions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chain_id` | path | `string` | no |
