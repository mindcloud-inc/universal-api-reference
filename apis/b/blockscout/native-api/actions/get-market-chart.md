# Get Market Chart with Blockscout

Retrieves market chart data from Blockscout.

## Endpoint

- **Method:** `GET`
- **Path:** `/:chain_id/api/v2/stats/charts/market`
- **Base URL:** `https://api.blockscout.com`
- **Official documentation:** [Get Market Chart](https://docs.blockscout.com/api-reference/get-market-chart)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chain_id` | path | `string` | no |
