# Get Main Page Transactions with Blockscout

Retrieves main page transactions from Blockscout.

## Endpoint

- **Method:** `GET`
- **Path:** `/:chain_id/api/v2/main-page/transactions`
- **Base URL:** `https://api.blockscout.com`
- **Official documentation:** [Get Main Page Transactions](https://docs.blockscout.com/api-reference/get-main-page-transactions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chain_id` | path | `string` | no |
