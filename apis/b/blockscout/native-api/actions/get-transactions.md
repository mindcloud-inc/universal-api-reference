# Get Transactions with Blockscout

Retrieves blockchain transaction listings from Blockscout.

## Endpoint

- **Method:** `GET`
- **Path:** `/:chain_id/api/v2/transactions`
- **Base URL:** `https://api.blockscout.com`
- **Official documentation:** [Get Transactions](https://docs.blockscout.com/api-reference/get-transactions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chain_id` | path | `string` | no |
