# Get Main Page Blocks with Blockscout

Retrieves main page blocks from Blockscout.

## Endpoint

- **Method:** `GET`
- **Path:** `/:chain_id/api/v2/main-page/blocks`
- **Base URL:** `https://api.blockscout.com`
- **Official documentation:** [Get Main Page Blocks](https://docs.blockscout.com/api-reference/get-main-page-blocks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chain_id` | path | `string` | no |
