# Get Indexing Status with Blockscout

Retrieves current indexing status from Blockscout.

## Endpoint

- **Method:** `GET`
- **Path:** `/:chain_id/api/v2/main-page/indexing-status`
- **Base URL:** `https://api.blockscout.com`
- **Official documentation:** [Get Indexing Status](https://docs.blockscout.com/api-reference/get-indexing-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chain_id` | path | `string` | no |
