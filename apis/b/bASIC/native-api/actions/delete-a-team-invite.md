# Delete a team invite with BASIC

Deletes a team invite from BASIC.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/team/{team_id}/invite/{invite_id}`
- **Base URL:** `https://api.basic.tech`
- **Official documentation:** [Delete a team invite](https://docs.basic.tech/api-reference/teams/delete-a-team-invite)
