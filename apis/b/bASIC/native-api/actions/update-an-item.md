# Update an item with BASIC

Updates an existing item in a BASIC table.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/project/{id}/user/{user_id}/db/{table_id}/{item_id}`
- **Base URL:** `https://api.basic.tech`
- **Official documentation:** [Update an item](https://docs.basic.tech/api-reference/project-users/update-an-item-in-the-users-database-1)
