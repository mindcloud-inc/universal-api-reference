# Delete an item with BASIC

Deletes an existing item from a BASIC table.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/project/{id}/user/{user_id}/db/{table_id}/{item_id}`
- **Base URL:** `https://api.basic.tech`
- **Official documentation:** [Delete an item](https://docs.basic.tech/api-reference/project-users/delete-an-item)
