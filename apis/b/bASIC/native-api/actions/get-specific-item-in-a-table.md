# Get specific item in a table with BASIC

Retrieves an item from a BASIC table.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/{id}/user/{user_id}/db/{table_id}/{item_id}`
- **Base URL:** `https://api.basic.tech`
- **Official documentation:** [Get specific item in a table](https://docs.basic.tech/api-reference/project-users/get-specific-item)
