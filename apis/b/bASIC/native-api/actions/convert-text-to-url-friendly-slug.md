# Convert text to URL-friendly slug with BASIC

Converts text to a URL-friendly slug in BASIC.

## Endpoint

- **Method:** `GET`
- **Path:** `/utils/slugify`
- **Base URL:** `https://api.basic.tech`
- **Official documentation:** [Convert text to URL-friendly slug](https://docs.basic.tech/api-reference/utils/convert-text-to-url-friendly-slug)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | query | `string` | yes | Text to convert into a URL-friendly slug. |
