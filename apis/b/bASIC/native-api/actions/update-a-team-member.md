# Update a team member with BASIC

Updates an existing team member in BASIC.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/team/{team_id}/member/{member_id}`
- **Base URL:** `https://api.basic.tech`
- **Official documentation:** [Update a team member](https://docs.basic.tech/api-reference/teams/update-a-team-member)
