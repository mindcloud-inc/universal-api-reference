# Delete a team member with BASIC

Deletes a team member from BASIC.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/team/{team_id}/member/{member_id}`
- **Base URL:** `https://api.basic.tech`
- **Official documentation:** [Delete a team member](https://docs.basic.tech/api-reference/teams/delete-a-team-member)
