# Get specific API key with BASIC

Retrieves a specific API key from BASIC.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/{id}/key/{key_id}`
- **Base URL:** `https://api.basic.tech`
- **Official documentation:** [Get specific API key](https://docs.basic.tech/api-reference/project-keys/get-specific-api-key)
