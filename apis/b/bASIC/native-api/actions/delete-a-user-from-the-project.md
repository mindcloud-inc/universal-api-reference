# Delete a user from the project with BASIC

Deletes a user from a BASIC project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/project/{id}/user/{user_id}`
- **Base URL:** `https://api.basic.tech`
- **Official documentation:** [Delete a user from the project](https://docs.basic.tech/api-reference/project-users/delete-a-user-from-the-project)
