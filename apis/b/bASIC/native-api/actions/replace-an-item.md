# Replace an item with BASIC

Replaces an existing item in a BASIC table.

## Endpoint

- **Method:** `PUT`
- **Path:** `/project/{id}/user/{user_id}/db/{table_id}/{item_id}`
- **Base URL:** `https://api.basic.tech`
- **Official documentation:** [Replace an item](https://docs.basic.tech/api-reference/project-users/replace-an-item)
