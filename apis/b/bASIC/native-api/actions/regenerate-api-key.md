# Regenerate API key with BASIC

Regenerates an API key in BASIC.

## Endpoint

- **Method:** `POST`
- **Path:** `/project/{id}/key/{key_id}/regenerate`
- **Base URL:** `https://api.basic.tech`
- **Official documentation:** [Regenerate API key](https://docs.basic.tech/api-reference/project-keys/regenerate-api-key)
