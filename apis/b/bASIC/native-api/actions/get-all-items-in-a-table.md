# Get all items in a table with BASIC

Retrieves all items from a BASIC table.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/{id}/user/{user_id}/db/{table_id}`
- **Base URL:** `https://api.basic.tech`
- **Official documentation:** [Get all items in a table](https://docs.basic.tech/api-reference/project-users/get-all-items)
