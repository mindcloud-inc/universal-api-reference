# Resolve Contact with Bland AI

Finds or creates a contact in Bland AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contacts/resolve`
- **Base URL:** `https://api.bland.ai`
- **Official documentation:** [Resolve Contact](https://docs.bland.ai/api-v1/post/contacts-resolve)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `phone_number` | body | `string` | no |
