# List Batches with Bland AI

Retrieves batches from your Bland AI account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/batches/list`
- **Base URL:** `https://api.bland.ai`
- **Official documentation:** [List Batches](https://docs.bland.ai/api-v1/get/batches)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `take` | query | `number` | no |
| `skip` | query | `number` | no |
