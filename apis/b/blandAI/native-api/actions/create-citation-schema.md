# Create Citation Schema with Bland AI

Creates a new citation schema in Bland AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/citation_schemas/`
- **Base URL:** `https://api.bland.ai`
- **Official documentation:** [Create Citation Schema](https://docs.bland.ai/api-v1/post/citation-schemas)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `schema` | body | `object` | no |
