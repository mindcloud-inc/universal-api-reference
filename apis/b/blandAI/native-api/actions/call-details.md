# Call Details with Bland AI

Retrieves call details from your Bland AI account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/calls/{call_id}`
- **Base URL:** `https://api.bland.ai`
- **Official documentation:** [Call Details](https://docs.bland.ai/api-v1/get/calls-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `call_id` | path | `string` | yes |
