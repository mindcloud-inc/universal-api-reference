# Discover Sitemap URLs with Bland AI

Retrieves sitemap URLs from a website in Bland AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/knowledge/crawl`
- **Base URL:** `https://api.bland.ai`
- **Official documentation:** [Discover Sitemap URLs](https://docs.bland.ai/api-v1/post/knowledge-crawl)
