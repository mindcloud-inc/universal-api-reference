# List Contacts with Bland AI

Retrieves contacts from your Bland AI account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts`
- **Base URL:** `https://api.bland.ai`
- **Official documentation:** [List Contacts](https://docs.bland.ai/api-v1/get/contacts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | query | `number` | no |
| `offset` | query | `number` | no |
