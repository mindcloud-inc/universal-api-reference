# Get Corrected Transcripts with Bland AI

Retrieves corrected transcripts for a call in Bland AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/calls/{call_id}/correct`
- **Base URL:** `https://api.bland.ai`
- **Official documentation:** [Get Corrected Transcripts](https://docs.bland.ai/api-v1/get/calls-corrected-transcript)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `call_id` | path | `string` | yes |
