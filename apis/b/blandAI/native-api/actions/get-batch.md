# Get Batch with Bland AI

Retrieves a batch from your Bland AI account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/batches/{batch_id}`
- **Base URL:** `https://api.bland.ai`
- **Official documentation:** [Get Batch](https://docs.bland.ai/api-v1/get/batches-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `batch_id` | path | `string` | yes |
