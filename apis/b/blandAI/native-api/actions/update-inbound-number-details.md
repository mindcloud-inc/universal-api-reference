# Update Inbound Number Details with Bland AI

Updates inbound number details in Bland AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/inbound/{phone_number}`
- **Base URL:** `https://api.bland.ai`
- **Official documentation:** [Update Inbound Number Details](https://docs.bland.ai/api-v1/post/inbound-number-update)
