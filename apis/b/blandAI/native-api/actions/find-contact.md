# Find Contact with Bland AI

Finds a contact in Bland AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contacts/find`
- **Base URL:** `https://api.bland.ai`
- **Official documentation:** [Find Contact](https://docs.bland.ai/api-v1/get/contacts-find)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `phone_number` | body | `string` | no |
| `email` | body | `string` | no |
| `external_id` | body | `string` | no |
