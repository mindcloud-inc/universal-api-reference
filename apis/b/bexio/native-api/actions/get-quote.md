# Get Quote with Bexio

Retrieves a quote from Bexio.

## Endpoint

- **Method:** `GET`
- **Path:** `/2.0/kb_offer/:quote_id`
- **Base URL:** `https://api.bexio.com`
- **Official documentation:** [Get Quote](https://docs.bexio.com/#tag/Quotes/operation/v2ShowQuote)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `quote_id` | path | `number` | yes | The ID of the quote. |
