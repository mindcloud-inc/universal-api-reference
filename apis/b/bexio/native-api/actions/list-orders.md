# List Orders with Bexio

Retrieves orders from Bexio.

## Endpoint

- **Method:** `GET`
- **Path:** `/2.0/kb_order`
- **Base URL:** `https://api.bexio.com`
- **Official documentation:** [List Orders](https://docs.bexio.com/#tag/Orders/operation/v2ListOrders)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
