# List Quotes with Bexio

Retrieves quotes from Bexio.

## Endpoint

- **Method:** `GET`
- **Path:** `/2.0/kb_offer`
- **Base URL:** `https://api.bexio.com`
- **Official documentation:** [List Quotes](https://docs.bexio.com/#tag/Quotes/operation/v2ListQuotes)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
