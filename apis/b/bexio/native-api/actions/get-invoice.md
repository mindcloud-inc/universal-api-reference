# Get Invoice with Bexio

Retrieves an invoice from Bexio.

## Endpoint

- **Method:** `GET`
- **Path:** `/2.0/kb_invoice/:invoice_id`
- **Base URL:** `https://api.bexio.com`
- **Official documentation:** [Get Invoice](https://docs.bexio.com/#tag/Invoices/operation/v2ShowInvoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_id` | path | `number` | yes | The ID of the invoice. |
