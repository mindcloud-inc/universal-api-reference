# Get Purchase Order with Bexio

Retrieves a purchase order from Bexio.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0/purchase_orders/:purchase_order_id`
- **Base URL:** `https://api.bexio.com`
- **Official documentation:** [Get Purchase Order](https://docs.bexio.com/#tag/Purchase-Orders/operation/v3PurchaseOrderShow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `purchase_order_id` | path | `number` | yes | The ID of the purchase order. |
