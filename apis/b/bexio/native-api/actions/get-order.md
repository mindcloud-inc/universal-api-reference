# Get Order with Bexio

Retrieves an order from Bexio.

## Endpoint

- **Method:** `GET`
- **Path:** `/2.0/kb_order/:order_id`
- **Base URL:** `https://api.bexio.com`
- **Official documentation:** [Get Order](https://docs.bexio.com/#tag/Orders/operation/v2ShowOrder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | path | `number` | yes | The ID of the order. |
