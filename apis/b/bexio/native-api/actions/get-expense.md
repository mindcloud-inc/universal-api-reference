# Get Expense with Bexio

Retrieves an expense from Bexio.

## Endpoint

- **Method:** `GET`
- **Path:** `/4.0/expenses/:id`
- **Base URL:** `https://api.bexio.com`
- **Official documentation:** [Get Expense](https://docs.bexio.com/#tag/Expenses/operation/ApiExpenses_GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The expense UUID. |
