# Issue Quote with Bexio

Issues a quote in Bexio.

## Endpoint

- **Method:** `POST`
- **Path:** `/2.0/kb_offer/:quote_id/issue`
- **Base URL:** `https://api.bexio.com`
- **Official documentation:** [Issue Quote](https://docs.bexio.com/#tag/Quotes/operation/v2IssueQuote)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `quote_id` | path | `number` | yes | The ID of the quote. |
