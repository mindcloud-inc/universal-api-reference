# Create Client Token with Braintree

Creates a new client token in Braintree.

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://payments.sandbox.braintree-api.com`
- **Official documentation:** [Create Client Token](https://developer.paypal.com/braintree/graphql/reference/#Mutation--createClientToken)
