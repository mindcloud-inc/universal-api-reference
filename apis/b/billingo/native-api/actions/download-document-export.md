# Download Document Export with Billingo

Retrieves an exported document file from Billingo.

## Endpoint

- **Method:** `GET`
- **Path:** `/document-export/:id/download`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [Download Document Export](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Billingo document export ID from the path. |
