# List Partners with Billingo

Retrieves partner records from your Billingo account.

## Endpoint

- **Method:** `GET`
- **Path:** `/partners`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [List Partners](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
