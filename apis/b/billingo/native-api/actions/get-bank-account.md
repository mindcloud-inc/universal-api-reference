# Get Bank Account with Billingo

Retrieves a bank account from Billingo.

## Endpoint

- **Method:** `GET`
- **Path:** `/bank-accounts/:id`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [Get Bank Account](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Billingo bank account ID from the path. |
