# Convert Legacy ID with Billingo

Retrieves a Billingo v3 ID from legacy ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/utils/convert-legacy-id/:id`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [Convert Legacy ID](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Legacy Billingo ID to convert to a v3 ID. |
