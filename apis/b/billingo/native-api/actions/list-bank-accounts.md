# List Bank Accounts with Billingo

Retrieves bank account records from Billingo.

## Endpoint

- **Method:** `GET`
- **Path:** `/bank-accounts`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [List Bank Accounts](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Capabilities

This operation supports [pagination](../README.md#pagination).
