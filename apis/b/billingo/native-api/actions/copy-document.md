# Copy Document with Billingo

Creates a copy of a document in Billingo.

## Endpoint

- **Method:** `POST`
- **Path:** `/documents/:id/copy`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [Copy Document](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Billingo document ID to copy. |
