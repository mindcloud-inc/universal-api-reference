# Get Product with Billingo

Retrieves a product record from Billingo.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:id`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [Get Product](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Billingo product ID from the path. |
