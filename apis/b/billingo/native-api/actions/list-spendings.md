# List Spendings with Billingo

Retrieves spending items from Billingo by due date.

## Endpoint

- **Method:** `GET`
- **Path:** `/spendings`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [List Spendings](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
