# Download Document with Billingo

Retrieves a document PDF from Billingo.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id/download`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [Download Document](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Billingo document ID from the path. |
