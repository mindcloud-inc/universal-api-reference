# Get Document Online Szamla Status with Billingo

Retrieves a document Online Szamla status from Billingo.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id/online-szamla`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [Get Document Online Szamla Status](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Billingo document ID from the path. |
