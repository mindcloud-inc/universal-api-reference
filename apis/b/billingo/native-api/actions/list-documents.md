# List Documents with Billingo

Retrieves document records from your Billingo account.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [List Documents](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
