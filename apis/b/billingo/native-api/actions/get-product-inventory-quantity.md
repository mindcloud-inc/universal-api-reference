# Get Product Inventory Quantity with Billingo

Retrieves product quantity from Billingo's default warehouse.

## Endpoint

- **Method:** `GET`
- **Path:** `/inventory/product/:id/quantity`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [Get Product Inventory Quantity](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Billingo product ID. |
