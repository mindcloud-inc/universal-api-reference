# List Document Blocks with Billingo

Retrieves document blocks from your Billingo account.

## Endpoint

- **Method:** `GET`
- **Path:** `/document-blocks`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [List Document Blocks](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
