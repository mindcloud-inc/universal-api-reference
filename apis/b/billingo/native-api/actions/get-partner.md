# Get Partner with Billingo

## Endpoint

- **Method:** `GET`
- **Path:** `/partners/:id`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [Get Partner](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Billingo partner ID from the path. |
