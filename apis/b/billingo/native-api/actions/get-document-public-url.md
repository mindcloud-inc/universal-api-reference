# Get Document Public URL with Billingo

Retrieves a public document download URL from Billingo.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id/public-url`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [Get Document Public URL](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Billingo document ID from the path. |
