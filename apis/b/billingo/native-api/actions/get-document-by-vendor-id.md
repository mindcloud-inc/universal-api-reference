# Get Document By Vendor ID with Billingo

Retrieves a document from Billingo by vendor ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/vendor/:vendorId`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [Get Document By Vendor ID](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vendor_id` | path | `string` | yes | Vendor ID used to retrieve a Billingo document. |
