# Get Spending with Billingo

Retrieves a spending record from Billingo.

## Endpoint

- **Method:** `GET`
- **Path:** `/spendings/:id`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [Get Spending](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Billingo spending ID from the path. |
