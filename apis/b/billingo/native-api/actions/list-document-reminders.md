# List Document Reminders with Billingo

Retrieves document reminders from Billingo by status.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id/reminders`
- **Base URL:** `https://api.billingo.hu/v3`
- **Official documentation:** [List Document Reminders](https://api.swaggerhub.com/apis/Billingo/Billingo/3.0.15)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Billingo document ID. |
