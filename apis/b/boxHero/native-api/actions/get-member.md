# Get Member with BoxHero

Retrieves a team member from BoxHero.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/members/:member_id`
- **Base URL:** `https://rest.boxhero-app.com`
- **Official documentation:** [Get Member](https://rest.boxhero-app.com/docs/api#/members/MembersController_getMember)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `member_id` | path | `number` | yes | Unique identifier for the member |
