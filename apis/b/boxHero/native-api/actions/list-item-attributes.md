# List Item Attributes with BoxHero

Retrieves item attributes from BoxHero.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/item-attrs`
- **Base URL:** `https://rest.boxhero-app.com`
- **Official documentation:** [List Item Attributes](https://rest.boxhero-app.com/docs/api#/item-attrs/BarcodeAttrsController_getAttrs)
