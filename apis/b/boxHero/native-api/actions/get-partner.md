# Get Partner with BoxHero

Retrieves a partner from BoxHero.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/partners/:partner_id`
- **Base URL:** `https://rest.boxhero-app.com`
- **Official documentation:** [Get Partner](https://rest.boxhero-app.com/docs/api#/partners/VendorsController_getVendor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `partner_id` | path | `number` | yes | Unique identifier for the partner |
