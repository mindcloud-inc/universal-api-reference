# List Locations with BoxHero

Retrieves locations from BoxHero.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/locations`
- **Base URL:** `https://rest.boxhero-app.com`
- **Official documentation:** [List Locations](https://rest.boxhero-app.com/docs/api#/locations/LocationsController_getLocations)
