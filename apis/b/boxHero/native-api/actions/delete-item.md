# Delete Item with BoxHero

Deletes an existing item from BoxHero.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/items/:item_id`
- **Base URL:** `https://rest.boxhero-app.com`
- **Official documentation:** [Delete Item](https://rest.boxhero-app.com/docs/api#/items/BarcodesController_deleteBarcode)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `number` | yes | Unique identifier for the item |
