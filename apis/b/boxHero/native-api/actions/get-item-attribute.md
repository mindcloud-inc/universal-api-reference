# Get Item Attribute with BoxHero

Retrieves an item attribute from BoxHero.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/item-attrs/:attr_id`
- **Base URL:** `https://rest.boxhero-app.com`
- **Official documentation:** [Get Item Attribute](https://rest.boxhero-app.com/docs/api#/item-attrs/BarcodeAttrsController_getAttr)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `attr_id` | path | `number` | yes | Unique identifier for the item attribute |
