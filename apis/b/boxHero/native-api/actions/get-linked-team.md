# Get Linked Team with BoxHero

Retrieves the linked team from BoxHero.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/teams/linked`
- **Base URL:** `https://rest.boxhero-app.com`
- **Official documentation:** [Get Linked Team](https://rest.boxhero-app.com/docs/api#/teams/TeamsController_getCurrentTeam)
