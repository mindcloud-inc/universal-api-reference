# Get Location with BoxHero

Retrieves a location from BoxHero.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/locations/:location_id`
- **Base URL:** `https://rest.boxhero-app.com`
- **Official documentation:** [Get Location](https://rest.boxhero-app.com/docs/api#/locations/LocationsController_getLocation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `location_id` | path | `number` | yes | Unique identifier for the location |
