# Get Access Token with Bitport

Creates a Bitport access token from an access code.

## Endpoint

- **Method:** `POST`
- **Path:** `/oauth2/access-token`
- **Base URL:** `https://api.bitport.io/v2`
- **Official documentation:** [Get Access Token](https://bitport.io/api)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
