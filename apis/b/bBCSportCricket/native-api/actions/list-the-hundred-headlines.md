# List The Hundred Headlines with BBC Sport - Cricket

Retrieves BBC Sport The Hundred cricket headlines.

## Endpoint

- **Method:** `GET`
- **Path:** `/sport/cricket/the-hundred/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk`
- **Official documentation:** [List The Hundred Headlines](https://feeds.bbci.co.uk/sport/cricket/the-hundred/rss.xml)
