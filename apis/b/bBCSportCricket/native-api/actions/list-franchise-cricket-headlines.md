# List Franchise Cricket Headlines with BBC Sport - Cricket

Retrieves BBC Sport franchise cricket headlines.

## Endpoint

- **Method:** `GET`
- **Path:** `/sport/cricket/franchise-cricket/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk`
- **Official documentation:** [List Franchise Cricket Headlines](https://feeds.bbci.co.uk/sport/cricket/franchise-cricket/rss.xml)
