# List England Cricket Headlines with BBC Sport - Cricket

Retrieves BBC Sport England cricket headlines.

## Endpoint

- **Method:** `GET`
- **Path:** `/sport/cricket/teams/england/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk`
- **Official documentation:** [List England Cricket Headlines](https://feeds.bbci.co.uk/sport/cricket/teams/england/rss.xml)
