# List Yorkshire Cricket Headlines with BBC Sport - Cricket

Retrieves BBC Sport Yorkshire cricket headlines.

## Endpoint

- **Method:** `GET`
- **Path:** `/sport/cricket/teams/yorkshire/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk`
- **Official documentation:** [List Yorkshire Cricket Headlines](https://feeds.bbci.co.uk/sport/cricket/teams/yorkshire/rss.xml)
