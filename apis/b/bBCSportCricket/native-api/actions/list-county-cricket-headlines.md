# List County Cricket Headlines with BBC Sport - Cricket

Retrieves BBC Sport county cricket headlines.

## Endpoint

- **Method:** `GET`
- **Path:** `/sport/cricket/counties/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk`
- **Official documentation:** [List County Cricket Headlines](https://feeds.bbci.co.uk/sport/cricket/counties/rss.xml)
