# List Bangladesh Cricket Headlines with BBC Sport - Cricket

Retrieves BBC Sport Bangladesh cricket headlines.

## Endpoint

- **Method:** `GET`
- **Path:** `/sport/cricket/teams/bangladesh/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk`
- **Official documentation:** [List Bangladesh Cricket Headlines](https://feeds.bbci.co.uk/sport/cricket/teams/bangladesh/rss.xml)
