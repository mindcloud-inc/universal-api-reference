# List India Cricket Headlines with BBC Sport - Cricket

Retrieves BBC Sport India cricket headlines.

## Endpoint

- **Method:** `GET`
- **Path:** `/sport/cricket/teams/india/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk`
- **Official documentation:** [List India Cricket Headlines](https://feeds.bbci.co.uk/sport/cricket/teams/india/rss.xml)
