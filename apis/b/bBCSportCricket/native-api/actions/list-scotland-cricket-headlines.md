# List Scotland Cricket Headlines with BBC Sport - Cricket

Retrieves BBC Sport Scotland cricket headlines.

## Endpoint

- **Method:** `GET`
- **Path:** `/sport/cricket/teams/scotland/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk`
- **Official documentation:** [List Scotland Cricket Headlines](https://feeds.bbci.co.uk/sport/cricket/teams/scotland/rss.xml)
