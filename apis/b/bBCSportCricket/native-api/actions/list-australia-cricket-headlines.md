# List Australia Cricket Headlines with BBC Sport - Cricket

Retrieves BBC Sport Australia cricket headlines.

## Endpoint

- **Method:** `GET`
- **Path:** `/sport/cricket/teams/australia/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk`
- **Official documentation:** [List Australia Cricket Headlines](https://feeds.bbci.co.uk/sport/cricket/teams/australia/rss.xml)
