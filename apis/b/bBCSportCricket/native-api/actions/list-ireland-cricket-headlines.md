# List Ireland Cricket Headlines with BBC Sport - Cricket

Retrieves BBC Sport Ireland cricket headlines.

## Endpoint

- **Method:** `GET`
- **Path:** `/sport/cricket/teams/ireland/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk`
- **Official documentation:** [List Ireland Cricket Headlines](https://feeds.bbci.co.uk/sport/cricket/teams/ireland/rss.xml)
