# List Zimbabwe Cricket Headlines with BBC Sport - Cricket

Retrieves BBC Sport Zimbabwe cricket headlines.

## Endpoint

- **Method:** `GET`
- **Path:** `/sport/cricket/teams/zimbabwe/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk`
- **Official documentation:** [List Zimbabwe Cricket Headlines](https://feeds.bbci.co.uk/sport/cricket/teams/zimbabwe/rss.xml)
