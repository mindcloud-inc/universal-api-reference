# List New Zealand Cricket Headlines with BBC Sport - Cricket

Retrieves BBC Sport New Zealand cricket headlines.

## Endpoint

- **Method:** `GET`
- **Path:** `/sport/cricket/teams/new-zealand/rss.xml`
- **Base URL:** `https://feeds.bbci.co.uk`
- **Official documentation:** [List New Zealand Cricket Headlines](https://feeds.bbci.co.uk/sport/cricket/teams/new-zealand/rss.xml)
