# Check Credit Balance with BetterContact

Retrieves the current BetterContact credit balance and account email.

## Endpoint

- **Method:** `GET`
- **Path:** `/account`
- **Base URL:** `https://app.bettercontact.rocks/api/v2`
- **Official documentation:** [Check Credit Balance](https://doc.bettercontact.rocks/api-reference/endpoint/account)
