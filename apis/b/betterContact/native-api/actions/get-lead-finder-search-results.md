# Get Lead Finder Search Results with BetterContact

Retrieves BetterContact lead finder search results by request ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lead_finder/async/:request_id`
- **Base URL:** `https://app.bettercontact.rocks/api/v2`
- **Official documentation:** [Get Lead Finder Search Results](https://doc.bettercontact.rocks/api-reference/endpoint/lead_finder_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `request_id` | path | `string` | yes | The BetterContact lead finder request ID. |
