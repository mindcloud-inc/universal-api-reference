# Get Enrichment Results with BetterContact

Retrieves BetterContact enrichment results by request ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/async/:request_id`
- **Base URL:** `https://app.bettercontact.rocks/api/v2`
- **Official documentation:** [Get Enrichment Results](https://doc.bettercontact.rocks/api-reference/endpoint/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `request_id` | path | `string` | yes | The BetterContact enrichment request ID. |
