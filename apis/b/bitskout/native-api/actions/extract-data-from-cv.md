# Extract Data from CV with Bitskout

Extracts CV data with a Bitskout plugin.

## Endpoint

- **Method:** `POST`
- **Path:** `/actions/cv`
- **Base URL:** `https://api.bitskout.com/v2`
- **Official documentation:** [Extract Data from CV](https://learn.microsoft.com/en-us/connectors/bitskout/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_url` | body | `string` | no | Direct download URL for the resume file to extract. |
