# Detect Response to Cold Email with Bitskout

Detects responses to cold emails with Bitskout.

## Endpoint

- **Method:** `POST`
- **Path:** `/actions/cold_response`
- **Base URL:** `https://api.bitskout.com/v2`
- **Official documentation:** [Detect Response to Cold Email](https://learn.microsoft.com/en-us/connectors/bitskout/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | body | `string` | no | Cold email reply text to analyze. |
