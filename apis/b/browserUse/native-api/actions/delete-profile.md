# Delete Profile with Browser Use

Deletes an existing profile from Browser Use.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/profiles/:profile_id`
- **Base URL:** `https://api.browser-use.com/api/v3`
- **Official documentation:** [Delete Profile](https://docs.browser-use.com/cloud/api-v3/profiles/delete-browser-profile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profile_id` | path | `string` | yes | Browser profile ID. |
