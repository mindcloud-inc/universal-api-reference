# Get Profile with Browser Use

Retrieves a profile from Browser Use.

## Endpoint

- **Method:** `GET`
- **Path:** `/profiles/:profile_id`
- **Base URL:** `https://api.browser-use.com/api/v3`
- **Official documentation:** [Get Profile](https://docs.browser-use.com/cloud/api-v3/profiles/get-profile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profile_id` | path | `string` | yes | Browser profile ID. |
