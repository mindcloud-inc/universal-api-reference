# Delete Workspace with Browser Use

Deletes an existing workspace from Browser Use.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workspaces/:workspace_id`
- **Base URL:** `https://api.browser-use.com/api/v3`
- **Official documentation:** [Delete Workspace](https://docs.browser-use.com/cloud/api-v3/workspaces/delete-workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspace_id` | path | `string` | yes | Workspace ID. |
