# Create Workspace with Browser Use

Creates a workspace in Browser Use.

## Endpoint

- **Method:** `POST`
- **Path:** `/workspaces`
- **Base URL:** `https://api.browser-use.com/api/v3`
- **Official documentation:** [Create Workspace](https://docs.browser-use.com/cloud/api-v3/workspaces/create-workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Optional workspace name. |
