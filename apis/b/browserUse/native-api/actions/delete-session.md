# Delete Session with Browser Use

Deletes an existing session from Browser Use.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sessions/:session_id`
- **Base URL:** `https://api.browser-use.com/api/v3`
- **Official documentation:** [Delete Session](https://docs.browser-use.com/cloud/api-v3/sessions/delete-session)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `string` | yes | Browser Use session ID. |
