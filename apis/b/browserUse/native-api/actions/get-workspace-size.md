# Get Workspace Size with Browser Use

Retrieves workspace storage usage from Browser Use.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspace_id/size`
- **Base URL:** `https://api.browser-use.com/api/v3`
- **Official documentation:** [Get Workspace Size](https://docs.browser-use.com/cloud/api-v3/workspaces/get-workspace-size)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspace_id` | path | `string` | yes | Workspace ID. |
