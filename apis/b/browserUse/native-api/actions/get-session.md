# Get Session with Browser Use

Retrieves a session from Browser Use.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/:session_id`
- **Base URL:** `https://api.browser-use.com/api/v3`
- **Official documentation:** [Get Session](https://docs.browser-use.com/cloud/api-v3/sessions/get-session)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `string` | yes | Browser Use session ID. |
