# Get Browser Session with Browser Use

Retrieves a browser session from Browser Use.

## Endpoint

- **Method:** `GET`
- **Path:** `/browsers/:session_id`
- **Base URL:** `https://api.browser-use.com/api/v3`
- **Official documentation:** [Get Browser Session](https://docs.browser-use.com/cloud/api-v3/browsers/get-browser-session)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `string` | yes | Browser session ID. |
