# Get Member with Buy Me a Coffee

Retrieves a member from Buy Me a Coffee by membership ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions/:id`
- **Base URL:** `https://developers.buymeacoffee.com/api/v1`
- **Official documentation:** [Get Member](https://developers.buymeacoffee.com/apireference.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique ID of the membership returned by the list memberships action. |
