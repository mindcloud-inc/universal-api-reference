# Get Onetime Supporter with Buy Me a Coffee

Retrieves one-time supporter details from Buy Me a Coffee by supporter ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/supporters/:id`
- **Base URL:** `https://developers.buymeacoffee.com/api/v1`
- **Official documentation:** [Get Onetime Supporter](https://developers.buymeacoffee.com/apireference.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique ID of the supporter returned by the list supporters action. |
