# List Onetime Supporters with Buy Me a Coffee

Retrieves onetime supporters from Buy Me a Coffee.

## Endpoint

- **Method:** `GET`
- **Path:** `/supporters`
- **Base URL:** `https://developers.buymeacoffee.com/api/v1`
- **Official documentation:** [List Onetime Supporters](https://developers.buymeacoffee.com/apireference.md)
