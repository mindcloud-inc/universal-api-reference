# Get webhook details with Bulldog-WP

Retrieves a webhook from Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/{webhookId}`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Get webhook details](https://console.bulldog-wp.co.il/docs/specification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Webhook endpoint ID. |
