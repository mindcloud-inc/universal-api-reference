# Get campaigns with Bulldog-WP

Retrieves campaigns from Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Get campaigns](https://console.bulldog-wp.co.il/docs/specification)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
