# Search messages with Bulldog-WP

Finds messages in Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Search messages](https://console.bulldog-wp.co.il/docs/specification)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
