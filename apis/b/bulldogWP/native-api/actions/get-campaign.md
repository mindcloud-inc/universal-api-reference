# Get campaign with Bulldog-WP

Retrieves a campaign from Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/{campaignId}`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Get campaign](https://console.bulldog-wp.co.il/docs/specification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | Campaign ID. |
