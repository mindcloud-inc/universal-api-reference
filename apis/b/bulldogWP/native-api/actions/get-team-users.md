# Get users with Bulldog-WP

Retrieves users from Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/team`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Get users](https://console.bulldog-wp.co.il/docs/specification)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
