# Get file information with Bulldog-WP

Retrieves file details from Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/{fileId}`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Get file information](https://console.bulldog-wp.co.il/docs/specification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | Uploaded file resource ID. |
