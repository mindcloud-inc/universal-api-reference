# Get webhooks with Bulldog-WP

Retrieves webhooks from Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Get webhooks](https://console.bulldog-wp.co.il/docs/specification)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
