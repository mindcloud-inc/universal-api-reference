# Preview image with Bulldog-WP

Retrieves an image preview from Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/{fileId}/preview`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Preview image](https://console.bulldog-wp.co.il/docs/specification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | Uploaded file resource ID. |
