# Get number by ID with Bulldog-WP

Retrieves a phone number from Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/devices/{deviceId}`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Get number by ID](https://console.bulldog-wp.co.il/docs/specification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deviceId` | path | `string` | yes | WhatsApp number device ID from Bulldog WP. |
