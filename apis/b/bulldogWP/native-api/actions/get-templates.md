# List templates with Bulldog-WP

Retrieves templates from Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/waba/templates`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [List templates](https://console.bulldog-wp.co.il/docs/specification)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
