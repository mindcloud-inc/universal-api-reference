# Get messaging prices with Bulldog-WP

Retrieves messaging prices from Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/waba/prices`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Get messaging prices](https://console.bulldog-wp.co.il/docs/specification)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
