# Download file content with Bulldog-WP

Downloads file content from Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/{fileId}/download`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Download file content](https://console.bulldog-wp.co.il/docs/specification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | Uploaded file resource ID. |
