# Search files with Bulldog-WP

Finds files in Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/files`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Search files](https://console.bulldog-wp.co.il/docs/specification)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
