# Get session health with Bulldog-WP

Retrieves session health from Bulldog-WP.

## Endpoint

- **Method:** `GET`
- **Path:** `/devices/{deviceId}/health`
- **Base URL:** `https://api.bulldog-wp.co.il/v1`
- **Official documentation:** [Get session health](https://console.bulldog-wp.co.il/docs/specification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deviceId` | path | `string` | yes | WhatsApp number device ID from Bulldog WP. |
