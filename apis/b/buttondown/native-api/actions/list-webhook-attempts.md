# List Webhook Attempts with Buttondown

Retrieves webhook attempts from Buttondown.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:id/attempts`
- **Base URL:** `https://api.buttondown.com/v1`
- **Official documentation:** [List Webhook Attempts](https://docs.buttondown.com/api-webhooks-attempts-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook ID. |
