# Retrieve Webhook with Buttondown

Retrieves a webhook from Buttondown.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.buttondown.com/v1`
- **Official documentation:** [Retrieve Webhook](https://docs.buttondown.com/api-webhooks-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook ID. |
