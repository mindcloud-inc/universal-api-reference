# Delete Webhook with Buttondown

Deletes an existing webhook from Buttondown.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.buttondown.com/v1`
- **Official documentation:** [Delete Webhook](https://docs.buttondown.com/api-webhooks-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook ID. |
