# Delete Email with Buttondown

Deletes an existing email from Buttondown.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/emails/:id`
- **Base URL:** `https://api.buttondown.com/v1`
- **Official documentation:** [Delete Email](https://docs.buttondown.com/api-emails-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Email ID. |
