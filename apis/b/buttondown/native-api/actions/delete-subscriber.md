# Delete Subscriber with Buttondown

Deletes an existing subscriber from Buttondown.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscribers/:id_or_email`
- **Base URL:** `https://api.buttondown.com/v1`
- **Official documentation:** [Delete Subscriber](https://docs.buttondown.com/api-subscribers-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id_or_email` | path | `string` | yes | Subscriber ID or email address. |
