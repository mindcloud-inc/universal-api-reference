# Retrieve Email with Buttondown

Retrieves an email from Buttondown.

## Endpoint

- **Method:** `GET`
- **Path:** `/emails/:id`
- **Base URL:** `https://api.buttondown.com/v1`
- **Official documentation:** [Retrieve Email](https://docs.buttondown.com/api-emails-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Email ID. |
