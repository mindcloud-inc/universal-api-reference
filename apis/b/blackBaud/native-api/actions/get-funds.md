# Get Funds with BlackBaud

## Endpoint

- **Method:** `GET`
- **Path:** `fundraising/v1/funds`
- **Base URL:** `https://api.sky.blackbaud.com/`
- **Official documentation:** [Get Funds](https://developer.blackbaud.com/skyapi/renxt/fundraising/entities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of funds to return. |
| `offset` | query | `number` | no | Number of rows to skip before returning funds. |
