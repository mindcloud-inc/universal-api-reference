# Get Gifts with BlackBaud

## Endpoint

- **Method:** `GET`
- **Path:** `gift/v1/gifts`
- **Base URL:** `https://api.sky.blackbaud.com/`
- **Official documentation:** [Get Gifts](https://developer.blackbaud.com/skyapi/renxt/gift/entities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of gifts to return. |
| `offset` | query | `number` | no | Number of rows to skip before returning gifts. |
