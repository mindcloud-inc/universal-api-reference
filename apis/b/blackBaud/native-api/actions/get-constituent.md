# Get Constituent with BlackBaud

## Endpoint

- **Method:** `GET`
- **Path:** `constituent/v1/constituents/{constituent_id}`
- **Base URL:** `https://api.sky.blackbaud.com/`
- **Official documentation:** [Get Constituent](https://developer.blackbaud.com/skyapi/renxt/constituent/entities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `constituent_id` | path | `string` | yes | The Blackbaud constituent identifier. |
