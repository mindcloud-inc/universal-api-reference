# Get Fund with BlackBaud

## Endpoint

- **Method:** `GET`
- **Path:** `fundraising/v1/funds/{fund_id}`
- **Base URL:** `https://api.sky.blackbaud.com/`
- **Official documentation:** [Get Fund](https://developer.blackbaud.com/skyapi/renxt/fundraising/entities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fund_id` | path | `string` | yes | The Blackbaud fund identifier. |
