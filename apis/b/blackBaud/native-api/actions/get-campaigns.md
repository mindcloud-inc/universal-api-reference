# Get Campaigns with BlackBaud

## Endpoint

- **Method:** `GET`
- **Path:** `fundraising/v1/campaigns`
- **Base URL:** `https://api.sky.blackbaud.com/`
- **Official documentation:** [Get Campaigns](https://developer.blackbaud.com/skyapi/renxt/fundraising/entities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of campaigns to return. |
| `offset` | query | `number` | no | Number of rows to skip before returning campaigns. |
