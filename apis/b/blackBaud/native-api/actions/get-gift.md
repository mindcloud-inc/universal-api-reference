# Get Gift with BlackBaud

## Endpoint

- **Method:** `GET`
- **Path:** `gift/v1/gifts/{gift_id}`
- **Base URL:** `https://api.sky.blackbaud.com/`
- **Official documentation:** [Get Gift](https://developer.blackbaud.com/skyapi/renxt/gift/entities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `gift_id` | path | `string` | yes | The Blackbaud gift identifier. |
