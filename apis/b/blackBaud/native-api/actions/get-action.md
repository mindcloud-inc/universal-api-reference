# Get Action with BlackBaud

## Endpoint

- **Method:** `GET`
- **Path:** `constituent/v1/actions/{action_id}`
- **Base URL:** `https://api.sky.blackbaud.com/`
- **Official documentation:** [Get Action](https://developer.blackbaud.com/skyapi/renxt/constituent/entities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `action_id` | path | `string` | yes | The Blackbaud action identifier. |
