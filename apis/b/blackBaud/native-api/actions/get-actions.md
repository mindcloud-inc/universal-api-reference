# Get Actions with BlackBaud

## Endpoint

- **Method:** `GET`
- **Path:** `constituent/v1/actions`
- **Base URL:** `https://api.sky.blackbaud.com/`
- **Official documentation:** [Get Actions](https://developer.blackbaud.com/skyapi/renxt/constituent/entities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of constituents to return. |
| `offset` | query | `number` | no | Number of rows to skip before returning constituents. |
