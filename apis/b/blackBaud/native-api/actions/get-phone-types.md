# Get Phone Types with BlackBaud

## Endpoint

- **Method:** `GET`
- **Path:** `constituent/v1/phonetypes`
- **Base URL:** `https://api.sky.blackbaud.com/`
- **Official documentation:** [Get Phone Types](https://developer.blackbaud.com/skyapi/renxt/constituent/entities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of phone types to return. |
