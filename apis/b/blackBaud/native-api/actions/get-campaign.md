# Get Campaign with BlackBaud

## Endpoint

- **Method:** `GET`
- **Path:** `fundraising/v1/campaigns/{campaign_id}`
- **Base URL:** `https://api.sky.blackbaud.com/`
- **Official documentation:** [Get Campaign](https://developer.blackbaud.com/skyapi/renxt/fundraising/entities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | The Blackbaud campaign identifier. |
