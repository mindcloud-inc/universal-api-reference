# Add Live Thumbnail with BunnyCDN

Adds a live thumbnail to a BunnyCDN video library.

## Endpoint

- **Method:** `PUT`
- **Path:** `/videolibrary/:id/live/thumbnail`
- **Base URL:** `https://api.bunny.net`
- **Official documentation:** [Add Live Thumbnail](https://docs.bunny.net/reference/bunnynet-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Bunny video library ID. |
