# Delete Live Thumbnail with BunnyCDN

Deletes a live thumbnail from a BunnyCDN video library.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/videolibrary/:id/live/thumbnail`
- **Base URL:** `https://api.bunny.net`
- **Official documentation:** [Delete Live Thumbnail](https://docs.bunny.net/reference/bunnynet-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Bunny video library ID. |
