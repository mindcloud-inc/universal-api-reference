# Add Pull Zone with BunnyCDN

Creates a new pull zone in BunnyCDN.

## Endpoint

- **Method:** `POST`
- **Path:** `/pullzone`
- **Base URL:** `https://api.bunny.net`
- **Official documentation:** [Add Pull Zone](https://docs.bunny.net/reference/bunnynet-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Name` | body | `string` | yes | Name of the pull zone. |
