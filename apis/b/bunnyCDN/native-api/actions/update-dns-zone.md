# Update DNS Zone with BunnyCDN

Updates an existing DNS zone in BunnyCDN.

## Endpoint

- **Method:** `POST`
- **Path:** `/dnszone/:id`
- **Base URL:** `https://api.bunny.net`
- **Official documentation:** [Update DNS Zone](https://docs.bunny.net/reference/bunnynet-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Bunny DNS zone ID. |
