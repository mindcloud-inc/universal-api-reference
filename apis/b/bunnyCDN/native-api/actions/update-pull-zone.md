# Update Pull Zone with BunnyCDN

Updates an existing pull zone in BunnyCDN.

## Endpoint

- **Method:** `POST`
- **Path:** `/pullzone/:id`
- **Base URL:** `https://api.bunny.net`
- **Official documentation:** [Update Pull Zone](https://docs.bunny.net/reference/bunnynet-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Bunny pull zone ID. |
