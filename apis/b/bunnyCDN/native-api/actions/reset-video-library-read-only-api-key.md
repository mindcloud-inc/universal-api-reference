# Reset Video Library Read Only API Key with BunnyCDN

Resets a BunnyCDN video library read-only API key.

## Endpoint

- **Method:** `POST`
- **Path:** `/videolibrary/:id/resetReadOnlyApiKey`
- **Base URL:** `https://api.bunny.net`
- **Official documentation:** [Reset Video Library Read Only API Key](https://docs.bunny.net/reference/bunnynet-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Bunny video library ID. |
