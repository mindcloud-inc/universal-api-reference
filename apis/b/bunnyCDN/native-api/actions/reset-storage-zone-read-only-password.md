# Reset Storage Zone Read Only Password with BunnyCDN

Resets a BunnyCDN storage zone read-only password.

## Endpoint

- **Method:** `POST`
- **Path:** `/storagezone/resetReadOnlyPassword`
- **Base URL:** `https://api.bunny.net`
- **Official documentation:** [Reset Storage Zone Read Only Password](https://docs.bunny.net/reference/bunnynet-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The Bunny storage zone ID. |
