# Trigger DNS Record Scan with BunnyCDN

Triggers a DNS record scan in BunnyCDN.

## Endpoint

- **Method:** `POST`
- **Path:** `/dnszone/records/scan`
- **Base URL:** `https://api.bunny.net`
- **Official documentation:** [Trigger DNS Record Scan](https://docs.bunny.net/reference/bunnynet-api-overview)
