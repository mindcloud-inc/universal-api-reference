# Get Pending Payment Requests with BunnyCDN

Retrieves pending payment requests from BunnyCDN.

## Endpoint

- **Method:** `GET`
- **Path:** `/billing/payment-requests`
- **Base URL:** `https://api.bunny.net`
- **Official documentation:** [Get Pending Payment Requests](https://docs.bunny.net/reference/bunnynet-api-overview)
