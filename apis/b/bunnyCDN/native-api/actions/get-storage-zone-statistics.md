# Get Storage Zone Statistics with BunnyCDN

Retrieves storage zone statistics from BunnyCDN.

## Endpoint

- **Method:** `GET`
- **Path:** `/storagezone/:id/statistics`
- **Base URL:** `https://api.bunny.net`
- **Official documentation:** [Get Storage Zone Statistics](https://docs.bunny.net/reference/bunnynet-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Bunny storage zone ID. |
