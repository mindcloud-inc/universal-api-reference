# Delete Video Library Watermark with BunnyCDN

Deletes a watermark from a BunnyCDN video library.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/videolibrary/:id/watermark`
- **Base URL:** `https://api.bunny.net`
- **Official documentation:** [Delete Video Library Watermark](https://docs.bunny.net/reference/bunnynet-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Bunny video library ID. |
