# Retrieve Official Workflow Template with BrowserAct

Retrieves an official workflow template from BrowserAct.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-official-workflow-template`
- **Base URL:** `https://api.browseract.com/v2/workflow`
- **Official documentation:** [Retrieve Official Workflow Template](https://docs.browseract.com/api-reference/workflow-templates/retrieve-an-official-workflow-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflow_template_id` | query | `string` | yes | Official BrowserAct workflow template ID to retrieve. |
