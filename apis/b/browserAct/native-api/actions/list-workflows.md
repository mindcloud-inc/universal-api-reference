# List Workflows with BrowserAct

Retrieves workflows from BrowserAct.

## Endpoint

- **Method:** `GET`
- **Path:** `/list-workflows`
- **Base URL:** `https://api.browseract.com/v2/workflow`
- **Official documentation:** [List Workflows](https://docs.browseract.com/api-reference/workflows/list-workflows)

## Capabilities

This operation supports [pagination](../README.md#pagination).
