# List Supported Proxy Regions with BrowserAct

Retrieves supported proxy regions from BrowserAct.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-region-list`
- **Base URL:** `https://api.browseract.com/v2/workflow`
- **Official documentation:** [List Supported Proxy Regions](https://docs.browseract.com/api-reference/regions/list-supported-proxy-regions)
