# List Official Workflow Templates with BrowserAct

Retrieves official workflow templates from BrowserAct.

## Endpoint

- **Method:** `GET`
- **Path:** `/list-official-workflow-templates`
- **Base URL:** `https://api.browseract.com/v2/workflow`
- **Official documentation:** [List Official Workflow Templates](https://docs.browseract.com/api-reference/workflow-templates/list-official-workflow-templates)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyword` | query | `string` | no | Optional search keyword for filtering official workflow templates. |
