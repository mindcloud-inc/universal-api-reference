# Retrieve Workflow with BrowserAct

Retrieves a workflow from BrowserAct.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-workflow`
- **Base URL:** `https://api.browseract.com/v2/workflow`
- **Official documentation:** [Retrieve Workflow](https://docs.browseract.com/api-reference/workflows/retrieve-a-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflow_id` | query | `string` | yes | Workflow ID to retrieve. |
