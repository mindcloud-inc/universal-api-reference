# Execute Calculator with Businesslogic.online

Executes a calculator with input values in Businesslogic.online.

## Endpoint

- **Method:** `POST`
- **Path:** `/execute`
- **Base URL:** `https://api.businesslogic.online`
- **Official documentation:** [Execute Calculator](https://api.businesslogic.online/execute)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input_value` | body | `number` | no | Numeric input passed to the Businesslogic calculator. |
