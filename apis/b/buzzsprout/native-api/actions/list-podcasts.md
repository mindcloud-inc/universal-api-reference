# List Podcasts with Buzzsprout

Retrieves podcasts from Buzzsprout.

## Endpoint

- **Method:** `GET`
- **Path:** `/podcasts.json`
- **Base URL:** `https://www.buzzsprout.com/api`
- **Official documentation:** [List Podcasts](https://raw.githubusercontent.com/buzzsprout/buzzsprout-api/master/sections/podcasts.md)
