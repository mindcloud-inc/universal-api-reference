# Show Segment with Baremetrics

Retrieves a segment from Baremetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/segments/:id`
- **Base URL:** `https://sandbox.baremetrics.com`
- **Official documentation:** [Show Segment](https://developers.baremetrics.com/reference/show-segment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
