# List Segments with Baremetrics

Retrieves segments from Baremetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/segments`
- **Base URL:** `https://sandbox.baremetrics.com`
- **Official documentation:** [List Segments](https://developers.baremetrics.com/reference/list-segments)

## Capabilities

This operation supports [pagination](../README.md#pagination).
