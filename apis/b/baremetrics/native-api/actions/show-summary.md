# Show Summary with Baremetrics

Retrieves summary metrics from Baremetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/metrics`
- **Base URL:** `https://sandbox.baremetrics.com`
- **Official documentation:** [Show Summary](https://developers.baremetrics.com/reference/show-summary)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `start_date` | query | `string` | yes |
| `end_date` | query | `string` | yes |
