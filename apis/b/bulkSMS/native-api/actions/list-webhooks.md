# List Webhooks with BulkSMS

Retrieves webhooks configured for your BulkSMS account.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.bulksms.com/v1`
- **Official documentation:** [List Webhooks](https://www.bulksms.com/developer/json/v1/#tag/webhooks/GET/webhooks)
