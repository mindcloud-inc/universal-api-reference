# Capture Screenshot with Browserless

Captures a page screenshot in Browserless.

## Endpoint

- **Method:** `POST`
- **Path:** `/screenshot`
- **Base URL:** `https://production-sfo.browserless.io`
- **Official documentation:** [Capture Screenshot](https://docs.browserless.io/rest-apis/screenshot-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | The URL to capture as a screenshot. |
