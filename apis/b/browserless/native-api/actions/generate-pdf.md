# Generate Pdf with Browserless

Generates a PDF from a page in Browserless.

## Endpoint

- **Method:** `POST`
- **Path:** `/pdf`
- **Base URL:** `https://production-sfo.browserless.io`
- **Official documentation:** [Generate Pdf](https://docs.browserless.io/rest-apis/pdf-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | The URL to render as a PDF. |
