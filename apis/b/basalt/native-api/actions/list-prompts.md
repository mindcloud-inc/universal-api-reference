# List Prompts with Basalt

Retrieves a list of prompts from Basalt.

## Endpoint

- **Method:** `GET`
- **Path:** `/prompts`
- **Base URL:** `https://api.getbasalt.ai`
- **Official documentation:** [List Prompts](https://docs.getbasalt.ai/v1/api-reference/prompts/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `featureSlug` | query | `string` | no | Filter prompts by feature slug. |
