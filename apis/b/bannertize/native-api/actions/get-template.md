# Get Template with Bannertize

Retrieves a template and its modifications from Bannertize.

## Endpoint

- **Method:** `GET`
- **Path:** `template/:template_uid`
- **Base URL:** `https://api.bannertize.com/v1`
- **Official documentation:** [Get Template](https://docs.bannertize.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_uid` | path | `string` | yes | The Bannertize template UID to retrieve. |
