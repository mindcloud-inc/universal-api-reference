# Retrieve Image with Bannertize

Retrieves a generated image and render status from Bannertize.

## Endpoint

- **Method:** `GET`
- **Path:** `image/:image_uid`
- **Base URL:** `https://api.bannertize.com/v1`
- **Official documentation:** [Retrieve Image](https://docs.bannertize.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image_uid` | path | `string` | yes | The Bannertize image render UID to retrieve. |
