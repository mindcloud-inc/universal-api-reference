# Retrieve Set with Bannertize

Retrieves a generated set instance from Bannertize.

## Endpoint

- **Method:** `GET`
- **Path:** `set/:set_uid`
- **Base URL:** `https://api.bannertize.com/v1`
- **Official documentation:** [Retrieve Set](https://docs.bannertize.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `set_uid` | path | `string` | yes | The Bannertize set render UID to retrieve. |
