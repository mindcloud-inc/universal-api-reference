- **Path:** `/graphql`
- **Base URL:** `https://api.buildbetter.app/v1`
- **Official documentation:** [List People](https://docs.buildbetter.ai/pages/api/graphql-queries#get-people)

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
