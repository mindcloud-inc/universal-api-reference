# List Projects with Bannerbite

Retrieves a list of projects from Bannerbite.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/projects`
- **Base URL:** `https://api.bannerbite.com`
- **Official documentation:** [List Projects](https://developer.bannerbite.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Number of projects to return. Bannerbite defaults to 10 and supports up to 100. |
