# Get Project with Bannerbite

Retrieves a project from Bannerbite by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/projects/:id`
- **Base URL:** `https://api.bannerbite.com`
- **Official documentation:** [Get Project](https://developer.bannerbite.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Bannerbite project ID to retrieve. |
