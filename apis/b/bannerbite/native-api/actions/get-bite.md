# Get Bite with Bannerbite

Retrieves a bite from Bannerbite by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/bites/:id`
- **Base URL:** `https://api.bannerbite.com`
- **Official documentation:** [Get Bite](https://developer.bannerbite.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Bannerbite bite ID to retrieve. |
