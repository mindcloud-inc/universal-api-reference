# Get Scene Data with Bannerbite

Retrieves scene data for a Bannerbite bite.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/sceneData/:id`
- **Base URL:** `https://api.bannerbite.com`
- **Official documentation:** [Get Scene Data](https://developer.bannerbite.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Bannerbite bite ID whose scene data you want to retrieve. |
