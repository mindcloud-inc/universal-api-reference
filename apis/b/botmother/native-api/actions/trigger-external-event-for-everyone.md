# Trigger External Event For Everyone with Botmother

Triggers an external event in Botmother for all users.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `{eventUrl}`
- **Official documentation:** [Trigger External Event For Everyone](https://docs.botmother.com/article/42097#request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data` | body | `object` | yes | Optional JSON payload copied into last_request. |
