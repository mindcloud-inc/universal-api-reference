# Generate Subtitle File with Bookoly

Creates a subtitle file in Bookoly.

## Endpoint

- **Method:** `POST`
- **Path:** `/generate-subtitle-file`
- **Base URL:** `https://bookoly.com/api/v1`
- **Official documentation:** [Generate Subtitle File](https://bookoly.com/docs/api/v1#/paths/~1generate-subtitle-file/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subtitle` | body | `object` | yes | Subtitle generation payload from the Bookoly docs. |
