# Create Speech Dialogue with Bookoly

Creates a speech dialogue in Bookoly.

## Endpoint

- **Method:** `POST`
- **Path:** `/create-speech-dialogue`
- **Base URL:** `https://bookoly.com/api/v1`
- **Official documentation:** [Create Speech Dialogue](https://bookoly.com/docs/api/v1#/paths/~1create-speech-dialogue/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `speech_dialogue` | body | `object` | yes | Speech dialogue payload from the Bookoly docs. |
