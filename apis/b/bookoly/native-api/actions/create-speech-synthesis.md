# Create Speech Synthesis with Bookoly

Creates speech synthesis from text in Bookoly.

## Endpoint

- **Method:** `POST`
- **Path:** `/text-to-speech`
- **Base URL:** `https://bookoly.com/api/v1`
- **Official documentation:** [Create Speech Synthesis](https://bookoly.com/docs/api/v1#/paths/~1text-to-speech/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `speech` | body | `object` | yes | Speech synthesis payload from the Bookoly docs. |
