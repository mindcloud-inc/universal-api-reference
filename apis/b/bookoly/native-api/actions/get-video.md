# Get Video with Bookoly

Retrieves a specific video from Bookoly.

## Endpoint

- **Method:** `GET`
- **Path:** `/videos/{video}`
- **Base URL:** `https://bookoly.com/api/v1`
- **Official documentation:** [Get Video](https://bookoly.com/docs/api/v1#/paths/~1videos~1{video}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video` | path | `string` | yes | The video ID. |
