# Combine Sounds with Bookoly

Combines multiple sounds into one in Bookoly.

## Endpoint

- **Method:** `POST`
- **Path:** `/combine-sounds`
- **Base URL:** `https://bookoly.com/api/v1`
- **Official documentation:** [Combine Sounds](https://bookoly.com/docs/api/v1#/paths/~1combine-sounds/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sound` | body | `object` | yes | Sound combination payload from the Bookoly docs. |
