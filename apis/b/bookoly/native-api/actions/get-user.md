# Get User with Bookoly

Retrieves a specific user from Bookoly.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{user}`
- **Base URL:** `https://bookoly.com/api/v1`
- **Official documentation:** [Get User](https://bookoly.com/docs/api/v1#/paths/~1users~1{user}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user` | path | `string` | yes | The user ID. |
