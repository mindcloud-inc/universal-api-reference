# Create Video From Images/Videos with Bookoly

Creates a video from images or videos in Bookoly.

## Endpoint

- **Method:** `POST`
- **Path:** `/assets-to-video`
- **Base URL:** `https://bookoly.com/api/v1`
- **Official documentation:** [Create Video From Images/Videos](https://bookoly.com/docs/api/v1#/paths/~1assets-to-video/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video` | body | `object` | yes | Video creation payload from the Bookoly v1 docs. |
