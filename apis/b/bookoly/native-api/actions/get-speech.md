# Get Speech with Bookoly

Retrieves a specific speech from Bookoly.

## Endpoint

- **Method:** `GET`
- **Path:** `/speeches/{speech}`
- **Base URL:** `https://bookoly.com/api/v1`
- **Official documentation:** [Get Speech](https://bookoly.com/docs/api/v1#/paths/~1speeches~1{speech}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `speech` | path | `string` | yes | The speech ID. |
