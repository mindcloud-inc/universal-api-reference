# Get Speech Dialogue with Bookoly

Retrieves a specific speech dialogue from Bookoly.

## Endpoint

- **Method:** `GET`
- **Path:** `/speechDialogues/{speechDialogue}`
- **Base URL:** `https://bookoly.com/api/v1`
- **Official documentation:** [Get Speech Dialogue](https://bookoly.com/docs/api/v1#/paths/~1speechDialogues~1{speechDialogue}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `speechDialogue` | path | `string` | yes | The speech dialogue ID. |
