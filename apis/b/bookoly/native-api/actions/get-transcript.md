# Get Transcript with Bookoly

Retrieves a specific transcript from Bookoly.

## Endpoint

- **Method:** `GET`
- **Path:** `/transcripts/{transcript}`
- **Base URL:** `https://bookoly.com/api/v1`
- **Official documentation:** [Get Transcript](https://bookoly.com/docs/api/v1#/paths/~1transcripts~1{transcript}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transcript` | path | `string` | yes | The transcript ID. |
