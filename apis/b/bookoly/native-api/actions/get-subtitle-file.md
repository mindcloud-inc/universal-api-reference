# Get Subtitle File with Bookoly

Retrieves a specific subtitle file from Bookoly.

## Endpoint

- **Method:** `GET`
- **Path:** `/subtitleFiles/{subtitleFile}`
- **Base URL:** `https://bookoly.com/api/v1`
- **Official documentation:** [Get Subtitle File](https://bookoly.com/docs/api/v1#/paths/~1subtitleFiles~1{subtitleFile}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subtitleFile` | path | `string` | yes | The subtitle file ID. |
