# Get Sound with Bookoly

Retrieves a specific sound from Bookoly.

## Endpoint

- **Method:** `GET`
- **Path:** `/sounds/{sound}`
- **Base URL:** `https://bookoly.com/api/v1`
- **Official documentation:** [Get Sound](https://bookoly.com/docs/api/v1#/paths/~1sounds~1{sound}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sound` | path | `string` | yes | The sound ID. |
