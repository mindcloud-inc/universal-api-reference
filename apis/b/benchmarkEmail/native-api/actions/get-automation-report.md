# Get Automation Report with Benchmark Email

Retrieves an automation report from Benchmark Email.

## Endpoint

- **Method:** `GET`
- **Path:** `/Automation/:automationId/Report`
- **Base URL:** `https://clientapi.benchmarkemail.com`
- **Official documentation:** [Get Automation Report](https://developer.benchmarkemail.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `automationId` | path | `string` | yes | Benchmark automation ID. |
