# Get Profile Details with Benchmark Email

Retrieves client profile details from Benchmark Email.

## Endpoint

- **Method:** `GET`
- **Path:** `/Client/ProfileDetails`
- **Base URL:** `https://clientapi.benchmarkemail.com`
- **Official documentation:** [Get Profile Details](https://developer.benchmarkemail.com/#da6e98f3-94b7-b0e0-b07b-cd6ae5541e45)
