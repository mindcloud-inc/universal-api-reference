# List Contacts with Benchmark Email

Retrieves contacts from a Benchmark Email contact list.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contact/:listId/ContactDetails`
- **Base URL:** `https://clientapi.benchmarkemail.com`
- **Official documentation:** [List Contacts](https://developer.benchmarkemail.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Benchmark contact list ID. |
