# Get Contact Segment with Benchmark Email

Retrieves a contact segment from Benchmark Email.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contact/Segments/:segmentId`
- **Base URL:** `https://clientapi.benchmarkemail.com`
- **Official documentation:** [Get Contact Segment](https://developer.benchmarkemail.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segmentId` | path | `string` | yes | Benchmark segment ID. |
