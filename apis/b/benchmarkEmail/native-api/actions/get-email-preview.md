# Get Email Preview with Benchmark Email

Retrieves an email preview from Benchmark Email.

## Endpoint

- **Method:** `GET`
- **Path:** `/Emails/:id/Preview`
- **Base URL:** `https://clientapi.benchmarkemail.com`
- **Official documentation:** [Get Email Preview](https://developer.benchmarkemail.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Benchmark email ID. |
