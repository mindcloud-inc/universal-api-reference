# Get Automation with Benchmark Email

Retrieves an automation from Benchmark Email.

## Endpoint

- **Method:** `GET`
- **Path:** `/Automation/:automationId`
- **Base URL:** `https://clientapi.benchmarkemail.com`
- **Official documentation:** [Get Automation](https://developer.benchmarkemail.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `automationId` | path | `string` | yes | Benchmark automation ID. |
