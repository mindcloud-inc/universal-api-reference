# Create Contact List with Benchmark Email

Creates a contact list in Benchmark Email.

## Endpoint

- **Method:** `POST`
- **Path:** `/Contact/`
- **Base URL:** `https://clientapi.benchmarkemail.com`
- **Official documentation:** [Create Contact List](https://developer.benchmarkemail.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Data` | body | `object` | yes | Contact list payload object. |
