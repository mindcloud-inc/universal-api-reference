# Create Email with Benchmark Email

Creates an email in Benchmark Email.

## Endpoint

- **Method:** `POST`
- **Path:** `/Emails/`
- **Base URL:** `https://clientapi.benchmarkemail.com`
- **Official documentation:** [Create Email](https://developer.benchmarkemail.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Detail` | body | `object` | yes | Email payload object. |
