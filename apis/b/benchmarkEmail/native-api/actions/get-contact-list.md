# Get Contact List with Benchmark Email

Retrieves a contact list from Benchmark Email.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contact/:listId`
- **Base URL:** `https://clientapi.benchmarkemail.com`
- **Official documentation:** [Get Contact List](https://developer.benchmarkemail.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Benchmark contact list ID. |
