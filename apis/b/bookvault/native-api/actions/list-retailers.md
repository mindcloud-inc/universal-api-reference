# List Retailers with Bookvault

Retrieves available retailers from Bookvault.

## Endpoint

- **Method:** `GET`
- **Path:** `/Retailers`
- **Base URL:** `https://api.bookvault.app/v3`
- **Official documentation:** [List Retailers](https://api.bookvault.app/v3/docs#tag/Wholesale/operation/Retailers_Get)
