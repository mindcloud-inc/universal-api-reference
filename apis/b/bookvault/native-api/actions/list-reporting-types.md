# List Reporting Types with Bookvault

Retrieves available reporting types from Bookvault.

## Endpoint

- **Method:** `GET`
- **Path:** `/ReportingTypes`
- **Base URL:** `https://api.bookvault.app/v3`
- **Official documentation:** [List Reporting Types](https://api.bookvault.app/v3/docs#tag/Reporting/operation/ReportingTypes_Get)
