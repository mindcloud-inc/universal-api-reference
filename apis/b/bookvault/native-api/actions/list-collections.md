# List Collections with Bookvault

Retrieves available collections from Bookvault.

## Endpoint

- **Method:** `GET`
- **Path:** `/Collections`
- **Base URL:** `https://api.bookvault.app/v3`
- **Official documentation:** [List Collections](https://api.bookvault.app/v3/docs#tag/TGBBS/operation/Collections_Get)
