# List Addresses with Bookvault

Retrieves saved addresses from your Bookvault account.

## Endpoint

- **Method:** `GET`
- **Path:** `/Addresses`
- **Base URL:** `https://api.bookvault.app/v3`
- **Official documentation:** [List Addresses](https://api.bookvault.app/v3/docs#tag/Orders/operation/Addresses_get)
