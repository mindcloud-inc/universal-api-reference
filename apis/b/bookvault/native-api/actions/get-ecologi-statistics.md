# Get Ecologi Statistics with Bookvault

Retrieves current Ecologi statistics from Bookvault.

## Endpoint

- **Method:** `GET`
- **Path:** `/Ecologi`
- **Base URL:** `https://api.bookvault.app/v3`
- **Official documentation:** [Get Ecologi Statistics](https://api.bookvault.app/v3/docs#tag/Enviromental/operation/Ecologi_get)
