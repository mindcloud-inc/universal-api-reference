# List Address Groups with Bookvault

Retrieves address groups from your Bookvault account.

## Endpoint

- **Method:** `GET`
- **Path:** `/AddressLists`
- **Base URL:** `https://api.bookvault.app/v3`
- **Official documentation:** [List Address Groups](https://api.bookvault.app/v3/docs#tag/Addresses/operation/AddressLists_get)
