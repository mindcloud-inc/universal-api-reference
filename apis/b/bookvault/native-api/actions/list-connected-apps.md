# List Connected Apps with Bookvault

Retrieves connected apps from your Bookvault account.

## Endpoint

- **Method:** `GET`
- **Path:** `/App`
- **Base URL:** `https://api.bookvault.app/v3`
- **Official documentation:** [List Connected Apps](https://api.bookvault.app/v3/docs#tag/Account/operation/App_Get)
