# List Account Credit Notes with Billforward

Retrieves credit notes for a Billforward account.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/credit`
- **Base URL:** `https://app-sandbox.billforward.net/v1`
- **Official documentation:** [List Account Credit Notes](https://app.billforward.net/#/api/method/accounts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | The Billforward account ID. |
