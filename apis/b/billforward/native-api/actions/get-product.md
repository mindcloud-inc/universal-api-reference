# Get Product with Billforward

Retrieves a product from Billforward.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:productId`
- **Base URL:** `https://app-sandbox.billforward.net/v1`
- **Official documentation:** [Get Product](https://app.billforward.net/#/api/method/products)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | yes | The Billforward product ID. |
