# List Profiles By Account with Billforward

Retrieves profiles for a Billforward account.

## Endpoint

- **Method:** `GET`
- **Path:** `/profiles/account/:accountId`
- **Base URL:** `https://app-sandbox.billforward.net/v1`
- **Official documentation:** [List Profiles By Account](https://app.billforward.net/#/api/method/profiles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | The Billforward account ID. |
