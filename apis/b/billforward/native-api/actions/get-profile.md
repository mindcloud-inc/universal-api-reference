# Get Profile with Billforward

Retrieves a profile from Billforward.

## Endpoint

- **Method:** `GET`
- **Path:** `/profiles/:profileId`
- **Base URL:** `https://app-sandbox.billforward.net/v1`
- **Official documentation:** [Get Profile](https://app.billforward.net/#/api/method/profiles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profileId` | path | `string` | yes | The Billforward profile ID. |
