# Get Account with Billforward

Retrieves an account from Billforward.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId`
- **Base URL:** `https://app-sandbox.billforward.net/v1`
- **Official documentation:** [Get Account](https://app.billforward.net/#/api/method/accounts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | The Billforward account ID. |
