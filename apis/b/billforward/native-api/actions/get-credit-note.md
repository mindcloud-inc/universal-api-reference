# Get Credit Note with Billforward

Retrieves a credit note from Billforward.

## Endpoint

- **Method:** `GET`
- **Path:** `/credit-notes/:creditNoteId`
- **Base URL:** `https://app-sandbox.billforward.net/v1`
- **Official documentation:** [Get Credit Note](https://app.billforward.net/#/api/method/credit-notes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `creditNoteId` | path | `string` | yes | The Billforward credit note ID. |
