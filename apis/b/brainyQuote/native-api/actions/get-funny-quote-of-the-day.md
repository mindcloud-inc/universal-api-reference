# Get Funny Quote of the Day with BrainyQuote

Retrieves the BrainyQuote funny quote of the day feed.

## Endpoint

- **Method:** `GET`
- **Path:** `/link/quotefu.rss`
- **Base URL:** `https://www.brainyquote.com`
- **Official documentation:** [Get Funny Quote of the Day](https://www.brainyquote.com/feeds/funny)
