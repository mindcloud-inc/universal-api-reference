# Get Group with bitFit Asset Management Software

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/groups/:id`
- **Base URL:** `https://api-assets.bitfit.com`
- **Official documentation:** [Get Group](https://assets.bitfit.com/setup/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The BitFit group ID to retrieve. |
