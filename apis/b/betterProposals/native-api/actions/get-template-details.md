# Get Template Details with Better Proposals

Retrieves template details from Better Proposals.

## Endpoint

- **Method:** `GET`
- **Path:** `/template/:TEMPLATE_ID`
- **Base URL:** `https://api.betterproposals.io`
- **Official documentation:** [Get Template Details](https://betterproposals.io/resources/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `TEMPLATE_ID` | path | `string` | yes | The Better Proposals template ID. |
