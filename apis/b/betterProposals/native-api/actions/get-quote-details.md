# Get Quote Details with Better Proposals

Retrieves quote details from Better Proposals.

## Endpoint

- **Method:** `GET`
- **Path:** `/quote/:QUOTE_ID`
- **Base URL:** `https://api.betterproposals.io`
- **Official documentation:** [Get Quote Details](https://betterproposals.io/resources/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `QUOTE_ID` | path | `string` | yes | The Better Proposals quote ID. |
