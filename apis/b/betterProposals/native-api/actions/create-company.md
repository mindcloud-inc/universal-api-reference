# Create Company with Better Proposals

Creates a company in Better Proposals.

## Endpoint

- **Method:** `POST`
- **Path:** `/company/create`
- **Base URL:** `https://api.betterproposals.io`
- **Official documentation:** [Create Company](https://betterproposals.io/resources/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CompanyName` | body | `string` | yes | Company name. |
