# Get Currency Details with Better Proposals

Retrieves currency details from Better Proposals.

## Endpoint

- **Method:** `GET`
- **Path:** `/currency/:CURRENCY_ID`
- **Base URL:** `https://api.betterproposals.io`
- **Official documentation:** [Get Currency Details](https://betterproposals.io/resources/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CURRENCY_ID` | path | `string` | yes | The Better Proposals currency ID. |
