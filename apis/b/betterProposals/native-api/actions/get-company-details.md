# Get Company Details with Better Proposals

Retrieves company details from Better Proposals.

## Endpoint

- **Method:** `GET`
- **Path:** `/company/:COMPANY_ID`
- **Base URL:** `https://api.betterproposals.io`
- **Official documentation:** [Get Company Details](https://betterproposals.io/resources/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `COMPANY_ID` | path | `string` | yes | The Better Proposals company ID. |
