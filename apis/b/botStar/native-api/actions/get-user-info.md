# Get User Info with BotStar

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:botId/users/:userId`
- **Base URL:** `https://apis.botstar.com/v1`
- **Official documentation:** [Get User Info](https://apis.botstar.com/docs/#/Users/get_bots__botId__users__userId_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botId` | path | `string` | yes |
| `userId` | path | `string` | yes |
