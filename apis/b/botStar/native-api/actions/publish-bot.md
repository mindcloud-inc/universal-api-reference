# Publish Bot with BotStar

## Endpoint

- **Method:** `POST`
- **Path:** `/bots/:botId/publish`
- **Base URL:** `https://apis.botstar.com/v1`
- **Official documentation:** [Publish Bot](https://apis.botstar.com/docs/#/Bots/post_bots__botId__publish)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botId` | path | `string` | yes |
