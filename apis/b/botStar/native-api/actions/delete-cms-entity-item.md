# Delete CMS Entity Item with BotStar

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bots/:botId/cms_entities/:entityId/items/:entityItemId`
- **Base URL:** `https://apis.botstar.com/v1`
- **Official documentation:** [Delete CMS Entity Item](https://apis.botstar.com/docs/#/CMS%20Entity%20Items/delete_bots__botId__cms_entities__entityId__items__entityItemId_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botId` | path | `string` | yes |
| `entityId` | path | `string` | yes |
| `entityItemId` | path | `string` | yes |
| `env` | query | `string` | no |
