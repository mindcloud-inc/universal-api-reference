# Get CMS Entity with BotStar

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:botId/cms_entities/:entityId`
- **Base URL:** `https://apis.botstar.com/v1`
- **Official documentation:** [Get CMS Entity](https://apis.botstar.com/docs/#/CMS%20Entities/get_bots__botId__cms_entities__entityId_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botId` | path | `string` | yes |
| `entityId` | path | `string` | yes |
| `env` | query | `string` | no |
