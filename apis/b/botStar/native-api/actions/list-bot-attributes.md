# List Bot Attributes with BotStar

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:botId/attributes`
- **Base URL:** `https://apis.botstar.com/v1`
- **Official documentation:** [List Bot Attributes](https://apis.botstar.com/docs/#/Bots/get_bots__botId__attributes)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botId` | path | `string` | yes |
| `env` | query | `string` | no |
