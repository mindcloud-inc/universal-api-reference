# Delete CMS Entity with BotStar

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bots/:botId/cms_entities/:entityId`
- **Base URL:** `https://apis.botstar.com/v1`
- **Official documentation:** [Delete CMS Entity](https://apis.botstar.com/docs/#/CMS%20Entities/delete_bots__botId__cms_entities__entityId_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botId` | path | `string` | yes |
| `entityId` | path | `string` | yes |
| `env` | query | `string` | no |
