- **Method:** `GET`
- **Path:** `/bots/:botId`
- **Base URL:** `https://apis.botstar.com/v1`
- **Official documentation:** [Get Bot](https://apis.botstar.com/docs/#/Bots/get_bots__botId_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botId` | path | `string` | yes |
