# List CMS Entities with BotStar

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:botId/cms_entities`
- **Base URL:** `https://apis.botstar.com/v1`
- **Official documentation:** [List CMS Entities](https://apis.botstar.com/docs/#/CMS%20Entities/get_bots__botId__cms_entities)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botId` | path | `string` | yes |
| `env` | query | `string` | no |
