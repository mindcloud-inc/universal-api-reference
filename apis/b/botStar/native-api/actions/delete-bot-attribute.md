# Delete Bot Attribute with BotStar

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bots/:botId/attributes/:attributeId`
- **Base URL:** `https://apis.botstar.com/v1`
- **Official documentation:** [Delete Bot Attribute](https://apis.botstar.com/docs/#/Bots/delete_bots__botId__attributes__attributeId_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `attributeId` | path | `string` | yes |
| `botId` | path | `string` | yes |
| `env` | query | `string` | no |
