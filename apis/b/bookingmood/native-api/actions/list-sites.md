# List Sites with Bookingmood

Retrieves site records from the Bookingmood API.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [List Sites](https://www.bookingmood.com/en-US/api-reference/sites)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
