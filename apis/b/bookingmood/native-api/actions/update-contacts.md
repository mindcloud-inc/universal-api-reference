# Update Contacts with Bookingmood

Updates contact records in the Bookingmood API.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/contacts`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [Update Contacts](https://www.bookingmood.com/en-US/api-reference/contacts)

## Capabilities

This operation supports [filtering](../README.md#filtering).
