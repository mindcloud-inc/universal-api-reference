# List Invoices with Bookingmood

Retrieves invoice records from the Bookingmood API.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [List Invoices](https://www.bookingmood.com/en-US/api-reference/invoices)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
