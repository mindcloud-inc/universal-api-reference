# List Contacts with Bookingmood

Retrieves contact records from the Bookingmood API.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [List Contacts](https://www.bookingmood.com/en-US/api-reference/contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
