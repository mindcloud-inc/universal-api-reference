# List Products with Bookingmood

Retrieves product records from the Bookingmood API.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [List Products](https://www.bookingmood.com/en-US/api-reference/products)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
