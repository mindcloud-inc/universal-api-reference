# Update Payments with Bookingmood

Updates payment records in the Bookingmood API.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/payments`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [Update Payments](https://www.bookingmood.com/en-US/api-reference/payments)

## Capabilities

This operation supports [filtering](../README.md#filtering).
