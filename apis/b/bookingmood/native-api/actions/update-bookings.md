# Update Bookings with Bookingmood

Updates booking records in the Bookingmood API.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/bookings`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [Update Bookings](https://www.bookingmood.com/en-US/api-reference/bookings)

## Capabilities

This operation supports [filtering](../README.md#filtering).
