# List Bookings with Bookingmood

Retrieves booking records from the Bookingmood API.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [List Bookings](https://www.bookingmood.com/en-US/api-reference/bookings)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
