# Update Calendar Events with Bookingmood

Updates calendar event records in the Bookingmood API.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/calendar_events`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [Update Calendar Events](https://www.bookingmood.com/en-US/api-reference/calendar_events)

## Capabilities

This operation supports [filtering](../README.md#filtering).
