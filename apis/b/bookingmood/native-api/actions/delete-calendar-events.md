# Delete Calendar Events with Bookingmood

Deletes calendar event records from the Bookingmood API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/calendar_events`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [Delete Calendar Events](https://www.bookingmood.com/en-US/api-reference/calendar_events)

## Capabilities

This operation supports [filtering](../README.md#filtering).
