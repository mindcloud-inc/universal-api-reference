# List Calendar Events with Bookingmood

Retrieves calendar event records from the Bookingmood API.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar_events`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [List Calendar Events](https://www.bookingmood.com/en-US/api-reference/calendar_events)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
