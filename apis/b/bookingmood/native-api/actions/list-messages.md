# List Messages with Bookingmood

Retrieves messages scheduled or sent to Bookingmood guests.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [List Messages](https://www.bookingmood.com/en-US/api-reference/messages)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
