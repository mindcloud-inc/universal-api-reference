# List Payments with Bookingmood

Retrieves payment records from the Bookingmood API.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [List Payments](https://www.bookingmood.com/en-US/api-reference/payments)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
