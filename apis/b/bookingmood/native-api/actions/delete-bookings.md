# Delete Bookings with Bookingmood

Deletes booking records from the Bookingmood API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bookings`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [Delete Bookings](https://www.bookingmood.com/en-US/api-reference/bookings)

## Capabilities

This operation supports [filtering](../README.md#filtering).
