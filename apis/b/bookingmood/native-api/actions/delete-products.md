# Delete Products with Bookingmood

Deletes product records from the Bookingmood API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/products`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [Delete Products](https://www.bookingmood.com/en-US/api-reference/products)

## Capabilities

This operation supports [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Product id to delete. |
