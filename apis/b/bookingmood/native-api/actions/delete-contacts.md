# Delete Contacts with Bookingmood

Deletes contact records from the Bookingmood API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts`
- **Base URL:** `https://api.bookingmood.com/v1`
- **Official documentation:** [Delete Contacts](https://www.bookingmood.com/en-US/api-reference/contacts)

## Capabilities

This operation supports [filtering](../README.md#filtering).
