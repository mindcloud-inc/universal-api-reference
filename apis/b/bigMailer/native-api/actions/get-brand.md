# Get Brand with BigMailer

Retrieves a brand from your BigMailer account.

## Endpoint

- **Method:** `GET`
- **Path:** `/brands/:brand_id`
- **Base URL:** `https://api.bigmailer.io/v1`
- **Official documentation:** [Get Brand](https://docs.bigmailer.io/reference/getbrand)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `brand_id` | path | `string` | yes | ID of the brand to get. |
