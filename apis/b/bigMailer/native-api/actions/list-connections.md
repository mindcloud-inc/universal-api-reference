# List Connections with BigMailer

Retrieves connections from your BigMailer account.

## Endpoint

- **Method:** `GET`
- **Path:** `/connections`
- **Base URL:** `https://api.bigmailer.io/v1`
- **Official documentation:** [List Connections](https://docs.bigmailer.io/reference/listconnections)

## Capabilities

This operation supports [pagination](../README.md#pagination).
