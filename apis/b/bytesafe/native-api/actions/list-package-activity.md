# List Package Activity with Bytesafe

Retrieves package activity from Bytesafe dashboards.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboard/activity/packages`
- **Base URL:** `https://mindcloud.bytesafe.dev/api/v1/`
- **Official documentation:** [List Package Activity](https://docs.bytesafe.dev/working-with-registries/dashboards/)
