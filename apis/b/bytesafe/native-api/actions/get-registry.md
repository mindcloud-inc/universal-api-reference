# Get Registry with Bytesafe

Retrieves a registry from your Bytesafe workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/artifacts/registries/:registryId`
- **Base URL:** `https://mindcloud.bytesafe.dev/api/v1/`
- **Official documentation:** [Get Registry](https://docs.bytesafe.dev/working-with-registries/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `registryId` | path | `string` | yes | The Bytesafe registry ID to fetch. |
