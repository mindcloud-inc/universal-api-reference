# List IAM Roles with Bytesafe

Retrieves role-based access control roles from Bytesafe.

## Endpoint

- **Method:** `GET`
- **Path:** `/iam/roles`
- **Base URL:** `https://mindcloud.bytesafe.dev/api/v1/`
- **Official documentation:** [List IAM Roles](https://docs.bytesafe.dev/account-and-profile/iam/)
