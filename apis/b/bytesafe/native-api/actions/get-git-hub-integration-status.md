# Get GitHub Integration Status with Bytesafe

Retrieves GitHub integration status from Bytesafe.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations/github/status`
- **Base URL:** `https://mindcloud.bytesafe.dev/api/v1/`
- **Official documentation:** [Get GitHub Integration Status](https://docs.bytesafe.dev/integrations/github/)
