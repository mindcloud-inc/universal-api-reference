# List Registries with Bytesafe

Retrieves registries from your Bytesafe workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/artifacts/registries`
- **Base URL:** `https://mindcloud.bytesafe.dev/api/v1/`
- **Official documentation:** [List Registries](https://docs.bytesafe.dev/working-with-registries/)
