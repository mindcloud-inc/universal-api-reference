# List Team Members with Bytesafe

Retrieves team members from your Bytesafe workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/team/members`
- **Base URL:** `https://mindcloud.bytesafe.dev/api/v1/`
- **Official documentation:** [List Team Members](https://docs.bytesafe.dev/getting-started/invite-team-members/)
