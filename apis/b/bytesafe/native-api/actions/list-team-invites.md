# List Team Invites with Bytesafe

Retrieves team invites from your Bytesafe workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/team/invites`
- **Base URL:** `https://mindcloud.bytesafe.dev/api/v1/`
- **Official documentation:** [List Team Invites](https://docs.bytesafe.dev/getting-started/invite-team-members/)
