# Get Slack Integration Status with Bytesafe

Retrieves Slack integration status from Bytesafe.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations/slack/status`
- **Base URL:** `https://mindcloud.bytesafe.dev/api/v1/`
- **Official documentation:** [Get Slack Integration Status](https://docs.bytesafe.dev/integrations/slack/)
