# Get Storage Metrics with Bytesafe

Retrieves storage metrics from Bytesafe dashboards.

## Endpoint

- **Method:** `GET`
- **Path:** `/metrics/storage`
- **Base URL:** `https://mindcloud.bytesafe.dev/api/v1/`
- **Official documentation:** [Get Storage Metrics](https://docs.bytesafe.dev/working-with-registries/dashboards/)
