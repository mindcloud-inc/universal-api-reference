# Get Authenticated User with Bytesafe

Retrieves the authenticated user from your Bytesafe workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/whoami`
- **Base URL:** `https://mindcloud.bytesafe.dev/api/v1/`
- **Official documentation:** [Get Authenticated User](https://docs.bytesafe.dev/account-and-profile/profile/)
