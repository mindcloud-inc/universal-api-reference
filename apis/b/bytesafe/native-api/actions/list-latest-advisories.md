# List Latest Advisories with Bytesafe

Retrieves the latest advisories from Bytesafe.

## Endpoint

- **Method:** `GET`
- **Path:** `/artifacts/advisory/latest`
- **Base URL:** `https://mindcloud.bytesafe.dev/api/v1/`
- **Official documentation:** [List Latest Advisories](https://docs.bytesafe.dev/issues/)
