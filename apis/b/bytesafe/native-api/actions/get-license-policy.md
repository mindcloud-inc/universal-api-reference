# Get License Policy with Bytesafe

Retrieves a license compliance policy from Bytesafe.

## Endpoint

- **Method:** `GET`
- **Path:** `/license-policies/:policyName`
- **Base URL:** `https://mindcloud.bytesafe.dev/api/v1/`
- **Official documentation:** [Get License Policy](https://docs.bytesafe.dev/license-compliance/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `policyName` | path | `string` | yes | The Bytesafe license policy name. |
