# Get Bot User with Botbaba

## Endpoint

- **Method:** `GET`
- **Path:** `/api/GetBotUserById`
- **Base URL:** `https://app.botbaba.io`
- **Official documentation:** [Get Bot User](https://app.botbaba.io/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `botUserId` | query | `number` | yes | The Botbaba bot user identifier. |
| `botId` | query | `number` | yes | The Botbaba bot identifier. |
