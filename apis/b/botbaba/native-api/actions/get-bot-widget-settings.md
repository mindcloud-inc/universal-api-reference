# Get Bot Widget Settings with Botbaba

## Endpoint

- **Method:** `GET`
- **Path:** `/api/GetBotWidgetSettings`
- **Base URL:** `https://app.botbaba.io`
- **Official documentation:** [Get Bot Widget Settings](https://app.botbaba.io/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `botId` | query | `number` | yes | The Botbaba bot identifier. |
