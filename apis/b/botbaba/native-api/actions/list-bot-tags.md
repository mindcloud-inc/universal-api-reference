# List Bot Tags with Botbaba

## Endpoint

- **Method:** `GET`
- **Path:** `/api/GetBotTags`
- **Base URL:** `https://app.botbaba.io`
- **Official documentation:** [List Bot Tags](https://app.botbaba.io/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `botId` | query | `number` | yes | The Botbaba bot identifier. |
