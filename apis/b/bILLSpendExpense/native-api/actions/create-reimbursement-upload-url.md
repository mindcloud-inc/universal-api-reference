# Create Reimbursement Upload URL with BILL Spend & Expense

Creates a reimbursement upload URL in BILL Spend & Expense.

## Endpoint

- **Method:** `POST`
- **Path:** `spend/reimbursements/image-upload-url`
- **Base URL:** `https://gateway.{environment}.bill.com/connect/v3`
- **Official documentation:** [Create Reimbursement Upload URL](https://developer.bill.com/reference/createimageuploadurl)
