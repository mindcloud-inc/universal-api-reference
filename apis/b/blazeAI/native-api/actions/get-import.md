# Get Import with Blaze AI

Retrieves a document import from Blaze AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/w/:workspace_id/imports/:id`
- **Base URL:** `https://api.blaze.ai`
- **Official documentation:** [Get Import](https://api.blaze.ai/api/documentation#!/imports/getApiV1WWorkspaceIdImportsId)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspace_id` | path | `number` | yes |
| `id` | path | `number` | yes |
