# Get Published Docs Polling Test with Blaze AI

Retrieves published document polling test data from Blaze AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/w/:workspace_id/zapier_published_docs_polling_test`
- **Base URL:** `https://api.blaze.ai`
- **Official documentation:** [Get Published Docs Polling Test](https://api.blaze.ai/api/documentation#!/w/getApiV1WWorkspaceIdZapierPublishedDocsPollingTest)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspace_id` | path | `number` | yes |
