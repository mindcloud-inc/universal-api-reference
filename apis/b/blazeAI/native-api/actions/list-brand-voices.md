# List Brand Voices with Blaze AI

Retrieves brand voices from Blaze AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/w/:workspace_id/brand_voices`
- **Base URL:** `https://api.blaze.ai`
- **Official documentation:** [List Brand Voices](https://api.blaze.ai/api/documentation#!/brand_voices/getApiV1WWorkspaceIdBrandVoices)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspace_id` | path | `number` | yes |
