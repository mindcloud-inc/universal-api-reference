# List Workspace Properties with Blaze AI

Retrieves workspace properties from Blaze AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/w/:workspace_id/properties`
- **Base URL:** `https://api.blaze.ai`
- **Official documentation:** [List Workspace Properties](https://api.blaze.ai/api/documentation#!/properties/getApiV1WWorkspaceIdProperties)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspace_id` | path | `number` | yes |
