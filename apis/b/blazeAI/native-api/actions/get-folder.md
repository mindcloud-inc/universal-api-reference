# Get Folder with Blaze AI

Retrieves a folder from Blaze AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/w/:workspace_id/folders/:id`
- **Base URL:** `https://api.blaze.ai`
- **Official documentation:** [Get Folder](https://api.blaze.ai/api/documentation#!/folders/getApiV1WWorkspaceIdFoldersId)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspace_id` | path | `number` | yes |
| `id` | path | `number` | yes |
