# Delete Job with Botster

Deletes an existing job from Botster.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/jobs/:jobId`
- **Base URL:** `https://botster.io/api/v2`
- **Official documentation:** [Delete Job](https://botster.io/info/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The Botster job UUID. |
