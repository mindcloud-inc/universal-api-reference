# Get Job with Botster

Retrieves a Botster job and its runs.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:jobId`
- **Base URL:** `https://botster.io/api/v2`
- **Official documentation:** [Get Job](https://botster.io/info/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The Botster job UUID. |
