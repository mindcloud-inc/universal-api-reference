# Delete Run with Botster

Deletes an existing run from Botster.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/runs/:runId`
- **Base URL:** `https://botster.io/api/v2`
- **Official documentation:** [Delete Run](https://botster.io/info/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `runId` | path | `string` | yes | The Botster run UUID. |
