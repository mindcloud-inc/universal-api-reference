# Get Run with Botster

Retrieves result data for a Botster run.

## Endpoint

- **Method:** `GET`
- **Path:** `/runs/:runId`
- **Base URL:** `https://botster.io/api/v2`
- **Official documentation:** [Get Run](https://botster.io/info/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `runId` | path | `string` | yes | The Botster run UUID. |
