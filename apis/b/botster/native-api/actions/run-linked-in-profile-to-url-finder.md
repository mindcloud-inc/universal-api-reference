# Run LinkedIn Profile to URL Finder with Botster

Creates a Botster LinkedIn profile website lookup job.

## Endpoint

- **Method:** `POST`
- **Path:** `/bots/linkedin-profile-to-url`
- **Base URL:** `https://botster.io/api/v2`
- **Official documentation:** [Run LinkedIn Profile to URL Finder](https://botster.io/bots/linkedin-profile-to-url)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | LinkedIn profile URLs. |
