# List Jobs with Botster

Retrieves the jobs in your Botster account.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs`
- **Base URL:** `https://botster.io/api/v2`
- **Official documentation:** [List Jobs](https://botster.io/info/api-docs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
