# List Bots with Botster

Retrieves the available bots from Botster.

## Endpoint

- **Method:** `GET`
- **Path:** `/bots`
- **Base URL:** `https://botster.io/api/v2`
- **Official documentation:** [List Bots](https://botster.io/info/api-docs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
