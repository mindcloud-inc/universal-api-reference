# Unarchive Job with Botster

Unarchives an existing job in Botster.

## Endpoint

- **Method:** `POST`
- **Path:** `/jobs/:jobId/unarchive`
- **Base URL:** `https://botster.io/api/v2`
- **Official documentation:** [Unarchive Job](https://botster.io/info/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The Botster job UUID. |
