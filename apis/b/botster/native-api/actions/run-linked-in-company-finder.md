# Run LinkedIn Company Finder with Botster

Creates a Botster LinkedIn company lookup job.

## Endpoint

- **Method:** `POST`
- **Path:** `/bots/linkedin-company-finder`
- **Base URL:** `https://botster.io/api/v2`
- **Official documentation:** [Run LinkedIn Company Finder](https://botster.io/bots/linkedin-company-finder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | Company names or official website domains. |
