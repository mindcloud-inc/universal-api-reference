# Validate BIC with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/bic`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Validate BIC](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bic` | query | `string` | no | Bank Identifier Code to validate. |
