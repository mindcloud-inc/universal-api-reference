# Lookup Postcode with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/postcode`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Lookup Postcode](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `country_code` | query | `string` | no | ISO2 country code. |
| `postcode` | query | `string` | no | Postcode to look up. |
