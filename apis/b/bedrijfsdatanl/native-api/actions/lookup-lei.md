# Lookup LEI with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/lei`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Lookup LEI](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | Organization name to search for an LEI. |
