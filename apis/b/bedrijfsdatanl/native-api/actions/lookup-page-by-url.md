# Lookup Page By URL with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/rag_url`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Lookup Page By URL](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | no | URL to analyze with RAG. |
