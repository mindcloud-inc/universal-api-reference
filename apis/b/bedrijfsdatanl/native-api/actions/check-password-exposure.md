# Check Password Exposure with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/password`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Check Password Exposure](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `password` | query | `string` | no | Password value to check for known exposure. |
