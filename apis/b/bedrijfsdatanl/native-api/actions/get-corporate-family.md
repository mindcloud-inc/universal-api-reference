# Get Corporate Family with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/corporate_family`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Get Corporate Family](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | Company ID used to resolve a corporate family. |
