# Find Company Vacancies with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/vacancies`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Find Company Vacancies](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `coc` | query | `string` | no | Dutch Chamber of Commerce number used to find vacancies. |
