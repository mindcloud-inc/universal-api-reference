# Lookup Company By KVK with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/kvk`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Lookup Company By KVK](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/request/k4v1n7x/kvk)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `coc` | query | `string` | no | Optional Dutch Chamber of Commerce number. |
