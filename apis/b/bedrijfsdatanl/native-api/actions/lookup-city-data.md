# Lookup City Data with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/city`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Lookup City Data](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `city` | query | `string` | no | City name to look up. |
| `country_code` | query | `string` | no | ISO2 country code. |
