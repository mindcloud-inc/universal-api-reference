# Find Companies At Shared Address with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/shared_address`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Find Companies At Shared Address](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | Company ID used to find related companies at the same address. |
