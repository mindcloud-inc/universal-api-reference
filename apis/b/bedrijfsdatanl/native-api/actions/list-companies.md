# List Companies with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/companies`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [List Companies](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/request/75odte9/companies)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Optional search query for company discovery. |
