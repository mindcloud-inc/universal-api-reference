# Suggest Companies with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/suggest`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Suggest Companies](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | query | `string` | no | Text to autocomplete. |
| `type` | query | `string` | no | Suggestion type, for example company. |
