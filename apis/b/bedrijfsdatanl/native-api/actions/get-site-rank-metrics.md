# Get Site Rank Metrics with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/siterank`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Get Site Rank Metrics](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | no | Domain to evaluate for site metrics. |
