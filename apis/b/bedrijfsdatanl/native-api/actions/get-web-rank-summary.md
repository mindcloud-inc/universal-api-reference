# Get Web Rank Summary with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/webrank`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Get Web Rank Summary](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | no | Domain to evaluate for web rank data. |
