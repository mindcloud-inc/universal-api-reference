# Search Web Pages with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/rag_search`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Search Web Pages](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Keyword query for RAG search. |
