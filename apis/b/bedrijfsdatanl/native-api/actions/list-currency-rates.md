# List Currency Rates with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/currency`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [List Currency Rates](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `currency` | query | `string` | no | Base currency code, for example EUR. |
