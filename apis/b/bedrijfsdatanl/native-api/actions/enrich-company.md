# Enrich Company with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/enrich`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Enrich Company](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | Bedrijfsdata company ID to enrich. |
