# Lookup BAG Address with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/bag`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Lookup BAG Address](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `number` | query | `string` | no | House number for the postcode lookup. |
| `postcode` | query | `string` | no | Dutch postcode. |
