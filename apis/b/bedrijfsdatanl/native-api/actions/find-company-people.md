# Find Company People with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/people`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Find Company People](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | Company name used to find people records. |
