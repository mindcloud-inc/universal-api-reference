# Validate VAT Number with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/vat`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Validate VAT Number](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vat` | query | `string` | no | VAT number to validate. |
