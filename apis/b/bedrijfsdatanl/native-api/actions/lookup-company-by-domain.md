# Lookup Company By Domain with Bedrijfsdata.nl

## Endpoint

- **Method:** `GET`
- **Path:** `/rag_domain`
- **Base URL:** `https://fapi.bedrijfsdata.nl/v1.2`
- **Official documentation:** [Lookup Company By Domain](https://www.postman.com/bedrijfsdatanl/bedrijfsdata-nl-api/collection/rz54v2q/bedrijfsdata-nl-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | no | Domain to analyze with RAG. |
