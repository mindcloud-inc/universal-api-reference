# List Projects with Blue

Retrieves projects for a Blue company.

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.blue.cc`
- **Official documentation:** [List Projects](https://blue.cc/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.companyId` | body | `string` | yes | Blue company node ID. |
