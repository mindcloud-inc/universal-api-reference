# Get Company with Blue

Retrieves a company from Blue by ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.blue.cc`
- **Official documentation:** [Get Company](https://blue.cc/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.companyId` | body | `string` | yes | Blue company node ID. |
