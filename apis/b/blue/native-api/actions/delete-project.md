# Delete Project with Blue

Deletes an existing project from Blue.

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.blue.cc`
- **Official documentation:** [Delete Project](https://blue.cc/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.projectId` | body | `string` | yes | Blue project node ID. |
