# Get User with Blue

Retrieves a user from Blue by ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.blue.cc`
- **Official documentation:** [Get User](https://blue.cc/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.userId` | body | `string` | yes | Blue user node ID. |
