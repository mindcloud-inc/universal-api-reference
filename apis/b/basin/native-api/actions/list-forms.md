# List Forms with Basin

Retrieves form records from Basin.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/forms`
- **Base URL:** `https://usebasin.com`
- **Official documentation:** [List Forms](https://usebasin.com/api_docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Filter forms by ID, name, UUID, or project ID. |
