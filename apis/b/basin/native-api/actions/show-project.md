# Show Project with Basin

Retrieves project details from Basin.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/projects/:id`
- **Base URL:** `https://usebasin.com`
- **Official documentation:** [Show Project](https://usebasin.com/api_docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the project to show. |
