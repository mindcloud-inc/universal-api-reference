# List Form Views with Basin

Retrieves form view records from Basin.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/form_views`
- **Base URL:** `https://usebasin.com`
- **Official documentation:** [List Form Views](https://usebasin.com/api_docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Filter form views by ID, UUID, form ID, or form UUID. |
