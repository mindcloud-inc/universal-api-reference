# Delete Submission with Basin

Deletes an existing submission from Basin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/submissions/:id`
- **Base URL:** `https://usebasin.com`
- **Official documentation:** [Delete Submission](https://usebasin.com/api_docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the submission to destroy. |
