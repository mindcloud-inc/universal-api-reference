# List Domains with Basin

Retrieves domain records from Basin.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/domains`
- **Base URL:** `https://usebasin.com`
- **Official documentation:** [List Domains](https://usebasin.com/api_docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Filter domains by ID or name. |
