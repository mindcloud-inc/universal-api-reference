# List Projects with Basin

Retrieves project records from Basin.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/projects`
- **Base URL:** `https://usebasin.com`
- **Official documentation:** [List Projects](https://usebasin.com/api_docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Filter projects by ID or name. |
