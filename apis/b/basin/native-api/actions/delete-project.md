# Delete Project with Basin

Deletes an existing project from Basin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/projects/:id`
- **Base URL:** `https://usebasin.com`
- **Official documentation:** [Delete Project](https://usebasin.com/api_docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the project to delete. |
