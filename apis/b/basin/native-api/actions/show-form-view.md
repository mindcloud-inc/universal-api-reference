# Show Form View with Basin

Retrieves form view details from Basin.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/form_views/:id`
- **Base URL:** `https://usebasin.com`
- **Official documentation:** [Show Form View](https://usebasin.com/api_docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the form view to show. |
