# Show Submission with Basin

Retrieves submission details from Basin.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/submissions/:id`
- **Base URL:** `https://usebasin.com`
- **Official documentation:** [Show Submission](https://usebasin.com/api_docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Submission ID to show. |
