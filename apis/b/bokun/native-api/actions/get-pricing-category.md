# Get Pricing Category with Bokun

Retrieves a pricing category by ID from Bokun.

## Endpoint

- **Method:** `GET`
- **Path:** `/restapi/v2.0/pricing/category/:pricingCategoryId`
- **Base URL:** `https://api.bokun.io`
- **Official documentation:** [Get Pricing Category](https://api-docs.bokun.dev/rest-v2.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pricingCategoryId` | path | `number` | yes | The Bokun pricing category ID. |
