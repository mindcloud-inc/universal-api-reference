# Get Price Schedule with Bokun

Retrieves a price schedule by ID from Bokun.

## Endpoint

- **Method:** `GET`
- **Path:** `/restapi/v2.0/pricing/schedule/:priceScheduleId`
- **Base URL:** `https://api.bokun.io`
- **Official documentation:** [Get Price Schedule](https://api-docs.bokun.dev/rest-v2.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `priceScheduleId` | path | `number` | yes | The Bokun price schedule ID. |
