# Get Customer with Bokun

Retrieves a customer by ID from Bokun.

## Endpoint

- **Method:** `GET`
- **Path:** `/restapi/v2.0/customer/:customerId`
- **Base URL:** `https://api.bokun.io`
- **Official documentation:** [Get Customer](https://api-docs.bokun.dev/rest-v2.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `number` | yes | The Bokun customer ID. |
