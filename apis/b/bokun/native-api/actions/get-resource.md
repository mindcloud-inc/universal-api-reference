# Get Resource with Bokun

Retrieves a resource by ID from Bokun.

## Endpoint

- **Method:** `GET`
- **Path:** `/restapi/v2.0/resource/:resourceId`
- **Base URL:** `https://api.bokun.io`
- **Official documentation:** [Get Resource](https://api-docs.bokun.dev/rest-v2.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resourceId` | path | `number` | yes | The Bokun resource ID. |
