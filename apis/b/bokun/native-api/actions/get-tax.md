# Get Tax with Bokun

Retrieves a tax by ID from Bokun.

## Endpoint

- **Method:** `GET`
- **Path:** `/restapi/v2.0/tax/:taxId`
- **Base URL:** `https://api.bokun.io`
- **Official documentation:** [Get Tax](https://api-docs.bokun.dev/rest-v2.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taxId` | path | `number` | yes | The Bokun tax ID. |
