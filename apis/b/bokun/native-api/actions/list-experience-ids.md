# List Experience IDs with Bokun

Retrieves owned experience product IDs from Bokun.

## Endpoint

- **Method:** `GET`
- **Path:** `/restapi/v2.0/experiences/ids`
- **Base URL:** `https://api.bokun.io`
- **Official documentation:** [List Experience IDs](https://api-docs.bokun.dev/rest-v2.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activated` | query | `boolean` | no | Optional flag to filter activated experience IDs only. |
