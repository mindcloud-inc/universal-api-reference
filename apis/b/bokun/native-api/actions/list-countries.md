# List Countries with Bokun

Retrieves supported country records from Bokun.

## Endpoint

- **Method:** `GET`
- **Path:** `/restapi/v2.0/countries`
- **Base URL:** `https://api.bokun.io`
- **Official documentation:** [List Countries](https://api-docs.bokun.dev/rest-v2.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `languageTag` | query | `string` | no | Optional IETF BCP 47 language tag, for example de-DE. |
