# Get Resource Pool with Bokun

Retrieves a resource pool by ID from Bokun.

## Endpoint

- **Method:** `GET`
- **Path:** `/restapi/v2.0/resource/pool/:resourcePoolId`
- **Base URL:** `https://api.bokun.io`
- **Official documentation:** [Get Resource Pool](https://api-docs.bokun.dev/rest-v2.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resourcePoolId` | path | `number` | yes | The Bokun resource pool ID. |
