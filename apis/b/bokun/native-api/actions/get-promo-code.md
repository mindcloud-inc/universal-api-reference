# Get Promo Code with Bokun

Retrieves a promo code by ID from Bokun.

## Endpoint

- **Method:** `GET`
- **Path:** `/restapi/v2.0/promo/code/:promoCodeId`
- **Base URL:** `https://api.bokun.io`
- **Official documentation:** [Get Promo Code](https://api-docs.bokun.dev/rest-v2.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `promoCodeId` | path | `number` | yes | The Bokun promo code ID. |
