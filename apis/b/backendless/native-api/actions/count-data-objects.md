# Count Data Objects with Backendless

Retrieves a data object count from Backendless.

## Endpoint

- **Method:** `GET`
- **Path:** `/{applicationId}/{apiKey}/data/{tableName}/count`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Count Data Objects](https://backendless.com/docs/rest/data_get_object_count.html)
