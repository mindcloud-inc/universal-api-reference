# Decrement Counter with Backendless

Decrements a counter in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/counters/{counterName}/decrement/get`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Decrement Counter](https://backendless.com/docs/rest/ut_decrement_by_1__return_current.html)
