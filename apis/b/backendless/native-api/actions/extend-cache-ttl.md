# Extend Cache TTL with Backendless

Extends a cache value TTL in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/cache/{key}/expireIn`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Extend Cache TTL](https://backendless.com/docs/rest/ut_extending_objects_life_in_cach.html)
