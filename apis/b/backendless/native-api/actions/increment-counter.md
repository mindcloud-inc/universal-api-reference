# Increment Counter with Backendless

Increments a counter in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/counters/{counterName}/increment/get`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Increment Counter](https://backendless.com/docs/rest/ut_increment_by_1__return_current.html)
