# Get First Data Object with Backendless

Retrieves the first data object from Backendless.

## Endpoint

- **Method:** `GET`
- **Path:** `/{applicationId}/{apiKey}/data/{tableName}/first`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Get First Data Object](https://backendless.com/docs/rest/data_basic_search.html)
