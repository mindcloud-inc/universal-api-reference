# Login User with Backendless

Logs a user into Backendless.

## Endpoint

- **Method:** `POST`
- **Path:** `/{applicationId}/{apiKey}/users/login`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Login User](https://backendless.com/docs/rest/users_login.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
