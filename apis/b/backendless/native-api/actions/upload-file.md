# Upload File with Backendless

Uploads a file to Backendless.

## Endpoint

- **Method:** `POST`
- **Path:** `/{applicationId}/{apiKey}/files/{path}/{fileName}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Upload File](https://backendless.com/docs/rest/files_file_upload.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `multipart/form-data` |
