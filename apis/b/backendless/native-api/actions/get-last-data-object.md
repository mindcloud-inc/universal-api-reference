# Get Last Data Object with Backendless

Retrieves the last data object from Backendless.

## Endpoint

- **Method:** `GET`
- **Path:** `/{applicationId}/{apiKey}/data/{tableName}/last`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Get Last Data Object](https://backendless.com/docs/rest/data_basic_search.html)
