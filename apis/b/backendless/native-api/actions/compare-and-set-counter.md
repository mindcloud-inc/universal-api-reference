# Compare And Set Counter with Backendless

Updates a counter conditionally in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/counters/{counterName}/get/compareandset`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Compare And Set Counter](https://backendless.com/docs/rest/ut_conditional_update.html)
