# Register User with Backendless

Registers a new user in Backendless.

## Endpoint

- **Method:** `POST`
- **Path:** `/{applicationId}/{apiKey}/users/register`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Register User](https://backendless.com/docs/rest/users_user_registration.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
