# Count Directory Items with Backendless

Retrieves the item count for a Backendless directory.

## Endpoint

- **Method:** `GET`
- **Path:** `/{applicationId}/{apiKey}/files/{path}/`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Count Directory Items](https://backendless.com/docs/rest/file_get_file_count.html)
