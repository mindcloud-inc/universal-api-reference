# Get Cache Value with Backendless

Retrieves a cache value from Backendless.

## Endpoint

- **Method:** `GET`
- **Path:** `/{applicationId}/{apiKey}/cache/{key}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Get Cache Value](https://backendless.com/docs/rest/ut_retrieving_data_from_cache.html)
