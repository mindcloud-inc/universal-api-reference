# Restore User Password with Backendless

Starts password recovery for a Backendless user.

## Endpoint

- **Method:** `GET`
- **Path:** `/{applicationId}/{apiKey}/users/restorepassword/{identity}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Restore User Password](https://backendless.com/docs/rest/users_password_recovery.html)
