# Move File Or Folder with Backendless

Moves a file or folder in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/files/move`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Move File Or Folder](https://backendless.com/docs/rest/file_renaming_a_file_director2.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
