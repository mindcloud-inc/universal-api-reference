# Rename File Or Folder with Backendless

Renames a file or folder in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/files/rename`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Rename File Or Folder](https://backendless.com/docs/rest/file_renaming_a_file_directory.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
