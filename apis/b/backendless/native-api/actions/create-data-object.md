# Create Data Object with Backendless

Creates a new data object in Backendless.

## Endpoint

- **Method:** `POST`
- **Path:** `/{applicationId}/{apiKey}/data/{tableName}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Create Data Object](https://backendless.com/docs/rest/data_single_object_save.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
