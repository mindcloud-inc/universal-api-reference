# Copy File Or Folder with Backendless

Copies a file or folder in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/files/copy`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Copy File Or Folder](https://backendless.com/docs/rest/file_file_copy.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
