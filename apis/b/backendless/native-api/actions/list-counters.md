# List Counters with Backendless

Retrieves counters from Backendless by name pattern.

## Endpoint

- **Method:** `GET`
- **Path:** `/{applicationId}/{apiKey}/counters/{counterNamePattern}/list`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [List Counters](https://backendless.com/docs/rest/ut_get_counters_listing.html)
