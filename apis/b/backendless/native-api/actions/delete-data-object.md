# Delete Data Object with Backendless

Deletes an existing data object from Backendless.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/{applicationId}/{apiKey}/data/{tableName}/{objectId}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Delete Data Object](https://backendless.com/docs/rest/data_single_object_deletion.html)
