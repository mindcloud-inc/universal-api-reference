# Upsert Data Object with Backendless

Creates or updates a data object in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/data/{tableName}/upsert`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Upsert Data Object](https://backendless.com/docs/rest/data_upsert_single_object.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
