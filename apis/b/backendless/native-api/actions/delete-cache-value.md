# Delete Cache Value with Backendless

Deletes an existing cache value from Backendless.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/{applicationId}/{apiKey}/cache/{key}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Delete Cache Value](https://backendless.com/docs/rest/ut_deleting_object_from_cache.html)
