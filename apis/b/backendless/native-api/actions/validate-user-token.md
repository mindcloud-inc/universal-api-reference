# Validate User Token with Backendless

Validates a user token in Backendless.

## Endpoint

- **Method:** `GET`
- **Path:** `/{applicationId}/{apiKey}/users/isvalidusertoken/{userToken}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Validate User Token](https://backendless.com/docs/rest/users_validating_user_login.html)
