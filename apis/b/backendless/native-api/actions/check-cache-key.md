# Check Cache Key with Backendless

Checks whether a cache key exists in Backendless.

## Endpoint

- **Method:** `GET`
- **Path:** `/{applicationId}/{apiKey}/cache/{key}/check`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Check Cache Key](https://backendless.com/docs/rest/ut_checking_if_key_exists_in_cach.html)
