# Bulk Delete Data Objects with Backendless

Deletes multiple data objects from Backendless.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/{applicationId}/{apiKey}/data/bulk/{tableName}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Bulk Delete Data Objects](https://backendless.com/docs/rest/data_multiple_objects_bulk_delete.html)
