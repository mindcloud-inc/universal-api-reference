# Update Data Object with Backendless

Updates an existing data object in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/data/{tableName}/{objectId}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Update Data Object](https://backendless.com/docs/rest/data_single_object_update.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
