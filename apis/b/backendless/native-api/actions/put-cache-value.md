# Put Cache Value with Backendless

Stores a cache value in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/cache/{key}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Put Cache Value](https://backendless.com/docs/rest/ut_putting_data_into_cache.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
