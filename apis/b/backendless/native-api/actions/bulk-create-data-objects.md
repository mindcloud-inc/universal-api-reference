# Bulk Create Data Objects with Backendless

Creates multiple data objects in Backendless.

## Endpoint

- **Method:** `POST`
- **Path:** `/{applicationId}/{apiKey}/data/bulk/{tableName}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Bulk Create Data Objects](https://backendless.com/docs/rest/data_multiple_objects_bulk_create.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
