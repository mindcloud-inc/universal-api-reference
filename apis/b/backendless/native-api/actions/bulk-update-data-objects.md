# Bulk Update Data Objects with Backendless

Updates multiple data objects in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/data/bulk/{tableName}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Bulk Update Data Objects](https://backendless.com/docs/rest/data_multiple_objects_bulk_update.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
