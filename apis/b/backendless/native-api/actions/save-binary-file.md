# Save Binary File with Backendless

Saves a binary file to Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/files/binary/{filePath}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Save Binary File](https://backendless.com/docs/rest/file_save_files_from_byte_arrays.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `text/plain` |
