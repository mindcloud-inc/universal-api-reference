# Append File with Backendless

Appends content to a file in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/files/append/{path}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Append File](https://backendless.com/docs/rest/file_append.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `text/plain` |
