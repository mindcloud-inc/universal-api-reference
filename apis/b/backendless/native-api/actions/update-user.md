# Update User with Backendless

Updates an existing user in Backendless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{applicationId}/{apiKey}/users/{userId}`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Update User](https://backendless.com/docs/rest/users_update_user_properties.html)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
