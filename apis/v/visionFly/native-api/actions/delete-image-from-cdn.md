# Delete Image from CDN with VisionFly

Deletes an image from the VisionFly CDN.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/cdn/:image_id`
- **Base URL:** `https://api.visionfly.ai`
- **Official documentation:** [Delete Image from CDN](https://api.visionfly.ai/docs#/default/delete_single_image_cdn__image_id__delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image_id` | path | `string` | yes | VisionFly image identifier to delete. |
