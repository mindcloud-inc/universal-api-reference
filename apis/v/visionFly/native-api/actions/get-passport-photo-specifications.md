# Get Passport Photo Specifications with VisionFly

Retrieves passport photo specifications from VisionFly.

## Endpoint

- **Method:** `GET`
- **Path:** `/passport-photo/specs`
- **Base URL:** `https://api.visionfly.ai`
- **Official documentation:** [Get Passport Photo Specifications](https://api.visionfly.ai/docs#/default/get_passport_specs_passport_photo_specs_get)
