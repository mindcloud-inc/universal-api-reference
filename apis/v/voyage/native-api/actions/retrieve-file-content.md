# Retrieve File Content with Voyage

Retrieves the contents of a file from Voyage.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/files/:fileId/content`
- **Base URL:** `https://api.voyageai.com`
- **Official documentation:** [Retrieve File Content](https://docs.voyageai.com/reference/retrieve-file-content)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | ID of the file whose content to retrieve. |
