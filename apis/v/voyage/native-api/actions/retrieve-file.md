# Retrieve File with Voyage

Retrieves a file from Voyage.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/files/:fileId`
- **Base URL:** `https://api.voyageai.com`
- **Official documentation:** [Retrieve File](https://docs.voyageai.com/reference/retrieve-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | ID of the file to retrieve. |
