# List Batches with Voyage

Retrieves batches for your Voyage organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/batches`
- **Base URL:** `https://api.voyageai.com`
- **Official documentation:** [List Batches](https://docs.voyageai.com/reference/list-batches)

## Capabilities

This operation supports [pagination](../README.md#pagination).
