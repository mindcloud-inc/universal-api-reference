# Retrieve Batch with Voyage

Retrieves a batch from Voyage.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/batches/:batchId`
- **Base URL:** `https://api.voyageai.com`
- **Official documentation:** [Retrieve Batch](https://docs.voyageai.com/reference/retrieve-batch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batchId` | path | `string` | yes | ID of the batch to retrieve. |
