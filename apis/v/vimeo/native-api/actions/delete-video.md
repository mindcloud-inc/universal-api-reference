# Delete Video with Vimeo

Deletes an existing video from Vimeo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/videos/:video_id`
- **Base URL:** `https://api.vimeo.com`
- **Official documentation:** [Delete Video](https://developer.vimeo.com/api/reference/videos#delete_video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `number` | yes | The ID of the video. |
