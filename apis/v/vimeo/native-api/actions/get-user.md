# Get User with Vimeo

Retrieves a user record from Vimeo.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user_id`
- **Base URL:** `https://api.vimeo.com`
- **Official documentation:** [Get User](https://developer.vimeo.com/api/reference/users#get_user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | The ID of the user. |
