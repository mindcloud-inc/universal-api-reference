# List Permissions with vionvi CRM

Retrieves permissions from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/permission`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Permissions](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
