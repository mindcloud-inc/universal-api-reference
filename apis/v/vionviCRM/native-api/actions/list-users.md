# List Users with vionvi CRM

Retrieves users from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/user`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Users](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
