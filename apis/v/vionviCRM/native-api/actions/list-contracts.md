# List Contracts with vionvi CRM

Retrieves contracts from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/contract`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Contracts](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
