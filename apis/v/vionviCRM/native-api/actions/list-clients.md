# List Clients with vionvi CRM

Retrieves clients from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/client`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Clients](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
