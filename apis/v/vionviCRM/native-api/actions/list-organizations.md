# List Organizations with vionvi CRM

Retrieves organizations from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/org`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Organizations](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
