# List Leads with vionvi CRM

Retrieves leads from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/lead`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Leads](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
