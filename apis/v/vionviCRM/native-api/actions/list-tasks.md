# List Tasks with vionvi CRM

Retrieves tasks from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/task`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Tasks](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
