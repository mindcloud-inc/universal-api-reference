# List Services with vionvi CRM

Retrieves services from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/service`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Services](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
