# List Catalog Items with vionvi CRM

Retrieves catalog items from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Catalog Items](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
