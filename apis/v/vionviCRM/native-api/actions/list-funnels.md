# List Funnels with vionvi CRM

Retrieves funnels from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/funnel`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Funnels](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
