# List Projects with vionvi CRM

Retrieves projects from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/project`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Projects](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
