# List Sources with vionvi CRM

Retrieves sources from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/source`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Sources](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
