# List Chats with vionvi CRM

Retrieves chats from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/chat`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Chats](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
