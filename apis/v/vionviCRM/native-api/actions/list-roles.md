# List Roles with vionvi CRM

Retrieves roles from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/role`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Roles](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
