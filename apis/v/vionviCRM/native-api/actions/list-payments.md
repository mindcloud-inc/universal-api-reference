# List Payments with vionvi CRM

Retrieves payments from vionvi CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/pay`
- **Base URL:** `https://280-crm-api.vionvi.com`
- **Official documentation:** [List Payments](https://280-crm-api.vionvi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
