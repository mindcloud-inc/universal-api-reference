# Get More Statements with Veracity Learning

Retrieves more statements from Veracity Learning.

## Endpoint

- **Method:** `GET`
- **Path:** `/statements/more`
- **Base URL:** `https://sample-lrs-rafehwe.lrs.io/xapi`
- **Official documentation:** [Get More Statements](https://xapi.ieee-saopen.org/standard/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Opaque continuation id returned by the statements resource |
