# Get Agent with Veracity Learning

Retrieves a Person Object for an agent from Veracity Learning.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents`
- **Base URL:** `https://sample-lrs-rafehwe.lrs.io/xapi`
- **Official documentation:** [Get Agent](https://xapi.ieee-saopen.org/standard/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent` | query | `object` | yes | Agent object used to fetch the expanded person record |
