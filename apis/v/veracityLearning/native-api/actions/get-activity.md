# Get Activity with Veracity Learning

Retrieves an activity from Veracity Learning.

## Endpoint

- **Method:** `GET`
- **Path:** `/activities`
- **Base URL:** `https://sample-lrs-rafehwe.lrs.io/xapi`
- **Official documentation:** [Get Activity](https://xapi.ieee-saopen.org/standard/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activityId` | query | `string` | yes | Activity id to load |
