# Create Project with v0

Creates a new project in v0.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/projects`
- **Base URL:** `https://api.v0.dev`
- **Official documentation:** [Create Project](https://v0.app/docs/api/platform/reference/projects/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the project to create. |
