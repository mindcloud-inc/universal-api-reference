# Get Billing with v0

Retrieves billing details for the current user in v0.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/user/billing`
- **Base URL:** `https://api.v0.dev`
- **Official documentation:** [Get Billing](https://v0.app/docs/api/platform/reference/user/get-billing)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scope` | query | `string` | no | Optionally scope billing data to a project ID or slug. |
