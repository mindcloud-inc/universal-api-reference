# Get Project by ID with v0

Retrieves a project from v0 by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:projectId`
- **Base URL:** `https://api.v0.dev`
- **Official documentation:** [Get Project by ID](https://v0.app/docs/api/platform/reference/projects/get-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The ID of the project to retrieve. |
