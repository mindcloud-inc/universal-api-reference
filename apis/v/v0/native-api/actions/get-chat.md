# Get Chat with v0

Retrieves a chat from v0 by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/chats/:chatId`
- **Base URL:** `https://api.v0.dev`
- **Official documentation:** [Get Chat](https://v0.app/docs/api/platform/reference/chats/get-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chatId` | path | `string` | yes | The ID of the chat to retrieve. |
