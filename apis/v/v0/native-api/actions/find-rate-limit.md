# Find Rate Limit with v0

Retrieves rate limit details from v0.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/rate-limits`
- **Base URL:** `https://api.v0.dev`
- **Official documentation:** [Find Rate Limit](https://v0.app/docs/api/platform/reference/rate-limits/find)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scope` | query | `string` | no | The scope to inspect for rate limit information. |
