# Get GIF Status Code Image with Vadivelu HTTP codes

## Endpoint

- **Method:** `GET`
- **Path:** `/gif/:statusCode`
- **Base URL:** `https://vadivelu.anoram.com`
- **Official documentation:** [Get GIF Status Code Image](https://vadivelu.anoram.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `statusCode` | path | `list` | yes | One status code with a first-party-documented GIF asset. Accepted values: `0`, `1`, `10`, `11`, `12`, `2`, `3`, `4`, `5`, `6`, `7`, `8`, `9`. |
