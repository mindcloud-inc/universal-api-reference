# List My Sites with Voog

Retrieves all available sites from your Voog account.

## Endpoint

- **Method:** `GET`
- **Path:** `/me/sites`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [List My Sites](https://www.voog.com/developers/api/resources/me/sites)

## Capabilities

This operation supports [pagination](../README.md#pagination).
