# Duplicate Page with Voog

Duplicates a page with its content in Voog.

## Endpoint

- **Method:** `POST`
- **Path:** `/pages/:pageId/duplicate`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [Duplicate Page](https://www.voog.com/developers/api/resources/pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageId` | path | `number` | yes | Numeric page ID. |
