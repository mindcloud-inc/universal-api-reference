# List Products with Voog

Retrieves products for the current Voog store.

## Endpoint

- **Method:** `GET`
- **Path:** `/ecommerce/v1/products`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [List Products](https://www.voog.com/developers/api/ecommerce/products)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
