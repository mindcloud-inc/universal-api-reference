# List Articles with Voog

Retrieves articles for the current Voog site.

## Endpoint

- **Method:** `GET`
- **Path:** `/articles`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [List Articles](https://www.voog.com/developers/api/resources/articles)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
