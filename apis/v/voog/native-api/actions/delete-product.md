# Delete Product with Voog

Deletes an existing product from the current Voog store.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ecommerce/v1/products/:productId`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [Delete Product](https://www.voog.com/developers/api/ecommerce/products)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `number` | yes | Numeric product ID. |
