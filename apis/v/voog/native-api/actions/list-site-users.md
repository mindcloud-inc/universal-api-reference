# List Site Users with Voog

Retrieves site users for the current Voog site.

## Endpoint

- **Method:** `GET`
- **Path:** `/site_users`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [List Site Users](https://www.voog.com/developers/api/resources/site_users)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
