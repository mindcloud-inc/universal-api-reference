# List Orders with Voog

Retrieves orders for the current Voog store.

## Endpoint

- **Method:** `GET`
- **Path:** `/ecommerce/v1/orders`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [List Orders](https://www.voog.com/developers/api/ecommerce/orders)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
