# Delete Site User with Voog

Deletes an existing site user from the current Voog site.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/site_users/:siteUserId`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [Delete Site User](https://www.voog.com/developers/api/resources/site_users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteUserId` | path | `number` | yes | Numeric site user ID. |
