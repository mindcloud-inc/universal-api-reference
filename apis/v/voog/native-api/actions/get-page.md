# Get Page with Voog

Retrieves a page from the current Voog site.

## Endpoint

- **Method:** `GET`
- **Path:** `/pages/:pageId`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [Get Page](https://www.voog.com/developers/api/resources/pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageId` | path | `number` | yes | Numeric page ID. |
