# List Categories with Voog

Retrieves categories for the current Voog store.

## Endpoint

- **Method:** `GET`
- **Path:** `/ecommerce/v1/categories`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [List Categories](https://www.voog.com/developers/api/ecommerce/categories)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
