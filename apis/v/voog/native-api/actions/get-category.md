# Get Category with Voog

Retrieves a category from the current Voog store.

## Endpoint

- **Method:** `GET`
- **Path:** `/ecommerce/v1/categories/:categoryId`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [Get Category](https://www.voog.com/developers/api/ecommerce/categories)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `categoryId` | path | `number` | yes | Numeric category ID. |
