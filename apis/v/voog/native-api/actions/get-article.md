# Get Article with Voog

Retrieves an article from the current Voog site.

## Endpoint

- **Method:** `GET`
- **Path:** `/articles/:articleId`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [Get Article](https://www.voog.com/developers/api/resources/articles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `articleId` | path | `number` | yes | Numeric article ID. |
