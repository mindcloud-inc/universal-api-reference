# List Webhooks with Voog

Retrieves webhooks for the current Voog site.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [List Webhooks](https://www.voog.com/developers/api/resources/webhooks)

## Capabilities

This operation supports [filtering](../README.md#filtering).
