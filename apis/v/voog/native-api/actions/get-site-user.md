# Get Site User with Voog

Retrieves a site user from the current Voog site.

## Endpoint

- **Method:** `GET`
- **Path:** `/site_users/:siteUserId`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [Get Site User](https://www.voog.com/developers/api/resources/site_users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteUserId` | path | `number` | yes | Numeric site user ID. |
