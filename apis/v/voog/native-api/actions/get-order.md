# Get Order with Voog

Retrieves an order from the current Voog store.

## Endpoint

- **Method:** `GET`
- **Path:** `/ecommerce/v1/orders/:orderId`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [Get Order](https://www.voog.com/developers/api/ecommerce/orders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderId` | path | `number` | yes | Numeric order ID. |
