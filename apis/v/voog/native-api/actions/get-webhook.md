# Get Webhook with Voog

Retrieves a webhook from the current Voog site.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [Get Webhook](https://www.voog.com/developers/api/resources/webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `number` | yes | Numeric webhook ID. |
