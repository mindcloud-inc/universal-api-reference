# List Assets with Voog

Retrieves assets for the current Voog site.

## Endpoint

- **Method:** `GET`
- **Path:** `/assets`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [List Assets](https://www.voog.com/developers/api/resources/assets)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
