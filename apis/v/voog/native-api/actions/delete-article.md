# Delete Article with Voog

Deletes an existing article from the current Voog site.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/articles/:articleId`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [Delete Article](https://www.voog.com/developers/api/resources/articles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `articleId` | path | `number` | yes | Numeric article ID. |
