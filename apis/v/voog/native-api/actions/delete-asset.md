# Delete Asset with Voog

Deletes an existing asset from the current Voog site.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/assets/:assetId`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [Delete Asset](https://www.voog.com/developers/api/resources/assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assetId` | path | `number` | yes | Numeric asset ID. |
