# List Pages with Voog

Retrieves pages for the current Voog site.

## Endpoint

- **Method:** `GET`
- **Path:** `/pages`
- **Base URL:** `{siteUrl}/admin/api`
- **Official documentation:** [List Pages](https://www.voog.com/developers/api/resources/pages)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
