# List Contact Methods with Verifalia

Retrieves contact methods from Verifalia.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{user-id}/contact-methods`
- **Base URL:** `https://api-1.verifalia.com/v2.7`
- **Official documentation:** [List Contact Methods](https://verifalia.com/developers/users/contact-methods)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user-id` | path | `string` | yes | The Verifalia user ID. |
