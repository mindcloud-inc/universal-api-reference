# Get Validation Job Overview with Verifalia

Retrieves an email validation job overview from Verifalia.

## Endpoint

- **Method:** `GET`
- **Path:** `/email-validations/{id}/overview`
- **Base URL:** `https://api-1.verifalia.com/v2.7`
- **Official documentation:** [Get Validation Job Overview](https://verifalia.com/developers/email-verifications/retrieving-jobs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Verifalia validation job ID. |
