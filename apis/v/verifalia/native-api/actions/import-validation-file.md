# Import Validation File with Verifalia

Creates a new email validation job from a file in Verifalia.

## Endpoint

- **Method:** `POST`
- **Path:** `/email-validations`
- **Base URL:** `https://api-1.verifalia.com/v2.7`
- **Official documentation:** [Import Validation File](https://verifalia.com/developers/email-verifications/creating-jobs)
