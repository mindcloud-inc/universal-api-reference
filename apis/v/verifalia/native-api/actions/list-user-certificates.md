# List User Certificates with Verifalia

Retrieves user certificates from Verifalia.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{user-id}/certificates`
- **Base URL:** `https://api-1.verifalia.com/v2.7`
- **Official documentation:** [List User Certificates](https://verifalia.com/developers/users/client-certificates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user-id` | path | `string` | yes | The Verifalia user ID. |
