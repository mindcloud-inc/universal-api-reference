# Delete User with Verifalia

Deletes an existing user from Verifalia.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/{user-id}`
- **Base URL:** `https://api-1.verifalia.com/v2.7`
- **Official documentation:** [Delete User](https://verifalia.com/developers/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user-id` | path | `string` | yes | The Verifalia user ID. |
