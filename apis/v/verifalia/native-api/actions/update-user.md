# Update User with Verifalia

Updates an existing user in Verifalia.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/users/{user-id}`
- **Base URL:** `https://api-1.verifalia.com/v2.7`
- **Official documentation:** [Update User](https://verifalia.com/developers/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user-id` | path | `string` | yes | The Verifalia user ID. |
