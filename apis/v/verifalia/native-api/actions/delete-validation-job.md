# Delete Validation Job with Verifalia

Deletes an email validation job from Verifalia.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/email-validations/{id}`
- **Base URL:** `https://api-1.verifalia.com/v2.7`
- **Official documentation:** [Delete Validation Job](https://verifalia.com/developers/email-verifications/deleting-jobs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Verifalia validation job ID. |
