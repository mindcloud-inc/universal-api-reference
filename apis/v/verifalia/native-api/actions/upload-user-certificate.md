# Upload User Certificate with Verifalia

Uploads a user certificate to Verifalia.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/{user-id}/certificates`
- **Base URL:** `https://api-1.verifalia.com/v2.7`
- **Official documentation:** [Upload User Certificate](https://verifalia.com/developers/users/client-certificates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user-id` | path | `string` | yes | The Verifalia user ID. |
