# List Models with Vercel AI Gateway Chat Model

Retrieves available models from Vercel AI Gateway.

## Endpoint

- **Method:** `GET`
- **Path:** `/models`
- **Base URL:** `https://ai-gateway.vercel.sh/v1`
- **Official documentation:** [List Models](https://vercel.com/docs/ai-gateway/sdks-and-apis/openai-compat/rest-api)
