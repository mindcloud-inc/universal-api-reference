# List Quotes with Vtiger CRM

Finds quotes in Vtiger CRM by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/query?query=select+id%2C+subject+from+Quotes+limit+0%2C+25%3B`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Quotes](https://vtap.vtiger.com/platform/rest-apis.html#query)
