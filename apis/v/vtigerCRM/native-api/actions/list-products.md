# List Products with Vtiger CRM

Finds products in Vtiger CRM by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/query?query=select+id%2C+productname+from+Products+limit+0%2C+25%3B`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Products](https://vtap.vtiger.com/platform/rest-apis.html#query)
