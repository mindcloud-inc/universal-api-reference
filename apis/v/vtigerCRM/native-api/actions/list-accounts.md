# List Accounts with Vtiger CRM

Finds accounts in Vtiger CRM by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/query?query=select+id%2C+accountname+from+Accounts+limit+0%2C+25%3B`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Accounts](https://vtap.vtiger.com/platform/rest-apis.html#query)
