# List Deals with Vtiger CRM

Finds deals in Vtiger CRM by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/query?query=select+id%2C+potentialname+from+Potentials+limit+0%2C+25%3B`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Deals](https://vtap.vtiger.com/platform/rest-apis.html#query)
