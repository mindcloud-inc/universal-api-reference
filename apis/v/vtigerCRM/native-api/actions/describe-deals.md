# Describe Deals with Vtiger CRM

Retrieves deal metadata from Vtiger CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/describe?elementType=Potentials`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Describe Deals](https://vtap.vtiger.com/platform/rest-apis.html#describe---module-metadata)
