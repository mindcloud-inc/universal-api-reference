# Describe Invoices with Vtiger CRM

Retrieves invoice metadata from Vtiger CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/describe?elementType=Invoice`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Describe Invoices](https://vtap.vtiger.com/platform/rest-apis.html#describe---module-metadata)
