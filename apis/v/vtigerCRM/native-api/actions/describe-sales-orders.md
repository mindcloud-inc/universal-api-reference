# Describe Sales Orders with Vtiger CRM

Retrieves sales order metadata from Vtiger CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/describe?elementType=SalesOrder`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Describe Sales Orders](https://vtap.vtiger.com/platform/rest-apis.html#describe---module-metadata)
