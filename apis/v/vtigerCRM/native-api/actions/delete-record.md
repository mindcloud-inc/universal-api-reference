# Delete Record with Vtiger CRM

Deletes an existing record from Vtiger CRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Delete Record](https://vtap.vtiger.com/platform/rest-apis.html#delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Vtiger record id to delete. |
