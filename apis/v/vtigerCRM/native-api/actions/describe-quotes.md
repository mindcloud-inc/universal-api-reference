# Describe Quotes with Vtiger CRM

Retrieves quote metadata from Vtiger CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/describe?elementType=Quotes`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Describe Quotes](https://vtap.vtiger.com/platform/rest-apis.html#describe---module-metadata)
