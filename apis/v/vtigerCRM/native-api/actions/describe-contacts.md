# Describe Contacts with Vtiger CRM

Retrieves contact metadata from Vtiger CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/describe?elementType=Contacts`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Describe Contacts](https://vtap.vtiger.com/platform/rest-apis.html#describe---module-metadata)
