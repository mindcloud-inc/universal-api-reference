# List Invoices with Vtiger CRM

Finds invoices in Vtiger CRM by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/query?query=select+id%2C+subject+from+Invoice+limit+0%2C+25%3B`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Invoices](https://vtap.vtiger.com/platform/rest-apis.html#query)
