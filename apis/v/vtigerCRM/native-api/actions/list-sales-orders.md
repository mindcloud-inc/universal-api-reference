# List Sales Orders with Vtiger CRM

Finds sales orders in Vtiger CRM by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/query?query=select+id%2C+subject+from+SalesOrder+limit+0%2C+25%3B`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Sales Orders](https://vtap.vtiger.com/platform/rest-apis.html#query)
