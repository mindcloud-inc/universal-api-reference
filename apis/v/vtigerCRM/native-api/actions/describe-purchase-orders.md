# Describe Purchase Orders with Vtiger CRM

Retrieves purchase order metadata from Vtiger CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/describe?elementType=PurchaseOrder`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Describe Purchase Orders](https://vtap.vtiger.com/platform/rest-apis.html#describe---module-metadata)
