# Describe Accounts with Vtiger CRM

Retrieves account metadata from Vtiger CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/describe?elementType=Accounts`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Describe Accounts](https://vtap.vtiger.com/platform/rest-apis.html#describe---module-metadata)
