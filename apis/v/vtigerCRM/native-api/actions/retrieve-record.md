# Retrieve Record with Vtiger CRM

Retrieves a record from Vtiger CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/retrieve`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Retrieve Record](https://vtap.vtiger.com/platform/rest-apis.html#retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Vtiger record id such as 4x489. |
