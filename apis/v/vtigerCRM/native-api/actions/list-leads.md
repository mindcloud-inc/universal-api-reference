# List Leads with Vtiger CRM

Finds leads in Vtiger CRM by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/query?query=select+id%2C+firstname%2C+lastname+from+Leads+limit+0%2C+25%3B`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Leads](https://vtap.vtiger.com/platform/rest-apis.html#query)
