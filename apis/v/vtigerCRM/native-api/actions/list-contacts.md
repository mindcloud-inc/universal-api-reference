# List Contacts with Vtiger CRM

Finds contacts in Vtiger CRM by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/query?query=select+id%2C+firstname%2C+lastname+from+Contacts+limit+0%2C+25%3B`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Contacts](https://vtap.vtiger.com/platform/rest-apis.html#query)
