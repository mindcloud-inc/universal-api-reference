# Describe Leads with Vtiger CRM

Retrieves lead metadata from Vtiger CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/describe?elementType=Leads`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Describe Leads](https://vtap.vtiger.com/platform/rest-apis.html#describe---module-metadata)
