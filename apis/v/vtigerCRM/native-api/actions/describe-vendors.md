# Describe Vendors with Vtiger CRM

Retrieves vendor metadata from Vtiger CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/describe?elementType=Vendors`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Describe Vendors](https://vtap.vtiger.com/platform/rest-apis.html#describe---module-metadata)
