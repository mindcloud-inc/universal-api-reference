# List Vendors with Vtiger CRM

Finds vendors in Vtiger CRM by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/query?query=select+id%2C+vendorname+from+Vendors+limit+0%2C+25%3B`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Vendors](https://vtap.vtiger.com/platform/rest-apis.html#query)
