# List Storyboards with Vocal Video

Retrieves storyboard samples from Vocal Video.

## Endpoint

- **Method:** `GET`
- **Path:** `/storyboards`
- **Base URL:** `https://vocalvideo.com/api/v1`
- **Official documentation:** [List Storyboards](https://help.vocalvideo.com/article/23-using-the-subscription-api)
