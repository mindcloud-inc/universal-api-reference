# Generate Voucher Code with Vouchery.io

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/:campaign_id/generate-voucher-code`
- **Base URL:** `https://mindcloud.sandbox.vouchery.app/api/v2.1`
- **Official documentation:** [Generate Voucher Code](https://docs.vouchery.io/reference/postapiv21campaignscampaignidgeneratevouchercode)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `number` | yes | Campaign ID from the path. |
