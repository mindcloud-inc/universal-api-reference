# Cancel Redemption By Redemption ID with Vouchery.io

## Endpoint

- **Method:** `DELETE`
- **Path:** `/redemptions/:redemption_id`
- **Base URL:** `https://mindcloud.sandbox.vouchery.app/api/v2.1`
- **Official documentation:** [Cancel Redemption By Redemption ID](https://docs.vouchery.io/reference/deleteapiv21redemptionsredemptionid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `redemption_id` | path | `number` | yes | Redemption ID |
