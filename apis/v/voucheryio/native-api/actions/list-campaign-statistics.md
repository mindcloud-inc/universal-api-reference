# List Campaign Statistics with Vouchery.io

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/stats`
- **Base URL:** `https://mindcloud.sandbox.vouchery.app/api/v2.1`
- **Official documentation:** [List Campaign Statistics](https://docs.vouchery.io/reference/getapiv21campaignsstats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `range` | query | `number` | no | Statistics range in days. Default 30, max 90. |
