# Get Voucher Details with Vouchery.io

## Endpoint

- **Method:** `GET`
- **Path:** `/vouchers/:code/extended`
- **Base URL:** `https://mindcloud.sandbox.vouchery.app/api/v2.1`
- **Official documentation:** [Get Voucher Details](https://docs.vouchery.io/reference/getapiv21voucherscodeextended)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Voucher code |
