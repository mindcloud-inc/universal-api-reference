# List Customers with Vouchery.io

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://mindcloud.sandbox.vouchery.app/api/v2.1`
- **Official documentation:** [List Customers](https://docs.vouchery.io/reference/getapiv21customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | query | `string` | no | Customer identifier filter. |
| `email` | query | `string` | no | Customer email filter. |
