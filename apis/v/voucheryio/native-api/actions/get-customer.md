# Get Customer with Vouchery.io

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:identifier`
- **Base URL:** `https://mindcloud.sandbox.vouchery.app/api/v2.1`
- **Official documentation:** [Get Customer](https://docs.vouchery.io/reference/getapiv21customersidentifier)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Customer identifier from the path. |
