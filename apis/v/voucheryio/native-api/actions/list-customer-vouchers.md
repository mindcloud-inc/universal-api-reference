# List Customer Vouchers with Vouchery.io

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:identifier/vouchers`
- **Base URL:** `https://mindcloud.sandbox.vouchery.app/api/v2.1`
- **Official documentation:** [List Customer Vouchers](https://docs.vouchery.io/reference/getapiv21customersidentifiervouchers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Customer Identifier |
