# Get Reward with Vouchery.io

## Endpoint

- **Method:** `GET`
- **Path:** `/rewards/:id`
- **Base URL:** `https://mindcloud.sandbox.vouchery.app/api/v2.1`
- **Official documentation:** [Get Reward](https://docs.vouchery.io/reference/getapiv21rewardsid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Reward ID from Vouchery. |
