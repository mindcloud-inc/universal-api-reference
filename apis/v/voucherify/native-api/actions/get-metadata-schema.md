# Get Metadata Schema with Voucherify

Retrieves a metadata schema from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/metadata-schemas/:relatedObject`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Metadata Schema](https://docs.voucherify.io/api-reference/metadata-schemas)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `relatedObject` | path | `string` | yes |
