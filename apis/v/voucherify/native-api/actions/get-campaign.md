# Get Campaign with Voucherify

Retrieves a campaign from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Campaign](https://docs.voucherify.io/reference/get-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | Voucherify campaign identifier. |
