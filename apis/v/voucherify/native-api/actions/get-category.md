# Get Category with Voucherify

Retrieves a category from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories/:categoryId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Category](https://docs.voucherify.io/reference/get-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `categoryId` | path | `string` | yes | Voucherify category identifier. |
