# Delete Voucher with Voucherify

Deletes an existing voucher from Voucherify.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/vouchers/:voucherId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Delete Voucher](https://docs.voucherify.io/api-reference/vouchers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `voucherId` | path | `string` | yes |
