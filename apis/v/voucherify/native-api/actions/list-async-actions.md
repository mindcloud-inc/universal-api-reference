# List Async Actions with Voucherify

Retrieves a list of async actions from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/async-actions`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [List Async Actions](https://docs.voucherify.io/api-reference/async-actions)
