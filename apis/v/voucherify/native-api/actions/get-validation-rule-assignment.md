# Get Validation Rule Assignment with Voucherify

## Endpoint

- **Method:** `GET`
- **Path:** `/validation-rules-assignments/:assignmentId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Validation Rule Assignment](https://docs.voucherify.io/reference/get-validation-rule-assignment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assignmentId` | path | `string` | yes | Voucherify validation rule assignment identifier. |
