# Get Export with Voucherify

Retrieves an export from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/exports/:exportId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Export](https://docs.voucherify.io/api-reference/exports)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exportId` | path | `string` | yes |
