# List Metadata Schemas with Voucherify

Retrieves a list of metadata schemas from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/metadata-schemas`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [List Metadata Schemas](https://docs.voucherify.io/api-reference/metadata-schemas)
