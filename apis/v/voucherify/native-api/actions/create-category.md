# Create Category with Voucherify

Creates a new category in Voucherify.

## Endpoint

- **Method:** `POST`
- **Path:** `/categories`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Create Category](https://docs.voucherify.io/api-reference/categories)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `hierarchy` | body | `number` | yes |
| `name` | body | `string` | yes |
