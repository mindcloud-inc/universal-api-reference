# List Validation Rules with Voucherify

Retrieves a list of validation rules from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/validation-rules`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [List Validation Rules](https://docs.voucherify.io/api-reference/validation-rules)
