# Get Reward with Voucherify

Retrieves a reward from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/rewards/:rewardId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Reward](https://docs.voucherify.io/api-reference/rewards)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `rewardId` | path | `string` | yes |
