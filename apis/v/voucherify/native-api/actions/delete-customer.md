# Delete Customer with Voucherify

Deletes an existing customer from Voucherify.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customers/:customerId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Delete Customer](https://docs.voucherify.io/reference/delete-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | Voucherify customer identifier. |
