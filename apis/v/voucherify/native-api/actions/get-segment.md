# Get Segment with Voucherify

Retrieves a segment from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/segments/:segmentId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Segment](https://docs.voucherify.io/reference/get-segment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segmentId` | path | `string` | yes | Voucherify segment identifier. |
