# List Validation Rule Assignments with Voucherify

Retrieves validation rule assignments from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/validation-rules-assignments`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [List Validation Rule Assignments](https://docs.voucherify.io/reference/list-validation-rule-assignments)
