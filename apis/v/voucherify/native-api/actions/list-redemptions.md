# List Redemptions with Voucherify

Retrieves a list of redemptions from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/redemptions`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [List Redemptions](https://docs.voucherify.io/reference/list-redemptions)
