# Get Async Action with Voucherify

Retrieves an async action from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/async-actions/:asyncActionId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Async Action](https://docs.voucherify.io/api-reference/async-actions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `asyncActionId` | path | `string` | yes |
