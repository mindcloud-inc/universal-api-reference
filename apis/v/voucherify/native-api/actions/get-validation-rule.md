# Get Validation Rule with Voucherify

Retrieves a validation rule from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/validation-rules/:validationRuleId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Validation Rule](https://docs.voucherify.io/api-reference/validation-rules)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `validationRuleId` | path | `string` | yes |
