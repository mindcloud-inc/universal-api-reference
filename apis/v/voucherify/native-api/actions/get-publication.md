# Get Publication with Voucherify

## Endpoint

- **Method:** `GET`
- **Path:** `/publications/:publicationId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Publication](https://docs.voucherify.io/reference/get-publication)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `publicationId` | path | `string` | yes | Voucherify publication identifier. |
