# Get Product Collection with Voucherify

Retrieves a product collection from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/product-collections/:collectionId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Product Collection](https://docs.voucherify.io/reference/get-product-collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | Voucherify product collection identifier. |
