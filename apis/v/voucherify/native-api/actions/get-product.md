# Get Product with Voucherify

Retrieves a product from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:productId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Product](https://docs.voucherify.io/reference/get-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | yes | Voucherify product identifier. |
