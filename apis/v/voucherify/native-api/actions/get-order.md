# Get Order with Voucherify

Retrieves an order from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:orderId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Order](https://docs.voucherify.io/reference/get-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderId` | path | `string` | yes | Voucherify order identifier. |
