# List Voucher Redemptions with Voucherify

Retrieves a voucher's redemptions from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/vouchers/:voucherId/redemptions`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [List Voucher Redemptions](https://docs.voucherify.io/api-reference/vouchers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `voucherId` | path | `string` | yes |
