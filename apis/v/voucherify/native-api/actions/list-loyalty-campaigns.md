# List Loyalty Campaigns with Voucherify

Retrieves a list of loyalty campaigns from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/loyalties`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [List Loyalty Campaigns](https://docs.voucherify.io/reference/list-loyalties)
