# Get Redemption with Voucherify

Retrieves a redemption from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/redemptions/:redemptionId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Get Redemption](https://docs.voucherify.io/reference/get-redemption)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `redemptionId` | path | `string` | yes | Voucherify redemption identifier. |
