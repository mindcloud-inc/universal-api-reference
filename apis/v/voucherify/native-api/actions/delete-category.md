# Delete Category with Voucherify

Deletes an existing category from Voucherify.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/categories/:categoryId`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [Delete Category](https://docs.voucherify.io/api-reference/categories)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `categoryId` | path | `string` | yes |
