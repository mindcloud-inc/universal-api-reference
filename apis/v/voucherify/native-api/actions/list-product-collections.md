# List Product Collections with Voucherify

Retrieves a list of product collections from Voucherify.

## Endpoint

- **Method:** `GET`
- **Path:** `/product-collections`
- **Base URL:** `https://us1.api.voucherify.io/v1`
- **Official documentation:** [List Product Collections](https://docs.voucherify.io/reference/list-product-collections)
