# Verify Resume Red Flags with Verify (Tailr Made)

Analyzes resume text for red flags in Verify.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/verify`
- **Base URL:** `https://api.tailrmadeai.com`
- **Official documentation:** [Verify Resume Red Flags](https://tailrmadeai.com/verify-api-guide/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resumeText` | body | `string` | yes | Text to analyze for red flags and fraud signals. |
