# Get Assistant with Vapi

Retrieves an assistant from Vapi by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/assistant/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Get Assistant](https://docs.vapi.ai/api-reference/assistants/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
