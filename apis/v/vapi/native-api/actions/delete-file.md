# Delete File with Vapi

Deletes an existing file from Vapi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/file/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Delete File](https://docs.vapi.ai/api-reference/files/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
