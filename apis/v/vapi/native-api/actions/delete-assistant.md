# Delete Assistant with Vapi

Deletes an existing assistant from Vapi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/assistant/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Delete Assistant](https://docs.vapi.ai/api-reference/assistants/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
