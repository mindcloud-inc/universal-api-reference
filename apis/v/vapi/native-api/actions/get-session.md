# Get Session with Vapi

Retrieves a session from Vapi by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/session/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Get Session](https://docs.vapi.ai/api-reference/sessions/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
