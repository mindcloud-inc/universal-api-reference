# Get Call with Vapi

Retrieves a call from Vapi by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/call/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Get Call](https://docs.vapi.ai/api-reference/calls/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
