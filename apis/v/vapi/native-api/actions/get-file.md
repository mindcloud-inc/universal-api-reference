# Get File with Vapi

Retrieves a file from Vapi by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/file/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Get File](https://docs.vapi.ai/api-reference/files/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
