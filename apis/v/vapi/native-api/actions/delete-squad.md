# Delete Squad with Vapi

Deletes an existing squad from Vapi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/squad/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Delete Squad](https://docs.vapi.ai/api-reference/squads/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
