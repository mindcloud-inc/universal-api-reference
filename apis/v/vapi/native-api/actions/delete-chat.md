# Delete Chat with Vapi

Deletes an existing chat from Vapi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/chat/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Delete Chat](https://docs.vapi.ai/api-reference/chats/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
