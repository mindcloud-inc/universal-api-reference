# Delete Tool with Vapi

Deletes an existing tool from Vapi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tool/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Delete Tool](https://docs.vapi.ai/api-reference/tools/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
