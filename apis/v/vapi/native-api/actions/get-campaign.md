# Get Campaign with Vapi

Retrieves a campaign from Vapi by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Get Campaign](https://docs.vapi.ai/api-reference/campaigns/campaign-controller-find-one)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
