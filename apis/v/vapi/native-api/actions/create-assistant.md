# Create Assistant with Vapi

Creates a new assistant in Vapi.

## Endpoint

- **Method:** `POST`
- **Path:** `/assistant`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Create Assistant](https://docs.vapi.ai/api-reference/assistants/create)
