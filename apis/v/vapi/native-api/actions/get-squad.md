# Get Squad with Vapi

Retrieves a squad from Vapi by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/squad/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Get Squad](https://docs.vapi.ai/api-reference/squads/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
