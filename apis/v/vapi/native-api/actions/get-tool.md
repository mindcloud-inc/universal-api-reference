# Get Tool with Vapi

Retrieves a tool from Vapi by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tool/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Get Tool](https://docs.vapi.ai/api-reference/tools/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
