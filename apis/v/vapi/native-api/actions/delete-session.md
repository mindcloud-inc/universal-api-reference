# Delete Session with Vapi

Deletes an existing session from Vapi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/session/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Delete Session](https://docs.vapi.ai/api-reference/sessions/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
