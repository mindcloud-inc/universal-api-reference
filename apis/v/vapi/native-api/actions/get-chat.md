# Get Chat with Vapi

Retrieves a chat from Vapi by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/chat/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Get Chat](https://docs.vapi.ai/api-reference/chats/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
