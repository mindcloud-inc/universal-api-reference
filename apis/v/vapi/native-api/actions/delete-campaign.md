# Delete Campaign with Vapi

Deletes an existing campaign from Vapi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/campaign/:id`
- **Base URL:** `https://api.vapi.ai`
- **Official documentation:** [Delete Campaign](https://docs.vapi.ai/api-reference/campaigns/campaign-controller-remove)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
