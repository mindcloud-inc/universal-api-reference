# Get Phone MNP Credits with Verificaremails

Retrieves available phone MNP credits from Verificaremails.

## Endpoint

- **Method:** `GET`
- **Path:** `/phonemnp/credits`
- **Base URL:** `https://dashboard.verificaremails.com/myapi`
- **Official documentation:** [Get Phone MNP Credits](https://dashboard.verificaremails.com/documentation/index.html?v=6)
