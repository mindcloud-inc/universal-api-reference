# Get Fuzzy Search Name Credits with Verificaremails

Retrieves available fuzzy search name credits from Verificaremails.

## Endpoint

- **Method:** `GET`
- **Path:** `/fuzzysearch/credits`
- **Base URL:** `https://dashboard.verificaremails.com/myapi`
- **Official documentation:** [Get Fuzzy Search Name Credits](https://dashboard.verificaremails.com/documentation/index.html?v=6)
