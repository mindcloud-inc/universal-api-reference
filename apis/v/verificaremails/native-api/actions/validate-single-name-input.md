# Validate Single Name Input with Verificaremails

Retrieves a name validation result from Verificaremails.

## Endpoint

- **Method:** `GET`
- **Path:** `/name/validate/single`
- **Base URL:** `https://dashboard.verificaremails.com/myapi`
- **Official documentation:** [Validate Single Name Input](https://dashboard.verificaremails.com/documentation/index.html?v=6)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `term` | query | `string` | yes | First or last name to validate. |
