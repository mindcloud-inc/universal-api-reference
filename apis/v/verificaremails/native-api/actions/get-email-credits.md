# Get Email Credits with Verificaremails

Retrieves available email verification credits from Verificaremails.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/credits`
- **Base URL:** `https://dashboard.verificaremails.com/myapi`
- **Official documentation:** [Get Email Credits](https://dashboard.verificaremails.com/documentation/index.html?v=6)
