# Get Complete Name Credits with Verificaremails

Retrieves available complete name credits from Verificaremails.

## Endpoint

- **Method:** `GET`
- **Path:** `/namecomplete/credits`
- **Base URL:** `https://dashboard.verificaremails.com/myapi`
- **Official documentation:** [Get Complete Name Credits](https://dashboard.verificaremails.com/documentation/index.html?v=6)
