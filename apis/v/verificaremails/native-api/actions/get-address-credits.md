# Get Address Credits with Verificaremails

Retrieves available address verification credits from Verificaremails.

## Endpoint

- **Method:** `GET`
- **Path:** `/address/credits`
- **Base URL:** `https://dashboard.verificaremails.com/myapi`
- **Official documentation:** [Get Address Credits](https://dashboard.verificaremails.com/documentation/index.html?v=6)
