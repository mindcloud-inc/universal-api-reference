# Get Phone Credits with Verificaremails

Retrieves available phone verification credits from Verificaremails.

## Endpoint

- **Method:** `GET`
- **Path:** `/phone/credits`
- **Base URL:** `https://dashboard.verificaremails.com/myapi`
- **Official documentation:** [Get Phone Credits](https://dashboard.verificaremails.com/documentation/index.html?v=6)
