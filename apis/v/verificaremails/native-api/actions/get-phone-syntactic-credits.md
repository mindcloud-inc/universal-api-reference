# Get Phone Syntactic Credits with Verificaremails

Retrieves available phone syntactic credits from Verificaremails.

## Endpoint

- **Method:** `GET`
- **Path:** `/phonesyntactic/credits`
- **Base URL:** `https://dashboard.verificaremails.com/myapi`
- **Official documentation:** [Get Phone Syntactic Credits](https://dashboard.verificaremails.com/documentation/index.html?v=6)
