# Get Name Credits with Verificaremails

Retrieves available name verification credits from Verificaremails.

## Endpoint

- **Method:** `GET`
- **Path:** `/name/credits`
- **Base URL:** `https://dashboard.verificaremails.com/myapi`
- **Official documentation:** [Get Name Credits](https://dashboard.verificaremails.com/documentation/index.html?v=6)
