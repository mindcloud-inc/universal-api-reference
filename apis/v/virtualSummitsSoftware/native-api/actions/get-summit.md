# Get Summit with Virtual Summits Software

## Endpoint

- **Method:** `GET`
- **Path:** `/summits/:summitId`
- **Base URL:** `https://api.virtualsummits.com/api/v1`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `summitId` | path | `number` | yes |
