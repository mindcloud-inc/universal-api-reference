# List Summit Sponsors with Virtual Summits Software

## Endpoint

- **Method:** `GET`
- **Path:** `/summits/:summitId/sponsors`
- **Base URL:** `https://api.virtualsummits.com/api/v1`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `summitId` | path | `number` | yes |
