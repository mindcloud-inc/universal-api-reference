# List Sponsorship Tiers with Virtual Summits Software

## Endpoint

- **Method:** `GET`
- **Path:** `/summits/:summitId/sponsorship-tiers`
- **Base URL:** `https://api.virtualsummits.com/api/v1`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `summitId` | path | `number` | yes |
