# Verify Single Email with Verify550

Verifies a single email address with Verify550.

## Endpoint

- **Method:** `GET`
- **Path:** `/singlemail`
- **Base URL:** `https://app.verify550.com/api`
- **Official documentation:** [Verify Single Email](https://verify550.com/documentation/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to verify. |
