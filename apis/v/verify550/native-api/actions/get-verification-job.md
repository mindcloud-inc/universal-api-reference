# Get Verification Job with Verify550

Retrieves a verification job from Verify550.

## Endpoint

- **Method:** `GET`
- **Path:** `/getjob/:jobId`
- **Base URL:** `https://app.verify550.com/api`
- **Official documentation:** [Get Verification Job](https://verify550.com/documentation/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | Verify550 bulk verification job ID. |
