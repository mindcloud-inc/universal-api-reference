# Download Ready File with Verify550

Downloads a ready verification file from Verify550.

## Endpoint

- **Method:** `GET`
- **Path:** `/details`
- **Base URL:** `https://app.verify550.com/api`
- **Official documentation:** [Download Ready File](https://verify550.com/documentation/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Verify550 file identifier. |
