# Verify Email with ValidEmail

Verifies an email address with ValidEmail.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://api.ValidEmail.net`
- **Official documentation:** [Verify Email](https://www.validemail.net/Docs/api-python)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | The email address to verify. |
