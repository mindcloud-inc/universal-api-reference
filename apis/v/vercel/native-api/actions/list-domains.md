# List Domains with Vercel

Retrieves all domain records from Vercel.

## Endpoint

- **Method:** `GET`
- **Path:** `/v5/domains`
- **Base URL:** `https://api.vercel.com`
- **Official documentation:** [List Domains](https://docs.vercel.com/docs/rest-api/reference/endpoints/domains/list-all-the-domains)
