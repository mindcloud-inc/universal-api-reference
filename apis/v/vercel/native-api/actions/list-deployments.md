# List Deployments with Vercel

Retrieves all deployment records from Vercel.

## Endpoint

- **Method:** `GET`
- **Path:** `/v6/deployments`
- **Base URL:** `https://api.vercel.com`
- **Official documentation:** [List Deployments](https://docs.vercel.com/docs/rest-api/reference/endpoints/deployments/list-deployments)
