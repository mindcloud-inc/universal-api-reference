# List Project Users with Viqeo

Retrieves all project users from Viqeo.

## Endpoint

- **Method:** `GET`
- **Path:** `/media-platform/v1/project/:projectId/user`
- **Base URL:** `https://api.viqeo.tv`
- **Official documentation:** [List Project Users](https://support.viqeo.tv/en/articles/8962790-media-editor-api#h_e0bfa8f879)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project identifier from the path. |
