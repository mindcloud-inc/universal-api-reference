# List Projects with Viqeo

Retrieves all project records from Viqeo.

## Endpoint

- **Method:** `GET`
- **Path:** `/media-platform/v1/project`
- **Base URL:** `https://api.viqeo.tv`
- **Official documentation:** [List Projects](https://support.viqeo.tv/en/articles/8962790-media-editor-api#h_fd2e63d987)
