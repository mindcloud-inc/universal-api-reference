# List Stories with Viqeo

Retrieves all story records from Viqeo.

## Endpoint

- **Method:** `GET`
- **Path:** `/media-platform/v1/project/:projectId/story`
- **Base URL:** `https://api.viqeo.tv`
- **Official documentation:** [List Stories](https://support.viqeo.tv/en/articles/8962790-media-editor-api#h_ee34c919cc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project identifier from the path. |
