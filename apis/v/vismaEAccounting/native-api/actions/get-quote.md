# Get Quote with Visma eAccounting

Retrieves a quote from Visma eAccounting.

## Endpoint

- **Method:** `GET`
- **Path:** `/quotes/{id}`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Get Quote](https://eaccountingapi.vismaonline.com/scalar/v2#quotes/get/quotes/{id})
