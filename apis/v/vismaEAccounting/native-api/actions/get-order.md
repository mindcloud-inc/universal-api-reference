# Get Order with Visma eAccounting

Retrieves an order from Visma eAccounting.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/{id}`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Get Order](https://eaccountingapi.vismaonline.com/scalar/v2#orders/get/orders/{id})
