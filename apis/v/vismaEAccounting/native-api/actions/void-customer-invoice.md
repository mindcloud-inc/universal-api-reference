# Void Customer Invoice with Visma eAccounting

Voids an existing customer invoice in Visma eAccounting.

## Endpoint

- **Method:** `POST`
- **Path:** `/customerinvoices/{invoiceId}/void`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Void Customer Invoice](https://eaccountingapi.vismaonline.com/scalar/v2#customerinvoices/post/customerinvoices/{invoiceId}/void)
