# List Customer Invoices with Visma eAccounting

Retrieves all customer invoices from Visma eAccounting.

## Endpoint

- **Method:** `GET`
- **Path:** `/customerinvoices`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [List Customer Invoices](https://eaccountingapi.vismaonline.com/scalar/v2#customerinvoices/get/customerinvoices)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
