# Get Customer with Visma eAccounting

Retrieves a customer from Visma eAccounting.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/{customerId}`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Get Customer](https://eaccountingapi.vismaonline.com/scalar/v2#customers/get/customers/{customerId})
