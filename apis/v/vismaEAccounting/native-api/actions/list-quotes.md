# List Quotes with Visma eAccounting

Retrieves all quotes from Visma eAccounting.

## Endpoint

- **Method:** `GET`
- **Path:** `/quotes`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [List Quotes](https://eaccountingapi.vismaonline.com/scalar/v2#quotes/get/quotes)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
