# List Customers with Visma eAccounting

Retrieves all customers from Visma eAccounting.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [List Customers](https://eaccountingapi.vismaonline.com/scalar/v2#customers/get/customers)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
