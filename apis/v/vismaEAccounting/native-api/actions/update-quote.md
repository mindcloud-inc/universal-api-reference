# Update Quote with Visma eAccounting

Updates an existing quote in Visma eAccounting.

## Endpoint

- **Method:** `PUT`
- **Path:** `/quotes/{id}`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Update Quote](https://eaccountingapi.vismaonline.com/scalar/v2#quotes/put/quotes/{id})
