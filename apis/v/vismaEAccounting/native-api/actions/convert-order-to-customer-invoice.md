# Convert Order To Customer Invoice with Visma eAccounting

Creates a customer invoice from an order in Visma eAccounting.

## Endpoint

- **Method:** `POST`
- **Path:** `/orders/{id}/convert`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Convert Order To Customer Invoice](https://eaccountingapi.vismaonline.com/scalar/v2#orders/post/orders/{id}/convert)
