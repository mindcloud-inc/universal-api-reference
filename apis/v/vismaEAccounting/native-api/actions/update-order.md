# Update Order with Visma eAccounting

Updates an existing order in Visma eAccounting.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orders/{id}`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Update Order](https://eaccountingapi.vismaonline.com/scalar/v2#orders/put/orders/{id})
