# Replace Article with Visma eAccounting

Updates an existing article in Visma eAccounting.

## Endpoint

- **Method:** `PUT`
- **Path:** `/articles/{articleId}`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Replace Article](https://eaccountingapi.vismaonline.com/scalar/v2#articles/put/articles/{articleId})
