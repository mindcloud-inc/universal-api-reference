# List Customer Invoice Drafts with Visma eAccounting

Retrieves all customer invoice drafts from Visma eAccounting.

## Endpoint

- **Method:** `GET`
- **Path:** `/customerinvoicedrafts`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [List Customer Invoice Drafts](https://eaccountingapi.vismaonline.com/scalar/v2#customerinvoicedrafts/get/customerinvoicedrafts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
