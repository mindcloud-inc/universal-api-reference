# Delete Customer with Visma eAccounting

Deletes an existing customer from Visma eAccounting.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customers/{customerId}`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Delete Customer](https://eaccountingapi.vismaonline.com/scalar/v2#customers/delete/customers/{customerId})
