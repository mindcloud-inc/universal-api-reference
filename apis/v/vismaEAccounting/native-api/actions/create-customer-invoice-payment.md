# Create Customer Invoice Payment with Visma eAccounting

Creates a customer invoice payment in Visma eAccounting.

## Endpoint

- **Method:** `POST`
- **Path:** `/customerinvoices/{invoiceId}/payments`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Create Customer Invoice Payment](https://eaccountingapi.vismaonline.com/scalar/v2#customerinvoices/post/customerinvoices/{invoiceId}/payments)
