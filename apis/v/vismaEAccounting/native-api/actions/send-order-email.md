# Send Order Email with Visma eAccounting

Sends an order email from Visma eAccounting.

## Endpoint

- **Method:** `POST`
- **Path:** `/orders/{id}/email`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Send Order Email](https://eaccountingapi.vismaonline.com/scalar/v2#orders/post/orders/{id}/email)
