# Create Customer with Visma eAccounting

Creates a new customer in Visma eAccounting.

## Endpoint

- **Method:** `POST`
- **Path:** `/customers`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Create Customer](https://eaccountingapi.vismaonline.com/scalar/v2#customers/post/customers)
