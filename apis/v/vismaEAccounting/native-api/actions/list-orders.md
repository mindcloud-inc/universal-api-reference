# List Orders with Visma eAccounting

Retrieves all orders from Visma eAccounting.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [List Orders](https://eaccountingapi.vismaonline.com/scalar/v2#orders/get/orders)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
