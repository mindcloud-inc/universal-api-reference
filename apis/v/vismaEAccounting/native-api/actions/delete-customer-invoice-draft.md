# Delete Customer Invoice Draft with Visma eAccounting

Deletes an existing customer invoice draft from Visma eAccounting.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customerinvoicedrafts/{customerInvoiceDraftId}`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Delete Customer Invoice Draft](https://eaccountingapi.vismaonline.com/scalar/v2#customerinvoicedrafts/delete/customerinvoicedrafts/{customerInvoiceDraftId})
