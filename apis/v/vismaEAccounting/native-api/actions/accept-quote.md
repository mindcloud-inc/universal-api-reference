# Accept Quote with Visma eAccounting

Accepts an existing quote in Visma eAccounting.

## Endpoint

- **Method:** `PUT`
- **Path:** `/quotes/{id}/accept`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Accept Quote](https://eaccountingapi.vismaonline.com/scalar/v2#quotes/put/quotes/{id}/accept)
