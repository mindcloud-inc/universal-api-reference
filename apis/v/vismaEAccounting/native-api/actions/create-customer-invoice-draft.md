# Create Customer Invoice Draft with Visma eAccounting

Creates a new customer invoice draft in Visma eAccounting.

## Endpoint

- **Method:** `POST`
- **Path:** `/customerinvoicedrafts`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Create Customer Invoice Draft](https://eaccountingapi.vismaonline.com/scalar/v2#customerinvoicedrafts/post/customerinvoicedrafts)
