# Create Order with Visma eAccounting

Creates a new order in Visma eAccounting.

## Endpoint

- **Method:** `POST`
- **Path:** `/orders`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Create Order](https://eaccountingapi.vismaonline.com/scalar/v2#orders/post/orders)
