# Update Customer with Visma eAccounting

Updates an existing customer in Visma eAccounting.

## Endpoint

- **Method:** `PUT`
- **Path:** `/customers/{customerId}`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Update Customer](https://eaccountingapi.vismaonline.com/scalar/v2#customers/put/customers/{customerId})
