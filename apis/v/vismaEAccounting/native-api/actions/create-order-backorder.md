# Create Order Backorder with Visma eAccounting

Creates a backorder from an order in Visma eAccounting.

## Endpoint

- **Method:** `POST`
- **Path:** `/orders/{id}/backorder`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Create Order Backorder](https://eaccountingapi.vismaonline.com/scalar/v2#orders/post/orders/{id}/backorder)
