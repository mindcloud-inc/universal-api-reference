# List Articles with Visma eAccounting

Retrieves all articles from Visma eAccounting.

## Endpoint

- **Method:** `GET`
- **Path:** `/articles`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [List Articles](https://eaccountingapi.vismaonline.com/scalar/v2#articles/get/articles)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
