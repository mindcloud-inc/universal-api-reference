# Create Article with Visma eAccounting

Creates a new article in Visma eAccounting.

## Endpoint

- **Method:** `POST`
- **Path:** `/articles`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Create Article](https://eaccountingapi.vismaonline.com/scalar/v2#articles/post/articles)
