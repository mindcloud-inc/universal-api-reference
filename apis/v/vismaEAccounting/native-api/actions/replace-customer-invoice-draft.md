# Replace Customer Invoice Draft with Visma eAccounting

Updates an existing customer invoice draft in Visma eAccounting.

## Endpoint

- **Method:** `PUT`
- **Path:** `/customerinvoicedrafts/{customerInvoiceDraftId}`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Replace Customer Invoice Draft](https://eaccountingapi.vismaonline.com/scalar/v2#customerinvoicedrafts/put/customerinvoicedrafts/{customerInvoiceDraftId})
