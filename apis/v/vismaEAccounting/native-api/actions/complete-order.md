# Complete Order with Visma eAccounting

Completes an existing order in Visma eAccounting.

## Endpoint

- **Method:** `POST`
- **Path:** `/orders/{id}/completed`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Complete Order](https://eaccountingapi.vismaonline.com/scalar/v2#orders/post/orders/{id}/completed)
