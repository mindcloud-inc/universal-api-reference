# Create Quote with Visma eAccounting

Creates a new quote in Visma eAccounting.

## Endpoint

- **Method:** `POST`
- **Path:** `/quotes`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Create Quote](https://eaccountingapi.vismaonline.com/scalar/v2#quotes/post/quotes)
