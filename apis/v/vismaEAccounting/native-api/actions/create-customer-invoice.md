# Create Customer Invoice with Visma eAccounting

Creates a new customer invoice in Visma eAccounting.

## Endpoint

- **Method:** `POST`
- **Path:** `/customerinvoices`
- **Base URL:** `https://eaccountingapi.vismaonline.com`
- **Official documentation:** [Create Customer Invoice](https://eaccountingapi.vismaonline.com/scalar/v2#customerinvoices/post/customerinvoices)
