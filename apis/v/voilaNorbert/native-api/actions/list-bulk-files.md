# List Bulk Files with VoilaNorbert

Retrieves bulk files from VoilaNorbert in chronological order.

## Endpoint

- **Method:** `GET`
- **Path:** `/massives/`
- **Base URL:** `https://api.voilanorbert.com/2018-01-08`
- **Official documentation:** [List Bulk Files](https://api.voilanorbert.com/2018-01-08/#bulk-search-endpoint-bulk-operations-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
