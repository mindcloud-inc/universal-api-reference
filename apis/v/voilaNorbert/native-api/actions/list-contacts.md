# List Contacts with VoilaNorbert

Retrieves a list of contacts from VoilaNorbert.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/`
- **Base URL:** `https://api.voilanorbert.com/2018-01-08`
- **Official documentation:** [List Contacts](https://api.voilanorbert.com/2018-01-08/#contacts-get)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
