# Get Bulk File with VoilaNorbert

Retrieves a bulk file status from VoilaNorbert.

## Endpoint

- **Method:** `GET`
- **Path:** `/massives/:id`
- **Base URL:** `https://api.voilanorbert.com/2018-01-08`
- **Official documentation:** [Get Bulk File](https://api.voilanorbert.com/2018-01-08/#bulk-search-endpoint-bulk-item-operations-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The bulk file id to retrieve. |
