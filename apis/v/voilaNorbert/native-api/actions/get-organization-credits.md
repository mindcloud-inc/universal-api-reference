# Get Organization Credits with VoilaNorbert

Retrieves current organization credits from VoilaNorbert.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/credits`
- **Base URL:** `https://api.voilanorbert.com/2018-01-08`
- **Official documentation:** [Get Organization Credits](https://api.voilanorbert.com/2018-01-08/#credits-get)
