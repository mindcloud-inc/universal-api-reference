# Get Contact with VoilaNorbert

Retrieves a single contact from VoilaNorbert.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.voilanorbert.com/2018-01-08`
- **Official documentation:** [Get Contact](https://api.voilanorbert.com/2018-01-08/#contacts-get-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The contact id to retrieve. |
