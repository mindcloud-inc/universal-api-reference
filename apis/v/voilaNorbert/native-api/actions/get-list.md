# Get List with VoilaNorbert

Retrieves one list from VoilaNorbert.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:id`
- **Base URL:** `https://api.voilanorbert.com/2018-01-08`
- **Official documentation:** [Get List](https://api.voilanorbert.com/2018-01-08/#lists-list-items-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The list id to retrieve. |
