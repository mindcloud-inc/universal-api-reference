# Pause Bulk File with VoilaNorbert

Pauses an active bulk file in VoilaNorbert.

## Endpoint

- **Method:** `POST`
- **Path:** `/massives/:id/pause`
- **Base URL:** `https://api.voilanorbert.com/2018-01-08`
- **Official documentation:** [Pause Bulk File](https://api.voilanorbert.com/2018-01-08/#bulk-search-endpoint-bulk-item-operations-post-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The bulk file id to pause. |
