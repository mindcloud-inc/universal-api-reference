# Create List with VoilaNorbert

Creates a new list in VoilaNorbert.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists/`
- **Base URL:** `https://api.voilanorbert.com/2018-01-08`
- **Official documentation:** [Create List](https://api.voilanorbert.com/2018-01-08/#lists-lists-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the list to create. |
