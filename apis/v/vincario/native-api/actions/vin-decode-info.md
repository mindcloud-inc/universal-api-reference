# VIN Decode Info with Vincario

## Endpoint

- **Method:** `GET`
- **Path:** `/:apiKey/:controlSum/decode/info/:vin.:format`
- **Base URL:** `https://api.vincario.com/3.2`
- **Official documentation:** [VIN Decode Info](https://vincario.com/api-docs/3.2/#operations-VIN_Decode_Info-VIN_Decode_Info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vin` | path | `string` | yes | Vehicle Identification Number. |
