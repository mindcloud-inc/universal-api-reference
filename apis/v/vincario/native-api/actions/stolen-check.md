# Stolen Check with Vincario

## Endpoint

- **Method:** `GET`
- **Path:** `/:apiKey/:controlSum/stolen-check/:vin.:format`
- **Base URL:** `https://api.vincario.com/3.2`
- **Official documentation:** [Stolen Check](https://vincario.com/api-docs/3.2/#operations-Stolen_Check-Stolen_Check)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vin` | path | `string` | yes | Vehicle Identification Number. |
