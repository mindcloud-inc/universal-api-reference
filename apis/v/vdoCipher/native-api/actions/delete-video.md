# Delete Video with VdoCipher

Deletes an existing video from VdoCipher.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/videos`
- **Base URL:** `https://dev.vdocipher.com/api`
- **Official documentation:** [Delete Video](https://www.vdocipher.com/docs/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videos` | query | `string` | no | Array of video ids Maximum 50 |
