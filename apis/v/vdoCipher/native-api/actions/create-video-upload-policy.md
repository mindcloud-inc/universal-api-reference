# Create Video Upload Policy with VdoCipher

Retrieves an upload policy for a new VdoCipher video.

## Endpoint

- **Method:** `PUT`
- **Path:** `/videos`
- **Base URL:** `https://dev.vdocipher.com/api`
- **Official documentation:** [Create Video Upload Policy](https://www.vdocipher.com/docs/server/upload/overview)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `title` | query | `string` | no |
