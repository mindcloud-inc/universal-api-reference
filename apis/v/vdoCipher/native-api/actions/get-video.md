# Get Video with VdoCipher

Retrieves video details from VdoCipher.

## Endpoint

- **Method:** `GET`
- **Path:** `/videos/:videoId`
- **Base URL:** `https://dev.vdocipher.com/api`
- **Official documentation:** [Get Video](https://www.vdocipher.com/docs/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `videoId` | path | `string` | no |
