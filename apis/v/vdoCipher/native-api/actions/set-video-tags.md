# Set Video Tags with VdoCipher

Replaces video tags for a VdoCipher video.

## Endpoint

- **Method:** `PUT`
- **Path:** `/videos/tags/`
- **Base URL:** `https://dev.vdocipher.com/api`
- **Official documentation:** [Set Video Tags](https://www.vdocipher.com/docs/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tags` | body | `string` | no |
| `videos` | body | `string` | no |
