# Get Video Parameters with VdoCipher

Retrieves video parameters from VdoCipher.

## Endpoint

- **Method:** `GET`
- **Path:** `/videos/:videoId/params`
- **Base URL:** `https://dev.vdocipher.com/api`
- **Official documentation:** [Get Video Parameters](https://www.vdocipher.com/docs/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keys` | query | `string` | no | CSV value of keys |
| `videoId` | path | `string` | no | — |
