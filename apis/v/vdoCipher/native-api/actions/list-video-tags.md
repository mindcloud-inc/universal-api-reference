# List Video Tags with VdoCipher

Lists video tags in VdoCipher.

## Endpoint

- **Method:** `GET`
- **Path:** `/videos/tags/`
- **Base URL:** `https://dev.vdocipher.com/api`
- **Official documentation:** [List Video Tags](https://www.vdocipher.com/docs/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `string` | no | page size will always be 10 |
| `q` | query | `string` | no | — |
