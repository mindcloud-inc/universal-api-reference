# Delete Webhook with VdoCipher

Deletes an existing webhook from VdoCipher.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/hooks/`
- **Base URL:** `https://dev.vdocipher.com/api`
- **Official documentation:** [Delete Webhook](https://www.vdocipher.com/docs/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | body | `string` | no |
