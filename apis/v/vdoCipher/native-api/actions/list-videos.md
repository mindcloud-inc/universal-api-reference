# List Videos with VdoCipher

Lists videos in VdoCipher.

## Endpoint

- **Method:** `GET`
- **Path:** `/videos`
- **Base URL:** `https://dev.vdocipher.com/api`
- **Official documentation:** [List Videos](https://www.vdocipher.com/docs/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | — |
| `limit` | query | `number` | no | — |
| `tags` | query | `string` | no | comma separated tags |
