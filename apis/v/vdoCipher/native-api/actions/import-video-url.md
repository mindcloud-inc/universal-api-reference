# Import Video URL with VdoCipher

Imports a video from a URL into VdoCipher.

## Endpoint

- **Method:** `PUT`
- **Path:** `/videos/importUrl`
- **Base URL:** `https://dev.vdocipher.com/api`
- **Official documentation:** [Import Video URL](https://www.vdocipher.com/docs/server/upload/import-url)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | body | `string` | no |
