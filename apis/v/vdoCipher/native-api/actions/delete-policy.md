# Delete Policy with VdoCipher

Deletes an existing policy from VdoCipher.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/policy/:id`
- **Base URL:** `https://dev.vdocipher.com/api`
- **Official documentation:** [Delete Policy](https://www.vdocipher.com/docs/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
