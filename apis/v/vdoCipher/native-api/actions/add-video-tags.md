# Add Video Tags with VdoCipher

Adds tags to videos in VdoCipher.

## Endpoint

- **Method:** `POST`
- **Path:** `/videos/tags/`
- **Base URL:** `https://dev.vdocipher.com/api`
- **Official documentation:** [Add Video Tags](https://www.vdocipher.com/docs/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tags` | body | `string` | no |
| `videos` | body | `string` | no |
