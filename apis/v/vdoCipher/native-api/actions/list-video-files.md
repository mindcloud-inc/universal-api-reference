# List Video Files with VdoCipher

Lists video files in VdoCipher.

## Endpoint

- **Method:** `GET`
- **Path:** `/videos/:videoId/files`
- **Base URL:** `https://dev.vdocipher.com/api`
- **Official documentation:** [List Video Files](https://www.vdocipher.com/docs/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `videoId` | path | `string` | no |
