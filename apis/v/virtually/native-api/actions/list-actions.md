# List Actions with Virtually

Retrieves actions from your Virtually workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgId/actions`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [List Actions](https://app.tryvirtually.com/api/docs#/Actions/ActionsController_findAll)
