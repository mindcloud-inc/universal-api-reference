# List Automations with Virtually

Retrieves automations from your Virtually workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgId/automations`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [List Automations](https://app.tryvirtually.com/api/docs#/Automations/AutomationsController_findAll)
