# Get Report Summary with Virtually

Retrieves a report summary from Virtually.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgId/reports/summary`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [Get Report Summary](https://app.tryvirtually.com/api/docs#/Reports/ReportsController_getSummary)
