# Delete Action with Virtually

Deletes an existing action from Virtually.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/orgs/:orgId/actions/:actionId`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [Delete Action](https://app.tryvirtually.com/api/docs#/Actions/ActionsController_remove)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `actionId` | path | `string` | yes |
