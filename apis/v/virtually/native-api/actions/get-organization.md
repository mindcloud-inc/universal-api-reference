# Get Organization with Virtually

Retrieves organization details from your Virtually workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgId`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [Get Organization](https://app.tryvirtually.com/api/docs#/App/AppController_getOrg)
