# Delete Member with Virtually

Deletes an existing member from Virtually.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/orgs/:orgId/members/:memberId`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [Delete Member](https://app.tryvirtually.com/api/docs#/Members/MembersController_remove)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `memberId` | path | `string` | yes | The member ID. |
