# List Member Tags with Virtually

Retrieves member tags from your Virtually workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgId/members/tags`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [List Member Tags](https://app.tryvirtually.com/api/docs#/Members/MembersController_getTags)
