# List Triggers with Virtually

Retrieves triggers from your Virtually workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgId/triggers`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [List Triggers](https://app.tryvirtually.com/api/docs#/Triggers/TriggersController_findAll)
