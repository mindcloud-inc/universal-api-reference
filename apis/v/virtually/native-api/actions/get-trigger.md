# Get Trigger with Virtually

Retrieves a trigger from your Virtually workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgId/triggers/:triggerId`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [Get Trigger](https://app.tryvirtually.com/api/docs#/Triggers/TriggersController_findOne)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `triggerId` | path | `string` | yes |
