# List Activity Feed Entries with Virtually

Retrieves activity feed entries from Virtually.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgId/activity-feed`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [List Activity Feed Entries](https://app.tryvirtually.com/api/docs#/App/AppController_getActivityLogs)
