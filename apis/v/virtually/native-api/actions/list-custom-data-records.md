# List Custom Data Records with Virtually

Retrieves custom data records from Virtually.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgId/customData`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [List Custom Data Records](https://app.tryvirtually.com/api/docs#/Custom%20Data/CustomDataController_findAll)
