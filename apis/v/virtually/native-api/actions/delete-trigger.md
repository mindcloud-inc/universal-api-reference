# Delete Trigger with Virtually

Deletes an existing trigger from Virtually.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/orgs/:orgId/triggers/:triggerId`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [Delete Trigger](https://app.tryvirtually.com/api/docs#/Triggers/TriggersController_remove)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `triggerId` | path | `string` | yes |
