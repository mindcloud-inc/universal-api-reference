# Get Action with Virtually

Retrieves an action from your Virtually workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgId/actions/:id`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [Get Action](https://app.tryvirtually.com/api/docs#/Actions/ActionsController_findOne)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
