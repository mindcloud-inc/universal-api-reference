# Get Automation with Virtually

Retrieves an automation from your Virtually workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgId/automations/:id`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [Get Automation](https://app.tryvirtually.com/api/docs#/Automations/AutomationsController_findOne)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
