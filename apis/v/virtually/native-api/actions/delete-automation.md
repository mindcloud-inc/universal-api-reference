# Delete Automation with Virtually

Deletes an existing automation from Virtually.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/orgs/:orgId/automations/:id`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [Delete Automation](https://app.tryvirtually.com/api/docs#/Automations/AutomationsController_remove)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The automation ID. |
