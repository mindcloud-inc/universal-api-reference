# List Custom Data Keys with Virtually

Retrieves custom data event keys from Virtually.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgId/customData/keys`
- **Base URL:** `https://app.tryvirtually.com`
- **Official documentation:** [List Custom Data Keys](https://app.tryvirtually.com/api/docs#/Custom%20Data/CustomDataController_getOrgCustomDataEventKeys)
