# Delete Sound File with VoiceShot

Deletes a sound file from VoiceShot.

## Endpoint

- **Method:** `POST`
- **Path:** `/ivrapi.asp`
- **Base URL:** `https://api.voiceshot.com`
- **Official documentation:** [Delete Sound File](https://secure.voiceshot.com/docs/ivrapiv5/deletingsoundfiles.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filename` | body | `string` | yes | WAV filename to delete from VoiceShot. |
