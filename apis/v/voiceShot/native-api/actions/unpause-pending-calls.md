# Unpause Pending Calls with VoiceShot

Resumes paused calls in a VoiceShot campaign.

## Endpoint

- **Method:** `POST`
- **Path:** `/ivrapi.asp`
- **Base URL:** `https://api.voiceshot.com`
- **Official documentation:** [Unpause Pending Calls](https://secure.voiceshot.com/docs/ivrapiv5/action.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `menuId` | body | `string` | yes | VoiceShot campaign identifier. |
