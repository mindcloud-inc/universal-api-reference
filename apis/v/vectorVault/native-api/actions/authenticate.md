# Authenticate with Vector Vault

## Endpoint

- **Method:** `POST`
- **Path:** `login_with_api`
- **Base URL:** `https://api.vectorvault.io`
- **Official documentation:** [Authenticate](https://github.com/John-Rood/VectorVault/blob/main/README.md#core-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | The Vector Vault account email. |
| `api_key` | body | `string` | yes | The Vector Vault API key. |
