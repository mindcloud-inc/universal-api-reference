# Get Group with Verix

Retrieves a credential group from Verix.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/credentials/groups/:group_id/`
- **Base URL:** `https://api.verix.io`
- **Official documentation:** [Get Group](https://docs.verix.io/verifiable_credentials_apis/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `number` | yes | Numeric Verix group ID. |
