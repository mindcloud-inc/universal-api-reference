# Get Corpus with Vectara

Retrieves metadata for a specific corpus from Vectara.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/corpora/:corpus_key`
- **Base URL:** `https://api.vectara.io`
- **Official documentation:** [Get Corpus](https://docs.vectara.com/docs/rest-api/vectara-rest-api-v-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `corpus_key` | path | `string` | yes | Unique key of the corpus. |
