# Delete Corpus with Vectara

Deletes an existing corpus from Vectara.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/corpora/:corpus_key`
- **Base URL:** `https://api.vectara.io`
- **Official documentation:** [Delete Corpus](https://docs.vectara.com/docs/rest-api/vectara-rest-api-v-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `corpus_key` | path | `string` | yes | Unique key of the corpus. |
