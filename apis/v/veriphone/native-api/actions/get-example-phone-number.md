# Get Example Phone Number with Veriphone

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/example`
- **Base URL:** `https://api.veriphone.io`
- **Official documentation:** [Get Example Phone Number](https://veriphone.io/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | query | `string` | no | Example number type |
| `country_code` | query | `string` | no | Country code |
