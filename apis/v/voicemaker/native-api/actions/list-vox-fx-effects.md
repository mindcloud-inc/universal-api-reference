# List VoxFX Effects with Voicemaker

Retrieves available VoxFX effects from Voicemaker.

## Endpoint

- **Method:** `GET`
- **Path:** `effects/voxfx`
- **Base URL:** `https://developer.voicemaker.in`
- **Official documentation:** [List VoxFX Effects](https://developer.voicemaker.in/apidocs/list-of-all-voxfx)
