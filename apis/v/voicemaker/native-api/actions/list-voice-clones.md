# List Voice Clones with Voicemaker

Retrieves all voice clones from Voicemaker.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/voice-clones`
- **Base URL:** `https://developer.voicemaker.in`
- **Official documentation:** [List Voice Clones](https://developer.voicemaker.in/apidocs/list-all-voice-clones)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to return. |
| `limit` | query | `number` | no | Maximum number of voice clones to return. |
