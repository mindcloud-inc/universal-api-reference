# Get Voice Clone with Voicemaker

Retrieves a single voice clone from Voicemaker.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/voice-clones/{VoiceId}`
- **Base URL:** `https://developer.voicemaker.in`
- **Official documentation:** [Get Voice Clone](https://developer.voicemaker.in/apidocs/get-single-voice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `VoiceId` | path | `string` | yes | Voice clone ID to retrieve. |
