# Delete Voice Clone with Voicemaker

Deletes an existing voice clone from Voicemaker.

## Endpoint

- **Method:** `DELETE`
- **Path:** `api/v1/voice-clones/{VoiceId}`
- **Base URL:** `https://developer.voicemaker.in`
- **Official documentation:** [Delete Voice Clone](https://developer.voicemaker.in/apidocs/delete-voice-clone)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `VoiceId` | path | `string` | yes | Voice clone ID to delete. |
