# List Transcription Files with Voicemaker

Retrieves all transcription files from Voicemaker.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/speech-to-text`
- **Base URL:** `https://developer.voicemaker.in`
- **Official documentation:** [List Transcription Files](https://developer.voicemaker.in/apidocs/list-transcription-files-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to return. |
| `limit` | query | `number` | no | Maximum number of transcription files to return. |
