# Get Verification with Vouchsafe

Retrieves a verification from Vouchsafe.

## Endpoint

- **Method:** `GET`
- **Path:** `/verifications/:id`
- **Base URL:** `https://app.vouchsafe.id/api/v1`
- **Official documentation:** [Get Verification](https://help.vouchsafe.id/en/articles/11979589-quick-start-guide)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The verification ID returned when you requested it. |
