# Get Alert Account Detail with Vouchsafe

Retrieves alert account details from Vouchsafe.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts/accounts/:id`
- **Base URL:** `https://app.vouchsafe.id/api/v1`
- **Official documentation:** [Get Alert Account Detail](https://app.vouchsafe.id/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The monitored account ID (Smart Lookup ID). |
