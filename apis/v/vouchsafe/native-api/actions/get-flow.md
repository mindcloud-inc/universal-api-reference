# Get Flow with Vouchsafe

Retrieves a verification flow from Vouchsafe.

## Endpoint

- **Method:** `GET`
- **Path:** `/flows/:id`
- **Base URL:** `https://app.vouchsafe.id/api/v1`
- **Official documentation:** [Get Flow](https://app.vouchsafe.id/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the flow to retrieve. |
