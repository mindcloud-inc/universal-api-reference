# Update User with Vyte

Updates an existing user in Vyte.

## Endpoint

- **Method:** `PUT`
- **Path:** `v2/users/:user_id`
- **Base URL:** `https://api.vyte.in`
- **Official documentation:** [Update User](https://developer.vyte.in/reference/users/#update-a-user)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | no | The Vyte user ID. |
