# List Events with Vyte

Retrieves a list of events from Vyte.

## Endpoint

- **Method:** `GET`
- **Path:** `v2/events`
- **Base URL:** `https://api.vyte.in`
- **Official documentation:** [List Events](https://developer.vyte.in/reference/events/#list-all-events)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
