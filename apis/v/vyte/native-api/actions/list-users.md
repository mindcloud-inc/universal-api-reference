# List Users with Vyte

Retrieves a list of users from Vyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/users`
- **Base URL:** `https://api.vyte.in`
- **Official documentation:** [List Users](https://developer.vyte.in/reference/users/#list-all-users)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
