# Update Event with Vyte

Updates an existing event in Vyte.

## Endpoint

- **Method:** `PUT`
- **Path:** `v2/events/:event_id`
- **Base URL:** `https://api.vyte.in`
- **Official documentation:** [Update Event](https://developer.vyte.in/reference/events/#update-an-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | no | The Vyte event ID. |
