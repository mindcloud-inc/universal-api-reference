# Create Team with Vyte

Creates a new team in Vyte.

## Endpoint

- **Method:** `POST`
- **Path:** `v2/teams`
- **Base URL:** `https://api.vyte.in`
- **Official documentation:** [Create Team](https://developer.vyte.in/reference/teams/#create-a-team)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
