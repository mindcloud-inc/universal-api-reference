# Confirm Event with Vyte

Confirms an event in Vyte.

## Endpoint

- **Method:** `POST`
- **Path:** `v2/events/:event_id/confirm`
- **Base URL:** `https://api.vyte.in`
- **Official documentation:** [Confirm Event](https://developer.vyte.in/reference/events/#confirm-an-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | no | The Vyte event ID. |
