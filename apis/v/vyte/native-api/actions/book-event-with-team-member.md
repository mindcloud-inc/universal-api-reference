# Book Event With Team Member with Vyte

Books an event with a team member in Vyte.

## Endpoint

- **Method:** `POST`
- **Path:** `v2/teams/:team_id/events`
- **Base URL:** `https://api.vyte.in`
- **Official documentation:** [Book Event With Team Member](https://developer.vyte.in/reference/teams/#create-a-team-event)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `string` | no | The Vyte team ID. |
