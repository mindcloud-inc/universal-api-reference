# Update Team with Vyte

Updates an existing team in Vyte.

## Endpoint

- **Method:** `PUT`
- **Path:** `v2/teams/:team_id`
- **Base URL:** `https://api.vyte.in`
- **Official documentation:** [Update Team](https://developer.vyte.in/reference/teams/#update-a-team)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `string` | no | The Vyte team ID. |
