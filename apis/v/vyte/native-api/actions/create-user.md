# Create User with Vyte

Creates a new user in Vyte.

## Endpoint

- **Method:** `POST`
- **Path:** `v2/users`
- **Base URL:** `https://api.vyte.in`
- **Official documentation:** [Create User](https://developer.vyte.in/reference/users/#create-a-user)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
