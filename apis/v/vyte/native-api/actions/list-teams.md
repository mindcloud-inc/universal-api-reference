# List Teams with Vyte

Retrieves a list of teams from Vyte.

## Endpoint

- **Method:** `GET`
- **Path:** `v2/teams`
- **Base URL:** `https://api.vyte.in`
- **Official documentation:** [List Teams](https://developer.vyte.in/reference/teams/#list-all-teams)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
