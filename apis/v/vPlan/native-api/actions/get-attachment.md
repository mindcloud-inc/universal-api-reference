# Get Attachment with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/collection/[:collection_id]/attachment/[:attachment_id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Attachment](https://docs.api.vplan.com/attachment.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection_id` | path | `string` | yes | — |
| `attachment_id` | path | `string` | yes | Attachment identifier. |
