# Get Webhook with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Webhook](https://docs.api.vplan.com/webhook.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook identifier. |
