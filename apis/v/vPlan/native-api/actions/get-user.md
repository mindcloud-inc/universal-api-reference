# Get User with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/user/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get User](https://docs.api.vplan.com/user.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | User identifier. |
