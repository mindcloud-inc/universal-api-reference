# Get Group with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/group/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Group](https://docs.api.vplan.com/group.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Group identifier. |
