# Update Project with vPlan

## Endpoint

- **Method:** `PUT`
- **Path:** `/project/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Update Project](https://docs.api.vplan.com/project.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project identifier. |
