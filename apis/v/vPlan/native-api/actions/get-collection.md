# Get Collection with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/collection/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Collection](https://docs.api.vplan.com/collection.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Collection identifier. |
