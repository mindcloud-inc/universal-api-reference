# Get Warehouse with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/warehouse/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Warehouse](https://docs.api.vplan.com/warehouse.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Warehouse identifier. |
