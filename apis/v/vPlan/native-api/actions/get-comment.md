# Get Comment with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/collection/[:collection_id]/comment/[:comment_id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Comment](https://docs.api.vplan.com/comment.md)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `collection_id` | path | `string` | yes |
| `comment_id` | path | `string` | yes |
