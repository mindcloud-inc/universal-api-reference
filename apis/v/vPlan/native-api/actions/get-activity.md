# Get Activity with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/activity/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Activity](https://docs.api.vplan.com/activity.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Activity identifier. |
