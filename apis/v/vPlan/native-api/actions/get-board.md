# Get Board with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/board/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Board](https://docs.api.vplan.com/board_show.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Board identifier. |
