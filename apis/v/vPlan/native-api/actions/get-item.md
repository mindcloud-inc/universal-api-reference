# Get Item with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/item/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Item](https://docs.api.vplan.com/item.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Item identifier. |
