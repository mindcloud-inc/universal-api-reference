# Get Time Tracking Entry with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/time_tracking/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Time Tracking Entry](https://docs.api.vplan.com/time_tracking.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Time tracking entry identifier. |
