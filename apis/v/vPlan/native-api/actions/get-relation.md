# Get Relation with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/relation/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Relation](https://docs.api.vplan.com/relation.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Relation identifier. |
