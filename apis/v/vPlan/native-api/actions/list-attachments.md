# List Attachments with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/collection/[:collection_id]/attachment`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [List Attachments](https://docs.api.vplan.com/attachment.md)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `collection_id` | path | `string` | yes |
