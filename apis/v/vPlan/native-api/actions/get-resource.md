# Get Resource with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/resource/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Resource](https://docs.api.vplan.com/resource.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier. |
