# Get Order with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/order/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Order](https://docs.api.vplan.com/order.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Order identifier. |
