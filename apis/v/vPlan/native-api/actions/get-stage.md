# Get Stage with vPlan

## Endpoint

- **Method:** `GET`
- **Path:** `/stage/[:id]`
- **Base URL:** `https://api.vplan.com/v1`
- **Official documentation:** [Get Stage](https://docs.api.vplan.com/stage.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Stage identifier. |
