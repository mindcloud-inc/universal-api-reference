- **Method:** `POST`

- **Official documentation:** [Create Project](https://docs.api.vplan.com/project.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Project name. |
