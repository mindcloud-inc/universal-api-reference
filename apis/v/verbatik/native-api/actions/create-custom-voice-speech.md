# Create Custom Voice Speech with Verbatik

Creates speech from a cloned voice in Verbatik.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/voice-cloning`
- **Base URL:** `https://api.verbatik.com/api`
- **Official documentation:** [Create Custom Voice Speech](https://docs.verbatik.com/docs/api/voice-cloning)
