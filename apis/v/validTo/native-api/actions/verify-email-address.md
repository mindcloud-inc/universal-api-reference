# Verify Email Address with validTo

Verifies an email address with validTo.

## Endpoint

- **Method:** `GET`
- **Path:** `/verify`
- **Base URL:** `https://api.validto.com/v1`
- **Official documentation:** [Verify Email Address](https://validto.readme.io/reference/single-validation-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | The email address to validate. |
