# Get Bulk Validation Progress with validTo

Retrieves bulk validation progress from validTo.

## Endpoint

- **Method:** `GET`
- **Path:** `/bulk/:jobId`
- **Base URL:** `https://api.validto.com/v1`
- **Official documentation:** [Get Bulk Validation Progress](https://validto.readme.io/reference/progress-of-a-bulk-validation-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | The bulk validation job ID. |
