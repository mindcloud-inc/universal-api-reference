# Delete Bulk Validation List with validTo

Deletes a bulk validation list from validTo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bulk/:jobId`
- **Base URL:** `https://api.validto.com/v1`
- **Official documentation:** [Delete Bulk Validation List](https://validto.readme.io/reference/delete-a-bulk-validation-list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `job_id` | path | `string` | yes |
