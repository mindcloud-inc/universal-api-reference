# Download Bulk Validation Results with validTo

Retrieves bulk validation results from validTo.

## Endpoint

- **Method:** `POST`
- **Path:** `/download`
- **Base URL:** `https://api.validto.com/v1`
- **Official documentation:** [Download Bulk Validation Results](https://validto.readme.io/reference/download-a-bulk-validation-list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `filterResult` | query | `string` | no |
| `jobId` | query | `string` | yes |
