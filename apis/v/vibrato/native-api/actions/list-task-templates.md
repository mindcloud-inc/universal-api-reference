# List task templates with Vibrato

Retrieves a list of task templates from Vibrato.

## Endpoint

- **Method:** `GET`
- **Path:** `/task_templates/`
- **Base URL:** `https://api.getvibrato.com/api/v1`
- **Official documentation:** [List task templates](https://docs.getvibrato.com/api-reference/tasktemplates/list-all-task-templates)
