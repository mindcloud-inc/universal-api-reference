# Get call transcript with Vibrato

Retrieves the transcript for a specific Vibrato call.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls/{id}/transcript/`
- **Base URL:** `https://api.getvibrato.com/api/v1`
- **Official documentation:** [Get call transcript](https://docs.getvibrato.com/api-reference/calls/get-transcript-for-a-specific-call)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Identifier from Vibrato. |
