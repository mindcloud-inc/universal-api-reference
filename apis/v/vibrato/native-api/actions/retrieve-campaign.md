# Retrieve campaign with Vibrato

Retrieves a specific campaign from Vibrato.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/{uuid}/`
- **Base URL:** `https://api.getvibrato.com/api/v1`
- **Official documentation:** [Retrieve campaign](https://docs.getvibrato.com/api-reference/campaigns/retrieve-a-specific-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID from Vibrato. |
