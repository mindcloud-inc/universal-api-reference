# Delete call with Vibrato

Deletes an existing call from Vibrato.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/calls/{id}/`
- **Base URL:** `https://api.getvibrato.com/api/v1`
- **Official documentation:** [Delete call](https://docs.getvibrato.com/api-reference/calls/delete-a-specific-call)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Identifier from Vibrato. |
