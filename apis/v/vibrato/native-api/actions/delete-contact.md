# Delete contact with Vibrato

Deletes an existing contact from Vibrato.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{uuid}/`
- **Base URL:** `https://api.getvibrato.com/api/v1`
- **Official documentation:** [Delete contact](https://docs.getvibrato.com/api-reference/contacts/delete-a-specific-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID from Vibrato. |
