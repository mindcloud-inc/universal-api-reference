# Delete task template with Vibrato

Deletes an existing task template from Vibrato.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/task_templates/{uuid}/`
- **Base URL:** `https://api.getvibrato.com/api/v1`
- **Official documentation:** [Delete task template](https://docs.getvibrato.com/api-reference/tasktemplates/delete-a-specific-task-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID from Vibrato. |
