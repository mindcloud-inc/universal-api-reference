# Retrieve contact with Vibrato

Retrieves a specific contact from Vibrato.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{uuid}/`
- **Base URL:** `https://api.getvibrato.com/api/v1`
- **Official documentation:** [Retrieve contact](https://docs.getvibrato.com/api-reference/contacts/retrieve-a-specific-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID from Vibrato. |
