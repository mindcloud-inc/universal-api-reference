# Delete campaign with Vibrato

Deletes an existing campaign from Vibrato.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/campaigns/{uuid}/`
- **Base URL:** `https://api.getvibrato.com/api/v1`
- **Official documentation:** [Delete campaign](https://docs.getvibrato.com/api-reference/campaigns/delete-a-specific-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID from Vibrato. |
