# End call with Vibrato

Ends an existing call in Vibrato.

## Endpoint

- **Method:** `POST`
- **Path:** `/calls/{id}/end/`
- **Base URL:** `https://api.getvibrato.com/api/v1`
- **Official documentation:** [End call](https://docs.getvibrato.com/api-reference/calls/end-a-specific-call)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Identifier from Vibrato. |
