# Retrieve task template with Vibrato

Retrieves a specific task template from Vibrato.

## Endpoint

- **Method:** `GET`
- **Path:** `/task_templates/{uuid}/`
- **Base URL:** `https://api.getvibrato.com/api/v1`
- **Official documentation:** [Retrieve task template](https://docs.getvibrato.com/api-reference/tasktemplates/retrieve-a-specific-task-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID from Vibrato. |
