# Retrieve call with Vibrato

Retrieves a specific call from Vibrato.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls/{id}/`
- **Base URL:** `https://api.getvibrato.com/api/v1`
- **Official documentation:** [Retrieve call](https://docs.getvibrato.com/api-reference/calls/retrieve-a-specific-call)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the call. |
