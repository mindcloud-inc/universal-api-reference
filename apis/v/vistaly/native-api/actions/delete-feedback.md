# Delete Feedback with Vistaly

Deletes existing feedback from Vistaly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/feedback/{feedbackId}`
- **Base URL:** `https://api.vistaly.com`
- **Official documentation:** [Delete Feedback](https://docs.vistaly.com/api-reference/feedback/delete-feedback)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `feedbackId` | path | `string` | yes | The unique identifier for the feedback. |
