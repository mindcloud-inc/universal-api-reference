# Get Interview Transcript with Vistaly

Retrieves an interview transcript from Vistaly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/interviews/{interviewId}/transcript`
- **Base URL:** `https://api.vistaly.com`
- **Official documentation:** [Get Interview Transcript](https://docs.vistaly.com/api-reference/interviews/get-interview-transcript)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `interviewId` | path | `string` | yes | The unique identifier for the interview. |
