# List Card Comments with Vistaly

Retrieves comments for a card from Vistaly.

## Endpoint

- **Method:** `GET`
- **Path:** `/beta/cards/{cardId}/comments`
- **Base URL:** `https://api.vistaly.com`
- **Official documentation:** [List Card Comments](https://docs.vistaly.com/api-reference/cards/list-comments-for-a-card)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `string` | yes | The unique identifier for the card. |
