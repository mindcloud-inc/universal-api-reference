# Get Card Details with Vistaly

Retrieves card details from Vistaly.

## Endpoint

- **Method:** `GET`
- **Path:** `/beta/cards/{cardId}`
- **Base URL:** `https://api.vistaly.com`
- **Official documentation:** [Get Card Details](https://docs.vistaly.com/api-reference/cards/get-card-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `string` | yes | The unique identifier for the card. |
