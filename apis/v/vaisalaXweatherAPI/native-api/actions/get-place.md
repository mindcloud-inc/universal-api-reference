# Get Place with Vaisala Xweather

Retrieves place details from Vaisala Xweather API.

## Endpoint

- **Method:** `GET`
- **Path:** `/places/:id`
- **Base URL:** `https://data.api.xweather.com`
- **Official documentation:** [Get Place](https://www.xweather.com/docs/weather-api/endpoints/places)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Location name, place identifier, postal code, or latitude/longitude. |
