# Get Customer with VentiPay

Retrieves a customer from VentiPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:id`
- **Base URL:** `https://api.ventipay.com/v1`
- **Official documentation:** [Get Customer](https://docs.ventipay.com/reference/customers-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Venti customer identifier. |
