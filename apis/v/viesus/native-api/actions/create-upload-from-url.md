# Create Upload From URL with Viesus

Creates an upload in Viesus from a URL.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.viesus.cloud/graphql`
- **Official documentation:** [Create Upload From URL](https://docs.viesus.cloud/reference/uploading/uploading-from-a-url)
