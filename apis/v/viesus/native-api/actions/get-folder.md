# Get Folder with Viesus

Retrieves a folder record from Viesus.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.viesus.cloud/graphql`
- **Official documentation:** [Get Folder](https://docs.viesus.cloud)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | no | GraphQL query document. |
