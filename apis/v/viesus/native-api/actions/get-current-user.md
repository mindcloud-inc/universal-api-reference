# Get Current User with Viesus

Retrieves the current user from Viesus.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.viesus.cloud/graphql`
- **Official documentation:** [Get Current User](https://docs.viesus.cloud)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | no | GraphQL query document. |
