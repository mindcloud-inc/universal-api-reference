# Get Enhanced Image with Viesus

Retrieves an enhanced image from Viesus.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.viesus.cloud/graphql`
- **Official documentation:** [Get Enhanced Image](https://docs.viesus.cloud/reference/enhancing)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | no | GraphQL query document. |
