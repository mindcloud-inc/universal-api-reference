# Get Upload with Viesus

Retrieves an upload record from Viesus.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.viesus.cloud/graphql`
- **Official documentation:** [Get Upload](https://docs.viesus.cloud/reference/retrieving-enhancements)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | no | GraphQL query document. |
