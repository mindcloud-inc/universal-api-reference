# Create Signed Upload URL with Viesus

Creates a signed upload URL in Viesus.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.viesus.cloud/graphql`
- **Official documentation:** [Create Signed Upload URL](https://docs.viesus.cloud/reference/uploading/uploading-with-a-signed-upload-url)
