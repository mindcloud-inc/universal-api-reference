# Validate IBAN with VAT Comply

Validates an IBAN in VAT Comply.

## Endpoint

- **Method:** `GET`
- **Path:** `/iban`
- **Base URL:** `https://api.vatcomply.com`
- **Official documentation:** [Validate IBAN](https://api.vatcomply.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `iban` | query | `string` | yes | The IBAN to validate. |
