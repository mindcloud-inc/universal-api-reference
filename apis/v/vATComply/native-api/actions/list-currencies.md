# List Currencies with VAT Comply

Retrieves supported currencies from VAT Comply.

## Endpoint

- **Method:** `GET`
- **Path:** `/currencies`
- **Base URL:** `https://api.vatcomply.com`
- **Official documentation:** [List Currencies](https://www.vatcomply.com/api/currencies/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter supported currencies by a search string. |
