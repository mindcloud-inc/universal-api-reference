# Validate VAT Number with VAT Comply

Validates a VAT number in VAT Comply.

## Endpoint

- **Method:** `GET`
- **Path:** `/vat`
- **Base URL:** `https://api.vatcomply.com`
- **Official documentation:** [Validate VAT Number](https://api.vatcomply.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vat_number` | query | `string` | yes | The VAT number to validate. |
