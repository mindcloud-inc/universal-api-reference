# List Messages with Vero

Retrieves all message records from Vero.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/messages`
- **Base URL:** `https://api.getvero.com`
- **Official documentation:** [List Messages](https://help.getvero.com/api-reference/messages/returns-messages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `string` | no | Optional page number for paginated list responses. |
| `per_page` | query | `string` | no | Optional page size for paginated list responses. |
