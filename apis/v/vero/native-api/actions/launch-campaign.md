# Launch Campaign with Vero

Launches an existing campaign in Vero.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v4/campaigns/:id/launch`
- **Base URL:** `https://api.getvero.com`
- **Official documentation:** [Launch Campaign](https://help.getvero.com/api-reference/campaigns/launch-a-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The campaign identifier. |
