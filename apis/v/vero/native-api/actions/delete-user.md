# Delete User with Vero

Deletes an existing user from Vero.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/users/delete`
- **Base URL:** `https://api.getvero.com`
- **Official documentation:** [Delete User](https://help.getvero.com/api-reference/users/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | The unique identifier of the user to delete. |
