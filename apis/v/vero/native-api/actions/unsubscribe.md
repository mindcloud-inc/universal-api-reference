# Unsubscribe with Vero

Unsubscribes a user in Vero globally.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/users/unsubscribe`
- **Base URL:** `https://api.getvero.com`
- **Official documentation:** [Unsubscribe](https://help.getvero.com/api-reference/users/unsubscribe)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | The unique identifier of the user to unsubscribe. |
