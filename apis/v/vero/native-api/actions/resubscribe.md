# Resubscribe with Vero

Resubscribes a user in Vero globally.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/users/resubscribe`
- **Base URL:** `https://api.getvero.com`
- **Official documentation:** [Resubscribe](https://help.getvero.com/api-reference/users/resubscribe)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | The unique identifier of the user to resubscribe. |
