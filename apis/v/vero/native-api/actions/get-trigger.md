# Get Trigger with Vero

Retrieves a trigger record from Vero.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/triggers/:id`
- **Base URL:** `https://api.getvero.com`
- **Official documentation:** [Get Trigger](https://help.getvero.com/api-reference/trigger/returns-a-trigger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The trigger identifier. |
