# Retrieve Campaign with Vero

Retrieves a campaign record from Vero.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/campaigns/:id`
- **Base URL:** `https://api.getvero.com`
- **Official documentation:** [Retrieve Campaign](https://help.getvero.com/api-reference/campaigns/retrieve-a-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The campaign identifier. |
