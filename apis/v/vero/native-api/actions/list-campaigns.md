# List Campaigns with Vero

Retrieves all campaign records from Vero.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/campaigns`
- **Base URL:** `https://api.getvero.com`
- **Official documentation:** [List Campaigns](https://help.getvero.com/api-reference/campaigns/returns-campaigns)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `string` | no | Optional page number for paginated list responses. |
| `per_page` | query | `string` | no | Optional page size for paginated list responses. |
