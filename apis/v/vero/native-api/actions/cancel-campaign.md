# Cancel Campaign with Vero

Cancels an existing campaign in Vero.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v4/campaigns/:id/cancel`
- **Base URL:** `https://api.getvero.com`
- **Official documentation:** [Cancel Campaign](https://help.getvero.com/api-reference/campaigns/cancels-a-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The campaign identifier. |
