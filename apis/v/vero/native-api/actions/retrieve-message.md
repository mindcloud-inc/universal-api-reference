# Retrieve Message with Vero

Retrieves a message record from Vero.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/messages/:id`
- **Base URL:** `https://api.getvero.com`
- **Official documentation:** [Retrieve Message](https://help.getvero.com/api-reference/messages/retrieve-a-message)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The message identifier. |
