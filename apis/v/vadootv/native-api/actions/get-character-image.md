# Get character image with Vadootv

Retrieves a generated character image URL from Vadootv.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/get_character_image`
- **Base URL:** `https://aiapi.vadoo.tv`
- **Official documentation:** [Get character image](https://docs.vadoo.tv/docs/guide/ai-character/get-character-image)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The image ID returned by the character image generation endpoint. |
