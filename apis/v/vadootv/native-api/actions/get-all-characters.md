# Get all characters with Vadootv

Retrieves AI characters from Vadootv.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/get_all_characters`
- **Base URL:** `https://aiapi.vadoo.tv`
- **Official documentation:** [Get all characters](https://docs.vadoo.tv/docs/guide/ai-character/get-list-characters)
