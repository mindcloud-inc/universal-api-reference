# Get video URL with Vadootv

Retrieves a generated video URL from Vadootv.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/get_video_url`
- **Base URL:** `https://aiapi.vadoo.tv`
- **Official documentation:** [Get video URL](https://docs.vadoo.tv/docs/guide/ai-story/get-video-url)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The video ID returned by a generation endpoint. |
