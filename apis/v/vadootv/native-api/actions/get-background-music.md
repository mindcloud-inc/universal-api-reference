# Get background music with Vadootv

Retrieves available background music tracks from Vadootv.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/get_background_music`
- **Base URL:** `https://aiapi.vadoo.tv`
- **Official documentation:** [Get background music](https://docs.vadoo.tv/docs/guide/ai-story/get-list-background-music)
