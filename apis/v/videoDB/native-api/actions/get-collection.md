# Get Collection with VideoDB

Retrieves a collection from VideoDB.

## Endpoint

- **Method:** `GET`
- **Path:** `/collection/:collection_id`
- **Base URL:** `https://api.videodb.io`
- **Official documentation:** [Get Collection](https://docs.videodb.io/api-reference/collections/get_collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection_id` | path | `string` | no | Collection ID to retrieve. Use default for the account's default collection. |
