# Get Video Transcription with VideoDB

Retrieves a video transcription from VideoDB.

## Endpoint

- **Method:** `GET`
- **Path:** `/video/:video_id/transcription/`
- **Base URL:** `https://api.videodb.io`
- **Official documentation:** [Get Video Transcription](https://docs.videodb.io/api-reference/videos/transcription/get_video_transcription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `string` | no | Video ID whose transcription should be retrieved. |
