# Delete Video with VideoDB

Deletes an existing video from VideoDB.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/video/:video_id`
- **Base URL:** `https://api.videodb.io`
- **Official documentation:** [Delete Video](https://docs.videodb.io/api-reference/videos/delete_video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `string` | yes | Video ID to delete |
