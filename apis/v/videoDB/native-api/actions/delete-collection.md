# Delete Collection with VideoDB

Deletes an existing collection from VideoDB.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/collection/:collection_id`
- **Base URL:** `https://api.videodb.io`
- **Official documentation:** [Delete Collection](https://docs.videodb.io/api-reference/collections/delete_collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection_id` | path | `string` | yes | Collection ID to delete |
