# Process Document with Veryfi OCR

Processes a document in Veryfi OCR.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v8/partner/documents`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Process Document](https://docs.veryfi.com/api/receipts-invoices/process-a-document/)
