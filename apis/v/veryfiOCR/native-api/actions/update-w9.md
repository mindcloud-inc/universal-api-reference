# Update W-9 with Veryfi OCR

Updates a W-9 in Veryfi OCR.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/w9s/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Update W-9](https://docs.veryfi.com/api/w9s/update-a-w-9/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
