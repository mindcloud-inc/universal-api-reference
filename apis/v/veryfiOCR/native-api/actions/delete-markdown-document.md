# Delete Markdown Document with Veryfi OCR

Deletes a markdown document from Veryfi OCR.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/document-to-markdown/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Delete Markdown Document](https://docs.veryfi.com/api/document-to-markdown/delete-a-markdown-document/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
