# Delete AnyDoc with Veryfi OCR

Deletes an AnyDoc from Veryfi OCR.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/any-documents/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Delete AnyDoc](https://docs.veryfi.com/api/anydocs/delete-a-A-doc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
