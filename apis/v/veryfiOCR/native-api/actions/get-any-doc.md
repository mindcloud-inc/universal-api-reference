# Get AnyDoc with Veryfi OCR

Retrieves an AnyDoc from Veryfi OCR.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/any-documents/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Get AnyDoc](https://docs.veryfi.com/api/anydocs/get-a-A-doc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
