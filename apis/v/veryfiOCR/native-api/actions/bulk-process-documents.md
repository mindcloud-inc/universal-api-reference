# Bulk Process Documents with Veryfi OCR

Processes multiple documents in Veryfi OCR.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v8/partner/documents/bulk`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Bulk Process Documents](https://docs.veryfi.com/api/receipts-invoices/bulk-process-multiple-documents/)
