# Split And Process W-2 PDF with Veryfi OCR

Processes W-2s from a split PDF in Veryfi OCR.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v8/partner/w2s-set`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Split And Process W-2 PDF](https://docs.veryfi.com/api/split-and-process-a-pdf-with-multiple-w-2-s/)
