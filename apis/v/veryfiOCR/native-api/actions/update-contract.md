# Update Contract with Veryfi OCR

Updates a contract in Veryfi OCR.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/contracts/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Update Contract](https://docs.veryfi.com/api/contracts/update-a-contract/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
