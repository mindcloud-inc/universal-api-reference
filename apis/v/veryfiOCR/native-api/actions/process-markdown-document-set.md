# Process Markdown Document Set with Veryfi OCR

Processes a markdown document set in Veryfi OCR.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v8/partner/document-to-markdown-set`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Process Markdown Document Set](https://docs.veryfi.com/api/document-to-markdown/process-a-markdown-document-set/)
