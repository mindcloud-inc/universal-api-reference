# Get W-2 with Veryfi OCR

Retrieves a W-2 from Veryfi OCR.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/w2s/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Get W-2](https://docs.veryfi.com/api/w2s/get-a-w-2/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
