# Get OpenAPI Schema with Veryfi OCR

Retrieves the OpenAPI schema from Veryfi OCR.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/documents/schema`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Get OpenAPI Schema](https://docs.veryfi.com/api/get-open-api-schema/)
