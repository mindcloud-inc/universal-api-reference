# Delete Check with Veryfi OCR

Deletes a check from Veryfi OCR.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/checks/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Delete Check](https://docs.veryfi.com/api/checks/delete-a-check/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
