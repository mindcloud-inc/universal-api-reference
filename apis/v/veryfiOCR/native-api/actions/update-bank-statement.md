# Update Bank Statement with Veryfi OCR

Updates a bank statement in Veryfi OCR.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/bank-statements/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Update Bank Statement](https://docs.veryfi.com/api/bank-statements/update-a-bank-statement/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
