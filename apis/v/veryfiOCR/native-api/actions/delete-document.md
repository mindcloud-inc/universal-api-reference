# Delete Document with Veryfi OCR

Deletes a document from Veryfi OCR.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/documents/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Delete Document](https://docs.veryfi.com/api/receipts-invoices/delete-a-document/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
