# Get Check with Veryfi OCR

Retrieves a check from Veryfi OCR.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/checks/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Get Check](https://docs.veryfi.com/api/checks/get-a-check/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
