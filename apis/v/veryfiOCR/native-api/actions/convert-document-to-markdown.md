# Convert Document To Markdown with Veryfi OCR

Converts a document to markdown in Veryfi OCR.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v8/partner/document-to-markdown`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Convert Document To Markdown](https://docs.veryfi.com/api/document-to-markdown/convert-a-document-to-markdown/)
