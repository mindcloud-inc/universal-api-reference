# Update Check with Veryfi OCR

Updates a check in Veryfi OCR.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/checks/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Update Check](https://docs.veryfi.com/api/checks/update-a-check/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
