# Unlink All Tags From Document with Veryfi OCR

Unlinks all tags from a document in Veryfi OCR.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/documents/:document_id/tags`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Unlink All Tags From Document](https://docs.veryfi.com/api/receipts-invoices/add-a-tag-to-a-document/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
