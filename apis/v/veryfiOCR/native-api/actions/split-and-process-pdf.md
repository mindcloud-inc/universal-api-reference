# Split And Process PDF with Veryfi OCR

Processes documents from a split PDF in Veryfi OCR.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v8/partner/documents-set`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Split And Process PDF](https://docs.veryfi.com/api/receipts-invoices/split-and-process-a-pdf/)
