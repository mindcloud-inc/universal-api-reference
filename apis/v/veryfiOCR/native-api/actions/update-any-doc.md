# Update AnyDoc with Veryfi OCR

Updates an AnyDoc in Veryfi OCR.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/any-documents/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Update AnyDoc](https://docs.veryfi.com/api/anydocs/update-a-A-doc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
