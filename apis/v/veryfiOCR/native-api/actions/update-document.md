# Update Document with Veryfi OCR

Updates a document in Veryfi OCR.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/documents/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Update Document](https://docs.veryfi.com/api/receipts-invoices/update-a-document/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
