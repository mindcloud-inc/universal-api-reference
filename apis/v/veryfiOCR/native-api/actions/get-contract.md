# Get Contract with Veryfi OCR

Retrieves a contract from Veryfi OCR.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/contracts/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Get Contract](https://docs.veryfi.com/api/contracts/get-a-contract/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
