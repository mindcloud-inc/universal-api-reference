# Delete Bank Statement with Veryfi OCR

Deletes a bank statement from Veryfi OCR.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/bank-statements/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Delete Bank Statement](https://docs.veryfi.com/api/bank-statements/delete-a-bank-statement/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
