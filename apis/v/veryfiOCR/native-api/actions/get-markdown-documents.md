# Get Markdown Documents with Veryfi OCR

Retrieves markdown documents from Veryfi OCR.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/document-to-markdown`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Get Markdown Documents](https://docs.veryfi.com/api/document-to-markdown/get-markdown-documents/)
