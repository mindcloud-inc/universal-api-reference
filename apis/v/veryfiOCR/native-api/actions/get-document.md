# Get Document with Veryfi OCR

Retrieves a document from Veryfi OCR.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/documents/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Get Document](https://docs.veryfi.com/api/receipts-invoices/get-a-document/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The Veryfi document identifier. |
