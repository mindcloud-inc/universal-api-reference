# Get Bank Statements with Veryfi OCR

Retrieves bank statements from Veryfi OCR.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/bank-statements`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Get Bank Statements](https://docs.veryfi.com/api/bank-statements/get-bank-statements/)
