# Update W-2 with Veryfi OCR

Updates a W-2 in Veryfi OCR.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/w2s/:document_id`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Update W-2](https://docs.veryfi.com/api/w2s/update-a-w-2/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | Path parameter document_id. |
