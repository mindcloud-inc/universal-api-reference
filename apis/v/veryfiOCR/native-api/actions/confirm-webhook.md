# Confirm Webhook with Veryfi OCR

Confirms a webhook in Veryfi OCR.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v8/partner/settings/webhooks/confirm`
- **Base URL:** `https://api.veryfi.com/`
- **Official documentation:** [Confirm Webhook](https://docs.veryfi.com/api/settings/confirm-a-webhook/)
