# Get Supplier with Ventrata

Retrieves a supplier from Ventrata.

## Endpoint

- **Method:** `GET`
- **Path:** `octo/suppliers/:supplierId`
- **Base URL:** `https://api.ventrata.com`
- **Official documentation:** [Get Supplier](https://docs.ventrata.com/octo-core/suppliers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `supplierId` | path | `string` | yes | Supplier identifier from Ventrata. |
