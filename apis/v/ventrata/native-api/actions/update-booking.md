# Update Booking with Ventrata

Updates an existing booking in Ventrata.

## Endpoint

- **Method:** `PATCH`
- **Path:** `octo/bookings/:uuid`
- **Base URL:** `https://api.ventrata.com`
- **Official documentation:** [Update Booking](https://docs.ventrata.com/octo-core/bookings#patch-bookings-uuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Booking UUID from Ventrata. |
