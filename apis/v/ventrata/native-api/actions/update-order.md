# Update Order with Ventrata

Updates an existing order in Ventrata.

## Endpoint

- **Method:** `PATCH`
- **Path:** `octo/orders/:orderId`
- **Base URL:** `https://api.ventrata.com`
- **Official documentation:** [Update Order](https://docs.ventrata.com/capabilities/cart#patch-orders-orderid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderId` | path | `string` | yes | Order identifier from Ventrata. |
