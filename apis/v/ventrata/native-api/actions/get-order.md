# Get Order with Ventrata

Retrieves an order from Ventrata.

## Endpoint

- **Method:** `GET`
- **Path:** `octo/orders/:orderId`
- **Base URL:** `https://api.ventrata.com`
- **Official documentation:** [Get Order](https://docs.ventrata.com/capabilities/cart#get-orders-orderid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderId` | path | `string` | yes | Order identifier from Ventrata. |
