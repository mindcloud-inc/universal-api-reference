# Delete Order with Ventrata

Deletes an existing order from Ventrata.

## Endpoint

- **Method:** `DELETE`
- **Path:** `octo/orders/:orderId`
- **Base URL:** `https://api.ventrata.com`
- **Official documentation:** [Delete Order](https://docs.ventrata.com/capabilities/cart#delete-orders-orderid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderId` | path | `string` | yes | Order identifier from Ventrata. |
