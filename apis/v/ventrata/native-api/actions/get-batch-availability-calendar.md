# Get Batch Availability Calendar with Ventrata

Retrieves batch availability calendar data from Ventrata.

## Endpoint

- **Method:** `POST`
- **Path:** `octo/availability/calendar/batch`
- **Base URL:** `https://api.ventrata.com`
- **Official documentation:** [Get Batch Availability Calendar](https://docs.ventrata.com/octo-core/availability#post-availability-calendar-batch)
