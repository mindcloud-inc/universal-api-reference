# Preview Booking Update with Ventrata

Previews an existing booking update in Ventrata.

## Endpoint

- **Method:** `PATCH`
- **Path:** `octo/bookings/:uuid/preview`
- **Base URL:** `https://api.ventrata.com`
- **Official documentation:** [Preview Booking Update](https://docs.ventrata.com/octo-core/bookings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Booking UUID from Ventrata. |
