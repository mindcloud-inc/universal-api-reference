# Get Booking with Ventrata

Retrieves a booking from Ventrata.

## Endpoint

- **Method:** `GET`
- **Path:** `octo/bookings/:uuid`
- **Base URL:** `https://api.ventrata.com`
- **Official documentation:** [Get Booking](https://docs.ventrata.com/octo-core/bookings#get-bookings-uuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Booking UUID from Ventrata. |
