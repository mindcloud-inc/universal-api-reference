# Get Product with Ventrata

Retrieves a product from Ventrata.

## Endpoint

- **Method:** `GET`
- **Path:** `octo/products/:productId`
- **Base URL:** `https://api.ventrata.com`
- **Official documentation:** [Get Product](https://docs.ventrata.com/octo-core/products#get-products-productid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | yes | Product identifier from Ventrata. |
