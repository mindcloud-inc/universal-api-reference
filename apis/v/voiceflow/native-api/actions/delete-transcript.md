# Delete Transcript with Voiceflow

Deletes an existing transcript from Voiceflow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://analytics-api.voiceflow.com/v1/transcript/:transcriptId`
- **Base URL:** `https://general-runtime.voiceflow.com`
- **Official documentation:** [Delete Transcript](https://docs.voiceflow.com/api-reference/transcript/delete-transcript)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transcriptId` | path | `string` | yes | ID of the transcript to target. |
