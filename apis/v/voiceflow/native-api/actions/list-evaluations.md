# List Evaluations with Voiceflow

Retrieves all transcript evaluations from Voiceflow.

## Endpoint

- **Method:** `GET`
- **Path:** `https://analytics-api.voiceflow.com/v1/transcript-evaluation/project/:projectId`
- **Base URL:** `https://general-runtime.voiceflow.com`
- **Official documentation:** [List Evaluations](https://docs.voiceflow.com/api-reference/transcript-evaluation/get-all-evaluations)
