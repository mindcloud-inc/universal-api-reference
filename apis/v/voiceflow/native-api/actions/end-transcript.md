# End Transcript with Voiceflow

Marks a Voiceflow transcript as complete.

## Endpoint

- **Method:** `POST`
- **Path:** `https://analytics-api.voiceflow.com/v1/transcript/:transcriptId/project/:projectId/end`
- **Base URL:** `https://general-runtime.voiceflow.com`
- **Official documentation:** [End Transcript](https://docs.voiceflow.com/api-reference/transcript/end-transcript)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transcriptId` | path | `string` | yes | ID of the transcript to target. |
