# Delete Document with Voiceflow

Deletes a knowledge base document from Voiceflow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://realtime-api.voiceflow.com/v1alpha1/public/knowledge-base/document/:documentId`
- **Base URL:** `https://general-runtime.voiceflow.com`
- **Official documentation:** [Delete Document](https://docs.voiceflow.com/api-reference/kbpublicapidocument/delete-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | ID of the document to delete. |
