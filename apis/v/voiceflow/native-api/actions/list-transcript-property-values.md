# List Transcript Property Values with Voiceflow

Retrieves transcript property values from Voiceflow.

## Endpoint

- **Method:** `GET`
- **Path:** `https://analytics-api.voiceflow.com/v1/transcript-property-value/transcript/:transcriptId`
- **Base URL:** `https://general-runtime.voiceflow.com`
- **Official documentation:** [List Transcript Property Values](https://docs.voiceflow.com/api-reference/transcript-property-value/get-all-transcript-property-values)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transcriptId` | path | `string` | yes | ID of the transcript to target. |
