# Get Transcript Property with Voiceflow

Retrieves a transcript property from Voiceflow.

## Endpoint

- **Method:** `GET`
- **Path:** `https://analytics-api.voiceflow.com/v1/transcript-property/:propertyId`
- **Base URL:** `https://general-runtime.voiceflow.com`
- **Official documentation:** [Get Transcript Property](https://docs.voiceflow.com/api-reference/transcript-property/get-transcript-property)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | path | `string` | yes | ID of the property to target. |
