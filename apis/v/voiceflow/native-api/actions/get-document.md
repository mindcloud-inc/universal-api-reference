# Get Document with Voiceflow

Retrieves a knowledge base document from Voiceflow.

## Endpoint

- **Method:** `GET`
- **Path:** `https://realtime-api.voiceflow.com/v1alpha1/public/knowledge-base/document/:documentId`
- **Base URL:** `https://general-runtime.voiceflow.com`
- **Official documentation:** [Get Document](https://docs.voiceflow.com/api-reference/kbpublicapidocument/get-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | ID of the document to fetch. |
