# Get Transcript Evaluation with Voiceflow

Retrieves a transcript evaluation from Voiceflow.

## Endpoint

- **Method:** `GET`
- **Path:** `https://analytics-api.voiceflow.com/v1/transcript-evaluation/:evaluationId`
- **Base URL:** `https://general-runtime.voiceflow.com`
- **Official documentation:** [Get Transcript Evaluation](https://docs.voiceflow.com/api-reference/transcript-evaluation/get-transcript-evaluation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `evaluationId` | path | `string` | yes | ID of the transcript evaluation to target. |
