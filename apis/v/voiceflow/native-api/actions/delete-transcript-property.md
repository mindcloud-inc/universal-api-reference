# Delete Transcript Property with Voiceflow

Deletes an existing transcript property from Voiceflow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://analytics-api.voiceflow.com/v1/transcript-property/:propertyId`
- **Base URL:** `https://general-runtime.voiceflow.com`
- **Official documentation:** [Delete Transcript Property](https://docs.voiceflow.com/api-reference/transcript-property/delete-transcript-property)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | path | `string` | yes | ID of the transcript property to target. |
