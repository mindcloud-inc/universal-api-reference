# List Contacts with VSCO Workspace

Retrieves contacts from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/address-book`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [List Contacts](https://workspace.vsco.co/api/#operation/listResourceAddressBook)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
