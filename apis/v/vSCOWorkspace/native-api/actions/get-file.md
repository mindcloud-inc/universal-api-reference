# Get File with VSCO Workspace

Retrieves a file from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/file/:id`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [Get File](https://workspace.vsco.co/api/#operation/getResourceFile)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
