# Get Gallery with VSCO Workspace

Retrieves a gallery from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/gallery/:id`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [Get Gallery](https://workspace.vsco.co/api/#operation/getResourceGallery)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
