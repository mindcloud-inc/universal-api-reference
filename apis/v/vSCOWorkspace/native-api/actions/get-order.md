# Get Order with VSCO Workspace

Retrieves an order from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/order/:id`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [Get Order](https://workspace.vsco.co/api/#operation/getResourceOrder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
