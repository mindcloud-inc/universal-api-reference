# List Orders with VSCO Workspace

Retrieves orders from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/order`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [List Orders](https://workspace.vsco.co/api/#operation/listResourceOrder)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
