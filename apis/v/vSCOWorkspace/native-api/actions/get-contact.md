# Get Contact with VSCO Workspace

Retrieves a contact from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/address-book/:id`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [Get Contact](https://workspace.vsco.co/api/#operation/getResourceAddressBook)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
