# List Events with VSCO Workspace

Retrieves events from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/event`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [List Events](https://workspace.vsco.co/api/#operation/listResourceEvent)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
