# List Payments with VSCO Workspace

Retrieves payments from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [List Payments](https://workspace.vsco.co/api/#operation/listResourcePayment)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
