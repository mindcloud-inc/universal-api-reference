# List Jobs with VSCO Workspace

Retrieves jobs from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/job`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [List Jobs](https://workspace.vsco.co/api/#operation/listResourceJob)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
