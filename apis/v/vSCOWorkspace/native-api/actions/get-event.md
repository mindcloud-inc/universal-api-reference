# Get Event with VSCO Workspace

Retrieves an event from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/event/:id`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [Get Event](https://workspace.vsco.co/api/#operation/getResourceEvent)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
