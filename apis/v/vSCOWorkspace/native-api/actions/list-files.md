# List Files with VSCO Workspace

Retrieves files from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/file`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [List Files](https://workspace.vsco.co/api/#operation/listResourceFile)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
