# List Galleries with VSCO Workspace

Retrieves galleries from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/gallery`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [List Galleries](https://workspace.vsco.co/api/#operation/listResourceGallery)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
