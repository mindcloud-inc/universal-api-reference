# Get Job with VSCO Workspace

Retrieves a job from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/job/:id`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [Get Job](https://workspace.vsco.co/api/#operation/getResourceJob)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
