# Get Payment with VSCO Workspace

Retrieves a payment from VSCO Workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment/:id`
- **Base URL:** `https://workspace.vsco.co/api/v2`
- **Official documentation:** [Get Payment](https://workspace.vsco.co/api/#operation/getResourcePayment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
