# Get DeepResearch Task Status with Valyu

## Endpoint

- **Method:** `GET`
- **Path:** `/deepresearch/tasks/:id/status`
- **Base URL:** `https://api.valyu.ai/v1`
- **Official documentation:** [Get DeepResearch Task Status](https://docs.valyu.ai/api-reference/endpoint/deepresearch-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The DeepResearch task ID. |
