# Get Contents Job Status with Valyu

## Endpoint

- **Method:** `GET`
- **Path:** `/contents/jobs/:job_id`
- **Base URL:** `https://api.valyu.ai/v1`
- **Official documentation:** [Get Contents Job Status](https://docs.valyu.ai/guides/content-extraction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | The contents job ID. |
