# List Datasources with Valyu

## Endpoint

- **Method:** `GET`
- **Path:** `/datasources`
- **Base URL:** `https://api.valyu.ai/v1`
- **Official documentation:** [List Datasources](https://docs.valyu.ai/api-reference/endpoint/datasources-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | query | `string` | no | Filter datasources by category. |
