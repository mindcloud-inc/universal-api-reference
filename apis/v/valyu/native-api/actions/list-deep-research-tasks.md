# List DeepResearch Tasks with Valyu

## Endpoint

- **Method:** `GET`
- **Path:** `/deepresearch/list`
- **Base URL:** `https://api.valyu.ai/v1`
- **Official documentation:** [List DeepResearch Tasks](https://docs.valyu.ai/api-reference/endpoint/deepresearch-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of tasks to return. |
