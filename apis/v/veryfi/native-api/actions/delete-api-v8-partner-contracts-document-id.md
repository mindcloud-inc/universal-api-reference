# Delete a Contract with Veryfi

Deletes a contract from Veryfi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/contracts/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Delete a Contract](https://docs.veryfi.com/api/contracts/delete-a-contract/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
