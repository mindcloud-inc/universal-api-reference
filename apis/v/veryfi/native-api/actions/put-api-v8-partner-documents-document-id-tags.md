# Add a Tag to a Document with Veryfi

Adds a tag to a document in Veryfi.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/documents/:document_id/tags`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Add a Tag to a Document](https://docs.veryfi.com/api/receipts-invoices/add-a-tag-to-a-document/)
