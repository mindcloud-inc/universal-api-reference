# Delete a Bank Statement with Veryfi

Deletes a bank statement from Veryfi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/bank-statements/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Delete a Bank Statement](https://docs.veryfi.com/api/bank-statements/delete-a-bank-statement/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
