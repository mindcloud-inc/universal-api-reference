# Process a Tls Certificate with Veryfi

Uploads a TLS certificate to Veryfi.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v8/partner/settings/tls-certificate`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Process a Tls Certificate](https://docs.veryfi.com/api/process-a-tls-certificate/)
