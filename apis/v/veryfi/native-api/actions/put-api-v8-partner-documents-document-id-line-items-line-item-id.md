# Update a Line Item with Veryfi

Updates a line item in a document in Veryfi.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/documents/:document_id/line-items/:line_item_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Update a Line Item](https://docs.veryfi.com/api/receipts-invoices/update-a-line-item/)
