# Get a W-2 set with Veryfi

Retrieves a W-2 set from Veryfi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/w2s-set/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Get a W-2 set](https://docs.veryfi.com/api/get-a-w-2-set/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
