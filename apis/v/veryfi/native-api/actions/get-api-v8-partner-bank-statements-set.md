# Get Bank Statement sets with Veryfi

Retrieves bank statement sets from Veryfi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/bank-statements-set`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Get Bank Statement sets](https://docs.veryfi.com/api/get-bank-statement-sets/)
