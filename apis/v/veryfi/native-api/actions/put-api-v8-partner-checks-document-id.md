# Update a Check with Veryfi

Updates an existing check in Veryfi.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/checks/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Update a Check](https://docs.veryfi.com/api/checks/update-a-check/)
