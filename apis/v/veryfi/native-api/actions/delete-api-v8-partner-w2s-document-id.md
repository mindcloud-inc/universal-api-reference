# Delete a W-2 with Veryfi

Deletes a W-2 from Veryfi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/w2s/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Delete a W-2](https://docs.veryfi.com/api/w2s/delete-a-w-2/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
