# Get Documents from PDF with Veryfi

Retrieves documents from a PDF in Veryfi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/documents-set/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Get Documents from PDF](https://docs.veryfi.com/api/receipts-invoices/get-documents-from-pdf/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
