# Delete all document Line Items with Veryfi

Deletes all line items from a document in Veryfi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/documents/:document_id/line-items`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Delete all document Line Items](https://docs.veryfi.com/api/receipts-invoices/delete-all-document-line-items/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
