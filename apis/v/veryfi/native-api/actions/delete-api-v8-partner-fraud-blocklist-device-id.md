# Remove a device from blocklist with Veryfi

Removes a device from Veryfi's blocklist.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/fraud/blocklist/:device_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Remove a device from blocklist](https://docs.veryfi.com/api/remove-a-device-from-blocklist/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `device_id` | path | `string` | yes |
