# Delete a Document with Veryfi

Deletes a document from Veryfi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/documents/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Delete a Document](https://docs.veryfi.com/api/receipts-invoices/delete-a-document/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
