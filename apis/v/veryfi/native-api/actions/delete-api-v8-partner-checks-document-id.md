# Delete a Check with Veryfi

Deletes a check from Veryfi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/checks/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Delete a Check](https://docs.veryfi.com/api/checks/delete-a-check/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
