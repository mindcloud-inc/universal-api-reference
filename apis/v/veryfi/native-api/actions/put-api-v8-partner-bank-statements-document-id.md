# Update a Bank Statement with Veryfi

Updates an existing bank statement in Veryfi.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/bank-statements/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Update a Bank Statement](https://docs.veryfi.com/api/bank-statements/update-a-bank-statement/)
