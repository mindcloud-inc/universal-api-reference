# Get document Line Items with Veryfi

Retrieves line items from a document in Veryfi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/documents/:document_id/line-items`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Get document Line Items](https://docs.veryfi.com/api/receipts-invoices/get-document-line-items/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
