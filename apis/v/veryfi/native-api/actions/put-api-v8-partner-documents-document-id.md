# Update a Document with Veryfi

Updates an existing document in Veryfi.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/documents/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Update a Document](https://docs.veryfi.com/api/receipts-invoices/update-a-document/)
