# Delete a W-9 with Veryfi

Deletes a W-9 from Veryfi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/w9s/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Delete a W-9](https://docs.veryfi.com/api/w9s/delete-a-w-9/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
