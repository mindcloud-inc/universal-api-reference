# Delete a Markdown Document with Veryfi

Deletes a markdown document from Veryfi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/document-to-markdown/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Delete a Markdown Document](https://docs.veryfi.com/api/document-to-markdown/delete-a-markdown-document/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
