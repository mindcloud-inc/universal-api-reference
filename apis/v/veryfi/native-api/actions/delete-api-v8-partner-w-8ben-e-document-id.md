# Delete a W-8BEN-E with Veryfi

Deletes a W-8BEN-E from Veryfi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/w-8ben-e/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Delete a W-8BEN-E](https://docs.veryfi.com/api/w-8ben-e/delete-a-w-8-ben-e/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
