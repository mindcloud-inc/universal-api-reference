# Get a Markdown Document Set with Veryfi

Retrieves a markdown document set from Veryfi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/document-to-markdown-set/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Get a Markdown Document Set](https://docs.veryfi.com/api/document-to-markdown/get-a-markdown-document-set/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
