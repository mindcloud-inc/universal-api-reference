# Delete a Tls Certificate with Veryfi

Deletes a TLS certificate from Veryfi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v8/partner/settings/tls-certificate/:certificate_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Delete a Tls Certificate](https://docs.veryfi.com/api/delete-a-tls-certificate/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `certificate_id` | path | `string` | yes |
