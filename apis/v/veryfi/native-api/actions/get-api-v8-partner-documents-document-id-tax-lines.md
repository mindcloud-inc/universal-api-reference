# Returns a list of document Tax Lines with Veryfi

Retrieves tax lines from a document in Veryfi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/documents/:document_id/tax-lines`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Returns a list of document Tax Lines](https://docs.veryfi.com/api/returns-a-list-of-document-tax-lines/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
