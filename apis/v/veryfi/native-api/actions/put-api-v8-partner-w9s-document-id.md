# Update a W-9 with Veryfi

Updates an existing W-9 in Veryfi.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v8/partner/w9s/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Update a W-9](https://docs.veryfi.com/api/w9s/update-a-w-9/)
