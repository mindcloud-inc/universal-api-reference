# Get Document Tags with Veryfi

Retrieves tags from a document in Veryfi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/documents/:document_id/tags`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Get Document Tags](https://docs.veryfi.com/api/receipts-invoices/get-document-tags/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
