# Process a Markdown Document Set with Veryfi

Creates markdown documents by splitting files in Veryfi.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v8/partner/document-to-markdown-set`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Process a Markdown Document Set](https://docs.veryfi.com/api/document-to-markdown/process-a-markdown-document-set/)
