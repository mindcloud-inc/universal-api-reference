# Get Markdown Document Sets with Veryfi

Retrieves markdown document sets from Veryfi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/document-to-markdown-set`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Get Markdown Document Sets](https://docs.veryfi.com/api/document-to-markdown/get-markdown-document-sets/)
