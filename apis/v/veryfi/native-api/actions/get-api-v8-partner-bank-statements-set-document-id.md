# Get a Bank Statement set with Veryfi

Retrieves a bank statement set from Veryfi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/bank-statements-set/:document_id`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Get a Bank Statement set](https://docs.veryfi.com/api/get-a-bank-statement-set/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
