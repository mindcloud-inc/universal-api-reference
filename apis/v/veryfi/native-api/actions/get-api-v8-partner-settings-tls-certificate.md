# Get Tls Certificates with Veryfi

Retrieves TLS certificates from Veryfi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v8/partner/settings/tls-certificate`
- **Base URL:** `https://api.veryfi.com`
- **Official documentation:** [Get Tls Certificates](https://docs.veryfi.com/api/get-tls-certificates/)
