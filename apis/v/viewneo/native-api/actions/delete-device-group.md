# Delete Device Group with Viewneo

Deletes an existing device group from Viewneo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/devicegroup/:id`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [Delete Device Group](https://cloud.viewneo.com/doc/api#/DeviceGroup/api.deviceGroup.delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | — |
| `id` | path | `number` | yes | ID of deviceGroup |
