# Delete Playlist with Viewneo

Deletes an existing playlist from Viewneo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/playlist/:id`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [Delete Playlist](https://cloud.viewneo.com/doc/api#/Playlist/api.playlist.delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
