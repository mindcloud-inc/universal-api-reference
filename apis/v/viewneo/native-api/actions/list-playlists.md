# List Playlists with Viewneo

Retrieves playlists for the current account in Viewneo.

## Endpoint

- **Method:** `GET`
- **Path:** `/playlist`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [List Playlists](https://cloud.viewneo.com/doc/api#/Playlist/api.playlist.index)
