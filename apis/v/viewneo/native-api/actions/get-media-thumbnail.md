# Get Media Thumbnail with Viewneo

Retrieves a media thumbnail from Viewneo.

## Endpoint

- **Method:** `GET`
- **Path:** `/mediafile/:id/thumbnail`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [Get Media Thumbnail](https://cloud.viewneo.com/doc/api#/MediaFile/api.mediaFile.thumbnail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of mediaFile |
