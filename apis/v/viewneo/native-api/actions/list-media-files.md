# List Media Files with Viewneo

Retrieves media files and folders from Viewneo.

## Endpoint

- **Method:** `GET`
- **Path:** `/mediafile`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [List Media Files](https://cloud.viewneo.com/doc/api#/MediaFile/api.mediaFile.index)
