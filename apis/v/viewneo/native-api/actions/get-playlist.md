# Get Playlist with Viewneo

Retrieves a specific playlist from Viewneo.

## Endpoint

- **Method:** `GET`
- **Path:** `/playlist/:id`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [Get Playlist](https://cloud.viewneo.com/doc/api#/Playlist/api.playlist.show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
