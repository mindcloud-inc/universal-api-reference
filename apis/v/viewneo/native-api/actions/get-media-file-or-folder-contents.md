# Get Media File or Folder Contents with Viewneo

Retrieves a media file or folder contents from Viewneo.

## Endpoint

- **Method:** `GET`
- **Path:** `/mediafile/:id`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [Get Media File or Folder Contents](https://cloud.viewneo.com/doc/api#/MediaFile/api.mediaFile.show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of mediaFile |
