# List Device Groups with Viewneo

Retrieves all device groups from Viewneo.

## Endpoint

- **Method:** `GET`
- **Path:** `/devicegroup`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [List Device Groups](https://cloud.viewneo.com/doc/api#/DeviceGroup/api.deviceGroup.index)
