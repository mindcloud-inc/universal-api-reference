# Create Device Group with Viewneo

Creates a new device group in Viewneo.

## Endpoint

- **Method:** `POST`
- **Path:** `/devicegroup`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [Create Device Group](https://cloud.viewneo.com/doc/api#/DeviceGroup/api.deviceGroup.store)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
