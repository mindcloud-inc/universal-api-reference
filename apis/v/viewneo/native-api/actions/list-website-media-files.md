# List Website Media Files with Viewneo

Retrieves website media files from Viewneo.

## Endpoint

- **Method:** `GET`
- **Path:** `/mediafile/websites`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [List Website Media Files](https://cloud.viewneo.com/doc/api#/MediaFile/api.mediaFile.getAllWebsiteMediaFiles)
