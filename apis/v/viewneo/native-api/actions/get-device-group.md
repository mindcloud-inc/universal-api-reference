# Get Device Group with Viewneo

Retrieves a device group from Viewneo.

## Endpoint

- **Method:** `GET`
- **Path:** `/devicegroup/:id`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [Get Device Group](https://cloud.viewneo.com/doc/api#/DeviceGroup/api.deviceGroup.show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
