# Check Website Embeddability with Viewneo

Checks website embeddability for a media file in Viewneo.

## Endpoint

- **Method:** `GET`
- **Path:** `/mediafile/:id/check-x-frame-options`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [Check Website Embeddability](https://cloud.viewneo.com/doc/api#/MediaFile/api.mediaFile.check-x-frame-options)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
