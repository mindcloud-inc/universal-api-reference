# List Devices For Analytics with Viewneo

Retrieves devices for analytics from Viewneo.

## Endpoint

- **Method:** `GET`
- **Path:** `/devices-for-analytics`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [List Devices For Analytics](https://cloud.viewneo.com/doc/api#/Device/api.device.getDevicesForAnalytics)
