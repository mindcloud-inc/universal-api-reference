# Create Playlist with Viewneo

Creates a new playlist in Viewneo.

## Endpoint

- **Method:** `POST`
- **Path:** `/playlist`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [Create Playlist](https://cloud.viewneo.com/doc/api#/Playlist/api.playlist.store)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
