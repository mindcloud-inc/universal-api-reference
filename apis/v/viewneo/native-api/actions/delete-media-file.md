# Delete Media File with Viewneo

Deletes an existing media file from Viewneo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/mediafile/:id`
- **Base URL:** `https://cloud.viewneo.com/api/v1.0`
- **Official documentation:** [Delete Media File](https://cloud.viewneo.com/doc/api#/MediaFile/api.mediaFile.delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
