# Append JSON Document with Vaiz

Appends JSON content to an existing document in Vaiz.

## Endpoint

- **Method:** `POST`
- **Path:** `appendJSONDocument`
- **Base URL:** `https://api.vaiz.com/v4`
- **Official documentation:** [Append JSON Document](https://docs-python-sdk.vaiz.com/api-reference/document-structure)
