# Subscribe to Vybit with Vybit

## Endpoint

- **Method:** `POST`
- **Path:** `/subscription/{{key}}`
- **Base URL:** `https://api.vybit.net/v1`
- **Official documentation:** [Subscribe to Vybit](https://developer.vybit.net/api-reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | no | The subscription key for the public vybit. |
