# Delete Vybit with Vybit

## Endpoint

- **Method:** `DELETE`
- **Path:** `/vybit/{{key}}`
- **Base URL:** `https://api.vybit.net/v1`
- **Official documentation:** [Delete Vybit](https://developer.vybit.net/api-reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | no | The unique key of the vybit. |
