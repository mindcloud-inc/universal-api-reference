# Get Sound Details with Vybit

## Endpoint

- **Method:** `GET`
- **Path:** `/sound/{{key}}`
- **Base URL:** `https://api.vybit.net/v1`
- **Official documentation:** [Get Sound Details](https://developer.vybit.net/api-reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | The unique key of the sound. |
