# Get Public Vybit by Subscription Key with Vybit

## Endpoint

- **Method:** `GET`
- **Path:** `/subscription/{{key}}`
- **Base URL:** `https://api.vybit.net/v1`
- **Official documentation:** [Get Public Vybit by Subscription Key](https://developer.vybit.net/api-reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | The subscription key for the public vybit. |
