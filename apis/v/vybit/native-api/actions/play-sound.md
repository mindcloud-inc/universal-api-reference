# Play Sound with Vybit

## Endpoint

- **Method:** `GET`
- **Path:** `/sound/{{key}}/play`
- **Base URL:** `https://api.vybit.net/v1`
- **Official documentation:** [Play Sound](https://developer.vybit.net/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | The unique sound key to stream or download. |
