# Unsubscribe from Vybit with Vybit

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscription/following/{{key}}`
- **Base URL:** `https://api.vybit.net/v1`
- **Official documentation:** [Unsubscribe from Vybit](https://developer.vybit.net/api-reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | no | The unique key of the subscription following record. |
