# List Reminders with Vybit

## Endpoint

- **Method:** `GET`
- **Path:** `/vybit/{{key}}/reminders`
- **Base URL:** `https://api.vybit.net/v1`
- **Official documentation:** [List Reminders](https://developer.vybit.net/api-reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | The unique key of the vybit. |
