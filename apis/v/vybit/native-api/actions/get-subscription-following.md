# Get Subscription Following with Vybit

## Endpoint

- **Method:** `GET`
- **Path:** `/subscription/following/{{key}}`
- **Base URL:** `https://api.vybit.net/v1`
- **Official documentation:** [Get Subscription Following](https://developer.vybit.net/api-reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | The unique key of the subscription following record. |
