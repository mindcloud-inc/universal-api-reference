# Get Peep with Vybit

## Endpoint

- **Method:** `GET`
- **Path:** `/peep/{{key}}`
- **Base URL:** `https://api.vybit.net/v1`
- **Official documentation:** [Get Peep](https://developer.vybit.net/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | The unique key of the peep to retrieve. |
