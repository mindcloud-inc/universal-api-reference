# List Vybit Subscriptions with Vybit

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions/following`
- **Base URL:** `https://api.vybit.net/v1`
- **Official documentation:** [List Vybit Subscriptions](https://developer.vybit.net/api-reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of records to return |
| `offset` | query | `number` | no | Number of records to skip for pagination |
| `search` | query | `string` | no | Text search query |
