# Get Log Entry with Vybit

## Endpoint

- **Method:** `GET`
- **Path:** `/log/{{logKey}}`
- **Base URL:** `https://api.vybit.net/v1`
- **Official documentation:** [Get Log Entry](https://developer.vybit.net/api-reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `logKey` | path | `string` | yes | The unique key of the log entry. |
