# Create Project with Vooplayer

Creates a new project in Vooplayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://api.spotlightr.com`
- **Official documentation:** [Create Project](https://app.spotlightr.com/docs/api/#groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the project. |
