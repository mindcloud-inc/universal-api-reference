# Add Whitelisted Domain with Vooplayer

Creates a whitelisted domain in Vooplayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/user/domain`
- **Base URL:** `https://api.spotlightr.com`
- **Official documentation:** [Add Whitelisted Domain](https://app.spotlightr.com/docs/api/#addDomain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | yes | Desired domain, for example example.com. |
