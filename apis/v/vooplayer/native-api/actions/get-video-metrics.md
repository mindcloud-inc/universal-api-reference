# Get Video Metrics with Vooplayer

Retrieves video analytics data from Vooplayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/video/metrics`
- **Base URL:** `https://api.spotlightr.com`
- **Official documentation:** [Get Video Metrics](https://app.spotlightr.com/docs/api/#metrics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videoID` | query | `number` | yes | Video ID. |
