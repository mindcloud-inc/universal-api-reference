# List Equipment Items with Universal API

Retrieves equipment items from Universal API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/am/equipment-items`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [List Equipment Items](https://docs.universalapi.io/reference/list-equipment-items)

## Capabilities

This operation supports [pagination](../README.md#pagination).
