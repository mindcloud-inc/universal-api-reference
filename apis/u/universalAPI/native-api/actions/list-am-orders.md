# List AM Orders with Universal API

Retrieves asset management orders from Universal API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/am/orders`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [List AM Orders](https://docs.universalapi.io/reference/list-orders)

## Capabilities

This operation supports [pagination](../README.md#pagination).
