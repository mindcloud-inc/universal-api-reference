# Get Consumer with Universal API

Retrieves a consumer from Universal API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/consumers/{id}`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [Get Consumer](https://docs.universalapi.io/reference/consumer-model)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Consumer ID. |
