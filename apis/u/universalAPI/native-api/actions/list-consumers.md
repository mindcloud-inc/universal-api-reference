# List Consumers with Universal API

Retrieves a list of consumers from Universal API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/consumers`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [List Consumers](https://docs.universalapi.io/reference/get-consumer)

## Capabilities

This operation supports [pagination](../README.md#pagination).
