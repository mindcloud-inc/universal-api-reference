# Get Product with Universal API

Retrieves a product from Universal API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/distributors/products/{id}`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [Get Product](https://docs.universalapi.io/reference/get-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Product ID. |
