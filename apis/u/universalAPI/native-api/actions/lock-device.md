# Lock Device with Universal API

Locks an existing device in Universal API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/mdm/devices/{id}/lock`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [Lock Device](https://docs.universalapi.io/reference/lock-device)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Device ID. |
