# Create Distributor Order with Universal API

Creates a new distributor order in Universal API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/distributors/orders`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [Create Distributor Order](https://docs.universalapi.io/reference/create-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Distributor order payload. |
