# Delete Webhook with Universal API

Deletes an existing webhook from Universal API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/webhooks/{id}`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [Delete Webhook](https://docs.universalapi.io/reference/delete-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook ID. |
