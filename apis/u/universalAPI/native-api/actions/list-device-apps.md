# List Device Apps with Universal API

Retrieves apps for a device from Universal API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/mdm/devices/{id}/apps`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [List Device Apps](https://docs.universalapi.io/reference/list-device-apps)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Device ID. |
