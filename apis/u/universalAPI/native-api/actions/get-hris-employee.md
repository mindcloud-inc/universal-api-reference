# Get HRIS Employee with Universal API

Retrieves an HRIS employee from Universal API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/hris/employees/{id}`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [Get HRIS Employee](https://docs.universalapi.io/reference/get-employee)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Employee ID. |
