# Create Consumer with Universal API

Creates a new consumer in Universal API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/consumers`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [Create Consumer](https://docs.universalapi.io/reference/create-consumer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Consumer name. |
