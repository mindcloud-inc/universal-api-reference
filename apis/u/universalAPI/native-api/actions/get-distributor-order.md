# Get Distributor Order with Universal API

Retrieves a distributor order from Universal API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/distributors/orders/{id}`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [Get Distributor Order](https://docs.universalapi.io/reference/get-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Order ID. |
