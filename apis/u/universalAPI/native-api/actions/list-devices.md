# List Devices with Universal API

Retrieves a list of devices from Universal API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/mdm/devices`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [List Devices](https://docs.universalapi.io/reference/list-devices)

## Capabilities

This operation supports [pagination](../README.md#pagination).
