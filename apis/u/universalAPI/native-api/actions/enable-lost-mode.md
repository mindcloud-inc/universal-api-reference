# Enable Lost Mode with Universal API

Enables lost mode for a device in Universal API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/mdm/devices/{id}/lost-mode/enable`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [Enable Lost Mode](https://docs.universalapi.io/reference/enable-lost-mode)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Device ID. |
