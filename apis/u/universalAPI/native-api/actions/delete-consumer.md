# Delete Consumer with Universal API

Deletes an existing consumer from Universal API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/consumers/{id}`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [Delete Consumer](https://docs.universalapi.io/reference/delete-consumer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Consumer ID. |
