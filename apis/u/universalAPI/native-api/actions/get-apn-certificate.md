# Get APN Certificate with Universal API

Retrieves an APN certificate from Universal API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/mdm/apn-cert`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [Get APN Certificate](https://docs.universalapi.io/reference/get-apn-cert)
