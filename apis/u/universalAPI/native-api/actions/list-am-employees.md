# List AM Employees with Universal API

Retrieves asset management employees from Universal API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/am/employees`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [List AM Employees](https://docs.universalapi.io/reference/list-employees-1)

## Capabilities

This operation supports [pagination](../README.md#pagination).
