# List HRIS Employees with Universal API

Retrieves HRIS employees from Universal API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/hris/employees`
- **Base URL:** `https://api.prod.universalapi.io`
- **Official documentation:** [List HRIS Employees](https://docs.universalapi.io/reference/list-employees)

## Capabilities

This operation supports [pagination](../README.md#pagination).
