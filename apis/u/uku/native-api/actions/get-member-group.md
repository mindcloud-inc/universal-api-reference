# Get Member Group with Uku

Retrieves a member group from Uku.

## Endpoint

- **Method:** `GET`
- **Path:** `/member_groups/:memberGroupId`
- **Base URL:** `https://app.getuku.com/api/v1.0`
- **Official documentation:** [Get Member Group](https://app.getuku.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `member_group_id` | path | `string` | yes | Uku member group ID |
