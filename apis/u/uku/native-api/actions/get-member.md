# Get Member with Uku

Retrieves a member from Uku.

## Endpoint

- **Method:** `GET`
- **Path:** `/members/:memberId`
- **Base URL:** `https://app.getuku.com/api/v1.0`
- **Official documentation:** [Get Member](https://app.getuku.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `member_id` | path | `string` | yes | Uku member ID |
