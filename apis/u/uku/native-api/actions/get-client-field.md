# Get Client Field with Uku

Retrieves a client field from Uku.

## Endpoint

- **Method:** `GET`
- **Path:** `/client_fields/:clientFieldId`
- **Base URL:** `https://app.getuku.com/api/v1.0`
- **Official documentation:** [Get Client Field](https://app.getuku.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_field_id` | path | `string` | yes | Uku client field ID |
