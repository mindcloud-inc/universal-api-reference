# Get Client Group with Uku

Retrieves a client group from Uku.

## Endpoint

- **Method:** `GET`
- **Path:** `/client_groups/:clientGroupId`
- **Base URL:** `https://app.getuku.com/api/v1.0`
- **Official documentation:** [Get Client Group](https://app.getuku.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_group_id` | path | `string` | yes | Uku client group ID |
