# Get Client with Uku

Retrieves a client from Uku.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:clientId`
- **Base URL:** `https://app.getuku.com/api/v1.0`
- **Official documentation:** [Get Client](https://app.getuku.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `string` | yes | Uku client ID |
