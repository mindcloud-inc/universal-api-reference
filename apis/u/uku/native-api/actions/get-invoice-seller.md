# Get Invoice Seller with Uku

Retrieves an invoice seller from Uku.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoice_sellers/:invoiceSellerId`
- **Base URL:** `https://app.getuku.com/api/v1.0`
- **Official documentation:** [Get Invoice Seller](https://app.getuku.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_seller_id` | path | `string` | yes | Uku invoice seller ID |
