# Get Topic with Uku

Retrieves a topic from Uku.

## Endpoint

- **Method:** `GET`
- **Path:** `/topics/:topicId`
- **Base URL:** `https://app.getuku.com/api/v1.0`
- **Official documentation:** [Get Topic](https://app.getuku.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `topic_id` | path | `string` | yes | Uku topic ID |
