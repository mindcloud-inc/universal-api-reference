# Delete File with Upload to URL

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/file/:file_id`
- **Base URL:** `https://uploadtourl.com`
- **Official documentation:** [Delete File](https://uploadtourl.com/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | The unique identifier of the file to delete. |
