# Get File Information with Upload to URL

## Endpoint

- **Method:** `GET`
- **Path:** `/api/file/:file_id`
- **Base URL:** `https://uploadtourl.com`
- **Official documentation:** [Get File Information](https://uploadtourl.com/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | The unique identifier of the file. |
