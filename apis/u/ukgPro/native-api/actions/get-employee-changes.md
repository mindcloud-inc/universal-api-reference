# Get Employee Changes with UKG Pro

## Endpoint

- **Method:** `GET`
- **Path:** `personnel/v1/employee-changes/:employeeId`
- **Base URL:** `https://{baseUrl}/`
- **Official documentation:** [Get Employee Changes](https://developer.ukg.com/hcm/reference/employeechanges_get_all)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `employeeId` | path | `string` | no |
| `endDate` | query | `string` | no |
| `startDate` | query | `string` | no |
