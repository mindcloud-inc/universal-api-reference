# Get Platform Configuration Fields with UKG Pro

## Endpoint

- **Method:** `GET`
- **Path:** `personnel/v1/platform-configuration-fields/class-name/:className`
- **Base URL:** `https://{baseUrl}/`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `className` | path | `string` | no | — |
| `fields` | query | `string` | no | Send multiple values as a array. |
