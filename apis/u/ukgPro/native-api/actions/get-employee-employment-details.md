# Get Employee Employment Details with UKG Pro

## Endpoint

- **Method:** `GET`
- **Path:** `personnel/v1/employee-employment-details`
- **Base URL:** `https://{baseUrl}/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `primaryJobCode` | query | `string` | no |
| `payGroup` | query | `string` | no |
| `employeeStatusCode` | query | `string` | no |
| `dateTimeChanged` | query | `string` | no |
| `employeeId` | query | `string` | no |
