# Get Client with Usedesk

Retrieves a client by ID from Usedesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/client`
- **Base URL:** `https://secure.usedesk.com/uapi`
- **Official documentation:** [Get Client](https://api.usedocs.com/article/51384)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | body | `number` | yes | Client ID. |
