# Get Manager with U-ON

Retrieves a manager record from U-ON.

## Endpoint

- **Method:** `GET`
- **Path:** `/manager/{user_id}.json`
- **Base URL:** `https://api.u-on.ru/{key}`
- **Official documentation:** [Get Manager](https://api.u-on.travel/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | user_id path parameter |
