# List Requests by Client with U-ON

Retrieves request records for a U-ON client.

## Endpoint

- **Method:** `GET`
- **Path:** `/request-by-client/{id}/{page}.json`
- **Base URL:** `https://api.u-on.ru/{key}`
- **Official documentation:** [List Requests by Client](https://api.u-on.travel/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | id path parameter |
