# Get Tourist with U-ON

Retrieves a tourist record from U-ON.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/{id}.json`
- **Base URL:** `https://api.u-on.ru/{key}`
- **Official documentation:** [Get Tourist](https://api.u-on.travel/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | id path parameter |
