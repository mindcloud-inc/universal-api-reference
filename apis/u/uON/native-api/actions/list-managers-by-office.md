# List Managers by Office with U-ON

Retrieves manager records for a U-ON office.

## Endpoint

- **Method:** `GET`
- **Path:** `/manager/office/{office_id}.json`
- **Base URL:** `https://api.u-on.ru/{key}`
- **Official documentation:** [List Managers by Office](https://api.u-on.travel/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `office_id` | path | `number` | yes | office_id path parameter |
