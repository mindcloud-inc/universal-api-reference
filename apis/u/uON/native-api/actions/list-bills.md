# List Bills with U-ON

Retrieves bill records stored in U-ON.

## Endpoint

- **Method:** `GET`
- **Path:** `/bills/{page}.json`
- **Base URL:** `https://api.u-on.ru/{key}`
- **Official documentation:** [List Bills](https://api.u-on.travel/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `r_id` | query | `number` | no | ID заявки / Request ID |
