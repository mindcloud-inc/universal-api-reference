# Find Tourist by Phone with U-ON

Finds a tourist in U-ON by phone number.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/phone/{phone}.json`
- **Base URL:** `https://api.u-on.ru/{key}`
- **Official documentation:** [Find Tourist by Phone](https://api.u-on.travel/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phone` | path | `string` | yes | phone path parameter |
