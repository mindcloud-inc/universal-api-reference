# List Managers with U-ON

Retrieves manager records stored in U-ON.

## Endpoint

- **Method:** `GET`
- **Path:** `/manager.json`
- **Base URL:** `https://api.u-on.ru/{key}`
- **Official documentation:** [List Managers](https://api.u-on.travel/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `office_id` | query | `number` | no | ID офиса (см. метод /company-office) / Office ID (see method /company-office) |
