# Get Payment with U-ON

Retrieves a payment record from U-ON.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment/{id}.json`
- **Base URL:** `https://api.u-on.ru/{key}`
- **Official documentation:** [Get Payment](https://api.u-on.travel/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | id path parameter |
