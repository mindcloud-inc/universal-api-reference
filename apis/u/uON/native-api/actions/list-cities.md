# List Cities with U-ON

Retrieves city records for a country in U-ON.

## Endpoint

- **Method:** `GET`
- **Path:** `/cities/{country_id}/{page}.json`
- **Base URL:** `https://api.u-on.ru/{key}`
- **Official documentation:** [List Cities](https://api.u-on.travel/doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `country_id` | path | `number` | yes | country_id path parameter |
