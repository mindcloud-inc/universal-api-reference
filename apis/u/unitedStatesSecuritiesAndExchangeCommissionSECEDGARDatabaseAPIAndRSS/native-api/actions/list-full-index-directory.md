# List Full Index Directory with United States Securities and Exchange Commission (SEC) EDGAR Database

Retrieves the SEC EDGAR full index directory listing.

## Endpoint

- **Method:** `GET`
- **Path:** `/Archives/edgar/full-index/index.json`
- **Base URL:** `https://www.sec.gov`
- **Official documentation:** [List Full Index Directory](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)
