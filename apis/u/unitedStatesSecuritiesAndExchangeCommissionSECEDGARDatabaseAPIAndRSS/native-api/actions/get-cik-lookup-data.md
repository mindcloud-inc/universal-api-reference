# Get CIK Lookup Data with United States Securities and Exchange Commission (SEC) EDGAR Database

Retrieves the EDGAR CIK lookup text file.

## Endpoint

- **Method:** `GET`
- **Path:** `/Archives/edgar/cik-lookup-data.txt`
- **Base URL:** `https://www.sec.gov`
- **Official documentation:** [Get CIK Lookup Data](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)
