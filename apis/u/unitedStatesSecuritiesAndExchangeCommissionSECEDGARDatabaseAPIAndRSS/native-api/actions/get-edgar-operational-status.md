# Get EDGAR Operational Status with United States Securities and Exchange Commission (SEC) EDGAR Database

Retrieves the current EDGAR operational status.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.edgarfiling.sec.gov/status`
- **Base URL:** `https://www.sec.gov`
- **Official documentation:** [Get EDGAR Operational Status](https://api.edgarfiling.sec.gov/openapi.json)
