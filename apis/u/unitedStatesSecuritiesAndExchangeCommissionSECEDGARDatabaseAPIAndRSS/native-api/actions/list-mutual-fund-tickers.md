# List Mutual Fund Tickers with United States Securities and Exchange Commission (SEC) EDGAR Database

Retrieves mutual fund ticker mappings from SEC EDGAR.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/company_tickers_mf.json`
- **Base URL:** `https://www.sec.gov`
- **Official documentation:** [List Mutual Fund Tickers](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)
