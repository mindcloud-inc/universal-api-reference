# List Daily Bulk Data Directory with United States Securities and Exchange Commission (SEC) EDGAR Database

Retrieves the SEC EDGAR bulk data directory listing.

## Endpoint

- **Method:** `GET`
- **Path:** `/Archives/edgar/daily-index/bulkdata/index.json`
- **Base URL:** `https://www.sec.gov`
- **Official documentation:** [List Daily Bulk Data Directory](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)
