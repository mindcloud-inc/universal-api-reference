# Get Current Full XBRL Index with United States Securities and Exchange Commission (SEC) EDGAR Database

Retrieves the current SEC EDGAR full XBRL index.

## Endpoint

- **Method:** `GET`
- **Path:** `/Archives/edgar/full-index/xbrl.idx`
- **Base URL:** `https://www.sec.gov`
- **Official documentation:** [Get Current Full XBRL Index](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)
