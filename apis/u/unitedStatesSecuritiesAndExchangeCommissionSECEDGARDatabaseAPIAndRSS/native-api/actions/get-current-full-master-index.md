# Get Current Full Master Index with United States Securities and Exchange Commission (SEC) EDGAR Database

Retrieves the current SEC EDGAR full master index.

## Endpoint

- **Method:** `GET`
- **Path:** `/Archives/edgar/full-index/master.idx`
- **Base URL:** `https://www.sec.gov`
- **Official documentation:** [Get Current Full Master Index](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)
