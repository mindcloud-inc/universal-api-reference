# List Daily Index Root Directory with United States Securities and Exchange Commission (SEC) EDGAR Database

Retrieves the SEC EDGAR daily index root listing.

## Endpoint

- **Method:** `GET`
- **Path:** `/Archives/edgar/daily-index/index.json`
- **Base URL:** `https://www.sec.gov`
- **Official documentation:** [List Daily Index Root Directory](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)
