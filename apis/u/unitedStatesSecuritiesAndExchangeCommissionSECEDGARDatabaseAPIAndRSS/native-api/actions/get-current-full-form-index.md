# Get Current Full Form Index with United States Securities and Exchange Commission (SEC) EDGAR Database

Retrieves the current SEC EDGAR full form index.

## Endpoint

- **Method:** `GET`
- **Path:** `/Archives/edgar/full-index/form.idx`
- **Base URL:** `https://www.sec.gov`
- **Official documentation:** [Get Current Full Form Index](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)
