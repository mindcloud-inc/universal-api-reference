# Get Current Full Company Index with United States Securities and Exchange Commission (SEC) EDGAR Database

Retrieves the current SEC EDGAR full company index.

## Endpoint

- **Method:** `GET`
- **Path:** `/Archives/edgar/full-index/company.idx`
- **Base URL:** `https://www.sec.gov`
- **Official documentation:** [Get Current Full Company Index](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)
