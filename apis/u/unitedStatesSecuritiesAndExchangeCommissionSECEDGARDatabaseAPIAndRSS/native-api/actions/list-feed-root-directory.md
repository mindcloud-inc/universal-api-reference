# List Feed Root Directory with United States Securities and Exchange Commission (SEC) EDGAR Database

Retrieves the SEC EDGAR feed root directory listing.

## Endpoint

- **Method:** `GET`
- **Path:** `/Archives/edgar/Feed/index.json`
- **Base URL:** `https://www.sec.gov`
- **Official documentation:** [List Feed Root Directory](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)
