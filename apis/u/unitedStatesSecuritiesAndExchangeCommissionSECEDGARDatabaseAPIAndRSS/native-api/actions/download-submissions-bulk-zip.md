# Download Submissions Bulk ZIP with United States Securities and Exchange Commission (SEC) EDGAR Database

Downloads the submissions bulk ZIP from SEC EDGAR.

## Endpoint

- **Method:** `GET`
- **Path:** `/Archives/edgar/daily-index/bulkdata/submissions.zip`
- **Base URL:** `https://www.sec.gov`
- **Official documentation:** [Download Submissions Bulk ZIP](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)
