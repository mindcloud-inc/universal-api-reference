# Create CRM Entity Item with Uspacy

Creates a new CRM entity item in Uspacy.

## Endpoint

- **Method:** `POST`
- **Path:** `/crm/v1/entities/:entity`
- **Base URL:** `https://{site}`
- **Official documentation:** [Create CRM Entity Item](https://uspacy.readme.io/reference/post_crm-v1-entities-entity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entity` | path | `string` | yes | The CRM entity key. |
