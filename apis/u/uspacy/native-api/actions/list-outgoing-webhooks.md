# List Outgoing Webhooks with Uspacy

Retrieves outgoing webhook entries from Uspacy.

## Endpoint

- **Method:** `GET`
- **Path:** `/company/v1/webhooks`
- **Base URL:** `https://{site}`
- **Official documentation:** [List Outgoing Webhooks](https://uspacy.readme.io/reference/get_company-v1-webhooks)
