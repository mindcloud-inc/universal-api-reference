# Update Task with Uspacy

Updates an existing task in Uspacy.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/tasks/v1/tasks/:taskId`
- **Base URL:** `https://{site}`
- **Official documentation:** [Update Task](https://uspacy.readme.io/reference/patch_tasks-v1-tasks-taskid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | The task ID. |
