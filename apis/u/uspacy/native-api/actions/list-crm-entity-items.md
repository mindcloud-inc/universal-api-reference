# List CRM Entity Items with Uspacy

Retrieves CRM entity items from Uspacy.

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/v1/entities/:entity`
- **Base URL:** `https://{site}`
- **Official documentation:** [List CRM Entity Items](https://uspacy.readme.io/reference/get_crm-v1-entities-entity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entity` | path | `string` | yes | The CRM entity key. |
