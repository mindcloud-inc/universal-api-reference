# Search Workspace Data with Uspacy

Finds matching workspace data in Uspacy.

## Endpoint

- **Method:** `GET`
- **Path:** `/search/v1/search`
- **Base URL:** `https://{site}`
- **Official documentation:** [Search Workspace Data](https://uspacy.readme.io/reference/get_search-v1-search-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Search text. |
