# Get Task with Uspacy

Retrieves a task record from Uspacy.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/v1/tasks/:taskId`
- **Base URL:** `https://{site}`
- **Official documentation:** [Get Task](https://uspacy.readme.io/reference/get_tasks-v1-tasks-taskid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | The task ID. |
