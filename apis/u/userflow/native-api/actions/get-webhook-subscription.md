# Get Webhook Subscription with Userflow

Retrieves a webhook subscription from Userflow by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook_subscriptions/:webhook_subscription_id`
- **Base URL:** `https://api.userflow.com`
- **Official documentation:** [Get Webhook Subscription](https://docs.userflow.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_subscription_id` | path | `string` | yes | ID of the webhook subscription. |
