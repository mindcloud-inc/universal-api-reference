# Get User with Userflow

Retrieves a user from Userflow by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user_id`
- **Base URL:** `https://api.userflow.com`
- **Official documentation:** [Get User](https://docs.userflow.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The Userflow user ID to retrieve. |
