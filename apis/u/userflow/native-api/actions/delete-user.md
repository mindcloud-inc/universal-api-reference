# Delete User with Userflow

Deletes an existing user from Userflow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:user_id`
- **Base URL:** `https://api.userflow.com`
- **Official documentation:** [Delete User](https://docs.userflow.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | Unique identifier for the user to delete. |
