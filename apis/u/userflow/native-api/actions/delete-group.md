# Delete Group with Userflow

Deletes an existing group from Userflow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/:group_id`
- **Base URL:** `https://api.userflow.com`
- **Official documentation:** [Delete Group](https://docs.userflow.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | yes | The Userflow group ID to delete. |
