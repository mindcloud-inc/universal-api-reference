# Get Content with Userflow

Retrieves a content object from Userflow by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/content/:content_id`
- **Base URL:** `https://api.userflow.com`
- **Official documentation:** [Get Content](https://docs.userflow.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `content_id` | path | `string` | yes | Unique identifier for the content object. |
