# Get Organization with Umbler Talk

Retrieves an organization summary from Umbler Talk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/organizations/[:id]/`
- **Base URL:** `https://app-utalk.umbler.com/api`
- **Official documentation:** [Get Organization](https://app-utalk.umbler.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The organization ID. |
