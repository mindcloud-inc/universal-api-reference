# Get Organization Details with Umbler Talk

Retrieves organization details from Umbler Talk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/organizations/[:id]/details/`
- **Base URL:** `https://app-utalk.umbler.com/api`
- **Official documentation:** [Get Organization Details](https://app-utalk.umbler.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The organization ID. |
