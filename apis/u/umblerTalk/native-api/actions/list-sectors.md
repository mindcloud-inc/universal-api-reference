# List Sectors with Umbler Talk

Retrieves sectors from Umbler Talk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sectors/`
- **Base URL:** `https://app-utalk.umbler.com/api`
- **Official documentation:** [List Sectors](https://app-utalk.umbler.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | query | `string` | yes | The organization ID. |
