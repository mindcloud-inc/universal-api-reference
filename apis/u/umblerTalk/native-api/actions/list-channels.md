# List Channels with Umbler Talk

Retrieves channels from Umbler Talk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/channels/`
- **Base URL:** `https://app-utalk.umbler.com/api`
- **Official documentation:** [List Channels](https://app-utalk.umbler.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | query | `string` | yes | The organization ID. |
