# Get Current Member with Umbler Talk

Retrieves the current member profile from Umbler Talk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/members/me/`
- **Base URL:** `https://app-utalk.umbler.com/api`
- **Official documentation:** [Get Current Member](https://app-utalk.umbler.com/api/docs/index.html)
