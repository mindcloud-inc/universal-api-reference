# Set Users And Groups To Roles In The Current Project with Unleash

Sets users and groups to roles in the current project in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/projects/{projectId}/access`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Set Users And Groups To Roles In The Current Project](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
| `projectId` | path | `string` | yes | Required path parameter. |
