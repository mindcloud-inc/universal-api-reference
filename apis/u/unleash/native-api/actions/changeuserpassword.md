# Change Password For A User with Unleash

Changes a user's password in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/user-admin/{id}/change-password`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Change Password For A User](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
| `id` | path | `string` | yes | Required path parameter. |
