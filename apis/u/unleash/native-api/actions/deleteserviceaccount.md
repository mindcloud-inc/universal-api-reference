# Delete A Service Account. with Unleash

Deletes a service account from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/service-account/{id}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete A Service Account.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
