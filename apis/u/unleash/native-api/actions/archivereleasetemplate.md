# Archives A Release Template By Its Id. with Unleash

Archives a release template by its id in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/release-plan-templates/archive/{templateId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Archives A Release Template By Its Id.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | Required path parameter. |
