# Update An Addon with Unleash

Updates an addon in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/addons/{id}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Update An Addon](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
| `id` | path | `string` | yes | Required path parameter. |
