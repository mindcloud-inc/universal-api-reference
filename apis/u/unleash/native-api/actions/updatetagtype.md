# Update A Tag Type with Unleash

Updates a tag type in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/tag-types/{name}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Update A Tag Type](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
| `name` | path | `string` | yes | Required path parameter. |
