# Update Unleash Feedback with Unleash

Updates feedback in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/feedback/{id}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Update Unleash Feedback](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
| `id` | path | `string` | yes | Required path parameter. |
