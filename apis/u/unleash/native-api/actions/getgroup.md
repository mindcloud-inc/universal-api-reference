# Get A Single Group with Unleash

Retrieves a group from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/groups/{groupId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get A Single Group](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | Required path parameter. |
