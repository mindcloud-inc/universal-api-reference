# Get Strategies That Use A Context Field with Unleash

Retrieves strategies that use a context field from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/context/{contextField}/strategies`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Strategies That Use A Context Field](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contextField` | path | `string` | yes | Required path parameter. |
