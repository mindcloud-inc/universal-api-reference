# Get All Personal Access Tokens (Pats) For The Current User. with Unleash

Retrieves personal access tokens (PATs) for the current user from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/user/tokens`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get All Personal Access Tokens (Pats) For The Current User.](https://docs.getunleash.io/api)
