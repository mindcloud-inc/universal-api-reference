# Get Integration Events For A Specific Integration Configuration. with Unleash

Retrieves integration events for a specific integration configuration from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/addons/{id}/events`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Integration Events For A Specific Integration Configuration.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
