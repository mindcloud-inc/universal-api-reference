# Delete A Strategy with Unleash

Deletes a strategy from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/strategies/{name}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete A Strategy](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Required path parameter. |
