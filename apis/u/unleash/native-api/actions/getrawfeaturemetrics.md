# Get Feature Metrics with Unleash

Retrieves feature metrics from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/client-metrics/features/{name}/raw`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Feature Metrics](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Required path parameter. |
