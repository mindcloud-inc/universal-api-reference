# Archives A Feature with Unleash

Archives a feature in Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/archive/{featureName}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Archives A Feature](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `featureName` | path | `string` | yes | Required path parameter. |
