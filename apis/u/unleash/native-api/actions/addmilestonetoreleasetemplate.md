# Adds A Milestone To A Release Template. with Unleash

Adds a milestone to a release template in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/release-plan-templates/{templateId}/milestones`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Adds A Milestone To A Release Template.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | Required path parameter. |
