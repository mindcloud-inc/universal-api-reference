# Remove Project From Favorites with Unleash

Removes a project from favorites from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/projects/{projectId}/favorites`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Remove Project From Favorites](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
