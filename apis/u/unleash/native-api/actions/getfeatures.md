# Get All Features In A Project with Unleash

Retrieves features in a project from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/features`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get All Features In A Project](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
