# [Beta] Subscribe To Email Subscription with Unleash

Subscribes to an email subscription in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/email-subscription/{subscription}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [[Beta] Subscribe To Email Subscription](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscription` | path | `string` | yes | Required path parameter. |
