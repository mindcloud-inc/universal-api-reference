# Get Application Overview with Unleash

Retrieves application overview from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/metrics/applications/{appName}/overview`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Application Overview](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appName` | path | `string` | yes | Required path parameter. |
