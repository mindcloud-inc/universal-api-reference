# Send Custom Metrics with Unleash

Sends custom metrics in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/client/metrics/custom`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Send Custom Metrics](https://docs.getunleash.io/api)
