# Get Simple Auth Settings with Unleash

Retrieves Simple auth settings from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/auth/simple/settings`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Simple Auth Settings](https://docs.getunleash.io/api)
