# Revive Project with Unleash

Revives a project in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/projects/revive/{projectId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Revive Project](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
