# Get All Events Related To A Specific Feature Flag. with Unleash

Retrieves events related to a specific feature flag from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/events/{featureName}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get All Events Related To A Specific Feature Flag.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `featureName` | path | `string` | yes | Required path parameter. |
