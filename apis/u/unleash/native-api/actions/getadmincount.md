# Get Total Count Of Admin Accounts with Unleash

Retrieves total count of admin accounts from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/user-admin/admin-count`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Total Count Of Admin Accounts](https://docs.getunleash.io/api)
