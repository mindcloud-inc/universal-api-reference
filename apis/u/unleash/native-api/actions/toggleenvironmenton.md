# Toggle The Environment With `Name` On with Unleash

Enables the named environment in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/environments/{name}/on`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Toggle The Environment With `Name` On](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Required path parameter. |
