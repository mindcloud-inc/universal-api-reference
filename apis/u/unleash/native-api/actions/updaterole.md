# Update A Role with Unleash

Updates a role in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/roles/{roleId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Update A Role](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
| `roleId` | path | `string` | yes | Required path parameter. |
