# Get All Tags For A Feature. with Unleash

Retrieves tags for a feature from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/features/{featureName}/tags`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get All Tags For A Feature.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `featureName` | path | `string` | yes | Required path parameter. |
