# Retrieves Change Request Configuration For A Project with Unleash

Retrieves change request configuration for a project from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/change-requests/config`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Retrieves Change Request Configuration For A Project](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
