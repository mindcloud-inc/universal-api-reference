# Get A Segment with Unleash

Retrieves a segment from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/segments/{id}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get A Segment](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
