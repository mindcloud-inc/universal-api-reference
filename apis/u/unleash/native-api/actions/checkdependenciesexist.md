# Check Dependencies Exist. with Unleash

Checks dependencies exist in Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/dependencies`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Check Dependencies Exist.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
