# Mark Notifications As Read with Unleash

Marks notifications as read in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/notifications/read`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Mark Notifications As Read](https://docs.getunleash.io/api)
