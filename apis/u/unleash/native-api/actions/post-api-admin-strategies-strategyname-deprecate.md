# Deprecate A Strategy with Unleash

Deprecates a strategy in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/strategies/{strategyName}/deprecate`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Deprecate A Strategy](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `strategyName` | path | `string` | yes | Required path parameter. |
