# Get Api Tokens For Project. with Unleash

Retrieves api tokens for project from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/api-tokens`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Api Tokens For Project.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
