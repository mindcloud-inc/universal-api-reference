# Disables A Banner. with Unleash

Disables a banner in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/banners/{id}/off`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Disables A Banner.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
