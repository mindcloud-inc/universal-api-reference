# Delete An Existing Context Field with Unleash

Deletes an existing context field from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/context/{contextField}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete An Existing Context Field](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contextField` | path | `string` | yes | Required path parameter. |
