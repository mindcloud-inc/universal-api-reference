# Update A Strategy Type with Unleash

Updates a strategy type in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/strategies/{name}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Update A Strategy Type](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Required path parameter. |
| `body` | body | `object` | yes | Required JSON request body. |
