# List All Tokens For A Service Account. with Unleash

Retrieves all tokens for a service account from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/service-account/{id}/token`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [List All Tokens For A Service Account.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
