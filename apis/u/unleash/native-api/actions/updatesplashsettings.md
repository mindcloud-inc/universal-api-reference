# Update Splash Settings with Unleash

Updates a splash settings in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/splash/{id}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Update Splash Settings](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
