# Get The Number Of Change Requests You Can Do Something With with Unleash

Retrieves the number of change requests you can do something with from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/change-requests/actionable`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get The Number Of Change Requests You Can Do Something With](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
