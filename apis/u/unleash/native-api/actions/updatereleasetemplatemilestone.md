# Updates Existing Milestone with Unleash

Updates an existing milestone in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/release-plan-templates/{templateId}/milestones/{milestoneId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Updates Existing Milestone](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | Required path parameter. |
| `milestoneId` | path | `string` | yes | Required path parameter. |
