# Deletes An Environment By Name with Unleash

Deletes an environment by name from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/environments/{name}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Deletes An Environment By Name](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Required path parameter. |
