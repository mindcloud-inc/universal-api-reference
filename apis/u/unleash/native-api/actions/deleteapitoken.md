# Delete Api Token with Unleash

Deletes an API token from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/api-tokens/{token}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete Api Token](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | path | `string` | yes | Required path parameter. |
