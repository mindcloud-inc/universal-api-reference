# Deletes A Segment By Id with Unleash

Deletes a segment by id from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/segments/{id}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Deletes A Segment By Id](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
