# Deletes A Feature Dependency. with Unleash

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/projects/{projectId}/features/{child}/dependencies/{parent}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Deletes A Feature Dependency.](https://docs.getunleash.io/api)
