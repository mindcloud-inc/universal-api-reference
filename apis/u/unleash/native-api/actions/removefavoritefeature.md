# Remove Feature From Favorites with Unleash

Removes a feature from favorites from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/projects/{projectId}/features/{featureName}/favorites`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Remove Feature From Favorites](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
| `featureName` | path | `string` | yes | Required path parameter. |
