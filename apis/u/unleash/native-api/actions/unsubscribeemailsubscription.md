# [Beta] Unsubscribe From Email Subscription with Unleash

- **Method:** `DELETE`
- **Path:** `/api/admin/email-subscription/{subscription}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [[Beta] Unsubscribe From Email Subscription](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscription` | path | `string` | yes | Required path parameter. |
