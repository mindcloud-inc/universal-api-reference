# Delete An Addon with Unleash

Deletes an addon from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/addons/{id}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete An Addon](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
