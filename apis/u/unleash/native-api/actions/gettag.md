# Get A Tag By Type And Value. with Unleash

Retrieves a tag by type and value from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/tags/{type}/{value}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get A Tag By Type And Value.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | path | `string` | yes | Required path parameter. |
| `value` | path | `string` | yes | Required path parameter. |
