# Get The Environment With `Name` with Unleash

Retrieves the named environment from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/environments/{name}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get The Environment With `Name`](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Required path parameter. |
