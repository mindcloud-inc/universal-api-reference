# Get Oidc Auth Settings with Unleash

Retrieves OIDC auth settings from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/auth/oidc/settings`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Oidc Auth Settings](https://docs.getunleash.io/api)
