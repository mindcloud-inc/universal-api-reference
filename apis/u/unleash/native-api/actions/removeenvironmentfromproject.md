# Remove An Environment From A Project. with Unleash

Removes an environment from a project from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/projects/{projectId}/environments/{environment}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Remove An Environment From A Project.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
| `environment` | path | `string` | yes | Required path parameter. |
