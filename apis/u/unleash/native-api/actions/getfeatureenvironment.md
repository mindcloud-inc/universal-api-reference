# Get A Feature Environment with Unleash

Retrieves a feature environment from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/features/{featureName}/environments/{environment}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get A Feature Environment](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
| `featureName` | path | `string` | yes | Required path parameter. |
| `environment` | path | `string` | yes | Required path parameter. |
