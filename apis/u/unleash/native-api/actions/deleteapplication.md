# Delete An Application with Unleash

Deletes an application from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/metrics/applications/{appName}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete An Application](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appName` | path | `string` | yes | Required path parameter. |
