# Get Users And Groups In Project with Unleash

Retrieves users and groups in project from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/access`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Users And Groups In Project](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
