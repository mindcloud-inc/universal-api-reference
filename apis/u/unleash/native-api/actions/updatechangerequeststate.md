# This Endpoint Will Update The State Of A Change Request with Unleash

Updates a change request state in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/projects/{projectId}/change-requests/{id}/state`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [This Endpoint Will Update The State Of A Change Request](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
| `id` | path | `string` | yes | Required path parameter. |
