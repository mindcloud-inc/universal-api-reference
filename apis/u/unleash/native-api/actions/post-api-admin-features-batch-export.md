# Export Feature Flags From An Environment with Unleash

Exports feature flags from an environment in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/features-batch/export`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Export Feature Flags From An Environment](https://docs.getunleash.io/api)
