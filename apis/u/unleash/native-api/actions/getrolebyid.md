# Get A Single Role with Unleash

Retrieves a role from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/roles/{roleId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get A Single Role](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roleId` | path | `string` | yes | Required path parameter. |
