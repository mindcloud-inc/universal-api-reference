# Retrieves Number Of Project Change Requests In Each State with Unleash

Retrieves number of project change requests in each state from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/change-requests/count`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Retrieves Number Of Project Change Requests In Each State](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
