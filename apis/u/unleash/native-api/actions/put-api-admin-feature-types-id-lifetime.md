# Update Feature Type Lifetime with Unleash

Updates a feature type lifetime in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/feature-types/{id}/lifetime`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Update Feature Type Lifetime](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
| `body` | body | `object` | yes | Required JSON request body. |
