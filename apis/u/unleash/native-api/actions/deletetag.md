# Delete A Tag. with Unleash

Deletes a tag from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/tags/{type}/{value}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete A Tag.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | path | `string` | yes | Required path parameter. |
| `value` | path | `string` | yes | Required path parameter. |
