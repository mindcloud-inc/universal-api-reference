# Update A Group with Unleash

Updates a group in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/groups/{groupId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Update A Group](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
| `groupId` | path | `string` | yes | Required path parameter. |
