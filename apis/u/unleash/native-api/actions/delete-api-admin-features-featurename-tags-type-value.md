# Removes A Tag From A Feature. with Unleash

Removes a tag from a feature from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/features/{featureName}/tags/{type}/{value}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Removes A Tag From A Feature.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `featureName` | path | `string` | yes | Required path parameter. |
| `type` | path | `string` | yes | Required path parameter. |
| `value` | path | `string` | yes | Required path parameter. |
