# Update Project with Unleash

Updates a project in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/projects/{projectId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Update Project](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
| `projectId` | path | `string` | yes | Required path parameter. |
