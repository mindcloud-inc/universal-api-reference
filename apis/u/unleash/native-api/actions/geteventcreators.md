# Get A List Of All Users That Have Created Events with Unleash

Retrieves users that have created events from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/event-creators`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get A List Of All Users That Have Created Events](https://docs.getunleash.io/api)
