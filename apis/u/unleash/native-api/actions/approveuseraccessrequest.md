# Approve A User Access Request. with Unleash

Approves a user access request in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/user-access-requests/{id}/approve`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Approve A User Access Request.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
| `id` | path | `string` | yes | Required path parameter. |
