# Evaluate An Unleash Context Against A Change Request Preview. with Unleash

Evaluates a change request preview against an Unleash context.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/playground/change-request/{id}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Evaluate An Unleash Context Against A Change Request Preview.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
| `id` | path | `string` | yes | Required path parameter. |
