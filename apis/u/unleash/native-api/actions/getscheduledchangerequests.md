# Get Scheduled Change Requests Matching A Query. with Unleash

Retrieves scheduled change requests matching a query from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/change-requests/scheduled`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Scheduled Change Requests Matching A Query.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
