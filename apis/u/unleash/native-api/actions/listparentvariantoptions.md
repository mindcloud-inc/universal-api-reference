# List Parent Feature Variants. with Unleash

Retrieves parent feature variants from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/features/{parent}/parent-variants`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [List Parent Feature Variants.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
| `parent` | path | `string` | yes | Required path parameter. |
