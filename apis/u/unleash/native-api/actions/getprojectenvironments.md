# Get The Environments Available To A Project with Unleash

Retrieves the environments available to a project from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/environments/project/{projectId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get The Environments Available To A Project](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
