# List All Tags Of A Given Type. with Unleash

Retrieves all tags of a given type from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/tags/{type}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [List All Tags Of A Given Type.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | path | `string` | yes | Required path parameter. |
