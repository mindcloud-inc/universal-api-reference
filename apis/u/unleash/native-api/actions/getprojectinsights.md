# Get An Overview Of A Project Insights. with Unleash

Retrieves an overview of a project insights from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/insights`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get An Overview Of A Project Insights.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
