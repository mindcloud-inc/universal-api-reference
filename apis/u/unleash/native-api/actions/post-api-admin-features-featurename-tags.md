# Adds A Tag To A Feature. with Unleash

Adds a tag to a feature in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/features/{featureName}/tags`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Adds A Tag To A Feature.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `featureName` | path | `string` | yes | Required path parameter. |
| `body` | body | `object` | yes | Required JSON request body. |
