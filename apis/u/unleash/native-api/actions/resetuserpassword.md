# Reset User Password with Unleash

Resets a user's password in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/user-admin/reset-password`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Reset User Password](https://docs.getunleash.io/api)
