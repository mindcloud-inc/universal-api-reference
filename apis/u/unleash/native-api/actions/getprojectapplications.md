# Get A List Of All Applications For A Project. with Unleash

Retrieves applications for a project from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/applications`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get A List Of All Applications For A Project.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
