# Get Application Data with Unleash

Retrieves application data from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/metrics/applications/{appName}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Application Data](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appName` | path | `string` | yes | Required path parameter. |
