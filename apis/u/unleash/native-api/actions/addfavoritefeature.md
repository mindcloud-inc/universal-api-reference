# Add Feature To Favorites with Unleash

Adds a feature to favorites in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/projects/{projectId}/features/{featureName}/favorites`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Add Feature To Favorites](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
| `featureName` | path | `string` | yes | Required path parameter. |
