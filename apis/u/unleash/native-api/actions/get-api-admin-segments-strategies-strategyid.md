# Get Strategy Segments with Unleash

Retrieves strategy segments from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/segments/strategies/{strategyId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Strategy Segments](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `strategyId` | path | `string` | yes | Required path parameter. |
