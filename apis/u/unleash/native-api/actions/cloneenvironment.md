# Clones An Environment with Unleash

Clones an environment in Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/environments/{name}/clone`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Clones An Environment](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
| `name` | path | `string` | yes | Required path parameter. |
