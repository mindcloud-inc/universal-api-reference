# Get Outdated Project Sdks with Unleash

Retrieves outdated project SDKs from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/sdks/outdated`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Outdated Project Sdks](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
