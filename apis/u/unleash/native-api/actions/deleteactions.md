# [Beta] Delete An Action Set. with Unleash

Deletes an action set from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/projects/{projectId}/actions/{id}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [[Beta] Delete An Action Set.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
| `id` | path | `string` | yes | Required path parameter. |
