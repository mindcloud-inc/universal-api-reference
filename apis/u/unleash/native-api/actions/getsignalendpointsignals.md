# [Beta] Get Signals Originated From A Specific Signal Endpoint. with Unleash

Retrieves signals originated from a specific signal endpoint from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/signal-endpoints/{signalEndpointId}/signals`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [[Beta] Get Signals Originated From A Specific Signal Endpoint.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `signalEndpointId` | path | `string` | yes | Required path parameter. |
