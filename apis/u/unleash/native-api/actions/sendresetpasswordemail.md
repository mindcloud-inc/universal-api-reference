# Reset Password with Unleash

Sends a password reset email from Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/auth/reset/password-email`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Reset Password](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
