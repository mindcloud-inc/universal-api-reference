# Get A Single Feature Flag with Unleash

Retrieves a feature flag from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/client/features/{featureName}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get A Single Feature Flag](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `featureName` | path | `string` | yes | Required path parameter. |
