# Get Project Role Mappings with Unleash

Retrieves project-role mappings from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/roles/{roleId}/access`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Project Role Mappings](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roleId` | path | `string` | yes | Required path parameter. |
