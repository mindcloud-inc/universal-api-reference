# Get Public Signup Tokens with Unleash

Retrieves public signup tokens from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/invite-link/tokens`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Public Signup Tokens](https://docs.getunleash.io/api)
