# Delete A Personal Access Token (Pat) For The Current User. with Unleash

Deletes a personal access token (PAT) for the current user from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/user/tokens/{id}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete A Personal Access Token (Pat) For The Current User.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
