# Remove Project Access For A Group with Unleash

Removes project access for a group from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/projects/{projectId}/groups/{groupId}/roles`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Remove Project Access For A Group](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
| `groupId` | path | `string` | yes | Required path parameter. |
