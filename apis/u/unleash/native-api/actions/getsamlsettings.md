# Get Saml Auth Settings with Unleash

Retrieves SAML auth settings from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/auth/saml/settings`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Saml Auth Settings](https://docs.getunleash.io/api)
