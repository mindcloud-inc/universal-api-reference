# Retrieve A Token with Unleash

Retrieves a token from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/invite-link/tokens/{token}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Retrieve A Token](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | path | `string` | yes | Required path parameter. |
