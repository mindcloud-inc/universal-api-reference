# Delete A Custom Role with Unleash

Deletes a custom role from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/roles/{roleId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete A Custom Role](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roleId` | path | `string` | yes | Required path parameter. |
