# Delete A Tag Type with Unleash

Deletes a tag type from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/tag-types/{name}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete A Tag Type](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Required path parameter. |
