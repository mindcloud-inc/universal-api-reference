# Get Strategies That Reference Segment with Unleash

Retrieves strategies that reference segment from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/segments/{id}/strategies`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Strategies That Reference Segment](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
