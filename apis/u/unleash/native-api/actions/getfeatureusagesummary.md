# Last Hour Of Usage And A List Of Applications That Have Reported Seeing This Fea with Unleash

Retrieves recent feature usage and reporting applications from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/client-metrics/features/{name}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Last Hour Of Usage And A List Of Applications That Have Reported Seeing This Fea](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Required path parameter. |
