# Enabled/Disabled Maintenance Mode with Unleash

Toggles maintenance mode in Unleash.

- **Method:** `POST`
- **Path:** `/api/admin/maintenance`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Enabled/Disabled Maintenance Mode](https://docs.getunleash.io/api)
