# Get A Strategy Definition with Unleash

Retrieves a strategy definition from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/strategies/{name}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get A Strategy Definition](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Required path parameter. |
