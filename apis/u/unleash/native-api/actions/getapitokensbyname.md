# Get Api Tokens By Name with Unleash

Retrieves API tokens by name from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/api-tokens/{name}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get Api Tokens By Name](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Required path parameter. |
