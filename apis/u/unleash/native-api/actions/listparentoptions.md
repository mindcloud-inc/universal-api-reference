# List Parent Options. with Unleash

Retrieves parent options from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/features/{child}/parents`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [List Parent Options.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
| `child` | path | `string` | yes | Required path parameter. |
