# Updates Multiple Tags For A Feature. with Unleash

Updates multiple tags for a feature in Unleash.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/features/{featureName}/tags`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Updates Multiple Tags For A Feature.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `featureName` | path | `string` | yes | Required path parameter. |
| `body` | body | `object` | yes | Required JSON request body. |
