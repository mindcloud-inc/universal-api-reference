# Get A Specific Addon with Unleash

Retrieves a specific addon from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/addons/{id}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get A Specific Addon](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
