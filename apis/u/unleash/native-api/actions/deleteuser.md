# Delete A User with Unleash

Deletes a user from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/user-admin/{id}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete A User](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
