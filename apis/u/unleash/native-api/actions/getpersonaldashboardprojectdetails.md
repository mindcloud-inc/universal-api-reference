# [Beta] Get Personal Project Details with Unleash

Retrieves personal project details from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/personal-dashboard/{projectId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [[Beta] Get Personal Project Details](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
