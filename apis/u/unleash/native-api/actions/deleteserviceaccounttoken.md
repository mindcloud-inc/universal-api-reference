# Delete A Token For A Service Account. with Unleash

Deletes a token for a service account from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/service-account/{id}/token/{tokenId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete A Token For A Service Account.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
| `tokenId` | path | `string` | yes | Required path parameter. |
