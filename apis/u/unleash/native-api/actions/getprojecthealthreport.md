# Get A Health Report For A Project. with Unleash

Retrieves a health report for a project from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/projects/{projectId}/health-report`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get A Health Report For A Project.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
