# Returns The List Of Permissions For The Service Account. with Unleash

Retrieves the list of permissions for the service account from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/service-account/{id}/permissions`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Returns The List Of Permissions For The Service Account.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path parameter. |
