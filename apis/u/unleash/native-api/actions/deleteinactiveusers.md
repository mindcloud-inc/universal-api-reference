# Deletes Inactive Users with Unleash

Deletes an inactive users from Unleash.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/user-admin/inactive/delete`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Deletes Inactive Users](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Required JSON request body. |
