# Delete Project with Unleash

Deletes a project from Unleash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/admin/projects/{projectId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Delete Project](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Required path parameter. |
