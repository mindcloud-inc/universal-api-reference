# Get A Release Template By Its Id. with Unleash

Retrieves a release template by its id from Unleash.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/release-plan-templates/{templateId}`
- **Base URL:** `https://us.app.getunleash.io/uspp0456`
- **Official documentation:** [Get A Release Template By Its Id.](https://docs.getunleash.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | Required path parameter. |
