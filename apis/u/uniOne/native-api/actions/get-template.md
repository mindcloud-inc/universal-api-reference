# Get Template with UniOne

Retrieves an email template from UniOne by ID.

## Endpoint

- **Method:** `POST`
- **Path:** `template/get.json`
- **Base URL:** `https://api.unione.io/en/transactional/api/v1`
- **Official documentation:** [Get Template](https://docs.unione.io/en/web-api-ref#template-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Template identifier. |
