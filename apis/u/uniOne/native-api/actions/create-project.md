# Create Project with UniOne

Creates a new project in UniOne.

## Endpoint

- **Method:** `POST`
- **Path:** `project/create.json`
- **Base URL:** `https://api.unione.io/en/transactional/api/v1`
- **Official documentation:** [Create Project](https://docs.unione.io/en/web-api-ref#project-create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project.name` | body | `string` | yes | Unique project name. |
