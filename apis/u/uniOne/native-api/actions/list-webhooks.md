# List Webhooks with UniOne

Retrieves configured webhooks from UniOne for the account.

## Endpoint

- **Method:** `POST`
- **Path:** `webhook/list.json`
- **Base URL:** `https://api.unione.io/en/transactional/api/v1`
- **Official documentation:** [List Webhooks](https://docs.unione.io/en/web-api-ref#webhook-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
