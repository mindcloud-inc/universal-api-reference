# List Event Dump Jobs with UniOne

Retrieves event dump jobs from UniOne.

## Endpoint

- **Method:** `POST`
- **Path:** `event-dump/list.json`
- **Base URL:** `https://api.unione.io/en/transactional/api/v1`
- **Official documentation:** [List Event Dump Jobs](https://docs.unione.io/en/web-api-ref#event-dump-list)
