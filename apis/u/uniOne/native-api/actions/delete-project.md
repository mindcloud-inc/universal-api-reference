# Delete Project with UniOne

Deletes an existing project from UniOne.

## Endpoint

- **Method:** `POST`
- **Path:** `project/delete.json`
- **Base URL:** `https://api.unione.io/en/transactional/api/v1`
- **Official documentation:** [Delete Project](https://docs.unione.io/en/web-api-ref#project-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | body | `string` | yes | Unique project identifier. |
