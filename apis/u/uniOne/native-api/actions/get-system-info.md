# Get System Info with UniOne

Retrieves account and usage details from UniOne.

## Endpoint

- **Method:** `POST`
- **Path:** `system/info.json`
- **Base URL:** `https://api.unione.io/en/transactional/api/v1`
- **Official documentation:** [Get System Info](https://docs.unione.io/en/web-api-ref#system-info)
