# List Alerts with Umbrella

Retrieves alert records from your Umbrella organization.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.sse.cisco.com/admin/v2/alerting/alerts`
- **Base URL:** `https://api.umbrella.com`
- **Official documentation:** [List Alerts](https://developer.cisco.com/docs/cloud-security/list-alerts/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
