# List Chrome Enterprise Integrations with Umbrella

Retrieves Chrome Enterprise integrations from Umbrella.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.sse.cisco.com/admin/v2/integrations?type=chrome-enterprise.v1`
- **Base URL:** `https://api.umbrella.com`
- **Official documentation:** [List Chrome Enterprise Integrations](https://developer.cisco.com/docs/cloud-security/list-integrations/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
