# List Alerts With Context with Umbrella

Retrieves alerts with context metadata from Umbrella.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.sse.cisco.com/admin/v2/alerting/alerts?filters={"include_context":true}`
- **Base URL:** `https://api.umbrella.com`
- **Official documentation:** [List Alerts With Context](https://developer.cisco.com/docs/cloud-security/list-alerts/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
