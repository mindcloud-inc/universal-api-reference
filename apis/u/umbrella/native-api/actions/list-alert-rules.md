# List Alert Rules with Umbrella

Retrieves alert rule definitions from Umbrella.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.sse.cisco.com/admin/v2/alerting/rules`
- **Base URL:** `https://api.umbrella.com`
- **Official documentation:** [List Alert Rules](https://developer.cisco.com/docs/cloud-security/list-alert-rules/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
