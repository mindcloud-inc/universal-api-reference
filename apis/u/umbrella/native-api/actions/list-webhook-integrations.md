# List Webhook Integrations with Umbrella

Retrieves webhook integration records from Umbrella.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.sse.cisco.com/admin/v2/integrations?type=webhook.v1`
- **Base URL:** `https://api.umbrella.com`
- **Official documentation:** [List Webhook Integrations](https://developer.cisco.com/docs/cloud-security/list-integrations/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
