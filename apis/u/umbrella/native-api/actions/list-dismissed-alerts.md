# List Dismissed Alerts with Umbrella

Retrieves dismissed alert records from Umbrella.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.sse.cisco.com/admin/v2/alerting/alerts?filters={"status":2}`
- **Base URL:** `https://api.umbrella.com`
- **Official documentation:** [List Dismissed Alerts](https://developer.cisco.com/docs/cloud-security/list-alerts/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
