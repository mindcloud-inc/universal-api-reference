# List Users with Umbrella

Retrieves user accounts from your Umbrella organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/v2/users`
- **Base URL:** `https://api.umbrella.com`
- **Official documentation:** [List Users](https://developer.cisco.com/docs/cloud-security/list-users/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
