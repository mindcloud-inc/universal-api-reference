# List Inactive Integrations with Umbrella

Retrieves inactive integration records from Umbrella.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.sse.cisco.com/admin/v2/integrations?status=inactive`
- **Base URL:** `https://api.umbrella.com`
- **Official documentation:** [List Inactive Integrations](https://developer.cisco.com/docs/cloud-security/list-integrations/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
