# Get Avatar Details with Uwear.ai

Retrieves avatar details from Uwear.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/avatar/:avatar_id`
- **Base URL:** `https://api.uwear.ai`
- **Official documentation:** [Get Avatar Details](https://docs.dev.uwear.ai/operations/external_read_avatar)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `avatar_id` | path | `number` | yes | Avatar ID. |
