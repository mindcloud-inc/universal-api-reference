# Get Generation Result Details with Uwear.ai

Retrieves generation result details from Uwear.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/generation-result/:generation_result_id`
- **Base URL:** `https://api.uwear.ai`
- **Official documentation:** [Get Generation Result Details](https://docs.dev.uwear.ai/operations/external_read_generation_result)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `generation_result_id` | path | `number` | yes | Generation result ID. |
