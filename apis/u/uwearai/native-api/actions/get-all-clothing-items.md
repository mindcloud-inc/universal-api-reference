# Get All Clothing Items with Uwear.ai

Retrieves clothing items from Uwear.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/clothing-items`
- **Base URL:** `https://api.uwear.ai`
- **Official documentation:** [Get All Clothing Items](https://docs.dev.uwear.ai/operations/external_read_clothing_items)

## Capabilities

This operation supports [pagination](../README.md#pagination).
