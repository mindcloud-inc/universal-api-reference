# Delete Clothing Item with Uwear.ai

Deletes an existing clothing item from Uwear.ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/clothing-item/:clothing_item_id`
- **Base URL:** `https://api.uwear.ai`
- **Official documentation:** [Delete Clothing Item](https://docs.dev.uwear.ai/operations/external_delete_clothing_item)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clothing_item_id` | path | `string` | no | The clothing item ID. |
