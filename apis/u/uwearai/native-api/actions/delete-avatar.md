# Delete Avatar with Uwear.ai

Deletes an existing avatar from Uwear.ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/avatar/:avatar_id`
- **Base URL:** `https://api.uwear.ai`
- **Official documentation:** [Delete Avatar](https://docs.dev.uwear.ai/operations/external_delete_avatar)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `avatar_id` | path | `number` | yes | Avatar ID. |
