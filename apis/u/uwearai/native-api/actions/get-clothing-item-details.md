# Get Clothing Item Details with Uwear.ai

Retrieves clothing item details from Uwear.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/clothing-item/:clothing_item_id`
- **Base URL:** `https://api.uwear.ai`
- **Official documentation:** [Get Clothing Item Details](https://docs.dev.uwear.ai/operations/external_read_clothing_item)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clothing_item_id` | path | `string` | no | The clothing item ID. |
