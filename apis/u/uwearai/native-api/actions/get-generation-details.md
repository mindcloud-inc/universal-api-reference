# Get Generation Details with Uwear.ai

Retrieves generation details from Uwear.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/generation/:generation_id`
- **Base URL:** `https://api.uwear.ai`
- **Official documentation:** [Get Generation Details](https://docs.dev.uwear.ai/operations/external_read_generation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `generation_id` | path | `number` | yes | Generation request ID. |
