# Burn Project NFT with Underdog Protocol

Burns a project NFT in Underdog Protocol.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/projects/n/:projectId/nfts/:nftId/burn`
- **Base URL:** `https://dev.underdogprotocol.com`
- **Official documentation:** [Burn Project NFT](https://docs.underdogprotocol.com/resources/projects/nfts/burn-an-nft)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `number` | yes |
| `nftId` | path | `number` | yes |
