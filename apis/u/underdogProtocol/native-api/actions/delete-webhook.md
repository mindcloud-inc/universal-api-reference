# Delete Webhook with Underdog Protocol

Deletes an existing webhook from Underdog Protocol.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/webhooks/:webhookId`
- **Base URL:** `https://dev.underdogprotocol.com`
- **Official documentation:** [Delete Webhook](https://docs.underdogprotocol.com/resources/webhooks/delete-a-webhook)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `webhookId` | path | `string` | yes |
