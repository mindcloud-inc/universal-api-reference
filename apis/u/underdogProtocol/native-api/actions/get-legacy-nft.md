# Get Legacy NFT with Underdog Protocol

Retrieves a legacy NFT from Underdog Protocol.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/nfts/:mintAddress`
- **Base URL:** `https://dev.underdogprotocol.com`
- **Official documentation:** [Get Legacy NFT](https://docs.underdogprotocol.com/resources/v1/nfts/retrieve-an-nft)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mintAddress` | path | `string` | yes |
