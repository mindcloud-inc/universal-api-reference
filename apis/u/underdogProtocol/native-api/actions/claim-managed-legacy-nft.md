# Claim Managed Legacy NFT with Underdog Protocol

Retrieves claim data for a managed legacy NFT in Underdog Protocol.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/nfts/:mintAddress/claim`
- **Base URL:** `https://dev.underdogprotocol.com`
- **Official documentation:** [Claim Managed Legacy NFT](https://docs.underdogprotocol.com/resources/v1/managed-nfts/claim)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mintAddress` | path | `string` | yes |
