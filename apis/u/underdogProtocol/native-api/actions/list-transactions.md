# List Transactions with Underdog Protocol

Retrieves a list of transactions from Underdog Protocol.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/transactions`
- **Base URL:** `https://dev.underdogprotocol.com`
- **Official documentation:** [List Transactions](https://docs.underdogprotocol.com/resources/transactions/list-all-transactions)
