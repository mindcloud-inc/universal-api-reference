# Revoke Managed Legacy NFT with Underdog Protocol

Revokes a managed legacy NFT in Underdog Protocol.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/nfts/:mintAddress/revoke`
- **Base URL:** `https://dev.underdogprotocol.com`
- **Official documentation:** [Revoke Managed Legacy NFT](https://docs.underdogprotocol.com/resources/v1/managed-nfts/revoke)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mintAddress` | path | `string` | yes |
