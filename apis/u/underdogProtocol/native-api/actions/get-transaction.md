# Get Transaction with Underdog Protocol

Retrieves a transaction from Underdog Protocol.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/transactions/:transactionId`
- **Base URL:** `https://dev.underdogprotocol.com`
- **Official documentation:** [Get Transaction](https://docs.underdogprotocol.com/resources/transactions/retrieve-a-transaction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `transactionId` | path | `string` | yes |
