# Get NFT By Mint Address with Underdog Protocol

Retrieves an NFT from Underdog Protocol by mint address.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/nfts/:mintAddress`
- **Base URL:** `https://dev.underdogprotocol.com`
- **Official documentation:** [Get NFT By Mint Address](https://docs.underdogprotocol.com/resources/nfts/retrieve-an-nft)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mintAddress` | path | `string` | yes |
