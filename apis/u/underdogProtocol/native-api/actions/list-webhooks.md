# List Webhooks with Underdog Protocol

Retrieves a list of webhooks from Underdog Protocol.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/webhooks`
- **Base URL:** `https://dev.underdogprotocol.com`
- **Official documentation:** [List Webhooks](https://docs.underdogprotocol.com/resources/webhooks/list-all-webhooks)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `limit` | query | `number` | no |
