# List Orgs with Underdog Protocol

Retrieves a list of organizations from Underdog Protocol.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/orgs`
- **Base URL:** `https://dev.underdogprotocol.com`
- **Official documentation:** [List Orgs](https://docs.underdogprotocol.com/resources/orgs/list-all-orgs)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `limit` | query | `number` | no |
