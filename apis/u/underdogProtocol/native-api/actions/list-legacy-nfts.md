# List Legacy NFTs with Underdog Protocol

Retrieves a list of legacy NFTs from Underdog Protocol.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/nfts`
- **Base URL:** `https://dev.underdogprotocol.com`
- **Official documentation:** [List Legacy NFTs](https://docs.underdogprotocol.com/resources/v1/nfts/list-all-nfts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `collectionAddress` | query | `string` | no |
| `ownerAddress` | query | `string` | no |
