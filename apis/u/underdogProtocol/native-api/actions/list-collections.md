# List Collections with Underdog Protocol

Retrieves a list of collections from Underdog Protocol.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/collections`
- **Base URL:** `https://dev.underdogprotocol.com`
- **Official documentation:** [List Collections](https://docs.underdogprotocol.com/resources/v1/collections/list-all-collections)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `limit` | query | `number` | no |
