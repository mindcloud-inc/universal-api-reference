# Look Up Definitions with Urban Dictionary

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/define`
- **Base URL:** `https://api.urbandictionary.com`
- **Official documentation:** [Look Up Definitions](https://api.urbandictionary.com/v0/define)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `term` | query | `string` | yes | Word or phrase to look up. |
