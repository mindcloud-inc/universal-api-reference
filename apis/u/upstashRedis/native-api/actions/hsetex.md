# HSETEX with Upstash Redis

Executes the HSETEX command in Upstash Redis to set fields with expiration.

## Endpoint

- **Method:** `GET`
- **Path:** `/hsetex`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HSETEX](https://upstash.com/docs/redis/overall/rediscompatibility)
