# BITFIELD with Upstash Redis

Executes the BITFIELD command in Upstash Redis to perform arbitrary bitfield operations.

## Endpoint

- **Method:** `GET`
- **Path:** `/bitfield`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [BITFIELD](https://upstash.com/docs/redis/overall/rediscompatibility)
