# GEOSEARCH with Upstash Redis

Executes the GEOSEARCH command in Upstash Redis to search for members in an area.

## Endpoint

- **Method:** `GET`
- **Path:** `/geosearch`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [GEOSEARCH](https://upstash.com/docs/redis/overall/rediscompatibility)
