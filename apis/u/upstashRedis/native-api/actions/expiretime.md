# EXPIRETIME with Upstash Redis

Executes the EXPIRETIME command in Upstash Redis to get expiry as Unix timestamp.

## Endpoint

- **Method:** `GET`
- **Path:** `/expiretime`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [EXPIRETIME](https://upstash.com/docs/redis/overall/rediscompatibility)
