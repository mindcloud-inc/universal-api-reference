# SMOVE with Upstash Redis

Executes the SMOVE command in Upstash Redis to move member between sets.

## Endpoint

- **Method:** `GET`
- **Path:** `/smove`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [SMOVE](https://upstash.com/docs/redis/overall/rediscompatibility)
