# HPEXPIRETIME with Upstash Redis

Executes the HPEXPIRETIME command in Upstash Redis to get field expiry as ms timestamp.

## Endpoint

- **Method:** `GET`
- **Path:** `/hpexpiretime`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HPEXPIRETIME](https://upstash.com/docs/redis/overall/rediscompatibility)
