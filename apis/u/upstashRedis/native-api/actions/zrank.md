# ZRANK with Upstash Redis

Executes the ZRANK command in Upstash Redis to get member’s rank.

## Endpoint

- **Method:** `GET`
- **Path:** `/zrank`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZRANK](https://upstash.com/docs/redis/overall/rediscompatibility)
