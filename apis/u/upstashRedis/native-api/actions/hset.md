# HSET with Upstash Redis

Executes the HSET command in Upstash Redis to set hash field values.

## Endpoint

- **Method:** `GET`
- **Path:** `/hset`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HSET](https://upstash.com/docs/redis/overall/rediscompatibility)
