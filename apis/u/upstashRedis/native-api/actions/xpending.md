# XPENDING with Upstash Redis

Executes the XPENDING command in Upstash Redis to get pending messages info.

## Endpoint

- **Method:** `GET`
- **Path:** `/xpending`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [XPENDING](https://upstash.com/docs/redis/overall/rediscompatibility)
