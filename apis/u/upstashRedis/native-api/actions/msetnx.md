# MSETNX with Upstash Redis

Executes the MSETNX command in Upstash Redis to set multiple keys if none exist.

## Endpoint

- **Method:** `GET`
- **Path:** `/msetnx`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [MSETNX](https://upstash.com/docs/redis/overall/rediscompatibility)
