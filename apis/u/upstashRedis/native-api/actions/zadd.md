# ZADD with Upstash Redis

Executes the ZADD command in Upstash Redis to add members with scores.

## Endpoint

- **Method:** `GET`
- **Path:** `/zadd`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZADD](https://upstash.com/docs/redis/overall/rediscompatibility)
