# SPOP with Upstash Redis

Executes the SPOP command in Upstash Redis to remove random members.

## Endpoint

- **Method:** `GET`
- **Path:** `/spop`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [SPOP](https://upstash.com/docs/redis/overall/rediscompatibility)
