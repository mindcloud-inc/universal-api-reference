# DECR with Upstash Redis

Executes the DECR command in Upstash Redis to decrement integer value by 1.

## Endpoint

- **Method:** `GET`
- **Path:** `/decr`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [DECR](https://upstash.com/docs/redis/overall/rediscompatibility)
