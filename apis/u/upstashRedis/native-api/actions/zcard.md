# ZCARD with Upstash Redis

Executes the ZCARD command in Upstash Redis to get sorted set cardinality.

## Endpoint

- **Method:** `GET`
- **Path:** `/zcard`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZCARD](https://upstash.com/docs/redis/overall/rediscompatibility)
