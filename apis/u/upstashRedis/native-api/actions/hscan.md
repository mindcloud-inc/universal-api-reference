# HSCAN with Upstash Redis

Executes the HSCAN command in Upstash Redis to incrementally iterate hash fields.

## Endpoint

- **Method:** `GET`
- **Path:** `/hscan`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HSCAN](https://upstash.com/docs/redis/overall/rediscompatibility)
