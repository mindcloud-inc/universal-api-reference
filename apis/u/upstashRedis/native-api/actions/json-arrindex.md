# JSON.ARRINDEX with Upstash Redis

Executes the JSON.ARRINDEX command in Upstash Redis to find index of value in array.

## Endpoint

- **Method:** `GET`
- **Path:** `/json.arrindex`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [JSON.ARRINDEX](https://upstash.com/docs/redis/overall/rediscompatibility)
