# PTTL with Upstash Redis

Executes the PTTL command in Upstash Redis to get TTL in milliseconds.

## Endpoint

- **Method:** `GET`
- **Path:** `/pttl`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [PTTL](https://upstash.com/docs/redis/overall/rediscompatibility)
