# DBSIZE with Upstash Redis

Executes the DBSIZE command in Upstash Redis to get number of keys in database.

## Endpoint

- **Method:** `GET`
- **Path:** `/dbsize`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [DBSIZE](https://upstash.com/docs/redis/overall/rediscompatibility)
