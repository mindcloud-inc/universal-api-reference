# PFCOUNT with Upstash Redis

Executes the PFCOUNT command in Upstash Redis to get estimated cardinality.

## Endpoint

- **Method:** `GET`
- **Path:** `/pfcount`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [PFCOUNT](https://upstash.com/docs/redis/overall/rediscompatibility)
