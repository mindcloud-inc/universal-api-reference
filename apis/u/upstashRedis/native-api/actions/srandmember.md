# SRANDMEMBER with Upstash Redis

Executes the SRANDMEMBER command in Upstash Redis to get random members.

## Endpoint

- **Method:** `GET`
- **Path:** `/srandmember`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [SRANDMEMBER](https://upstash.com/docs/redis/overall/rediscompatibility)
