# UNLINK with Upstash Redis

Executes the UNLINK command in Upstash Redis to delete keys asynchronously.

## Endpoint

- **Method:** `GET`
- **Path:** `/unlink`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [UNLINK](https://upstash.com/docs/redis/overall/rediscompatibility)
