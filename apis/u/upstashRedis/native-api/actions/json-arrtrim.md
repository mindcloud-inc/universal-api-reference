# JSON.ARRTRIM with Upstash Redis

Executes the JSON.ARRTRIM command in Upstash Redis to trim JSON array to range.

## Endpoint

- **Method:** `GET`
- **Path:** `/json.arrtrim`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [JSON.ARRTRIM](https://upstash.com/docs/redis/overall/rediscompatibility)
