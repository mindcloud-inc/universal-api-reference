# PFMERGE with Upstash Redis

Executes the PFMERGE command in Upstash Redis to merge multiple HyperLogLogs.

## Endpoint

- **Method:** `GET`
- **Path:** `/pfmerge`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [PFMERGE](https://upstash.com/docs/redis/overall/rediscompatibility)
