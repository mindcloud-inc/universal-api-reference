# TYPE with Upstash Redis

Executes the TYPE command in Upstash Redis to get the type of a key.

## Endpoint

- **Method:** `GET`
- **Path:** `/type`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [TYPE](https://upstash.com/docs/redis/overall/rediscompatibility)
