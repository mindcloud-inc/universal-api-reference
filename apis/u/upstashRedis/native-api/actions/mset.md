# MSET with Upstash Redis

Executes the MSET command in Upstash Redis to set multiple keys at once.

## Endpoint

- **Method:** `GET`
- **Path:** `/mset`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [MSET](https://upstash.com/docs/redis/overall/rediscompatibility)
