# LINSERT with Upstash Redis

Executes the LINSERT command in Upstash Redis to insert before or after pivot.

## Endpoint

- **Method:** `GET`
- **Path:** `/linsert`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [LINSERT](https://upstash.com/docs/redis/overall/rediscompatibility)
