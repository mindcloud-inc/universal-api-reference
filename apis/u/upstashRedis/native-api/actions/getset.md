# GETSET with Upstash Redis

Executes the GETSET command in Upstash Redis to set value and return old value.

## Endpoint

- **Method:** `GET`
- **Path:** `/getset`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [GETSET](https://upstash.com/docs/redis/overall/rediscompatibility)
