# GETBIT with Upstash Redis

Executes the GETBIT command in Upstash Redis to get the bit value at offset.

## Endpoint

- **Method:** `GET`
- **Path:** `/getbit`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [GETBIT](https://upstash.com/docs/redis/overall/rediscompatibility)
