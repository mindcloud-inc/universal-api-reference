# RPOPLPUSH with Upstash Redis

Moves a list item from tail to head in Upstash Redis.

## Endpoint

- **Method:** `GET`
- **Path:** `/rpoplpush`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [RPOPLPUSH](https://upstash.com/docs/redis/overall/rediscompatibility)
