# DUMP with Upstash Redis

Executes the DUMP command in Upstash Redis to serialize a key’s value.

## Endpoint

- **Method:** `GET`
- **Path:** `/dump`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [DUMP](https://upstash.com/docs/redis/overall/rediscompatibility)
