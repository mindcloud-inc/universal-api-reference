# LPOS with Upstash Redis

Executes the LPOS command in Upstash Redis to find element position.

## Endpoint

- **Method:** `GET`
- **Path:** `/lpos`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [LPOS](https://upstash.com/docs/redis/overall/rediscompatibility)
