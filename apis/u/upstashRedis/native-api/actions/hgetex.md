# HGETEX with Upstash Redis

Executes the HGETEX command in Upstash Redis to get fields and set their expiry.

## Endpoint

- **Method:** `GET`
- **Path:** `/hgetex`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HGETEX](https://upstash.com/docs/redis/overall/rediscompatibility)
