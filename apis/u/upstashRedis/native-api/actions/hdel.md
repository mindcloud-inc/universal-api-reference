# HDEL with Upstash Redis

Executes the HDEL command in Upstash Redis to delete one or more hash fields.

## Endpoint

- **Method:** `GET`
- **Path:** `/hdel`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HDEL](https://upstash.com/docs/redis/overall/rediscompatibility)
