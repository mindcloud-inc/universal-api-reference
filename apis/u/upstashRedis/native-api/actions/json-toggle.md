# JSON.TOGGLE with Upstash Redis

Executes the JSON.TOGGLE command in Upstash Redis to toggle JSON boolean.

- **Method:** `GET`
- **Path:** `/json.toggle`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [JSON.TOGGLE](https://upstash.com/docs/redis/overall/rediscompatibility)
