# SREM with Upstash Redis

Executes the SREM command in Upstash Redis to remove members from a set.

## Endpoint

- **Method:** `GET`
- **Path:** `/srem`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [SREM](https://upstash.com/docs/redis/overall/rediscompatibility)
