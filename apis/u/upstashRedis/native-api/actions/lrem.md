# LREM with Upstash Redis

Executes the LREM command in Upstash Redis to remove elements by value.

## Endpoint

- **Method:** `GET`
- **Path:** `/lrem`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [LREM](https://upstash.com/docs/redis/overall/rediscompatibility)
