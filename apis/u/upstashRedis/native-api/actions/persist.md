# PERSIST with Upstash Redis

Executes the PERSIST command in Upstash Redis to remove the expiration from a key.

## Endpoint

- **Method:** `GET`
- **Path:** `/persist`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [PERSIST](https://upstash.com/docs/redis/overall/rediscompatibility)
