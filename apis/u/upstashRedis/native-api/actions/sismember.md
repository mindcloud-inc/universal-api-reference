# SISMEMBER with Upstash Redis

Executes the SISMEMBER command in Upstash Redis to check if member exists in set.

- **Path:** `/sismember`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [SISMEMBER](https://upstash.com/docs/redis/overall/rediscompatibility)
