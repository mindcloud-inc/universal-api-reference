# ZRANGE with Upstash Redis

Executes the ZRANGE command in Upstash Redis to get members by index range.

## Endpoint

- **Method:** `GET`
- **Path:** `/zrange`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZRANGE](https://upstash.com/docs/redis/overall/rediscompatibility)
