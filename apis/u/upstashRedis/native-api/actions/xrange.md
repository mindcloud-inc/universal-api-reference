# XRANGE with Upstash Redis

Executes the XRANGE command in Upstash Redis to get range of stream entries.

## Endpoint

- **Method:** `GET`
- **Path:** `/xrange`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [XRANGE](https://upstash.com/docs/redis/overall/rediscompatibility)
