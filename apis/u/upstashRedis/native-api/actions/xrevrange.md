# XREVRANGE with Upstash Redis

Executes the XREVRANGE command in Upstash Redis to get range in reverse order.

## Endpoint

- **Method:** `GET`
- **Path:** `/xrevrange`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [XREVRANGE](https://upstash.com/docs/redis/overall/rediscompatibility)
