# LPUSHX with Upstash Redis

Executes the LPUSHX command in Upstash Redis to push to head if list exists.

- **Path:** `/lpushx`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [LPUSHX](https://upstash.com/docs/redis/overall/rediscompatibility)
