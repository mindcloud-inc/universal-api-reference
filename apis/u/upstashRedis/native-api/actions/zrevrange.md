# ZREVRANGE with Upstash Redis

Executes the ZREVRANGE command in Upstash Redis to get members in reverse order.

## Endpoint

- **Method:** `GET`
- **Path:** `/zrevrange`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZREVRANGE](https://upstash.com/docs/redis/overall/rediscompatibility)
