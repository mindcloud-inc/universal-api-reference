# GEOHASH with Upstash Redis

Executes the GEOHASH command in Upstash Redis to get geohash strings for members.

## Endpoint

- **Method:** `GET`
- **Path:** `/geohash`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [GEOHASH](https://upstash.com/docs/redis/overall/rediscompatibility)
