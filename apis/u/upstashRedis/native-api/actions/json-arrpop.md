# JSON.ARRPOP with Upstash Redis

Executes the JSON.ARRPOP command in Upstash Redis to pop value from JSON array.

## Endpoint

- **Method:** `GET`
- **Path:** `/json.arrpop`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [JSON.ARRPOP](https://upstash.com/docs/redis/overall/rediscompatibility)
