# INCR with Upstash Redis

Executes the INCR command in Upstash Redis to increment integer value by 1.

## Endpoint

- **Method:** `GET`
- **Path:** `/incr`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [INCR](https://upstash.com/docs/redis/overall/rediscompatibility)
