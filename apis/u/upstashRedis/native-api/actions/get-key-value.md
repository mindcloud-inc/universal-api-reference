# Get Key Value with Upstash Redis

Retrieves a key value from Upstash Redis.

## Endpoint

- **Method:** `GET`
- **Path:** `/get/:key`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [Get Key Value](https://upstash.com/docs/redis/features/restapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | Redis key to read. |
