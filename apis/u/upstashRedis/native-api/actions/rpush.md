# RPUSH with Upstash Redis

Executes the RPUSH command in Upstash Redis to push to list tail.

## Endpoint

- **Method:** `GET`
- **Path:** `/rpush`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [RPUSH](https://upstash.com/docs/redis/overall/rediscompatibility)
