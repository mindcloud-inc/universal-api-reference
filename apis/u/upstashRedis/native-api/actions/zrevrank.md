# ZREVRANK with Upstash Redis

Executes the ZREVRANK command in Upstash Redis to get member’s reverse rank.

## Endpoint

- **Method:** `GET`
- **Path:** `/zrevrank`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZREVRANK](https://upstash.com/docs/redis/overall/rediscompatibility)
