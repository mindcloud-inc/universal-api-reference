# HTTL with Upstash Redis

Executes the HTTL command in Upstash Redis to get field TTL in seconds.

## Endpoint

- **Method:** `GET`
- **Path:** `/httl`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HTTL](https://upstash.com/docs/redis/overall/rediscompatibility)
