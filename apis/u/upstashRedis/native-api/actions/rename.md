# RENAME with Upstash Redis

Executes the RENAME command in Upstash Redis to rename a key.

- **Method:** `GET`
- **Path:** `/rename`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [RENAME](https://upstash.com/docs/redis/overall/rediscompatibility)
