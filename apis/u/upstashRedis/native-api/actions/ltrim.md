# LTRIM with Upstash Redis

Executes the LTRIM command in Upstash Redis to trim list to range.

## Endpoint

- **Method:** `GET`
- **Path:** `/ltrim`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [LTRIM](https://upstash.com/docs/redis/overall/rediscompatibility)
