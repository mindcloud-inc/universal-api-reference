# HRANDFIELD with Upstash Redis

Executes the HRANDFIELD command in Upstash Redis to get random fields from a hash.

## Endpoint

- **Method:** `GET`
- **Path:** `/hrandfield`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HRANDFIELD](https://upstash.com/docs/redis/overall/rediscompatibility)
