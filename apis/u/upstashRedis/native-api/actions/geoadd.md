# GEOADD with Upstash Redis

Executes the GEOADD command in Upstash Redis to add geospatial items.

## Endpoint

- **Method:** `GET`
- **Path:** `/geoadd`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [GEOADD](https://upstash.com/docs/redis/overall/rediscompatibility)
