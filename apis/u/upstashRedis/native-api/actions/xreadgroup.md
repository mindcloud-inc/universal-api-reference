# XREADGROUP with Upstash Redis

Executes the XREADGROUP command in Upstash Redis to read as consumer group.

- **Path:** `/xreadgroup`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [XREADGROUP](https://upstash.com/docs/redis/overall/rediscompatibility)
