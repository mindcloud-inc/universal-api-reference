# SDIFFSTORE with Upstash Redis

Executes the SDIFFSTORE command in Upstash Redis to store set difference.

## Endpoint

- **Method:** `GET`
- **Path:** `/sdiffstore`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [SDIFFSTORE](https://upstash.com/docs/redis/overall/rediscompatibility)
