# BITOP with Upstash Redis

Executes the BITOP command in Upstash Redis to perform bitwise operations between strings.

## Endpoint

- **Method:** `GET`
- **Path:** `/bitop`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [BITOP](https://upstash.com/docs/redis/overall/rediscompatibility)
