# HEXPIRETIME with Upstash Redis

Executes the HEXPIRETIME command in Upstash Redis to get field expiry as timestamp.

## Endpoint

- **Method:** `GET`
- **Path:** `/hexpiretime`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HEXPIRETIME](https://upstash.com/docs/redis/overall/rediscompatibility)
