# XTRIM with Upstash Redis

Executes the XTRIM command in Upstash Redis to trim stream to max length.

## Endpoint

- **Method:** `GET`
- **Path:** `/xtrim`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [XTRIM](https://upstash.com/docs/redis/overall/rediscompatibility)
