# MGET with Upstash Redis

Executes the MGET command in Upstash Redis to get values of multiple keys.

## Endpoint

- **Method:** `GET`
- **Path:** `/mget`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [MGET](https://upstash.com/docs/redis/overall/rediscompatibility)
