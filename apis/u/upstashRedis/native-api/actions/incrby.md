# INCRBY with Upstash Redis

Executes the INCRBY command in Upstash Redis to increment integer by amount.

## Endpoint

- **Method:** `GET`
- **Path:** `/incrby`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [INCRBY](https://upstash.com/docs/redis/overall/rediscompatibility)
