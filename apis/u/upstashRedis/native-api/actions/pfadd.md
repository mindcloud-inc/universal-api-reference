# PFADD with Upstash Redis

Executes the PFADD command in Upstash Redis to add elements to HyperLogLog.

## Endpoint

- **Method:** `GET`
- **Path:** `/pfadd`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [PFADD](https://upstash.com/docs/redis/overall/rediscompatibility)
