# LRANGE with Upstash Redis

Executes the LRANGE command in Upstash Redis to get range of elements.

## Endpoint

- **Method:** `GET`
- **Path:** `/lrange`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [LRANGE](https://upstash.com/docs/redis/overall/rediscompatibility)
