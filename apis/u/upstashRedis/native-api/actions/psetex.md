# PSETEX with Upstash Redis

Executes the PSETEX command in Upstash Redis to set value with ms expiration.

## Endpoint

- **Method:** `GET`
- **Path:** `/psetex`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [PSETEX](https://upstash.com/docs/redis/overall/rediscompatibility)
