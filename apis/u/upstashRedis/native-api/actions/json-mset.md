# JSON.MSET with Upstash Redis

Executes the JSON.MSET command in Upstash Redis to set values in multiple keys.

- **Method:** `GET`
- **Path:** `/json.mset`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [JSON.MSET](https://upstash.com/docs/redis/overall/rediscompatibility)
