# DECRBY with Upstash Redis

Executes the DECRBY command in Upstash Redis to decrement integer by amount.

## Endpoint

- **Method:** `GET`
- **Path:** `/decrby`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [DECRBY](https://upstash.com/docs/redis/overall/rediscompatibility)
