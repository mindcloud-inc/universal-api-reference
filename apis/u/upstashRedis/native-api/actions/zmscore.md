# ZMSCORE with Upstash Redis

Executes the ZMSCORE command in Upstash Redis to get scores of multiple members.

## Endpoint

- **Method:** `GET`
- **Path:** `/zmscore`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZMSCORE](https://upstash.com/docs/redis/overall/rediscompatibility)
