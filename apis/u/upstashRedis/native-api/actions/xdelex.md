# XDELEX with Upstash Redis

Executes the XDELEX command in Upstash Redis to delete entries with expiration.

## Endpoint

- **Method:** `GET`
- **Path:** `/xdelex`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [XDELEX](https://upstash.com/docs/redis/overall/rediscompatibility)
