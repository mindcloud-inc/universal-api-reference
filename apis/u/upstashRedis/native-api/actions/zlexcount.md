# ZLEXCOUNT with Upstash Redis

Executes the ZLEXCOUNT command in Upstash Redis to count members in lex range.

## Endpoint

- **Method:** `GET`
- **Path:** `/zlexcount`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZLEXCOUNT](https://upstash.com/docs/redis/overall/rediscompatibility)
