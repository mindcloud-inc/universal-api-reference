# BITCOUNT with Upstash Redis

Executes the BITCOUNT command in Upstash Redis to count set bits in a string.

## Endpoint

- **Method:** `GET`
- **Path:** `/bitcount`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [BITCOUNT](https://upstash.com/docs/redis/overall/rediscompatibility)
