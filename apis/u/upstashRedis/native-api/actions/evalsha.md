Executes the EVALSHA command in Upstash Redis to execute cached Lua script by SHA.

- **Path:** `/evalsha`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [EVALSHA](https://upstash.com/docs/redis/overall/rediscompatibility)
