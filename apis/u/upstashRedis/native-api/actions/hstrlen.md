# HSTRLEN with Upstash Redis

Executes the HSTRLEN command in Upstash Redis to get length of a field’s value.

## Endpoint

- **Method:** `GET`
- **Path:** `/hstrlen`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HSTRLEN](https://upstash.com/docs/redis/overall/rediscompatibility)
