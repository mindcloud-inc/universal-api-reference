# SETNX with Upstash Redis

Executes the SETNX command in Upstash Redis to set value if key doesn’t exist.

## Endpoint

- **Method:** `GET`
- **Path:** `/setnx`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [SETNX](https://upstash.com/docs/redis/overall/rediscompatibility)
