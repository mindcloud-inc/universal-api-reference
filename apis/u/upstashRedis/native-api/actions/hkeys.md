# HKEYS with Upstash Redis

Executes the HKEYS command in Upstash Redis to get all fields in a hash.

## Endpoint

- **Method:** `GET`
- **Path:** `/hkeys`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HKEYS](https://upstash.com/docs/redis/overall/rediscompatibility)
