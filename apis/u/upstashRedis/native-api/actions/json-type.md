# JSON.TYPE with Upstash Redis

Executes the JSON.TYPE command in Upstash Redis to get JSON value type.

- **Method:** `GET`
- **Path:** `/json.type`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [JSON.TYPE](https://upstash.com/docs/redis/overall/rediscompatibility)
