# ZSCORE with Upstash Redis

Executes the ZSCORE command in Upstash Redis to get member’s score.

## Endpoint

- **Method:** `GET`
- **Path:** `/zscore`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZSCORE](https://upstash.com/docs/redis/overall/rediscompatibility)
