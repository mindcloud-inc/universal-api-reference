# PEXPIRETIME with Upstash Redis

Executes the PEXPIRETIME command in Upstash Redis to get expiry as Unix ms timestamp.

## Endpoint

- **Method:** `GET`
- **Path:** `/pexpiretime`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [PEXPIRETIME](https://upstash.com/docs/redis/overall/rediscompatibility)
