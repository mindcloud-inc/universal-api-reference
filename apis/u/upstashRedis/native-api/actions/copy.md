# COPY with Upstash Redis

Executes the COPY command in Upstash Redis to copy a key to another key.

## Endpoint

- **Method:** `GET`
- **Path:** `/copy`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [COPY](https://upstash.com/docs/redis/overall/rediscompatibility)
