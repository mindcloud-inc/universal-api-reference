# XINFO CONSUMERS with Upstash Redis

Executes the XINFO CONSUMERS command in Upstash Redis to list group consumers.

## Endpoint

- **Method:** `GET`
- **Path:** `/xinfo/consumers`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [XINFO CONSUMERS](https://upstash.com/docs/redis/overall/rediscompatibility)
