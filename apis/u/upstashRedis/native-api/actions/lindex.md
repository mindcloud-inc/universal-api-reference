# LINDEX with Upstash Redis

Executes the LINDEX command in Upstash Redis to get element by index.

## Endpoint

- **Method:** `GET`
- **Path:** `/lindex`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [LINDEX](https://upstash.com/docs/redis/overall/rediscompatibility)
