# LMOVE with Upstash Redis

Executes the LMOVE command in Upstash Redis to move element between lists.

## Endpoint

- **Method:** `GET`
- **Path:** `/lmove`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [LMOVE](https://upstash.com/docs/redis/overall/rediscompatibility)
