# PEXPIREAT with Upstash Redis

Executes the PEXPIREAT command in Upstash Redis to set expiry as Unix ms timestamp.

## Endpoint

- **Method:** `GET`
- **Path:** `/pexpireat`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [PEXPIREAT](https://upstash.com/docs/redis/overall/rediscompatibility)
