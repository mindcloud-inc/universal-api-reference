# UNSUBSCRIBE with Upstash Redis

Executes the UNSUBSCRIBE command in Upstash Redis to unsubscribe from channels.

## Endpoint

- **Method:** `GET`
- **Path:** `/unsubscribe`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [UNSUBSCRIBE](https://upstash.com/docs/redis/overall/rediscompatibility)
