# ZRANDMEMBER with Upstash Redis

Executes the ZRANDMEMBER command in Upstash Redis to get random members.

## Endpoint

- **Method:** `GET`
- **Path:** `/zrandmember`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZRANDMEMBER](https://upstash.com/docs/redis/overall/rediscompatibility)
