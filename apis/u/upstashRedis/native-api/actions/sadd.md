# SADD with Upstash Redis

Executes the SADD command in Upstash Redis to add members to a set.

## Endpoint

- **Method:** `GET`
- **Path:** `/sadd`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [SADD](https://upstash.com/docs/redis/overall/rediscompatibility)
