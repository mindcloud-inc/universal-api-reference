# HPTTL with Upstash Redis

Executes the HPTTL command in Upstash Redis to get field TTL in milliseconds.

## Endpoint

- **Method:** `GET`
- **Path:** `/hpttl`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HPTTL](https://upstash.com/docs/redis/overall/rediscompatibility)
