# JSON.STRLEN with Upstash Redis

Executes the JSON.STRLEN command in Upstash Redis to get JSON string length.

## Endpoint

- **Method:** `GET`
- **Path:** `/json.strlen`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [JSON.STRLEN](https://upstash.com/docs/redis/overall/rediscompatibility)
