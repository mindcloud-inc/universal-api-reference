# FLUSHALL with Upstash Redis

Executes the FLUSHALL command in Upstash Redis to delete all keys in all databases.

## Endpoint

- **Method:** `GET`
- **Path:** `/flushall`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [FLUSHALL](https://upstash.com/docs/redis/overall/rediscompatibility)
