# XDEL with Upstash Redis

Executes the XDEL command in Upstash Redis to delete stream entries.

## Endpoint

- **Method:** `GET`
- **Path:** `/xdel`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [XDEL](https://upstash.com/docs/redis/overall/rediscompatibility)
