# ZMPOP with Upstash Redis

Executes the ZMPOP command in Upstash Redis to pop members from sorted sets.

## Endpoint

- **Method:** `GET`
- **Path:** `/zmpop`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZMPOP](https://upstash.com/docs/redis/overall/rediscompatibility)
