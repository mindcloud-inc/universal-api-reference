# ZDIFFSTORE with Upstash Redis

Executes the ZDIFFSTORE command in Upstash Redis to store sorted set difference.

## Endpoint

- **Method:** `GET`
- **Path:** `/zdiffstore`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZDIFFSTORE](https://upstash.com/docs/redis/overall/rediscompatibility)
