# JSON.CLEAR with Upstash Redis

Executes the JSON.CLEAR command in Upstash Redis to clear JSON values.

## Endpoint

- **Method:** `GET`
- **Path:** `/json.clear`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [JSON.CLEAR](https://upstash.com/docs/redis/overall/rediscompatibility)
