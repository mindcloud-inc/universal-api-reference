# GEODIST with Upstash Redis

Executes the GEODIST command in Upstash Redis to get distance between two members.

## Endpoint

- **Method:** `GET`
- **Path:** `/geodist`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [GEODIST](https://upstash.com/docs/redis/overall/rediscompatibility)
