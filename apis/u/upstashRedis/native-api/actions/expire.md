# EXPIRE with Upstash Redis

Executes the EXPIRE command in Upstash Redis to set a key’s TTL in seconds.

## Endpoint

- **Method:** `GET`
- **Path:** `/expire`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [EXPIRE](https://upstash.com/docs/redis/overall/rediscompatibility)
