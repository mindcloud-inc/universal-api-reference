# SETEX with Upstash Redis

Executes the SETEX command in Upstash Redis to set value with expiration.

## Endpoint

- **Method:** `GET`
- **Path:** `/setex`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [SETEX](https://upstash.com/docs/redis/overall/rediscompatibility)
