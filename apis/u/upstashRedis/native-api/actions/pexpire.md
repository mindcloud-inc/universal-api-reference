# PEXPIRE with Upstash Redis

Executes the PEXPIRE command in Upstash Redis to set a key’s TTL in milliseconds.

## Endpoint

- **Method:** `GET`
- **Path:** `/pexpire`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [PEXPIRE](https://upstash.com/docs/redis/overall/rediscompatibility)
