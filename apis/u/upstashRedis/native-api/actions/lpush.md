# LPUSH with Upstash Redis

Executes the LPUSH command in Upstash Redis to push to list head.

## Endpoint

- **Method:** `GET`
- **Path:** `/lpush`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [LPUSH](https://upstash.com/docs/redis/overall/rediscompatibility)
