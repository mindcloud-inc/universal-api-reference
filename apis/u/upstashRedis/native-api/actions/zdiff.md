# ZDIFF with Upstash Redis

Executes the ZDIFF command in Upstash Redis to get sorted set difference.

## Endpoint

- **Method:** `GET`
- **Path:** `/zdiff`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZDIFF](https://upstash.com/docs/redis/overall/rediscompatibility)
