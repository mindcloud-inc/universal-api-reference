# FLUSHDB with Upstash Redis

Executes the FLUSHDB command in Upstash Redis to delete all keys in current database.

## Endpoint

- **Method:** `GET`
- **Path:** `/flushdb`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [FLUSHDB](https://upstash.com/docs/redis/overall/rediscompatibility)
