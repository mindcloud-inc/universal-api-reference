# XINFO GROUPS with Upstash Redis

Executes the XINFO GROUPS command in Upstash Redis to list stream groups.

## Endpoint

- **Method:** `GET`
- **Path:** `/xinfo/groups`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [XINFO GROUPS](https://upstash.com/docs/redis/overall/rediscompatibility)
