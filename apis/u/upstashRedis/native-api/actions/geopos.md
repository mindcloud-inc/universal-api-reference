# GEOPOS with Upstash Redis

Executes the GEOPOS command in Upstash Redis to get coordinates of members.

## Endpoint

- **Method:** `GET`
- **Path:** `/geopos`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [GEOPOS](https://upstash.com/docs/redis/overall/rediscompatibility)
