# JSON.OBJLEN with Upstash Redis

Executes the JSON.OBJLEN command in Upstash Redis to get JSON object size.

## Endpoint

- **Method:** `GET`
- **Path:** `/json.objlen`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [JSON.OBJLEN](https://upstash.com/docs/redis/overall/rediscompatibility)
