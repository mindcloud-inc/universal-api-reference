# PUNSUBSCRIBE with Upstash Redis

Executes the PUNSUBSCRIBE command in Upstash Redis to unsubscribe from patterns.

## Endpoint

- **Method:** `GET`
- **Path:** `/punsubscribe`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [PUNSUBSCRIBE](https://upstash.com/docs/redis/overall/rediscompatibility)
