# TIME with Upstash Redis

Executes the TIME command in Upstash Redis to get current server time.

## Endpoint

- **Method:** `GET`
- **Path:** `/time`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [TIME](https://upstash.com/docs/redis/overall/rediscompatibility)
