# ZSCAN with Upstash Redis

Executes the ZSCAN command in Upstash Redis to incrementally iterate sorted set.

## Endpoint

- **Method:** `GET`
- **Path:** `/zscan`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZSCAN](https://upstash.com/docs/redis/overall/rediscompatibility)
