# HPEXPIRE with Upstash Redis

Executes the HPEXPIRE command in Upstash Redis to set field TTL in milliseconds.

## Endpoint

- **Method:** `GET`
- **Path:** `/hpexpire`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HPEXPIRE](https://upstash.com/docs/redis/overall/rediscompatibility)
