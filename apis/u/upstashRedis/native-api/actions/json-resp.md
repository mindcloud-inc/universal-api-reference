# JSON.RESP with Upstash Redis

Executes the JSON.RESP command in Upstash Redis to get JSON in RESP format.

## Endpoint

- **Method:** `GET`
- **Path:** `/json.resp`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [JSON.RESP](https://upstash.com/docs/redis/overall/rediscompatibility)
