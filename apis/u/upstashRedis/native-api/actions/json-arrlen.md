# JSON.ARRLEN with Upstash Redis

Executes the JSON.ARRLEN command in Upstash Redis to get JSON array length.

## Endpoint

- **Method:** `GET`
- **Path:** `/json.arrlen`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [JSON.ARRLEN](https://upstash.com/docs/redis/overall/rediscompatibility)
