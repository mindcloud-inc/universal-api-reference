# HPEXPIREAT with Upstash Redis

Executes the HPEXPIREAT command in Upstash Redis to set field expiry as ms timestamp.

## Endpoint

- **Method:** `GET`
- **Path:** `/hpexpireat`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [HPEXPIREAT](https://upstash.com/docs/redis/overall/rediscompatibility)
