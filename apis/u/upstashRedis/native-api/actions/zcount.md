# ZCOUNT with Upstash Redis

Executes the ZCOUNT command in Upstash Redis to count members in score range.

## Endpoint

- **Method:** `GET`
- **Path:** `/zcount`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [ZCOUNT](https://upstash.com/docs/redis/overall/rediscompatibility)
