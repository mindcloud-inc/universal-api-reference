# RESTORE with Upstash Redis

Executes the RESTORE command in Upstash Redis to deserialize and restore a key.

## Endpoint

- **Method:** `GET`
- **Path:** `/restore`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [RESTORE](https://upstash.com/docs/redis/overall/rediscompatibility)
