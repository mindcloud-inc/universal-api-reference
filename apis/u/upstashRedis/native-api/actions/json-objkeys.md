# JSON.OBJKEYS with Upstash Redis

Executes the JSON.OBJKEYS command in Upstash Redis to get JSON object keys.

## Endpoint

- **Method:** `GET`
- **Path:** `/json.objkeys`
- **Base URL:** `https://choice-oriole-98954.upstash.io`
- **Official documentation:** [JSON.OBJKEYS](https://upstash.com/docs/redis/overall/rediscompatibility)
