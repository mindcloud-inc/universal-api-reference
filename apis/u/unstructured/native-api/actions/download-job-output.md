# Download Job Output with Unstructured

Downloads job output from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id/download`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Download Job Output](https://docs.unstructured.io/api-reference/jobs/download-job-output)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | The job ID. |
