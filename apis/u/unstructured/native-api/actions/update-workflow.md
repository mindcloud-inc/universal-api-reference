# Update Workflow with Unstructured

Updates a workflow in Unstructured.

## Endpoint

- **Method:** `PUT`
- **Path:** `/workflows/:workflow_id`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Update Workflow](https://docs.unstructured.io/api-reference/workflows/update-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflow_id` | path | `string` | yes | The workflow ID. |
