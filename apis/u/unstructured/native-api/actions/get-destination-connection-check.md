# Get Destination Connection Check with Unstructured

Retrieves a destination connection check from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/destinations/:destination_id/connection-check`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Get Destination Connection Check](https://docs.unstructured.io/api-reference/destinations/get-destination-connection-check)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `destination_id` | path | `string` | yes | The destination connector ID. |
