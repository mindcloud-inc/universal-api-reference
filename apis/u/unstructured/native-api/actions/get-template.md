# Get Template with Unstructured

Retrieves a template from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:template_id`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Get Template](https://docs.unstructured.io/api-reference/templates/get-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The template ID. |
