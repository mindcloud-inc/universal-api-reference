# Get Destination Connector with Unstructured

Retrieves a destination connector from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/destinations/:destination_id`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Get Destination Connector](https://docs.unstructured.io/api-reference/destinations/get-destination-connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `destination_id` | path | `string` | yes | The destination connector ID. |
