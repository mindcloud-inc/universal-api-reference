# Get Job Details with Unstructured

Retrieves job details from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id/details`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Get Job Details](https://docs.unstructured.io/api-reference/jobs/get-job-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | The job ID. |
