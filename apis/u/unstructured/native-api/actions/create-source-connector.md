# Create Source Connector with Unstructured

Creates a source connector in Unstructured.

## Endpoint

- **Method:** `POST`
- **Path:** `/sources/`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Create Source Connector](https://docs.unstructured.io/api-reference/sources/create-source-connector)
