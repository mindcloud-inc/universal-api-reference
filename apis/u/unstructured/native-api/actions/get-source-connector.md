# Get Source Connector with Unstructured

Retrieves a source connector from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/sources/:source_id`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Get Source Connector](https://docs.unstructured.io/api-reference/sources/get-source-connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `source_id` | path | `string` | yes | The source connector ID. |
