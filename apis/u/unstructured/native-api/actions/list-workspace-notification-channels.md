# List Workspace Notification Channels with Unstructured

Retrieves workspace notification channels from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications/channels`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [List Workspace Notification Channels](https://docs.unstructured.io/api-reference/webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_type` | query | `string` | no | Filter by channel type. |
