# Get Notification with Unstructured

Retrieves a notification from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications/:notification_id`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Get Notification](https://docs.unstructured.io/api-reference/webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `notification_id` | path | `string` | yes | Notification ID. |
