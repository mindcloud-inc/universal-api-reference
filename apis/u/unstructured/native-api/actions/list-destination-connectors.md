# List Destination Connectors with Unstructured

Retrieves a list of destination connectors from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/destinations/`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [List Destination Connectors](https://docs.unstructured.io/api-reference/destinations/list-destination-connectors)
