# Update Source Connector with Unstructured

Updates a source connector in Unstructured.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sources/:source_id`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Update Source Connector](https://docs.unstructured.io/api-reference/sources/update-source-connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `source_id` | path | `string` | yes | The source connector ID. |
