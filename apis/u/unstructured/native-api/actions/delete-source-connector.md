# Delete Source Connector with Unstructured

Deletes a source connector from Unstructured.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sources/:source_id`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Delete Source Connector](https://docs.unstructured.io/api-reference/sources/delete-source-connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `source_id` | path | `string` | yes | The source connector ID. |
