# List Workflows with Unstructured

Retrieves a list of workflows from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [List Workflows](https://docs.unstructured.io/api-reference/workflows/list-workflows)
