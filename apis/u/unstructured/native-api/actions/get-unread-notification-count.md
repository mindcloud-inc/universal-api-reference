# Get Unread Notification Count with Unstructured

Retrieves the unread notification count from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications/unread-count`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Get Unread Notification Count](https://docs.unstructured.io/api-reference/webhooks)
