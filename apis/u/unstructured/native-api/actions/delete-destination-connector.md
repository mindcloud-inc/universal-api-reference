# Delete Destination Connector with Unstructured

Deletes a destination connector from Unstructured.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/destinations/:destination_id`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Delete Destination Connector](https://docs.unstructured.io/api-reference/destinations/delete-destination-connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `destination_id` | path | `string` | yes | The destination connector ID. |
