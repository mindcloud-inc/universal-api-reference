# Get Source Connection Check with Unstructured

Retrieves a source connection check from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/sources/:source_id/connection-check`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Get Source Connection Check](https://docs.unstructured.io/api-reference/sources/get-source-connection-check)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `source_id` | path | `string` | yes | The source connector ID. |
