# Create On-Demand Job with Unstructured

Creates an on-demand job in Unstructured.

## Endpoint

- **Method:** `POST`
- **Path:** `/jobs/`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Create On-Demand Job](https://docs.unstructured.io/api-reference/quickstart)
