# Update Destination Connector with Unstructured

Updates a destination connector in Unstructured.

## Endpoint

- **Method:** `PUT`
- **Path:** `/destinations/:destination_id`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Update Destination Connector](https://docs.unstructured.io/api-reference/destinations/update-destination-connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `destination_id` | path | `string` | yes | The destination connector ID. |
