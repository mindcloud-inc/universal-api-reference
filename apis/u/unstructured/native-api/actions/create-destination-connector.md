# Create Destination Connector with Unstructured

Creates a destination connector in Unstructured.

## Endpoint

- **Method:** `POST`
- **Path:** `/destinations/`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Create Destination Connector](https://docs.unstructured.io/api-reference/destinations/create-destination-connector)
