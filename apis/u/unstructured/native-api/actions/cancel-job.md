# Cancel Job with Unstructured

Cancels a job in Unstructured.

## Endpoint

- **Method:** `POST`
- **Path:** `/jobs/:job_id/cancel`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Cancel Job](https://docs.unstructured.io/api-reference/jobs/cancel-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | The job ID. |
