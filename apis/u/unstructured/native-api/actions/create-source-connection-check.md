# Create Source Connection Check with Unstructured

Creates a source connection check in Unstructured.

## Endpoint

- **Method:** `POST`
- **Path:** `/sources/:source_id/connection-check`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Create Source Connection Check](https://docs.unstructured.io/api-reference/sources/create-source-connection-check)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `source_id` | path | `string` | yes | The source connector ID. |
