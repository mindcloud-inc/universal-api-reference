# Delete Workflow with Unstructured

Deletes a workflow from Unstructured.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workflows/:workflow_id`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Delete Workflow](https://docs.unstructured.io/api-reference/workflows/delete-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflow_id` | path | `string` | yes | The workflow ID. |
