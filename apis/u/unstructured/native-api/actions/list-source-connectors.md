# List Source Connectors with Unstructured

Retrieves a list of source connectors from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/sources/`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [List Source Connectors](https://docs.unstructured.io/api-reference/sources/list-source-connectors)
