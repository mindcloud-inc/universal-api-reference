# Get Workflow with Unstructured

Retrieves a workflow from Unstructured.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/:workflow_id`
- **Base URL:** `https://platform.unstructuredapp.io/api/v1`
- **Official documentation:** [Get Workflow](https://docs.unstructured.io/api-reference/workflows/get-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflow_id` | path | `string` | yes | The workflow ID. |
