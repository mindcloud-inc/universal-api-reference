# List Travel Percentages with USAJOBS

Retrieves travel percentage codes from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/travelpercentages`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Travel Percentages](https://developer.usajobs.gov/api-reference/get-codelist-travelpercentages)
