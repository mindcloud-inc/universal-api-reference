# List Postal Codes with USAJOBS

Retrieves postal code listings from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/postalcodes`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Postal Codes](https://developer.usajobs.gov/api-reference/get-codelist-postalcodes)
