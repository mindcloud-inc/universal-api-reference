# List Position Opening Statuses with USAJOBS

Retrieves position opening statuses from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/positionopeningstatuses`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Position Opening Statuses](https://developer.usajobs.gov/api-reference/get-codelist-positionopeningstatuses)
