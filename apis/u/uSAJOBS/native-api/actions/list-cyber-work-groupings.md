# List Cyber Work Groupings with USAJOBS

Retrieves cyber work groupings from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/cyberworkgroupings`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Cyber Work Groupings](https://developer.usajobs.gov/api-reference/get-codelist-cyberworkgroupings)
