# List Mission Critical Codes with USAJOBS

Retrieves mission critical codes from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/missioncriticalcodes`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Mission Critical Codes](https://developer.usajobs.gov/api-reference/get-codelist-missioncriticalcodes)
