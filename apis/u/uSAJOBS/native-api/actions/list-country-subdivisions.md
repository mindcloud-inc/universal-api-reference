# List Country Subdivisions with USAJOBS

Retrieves country subdivision codes from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/countrysubdivisions`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Country Subdivisions](https://developer.usajobs.gov/api-reference/get-codelist-countrysubdivisions)
