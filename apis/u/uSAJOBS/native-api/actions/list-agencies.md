# List Agencies with USAJOBS

Retrieves agency subelement codes from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/agencysubelements`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Agencies](https://developer.usajobs.gov/api-reference/get-codelist-agencysubelements)
