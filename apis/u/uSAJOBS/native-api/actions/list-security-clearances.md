# List Security Clearances with USAJOBS

Retrieves security clearance codes from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/securityclearances`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Security Clearances](https://developer.usajobs.gov/api-reference/get-codelist-securityclearances)
