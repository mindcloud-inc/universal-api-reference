# List Position Schedule Types with USAJOBS

Retrieves position schedule types from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/positionscheduletypes`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Position Schedule Types](https://developer.usajobs.gov/api-reference/get-codelist-positionscheduletypes)
