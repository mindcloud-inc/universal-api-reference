# List Position Offering Types with USAJOBS

Retrieves position offering types from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/positionofferingtypes`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Position Offering Types](https://developer.usajobs.gov/api-reference/get-codelist-positionofferingtypes)
