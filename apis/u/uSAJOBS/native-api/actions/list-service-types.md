# List Service Types with USAJOBS

Retrieves service type codes from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/servicetypes`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Service Types](https://developer.usajobs.gov/api-reference/get-codelist-servicetypes)
