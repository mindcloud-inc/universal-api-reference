# List Hiring Paths with USAJOBS

Retrieves hiring path codes from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/hiringpaths`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Hiring Paths](https://developer.usajobs.gov/api-reference/get-codelist-hiringpaths)
