# List Geographic Location Codes with USAJOBS

Retrieves geographic location codes from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/geoloccodes`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Geographic Location Codes](https://developer.usajobs.gov/api-reference/get-codelist-geoloccodes)
