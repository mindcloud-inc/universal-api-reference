# List Cyber Work Roles with USAJOBS

Retrieves cyber work roles from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/cyberworkroles`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Cyber Work Roles](https://developer.usajobs.gov/api-reference/get-codelist-cyberworkroles)
