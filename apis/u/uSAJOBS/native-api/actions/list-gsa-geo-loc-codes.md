# List GSA Geo-Loc Codes with USAJOBS

Retrieves GSA geo-loc codes from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/gsageoloccodes`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List GSA Geo-Loc Codes](https://developer.usajobs.gov/api-reference/get-codelist-gsageoloccodes)
