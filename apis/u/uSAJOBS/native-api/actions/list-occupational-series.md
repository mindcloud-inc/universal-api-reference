# List Occupational Series with USAJOBS

Retrieves occupational series codes from USAJOBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/codelist/occupationalseries`
- **Base URL:** `https://data.usajobs.gov`
- **Official documentation:** [List Occupational Series](https://developer.usajobs.gov/api-reference/get-codelist-occupationalseries)
