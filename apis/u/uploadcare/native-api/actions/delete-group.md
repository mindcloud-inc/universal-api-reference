# Delete Group with Uploadcare

Deletes an existing group from Uploadcare.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/:uuid/`
- **Base URL:** `https://api.uploadcare.com`
- **Official documentation:** [Delete Group](https://uploadcare.com/api-refs/rest-api/v0.7.0/#tag/Group/operation/deleteGroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Uploadcare group UUID. |
