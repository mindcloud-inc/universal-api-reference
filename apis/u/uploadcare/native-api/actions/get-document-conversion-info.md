# Get Document Conversion Info with Uploadcare

Retrieves document conversion info from Uploadcare.

## Endpoint

- **Method:** `GET`
- **Path:** `/convert/document/:uuid/`
- **Base URL:** `https://api.uploadcare.com`
- **Official documentation:** [Get Document Conversion Info](https://uploadcare.com/api-refs/rest-api/v0.7.0/#tag/Conversion/operation/documentConvertInfo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Uploadcare file UUID. |
