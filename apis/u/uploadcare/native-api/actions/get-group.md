# Get Group with Uploadcare

Retrieves a group record from Uploadcare.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:uuid/`
- **Base URL:** `https://api.uploadcare.com`
- **Official documentation:** [Get Group](https://uploadcare.com/api-refs/rest-api/v0.7.0/#tag/Group/operation/groupInfo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Uploadcare group UUID. |
