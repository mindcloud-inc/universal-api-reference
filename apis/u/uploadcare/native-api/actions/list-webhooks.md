# List Webhooks with Uploadcare

Retrieves all webhooks from your Uploadcare project.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/`
- **Base URL:** `https://api.uploadcare.com`
- **Official documentation:** [List Webhooks](https://uploadcare.com/api-refs/rest-api/v0.7.0/#tag/Webhook/operation/webhooksList)
