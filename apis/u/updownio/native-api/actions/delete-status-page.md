# Delete Status Page with updown.io

Deletes an existing status page from updown.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/status_pages/:token`
- **Base URL:** `https://updown.io/api`
- **Official documentation:** [Delete Status Page](https://updown.io/api#DELETE-/api/status-pages/:token)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | path | `string` | yes | The status page unique token. |
