# Delete Recipient with updown.io

Deletes an alert recipient from updown.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/recipients/:id`
- **Base URL:** `https://updown.io/api`
- **Official documentation:** [Delete Recipient](https://updown.io/api#DELETE-/api/recipients/:id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The recipient ID to delete. |
