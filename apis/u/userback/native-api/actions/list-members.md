# List Members with Userback

Lists the members available in Userback.

## Endpoint

- **Method:** `GET`
- **Path:** `/member`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [List Members](https://docs.userback.io/reference/listmembers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
