# List Feedbacks with Userback

Lists the feedback items available in Userback.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedback`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [List Feedbacks](https://docs.userback.io/reference/listfeedbacks)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
