# Delete Workflow with Userback

Deletes a workflow from Userback.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workflow/:id`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [Delete Workflow](https://docs.userback.io/reference/deleteworkflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The workflow ID to delete. |
