# List Workflows with Userback

Lists the workflows available in Userback.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflow`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [List Workflows](https://docs.userback.io/reference/listworkflows)

## Capabilities

This operation supports [pagination](../README.md#pagination).
