# Get Feedback with Userback

Retrieves a Userback feedback item by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedback/:id`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [Get Feedback](https://docs.userback.io/reference/getfeedback)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Feedback ID to retrieve. |
