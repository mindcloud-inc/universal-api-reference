# Delete Feedback with Userback

Deletes a Userback feedback item.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/feedback/:id`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [Delete Feedback](https://docs.userback.io/reference/deletefeedback)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Feedback ID to delete. |
