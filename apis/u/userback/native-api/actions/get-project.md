# Get Project with Userback

Retrieves a Userback project by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [Get Project](https://docs.userback.io/reference/getproject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The project ID to retrieve. |
