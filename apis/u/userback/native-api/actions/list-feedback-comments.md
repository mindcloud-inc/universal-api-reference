# List Feedback Comments with Userback

Lists the comments for Userback feedback items.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedback/comment`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [List Feedback Comments](https://docs.userback.io/reference/listfeedbackcomments)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
