# Get Feedback Comment with Userback

Retrieves a Userback feedback comment by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedback/comment/:id`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [Get Feedback Comment](https://docs.userback.io/reference/getfeedbackcomment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Feedback comment ID to retrieve. |
