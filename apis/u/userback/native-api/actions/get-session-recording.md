# Get Session Recording with Userback

Retrieves a Userback session recording by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessionRecording/:id`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [Get Session Recording](https://docs.userback.io/reference/getsessionrecording)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The session recording ID to retrieve. |
