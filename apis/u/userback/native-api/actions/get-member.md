# Get Member with Userback

Retrieves a Userback member by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/member/:id`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [Get Member](https://docs.userback.io/reference/getmember)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The member ID to retrieve. |
