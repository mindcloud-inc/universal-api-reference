# List Session Recordings with Userback

Lists the session recordings available in Userback.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessionRecording`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [List Session Recordings](https://docs.userback.io/reference/listsessionrecordings)

## Capabilities

This operation supports [pagination](../README.md#pagination).
