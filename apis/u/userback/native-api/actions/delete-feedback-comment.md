# Delete Feedback Comment with Userback

Deletes a Userback feedback comment.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/feedback/comment/:id`
- **Base URL:** `https://rest.userback.io/1.0`
- **Official documentation:** [Delete Feedback Comment](https://docs.userback.io/reference/deletefeedbackcomment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Feedback comment ID to delete. |
