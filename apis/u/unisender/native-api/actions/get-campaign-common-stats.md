# Get Campaign Common Stats with Unisender

Retrieves campaign summary stats from Unisender.

## Endpoint

- **Method:** `GET`
- **Path:** `/getCampaignCommonStats`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Get Campaign Common Stats](https://www.unisender.com/ru/support/api/statistics/get-campaign-common-stats/)
