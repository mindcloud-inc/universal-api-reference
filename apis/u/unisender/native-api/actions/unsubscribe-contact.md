# Unsubscribe Contact with Unisender

Updates a contact subscription in Unisender.

## Endpoint

- **Method:** `POST`
- **Path:** `/unsubscribe`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Unsubscribe Contact](https://www.unisender.com/ru/support/api/contacts/unsubscribe/)
