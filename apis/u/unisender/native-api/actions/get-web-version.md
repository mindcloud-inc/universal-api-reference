# Get Web Version with Unisender

Retrieves a message web version from Unisender.

## Endpoint

- **Method:** `GET`
- **Path:** `/getWebVersion`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Get Web Version](https://www.unisender.com/ru/support/api/messages/getwebversion/)
