# Get Contact Count with Unisender

Retrieves a filtered contact count from Unisender.

## Endpoint

- **Method:** `GET`
- **Path:** `/getContactCount`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Get Contact Count](https://www.unisender.com/ru/support/api/contacts/getcontactcount/)
