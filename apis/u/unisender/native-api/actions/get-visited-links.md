# Get Visited Links with Unisender

Retrieves visited links from Unisender.

## Endpoint

- **Method:** `GET`
- **Path:** `/getVisitedLinks`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Get Visited Links](https://www.unisender.com/ru/support/api/statistics/getvisitedlinks/)
