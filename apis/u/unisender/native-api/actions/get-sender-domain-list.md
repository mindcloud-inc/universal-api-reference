# Get Sender Domain List with Unisender

Retrieves sender domain details from Unisender.

## Endpoint

- **Method:** `GET`
- **Path:** `/getSenderDomainList`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Get Sender Domain List](https://www.unisender.com/ru/support/api/messages/getsenderdomainlist/)
