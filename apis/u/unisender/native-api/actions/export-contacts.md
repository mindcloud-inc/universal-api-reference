# Export Contacts with Unisender

Exports contacts from Unisender as an asynchronous job.

## Endpoint

- **Method:** `POST`
- **Path:** `/exportContacts`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Export Contacts](https://www.unisender.com/ru/support/api/contacts/exportcontacts/)
