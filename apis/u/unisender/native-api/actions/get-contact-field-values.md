# Get Contact Field Values with Unisender

Retrieves contact field values from Unisender.

## Endpoint

- **Method:** `GET`
- **Path:** `/getContactFieldValues`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Get Contact Field Values](https://www.unisender.com/ru/support/api/inputs/getcontactfieldvalues/)
