# Is Contact In Lists with Unisender

Finds whether a contact is in Unisender lists.

## Endpoint

- **Method:** `GET`
- **Path:** `/isContactInLists`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Is Contact In Lists](https://www.unisender.com/ru/support/api/contacts/iscontactinlists/)
