# Get Campaign Status with Unisender

Retrieves a campaign status from Unisender.

## Endpoint

- **Method:** `GET`
- **Path:** `/getCampaignStatus`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Get Campaign Status](https://www.unisender.com/ru/support/api/statistics/getcampaignstatus/)
