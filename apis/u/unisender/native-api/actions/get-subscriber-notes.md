# Get Subscriber Notes with Unisender

Retrieves subscriber notes from Unisender.

## Endpoint

- **Method:** `GET`
- **Path:** `/getSubscriberNotes`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Get Subscriber Notes](https://www.unisender.com/ru/support/api/notes/getsubscribernotes/)
