# Get Total Contacts Count with Unisender

Retrieves the total contact count from Unisender.

## Endpoint

- **Method:** `GET`
- **Path:** `/getTotalContactsCount`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Get Total Contacts Count](https://www.unisender.com/ru/support/api/contacts/gettotalcontactscount/)
