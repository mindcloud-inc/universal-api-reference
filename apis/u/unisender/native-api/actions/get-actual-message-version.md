# Get Actual Message Version with Unisender

Retrieves the current message version from Unisender.

## Endpoint

- **Method:** `GET`
- **Path:** `/getActualMessageVersion`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Get Actual Message Version](https://www.unisender.com/ru/support/api/messages/get-actual-message-version/)
