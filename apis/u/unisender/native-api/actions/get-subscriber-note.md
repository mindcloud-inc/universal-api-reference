# Get Subscriber Note with Unisender

Retrieves a subscriber note from Unisender.

## Endpoint

- **Method:** `GET`
- **Path:** `/getSubscriberNote`
- **Base URL:** `https://api.unisender.com/en/api`
- **Official documentation:** [Get Subscriber Note](https://www.unisender.com/ru/support/api/notes/getsubscribernote/)
