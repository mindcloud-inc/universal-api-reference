# Get Channel Feed Summaries with UbiBot

Retrieves channel feed summaries from UbiBot.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels/:channelId/summary.json`
- **Base URL:** `https://webapi.ubibot.com`
- **Official documentation:** [Get Channel Feed Summaries](https://www.ubibot.com/platform-api/2735/get-channel-feed-summaries/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | no | UbiBot channel identifier from the channel URL or channel list. |
