# Upload Channel Icon From Base64 with UbiBot

Updates a channel icon from a Base64 string in UbiBot.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/:channelId/device/upload_icon_base64`
- **Base URL:** `https://webapi.ubibot.com`
- **Official documentation:** [Upload Channel Icon From Base64](https://www.ubibot.com/platform-api/1885/upload-channel-icon-base64/)
