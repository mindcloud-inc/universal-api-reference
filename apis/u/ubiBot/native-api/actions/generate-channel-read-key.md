# Generate Channel Read Key with UbiBot

Creates a channel read-only key in UbiBot.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/:channelId/api_keys`
- **Base URL:** `https://webapi.ubibot.com`
- **Official documentation:** [Generate Channel Read Key](https://www.ubibot.com/app-platform-api/8225/generate-channel-read-only-key/)
