# Import Feeds From CSV with UbiBot

Imports channel feeds from a CSV file in UbiBot.

## Endpoint

- **Method:** `POST`
- **Path:** `/update.csv`
- **Base URL:** `https://webapi.ubibot.com`
- **Official documentation:** [Import Feeds From CSV](https://www.ubibot.com/platform-api/1213/csv-import-channel-feed/)
