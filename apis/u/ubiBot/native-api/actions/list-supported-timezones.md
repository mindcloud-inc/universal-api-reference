# List Supported Timezones with UbiBot

Retrieves supported platform timezones from UbiBot.

## Endpoint

- **Method:** `GET`
- **Path:** `/constants/timezones`
- **Base URL:** `https://webapi.ubibot.com`
- **Official documentation:** [List Supported Timezones](https://www.ubibot.com/platform-api/1232/quick-start/)
