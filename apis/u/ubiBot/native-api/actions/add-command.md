# Add Command with UbiBot

Creates a device command in UbiBot.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/:channelId/commands`
- **Base URL:** `https://webapi.ubibot.com`
- **Official documentation:** [Add Command](https://www.ubibot.com/platform-api/1987/add-command/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | no | UbiBot channel identifier from the channel URL or channel list. |
