# Delete Channel Read-only Key with UbiBot

Deletes a channel read-only key from UbiBot.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/:channelId/api_keys`
- **Base URL:** `https://webapi.ubibot.com`
- **Official documentation:** [Delete Channel Read-only Key](https://www.ubibot.com/app-platform-api/8223/delete-channel-read-only-key/)
