# Get Device with Ubidots

## Endpoint

- **Method:** `GET`
- **Path:** `/devices/:device_key/`
- **Base URL:** `https://industrial.api.ubidots.com/api/v2.0`
- **Official documentation:** [Get Device](https://docs.ubidots.com/reference/get-device)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `device_key` | path | `string` | yes | The device ID or API label. |
