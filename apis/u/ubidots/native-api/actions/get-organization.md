# Get Organization with Ubidots

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organization_key/`
- **Base URL:** `https://industrial.api.ubidots.com/api/v2.0`
- **Official documentation:** [Get Organization](https://docs.ubidots.com/reference/get-organization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_key` | path | `string` | yes | The organization ID or key. |
