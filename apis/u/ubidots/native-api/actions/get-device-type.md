# Get Device Type with Ubidots

## Endpoint

- **Method:** `GET`
- **Path:** `/device_types/:device_type_key/`
- **Base URL:** `https://industrial.api.ubidots.com/api/v2.0`
- **Official documentation:** [Get Device Type](https://docs.ubidots.com/reference/get-device-of-device-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `device_type_key` | path | `string` | yes | The device type ID or key. |
