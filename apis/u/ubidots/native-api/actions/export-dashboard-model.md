# Export Dashboard Model with Ubidots

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboards/:dashboard_key/_/export_models`
- **Base URL:** `https://industrial.api.ubidots.com/api/v2.0`
- **Official documentation:** [Export Dashboard Model](https://docs.ubidots.com/reference/export-dashboard-model)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dashboard_key` | path | `string` | yes | The dashboard ID or key. |
