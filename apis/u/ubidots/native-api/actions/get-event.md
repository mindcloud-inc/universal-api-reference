# Get Event with Ubidots

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:event_key/`
- **Base URL:** `https://industrial.api.ubidots.com/api/v2.0`
- **Official documentation:** [Get Event](https://docs.ubidots.com/reference/get-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_key` | path | `string` | yes | The event ID or key. |
