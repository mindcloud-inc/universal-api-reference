# Get Dashboard with Ubidots

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboards/:dashboard_key/`
- **Base URL:** `https://industrial.api.ubidots.com/api/v2.0`
- **Official documentation:** [Get Dashboard](https://docs.ubidots.com/reference/get-dashboard)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dashboard_key` | path | `string` | yes | The dashboard ID or key. |
