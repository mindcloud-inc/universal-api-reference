# Get Device Group with Ubidots

## Endpoint

- **Method:** `GET`
- **Path:** `/device_groups/:device_group_key/`
- **Base URL:** `https://industrial.api.ubidots.com/api/v2.0`
- **Official documentation:** [Get Device Group](https://docs.ubidots.com/reference/get-device-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `device_group_key` | path | `string` | yes | The device group ID or key. |
