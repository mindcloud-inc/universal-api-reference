# Get User with Ubidots

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user_key/`
- **Base URL:** `https://industrial.api.ubidots.com/api/v2.0`
- **Official documentation:** [Get User](https://docs.ubidots.com/reference/get-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_key` | path | `string` | yes | The user ID or key. |
