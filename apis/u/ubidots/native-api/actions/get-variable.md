# Get Variable with Ubidots

## Endpoint

- **Method:** `GET`
- **Path:** `/variables/:variable_id/`
- **Base URL:** `https://industrial.api.ubidots.com/api/v2.0`
- **Official documentation:** [Get Variable](https://docs.ubidots.com/reference/get-variable)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variable_id` | path | `string` | yes | The Ubidots variable ID. |
