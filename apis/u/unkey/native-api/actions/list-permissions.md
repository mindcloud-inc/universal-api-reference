# List permissions with Unkey

Retrieves all defined permissions from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/permissions.listPermissions`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [List permissions](https://unkey.com/docs/api-reference/permissions/list-permissions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
