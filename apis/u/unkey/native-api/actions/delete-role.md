# Delete role with Unkey

Deletes an existing role from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/permissions.deleteRole`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Delete role](https://unkey.com/docs/api-reference/permissions/delete-role)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `role` | body | `string` | yes |
