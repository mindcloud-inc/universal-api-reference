# Delete permission with Unkey

Deletes an existing permission from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/permissions.deletePermission`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Delete permission](https://unkey.com/docs/api-reference/permissions/delete-permission)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `permission` | body | `string` | yes |
