# Get Identity with Unkey

Retrieves an identity record from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/identities.getIdentity`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Get Identity](https://unkey.com/docs/api-reference/identities/get-identity)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `identity` | body | `string` | yes |
