# Delete API keys with Unkey

Deletes an API key from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/keys.deleteKey`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Delete API keys](https://unkey.com/docs/api-reference/keys/delete-api-keys)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `keyId` | body | `string` | yes |
