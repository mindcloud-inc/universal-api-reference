# Apply multiple rate limit checks with Unkey

Applies multiple rate limit checks in Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/ratelimit.multiLimit`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Apply multiple rate limit checks](https://unkey.com/docs/api-reference/ratelimit/apply-multiple-rate-limit-checks)
