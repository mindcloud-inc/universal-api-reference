# Delete Identity with Unkey

Deletes an existing identity from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/identities.deleteIdentity`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Delete Identity](https://unkey.com/docs/api-reference/identities/delete-identity)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `identity` | body | `string` | yes |
