# Create permission with Unkey

Creates a new permission in Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/permissions.createPermission`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Create permission](https://unkey.com/docs/api-reference/permissions/create-permission)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `slug` | body | `string` | yes |
