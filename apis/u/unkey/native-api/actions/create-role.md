# Create role with Unkey

Creates a new role in Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/permissions.createRole`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Create role](https://unkey.com/docs/api-reference/permissions/create-role)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
