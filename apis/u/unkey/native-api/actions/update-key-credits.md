# Update key credits with Unkey

Updates credits for an existing API key in Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/keys.updateCredits`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Update key credits](https://unkey.com/docs/api-reference/keys/update-key-credits)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `keyId` | body | `string` | yes |
| `operation` | body | `string` | yes |
