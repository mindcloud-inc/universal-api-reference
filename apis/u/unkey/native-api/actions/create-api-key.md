# Create API key with Unkey

Creates a new API key in Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/keys.createKey`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Create API key](https://unkey.com/docs/api-reference/keys/create-api-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `apiId` | body | `string` | yes |
