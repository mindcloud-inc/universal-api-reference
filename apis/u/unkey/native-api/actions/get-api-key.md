# Get API key with Unkey

Retrieves an API key from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/keys.getKey`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Get API key](https://unkey.com/docs/api-reference/keys/get-api-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `keyId` | body | `string` | yes |
