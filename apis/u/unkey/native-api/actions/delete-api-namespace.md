# Delete API namespace with Unkey

Deletes an API namespace from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/apis.deleteApi`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Delete API namespace](https://unkey.com/docs/api-reference/apis/delete-api-namespace)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `apiId` | body | `string` | yes |
