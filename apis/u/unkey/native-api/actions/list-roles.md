# List Roles with Unkey

Retrieves all configured roles from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/permissions.listRoles`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [List Roles](https://unkey.com/docs/api-reference/permissions/list-roles)

## Capabilities

This operation supports [pagination](../README.md#pagination).
