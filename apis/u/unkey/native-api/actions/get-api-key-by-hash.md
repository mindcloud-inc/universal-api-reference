# Get API key by hash with Unkey

Retrieves an API key from Unkey by hash.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/keys.whoami`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Get API key by hash](https://unkey.com/docs/api-reference/keys/get-api-key-by-hash)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | body | `string` | yes |
