# Get API namespace with Unkey

Retrieves an API namespace from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/apis.getApi`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Get API namespace](https://unkey.com/docs/api-reference/apis/get-api-namespace)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `apiId` | body | `string` | yes |
