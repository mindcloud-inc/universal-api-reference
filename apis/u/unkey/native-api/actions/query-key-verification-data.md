# Query key verification data with Unkey

Retrieves key verification data from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/analytics.getVerifications`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Query key verification data](https://unkey.com/docs/api-reference/analytics/query-key-verification-data)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | body | `string` | yes |
