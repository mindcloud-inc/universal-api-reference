# Get permission with Unkey

Retrieves a permission record from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/permissions.getPermission`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Get permission](https://unkey.com/docs/api-reference/permissions/get-permission)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `permission` | body | `string` | yes |
