# List Identities with Unkey

Retrieves all workspace identities from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/identities.listIdentities`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [List Identities](https://unkey.com/docs/api-reference/identities/list-identities)

## Capabilities

This operation supports [pagination](../README.md#pagination).
