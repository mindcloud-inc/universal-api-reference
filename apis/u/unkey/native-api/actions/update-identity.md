# Update Identity with Unkey

Updates an existing identity in Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/identities.updateIdentity`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Update Identity](https://unkey.com/docs/api-reference/identities/update-identity)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `identity` | body | `string` | yes |
