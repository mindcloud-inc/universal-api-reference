# Get role with Unkey

Retrieves a role record from Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/permissions.getRole`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Get role](https://unkey.com/docs/api-reference/permissions/get-role)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `role` | body | `string` | yes |
