# Verify API key with Unkey

Verifies an API key in Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/keys.verifyKey`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Verify API key](https://unkey.com/docs/api-reference/keys/verify-api-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | body | `string` | yes |
