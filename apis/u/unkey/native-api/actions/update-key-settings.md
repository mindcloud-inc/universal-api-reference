# Update key settings with Unkey

Updates settings for an existing API key in Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/keys.updateKey`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Update key settings](https://unkey.com/docs/api-reference/keys/update-key-settings)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `keyId` | body | `string` | yes |
