# Create Identity with Unkey

Creates a new identity in Unkey.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/identities.createIdentity`
- **Base URL:** `https://api.unkey.com`
- **Official documentation:** [Create Identity](https://unkey.com/docs/api-reference/identities/create-identity)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `externalId` | body | `string` | yes |
