# List Marketing Consents with Understory

Retrieves marketing consents from Understory.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/marketing-consents`
- **Base URL:** `https://api.understory.io`
- **Official documentation:** [List Marketing Consents](https://developer.understory.io/apis/marketing/getmarketingconsents.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
