# List Experiences with Understory

Retrieves experiences from Understory.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/experiences`
- **Base URL:** `https://api.understory.io`
- **Official documentation:** [List Experiences](https://developer.understory.io/apis/experience/getexperiences.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept-Language` | `en-GB` |
