# Get Booking with Understory

Retrieves a booking from Understory.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/bookings/{{bookingId}}`
- **Base URL:** `https://api.understory.io`
- **Official documentation:** [Get Booking](https://developer.understory.io/apis/booking/getbooking.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bookingId` | path | `string` | yes | The unique identifier of the booking. |
