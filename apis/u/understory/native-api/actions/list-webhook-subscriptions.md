# List Webhook Subscriptions with Understory

Retrieves webhook subscriptions from Understory.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhook-subscriptions`
- **Base URL:** `https://api.understory.io`
- **Official documentation:** [List Webhook Subscriptions](https://developer.understory.io/apis/webhook/listwebhooksubscriptions.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
