# Get Event with Understory

Retrieves an event from Understory.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/events/{{eventId}}`
- **Base URL:** `https://api.understory.io`
- **Official documentation:** [Get Event](https://developer.understory.io/apis/event/getevent.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | The unique identifier of the event. |
