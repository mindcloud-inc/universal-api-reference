# Get Contact with Ugosign

Retrieves a contact from Ugosign.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/:contact`
- **Base URL:** `https://app.ugosign.com/api`
- **Official documentation:** [Get Contact](https://app.ugosign.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contact` | path | `string` | yes |
