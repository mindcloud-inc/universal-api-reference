# Get Envelope with Ugosign

Retrieves an envelope from Ugosign.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/envelopes/:envelope`
- **Base URL:** `https://app.ugosign.com/api`
- **Official documentation:** [Get Envelope](https://app.ugosign.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `envelope` | path | `string` | yes |
