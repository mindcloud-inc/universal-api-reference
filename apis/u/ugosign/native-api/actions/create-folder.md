# Create Folder with Ugosign

Creates a new folder in Ugosign.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/folders`
- **Base URL:** `https://app.ugosign.com/api`
- **Official documentation:** [Create Folder](https://app.ugosign.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `parent_id` | body | `string` | no |
| `title` | body | `string` | yes |
