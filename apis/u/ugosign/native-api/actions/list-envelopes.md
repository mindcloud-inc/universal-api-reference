# List Envelopes with Ugosign

Retrieves envelopes from Ugosign.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/envelopes`
- **Base URL:** `https://app.ugosign.com/api`
- **Official documentation:** [List Envelopes](https://app.ugosign.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `status` | query | `string` | no |
