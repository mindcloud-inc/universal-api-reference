# Delete Contact with Ugosign

Deletes a contact from Ugosign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contacts/:contact`
- **Base URL:** `https://app.ugosign.com/api`
- **Official documentation:** [Delete Contact](https://app.ugosign.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contact` | path | `string` | yes |
