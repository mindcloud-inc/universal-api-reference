# Get Contract Custom Vars with Ugosign

Retrieves a contract's custom variables from Ugosign.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contracts/:contract/customVars`
- **Base URL:** `https://app.ugosign.com/api`
- **Official documentation:** [Get Contract Custom Vars](https://app.ugosign.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contract` | path | `string` | yes |
