# Delete Contract with Ugosign

Deletes a contract from Ugosign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contracts/:contract`
- **Base URL:** `https://app.ugosign.com/api`
- **Official documentation:** [Delete Contract](https://app.ugosign.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contract` | path | `string` | yes |
