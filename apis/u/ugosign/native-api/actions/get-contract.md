# Get Contract with Ugosign

Retrieves a contract from Ugosign.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contracts/:contract`
- **Base URL:** `https://app.ugosign.com/api`
- **Official documentation:** [Get Contract](https://app.ugosign.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contract` | path | `string` | yes |
