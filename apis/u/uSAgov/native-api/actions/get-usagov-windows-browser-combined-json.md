# List English Site Windows and Browser Combinations with USA.gov

Retrieves English site Windows and browser combinations from USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/en/windows-browsers.json`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [List English Site Windows and Browser Combinations](https://www.usa.gov/website-analytics/usagov/data/)
