# Download Spanish Site Device Types with USA.gov

Downloads Spanish site device types from USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/es/devices.csv`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [Download Spanish Site Device Types](https://www.usa.gov/website-analytics/usagov-en-espanol/data/)
