# Get Spanish Site Live Visitors with USA.gov

Retrieves live Spanish site visitor counts from USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/es/realtime.json`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [Get Spanish Site Live Visitors](https://www.usa.gov/website-analytics/usagov-en-espanol/data/)
