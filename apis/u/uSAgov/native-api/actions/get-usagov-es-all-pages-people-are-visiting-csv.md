# Download Spanish Site Live Pages with USA.gov

Downloads live Spanish site pages visited on USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/es/all-pages-realtime.csv`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [Download Spanish Site Live Pages](https://www.usa.gov/website-analytics/usagov-en-espanol/data/)
