# List English Site Screen Sizes with USA.gov

Retrieves English site screen sizes from USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/en/screen-size.json`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [List English Site Screen Sizes](https://www.usa.gov/website-analytics/usagov/data/)
