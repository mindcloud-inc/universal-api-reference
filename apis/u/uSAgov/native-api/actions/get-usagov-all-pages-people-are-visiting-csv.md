# Download English Site Live Pages with USA.gov

Downloads live English site pages visited on USA.gov.

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/en/all-pages-realtime.csv`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [Download English Site Live Pages](https://www.usa.gov/website-analytics/usagov/data/)
