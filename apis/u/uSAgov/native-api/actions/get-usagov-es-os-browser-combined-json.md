# List Spanish Site OS and Browser Combinations with USA.gov

Retrieves Spanish site OS and browser combinations from USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/es/os-browsers.json`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [List Spanish Site OS and Browser Combinations](https://www.usa.gov/website-analytics/usagov-en-espanol/data/)
