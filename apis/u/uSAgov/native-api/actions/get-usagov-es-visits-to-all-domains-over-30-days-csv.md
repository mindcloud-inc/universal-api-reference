# Download Spanish Site Domain Visits with USA.gov

Downloads 30-day Spanish site domain visits from USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/es/all-domains-30-days.csv`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [Download Spanish Site Domain Visits](https://www.usa.gov/website-analytics/usagov-en-espanol/data/)
