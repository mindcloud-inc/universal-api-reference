# Download Spanish Site Top Downloads with USA.gov

Downloads yesterday's Spanish site top downloads from USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/es/top-downloads-yesterday.csv`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [Download Spanish Site Top Downloads](https://www.usa.gov/website-analytics/usagov-en-espanol/data/)
