# List Spanish Site Top Exit Pages with USA.gov

Retrieves Spanish site top exit pages from USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/es/top-exit-pages-30-days.json`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [List Spanish Site Top Exit Pages](https://www.usa.gov/website-analytics/usagov-en-espanol/data/)
