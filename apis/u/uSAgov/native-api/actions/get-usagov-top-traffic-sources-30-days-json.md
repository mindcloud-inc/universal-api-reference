# List English Site Top Traffic Sources with USA.gov

Retrieves English site top traffic sources from USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/en/top-traffic-sources-30-days.json`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [List English Site Top Traffic Sources](https://www.usa.gov/website-analytics/usagov/data/)
