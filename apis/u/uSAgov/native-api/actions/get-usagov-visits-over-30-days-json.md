# Get English Site 30-Day Visit Summary with USA.gov

Retrieves the English site 30-day visit summary from USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/en/traffic-sources-30-days.json`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [Get English Site 30-Day Visit Summary](https://www.usa.gov/website-analytics/usagov/data/)
