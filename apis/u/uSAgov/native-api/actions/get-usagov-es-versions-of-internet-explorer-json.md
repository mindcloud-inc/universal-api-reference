# List Spanish Site Internet Explorer Versions with USA.gov

Retrieves Spanish site Internet Explorer versions from USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/es/ie.json`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [List Spanish Site Internet Explorer Versions](https://www.usa.gov/website-analytics/usagov-en-espanol/data/)
