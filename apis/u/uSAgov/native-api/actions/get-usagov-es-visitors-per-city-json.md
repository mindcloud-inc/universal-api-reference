# List Spanish Site Visitors by City with USA.gov

Retrieves Spanish site visitors by city from USA.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/cg-446f64bd-3bff-4571-aaf3-22e7fb880b2d/usagov-analytics/es/top-cities-90-days.json`
- **Base URL:** `https://s3-us-gov-west-1.amazonaws.com`
- **Official documentation:** [List Spanish Site Visitors by City](https://www.usa.gov/website-analytics/usagov-en-espanol/data/)
