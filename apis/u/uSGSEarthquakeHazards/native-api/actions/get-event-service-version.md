# Get Event Service Version with USGS Earthquake Hazards

Retrieves the event service version from USGS Earthquake Hazards.

## Endpoint

- **Method:** `GET`
- **Path:** `/fdsnws/event/1/version`
- **Base URL:** `https://earthquake.usgs.gov`
- **Official documentation:** [Get Event Service Version](https://earthquake.usgs.gov/fdsnws/event/1/)
