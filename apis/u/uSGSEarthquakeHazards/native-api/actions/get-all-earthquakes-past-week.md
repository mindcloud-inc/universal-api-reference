# Get All Earthquakes Past Week with USGS Earthquake Hazards

Retrieves all earthquakes from the past week.

## Endpoint

- **Method:** `GET`
- **Path:** `/earthquakes/feed/v1.0/summary/all_week.geojson`
- **Base URL:** `https://earthquake.usgs.gov`
- **Official documentation:** [Get All Earthquakes Past Week](https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php)
