# Get Event API Parameters with USGS Earthquake Hazards

Retrieves event API parameters from USGS Earthquake Hazards.

## Endpoint

- **Method:** `GET`
- **Path:** `/fdsnws/event/1/application.json`
- **Base URL:** `https://earthquake.usgs.gov`
- **Official documentation:** [Get Event API Parameters](https://earthquake.usgs.gov/fdsnws/event/1/)
