# Get All Earthquakes Past Hour with USGS Earthquake Hazards

Retrieves all earthquakes from the past hour.

## Endpoint

- **Method:** `GET`
- **Path:** `/earthquakes/feed/v1.0/summary/all_hour.geojson`
- **Base URL:** `https://earthquake.usgs.gov`
- **Official documentation:** [Get All Earthquakes Past Hour](https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php)
