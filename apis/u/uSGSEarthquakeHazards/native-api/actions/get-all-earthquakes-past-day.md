# Get All Earthquakes Past Day with USGS Earthquake Hazards

Retrieves all earthquakes from the past day.

## Endpoint

- **Method:** `GET`
- **Path:** `/earthquakes/feed/v1.0/summary/all_day.geojson`
- **Base URL:** `https://earthquake.usgs.gov`
- **Official documentation:** [Get All Earthquakes Past Day](https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php)
