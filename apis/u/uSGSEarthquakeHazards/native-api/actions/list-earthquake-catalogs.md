# List Earthquake Catalogs with USGS Earthquake Hazards

Retrieves available earthquake catalogs from USGS Earthquake Hazards.

## Endpoint

- **Method:** `GET`
- **Path:** `/fdsnws/event/1/catalogs`
- **Base URL:** `https://earthquake.usgs.gov`
- **Official documentation:** [List Earthquake Catalogs](https://earthquake.usgs.gov/fdsnws/event/1/)
