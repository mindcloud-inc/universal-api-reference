# List Earthquake Contributors with USGS Earthquake Hazards

Retrieves available earthquake contributors from USGS Earthquake Hazards.

## Endpoint

- **Method:** `GET`
- **Path:** `/fdsnws/event/1/contributors`
- **Base URL:** `https://earthquake.usgs.gov`
- **Official documentation:** [List Earthquake Contributors](https://earthquake.usgs.gov/fdsnws/event/1/)
