# Search Historical Results with urlscan.io

Retrieves historical scan results from urlscan.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/search`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [Search Historical Results](https://docs.urlscan.io/apis/urlscan-openapi/search/search.md)
