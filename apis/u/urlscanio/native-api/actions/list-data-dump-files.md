# List Data Dump Files with urlscan.io

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/datadump/list/{timeWindow}/{fileType}/{date}`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [List Data Dump Files](https://docs.urlscan.io/apis/urlscan-openapi/data-dumps/datadumplist.md)
