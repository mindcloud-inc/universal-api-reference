# Get Incident States with urlscan.io

Retrieves states for an incident in urlscan.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/user/incidentstates/{incidentId}/`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [Get Incident States](https://docs.urlscan.io/apis/urlscan-openapi/incidents/getincidentstates.md)
