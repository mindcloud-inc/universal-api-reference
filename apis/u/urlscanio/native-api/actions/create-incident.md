# Create Incident with urlscan.io

Creates a new incident in urlscan.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/user/incidents`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [Create Incident](https://docs.urlscan.io/apis/urlscan-openapi/incidents/createincident.md)
