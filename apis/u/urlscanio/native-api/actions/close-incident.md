# Close Incident with urlscan.io

Updates an incident by closing it in urlscan.io.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/user/incidents/{incidentId}/close`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [Close Incident](https://docs.urlscan.io/apis/urlscan-openapi/incidents/closeincident.md)
