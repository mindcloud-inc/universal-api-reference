# List Watchable Attributes with urlscan.io

Retrieves watchable incident attributes from urlscan.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/user/watchableAttributes`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [List Watchable Attributes](https://docs.urlscan.io/apis/urlscan-openapi/incidents/getwatchableattributes.md)
