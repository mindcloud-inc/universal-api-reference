# Fork Incident with urlscan.io

Creates a fork of an incident in urlscan.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/user/incidents/{incidentId}/fork`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [Fork Incident](https://docs.urlscan.io/apis/urlscan-openapi/incidents/forkincident.md)
