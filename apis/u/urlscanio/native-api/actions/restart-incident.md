# Restart Incident with urlscan.io

Updates an incident by restarting it in urlscan.io.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/user/incidents/{incidentId}/restart`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [Restart Incident](https://docs.urlscan.io/apis/urlscan-openapi/incidents/restartincident.md)
