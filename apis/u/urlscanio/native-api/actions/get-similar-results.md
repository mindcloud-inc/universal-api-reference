# Get Similar Results with urlscan.io

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/pro/result/{scanId}/similar/`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [Get Similar Results](https://docs.urlscan.io/apis/urlscan-openapi/search/similarsearch.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scanId` | path | `string` | no | The scan UUID to compare for similar results. |
