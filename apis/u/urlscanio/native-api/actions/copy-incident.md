# Copy Incident with urlscan.io

Creates a copy of an incident in urlscan.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/user/incidents/{incidentId}/copy`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [Copy Incident](https://docs.urlscan.io/apis/urlscan-openapi/incidents/copyincident.md)
