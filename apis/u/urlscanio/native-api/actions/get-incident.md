# Get Incident with urlscan.io

Retrieves an existing incident from urlscan.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/user/incidents/{incidentId}`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [Get Incident](https://docs.urlscan.io/apis/urlscan-openapi/incidents/getincident.md)
