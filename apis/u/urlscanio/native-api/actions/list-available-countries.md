# List Available Countries with urlscan.io

Retrieves available scan countries from urlscan.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/availableCountries`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [List Available Countries](https://docs.urlscan.io/apis/urlscan-openapi/scanning/availablecountries.md)
