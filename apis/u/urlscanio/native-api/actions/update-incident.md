# Update Incident with urlscan.io

Updates an existing incident in urlscan.io.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/user/incidents/{incidentId}`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [Update Incident](https://docs.urlscan.io/apis/urlscan-openapi/incidents/updateincident.md)
