# Download File with urlscan.io

Retrieves a file from urlscan.io by file hash.

## Endpoint

- **Method:** `GET`
- **Path:** `/downloads/{fileHash}`
- **Base URL:** `https://urlscan.io`
- **Official documentation:** [Download File](https://docs.urlscan.io/apis/urlscan-openapi/files/downloadfile.md)
