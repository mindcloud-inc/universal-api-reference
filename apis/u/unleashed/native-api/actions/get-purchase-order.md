# Get Purchase Order with Unleashed

Retrieves a purchase order from your Unleashed account.

## Endpoint

- **Method:** `GET`
- **Path:** `/PurchaseOrders/:orderGuid`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [Get Purchase Order](https://apidocs.unleashedsoftware.com/Purchases)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderGuid` | path | `string` | yes | The Unleashed purchase order GUID. |
