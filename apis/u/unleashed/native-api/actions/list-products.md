# List Products with Unleashed

Retrieves products from your Unleashed inventory catalog.

## Endpoint

- **Method:** `GET`
- **Path:** `/Products/:pageNumber`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [List Products](https://apidocs.unleashedsoftware.com/Products)

## Capabilities

This operation supports [pagination](../README.md#pagination).
