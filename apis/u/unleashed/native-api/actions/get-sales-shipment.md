# Get Sales Shipment with Unleashed

Retrieves a sales shipment from your Unleashed account.

## Endpoint

- **Method:** `GET`
- **Path:** `/SalesShipments/:salesShipmentGuid`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [Get Sales Shipment](https://apidocs.unleashedsoftware.com/SalesShipments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `salesShipmentGuid` | path | `string` | yes | The Unleashed sales shipment GUID. |
