# List Warehouses with Unleashed

Retrieves warehouses from your Unleashed account.

## Endpoint

- **Method:** `GET`
- **Path:** `/Warehouses/:pageNumber`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [List Warehouses](https://apidocs.unleashedsoftware.com/Warehouses)

## Capabilities

This operation supports [pagination](../README.md#pagination).
