# Delete Sales Shipment with Unleashed

Deletes an existing sales shipment from Unleashed.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/SalesShipments/:salesShipmentGuid`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [Delete Sales Shipment](https://apidocs.unleashedsoftware.com/SalesShipments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `salesShipmentGuid` | path | `string` | yes | The Unleashed sales shipment GUID. |
