# List Customer Contacts with Unleashed

Retrieves customer contacts from Unleashed by customer.

## Endpoint

- **Method:** `GET`
- **Path:** `/Customers/:customerGuid/Contacts`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [List Customer Contacts](https://apidocs.unleashedsoftware.com/Customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerGuid` | path | `string` | yes | The Unleashed customer GUID. |
