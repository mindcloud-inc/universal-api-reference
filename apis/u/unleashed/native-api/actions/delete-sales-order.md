# Delete Sales Order with Unleashed

Deletes an existing sales order from Unleashed.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/SalesOrders/:orderGuid`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [Delete Sales Order](https://apidocs.unleashedsoftware.com/SalesOrders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderGuid` | path | `string` | yes | The Unleashed sales order GUID. |
