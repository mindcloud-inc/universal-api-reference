# Get Product with Unleashed

Retrieves a product from your Unleashed inventory catalog.

## Endpoint

- **Method:** `GET`
- **Path:** `/Products/:productGuid`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [Get Product](https://apidocs.unleashedsoftware.com/Products)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productGuid` | path | `string` | yes | The Unleashed product GUID. |
