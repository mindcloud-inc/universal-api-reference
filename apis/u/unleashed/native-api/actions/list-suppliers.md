# List Suppliers with Unleashed

Retrieves suppliers from your Unleashed supplier directory.

## Endpoint

- **Method:** `GET`
- **Path:** `/Suppliers/:pageNumber`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [List Suppliers](https://apidocs.unleashedsoftware.com/Suppliers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
