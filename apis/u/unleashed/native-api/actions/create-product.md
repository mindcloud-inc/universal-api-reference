# Create Product with Unleashed

Creates a new product in Unleashed.

## Endpoint

- **Method:** `POST`
- **Path:** `/Products`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [Create Product](https://apidocs.unleashedsoftware.com/Products)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProductCode` | body | `string` | yes | Unique code for the product. |
| `ProductDescription` | body | `string` | yes | Description for the product. |
