# List Sales Shipments with Unleashed

Retrieves sales shipments from your Unleashed account.

## Endpoint

- **Method:** `GET`
- **Path:** `/SalesShipments/:pageNumber`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [List Sales Shipments](https://apidocs.unleashedsoftware.com/SalesShipments)

## Capabilities

This operation supports [pagination](../README.md#pagination).
