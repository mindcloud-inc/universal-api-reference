# Get Customer with Unleashed

Retrieves a customer from your Unleashed customer directory.

## Endpoint

- **Method:** `GET`
- **Path:** `/Customers/:customerGuid`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [Get Customer](https://apidocs.unleashedsoftware.com/Customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerGuid` | path | `string` | yes | The Unleashed customer GUID. |
