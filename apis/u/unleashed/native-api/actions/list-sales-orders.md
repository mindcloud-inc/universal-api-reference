# List Sales Orders with Unleashed

Retrieves sales orders from your Unleashed account.

## Endpoint

- **Method:** `GET`
- **Path:** `/SalesOrders/:pageNumber`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [List Sales Orders](https://apidocs.unleashedsoftware.com/SalesOrders)

## Capabilities

This operation supports [pagination](../README.md#pagination).
