# List Customers with Unleashed

Retrieves customers from your Unleashed customer directory.

## Endpoint

- **Method:** `GET`
- **Path:** `/Customers/:pageNumber`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [List Customers](https://apidocs.unleashedsoftware.com/Customers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
