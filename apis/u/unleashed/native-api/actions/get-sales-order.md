# Get Sales Order with Unleashed

Retrieves a sales order from your Unleashed account.

## Endpoint

- **Method:** `GET`
- **Path:** `/SalesOrders/:orderGuid`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [Get Sales Order](https://apidocs.unleashedsoftware.com/SalesOrders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderGuid` | path | `string` | yes | The Unleashed sales order GUID. |
