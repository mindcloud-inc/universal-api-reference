# List Stock On Hand with Unleashed

Retrieves stock-on-hand records from your Unleashed account.

## Endpoint

- **Method:** `GET`
- **Path:** `/StockOnHand/:pageNumber`
- **Base URL:** `https://api.unleashedsoftware.com`
- **Official documentation:** [List Stock On Hand](https://apidocs.unleashedsoftware.com/StockOnHand)

## Capabilities

This operation supports [pagination](../README.md#pagination).
