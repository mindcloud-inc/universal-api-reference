# List Feedback with UserVitals

Retrieves feedback items for a roadmap from the roadmap API.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedback/list/:roadmapId`
- **Base URL:** `https://app.roadmap.space/v1`
- **Official documentation:** [List Feedback](https://api.roadmap.space/#list-feedback)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roadmapId` | path | `string` | yes | The roadmap id. |
