# Get Widget Ideas with UserVitals

Retrieves widget ideas for a roadmap from the roadmap API.

## Endpoint

- **Method:** `GET`
- **Path:** `/roadmaps/:id/widget`
- **Base URL:** `https://app.roadmap.space/v1`
- **Official documentation:** [Get Widget Ideas](https://api.roadmap.space/#get-widget-ideas)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The roadmap id. |
