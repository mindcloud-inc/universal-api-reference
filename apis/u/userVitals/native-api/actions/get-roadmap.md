# Get Roadmap with UserVitals

Retrieves a roadmap by ID from the roadmap API.

## Endpoint

- **Method:** `GET`
- **Path:** `/roadmaps/:id`
- **Base URL:** `https://app.roadmap.space/v1`
- **Official documentation:** [Get Roadmap](https://api.roadmap.space/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The roadmap unique id to retrieve. |
