# List Ideas with UserVitals

Retrieves ideas for a roadmap from the roadmap API.

## Endpoint

- **Method:** `GET`
- **Path:** `/ideas/list/:roadmapId`
- **Base URL:** `https://app.roadmap.space/v1`
- **Official documentation:** [List Ideas](https://api.roadmap.space/#list-idea)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roadmapId` | path | `string` | yes | The roadmap id. |
