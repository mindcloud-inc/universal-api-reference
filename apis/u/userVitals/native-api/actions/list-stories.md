# List Stories with UserVitals

Retrieves stories for a roadmap from the roadmap API.

## Endpoint

- **Method:** `GET`
- **Path:** `/stories/:roadmapId`
- **Base URL:** `https://app.roadmap.space/v1`
- **Official documentation:** [List Stories](https://api.roadmap.space/#list-story)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roadmapId` | path | `string` | yes | The roadmap id. |
