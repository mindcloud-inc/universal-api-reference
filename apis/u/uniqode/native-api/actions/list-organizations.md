# List Organizations with Uniqode

Retrieves organizations from your Uniqode account.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [List Organizations](https://apidocs.uniqode.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
