# Update Tag with Uniqode

Updates an existing tag in Uniqode.

## Endpoint

- **Method:** `PUT`
- **Path:** `/tags/:tagId/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Update Tag](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tagId` | path | `number` | yes |
