# Update Media Object with Uniqode

Updates an existing media object in Uniqode.

## Endpoint

- **Method:** `PUT`
- **Path:** `/media/:mediaId/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Update Media Object](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mediaId` | path | `number` | yes |
