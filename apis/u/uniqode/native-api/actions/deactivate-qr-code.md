# Deactivate QR Code with Uniqode

Deactivates a dynamic QR code in Uniqode.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/qrcodes/:qrCodeId/activate/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Deactivate QR Code](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `qrCodeId` | path | `number` | yes |
