# Update QR Code with Uniqode

Updates an existing QR code in Uniqode.

## Endpoint

- **Method:** `PUT`
- **Path:** `/qrcodes/:qrCodeId/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Update QR Code](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `qrCodeId` | path | `number` | yes |
