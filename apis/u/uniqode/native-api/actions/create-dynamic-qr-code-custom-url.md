# Create Dynamic QR Code (Custom URL) with Uniqode

Creates a dynamic custom URL QR code in Uniqode.

## Endpoint

- **Method:** `POST`
- **Path:** `/qrcodes/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Create Dynamic QR Code (Custom URL)](https://apidocs.uniqode.com/)
