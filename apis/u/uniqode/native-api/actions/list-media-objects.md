# List Media Objects with Uniqode

Retrieves media objects from your Uniqode account.

## Endpoint

- **Method:** `GET`
- **Path:** `/media/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [List Media Objects](https://apidocs.uniqode.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
