# Get Tag with Uniqode

Retrieves a tag from your Uniqode account.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:tagId/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Get Tag](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `number` | yes | The Uniqode tag ID. |
