# Get Landing Page with Uniqode

Retrieves a landing page from your Uniqode account.

## Endpoint

- **Method:** `GET`
- **Path:** `/markdowncards/:landingPageId/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Get Landing Page](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `landingPageId` | path | `number` | yes | The Uniqode landing page ID. |
