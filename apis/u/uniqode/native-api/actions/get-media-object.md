# Get Media Object with Uniqode

Retrieves a media object from your Uniqode account.

## Endpoint

- **Method:** `GET`
- **Path:** `/media/:mediaId/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Get Media Object](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `number` | yes | The Uniqode media object ID. |
