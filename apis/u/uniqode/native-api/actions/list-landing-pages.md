# List Landing Pages with Uniqode

Retrieves landing pages from your Uniqode account.

## Endpoint

- **Method:** `GET`
- **Path:** `/markdowncards/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [List Landing Pages](https://apidocs.uniqode.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
