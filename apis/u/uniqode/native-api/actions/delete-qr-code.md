# Delete QR Code with Uniqode

Deletes an existing QR code from Uniqode.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/qrcodes/:qrCodeId/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Delete QR Code](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `qrCodeId` | path | `number` | yes |
