# Update Landing Page with Uniqode

Updates an existing landing page in Uniqode.

## Endpoint

- **Method:** `PUT`
- **Path:** `/markdowncards/:landingPageId/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Update Landing Page](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `landingPageId` | path | `number` | yes |
