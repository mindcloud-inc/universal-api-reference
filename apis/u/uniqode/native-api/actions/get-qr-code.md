# Get QR Code with Uniqode

Retrieves a QR code from your Uniqode account.

## Endpoint

- **Method:** `GET`
- **Path:** `/qrcodes/:qrCodeId/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Get QR Code](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `qrCodeId` | path | `number` | yes | The Uniqode QR code ID. |
