# Delete Tag with Uniqode

Deletes an existing tag from Uniqode.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:tagId/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Delete Tag](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tagId` | path | `number` | yes |
