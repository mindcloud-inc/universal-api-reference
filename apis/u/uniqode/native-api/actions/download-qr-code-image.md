# Download QR Code Image with Uniqode

Retrieves QR code image download URLs from Uniqode.

## Endpoint

- **Method:** `GET`
- **Path:** `/qrcodes/:qrCodeId/download/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Download QR Code Image](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `qrCodeId` | path | `number` | yes |
