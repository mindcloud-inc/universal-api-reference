# Get Organization with Uniqode

Retrieves an organization from your Uniqode account.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationId/`
- **Base URL:** `https://api.uniqode.com/api/2.0`
- **Official documentation:** [Get Organization](https://apidocs.uniqode.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `number` | yes | The Uniqode organization ID. |
