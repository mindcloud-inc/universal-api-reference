# List Sales Estimates with Upnify

Retrieves sales estimates from Upnify.

## Endpoint

- **Method:** `GET`
- **Path:** `v4/oportunidades/estimacion`
- **Base URL:** `https://api.upnify.com`
- **Official documentation:** [List Sales Estimates](https://desarrollo.upnify.com/api-rest/oportunidades/#api-Estimacion_de_ventas-GetOportunidadesEstimacion)
