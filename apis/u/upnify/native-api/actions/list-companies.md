# List Companies with Upnify

Retrieves companies from Upnify.

## Endpoint

- **Method:** `GET`
- **Path:** `v4/empresas`
- **Base URL:** `https://api.upnify.com`
- **Official documentation:** [List Companies](https://desarrollo.upnify.com/api-rest/empresas/#api-Empresas-GetEmpresas)

## Capabilities

This operation supports [pagination](../README.md#pagination).
