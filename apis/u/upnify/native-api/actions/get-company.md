# Get Company with Upnify

Retrieves a company from Upnify.

## Endpoint

- **Method:** `GET`
- **Path:** `v4/empresas/:tkEmpresa`
- **Base URL:** `https://api.upnify.com`
- **Official documentation:** [Get Company](https://desarrollo.upnify.com/api-rest/empresas/#api-Empresas-GetEmpresasTkempresa)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tkEmpresa` | path | `string` | yes | Código token que identifica de forma única a una empresa en el sistema, del cual se requiere obtener los detalles.  ¿Dónde obtengo el token? |
