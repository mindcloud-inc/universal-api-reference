# Get Sale with Upnify

Retrieves a sale from Upnify.

## Endpoint

- **Method:** `GET`
- **Path:** `v4/ventas/:tkVenta`
- **Base URL:** `https://api.upnify.com`
- **Official documentation:** [Get Sale](https://desarrollo.upnify.com/api-rest/ventas/#api-Ventas-GetVentasTkventa)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tkVenta` | path | `string` | yes | Identificador unico de una venta en el sistema, de la cual se requiere obtener los detalles.  ¿Dónde obtengo el token? |
