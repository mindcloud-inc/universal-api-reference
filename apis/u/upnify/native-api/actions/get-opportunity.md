# Get Opportunity with Upnify

Retrieves an opportunity from Upnify.

## Endpoint

- **Method:** `GET`
- **Path:** `v4/oportunidades/:tkOportunidad`
- **Base URL:** `https://api.upnify.com`
- **Official documentation:** [Get Opportunity](https://desarrollo.upnify.com/api-rest/oportunidades/#api-Oportunidades-GetOportunidadesTkoportunidad)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tkOportunidad` | path | `string` | yes | Identificador unico de una oportunidad en el sistema, de la cual se requiere obtener los detalles.  ¿Dónde obtengo el token? |
