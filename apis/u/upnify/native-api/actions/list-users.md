# List Users with Upnify

Retrieves users from Upnify.

## Endpoint

- **Method:** `GET`
- **Path:** `v4/catalogos/usuarios`
- **Base URL:** `https://api.upnify.com`
- **Official documentation:** [List Users](https://desarrollo.upnify.com/api-rest/catalogos/#api-Usuarios-GetCatalogosUsuarios)

## Capabilities

This operation supports [pagination](../README.md#pagination).
