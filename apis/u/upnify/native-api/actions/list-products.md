# List Products with Upnify

Retrieves products from Upnify.

## Endpoint

- **Method:** `GET`
- **Path:** `v4/catalogos/productos`
- **Base URL:** `https://api.upnify.com`
- **Official documentation:** [List Products](https://desarrollo.upnify.com/api-rest/catalogos/#api-Productos-GetCatalogosProductos)

## Capabilities

This operation supports [pagination](../README.md#pagination).
