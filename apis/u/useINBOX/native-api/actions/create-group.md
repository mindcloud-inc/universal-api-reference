# Create Group with UseINBOX

Creates a group in UseINBOX.

## Endpoint

- **Method:** `POST`
- **Path:** `/inbox/v1/groups`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Create Group](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupName` | body | `string` | yes | Group name. |
