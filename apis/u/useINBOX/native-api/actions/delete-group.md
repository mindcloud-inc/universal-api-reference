# Delete Group with UseINBOX

Deletes an existing group from UseINBOX.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inbox/v1/groups/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Delete Group](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Group ID from INBOX. |
