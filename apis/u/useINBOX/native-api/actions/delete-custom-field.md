# Delete Custom Field with UseINBOX

Deletes an existing custom field from UseINBOX.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inbox/v1/customfields/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Delete Custom Field](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Custom field ID from INBOX. |
