# Get Contact with UseINBOX

Retrieves a contact from UseINBOX.

## Endpoint

- **Method:** `GET`
- **Path:** `/inbox/v1/contacts/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Get Contact](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact ID from INBOX. |
