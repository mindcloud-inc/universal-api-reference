# Get Campaign with UseINBOX

Retrieves a campaign from UseINBOX.

## Endpoint

- **Method:** `GET`
- **Path:** `/inbox/v1/campaigns/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Get Campaign](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Campaign ID from INBOX. |
