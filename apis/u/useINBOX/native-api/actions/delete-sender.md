# Delete Sender with UseINBOX

Deletes an existing sender from UseINBOX.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inbox/v1/senders/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Delete Sender](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Sender ID from INBOX. |
