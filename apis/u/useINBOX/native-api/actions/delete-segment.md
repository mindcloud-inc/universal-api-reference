# Delete Segment with UseINBOX

Deletes an existing segment from UseINBOX.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inbox/v1/segments/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Delete Segment](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Segment ID from INBOX. |
