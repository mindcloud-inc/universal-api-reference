# Get Newsletter with UseINBOX

Retrieves a newsletter from UseINBOX.

## Endpoint

- **Method:** `GET`
- **Path:** `/inbox/v1/newsletters/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Get Newsletter](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Newsletter ID from INBOX. |
