# Delete Contact List with UseINBOX

Deletes an existing contact list from UseINBOX.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inbox/v1/contactlists/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Delete Contact List](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact list ID from INBOX. |
