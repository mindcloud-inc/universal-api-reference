# Delete Newsletter with UseINBOX

Deletes an existing newsletter from UseINBOX.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inbox/v1/newsletters/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Delete Newsletter](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Newsletter ID from INBOX. |
