# Get Identity Breach Details with UpGuard

Retrieves details for an identity breach in UpGuard.

## Endpoint

- **Method:** `GET`
- **Path:** `/breach`
- **Base URL:** `https://cyber-risk.upguard.com/api/public`
- **Official documentation:** [Get Identity Breach Details](https://cyber-risk.upguard.com/api/docs#operation/identity_breach)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The ID of the breach to fetch |
