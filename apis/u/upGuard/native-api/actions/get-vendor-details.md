# Get Vendor Details with UpGuard

Retrieves details for a vendor in UpGuard.

## Endpoint

- **Method:** `GET`
- **Path:** `/vendor`
- **Base URL:** `https://cyber-risk.upguard.com/api/public`
- **Official documentation:** [Get Vendor Details](https://cyber-risk.upguard.com/api/docs#operation/vendor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hostname` | query | `string` | no | The hostname for which to return vendor data when no vendor ID is provided. |
