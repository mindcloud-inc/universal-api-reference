# Get Risk Details with UpGuard

Retrieves details for an UpGuard risk.

## Endpoint

- **Method:** `GET`
- **Path:** `/available_risks/risk`
- **Base URL:** `https://cyber-risk.upguard.com/api/public`
- **Official documentation:** [Get Risk Details](https://cyber-risk.upguard.com/api/docs#operation/risk)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `risk_id` | query | `string` | yes | ID of the risk to fetch details for |
