# List Typosquat Domains with UpGuard

Retrieves typosquat domains from your UpGuard account.

## Endpoint

- **Method:** `GET`
- **Path:** `/typosquat`
- **Base URL:** `https://cyber-risk.upguard.com/api/public`
- **Official documentation:** [List Typosquat Domains](https://cyber-risk.upguard.com/api/docs#operation/listTyposquatDomains)
