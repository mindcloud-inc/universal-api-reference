# Get Onboarding Request with UpGuard

Retrieves an onboarding request from UpGuard.

## Endpoint

- **Method:** `GET`
- **Path:** `/onboarding_request`
- **Base URL:** `https://cyber-risk.upguard.com/api/public`
- **Official documentation:** [Get Onboarding Request](https://cyber-risk.upguard.com/api/docs#operation/onboardingRequestGet)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The ID of the onboarding request to retrieve. |
