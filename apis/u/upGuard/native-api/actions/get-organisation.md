# Get Organisation with UpGuard

Retrieves your organisation details from UpGuard.

## Endpoint

- **Method:** `GET`
- **Path:** `/organisation`
- **Base URL:** `https://cyber-risk.upguard.com/api/public`
- **Official documentation:** [Get Organisation](https://cyber-risk.upguard.com/api/docs#operation/getOrganisationV1)
