# Get Portfolio Risk Profile Overview with UpGuard

Retrieves a portfolio risk overview from UpGuard.

## Endpoint

- **Method:** `GET`
- **Path:** `/risks/vendors/all`
- **Base URL:** `https://cyber-risk.upguard.com/api/public`
- **Official documentation:** [Get Portfolio Risk Profile Overview](https://cyber-risk.upguard.com/api/docs#operation/vendor_risk_overview_params)

## Capabilities

This operation supports [pagination](../README.md#pagination).
