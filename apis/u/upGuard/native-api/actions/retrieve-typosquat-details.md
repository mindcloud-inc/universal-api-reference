# Retrieve Typosquat Details with UpGuard

Retrieves typosquat details for a domain in UpGuard.

## Endpoint

- **Method:** `GET`
- **Path:** `/typosquat/details`
- **Base URL:** `https://cyber-risk.upguard.com/api/public`
- **Official documentation:** [Retrieve Typosquat Details](https://cyber-risk.upguard.com/api/docs#operation/typosquat_details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | The domain for which to return typosquat details |
