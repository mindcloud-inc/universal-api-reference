# Retrieve IP Details with UpGuard

Retrieves details for an IP address in UpGuard.

## Endpoint

- **Method:** `GET`
- **Path:** `/ip`
- **Base URL:** `https://cyber-risk.upguard.com/api/public`
- **Official documentation:** [Retrieve IP Details](https://cyber-risk.upguard.com/api/docs#operation/ip_details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | query | `string` | yes | The IP address to get details for |
