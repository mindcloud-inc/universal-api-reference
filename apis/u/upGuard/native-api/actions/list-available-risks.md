# List Available Risks with UpGuard

Retrieves available risk definitions from the UpGuard platform.

## Endpoint

- **Method:** `GET`
- **Path:** `/available_risks/v2`
- **Base URL:** `https://cyber-risk.upguard.com/api/public`
- **Official documentation:** [List Available Risks](https://cyber-risk.upguard.com/api/docs#operation/available_risks_v2)
