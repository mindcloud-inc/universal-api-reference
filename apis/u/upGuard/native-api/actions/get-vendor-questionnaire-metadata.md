# Get Vendor Questionnaire Metadata with UpGuard

Retrieves metadata for a vendor questionnaire in UpGuard.

## Endpoint

- **Method:** `GET`
- **Path:** `/vendor/questionnaire`
- **Base URL:** `https://cyber-risk.upguard.com/api/public`
- **Official documentation:** [Get Vendor Questionnaire Metadata](https://cyber-risk.upguard.com/api/docs#operation/questionnaireGet)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The numeric ID of the questionnaire to retrieve. |
