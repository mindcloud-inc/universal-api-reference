# Get Event Data with Umami

## Endpoint

- **Method:** `GET`
- **Path:** `/websites/:websiteId/event-data/:eventId`
- **Base URL:** `https://api.umami.is/v1`
- **Official documentation:** [Get Event Data](https://docs.umami.is/docs/api/events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `websiteId` | path | `string` | yes | The website ID. |
| `eventId` | path | `string` | yes | The event ID. |
