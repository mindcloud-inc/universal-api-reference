# Get Session with Umami

## Endpoint

- **Method:** `GET`
- **Path:** `/websites/:websiteId/sessions/:sessionId`
- **Base URL:** `https://api.umami.is/v1`
- **Official documentation:** [Get Session](https://docs.umami.is/docs/api/sessions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `websiteId` | path | `string` | yes | The website ID. |
| `sessionId` | path | `string` | yes | The session ID. |
