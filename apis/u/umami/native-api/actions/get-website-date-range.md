# Get Website Date Range with Umami

## Endpoint

- **Method:** `GET`
- **Path:** `/websites/:websiteId/daterange`
- **Base URL:** `https://api.umami.is/v1`
- **Official documentation:** [Get Website Date Range](https://docs.umami.is/docs/api/website-stats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `websiteId` | path | `string` | yes | The website ID. |
