# Get Realtime with Umami

## Endpoint

- **Method:** `GET`
- **Path:** `/realtime/:websiteId`
- **Base URL:** `https://api.umami.is/v1`
- **Official documentation:** [Get Realtime](https://docs.umami.is/docs/api/realtime)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `websiteId` | path | `string` | yes | The website ID. |
