# Delete Time Entry with UKG Ready

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/companies/:cid/time-entries/:time_entry_id`
- **Base URL:** `https://{hostname}/ta/rest`
- **Official documentation:** [Delete Time Entry](https://secure7.saashr.com/ta/docs/rest/public)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cid` | path | `string` | no |
| `time_entry_id` | path | `string` | no |
