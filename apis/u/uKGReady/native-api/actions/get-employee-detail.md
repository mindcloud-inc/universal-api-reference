# Get Employee Detail with UKG Ready

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/companies/:cid/employees/:employeeId`
- **Base URL:** `https://{hostname}/ta/rest`
- **Official documentation:** [Get Employee Detail](https://secure7.saashr.com/ta/docs/rest/public)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cid` | path | `string` | no |
| `employeeId` | path | `string` | no |
