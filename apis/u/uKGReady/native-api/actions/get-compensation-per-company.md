# Get Compensation per company with UKG Ready

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/companies/:cid/compensation/total`
- **Base URL:** `https://{hostname}/ta/rest`
- **Official documentation:** [Get Compensation per company](https://secure7.saashr.com/ta/docs/rest/public)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cid` | path | `string` | no |
