# Get Account Assignments with UKG Ready

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/companies/:cid/position/assignments/:accountId`
- **Base URL:** `https://{hostname}/ta/rest`
- **Official documentation:** [Get Account Assignments](https://secure7.saashr.com/ta/docs/rest/public)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cid` | path | `string` | no |
| `accountId` | path | `string` | no |
