- **Method:** `DELETE`
- **Path:** `/trackers/:trackerSlug`
- **Base URL:** `https://api.ubiqod.com`
- **Official documentation:** [Delete Tracker](https://github.com/microsoft/PowerPlatformConnectors/tree/dev/certified-connectors/Ubiqod%20by%20Skiply%20(v2))

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trackerSlug` | path | `string` | yes | Tracker slug. |
