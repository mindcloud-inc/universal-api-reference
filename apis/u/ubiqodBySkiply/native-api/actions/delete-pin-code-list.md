# Delete PIN Code List with Ubiqod by Skiply

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pincodes/:pinCodeListId`
- **Base URL:** `https://api.ubiqod.com`
- **Official documentation:** [Delete PIN Code List](https://github.com/microsoft/PowerPlatformConnectors/tree/dev/certified-connectors/Ubiqod%20by%20Skiply%20(v2))

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pinCodeListId` | path | `string` | yes | PIN code list ID. |
