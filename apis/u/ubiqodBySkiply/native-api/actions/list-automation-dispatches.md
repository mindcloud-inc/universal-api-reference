# List Automation Dispatches with Ubiqod by Skiply

## Endpoint

- **Method:** `GET`
- **Path:** `/dispatchs/`
- **Base URL:** `https://api.ubiqod.com`
- **Official documentation:** [List Automation Dispatches](https://github.com/microsoft/PowerPlatformConnectors/tree/dev/certified-connectors/Ubiqod%20by%20Skiply%20(v2))

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | query | `string` | no | Dispatch type. Defaults to POWERAUTOMATE in Ubiqod's connector definition. |
