# Validate Email with UserCheck

Retrieves email validation details from UserCheck.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/:email`
- **Base URL:** `https://api.usercheck.com`
- **Official documentation:** [Validate Email](https://www.usercheck.com/docs/api/email-endpoint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Email address to validate. |
