# Validate Domain with UserCheck

Retrieves domain validation details from UserCheck.

## Endpoint

- **Method:** `GET`
- **Path:** `/domain/:domain`
- **Base URL:** `https://api.usercheck.com`
- **Official documentation:** [Validate Domain](https://www.usercheck.com/docs/api/domain-endpoint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain to validate. |
