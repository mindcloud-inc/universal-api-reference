# Get Blocklisted Domain with UserCheck

Retrieves a blocklisted domain from UserCheck.

## Endpoint

- **Method:** `GET`
- **Path:** `/blocklist/:domain`
- **Base URL:** `https://api.usercheck.com`
- **Official documentation:** [Get Blocklisted Domain](https://www.usercheck.com/docs/api/blocklist-endpoint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain to check in the blocklist. |
