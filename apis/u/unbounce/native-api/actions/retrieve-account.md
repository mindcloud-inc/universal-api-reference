# Retrieve Account with Unbounce

Retrieves details for an Unbounce account.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:account_id`
- **Base URL:** `https://api.unbounce.com`
- **Official documentation:** [Retrieve Account](https://developer.unbounce.com/api_reference/#id_accounts__account_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `string` | yes | Unbounce account ID. |
