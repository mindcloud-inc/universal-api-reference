# List Sub Account Page Groups with Unbounce

Retrieves page groups for an Unbounce sub-account.

## Endpoint

- **Method:** `GET`
- **Path:** `/sub_accounts/:sub_account_id/page_groups`
- **Base URL:** `https://api.unbounce.com`
- **Official documentation:** [List Sub Account Page Groups](https://developer.unbounce.com/api_reference/#id_sub_accounts__sub_account_id__page_groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sub_account_id` | path | `string` | yes | Unbounce sub-account ID. |
