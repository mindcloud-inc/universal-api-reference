# List Sub Account Pages with Unbounce

Retrieves pages for an Unbounce sub-account.

## Endpoint

- **Method:** `GET`
- **Path:** `/sub_accounts/:sub_account_id/pages`
- **Base URL:** `https://api.unbounce.com`
- **Official documentation:** [List Sub Account Pages](https://developer.unbounce.com/api_reference/#id_sub_accounts__sub_account_id__pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sub_account_id` | path | `string` | yes | Unbounce sub-account ID. |
