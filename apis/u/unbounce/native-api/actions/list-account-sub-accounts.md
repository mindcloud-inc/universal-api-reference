# List Account Sub Accounts with Unbounce

Retrieves sub-accounts for a specified Unbounce account.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:account_id/sub_accounts`
- **Base URL:** `https://api.unbounce.com`
- **Official documentation:** [List Account Sub Accounts](https://developer.unbounce.com/api_reference/#id_accounts__account_id__sub_accounts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `string` | yes | Unbounce account ID. |
