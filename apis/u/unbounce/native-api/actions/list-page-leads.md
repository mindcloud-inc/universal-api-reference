# List Page Leads with Unbounce

Retrieves leads for an Unbounce page.

## Endpoint

- **Method:** `GET`
- **Path:** `/pages/:page_id/leads`
- **Base URL:** `https://api.unbounce.com`
- **Official documentation:** [List Page Leads](https://developer.unbounce.com/api_reference/#id_pages__page_id__leads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | path | `string` | yes | Unbounce page ID. |
