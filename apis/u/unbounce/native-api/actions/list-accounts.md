# List Accounts with Unbounce

Retrieves the accounts collection from Unbounce.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://api.unbounce.com`
- **Official documentation:** [List Accounts](https://developer.unbounce.com/api_reference/#id_accounts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sort_order` | query | `string` | no | Sort by creation date order. Accepted values: `0`, `1`. |
