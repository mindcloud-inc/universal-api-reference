# List Account Pages with Unbounce

Retrieves pages for a specified Unbounce account.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:account_id/pages`
- **Base URL:** `https://api.unbounce.com`
- **Official documentation:** [List Account Pages](https://developer.unbounce.com/api_reference/#id_accounts__account_id__pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `string` | yes | Unbounce account ID. |
