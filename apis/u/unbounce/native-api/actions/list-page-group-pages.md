# List Page Group Pages with Unbounce

Retrieves pages for an Unbounce page group.

## Endpoint

- **Method:** `GET`
- **Path:** `/page_groups/:page_group_id/pages`
- **Base URL:** `https://api.unbounce.com`
- **Official documentation:** [List Page Group Pages](https://developer.unbounce.com/api_reference/#id_page_groups__page_group_id__pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_group_id` | path | `string` | yes | Unbounce page group ID. |
