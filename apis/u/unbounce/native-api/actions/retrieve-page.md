# Retrieve Page with Unbounce

Retrieves details for an Unbounce page.

## Endpoint

- **Method:** `GET`
- **Path:** `/pages/:page_id`
- **Base URL:** `https://api.unbounce.com`
- **Official documentation:** [Retrieve Page](https://developer.unbounce.com/api_reference/#id_pages__page_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | path | `string` | yes | Unbounce page ID. |
