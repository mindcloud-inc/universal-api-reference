# Get Lead with Unbounce

Retrieves a specific lead from Unbounce.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:lead_id`
- **Base URL:** `https://api.unbounce.com`
- **Official documentation:** [Get Lead](https://developer.unbounce.com/api_reference/#id_leads__lead_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lead_id` | path | `string` | yes | Unbounce lead ID. |
