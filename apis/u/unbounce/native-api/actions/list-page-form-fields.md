# List Page Form Fields with Unbounce

Retrieves form fields across all variants of an Unbounce page.

## Endpoint

- **Method:** `GET`
- **Path:** `/pages/:page_id/form_fields`
- **Base URL:** `https://api.unbounce.com`
- **Official documentation:** [List Page Form Fields](https://developer.unbounce.com/api_reference/#id_pages__page_id__form_fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | path | `string` | yes | Unbounce page ID. |
