# Retrieve Sub Account with Unbounce

Retrieves details for an Unbounce sub-account.

## Endpoint

- **Method:** `GET`
- **Path:** `/sub_accounts/:sub_account_id`
- **Base URL:** `https://api.unbounce.com`
- **Official documentation:** [Retrieve Sub Account](https://developer.unbounce.com/api_reference/#id_sub_accounts__sub_account_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sub_account_id` | path | `string` | yes | Unbounce sub-account ID. |
