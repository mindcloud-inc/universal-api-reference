# Get folder with UiPath Orchestrator

## Endpoint

- **Method:** `GET`
- **Path:** `/odata/Folders(:id)`
- **Base URL:** `https://cloud.uipath.com/{organizationName}/{tenantName}/orchestrator_`
- **Official documentation:** [Get folder](https://docs.uipath.com/orchestrator/automation-cloud/latest/api-guide/folders-requests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric folder ID. |
