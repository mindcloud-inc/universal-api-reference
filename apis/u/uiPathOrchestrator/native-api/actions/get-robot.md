# Get robot with UiPath Orchestrator

## Endpoint

- **Method:** `GET`
- **Path:** `/odata/Robots(:id)`
- **Base URL:** `https://cloud.uipath.com/{organizationName}/{tenantName}/orchestrator_`
- **Official documentation:** [Get robot](https://docs.uipath.com/orchestrator/automation-cloud/latest/api-guide/robots-requests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric robot ID. |
