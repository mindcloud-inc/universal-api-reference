# List tasks across folders with UiPath Orchestrator

## Endpoint

- **Method:** `GET`
- **Path:** `/odata/Tasks/UiPath.Server.Configuration.OData.GetTasksAcrossFolders`
- **Base URL:** `https://cloud.uipath.com/{organizationName}/{tenantName}/orchestrator_`
- **Official documentation:** [List tasks across folders](https://docs.uipath.com/orchestrator/automation-cloud/latest/api-guide/tasks-requests)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
