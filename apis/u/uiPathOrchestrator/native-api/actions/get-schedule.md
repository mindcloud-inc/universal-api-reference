# Get schedule with UiPath Orchestrator

## Endpoint

- **Method:** `GET`
- **Path:** `/odata/ProcessSchedules(:id)`
- **Base URL:** `https://cloud.uipath.com/{organizationName}/{tenantName}/orchestrator_`
- **Official documentation:** [Get schedule](https://docs.uipath.com/orchestrator/automation-cloud/latest/api-guide/schedules-requests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric schedule ID. |
