# List machines with UiPath Orchestrator

## Endpoint

- **Method:** `GET`
- **Path:** `/odata/Machines`
- **Base URL:** `https://cloud.uipath.com/{organizationName}/{tenantName}/orchestrator_`
- **Official documentation:** [List machines](https://docs.uipath.com/orchestrator/automation-cloud/latest/api-guide/machines-requests)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
