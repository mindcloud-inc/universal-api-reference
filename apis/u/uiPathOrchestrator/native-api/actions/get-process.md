# Get process with UiPath Orchestrator

## Endpoint

- **Method:** `GET`
- **Path:** `/odata/Processes(:id)`
- **Base URL:** `https://cloud.uipath.com/{organizationName}/{tenantName}/orchestrator_`
- **Official documentation:** [Get process](https://docs.uipath.com/orchestrator/automation-cloud/latest/api-guide/processes-requests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric process ID. |
