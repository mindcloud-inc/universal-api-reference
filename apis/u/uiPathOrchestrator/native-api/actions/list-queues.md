# List queues with UiPath Orchestrator

## Endpoint

- **Method:** `GET`
- **Path:** `/odata/QueueDefinitions`
- **Base URL:** `https://cloud.uipath.com/{organizationName}/{tenantName}/orchestrator_`
- **Official documentation:** [List queues](https://docs.uipath.com/orchestrator/automation-cloud/latest/api-guide/queue-items-requests)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
