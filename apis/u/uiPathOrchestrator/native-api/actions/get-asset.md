# Get asset with UiPath Orchestrator

## Endpoint

- **Method:** `GET`
- **Path:** `/odata/Assets(:id)`
- **Base URL:** `https://cloud.uipath.com/{organizationName}/{tenantName}/orchestrator_`
- **Official documentation:** [Get asset](https://docs.uipath.com/orchestrator/automation-cloud/latest/api-guide/assets-requests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric asset ID. |
