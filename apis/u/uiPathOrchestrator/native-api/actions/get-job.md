# Get job with UiPath Orchestrator

## Endpoint

- **Method:** `GET`
- **Path:** `/odata/Jobs(:id)`
- **Base URL:** `https://cloud.uipath.com/{organizationName}/{tenantName}/orchestrator_`
- **Official documentation:** [Get job](https://docs.uipath.com/orchestrator/automation-cloud/latest/api-guide/jobs-requests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric job ID. |
