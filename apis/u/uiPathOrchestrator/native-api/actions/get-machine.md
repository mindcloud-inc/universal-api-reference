# Get machine with UiPath Orchestrator

## Endpoint

- **Method:** `GET`
- **Path:** `/odata/Machines(:id)`
- **Base URL:** `https://cloud.uipath.com/{organizationName}/{tenantName}/orchestrator_`
- **Official documentation:** [Get machine](https://docs.uipath.com/orchestrator/automation-cloud/latest/api-guide/machines-requests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric machine ID. |
