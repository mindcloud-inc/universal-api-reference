# Delete Monitor with UptimeRobot

Deletes an existing monitor from UptimeRobot.

## Endpoint

- **Method:** `POST`
- **Path:** `/deleteMonitor`
- **Base URL:** `https://api.uptimerobot.com/v2`
- **Official documentation:** [Delete Monitor](https://uptimerobot.com/api/legacy/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | ID of the monitor to delete. |
