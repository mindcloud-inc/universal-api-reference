# Delete Maintenance Window with UptimeRobot

Deletes an existing maintenance window from UptimeRobot.

## Endpoint

- **Method:** `POST`
- **Path:** `/deleteMWindow`
- **Base URL:** `https://api.uptimerobot.com/v2`
- **Official documentation:** [Delete Maintenance Window](https://uptimerobot.com/api/legacy/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | ID of the maintenance window to delete. |
