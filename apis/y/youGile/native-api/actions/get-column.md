# Get column with YouGile

Retrieves details for a column from YouGile.

## Endpoint

- **Method:** `GET`
- **Path:** `/columns/:id`
- **Base URL:** `{companyDomain}/api-v2`
- **Official documentation:** [Get column](https://ru.yougile.com/api-v2#/operations/ColumnController_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The YouGile column ID. |
