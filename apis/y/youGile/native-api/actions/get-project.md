# Get project with YouGile

Retrieves details for a project from YouGile.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `{companyDomain}/api-v2`
- **Official documentation:** [Get project](https://ru.yougile.com/api-v2#/operations/ProjectController_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The YouGile project ID. |
