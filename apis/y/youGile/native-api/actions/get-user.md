# Get user with YouGile

Retrieves details for a user from YouGile.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `{companyDomain}/api-v2`
- **Official documentation:** [Get user](https://ru.yougile.com/api-v2#/operations/UserController_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The YouGile user ID. |
