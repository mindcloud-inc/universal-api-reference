# Get group chat with YouGile

Retrieves details for a group chat from YouGile.

## Endpoint

- **Method:** `GET`
- **Path:** `/group-chats/:id`
- **Base URL:** `{companyDomain}/api-v2`
- **Official documentation:** [Get group chat](https://ru.yougile.com/api-v2#/operations/GroupChatController_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The YouGile group chat ID. |
