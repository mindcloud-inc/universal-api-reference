# Get task with YouGile

Retrieves details for a task from YouGile.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `{companyDomain}/api-v2`
- **Official documentation:** [Get task](https://ru.yougile.com/api-v2#/operations/TaskController_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The YouGile task ID. |
