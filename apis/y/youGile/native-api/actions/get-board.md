# Get board with YouGile

Retrieves details for a board from YouGile.

## Endpoint

- **Method:** `GET`
- **Path:** `/boards/:id`
- **Base URL:** `{companyDomain}/api-v2`
- **Official documentation:** [Get board](https://ru.yougile.com/api-v2#/operations/BoardController_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The YouGile board ID. |
