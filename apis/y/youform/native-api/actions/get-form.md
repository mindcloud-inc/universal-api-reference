# Get Form with Youform

Retrieves a form from Youform.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formSlug`
- **Base URL:** `https://app.youform.com/api`
- **Official documentation:** [Get Form](https://youform.com/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formSlug` | path | `string` | yes | Slug of the form to retrieve. |
