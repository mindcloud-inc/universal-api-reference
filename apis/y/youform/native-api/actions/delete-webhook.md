# Delete Webhook with Youform

Deletes a webhook from Youform.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://app.youform.com/api`
- **Official documentation:** [Delete Webhook](https://youform.com/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `number` | yes | Numeric ID of the webhook to delete. |
