# Get Site SEO Head with Yoast SEO

Retrieves Yoast SEO metadata for the connected site URL.

## Endpoint

- **Method:** `GET`
- **Path:** `/yoast/v1/get_head`
- **Base URL:** `{siteUrl}/wp-json`
- **Official documentation:** [Get Site SEO Head](https://developer.yoast.com/customization/apis/rest-api/)
