# Get Schema Aggregator Sitemap XML with Yoast SEO

Retrieves the Schema Aggregator sitemap XML.

## Endpoint

- **Method:** `GET`
- **Path:** `/yoast/v1/schema-aggregator/get-xml`
- **Base URL:** `{siteUrl}/wp-json`
- **Official documentation:** [Get Schema Aggregator Sitemap XML](https://developer.yoast.com/features/schema/schema-aggregator/api-reference/)
