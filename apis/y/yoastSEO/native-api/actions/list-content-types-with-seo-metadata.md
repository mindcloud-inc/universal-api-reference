# List Content Types With SEO Metadata with Yoast SEO

Lists content types with Yoast SEO metadata.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/types`
- **Base URL:** `{siteUrl}/wp-json`
- **Official documentation:** [List Content Types With SEO Metadata](https://developer.yoast.com/customization/apis/rest-api/)
