# Get Page SEO Metadata with Yoast SEO

Retrieves Yoast SEO metadata for a page.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/pages/:id`
- **Base URL:** `{siteUrl}/wp-json`
- **Official documentation:** [Get Page SEO Metadata](https://developer.yoast.com/customization/apis/rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique identifier of the WordPress page. |
