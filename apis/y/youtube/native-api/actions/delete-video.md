# Delete Video with YouTube

Deletes an existing video from YouTube.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/youtube/v3/videos`
- **Base URL:** `https://www.googleapis.com`
- **Official documentation:** [Delete Video](https://developers.google.com/youtube/v3/docs/videos/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
| `onBehalfOfContentOwner` | query | `string` | no |
