# Get User with Yousign

Retrieves a user from Yousign.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://api-sandbox.yousign.app/v3`
- **Official documentation:** [Get User](https://developers.yousign.com/reference/get-users-userid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The Yousign user ID. |
