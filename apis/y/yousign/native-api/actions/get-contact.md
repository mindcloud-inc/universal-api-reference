# Get Contact with Yousign

Retrieves a contact from Yousign.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId`
- **Base URL:** `https://api-sandbox.yousign.app/v3`
- **Official documentation:** [Get Contact](https://developers.yousign.com/reference/get-contacts-contactid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The Yousign contact ID. |
