# Get Default Workspace with Yousign

Retrieves the default workspace from Yousign.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/default`
- **Base URL:** `https://api-sandbox.yousign.app/v3`
- **Official documentation:** [Get Default Workspace](https://developers.yousign.com/reference/get-workspaces-default-1)
