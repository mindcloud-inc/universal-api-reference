# Create Label with Yousign

Creates a new label in Yousign.

## Endpoint

- **Method:** `POST`
- **Path:** `/labels`
- **Base URL:** `https://api-sandbox.yousign.app/v3`
- **Official documentation:** [Create Label](https://developers.yousign.com/reference/post-labels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Label name. |
