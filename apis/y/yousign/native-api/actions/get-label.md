# Get Label with Yousign

Retrieves a label from Yousign.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels/:labelId`
- **Base URL:** `https://api-sandbox.yousign.app/v3`
- **Official documentation:** [Get Label](https://developers.yousign.com/reference/get-labels-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `labelId` | path | `string` | yes | The Yousign label ID. |
