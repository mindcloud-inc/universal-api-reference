# Get Delegation with Yeeflow

- **Method:** `GET`
- **Path:** `/workflow/delegates/:id`
- **Base URL:** `https://api.yeeflow.com/v1`
- **Official documentation:** [Get Delegation](https://developer.yeeflow.com/api/#tag/Workflows/paths/~1workflow~1delegates~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Delegation ID from Yeeflow. |
