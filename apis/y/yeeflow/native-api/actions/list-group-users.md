# List Group Users with Yeeflow

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id/users`
- **Base URL:** `https://api.yeeflow.com/v1`
- **Official documentation:** [List Group Users](https://developer.yeeflow.com/api/#tag/Groups/paths/~1groups~1{id}~1users/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Group ID from Yeeflow. |
