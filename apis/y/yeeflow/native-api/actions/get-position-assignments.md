# Get Position Assignments with Yeeflow

## Endpoint

- **Method:** `GET`
- **Path:** `/positions/:id/users`
- **Base URL:** `https://api.yeeflow.com/v1`
- **Official documentation:** [Get Position Assignments](https://developer.yeeflow.com/api/#tag/Positions/paths/~1positions~1{id}~1users/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Position ID from Yeeflow. |
