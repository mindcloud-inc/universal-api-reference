# Add Users To Group with Yeeflow

## Endpoint

- **Method:** `POST`
- **Path:** `/groups/:id/users`
- **Base URL:** `https://api.yeeflow.com/v1`
- **Official documentation:** [Add Users To Group](https://developer.yeeflow.com/api/#tag/Groups/paths/~1groups~1{id}~1users/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Group ID from Yeeflow. |
