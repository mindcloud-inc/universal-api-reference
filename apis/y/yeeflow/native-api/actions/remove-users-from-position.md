# Remove Users From Position with Yeeflow

## Endpoint

- **Method:** `POST`
- **Path:** `/positions/:id/users/remove`
- **Base URL:** `https://api.yeeflow.com/v1`
- **Official documentation:** [Remove Users From Position](https://developer.yeeflow.com/api/#tag/Positions/paths/~1positions~1{id}~1users~1remove/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Position ID from Yeeflow. |
