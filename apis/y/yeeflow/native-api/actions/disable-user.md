# Disable User with Yeeflow

## Endpoint

- **Method:** `PUT`
- **Path:** `/users/:id/disable`
- **Base URL:** `https://api.yeeflow.com/v1`
- **Official documentation:** [Disable User](https://developer.yeeflow.com/api/#tag/Users/paths/~1users~1{id}~1disable/put)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | User ID from Yeeflow. |
