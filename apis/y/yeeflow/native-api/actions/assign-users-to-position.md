# Assign Users To Position with Yeeflow

## Endpoint

- **Method:** `POST`
- **Path:** `/positions/:id/users`
- **Base URL:** `https://api.yeeflow.com/v1`
- **Official documentation:** [Assign Users To Position](https://developer.yeeflow.com/api/#tag/Positions/paths/~1positions~1{id}~1users/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Position ID from Yeeflow. |
