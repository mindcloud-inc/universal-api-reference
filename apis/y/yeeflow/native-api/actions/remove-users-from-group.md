# Remove Users From Group with Yeeflow

## Endpoint

- **Method:** `POST`
- **Path:** `/groups/:id/users/remove`
- **Base URL:** `https://api.yeeflow.com/v1`
- **Official documentation:** [Remove Users From Group](https://developer.yeeflow.com/api/#tag/Groups/paths/~1groups~1{id}~1users~1remove/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Group ID from Yeeflow. |
