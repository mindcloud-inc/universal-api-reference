# Enable Delegation with Yeeflow

## Endpoint

- **Method:** `PUT`
- **Path:** `/workflow/delegates/:id/enable`
- **Base URL:** `https://api.yeeflow.com/v1`
- **Official documentation:** [Enable Delegation](https://developer.yeeflow.com/api/#tag/Workflows/paths/~1workflow~1delegates~1{id}~1enable/put)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Delegation ID from Yeeflow. |
