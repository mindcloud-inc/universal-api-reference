# List Users From List with Yanado

Retrieves users from a Yanado list.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/lists/:listId/users`
- **Base URL:** `https://api.yanado.com`
- **Official documentation:** [List Users From List](https://api.yanado.com/docs/#get-users-from-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Yanado list ID. |
