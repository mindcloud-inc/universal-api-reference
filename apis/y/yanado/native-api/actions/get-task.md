# Get Task with Yanado

Retrieves a task from Yanado.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/tasks/:taskId`
- **Base URL:** `https://api.yanado.com`
- **Official documentation:** [Get Task](https://api.yanado.com/docs/#get-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | Yanado task ID. |
