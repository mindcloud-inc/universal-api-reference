# List Users From Team with Yanado

Retrieves users from a Yanado team.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/users`
- **Base URL:** `https://api.yanado.com`
- **Official documentation:** [List Users From Team](https://api.yanado.com/docs/#get-users-from-a-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | query | `string` | no | Optionally limit users to one list. |
