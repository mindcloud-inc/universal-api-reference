# List Statuses From List with Yanado

Retrieves statuses from a Yanado list.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/lists/:listId/statuses`
- **Base URL:** `https://api.yanado.com`
- **Official documentation:** [List Statuses From List](https://api.yanado.com/docs/#get-statuses-from-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Yanado list ID. |
