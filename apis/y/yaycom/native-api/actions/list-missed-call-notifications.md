# List Missed Call Notifications with Yay.com

Retrieves missed call notifications from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/voip/missed-call`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [List Missed Call Notifications](https://www.yay.com/voip/api-docs/calls/call-missed-notification/)
