# List Allowed International Call Exceptions with Yay.com

Retrieves allowed international call exceptions from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/voip/call-restrictions/international-exception`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [List Allowed International Call Exceptions](https://www.yay.com/voip/api-docs/calls/call-restriction/)
