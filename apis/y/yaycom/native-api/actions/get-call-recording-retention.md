# Get Call Recording Retention with Yay.com

Retrieves call recording retention from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/voip/call-retention`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [Get Call Recording Retention](https://www.yay.com/voip/api-docs/calls/call-retention/)
