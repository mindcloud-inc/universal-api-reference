# List Call Restriction Patterns with Yay.com

Retrieves call restriction patterns from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/voip/call-restrictions/call-pattern`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [List Call Restriction Patterns](https://www.yay.com/voip/api-docs/calls/call-restriction/)
