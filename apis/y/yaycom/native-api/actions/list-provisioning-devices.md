# List Provisioning Devices with Yay.com

Retrieves provisioning devices from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/provisioning/device`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [List Provisioning Devices](https://www.yay.com/voip/api-docs/provisioning/provisioning-device/)
