# List Call Statistics Schedules with Yay.com

Retrieves call statistics schedules from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/voip/call/statistics/schedule`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [List Call Statistics Schedules](https://www.yay.com/voip/api-docs/calls/call-statistics-schedule/)
