# List Emergency Addresses with Yay.com

Retrieves emergency addresses from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/voip/emergency-address`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [List Emergency Addresses](https://www.yay.com/voip/api-docs/numbers/emergency-address/)
