# Get Account Balance with Yay.com

Retrieves the account balance from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/balance`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [Get Account Balance](https://www.yay.com/voip/api-docs/account/account-reseller-balance/)
