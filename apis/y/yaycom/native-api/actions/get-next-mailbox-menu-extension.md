# Get Next Mailbox Menu Extension with Yay.com

Retrieves the next mailbox menu extension from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/voip/next-extension/mailbox-menu`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [Get Next Mailbox Menu Extension](https://www.yay.com/voip/api-docs/mailbox/mailbox-menu/)
