# Get Next Hunt Group Extension with Yay.com

Retrieves the next hunt group extension from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/voip/next-extension/group`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [Get Next Hunt Group Extension](https://www.yay.com/voip/api-docs/users/hunt-group/)
