# Get Next SIP User Extension with Yay.com

Retrieves the next SIP user extension from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/voip/next-extension/user`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [Get Next SIP User Extension](https://www.yay.com/voip/api-docs/users/sip-user/)
