# List Reseller Addresses with Yay.com

Retrieves reseller addresses from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/reseller-address`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [List Reseller Addresses](https://www.yay.com/voip/api-docs/account/account-reseller-address/)
