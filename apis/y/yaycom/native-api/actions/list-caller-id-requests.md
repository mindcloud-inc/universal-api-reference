# List Caller ID Requests with Yay.com

Retrieves caller ID requests from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/voip/cli-request`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [List Caller ID Requests](https://www.yay.com/voip/api-docs/caller-id/cli-request/)
