# List Reseller Users with Yay.com

Retrieves reseller users from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/reseller-user`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [List Reseller Users](https://www.yay.com/voip/api-docs/account/account-reseller-user/)
