# Get Maximum Call Cost Restriction with Yay.com

Retrieves the maximum call cost restriction from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/voip/call-restrictions/max-call-cost`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [Get Maximum Call Cost Restriction](https://www.yay.com/voip/api-docs/calls/call-restriction/)
