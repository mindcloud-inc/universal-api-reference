# Get Next Call Flow Extension with Yay.com

Retrieves the next call flow extension from Yay.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/voip/next-extension/flow`
- **Base URL:** `https://api.yay.com`
- **Official documentation:** [Get Next Call Flow Extension](https://www.yay.com/voip/api-docs/numbers/call-route/)
