# Get Sub-contractor with Yeti Snow

## Endpoint

- **Method:** `GET`
- **Path:** `sub_contractor/show/{{sub_contractor_id}}`
- **Base URL:** `https://sandbox_api.yetisoftware.com/api/en/public_access/1715`
- **Official documentation:** [Get Sub-contractor](https://documenter.getpostman.com/view/5759255/Uyxohiig)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sub_contractor_id` | path | `string` | no | Sub-contractor identifier from List Sub-contractors. |
