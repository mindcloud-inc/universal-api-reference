# Get Contractor with Yeti Snow

## Endpoint

- **Method:** `GET`
- **Path:** `contractor/show/{{contractor_id}}`
- **Base URL:** `https://sandbox_api.yetisoftware.com/api/en/public_access/1715`
- **Official documentation:** [Get Contractor](https://documenter.getpostman.com/view/5759255/Uyxohiig)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contractor_id` | path | `string` | no | Contractor identifier from List Contractors. |
