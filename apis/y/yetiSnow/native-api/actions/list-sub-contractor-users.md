# List Sub-contractor Users with Yeti Snow

## Endpoint

- **Method:** `GET`
- **Path:** `sub_contractor/show/{{sub_contractor_id}}/users`
- **Base URL:** `https://sandbox_api.yetisoftware.com/api/en/public_access/1715`
- **Official documentation:** [List Sub-contractor Users](https://documenter.getpostman.com/view/5759255/Uyxohiig)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `string` | no | Page number to retrieve. |
| `sub_contractor_id` | path | `string` | no | Sub-contractor identifier from List Sub-contractors. |
