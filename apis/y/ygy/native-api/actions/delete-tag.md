# Delete Tag with y.gy

Deletes an existing tag from y.gy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/tag/:id`
- **Base URL:** `https://api.y.gy`
- **Official documentation:** [Delete Tag](https://app.y.gy/docs/api-docs/tags)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
