# Create Tag with y.gy

Creates a new tag in y.gy.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/tag`
- **Base URL:** `https://api.y.gy`
- **Official documentation:** [Create Tag](https://app.y.gy/docs/api-docs/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the tag to create. |
