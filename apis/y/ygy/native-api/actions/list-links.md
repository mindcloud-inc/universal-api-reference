# List Links with y.gy

Retrieves short links from y.gy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/link`
- **Base URL:** `https://api.y.gy`
- **Official documentation:** [List Links](https://app.y.gy/docs/api-docs/links)

## Capabilities

This operation supports [pagination](../README.md#pagination).
