# Delete Short Link with y.gy

Deletes an existing short link from y.gy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/link/:id`
- **Base URL:** `https://api.y.gy`
- **Official documentation:** [Delete Short Link](https://app.y.gy/docs/api-docs/links)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
