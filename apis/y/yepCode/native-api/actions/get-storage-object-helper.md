# Get storage object helper with YepCode

Retrieves a storage object from YepCode.

## Endpoint

- **Method:** `GET`
- **Path:** `/storage/objects/:filename`
- **Base URL:** `https://cloud.yepcode.io/api/{team}/rest`
- **Official documentation:** [Get storage object helper](https://cloud.yepcode.io/api/rest/public/swagger-ui/index.html#/Storage/getStorageObject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filename` | path | `string` | yes | Storage object filename. |
