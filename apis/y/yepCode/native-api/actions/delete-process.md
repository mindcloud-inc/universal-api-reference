# Delete process with YepCode

Deletes an existing process from YepCode.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/processes/:identifier`
- **Base URL:** `https://cloud.yepcode.io/api/{team}/rest`
- **Official documentation:** [Delete process](https://cloud.yepcode.io/api/rest/public/swagger-ui/index.html#/Processes/deleteProcess)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `identifier` | path | `string` | yes |
