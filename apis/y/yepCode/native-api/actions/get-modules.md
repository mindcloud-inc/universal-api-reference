# Get modules with YepCode

Retrieves a list of modules from YepCode.

## Endpoint

- **Method:** `GET`
- **Path:** `/modules`
- **Base URL:** `https://cloud.yepcode.io/api/{team}/rest`
- **Official documentation:** [Get modules](https://cloud.yepcode.io/api/rest/public/swagger-ui/index.html#/Modules/getModules)

## Capabilities

This operation supports [pagination](../README.md#pagination).
