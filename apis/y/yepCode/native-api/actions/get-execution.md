# Get execution with YepCode

Retrieves details for an execution from YepCode.

## Endpoint

- **Method:** `GET`
- **Path:** `/executions/:id`
- **Base URL:** `https://cloud.yepcode.io/api/{team}/rest`
- **Official documentation:** [Get execution](https://cloud.yepcode.io/api/rest/public/swagger-ui/index.html#/Executions/getExecution)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the execution to retrieve. |
