# Delete module with YepCode

Deletes an existing module from YepCode.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/modules/:id`
- **Base URL:** `https://cloud.yepcode.io/api/{team}/rest`
- **Official documentation:** [Delete module](https://cloud.yepcode.io/api/rest/public/swagger-ui/index.html#/Modules/deleteModule)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
