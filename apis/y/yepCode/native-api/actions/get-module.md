# Get module with YepCode

Retrieves details for a module from YepCode.

## Endpoint

- **Method:** `GET`
- **Path:** `/modules/:id`
- **Base URL:** `https://cloud.yepcode.io/api/{team}/rest`
- **Official documentation:** [Get module](https://cloud.yepcode.io/api/rest/public/swagger-ui/index.html#/Modules/getModule)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the module to retrieve. |
