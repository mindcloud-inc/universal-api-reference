# Get variables with YepCode

Retrieves a list of variables from YepCode.

## Endpoint

- **Method:** `GET`
- **Path:** `/variables`
- **Base URL:** `https://cloud.yepcode.io/api/{team}/rest`
- **Official documentation:** [Get variables](https://cloud.yepcode.io/api/rest/public/swagger-ui/index.html#/Variables/getVariables)

## Capabilities

This operation supports [pagination](../README.md#pagination).
