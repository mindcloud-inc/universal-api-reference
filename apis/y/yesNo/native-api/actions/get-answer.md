# Get Answer with Yes/No

## Endpoint

- **Method:** `GET`
- **Path:** `/api`
- **Base URL:** `https://yesno.wtf`
- **Official documentation:** [Get Answer](https://yesno.wtf/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `force` | query | `list<string>` | no | Optionally force the response to yes, no, or maybe. Accepted values: `maybe`, `no`, `yes`. |
