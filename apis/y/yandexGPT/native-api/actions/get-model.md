# Get Model with YandexGPT

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/models/:model_id`
- **Base URL:** `https://ai.api.cloud.yandex.net`
- **Official documentation:** [Get Model](https://yandex.cloud/en/docs/ai-studio/models/getModel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | yes | The AI Studio model identifier to retrieve. |
