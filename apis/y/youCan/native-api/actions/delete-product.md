# Delete Product with YouCan

Deletes an existing product from YouCan.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/products/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Delete Product](https://developer.youcan.shop/store-admin/products/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
