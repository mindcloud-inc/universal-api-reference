# Create Customer Address with YouCan

Creates a customer address in YouCan.

## Endpoint

- **Method:** `POST`
- **Path:** `/customers/{id}/addresses`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Create Customer Address](https://developer.youcan.shop/store-admin/customers/addresses/create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
