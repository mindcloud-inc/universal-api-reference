# Update Page with YouCan

Updates an existing page in YouCan.

## Endpoint

- **Method:** `POST`
- **Path:** `/pages/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Update Page](https://developer.youcan.shop/store-admin/pages/update)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
