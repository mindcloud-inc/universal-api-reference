# Get Order with YouCan

Retrieves details for an order from YouCan.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Get Order](https://developer.youcan.shop/store-admin/orders/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
