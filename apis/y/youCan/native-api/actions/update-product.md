# Update Product with YouCan

Updates an existing product in YouCan.

## Endpoint

- **Method:** `POST`
- **Path:** `/products/update/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Update Product](https://developer.youcan.shop/store-admin/products/update)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
