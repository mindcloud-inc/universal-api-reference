# Update Customer with YouCan

Updates an existing customer in YouCan.

## Endpoint

- **Method:** `PUT`
- **Path:** `/customers/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Update Customer](https://developer.youcan.shop/store-admin/customers/update)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
