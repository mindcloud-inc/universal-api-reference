# Get Coupon with YouCan

Retrieves details for a coupon from YouCan.

## Endpoint

- **Method:** `GET`
- **Path:** `/coupons/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Get Coupon](https://developer.youcan.shop/store-admin/coupons/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
