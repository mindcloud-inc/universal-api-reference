# Delete Customer with YouCan

Deletes an existing customer from YouCan.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customers/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Delete Customer](https://developer.youcan.shop/store-admin/customers/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
