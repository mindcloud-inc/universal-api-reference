# Update Customer Address with YouCan

Updates an existing customer address in YouCan.

## Endpoint

- **Method:** `PUT`
- **Path:** `/customers/{id}/addresses/{addressId}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Update Customer Address](https://developer.youcan.shop/store-admin/customers/addresses/update)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `addressId` | path | `string` | yes |
| `id` | path | `string` | yes |
