# Fulfill Order with YouCan

Updates an order in YouCan by fulfilling it.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orders/{id}/fulfill`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Fulfill Order](https://developer.youcan.shop/store-admin/orders/fulfill)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
