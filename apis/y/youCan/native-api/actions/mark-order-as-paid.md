# Mark Order As Paid with YouCan

Updates an order in YouCan by marking it paid.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orders/{id}/pay`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Mark Order As Paid](https://developer.youcan.shop/store-admin/orders/pay)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
