# Delete Coupon with YouCan

Deletes an existing coupon from YouCan.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/coupons/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Delete Coupon](https://developer.youcan.shop/store-admin/coupons/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
