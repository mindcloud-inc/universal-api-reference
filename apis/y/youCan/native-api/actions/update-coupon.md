# Update Coupon with YouCan

Updates an existing coupon in YouCan.

## Endpoint

- **Method:** `PUT`
- **Path:** `/coupons/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Update Coupon](https://developer.youcan.shop/store-admin/coupons/update)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
