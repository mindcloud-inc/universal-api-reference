# Delete Page with YouCan

Deletes an existing page from YouCan.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pages/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Delete Page](https://developer.youcan.shop/store-admin/pages/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
