# Get Customer with YouCan

Retrieves details for a customer from YouCan.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Get Customer](https://developer.youcan.shop/store-admin/customers/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
