# Get Product with YouCan

Retrieves details for a product from YouCan.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Get Product](https://developer.youcan.shop/store-admin/products/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
