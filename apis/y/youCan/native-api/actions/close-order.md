# Close Order with YouCan

Updates an order in YouCan by closing it.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orders/{id}/close`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Close Order](https://developer.youcan.shop/store-admin/orders/close)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
