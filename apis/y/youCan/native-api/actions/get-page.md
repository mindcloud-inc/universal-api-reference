# Get Page with YouCan

Retrieves details for a page from YouCan.

## Endpoint

- **Method:** `GET`
- **Path:** `/pages/{id}`
- **Base URL:** `https://api.youcan.shop`
- **Official documentation:** [Get Page](https://developer.youcan.shop/store-admin/pages/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
