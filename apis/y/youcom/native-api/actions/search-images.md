# Search Images with You.com

Retrieves image search results from You.com.

## Endpoint

- **Method:** `GET`
- **Path:** `https://image-search.ydc-index.io/images`
- **Base URL:** `https://api.you.com`
- **Official documentation:** [Search Images](https://docs.you.com/custom-solutions/images/images)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Image search query. |
