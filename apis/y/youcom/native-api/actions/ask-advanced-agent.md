# Ask Advanced Agent with You.com

Retrieves an advanced agent response from You.com.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/agents/runs`
- **Base URL:** `https://api.you.com`
- **Official documentation:** [Ask Advanced Agent](https://docs.you.com/custom-solutions/agents/advanced-agent/advanced-agent-runs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | Question to answer. |
