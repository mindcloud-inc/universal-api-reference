# Get Scout with Yutori

Retrieves details for a specific scout in Yutori.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/scouting/tasks/:scout_id`
- **Base URL:** `https://api.yutori.com`
- **Official documentation:** [Get Scout](https://docs.yutori.com/reference/scout-get-detail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scout_id` | path | `string` | yes | The scout UUID. |
