# Get Browsing Task Status with Yutori

Retrieves the status and results of a Yutori browsing task.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/browsing/tasks/:id`
- **Base URL:** `https://api.yutori.com`
- **Official documentation:** [Get Browsing Task Status](https://docs.yutori.com/reference/browsing-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
