# Get Research Task Result with Yutori

Retrieves the status and results of a Yutori research task.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/research/tasks/:task_id`
- **Base URL:** `https://api.yutori.com`
- **Official documentation:** [Get Research Task Result](https://docs.yutori.com/reference/research-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | path | `string` | yes |
