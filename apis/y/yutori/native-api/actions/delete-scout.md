# Delete Scout with Yutori

Deletes an existing scout from Yutori.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/scouting/tasks/:scout_id`
- **Base URL:** `https://api.yutori.com`
- **Official documentation:** [Delete Scout](https://docs.yutori.com/reference/scouts-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scout_id` | path | `string` | yes | The scout UUID. |
