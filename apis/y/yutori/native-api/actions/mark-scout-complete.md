# Mark Scout Complete with Yutori

Marks a Yutori scout as complete.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/scouting/tasks/:scout_id/complete`
- **Base URL:** `https://api.yutori.com`
- **Official documentation:** [Mark Scout Complete](https://docs.yutori.com/reference/scouts-complete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scout_id` | path | `string` | yes | The scout UUID. |
