# Fetch Recently Updated Customers with Yotpo Loyalty & Referrals

Retrieves recently updated customers from Yotpo Loyalty & Referrals.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/customers/recent`
- **Base URL:** `https://loyalty.yotpo.com`
- **Official documentation:** [Fetch Recently Updated Customers](https://loyaltyapi.yotpo.com/reference/fetch-all-recently-updated-customers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
