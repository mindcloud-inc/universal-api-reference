# Fetch VIP Tiers with Yotpo Loyalty & Referrals

Retrieves VIP tiers from Yotpo Loyalty & Referrals.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/vip_tiers`
- **Base URL:** `https://loyalty.yotpo.com`
- **Official documentation:** [Fetch VIP Tiers](https://loyaltyapi.yotpo.com/reference/fetch-vip-tiers)
