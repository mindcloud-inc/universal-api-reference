# Get User Data with Yotpo Loyalty & Referrals

Retrieves user data from Yotpo Loyalty & Referrals.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/privacy/data`
- **Base URL:** `https://loyalty.yotpo.com`
- **Official documentation:** [Get User Data](https://loyaltyapi.yotpo.com/reference/user-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | The email address of the user to retrieve. |
