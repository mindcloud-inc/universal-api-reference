# Get Category with Yampi

Retrieves the specified category from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/catalog/categories/:id`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [Get Category](https://docs.yampi.com.br/api-reference/catalogo/categorias/visualizar-categoria)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
