# List Products with Yampi

Retrieves a list of products from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/catalog/products`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [List Products](https://docs.yampi.com.br/api-reference/catalogo/produtos/listar-produtos)

## Capabilities

This operation supports [pagination](../README.md#pagination).
