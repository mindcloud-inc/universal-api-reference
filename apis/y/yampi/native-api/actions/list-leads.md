# List Leads with Yampi

Retrieves a list of leads from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/leads`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [List Leads](https://docs.yampi.com.br/api-reference/leads/listar-leads)

## Capabilities

This operation supports [pagination](../README.md#pagination).
