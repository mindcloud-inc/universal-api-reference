# Get Authenticated User with Yampi

Retrieves the authenticated user from Yampi.

## Endpoint

- **Method:** `POST`
- **Path:** `/auth/me`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [Get Authenticated User](https://docs.yampi.com.br/api-reference/auth/auth-user-token)
