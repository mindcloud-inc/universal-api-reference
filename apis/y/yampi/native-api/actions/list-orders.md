# List Orders with Yampi

Retrieves a list of orders from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/orders`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [List Orders](https://docs.yampi.com.br/api-reference/pedidos/pedido/listar-pedidos)

## Capabilities

This operation supports [pagination](../README.md#pagination).
