# List Categories with Yampi

Retrieves a list of categories from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/catalog/categories`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [List Categories](https://docs.yampi.com.br/api-reference/catalogo/categorias/listar-categorias)

## Capabilities

This operation supports [pagination](../README.md#pagination).
