# Get Customer with Yampi

Retrieves the specified customer from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/customers/:id`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [Get Customer](https://docs.yampi.com.br/api-reference/clientes/introduction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
