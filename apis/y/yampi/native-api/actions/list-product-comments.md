# List Product Comments with Yampi

Retrieves a list of product comments from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/catalog/comments`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [List Product Comments](https://docs.yampi.com.br/api-reference/catalogo/produtos/comentarios-de-produtos/listar-comentarios-de-produtos)

## Capabilities

This operation supports [pagination](../README.md#pagination).
