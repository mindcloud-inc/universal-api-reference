# Get Brand with Yampi

Retrieves the specified brand from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/catalog/brands/:id`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [Get Brand](https://docs.yampi.com.br/api-reference/catalogo/marcas/visualizar-marca)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
