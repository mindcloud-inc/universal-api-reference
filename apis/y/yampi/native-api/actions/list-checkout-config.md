# List Checkout Config with Yampi

Retrieves the checkout configuration from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/config/checkout`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [List Checkout Config](https://docs.yampi.com.br/api-reference/configuracoes/checkout/listar-configuracao-do-checkout)
