# Get Product with Yampi

Retrieves public product details from Yampi by slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/public/catalog/products/:slug`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [Get Product](https://docs.yampi.com.br/api-reference/publico/catalogo/visualizar-informacoes-publicas-do-produto)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `slug` | path | `string` | yes |
