# List Lead Filters with Yampi

Retrieves lead search filters from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/leads/filters`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [List Lead Filters](https://docs.yampi.com.br/api-reference/leads/listar-filtros-de-busca-dos-leads)
