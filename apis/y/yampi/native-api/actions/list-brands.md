# List Brands with Yampi

Retrieves a list of brands from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/catalog/brands`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [List Brands](https://docs.yampi.com.br/api-reference/catalogo/marcas/listar-marcas)

## Capabilities

This operation supports [pagination](../README.md#pagination).
