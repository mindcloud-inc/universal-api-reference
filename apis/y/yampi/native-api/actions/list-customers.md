# List Customers with Yampi

Retrieves a list of customers from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/customers`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [List Customers](https://docs.yampi.com.br/api-reference/clientes/introduction)

## Capabilities

This operation supports [pagination](../README.md#pagination).
