# Get Order with Yampi

Retrieves the specified order from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/orders/:id`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [Get Order](https://docs.yampi.com.br/api-reference/pedidos/visualizar-detalhes-de-um-pedido)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
