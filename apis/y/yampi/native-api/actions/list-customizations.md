# List Customizations with Yampi

Retrieves a list of customizations from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/catalog/customizations`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [List Customizations](https://docs.yampi.com.br/api-reference/catalogo/customizacoes/listar-customizacoes)

## Capabilities

This operation supports [pagination](../README.md#pagination).
