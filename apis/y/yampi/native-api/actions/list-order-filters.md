# List Order Filters with Yampi

Retrieves order search filters from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/orders/filters`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [List Order Filters](https://docs.yampi.com.br/api-reference/pedidos/pedido/listar-filtros-de-busca-de-pedidos)
