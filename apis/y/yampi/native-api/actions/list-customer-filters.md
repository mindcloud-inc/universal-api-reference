# List Customer Filters with Yampi

Retrieves customer search filters from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/customers/filters`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [List Customer Filters](https://docs.yampi.com.br/api-reference/clientes/listar-filtros-de-busca-de-clientes)
