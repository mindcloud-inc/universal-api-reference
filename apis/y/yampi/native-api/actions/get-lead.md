# Get Lead with Yampi

Retrieves the specified lead from Yampi.

## Endpoint

- **Method:** `GET`
- **Path:** `/:merchantAlias/leads/:id`
- **Base URL:** `https://api.dooki.com.br/v2`
- **Official documentation:** [Get Lead](https://docs.yampi.com.br/api-reference/leads/visualizar-lead)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
