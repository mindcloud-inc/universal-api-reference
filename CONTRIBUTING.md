# Contributing

This repository is generated from MindCloud's integration catalog. Files under
`apis/`, `catalog/`, and `indexes/` are replaced during each publication, so
pull requests that edit generated content cannot be accepted.

To report incorrect or missing documentation, open an issue and include:

- the API and action name;
- the affected file or URL;
- what the reference says now;
- what it should say;
- a link to the vendor's documentation, when available.

MindCloud fixes accepted reports in the source catalog. The next publication
then updates this repository.

Report secrets, private data, or other security concerns through
[GitHub's private vulnerability reporting](https://github.com/mindcloud-inc/universal-api-reference/security/advisories/new),
not through a public issue.
